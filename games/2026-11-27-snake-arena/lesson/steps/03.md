## このステップのゴール

自分の **ヘビ** を作って、アリーナを泳がせます。ヘビは「丸い節（ふし）の行列」で、先頭の頭だけを動かし、残りの節は **前の節に引っぱられてついていく** しくみです。カメラも頭を追いかけるようにします。

## 便利な道具（小さな関数）

`const R = 1300;` の下に追加します。

```js:game.js
  const rand = (a, b) => a + Math.random() * (b - a);
  const radiusOf = (m) => Math.min(24, 7 + Math.sqrt(m) * 0.55);
  const segCountOf = (m) => Math.floor(10 + m * 0.45);
  function angDiff(a, b) { let d = b - a; while (d > Math.PI) d -= Math.PI * 2; while (d < -Math.PI) d += Math.PI * 2; return d; }

  function randInArena(margin) {
    const a = Math.random() * Math.PI * 2, d = Math.sqrt(Math.random()) * (R - margin);
    return { x: Math.cos(a) * d, y: Math.sin(a) * d };
  }
```

- `rand(a, b)` …… a 以上 b 未満のランダムな小数
- `radiusOf(m)` …… ヘビの **重さ（mass）** から太さ（半径）を決めます。重いほど太くなりますが、`Math.sqrt` なのでだんだん太りにくくなり、最大 24 で止まります
- `segCountOf(m)` …… 重さから **節の数** を決めます。重さ 20 なら 19 節です
- `angDiff(a, b)` …… 角度 a から角度 b へ、**近いほうの回り方** で何ラジアン回ればいいかを返します。角度は 360° = `Math.PI * 2` でひと回りするので、差が π（180°）より大きければひと回り分引いて、-π〜π の範囲に収めます
- `randInArena(margin)` …… アリーナの中のランダムな位置。壁から `margin` 以上はなします

> [!NOTE]
> `randInArena` で距離に `Math.sqrt(Math.random())` を使っているのは、円の中に **かたよりなく** ばらまくためです。ただの `Math.random()` だと中心のあたりに集まってしまいます（外側の輪ほど面積が広いので、外側を多めに選ぶ必要があるのです）。

## ヘビを作る：makeSnake()

`let state = ...` の上に、ヘビを入れておく変数を追加します。

```js:game.js
  let snakes = [], player = null;
```

`randInArena()` の下に `makeSnake()` と `reset()` を追加します。

```js:game.js
  function makeSnake(isPlayer, idx) {
    const pos = randInArena(500);
    const pal = ['#7dffb0', '#e6fff0'];
    const mass = 20;
    const ang = Math.atan2(-pos.y, -pos.x) + rand(-0.8, 0.8);
    const s = {
      isPlayer, name: 'あなた',
      c1: pal[0], c2: pal[1], mass, ang, target: ang, boost: false, alive: true, kills: 0,
      segs: [], dropT: 0, think: 0, wander: ang, aggro: 0,
    };
    const n = segCountOf(mass), sp = radiusOf(mass) * 0.55;
    for (let i = 0; i < n; i++) s.segs.push({ x: pos.x - Math.cos(ang) * sp * i, y: pos.y - Math.sin(ang) * sp * i });
    return s;
  }

  function reset() {
    snakes = [];
    player = makeSnake(true, 0);
    snakes.push(player);
    player.target = player.ang;
    camX = player.segs[0].x; camY = player.segs[0].y;
  }
```

ヘビは1つのオブジェクトです。おもな中身を見ておきましょう。

- `mass` …… 重さ。エサを食べると増え、これで太さと長さが決まります。長さの表示（LENGTH）もこの数字です
- `ang` …… いま向いている角度、`target` …… 向きたい角度。`ang` を `target` に少しずつ近づけて曲がります
- `segs` …… 節の座標 `{ x, y }` の配列。`segs[0]` が頭です
- `c1, c2` …… 体の2色（しましまにします）
- `boost`・`alive`・`kills`・`dropT`・`think`・`wander`・`aggro` は、このあとのステップ（ダッシュ・当たり判定・AI）で使う入れ物です。今は最初の値を入れておくだけです

体の節は、頭の位置から **向きと反対方向** に `sp`（太さの 0.55 倍）ずつずらして並べます。`ang` はアリーナの中心を向く角度（`Math.atan2(-pos.y, -pos.x)`）に、少しランダムなずれを足したものです。

`reset()` は1回のゲームの準備です。ヘビの配列を空にして自分のヘビを作り、カメラを頭の位置に合わせます。

## ヘビを動かす：moveSnake()

`// ---- simulation ----` の下、`update()` の上に追加します。

```js:game.js
  function moveSnake(s, dt) {
    const r = radiusOf(s.mass);
    const turn = 4.2 - Math.min(1.8, s.mass / 160);
    const d = angDiff(s.ang, s.target);
    const mt = turn * dt;
    s.ang += Math.abs(d) < mt ? d : Math.sign(d) * mt;
    const speed = 135;
    const h = s.segs[0];
    h.x += Math.cos(s.ang) * speed * dt;
    h.y += Math.sin(s.ang) * speed * dt;
    const sp = r * 0.55;
    for (let i = 1; i < s.segs.length; i++) {
      const a = s.segs[i - 1], b = s.segs[i];
      const dx = b.x - a.x, dy = b.y - a.y;
      const dd = Math.hypot(dx, dy);
      if (dd > sp) { const k = sp / dd; b.x = a.x + dx * k; b.y = a.y + dy * k; }
    }
  }
```

### 曲がる

`turn` は1秒に曲がれる角度（ラジアン）です。重いヘビほど少しだけ曲がりにくくなります。`angDiff` で「目標まであと何ラジアンか」を求め、1フレームに曲がれる量 `mt` を超えないように `ang` を近づけます。

### 進む

頭を `ang` の向きに `speed`（1秒に 135）だけ進めます。`Math.cos(ang)` が横、`Math.sin(ang)` が縦の成分です。

### 体がついてくる

ここがヘビらしさのひみつです。2番目の節から順に、**前の節との距離が `sp` より離れていたら、`sp` の距離まで引き寄せます**。

- `dx, dy` …… 前の節 `a` から自分 `b` への向き
- `dd` …… その距離。`sp` より長ければ、`k = sp / dd` 倍に縮めた位置へ `b` を動かします

頭が動くと2番目が引っぱられ、2番目が動くと3番目が引っぱられ……と順に伝わるので、体が頭の通った道をなめらかになぞるように動きます。

## update() を書きかえる

`update()` を次のように書きかえます。

```js:game.js
  function update(dt) {
    for (const s of snakes) if (s.alive && (state === 'play' || !s.isPlayer)) moveSnake(s, dt);
    const h = player.segs[0];
    camX += (h.x - camX) * Math.min(1, dt * 8);
    camY += (h.y - camY) * Math.min(1, dt * 8);
    const want = (Math.min(W, H * 0.8) / 380) * Math.max(0.55, 1 - (radiusOf(player.mass) - 9) * 0.028);
    camS += (want - camS) * Math.min(1, dt * 2);
  }
```

- プレイ中は自分のヘビを動かします（`state === 'play' || !s.isPlayer` は、このあと出てくる AI のヘビはタイトル画面でも動かす、という条件です）
- カメラの位置を頭へ、ステップ2の倍率と同じ書き方で近づけます。1秒に 8 倍の割合で近づくので、すばやく、でもカクッとせずについていきます
- 倍率 `want` に、**太いヘビほど引いて広く映す** 係数をかけるようにしました。大きくなると周りがよく見えるようになります（最小 0.55 倍まで）

## ヘビを描く：drawSnake()

まず `draw()` の中、壁を描いた行（`ctx.beginPath(); ctx.arc(0, 0, R + 7, ...`）と `ctx.restore();` の **間** に追加します。

```js:game.js
    // snakes (player drawn last)
    const order = snakes.filter((s) => s.alive && !s.isPlayer);
    if (player.alive) order.push(player);
    for (const s of order) drawSnake(s, x0, x1, y0, y1, t);
```

あとで出てくる AI のヘビを先に、自分のヘビを最後に描くので、自分のヘビがいつもいちばん手前に見えます。

次に、`draw()` の下に `drawSnake()` を追加します。

```js:game.js
  function drawSnake(s, x0, x1, y0, y1, t) {
    const r = radiusOf(s.mass);
    const segs = s.segs;
    for (let i = segs.length - 1; i >= 0; i--) {
      const g = segs[i];
      if (g.x < x0 - r || g.x > x1 + r || g.y < y0 - r || g.y > y1 + r) continue;
      const stripe = Math.floor(i / 4) % 2 === 0;
      ctx.fillStyle = 'rgba(0,0,0,.25)';
      ctx.beginPath(); ctx.arc(g.x + 1.5, g.y + 2.5, r, 0, Math.PI * 2); ctx.fill();
      ctx.fillStyle = stripe ? s.c1 : s.c2;
      ctx.beginPath(); ctx.arc(g.x, g.y, r, 0, Math.PI * 2); ctx.fill();
    }
    // head + eyes
    const h = segs[0];
    const ca = Math.cos(s.ang), sa = Math.sin(s.ang);
    ctx.fillStyle = s.c1;
    ctx.beginPath(); ctx.arc(h.x, h.y, r * 1.08, 0, Math.PI * 2); ctx.fill();
    for (const side of [-1, 1]) {
      const ex = h.x + ca * r * 0.35 - sa * r * 0.5 * side;
      const ey = h.y + sa * r * 0.35 + ca * r * 0.5 * side;
      ctx.fillStyle = '#fff';
      ctx.beginPath(); ctx.arc(ex, ey, r * 0.38, 0, Math.PI * 2); ctx.fill();
      ctx.fillStyle = '#1b1b2e';
      ctx.beginPath(); ctx.arc(ex + ca * r * 0.14, ey + sa * r * 0.14, r * 0.2, 0, Math.PI * 2); ctx.fill();
    }
  }
```

- 節は **しっぽから頭へ** の順に描きます。あとに描いたものが上に重なるので、頭に近い節が手前に見えます
- 画面の外にある節は `continue` で飛ばします（ステップ2の「見えている範囲だけ描く」と同じ考え方）
- `Math.floor(i / 4) % 2` で、4節ごとに `c1` と `c2` を入れかえて **しましま** にしています
- 各節の前に、少し右下にずらした半透明の黒い円を描いて **影** にしています
- 頭は少し大きめの円にして、目を2つ描きます。`ca, sa` は向いている方向、`(-sa, ca)` はそれを90度回した「横」の方向です。頭の中心から前に `r * 0.35`、横に `r * 0.5` ずらした位置に白目、そこから前に少しずらして黒目を描くので、目がいつも進む方向を見ます

## start() とループの前で reset() を呼ぶ

`start()` の最初に `reset();` を追加します。

```js:game.js
  function start() {
    reset();
    state = 'play';
    overlay.classList.add('hidden');
    msgEl.textContent = '進みたい方向をタッチ！';
  }
```

さらに、ファイルの最後の `requestAnimationFrame(frame);`（`frame()` の外の行）の上に `reset();` を追加します。

```js:game.js
  reset();
  requestAnimationFrame(frame);
```

ページを開いた時点でヘビを作っておかないと、`update()` の `player.segs[0]` でエラーになるからです。

> [!CHECK] 動作チェック
> - タイトル画面の後ろに、緑と白のしましまのヘビが止まって見える
> - スタートを押すと、ヘビが目の向いている方向へまっすぐ進み、体がそのあとをついてくる
> - 画面はヘビの頭を追いかけて動き、点のもようが流れていく
> - そのまま進むと赤い壁を通りぬけてしまう（壁の当たり判定はステップ7で作ります）
