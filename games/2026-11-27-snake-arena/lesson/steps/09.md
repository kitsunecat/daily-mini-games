## このステップのゴール

最後の仕上げです。**効果音** を Web Audio API でその場で作って鳴らし、**ハイスコア（BEST）** を `localStorage` に保存して、ページを閉じても残るようにします。これで完成品と同じゲームになります。

## ハイスコアを読みこむ

`const boostBtn = ...` の行の下に追加します。

```js:game.js
  const KEY = 'nyoro-arena-best';
  let best = 0;
  try { best = parseInt(localStorage.getItem(KEY), 10) || 0; } catch (e) { best = 0; }
  bestEl.textContent = best;
```

`localStorage` は、ブラウザにちょっとしたデータを **ずっと** 保存しておける場所です。`setItem(キー, 文字列)` で保存し、`getItem(キー)` で読み出します。

- 保存されるのは **文字列** なので、`parseInt(..., 10)` で数に直します。まだ保存されていないと `getItem` は `null` を返し、`parseInt(null)` は `NaN` になるので、`|| 0` で 0 にします
- プライベートブラウズなどでは `localStorage` が使えずエラーになることがあります。`try { ... } catch (e) { ... }` で囲んでおくと、エラーになってもゲームは止まりません
- キーの名前はほかのゲームと重ならないように、ゲームごとの名前（`nyoro-arena-best`）にしておきます

## 効果音：blip()

`drawSnake()` の下、`let flashTimer = 0;` の上に、見出しと `blip()` を追加します。

```js:game.js
  // ---- sound ----
  let actx = null;
  function blip(freq, dur, vol) {
    try {
      if (!actx) actx = new (window.AudioContext || window.webkitAudioContext)();
      const o = actx.createOscillator(), gn = actx.createGain();
      o.type = 'triangle'; o.frequency.value = freq;
      gn.gain.setValueAtTime(vol, actx.currentTime);
      gn.gain.exponentialRampToValueAtTime(0.0001, actx.currentTime + dur);
      o.connect(gn); gn.connect(actx.destination);
      o.start(); o.stop(actx.currentTime + dur + 0.02);
    } catch (e) { /* no audio */ }
  }
```

**Web Audio API** を使うと、音のファイルを用意しなくても、JavaScript で音を作れます。

- `AudioContext` …… 音の工場です。最初に音を鳴らすときに1つだけ作ります（古い Safari 用に `webkitAudioContext` も見ています）
- `createOscillator()` …… 決まった高さ（`frequency`、単位は Hz）の音を出し続ける **発振器** です。`type = 'triangle'`（三角波）は、やわらかいピコッという音になります
- `createGain()` …… 音量のつまみです。`setValueAtTime` で最初の音量にし、`exponentialRampToValueAtTime` で `dur` 秒かけてほぼ 0 まで小さくします。だんだん消えるので「ポン」と短く鳴ります（0 ちょうどにはできないので 0.0001 にします）
- 発振器 → 音量 → スピーカー（`actx.destination`）の順に `connect` でつなぎ、`start()` で鳴らし、`stop()` で止めます

音が出せない環境でもゲームが止まらないよう、全体を `try` で囲んでいます。

## 音を鳴らす場所

`eat()` の中、`pellets[i] = ...; pellets.pop();` の行の下に追加します。

```js:game.js
        if (s.isPlayer) blip(520 + Math.min(400, p.v * 60), 0.04, 0.05);
```

プレイヤーがエサを食べるたびに、短いピッという音を鳴らします。栄養の多いエサほど高い音になります（上限あり）。ライバルが食べたときは鳴らしません。

`kill()` の中、`flash(s.name + ' をたおした！');` の下に追加します。

```js:game.js
      blip(330, 0.12, 0.1); setTimeout(() => blip(660, 0.15, 0.1), 90);
```

ライバルを倒したら、低い音のあとに1オクターブ高い音（周波数が2倍）を 0.09 秒ずらして鳴らし、「ポポン！」というごほうびの音にします。

## start() と gameOver() を書きかえる

`start()` と `gameOver()` を次のように書きかえます。

```js:game.js
  function start() {
    if (actx && actx.state === 'suspended') actx.resume();
    reset();
    state = 'play';
    overlay.classList.add('hidden');
    msgEl.textContent = '進みたい方向をタッチ！';
    blip(440, 0.08, 0.06);
  }

  function gameOver(reason) {
    if (state !== 'play') return;
    state = 'dying';
    dyingT = 1.4;
    overlay.dataset.reason = reason;
    boostBtn.classList.remove('on');
    blip(180, 0.4, 0.12);
    msgEl.textContent = reason;
  }
```

- ブラウザは、ユーザーが画面にふれる前に音が鳴らないように、`AudioContext` を **一時停止（suspended）** にしていることがあります。スタートボタンを押したタイミング（ユーザーの操作の中）で `resume()` すると、音が出るようになります
- スタートで「ピッ」、やられたら低い「ブー」を鳴らします

## showOver() でハイスコアを保存する

`showOver()` 全体を次のように書きかえます。

```js:game.js
  function showOver() {
    state = 'over';
    const sc = Math.floor(player.mass);
    let nb = false;
    if (sc > best) { best = sc; nb = true; try { localStorage.setItem(KEY, String(best)); } catch (e) { /* ignore */ } }
    bestEl.textContent = best;
    ovTitle.textContent = 'ゲームオーバー';
    ovText.innerHTML = `${overlay.dataset.reason || ''}<br>長さ <b class="hl">${sc}</b>　たおした数 <b class="hl">${player.kills}</b>` +
      (nb ? '<br><b class="hl">ハイスコア更新！</b>' : `<br>ベスト ${best}`);
    startBtn.textContent = 'もう一度';
    overlay.classList.remove('hidden');
  }
```

- 今回の長さ `sc` が `best` より大きければ、`best` を更新して `localStorage` に保存し、`nb`（new best）を `true` にします
- 上の BEST の表示も更新します
- ハイスコアを更新したら「ハイスコア更新！」、そうでなければ「ベスト 〇〇」を、ゲームオーバー画面の最後に出します。`条件 ? A : B` は、条件が `true` なら A、`false` なら B になる書き方です

これで完成品と同じゲームになりました！

> [!CHECK] 動作チェック
> - スタートで「ピッ」と鳴り、エサを食べるたびに小さな音がする（スマホはマナーモードを解除）
> - ライバルを倒すと「ポポン！」と鳴る。やられると低い音が鳴る
> - 初めてのゲームオーバーで「ハイスコア更新！」と出て、上の BEST が更新される
> - 次のゲームで記録より短く終わると「ベスト 〇〇」と出て、BEST は変わらない
> - ページを再読み込みしても BEST が残っている

## 改造アイデア

> [!TIP]
> **ライバルの性格を変える**：`aiThink()` の数字を変えてみましょう。プレイヤーをねらう確率 `0.35` や距離 `260` を大きくすると、どんどん前に回りこんでくる **攻撃的なライバル** に。ヘビごとに `s.aggro`（今は使っていない入れ物）に 0〜1 の値を入れて、その値で確率を変えると、性格のちがうライバルがまざったアリーナになります。

> [!TIP]
> **アイテムを足す**：`addPellet()` と同じように、たまに **金色のスター** を置いて、取ると 5 秒間「ダッシュしても縮まない」「ほかのヘビにぶつかっても平気」などの効果をつけてみましょう。効果の残り時間は `dropT` や `think` と同じように `dt` で減らすタイマーで作れます。

> [!TIP]
> **アリーナが縮む**：`R` を `let` にして、時間とともに少しずつ小さくすると、だんだん逃げ場がなくなる **バトルロワイヤル** になります。描画・壁の判定・ミニマップはすべて `R` を使っているので、数字を1つ変えるだけで全部ついてきます。

> [!TIP]
> **見た目を変える**：`drawSnake()` で、しましまの間隔（`i / 4` の 4）を変えたり、頭に王冠を描いたり、ランキング1位のヘビだけ金色にしたりしてみましょう。`PAL` と `NAMES` を自分好みにするだけでも、ぐっと自分のゲームらしくなります。
