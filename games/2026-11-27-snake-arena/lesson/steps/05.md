## このステップのゴール

アリーナに 700 個の **光るエサ** をばらまき、ヘビが食べると **長く・太く** なるようにします。近くのエサが頭に吸いよせられる「マグネット」も入れて、食べる気持ちよさを出します。上の LENGTH にも長さを表示します。

## エサの数と色

`const R = 1300;` の下に追加します。

```js:game.js
  const PELLETS = 700;
  const PELLET_COLORS = ['#ff8787', '#ffd43b', '#69db7c', '#4dabf7', '#da77f2', '#ffa94d', '#63e6be', '#f783ac'];
```

`let snakes = [], player = null;` を、`pellets` を加えた形に書きかえます。

```js:game.js
  let snakes = [], pellets = [], player = null;
```

## エサを置く：addPellet()

`randInArena()` の下に追加します。

```js:game.js
  function addPellet(x, y, v, c) {
    if (x === undefined) { const p = randInArena(30); x = p.x; y = p.y; v = Math.random() < 0.1 ? 2 : 1; }
    pellets.push({ x, y, v, r: 3 + Math.sqrt(v) * 2.2, c: c || PELLET_COLORS[(Math.random() * PELLET_COLORS.length) | 0], ph: Math.random() * 6 });
  }
```

エサは `{ x, y, v, r, c, ph }` のオブジェクトです。

- `v` …… 栄養（食べると増える重さ）。ふつうは 1、10% の確率で 2 の大きめのエサになります
- `r` …… 見た目の半径。栄養が多いほど大きく描きます
- `c` …… 色。指定がなければ `PELLET_COLORS` からランダムに選びます
- `ph` …… 光の明滅をずらすための値（phase：位相）。全部のエサが同時にピカピカしないようにします

引数を何も渡さずに `addPellet()` と呼ぶと、`x === undefined` なのでアリーナのランダムな場所に置きます。あとのステップでは `addPellet(x, y, 栄養, 色)` のように、場所と栄養を指定して置く使い方もします（倒れたヘビが落とすエサなど）。

`reset()` の最初の行 `snakes = [];` を、次のように書きかえます。

```js:game.js
    snakes = []; pellets = [];
    for (let i = 0; i < PELLETS; i++) addPellet();
```

## 長さを重さに合わせる

`moveSnake()` の最後（体がついてくる `for` の下）に追加します。

```js:game.js
    const target = segCountOf(s.mass);
    while (s.segs.length < target) { const t = s.segs[s.segs.length - 1]; s.segs.push({ x: t.x, y: t.y }); }
    while (s.segs.length > target && s.segs.length > 10) s.segs.pop();
```

重さが増えて節が足りなくなったら、しっぽの位置に節を足します。足した節は次のフレームから「前の節に引っぱられる」しくみで自然に伸びていきます。逆に重さが減ったら（ダッシュしたときなど）、しっぽから節を減らします。ただし 10 節より短くはしません。

## エサを食べる：eat()

`moveSnake()` の下に追加します。

```js:game.js
  function eat(s) {
    const h = s.segs[0], r = radiusOf(s.mass);
    const reach = r + 30;
    for (let i = pellets.length - 1; i >= 0; i--) {
      const p = pellets[i];
      const dx = h.x - p.x, dy = h.y - p.y;
      if (Math.abs(dx) > reach || Math.abs(dy) > reach) continue;
      const d = Math.hypot(dx, dy);
      if (d < r + p.r) {
        s.mass += p.v;
        pellets[i] = pellets[pellets.length - 1]; pellets.pop();
      } else if (d < reach) {
        const k = Math.min(1, 160 / d) * 0.06; // magnet
        p.x += dx * k; p.y += dy * k;
      }
    }
  }
```

### 円と円の当たり判定

頭（半径 `r`）とエサ（半径 `p.r`）は、**中心どうしの距離が半径の合計より短ければ** 重なっています。`Math.hypot(dx, dy)` は三平方の定理で距離 `√(dx² + dy²)` を求める関数です。重なったら重さを `p.v` だけ増やし、エサを配列から取りのぞきます。

### 速く調べるくふう

エサは 700 個以上あるので、毎フレーム全部の距離を計算すると少しもったいないです。そこで先に `Math.abs(dx) > reach` のように **縦と横の差だけ** で「明らかに遠い」ものを飛ばしています。`Math.hypot` を使うのは、近くにあるものだけです。

### 配列から速く取りのぞく

`pellets[i] = pellets[pellets.length - 1]; pellets.pop();` は、「最後の要素を i 番目にコピーして、最後を捨てる」書き方です。`splice(i, 1)` だと後ろの要素を全部1つずつずらすので遅くなりますが、この方法なら一瞬です（順番は変わりますが、エサの順番はどうでもいいので問題ありません）。配列を **後ろから** 回しているので、入れかえたあとの要素を調べ忘れることもありません。

### マグネット

食べるほど近くはないけれど `reach`（半径 + 30）以内のエサは、頭のほうへ少し動かします。毎フレーム距離の 6% ほど近づくので、エサがすうっと吸いこまれるように見えます。

## update() を書きかえる

`update()` 全体を次のように書きかえます（追加したのは `eat` を呼ぶ行から、LENGTH を表示する `if` までです）。

```js:game.js
  function update(dt) {
    if (state === 'play') {
      if (input.left) input.ang -= 3.6 * dt;
      if (input.right) input.ang += 3.6 * dt;
      player.target = input.ang;
    }
    for (const s of snakes) if (s.alive && (state === 'play' || !s.isPlayer)) moveSnake(s, dt);
    for (const s of snakes) if (s.alive) eat(s);
    while (pellets.length < PELLETS) addPellet();
    if (pellets.length > 1800) pellets.splice(0, pellets.length - 1800);

    if (state === 'play') {
      const m = Math.floor(player.mass);
      scoreEl.textContent = m;
    }
    const h = player.segs[0];
    camX += (h.x - camX) * Math.min(1, dt * 8);
    camY += (h.y - camY) * Math.min(1, dt * 8);
    const want = (Math.min(W, H * 0.8) / 380) * Math.max(0.55, 1 - (radiusOf(player.mass) - 9) * 0.028);
    camS += (want - camS) * Math.min(1, dt * 2);
  }
```

- 全部の生きているヘビに `eat()` させます
- 食べられてエサが 700 個より減ったら、ランダムな場所に足して数を保ちます
- あとでヘビが倒れるとエサがどっさり増えるので、多すぎて重くならないよう 1800 個を超えたら古いものから消します
- プレイ中は、重さの整数部分を LENGTH に表示します

## エサを描く

`draw()` の中、壁を描いた行と `// snakes (player drawn last)` の **間** に追加します。

```js:game.js
    // pellets
    for (const p of pellets) {
      if (p.x < x0 || p.x > x1 || p.y < y0 || p.y > y1) continue;
      const pulse = 1 + Math.sin(t * 0.004 + p.ph) * 0.15;
      ctx.globalAlpha = 0.25;
      ctx.fillStyle = p.c;
      ctx.beginPath(); ctx.arc(p.x, p.y, p.r * 2 * pulse, 0, Math.PI * 2); ctx.fill();
      ctx.globalAlpha = 1;
      ctx.beginPath(); ctx.arc(p.x, p.y, p.r, 0, Math.PI * 2); ctx.fill();
    }
```

- 画面の外のエサは描きません
- まず、半透明（`globalAlpha = 0.25`）で2倍の大きさの円を描いて **光のにじみ** にします。その上に、不透明な本体を描きます
- `Math.sin(t * 0.004 + p.ph)` は時間とともに -1〜1 をゆっくり行き来する値です。これで光の大きさを ±15% ふくらませたり縮めたりして、エサがふわふわ光って見えます
- `globalAlpha` は描いたあと必ず 1 に戻します。戻し忘れると、ほかの絵まで半透明になってしまいます

> [!CHECK] 動作チェック
> - アリーナ一面に、色とりどりの光るエサがふわふわ明滅している
> - ヘビの頭が近づくと、エサがすうっと吸いよせられて消える
> - 食べるたびに LENGTH の数字が増え、ヘビが少しずつ長く・太くなる
> - 太くなるにつれて、カメラが少しずつ引いて広く映るようになる
