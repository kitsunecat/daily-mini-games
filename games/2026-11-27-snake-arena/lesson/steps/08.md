## このステップのゴール

ゲームを盛り上げる3つの機能を足します。

- **ダッシュ** …… 速く進めるけれど、体がだんだん縮み、しっぽからエサがこぼれる。体が光る
- **ランキング** …… 右上に、重い順の上位5匹と自分の順位を出す
- **ミニマップ** …… 左下に、アリーナ全体とヘビの位置を小さく描く

## ダッシュの計算：moveSnake()

`moveSnake()` 全体を次のように書きかえます。

```js:game.js
  function moveSnake(s, dt) {
    const r = radiusOf(s.mass);
    const turn = 4.2 - Math.min(1.8, s.mass / 160);
    const d = angDiff(s.ang, s.target);
    const mt = turn * dt;
    s.ang += Math.abs(d) < mt ? d : Math.sign(d) * mt;
    const boosting = s.boost && s.mass > 12;
    const speed = boosting ? 250 : 135;
    const h = s.segs[0];
    h.x += Math.cos(s.ang) * speed * dt;
    h.y += Math.sin(s.ang) * speed * dt;
    const sp = r * 0.55;
    for (let i = 1; i < s.segs.length; i++) {
      const a = s.segs[i - 1], b = s.segs[i];
      const dx = b.x - a.x, dy = b.y - a.y;
      const dd = Math.hypot(dx, dy);
      if (dd > sp) { const k = sp / dd; b.x = a.x + dx * k; b.y = a.y + dy * k; }
    }
    if (boosting) {
      s.mass -= 5 * dt;
      s.dropT -= dt;
      if (s.dropT <= 0) {
        s.dropT = 0.14;
        const t = s.segs[s.segs.length - 1];
        addPellet(t.x + rand(-4, 4), t.y + rand(-4, 4), 0.6, s.c1);
      }
    }
    const target = segCountOf(s.mass);
    while (s.segs.length < target) { const t = s.segs[s.segs.length - 1]; s.segs.push({ x: t.x, y: t.y }); }
    while (s.segs.length > target && s.segs.length > 10) s.segs.pop();
  }
```

- `boosting` は「ダッシュしたい」かつ「重さが 12 より大きい」ときだけ `true` です。小さすぎるヘビはダッシュできません
- ダッシュ中は速さを 135 → 250 にします
- ダッシュ中は1秒に重さ 5 ずつ減らします。重さが減ると、ステップ5で書いた「長さを重さに合わせる」しくみで、しっぽが自然に縮みます
- `dropT` は 0.14 秒のタイマーで、0 になるたびにしっぽの位置に栄養 0.6 の小さなエサを落とします。後ろのヘビに食べられてしまうので、ダッシュには「逃げ切るか、追いつくか」の駆け引きが生まれます

ライバルの AI は、ステップ6の `aiThink()` で `s.boost = true` にしていたので、ここからライバルもダッシュするようになります。

## プレイヤーのダッシュ入力

`update()` の中、`player.target = input.ang;` の下に追加します。

```js:game.js
      player.boost = input.boost || input.keyBoost || input.mouseDown;
      boostBtn.classList.toggle('on', player.boost && player.mass > 12);
```

ダッシュボタン・Space キー（↑ / W）・マウスの左ボタンのどれか1つでも押されていればダッシュです。`classList.toggle('on', 条件)` は、条件が `true` なら `on` クラスを付け、`false` なら外します。ダッシュできているときだけボタンが光ります。

`// ---- input ----` の中、`window.addEventListener('pointercancel', endPtr);` の下に、ダッシュボタンのイベントを追加します。

```js:game.js
  boostBtn.addEventListener('pointerdown', (e) => { e.preventDefault(); e.stopPropagation(); input.boost = true; });
  const endBoost = () => { input.boost = false; };
  boostBtn.addEventListener('pointerup', endBoost);
  boostBtn.addEventListener('pointercancel', endBoost);
  boostBtn.addEventListener('pointerleave', endBoost);
```

- ボタンの `pointerdown` で `e.stopPropagation()` を呼んでいます。ボタンを押したタッチが下の Canvas に伝わって、ヘビが右下へ曲がってしまうのを防ぐためです
- 指を離したとき（`pointerup`）だけでなく、指がボタンの外へずれたとき（`pointerleave`）や、タッチが取り消されたとき（`pointercancel`）もダッシュをやめます。こうしないと、押しっぱなしのままになることがあります
- スマホなら、片方の指で方向をタッチしながら、もう片方の指でダッシュボタンを押せます

`gameOver()` の中、`overlay.dataset.reason = reason;` の下に、ボタンの光を消す行を追加します。

```js:game.js
    boostBtn.classList.remove('on');
```

## ダッシュ中に体を光らせる：drawSnake()

`drawSnake()` 全体を次のように書きかえます（増えたのは `glow` の行と、`if (glow) { ... }` の部分です）。

```js:game.js
  function drawSnake(s, x0, x1, y0, y1, t) {
    const r = radiusOf(s.mass);
    const segs = s.segs;
    const glow = s.boost && s.mass > 12;
    for (let i = segs.length - 1; i >= 0; i--) {
      const g = segs[i];
      if (g.x < x0 - r || g.x > x1 + r || g.y < y0 - r || g.y > y1 + r) continue;
      const stripe = Math.floor(i / 4) % 2 === 0;
      if (glow) {
        ctx.globalAlpha = 0.25 + 0.15 * Math.sin(t * 0.02 - i * 0.5);
        ctx.fillStyle = s.c2;
        ctx.beginPath(); ctx.arc(g.x, g.y, r * 1.45, 0, Math.PI * 2); ctx.fill();
        ctx.globalAlpha = 1;
      }
      ctx.fillStyle = 'rgba(0,0,0,.25)';
      ctx.beginPath(); ctx.arc(g.x + 1.5, g.y + 2.5, r, 0, Math.PI * 2); ctx.fill();
      ctx.fillStyle = stripe ? s.c1 : s.c2;
      ctx.beginPath(); ctx.arc(g.x, g.y, r, 0, Math.PI * 2); ctx.fill();
    }
    // head + eyes
    const h = segs[0];
    const ca = Math.cos(s.ang), sa = Math.sin(s.ang);
    ctx.fillStyle = s.c1;
    ctx.beginPath(); ctx.arc(h.x, h.y, r * 1.08, 0, Math.PI * 2); ctx.fill();
    for (const side of [-1, 1]) {
      const ex = h.x + ca * r * 0.35 - sa * r * 0.5 * side;
      const ey = h.y + sa * r * 0.35 + ca * r * 0.5 * side;
      ctx.fillStyle = '#fff';
      ctx.beginPath(); ctx.arc(ex, ey, r * 0.38, 0, Math.PI * 2); ctx.fill();
      ctx.fillStyle = '#1b1b2e';
      ctx.beginPath(); ctx.arc(ex + ca * r * 0.14, ey + sa * r * 0.14, r * 0.2, 0, Math.PI * 2); ctx.fill();
    }
    if (!s.isPlayer && s.segs[0].x > x0 && s.segs[0].x < x1 && s.segs[0].y > y0 && s.segs[0].y < y1) {
      ctx.fillStyle = 'rgba(255,255,255,.75)';
      ctx.font = '11px system-ui, sans-serif';
      ctx.textAlign = 'center';
      ctx.fillText(s.name, h.x, h.y - r - 8);
    }
  }
```

ダッシュ中は、各節の下に `c2`（明るいほうの色）で 1.45 倍の大きな半透明の円を描きます。`Math.sin(t * 0.02 - i * 0.5)` で透明度を変えていて、`- i * 0.5` のおかげで節ごとに少しずつタイミングがずれるので、光が **頭からしっぽへ流れていく** ように見えます。

## ランキング：updateBoard()

`let lastT = 0, dyingT = 0;` を次のように書きかえます。

```js:game.js
  let lastT = 0, boardT = 0, dyingT = 0;
```

`update()` の下に `updateBoard()` を追加します。

```js:game.js
  function updateBoard() {
    const list = snakes.filter((s) => s.alive || s.isPlayer).sort((a, b) => b.mass - a.mass);
    const rank = list.indexOf(player) + 1;
    let html = '';
    list.slice(0, 5).forEach((s, i) => {
      html += `<li class="${s.isPlayer ? 'me' : ''}"><i style="background:${s.c1}"></i><span>${i + 1}. ${s.name}</span>${Math.floor(s.mass)}</li>`;
    });
    if (rank > 5) html += `<li class="me"><i style="background:${player.c1}"></i><span>${rank}. あなた</span>${Math.floor(player.mass)}</li>`;
    boardEl.innerHTML = html;
  }
```

- 生きているヘビ（とプレイヤー）を `sort((a, b) => b.mass - a.mass)` で **重い順** にならべます。`sort` に渡す関数が正の数を返すと `b` が前に来るので、この書き方で大きい順になります
- `indexOf(player) + 1` がプレイヤーの順位です
- 上位5匹を `<li>` にして、色の丸・順位・名前・重さを並べます。テンプレート文字列（`` ` `` で囲んだ文字列）の `${...}` には、変数や式をそのまま書けます
- プレイヤーには `me` クラスを付けて黄色く目立たせます。6位以下なら、最後に自分の行を追加します
- できた HTML を `innerHTML` で一度に入れかえます

`update()` の最後、`if (state === 'dying') ...` の **上** に追加します。

```js:game.js
    boardT -= dt;
    if (boardT <= 0) { boardT = 0.5; updateBoard(); }
```

ランキングを毎フレーム作り直すと、HTML の書きかえが多くて重くなります。`boardT` を 0.5 秒のタイマーにして、0.5 秒に1回だけ更新します。

`reset()` の最後（`kcEl.textContent = 0;` の下）にも追加して、始めた瞬間にランキングを出します。

```js:game.js
    updateBoard();
```

## ミニマップ

`draw()` の最後、`ctx.restore();` の **下**（`draw()` の閉じかっこの上）に追加します。

```js:game.js
    // minimap
    const mr = 34, mx = 12 + mr, my = H - 12 - mr;
    ctx.globalAlpha = 0.8;
    ctx.fillStyle = 'rgba(10, 12, 30, .6)';
    ctx.beginPath(); ctx.arc(mx, my, mr, 0, Math.PI * 2); ctx.fill();
    ctx.strokeStyle = 'rgba(255, 80, 90, .7)'; ctx.lineWidth = 2; ctx.stroke();
    for (const s of snakes) {
      if (!s.alive) continue;
      const h = s.segs[0];
      ctx.fillStyle = s.isPlayer ? '#ffffff' : s.c1;
      const rr = s.isPlayer ? 3.5 : 2;
      ctx.beginPath(); ctx.arc(mx + (h.x / R) * mr, my + (h.y / R) * mr, rr, 0, Math.PI * 2); ctx.fill();
    }
    ctx.globalAlpha = 1;
```

`ctx.restore()` でカメラの変形が外れたあとなので、ここからは **画面の座標** で描けます。左下に半径 34 の円を描き、ヘビの頭の位置を `h.x / R * mr` で縮めて点を打ちます（アリーナの半径 `R` が、ミニマップの半径 `mr` になる計算です）。プレイヤーは少し大きな白い点です。

> [!CHECK] 動作チェック
> - ダッシュボタン（PC は Space キーかマウスの左ボタン）を押している間、ヘビが速くなり、体がしっぽへ流れるように光る。ボタンもオレンジに光る
> - ダッシュ中は LENGTH が少しずつ減り、しっぽから小さなエサがこぼれる。LENGTH が 12 以下ではダッシュできない
> - 右上のランキングに上位5匹が重い順に並び、自分の行は黄色。6位以下なら最後に自分の順位が出る
> - 左下のミニマップに、白い点（自分）と色つきの点（ライバル）が動いている
> - ライバルもときどき光ってダッシュしている
