## このステップのゴール

ヘビを **操作** できるようにします。スマホは「進みたい方向をタッチ（指をすべらせてもOK）」、PC は「マウスの方向へ進む」と「← → キーで旋回」です。どの操作も、最後は「向きたい角度」をひとつ決めるだけ、というのがポイントです。

## 入力をためておく input

`let camX ...` の下に追加します。

```js:game.js
  const input = { ang: 0, boost: false, left: false, right: false, keyBoost: false, mouseDown: false };
```

- `ang` …… プレイヤーが向きたい角度
- `left` / `right` …… ← → キーが押されているか
- `boost` / `keyBoost` / `mouseDown` …… ダッシュの入力（ダッシュボタン・Space キー・マウスの左ボタン）。ステップ8で使いますが、キーやマウスの記録はこのステップでまとめて書いておきます

イベント（タッチやキー）が起きたときは `input` を書きかえるだけにして、ヘビを実際に動かすのは `update()` にまかせます。入力とゲームの計算を分けておくと、操作方法が増えてもゲームの計算はそのままで済みます。

## reset() で向きをそろえる

`reset()` の中の `player.target = player.ang;` の行を、次のように書きかえます。

```js:game.js
    input.ang = player.ang; player.target = player.ang;
```

ゲームを始めた瞬間に、前のゲームの向きへ急に曲がらないようにするためです。

## update() で input を使う

`update()` の最初（`function update(dt) {` のすぐ下）に追加します。

```js:game.js
  function update(dt) {
    if (state === 'play') {
      if (input.left) input.ang -= 3.6 * dt;
      if (input.right) input.ang += 3.6 * dt;
      player.target = input.ang;
    }
```

← → キーが押されている間は、1秒に 3.6 ラジアン（約 200°）ずつ `input.ang` を回します。そしてプレイヤーのヘビの `target` を `input.ang` にします。実際に曲がる速さは `moveSnake()` の `turn` で決まるので、キーでもタッチでも同じように曲がります。

## タッチとマウス：pointer イベント

`// ---- input ----` の下に追加します（`startBtn.addEventListener(...)` の **上**）。

```js:game.js
  function steerTo(clientX, clientY) {
    const r = cv.getBoundingClientRect();
    const x = clientX - r.left - r.width / 2, y = clientY - r.top - r.height / 2;
    if (x * x + y * y > 16) input.ang = player.ang + angDiff(player.ang, Math.atan2(y, x));
  }
  const touches = new Set();
  cv.addEventListener('pointerdown', (e) => {
    e.preventDefault();
    if (state !== 'play') return;
    if (e.pointerType === 'mouse') { if (e.button === 0) input.mouseDown = true; }
    else touches.add(e.pointerId);
    steerTo(e.clientX, e.clientY);
  });
  cv.addEventListener('pointermove', (e) => {
    if (state !== 'play') return;
    if (e.pointerType === 'mouse' || touches.has(e.pointerId)) steerTo(e.clientX, e.clientY);
  });
  const endPtr = (e) => { if (e.pointerType === 'mouse') input.mouseDown = false; touches.delete(e.pointerId); };
  window.addEventListener('pointerup', endPtr);
  window.addEventListener('pointercancel', endPtr);
```

### steerTo()：タッチした場所 → 角度

自分のヘビの頭は、いつも画面の **まん中** に映っています（カメラが追いかけているので）。だから「画面のまん中から、タッチした場所への向き」が、そのまま進みたい方向になります。

- `getBoundingClientRect()` で Canvas の位置を調べ、タッチ位置を「Canvas のまん中が (0, 0)」の座標 `x, y` に直します
- `Math.atan2(y, x)` で、その向きの角度が求まります
- まん中から 4px 以内（`x * x + y * y > 16` でない）のときは、向きが定まらないので無視します

`input.ang = player.ang + angDiff(player.ang, ...)` と書いているのは、← → キーで `input.ang` が 1 周以上回っていても、いまの向きから **近いほうへ** 曲がるようにするためです。

### pointer イベント

`pointerdown`・`pointermove`・`pointerup` は、マウスでもタッチでもペンでも同じように届くイベントです。`e.pointerType` で `'mouse'` か `'touch'` かを見分けられます。

- **マウス** …… 動かすだけで（ボタンを押していなくても）`pointermove` が届くので、マウスの方向へ進みます。左ボタン（`e.button === 0`）を押している間は `mouseDown` を `true` にします（ステップ8のダッシュ用）
- **タッチ** …… 指が画面にふれている間だけ `pointermove` が届きます。どの指が Canvas の上で始まったかを `touches`（**Set**：同じものを2回入れない集合）に `pointerId` で覚えておき、その指が動いたときだけ向きを変えます
- 指やボタンを離したときは、`window` で `pointerup` / `pointercancel` を受け取ります。Canvas の外で離しても取りこぼしません
- `pointerdown` の `e.preventDefault()` は、タッチしたときのスクロールや文字選択などのブラウザ標準の動きを止めます

## キーボード

`keydown` のイベントを、次のように書きかえます。その下に `keyup` と `blur` も追加します。

```js:game.js
  window.addEventListener('keydown', (e) => {
    const k = e.key;
    if ((k === 'Enter' || k === ' ') && state !== 'play' && state !== 'dying') { e.preventDefault(); start(); return; }
    if (k === 'ArrowLeft' || k === 'a' || k === 'A') { input.left = true; e.preventDefault(); }
    if (k === 'ArrowRight' || k === 'd' || k === 'D') { input.right = true; e.preventDefault(); }
    if (k === ' ' || k === 'ArrowUp' || k === 'w' || k === 'W') { input.keyBoost = true; e.preventDefault(); }
  });
  window.addEventListener('keyup', (e) => {
    const k = e.key;
    if (k === 'ArrowLeft' || k === 'a' || k === 'A') input.left = false;
    if (k === 'ArrowRight' || k === 'd' || k === 'D') input.right = false;
    if (k === ' ' || k === 'ArrowUp' || k === 'w' || k === 'W') input.keyBoost = false;
  });
  window.addEventListener('blur', () => { input.left = input.right = input.keyBoost = input.boost = input.mouseDown = false; });
```

- キーを押したら `true`、離したら `false` にするだけです。こうしておくと「押しっぱなし」を `update()` で毎フレーム調べられます
- ← → のほか、A / D キーでも旋回できます。Space・↑・W はダッシュ（ステップ8）です
- `e.preventDefault()` で、矢印キーや Space でページがスクロールするのを止めます
- `blur` は、ウィンドウからフォーカスが外れたとき（別のアプリに切りかえたときなど）に届きます。そのときキーを離したことが伝わらず「押しっぱなし」になるのを防ぐため、全部 `false` に戻します

> [!CHECK] 動作チェック
> - スマホ：画面の右上をタッチすると、ヘビが右上へ曲がっていく。指をすべらせると、その方向へついてくる
> - PC：マウスを動かすと、ヘビがマウスの方向へ曲がる。← → キー（A / D）を押している間はぐるっと旋回する
> - 指を画面のまん中（自分の頭のあたり）に置いても、ヘビがおかしな方向へ急に曲がらない
> - 矢印キーや Space でページがスクロールしない
