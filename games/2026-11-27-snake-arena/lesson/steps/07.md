## このステップのゴール

このゲームの心臓部、**当たり判定** を作ります。ルールは「**頭** がほかのヘビの **体** にぶつかったら、ぶつかったほうがアウト」と「壁にぶつかったらアウト」です。倒れたヘビは体のあとに **エサをどっさり** 落とし、ライバルは少したつと別の場所に生まれ変わります。プレイヤーがやられたらゲームオーバー画面を出し、「もう一度」で遊び直せるようにします。

## 状態の変数

`let lastT = 0;` を次のように書きかえます。

```js:game.js
  let lastT = 0, dyingT = 0;
```

`dyingT` は、やられてからゲームオーバー画面を出すまでの残り時間です。

`reset()` の `camX = ...` の行の下に、たおした数のリセットを追加します。

```js:game.js
    kcEl.textContent = 0;
```

## ヘビが倒れる：kill() と respawnAI()

`eat()` の下に追加します。

```js:game.js
  function kill(s, killer) {
    s.alive = false;
    const n = s.segs.length;
    const total = s.mass * 0.85;
    const step = 2;
    const cnt = Math.ceil(n / step);
    const v = Math.max(1, total / cnt);
    for (let i = 0; i < n; i += step) {
      const g = s.segs[i];
      addPellet(g.x + rand(-6, 6), g.y + rand(-6, 6), v, Math.random() < 0.5 ? s.c1 : s.c2);
    }
    if (killer) killer.kills++;
    if (killer === player) {
      kcEl.textContent = player.kills;
      flash(s.name + ' をたおした！');
    }
    if (!s.isPlayer) setTimeout(() => { if (state === 'play' || state === 'dying') respawnAI(s); }, 2200);
  }

  function respawnAI(dead) {
    const i = snakes.indexOf(dead);
    if (i < 0) return;
    snakes[i] = makeSnake(false, (Math.random() * PAL.length) | 0);
  }
```

### エサに変わる

倒れたヘビの重さの 85% を、体の上に **1節おき** にエサとしてばらまきます。1個あたりの栄養 `v` は「重さの 85% ÷ エサの個数」です（最低 1）。大きなヘビを倒すほど、大きなエサがたくさん落ちます。色は体の2色をランダムに使うので、ヘビの形のままエサが光ります。

### たおした数とメッセージ

`killer` は「誰の体にぶつかって倒れたか」です（壁なら `null`）。`killer` がプレイヤーなら、左上の「たおした数」を増やし、下のメッセージに「〇〇 をたおした！」と出します（`flash()` はこのあと作ります）。

### 生まれ変わり

ライバルは `setTimeout` で 2.2 秒後に `respawnAI()` を呼び、配列の **同じ場所** に新しいヘビを作ります。こうするとライバルの数がいつも 11 匹に保たれます。そのころにはゲームオーバーで遊び直しているかもしれないので、`state` がプレイ中かやられた直後のときだけ生まれ変わらせます。

## ぶつかったか調べる：collisions()

`respawnAI()` の下に追加します。

```js:game.js
  function collisions() {
    for (const s of snakes) {
      if (!s.alive) continue;
      const h = s.segs[0], r = radiusOf(s.mass);
      if (Math.hypot(h.x, h.y) + r > R) { kill(s, null); if (s.isPlayer) gameOver('壁にぶつかった！'); continue; }
      for (const o of snakes) {
        if (o === s || !o.alive) continue;
        const or = radiusOf(o.mass);
        const lim = (r * 0.7 + or) ** 2;
        const oh = o.segs[0];
        const bound = o.segs.length * or * 0.55 + r + or;
        if (Math.abs(oh.x - h.x) > bound || Math.abs(oh.y - h.y) > bound) continue;
        let hit = false;
        for (let i = 1; i < o.segs.length; i++) {
          const g = o.segs[i];
          const dx = g.x - h.x, dy = g.y - h.y;
          if (dx * dx + dy * dy < lim) { hit = true; break; }
        }
        if (hit) {
          kill(s, o);
          if (s.isPlayer) gameOver(o.name + ' にぶつかった！');
          break;
        }
      }
    }
  }
```

全部の生きているヘビ `s` について、次の2つを調べます。

- **壁** …… 中心から頭までの距離に頭の半径を足して、`R` を超えたらアウトです
- **ほかのヘビ `o` の体** …… 頭と、`o` の体の各節（`i = 1` から。相手の **頭** はふくめません）が重なっていればアウトです

頭どうしの正面衝突は判定しないので、ぶつかったときは「相手の体に先にふれたほう」が負けになります。これがこのゲームの駆け引きです。

重なりの判定は円と円ですが、自分の頭の半径を `r * 0.7` と少し小さめにしています。見た目より少しだけ判定を甘くすると、「今のはかすっただけなのに！」という理不尽さが減ります。ここでも、まず頭どうしの距離が体の長さ（`bound`）より遠ければ飛ばして、計算を減らしています。

1匹のヘビがアウトになったら `break` して、次のヘビの判定に進みます。

## ゲームオーバー：gameOver() と showOver()

`start()` の下に追加します。

```js:game.js
  function gameOver(reason) {
    if (state !== 'play') return;
    state = 'dying';
    dyingT = 1.4;
    overlay.dataset.reason = reason;
    msgEl.textContent = reason;
  }

  function showOver() {
    state = 'over';
    const sc = Math.floor(player.mass);
    ovTitle.textContent = 'ゲームオーバー';
    ovText.innerHTML = `${overlay.dataset.reason || ''}<br>長さ <b class="hl">${sc}</b>　たおした数 <b class="hl">${player.kills}</b>`;
    startBtn.textContent = 'もう一度';
    overlay.classList.remove('hidden');
  }
```

- `gameOver(reason)` は、やられた瞬間に呼ばれます。すぐにゲームオーバー画面を出すのではなく、状態を `dying` にして 1.4 秒待ちます。そのあいだ、自分のヘビがエサに変わる様子や、ライバルが集まってくる様子が見えます
- やられた理由は `overlay.dataset.reason` に入れておきます。`dataset` は HTML 要素に好きなデータを持たせられる入れ物です（`data-reason` 属性になります）
- `showOver()` は、タイトル画面と同じオーバーレイの文字を書きかえて表示します。ボタンの文字は「もう一度」にします。押すとステップ1の `start()` が呼ばれ、`reset()` で最初からになります
- `if (state !== 'play') return;` は、同じフレームで2回呼ばれても1回分しか処理しないための用心です

## メッセージをしばらく出す：flash()

`// ---- flow ----` の上に追加します。

```js:game.js
  let flashTimer = 0;
  function flash(text) {
    msgEl.textContent = text;
    clearTimeout(flashTimer);
    flashTimer = setTimeout(() => { if (state === 'play') msgEl.textContent = 'ほかのヘビの前に回りこもう'; }, 1600);
  }
```

メッセージを出して、1.6 秒後に「ほかのヘビの前に回りこもう」に戻します。続けて2匹倒したときに前のタイマーで早く消えてしまわないよう、`clearTimeout` で前のタイマーを取り消してから、新しいタイマーをセットします。

## update() に当たり判定を入れる

`update()` の中、`eat()` を呼ぶ行の下に追加します。

```js:game.js
    if (state === 'play') collisions();
    else for (const s of snakes) if (!s.isPlayer && s.alive) { // AIs keep living after player death
      const h = s.segs[0];
      if (Math.hypot(h.x, h.y) + radiusOf(s.mass) > R) kill(s, null);
    }
```

プレイ中は `collisions()` で全部の判定をします。プレイヤーがやられたあと（`dying` や `over`、タイトル画面）も、ライバルは泳ぎつづけるので、壁の判定だけはしておきます。

さらに `update()` の最後（`camS += ...` の行の下）に、1行あけて追加します。

```js:game.js

    if (state === 'dying') { dyingT -= dt; if (dyingT <= 0) showOver(); }
```

> [!CHECK] 動作チェック
> - 壁にまっすぐ突っこむと、ヘビが消えてエサに変わり、下に「壁にぶつかった！」と出る。1.4 秒後に「ゲームオーバー」画面が出て、理由・長さ・たおした数が表示される
> - ライバルの体に頭からぶつかると、「〇〇 にぶつかった！」でゲームオーバーになる
> - ライバルの進む先に回りこんで自分の体にぶつけさせると、ライバルがエサの列に変わり、「〇〇 をたおした！」と出て、左上のたおした数が増える
> - 「もう一度」（または Enter キー）で、たおした数 0・LENGTH 20 前後から遊び直せる
