## このステップのゴール

アリーナに **11匹のライバル** を放ちます。ライバルは自分で考えて動く **AI** で、「近くのおいしそうなエサへ向かう」「自分より小さいプレイヤーの前に回りこむ」「ぶつかりそうなら よける」「壁に近づいたら中へ戻る」をくり返します。頭の上には名前も出します。

## ライバルの数・色・名前

`const R = 1300;` の下（`const PELLETS` の上）に追加します。

```js:game.js
  const AI_COUNT = 11;
  const PAL = [
    ['#ff6b6b', '#ffb3b3'], ['#4dabf7', '#a5d8ff'], ['#ffd43b', '#fff3bf'], ['#b197fc', '#e5dbff'],
    ['#69db7c', '#d3f9d8'], ['#ff922b', '#ffd8a8'], ['#f783ac', '#ffdeeb'], ['#3bc9db', '#c5f6fa'],
    ['#a9e34b', '#e9fac8'], ['#e599f7', '#f8f0fc'], ['#ffa8a8', '#fff5f5'], ['#74c0fc', '#e7f5ff'],
  ];
  const NAMES = ['にょろ太', 'ぺこ', 'スピン', 'ミント', 'ごま', 'トマト', 'ルル', 'ぽてと', 'ジグ', 'サバ', 'もち', 'くるり', 'ポン', 'ラムネ'];
```

`PAL` は体の2色の組み合わせ、`NAMES` はライバルの名前の候補です。

## 名前を選ぶ：pickName()

`addPellet()` の下に追加します。

```js:game.js
  function pickName() {
    const used = new Set(snakes.filter((o) => o.alive).map((o) => o.name));
    const free = NAMES.filter((n) => !used.has(n));
    const pool = free.length ? free : NAMES;
    return pool[(Math.random() * pool.length) | 0];
  }
```

いま生きているヘビが使っている名前を `Set` に集め、使われていない名前から選びます。同じ名前のヘビが2匹いると、ランキングでまぎらわしいからです（全部使われていたら、しかたなく全部から選びます）。

## makeSnake() を書きかえる

`makeSnake()` 全体を次のように書きかえます。

```js:game.js
  function makeSnake(isPlayer, idx) {
    let pos;
    for (let tries = 0; tries < 30; tries++) {
      pos = isPlayer ? randInArena(500) : randInArena(250);
      if (isPlayer || !player || Math.hypot(pos.x - player.segs[0].x, pos.y - player.segs[0].y) > 450) break;
    }
    const pal = isPlayer ? ['#7dffb0', '#e6fff0'] : PAL[idx % PAL.length];
    const mass = isPlayer ? 20 : rand(14, 90);
    const ang = Math.atan2(-pos.y, -pos.x) + rand(-0.8, 0.8);
    const s = {
      isPlayer, name: isPlayer ? 'あなた' : pickName(),
      c1: pal[0], c2: pal[1], mass, ang, target: ang, boost: false, alive: true, kills: 0,
      segs: [], dropT: 0, think: 0, wander: ang, aggro: 0,
    };
    const n = segCountOf(mass), sp = radiusOf(mass) * 0.55;
    for (let i = 0; i < n; i++) s.segs.push({ x: pos.x - Math.cos(ang) * sp * i, y: pos.y - Math.sin(ang) * sp * i });
    return s;
  }
```

- **出てくる場所** …… プレイヤーは壁から 500、ライバルは 250 以上はなれた場所です。ライバルがプレイヤーのすぐ近く（450 以内）に出てくると、いきなりぶつかって不公平なので、最大 30 回まで場所を選び直します
- **色** …… `idx % PAL.length` で、何番目のライバルかによって色を変えます
- **重さ** …… プレイヤーは 20 から、ライバルは 14〜90 のランダムです。最初から大きいライバルもいるので、アリーナがにぎやかになります
- **名前** …… プレイヤーは「あなた」、ライバルは `pickName()` で選びます

`reset()` の `snakes.push(player);` の下に、ライバルを作る行を追加します。

```js:game.js
    for (let i = 0; i < AI_COUNT; i++) snakes.push(makeSnake(false, i));
```

## 危ない場所か調べる：dangerAt()

`reset()` の下、`// ---- simulation ----` の上に、見出しと `dangerAt()` を追加します。

```js:game.js
  // ---- AI ----
  function dangerAt(s, x, y, pad) {
    if (Math.hypot(x, y) > R - 40) return true;
    for (const o of snakes) {
      if (!o.alive || o === s) continue;
      const or = radiusOf(o.mass) + pad;
      const h = o.segs[0];
      if (Math.abs(h.x - x) > 600 || Math.abs(h.y - y) > 600) {
        // quick reject using head distance vs length bound
        const bound = o.segs.length * radiusOf(o.mass) * 0.55 + 40;
        if (Math.hypot(h.x - x, h.y - y) > bound) continue;
      }
      for (let i = 0; i < o.segs.length; i += 2) {
        const g = o.segs[i];
        const dx = g.x - x, dy = g.y - y;
        if (dx * dx + dy * dy < or * or) return true;
      }
    }
    return false;
  }
```

点 `(x, y)` が「壁の近く」か「ほかのヘビの体の近く」なら `true` を返します。AI はこれを使って、進む先が安全かどうかを調べます。

- `o === s` で自分自身は調べません
- 遠くのヘビは、頭の位置と「体の長さの最大値（`bound`）」だけで先に飛ばします。頭からの距離が体の長さより遠ければ、体のどこにもふれようがないからです
- 体は `i += 2` で **1つおき** に調べます。節どうしは重なるくらい近いので、1つおきでも十分で、計算は半分になります
- ここでも距離は `dx * dx + dy * dy < or * or` と **2乗のまま** くらべています。`Math.sqrt` を使わなくても大小は同じなので、少し速くなります

## AI の考え：aiThink()

`dangerAt()` の下に追加します。

```js:game.js
  function aiThink(s, dt) {
    const h = s.segs[0];
    const r = radiusOf(s.mass);
    s.think -= dt;
    if (s.think <= 0) {
      s.think = rand(0.15, 0.35);
      s.boost = false;
      const dc = Math.hypot(h.x, h.y);
      if (dc > R - 220) {
        s.target = Math.atan2(-h.y, -h.x) + rand(-0.4, 0.4);
      } else {
        // hunt the player sometimes when bigger
        let goal = null;
        if (player.alive && s.mass > player.mass * 0.8) {
          const ph = player.segs[0];
          const d = Math.hypot(ph.x - h.x, ph.y - h.y);
          if (d < 260 && Math.random() < 0.35) {
            goal = { x: ph.x + Math.cos(player.ang) * 90, y: ph.y + Math.sin(player.ang) * 90 };
            if (s.mass > 30 && Math.random() < 0.4) s.boost = true;
          }
        }
        if (!goal) {
          let bestScore = -1;
          for (const p of pellets) {
            const dx = p.x - h.x, dy = p.y - h.y;
            if (Math.abs(dx) > 320 || Math.abs(dy) > 320) continue;
            const d = Math.hypot(dx, dy) + 1;
            const a = Math.abs(angDiff(s.ang, Math.atan2(dy, dx)));
            const sc = (p.v * p.v) / (d * (1 + a));
            if (sc > bestScore) { bestScore = sc; goal = p; }
          }
          if (goal && goal.v >= 3 && s.mass > 25 && Math.random() < 0.25) s.boost = true;
        }
        if (goal) s.target = Math.atan2(goal.y - h.y, goal.x - h.x);
        else { s.wander += rand(-0.6, 0.6); s.target = s.wander; }
      }
    }
    // avoidance each frame
    let blocked = false;
    for (const k of [r * 2.2, r * 4.5, r * 7]) {
      if (dangerAt(s, h.x + Math.cos(s.ang) * k, h.y + Math.sin(s.ang) * k, r + 4)) { blocked = true; break; }
    }
    if (blocked) {
      const opts = [0.9, -0.9, 1.8, -1.8, 2.8];
      let chosen = null;
      for (const o of opts) {
        const a = s.ang + o;
        if (!dangerAt(s, h.x + Math.cos(a) * r * 4, h.y + Math.sin(a) * r * 4, r + 4)) { chosen = a; break; }
      }
      s.target = chosen === null ? s.ang + 2.5 : chosen;
      s.think = 0.25;
      s.boost = false;
    }
  }
```

### ときどき考える

毎フレーム行き先を考え直すと動きがせわしなくなるうえ、計算も重くなります。そこで `s.think` を 0.15〜0.35 秒のタイマーにして、0 になったときだけ行き先（`s.target`）を決め直します。ヘビごとにタイマーがばらばらなので、動きも自然になります。

行き先は、上から順に次のように決めます。

1. **壁が近い**（中心から `R - 220` より外）…… 中心のほうへ向かいます
1. **プレイヤーより大きく、近くにいる** …… 35% の確率で、プレイヤーの頭の **90 先**（進む先）をねらいます。前に回りこんで、プレイヤーを自分の体にぶつけさせる作戦です。ときどきダッシュもします
1. **エサをさがす** …… 近く（縦横 320 以内）のエサに点数をつけて、いちばん高いものへ向かいます。点数は `栄養² ÷ (距離 × (1 + 向きのずれ))` で、**栄養が多いほど・近いほど・正面にあるほど** 高くなります。栄養 3 以上のごちそうならダッシュすることもあります
1. **何も見つからない** …… `wander`（ぶらぶら歩きの向き）を少しずつランダムに変えて進みます

### 毎フレームよける

行き先とは別に、**毎フレーム** 進む先の3か所（太さの 2.2 倍・4.5 倍・7 倍先）を `dangerAt()` で調べます。どこか1か所でも危なければ、右 0.9・左 0.9・右 1.8・左 1.8・2.8 ラジアンの順に「その向きなら安全か」を試し、最初に見つかった安全な向きへ曲がります。どれもだめなら、大きく 2.5 ラジアン曲がります。

よけたあとは `think = 0.25` にして、0.25 秒は行き先を考え直さないようにします。すぐにまた危ない方向へ戻らないようにするためです。

> [!NOTE]
> この AI は「点数をつけていちばんよいものを選ぶ」「行動に優先順位をつける」「ときどきランダムにする」という、ゲームの AI でよく使う考え方の組み合わせです。数字を変えると、性格の違うライバルが作れます。

## update() で AI を考えさせる

`update()` の中、`moveSnake()` を呼ぶ `for` の **上** に追加します。

## 名前を表示する

`drawSnake()` の最後、目を描く `for` の **下** に追加します。

```js:game.js
    if (!s.isPlayer && s.segs[0].x > x0 && s.segs[0].x < x1 && s.segs[0].y > y0 && s.segs[0].y < y1) {
      ctx.fillStyle = 'rgba(255,255,255,.75)';
      ctx.font = '11px system-ui, sans-serif';
      ctx.textAlign = 'center';
      ctx.fillText(s.name, h.x, h.y - r - 8);
    }
```

頭が画面の中にあるライバルだけ、頭の少し上に名前を書きます。`ctx.textAlign = 'center'` にすると、指定した x 座標が文字の **まん中** になります。
