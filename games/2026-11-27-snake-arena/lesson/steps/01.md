## このステップのゴール

3つのファイルを用意して、ゲーム画面の土台を作ります。上に「← 一覧・LENGTH・BEST」、まん中にアリーナを描く **Canvas**、その上に重ねる「たおした数」「ランキング」「ダッシュボタン」とタイトル画面（オーバーレイ）、いちばん下にメッセージを置きます。スタートを押すとタイトル画面が消えるところまで作ります。

完成すると、こんなゲームになります。

- 丸い **アリーナ** の中を、自分のヘビ（緑）が泳ぎまわる。進みたい方向を **タッチ**（PC はマウスの方向）すると曲がる
- 光る **エサ** を食べると体が長くなり、太くなる。長さ（LENGTH）がスコア
- アリーナには **11匹のライバル（AI）** がいて、エサを探したり、こちらの前に回りこもうとしたりする
- **頭** がほかのヘビの **体** にぶつかるとアウト。逆に相手をこちらの体にぶつけさせれば、倒れたヘビが **エサをどっさり** 落とす
- **ダッシュ** すると速くなるけれど、少しずつ縮む。外周の **赤い壁** にぶつかってもアウト

- `<meta name="viewport" ...>` はスマホで画面幅に合わせて表示し、ピンチで拡大されないようにする設定です
- JavaScript から書きかえる場所には `id`（`score`・`best`・`kc`・`board`・`msg`・`ov-title`・`ov-text` など）をつけておきます
- `<canvas id="cv">` がゲームの絵を描く場所です。アリーナ・エサ・ヘビ・ミニマップはすべてここに JavaScript で描きます
- `#board`（右上のランキング）・`#kills`（左上のたおした数）・`#boost`（右下のダッシュボタン）は、Canvas の **上に重ねる HTML** です。文字は HTML で出したほうが、くっきり読みやすく作るのもかんたんです
- `#overlay` はタイトル画面とゲームオーバー画面を兼ねた「ふた」で、ステージの上に重ねて表示します
- 「← 一覧」のリンク先はこのサイトのトップです。自分のフォルダで作るときは好きなページに変えてかまいません
- `<script>` を `</body>` の直前に置くと、HTML の要素がすべて読みこまれてから JavaScript が動きます

- `#cv` は `width: 100%; height: 100%` で `#stage` いっぱいに広げます。Canvas の **中の解像度** はステップ2で JavaScript から合わせます
- `touch-action: none` は、スマホで画面を触ったときにスクロールやズームが起きないようにする設定です。指をすべらせてヘビを操るゲームなので大事です

- `#board` と `#kills` には `pointer-events: none` をつけています。ランキングの上をタッチしても、その下の Canvas に指が届くようにするためです
- `#boost.on` は押されているダッシュボタンの見た目です（ステップ8で JavaScript から `on` を付け外しします）
- `#overlay.hidden { display: none; }` のように、クラスを1つ付けるだけで表示を切りかえられるようにしておきます

## game.js

JavaScript はまず「スタートでタイトル画面を消す」だけを書きます。あとで使う要素も、ここでまとめて取り出しておきます。

```js:game.js
(() => {
  'use strict';
  const cv = document.getElementById('cv');
  const ctx = cv.getContext('2d');
  const stage = document.getElementById('stage');
  const $ = (id) => document.getElementById(id);
  const scoreEl = $('score'), bestEl = $('best'), kcEl = $('kc'), boardEl = $('board');
  const overlay = $('overlay'), ovTitle = $('ov-title'), ovText = $('ov-text'), startBtn = $('start');
  const boostBtn = $('boost'), msgEl = $('msg');

  let state = 'title';   // title | play | dying | over

  // ---- flow ----
  function start() {
    state = 'play';
    overlay.classList.add('hidden');
    msgEl.textContent = '進みたい方向をタッチ！';
  }

  // ---- input ----
  startBtn.addEventListener('click', start);
  overlay.addEventListener('pointerdown', (e) => { if (e.target === overlay) { e.preventDefault(); start(); } });
  window.addEventListener('keydown', (e) => {
    const k = e.key;
    if ((k === 'Enter' || k === ' ') && state !== 'play' && state !== 'dying') { e.preventDefault(); start(); return; }
  });
})();
```

### 全体を (() => { ... })(); で囲む

ファイル全体を「すぐ実行される関数」で囲むと、中で作った変数がページ全体（グローバル）に漏れません。`'use strict';` は、うっかりミスをエラーとして教えてくれるモードです。

- `cv` は Canvas の要素、`ctx` は Canvas に絵を描くための **2D コンテキスト**（ペンのようなもの）です
- `const $ = (id) => document.getElementById(id);` は、何度も書く `document.getElementById` を短く書くための小さな関数です
- `state` はゲームの状態です。`'title'`（タイトル画面）→ `'play'`（プレイ中）→ `'dying'`（やられた直後の演出）→ `'over'`（ゲームオーバー画面）と変わっていきます。今は `title` と `play` だけ使います

### start() とスタートの受け付け

- `start()` はゲームを始める関数です。今は状態を `play` にして、オーバーレイに `hidden` クラスをつけて隠すだけです。ここに少しずつ処理を足していきます
- オーバーレイの `pointerdown` は「ボタン以外の場所を押してもスタート」するためのものです。`e.target === overlay` で、文字やボタンではなく **オーバーレイそのもの** を押したときだけ反応させます
- キーボードでは Enter か Space でスタートできます。`state !== 'play' && state !== 'dying'` で、プレイ中に押しても始め直さないようにしています

> [!NOTE]
> 関数は `// ---- flow ----` のような見出しコメントで区切っていきます。このあと「〇〇の **下** に追加」「〇〇を **書きかえる**」という指示が出てくるので、見出しを目印にして正しい場所に入れましょう。
