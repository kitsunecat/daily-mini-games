## このステップのゴール

盤面を「宝石のデータが入った2次元配列」として作り、6種類の宝石を色と形を変えて Canvas に描きます。最初から3つそろっている場所ができないように並べるのもポイントです。

## 色の定義

`const N = 8;` の **下** に、宝石の種類数と色を追加します。

```js:game.js
  const COLORS = 6;
  const PALETTE = [
    ['#ff5f7e', '#c2184b'], // ハート系の赤（丸）
    ['#ffb238', '#c76a00'], // オレンジ（ひし形）
    ['#ffe45c', '#b49b00'], // 黄（星）
    ['#4cd97b', '#14843d'], // 緑（四角）
    ['#4cb8ff', '#1462b4'], // 青（しずく型の三角）
    ['#c27dff', '#6b2fb3'], // 紫（六角形）
  ];
```

宝石の種類は 0〜5 の番号で表し、`PALETTE[番号]` に「明るい色・暗い色」の2色を入れておきます。2色あると上から下へのグラデーションで立体感が出せます。色だけでなく **形も種類ごとに変える** と、色の見分けが苦手な人でも遊びやすくなります。

## 盤面のデータ

`let size = 0, cell = 0, dpr = 1;` の **下** に1行追加します。

```js:game.js
  let grid = [];
```

続けて、`// ---------- 描画 ----------` の **上** に盤面のブロックを追加します。

```js:game.js
  // ---------- 盤面 ----------
  const rnd = (n) => Math.floor(Math.random() * n);
  const gem = (t, s) => ({ t, s: s || 0, dy: 0, scale: 1 });
  const inside = (r, c) => r >= 0 && r < N && c >= 0 && c < N;

  function newBoard() {
    grid = [];
    for (let r = 0; r < N; r++) {
      grid.push([]);
      for (let c = 0; c < N; c++) {
        let t;
        do { t = rnd(COLORS); } while (
          (c >= 2 && grid[r][c - 1].t === t && grid[r][c - 2].t === t) ||
          (r >= 2 && grid[r - 1][c].t === t && grid[r - 2][c].t === t)
        );
        grid[r].push(gem(t));
      }
    }
  }
```

### 2次元配列で盤面を表す

`grid[r][c]` が「上から r 行目・左から c 列目」の宝石です。配列の中に配列を入れた形なので **2次元配列** と呼びます。Canvas 上の位置は `x = c * cell`、`y = r * cell` で求められます（列が x、行が y なので順番に注意）。

### 宝石は小さなオブジェクト

`gem(t, s)` は宝石1個ぶんのオブジェクトを作る関数です。

- `t` … 種類（0〜5）
- `s` … 特殊ジェムの種類（ステップ7で使います。今はいつも 0）
- `dy` … 落ちてくる途中の「ずれ」（ステップ6で使います）
- `scale` … 消えるときに小さくするための拡大率（ステップ6で使います）

アロー関数で `({ ... })` とカッコで囲んでいるのは、`{` がオブジェクトの始まりであって関数の本体ではないことを JavaScript に伝えるためです。

### 最初から3つそろわないように並べる

`do { ... } while (条件)` は「まず1回実行して、条件が真のあいだ繰り返す」ループです。ランダムに選んだ色 `t` が、

- 左の2つ（`c - 1` と `c - 2`）と同じ色、または
- 上の2つ（`r - 1` と `r - 2`）と同じ色

になってしまったら選び直します。左上から順に置いていくので、右や下はまだ空っぽで、左と上だけ調べれば十分です。

`inside(r, c)` は、その場所が盤面の中かどうかを調べる関数です。あとで何度も使います。

## 宝石を描く

`resize()` 関数の **後ろ** に、図形を作る関数と宝石を描く関数を追加します。

```js:game.js
  function shapePath(t, cx, cy, R) {
    ctx.beginPath();
    if (t === 0) { ctx.arc(cx, cy, R, 0, Math.PI * 2); }
    else if (t === 1) { ctx.moveTo(cx, cy - R); ctx.lineTo(cx + R, cy); ctx.lineTo(cx, cy + R); ctx.lineTo(cx - R, cy); }
    else if (t === 2) {
      for (let i = 0; i < 10; i++) {
        const rr = i % 2 ? R * 0.48 : R * 1.05;
        const a = -Math.PI / 2 + i * Math.PI / 5;
        ctx.lineTo(cx + Math.cos(a) * rr, cy + Math.sin(a) * rr);
      }
    }
    else if (t === 3) { const s = R * 0.85; roundRect(cx - s, cy - s, s * 2, s * 2, R * 0.3); }
    else if (t === 4) { ctx.moveTo(cx, cy - R); ctx.lineTo(cx + R * 0.95, cy + R * 0.75); ctx.lineTo(cx - R * 0.95, cy + R * 0.75); }
    else {
      for (let i = 0; i < 6; i++) {
        const a = Math.PI / 6 + i * Math.PI / 3;
        ctx.lineTo(cx + Math.cos(a) * R, cy + Math.sin(a) * R);
      }
    }
    ctx.closePath();
  }
  function roundRect(x, y, w, h, r) {
    ctx.moveTo(x + r, y);
    ctx.arcTo(x + w, y, x + w, y + h, r);
    ctx.arcTo(x + w, y + h, x, y + h, r);
    ctx.arcTo(x, y + h, x, y, r);
    ctx.arcTo(x, y, x + w, y, r);
  }

  function drawGem(g, x, y, scale) {
    const cx = x + cell / 2, cy = y + cell / 2;
    const R = cell * 0.38 * scale;
    if (R <= 0.5) return;
    const [light, dark] = PALETTE[g.t];
    const grad = ctx.createLinearGradient(cx, cy - R, cx, cy + R);
    grad.addColorStop(0, light); grad.addColorStop(1, dark);
    shapePath(g.t, cx, cy, R);
    ctx.fillStyle = grad; ctx.fill();
    ctx.lineWidth = Math.max(1, cell * 0.03);
    ctx.strokeStyle = 'rgba(255,255,255,.55)'; ctx.stroke();
    // ツヤ
    ctx.fillStyle = 'rgba(255,255,255,.35)';
    ctx.beginPath(); ctx.ellipse(cx - R * 0.3, cy - R * 0.4, R * 0.28, R * 0.16, -0.5, 0, Math.PI * 2); ctx.fill();
  }
```

### パス（path）で形を作る

Canvas で好きな形を描くときは、`beginPath()` で描き始め、`moveTo`（ペンを移動）・`lineTo`（線を引く）・`arc`（円弧）などで輪郭をなぞり、`closePath()` で閉じます。この輪郭を **パス** と呼び、できたパスに `fill()`（塗る）や `stroke()`（線を引く）を命令します。

`shapePath` は「中心 `(cx, cy)`・半径 `R` の、種類 `t` の形のパス」を作るだけの関数です。塗るのは呼び出し側に任せているので、あとで「同じ形で切り抜く」といった使い回しもできます。

- **星と六角形** は、円周上の点を `Math.cos(角度) * 半径`・`Math.sin(角度) * 半径` で求めて順に結んでいます。角度は **ラジアン**（`Math.PI` が 180°）です。星は10個の点を「外側・内側・外側…」と半径を交互に変えて結ぶと、とがった形になります。
- **四角** は角を丸くしたいので、`arcTo` で角ごとに丸めながらなぞる `roundRect` を自作しています。

### 宝石の描き方

`drawGem` は `(x, y)` を左上とするマスの中心に、半径 `cell × 0.38 × scale` の宝石を描きます。

1. `createLinearGradient` で上から下へ「明るい色→暗い色」のグラデーションを作って塗る
2. 半透明の白で縁取る
3. 左上に半透明の白い楕円（`ellipse`）を置いてツヤを出す

`R <= 0.5` のときに何も描かないのは、消えかけでほとんど見えない宝石を描く手間を省くためです。

## draw() で宝石を描く

`draw()` 関数を次のように書きかえます（マス目のループの **後ろ** に宝石のループを足します）。

```js:game.js
  function draw() {
    ctx.clearRect(0, 0, size, size);
    // マス目
    for (let r = 0; r < N; r++) for (let c = 0; c < N; c++) {
      ctx.fillStyle = (r + c) % 2 ? 'rgba(255,255,255,.04)' : 'rgba(255,255,255,.08)';
      ctx.fillRect(c * cell, r * cell, cell, cell);
    }
    if (!grid.length) return;
    for (let r = 0; r < N; r++) for (let c = 0; c < N; c++) {
      const g = grid[r][c];
      if (!g) continue;
      const x = c * cell, y = (r + g.dy) * cell;
      drawGem(g, x, y, g.scale);
    }
  }
```

`y` の計算に `g.dy` を足しているのは、ステップ6で「上から落ちてくる途中」を描くための準備です（今はいつも 0）。`if (!g) continue;` も、あとで宝石が消えて空になったマスを飛ばすための準備です。

最後に、ファイル末尾の `resize();` と `draw();` の **間** に `newBoard();` を入れます。

```js:game.js
  resize();
  newBoard();
  draw();
```

> [!CHECK] 動作チェック
> - スタートすると、盤面に赤い丸・オレンジのひし形・黄色い星・緑の四角・青い三角・紫の六角形がランダムに並んでいる
> - 再読み込みするたびに並びが変わる
> - 何度再読み込みしても、縦や横に同じ宝石が3つ以上並んでいる場所が **最初から** できていない
