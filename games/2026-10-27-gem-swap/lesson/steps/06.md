## このステップのゴール

そろった宝石を小さくしながら消し、上の宝石を落として、空いたところに新しい宝石を補充します。落ちた結果またそろったら続けて消える **連鎖** と、スコア計算、「動かせる手がなくなったらシャッフル」もここで作ります。マッチ3パズルの心臓部です。

## 表示用の要素と変数

`const movesEl = ...` の **下** に追加します。

```js:game.js
  const scoreEl = document.getElementById('score');
  const comboEl = document.getElementById('combo');
```

`let state = ...` の行のコメントを更新し、`let moves = MAX_MOVES;` の行を書きかえて、その下に `comboTimer` を追加します。

```js:game.js
  let state = 'title'; // title, idle, swap, unswap, clear, fall
```

```js:game.js
  let moves = MAX_MOVES, score = 0, combo = 0;
  let comboTimer = 0;
```

新しい状態は `'clear'`（消している途中）と `'fall'`（落ちている途中）です。`combo` は「いま何連鎖目か」を数えます。

## シャッフル

`hasMove()` 関数の **後ろ** に追加します。

```js:game.js
  function shuffle() {
    const all = [];
    for (let r = 0; r < N; r++) for (let c = 0; c < N; c++) all.push(grid[r][c]);
    let tries = 0;
    do {
      for (let i = all.length - 1; i > 0; i--) {
        const j = rnd(i + 1);
        [all[i], all[j]] = [all[j], all[i]];
      }
      for (let r = 0; r < N; r++) for (let c = 0; c < N; c++) grid[r][c] = all[r * N + c];
      tries++;
    } while ((findRuns().length > 0 || !hasMove()) && tries < 200);
    if (tries >= 200) newBoard();
    showCombo('シャッフル！');
  }
```

- 盤面の宝石をいったん1列の配列 `all` に並べ、**フィッシャー–イェーツのシャッフル**（後ろから順に、自分より前のランダムな位置と入れかえる）で混ぜてから盤面に戻します。偏りなく混ぜられる定番の方法です。`[a, b] = [b, a]` は **分割代入** を使った入れかえの書き方です。
- 混ぜた結果「最初からそろっている」か「動かせる手がない」ならやり直します。200回やってもだめなら盤面ごと作り直します（無限ループの保険）。
- `r * N + c` は、2次元の位置 `(r, c)` を 0〜63 の1つの番号にする計算です。

## 消去処理

`shuffle()` の **後ろ** に、消去処理のブロックを追加します。

```js:game.js
  // ---------- 消去処理 ----------
  const key = (r, c) => r * N + c;

  // 消すマスと、新しく生まれる特殊ジェムを決める
  function planClear(runs) {
    const set = new Set();
    const spawns = [];
    for (const run of runs) for (const [r, c] of run.cells) set.add(key(r, c));
    return { set, spawns };
  }

  function startClear(plan) {
    combo++;
    const n = plan.set.size;
    const gained = n * 10 * combo + plan.spawns.length * 50;
    score += gained;
    scoreEl.textContent = score;
    if (combo >= 2) showCombo(combo + ' 連鎖！');
    state = 'clear';
    anim = { t: 0, dur: 220, plan };
  }

  function finishClear(plan) {
    for (const k of plan.set) {
      grid[Math.floor(k / N)][k % N] = null;
    }
    for (const sp of plan.spawns) {
      grid[Math.floor(sp.k / N)][sp.k % N] = gem(sp.t, sp.s);
    }
    // 落下
    for (let c = 0; c < N; c++) {
      let w = N - 1;
      for (let r = N - 1; r >= 0; r--) {
        const g = grid[r][c];
        if (g) {
          grid[r][c] = null;
          grid[w][c] = g;
          g.dy = r - w; // 負の値＝上から落ちてくる
          w--;
        }
      }
      const empty = w + 1;
      for (let r = w; r >= 0; r--) {
        const g = gem(rnd(COLORS));
        g.dy = -empty - 0.5;
        g.scale = 1;
        grid[r][c] = g;
      }
    }
    for (let r = 0; r < N; r++) for (let c = 0; c < N; c++) grid[r][c].scale = 1;
    state = 'fall';
  }

  function settle() {
    const runs = findRuns();
    if (runs.length) {
      startClear(planClear(runs));
      return;
    }
    combo = 0;
    if (!hasMove()) shuffle();
    state = 'idle';
  }
```

### Set で「消すマス」を重複なく集める

横のそろいと縦のそろいが交差する（L字やT字）と、同じマスが2回出てきます。**Set**（セット）は「同じ値は1つしか入らない」入れ物なので、`set.add()` で入れるだけで重複が自然になくなり、`set.size` でちょうど消える個数が分かります。マスは `key(r, c)` で1つの数にしてから入れます（配列 `[r, c]` のままだと、中身が同じでも別物と扱われてしまうためです）。番号から行・列に戻すときは `Math.floor(k / N)` と `k % N` です。

`planClear` は「何を消すか」の計画書 `{ set, spawns }` を作るだけの関数です。`spawns`（新しく生まれる特殊ジェム）は次のステップで使うので、今は空っぽです。

### スコアと連鎖

`startClear` で、消える個数 × 10 点 × 連鎖数 を加算します。2連鎖目は2倍、3連鎖目は3倍になるので、連鎖を起こすと一気に点が伸びます。2連鎖以上なら「2 連鎖！」を表示し、`'clear'` 状態で 220 ミリ秒のアニメーションを始めます。

### 落下：列ごとに下から詰める

`finishClear` が一番の見どころです。まず消すマスを `null`（空）にしてから、**列ごとに** 次のことをします。

1. 書きこみ位置 `w` を一番下（`N - 1`）にしておく
2. 下から上へ見ていき、宝石があったら `w` の位置へ移して `w` を1つ上げる
3. 最後に残った `w` から上は空きなので、新しい宝石で埋める

こうすると、すき間が詰まって宝石が下にそろいます。

ただしデータだけ一瞬で動かすと、宝石がワープしたように見えます。そこで移した宝石には **見た目のずれ** `dy = 元の行 - 新しい行` を入れておきます。たとえば 5 行目から 7 行目へ落ちた宝石は `dy = -2` で、「本当は7行目にいるけれど、2マス上に描く」という意味になります。新しく補充する宝石は、空いたマス数 `empty` より少し上（盤面の外）から落ちてくるように `dy` を設定します。

### settle：落ち終わったら次を決める

`settle` は落下が終わったときに呼ばれ、もう一度 `findRuns()` します。またそろっていれば連鎖として `startClear` へ、そろいがなければ連鎖数を 0 に戻し、手がなければシャッフルしてから操作待ちに戻ります。

「消す → 落とす → 調べる → また消す…」と、状態が `clear → fall → (clear → fall →) idle` とぐるぐる回るのが、連鎖の仕組みです。

## 連鎖の文字を出す

`start()` の **後ろ** に追加します。

```js:game.js
  function showCombo(text) {
    comboEl.textContent = text;
    comboEl.classList.add('show');
    clearTimeout(comboTimer);
    comboTimer = setTimeout(() => comboEl.classList.remove('show'), 700);
  }
```

`show` クラスをつけて、0.7 秒後に外します。`setTimeout` は「指定したミリ秒後に1回だけ関数を呼ぶ」命令です。連鎖が続いて短い間隔で呼ばれたときに、前のタイマーで途中で消えてしまわないよう `clearTimeout` で前の予約を取り消しています。

## ループで「消す」と「落ちる」を進める

`loop()` 関数を次のように書きかえます。

```js:game.js
  function loop(now) {
    const dt = Math.min(50, now - prev); prev = now;
    if (anim && (state === 'swap' || state === 'unswap' || state === 'clear')) {
      anim.t += dt;
      if (state === 'clear') {
        const p = Math.min(1, anim.t / anim.dur);
        for (const k of anim.plan.set) {
          const g = grid[Math.floor(k / N)][k % N];
          if (g) g.scale = 1 - p;
        }
      }
      if (anim.t >= anim.dur) {
        const a = anim; anim = null;
        if (state === 'swap') afterSwap(a.a, a.b);
        else if (state === 'unswap') state = 'idle';
        else if (state === 'clear') finishClear(a.plan);
      }
    }
    if (state === 'fall') {
      let moving = false;
      const v = dt / 1000 * 14;
      for (let r = 0; r < N; r++) for (let c = 0; c < N; c++) {
        const g = grid[r][c];
        if (g.dy < 0) { g.dy = Math.min(0, g.dy + v); moving = true; }
      }
      if (!moving) settle();
    }
    draw(now);
    requestAnimationFrame(loop);
  }
```

- `'clear'` 中は、消えるマスの宝石の `scale` を 1 → 0 へ小さくしていきます。`drawGem` は半径に `scale` を掛けて描くので、宝石がしゅっとしぼんで消えます。
- `'fall'` 中は、すべての宝石の `dy` を毎秒 14 マスの速さで 0 に近づけます（`Math.min(0, ...)` で 0 を通りこさないようにします）。1つも動いていなければ全部着地したので `settle()` を呼びます。

> [!CHECK] 動作チェック
> - 3つそろえると、宝石がしぼんで消え、上の宝石が落ちてきて、空いたところに新しい宝石が上から降ってくる
> - SCORE が増える（3つ消しなら 30 点）
> - 落ちてきた宝石で偶然またそろうと続けて消え、「2 連鎖！」の文字が出る。連鎖目ほど点数が多く入る
> - 縦と横が交差してそろったとき（L字・T字）、交差したマスも含めて全部消える
