## このステップのゴール

**ゲームループ** を作って毎フレーム画面を描き直すようにし、宝石をタップ（クリック）すると黄色い枠で「選択中」になるようにします。ゲームの「いまの状態」を表す変数 `state` もここで登場します。

## 状態と選択中のマス

`let grid = [];` の **下** に2行追加します。

```js:game.js
  let state = 'title'; // title, idle
  let selected = null;
```

- `state` はゲームがいま何をしているかを表す文字列です。今は `'title'`（タイトル画面）と `'idle'`（プレイヤーの操作待ち）の2つだけですが、このあと「入れかえ中」「消している途中」「落ちている途中」などが増えていきます。**操作を受け付けるのは `'idle'` のときだけ** にすると、アニメーション中に変な操作が混ざるのを防げます。
- `selected` は選択中のマスの `[行, 列]` です。何も選んでいなければ `null` です。

## ゲーム開始の処理

`// ---------- 描画 ----------` の **上** に追加します。

```js:game.js
  // ---------- ゲーム進行 ----------
  function start() {
    newBoard();
    selected = null;
    overlay.classList.add('hidden');
    state = 'idle';
  }
```

スタートするたびに新しい盤面を作り直し、オーバーレイを隠して操作待ちにします。

## 選択枠を描く

`draw()` 関数の1行目を `function draw(now) {` に変え、マス目のループの **後ろ** に選択枠を足します。

```js:game.js
  function draw(now) {
    ctx.clearRect(0, 0, size, size);
    // マス目
    for (let r = 0; r < N; r++) for (let c = 0; c < N; c++) {
      ctx.fillStyle = (r + c) % 2 ? 'rgba(255,255,255,.04)' : 'rgba(255,255,255,.08)';
      ctx.fillRect(c * cell, r * cell, cell, cell);
    }
    if (selected) {
      ctx.strokeStyle = '#ffe36e'; ctx.lineWidth = 3;
      ctx.strokeRect(selected[1] * cell + 2, selected[0] * cell + 2, cell - 4, cell - 4);
    }
```

（以降の宝石を描くループはそのままです。）`strokeRect` は四角の枠線だけを描く命令です。`selected[1]` が列（x 方向）、`selected[0]` が行（y 方向）なのに注意しましょう。`now`（いまの時刻）はステップ7で、虹色に回るカラーボムを描くときに使います。

## ゲームループ

ファイル末尾の

```js:game.js
  startBtn.addEventListener('click', () => { overlay.classList.add('hidden'); });
  window.addEventListener('resize', () => { resize(); draw(); });

  resize();
  newBoard();
  draw();
```

を **すべて消して**、代わりに次のコードを入れます。

```js:game.js
  // ---------- ループ ----------
  let prev = performance.now();
  function loop(now) {
    const dt = Math.min(50, now - prev); prev = now;
    draw(now);
    requestAnimationFrame(loop);
  }

  // ---------- 入力 ----------
  let down = null;
  function cellAt(e) {
    const rect = cv.getBoundingClientRect();
    const x = e.clientX - rect.left, y = e.clientY - rect.top;
    const c = Math.floor(x / cell), r = Math.floor(y / cell);
    return inside(r, c) ? [r, c] : null;
  }
  cv.addEventListener('pointerdown', (e) => {
    if (state !== 'idle') return;
    const p = cellAt(e);
    if (!p) return;
    e.preventDefault();
    down = { p, x: e.clientX, y: e.clientY, used: false };
  });
  window.addEventListener('pointerup', () => {
    if (!down) return;
    const d = down; down = null;
    if (d.used || state !== 'idle') return;
    const p = d.p;
    if (selected && selected[0] === p[0] && selected[1] === p[1]) {
      selected = null;
    } else {
      selected = p;
    }
  });
  startBtn.addEventListener('click', start);
  window.addEventListener('resize', resize);

  resize();
  newBoard();
  requestAnimationFrame(loop);
```

### requestAnimationFrame とゲームループ

`requestAnimationFrame(loop)` は「次に画面を描きかえるタイミングで `loop` を呼んでね」とブラウザに頼む命令です。`loop` の最後でもう一度頼むので、1秒間に約60回 `loop` が呼ばれ続けます。これが **ゲームループ** です。

- 呼ばれるとき、引数 `now` にいまの時刻（ミリ秒）が入ってきます。
- `dt`（delta time）は前のフレームからの経過時間です。動く速さを `dt` に比例させると、60Hz の画面でも 120Hz の画面でも同じ速さで動きます。次のステップから使います。
- `Math.min(50, ...)` で上限をつけているのは、タブを裏に回して戻ったときなどに `dt` が巨大になり、アニメーションが一瞬で飛んでしまうのを防ぐためです。

毎フレーム描き直すので、`resize` イベントでは `resize()` を呼ぶだけでよくなりました。

### Pointer Events でタップとクリックをまとめて扱う

`pointerdown`（押した）・`pointerup`（離した）は **Pointer Events** と呼ばれるイベントで、マウスのクリックもスマホのタッチも同じように受け取れます。

- `cellAt(e)` は、押した位置 `e.clientX, e.clientY`（画面の左上が基準）から Canvas の左上の位置 `rect.left, rect.top` を引いて Canvas 内の座標にし、`cell` で割ってマスの行・列に変換します。盤面の外なら `null` を返します。
- `pointerdown` では、どのマスを押したかを `down` に覚えておくだけです。`used` は次のステップで「スワイプとして使ったか」を記録するのに使います。
- `pointerup` は `window` に登録しています。Canvas の外で指を離しても確実に受け取れるようにするためです。
- 同じマスをもう一度押すと選択解除、別のマスなら選択しなおし、という動きにしています。

> [!CHECK] 動作チェック
> - スタートを押すと宝石が並んだ盤面になる（スタートのたびに並びが変わる）
> - 宝石をクリック（タップ）すると、そのマスに黄色い枠がつく
> - 別の宝石を押すと枠が移動し、同じ宝石をもう一度押すと枠が消える
> - Console にエラーが出ていない
