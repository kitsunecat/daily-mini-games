## このステップのゴール

3つのファイルを用意して、画面の土台を作ります。上に「残り手数・スコア・ベスト」の表示、その下に 8×8 の盤面を描く **Canvas**、さらにその上に重ねるタイトル画面（オーバーレイ）を置き、Canvas には市松模様のマス目を描きます。

## index.html

まずは HTML です。このステップで画面の部品はすべてそろえてしまい、以降は `game.js` を育てていきます。


- `header` に残り手数（MOVES）・スコア・ベストの3つの数字を並べます。JavaScript から書き換えるので、数字の `b` 要素に `id` をつけています。
- `#stage` の中に `canvas`・`#combo`（「2 連鎖！」などの文字を出す場所）・`#overlay` を **重ねて** 置きます。オーバーレイはタイトル画面とゲームオーバー画面の両方に使い回します。
- 「← 一覧」のリンク先は自分の環境に合わせて変えてかまいません。
- `<script>` を `body` の最後に置くと、HTML の要素が全部できてからスクリプトが動くので `getElementById` で確実に要素が取れます。

ポイントは次のとおりです。

- `#app` を縦方向の **Flexbox** にして、`#stage` に `flex: 1` を指定すると「ヘッダーの残り全部」がゲーム画面になります。`min-height: 0` は、中身が大きくてもはみ出さずに縮めるためのおまじないです。
- `#stage` も Flexbox にして `align-items` と `justify-content` を `center` にすると、正方形の Canvas が真ん中に置かれます。
- `#stage` を `position: relative`、`#overlay` を `position: absolute; inset: 0` にすると、オーバーレイが Canvas の上にぴったり重なります。`hidden` クラスをつけ外しするだけで表示を切り替えられます。
- `#combo` はふだん `opacity: 0` で見えず、`show` クラスがつくとふわっと現れます（`transition`）。`pointer-events: none` なので、上に重なっていても盤面の操作のじゃまをしません。
- `touch-action: none` は、スマホでスワイプしたときに画面がスクロールしたり拡大したりするのを防ぎます。

## game.js

```js:game.js
(() => {
  'use strict';

  const N = 8;

  const cv = document.getElementById('cv');
  const ctx = cv.getContext('2d');
  const stage = document.getElementById('stage');
  const overlay = document.getElementById('overlay');
  const startBtn = document.getElementById('start');

  let size = 0, cell = 0, dpr = 1;

  // ---------- 描画 ----------
  function resize() {
    const rect = stage.getBoundingClientRect();
    const avail = Math.min(rect.width - 16, rect.height - 16);
    cell = Math.max(24, Math.floor(avail / N));
    size = cell * N;
    dpr = window.devicePixelRatio || 1;
    cv.width = size * dpr; cv.height = size * dpr;
    cv.style.width = size + 'px'; cv.style.height = size + 'px';
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
  }

  function draw() {
    ctx.clearRect(0, 0, size, size);
    // マス目
    for (let r = 0; r < N; r++) for (let c = 0; c < N; c++) {
      ctx.fillStyle = (r + c) % 2 ? 'rgba(255,255,255,.04)' : 'rgba(255,255,255,.08)';
      ctx.fillRect(c * cell, r * cell, cell, cell);
    }
  }

  startBtn.addEventListener('click', () => { overlay.classList.add('hidden'); });
  window.addEventListener('resize', () => { resize(); draw(); });

  resize();
  draw();
})();
```

### コード全体を `(() => { ... })();` で包む理由

これは **即時実行関数** と呼ばれる書き方です。中で宣言した変数がページ全体（グローバル）に漏れないので、ほかのスクリプトと名前がぶつかりません。`'use strict';` は、宣言し忘れた変数などのミスをエラーとして教えてくれるモードです。

### Canvas とは

`<canvas>` は JavaScript で自由に絵を描ける「キャンバス」です。`getContext('2d')` で取り出した `ctx`（コンテキスト）に `fillRect`（四角を塗る）などの命令を出して描きます。座標は左上が `(0, 0)` で、右に行くほど x、**下に行くほど y が大きく** なります。

### 盤面の大きさを決める `resize()`

- `N` は盤面の1辺のマス数（8）です。`stage` の幅と高さの **小さいほう** から余白 16px を引いて `N` で割ると、画面に収まる1マスの大きさ `cell` が決まります。`Math.floor` で整数にしておくと、マスの境目がにじみません。
- `size = cell * N` が盤面全体の1辺です。Canvas には「CSS で見える大きさ」（`cv.style.width`）と「内部の画素数」（`cv.width`）の2つのサイズがあり、高精細な画面では1 CSS ピクセルに複数の物理ピクセルが詰まっている（`devicePixelRatio`）ので、内部の画素数を `size × dpr` にしないとぼやけます。
- 最後の `ctx.setTransform(dpr, 0, 0, dpr, 0, 0)` で、以降は CSS ピクセル単位で座標を指定するだけで自動的に拡大して描かれます。

### 市松模様のマス目

`r`（row＝行）と `c`（column＝列）の二重ループで 64 マスを塗ります。`(r + c) % 2` は隣のマスどうしで必ず 0 と 1 が入れかわるので、濃い・薄いが交互になる市松模様になります。色は `rgba(...)` の半透明の白なので、CSS で塗った Canvas の背景グラデーションが透けて見えます。
