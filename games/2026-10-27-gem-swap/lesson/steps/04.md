## このステップのゴール

となりどうしの宝石を、スーッとすべるアニメーションつきで入れかえられるようにします。操作は「スワイプ（ドラッグ）」と「タップで選んでからとなりをタップ」の2通りです。まだ3つそろっても消えませんが、まずは「動かす」ところを作ります。

## アニメーション用の変数

`let state = ...` の行を書きかえ、その下に `anim` を追加します。

```js:game.js
  let state = 'title'; // title, idle, swap, unswap
  let anim = null;
```

`anim` は「いま再生中のアニメーション」の情報（経過時間 `t`、長さ `dur`、動かすマス `a` と `b` など）を入れておく箱です。`'swap'` は入れかえ中、`'unswap'` は「そろわなかったので元に戻している最中」の状態で、次のステップで使います。

## マスの中身を入れかえる

`newBoard()` 関数の **後ろ** に追加します。

```js:game.js
  function swapCells(a, b) {
    const tmp = grid[a[0]][a[1]];
    grid[a[0]][a[1]] = grid[b[0]][b[1]];
    grid[b[0]][b[1]] = tmp;
  }
```

2つの変数の中身を入れかえる定番の書き方です。一時置き場 `tmp` に片方を避難させてから、上書きしていきます。

## 入れかえの開始と終了

`swapCells` のすぐ **後ろ**（`// ---------- ゲーム進行 ----------` の上）に追加します。

```js:game.js
  // ---------- 入れかえ ----------
  function trySwap(a, b) {
    if (state !== 'idle') return;
    if (Math.abs(a[0] - b[0]) + Math.abs(a[1] - b[1]) !== 1) return;
    selected = null;
    state = 'swap';
    anim = { t: 0, dur: 160, a, b };
  }

  function afterSwap(a, b) {
    swapCells(a, b);
    state = 'idle';
  }
```

- `Math.abs(行の差) + Math.abs(列の差)` は **マンハッタン距離** と呼ばれ、マス目を縦横に何歩で行けるかを表します。これがちょうど 1 なら上下左右のとなりです（ななめは 2 になるので入れかえられません）。
- `trySwap` ではまだ `grid` を書きかえません。`state = 'swap'` にして 160 ミリ秒のアニメーションを始めるだけです。アニメーションが終わったら `afterSwap` で本当に入れかえます。「見た目を動かす期間」と「データを変える瞬間」を分けておくと、処理がすっきりします。

## ループでアニメーションを進める

`loop()` 関数を次のように書きかえます。

```js:game.js
  function loop(now) {
    const dt = Math.min(50, now - prev); prev = now;
    if (anim && (state === 'swap' || state === 'unswap')) {
      anim.t += dt;
      if (anim.t >= anim.dur) {
        const a = anim; anim = null;
        if (state === 'swap') afterSwap(a.a, a.b);
        else if (state === 'unswap') state = 'idle';
      }
    }
    draw(now);
    requestAnimationFrame(loop);
  }
```

毎フレーム `anim.t` に経過時間 `dt` を足していき、`dur` に届いたら終了です。`anim` を先に `null` にしてから `afterSwap` を呼んでいるのは、`afterSwap` の中で新しいアニメーションを始めたときに、それを消してしまわないためです。

## 動いている途中を描く

`draw()` の宝石のループ（`if (!grid.length) return;` から最後まで）を次のように書きかえます。

```js:game.js
    if (!grid.length) return;
    const sw = (state === 'swap' || state === 'unswap') ? anim : null;
    let p = sw ? Math.min(1, sw.t / sw.dur) : 0;
    if (sw && state === 'unswap') p = 1 - p;
    for (let r = 0; r < N; r++) for (let c = 0; c < N; c++) {
      const g = grid[r][c];
      if (!g) continue;
      let x = c * cell, y = (r + g.dy) * cell;
      if (sw) {
        const ease = p * p * (3 - 2 * p);
        if (r === sw.a[0] && c === sw.a[1]) { x += (sw.b[1] - c) * cell * ease; y += (sw.b[0] - r) * cell * ease; }
        else if (r === sw.b[0] && c === sw.b[1]) { x += (sw.a[1] - c) * cell * ease; y += (sw.a[0] - r) * cell * ease; }
      }
      if (y < -cell) continue;
      drawGem(g, x, y, g.scale);
    }
  }
```

- `p` はアニメーションの進み具合で、0（始まり）→ 1（終わり）と増えていきます。
- マス `a` の宝石は `b` の方向へ、マス `b` の宝石は `a` の方向へ、`p` の割合だけずらして描きます。こうして2つが交差するように見えます。
- `ease = p * p * (3 - 2 * p)` は **イージング**（smoothstep）と呼ばれる式で、動き始めと止まる直前をゆっくりにしてくれます。`p` をそのまま使うより、ずっと自然な動きになります。
- `'unswap'` のときは `p = 1 - p` にして、逆再生（入れかえた位置から元の位置へ）に見せます。
- `if (y < -cell) continue;` は、盤面の上の外側にある宝石（ステップ6で使います）を描かないための行です。

## スワイプ操作と「選んでからタップ」

`cv.addEventListener('pointerdown', ...)` の **後ろ** に `pointermove` を追加し、`pointerup` を書きかえます。

```js:game.js
  window.addEventListener('pointermove', (e) => {
    if (!down || down.used || state !== 'idle') return;
    const dx = e.clientX - down.x, dy = e.clientY - down.y;
    if (Math.max(Math.abs(dx), Math.abs(dy)) < cell * 0.35) return;
    down.used = true;
    const [r, c] = down.p;
    const t = Math.abs(dx) > Math.abs(dy) ? [r, c + Math.sign(dx)] : [r + Math.sign(dy), c];
    if (inside(t[0], t[1])) trySwap(down.p, t);
  });
  window.addEventListener('pointerup', () => {
    if (!down) return;
    const d = down; down = null;
    if (d.used || state !== 'idle') return;
    const p = d.p;
    if (selected && Math.abs(selected[0] - p[0]) + Math.abs(selected[1] - p[1]) === 1) {
      trySwap(selected, p);
    } else if (selected && selected[0] === p[0] && selected[1] === p[1]) {
      selected = null;
    } else {
      selected = p;
    }
  });
```

### スワイプの向きの決め方

- 押した位置からの移動量 `dx, dy` が、マスの大きさの 35% を超えたら「スワイプした」とみなします。少し指がぶれただけで入れかわらないようにするためです。
- 横の移動量が縦より大きければ左右、そうでなければ上下に入れかえます。`Math.sign(dx)` は `dx` が正なら `1`、負なら `-1` を返すので、そのまま「右（+1）か左（-1）か」に使えます。
- 1回のスワイプで何度も入れかわらないよう `down.used = true` にしておき、`pointerup` でもタップとしては扱いません。

`pointerup` では、選択中のマスのとなりを押したら `trySwap` で入れかえる分岐が増えました。

> [!CHECK] 動作チェック
> - 宝石を上下左右にドラッグ（スワイプ）すると、となりの宝石とスーッと入れかわる
> - 宝石をクリックして黄色い枠をつけ、となりの宝石をクリックしても入れかわる（枠は消える）
> - ななめのマスや離れたマスをクリックしたときは、入れかわらずに選択が移るだけ
> - 盤面の端で外側に向かってスワイプしても何も起きない
