## このステップのゴール

マッチ3パズルの楽しさを一気に広げる **特殊ジェム** を作ります。

- 4つそろえると **ラインボム** が生まれる。横に4つなら横1列、縦に4つなら縦1列をまるごと消す
- 5つ以上そろえると **カラーボム** が生まれる。となりの宝石と入れかえると、その色を盤面から全部消す
- 特殊ジェムが別の特殊ジェムの爆発に巻きこまれると、それも発動する（誘爆）

## 特殊ジェムの番号と変数

`const PALETTE = [` の **上** に、`s` の意味をコメントで書いておきます。

```js:game.js
  // special: 0 なし, 1 横ライン, 2 縦ライン, 3 カラーボム
```

ステップ2で作った `gem(t, s)` の `s` がこの番号です。カラーボムは色を持たないので、種類 `t` には `COLORS`（6）を入れます。ステップ5の `findRuns()` に入れた `t < COLORS` は、カラーボムを「3つそろい」の色として数えないためのものでした。

`let comboTimer = 0;` の **上** に追加します。

```js:game.js
  let lastSwap = null;
```

最後に入れかえた2マスを覚えておき、特殊ジェムを「プレイヤーが動かした宝石の位置」に生み出すために使います。

## カラーボムがあれば手はある

`hasMove()` の2重ループの中、`for (const [dr, dc] of ...` の **上** に1行足します。

```js:game.js
        if (grid[r][c].s === 3) return true;
```

カラーボムはどの宝石と入れかえても発動するので、盤面にあれば必ず手があります。

## 爆発を広げる

`const key = ...` の行の **後ろ** に追加します。

```js:game.js
  function expandSpecials(set, colorFor) {
    const queue = [...set];
    const done = new Set();
    while (queue.length) {
      const k = queue.pop();
      if (done.has(k)) continue;
      done.add(k);
      const r = Math.floor(k / N), c = k % N;
      const g = grid[r][c];
      let add = [];
      if (g.s === 1) add = range(0, N).map((x) => key(r, x));
      else if (g.s === 2) add = range(0, N).map((y) => key(y, c));
      else if (g.s === 3) {
        const t = colorFor != null && colorFor.k === k ? colorFor.t : mostCommonColor();
        for (let y = 0; y < N; y++) for (let x = 0; x < N; x++) {
          if (t === -1 || grid[y][x].t === t) add.push(key(y, x));
        }
      }
      for (const a of add) if (!set.has(a)) { set.add(a); queue.push(a); }
    }
  }

  function mostCommonColor() {
    const cnt = new Array(COLORS).fill(0);
    for (let r = 0; r < N; r++) for (let c = 0; c < N; c++) if (grid[r][c].t < COLORS) cnt[grid[r][c].t]++;
    return cnt.indexOf(Math.max(...cnt));
  }
```

### キューで誘爆をたどる

`set` に入っている「消えるマス」を1つずつ調べ、そこが特殊ジェムなら巻きこむマスを `add` に集めます。

- 横ライン（`s === 1`）… 同じ行の全マス
- 縦ライン（`s === 2`）… 同じ列の全マス
- カラーボム（`s === 3`）… 指定された色 `t` の全マス。`t === -1` なら盤面全部

新しく巻きこんだマスは `set` に加えるだけでなく `queue`（調べる予定のリスト）にも入れます。そうすると、巻きこまれた先にまた特殊ジェムがあれば、それもあとで調べられて発動します。これが誘爆です。「調べる予定を積んでおき、1つ取り出しては調べ、見つかったものをまた積む」というやり方は、**幅優先探索** や **深さ優先探索** と呼ばれるアルゴリズムの基本形です。`done` は同じマスを2回調べないための記録です。

カラーボムが「プレイヤーが入れかえた相手の色」ではなく誘爆で発動したときは、`mostCommonColor()` で盤面に一番多い色を選びます。`Math.max(...cnt)` の `...` は **スプレッド構文** で、配列を引数のリストに広げています。

## 特殊ジェムの生まれる場所を決める

`planClear()` 関数を次のように書きかえます。

```js:game.js
  // 消すマスと、新しく生まれる特殊ジェムを決める
  function planClear(runs, extra) {
    const set = new Set(extra ? extra.set : []);
    const spawns = [];
    for (const run of runs) for (const [r, c] of run.cells) set.add(key(r, c));
    for (const run of runs) {
      if (run.cells.length < 4) continue;
      let pos = run.cells[Math.floor(run.cells.length / 2)];
      if (lastSwap) {
        for (const p of lastSwap) {
          if (run.cells.some(([r, c]) => r === p[0] && c === p[1])) { pos = p; break; }
        }
      }
      const k = key(pos[0], pos[1]);
      if (spawns.some((s) => s.k === k)) continue;
      const s = run.cells.length >= 5 ? 3 : (run.dir === 'h' ? 1 : 2);
      spawns.push({ k, t: s === 3 ? COLORS : run.t, s });
    }
    expandSpecials(set, extra ? extra.colorFor : null);
    for (const sp of spawns) {
      // 生まれる場所にあった特殊ジェムは既に発動済みなので上書きしてよい
      set.delete(sp.k);
    }
    return { set, spawns };
  }
```

- 長さ 4 以上の run ごとに特殊ジェムを1つ予約します。5 以上ならカラーボム、4 なら run の向き `dir` に合わせて横か縦のラインボムです。ラインボムはそろえた宝石と同じ色になります。
- 生まれる場所は、ふつうは run の真ん中です。ただし入れかえた2マス（`lastSwap`）のどちらかが run に含まれていれば、そのマスにします。「自分が動かした宝石が変身した」と感じられて気持ちいいからです。`some()` は配列の中に条件を満たす要素が1つでもあれば `true` を返すメソッドです。
- `expandSpecials` で誘爆を広げたあと、特殊ジェムが生まれるマスだけは `set` から外します。ここは消さずに、新しい特殊ジェムで上書きするためです。
- 引数 `extra` はカラーボムを動かしたときに使います（すぐ下の `afterSwap` で説明します）。

`finishClear()` の最後の `state = 'fall';` の **上** に1行足します。

```js:game.js
    lastSwap = null;
```

連鎖で消えたときは「プレイヤーが動かした場所」は関係ないので、1回目の消去が終わったら忘れます。`finishClear` の中の `for (const sp of plan.spawns)` は前のステップで書いてあるので、これで予約した場所に特殊ジェムが置かれるようになります。

## カラーボムを動かしたとき

`afterSwap()` 関数を次のように書きかえます。

```js:game.js
  function afterSwap(a, b) {
    swapCells(a, b);
    const ga = grid[a[0]][a[1]], gb = grid[b[0]][b[1]];
    lastSwap = [a, b];
    // カラーボムを動かした場合
    if (ga.s === 3 || gb.s === 3) {
      moves--; movesEl.textContent = moves;
      const set = new Set();
      let colorFor = null;
      if (ga.s === 3 && gb.s === 3) {
        set.add(key(a[0], a[1])); set.add(key(b[0], b[1]));
        colorFor = { k: key(a[0], a[1]), t: -1 };
      } else {
        const bomb = ga.s === 3 ? a : b;
        const other = ga.s === 3 ? gb : ga;
        set.add(key(bomb[0], bomb[1]));
        colorFor = { k: key(bomb[0], bomb[1]), t: other.t };
        if (other.s) set.add(ga.s === 3 ? key(b[0], b[1]) : key(a[0], a[1]));
      }
      startClear(planClear(findRuns(), { set, colorFor }));
      return;
    }
    const runs = findRuns();
    if (!runs.length) {
      state = 'unswap';
      anim = { t: 0, dur: 160, a, b };
      swapCells(a, b);
      return;
    }
    moves--; movesEl.textContent = moves;
    startClear(planClear(runs));
  }
```

カラーボムはそろわなくても入れかえるだけで発動します。

- 相手がふつうの宝石なら、カラーボム自身を `set` に入れ、`colorFor` で「このマスのカラーボムは相手の色 `other.t` を消す」と指定します。相手がラインボムなら、それも `set` に入れて一緒に発動させます。
- カラーボムどうしなら、色 `-1`（全部）を指定して盤面をまるごと消します。

最後の `findRuns()` は、入れかえで同時にふつうのそろいもできていたときのためです。

## 特殊ジェムを描く

`drawGem()` 関数を次のように書きかえます（引数に `now` が増えています）。

```js:game.js
  function drawGem(g, x, y, scale, now) {
    const cx = x + cell / 2, cy = y + cell / 2;
    const R = cell * 0.38 * scale;
    if (R <= 0.5) return;
    if (g.s === 3) {
      const grad = ctx.createConicGradient ? ctx.createConicGradient(now / 600, cx, cy) : null;
      if (grad) {
        ['#ff5f7e', '#ffb238', '#ffe45c', '#4cd97b', '#4cb8ff', '#c27dff', '#ff5f7e']
          .forEach((col, i) => grad.addColorStop(i / 6, col));
        ctx.fillStyle = grad;
      } else ctx.fillStyle = '#fff';
      ctx.beginPath(); ctx.arc(cx, cy, R, 0, Math.PI * 2); ctx.fill();
      ctx.fillStyle = 'rgba(255,255,255,.9)';
      ctx.beginPath(); ctx.arc(cx, cy, R * 0.35, 0, Math.PI * 2); ctx.fill();
      return;
    }
    const [light, dark] = PALETTE[g.t];
    const grad = ctx.createLinearGradient(cx, cy - R, cx, cy + R);
    grad.addColorStop(0, light); grad.addColorStop(1, dark);
    shapePath(g.t, cx, cy, R);
    ctx.fillStyle = grad; ctx.fill();
    ctx.lineWidth = Math.max(1, cell * 0.03);
    ctx.strokeStyle = 'rgba(255,255,255,.55)'; ctx.stroke();
    // ツヤ
    ctx.fillStyle = 'rgba(255,255,255,.35)';
    ctx.beginPath(); ctx.ellipse(cx - R * 0.3, cy - R * 0.4, R * 0.28, R * 0.16, -0.5, 0, Math.PI * 2); ctx.fill();
    if (g.s === 1 || g.s === 2) {
      ctx.save();
      shapePath(g.t, cx, cy, R); ctx.clip();
      ctx.fillStyle = 'rgba(255,255,255,.75)';
      const w = R * 0.22;
      for (const off of [-R * 0.45, R * 0.45]) {
        if (g.s === 1) ctx.fillRect(cx - R, cy + off - w / 2, R * 2, w);
        else ctx.fillRect(cx + off - w / 2, cy - R, w, R * 2);
      }
      ctx.restore();
    }
  }
```

そして `draw()` の宝石のループの最後の行も `now` を渡すように変えます。

```js:game.js
      drawGem(g, x, y, g.scale, now);
```

- **カラーボム** は `createConicGradient(開始角, cx, cy)` で作る **扇形のグラデーション** で虹色の玉にします。開始角に `now / 600`（時間とともに増える値）を渡すので、毎フレーム少しずつ回転して見えます。古いブラウザにはこの命令がないので、ないときは白で塗ります。
- **ラインボム** は宝石の上に白い帯を2本引きます。`ctx.clip()` を呼ぶと、直前のパス（宝石の形）の内側にしか描けなくなるので、帯が宝石の形にきれいに切り抜かれます。`clip` は元に戻せないので、`ctx.save()` で状態を保存しておき、描き終えたら `ctx.restore()` で戻します。

> [!CHECK] 動作チェック
> - 横に4つそろえると、動かした宝石の位置に横じまの入った宝石（横ラインボム）が残る。縦に4つなら縦じま
> - ラインボムをそろえて消すと、その行（または列）がまるごと消える
> - 5つ並べると虹色にくるくる回る玉（カラーボム）が生まれる
> - カラーボムをとなりの宝石と入れかえると、その色の宝石が盤面から全部消える
> - 4つ・5つ消しで特殊ジェムが生まれると、その分スコアが多く入る（1個につき +50 点）

> [!TIP]
> 4つ・5つそろえるのは狙わないと難しいので、テストのときは `newBoard()` の最後（`} while (!hasMove());` の下）に `grid[0][0] = gem(COLORS, 3);` のような行を一時的に足すと、最初からカラーボムを置いて試せます。確認できたら消しておきましょう。
