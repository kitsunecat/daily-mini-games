## このステップのゴール

ゲームとして仕上げます。

- 手数が 0 になったらゲームオーバー画面を出し、「もう一度」で遊び直せるようにする
- ハイスコアを **localStorage** に保存して、ページを閉じても残るようにする
- **Web Audio API** で効果音を鳴らす
- 消えるときに光の粒（パーティクル）を飛ばし、ラインボムは列に沿って光らせる
- Enter / Space キーでもスタートできるようにする

## ハイスコアの読みこみと効果音

`let comboTimer = 0;` の **下**（`// ---------- 盤面 ----------` の上）に追加します。

```js:game.js
  try { best = parseInt(localStorage.getItem(BEST_KEY), 10) || 0; } catch (e) { best = 0; }
  bestEl.textContent = best;

  // ---------- サウンド（Web Audio で生成） ----------
  let actx = null;
  function beep(freq, dur, type, vol) {
    try {
      if (!actx) actx = new (window.AudioContext || window.webkitAudioContext)();
      const o = actx.createOscillator();
      const g = actx.createGain();
      o.type = type || 'sine';
      o.frequency.value = freq;
      g.gain.setValueAtTime(vol || 0.08, actx.currentTime);
      g.gain.exponentialRampToValueAtTime(0.0001, actx.currentTime + dur);
      o.connect(g); g.connect(actx.destination);
      o.start(); o.stop(actx.currentTime + dur);
    } catch (e) { /* 音が出せなくても遊べる */ }
  }
```

### localStorage

`localStorage` はブラウザにずっと残る小さな保存場所です。`setItem(キー, 文字列)` で保存、`getItem(キー)` で読み出します。保存できるのは文字列だけなので、読むときは `parseInt(..., 10)` で数に直し、まだ何も保存されていない（`null` → `NaN`）ときは `|| 0` で 0 にします。

プライベートブラウズなどでは `localStorage` が使えずエラーになることがあるので、`try { ... } catch (e) { ... }` で囲んで、失敗してもゲームが止まらないようにしています。

### Web Audio API で音を作る

音声ファイルを用意しなくても、ブラウザの中で音を合成できます。

- `AudioContext` … 音を扱う作業場。最初に音を鳴らすときに1回だけ作ります（ブラウザは「ユーザーが操作したあと」でないと音を出させてくれないため、ページを開いた瞬間には作りません）
- `createOscillator()` … 発振器。`frequency`（周波数、Hz）の高さで、`type`（`sine` 正弦波、`square` 矩形波、`triangle` 三角波、`sawtooth` のこぎり波）の音色の音を出します
- `createGain()` … 音量つまみ。`exponentialRampToValueAtTime` で `dur` 秒かけて音量をほぼ 0 まで下げると、「ピッ」と自然に減衰する音になります

発振器 → 音量つまみ → スピーカー（`actx.destination`）とつないで、`start()` と `stop()` で鳴らします。

## ゲームオーバー

`settle()` の `combo = 0;` の **下** に1行足します。

```js:game.js
    if (moves <= 0) { gameOver(); return; }
```

手数のチェックを `settle()`（連鎖が全部終わったところ）で行うのがポイントです。最後の1手で起きた連鎖も、最後まで見届けてから終わります。

`start()` 関数を次のように書きかえ、その **後ろ** に `gameOver()` を追加します。

```js:game.js
  function start() {
    newBoard();
    moves = MAX_MOVES; score = 0; combo = 0; selected = null; particles = [];
    movesEl.textContent = moves;
    scoreEl.textContent = score;
    overlay.classList.add('hidden');
    state = 'idle';
    beep(660, 0.1, 'triangle', 0.07);
  }

  function gameOver() {
    state = 'over';
    let isBest = false;
    if (score > best) {
      best = score; isBest = true;
      try { localStorage.setItem(BEST_KEY, String(best)); } catch (e) { /* 保存できなくても続行 */ }
      bestEl.textContent = best;
    }
    setTimeout(() => {
      ovTitle.textContent = '手数おしまい！';
      ovText.innerHTML = 'スコア <b>' + score + '</b>' + (isBest ? '<br>ハイスコア更新！' : '<br>ベスト ' + best);
      startBtn.textContent = 'もう一度';
      overlay.classList.remove('hidden');
    }, 500);
  }
```

- スコアがベストを超えていたら `best` を更新して保存します。
- オーバーレイはタイトル画面と同じ要素を使い回し、見出し・本文・ボタンの文字だけを書きかえます。0.5 秒待ってから出すのは、最後に消えた宝石のパーティクルを少し見せてあげるためです。
- ボタンは前と同じ `start` を呼ぶので、そのまま「もう一度」遊べます。

## パーティクル

`draw()` 関数の最後（宝石のループのあと、閉じカッコ `}` の **上**）に追加します。

```js:game.js
    for (const pt of particles) {
      ctx.globalAlpha = Math.max(0, pt.life);
      ctx.fillStyle = pt.col;
      ctx.beginPath(); ctx.arc(pt.x, pt.y, pt.r, 0, Math.PI * 2); ctx.fill();
    }
    ctx.globalAlpha = 1;
```

`draw()` の **後ろ** に、パーティクルを作る2つの関数を追加します。

```js:game.js
  function spawnParticles(r, c, t) {
    const col = t < COLORS ? PALETTE[t][0] : '#fff';
    for (let i = 0; i < 5; i++) {
      const a = Math.random() * Math.PI * 2, sp = 60 + Math.random() * 140;
      particles.push({ x: (c + 0.5) * cell, y: (r + 0.5) * cell, vx: Math.cos(a) * sp, vy: Math.sin(a) * sp, r: 2 + Math.random() * 3, life: 1, col });
    }
  }
  function burstLine(s, r, c) {
    beep(s === 3 ? 1320 : 880, 0.25, 'square', 0.05);
    if (s === 3) return;
    for (let i = 0; i < N; i++) {
      const rr = s === 1 ? r : i, cc = s === 1 ? i : c;
      particles.push({ x: (cc + 0.5) * cell, y: (rr + 0.5) * cell, vx: 0, vy: 0, r: cell * 0.2, life: 0.8, col: '#fff' });
    }
  }
```

`loop()` の中、`if (state === 'fall') { ... }` のブロックの **後ろ**（`draw(now);` の上）に追加します。

```js:game.js
    for (const pt of particles) {
      pt.x += pt.vx * dt / 1000; pt.y += pt.vy * dt / 1000;
      pt.vy += 300 * dt / 1000; pt.life -= dt / 600;
    }
    particles = particles.filter((pt) => pt.life > 0);
```

### パーティクルの仕組み

1つの粒は「位置 `x, y`・速度 `vx, vy`・半径 `r`・寿命 `life`・色 `col`」を持つオブジェクトです。

- 消えたマスの中心から、ランダムな方向（`cos`・`sin` で角度から方向を作る）とランダムな速さで5粒ずつ飛ばします。
- 毎フレーム「位置に速度 × 時間を足す」「下向きの速度を少しずつ増やす（重力）」「寿命を減らす」を行い、`globalAlpha`（透明度）に寿命を使うので、放物線を描きながらふわっと消えていきます。
- `filter` で寿命が尽きた粒を配列から取り除きます。こうしないと配列がどんどん大きくなって重くなります。
- `burstLine` はラインボム用で、発動した列に沿って白く大きな粒を並べ、その場で光って消える演出にしています。

## キーボードでスタート

`window.addEventListener('pointerup', ...)` の **後ろ** に追加します。

```js:game.js
  window.addEventListener('keydown', (e) => {
    if ((e.key === 'Enter' || e.key === ' ') && (state === 'title' || state === 'over') && !overlay.classList.contains('hidden')) {
      e.preventDefault(); start();
    }
  });
```

タイトル画面かゲームオーバー画面が出ているときだけ、Enter か Space でスタートします。`e.preventDefault()` で、Space でページがスクロールするのを止めています。

> [!CHECK] 動作チェック
> - スタート、入れかえ、そろわず戻る、消える、特殊ジェム誕生・発動で、それぞれ違う効果音が鳴る。連鎖するほど消える音が高くなる
> - 宝石が消えるとき、その色の小さな粒が飛び散って落ちていく。ラインボムは列に沿って白く光る
> - MOVES が 0 になって連鎖が止まると、「手数おしまい！」とスコアが表示される
> - 初回は「ハイスコア更新！」と出て、右上の BEST がスコアと同じ値になる。ベストより低いと「ベスト 〇〇」と出る
> - 「もう一度」または Enter キーで、手数 25・スコア 0 から遊び直せる
> - ページを再読み込みしても BEST の値が残っている

> [!TIP]
> **改造アイデア**
> - 盤面のサイズ `N` や色の数 `COLORS` を変えてみよう。色を5色に減らすと連鎖が起きやすくなり、7色に増やすと（`PALETTE` と `shapePath` に1種類足して）難しくなります
> - ラインボムどうしを入れかえたら「縦横の十字」に消える、という組み合わせ技を作ってみよう。`afterSwap` のカラーボムの分岐と同じように、`ga.s` と `gb.s` を見て `set` を作れば実現できます
> - 3×3 を吹き飛ばす「爆弾」を作ってみよう。L字・T字に5つそろったときに生まれるようにするには、`planClear` で横と縦の run が同じマスを共有しているかを調べます
> - 手数制ではなく「60秒で何点取れるか」のタイムアタックにしてみよう。`loop` の中で `dt` を使って残り時間を減らし、`settle` の `moves <= 0` を時間切れの判定に変えます
> - 「スコア 3000 点で星1つ」のように目標を決めて、ゲームオーバー画面に星を表示してみよう
