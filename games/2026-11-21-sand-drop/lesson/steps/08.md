## このステップのゴール

最後の仕上げです。

- 砂が **赤い線より上で止まったら** ゲームオーバーにして、スコアを表示する
- **ハイスコア** をブラウザに保存し、次に開いたときも残るようにする
- 「もう一度」ボタンや Enter キーで **リトライ** できるようにする
- スコアが増えると **色の種類が増えて** 難しくなる

これで完成品と同じゲームになります。

## ハイスコアを読みこむ

`const SPAWN = 16;` の行の **下** に追加します。

```js:game.js
  const BEST_KEY = 'sand-drop-best';
```

変数の宣言を、次のように **書きかえます**（`best` と `settledFrames` が増えます）。

```js:game.js
  let score = 0, best = 0, chain = 0;
  let piece = null, nextPiece = null, px = 0;
  let cooldown = 0, settledFrames = 0, numColors = 3;
```

`let view = ...` の行の **下**（`beep()` の上）に追加します。

```js:game.js

  try { best = parseInt(localStorage.getItem(BEST_KEY) || '0', 10) || 0; } catch (e) { best = 0; }
  bestEl.textContent = best;
```

### localStorage … ブラウザに小さなデータを保存する

`localStorage` は、ページを閉じても消えない、ブラウザの小さな保存場所です。`localStorage.setItem(キー, 文字列)` で保存し、`localStorage.getItem(キー)` で取り出します。

- 保存できるのは **文字列だけ** なので、取り出したら `parseInt(..., 10)` で数（10進数）に直します
- まだ一度も保存していなければ `getItem` は `null` を返すので、`|| '0'` で `'0'` にしておきます。数に直せなかったとき（`NaN`）のために、最後にも `|| 0` をつけています
- キーの名前は、同じサイトのほかのゲームとぶつからないよう、ゲームごとにちがう名前にします
- プライベートブラウズなどで localStorage が使えないとエラーになることがあるので、`try { ... } catch` で囲んでおきます

## 色を増やして難しくする

`startFlash()` の最後（`setTimeout(...)` の行の **下**）に追加します。

```js:game.js
    numColors = score >= 4000 ? 5 : score >= 1500 ? 4 : 3;
```

スコアが 1500 以上で4色（緑が登場）、4000 以上で5色（紫が登場）にします。`randPiece()` は `numColors` を見て色を選んでいるので、これだけで新しい色のブロックが出てくるようになります。色が増えるほど同じ色をつなげにくくなるので、だんだん難しくなります。

`条件 ? A : B` は **三項演算子** で、「条件が正しければ A、そうでなければ B」です。2つつなげると「4000 以上なら 5、そうでなく 1500 以上なら 4、それ以外は 3」と読めます。

## gameOver() を追加する

`startFlash()` の **下**（`start()` の上）に追加します。

```js:game.js

  function gameOver() {
    state = 'over';
    if (score > best) {
      best = score;
      bestEl.textContent = best;
      try { localStorage.setItem(BEST_KEY, String(best)); } catch (e) { /* ignore */ }
    }
    ovTitle.textContent = 'ゲームオーバー';
    ovText.innerHTML = 'スコア <b class="hl">' + score + '</b><br>ベスト ' + best;
    startBtn.textContent = 'もう一度';
    overlay.classList.remove('hidden');
    beep(160, 0.5, 'sawtooth', 0.06);
  }
```

1. `state` を `'over'` にします。これで `loop()` の砂の動きや、`dropPiece()`・`rotate()`・ポインター操作が止まります
2. スコアが `best` より大きければ、`best` を書きかえて `localStorage` に保存します。`String(best)` で文字列にしてから保存します
3. オーバーレイの見出しと文章を書きかえ、ボタンの文字を「もう一度」にして、`hidden` クラスを外して表示します。`innerHTML` は HTML として文字を入れるので `<br>` や `<b>` が使えます（ここで入れているのは自分で計算した数字だけなので安全です）

「もう一度」ボタンを押したときに呼ばれるのは、これまでどおり `start()` です。

## start() を仕上げる

`start()` 全体を、次のコードに **書きかえます**。

```js:game.js
  function start() {
    grid = new Uint8Array(W * H);
    score = 0; chain = 0; numColors = 3; popups = [];
    flashMask = null; flashT = 0; cooldown = 0.2; settledFrames = 0;
    scoreEl.textContent = '0';
    piece = randPiece(); nextPiece = randPiece();
    px = Math.round((W - pieceSize(piece).w) / 2 / B) * B;
    drawNext();
    state = 'play';
    overlay.classList.add('hidden');
    beep(440, 0.1, 'triangle', 0.06);
  }
```

リトライのときのために、色の数（`numColors`）と `settledFrames` も最初に戻します。`numColors` は `randPiece()` より先に戻しておかないと、前のゲームの色数で最初のブロックが作られてしまいます。

## 砂が止まってから判定する

`dropPiece()` の `cooldown = 0.3;` の行の **下** に追加します。

```js:game.js
    settledFrames = 0;
```

そして `loop()` の中の `if (state === 'play') { ... }` を、次のように **書きかえます**。

```js:game.js
    if (state === 'play') {
      if (cooldown > 0) cooldown -= dt;
      if (flashMask) {
        flashT -= dt;
        if (flashT <= 0) {
          for (const i of flashMask) grid[i] = 0;
          flashMask = null;
          settledFrames = 0;
        }
      } else {
        let moved = simStep();
        moved = simStep() || moved;
        const comp = findClear();
        if (comp) startFlash(comp);
        else if (!moved) {
          settledFrames++;
          if (settledFrames > 3) {
            for (let i = 0; i < SPAWN * W; i++) if (grid[i]) { gameOver(); break; }
          }
        } else settledFrames = 0;
      }
    }
```

### 「止まったか」を数える

ブロックを落とした直後は、砂が赤い線より上にあるのが当たり前です。そこで「赤い線より上に砂がある」だけではなく、**砂が全部止まっている** ときだけゲームオーバーにします。

- ステップ3で作った `simStep()` は、1つぶでも動いたら `true` を返します。2回呼んだ結果を `||` でまとめて `moved` にします。`simStep() || moved` の順番に書くのがポイントで、`moved || simStep()` だと `moved` が `true` のときに2回目の `simStep()` が呼ばれなくなってしまいます
- 動かなかったフレームが続いた数を `settledFrames` で数え、**4フレーム続けて** 止まっていたら「完全に止まった」とみなします。ななめにすべる砂は運しだいで1フレームだけ止まることがあるので、少し余裕を持たせています
- 止まっていたら、赤い線より上のマス（番号 0 〜 `SPAWN * W - 1`）を調べ、1つでも砂があればゲームオーバーです
- 砂が動いたり、ブロックを落としたり、砂が消えたりしたら、`settledFrames` を 0 に戻して数えなおします

## キーボードでリトライ

`keydown` の中の最初の行

```js:game.js
    if (state !== 'play') return;
```

を、次のように **書きかえます**。

```js:game.js
    if (state !== 'play') {
      if (e.key === 'Enter' || e.key === ' ') { e.preventDefault(); start(); }
      return;
    }
```

タイトル画面とゲームオーバー画面では、Enter キーかスペースキーでスタート（リトライ）できるようにします。

> [!CHECK] 動作チェック
> - 砂を積み上げて、赤い線より上で砂が止まると「ゲームオーバー」の画面が出てスコアが表示される
> - ブロックを落とした直後（砂が赤い線より上を落ちている途中）では、ゲームオーバーにならない
> - 上の BEST にスコアが入り、ページを再読み込みしても残っている
> - 「もう一度」や Enter / Space キーで、最初から遊べる
> - スコアが 1500 を超えると緑、4000 を超えると紫のブロックが出てくる
> - 完成品（このゲームのページ）と同じように遊べる

## 改造アイデア

> [!TIP] 砂の箱を広くする
> `W` を 48 や 60 に変えると、横に長くつなげる必要があるので難しくなります。`H` を変えると高さが変わります。`B`（ブロック1マスのつぶ数）を 3 や 5 にすると、砂の細かさの印象ががらっと変わります。

> [!TIP] 水のように流れる砂
> `simStep()` で、真下にもななめ下にも行けないときに、**真横** が空いていれば横に1マス動く処理を足してみましょう。砂が水のように平らに広がるようになり、ちがう遊びごたえになります。

> [!TIP] 消える瞬間に砂が飛び散る
> `flashT` が 0 になって消すとき、消えるつぶのいくつかを「粒子」として `popups` のような一覧に入れ、速度をつけて飛ばしてみましょう。重力（毎フレーム y 方向の速度を少し増やす）を入れると、はじけるような演出になります。

> [!TIP] 次の次まで見せる
> `nextPiece` を配列にして、2つ先・3つ先のブロックまで NEXT に並べてみましょう。先が読めると、連鎖をねらった積み方を考えやすくなります。
