## このステップのゴール

3つのファイルを用意して、ゲーム画面の土台を作ります。上に「SCORE・BEST」、まん中にゲームを描く **Canvas**（キャンバス）とその上に重ねるタイトル画面（オーバーレイ）、下に「NEXT」と「回転」ボタンを置きます。Canvas には、砂をためる縦長の **箱** と、ゲームオーバーの目印になる **赤い点線** を描きます。

完成すると、こんなゲームになります。

- 上から落としたブロックが、着地すると **さらさらの砂つぶ** になってくずれ、山のように積もる
- 落とす位置は、画面を **左右になぞって** 決め、指を離すと落ちる。「回転」ボタンでブロックの向きを変えられる
- 同じ色の砂が **左のかべから右のかべまで** ひと続きにつながると、その色の砂がまとめて消えてスコアになる
- 消えたあとに砂がくずれて、また別の色がつながると **連鎖** でスコアが倍増
- 砂が **赤い線より上** で止まったらゲームオーバー。ハイスコアはブラウザに保存される

## game.js

JavaScript はまず「画面の大きさに合わせて Canvas を用意し、砂をためる箱を描きつづける」ところまでを書きます。

```js:game.js
(() => {
  'use strict';
  const W = 40, H = 76, B = 4;          // grid size in grains, block = 4x4 grains
  const SPAWN = 16;                       // rows above the red line

  const cv = document.getElementById('cv');
  const ctx = cv.getContext('2d');
  const nextCv = document.getElementById('nextcv');
  const nctx = nextCv.getContext('2d');
  const scoreEl = document.getElementById('score');
  const bestEl = document.getElementById('best');
  const overlay = document.getElementById('overlay');
  const ovTitle = document.getElementById('ov-title');
  const ovText = document.getElementById('ov-text');
  const startBtn = document.getElementById('start');
  const rotBtn = document.getElementById('rot');

  let state = 'title';
  let view = { x: 0, y: 0, s: 1 };

  function start() {
    state = 'play';
    overlay.classList.add('hidden');
  }

  // --- input ---
  startBtn.addEventListener('click', start);

  // --- render ---
  function resize() {
    const r = cv.getBoundingClientRect();
    const dpr = window.devicePixelRatio || 1;
    cv.width = Math.round(r.width * dpr);
    cv.height = Math.round(r.height * dpr);
    const s = Math.min(cv.width / W, cv.height / H);
    view = { s: s / dpr, x: (r.width - W * s / dpr) / 2, y: (r.height - H * s / dpr) / 2, dpr };
  }
  window.addEventListener('resize', resize);

  function render(time) {
    const dpr = view.dpr || 1;
    ctx.setTransform(1, 0, 0, 1, 0, 0);
    ctx.clearRect(0, 0, cv.width, cv.height);
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);

    const s = view.s;
    // field background (step 2 で砂の絵に置きかえる)
    ctx.fillStyle = 'rgb(44,34,22)';
    ctx.fillRect(view.x, view.y, W * s, SPAWN * s);
    ctx.fillStyle = 'rgb(58,48,36)';
    ctx.fillRect(view.x, view.y + SPAWN * s, W * s, (H - SPAWN) * s);

    // red danger line
    ctx.strokeStyle = 'rgba(255,80,80,.9)';
    ctx.lineWidth = 2;
    ctx.setLineDash([8, 6]);
    ctx.beginPath();
    ctx.moveTo(view.x, view.y + SPAWN * s);
    ctx.lineTo(view.x + W * s, view.y + SPAWN * s);
    ctx.stroke();
    ctx.setLineDash([]);

    // frame
    ctx.strokeStyle = '#6b5136';
    ctx.lineWidth = 2;
    ctx.strokeRect(view.x - 1, view.y - 1, W * s + 2, H * s + 2);
  }

  function loop(now) {
    render(now);
    requestAnimationFrame(loop);
  }

  resize();
  requestAnimationFrame(loop);
})();
```

### 全体を (() => { ... })(); で囲む

ファイル全体を「すぐ実行される関数」で囲むと、中で作った変数がページ全体（グローバル）に漏れません。`'use strict';` は、うっかりミスをエラーとして教えてくれるモードです。

### 砂の世界は「40 × 76 マス」

このゲームのいちばん大事な決めごとが、最初の2行です。

- `W = 40, H = 76` … 砂の箱は **横 40 つぶ × 縦 76 つぶ** のマス目（グリッド）でできています。1マスに砂つぶが1つ入ります
- `B = 4` … ブロックの1マスは **砂つぶ 4 × 4 個分** の大きさです。つまり箱の横幅はブロック10個分です
- `SPAWN = 16` … 上から 16 つぶ分が「ブロックが浮かんでいる場所」で、その下の境目が **赤い線** です

画面のピクセルではなく「つぶ」を単位にして考えておくと、スマホでもパソコンでも同じルールで動き、表示するときに拡大するだけで済みます。

### resize() … 画面の大きさから表示の倍率を決める

1. `cv.getBoundingClientRect()` で、Canvas の実際の大きさ（CSS ピクセル）を測ります
2. `devicePixelRatio`（dpr）は、高精細な画面で「CSS の 1px が実際は何ドットか」を表す数です。Canvas の中身のピクセル数（`cv.width`・`cv.height`）を dpr 倍にすると、ぼやけずにくっきり描けます
3. `s = Math.min(cv.width / W, cv.height / H)` は「砂つぶ1つを何ドットで描くか」です。横に合わせた倍率と縦に合わせた倍率の **小さいほう** を選ぶと、箱がはみ出さずに画面に収まります
4. `view` には、倍率 `s`（CSS ピクセル単位に直したもの）と、箱を画面のまん中に置くための左上の位置 `x`・`y` を入れます。これからは **「つぶの座標 × view.s + view.x」で画面の位置** が求まります

ウィンドウの大きさが変わったら（スマホを横にしたときなど）、もう一度 `resize()` を呼びます。

### render() と loop() … 毎フレーム描きなおす

`render()` の最初の3行は、まず変形をリセットして画面を全部消し、それから `ctx.setTransform(dpr, 0, 0, dpr, 0, 0)` で「これから描くものを全部 dpr 倍する」設定にしています。これで、このあとは CSS ピクセルの座標のまま描けば画面にぴったり合います。

- 赤い線より上（ブロックが浮かぶ場所）を少し暗い茶色、下（砂がたまる場所）を少し明るい茶色でぬります。この2つの四角は、ステップ2で砂の絵に置きかえます
- `setLineDash([8, 6])` は「8 描いて 6 あける」点線の設定です。描いたら `setLineDash([])` で実線に戻しておきます
- 最後に `strokeRect` で箱のふちを描きます

`loop()` は `render()` を呼んだあと `requestAnimationFrame(loop)` で「次に画面を書きかえるタイミングで、もう一度 loop を呼んで」とブラウザに頼みます。これで1秒間に約60回、描きなおしが続きます。`loop` には、ブラウザが「今の時刻（ミリ秒）」を `now` として渡してくれます。

### start() とボタン

スタートボタンが押されたら `start()` を呼び、`state` を `'play'` にしてオーバーレイに `hidden` クラスをつけて隠します。`state` はゲームの状態で、`'title'`（タイトル画面）・`'play'`（プレイ中）・`'over'`（ゲームオーバー）のどれかになります。

> `scoreEl`・`nctx`・`rotBtn` などはまだ使っていませんが、先に取り出しておきます。あとのステップで使います。
