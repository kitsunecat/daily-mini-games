## このステップのゴール

ゲームを気持ちよくする演出を足します。

- 消えたあとに砂がくずれて、また別の色がつながったら **連鎖**。2連鎖なら2倍、3連鎖なら3倍の点数にする
- 消えた場所に「+120」「2連鎖! +240」のような **得点のポップアップ** を出して、ふわっと上に消す
- 回転・落下・消去・スタートで **効果音** を鳴らす

## 変数を追加する

`let score = 0;` の行を、次のように **書きかえます**。

```js:game.js
  let score = 0, chain = 0;
```

`let cooldown = 0, numColors = 3;` の **下** に追加します。

```js:game.js
  let popups = [];
  let audio = null;
```

`chain` は今の連鎖数、`popups` は表示中の得点ポップアップの一覧、`audio` は効果音を鳴らす装置（あとで作ります）です。

## 効果音を鳴らす beep()

`let view = ...` の行の **下**（`randPiece()` の上）に追加します。

```js:game.js

  function beep(freq, dur, type, vol) {
    try {
      if (!audio) audio = new (window.AudioContext || window.webkitAudioContext)();
      const o = audio.createOscillator(), g = audio.createGain();
      o.type = type || 'sine'; o.frequency.value = freq;
      g.gain.setValueAtTime(vol || 0.08, audio.currentTime);
      g.gain.exponentialRampToValueAtTime(0.001, audio.currentTime + dur);
      o.connect(g); g.connect(audio.destination);
      o.start(); o.stop(audio.currentTime + dur);
    } catch (e) { /* ignore */ }
  }
```

### Web Audio API

音声ファイルを用意しなくても、ブラウザの **Web Audio API** で「ピッ」という音をその場で作れます。

- `AudioContext` … 音を作る装置。古い Safari 用に `webkitAudioContext` も試します。ブラウザは「ユーザーが何か操作するまで音を鳴らさない」決まりがあるので、最初に音を鳴らすとき（スタートボタンを押したとき）に作ります
- `createOscillator()` … 決まった高さ（`frequency`、ヘルツ）の音をずっと出す **発振器**。`type` で音色を選べます（`'sine'` はやわらかい音、`'square'` はピコピコ音、`'triangle'` はその中間、`'sawtooth'` はジリジリした音）
- `createGain()` … 音量つまみ。`exponentialRampToValueAtTime` で、`dur` 秒かけて音量を 0.001 までなめらかに下げると、「ポン」と減衰する音になります
- 発振器 → 音量つまみ → スピーカー（`audio.destination`）の順に `connect` でつなぎ、`start()` で鳴らして `stop()` で止めます

音が出ない環境でもゲームが止まらないように、全体を `try { ... } catch` で囲んでいます。

## 効果音を鳴らす場所

`rotate()` の最後の `clampPx();` の **下** に追加します。

```js:game.js
    beep(520, 0.05, 'triangle', 0.05);
```

`dropPiece()` の後半を、次のように **書きかえます**（`chain = 0;` と `beep(...)` の2行が増えます）。

```js:game.js
    chain = 0;
    piece = nextPiece;
    nextPiece = randPiece();
    clampPx();
    cooldown = 0.3;
    drawNext();
    beep(220, 0.08, 'square', 0.04);
  }
```

新しいブロックを落としたら、連鎖の数を 0 に戻します。つまり「ブロックを1つ落としてから、次を落とすまでに何回消えたか」が連鎖数になります。

## startFlash() で連鎖とポップアップ

`startFlash()` 全体を、次のコードに **書きかえます**。

```js:game.js
  function startFlash(comp) {
    flashMask = comp;
    flashT = 0.4;
    chain++;
    const mult = chain;
    const gained = Math.round(comp.length / 4) * 10 * mult;
    score += gained;
    scoreEl.textContent = score;
    let sy = 0;
    for (const i of comp) sy += (i / W) | 0;
    popups.push({ text: (mult > 1 ? chain + '連鎖! ' : '') + '+' + gained, y: sy / comp.length, t: 1.2 });
    beep(660 + chain * 120, 0.18, 'triangle', 0.09);
    setTimeout(() => beep(880 + chain * 120, 0.2, 'triangle', 0.07), 90);
  }
```

- 消えるたびに `chain` を1増やし、点数を `chain` 倍にします
- ポップアップは、消える砂つぶの y 座標の **平均**（`sy / comp.length`）の高さに出します。だいたい消えた帯のまん中あたりです
- `t: 1.2` はポップアップの残り時間（秒）です
- 効果音は2つ続けて鳴らします。`setTimeout(関数, 90)` で 90 ミリ秒後に少し高い音を鳴らすと「ピロン♪」と聞こえます。連鎖するほど音が高くなります

## start() で連鎖とポップアップをリセット

`start()` の `score = 0;` の行を、次のように **書きかえます**。

```js:game.js
    score = 0; chain = 0; popups = [];
```

さらに `start()` の最後の `overlay.classList.add('hidden');` の **下** に追加します。

```js:game.js
    beep(440, 0.1, 'triangle', 0.06);
```

## ポップアップを動かして描く

`loop()` の中、`if (state === 'play') { ... }` の **下**（`render(now);` の上）に追加します。

```js:game.js
    for (const p of popups) p.t -= dt;
    popups = popups.filter(p => p.t > 0);
```

残り時間を減らし、`filter` で時間切れのものを一覧から取りのぞきます。

`render()` の中、`// hovering piece + guide` の `if` ブロックの **下**（`// frame` の上）に追加します。

```js:game.js

    // popups
    ctx.textAlign = 'center';
    ctx.font = 'bold 22px system-ui, sans-serif';
    for (const p of popups) {
      ctx.globalAlpha = Math.min(1, p.t);
      ctx.fillStyle = '#fff3c4';
      ctx.strokeStyle = 'rgba(0,0,0,.6)';
      ctx.lineWidth = 4;
      const y = view.y + p.y * s - (1.2 - p.t) * 40;
      ctx.strokeText(p.text, view.x + W * s / 2, y);
      ctx.fillText(p.text, view.x + W * s / 2, y);
    }
    ctx.globalAlpha = 1;
```

- 文字は箱の横まん中（`textAlign = 'center'`）に描きます
- 時間がたつほど `(1.2 - p.t) * 40` が大きくなるので、**だんだん上に** ずれていきます。残り1秒を切ると `globalAlpha` が下がって **うすれて** 消えます
- `strokeText` で黒っぽいふちどりを描いてから `fillText` で中をぬると、どんな色の砂の上でも文字が読みやすくなります

> [!CHECK] 動作チェック
> - ブロックを回す・落とす・スタートするたびに短い効果音が鳴る
> - 砂が消えると「ピロン♪」と鳴り、消えた高さに「+〇〇」の文字が出て、上にずれながらうすれて消える
> - 1回消えたあとに砂がくずれて別の色がつながると「2連鎖! +〇〇」と出て、点数が2倍になる
