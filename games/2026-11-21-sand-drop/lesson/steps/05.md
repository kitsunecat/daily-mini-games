## このステップのゴール

スマホでも遊べるように、**画面を左右になぞってブロックの位置を合わせ、指を離すと落ちる** 操作を作ります。パソコンではマウスで同じ操作ができ、さらにマウスを動かすだけでブロックがついてきます。あわせて「回転」ボタンと ↑ キーでブロックを90度回せるようにします。

## rotate() を追加する

`function clampPx() {` の **上** に追加します。

```js:game.js
  function rotate() {
    if (state !== 'play' || !piece) return;
    const cx = px + pieceSize(piece).w / 2;
    let cells = piece.cells.map(([x, y]) => [-y, x]);
    const mx = Math.min(...cells.map(c => c[0])), my = Math.min(...cells.map(c => c[1]));
    piece.cells = cells.map(([x, y]) => [x - mx, y - my]);
    px = Math.round(cx - pieceSize(piece).w / 2);
    clampPx();
  }
```

### 座標を [-y, x] にすると90度回る

点 `(x, y)` を `(-y, x)` に移すと、原点のまわりを **90度回転** します（画面の座標は y が下向きなので、見た目は時計回りです）。たとえば横棒 `[0,0] [1,0] [2,0] [3,0]` は `[0,0] [0,1] [0,2] [0,3]` の縦棒になります。

ただし回転すると x がマイナスになることがあります。そこで、回転後のいちばん小さい x（`mx`）と y（`my`）を全部から引いて、**左上が (0, 0) から始まる形** に直します。`Math.min(...配列)` の `...` は、配列の中身をばらして関数に渡す書き方（スプレッド構文）です。

### 中心をそろえる

回転すると幅が変わるので、そのままだとブロックが右や左にずれて見えます。回す前のブロックの中心 `cx` を覚えておき、回したあとに **同じ中心になるように `px` を計算しなおし** ます。最後に `clampPx()` で、かべからはみ出していれば押しもどします。

## 指・マウスの操作を追加する

`// --- input ---` の行の **下**、`startBtn.addEventListener('click', start);` の **上** に追加します。

```js:game.js
  let dragging = false;
  function pointerToPx(clientX) {
    const r = cv.getBoundingClientRect();
    const gx = (clientX - r.left - view.x) / view.s;
    if (!piece) return;
    px = Math.round(gx - pieceSize(piece).w / 2);
    clampPx();
  }
  cv.addEventListener('pointerdown', e => {
    if (state !== 'play') return;
    e.preventDefault();
    dragging = true;
    try { cv.setPointerCapture(e.pointerId); } catch (err) { /* ignore */ }
    pointerToPx(e.clientX);
  });
  cv.addEventListener('pointermove', e => {
    if (state !== 'play') return;
    if (dragging || e.pointerType === 'mouse') pointerToPx(e.clientX);
  });
  cv.addEventListener('pointerup', e => {
    if (!dragging) return;
    dragging = false;
    pointerToPx(e.clientX);
    dropPiece();
  });
  cv.addEventListener('pointercancel', () => { dragging = false; });
  rotBtn.addEventListener('click', e => { e.preventDefault(); rotate(); });
```

### ポインターイベント

`pointerdown`（押した）・`pointermove`（動いた）・`pointerup`（離した）は **ポインターイベント** といって、マウスでも指でもペンでも同じように受け取れる便利なイベントです。`e.pointerType` を見ると、`'mouse'`・`'touch'`・`'pen'` のどれで操作されたか分かります。

- 押したら `dragging = true` にして、その位置にブロックを動かします
- 動いたら、押している間（`dragging`）だけブロックを動かします。ただしマウスのときは、押していなくても **ついてくる** ようにしています
- 離したら、最後の位置に合わせてから `dropPiece()` で落とします
- `pointercancel` は、電話がかかってきたときなど、操作が途中で取り消されたときに来ます。落とさずに終わりにします

`setPointerCapture` は「指が Canvas の外に出ても、離すまでこの Canvas にイベントを送って」という設定です。なぞっている途中で指が少しはみ出しても、ちゃんと `pointerup` が届きます。

### 画面の座標 → 砂つぶの座標

`pointerToPx()` は、ステップ1の「つぶの座標 × view.s + view.x = 画面の位置」を **逆算** しています。

1. `e.clientX` はページの左はしからの位置なので、Canvas の左はし（`r.left`）を引いて、Canvas の中の位置にします
2. さらに箱の左はし（`view.x`）を引いて、倍率 `view.s` で割ると、**砂つぶ単位の x**（`gx`）になります
3. 指の位置がブロックの **まん中** に来るように、幅の半分を引いて `px` にします

## キーボードで回転

`keydown` の中、`ArrowRight` の行の **下** に追加します。

```js:game.js
    else if (e.key === 'ArrowUp' || e.key === 'x' || e.key === 'X') { rotate(); e.preventDefault(); }
```

> [!TIP]
> 指を離したときに落とす方式なら、なぞっている間はまだ落ちないので、ゆっくり位置を合わせられます。「タップした瞬間に落ちる」方式とくらべて、小さな画面でもねらった場所に落としやすくなります。

> [!CHECK] 動作チェック
> - パソコンでは、マウスを左右に動かすとブロックがついてくる。クリックするとその位置に落ちる
> - スマホ（または開発者ツールのデバイスモード）では、画面を左右になぞるとブロックが動き、指を離すと落ちる
> - 「⟳ 回転」ボタンや ↑ キーで、ブロックが90度ずつ回る。回してもブロックの中心がずれない
> - 箱のはしで回しても、ブロックがかべからはみ出さない
