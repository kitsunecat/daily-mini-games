## このステップのゴール

このゲームの主役、**砂が落ちてくずれるシミュレーション** を作ります。ルールはとてもシンプルです。

1. 真下が空いていたら、真下に落ちる
2. 真下がふさがっていたら、**ななめ下**（左下か右下）が空いていれば、そちらへすべり落ちる
3. どちらもふさがっていたら、そのまま止まる

これを全部のつぶに毎フレームくり返すだけで、砂が山の形に積もっていきます。

## simStep() を追加する

`start()` 関数の **上** に追加します。

```js:game.js
  let flip = false;
  function simStep() {
    let moved = false;
    flip = !flip;
    for (let y = H - 2; y >= 0; y--) {
      const row = y * W, below = row + W;
      for (let i = 0; i < W; i++) {
        const x = flip ? i : W - 1 - i;
        const v = grid[row + x];
        if (!v) continue;
        if (!grid[below + x]) { grid[below + x] = v; grid[row + x] = 0; moved = true; continue; }
        const d = Math.random() < 0.5 ? -1 : 1;
        const x1 = x + d, x2 = x - d;
        if (x1 >= 0 && x1 < W && !grid[below + x1] && !grid[row + x1]) {
          grid[below + x1] = v; grid[row + x] = 0; moved = true;
        } else if (x2 >= 0 && x2 < W && !grid[below + x2] && !grid[row + x2]) {
          grid[below + x2] = v; grid[row + x] = 0; moved = true;
        }
      }
    }
    return moved;
  }
```

### 下の行から上へ順に調べる

`y` を `H - 2`（下から2行目）から `0`（いちばん上）へ、**下から順に** 調べます。いちばん下の行（`H - 1`）は、もう下がないので調べません。

もし上から順に調べると、1行落としたつぶを次の行でまた見つけて、さらに落として…と、**1回で底まで一気に落ちて** しまいます。下から調べれば、1回の `simStep()` でどのつぶも最大1マスしか動きません。

`row` は y 行目の先頭の番号、`below` はその真下の行の先頭の番号です。`grid[below + x]` で真下のマスが見られます。

### 真下 → ななめ下の順に空きを探す

- 真下が空いていれば（`!grid[below + x]`）、値を真下に移して元の場所を 0 にします。`continue` で次のつぶへ進みます
- 真下がふさがっていたら、左右どちらを先に試すかを `Math.random()` で決めます（`d` が -1 なら左、1 なら右）。いつも左から試すと、砂山が左にかたむいてしまうからです
- ななめに動くときは、**ななめ下だけでなく真横（`grid[row + x1]`）も空いているか** 確かめます。かべのすき間を砂がすりぬけないようにするためです
- `x1 >= 0 && x1 < W` で、箱の外に出ないようにします

### flip … 左右の調べる順番を毎回入れかえる

1行の中でも、左から調べるか右から調べるかで結果がかたよります（たとえば右へすべったつぶを、同じ行のうちにもう一度見つけてしまう）。そこで `flip` を毎回反転させ、**左から → 右から → 左から…** と交互に調べます。

`moved` は「1つぶでも動いたか」です。今はまだ使いませんが、ステップ8で「砂が止まったか」を判定するのに使います。

## loop() で毎フレーム動かす

`loop()` を次のように **書きかえます**。

```js:game.js
  function loop(now) {
    if (state === 'play') {
      simStep();
      simStep();
    }
    render(now);
    requestAnimationFrame(loop);
  }
```

プレイ中だけ、1フレームに `simStep()` を **2回** 呼びます。1回だと砂の落ちるのが少しゆっくりすぎるので、2回にして速さを調整しています。3回にすればもっと速く落ちます。

> [!NOTE]
> このような「マス目の1つ1つが、まわりの様子を見て次の状態を決める」しくみを **セル・オートマトン** と呼びます。水や火、植物の成長などを表現するゲームでもよく使われます。

> [!CHECK] 動作チェック
> - スタートすると、赤と青の四角がくずれながら落ちていく
> - 底に着くと、左右にすべり落ちて **三角の山** の形に積もる
> - 青い砂は赤い線より上から落ちてきて、赤い線を通りすぎて底にたまる
> - 箱の左右のかべから砂がはみ出さない
