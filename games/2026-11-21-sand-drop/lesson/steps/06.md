## このステップのゴール

ゲームのルールの核心、**同じ色の砂が左のかべから右のかべまでつながったら消える** を作ります。

- 左のかべに接している砂から、同じ色でつながっている砂を全部たどる（**塗りつぶし探索**）
- その中に右のかべに接している砂があれば「つながった！」
- つながった砂を 0.4 秒ピカピカ光らせてから消し、スコアを足す

## 変数を追加する

`let grid = new Uint8Array(W * H);` の **下** に追加します。

```js:game.js
  let flashMask = null, flashT = 0;
```

`let state = 'title';` の **下** に追加します。

```js:game.js
  let score = 0;
```

`flashMask` は「いま光っている（これから消える）砂つぶの番号の一覧」、`flashT` は消えるまでの残り時間（秒）です。

## findClear() と startFlash() を追加する

`start()` 関数の **上**（`simStep()` の下）に追加します。

```js:game.js
  // Find colors connected from left wall to right wall.
  function findClear() {
    const seen = new Uint8Array(W * H);
    const stack = [];
    for (let y0 = SPAWN; y0 < H; y0++) {
      const start = y0 * W;
      const v0 = grid[start];
      if (!v0 || seen[start]) continue;
      const c = v0 >> 2;
      const comp = [];
      let reachRight = false;
      stack.push(start); seen[start] = 1;
      while (stack.length) {
        const i = stack.pop();
        comp.push(i);
        const x = i % W, y = (i / W) | 0;
        if (x === W - 1) reachRight = true;
        const nb = [x > 0 ? i - 1 : -1, x < W - 1 ? i + 1 : -1, y > 0 ? i - W : -1, y < H - 1 ? i + W : -1];
        for (const n of nb) {
          if (n < 0 || seen[n]) continue;
          const v = grid[n];
          if (v && (v >> 2) === c) { seen[n] = 1; stack.push(n); }
        }
      }
      if (reachRight) return comp;
    }
    return null;
  }

  function startFlash(comp) {
    flashMask = comp;
    flashT = 0.4;
    const gained = Math.round(comp.length / 4) * 10;
    score += gained;
    scoreEl.textContent = score;
  }
```

### 左のかべから出発する

左右をつなぐ砂の帯は、**必ず左のかべ（x = 0）のどこかに接して** います。なので、左はしの列を赤い線より下（`SPAWN`）から底まで1マスずつ見て、砂があればそこを出発点にします。左はしのマスの番号は `y0 * W` です。

### 塗りつぶし探索（フラッドフィル）

出発点と同じ色でつながっている砂を全部見つけるのに、**スタック**（積み上げる配列）を使います。

1. 出発点をスタックに積み、`seen`（もう見たよ、の印）をつける
2. スタックから1つ取り出し（`pop`）、`comp`（見つけた仲間の一覧）に入れる
3. その **上下左右** のマスを調べ、まだ見ていない同じ色の砂なら印をつけてスタックに積む
4. スタックが空になるまで 2〜3 をくり返す

ペンキを1か所にたらすと、同じ色の部分にだけ広がっていくイメージです。お絵かきソフトの「塗りつぶし」と同じしくみなので **フラッドフィル** と呼ばれます。

- 上下左右のとなりの番号は、左 `i - 1`・右 `i + 1`・上 `i - W`・下 `i + W` です。箱の外になるときは `-1` にしておき、`n < 0` で飛ばします。左右のはしで `i - 1` をそのまま使うと、1つ上の行の右はしにつながってしまうので注意しましょう
- 色が同じかどうかは `>> 2` で色の番号だけ取り出して比べます（濃さはちがってもよい）
- 調べた中に x が `W - 1`（右はし）のマスがあれば `reachRight = true` です。たどり終わったときに `true` なら、その仲間の一覧を返します

一度たどった砂には `seen` の印がつくので、左はしで同じかたまりに何度も出会っても、もう一度たどることはありません。

### startFlash() … 光らせて点数を足す

つながった砂の一覧を `flashMask` に入れ、0.4 秒のタイマーをセットします。点数は **消える砂つぶの数 ÷ 4 × 10 点** です。たくさんの砂をまとめて消すほど高得点になります。

## start() を書きかえる

`start()` の最初の2行を、次のように **書きかえます**。

```js:game.js
  function start() {
    grid = new Uint8Array(W * H);
    score = 0;
    flashMask = null; flashT = 0; cooldown = 0.2;
    scoreEl.textContent = '0';
    piece = randPiece(); nextPiece = randPiece();
```

`piece = randPiece(); ...` から下はそのままです。

## 光っている砂を描く

`render()` の最初の `const d = img.data;` の **下** に追加します。

```js:game.js
    const flashOn = flashMask && Math.floor(time / 70) % 2 === 0;
    let fm = null;
    if (flashOn) { fm = new Uint8Array(W * H); for (const i of flashMask) fm[i] = 1; }
```

さらに、`for` の中の `if (!v) { ... continue; }` の **下**（`const c = COLORS[...]` の上）に追加します。

```js:game.js
      if (fm && fm[i]) { d[o] = 255; d[o + 1] = 255; d[o + 2] = 240; d[o + 3] = 255; continue; }
```

- `time` は `loop()` から渡されている今の時刻（ミリ秒）です。`Math.floor(time / 70) % 2` は 70 ミリ秒ごとに 0 と 1 が入れかわるので、**点滅** に使えます
- 点灯中は、消える砂つぶに印をつけた配列 `fm` を作り、そのマスを白っぽい色でぬります。`flashMask` の一覧のまま「このマスは入っている？」と毎回探すと遅いので、いったん印の配列に変えています

## loop() で消す流れを作る

`loop()` の中の `if (state === 'play') { ... }` を、次のように **書きかえます**。

```js:game.js
    if (state === 'play') {
      if (cooldown > 0) cooldown -= dt;
      if (flashMask) {
        flashT -= dt;
        if (flashT <= 0) {
          for (const i of flashMask) grid[i] = 0;
          flashMask = null;
        }
      } else {
        simStep();
        simStep();
        const comp = findClear();
        if (comp) startFlash(comp);
      }
    }
```

- 光っている間（`flashMask` がある間）は、**砂の動きを止めて** タイマーだけ進めます。止めておかないと、光っている砂が動いて、消す場所がずれてしまいます
- 時間が来たら、一覧の砂を全部 0 にして消します。すると上に乗っていた砂が、次のフレームからまたさらさら落ちてきます
- 光っていないときは、砂を動かしたあとに `findClear()` で毎フレームつながりを調べます

> [!NOTE]
> 毎フレーム全部の砂をたどるのは重そうに見えますが、マスは全部で 3040 個しかないので、今のパソコンやスマホなら一瞬で終わります。

> [!CHECK] 動作チェック
> - 同じ色のブロックを横に並べて落とし、左のかべから右のかべまでつなげると、その色の砂が白く点滅してから消える
> - 消えると SCORE が増える。たくさん消すほど増え方が大きい
> - 消えたあと、上に乗っていた砂がくずれ落ちる
> - 色がちがう砂がまざって途切れていると消えない
