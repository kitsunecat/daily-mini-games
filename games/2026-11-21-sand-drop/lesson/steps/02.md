## このステップのゴール

砂つぶ1つ1つを、40 × 76 の **ドット絵** として描けるようにします。砂の情報は1本の数の配列（`grid`）に入れておき、それを毎フレーム画像に変換して、箱いっぱいに拡大して表示します。

まだ砂は動きません。動作確認のために、スタートすると赤と青の砂のかたまりが置かれるようにしておきます（このテスト用コードはステップ4で消します）。

## 色の一覧を追加する

`const SPAWN = 16;` の行の **下** に追加します。

```js:game.js
  const COLORS = [
    null,
    [232, 76, 61],   // red
    [246, 196, 52],  // yellow
    [64, 140, 230],  // blue
    [76, 190, 110],  // green
    [170, 100, 220], // purple
  ];
```

砂の色を `[赤, 緑, 青]`（それぞれ 0〜255）の3つの数で持ちます。番号 0 は「砂がない」の意味で使いたいので、先頭は `null` にしておき、**色の番号は 1 から** 始めます（1 = 赤、2 = 黄、3 = 青、4 = 緑、5 = 紫）。

## グリッドと「裏の Canvas」を用意する

`const rotBtn = ...` の行の下、`let state = 'title';` の **上** に追加します。

```js:game.js
  const off = document.createElement('canvas');
  off.width = W; off.height = H;
  const octx = off.getContext('2d');
  const img = octx.createImageData(W, H);

  // grid value: 0 empty, otherwise color*4 + shade (shade 0..3)
  let grid = new Uint8Array(W * H);
```

### grid … 盤面を1本の配列で持つ

`Uint8Array(W * H)` は、0〜255 の整数だけを入れられる、長さ 40 × 76 = 3040 の配列です。最初は全部 0（砂なし）です。

2次元のマス目を1本の配列で持つときは、**(x, y) のマスを `grid[y * W + x]` に入れる** と決めます。1行は W 個なので、y 行目は `y * W` 番目から始まる、という考え方です。逆に、番号 `i` から座標に戻すときは `x = i % W`（割った余り）、`y = (i / W) | 0`（割り算して小数を切り捨て）です。`| 0` は「整数にする」ためのよく使う書き方です。

### 1つの数に「色」と「濃さ」を詰めこむ

本物の砂っぽく見せるため、つぶごとに少しずつ明るさを変えます。そこで、マスに入れる数を **`色の番号 × 4 + 濃さ（0〜3）`** にします。

- 赤（1）で濃さ 2 なら `1 * 4 + 2 = 6`
- 取り出すときは、色が `v >> 2`、濃さが `v & 3` です

`>> 2` は「2ビット右にずらす」で、4 で割って切り捨てるのと同じです。`& 3` は「下の2ビットだけ取り出す」で、4 で割った余りと同じです。こうしておくと、0 以外ならどんな値でも「砂がある」と判定でき、色が同じかどうかも `>> 2` で比べるだけで済みます。

### 裏の Canvas（オフスクリーン Canvas）

`document.createElement('canvas')` で、画面には出さない **40 × 76 ピクセルの小さな Canvas** を作ります。`createImageData(W, H)` は、その大きさの **ピクセルの入れもの**（ImageData）です。`img.data` は1ピクセルにつき `[R, G, B, A]` の4つの数が並んだ配列で、ここに直接色を書きこめます。

1つぶ = 1ピクセルの絵を裏の Canvas に作ってから、本物の Canvas に拡大して貼る、という2段がまえで描きます。3040 個のつぶを1つずつ `fillRect` で描くより、ずっと速く描けます。

## render() の前半を書きかえる

`function render(time) {` から `const s = view.s;` までと、その下の `// field background` の2つの四角をぬる部分を、次のように **書きかえます**。`render()` の上に `SHADE` の行も足します。

```js:game.js
  const SHADE = [1.0, 0.9, 0.8, 1.1];
  function render(time) {
    const d = img.data;
    for (let i = 0; i < W * H; i++) {
      const v = grid[i], o = i * 4;
      if (!v) {
        const y = (i / W) | 0;
        const base = y < SPAWN ? 44 : 58;
        d[o] = base; d[o + 1] = base - 10; d[o + 2] = base - 22; d[o + 3] = 255;
        continue;
      }
      const c = COLORS[v >> 2], k = SHADE[v & 3];
      d[o] = Math.min(255, c[0] * k); d[o + 1] = Math.min(255, c[1] * k); d[o + 2] = Math.min(255, c[2] * k); d[o + 3] = 255;
    }
    octx.putImageData(img, 0, 0);

    const dpr = view.dpr || 1;
    ctx.setTransform(1, 0, 0, 1, 0, 0);
    ctx.clearRect(0, 0, cv.width, cv.height);
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
    ctx.imageSmoothingEnabled = false;
    ctx.drawImage(off, view.x, view.y, W * view.s, H * view.s);

    const s = view.s;
    // red danger line
```

`// red danger line` から下（赤い点線と箱のふち）は、ステップ1のままです。

- グリッドの全マスを1つずつ見て、`img.data` の `i * 4` 番目から4つの数（R, G, B, 不透明度）を書きこみます
- 砂がないマス（`!v`）は背景の色です。ステップ1の四角と同じく、赤い線より上は `44`、下は `58` を元にした茶色にします
- 砂があるマスは `COLORS[色]` に `SHADE[濃さ]` をかけた色にします。`1.1` 倍で 255 を超えないように `Math.min(255, ...)` で頭打ちにしています
- `putImageData` で、できたピクセルを裏の Canvas に一気に書きこみます
- `drawImage(off, x, y, 幅, 高さ)` で、40 × 76 の小さな絵を箱の大きさまで **拡大して** 貼ります。`imageSmoothingEnabled = false` にすると、拡大してもぼやけず、カクカクのドット絵のままになります

## テスト用の砂を置く

`start()` を次のように **書きかえます**。

```js:game.js
  function start() {
    grid = new Uint8Array(W * H);
    // テスト用: 赤と青の砂のかたまりを置く（ステップ4で消す）
    for (let y = 40; y < 52; y++) for (let x = 4; x < 16; x++) grid[y * W + x] = 1 * 4 + Math.floor(Math.random() * 4);
    for (let y = 4; y < 14; y++) for (let x = 22; x < 34; x++) grid[y * W + x] = 3 * 4 + Math.floor(Math.random() * 4);
    state = 'play';
    overlay.classList.add('hidden');
  }
```

スタートのたびに `grid` を新しい空の配列にしてから、赤（1）と青（3）の四角いかたまりを置きます。濃さは `Math.floor(Math.random() * 4)` で 0〜3 をランダムに選ぶので、ざらっとした砂の見た目になります。

> [!CHECK] 動作チェック
> - スタートすると、赤い線より上に青い四角、下に赤い四角が表示される
> - 四角の中が少しずつ明るさのちがうドットでできていて、ぼやけずにくっきり見える
> - ウィンドウの大きさを変えても、ドットがにじまない
> - Console にエラーが出ていない
