## このステップのゴール

困ったときの助け舟、**ヒント** と **シャッフル** を作ります。

- ヒント（3回）… 取れるペアを1組、水色に光らせる
- シャッフル（2回）… 残っている牌の絵柄を、必ず解けるように配りなおす
- PC では H キーでヒント、S キーでシャッフル、タイトル画面では Enter / Space でスタート

## 回数を状態に足す

`let selected = null, running = false;` の行を **書きかえ** ます。

```js:game.js
  let selected = null, hints = 3, shuffles = 2, running = false;
```

## ボタンの表示

`refresh()` の最後に4行足して、次のようにします。

```js:game.js
  function refresh() {
    const al = alive();
    al.forEach((t) => { t.el.classList.toggle('blocked', !isFree(t, al)); });
    $('left').textContent = '残り ' + al.length;
    $('hintN').textContent = hints; $('shufN').textContent = shuffles;
    $('hintbtn').disabled = !running || hints <= 0;
    $('shufbtn').disabled = !running || shuffles <= 0;
  }
```

ボタンの `disabled` を `true` にすると押せなくなり、CSS の `#bar button:disabled` でうすく表示されます。プレイ中でないとき・回数を使い切ったときに押せなくします。

## ヒントの光を消す関数

`function setMsg` の行の **下** に追加します。

```js:game.js
  function clearHints() { tiles.forEach((t) => t.el && t.el.classList.remove('hint')); }
```

ペアを消したらヒントの光も消したいので、`tap()` の `// match!` のところに1行足します。

```js:game.js
    // match!
    const a = selected; selected = null;
    clearHints();
```

## ヒントとシャッフル

`checkStuck()` を次のように **書きかえ**、その下に `doHint()` と `doShuffle()` を追加します。

```js:game.js
  function checkStuck() {
    if (freePairs().length) { setMsg('同じ絵柄をペアで消そう'); return; }
    if (shuffles > 0) setMsg('手づまり！ シャッフルしよう');
    else { running = false; setMsg('手づまり… もう打つ手がない'); refresh(); }
  }

  function doHint() {
    if (!running || hints <= 0) return;
    const p = freePairs();
    if (!p.length) { setMsg('取れるペアがない！ シャッフルしよう'); return; }
    hints--; clearHints();
    p[0].forEach((t) => t.el.classList.add('hint'));
    refresh();
  }

  function doShuffle() {
    if (!running || shuffles <= 0) return;
    shuffles--; clearHints();
    if (selected) { selected.el.classList.remove('sel'); selected = null; }
    const al = alive();
    const kinds = shuffleArr(al.map((t) => t.kind));
    // re-pair remaining tiles so a solution exists, reusing the kinds present
    const pairKinds = []; const cnt = {};
    kinds.forEach((k) => { cnt[k] = (cnt[k] || 0) + 1; });
    Object.keys(cnt).forEach((k) => { for (let i = 0; i < cnt[k] / 2; i++) pairKinds.push(+k); });
    shuffleArr(pairKinds);
    for (let attempt = 0; attempt < 300; attempt++) {
      const rem = al.slice(), pairs = []; let ok = true;
      while (rem.length) {
        const free = shuffleArr(rem.filter((t) => isFree(t, rem)));
        if (free.length < 2) { ok = false; break; }
        pairs.push([free[0], free[1]]); rem.splice(rem.indexOf(free[0]), 1); rem.splice(rem.indexOf(free[1]), 1);
      }
      if (!ok) continue;
      pairs.forEach((p, i) => { p[0].kind = p[1].kind = pairKinds[i]; });
      break;
    }
    al.forEach((t) => { t.el.innerHTML = kindSvg(t.kind); });
    refresh(); checkStuck();
  }
```

### checkStuck()

シャッフルが残っていれば「シャッフルしよう」と案内し、残っていなければもう遊べないので `running = false` にします（ステップ9でゲームオーバー画面に変えます）。

### doHint()

ステップ6の `freePairs()` で取れるペアを探し、最初の1組に `hint` クラスを付けます。ペアが無いときは回数をへらさずにメッセージだけ出します。

### doShuffle()

ただ絵柄をランダムに混ぜると、また解けない山になるかもしれません。そこで、ステップ6の `assignKinds()` と同じ「取る手順のシミュレーション」をもう一度行います。ちがうのは、**新しい絵柄を作らず、今残っている絵柄を使い回す** ところです。

1. 残っている牌の絵柄を数えます。`cnt` は「絵柄の番号 → 枚数」の対応表（オブジェクト）です
2. 各絵柄を「枚数 ÷ 2」ペア分、`pairKinds` に入れてシャッフルします。たとえば 4 枚ある絵柄は 2 ペア分です
3. 残りの牌で取る手順をシミュレーションして、取れた順のペアに `pairKinds` を割りあてます
4. 最後に、すべての牌の SVG を描きなおします

`Object.keys(cnt)` で取り出したキーは **文字列** になるので、`+k` で数にもどしてから入れています。`p[0].kind = p[1].kind = pairKinds[i]` は、右から順に代入して2枚を同じ値にする書き方です。

## ボタンとキーボード

`$('start').addEventListener(...)` の行の **下** に追加します。

```js:game.js
  $('hintbtn').addEventListener('click', doHint);
  $('shufbtn').addEventListener('click', doShuffle);
  window.addEventListener('keydown', (e) => {
    if (!$('overlay').classList.contains('hide')) {
      if (e.key === 'Enter' || e.key === ' ') { e.preventDefault(); $('start').click(); }
      return;
    }
    if (e.key === 'h' || e.key === 'H') doHint();
    if (e.key === 's' || e.key === 'S') doShuffle();
  });
```

- ボタンは `click` で `doHint`・`doShuffle` を呼びます。どちらの関数も最初に「プレイ中か」「回数が残っているか」を確かめているので、キーで呼んでも安全です
- `keydown` はキーを押したときのイベントです。`e.key` に押したキーの名前が入ります
- タイトル画面が出ているとき（`#overlay` に `hide` が付いていないとき）は、Enter か Space で「スタートボタンを押したこと」にします。`$('start').click()` はボタンをプログラムから押す命令です。Space でページがスクロールしないよう `e.preventDefault()` を呼びます

> [!CHECK] 動作チェック
> - スタート前はヒント・シャッフルのボタンがうすく、押せない
> - スタート後に「ヒント」を押す（または H キー）と、取れるペアが水色に点滅し、回数が 1 へる。そのペアを消すと点滅も消える
> - 「シャッフル」を押す（または S キー）と、残りの牌の絵柄が入れかわり、回数が 1 へる
> - 回数が 0 になったボタンは押せなくなる
> - 再読み込みして、タイトル画面で Enter キーを押すとスタートできる
