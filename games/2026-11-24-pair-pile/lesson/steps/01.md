## このステップのゴール

3つのファイルを用意して、ゲーム画面の土台を作ります。上に「STAGE・SCORE・BEST」、その下に「残り時間バー」と「残りの牌の数」、まん中に牌を並べる **盤面** とその上に重ねるタイトル画面（オーバーレイ）、いちばん下に「ヒント」「シャッフル」ボタンとメッセージを置きます。スタートを押すとタイトル画面が消えるところまで作ります。

完成すると、こんなゲームになります。

- 何段にも積み上がった **牌の山** がある。牌には ●・▲・★ などの絵柄が描かれている
- **同じ絵柄の2枚** を順にタップすると、ペアで消える
- 取れるのは **上に何も乗っておらず**、**左か右のどちらかがあいている** 牌だけ。取れる牌は明るく、取れない牌は暗く表示される
- 3.5 秒以内に続けて消すと **コンボ** で得点アップ
- 時間内に全部消すと残り時間ボーナスつきで **ステージクリア**。ステージが進むと山の形が変わり、絵柄の種類も増える
- 困ったら **ヒント**（取れるペアを光らせる）と **シャッフル**（残りの牌の絵柄を混ぜなおす）
- 手づまりでシャッフルも残っていないか、時間切れでゲームオーバー。ハイスコアはブラウザに保存される

このゲームは Canvas を使いません。牌の1枚1枚を **`<div>` 要素** で作り、CSS の `position: absolute` で好きな位置に置きます。タップの判定はブラウザまかせにできるので、「どこをタップしたか」の計算が要らないのが DOM で作るよさです。

- `<meta name="viewport" ...>` はスマホで画面幅に合わせて表示し、ピンチで拡大されないようにする設定です
- JavaScript から書きかえる場所には `id`（`stageNo`・`score`・`best`・`timefill`・`left`・`msg`・`hintN`・`shufN` など）をつけておきます

- `<script>` を `</body>` の直前に置くと、HTML の要素がすべて読みこまれてから JavaScript が動きます

ポイントをいくつか見ておきましょう。

- `#app` を `display: flex; flex-direction: column;` にして、ヘッダー・時間バー・盤面・下のバーを縦に積みます。`#board-wrap` だけ `flex: 1` なので、残りの高さを全部もらいます
- `#board-wrap` は `position: relative`、その中の `#board` と `.tile` は `position: absolute` です。こうすると牌の `left`・`top` を **盤面の左上からの距離** で指定できます
- `#board` の `left: 50%; top: 50%` と `transform-origin: 0 0` は、あとで盤面をまん中に置いて拡大・縮小するための準備です（ステップ3）
- `.tile` の `box-shadow` は、ぼかしの無い影を左下に2枚重ねて、牌の **厚み** に見せています
- `.tile.blocked`（取れない牌）は `filter: brightness(.62)` で暗く、`.tile.sel`（選んだ牌）は黄色く少し浮かせ、`.tile.hint`（ヒント）は水色のわくを点滅させ、`.tile.gone`（消えた牌）は透明にして縮めます。**クラスを付けたり外したりするだけで見た目が切りかわる** ように、見た目は全部 CSS にまかせます
- `transition: transform .12s, filter .15s, opacity .25s` があるので、クラスが変わると見た目がなめらかに変わります
- `@keyframes` はアニメーションの動きの定義です。`shake` は取れない牌をタップしたときに左右にぷるっとゆらします
- `#overlay.hide { display: none; }` のように、クラスを1つ付けるだけで表示を切りかえられるようにしておきます

## game.js

JavaScript はまず「スタートボタンでタイトル画面を消す」だけを書きます。

```js:game.js
(() => {
  'use strict';
  const $ = (id) => document.getElementById(id);
  const boardEl = $('board'), wrap = $('board-wrap');

  function setMsg(t) { $('msg').textContent = t; }

  function startStage() {
    $('overlay').classList.add('hide');
    setMsg('同じ絵柄をペアで消そう');
  }

  $('start').addEventListener('click', startStage);
})();
```

### 全体を (() => { ... })(); で囲む

ファイル全体を「すぐ実行される関数」で囲むと、中で作った変数がページ全体（グローバル）に漏れません。`'use strict';` は、うっかりミスをエラーとして教えてくれるモードです。

`const $ = (id) => document.getElementById(id);` は、何度も書く `document.getElementById` を短く書くための小さな関数です。`$('board')` で盤面の要素が取れます。`boardEl`（牌を入れる箱）と `wrap`（盤面の外わく）はこのあと何度も使うので、最初に取り出しておきます。

### setMsg() と startStage()

- `setMsg(t)` は下のバーのメッセージを書きかえる関数です
- `startStage()` はステージを始める関数です。今はオーバーレイに `hide` クラスをつけて隠し、メッセージを出すだけです。ここに少しずつ処理を足していきます
- `addEventListener('click', startStage)` で、ボタンが押されたら `startStage` を呼ぶように登録します

> [!NOTE]
> `wrap` はまだ使っていませんが、ステップ3で盤面の大きさを合わせるときに使います。
