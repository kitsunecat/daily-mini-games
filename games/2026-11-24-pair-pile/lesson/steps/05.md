## このステップのゴール

牌をタップして選び、**同じ絵柄の2枚** をそろえて消せるようにします。

- 取れない牌をタップすると、ぷるっとゆれる
- 取れる牌をタップすると黄色く光って **選択中** になる。もう一度タップすると選択解除
- 選択中に **ちがう絵柄** の取れる牌をタップすると、選択がそちらに移る
- 選択中に **同じ絵柄** の取れる牌をタップすると、2枚とも消える

## 状態を足す

`let tiles = [], stage = 1;` の **下** に追加します。

```js:game.js
  let selected = null, running = false;
```

- `selected` は選択中の牌（無ければ `null`）
- `running` はプレイ中かどうか。タイトル画面のうしろに見えている山はさわれないようにします

## 牌にタップを登録する

`buildStage()` の中、`el.innerHTML = kindSvg(t.kind);` の **下** に1行追加します。

```js:game.js
      el.innerHTML = kindSvg(t.kind);
      el.addEventListener('pointerdown', (e) => { e.preventDefault(); tap(t); });
```

同じく `buildStage()` の最後を、次のように変えます（`selected = null;` を追加）。

```js:game.js
    fit();
    selected = null;
    refresh();
  }
```

- `pointerdown` は、マウスのボタンを押したとき・指で画面にふれたときの **両方** で起きるイベントです。`click` より早く反応するので、テンポよく遊べます
- `e.preventDefault()` で、スマホで長押ししたときの文字選択などを防ぎます
- 牌のオブジェクト `t` と要素 `el` を同じループの中でつないでいるので、タップされた要素がどの牌なのかを探す必要がありません。**DOM で作るゲームの便利なところ** です

## tap() を書く

`function setMsg` の行の **下** に追加します。

```js:game.js
  function tap(t) {
    if (!running || !t.alive) return;
    if (!isFree(t, alive())) { t.el.classList.remove('shake'); void t.el.offsetWidth; t.el.classList.add('shake'); return; }
    if (selected === t) { t.el.classList.remove('sel'); selected = null; return; }
    if (!selected) { selected = t; t.el.classList.add('sel'); return; }
    if (selected.kind !== t.kind) {
      selected.el.classList.remove('sel'); selected = t; t.el.classList.add('sel'); return;
    }
    // match!
    const a = selected; selected = null;
    [a, t].forEach((x) => { x.alive = false; x.el.classList.remove('sel'); x.el.classList.add('gone'); });
    refresh();
    if (alive().length === 0) { running = false; setMsg('ぜんぶ消せた！'); return; }
  }
```

上から順に、場合分けしています。**当てはまったらすぐ `return`** する書き方（早期リターン）にすると、`if` の入れ子が深くならずに読みやすくなります。

1. プレイ中でない、またはもう消えた牌なら何もしない
2. 取れない牌なら `shake` クラスでゆらす。いったん外して `void t.el.offsetWidth;`（要素の幅を読むだけの、意味のない行）をはさんでから付けなおすと、続けてタップしても **アニメーションが最初から再生** されます。ブラウザに「一度クラスが外れた状態」を確定させるためのおまじないです
3. 選択中の牌をもう一度タップしたら、選択解除
4. 何も選んでいなければ、この牌を選ぶ
5. 選んでいる牌と絵柄の番号 `kind` がちがえば、選択をこの牌に移す
6. ここまで来たら **同じ絵柄のペア**。2枚とも `alive = false` にして、`gone` クラスで消えるアニメーションをつけます

要素は `remove()` せずに残し、透明にしているだけです（CSS の `.tile.gone` に `pointer-events: none` があるので、タップも素通りします）。消えたあとに `refresh()` を呼ぶと、その下やとなりの牌が明るくなって取れるようになります。

## スタートで山を作りなおす

`startStage()` を次のように **書きかえ** ます。

```js:game.js
  function startStage() {
    $('overlay').classList.add('hide');
    buildStage();
    running = true;
    setMsg('同じ絵柄をペアで消そう');
  }
```

ファイルの最後の `buildStage();` はそのまま残します。タイトル画面のうしろに山を見せるためです（`running` は `false` なのでさわれません）。

> [!CHECK] 動作チェック
> - スタート前は、うしろの山をタップしても何も起きない
> - スタート後、暗い牌をタップすると左右にぷるっとゆれる
> - 明るい牌をタップすると黄色く浮き上がる。もう一度タップすると元にもどる
> - 同じ絵柄の明るい牌を2枚続けてタップすると、2枚とも消えて「残り」が 2 へる
> - 消した牌の下やとなりの牌が明るくなり、取れるようになる
