## このステップのゴール

このゲームでいちばん大事なルール、「**取れる牌**」の判定を作ります。取れない牌を暗く表示して、どの牌が取れるのかひと目でわかるようにします。あわせて、時間バーの右に「残り 〇」と牌の枚数を出します。

取れる牌の条件は2つです。

1. **上に何も乗っていない**（1つ上の段以上に、少しでも重なっている牌がない）
2. **左か右のどちらかがあいている**（同じ段で、左右の両方をはさまれていない）

## 判定の関数

`let tiles = [], stage = 1;` の **下** に追加します。

```js:game.js
  const overlaps = (a, b) => Math.abs(a.x - b.x) < 2 && Math.abs(a.y - b.y) < 2;
  function isFree(t, list) {
    let left = false, right = false;
    for (const o of list) {
      if (o === t) continue;
      if (o.l > t.l && overlaps(o, t)) return false;
      if (o.l === t.l && Math.abs(o.y - t.y) < 2) {
        if (o.x - t.x === -2) left = true; else if (o.x - t.x === 2) right = true;
      }
    }
    return !(left && right);
  }
```

### overlaps() … 2枚が重なっているか

牌は半マス 2 × 2 の大きさなので、`x` の差も `y` の差も **2 より小さければ** 少しでも重なっています。半分ずれた牌（差が 1）も「重なっている」と判定されます。`Math.abs()` は絶対値（マイナスを取った数）です。

### isFree(t, list) … 牌 t は取れるか

`list`（残っている牌の一覧）の牌 `o` を1枚ずつ調べます。

- 自分自身（`o === t`）は飛ばす
- `o` が自分より上の段（`o.l > t.l`）で、重なっていたら、その時点で **取れない**（`return false`）
- `o` が同じ段で、たての位置が重なっている（`Math.abs(o.y - t.y) < 2`）とき、`x` の差が `-2` なら左どなり、`+2` なら右どなりがふさがっている、と印をつける

最後に `!(left && right)`、つまり「左右の **両方** がふさがっている」のでなければ取れる、と答えます。

`list` を引数で受け取るようにしているのは、ステップ6で「まだ消していない、頭の中だけの牌の一覧」に対しても同じ判定を使いたいからです。

## 表示に反映する

`window.addEventListener('resize', fit);` の **下** に追加します。

```js:game.js

  const alive = () => tiles.filter((t) => t.alive);

  function refresh() {
    const al = alive();
    al.forEach((t) => { t.el.classList.toggle('blocked', !isFree(t, al)); });
    $('left').textContent = '残り ' + al.length;
  }
```

`buildStage()` の最後、`fit();` の **下** に1行追加します。

```js:game.js
    fit();
    refresh();
  }
```

- `alive()` は「まだ残っている牌」だけを `filter` で取り出す関数です
- `refresh()` は、画面の表示を今の状態に合わせる関数です。このあとのステップで、スコアやボタンの表示もここに足していきます
- `classList.toggle('blocked', 条件)` は、条件が `true` ならクラスを付け、`false` なら外します。取れない牌に `blocked` が付くと、CSS で暗く表示されます

> [!NOTE]
> 牌が 82 枚あると、`refresh()` は 82 × 82 回くらい比べることになります。それでも 1 万回もいかないので、今のパソコンやスマホならあっという間です。わかりやすさを優先して、単純な書き方にしています。

> [!CHECK] 動作チェック
> - 山の **いちばん上の牌** と、各段の **左はし・右はしの牌** だけが明るく、ほかは暗く表示される
> - いちばん上の2枚にまたがられている下の牌は、暗くなっている
> - 時間バーの右に「残り 82」と出る
