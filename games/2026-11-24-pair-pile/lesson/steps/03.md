## このステップのゴール

牌を **山の形に積んで** 表示します。山は何段か重なっていて、上の段の牌は少し右上にずらして描くことで、立体的に見せます。また、画面の大きさに合わせて盤面全体を拡大・縮小し、スマホでもはみ出さないようにします。

## 牌の位置を「半マス」単位で持つ

上海ソリティアの山では、上の段の牌が下の段の **2枚の間にまたがって** 乗っていることがよくあります。そこで、牌1枚の大きさを **2 × 2 の半マス** と考え、位置 `x`・`y` を半マス単位で持つことにします。

- となりの牌とは `x` が **2** ちがう
- 半分ずれた牌は `x`（または `y`）が **1** ちがう
- `l`（layer）は何段目か。0 がいちばん下

1枚の牌は `{ x: 4, y: 2, l: 1 }` のようなオブジェクトで表します。

## 定数とレイアウト

`const boardEl = ...` の行の **下** に、定数を1行追加します。

```js:game.js
  const UX = 22, UY = 29, LX = 4, LY = -5; // half-unit size, per-layer offset
```

- `UX`・`UY` は半マスの幅・高さ（px）。牌は 44 × 58px なので、ちょうどその半分です
- `LX`・`LY` は「1段上がるごとに、どれだけずらして描くか」。右に 4px・上に 5px ずらすと、上の段が浮いて見えます

`const kindSvg = ...` の行の **下** に、山の形（レイアウト）を追加します。さらにその下に、ゲームの状態を入れる変数を書きます。

```js:game.js
  // ---- layouts (x,y in half units; tile = 2x2) ----
  function rect(out, l, x0, y0, cols, rows) {
    for (let r = 0; r < rows; r++) for (let c = 0; c < cols; c++) out.push({ x: x0 + c * 2, y: y0 + r * 2, l });
  }
  const LAYOUTS = [
    () => { const o = []; rect(o, 0, 0, 0, 8, 6); rect(o, 1, 2, 2, 6, 4); rect(o, 2, 4, 4, 4, 2); rect(o, 3, 6, 5, 2, 1); return o; },
    () => { const o = []; [4, 6, 8, 8, 6, 4].forEach((w, i) => rect(o, 0, 8 - w, i * 2, w, 1));
      [3, 5, 7, 5, 3].forEach((w, i) => rect(o, 1, 8 - w, 1 + i * 2, w, 1));
      rect(o, 2, 6, 3, 2, 1); rect(o, 2, 6, 5, 2, 1); rect(o, 3, 7, 4, 1, 1); return o; },
    () => { const o = []; rect(o, 0, 0, 0, 8, 6); rect(o, 1, 0, 2, 3, 4); rect(o, 1, 10, 2, 3, 4);
      rect(o, 2, 1, 3, 2, 2); rect(o, 2, 11, 3, 2, 2); rect(o, 3, 2, 4, 1, 1); rect(o, 3, 12, 4, 1, 1); return o; },
    () => { const o = []; rect(o, 0, 0, 0, 8, 2); rect(o, 0, 0, 8, 8, 2); rect(o, 0, 0, 4, 2, 2); rect(o, 0, 12, 4, 2, 2);
      rect(o, 0, 5, 5, 3, 1); rect(o, 1, 1, 1, 7, 1); rect(o, 1, 1, 9, 7, 1); rect(o, 1, 6, 5, 2, 1);
      rect(o, 2, 3, 1, 5, 1); rect(o, 2, 3, 9, 5, 1); rect(o, 2, 7, 5, 1, 1); rect(o, 3, 7, 4, 1, 1); return o; },
  ];

  // ---- state ----
  let tiles = [], stage = 1;
```

- `rect(out, l, x0, y0, cols, rows)` は、「`l` 段目の `(x0, y0)` から、よこ `cols` 枚 × たて `rows` 枚の長方形に牌を並べて、配列 `out` に入れる」関数です。牌は半マス 2 つ分なので `c * 2`・`r * 2` ずつずらします
- `LAYOUTS` は **山を作る関数の配列** です。4種類あり、ステージ1は1つ目、ステージ2は2つ目……と順に使います
- 1つ目のレイアウトを見てみましょう。0段目に 8 × 6、1段目に 6 × 4、2段目に 4 × 2、3段目に 2 × 1 を、中心をそろえて積んだピラミッドです。3段目の `y0` が `5`（奇数）なので、この2枚は下の段の牌に **半分ずつまたがって** 乗ります
- 2つ目のレイアウトは `[4, 6, 8, 8, 6, 4].forEach(...)` で行ごとに幅を変えて、ひし形に近い形を作っています。`8 - w` を左はしにすると、行の中心がそろいます

## buildStage() を本物にする

ステップ2の仮の `buildStage()` を、まるごと次のコードに **書きかえ** ます。その下に `fit()` も追加します。

```js:game.js
  function buildStage() {
    boardEl.innerHTML = '';
    let list = LAYOUTS[(stage - 1) % LAYOUTS.length]();
    if (list.length % 2) list.pop();
    tiles = list.map((p) => ({ ...p, kind: 0, el: null, alive: true }));
    tiles.forEach((t, i) => { t.kind = Math.floor(i / 2) % 12; }); // 仮の絵柄（ステップ6で作りなおす）
    let maxX = 0, maxY = 0;
    tiles.forEach((t) => { maxX = Math.max(maxX, t.x); maxY = Math.max(maxY, t.y); });
    tiles.sort((a, b) => a.l - b.l || a.x - b.x || a.y - b.y);
    tiles.forEach((t, i) => {
      const el = document.createElement('div');
      el.className = 'tile';
      el.style.left = (t.x * UX + t.l * LX + 6) + 'px';
      el.style.top = (t.y * UY + t.l * LY + 20) + 'px';
      el.style.zIndex = t.l * 1000 + t.x * 10 + (40 - t.y);
      el.innerHTML = kindSvg(t.kind);
      t.el = el;
      boardEl.appendChild(el);
    });
    boardEl.style.width = ((maxX + 2) * UX + 30) + 'px';
    boardEl.style.height = ((maxY + 2) * UY + 30) + 'px';
    fit();
  }

  function fit() {
    const w = parseFloat(boardEl.style.width) || 1, h = parseFloat(boardEl.style.height) || 1;
    const s = Math.min((wrap.clientWidth - 8) / w, (wrap.clientHeight - 8) / h, 1.6);
    boardEl.style.transform = `scale(${s}) translate(-50%,-50%)`;
  }
  window.addEventListener('resize', fit);
```

### 牌のデータを作る

1. `(stage - 1) % LAYOUTS.length` で、ステージ番号からレイアウトを選びます。`%`（余り）を使うので、ステージ5ではまた1つ目にもどります
2. 牌は2枚ずつ消すので、枚数が奇数だと最後の1枚が残ってしまいます。`list.length % 2` が 1（奇数）なら `pop()` で1枚へらします
3. `list.map((p) => ({ ...p, kind: 0, el: null, alive: true }))` で、位置 `x, y, l` に「絵柄の番号 `kind`」「画面の要素 `el`」「まだ残っているか `alive`」を足したオブジェクトを作ります。`...p` は「p の中身を全部コピー」という書き方です
4. 絵柄は **仮に**、となり同士の2枚を同じ番号にしておきます（`Math.floor(i / 2)` は 0, 0, 1, 1, 2, 2, …）。これだと簡単すぎるので、ステップ6で「必ず解ける配り方」に作りなおします

### 重なりの順番を決める

`tiles.sort(...)` で、下の段から順に並べかえてから要素を作ります。さらに `zIndex`（重なりの順番。大きいほど手前）を `t.l * 1000 + t.x * 10 + (40 - t.y)` にしています。

- 段 `l` がいちばん強く効く（上の段は必ず手前）
- 同じ段では、`x` が大きい（右の）牌ほど手前、`y` が小さい（上の）牌ほど手前

牌の厚み（`box-shadow`）は **左下** に出るので、右の牌・上の牌を手前にすると、となりの厚みがきれいに隠れます。

### 画面に合わせて拡大・縮小する fit()

1. 盤面の大きさ（`boardEl.style.width` に入れた数字）を `parseFloat` で数として取り出します
2. 外わく `wrap` の幅・高さ（`clientWidth`・`clientHeight`）を、盤面の幅・高さで割ると「何倍にすればぴったり入るか」がわかります。**小さいほう** を選べばはみ出しません。大きくしすぎないよう、上限を 1.6 倍にしています
3. `transform: scale(s) translate(-50%, -50%)` で、拡大・縮小してからまん中にそろえます。CSS の `transform-origin: 0 0` で拡大の中心を左上にしてあるので、この順番でちょうど中央に来ます

ウィンドウの大きさが変わったら、もう一度 `fit()` を呼びます。

> [!TIP]
> 他の山の形も見てみたいときは、`let tiles = [], stage = 1;` の `1` を `2`〜`4` に変えて再読み込みしてみましょう。確認したら `1` にもどしておきます。

> [!CHECK] 動作チェック
> - 何段にも積み上がった牌の山が、盤面のまん中に表示される（全部で 82 枚）
> - 上の段の牌ほど少し右上にずれ、下の段に重なって立体的に見える。いちばん上の2枚は、下の牌に半分ずつまたがっている
> - となり合う2枚ずつが同じ絵柄になっている（仮の配り方なので、今はこれで OK）
> - ウィンドウの幅を変えると、山全体が拡大・縮小されて、はみ出さない
