## このステップのゴール

ゲームらしい緊張感を足します。

- **制限時間**。時間バーがだんだん短くなり、残り 20 秒を切ると赤くなる。0 になったら終わり
- **スコア**。ペアを消すたびに 10 点
- **コンボ**。前に消してから 3.5 秒以内に続けて消すと、倍率が ×2、×3 …（最大 ×5）と上がり、「COMBO ×3」のように表示される

## 状態を足す

状態の2行を、次のように **書きかえ** ます。

```js:game.js
  let tiles = [], stage = 1, score = 0, timeLeft = 0, timeMax = 1;
  let selected = null, hints = 3, shuffles = 2, running = false, lastMatch = 0, combo = 0, lastTick = 0;
```

- `timeLeft` は残り秒数、`timeMax` はそのステージの持ち時間（バーの長さの計算に使います）
- `lastMatch` は最後にペアを消した時刻、`combo` は今のコンボ数
- `lastTick` は、前回時間をへらした時刻です

## ステージの持ち時間

`buildStage()` の最後を、次のように変えます（`timeMax = ...` の行を追加）。

```js:game.js
    fit();
    timeMax = timeLeft = Math.max(90, 60 + tiles.length * 1.6 - (stage - 1) * 8);
    selected = null;
    refresh();
  }
```

牌の数が多いほど時間を長くし、ステージが進むごとに 8 秒ずつ短くします。ただし 90 秒より短くはしません。82 枚のステージ1なら 60 + 82 × 1.6 = 約 191 秒です。

## スコアとステージ番号の表示

`refresh()` の `$('left').textContent = ...` の行の **下** に2行追加します。

```js:game.js
    $('left').textContent = '残り ' + al.length;
    $('score').textContent = score;
    $('stageNo').textContent = stage;
```

## コンボの計算

`tap()` の `// match!` の部分を、次のように変えます（`const now = ...` から `showCombo` までの5行を追加）。

```js:game.js
    // match!
    const a = selected; selected = null;
    clearHints();
    [a, t].forEach((x) => { x.alive = false; x.el.classList.remove('sel'); x.el.classList.add('gone'); });
    const now = performance.now();
    combo = now - lastMatch < 3500 ? Math.min(combo + 1, 5) : 1;
    lastMatch = now;
    score += 10 * combo;
    if (combo > 1) showCombo('COMBO ×' + combo);
    refresh();
```

- `performance.now()` は、ページを開いてからの時間をミリ秒（1000 分の 1 秒）で返します。時間の差を測るのに向いています
- 前に消した時刻 `lastMatch` から 3500 ミリ秒（3.5 秒）以内なら `combo` を1つ上げ（最大 5）、それより遅ければ 1 にもどします
- 点数は `10 × combo`。コンボが続くほど 20 点、30 点……と増えます

`checkStuck()` の **下** に、コンボ表示の関数を追加します。

```js:game.js
  function showCombo(t) {
    const c = $('combo'); c.textContent = t; c.classList.add('show');
    clearTimeout(showCombo.tm); showCombo.tm = setTimeout(() => c.classList.remove('show'), 700);
  }
```

`#combo` に文字を入れて `show` クラスを付けると、CSS の `transition` でふわっと出ます。0.7 秒後に `show` を外すと、ふわっと消えます。続けて消したときに前のタイマーで早く消えてしまわないよう、`clearTimeout` で前の予約を取り消してから新しく予約します。タイマーの番号は `showCombo.tm` に入れています。関数もオブジェクトなので、こうして **関数そのものに値を持たせる** ことができます。

## 時間をへらす tick()

`startStage()` を次のように **書きかえ**、その下に `tick()` を追加します。

```js:game.js
  function startStage() {
    $('overlay').classList.add('hide');
    buildStage();
    running = true; combo = 0; lastMatch = 0; $('combo').classList.remove('show');
    lastTick = performance.now();
    setMsg('同じ絵柄をペアで消そう');
    refresh(); checkStuck();
  }

  function tick() {
    const now = performance.now();
    if (running) {
      timeLeft -= (now - lastTick) / 1000;
      if (timeLeft <= 0) { timeLeft = 0; running = false; setMsg('時間切れ…'); refresh(); }
    }
    lastTick = now;
    const f = $('timefill');
    f.style.width = (100 * timeLeft / timeMax) + '%';
    f.classList.toggle('low', timeLeft < 20);
    requestAnimationFrame(tick);
  }
  requestAnimationFrame(tick);
```

### requestAnimationFrame

`requestAnimationFrame(tick)` は「次に画面を書きかえるタイミングで `tick` を呼んで」とブラウザに頼む命令です。`tick()` の最後でもう一度頼むので、1秒間に約 60 回、`tick()` が呼ばれつづけます。

ただし、呼ばれる間隔はパソコンや画面によってちがいます（120 回のものもあります）。そこで「1回で何秒へらす」と決めず、**前回からの実際の経過時間**（`now - lastTick`）を 1000 で割って秒にし、それだけへらします。こうすれば、どの端末でも同じ速さで時間が進みます。

`startStage()` で `lastTick` を今の時刻にしておくのは、タイトル画面にいた時間がまとめて引かれてしまわないようにするためです。

### 時間バー

バーの幅を「残り時間 ÷ 持ち時間」の % にします。CSS の `transition: width .25s linear` があるので、なめらかに縮みます。20 秒を切ったら `low` クラスで赤くします。

> [!CHECK] 動作チェック
> - スタートすると、時間バーが少しずつ短くなっていく
> - ペアを消すと SCORE が 10 ふえる。3.5 秒以内に続けて消すと「COMBO ×2」「COMBO ×3」…と出て、20 点・30 点とふえる
> - しばらく間をあけてから消すと、また 10 点にもどる
> - （確認用に）`Math.max(90, ...)` の `90` を `5` に、`60 + ...` の `60` を `-200` のように一時的に変えると、すぐ時間切れになり、バーが赤くなってから「時間切れ…」と出る。確認したら元にもどす
