## このステップのゴール

ゲームとして仕上げます。

- 全部消したら **ステージクリア画面**。残り秒数 × 5 点のボーナスを足し、ボタンで次のステージへ。ヒントとシャッフルが1回ずつ回復する
- 手づまり（シャッフル無し）・時間切れで **ゲームオーバー画面**。「もう一度あそぶ」で最初から
- **ハイスコア** をブラウザに保存する
- **効果音** を鳴らす

これで完成品と同じになります。

## ハイスコアの読みこみ

いちばん上の定数の行の **下** に、保存に使う名前を足します。

```js:game.js
  const UX = 22, UY = 29, LX = 4, LY = -5; // half-unit size, per-layer offset
  const BEST_KEY = 'pair-pile-best';
```

状態の1行目に `best = 0` を足し、その下で保存されたハイスコアを読みこみます。

```js:game.js
  // ---- state ----
  let tiles = [], stage = 1, score = 0, best = 0, timeLeft = 0, timeMax = 1;
  let selected = null, hints = 3, shuffles = 2, running = false, lastMatch = 0, combo = 0, lastTick = 0;
  try { best = parseInt(localStorage.getItem(BEST_KEY), 10) || 0; } catch (e) { best = 0; }
  $('best').textContent = best;
```

**localStorage** は、ブラウザにちょっとした文字列を保存しておける場所です。ページを閉じても消えません。`getItem(名前)` で読み、`setItem(名前, 文字列)` で書きます。まだ何も保存されていないと `null` が返り、`parseInt(null)` は `NaN`（数ではない）になるので、`|| 0` で 0 にします。プライベートモードなどで localStorage が使えないとエラーになることがあるので、`try { ... } catch` でかこんでおきます。

## クリア・ゲームオーバー・ハイスコア保存

`doShuffle()` の **下** に追加します。

```js:game.js
  function stageClear() {
    running = false;
    const bonus = Math.ceil(timeLeft) * 5;
    score += bonus;
    saveBest();
    refresh();
    [523, 659, 784, 1046].forEach((f, i) => setTimeout(() => beep(f, 0.12), i * 110));
    showOverlay('ステージ ' + stage + ' クリア！', `残り時間ボーナス <b class="hl">+${bonus}</b><br>スコア ${score}<br>次はもっと絵柄が増えるよ`, '次のステージへ', () => {
      stage++; hints = Math.min(hints + 1, 5); shuffles = Math.min(shuffles + 1, 4); startStage();
    });
  }

  function gameOver(reason) {
    running = false;
    const isBest = saveBest();
    refresh();
    [392, 330, 262].forEach((f, i) => setTimeout(() => beep(f, 0.15), i * 150));
    showOverlay('ゲームオーバー', `${reason}<br>ステージ ${stage} ・ スコア <b class="hl">${score}</b>${isBest ? '<br><b class="hl">ハイスコア更新！</b>' : ''}`, 'もう一度あそぶ', newGame);
  }

  function saveBest() {
    if (score > best) {
      best = score; $('best').textContent = best;
      try { localStorage.setItem(BEST_KEY, String(best)); } catch (e) { /* ignore */ }
      return true;
    }
    return false;
  }

  let overlayAction = null;
  function showOverlay(title, html, btn, action) {
    $('ov-title').textContent = title; $('ov-text').innerHTML = html; $('start').textContent = btn;
    document.querySelector('#overlay .keys').style.display = 'none';
    overlayAction = action;
    $('overlay').classList.remove('hide');
  }
```

### stageClear()

`running = false` で操作を止め、残り秒数を切り上げて 5 倍したボーナスを足します。オーバーレイのボタンには「次のステージへ」の処理（ステージを1つ進め、ヒントを最大 5・シャッフルを最大 4 まで1回ずつ回復して `startStage()`）を渡します。

### gameOver(reason)

`reason` には「時間切れ…」「手づまり…」のような理由が入ります。ハイスコアを更新していたら「ハイスコア更新！」も出します。ボタンには `newGame`（あとで作ります）を渡します。

### saveBest()

スコアがハイスコアをこえていたら保存して `true` を、こえていなければ `false` を返します。

### showOverlay() と overlayAction

タイトル・クリア・ゲームオーバーの画面を、**同じ1つのオーバーレイ** で使い回します。題名・本文・ボタンの文字を書きかえ、ボタンを押したときにする処理を `overlayAction` という変数に入れておきます。**関数を変数に入れておいて、あとで呼ぶ** やり方です。タイトル画面にだけ必要な操作説明（`.keys`）は隠します。

本文にはスコアの数字や `<b>` タグを入れたいので、`innerHTML` を使っています。ここに入るのは自分のプログラムで作った文字だけなので安全です（外から入ってきた文字を `innerHTML` に入れるのは危ないので注意しましょう）。

## 新しいゲームとスタートボタン

`startStage()` の **下** に、`newGame()` を追加します。

```js:game.js
  function newGame() { stage = 1; score = 0; hints = 3; shuffles = 2; startStage(); }
  overlayAction = newGame;
```

最初はタイトル画面なので、ボタンを押したら `newGame` が動くように `overlayAction` に入れておきます。

スタートボタンの登録を、次のように **書きかえ** ます。

```js:game.js
  $('start').addEventListener('click', () => { ensureAudio(); overlayAction && overlayAction(); });
```

`overlayAction && overlayAction()` は「`overlayAction` が入っていれば呼ぶ」という短い書き方です。`ensureAudio()` は次の「効果音」で作ります。

## 効果音

ファイルのいちばん最後にある `buildStage();` を、次のコードに **書きかえ** ます。

```js:game.js
  // ---- sound ----
  let ac = null;
  function ensureAudio() {
    try { if (!ac) ac = new (window.AudioContext || window.webkitAudioContext)(); if (ac.state === 'suspended') ac.resume(); } catch (e) { ac = null; }
  }
  function beep(freq, dur) {
    if (!ac) return;
    try {
      const o = ac.createOscillator(), g = ac.createGain();
      o.type = 'triangle'; o.frequency.value = freq;
      g.gain.setValueAtTime(0.12, ac.currentTime);
      g.gain.exponentialRampToValueAtTime(0.001, ac.currentTime + dur + 0.05);
      o.connect(g); g.connect(ac.destination); o.start(); o.stop(ac.currentTime + dur + 0.06);
    } catch (e) { /* ignore */ }
  }
  function chord(c) { const base = 520 + c * 60; beep(base, 0.08); setTimeout(() => beep(base * 1.5, 0.1), 60); }

  // initial preview board behind the title
  buildStage(); running = false; refresh();
```

### Web Audio API

**Web Audio API** を使うと、音声ファイルなしで、プログラムから音を作って鳴らせます。

- `AudioContext` は音を鳴らすための「装置」です。スマホのブラウザは、**ユーザーがタップしてからでないと音を出せない** 決まりがあるので、スタートボタンを押したときに `ensureAudio()` で作ります（止まっていたら `resume()` で動かします）
- `createOscillator()` は一定の高さの音を出す「発振器」です。`type = 'triangle'` で、やわらかい三角波の音になります。`frequency.value` が音の高さ（Hz）です
- `createGain()` は音量のつまみです。`exponentialRampToValueAtTime` で、0.12 から 0.001 まで **だんだん小さく** して「ポン」という短い音にします
- 発振器 → 音量 → スピーカー（`ac.destination`）の順に `connect` でつなぎ、`start()` で鳴らし、`stop()` で止める時刻を予約します

`chord(c)` はペアを消したときの音で、コンボが上がるほど高い音（`520 + c * 60`）になります。1.5 倍の高さの音を少しおくれて重ねると、明るい和音に聞こえます。

### 効果音を鳴らす場所

`tap()` に4か所、`beep()` と `chord()` を足します。`tap()` 全体はこうなります。

```js:game.js
  function tap(t) {
    if (!running || !t.alive) return;
    if (!isFree(t, alive())) { t.el.classList.remove('shake'); void t.el.offsetWidth; t.el.classList.add('shake'); beep(160, 0.06); return; }
    if (selected === t) { t.el.classList.remove('sel'); selected = null; return; }
    if (!selected) { selected = t; t.el.classList.add('sel'); beep(520, 0.04); return; }
    if (selected.kind !== t.kind) {
      selected.el.classList.remove('sel'); selected = t; t.el.classList.add('sel'); beep(380, 0.04); return;
    }
    // match!
    const a = selected; selected = null;
    clearHints();
    [a, t].forEach((x) => { x.alive = false; x.el.classList.remove('sel'); x.el.classList.add('gone'); });
    const now = performance.now();
    combo = now - lastMatch < 3500 ? Math.min(combo + 1, 5) : 1;
    lastMatch = now;
    score += 10 * combo;
    if (combo > 1) showCombo('COMBO ×' + combo);
    chord(combo);
    refresh();
    if (alive().length === 0) { stageClear(); return; }
    checkStuck();
  }
```

`doShuffle()` の最後、`refresh(); checkStuck();` の **上** にも、シャッフルの音を足します。

```js:game.js
    al.forEach((t) => { t.el.innerHTML = kindSvg(t.kind); });
    beep(300, 0.08); setTimeout(() => beep(450, 0.08), 80);
    refresh(); checkStuck();
```

`stageClear()` と `gameOver()` の中の `[523, 659, 784, 1046].forEach(...)` のような行は、ドミソド（上がる音）・ソミド（下がる音）を `setTimeout` で少しずつずらして鳴らしています。

> [!CHECK] 動作チェック
> - 牌を選ぶ・ちがう絵柄に移る・取れない牌をタップする・ペアを消す・シャッフルで、それぞれちがう音が鳴る（音が出ないときはマナーモードや音量を確認）
> - コンボが続くほど、消したときの音が高くなる
> - 全部消すと「ステージ 1 クリア！」と残り時間ボーナスが出て、「次のステージへ」でちがう形の山・増えた絵柄のステージ2が始まる。ヒントとシャッフルが1回ずつふえている
> - 時間切れや、シャッフルを使い切っての手づまりで「ゲームオーバー」が出る。「もう一度あそぶ」でステージ1・スコア0からやりなおせる
> - 右上の BEST が更新され、ページを再読み込みしても残っている

これで完成です！ 元の「つみ牌ペア」と同じように遊べるはずです。

## 改造アイデア

> [!TIP] 自分だけの山の形
> `LAYOUTS` に新しい関数を足すと、オリジナルの山が作れます。`rect()` で長方形を重ねていくだけです。上の段の `x0`・`y0` を奇数にすると、半分ずれて乗る牌が作れます。枚数が奇数でも最後の1枚は自動で取りのぞかれます。

> [!TIP] 元にもどす（アンドゥ）ボタン
> 消したペアを配列に記録しておき、ボタンで最後のペアの `alive` を `true` にもどして `gone` クラスを外せば、1手もどせます。使える回数を決めておくと、ヒント・シャッフルと同じ「助け舟」になります。

> [!TIP] 絵柄を変える
> `SHAPES` の SVG を書きかえれば、果物・動物・漢字など好きな絵柄にできます。`<text>` タグで絵文字や文字を描くのも手軽です（`<text x="16" y="24" font-size="22" text-anchor="middle">🍎</text>` など）。

> [!TIP] 時間制限なしモード
> タイトル画面に「のんびりモード」のボタンを足し、そのときは `tick()` で時間をへらさないようにしてみましょう。クリアまでの手数や、ヒントを使った回数で点数をつけると、じっくり考えるパズルになります。
