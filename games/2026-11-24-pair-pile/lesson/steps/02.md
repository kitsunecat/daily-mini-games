## このステップのゴール

牌に描く **絵柄** を作ります。画像ファイルは使わず、**SVG**（線や図形を文字で書く画像の形式）を JavaScript の文字列で組み立てます。9種類の形 × 4色 = **36種類** の絵柄を、番号 `0`〜`35` から作れるようにして、試しに 6 × 6 に並べて表示します。

## 絵柄を作るコード

`const boardEl = ...` の行の **下** に追加します。

```js:game.js
  // ---- shapes (SVG) ----
  const COLORS = ['#d9433a', '#2e8b57', '#2f6fd6', '#c98a10'];
  const SHAPES = [
    (c) => `<circle cx="16" cy="16" r="11" fill="${c}"/>`,
    (c) => `<polygon points="16,4 29,27 3,27" fill="${c}"/>`,
    (c) => `<rect x="6" y="6" width="20" height="20" rx="3" fill="${c}"/>`,
    (c) => `<polygon points="16,2 30,16 16,30 2,16" fill="${c}"/>`,
    (c) => `<polygon points="16,2 19.8,11.6 30,12 22,18.6 24.8,29 16,23 7.2,29 10,18.6 2,12 12.2,11.6" fill="${c}"/>`,
    (c) => `<path d="M16 28 C4 20 2 13 6 8 C10 4 14 6 16 10 C18 6 22 4 26 8 C30 13 28 20 16 28Z" fill="${c}"/>`,
    (c) => `<path d="M12 3h8v9h9v8h-9v9h-8v-9H3v-8h9z" fill="${c}"/>`,
    (c) => `<circle cx="16" cy="16" r="10" fill="none" stroke="${c}" stroke-width="5"/>`,
    (c) => `<polygon points="16,3 28,10 28,22 16,29 4,22 4,10" fill="${c}"/><circle cx="16" cy="16" r="4" fill="#fffaf0"/>`,
  ];
  const kindSvg = (k) => `<svg viewBox="0 0 32 32">${SHAPES[k % 9](COLORS[Math.floor(k / 9) % 4])}</svg>`;
```

### SVG を文字列で作る

SVG は HTML と同じようにタグで書ける画像です。たとえば `<circle cx="16" cy="16" r="11" fill="red"/>` は「中心 (16, 16)・半径 11 の赤い丸」です。`<svg viewBox="0 0 32 32">` で「32 × 32 の方眼紙に描く」と決めておくと、実際に表示する大きさ（CSS の `.tile svg { width: 32px; height: 32px }`）が変わっても、形がそのまま拡大・縮小されます。

- `circle`（円）・`polygon`（点を順につないだ多角形）・`rect`（四角形。`rx` で角を丸める）・`path`（線を自由に描く）を使って、丸・三角・四角・ひし形・星・ハート・十字・輪・六角形の9種類を作っています
- 輪（8番目）は `fill="none"` でぬりつぶさず、`stroke`（線の色）と `stroke-width`（線の太さ）で描きます

### 関数を配列に入れる

`SHAPES` は **関数の配列** です。`SHAPES[0]` は「色 `c` を受け取って丸の SVG を返す関数」、`SHAPES[1]` は三角を返す関数……となっています。`` `...${c}...` `` はテンプレート文字列で、`${c}` の部分に色が入ります。

### 番号から絵柄を決める kindSvg()

絵柄の番号 `k`（0〜35）から、形と色を次のように決めます。

- 形: `k % 9`（9 で割った余り）。0〜8 がくり返される
- 色: `Math.floor(k / 9) % 4`（9 で割った商）。0〜8 は赤、9〜17 は緑、18〜26 は青、27〜35 は黄色

こうすると **番号が同じなら必ず同じ絵柄、番号がちがえば必ずちがう絵柄** になります。ゲームの中では「絵柄が同じか」を見た目ではなく **番号（kind）が同じか** で判定します。

## 試しに36種類を並べる

`function setMsg` の **上** に、仮の `buildStage()` を追加します。次のステップで本物に書きかえます。

```js:game.js
  // 仮: 36種類の絵柄を 6×6 に並べて見てみる
  function buildStage() {
    boardEl.innerHTML = '';
    for (let k = 0; k < 36; k++) {
      const el = document.createElement('div');
      el.className = 'tile';
      el.style.left = (k % 6) * 50 + 'px';
      el.style.top = Math.floor(k / 6) * 66 + 'px';
      el.innerHTML = kindSvg(k);
      boardEl.appendChild(el);
    }
    boardEl.style.width = '300px';
    boardEl.style.height = '396px';
    boardEl.style.transform = 'translate(-50%,-50%)';
  }
```

ファイルのいちばん最後、`})();` の **上** に、呼び出しを1行追加します。

```js:game.js
  buildStage();
```

- `document.createElement('div')` で新しい `<div>` を作り、`className = 'tile'` で牌の見た目（CSS の `.tile`）をつけます
- `el.style.left`・`el.style.top` で位置を決めます。`k % 6` で列、`Math.floor(k / 6)` で行がわかります。牌は幅 44px・高さ 58px なので、少しすき間をあけて 50px・66px ずつずらしています
- `el.innerHTML = kindSvg(k)` で、牌の中に SVG を入れます
- `boardEl.appendChild(el)` で盤面の箱に入れると、はじめて画面に出ます
- `#board` は CSS で `left: 50%; top: 50%` に置かれているので、左上の角が盤面のまん中に来ます。`translate(-50%, -50%)`（自分の幅・高さの半分だけ左上にもどす）で、ちょうどまん中にそろいます
