## このステップのゴール

ゲームを仕上げます。山を全部片づけたら **ステージクリア** のボーナスを入れて次のステージへ進み、山札が尽きて動けなくなったら **ゲームオーバー** の画面を出します。いちばんよかったスコアを **localStorage に保存** して、ブラウザを閉じても BEST が残るようにします。

## ハイスコアを読みこむ

`let state = ...` の行の **上** に追加します。

```js:game.js
  let best = 0;
  try { best = parseInt(localStorage.getItem('peak-solitaire-best') || '0', 10) || 0; } catch (e) {}
  bestEl.textContent = best;

```

**localStorage** は、ブラウザにちょっとしたデータを保存しておける仕組みです。`localStorage.getItem('名前')` で読み、`localStorage.setItem('名前', 文字列)` で書きます。ページを閉じても、次に開いたときに残っています。

- 保存されるのは **文字列** なので、`parseInt(..., 10)` で10進数の数値に直します
- まだ何も保存されていないときは `getItem()` が `null` を返すので、`|| '0'` で `'0'` を使います。数値にできなかったとき（`NaN`）も、最後の `|| 0` で 0 にします
- プライベートモードなど、localStorage が使えないブラウザではエラーになることがあるので、`try { ... } catch (e) {}` で包んでいます

## ステージとバナーの変数

`let score = ...` と `let stuckT = ...` の2行を **書きかえ** ます。

```js:game.js
  let score = 0, level = 1, streak = 0, maxStreak = 0, cleared = 0, sel = -1, time = 0;
  let bannerT = 0, bannerText = '', stuckT = 0, scale = 1;
```

- `level` … 今のステージ番号
- `bannerText`・`bannerT` … 「ステージ 1 クリア！」のような帯の文字と、それを表示しておく残り時間

`deal()` の最後、`flying = []; ...` の行の **下** に、ヘッダーのステージ表示を更新する1行を足します。`deal()` の完成形はこうなります。

```js:game.js
  function deal() {
    const d = shuffled();
    board = SLOTS.map((s, i) => ({
      ...d[i], row: s.row, cov: s.cov, removed: false, shake: 0, flip: 1,
      x: OX + s.x * STEP, y: OY + s.row * ROWY
    }));
    waste = [d[28]];
    stock = d.slice(29);
    flying = []; streak = 0; sel = -1; stuckT = 0;
    stageEl.textContent = level;
  }
```

`start()` の最初の2行を **書きかえ** て、ステージを1に、バナーを0に戻します。

```js:game.js
  function start() {
    score = 0; level = 1; maxStreak = 0; cleared = 0; scoreEl.textContent = 0;
    popups = []; sparks = []; bannerT = 0;
    deal(); state = 'play'; overlay.classList.add('hidden');
    beep(523, 0.1, 'triangle'); beep(784, 0.14, 'triangle', 0.1, 0.08);
  }
```

## 全部片づけたらステージクリア

`playCard()` の最後のほう、`sel = -1;` の **上** に1行足します。

```js:game.js
    if (board.every(b => b.removed)) stageClear();
```

`board` のカードが **全部（`every`）** 取りのぞかれていたら、ステージクリアです。

`function draw1() {...}` の **下** に、`stageClear()` と `gameOver()` を追加します。

```js:game.js

  function stageClear() {
    const bonus = 500 + stock.length * 50 + level * 100;
    score += bonus; scoreEl.textContent = score;
    bannerText = `ステージ ${level} クリア！ +${bonus}`;
    bannerT = 1.8; state = 'clear';
    [523, 659, 784, 1047].forEach((f, i) => beep(f, 0.18, 'triangle', 0.1, i * 0.09));
  }

  function gameOver() {
    state = 'over';
    if (score > best) { best = score; try { localStorage.setItem('peak-solitaire-best', String(best)); } catch (e) {} }
    bestEl.textContent = best;
    ovTitle.textContent = 'ゲームオーバー';
    ovText.innerHTML = `スコア <b class="hl">${score}</b>（ベスト ${best}）<br>ステージ ${level} まで到達 / 最大 ${maxStreak} コンボ<br>片づけたカード ${cleared} 枚`;
    startBtn.textContent = 'もう一度';
    overlay.classList.remove('hidden');
    beep(260, 0.25, 'sawtooth', 0.06); beep(180, 0.4, 'sawtooth', 0.06, 0.2);
  }
```

- **ステージクリアのボーナス** … 基本の 500 点に、**残った山札1枚につき 50 点**、さらにステージ番号 × 100 点を足します。山札を節約してクリアするほど高得点です
- `state` を `'clear'` にして、1.8 秒間バナーを出します。ドミソド（523・659・784・1047Hz）を 0.09 秒ずつずらして鳴らすファンファーレつきです
- **ゲームオーバー** … 今回のスコアがベストより高ければ `best` を更新して localStorage に保存します。オーバーレイのタイトル・本文・ボタンの文字を書きかえて表示し、低いブザー音を2つ鳴らします
- `innerHTML` に入れると `<br>` や `<b>` がタグとして働きます。ここに入れる値は自分で計算した数値だけなので安全です
- ボタンの文字は「もう一度」になりますが、押したときの動きは `start()` のままなので、何度でも遊び直せます

## ゲームループで状態を進める

`loop()` の **上** の `let last = performance.now();` の行を **書きかえ** ます。

```js:game.js
  let last = performance.now(), overT = 0;
```

`loop()` の中の `if (state === 'play') { stuckT += dt; }` を、次のように **書きかえ** ます。

```js:game.js
    if (state === 'play') {
      stuckT += dt;
      if (!playable().length && !stock.length && !flying.length) {
        overT += dt; if (overT > 1.2) { overT = 0; gameOver(); }
      } else overT = 0;
    } else if (state === 'clear') {
      bannerT -= dt;
      if (bannerT <= 0) { level++; deal(); state = 'play'; }
    }
```

- **動けない判定** … 取れるカードがなく、山札も空で、飛んでいるカードもないとき。すぐにゲームオーバーにせず、1.2 秒（`overT`）待ってから `gameOver()` を呼びます。最後の1枚が手札に着いたのを見届けられるようにするためです
- **ステージクリア中** … バナーの残り時間を減らし、0 になったら `level` を1つ上げて、新しく配り直してゲームを再開します。得点はそのまま持ちこします

このように、ゲームを `'title'`（タイトル）・`'play'`（プレイ中）・`'clear'`（クリア演出中）・`'over'`（ゲームオーバー）の **状態（state）** で分けて、状態ごとにやることを切りかえる作り方を **ステートマシン** といいます。入力の処理でも `state !== 'play'` なら受けつけないようにしてあるので、クリア演出中にカードをタップしてしまう心配もありません。

## バナーを描く

`render()` のいちばん最後、浮かぶ文字を描く `for (const p of popups) {...}` の **下** に追加します。

```js:game.js

    if (state === 'clear' || (state === 'play' && !pl.length && !stock.length && !flying.length)) {
      ctx.fillStyle = 'rgba(0,0,0,.45)'; ctx.fillRect(0, 225, W, 50);
      ctx.fillStyle = '#ffe17a'; ctx.font = 'bold 20px system-ui, sans-serif';
      ctx.fillText(state === 'clear' ? bannerText : 'もう動かせない…', W / 2, 250);
    }
```

ステージクリア中はクリアのメッセージを、動けなくなってゲームオーバーまでの 1.2 秒間は「もう動かせない…」を、画面のまん中に半透明の黒い帯で表示します。

これで完成です！ ステップ1から順に作ってきた `game.js` は、完成品とまったく同じ内容になっています。

> [!CHECK] 動作チェック
> - 山のカードを全部片づけると「ステージ 1 クリア！ +〇〇」の帯が出て、少しすると新しいカードが配られ、STAGE が 2 になる。スコアは持ちこされる
> - 山札が尽きて取れるカードもなくなると「もう動かせない…」と出て、ゲームオーバー画面にスコア・到達ステージ・最大コンボ・片づけた枚数が表示される
> - ベストを更新すると BEST が変わり、ページを再読み込みしても残っている
> - 「もう一度」ボタン（または Enter / Space）で、ステージ1からやり直せる
> - 開発者ツールの Console にエラーが出ていない

## 改造アイデア

> [!TIP]
> - `playCard()` で作っている `label` を `addScore(pts, c.x + CW / 2, c.y, label)` のように4番目の引数で渡して、「3コンボ +30 山頂!」と表示されるようにしてみよう
> - 直前に取ったカードを山の元の場所に戻せる「やり直し（アンドゥ）」を、ステージに1回だけ使えるルールで足してみよう（`removed` を false に戻して `waste` から `pop()` する）
> - `layout()` を書きかえて、ピラミッド1つや、ハートの形など、別の並べ方のステージを作ってみよう
> - ステージが進むほど山札を減らして（`stock = d.slice(29 + level)` など）、だんだん難しくなるようにしてみよう
> - 同じマーク（`suit`）で続けて取ったら追加ボーナス、のような自分だけのルールを足してみよう
