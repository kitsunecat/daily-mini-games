## このステップのゴール

28枚のカードを **3つの山の形** に並べます。カードどうしの **重なり（どのカードがどのカードを隠しているか）** をデータで持たせ、上に何も重なっていないカードだけを表向きに描きます。

## 並べ方を決める定数

`const CW = 32, CH = 46;` の行を、次のように **書きかえ** ます。

```js:game.js
  const CW = 32, CH = 46, STEP = 34, ROWY = 28, OX = (W - (STEP * 9 + CW)) / 2, OY = 56;
```

- `STEP` … 横に並ぶカードの間隔。カードの幅 32 より少しだけ広い 34 です
- `ROWY` … 1段下がるときの縦のずれ。カードの高さ 46 より小さいので、下の段が上の段に **半分ほど重なって** 見えます
- `OX`・`OY` … 並び全体の左上の位置。いちばん下の段は10枚なので、幅は `STEP * 9 + CW` になります。それを画面幅 `W` から引いて半分にすると、ちょうど左右中央にそろいます

`let state = 'title';` の行も **書きかえ** ます。

```js:game.js
  let state = 'title', board = [];
```

`board` は山に並んだ28枚のカードの配列です。

## 山の形をデータにする layout()

`const demo = shuffled(); // 見本（ステップ3で消す）` の行を **消して**、かわりに次のコードを入れます。

```js:game.js

  function layout() {
    // rows: 0 = peak tops (3), 1 = (6), 2 = (9), 3 = bottom (10)
    const slots = [];
    for (let p = 0; p < 3; p++) slots.push({ row: 0, x: 1.5 + 3 * p, cov: [3 + 2 * p, 4 + 2 * p] });
    for (let p = 0; p < 3; p++) for (let j = 0; j < 2; j++) {
      const i = 3 * p + j;
      slots.push({ row: 1, x: 1 + 3 * p + j, cov: [9 + i, 10 + i] });
    }
    for (let i = 0; i < 9; i++) slots.push({ row: 2, x: 0.5 + i, cov: [18 + i, 19 + i] });
    for (let i = 0; i < 10; i++) slots.push({ row: 3, x: i, cov: [] });
    return slots;
  }
  const SLOTS = layout();
```

山は上から4段で、段ごとの枚数は 3・6・9・10 枚、合計28枚です。`layout()` は28個の **置き場所（スロット）** を上の段から順に作ります。スロットの番号は配列の順番そのままで、

- 0〜2 番 … いちばん上（0段目）の3枚。それぞれの山のてっぺん
- 3〜8 番 … 1段目の6枚（山ごとに2枚）
- 9〜17 番 … 2段目の9枚
- 18〜27 番 … いちばん下（3段目）の10枚

になっています。各スロットが持つ値は次の3つです。

- `row` … 何段目か
- `x` … 横の位置を「カード何枚分か」で表したもの。上の段のカードは、すぐ下の2枚のちょうどまん中に来るように 0.5 ずつずらしています
- `cov` … **このカードの上に重なっている（このカードを隠している）カードの番号** の配列

### cov（カバー）の考え方

このゲームでは、画面で **下にある段のカードほど手前** に置かれています。たとえば山のてっぺん（0 番）は、1段目の 3 番と 4 番に半分ずつ隠されているので `cov: [3, 4]` です。2段目の 9 番は、3段目の 18 番と 19 番に隠されています（`cov: [18, 19]`）。いちばん下の段は何にも隠されていないので `cov: []` です。

1段目は山ごとに2枚ずつなので、`i = 3 * p + j` という番号で「2段目のうちどの2枚が自分を隠すか」を計算しています（山1つぶんで2段目のカードが3枚進むので `3 * p`）。2段目と3段目は山どうしがつながって、横一列に並びます。

こうしておけば「このカードは表向きか？」は「`cov` に入っているカードが全部取りのぞかれたか？」で判定できます。

## カードを配る deal() と faceUp()

`const SLOTS = layout();` の **下** に追加します。

```js:game.js

  function deal() {
    const d = shuffled();
    board = SLOTS.map((s, i) => ({
      ...d[i], row: s.row, cov: s.cov, removed: false,
      x: OX + s.x * STEP, y: OY + s.row * ROWY
    }));
  }

  function faceUp(c) { return !c.removed && c.cov.every(i => board[i].removed); }
```

- `SLOTS.map()` で、スロット1つにつきシャッフルしたデッキから1枚ずつ割り当てます。`...d[i]` は **スプレッド構文** で、カードの `rank` と `suit` をそのまま新しいオブジェクトにコピーします
- `removed` は「もう手札に移したか」のしるしです。カードは配列から消さずに、このしるしで管理します。配列の番号がずれないので、`cov` の番号がいつでも正しく使えます
- `x`・`y` は Canvas 上の左上の座標です。スロットの `x`（カード何枚分か）に `STEP` を掛けてピクセルにします
- `faceUp(c)` は「取りのぞかれていなくて、`cov` のカードが **全部（`every`）** 取りのぞかれている」なら true を返します。`[].every(...)` は常に true なので、いちばん下の段は最初から表向きです

`start()` の中の `state = 'play';` の **前** に `deal();` を足して、次のようにします。

```js:game.js
  function start() {
    deal(); state = 'play'; overlay.classList.add('hidden');
  }
```

ファイルのいちばん下の `resize();` の **下** にも `deal();` を足します。タイトル画面の後ろにもカードが並んで見えるようにするためです。

```js:game.js
  resize();
  deal(); // background deal for title screen
  requestAnimationFrame(loop);
```

## 山を描く

`render()` の中の、ステップ2で入れた「見本」の4行を **消して**、かわりに次のコードを入れます。

```js:game.js

    // mountains silhouette
    ctx.fillStyle = 'rgba(0,0,0,.12)';
    for (let p = 0; p < 3; p++) {
      const cx = OX + (1.5 + 3 * p) * STEP + CW / 2;
      ctx.beginPath(); ctx.moveTo(cx - 62, OY + ROWY * 3 + CH + 8); ctx.lineTo(cx, OY - 16); ctx.lineTo(cx + 62, OY + ROWY * 3 + CH + 8); ctx.fill();
    }

    // board
    for (const c of board) {
      if (c.removed) continue;
      const up = faceUp(c);
      ctx.save(); ctx.shadowColor = 'rgba(0,0,0,.3)'; ctx.shadowBlur = 4; ctx.shadowOffsetY = 2;
      if (up) cardFace(c, c.x, c.y, CW, CH); else cardBack(c.x, c.y, CW, CH);
      ctx.restore();
    }

    // cards remaining label
    const left = board.filter(c => !c.removed).length;
    ctx.fillStyle = 'rgba(255,255,255,.75)'; ctx.font = '13px system-ui, sans-serif'; ctx.textAlign = 'center'; ctx.textBaseline = 'middle';
    ctx.fillText(`のこり ${left} 枚`, W / 2, OY + ROWY * 3 + CH + 24);
```

- **山のシルエット** … 各山のてっぺんのカードの中心 `cx` を頂点にした、うすい黒の三角形を3つ描いて「山」らしさを出します
- **カード** … `board` を **番号の小さい順（上の段から）** に描きます。Canvas は後から描いたものが手前に来るので、下の段のカードが上の段のカードに重なって見えます。これが `cov` の「下の段ほど手前」という決まりと一致しています
- `shadowColor`・`shadowBlur`・`shadowOffsetY` を設定すると、そのあと描く図形に影がつきます。影の設定は `save()`〜`restore()` ではさんで、ほかの描画に影響しないようにします
- **のこり枚数** … `filter()` で取りのぞかれていないカードを数えて、山の下に表示します

> [!CHECK] 動作チェック
> - 3つの山の形に28枚のカードが並ぶ。表向きなのは、いちばん下の段の10枚だけ
> - 下の段のカードが上の段のカードに半分ずつ重なって見える
> - 山の下に「のこり 28 枚」と表示される
> - タイトル画面の後ろにもカードが並んでいて、スタートするたびに並びが変わる
