## このステップのゴール

3つのファイルを用意して、ゲーム画面の土台を作ります。上に「STAGE・SCORE・BEST」の表示、まん中にゲームを描く **Canvas**（キャンバス）とその上に重ねるタイトル画面（オーバーレイ）、下にひとことヒントを置き、Canvas に **緑のフェルトのテーブル** を描くところまで進めます。

完成すると、こんなゲームになります。

- 3つの山の形に **28枚のカード** が並んでいて、上に何も重なっていないカードだけが表を向いている
- 右下の **手札** のいちばん上のカードより **1つ大きいか1つ小さい** 数の表向きカードをタップすると、そのカードが手札に移る（K と A はつながる）
- 取れるカードがなければ左下の **山札** をタップして1枚めくる。めくらずに続けて取るほど **コンボ** で高得点、山のてっぺんはボーナス
- 山を全部片づけるとステージクリアで次のステージへ。山札が尽きて動けなくなるとゲームオーバー。ベストはブラウザに保存される

- `<meta name="viewport" ...>` はスマホで画面幅に合わせて表示し、ピンチで拡大されないようにする設定です

- `<script>` を `</body>` の直前に置くと、HTML の要素がすべて読みこまれてから JavaScript が動きます

## game.js

JavaScript は、このあとのステップで少しずつ育てていきます。まずは土台です。

```js:game.js
(() => {
  'use strict';
  const W = 360, H = 560;

  const cv = document.getElementById('cv'), ctx = cv.getContext('2d');
  const scoreEl = document.getElementById('score'), bestEl = document.getElementById('best');
  const stageEl = document.getElementById('stage-no');
  const overlay = document.getElementById('overlay'), ovTitle = document.getElementById('ov-title');
  const ovText = document.getElementById('ov-text'), startBtn = document.getElementById('start');
  const stage = document.getElementById('stage');

  let state = 'title';
  let time = 0;
  let scale = 1;

  function resize() {
    const sw = stage.clientWidth - 16, sh = stage.clientHeight - 8;
    scale = Math.max(0.3, Math.min(sw / W, sh / H));
    const dpr = window.devicePixelRatio || 1;
    cv.style.width = Math.floor(W * scale) + 'px';
    cv.style.height = Math.floor(H * scale) + 'px';
    cv.width = Math.floor(W * scale * dpr);
    cv.height = Math.floor(H * scale * dpr);
    ctx.setTransform(scale * dpr, 0, 0, scale * dpr, 0, 0);
  }
  window.addEventListener('resize', resize);

  function start() {
    state = 'play'; overlay.classList.add('hidden');
  }

  // --- input ---
  startBtn.addEventListener('click', start);

  // --- drawing ---
  function rr(x, y, w, h, r) {
    ctx.beginPath(); ctx.moveTo(x + r, y); ctx.arcTo(x + w, y, x + w, y + h, r); ctx.arcTo(x + w, y + h, x, y + h, r);
    ctx.arcTo(x, y + h, x, y, r); ctx.arcTo(x, y, x + w, y, r); ctx.closePath();
  }

  function render() {
    ctx.clearRect(0, 0, W, H);
    const bg = ctx.createRadialGradient(W / 2, H * 0.3, 40, W / 2, H * 0.4, H * 0.8);
    bg.addColorStop(0, '#2c8a5f'); bg.addColorStop(1, '#14553a');
    ctx.fillStyle = bg; ctx.fillRect(0, 0, W, H);
    ctx.strokeStyle = 'rgba(255,255,255,.08)'; ctx.lineWidth = 2;
    rr(6, 6, W - 12, H - 12, 12); ctx.stroke();
  }

  // --- loop ---
  let last = performance.now();
  function loop(now) {
    const dt = Math.min(0.05, (now - last) / 1000); last = now; time += dt;
    render();
    requestAnimationFrame(loop);
  }

  resize();
  requestAnimationFrame(loop);
})();
```

### 全体を `(() => { ... })();` で包む

ファイル全体を **即時実行関数** で包んでいます。中で作った変数や関数が外（ほかのスクリプト）とぶつからないようにするための、昔からある書き方です。`'use strict';` は書きまちがいをエラーとして教えてくれるモードです。

### 固定サイズの座標で考える

`W = 360, H = 560` が **ゲームの中の座標** の大きさです。カードの位置などはすべてこの 360×560 の世界で考えます。実際の画面の大きさに合わせて拡大・縮小するのが `resize()` の仕事です。

- `scale` … 画面に収まる倍率。横と縦で小さいほうに合わせるので、はみ出しません
- `cv.style.width/height` … 画面上の見た目の大きさ
- `cv.width/height` … Canvas の中身の画素数。`devicePixelRatio`（スマホなどの高解像度画面では 2〜3）を掛けて、ぼやけないようにしています
- `ctx.setTransform(scale * dpr, 0, 0, scale * dpr, 0, 0)` … 「これから描くものを全部 `scale * dpr` 倍する」設定。これで描く側は 360×560 の座標のまま書けます

### rr() で角の丸い四角形

`rr(x, y, w, h, r)` は角の丸い四角形の **パス（輪郭）** を作るだけの関数です。`arcTo()` で4つの角を丸めながら一周します。塗るときは `ctx.fill()`、線を引くときは `ctx.stroke()` を後から呼びます。カードもテーブルの縁も、全部この関数で描きます。

### ゲームループ

`requestAnimationFrame(loop)` は「次に画面を描きかえるタイミングで `loop` を呼んで」とブラウザに頼む関数です。`loop` の最後でもう一度頼むので、1秒に約60回 `loop` が呼ばれ続けます。これが **ゲームループ** です。

- `now` はブラウザが渡してくれる現在時刻（ミリ秒）。前回との差を秒にしたものが `dt`（デルタタイム）です
- `Math.min(0.05, ...)` で、タブを切りかえて戻ってきたときなどに `dt` が大きくなりすぎないようにしています
- `time` は経過時間の合計。あとで「光が点滅する」などの演出に使います

`render()` は今はテーブルを描くだけですが、毎フレーム「全部消して、全部描き直す」のが Canvas でのゲームの基本です。
