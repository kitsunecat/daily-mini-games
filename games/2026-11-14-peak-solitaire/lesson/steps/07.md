## このステップのゴール

カードの動きに **アニメーション** をつけます。取ったカードが山から手札へ **弧を描いて飛び**、山札からめくったカードは **くるっと裏返り** ながら手札に乗ります。隠れていたカードが表になるときも、めくれる動きをつけます。さらに、しばらく手が止まったら取れるカードを光らせる **ヒント** と、取れるカードがないときに山札を光らせる表示も入れます。

## 変数を足す

`let state = ...` の行と `let scale = 1;` の行を **書きかえ** ます（まん中の `let score = ...` の行はそのまま）。

```js:game.js
  let state = 'title', board = [], stock = [], waste = [], flying = [], popups = [], sparks = [];
  let score = 0, streak = 0, maxStreak = 0, cleared = 0, time = 0;
  let stuckT = 0, scale = 1;
```

- `flying` … 手札に向かって飛んでいる途中のカードの配列
- `stuckT` … 最後に山札をめくってから（またはステージ開始から）の経過時間。ヒントを出すタイミングに使います

`deal()` を、次のように **書きかえ** ます。

```js:game.js
  function deal() {
    const d = shuffled();
    board = SLOTS.map((s, i) => ({
      ...d[i], row: s.row, cov: s.cov, removed: false, shake: 0, flip: 1,
      x: OX + s.x * STEP, y: OY + s.row * ROWY
    }));
    waste = [d[28]];
    stock = d.slice(29);
    flying = []; streak = 0; stuckT = 0;
  }
```

`flip` はカードがめくれる途中の進み具合で、0（めくり始め）〜1（めくり終わり）です。最初は 1（めくれ終わった状態）にしておきます。

## 飛ぶカードを登録する

`playCard()` の中、`waste.push(c);` の **下** に1行足します。

```js:game.js
    flying.push({ card: c, fx: c.x, fy: c.y, fw: CW, fh: CH, t: 0 });
```

`fx`・`fy`・`fw`・`fh` は **飛び始めの位置と大きさ**（from の f）、`t` は飛び始めてからの時間です。カードのデータそのものはもう `waste` に入っているので、`flying` は「見た目の動き」だけを受け持ちます。

同じく `playCard()` の最後、`beep(330 * ...);` の **下** に追加します。

```js:game.js
    // newly revealed cards flip
    for (const b of board) if (!b.removed && b.flip >= 1 && faceUp(b) && b._wasDown) { b.flip = 0; b._wasDown = false; }
```

`_wasDown` は「さっきまで裏向きだった」というしるしです（このあとゲームループでつけます）。カードを1枚取ったあとで「今は表向きなのに、さっきまで裏向きだった」カードを探し、`flip` を 0 にしてめくるアニメーションを始めます。

`draw1()` は、`waste.push(c);` の **下** に `flying.push(...)` を足し、`streak = 0;` を `streak = 0; stuckT = 0;` に変えて、次のようにします。

```js:game.js
  function draw1() {
    if (state !== 'play' || !stock.length) { if (state === 'play') beep(150, 0.1, 'square', 0.04); return; }
    const c = stock.pop();
    waste.push(c);
    flying.push({ card: c, fx: STOCK_X, fy: HAND_Y, fw: HW, fh: HH, t: 0, fromStock: true });
    if (streak >= 3) popups.push({ x: W / 2, y: HAND_Y - 20, text: 'コンボ終了', t: 0, dim: true });
    streak = 0; stuckT = 0;
    beep(440, 0.06, 'sine', 0.07);
  }
```

山札からのカードには `fromStock: true` をつけて、飛びながら裏から表に返るようにします。

## めくれる動きを描く drawCard()

`function cardFace(...) {...}` の **下** に追加します。

```js:game.js

  function drawCard(c, x, y, w, h, opt) {
    const f = opt.flip === undefined ? 1 : opt.flip;
    if (f < 1) {
      const s = Math.abs(Math.cos(f * Math.PI));
      ctx.save(); ctx.translate(x + w / 2, 0); ctx.scale(Math.max(0.02, s), 1); ctx.translate(-(x + w / 2), 0);
      if (f < 0.5) cardBack(x, y, w, h); else cardFace(c, x, y, w, h, opt);
      ctx.restore();
    } else if (opt.back) cardBack(x, y, w, h);
    else cardFace(c, x, y, w, h, opt);
  }
```

カードを **横方向にだけ縮めて、また広げる** と、くるっとめくれたように見えます。

- `Math.cos(f * Math.PI)` は、`f` が 0 → 0.5 → 1 と進むと 1 → 0 → −1 と変わります。絶対値をとった `s` は **1 → 0 → 1** になるので、これを横の倍率にします
- 前半（`f < 0.5`）は裏、後半は表を描くので、幅が 0 になった瞬間に裏から表に切りかわります
- `ctx.scale()` は原点（左上）を中心に拡大縮小するので、`translate()` でいったんカードの中心に原点を動かしてから縮め、元に戻しています。こうするとカードの中心を軸にしてめくれます。倍率が 0 だと描けないので、最小 0.02 にしています
- めくれていないとき（`f` が 1）は、`opt.back` に合わせて裏か表をそのまま描きます

## 山のカードの描き方を変える

`render()` の `// board` の部分を、次のように **書きかえ** ます（`// board` の上に2行増えます）。

```js:game.js
    const pl = state === 'play' ? playable() : [];
    const hintOn = state === 'play' && stuckT > 4 && pl.length;
    // board
    for (const c of board) {
      if (c.removed) continue;
      const up = faceUp(c);
      let x = c.x;
      if (c.shake > 0) x += Math.sin(c.shake * 60) * 3;
      const glow = up && hintOn && pl.includes(c) && Math.sin(time * 6) > 0;
      ctx.save(); ctx.shadowColor = 'rgba(0,0,0,.3)'; ctx.shadowBlur = 4; ctx.shadowOffsetY = 2;
      drawCard(c, x, c.y, CW, CH, { back: !up, flip: up ? c.flip : 1, glow });
      ctx.restore();
    }
```

- `pl` … 今取れるカードの一覧。`hintOn` … 取れるカードがあるのに **4秒以上** 山札もめくらずに止まっているとき true
- `glow` … ヒント中で、取れるカードなら光らせます。`Math.sin(time * 6) > 0` で約0.5秒ごとに光ったり消えたりします
- `drawCard()` に `{ back: !up, flip: ..., glow }` を渡して描きます。`{ glow }` は `{ glow: glow }` の省略形です

## 山札を光らせる

`// stock` の部分を、次のように **書きかえ** ます（`const stuck` の行と `if (stuck) {...}` が増えます）。

```js:game.js
    // stock
    const stuck = state === 'play' && !pl.length && stock.length;
    if (stock.length) {
      const n = Math.min(4, Math.ceil(stock.length / 6));
      for (let i = n - 1; i >= 0; i--) {
        ctx.save(); ctx.shadowColor = 'rgba(0,0,0,.3)'; ctx.shadowBlur = 5; ctx.shadowOffsetY = 2;
        cardBack(STOCK_X - i * 2, HAND_Y - i * 2, HW, HH); ctx.restore();
      }
      if (stuck) {
        ctx.strokeStyle = `rgba(255,225,122,${0.5 + 0.5 * Math.sin(time * 6)})`; ctx.lineWidth = 3;
        rr(STOCK_X - 4, HAND_Y - 4, HW + 8, HH + 8, 10); ctx.stroke();
      }
    } else {
      ctx.strokeStyle = 'rgba(255,255,255,.3)'; ctx.setLineDash([5, 4]); ctx.lineWidth = 2;
      rr(STOCK_X, HAND_Y, HW, HH, 8); ctx.stroke(); ctx.setLineDash([]);
    }
```

取れるカードが1枚もないときは、山札のまわりの黄色い枠の不透明度を `sin` でゆらして、「めくって！」と知らせます。

## 手札と飛ぶカードを描く

`// waste` の3行を、次のように **書きかえ** ます。

```js:game.js
    // waste: show topmost non-flying card, then flying
    const flyingSet = new Set(flying.map(f => f.card));
    let base = null;
    for (let i = waste.length - 1; i >= 0; i--) if (!flyingSet.has(waste[i])) { base = waste[i]; break; }
    if (base) {
      ctx.save(); ctx.shadowColor = 'rgba(0,0,0,.35)'; ctx.shadowBlur = 6; ctx.shadowOffsetY = 3;
      cardFace(base, WASTE_X, HAND_Y, HW, HH); ctx.restore();
    }
    for (const f of flying) {
      const t = Math.min(1, f.t / 0.22), e = 1 - Math.pow(1 - t, 3);
      const x = f.fx + (WASTE_X - f.fx) * e, y = f.fy + (HAND_Y - f.fy) * e - Math.sin(t * Math.PI) * 30;
      const w = f.fw + (HW - f.fw) * e, h = f.fh + (HH - f.fh) * e;
      ctx.save(); ctx.shadowColor = 'rgba(0,0,0,.4)'; ctx.shadowBlur = 8; ctx.shadowOffsetY = 4;
      drawCard(f.card, x, y, w, h, { flip: f.fromStock ? t : 1 }); ctx.restore();
    }
```

- 手札のいちばん上のカードがまだ飛んでいる途中なら、それはまだ手札に届いていないので、**飛んでいないカードのうちいちばん上** を `base` として手札に描きます。`Set` は「入っているかどうか」を `has()` ですばやく調べられる入れ物です
- 飛ぶカードは 0.22 秒で手札に着きます。`t` は進み具合（0〜1）です
- `e = 1 - (1 - t)³` は **イージング** と呼ばれる式で、最初は速く、着く直前にゆっくりになる動きにします
- 位置と大きさを、始まり（`fx` など）から手札（`WASTE_X` など）まで `e` の割合で近づけます。これを **線形補間** といいます。さらに `y` から `sin(t × π) × 30` を引くと、まん中で 30 だけ持ち上がって **弧を描く** ように飛びます
- 山札からのカードは `flip` に `t` を渡すので、飛びながら裏から表にめくれます

## アニメーションを進める

`loop()` の中の `shake` を減らすループを、次のように **書きかえ**、その **下** に `flying` の更新を足します。

```js:game.js
    for (const c of board) {
      if (c.shake > 0) c.shake = Math.max(0, c.shake - dt);
      if (c.flip < 1) c.flip = Math.min(1, c.flip + dt / 0.25);
      if (!c.removed && !faceUp(c)) c._wasDown = true;
    }
    for (const f of flying) f.t += dt;
    flying = flying.filter(f => f.t < 0.22);
```

- めくれる途中のカードは、`flip` を 0.25 秒で 1 まで進めます
- 裏向きのカードに毎フレーム `_wasDown` のしるしをつけておきます。最初から表向きの下の段のカードにはしるしがつかないので、めくれる動きは起きません
- 着いた（0.22 秒たった）カードは `flying` から取りのぞきます

同じく `loop()` の中、`popups = popups.filter(...)` の **下** に追加します。

```js:game.js

    if (state === 'play') {
      stuckT += dt;
    }
```

> [!CHECK] 動作チェック
> - 山のカードを取ると、小さいカードが大きくなりながら弧を描いて手札まで飛んでいく
> - 山札をめくると、カードが裏から表にくるっと返りながら手札へ飛んでいく
> - 隠れていたカードが表になるとき、くるっとめくれる
> - 取れるカードがあるのに4秒ほど何もしないと、取れるカードのふちが黄色く点滅する
> - 取れるカードがないときは、山札のまわりが黄色く光る
