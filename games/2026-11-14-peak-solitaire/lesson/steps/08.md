## このステップのゴール

PC で遊びやすいように **キーボード操作** をつけます。← → （または A / D）で表向きのカードを選び、Enter で取る。何も選んでいなければ取れるカードを自動で選んで取ります。Space（または ↓ / S）で山札をめくり、タイトル画面では Enter / Space でスタートできるようにします。

## 選んでいるカードの変数

`let score = ...` の行を **書きかえ** て、`sel` を足します。

```js:game.js
  let score = 0, streak = 0, maxStreak = 0, cleared = 0, sel = -1, time = 0;
```

`sel` は **選んでいるカードの `board` での番号** です。何も選んでいないときは -1 にします。

`deal()` の中の `flying = []; streak = 0; stuckT = 0;` の行を **書きかえ** ます。

```js:game.js
    flying = []; streak = 0; sel = -1; stuckT = 0;
```

`playCard()` のいちばん最後（カードをめくる `for` の行の **下**）にも1行足します。カードを取ったら選択を外すためです。

```js:game.js
    sel = -1;
```

## 表向きのカードを左から順に並べる

`function playable() {...}` の **下** に追加します。

```js:game.js
  function openCards() { return board.filter(faceUp).sort((a, b) => a.x - b.x || b.row - a.row); }
```

← → で選ぶには、表向きのカードを **画面の左から右の順** に並べた一覧が必要です。`sort()` の比べ方は、

- まず `a.x - b.x` で横位置の小さい順
- 横位置が同じ（差が 0）なら、`||` の右の `b.row - a.row` で手前の段を先に

という意味です。`0 || 値` は右の値になるので、「第1条件が同じなら第2条件で比べる」がこの1行で書けます。

## キー入力を受け取る

`startBtn.addEventListener('click', start);` の **下** に追加します。

```js:game.js
  window.addEventListener('keydown', e => {
    if (state === 'title' || state === 'over') {
      if (e.key === 'Enter' || e.key === ' ') { e.preventDefault(); start(); }
      return;
    }
    if (state !== 'play') return;
    const open = openCards();
    if (e.key === 'ArrowLeft' || e.key === 'ArrowRight' || e.key === 'a' || e.key === 'd') {
      e.preventDefault();
      if (!open.length) return;
      const cur = open.indexOf(board[sel]);
      const dir = (e.key === 'ArrowLeft' || e.key === 'a') ? -1 : 1;
      const ni = cur < 0 ? (dir > 0 ? 0 : open.length - 1) : (cur + dir + open.length) % open.length;
      sel = board.indexOf(open[ni]);
    } else if (e.key === 'Enter') {
      e.preventDefault();
      if (sel >= 0 && faceUp(board[sel])) playCard(board[sel]);
      else { const pl = playable(); if (pl.length) playCard(pl[0]); }
    } else if (e.key === ' ' || e.key === 'ArrowDown' || e.key === 's') {
      e.preventDefault(); draw1();
    }
  });
```

- `e.key` には押したキーの名前が入ります。矢印キーは `'ArrowLeft'` など、スペースは `' '`（空白1文字）です
- タイトル画面とゲームオーバー画面（`'over'` はステップ9で使います）では、Enter / Space でスタートします
- **← →** … 今選んでいるカードが一覧の何番目か（`cur`）を調べて、`dir`（−1 か +1）だけずらします。`(cur + dir + open.length) % open.length` は、はしまで行ったら反対のはしに戻る **ぐるっと一周** の計算です（`+ open.length` は、−1 になったときに負の数で割らないための工夫）。まだ何も選んでいない（`cur` が -1）なら、→ で左はし、← で右はしを選びます
- **Enter** … 選んでいるカードがあればそれを取ります（取れない数なら震えます）。選んでいなければ `playable()` の最初のカードを自動で取ります
- **Space / ↓ / S** … 山札をめくります
- `e.preventDefault()` で、矢印キーやスペースでページがスクロールするのを防ぎます

## 選んだカードを光らせる

`render()` の `const glow = ...` の行を **書きかえ** ます。

```js:game.js
      const glow = up && (board.indexOf(c) === sel || (hintOn && pl.includes(c) && Math.sin(time * 6) > 0));
```

選んでいるカード（番号が `sel`）なら、ヒントとは関係なく、ずっと黄色いふちで光らせます。

> [!CHECK] 動作チェック
> - タイトル画面で Enter か Space を押すとゲームが始まる
> - → を押すと左はしの表向きカードが黄色いふちで光り、← → で左右に選ぶカードが移る。はしまで行くと反対のはしに戻る
> - 選んだカードで Enter を押すと、数がつながっていれば取れて、つながっていなければ震える
> - 何も選んでいないときに Enter を押すと、取れるカードが自動で1枚取られる
> - Space を押すと山札が1枚めくれる
