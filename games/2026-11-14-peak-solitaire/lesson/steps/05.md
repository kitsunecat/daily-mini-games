## このステップのゴール

ゲームの中心ルール「**手札より1つ大きいか小さい数の表向きカードを取れる**」を作ります。取れないカードをタップしたら、カードを **ぷるぷる震わせて** 知らせます。ここまでで、ソリティアとして遊べるようになります。

## 取れるかどうかを調べる

`function top() {...}` の **下** に2つの関数を追加します。

```js:game.js
  function fits(c) { const d = Math.abs(c.rank - top().rank); return d === 1 || d === 12; }
  function playable() { return board.filter(c => faceUp(c) && fits(c)); }
```

- `fits(c)` … カード `c` と手札のいちばん上のカードの数の差を、`Math.abs()`（絶対値）で求めます。差が 1 なら「1つ大きいか小さい」です
- **K と A がつながる** ルールは `d === 12` で表しています。K は 13、A は 1 なので差は 12 です。数を 1〜13 の数値にしておいたおかげで、この1行で書けます
- `playable()` … 表向きで、しかも取れるカードだけを集めた配列を返します。このステップではまだ使いませんが、ヒントの表示（ステップ7）やゲームオーバーの判定（ステップ9）で活躍します

## カードを取る playCard()

`function draw1() {...}` の **上**（`start()` との間）に追加します。

```js:game.js
  function playCard(c) {
    if (state !== 'play' || !faceUp(c)) return;
    if (!fits(c)) {
      c.shake = 0.35; return;
    }
    c.removed = true;
    waste.push(c);
  }

```

1. ゲーム中でなかったり、裏向きのカードだったりしたら何もしません
2. 数がつながらないときは、`c.shake` に 0.35（秒）を入れて震えるアニメーションを始めます
3. 取れるときは `removed` を true にして、カードを手札に積みます。これで `top()` がこのカードを返すようになり、`faceUp()` の判定で、このカードに隠されていたカードが自動的に表向きになります

山を全部片づけたときの「ステージクリア」は、ステップ9で作ります。

`deal()` の中の `removed: false,` の **後ろ** に `shake: 0,` を足します。

```js:game.js
      ...d[i], row: s.row, cov: s.cov, removed: false, shake: 0,
```

## 山のカードのタップ

`pointerdown` の中の `const p = toLocal(e);` の **下** に追加します。山札の判定より前に入れてください。

```js:game.js
    // board (front rows first)
    const open = board.filter(faceUp).sort((a, b) => b.row - a.row);
    for (const c of open) {
      if (p.x >= c.x - 1 && p.x <= c.x + CW + 1 && p.y >= c.y && p.y <= c.y + CH) { playCard(c); return; }
    }
```

- 判定するのは **表向きのカードだけ** です。裏向きのカードは取れないので、最初から候補に入れません
- 表向きのカードどうしが重なって見えることがあるので、`sort((a, b) => b.row - a.row)` で **段の数が大きい（手前にある）カードから** 調べます。最初に当たったカードで `return` するので、見た目どおり手前のカードが選ばれます
- 左右に 1 ずつ広げているのは、となりのカードとのすき間（2 ピクセル）をタップしても反応させるためです

## カードを震わせる

ゲームループ `loop()` の中、`time += dt;` の行の **下** に追加します。

```js:game.js
    for (const c of board) {
      if (c.shake > 0) c.shake = Math.max(0, c.shake - dt);
    }
```

`shake` を毎フレーム `dt` ずつ減らして、0 になったら止まります。**残り時間** をカードに持たせるのは、アニメーションの基本的な作り方です。

`render()` のカードを描くループを、次のように **書きかえ** ます。

```js:game.js
    // board
    for (const c of board) {
      if (c.removed) continue;
      const up = faceUp(c);
      let x = c.x;
      if (c.shake > 0) x += Math.sin(c.shake * 60) * 3;
      ctx.save(); ctx.shadowColor = 'rgba(0,0,0,.3)'; ctx.shadowBlur = 4; ctx.shadowOffsetY = 2;
      if (up) cardFace(c, x, c.y, CW, CH); else cardBack(x, c.y, CW, CH);
      ctx.restore();
    }
```

`Math.sin()` は −1〜1 を行ったり来たりする関数です。残り時間 `c.shake` に 60 を掛けて渡すと、時間が減るにつれて値が速く振動するので、横位置が左右に ±3 ピクセルぶれて **ぷるぷる** 震えて見えます。

> [!CHECK] 動作チェック
> - 手札より1つ大きいか小さい数の表向きカードをタップすると、そのカードが山から消えて手札に移る
> - K の上に A、A の上に K も置ける
> - 数がつながらないカードをタップすると、そのカードが左右に震えて、取れない
> - 下の段の隣どうしの2枚を両方取ると、その上に隠れていたカードが表向きになる
> - 取れるカードがないときは山札をめくって続けられる
