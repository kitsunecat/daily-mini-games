## このステップのゴール

**スコアとコンボ** を入れて、ゲームらしい手ごたえを作ります。山札をめくらずに続けて取るほど点が増え、山のてっぺんを取るとボーナス。取った点数が浮かび上がる表示、キラキラの火花、コンボメーター、そして **Web Audio API で作る効果音** も加えます。

## 変数と効果音

`let state = ...` から `let scale = 1;` までの3行を、次のように **書きかえ** ます（`beep()` も一緒に追加します）。

```js:game.js
  let state = 'title', board = [], stock = [], waste = [], popups = [], sparks = [];
  let score = 0, streak = 0, maxStreak = 0, cleared = 0, time = 0;
  let scale = 1;

  // --- sound ---
  let ac = null;
  function beep(freq, dur, type = 'sine', vol = 0.1, delay = 0) {
    try {
      if (!ac) ac = new (window.AudioContext || window.webkitAudioContext)();
      const t0 = ac.currentTime + delay;
      const o = ac.createOscillator(), g = ac.createGain();
      o.type = type; o.frequency.value = freq;
      g.gain.setValueAtTime(vol, t0);
      g.gain.exponentialRampToValueAtTime(0.001, t0 + dur);
      o.connect(g); g.connect(ac.destination);
      o.start(t0); o.stop(t0 + dur);
    } catch (e) {}
  }
```

- `popups` … 「+30」のように浮かび上がる文字の配列。`sparks` … 火花の粒の配列
- `score` … 得点。`streak` … 今のコンボ数（続けて取った枚数）。`maxStreak` … いちばん長かったコンボ。`cleared` … 片づけたカードの合計枚数（最後の結果表示に使います）

### Web Audio API で音を鳴らす

音声ファイルを用意しなくても、ブラウザの中で音を作れます。

1. `AudioContext` … 音を扱うための「音の作業台」。最初に音を鳴らすときに1回だけ作ります（ブラウザは、ユーザーが画面を触る前に音を出すことを禁止しているので、タップのあとに作るのが安全です）
2. `createOscillator()` … 決まった高さ（`frequency`、単位はヘルツ）の音を出し続ける **発振器**。`type` で音色（`sine` はやわらかい音、`square` や `sawtooth` はブザーのような音、`triangle` はその中間）を選びます
3. `createGain()` … 音量のつまみ。`exponentialRampToValueAtTime()` で、`dur` 秒かけて音量をほぼ 0 まで下げて「ポン」と消える音にします
4. 発振器 → 音量 → スピーカー（`ac.destination`）の順に `connect()` でつないで、`start()` と `stop()` で鳴らす時間を決めます

`delay` を使うと少し後から鳴らせるので、何回か呼ぶだけで和音やメロディーになります。古いブラウザで失敗してもゲームが止まらないように、全体を `try { ... } catch (e) {}` で包んでいます。

## スタートと得点

`function start() {...}` を **書きかえ**、その **下** に `addScore()` を追加します。

```js:game.js
  function start() {
    score = 0; maxStreak = 0; cleared = 0; scoreEl.textContent = 0;
    popups = []; sparks = [];
    deal(); state = 'play'; overlay.classList.add('hidden');
    beep(523, 0.1, 'triangle'); beep(784, 0.14, 'triangle', 0.1, 0.08);
  }

  function addScore(n, x, y, text) {
    score += n; scoreEl.textContent = score;
    popups.push({ x, y, text: text || ('+' + n), t: 0 });
  }
```

- `start()` で得点などを0に戻します。最後の2つの `beep()` はド（523Hz）とソ（784Hz）を少しずらして鳴らす、スタートの合図です
- `addScore()` は得点を足してヘッダーの表示を更新し、その場所に浮かび上がる文字を追加します。`text` を渡さなければ「+点数」を表示します。`{ x, y }` は `{ x: x, y: y }` の省略形です

## playCard() に得点をつける

`playCard()` 全体を、次のように **書きかえ** ます。

```js:game.js
  function playCard(c) {
    if (state !== 'play' || !faceUp(c)) return;
    if (!fits(c)) {
      c.shake = 0.35; beep(150, 0.12, 'square', 0.05); return;
    }
    c.removed = true; cleared++;
    waste.push(c);
    streak++; maxStreak = Math.max(maxStreak, streak);
    let pts = 10 * streak;
    let label = streak >= 2 ? `${streak}コンボ +${pts}` : `+${pts}`;
    if (c.row === 0) { pts += 150; label += ' 山頂!'; }
    addScore(pts, c.x + CW / 2, c.y);
    for (let i = 0; i < 8; i++) sparks.push({ x: c.x + CW / 2, y: c.y + CH / 2, vx: (Math.random() - .5) * 160, vy: (Math.random() - .8) * 160, t: 0 });
    // rising pitch combo
    beep(330 * Math.pow(2, Math.min(streak - 1, 18) / 12), 0.13, 'triangle', 0.1);
  }
```

- **コンボ** … 取るたびに `streak` を1増やし、`10 × コンボ数` 点を入れます。1枚目は 10 点、2枚目は 20 点、3枚目は 30 点…と、続けるほど1枚あたりの点が大きくなります
- **山頂ボーナス** … `row === 0`（山のてっぺん）のカードなら 150 点を足します
- `label` は「3コンボ +30 山頂!」のような表示用の文字を組み立てていますが、完成品では `addScore()` に渡していないので、実際には「+点数」だけが表示されます（改造アイデアで使います）
- **火花** … カードの中心から8つの粒を、ランダムな速さ `vx`・`vy` で飛ばします。`vy` は `(Math.random() - .8)` なので、ほとんどが上向きに飛び出します
- **だんだん高くなる音** … 音の高さは `2 の (n / 12) 乗` 倍すると **半音 n 個ぶん** 上がります。コンボ数に合わせて半音ずつ上がっていくので、続けて取るほど気持ちよく音階が上がります（18 半音で頭打ち）
- 取れないカードには低いブザー音（150Hz の `square`）を鳴らします

## めくるとコンボが切れる

`draw1()` 全体を **書きかえ** ます。

```js:game.js
  function draw1() {
    if (state !== 'play' || !stock.length) { if (state === 'play') beep(150, 0.1, 'square', 0.04); return; }
    const c = stock.pop();
    waste.push(c);
    if (streak >= 3) popups.push({ x: W / 2, y: HAND_Y - 20, text: 'コンボ終了', t: 0, dim: true });
    streak = 0;
    beep(440, 0.06, 'sine', 0.07);
  }
```

山札をめくると `streak` が 0 に戻ります。3コンボ以上だったときは「コンボ終了」と表示します（`dim: true` で少し落ち着いた色にします）。山札が空のときにタップしたら、ブザー音で知らせます。

## 浮かぶ文字と火花を動かす

`loop()` の中、`shake` を減らすループ（`for (const c of board) { ... }`）の **下** に追加します。

```js:game.js
    for (const s of sparks) { s.t += dt; s.x += s.vx * dt; s.y += s.vy * dt; s.vy += 400 * dt; }
    sparks = sparks.filter(s => s.t < 0.6);
    for (const p of popups) p.t += dt;
    popups = popups.filter(p => p.t < 0.9);
```

- 火花は「位置 += 速さ × 時間」で動かし、`vy += 400 * dt` で下向きに加速させて（重力）、放物線を描いて落ちるようにします
- どちらも `t` に経過時間を持たせ、寿命（火花 0.6 秒、文字 0.9 秒）をすぎたものを `filter()` で配列から取りのぞきます。こうすれば配列がどんどん大きくなりません

## コンボメーター・火花・浮かぶ文字を描く

`render()` の「のこり 〇 枚」の `ctx.fillText(...)` の **下**（`// stock` の上）に追加します。

```js:game.js

    // streak meter
    const my = 290;
    ctx.fillStyle = 'rgba(0,0,0,.25)'; rr(40, my, W - 80, 14, 7); ctx.fill();
    const sw = Math.min(1, streak / 15) * (W - 84);
    if (sw > 0) {
      const g = ctx.createLinearGradient(40, 0, W - 40, 0);
      g.addColorStop(0, '#ffe17a'); g.addColorStop(1, '#ff7a3a');
      ctx.fillStyle = g; rr(42, my + 2, Math.max(10, sw), 10, 5); ctx.fill();
    }
    ctx.fillStyle = '#fff'; ctx.font = 'bold 15px system-ui, sans-serif';
    ctx.fillText(streak >= 2 ? `${streak} コンボ！` : 'コンボ', W / 2, my - 14);
```

暗いバーの上に、コンボ数に応じた長さの黄色→オレンジのバーを重ねます。15 コンボで満タンです（`Math.min(1, ...)` でそれ以上は伸びません）。

`render()` のいちばん最後、矢印「→」を描く `ctx.fillText(...)` の **下** に追加します。

```js:game.js

    // sparks & popups
    for (const s of sparks) {
      ctx.fillStyle = `rgba(255,230,120,${1 - s.t / 0.6})`;
      ctx.beginPath(); ctx.arc(s.x, s.y, 2.5, 0, Math.PI * 2); ctx.fill();
    }
    for (const p of popups) {
      ctx.globalAlpha = Math.max(0, 1 - p.t / 0.9);
      ctx.font = 'bold 15px system-ui, sans-serif';
      ctx.lineWidth = 3; ctx.strokeStyle = 'rgba(0,0,0,.5)';
      const px = Math.min(W - 60, Math.max(60, p.x));
      ctx.strokeText(p.text, px, p.y - p.t * 40);
      ctx.fillStyle = p.dim ? '#cfe' : '#ffe17a';
      ctx.fillText(p.text, px, p.y - p.t * 40);
      ctx.globalAlpha = 1;
    }
```

- 火花は `arc()` で小さな円を描き、経過時間に合わせて透明にしていきます
- 浮かぶ文字は `p.y - p.t * 40` で1秒に 40 ずつ上に動き、`globalAlpha`（全体の不透明度）を下げて消えていきます。先に `strokeText()` で黒いふちを描いてから `fillText()` で中を塗ると、どんな背景の上でも読みやすい文字になります
- `px` は、はしのカードを取ったときに文字が画面からはみ出さないように、横位置を 60〜300 の範囲におさめたものです

> [!CHECK] 動作チェック
> - カードを取ると「+10」「+20」…と点数が浮かび上がって消え、ヘッダーの SCORE が増える
> - 続けて取るほど点数が大きくなり、効果音の高さも上がっていく。コンボメーターも伸びる
> - 山のてっぺんのカードを取ると 150 点のボーナスが加わる
> - 3コンボ以上で山札をめくると「コンボ終了」と表示され、メーターが空になる
> - 取ったカードから黄色い火花が飛び散る
