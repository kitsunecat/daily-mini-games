## このステップのゴール

残りの24枚を **手札（1枚）と山札（23枚）** に分けて画面の下に置き、**山札をタップすると1枚めくって手札に乗せる** ところまで作ります。タップした位置を、ゲームの座標に変換する方法も学びます。

## 置き場所の定数

`const HW = 58, HH = 82;` の行を、次の2行に **書きかえ** ます。

```js:game.js
  const HW = 58, HH = 82, HAND_Y = 372;
  const STOCK_X = 54, WASTE_X = W - 54 - HW;
```

- `HAND_Y` … 山札と手札の上の位置
- `STOCK_X` … 山札（左）の左の位置
- `WASTE_X` … 手札（右）の左の位置。右はしから 54 だけ内側になるように、画面幅から計算しています

プログラムの中では、手札のことを **waste（捨て札）** と呼んでいます。トランプのソリティアでは、めくったカードを表向きに積んでいく場所をこう呼ぶことが多いからです。山札は **stock** です。

`let state = 'title', board = [];` の行を **書きかえ** ます。

```js:game.js
  let state = 'title', board = [], stock = [], waste = [];
```

## 残りのカードを分ける

`deal()` の最後、`}));` の **下** に2行足して、`deal()` 全体を次のようにします。

```js:game.js
  function deal() {
    const d = shuffled();
    board = SLOTS.map((s, i) => ({
      ...d[i], row: s.row, cov: s.cov, removed: false,
      x: OX + s.x * STEP, y: OY + s.row * ROWY
    }));
    waste = [d[28]];
    stock = d.slice(29);
  }
```

シャッフルしたデッキの 0〜27 番は山に使ったので、28 番を最初の手札にし、29 番から最後までの23枚を山札にします。`slice(29)` は「29 番から最後まで」を新しい配列として取り出すメソッドです。

`function faceUp(c) {...}` の **下** に、手札のいちばん上のカードを返す小さな関数を追加します。

```js:game.js
  function top() { return waste[waste.length - 1]; }
```

手札も山札も **配列の最後をいちばん上** として扱います。こうすると、上に積むのは `push()`、上から取るのは `pop()` で済みます。

## 山札をめくる draw1()

`function start() {...}` の **下** に追加します。

```js:game.js

  function draw1() {
    if (state !== 'play' || !stock.length) return;
    const c = stock.pop();
    waste.push(c);
  }
```

ゲーム中で、山札が残っているときだけ、山札のいちばん上を `pop()` で取り出して手札に `push()` で積みます。

## タップを受け取る

`// --- input ---` の **下**（`startBtn.addEventListener(...)` の上）に追加します。

```js:game.js
  function toLocal(e) {
    const r = cv.getBoundingClientRect();
    return { x: (e.clientX - r.left) / scale, y: (e.clientY - r.top) / scale };
  }
  cv.addEventListener('pointerdown', e => {
    e.preventDefault();
    if (state !== 'play') return;
    const p = toLocal(e);
    if (p.x >= STOCK_X - 10 && p.x <= STOCK_X + HW + 10 && p.y >= HAND_Y - 10 && p.y <= HAND_Y + HH + 10) { draw1(); return; }
  });
```

### Pointer Events

`pointerdown` は **マウスのクリックとスマホのタッチの両方** で起きるイベントです。`click` よりも押した瞬間に反応するので、テンポよく遊べます。`e.preventDefault()` で、タッチしたときのスクロールなどブラウザの標準の動きを止めます。

### 画面の座標 → ゲームの座標

イベントの `e.clientX`・`e.clientY` は **ブラウザの画面での位置** です。これをゲームの 360×560 の座標に直すのが `toLocal()` です。

1. `getBoundingClientRect()` で Canvas が画面のどこにあるか（左上の位置）を調べて、そこからの距離にする
2. 画面では `scale` 倍に拡大して表示しているので、`scale` で割って元の大きさに戻す

### 当たり判定

タップした点 `p` が山札の四角形の中にあるかを、`x` と `y` がそれぞれ範囲に入っているかで調べます。指で押しやすいように、カードより上下左右 10 ずつ広めにとっています。

## 山札と手札を描く

`render()` の最後、「のこり 〇 枚」を書く `ctx.fillText(...)` の **下** に追加します。

```js:game.js

    // stock
    if (stock.length) {
      const n = Math.min(4, Math.ceil(stock.length / 6));
      for (let i = n - 1; i >= 0; i--) {
        ctx.save(); ctx.shadowColor = 'rgba(0,0,0,.3)'; ctx.shadowBlur = 5; ctx.shadowOffsetY = 2;
        cardBack(STOCK_X - i * 2, HAND_Y - i * 2, HW, HH); ctx.restore();
      }
    } else {
      ctx.strokeStyle = 'rgba(255,255,255,.3)'; ctx.setLineDash([5, 4]); ctx.lineWidth = 2;
      rr(STOCK_X, HAND_Y, HW, HH, 8); ctx.stroke(); ctx.setLineDash([]);
    }
    ctx.fillStyle = '#fff'; ctx.font = 'bold 13px system-ui, sans-serif';
    ctx.fillText(`山札 ${stock.length}`, STOCK_X + HW / 2, HAND_Y + HH + 16);
    ctx.fillText('手札', WASTE_X + HW / 2, HAND_Y + HH + 16);

    // waste
    ctx.save(); ctx.shadowColor = 'rgba(0,0,0,.35)'; ctx.shadowBlur = 6; ctx.shadowOffsetY = 3;
    cardFace(top(), WASTE_X, HAND_Y, HW, HH); ctx.restore();

    // arrows between
    ctx.fillStyle = 'rgba(255,255,255,.35)'; ctx.font = '22px system-ui, sans-serif';
    ctx.fillText('→', W / 2, HAND_Y + HH / 2);
```

- **山札** … 残り枚数に応じて、裏向きのカードを最大4枚、少しずつ左上にずらして重ねて描きます。`Math.ceil(stock.length / 6)` で、6枚減るごとに重なりが1枚へります。山札が空になったら、`setLineDash([5, 4])` で **点線の枠** だけを描きます（描いたら `setLineDash([])` で実線に戻します）
- **ラベル** … それぞれのカードの下に「山札 23」「手札」と書きます。文字のそろえ方は、すぐ上の「のこり 〇 枚」で設定した `textAlign = 'center'` がそのまま使われます
- **手札** … `top()` のカードを大きいサイズで表向きに描きます
- **矢印** … 山札から手札へ動くことが分かるように、あいだに「→」を描きます

> [!CHECK] 動作チェック
> - スタートすると、左下に裏向きの山札（「山札 23」）、右下に表向きの手札が1枚表示される
> - 山札をタップ（クリック）するたびに、手札のカードが新しいカードに変わり、山札の数字が1つ減る
> - 23回めくると山札が点線の枠になり、それ以上はめくれない
