## このステップのゴール

ゲームとして仕上げます。**ひっくり返って運転手の頭が地面にぶつかる** か、**ガス欠で止まる** とゲームオーバー。結果を表示して「もう一度」で何回でも遊べるようにし、**ハイスコアをブラウザに保存** します。コース上には、自己ベストの距離に赤い点線の目印を立てます。

## 要素とハイスコアの読みこみ

`const scoreEl = ...` と `const overlay = ...` の2行を書きかえます。

```js:game.js
  const scoreEl = $('score'), bestEl = $('best'), distEl = $('dist'), coinsEl = $('coins');
```

```js:game.js
  const overlay = $('overlay'), ovTitle = $('ov-title'), ovText = $('ov-text'), startBtn = $('start');
```

`const pdGas = ...` の行の下に追加します。

```js:game.js

  const KEY = 'hill-drive-best';
  let best = 0;
  try { best = parseInt(localStorage.getItem(KEY), 10) || 0; } catch (e) { best = 0; }
  bestEl.textContent = best;
```

**`localStorage`** は、ブラウザに文字列を保存しておける場所です。ページを閉じても消えません。`setItem(キー, 値)` で保存、`getItem(キー)` で読み出します。

- 保存されるのは文字列なので、`parseInt(..., 10)` で数に直します。まだ保存されていないと `null` が返り、`parseInt` の結果は `NaN` になるので、`|| 0` で 0 にします
- プライベートブラウズなどで `localStorage` が使えない環境では例外が出ることがあるので、`try...catch` で囲みます

## ガス欠を数えるタイマー

`let gas = false, ...` の行に `emptyTimer = 0` を足し、`reset()` の `nextFuel = ...` の行にも `emptyTimer = 0;` を足します。

```js:game.js
  let gas = false, brake = false, groundedA = false, groundedB = false, emptyTimer = 0, flash = 0;
```

```js:game.js
    nextFuel = 1300; nextCoin = 600; emptyTimer = 0;
```

## step() にゲームオーバーの判定を足す

`step()` の `spawnItems();` の下、`setEngine(true, Math.abs(speed));` の **上** に追加します。

```js:game.js

    // crash: head touches ground
    const hx = c.mx + c.nx * 30 - c.dx * 4, hy = c.my + c.ny * 30 - c.dy * 4;
    const roofX = c.mx + c.nx * 22 + c.dx * 18, roofY = c.my + c.ny * 22 + c.dy * 18;
    if (hy + 9 > ground(hx) || roofY > ground(roofX)) { gameOver('ひっくり返った！', 'あたまをぶつけてしまった…'); return; }
    if (fuel <= 0 && Math.abs(speed) < 0.15) {
      emptyTimer++;
      if (emptyTimer > 90) { gameOver('ガス欠！', '燃料タンクを拾いながら進もう'); return; }
    } else emptyTimer = 0;
```

### ひっくり返りの判定

ステップ4で作った `carFrame()` の「上向き `nx, ny`」と「前向き `dx, dy`」を使って、**運転手の頭の位置** と **ロールバーの前の角（屋根）** の2点を求めます。

- 頭 …… 中心から上に 30px、後ろに 4px。頭の半径ぶん（9px）下まで含めて、地面より下に入ったらアウト
- 屋根 …… 中心から上に 22px、前に 18px。前のめりにひっくり返ったときに当たる場所です

クルマが水平なら頭は地面よりずっと上にあるので、ふつうに走っている限り当たりません。ひっくり返ると「上」が地面を向くので、頭が地面にめりこみ、ゲームオーバーになります。**タイヤ2つの位置から決まる座標軸** さえあれば、クルマのどこの点でも同じように計算できるのが、この作り方のよいところです。

### ガス欠の判定

燃料が 0 になっても、勢いで坂を下っている間はまだ終わりにしません。**燃料 0 かつ ほぼ止まっている** 状態が 90 フレーム（1.5秒）続いたらゲームオーバーです。少しでも動けば `emptyTimer` を 0 に戻します。

どちらも `gameOver()` を呼んだら `return` で `step()` をすぐ抜けます。`loop()` の `while (acc >= 1 / 60 && state === 'play')` は `state` が変わるとくり返しをやめるので、ゲームオーバーのあとに物理が進むことはありません。

## gameOver() を作る

`start()` の下に追加します。

```js:game.js
  function gameOver(title, text) {
    state = 'over';
    setEngine(false, 0);
    beep(160, 0.4, 'sawtooth', 0.1);
    const s = score();
    let nb = false;
    if (s > best) { best = s; nb = true; try { localStorage.setItem(KEY, String(best)); } catch (e) { /* ignore */ } }
    bestEl.textContent = best;
    updateHud();
    ovTitle.textContent = title;
    const d = Math.max(0, Math.floor((maxX - START_X) / PX_PER_M));
    ovText.innerHTML = `${text}<br>距離 <b class="hl">${d} m</b> ・ コイン <b class="hl">${coins}</b><br>スコア <b class="hl">${s}</b>${nb ? '<br><b class="hl">ハイスコア更新！</b>' : ''}`;
    startBtn.textContent = 'もう一度';
    setTimeout(() => overlay.classList.remove('hidden'), 500);
    msgEl.textContent = 'スコア = 距離(m) + コイン × 10';
  }
```

- `state = 'over'` にして物理を止め、エンジン音を切って「ブー」と低い音を鳴らします
- スコアがハイスコアより大きければ更新し、`localStorage.setItem` で保存します。`nb`（new best）を覚えておいて、結果に「ハイスコア更新！」を出します
- オーバーレイのタイトルと本文を、ゲームオーバーの理由と結果に書きかえます。本文には `<b>` タグを使いたいので `innerHTML` を使い、テンプレート文字列（`` ` `` で囲む）で数字を埋めこみます
- ボタンの文字を「もう一度」に変えます。押すと `start()` が呼ばれ、`reset()` で新しいコースから始まります
- `setTimeout(..., 500)` で、0.5 秒待ってからオーバーレイを出します。ひっくり返った瞬間が見えてから結果が出るほうが、何が起きたか分かりやすいからです

> [!NOTE]
> `innerHTML` に入れているのは、ゲームの中で計算した数字と決まった文字だけなので安全です。ユーザーが入力した文字をそのまま `innerHTML` に入れると、悪意あるタグを埋めこまれる危険があるので注意しましょう。

## Enter / Space でもスタート

`keydown` の中に1行足して、タイトル画面やゲームオーバー画面では Enter キー・スペースキーでもスタートできるようにします。

```js:game.js
  window.addEventListener('keydown', (e) => {
    const k = e.key.toLowerCase();
    if (k === 'arrowright' || k === 'd') { keyGas = true; e.preventDefault(); }
    else if (k === 'arrowleft' || k === 'a') { keyBrake = true; e.preventDefault(); }
    else if ((k === 'enter' || k === ' ') && state !== 'play') { e.preventDefault(); start(); return; }
    refreshInput();
  });
```

## 自己ベストの目印

`drawTerrain()` の最後（距離の看板の `for` の下）に追加します。

```js:game.js
    // best marker
    if (best > 0) {
      const bx = START_X + best * PX_PER_M;
      if (bx > x0 && bx < x1) {
        const [px, py] = toScreen(bx, ground(bx));
        ctx.strokeStyle = 'rgba(255,80,80,.6)'; ctx.lineWidth = 2; ctx.setLineDash([5, 5]);
        ctx.beginPath(); ctx.moveTo(px, py); ctx.lineTo(px, py - 120); ctx.stroke(); ctx.setLineDash([]);
      }
    }
```

ハイスコアの数字を「距離(m)」とみなして、その位置に赤い点線を立てます（スコアにはコインの点も入っているので、実際の最高到達点より少し先に立ちます。「ここを越えればハイスコア」の目安です）。`ctx.setLineDash([5, 5])` で 5px 描いて 5px 空ける点線になります。ほかの線まで点線にならないよう、描いたら `setLineDash([])` で元に戻します。

これで完成品と同じゲームになりました！

> [!CHECK] 動作チェック
> - 急な坂でアクセルを踏みすぎて後ろにひっくり返ると、0.5 秒後に「ひっくり返った！」と距離・コイン・スコアが表示される
> - 燃料が切れて止まると、少しして「ガス欠！」になる
> - 初めてのゲームオーバーで「ハイスコア更新！」と出て、上の BEST が更新される
> - 「もう一度」（または Enter キー）で、新しい形のコースで最初から遊べる。前回の距離のあたりに赤い点線の目印が立っている
> - ページを再読み込みしても BEST が残っている

## 改造アイデア

> [!TIP]
> **クルマを変える**：`L`（ホイールベース）を長くすると安定してひっくり返りにくく、短くすると小回りがききます。`R` を大きくすると段差に強いモンスタートラックに。アクセルの力 `0.2` や最高速度 `11` もいじってみましょう。

> [!TIP]
> **月面モード**：重力 `G` を 0.12 くらいにすると、ふわふわ飛ぶ月面ドライブになります。空中での回転の強さ `0.09` と組み合わせて、空中で1回転したらボーナス、という仕組みも作れます（`Math.atan2` で求めた角度の変化を足し合わせる）。

> [!TIP]
> **コースを作りかえる**：`ground(x)` の波の数や周期を変えるだけで、まったく別のコースになります。`Math.abs(Math.sin(...))` で岩のようなとがった山、一定間隔で `ground` を急に下げて谷（落ちたら終わり）を作る、なども面白いです。

> [!TIP]
> **ショップとアップグレード**：拾ったコインを `localStorage` にためておき、タイトル画面で「エンジン強化」「燃料タンク拡大」などに使えるようにすると、何度も遊びたくなるゲームになります。
