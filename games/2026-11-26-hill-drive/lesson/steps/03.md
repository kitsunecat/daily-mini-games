## このステップのゴール

**タイヤを2つ** 作り、重力で落として **地面で受け止め** ます。物理の計算には「ベルレ積分（Verlet）」というシンプルな方法を使います。また、端末の速さに左右されない **固定タイムステップ** のゲームループに作りかえます。

## 定数・変数とタイヤを作る wheel()

`// ---------- state ----------` の下の `let state = ...` の行を、次のように **書きかえ** ます。

```js:game.js
  const R = 15, L = 64, G = 0.36;
  let A, B, state = 'title', camX = 0, camY = 0;
  let groundedA = false, groundedB = false;

  function wheel(x) { const y = ground(x) - R; return { x, y, px: x, py: y, rot: 0 }; }
```

- `R` はタイヤの半径、`L` は前後のタイヤの距離（ホイールベース）、`G` は重力（1コマで下向きに増える速さ）です
- `A` が **後ろのタイヤ**、`B` が **前のタイヤ** です
- `groundedA` / `groundedB` は、そのタイヤがいま地面に触れているかどうか
- `wheel(x)` は、横位置 x の地面にちょうど乗った状態のタイヤを作ります。`y` は中心の高さなので、地面から半径 `R` だけ上（マイナス）です

タイヤのオブジェクトには、いまの位置 `x, y` のほかに **1コマ前の位置** `px, py`（previous x, y）を持たせます。`rot` はタイヤの回転角度です。

## reset() でタイヤを置く

`reset()` を次のように書きかえます。

```js:game.js
  function reset() {
    ph = [Math.random() * 6.28, Math.random() * 6.28, Math.random() * 6.28];
    A = wheel(START_X); B = wheel(START_X + L);
    A.y -= 100; A.py = A.y; B.y -= 160; B.py = B.y; // 仮：空中から落とす（ステップ5で消す）
    camX = START_X; camY = ground(START_X);
  }
```

本来タイヤは地面の上から始まりますが、それだと動きが見えないので、**仮のコード** で空中に持ち上げています。`py` も同じだけ動かしているのは、「1コマ前も同じ場所にいた＝速さ 0」にするためです。

## ベルレ積分：位置だけで動かす

ふつう動くものは「位置」と「速度」を持ちますが、ベルレ積分では **速度を持ちません**。代わりに「今の位置 − 1コマ前の位置」を速度とみなします。

1. 速度 = いまの位置 − 1コマ前の位置
2. 1コマ前の位置 ← いまの位置
3. いまの位置 ← いまの位置 + 速度（＋重力）

この方法のよいところは、**位置を直接ずらすだけで、速度も自然に変わる** ことです。地面にめりこんだタイヤを押し出したり、2つのタイヤの距離をそろえたり（ステップ4）するとき、位置をいじるだけで済みます。

## 地面との当たり判定：collide()

`reset()` の下に `// ---------- physics ----------` の見出しを作り、`collide()` と `step()` を追加します。

```js:game.js
  // ---------- physics ----------
  function collide(w) {
    const gy = ground(w.x);
    if (w.y + R <= gy) return false;
    const s = slope(w.x);
    const len = Math.hypot(s, 1);
    const nx = s / len, ny = -1 / len;
    const pen = (w.y + R - gy) / len;
    w.x += nx * pen; w.y += ny * pen;
    let vx = w.x - w.px, vy = w.y - w.py;
    const vn = vx * nx + vy * ny;
    if (vn < 0) { vx -= nx * vn * 1.15; vy -= ny * vn * 1.15; }
    w.px = w.x - vx; w.py = w.y - vy;
    return true;
  }

  function step() {
    // integrate
    for (const w of [A, B]) {
      const vx = (w.x - w.px) * 0.998, vy = (w.y - w.py) * 0.998;
      w.px = w.x; w.py = w.y;
      w.x += vx; w.y += vy + G;
    }
    groundedA = groundedB = false;
    for (let i = 0; i < 4; i++) {
      if (collide(A)) groundedA = true;
      if (collide(B)) groundedB = true;
    }
    // wheel spin
    for (const w of [A, B]) w.rot += (w.x - w.px) / R;
  }
```

`collide(w)` は、タイヤ `w` が地面にめりこんでいたら押し出す関数です。

- タイヤの下の端 `w.y + R` が地面 `gy` より上なら、触れていないので `false` を返して終わり
- 触れていたら、その場所の **法線**（地面に垂直で外向きの向き）`nx, ny` を求めます。傾き `s` の坂に垂直な向きは `(s, -1)` で、`Math.hypot` で長さ1にそろえます
- めりこんだ深さ `pen` だけ、法線の向きに押し出します
- 次に速度 `vx, vy` のうち **地面に向かう成分** `vn`（法線との内積）を調べ、地面に向かっていたら（`vn < 0`）その成分を消します。1.15 倍して少しだけはね返すと、着地で軽くバウンドします
- 最後に `px, py` を「新しい速度になるように」決め直します

> [!NOTE]
> **内積** `vx * nx + vy * ny` は「速度のうち、法線の向きにどれだけ進んでいるか」を表します。マイナスなら地面に向かっている、プラスなら離れている、ということです。坂道の当たり判定でよく使うテクニックです。

`step()` は物理を **1コマ進める** 関数です。

- `* 0.998` はわずかな空気抵抗です。これがないと、いつまでも速さが落ちません
- `collide` を **4回くり返す** のは、ステップ4でタイヤ同士をつなぐ処理と交互に何度か直すと、めりこみや伸び縮みが小さく落ち着くからです
- タイヤは進んだ距離 ÷ 半径 だけ回します（弧の長さ = 半径 × 角度）。これで転がっているように見えます

## タイヤを描く：drawWheel()

`drawTerrain()` の下に追加し、`render()` を書きかえます。

```js:game.js
  function drawWheel(w) {
    const [x, y] = toScreen(w.x, w.y);
    ctx.save(); ctx.translate(x, y); ctx.rotate(w.rot);
    ctx.fillStyle = '#26272b'; ctx.beginPath(); ctx.arc(0, 0, R, 0, Math.PI * 2); ctx.fill();
    ctx.fillStyle = '#c9ced8'; ctx.beginPath(); ctx.arc(0, 0, R * 0.5, 0, Math.PI * 2); ctx.fill();
    ctx.strokeStyle = '#6c7280'; ctx.lineWidth = 2;
    for (let i = 0; i < 3; i++) { ctx.rotate(Math.PI / 3); ctx.beginPath(); ctx.moveTo(-R * 0.5, 0); ctx.lineTo(R * 0.5, 0); ctx.stroke(); }
    ctx.restore();
  }

  function render() {
    drawBackground();
    drawTerrain();
    drawWheel(A); drawWheel(B);
  }
```

`ctx.translate(x, y)` で描く原点をタイヤの中心へ動かし、`ctx.rotate(w.rot)` で回転させてから、原点 (0, 0) を中心にタイヤを描きます。こうすると回転したタイヤも簡単に描けます。`ctx.save()` と `ctx.restore()` で、移動・回転の設定を元に戻すのを忘れないようにします。中のスポーク（3本の線）が回ることで、タイヤが転がっているのが分かります。

## 固定タイムステップのゲームループ

`loop()` を次のように書きかえます（仮のカメラ移動は消します）。

```js:game.js
  let last = 0, acc = 0;
  function loop(ts) {
    const dt = Math.min(0.1, (ts - last) / 1000 || 0);
    last = ts;
    if (state === 'play') {
      acc += dt;
      while (acc >= 1 / 60 && state === 'play') { step(); acc -= 1 / 60; }
    }
    if (A) {
      render();
    }
    requestAnimationFrame(loop);
  }
```

`requestAnimationFrame` は、画面が 1秒に60回の端末もあれば 120回の端末もあります。毎回 `step()` を1回呼ぶと、120Hz の画面ではクルマが2倍速で走ってしまいます。

そこで、`loop` に渡される時刻 `ts`（ミリ秒）から前回との差 `dt`（秒）を求めて `acc`（ためた時間）に足し、**1/60 秒たまるごとに `step()` を1回** 呼びます。こうすると、どの端末でも物理は「1秒に60回」で進みます。これを **固定タイムステップ** といいます。`Math.min(0.1, ...)` は、タブを裏に回して戻ったときなどに一気に何百回も計算しないための上限です。

`if (A)` は「タイヤができてから描く」ための安全策です。最後に `start()` の終わりに `acc = 0;` を足して、スタート直後にたまった時間をリセットします。

```js:game.js
  function start() {
    reset();
    state = 'play';
    overlay.classList.add('hidden');
    msgEl.textContent = '右でアクセル、左でブレーキ。空中で向きを整えよう';
    acc = 0;
  }
```

> [!CHECK] 動作チェック
> - スタートを押すと、空中にある2つのタイヤが重力で落ちてくる
> - 低い方（左）のタイヤが先に、高い方（右）のタイヤがあとから地面に着き、少しだけ弾んで止まる
> - タイヤは地面にめりこまない
> - 再読み込みしてスタートするたびに、同じように落ちる
