## このステップのゴール

いよいよ **運転** できるようにします。画面の右半分（または → / D キー）でアクセル、左半分（← / A キー）でブレーキ。地面ではタイヤが坂に沿って進み、空中ではアクセル・ブレーキで **車体を回転** させて姿勢を整えられます。押しているペダルは画面の下で光ります。

## 要素と変数を追加する

`const overlay = ...` の下にペダルの要素を、`let groundedA = ...` の行は `gas`・`brake` を足して書きかえます。

```js:game.js
  const pdGas = $('pd-gas'), pdBrake = $('pd-brake');
```

```js:game.js
  let gas = false, brake = false, groundedA = false, groundedB = false;
```

`gas` はアクセルを踏んでいるか、`brake` はブレーキを踏んでいるか、です。

ステップ3で入れた **仮のコード** はもう要らないので、`reset()` から次の行を消してください。

```js:game.js
    A.y -= 100; A.py = A.y; B.y -= 160; B.py = B.y; // 仮：空中から落とす（ステップ5で消す）
```

## step() に運転の処理を足す

`step()` の先頭、`// integrate` の **前** に、運転と傾きの処理を追加します。`step()` 全体はこうなります。

```js:game.js
  function step() {
    const onGround = groundedA || groundedB;
    const f = carFrame();
    // drive
    for (const [w, g] of [[A, groundedA], [B, groundedB]]) {
      if (!g) continue;
      const s = slope(w.x), len = Math.hypot(1, s);
      const tx = 1 / len, ty = s / len;
      const vt = (w.x - w.px) * tx + (w.y - w.py) * ty;
      if (gas && vt < 11) { w.x += tx * 0.2; w.y += ty * 0.2; }
      if (brake) {
        if (vt > 0.3) { w.px += (w.x - w.px) * 0.07; w.py += (w.y - w.py) * 0.07; }
        else if (vt > -4) { w.x -= tx * 0.12; w.y -= ty * 0.12; }
      }
      if (!gas && !brake) { w.px += (w.x - w.px) * 0.004; w.py += (w.y - w.py) * 0.004; }
    }
    // air control / tilt
    const tilt = onGround ? 0.035 : 0.09;
    if (gas) { B.x += f.nx * tilt; B.y += f.ny * tilt; A.x -= f.nx * tilt; A.y -= f.ny * tilt; }
    if (brake) { B.x -= f.nx * tilt; B.y -= f.ny * tilt; A.x += f.nx * tilt; A.y += f.ny * tilt; }
    // integrate
    for (const w of [A, B]) {
      const vx = (w.x - w.px) * 0.998, vy = (w.y - w.py) * 0.998;
      w.px = w.x; w.py = w.y;
      w.x += vx; w.y += vy + G;
    }
    groundedA = groundedB = false;
    for (let i = 0; i < 4; i++) {
      constrain();
      if (collide(A)) groundedA = true;
      if (collide(B)) groundedB = true;
    }
    // wheel spin
    for (const w of [A, B]) w.rot += (w.x - w.px) / R;
  }
```

### 地面の上での運転（drive）

地面に触れているタイヤ（`g` が true）だけに力をかけます。空中でタイヤを回しても進まないからです。

- `tx, ty` はその場所の **坂に沿った前向き**（接線）です。傾き `s` の坂なら `(1, s)` の向きで、長さ1にそろえます
- `vt` は、いまの速度のうち **坂に沿った成分**（接線との内積）。前に進んでいればプラスです
- **アクセル**：`vt < 11`（最高速度）なら、坂に沿って前へ 0.2px 押します。ベルレ積分なので、毎コマ少しずつ押すと速度がだんだん上がります
- **ブレーキ**：前に進んでいる（`vt > 0.3`）なら `px, py` を今の位置に 7% 近づけます。「1コマ前との差」が小さくなる＝速度が落ちる、という意味です。ほぼ止まったら、今度は後ろへ押して **バック** します（`vt > -4` まで）
- **何も押していない**：ごくわずかに速度を落とします（転がり抵抗）

### 傾ける力（air control / tilt）

アクセルを踏むと **前のタイヤ B をクルマの上向き（`nx, ny`）に**、後ろのタイヤ A を下向きに少し動かします。すると車体が **後ろ向きに回転**（前が上がる）します。ブレーキはその逆で、前が下がります。

- 空中（`onGround` が false）では 0.09 と強めにかけるので、ジャンプ中にクルマの向きをくるっと変えられます
- 地面の上でも 0.035 だけかかります。これで「アクセルを踏みすぎると前輪が浮いてウィリーし、ひっくり返りそうになる」という、このゲームらしい手ごたえが出ます

## 入力を受け取る

`// ---------- flow ----------` のブロック（`start()` と、そのあとの `addEventListener` 2行）の下、ファイルの終わりにある `reset();` `requestAnimationFrame(loop);` の **上** に、`// ---------- input ----------` を追加します。

```js:game.js
  // ---------- input ----------
  const pointers = new Map();
  let keyGas = false, keyBrake = false;
  function refreshInput() {
    let g = keyGas, b = keyBrake;
    for (const side of pointers.values()) { if (side === 'g') g = true; else b = true; }
    gas = g; brake = b;
    pdGas.classList.toggle('on', gas); pdBrake.classList.toggle('on', brake);
  }
  cv.addEventListener('pointerdown', (e) => {
    e.preventDefault();
    const r = cv.getBoundingClientRect();
    pointers.set(e.pointerId, (e.clientX - r.left) > r.width / 2 ? 'g' : 'b');
    try { cv.setPointerCapture(e.pointerId); } catch (err) { /* ignore */ }
    refreshInput();
  });
  const up = (e) => { pointers.delete(e.pointerId); refreshInput(); };
  cv.addEventListener('pointerup', up);
  cv.addEventListener('pointercancel', up);
  cv.addEventListener('lostpointercapture', up);
  window.addEventListener('blur', () => { pointers.clear(); keyGas = keyBrake = false; refreshInput(); });
  window.addEventListener('keydown', (e) => {
    const k = e.key.toLowerCase();
    if (k === 'arrowright' || k === 'd') { keyGas = true; e.preventDefault(); }
    else if (k === 'arrowleft' || k === 'a') { keyBrake = true; e.preventDefault(); }
    refreshInput();
  });
  window.addEventListener('keyup', (e) => {
    const k = e.key.toLowerCase();
    if (k === 'arrowright' || k === 'd') keyGas = false;
    else if (k === 'arrowleft' || k === 'a') keyBrake = false;
    refreshInput();
  });
```

### 指の数だけ覚える：pointers（Map）

スマホでは **2本の指で同時に** 押すこともあります。片方の指を離しただけで、もう片方のペダルまで外れてしまってはいけません。そこで `Map` を使い、「指の番号（`pointerId`）→ どちら側を押しているか（`'g'` か `'b'`）」を覚えておきます。

- `pointerdown`：押した場所が Canvas の右半分なら `'g'`（gas）、左半分なら `'b'`（brake）として登録
- `pointerup` / `pointercancel` / `lostpointercapture`：その指を `Map` から消す
- `setPointerCapture` は、指が Canvas の外へずれても、離すまでその指のイベントを Canvas に届け続けるための指定です

`pointer` イベントは、マウス・タッチ・ペンをまとめて扱えるイベントです。PC ではマウスのクリック長押しでも運転できます。

### refreshInput() で1か所にまとめる

キーボードの状態（`keyGas`・`keyBrake`）と、`Map` に入っている指の状態を合わせて、最終的な `gas`・`brake` を決めます。入力が変わるたびにこの関数を呼べば、どの入力方法でも同じ結果になります。ペダルの見た目も `classList.toggle('on', 真偽値)` で、ここでまとめて切りかえます。

- `keydown` / `keyup` では、`e.key.toLowerCase()` で小文字にそろえて比べます（`ArrowRight` → `arrowright`）
- `e.preventDefault()` は、矢印キーでページがスクロールするのを防ぎます
- `blur`（ウィンドウからフォーカスが外れた）ときは全部離したことにします。キーを押したまま別のアプリに切りかえると `keyup` が来ず、アクセルが踏みっぱなしになってしまうためです

> [!CHECK] 動作チェック
> - スタート後、画面の右半分を押し続ける（または → キー）とクルマが前へ走り出し、右下の「アクセル」が緑に光る
> - 坂ではゆっくりに、下り坂では速くなる。丘を越えるとジャンプすることもある
> - 左半分（← キー）でブレーキがかかって止まり、そのまま押し続けるとバックする。「ブレーキ」が赤く光る
> - ジャンプ中にアクセルを押すと前が上がり、ブレーキを押すと前が下がる
> - 平地でアクセルを急に踏むと、前輪が少し浮く
