## このステップのゴール

3つのファイルを用意して、ゲーム画面の土台を作ります。上に「← 一覧・SCORE・BEST」、その下に「距離・コイン・燃料メーター」、まん中にクルマと丘を描く **Canvas**、その上に重ねる「ブレーキ／アクセル」のペダル表示とタイトル画面（オーバーレイ）、いちばん下にメッセージを置きます。スタートを押すとタイトル画面が消えるところまで作ります。

完成すると、こんなゲームになります。

- でこぼこの **丘がどこまでも続く** コースを、小さなオフロードカーで右へ進む
- 画面の **右半分を押すとアクセル**、**左半分を押すとブレーキ（止まっているとバック）**。PC では → / ← キー
- 空中では **アクセルで前が上がり、ブレーキで前が下がる**。これで着地の姿勢を整える
- 走ると **燃料** が減る。ときどき置いてある **燃料タンク** を拾うと満タンに戻る
- 坂の上の **コイン** を拾うとスコアが増える。スコア = 距離(m) + コイン × 10
- ひっくり返って **運転手の頭が地面にぶつかる** か、**ガス欠で止まる** とゲームオーバー

- `<meta name="viewport" ...>` はスマホで画面幅に合わせて表示し、ピンチで拡大されないようにする設定です
- JavaScript から書きかえる場所には `id`（`score`・`best`・`dist`・`coins`・`fuelfill`・`msg`・`ov-title`・`ov-text` など）をつけておきます
- `#fuel` は燃料メーターです。`#fuelbar` が灰色の入れ物、中の `#fuelfill` が緑のバーで、この **幅** を JavaScript で 100% → 0% と変えて残量を表します
- `<canvas id="cv">` がゲームの絵を描く場所です。空・丘・クルマ・コインはすべてここに JavaScript で描きます
- `#pedals` はペダルの **見た目だけ** です。実際のタッチは Canvas 全体で受け取り、「右半分か左半分か」で判定します（ステップ5）
- `#overlay` はタイトル画面とゲームオーバー画面を兼ねた「ふた」で、Canvas の上に重ねて表示します
- 「← 一覧」のリンク先はこのサイトのトップです。自分のフォルダで作るときは好きなページに変えてかまいません
- `<script>` を `</body>` の直前に置くと、HTML の要素がすべて読みこまれてから JavaScript が動きます

- `touch-action: none` は、スマホで画面を押したときにスクロールやズームが起きないようにする設定です。ペダルを長押しするゲームなので大事です

- `#pedals` には `pointer-events: none` をつけています。ペダルの上を押しても、その下の Canvas にタッチが届くようにするためです
- `.pedal.on` は押されているペダルの見た目です。少し縮んで色がつきます（ステップ5で JavaScript から `on` を付け外しします）
- `#fuelfill.low` は残りわずかのときに赤くする指定です。`transition: background .3s` で色がふわっと変わります
- `#stage` は `position: relative`、`#overlay` は `position: absolute; inset: 0` なので、オーバーレイはステージにぴったり重なります。`#overlay.hidden { display: none; }` のように、クラスを1つ付けるだけで表示を切りかえられるようにしておきます

## game.js

JavaScript はまず「スタートでタイトル画面を消す」だけを書きます。

```js:game.js
(() => {
  'use strict';
  const $ = (id) => document.getElementById(id);
  const msgEl = $('msg');
  const overlay = $('overlay'), startBtn = $('start');

  // ---------- flow ----------
  function start() {
    overlay.classList.add('hidden');
    msgEl.textContent = '右でアクセル、左でブレーキ。空中で向きを整えよう';
  }

  startBtn.addEventListener('click', (e) => { e.stopPropagation(); start(); });
  overlay.addEventListener('pointerdown', (e) => { if (e.target === overlay) start(); });
})();
```

### 全体を (() => { ... })(); で囲む

ファイル全体を「すぐ実行される関数」で囲むと、中で作った変数がページ全体（グローバル）に漏れません。`'use strict';` は、うっかりミスをエラーとして教えてくれるモードです。

`const $ = (id) => document.getElementById(id);` は、何度も書く `document.getElementById` を短く書くための小さな関数です。何度も使う要素（`msgEl`・`overlay`・`startBtn`）は最初に取り出して変数に入れておきます。

### start() とスタートの受け付け

- `start()` はゲームを始める関数です。今はオーバーレイに `hidden` クラスをつけて隠し、メッセージを出すだけです。ここに少しずつ処理を足していきます
- ボタンの `click` では `e.stopPropagation()` を呼んでいます。ボタンのクリックが親のオーバーレイに伝わって、`start()` が2回呼ばれるのを防ぐためです
- オーバーレイの `pointerdown` は「ボタン以外の場所を押してもスタート」するためのものです。`e.target === overlay` で、文字やボタンではなく **オーバーレイそのもの** を押したときだけ反応させます

> [!NOTE]
> `start` は `addEventListener` の行より **上** で定義していますが、`function 名前() {}` の形で書いた関数は、ファイルの中のどこからでも呼べます（巻き上げ）。このあと関数がどんどん増えるので、`// ---------- flow ----------` のような見出しコメントで区切っておくと迷子になりません。
