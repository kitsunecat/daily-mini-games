## このステップのゴール

Canvas に **空・遠くの山・どこまでも続く丘** を描きます。丘の形は `ground(x)` という「横位置 x を渡すと地面の高さを返す関数」で決めます。スタートを押すとカメラが右へ流れていき、丘が次々に現れることを確かめます。

## game.js を書きかえる

このステップで新しく出てくるものが多いので、`game.js` 全体を載せます。ステップ1のファイルをまるごと置きかえてください。

```js:game.js
(() => {
  'use strict';
  const cv = document.getElementById('cv');
  const ctx = cv.getContext('2d');
  const stage = document.getElementById('stage');
  const $ = (id) => document.getElementById(id);
  const msgEl = $('msg');
  const overlay = $('overlay'), startBtn = $('start');

  // ---------- canvas size ----------
  let W = 0, H = 0, DPR = 1;
  function resize() {
    const r = stage.getBoundingClientRect();
    DPR = Math.min(window.devicePixelRatio || 1, 2);
    W = Math.max(1, r.width); H = Math.max(1, r.height);
    cv.width = Math.round(W * DPR); cv.height = Math.round(H * DPR);
    ctx.setTransform(DPR, 0, 0, DPR, 0, 0);
  }
  window.addEventListener('resize', resize);
  resize();

  // ---------- terrain ----------
  const PX_PER_M = 20;
  const START_X = 120;
  let ph = [0, 0, 0, 0];
  function ground(x) {
    if (x < 400) return 0;
    const t = x - 400;
    const ramp = Math.min(1, t / 500);
    const a = Math.min(140, 30 + t / 60);
    return ramp * (
      0.6 * a * Math.sin(t * 0.004 + ph[0]) - 0.6 * a * Math.sin(ph[0]) +
      0.4 * a * Math.sin(t * 0.011 + ph[1]) - 0.4 * a * Math.sin(ph[1]) +
      Math.min(22, 6 + t / 400) * Math.sin(t * 0.023 + ph[2]) - Math.min(22, 6 + t / 400) * Math.sin(ph[2])
    );
  }
  function slope(x) { return (ground(x + 1) - ground(x - 1)) / 2; }

  // ---------- state ----------
  let state = 'title', camX = 0, camY = 0;

  function reset() {
    ph = [Math.random() * 6.28, Math.random() * 6.28, Math.random() * 6.28];
    camX = START_X; camY = ground(START_X);
  }

  // ---------- drawing ----------
  function drawBackground() {
    const g = ctx.createLinearGradient(0, 0, 0, H);
    g.addColorStop(0, '#6fc3ff'); g.addColorStop(1, '#d6f0ff');
    ctx.fillStyle = g; ctx.fillRect(0, 0, W, H);
    // sun
    ctx.fillStyle = 'rgba(255,240,180,.9)';
    ctx.beginPath(); ctx.arc(W * 0.8, H * 0.14, 26, 0, Math.PI * 2); ctx.fill();
    // far hills (parallax)
    const layers = [[0.15, '#a9d8c0', 0.55, 50], [0.35, '#8cc7a4', 0.65, 40]];
    for (const [p, col, base, amp] of layers) {
      ctx.fillStyle = col; ctx.beginPath(); ctx.moveTo(0, H);
      for (let x = 0; x <= W + 10; x += 10) {
        const wx = x + camX * p;
        ctx.lineTo(x, H * base + Math.sin(wx * 0.006) * amp + Math.sin(wx * 0.017) * amp * 0.3);
      }
      ctx.lineTo(W, H); ctx.fill();
    }
  }

  function toScreen(x, y) { return [x - camX + W * 0.32, y - camY + H * 0.58]; }

  function drawTerrain() {
    const x0 = camX - W * 0.32 - 20, x1 = x0 + W + 40;
    ctx.beginPath();
    let [sx, sy] = toScreen(x0, ground(x0));
    ctx.moveTo(sx, H + 10);
    for (let x = x0; x <= x1; x += 6) { [sx, sy] = toScreen(x, ground(x)); ctx.lineTo(sx, sy); }
    ctx.lineTo(sx, H + 10); ctx.closePath();
    ctx.fillStyle = '#9a6a3e'; ctx.fill();
    // grass
    ctx.beginPath();
    for (let x = x0; x <= x1; x += 6) { [sx, sy] = toScreen(x, ground(x)); x === x0 ? ctx.moveTo(sx, sy) : ctx.lineTo(sx, sy); }
    ctx.strokeStyle = '#4dbb4f'; ctx.lineWidth = 10; ctx.lineJoin = 'round'; ctx.stroke();
    ctx.strokeStyle = '#7ad66a'; ctx.lineWidth = 3; ctx.stroke();
    // distance posts every 50m
    ctx.font = 'bold 11px system-ui, sans-serif'; ctx.textAlign = 'center';
    const step50 = 50 * PX_PER_M;
    for (let x = Math.ceil((x0 - START_X) / step50) * step50 + START_X; x < x1; x += step50) {
      const m = Math.round((x - START_X) / PX_PER_M);
      if (m <= 0) continue;
      const [px, py] = toScreen(x, ground(x));
      ctx.fillStyle = '#5b3d22'; ctx.fillRect(px - 2, py - 34, 4, 34);
      ctx.fillStyle = '#fff'; ctx.fillRect(px - 18, py - 48, 36, 16);
      ctx.fillStyle = '#333'; ctx.fillText(m + 'm', px, py - 36);
    }
  }

  function render() {
    drawBackground();
    drawTerrain();
  }

  // ---------- loop ----------
  function loop() {
    if (state === 'play') camX += 3; // 仮：カメラを右へ流して地形を眺める（ステップ4で消す）
    render();
    requestAnimationFrame(loop);
  }

  // ---------- flow ----------
  function start() {
    reset();
    state = 'play';
    overlay.classList.add('hidden');
    msgEl.textContent = '右でアクセル、左でブレーキ。空中で向きを整えよう';
  }

  startBtn.addEventListener('click', (e) => { e.stopPropagation(); start(); });
  overlay.addEventListener('pointerdown', (e) => { if (e.target === overlay) start(); });

  reset();
  requestAnimationFrame(loop);
})();
```

上から順に見ていきましょう。

## Canvas の準備と resize()

Canvas には **2つの大きさ** があります。CSS で決めた「画面に表示される大きさ」と、`cv.width` / `cv.height` で決める「中の絵の解像度（ピクセル数）」です。この2つがずれていると、絵がぼやけたり引き伸ばされたりします。

- `stage.getBoundingClientRect()` で、ステージが画面上で何px × 何px かを調べ、`W` と `H` に入れます。以降の絵はすべてこの `W` × `H` の座標で描きます
- `devicePixelRatio` は「CSS の 1px が実際の画面の何ピクセルか」です。スマホでは 2〜3 あります。`cv.width = W * DPR` として細かく描き、`ctx.setTransform(DPR, 0, 0, DPR, 0, 0)` で「全部 DPR 倍に拡大して描く」設定にすると、くっきりした絵になります（重くなりすぎないよう最大2にしています）
- `window.addEventListener('resize', resize)` で、画面の向きやウィンドウの大きさが変わったら測り直します

`const ctx = cv.getContext('2d');` の `ctx` が、Canvas に絵を描くための道具箱です。`ctx.fillRect()`（四角をぬる）、`ctx.arc()`（円）、`ctx.lineTo()`（線を引く）などを使います。

## 地形：ground(x)

このゲームのコースは、**サイン波（`Math.sin`）を3つ足し合わせて** 作っています。

- ゆっくりうねる大きな波（`t * 0.004`）……大きな丘
- 少し細かい波（`t * 0.011`）……丘の上のこぶ
- さらに細かい波（`t * 0.023`）……でこぼこ

周期の違う波を重ねると、規則的に見えない自然な丘になります。ほかにもいくつか工夫があります。

- `if (x < 400) return 0;` ……スタート地点のまわりは平らにして、落ち着いて走り出せるようにします
- `ramp` は 0 → 1 へ 500px かけて増える数で、平地から丘へなめらかにつなげます
- `a`（振れ幅）は進むほど大きくなり（最大140）、**先へ行くほど坂が険しく** なります
- `ph`（phase＝位相）は波のずらし量です。`reset()` で毎回ランダムに決めるので、**遊ぶたびにコースが変わります**
- `- 0.6 * a * Math.sin(ph[0])` のような引き算は、`t = 0` のとき（x = 400）に高さがちょうど 0 になるよう、ずれを打ち消すためのものです

> [!NOTE]
> Canvas の座標は **下に行くほど y が大きく** なります。なので `ground(x)` がマイナスの所は「高い所（山）」、プラスの所は「低い所（谷）」です。最初は混乱しやすいので気をつけましょう。

`slope(x)` は、その場所の **坂の傾き** です。少し右の高さと少し左の高さの差を取って「1px 右へ進むと何px 下がるか」を出しています。ステップ3でタイヤを坂に沿って押し返すときに使います。

`PX_PER_M = 20` は「20px を 1m と数える」という約束、`START_X = 120` はクルマのスタート位置です。

## 世界の座標と画面の座標：toScreen()

丘は横に何千px も続きますが、画面に映るのはその一部だけです。そこで「カメラ」の位置 `camX`, `camY` を決めて、**世界の座標を画面の座標に変換** します。

```js:game.js
  function toScreen(x, y) { return [x - camX + W * 0.32, y - camY + H * 0.58]; }
```

カメラが見ている点を、画面の **左から32%・上から58%** の位置に映す、という意味です。クルマは右へ進むので、前方（右）が広く見えるように少し左寄りにしています。戻り値は `[画面x, 画面y]` の配列で、`const [px, py] = toScreen(...)` のように分割代入で受け取ります。

## 描画：drawBackground() と drawTerrain()

`drawBackground()` は空のグラデーション（`createLinearGradient`）、太陽、そして **遠くの山2枚** を描きます。遠くの山は `camX * p`（p = 0.15 と 0.35）だけずらして描くので、カメラが動いても **ゆっくりしか動きません**。手前ほど速く、奥ほどゆっくり動く「パララックス（視差）」という表現で、奥行きが出ます。

`drawTerrain()` は画面に映る範囲 `x0`〜`x1` だけ、6px おきに `ground(x)` を調べて線でつなぎます。

1. 画面の下 → 地面の線 → 画面の下、と囲んで **茶色にぬる**（土）
2. 同じ地面の線を **太い緑・細い明るい緑** の2回なぞる（草）
3. 50m ごとに **距離の看板** を立てる

`ctx.beginPath()` → `moveTo` / `lineTo` で形をなぞる → `fill()`（ぬる）か `stroke()`（線を引く）、が Canvas で形を描く基本の流れです。

## ゲームループ：requestAnimationFrame

```js:game.js
  function loop() {
    if (state === 'play') camX += 3; // 仮：カメラを右へ流して地形を眺める（ステップ4で消す）
    render();
    requestAnimationFrame(loop);
  }
```

`requestAnimationFrame(loop)` は「次に画面を書きかえるタイミング（ふつう1秒に60回）で `loop` を呼んで」というお願いです。`loop` の最後でまた自分を予約するので、ずっと呼ばれ続けます。これがゲームの心臓部「ゲームループ」です。

今はまだクルマがいないので、**仮のコード** で `camX` を毎回 3px ずつ増やし、カメラだけを右へ流しています。ステップ4でクルマを追いかけるカメラに置きかえます。

`start()` では `reset()` で新しいコースを作ってから `state = 'play'` にします。`state` は `'title'`（タイトル画面）・`'play'`（プレイ中）・`'over'`（ゲームオーバー）のどれかで、いまどの場面かを表します。

> [!CHECK] 動作チェック
> - タイトル画面の後ろに、水色の空・太陽・茶色の地面と緑の草が見える
> - スタートを押すと景色が右から左へ流れはじめ、平地のあとに丘が現れる
> - 50m・100m…と距離の看板が流れてくる。奥の山は手前の丘よりゆっくり動く
> - 再読み込みしてもう一度スタートすると、丘の形が毎回ちがう
