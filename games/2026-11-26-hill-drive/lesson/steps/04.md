## このステップのゴール

2つのタイヤを **一定の距離でつなぎ**、その上に **車体と運転手** を描きます。タイヤ2つの位置だけから車体の向きを計算するのがポイントです。カメラもクルマを追いかけるようにします。

## 距離をそろえる：constrain()

`collide()` の下に、`constrain()` と `carFrame()` を追加します。

```js:game.js
  function constrain() {
    const dx = B.x - A.x, dy = B.y - A.y;
    const d = Math.hypot(dx, dy) || 1;
    const diff = (d - L) / d / 2;
    A.x += dx * diff; A.y += dy * diff; B.x -= dx * diff; B.y -= dy * diff;
  }

  function carFrame() {
    const dx = (B.x - A.x) / L, dy = (B.y - A.y) / L;
    const mx = (A.x + B.x) / 2, my = (A.y + B.y) / 2;
    return { dx, dy, nx: dy, ny: -dx, mx, my };
  }
```

`constrain()` は、2つのタイヤの距離を `L` に **戻す** 関数です。

- いまの距離 `d` が `L` より長ければ近づけ、短ければ離します
- ずれ `d - L` を **半分ずつ** 2つのタイヤに分けて動かします。片方だけ動かすより自然です
- ベルレ積分なので、位置を動かすだけで速度も自然に変わります。これが「見えない棒」でつながったクルマになります

`|| 1` は、2つが同じ位置で `d` が 0 のときに 0 で割らないための用心です。

## クルマの向き：carFrame()

`carFrame()` は、タイヤの位置から **クルマの座標軸** を作ります。

- `dx, dy` …… 後ろ → 前 の向き（長さ1）。クルマの「前」
- `nx, ny` …… それを90度回した向き `(dy, -dx)`。クルマの「上」
- `mx, my` …… 2つのタイヤのまん中。クルマの中心

この3つがあれば「クルマの中心から上に30px」の点は `mx + nx * 30, my + ny * 30` と書けます。このあとの描画・アクセルの傾け・ひっくり返り判定（ステップ8）など、あちこちで使います。

## step() で constrain を呼ぶ

`step()` の中の、当たり判定を4回くり返す `for` を次のように書きかえます。

```js:game.js
    for (let i = 0; i < 4; i++) {
      constrain();
      if (collide(A)) groundedA = true;
      if (collide(B)) groundedB = true;
    }
```

「距離をそろえる → 地面から押し出す」を交互に4回くり返します。片方を直すともう片方が少しずれるので、何度かくり返して両方をだいたい満たすようにします。物理エンジンでもよく使われる考え方です。

## 車体を描く：drawCar()

`drawWheel()` の下に `drawCar()` を追加し、`render()` の `drawWheel(A); drawWheel(B);` を `drawCar();` に書きかえます。

```js:game.js
  function drawCar() {
    const c = carFrame();
    const [mx, my] = toScreen(c.mx, c.my);
    const ang = Math.atan2(c.dy, c.dx);
    // suspension
    ctx.strokeStyle = '#555'; ctx.lineWidth = 4;
    for (const w of [A, B]) {
      const [wx, wy] = toScreen(w.x, w.y);
      ctx.beginPath(); ctx.moveTo(wx, wy); ctx.lineTo(wx + c.nx * 12, wy + c.ny * 12); ctx.stroke();
    }
    ctx.save(); ctx.translate(mx, my); ctx.rotate(ang);
    // body (local: x forward, y down)
    ctx.fillStyle = '#ff7a2f'; ctx.strokeStyle = '#a8411a'; ctx.lineWidth = 2;
    ctx.beginPath();
    ctx.moveTo(-44, -8); ctx.lineTo(-42, -22); ctx.lineTo(10, -22); ctx.lineTo(30, -16); ctx.lineTo(46, -14);
    ctx.lineTo(48, -4); ctx.lineTo(-44, -4); ctx.closePath(); ctx.fill(); ctx.stroke();
    // roll bar
    ctx.strokeStyle = '#333'; ctx.lineWidth = 3;
    ctx.beginPath(); ctx.moveTo(-14, -22); ctx.lineTo(-10, -44); ctx.lineTo(4, -44); ctx.lineTo(8, -22); ctx.stroke();
    // driver
    ctx.fillStyle = '#3e6fd8'; ctx.fillRect(-10, -36, 12, 14);
    ctx.fillStyle = '#ffd9b0'; ctx.beginPath(); ctx.arc(-4, -40, 8, 0, Math.PI * 2); ctx.fill();
    ctx.fillStyle = '#e8453c'; ctx.beginPath(); ctx.arc(-4, -42, 8, Math.PI, Math.PI * 2); ctx.fill();
    ctx.fillStyle = '#222'; ctx.fillRect(-1, -41, 3, 3);
    // headlight
    ctx.fillStyle = '#fff6b0'; ctx.fillRect(43, -13, 5, 5);
    ctx.restore();
    drawWheel(A); drawWheel(B);
  }

  function render() {
    drawBackground();
    drawTerrain();
    drawCar();
  }
```

- 最初に、タイヤからクルマの「上」向きに 12px の太い線を引きます。これがサスペンション（タイヤと車体をつなぐ棒）です
- `Math.atan2(c.dy, c.dx)` で、前向きのベクトルから **角度** を求めます
- `ctx.translate(mx, my); ctx.rotate(ang);` で、原点をクルマの中心に動かし、クルマの傾きぶん回します。ここから先は **x がクルマの前、y がクルマの下** という「クルマから見た座標」で描けるので、車体がどれだけ傾いても同じ数字で描けます
- 車体は `moveTo` / `lineTo` で角をなぞったオレンジの多角形。その上にロールバー（黒い枠）、運転手（青い服・顔・赤いヘルメット・目）、前のライトを描きます
- 最後に `ctx.restore()` で回転を戻してから、タイヤを上から描きます（タイヤが車体の手前に見えます）

> [!TIP]
> 車体の数字（`-44, -22` など）を書きかえると、クルマの形を自由に変えられます。運転手の頭の位置（`-4, -40` 付近）は、ステップ8の「頭をぶつけたら終わり」の判定と関係するので、大きく動かすときは判定の数字も合わせましょう。

## カメラをクルマに追いかけさせる

`loop()` の `if (A) { ... }` を次のように書きかえます。

```js:game.js
    if (A) {
      const c = carFrame();
      camX += (c.mx - camX) * 0.2;
      camY += (c.my - camY) * 0.08;
      render();
    }
```

カメラをクルマの位置に **いきなり合わせるのではなく**、差の 20%（縦は 8%）ずつ近づけます。こうすると、急な坂やジャンプでも画面がガクッと動かず、なめらかに追いかけます。縦を小さくしているのは、着地の小さなバウンドで画面が揺れないようにするためです。

> [!CHECK] 動作チェック
> - スタートを押すと、前が上がった姿勢のオレンジのクルマが空中から落ちてくる
> - 後ろのタイヤが先に着地し、そのあと前のタイヤが倒れこむように着地して、車体が水平になる
> - タイヤの間隔は落ちている間も変わらない（バラバラにならない）
> - クルマは画面の左寄りに映り、カメラが少し遅れてついてくる
