## このステップのゴール

ゲームらしい要素を入れます。走ると **燃料** が減り、ときどき置いてある **燃料タンク（F）** を拾うと満タンに戻ります。丘の上には **コイン** が並び、拾うとスコアが増えます。画面上の **距離・コイン・スコア・燃料メーター** も動くようにします。

## 要素と変数を追加する

`const msgEl = $('msg');` の行を、次の2行に書きかえます。

```js:game.js
  const scoreEl = $('score'), distEl = $('dist'), coinsEl = $('coins');
  const fuelFill = $('fuelfill'), msgEl = $('msg');
```

`let A, B, state = ...` の行を書きかえます。

```js:game.js
  let A, B, fuel, coins, maxX, items, nextFuel, nextCoin, state = 'title', camX = 0, camY = 0;
```

- `fuel` …… 燃料の残り。1 が満タン、0 が空っぽ
- `coins` …… 拾ったコインの枚数
- `maxX` …… これまでに進んだ **いちばん右** の位置。バックしても距離が減らないように、最大値を覚えておきます
- `items` …… コインと燃料タンクの配列。1つ1つは `{ type: 'coin' か 'fuel', x, y, got: 拾ったか }`
- `nextCoin` / `nextFuel` …… 次にコイン・燃料タンクを置く x 座標

## reset() とアイテムを置く spawnItems()

`reset()` を書きかえ、その下に `spawnItems()` を追加します。

```js:game.js
  function reset() {
    ph = [Math.random() * 6.28, Math.random() * 6.28, Math.random() * 6.28];
    A = wheel(START_X); B = wheel(START_X + L);
    fuel = 1; coins = 0; maxX = START_X; items = [];
    nextFuel = 1300; nextCoin = 600;
    camX = START_X; camY = ground(START_X);
    spawnItems();
    updateHud();
  }

  function spawnItems() {
    const limit = maxX + 1600;
    while (nextCoin < limit) {
      const n = 4 + Math.floor(Math.random() * 4);
      for (let i = 0; i < n; i++) {
        const x = nextCoin + i * 34;
        items.push({ type: 'coin', x, y: ground(x) - 34, got: false });
      }
      nextCoin += 450 + Math.random() * 500;
    }
    while (nextFuel < limit) {
      items.push({ type: 'fuel', x: nextFuel, y: ground(nextFuel) - 30, got: false });
      nextFuel += 1500 + Math.min(1500, nextFuel / 12) + Math.random() * 400;
    }
    items = items.filter((it) => it.x > maxX - 800 && !it.got);
  }
```

コースは無限に続くので、アイテムを最初に全部置くことはできません。そこで **クルマの少し先（`maxX + 1600` まで）だけ** 置いておき、進むたびに先へ先へと追加していきます。

- コインは 4〜7 枚を 34px おきに並べ、地面から 34px 上に浮かべます。次のコインの列は 450〜950px 先
- 燃料タンクは最初 1300px 先。間隔は `1500 + Math.min(1500, nextFuel / 12)` で、**遠くへ行くほど間隔が広がり**、だんだん厳しくなります
- 最後の `filter` で、**拾ったものと、ずっと後ろ（800px 以上）に置いてきたもの** を配列から消します。消さないと配列がどんどん大きくなって重くなります

`while (nextCoin < limit)` のように「足りない分だけ足す」書き方にしておくと、毎コマ呼んでも、置く必要があるときだけ追加されます。

## step() に燃料とアイテムの処理を足す

まず、`step()` の先頭の `const f = carFrame();` の下に1行足します。

```js:game.js
    const canGas = gas && fuel > 0;
```

そして `step()` の中の **`gas` を使っている2か所** を `canGas` に書きかえます。燃料が無いときはアクセルが効かなくなります（ブレーキとバックは使えます）。

```js:game.js
      if (canGas && vt < 11) { w.x += tx * 0.2; w.y += ty * 0.2; }
```

```js:game.js
    if (canGas) { B.x += f.nx * tilt; B.y += f.ny * tilt; A.x -= f.nx * tilt; A.y -= f.ny * tilt; }
```

次に、`step()` の最後（`// wheel spin` の行の下）に追加します。

```js:game.js

    // fuel
    fuel -= canGas ? 0.0011 : 0.00035;
    if (fuel < 0) fuel = 0;

    const c = carFrame();
    maxX = Math.max(maxX, c.mx);

    // pickups
    for (const it of items) {
      if (it.got) continue;
      const near = Math.hypot(it.x - c.mx, it.y - (c.my - 10)) < 40 ||
        Math.hypot(it.x - A.x, it.y - A.y) < 26 || Math.hypot(it.x - B.x, it.y - B.y) < 26;
      if (!near) continue;
      it.got = true;
      if (it.type === 'coin') { coins++; }
      else { fuel = 1; }
    }
    spawnItems();
```

- 燃料は **アクセルを踏んでいる間は多めに、踏んでいなくても少しずつ** 減ります。踏みっぱなしだと約15秒、何もしなくても約48秒で空になります
- アイテムを拾ったかどうかは、**距離で判定** します（円どうしの当たり判定）。`Math.hypot(dx, dy)` は2点間の距離です。車体の中心から 40px 以内か、どちらかのタイヤから 26px 以内なら「拾った」ことにします
- 拾ったら `got = true` にして、コインなら枚数を1増やし、燃料タンクなら満タンにします

## スコアと表示：score() と updateHud()

`step()` の下に追加します。

```js:game.js
  function score() { return Math.floor((maxX - START_X) / PX_PER_M) + coins * 10; }

  function updateHud() {
    const d = Math.max(0, Math.floor((maxX - START_X) / PX_PER_M));
    distEl.textContent = d;
    coinsEl.textContent = coins;
    scoreEl.textContent = score();
    fuelFill.style.width = (fuel * 100).toFixed(1) + '%';
    fuelFill.classList.toggle('low', fuel < 0.25);
  }
```

- 距離は「スタートから何px 進んだか ÷ 20」で m に直します
- スコア = 距離(m) + コイン × 10
- 燃料メーターは、中の緑のバーの **幅** を `fuel` に合わせて変えます。25% を切ったら `low` クラスで赤くします

`loop()` の中、`while (...) { step(); ... }` の行の **下** に `updateHud();` を足し、プレイ中は毎フレーム表示を更新します。

```js:game.js
    if (state === 'play') {
      acc += dt;
      while (acc >= 1 / 60 && state === 'play') { step(); acc -= 1 / 60; }
      updateHud();
    }
```

## アイテムを描く：drawItems()

`drawWheel()` の **上** に追加し、`render()` の `drawTerrain();` と `drawCar();` の間で呼びます。

```js:game.js
  function drawItems() {
    const t = performance.now() / 300;
    for (const it of items) {
      if (it.got) continue;
      const [x, y] = toScreen(it.x, it.y);
      if (x < -30 || x > W + 30) continue;
      if (it.type === 'coin') {
        const w = Math.abs(Math.cos(t + it.x * 0.01)) * 9 + 2;
        ctx.fillStyle = '#ffcf3f'; ctx.strokeStyle = '#d79a12'; ctx.lineWidth = 2;
        ctx.beginPath(); ctx.ellipse(x, y, w, 11, 0, 0, Math.PI * 2); ctx.fill(); ctx.stroke();
      } else {
        const by = y + Math.sin(t) * 3;
        ctx.fillStyle = '#e8453c'; ctx.strokeStyle = '#8f1f18'; ctx.lineWidth = 2;
        ctx.beginPath(); ctx.roundRect ? ctx.roundRect(x - 11, by - 14, 22, 28, 4) : ctx.rect(x - 11, by - 14, 22, 28);
        ctx.fill(); ctx.stroke();
        ctx.fillStyle = '#8f1f18'; ctx.fillRect(x + 3, by - 20, 7, 6);
        ctx.fillStyle = '#fff'; ctx.font = 'bold 13px system-ui, sans-serif'; ctx.textAlign = 'center';
        ctx.fillText('F', x, by + 5);
      }
    }
  }

  function render() {
    drawBackground();
    drawTerrain();
    drawItems();
    drawCar();
  }
```

- `performance.now()` はページを開いてからのミリ秒です。これを時計がわりにして、アイテムを動かします
- コインは楕円（`ctx.ellipse`）で描き、横幅を `Math.abs(Math.cos(...))` で太く細く変えて **くるくる回っている** ように見せます。`it.x * 0.01` を足して、1枚ずつ回るタイミングをずらしています
- 燃料タンクは赤い角丸の四角に「F」の文字。`Math.sin(t) * 3` で上下にふわふわ揺らします
- 画面の外（左右30px より外）にあるアイテムは描かずに飛ばして、むだな描画を減らします

> [!NOTE]
> `ctx.roundRect` は比較的新しい機能なので、古いブラウザでは使えないことがあります。`ctx.roundRect ? ... : ctx.rect(...)` と書いて、無いときはふつうの四角で代用しています。

> [!CHECK] 動作チェック
> - スタートすると、少し先にコインが並んでいるのが見える。通るとコインが消え、上のコイン数と SCORE が増える
> - 走ると「0 m」の数字が増え、SCORE は「距離 + コイン × 10」になる。バックしても距離は減らない
> - FUEL の緑のバーがだんだん短くなり、残り4分の1を切ると赤くなる
> - 赤い「F」のタンクを拾うと、燃料メーターが満タンに戻る
> - 燃料が空になるとアクセルが効かなくなる（このステップではまだゲームオーバーにはならない）
