## このステップのゴール

**音とエフェクト** で手ごたえを出します。走っている間は **エンジン音** が鳴り、速くなるほど・アクセルを踏むほど音が高くなります。コインを拾うと「チャリン」、燃料タンクで「ピロン」と鳴り、キラキラの粒が飛び散ります。燃料が少なくなったら画面に警告を点滅させます。

## 変数を追加する

`let gas = false, ...` の行を書きかえ、その下に `particles` を足します。

```js:game.js
  let gas = false, brake = false, groundedA = false, groundedB = false, flash = 0;
  let particles = [];
```

- `flash` …… 燃料タンクを拾ったときに画面を白く光らせる強さ（1 → 0 へ減っていく）
- `particles` …… 飛び散る粒の配列

`reset()` の `fuel = 1; ...` の行の最後に `particles = [];` を足します。

```js:game.js
    fuel = 1; coins = 0; maxX = START_X; items = []; particles = [];
```

## Web Audio API で音を作る

`spawnItems()` の下（`// ---------- physics ----------` の **上**）に、`// ---------- audio ----------` を追加します。

```js:game.js
  // ---------- audio ----------
  let ac = null, eng = null, engGain = null;
  function initAudio() {
    try {
      if (!ac) {
        ac = new (window.AudioContext || window.webkitAudioContext)();
        eng = ac.createOscillator(); eng.type = 'sawtooth';
        const f = ac.createBiquadFilter(); f.type = 'lowpass'; f.frequency.value = 500;
        engGain = ac.createGain(); engGain.gain.value = 0;
        eng.connect(f); f.connect(engGain); engGain.connect(ac.destination);
        eng.frequency.value = 50; eng.start();
      }
      if (ac.state === 'suspended') ac.resume();
    } catch (e) { ac = null; }
  }
  function beep(freq, dur, type, vol) {
    if (!ac) return;
    try {
      const o = ac.createOscillator(), g = ac.createGain();
      o.type = type || 'square'; o.frequency.value = freq;
      g.gain.setValueAtTime(vol || 0.08, ac.currentTime);
      g.gain.exponentialRampToValueAtTime(0.0001, ac.currentTime + dur);
      o.connect(g); g.connect(ac.destination); o.start(); o.stop(ac.currentTime + dur);
    } catch (e) { /* ignore */ }
  }
  function setEngine(on, speed) {
    if (!ac || !eng) return;
    const t = ac.currentTime;
    engGain.gain.setTargetAtTime(on ? 0.05 : 0.0, t, 0.08);
    eng.frequency.setTargetAtTime(45 + speed * 9 + (gas ? 25 : 0), t, 0.1);
  }
```

このゲームは音声ファイルを使わず、ブラウザの **Web Audio API** で音をその場で作ります。

- `AudioContext`（`ac`）が音の工場です。ここから部品を作り、`connect` でつないで、最後に `ac.destination`（スピーカー）へ流します
- `OscillatorNode`（オシレーター）は決まった高さ（周波数 Hz）の音を出し続ける部品です。`type` で `'square'`（ピコピコ）・`'triangle'`（やわらかい）・`'sawtooth'`（ジージー）などの音色を選べます
- `GainNode` は音量つまみです

### エンジン音

`initAudio()` で、**ずっと鳴りっぱなしのオシレーター** `eng` を1つ作ります。ノコギリ波（`sawtooth`）を `BiquadFilter`（`lowpass` ＝ 高い音をカットするフィルター）に通すと、「ブーン」というこもったエンジンらしい音になります。音量 `engGain` は最初 0 にしておき、`setEngine()` で上げ下げします。

`setEngine(on, speed)` は、エンジン音の **音量と高さ** を変えます。`setTargetAtTime(目標, 時刻, 時定数)` は「いきなりではなく、なめらかに目標へ近づける」指定なので、急に音が変わってもプツッというノイズが出ません。速さ `speed` が大きいほど、アクセルを踏んでいるほど高い音になります。

### 効果音

`beep(freq, dur, type, vol)` は短い効果音を1回鳴らします。鳴らすたびにオシレーターを作り、`exponentialRampToValueAtTime` で音量を `dur` 秒かけて 0 近くまで下げて「ポン」と消し、`o.stop()` で止めます。

> [!WARNING]
> ブラウザは、ユーザーが画面をさわる前に音を出すことを禁止しています。なので `AudioContext` は **スタートボタンや画面を押したとき** に作ります。`ac.state === 'suspended'`（一時停止中）なら `resume()` で再開します。古い Safari 用に `webkitAudioContext` も試し、どちらも無い環境では `try...catch` で `ac = null` にして、音なしで遊べるようにしています。

`start()` の先頭と、Canvas の `pointerdown` の `e.preventDefault();` の下に `initAudio();` を足します。

```js:game.js
  function start() {
    initAudio();
    reset();
```

```js:game.js
  cv.addEventListener('pointerdown', (e) => {
    e.preventDefault();
    initAudio();
```

## step() で音を鳴らす

`step()` の先頭、`const f = carFrame();` の下に、クルマの横方向の速さを求める行を足します（2つのタイヤの速さの平均です）。

```js:game.js
    const speed = ((A.x - A.px) + (B.x - B.px)) / 2;
```

アイテムを拾ったところ（`// pickups` の `for` の中）の2行を書きかえます。

```js:game.js
      if (it.type === 'coin') { coins++; beep(1320, 0.12, 'square', 0.05); burst(it.x, it.y, '#ffcf3f', 6); }
      else { fuel = 1; beep(520, 0.1, 'triangle', 0.1); setTimeout(() => beep(780, 0.15, 'triangle', 0.1), 90); burst(it.x, it.y, '#ff6b5b', 10); flash = 1; }
```

燃料タンクは `setTimeout` で 0.09 秒ずらしてもう1音鳴らし、「ピ・ロン」と上がる2音にしています。

`step()` の最後、`spawnItems();` の下にエンジン音の更新を足します。

```js:game.js

    setEngine(true, Math.abs(speed));
```

## 飛び散る粒：burst() と drawParticles()

`step()` の **下** に `burst()` を追加します。

```js:game.js
  function burst(x, y, color, n) {
    for (let i = 0; i < n; i++) {
      const a = Math.random() * Math.PI * 2, s = 1 + Math.random() * 3;
      particles.push({ x, y, vx: Math.cos(a) * s, vy: Math.sin(a) * s - 1, life: 30, color });
    }
  }
```

ランダムな向き `a` と速さ `s` で、`n` 個の粒を作ります。`Math.cos(a)`・`Math.sin(a)` で「向き a の長さ1の矢印」が作れるので、それに速さをかけて速度にします。`- 1` で少し上向きに飛ばし、`life: 30` は 30 フレーム（約0.5秒）で消えるという寿命です。

`drawCar()` の下に `drawParticles()` を追加し、`render()` を書きかえます。

```js:game.js
  function drawParticles() {
    for (const p of particles) {
      const [x, y] = toScreen(p.x, p.y);
      ctx.globalAlpha = Math.max(0, p.life / 30);
      ctx.fillStyle = p.color; ctx.fillRect(x - 3, y - 3, 6, 6);
    }
    ctx.globalAlpha = 1;
  }

  function render() {
    drawBackground();
    drawTerrain();
    drawItems();
    drawCar();
    drawParticles();
    if (flash > 0) { ctx.fillStyle = `rgba(255,255,255,${flash * 0.35})`; ctx.fillRect(0, 0, W, H); }
    if (state === 'play' && fuel < 0.2 && Math.floor(performance.now() / 300) % 2 === 0) {
      ctx.fillStyle = '#e8453c'; ctx.font = 'bold 18px system-ui, sans-serif'; ctx.textAlign = 'center';
      ctx.fillText('燃料が少ない！', W / 2, 30);
    }
  }
```

- 粒は `globalAlpha`（全体の不透明度）を寿命に合わせて下げ、だんだん透明にします。描き終わったら必ず `1` に戻します
- `flash` が残っている間は、画面全体に白い半透明の四角を重ねて「パッ」と光らせます
- 燃料が 20% を切ったら、画面の上に「燃料が少ない！」を表示します。`Math.floor(performance.now() / 300) % 2 === 0` は「0.3 秒ごとに 0 と 1 が入れかわる」ので、表示・非表示をくり返して **点滅** します

最後に、`loop()` の `if (state === 'play') { ... }` の **下** に、粒を動かす処理と `flash` を弱める処理を足します。

```js:game.js
    for (const p of particles) { p.x += p.vx; p.y += p.vy; p.vy += 0.15; p.life--; }
    particles = particles.filter((p) => p.life > 0);
    if (flash > 0) flash = Math.max(0, flash - 0.05);
```

粒には重力 `0.15` をかけて放物線を描かせ、寿命が尽きたものを `filter` で取り除きます。

> [!CHECK] 動作チェック
> - スタートすると「ブーン」とエンジン音が鳴り、アクセルを踏むと音が高くなる（スマホはマナーモードを解除）
> - コインを拾うと「チャリン」と鳴り、黄色い粒が飛び散る
> - 燃料タンクを拾うと「ピ・ロン」と2音鳴り、赤い粒が散って画面が一瞬白く光る
> - 燃料が残り少なくなると、画面上に赤い「燃料が少ない！」が点滅する
