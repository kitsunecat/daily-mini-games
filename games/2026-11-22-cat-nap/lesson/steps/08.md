## このステップのゴール

最後の仕上げです。これで完成品と同じゲームになります。

- **ハイスコア** をブラウザに保存し、次に開いたときも残るようにする
- ねこを置くと **ぽよん** と弾み、寝ているねこがゆっくり **上下にゆれて**、ときどき「z」が出る
- クリアすると盤面が白く光って「**おやすみ〜**」の文字が出る
- **効果音** … ねこを置いた音・× の音・クリアのファンファーレ・タイムアップの音

### localStorage … ブラウザに小さなデータを保存する

`localStorage` は、ページを閉じても消えない、ブラウザの小さな保存場所です。`localStorage.setItem(キー, 文字列)` で保存し、`localStorage.getItem(キー)` で取り出します。

- 保存できるのは **文字列だけ** なので、取り出したら `parseInt(..., 10)` で数（10進数）に直します
- まだ一度も保存していなければ `getItem` は `null` を返し、`parseInt` は `NaN`（数ではない）になります。`|| 0` をつけておくと、そのときは 0 になります
- キーの名前は、同じサイトのほかのゲームとぶつからないよう、ゲームごとにちがう名前にします
- プライベートブラウズなどで localStorage が使えないとエラーになることがあるので、`try { ... } catch` で囲んでおきます

## 効果音

`window.addEventListener('resize', resize);` の **下**（`resize();` の上）に追加します。

```js:game.js

  // ---------- sound ----------
  let ac = null;
  function initAudio() {
    if (ac) return;
    try { ac = new (window.AudioContext || window.webkitAudioContext)(); } catch (e) { ac = null; }
  }
  function beep(freqs, len) {
    if (!ac) return;
    try {
      const now = ac.currentTime;
      freqs.forEach((f, k) => {
        const o = ac.createOscillator(), g = ac.createGain();
        o.type = 'triangle'; o.frequency.value = f;
        const s = now + k * len;
        g.gain.setValueAtTime(0.0001, s);
        g.gain.exponentialRampToValueAtTime(0.12, s + 0.01);
        g.gain.exponentialRampToValueAtTime(0.0001, s + len * 1.6);
        o.connect(g); g.connect(ac.destination);
        o.start(s); o.stop(s + len * 1.8);
      });
    } catch (e) { /* ignore */ }
  }
```

### Web Audio API … 音をプログラムで作る

音のファイルを用意しなくても、ブラウザの **Web Audio API** で「ピッ」という音を作れます。

- `AudioContext` は音を作る作業場です。スマホのブラウザは「ユーザーが画面を触ったあと」でないと音を出させてくれないので、スタートボタンを押したときに `initAudio()` で作ります
- `createOscillator()` は一定の高さの音を出し続ける **発振器** です。`type = 'triangle'`（三角波）はやわらかい音、`frequency` は音の高さ（Hz）です
- `createGain()` は **音量のつまみ** です。`exponentialRampToValueAtTime` で、ほぼ 0 → 0.12 に一瞬で上げて、すぐにまた小さくしています。いきなり鳴らしていきなり止めると「プツッ」と雑音が出るので、こうしてふわっと鳴らします
- `beep([660, 880, 1100], 0.09)` のように高さを配列で渡すと、`k * len` ずつ時間をずらして順に鳴らすので、短いメロディになります
- 音が出せない環境でもゲームが止まらないよう、`ac` が無いときは何もせず、エラーも `try` で無視します

## 置いたときの音と弾み

`setCell()` を **書きかえます**。

```js:game.js
  function setCell(i, v) {
    if (cells[i] === v) return;
    cells[i] = v;
    if (v === 2) { pops.push({ i, t: 0 }); beep([520 + (i % N) * 30], 0.05); }
    else if (v === 1) beep([300], 0.025);
    check();
  }
```

ねこを置いたら `pops` に記録して、短い音を鳴らします。列（`i % N`）が右にいくほど音が少し高くなるので、置く場所で音がちがって楽しくなります。× のときは低くて短い音です。

ステップ3で「状態を変える場所を `setCell()` にまとめた」おかげで、タップ・なぞる・キーボード・ヒントのどれで置いても、ここに書くだけで全部に音がつきます。

## クリアとゲームオーバーの仕上げ

`win()` の中の `timeLeft = Math.min(...);` の行の **下** に `clearAnim = 0.0001;` を、`msgEl.textContent = 'クリア！ +' + gain;` の行の **下** に `beep(...)` を追加します。`win()` 全体はこうなります。

```js:game.js
  function win() {
    state = 'clear';
    const secs = (performance.now() - levelStart) / 1000;
    const gain = N * 100 + Math.max(0, Math.round((N * 12 - secs) * 10));
    score += gain;
    scoreEl.textContent = score;
    timeLeft = Math.min(MAX_TIME, timeLeft + 15 + N * 2);
    clearAnim = 0.0001;
    msgEl.textContent = 'クリア！ +' + gain;
    beep([660, 880, 1100], 0.09);
    setTimeout(() => { if (state === 'clear') { level++; newLevel(); state = 'play'; } }, 1300);
  }
```

`clearAnim` に 0 より少しだけ大きい数を入れると、「演出中」の合図になります。


## ねこを弾ませる・ゆらす・z を出す

`draw()` の `// marks & cats` のループの中、`drawCat(cx, cy, cs * 0.9, catColor[i], conflicts.has(i), 1);` の1行を、次のように **書きかえます**。

```js:game.js
        const p = pops.find((q) => q.i === i);
        let sc = 1;
        if (p) sc = 1 + Math.sin(Math.min(1, p.t / 0.25) * Math.PI) * 0.25;
        if (clearAnim > 0) sc *= 1 + Math.sin(clearAnim * 10 + c) * 0.08;
        const bob = Math.sin(t / 600 + i) * cs * 0.015;
        drawCat(cx, cy + bob, cs * 0.9, catColor[i], conflicts.has(i), sc);
        if (clearAnim > 0 || (state === 'play' && !conflicts.has(i) && Math.sin(t / 900 + i * 1.7) > 0.96)) {
          ctx.fillStyle = 'rgba(70,55,95,.7)'; ctx.font = 'bold ' + Math.round(cs * 0.22) + 'px sans-serif';
          ctx.fillText('z', cx + cs * 0.22, cy - cs * 0.25 - (clearAnim * 20) % (cs * 0.2));
        }
```

### Math.sin で「ゆれ」を作る

`Math.sin` は、入れる数が増えていくと **-1 と 1 のあいだを行ったり来たり** する値を返します。アニメーションでとても便利です。

- **弾み**: `p.t / 0.25` は 0.25 秒で 0 → 1 になります。それに `Math.PI` をかけた `sin` は 0 → 1 → 0 と山の形に変わるので、大きさが 1 → 1.25 → 1 と、ぽよんと一度だけ弾みます
- **寝息のゆれ**: `t / 600` は時間とともにゆっくり増えるので、ねこが上下にふわふわゆれます。`+ i` でマスごとにタイミングをずらすと、全員がそろって動かず自然に見えます
- **クリア**: 演出中は全員の大きさを小きざみにゆらします。`+ c` で列ごとにずらすと、波のように見えます
- **z**: `sin(...)` が 0.96 をこえるのは、山のてっぺん付近のほんの少しの時間だけです。だから「z」はときどき、ねこごとにばらばらのタイミングで出ます。クリア演出中は全員に出して、上へ流れるように動かします

## 「おやすみ〜」の文字

`draw()` の最後（`// cursor (keyboard)` のブロックの **下**、`draw()` の閉じかっこ `}` の上）に追加します。

```js:game.js
    if (clearAnim > 0) {
      ctx.fillStyle = 'rgba(255,255,255,' + Math.max(0, 0.5 - clearAnim) + ')';
      ctx.fillRect(ox, oy, cs * N, cs * N);
      ctx.fillStyle = '#ffd36b'; ctx.strokeStyle = '#5b2f6b'; ctx.lineWidth = 6;
      ctx.font = 'bold ' + Math.round(cs * N * 0.13) + 'px sans-serif';
      ctx.textAlign = 'center'; ctx.textBaseline = 'middle';
      ctx.strokeText('おやすみ〜', W / 2, H / 2); ctx.fillText('おやすみ〜', W / 2, H / 2);
      ctx.textAlign = 'start'; ctx.textBaseline = 'alphabetic';
    }
```

- 盤面に白い半とうめいの四角を重ねます。とうめい度が `0.5 - clearAnim` なので、0.5 秒かけてすうっと消えていきます。これで「パッと光る」感じになります
- 文字は `strokeText`（ふち）を先に、`fillText`（中身）をあとに描くと、ふちどりのある読みやすい文字になります
- `textAlign` と `textBaseline` を `'center'`・`'middle'` にすると、指定した点が文字のまん中になります。描き終わったら元の設定にもどしておきます（「z」の位置がずれないように）

## 改造アイデア

> [!TIP] ねこを2匹ずつ寝かせる
> 「どの行・列・エリアにもねこは2匹」にすると、ぐっと難しいパズルになります。`placeCats()` と `solve()` を「1行に2匹」に変え、`check()` の判定を「同じ行・列・エリアに3匹以上でぶつかり」に変えてみましょう。盤面は 8 × 8 以上がおすすめです。

> [!TIP] 自動 × ボタン
> ねこを置いたとき、同じ行・列・エリアと、まわり8マスに自動で × をつける機能を作ってみましょう。`check()` の中の判定と同じ条件を使えば書けます。初心者向けのモードとして、ボタンで ON / OFF できるようにすると便利です。

> [!TIP] 1回もどす（アンドゥ）
> `setCell()` が呼ばれるたびに「どのマスが何から何に変わったか」を配列にためておき、もどすボタンで最後の1つを元にもどします。状態の変更を `setCell()` 1か所にまとめてあるので、記録する場所も1か所で済みます。

> [!TIP] 今日の問題
> `Math.random()` の代わりに「日付から決まる乱数」を使うと、その日はだれが遊んでも同じ問題になります。友だちとタイムを比べられるようになります。
