## このステップのゴール

マス目を、色ちがいの **ざぶとん（エリア）** に分けて描きます。エリアの境目には太い線を引いて、どこからどこまでが同じエリアか一目で分かるようにします。

問題を自動で作るのはステップ5です。それまでは、手で書いた **お手本の問題** を1つ使います。

## 問題を「数の配列」で表す

`const overlay = ...` の行の **下** に追加します。

```js:game.js
  const COLORS = ['#ffb3ba', '#ffdfa3', '#fff3a8', '#b9f0c2', '#a8e4f0', '#b8c4ff', '#dcb8ff', '#ffc4e8'];

  // sample puzzle (step 5 で自動生成に置きかえる)
  const SAMPLE = {
    sol: [0, 3, 1, 4, 2],
    reg: [
      0, 0, 0, 0, 0,
      0, 1, 1, 1, 2,
      0, 2, 2, 2, 2,
      4, 4, 2, 3, 3,
      4, 4, 4, 4, 3,
    ],
  };
```

### reg … どのマスがどのエリアか

`reg`（region＝エリア）は、ステップ1で出てきた「1本の番号」で並べた25個の数です。見やすいように5個ずつ改行していますが、ただの1本の配列です。

- 同じ数のマスが同じエリアです。たとえば `1` のマスは2行目のまん中の3マスで、1つのエリアになっています
- エリアの数はマス目の1辺と同じ **N 個**（ここでは 0〜4 の5つ）です。ねこはエリアごとに1匹なので、全部で N 匹寝かせることになります
- 色は `COLORS[エリアの番号]` で決めます。ステージが進むと最大 8 × 8（8エリア）になるので、8色用意しておきます

### sol … 答え

`sol`（solution＝答え）は「**r 行目のねこは何列目にいるか**」を並べたものです。`[0, 3, 1, 4, 2]` は、1行目は0列目、2行目は3列目、3行目は1列目…という意味です。

- 1行に1つずつ数が入るので、「どの行にもねこは1匹」が自動的に守られます
- 数がすべてちがうので、「どの列にもねこは1匹」も守られます
- このあと判定やヒントで使います。今は描くときには使いません

## 状態に puzzle と level を足す

`// ---------- state ----------` の下の変数と `startGame()` を、次のように **書きかえます**。`newLevel()` が新しく増えます。

```js:game.js
  let N = 5, puzzle = null;
  let state = 'title', level = 1;

  function newLevel() {
    N = 5;
    puzzle = SAMPLE;
    levelEl.textContent = 'ステージ ' + level;
  }

  function startGame() {
    level = 1;
    newLevel();
    state = 'play';
    overlay.classList.add('hidden');
  }
```

`newLevel()` は「新しいステージを用意する」関数です。今はお手本の問題を `puzzle` に入れるだけですが、このあとのステップで、盤面のリセットや問題の自動生成をここに足していきます。

## エリアの色と太い境目を描く

`draw()` の中を書きかえます。まず、最初の `if (state === 'title') return;` から `ctx.fillRect(x, y, cs, cs);` までを、次のように **書きかえます**。

```js:game.js
    if (!puzzle) {
      // title backdrop: a sleeping cat pattern
      return;
    }
    layout();
    const reg = puzzle.reg;
    // board shadow
    ctx.fillStyle = 'rgba(0,0,0,.25)';
    roundRect(ox - 6, oy - 2, cs * N + 12, cs * N + 12, 14); ctx.fill();
    ctx.fillStyle = '#3a3154';
    roundRect(ox - 6, oy - 6, cs * N + 12, cs * N + 12, 14); ctx.fill();
    for (let i = 0; i < N * N; i++) {
      const r = i / N | 0, c = i % N, x = ox + c * cs, y = oy + r * cs;
      ctx.fillStyle = COLORS[reg[i]];
      ctx.fillRect(x, y, cs, cs);
    }
```

- 問題（`puzzle`）がまだ無いタイトル画面では何も描きません
- マスの色を `COLORS[reg[i]]` にしました。i 番目のマスのエリア番号を見て、その色でぬります

続いて、`draw()` の最後（細い線の `ctx.stroke();` の **下**、`draw()` の閉じかっこ `}` の上）に追加します。

```js:game.js
    // thick region borders
    ctx.strokeStyle = '#3a3154'; ctx.lineWidth = Math.max(2.5, cs * 0.06); ctx.lineCap = 'round';
    ctx.beginPath();
    for (let r = 0; r < N; r++) for (let c = 0; c < N; c++) {
      const i = r * N + c, x = ox + c * cs, y = oy + r * cs;
      if (c < N - 1 && reg[i] !== reg[i + 1]) { ctx.moveTo(x + cs, y); ctx.lineTo(x + cs, y + cs); }
      if (r < N - 1 && reg[i] !== reg[i + N]) { ctx.moveTo(x, y + cs); ctx.lineTo(x + cs, y + cs); }
    }
    ctx.stroke();
    ctx.strokeRect(ox, oy, cs * N, cs * N);
```

### 境目は「となりとエリアがちがうか」で決める

エリアの形を覚えておく必要はありません。マスごとに **右どなり** と **下どなり** だけを見ます。

- 右どなりは番号が `i + 1`、下どなりは `i + N` です（1行は N マスなので、N 個先が1つ下）
- エリアの番号がちがえば、そのあいだに太い線を引きます。右どなりとの境目は **マスの右の辺**（縦線）、下どなりとの境目は **マスの下の辺**（横線）です
- いちばん右の列（`c === N - 1`）には右どなりがないので、`c < N - 1` で調べないようにします。下も同じです
- 最後に `strokeRect` で盤面の外わくを太線で囲みます

左どなりや上どなりを見ないのは、それらは「となりのマスの右・下」としてすでに調べているからです。

`ctx.lineCap = 'round'` は線の端を丸くする設定です。縦線と横線がつながる角が、すき間なくきれいにつながります。

> [!CHECK] 動作チェック

> - 同じ色のエリアのまわりだけに太い線が引かれ、同じエリアの中は細い線だけになっている
> - 2行目のまん中3マスがオレンジのエリア、右下が緑の L 字のエリアになっている
> - 左上の「ステージ 1」が表示されている
