## このステップのゴール

操作を快適にします。

- **なぞって × をまとめてつける** … 空きマスから押したまま指をすべらせると、通ったマスに次々と × がつく。× のマスからなぞると、通ったマスの × を消す
- **キーボード操作** … 矢印キーで白いカーソルを動かし、Space / Enter で切りかえ、X キーで × だけをつけ外し
- タイトル画面やゲームオーバー画面で Enter / Space を押すとスタート

このパズルは「ここには絶対ねこがいない」というマスに × をつけて、候補をしぼっていくのが解き方のコツです。× をつける操作が楽になると、ぐっと遊びやすくなります。

## カーソルの変数

`let conflicts = new Set();` の行を **書きかえます**。

```js:game.js
  let cursor = -1, conflicts = new Set();
```

`cursor` はキーボードで選んでいるマスの番号です。`-1` は「カーソルを出していない」という意味です。

`newLevel()` の `conflicts = new Set();` の行を **書きかえます**。

```js:game.js
    conflicts = new Set(); cursor = -1;
```

## なぞる操作とキーボード

`// ---------- input ----------` の中の、`cv.addEventListener('pointerdown', ...)` から `cv.addEventListener('pointercancel', ...);` までを、次のように **書きかえます**（`window.addEventListener('keydown', ...)` が新しく増えます）。`let drag = null;` と `cellAt()` はそのままです。

```js:game.js
  cv.addEventListener('pointerdown', (e) => {
    if (state !== 'play') return;
    const i = cellAt(e);
    if (i < 0) return;
    e.preventDefault();
    try { cv.setPointerCapture(e.pointerId); } catch (err) { /* ignore */ }
    cursor = -1;
    drag = { start: i, moved: false, mode: cells[i] === 0 ? 1 : cells[i] === 1 ? 0 : -1 };
  });
  cv.addEventListener('pointermove', (e) => {
    if (!drag || state !== 'play') return;
    const i = cellAt(e);
    if (i < 0 || (i === drag.start && !drag.moved)) return;
    if (drag.mode < 0) return; // started on a cat: no painting
    if (!drag.moved) { drag.moved = true; if (cells[drag.start] !== 2) setCell(drag.start, drag.mode); }
    if (cells[i] !== 2) setCell(i, drag.mode);
  });
  const endDrag = () => {
    if (drag && !drag.moved && state === 'play') cycle(drag.start);
    drag = null;
  };
  cv.addEventListener('pointerup', endDrag);
  cv.addEventListener('pointercancel', () => { drag = null; });

  window.addEventListener('keydown', (e) => {
    if (state === 'title' || state === 'over') {
      if (e.key === 'Enter' || e.key === ' ') { e.preventDefault(); startGame(); }
      return;
    }
    if (state !== 'play') return;
    const mv = { ArrowUp: [-1, 0], ArrowDown: [1, 0], ArrowLeft: [0, -1], ArrowRight: [0, 1] }[e.key];
    if (mv) {
      e.preventDefault();
      if (cursor < 0) cursor = 0;
      else {
        const r = Math.min(N - 1, Math.max(0, (cursor / N | 0) + mv[0]));
        const c = Math.min(N - 1, Math.max(0, cursor % N + mv[1]));
        cursor = r * N + c;
      }
    } else if (e.key === ' ' || e.key === 'Enter') {
      e.preventDefault(); if (cursor < 0) cursor = 0; else cycle(cursor);
    } else if (e.key === 'x' || e.key === 'X') {
      if (cursor >= 0) setCell(cursor, cells[cursor] === 1 ? 0 : 1);
    }
  });
```

### drag.mode … なぞったマスを何にするか

押したマスの状態で、なぞったときに何をつけるかを決めます。

- 空き（0）から始めたら `mode = 1` … 通ったマスを × にする
- ×（1）から始めたら `mode = 0` … 通ったマスを空きにもどす（× を消す）
- ねこ（2）から始めたら `mode = -1` … なぞっても何もしない

ねこのマス（`cells[i] === 2`）は、なぞってもそのまま残します。せっかく置いたねこを、うっかり消さないためです。

### pointermove … 押したまま動いたとき

1. 押していないとき（`drag` が `null`）は何もしません
2. まだ最初のマスの中にいるあいだ（`i === drag.start && !drag.moved`）も何もしません。少し指がぶれただけで「なぞった」扱いにならないようにです
3. 初めて別のマスに入ったら `moved = true` にして、**最初のマスにも** mode をつけます。そうしないと、なぞり始めのマスだけ × がつかなくなります
4. あとは通ったマスに `setCell(i, drag.mode)` するだけです。`setCell()` は同じ値なら何もしないので、同じマスを何度通っても大丈夫です

`moved` が `true` になっていれば、指を離したとき（`endDrag`）に `cycle()` は呼ばれません。これで「タップ」と「なぞる」を区別できます。

### setPointerCapture … 指が Canvas の外に出ても追いかける

`cv.setPointerCapture(e.pointerId)` を呼ぶと、そのあとの `pointermove`・`pointerup` は、指が Canvas の外に出ても Canvas に届きます。盤面のはしまでなぞって外で離したときに、`drag` が残ったままになるのを防ぎます。古いブラウザでエラーになっても困らないよう `try { ... } catch` で囲んでいます。

タップしたときに `cursor = -1` にして、キーボードのカーソルを消しているのもポイントです。

### keydown … キーボード

- タイトル画面・ゲームオーバー画面（`'title'`・`'over'`）では、Enter か Space でスタートします
- 矢印キーは `{ ArrowUp: [-1, 0], ... }[e.key]` で、押されたキーに合う `[行の変化, 列の変化]` を取り出しています。キーの名前をそのまま「辞書」のキーに使うと、`if` を4つ並べずに書けます。矢印キー以外なら `undefined` になります
- カーソルがまだ無ければ左上（0番）に出し、あれば動かします。`Math.min(N - 1, Math.max(0, ...))` は、値を 0〜N-1 のあいだに **おさえる** 定番の書き方で、盤面の外にはみ出しません
- Space / Enter で `cycle()`、X キーで × だけをつけ外しします
- `e.preventDefault()` は、矢印キーや Space でページがスクロールするのを止めます

## カーソルを描く

`draw()` の最後（`// marks & cats` のループの **下**、`draw()` の閉じかっこ `}` の上）に追加します。

```js:game.js
    // cursor (keyboard)
    if (cursor >= 0 && state === 'play') {
      const r = cursor / N | 0, c = cursor % N;
      ctx.strokeStyle = '#ffffff'; ctx.lineWidth = 3;
      ctx.strokeRect(ox + c * cs + 3, oy + r * cs + 3, cs - 6, cs - 6);
    }
```

マスより少し内側（3px ずつ小さく）に白い四角を描きます。

> [!CHECK] 動作チェック
> - 空きマスから押したまま横になぞると、通ったマスに × がつく。× のマスからなぞると × が消える
> - ねこのマスはなぞっても消えない
> - タップ1回は、これまでどおり「空き → × → ねこ」と切りかわる
> - PC で矢印キーを押すと白いカーソルが出て動き、Space でそのマスが切りかわる。X キーで × だけをつけ外しできる
> - タイトル画面で Enter を押してもスタートできる
