## このステップのゴール

お手本の問題をやめて、**問題をプログラムで自動生成** します。クリアしたら少し待って次のステージへ進み、ステージが進むとマス目が 6 × 6、7 × 7、8 × 8 と大きくなります。クリアするとスコアも入ります。

パズルの自動生成は、このゲームでいちばん頭を使うところです。次の4段階で作ります。

1. **答えを先に決める** … ルールを満たすねこの置き方をランダムに1つ作る
2. **エリアを育てる** … 各ねこのマスを「種」にして、エリアをまわりへ広げていく
3. **答えが1つだけか調べる** … 別の答えがあったら、エリアの形を少し変える
4. これを、答えが1つだけになるまでくり返す

「先に答えを作ってから問題を作る」と、**必ず解ける問題** になります。

## 準備: SAMPLE を消して、道具を2つ用意する

ステップ2で追加した `// sample puzzle` から `};` まで（`const SAMPLE = ...` 全体）を **消して**、同じ場所に次を追加します。

```js:game.js
  // ---------- puzzle generation ----------
  const shuffle = (a) => { for (let i = a.length - 1; i > 0; i--) { const j = Math.random() * (i + 1) | 0; [a[i], a[j]] = [a[j], a[i]]; } return a; };
  const DIRS = [[1, 0], [-1, 0], [0, 1], [0, -1]];
```

- `shuffle(a)` は配列の中身をランダムに並べかえる関数です（**フィッシャー–イェーツのシャッフル** という定番のやり方）。後ろから順に、「自分より前のどれか」と入れかえていきます。`[a[i], a[j]] = [a[j], a[i]]` は2つの値を入れかえる書き方です
- `DIRS` は上下左右の4方向です。`[行の変化, 列の変化]` の組で、となりのマスを順に調べるときに使います

以下の関数は、すべてこの2つの **下** に順に追加していきます。

## 1. placeCats() … 答えを先に決める

```js:game.js
  function placeCats(N) {
    const cols = [], used = new Array(N).fill(false);
    (function rec(r) {
      if (r === N) return true;
      for (const c of shuffle([...Array(N).keys()])) {
        if (used[c] || (r > 0 && Math.abs(cols[r - 1] - c) <= 1)) continue;
        used[c] = true; cols[r] = c;
        if (rec(r + 1)) return true;
        used[c] = false;
      }
      return false;
    })(0);
    return cols;
  }
```

上の行から1匹ずつ、置ける列をさがしていきます。`cols[r]` が「r 行目のねこの列」で、ステップ2の `sol` と同じ形です。

- `used[c]` … その列にもうねこがいるか。いれば置けません（同じ列に2匹はダメ）
- `Math.abs(cols[r - 1] - c) <= 1` … 1つ上の行のねこと、列が1以内しかはなれていなければ、となり（ななめ）になるので置けません
- 各行に1匹ずつ置いていくので、「同じ行に2匹」は最初から起きません

### 再帰とバックトラック

`rec(r)` は「r 行目に置いて、残りの行もうまく置けたら `true`」を返す関数で、中で自分自身 `rec(r + 1)` を呼んでいます。これを **再帰** といいます。

ある行でどの列にも置けなくなったら `false` を返し、1つ前の行にもどって `used[c] = false` で置いたのを取り消し、別の列をためします。この「行きづまったらもどってやりなおす」探し方を **バックトラック** といいます。列の順番を `shuffle` しておくので、毎回ちがう答えになります。

`[...Array(N).keys()]` は `[0, 1, 2, …, N-1]` を作る書き方です。`(function rec(r) { ... })(0);` は、名前つきの関数を作ってすぐ `0` 行目から呼んでいます。

## 2. growRegions() … エリアを育てる

```js:game.js
  function growRegions(N, cols) {
    const reg = new Array(N * N).fill(-1);
    cols.forEach((c, r) => { reg[r * N + c] = r; });
    let left = N * N - N;
    while (left > 0) {
      const k = Math.random() * N | 0, cand = [];
      for (let i = 0; i < N * N; i++) {
        if (reg[i] !== k) continue;
        const r = i / N | 0, c = i % N;
        for (const [dr, dc] of DIRS) {
          const rr = r + dr, cc = c + dc;
          if (rr >= 0 && cc >= 0 && rr < N && cc < N && reg[rr * N + cc] === -1) cand.push(rr * N + cc);
        }
      }
      if (!cand.length) continue;
      reg[cand[Math.random() * cand.length | 0]] = k; left--;
    }
    return reg;
  }
```

1. まず全部のマスを `-1`（まだどのエリアでもない）にして、答えのねこのマスにだけ、エリア番号として **行の番号 r** を入れます。r 行目のねこが、エリア r の種になります
2. ランダムにエリア `k` を1つ選び、そのエリアのマスの上下左右で、まだ空いているマスを `cand`（候補）に集めます
3. 候補の中からランダムに1マス選んでエリア `k` にします。これを、空いているマスがなくなる（`left` が 0 になる）までくり返します

エリアは必ず「となりのマス」に広がるので、どのエリアも **ひと続き** になります。そして各エリアには種のねこがちょうど1匹ずついるので、最初に決めた答えはこの問題の正解になっています。

> [!NOTE]
> 候補が無いエリア（まわりがほかのエリアに囲まれてしまった）を選んだときは `continue` で選びなおします。ほかのエリアが空きマスを持っているかぎり、いつかは進むので止まることはありません。

## 3. solve() … 答えをさがす

```js:game.js
  function solve(N, reg, limit) {
    const sols = [], uc = new Array(N).fill(false), ur = new Array(N).fill(false), cols = [];
    (function rec(r) {
      if (sols.length >= limit) return;
      if (r === N) { sols.push(cols.slice()); return; }
      for (let c = 0; c < N; c++) {
        if (uc[c] || (r > 0 && Math.abs(cols[r - 1] - c) <= 1)) continue;
        const g = reg[r * N + c];
        if (ur[g]) continue;
        uc[c] = ur[g] = true; cols[r] = c;
        rec(r + 1);
        uc[c] = ur[g] = false;
      }
    })(0);
    return sols;
  }
```

`placeCats()` とほとんど同じバックトラックですが、こちらは「**この問題（`reg`）の答え** をさがす」関数です。

- `uc[c]` は列が使用ずみか、`ur[g]` は **エリア** g が使用ずみかです。同じエリアにはもう置けません
- 見つけた答えは `sols` にためていき、`limit` 個見つかったらすぐやめます

生成では `solve(N, reg, 2)` と、**最大2個** だけさがします。答えが「1つだけ」かどうか知りたいだけなので、2個目が見つかった時点で「1つだけではない」と分かるからです。全部数えるより、ずっと速く終わります。

## 4. connected() … エリアがひと続きか調べる

```js:game.js
  function connected(N, reg, k) {
    let start = -1, tot = 0;
    for (let i = 0; i < N * N; i++) if (reg[i] === k) { tot++; if (start < 0) start = i; }
    if (!tot) return false;
    const seen = new Set([start]), st = [start];
    while (st.length) {
      const i = st.pop(), r = i / N | 0, c = i % N;
      for (const [dr, dc] of DIRS) {
        const rr = r + dr, cc = c + dc, j = rr * N + cc;
        if (rr >= 0 && cc >= 0 && rr < N && cc < N && reg[j] === k && !seen.has(j)) { seen.add(j); st.push(j); }
      }
    }
    return seen.size === tot;
  }
```

エリア `k` のマスを1つ見つけて、そこから上下左右に同じエリアのマスをたどっていきます。たどれたマスの数（`seen.size`）が、エリアのマスの総数（`tot`）と同じなら、ひと続きです。

- `st` は「これから調べるマス」をためておく **スタック**（後から入れたものを先に取り出す入れもの）です。`push` で入れて `pop` で取り出します
- `seen` は「もう見たマス」の `Set` です。同じマスを2回調べないようにします
- エリアが1マスも無くなっていたら `false` です

次の `generate()` でエリアの形を変えたとき、エリアが2つにちぎれていないかを確かめるのに使います。

## 5. generate() … 答えが1つだけの問題を作る

```js:game.js
  function generate(N) {
    let fallback = null;
    for (let a = 0; a < 60; a++) {
      const sol = placeCats(N), reg = growRegions(N, sol);
      const isSol = (i) => sol[i / N | 0] === i % N;
      fallback = { sol, reg };
      for (let step = 0; step < 300; step++) {
        const s = solve(N, reg, 2);
        if (s.length === 1) return { sol, reg };
        const alt = s.find((x) => x.some((c, r) => c !== sol[r]));
        const cells = shuffle(alt.map((c, r) => r * N + c).filter((i) => !isSol(i)));
        let moved = false;
        for (const i of cells) {
          const r = i / N | 0, c = i % N, old = reg[i];
          for (const [dr, dc] of shuffle(DIRS.slice())) {
            const rr = r + dr, cc = c + dc;
            if (rr < 0 || cc < 0 || rr >= N || cc >= N) continue;
            const nk = reg[rr * N + cc];
            if (nk === old) continue;
            reg[i] = nk;
            if (connected(N, reg, old)) { moved = true; break; }
            reg[i] = old;
          }
          if (moved) break;
        }
        if (!moved) break;
      }
    }
    return fallback; // any valid answer is accepted anyway
  }
```

1. 答え `sol` を決めて、エリア `reg` を育てます
2. `solve(N, reg, 2)` で答えをさがします。**ちょうど1個** なら完成です
3. 2個見つかったら、最初に決めた答えとちがうほうを `alt`（別解）として取り出します
4. 別解のねこのマスのうち、本来の答えのマスではないもの（`!isSol(i)`）を1つ選び、そのマスを **となりのエリアにつけかえ** ます。すると、別解ではそのエリアにねこが2匹いることになり、別解がこわれます
5. ただし、つけかえたせいで元のエリアがちぎれたらダメなので、`connected()` で確かめ、ちぎれたら元にもどして別の方向・別のマスをためします
6. 本来の答えのマスは動かさないので、本来の答えはずっと正解のままです。2 にもどってくり返します

それでもうまくいかないときは（`moved` が `false`）、最初からやりなおします。60回ためしてもダメだったときは、答えが複数ある問題をそのまま使います（`fallback`）。ステップ4で作ったとおり、判定は「ルールを満たしているか」で見ているので、別解で解いてもちゃんとクリアになります。

`isSol(i)` は「i 番のマスが本来の答えか」を返す小さな関数です。i から行 `i / N | 0` と列 `i % N` を出して、`sol[行] === 列` かを見ています。

## ステージとスコア

`// ---------- state ----------` の下の変数を、次のように **書きかえます**。

```js:game.js
  let N = 5, puzzle = null, cells = [], catColor = [];
  let state = 'title', score = 0, level = 1;
  let conflicts = new Set();
  const sizeFor = (lv) => (lv <= 1 ? 5 : lv <= 3 ? 6 : lv <= 6 ? 7 : 8);
```

`sizeFor(lv)` は「ステージ lv の盤面の大きさ」です。ステージ1は 5 × 5、2〜3 は 6 × 6、4〜6 は 7 × 7、7 からは 8 × 8 になります。`条件 ? A : B` は **三項演算子** で、「条件が正しければ A、そうでなければ B」です。

`newLevel()` の最初の2行を **書きかえます**。

```js:game.js
    N = sizeFor(level);
    puzzle = generate(N);
```

`win()` を **書きかえます**。

```js:game.js
  function win() {
    state = 'clear';
    const gain = N * 100;
    score += gain;
    scoreEl.textContent = score;
    msgEl.textContent = 'クリア！ +' + gain;
    setTimeout(() => { if (state === 'clear') { level++; newLevel(); state = 'play'; } }, 1300);
  }
```

`setTimeout(関数, ミリ秒)` は「〇ミリ秒後に1回だけ関数を呼ぶ」命令です。クリアから 1.3 秒待って次のステージを用意し、`state` を `'play'` にもどします。待っているあいだに状態が変わっていたら（ステップ7のゲームオーバーなど）何もしないよう、`state === 'clear'` を確かめています。

`startGame()` の最初の2行を **書きかえます**。

```js:game.js
    score = 0; level = 1;
    scoreEl.textContent = 0;
    newLevel();
```
