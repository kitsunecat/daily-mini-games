## このステップのゴール

3つのファイルを用意して、ゲーム画面の土台を作ります。上に「SCORE・BEST」、その下に「ステージ・残り時間のバー」、まん中にゲームを描く **Canvas**（キャンバス）とその上に重ねるタイトル画面（オーバーレイ）、下に「ヒント」「リセット」ボタンを置きます。スタートを押すと、Canvas のまん中に **5 × 5 のマス目** が出るところまで作ります。

完成すると、こんなゲームになります。

- マス目は、色ちがいの **ざぶとん（エリア）** で区切られている
- マスをタップするたびに「空き → ×（ねこは寝ていない印） → ねこ → 空き」と切りかわる
- **どのエリアにも、どのたての列にも、どのよこの列にも、ねこはちょうど1匹**。しかもねこ同士は **となり（ななめも）に寝られない**
- ルールどおりに全部のねこを寝かせるとクリアで、次のステージへ。ステージが進むとマス目が大きくなる
- 制限時間があり、時間切れでゲームオーバー。ヒントは時間と引きかえ。ハイスコアはブラウザに保存される

パズルの問題は **プログラムが毎回自動で作ります**。そこがこの教材のいちばんの見どころです。

## game.js

JavaScript はまず「画面の大きさに合わせて Canvas を用意し、スタートしたらマス目を描きつづける」ところまでを書きます。

```js:game.js
(() => {
  'use strict';
  const $ = (id) => document.getElementById(id);
  const cv = $('cv'), ctx = cv.getContext('2d');
  const scoreEl = $('score'), bestEl = $('best'), levelEl = $('level'), timeEl = $('time'), fillEl = $('timefill'), msgEl = $('msg');
  const overlay = $('overlay'), ovTitle = $('ov-title'), ovText = $('ov-text'), startBtn = $('start');

  // ---------- state ----------
  let N = 5;
  let state = 'title';

  function startGame() {
    state = 'play';
    overlay.classList.add('hidden');
  }

  // ---------- layout & drawing ----------
  let W = 0, H = 0, dpr = 1, ox = 0, oy = 0, cs = 40;
  function resize() {
    dpr = Math.min(window.devicePixelRatio || 1, 3);
    const r = cv.getBoundingClientRect();
    W = r.width; H = r.height;
    cv.width = Math.round(W * dpr); cv.height = Math.round(H * dpr);
  }
  function layout() {
    const size = Math.max(100, Math.min(W - 24, H - 24));
    cs = Math.floor(size / N);
    ox = Math.round((W - cs * N) / 2); oy = Math.round((H - cs * N) / 2);
  }

  function draw(t) {
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
    ctx.clearRect(0, 0, W, H);
    if (state === 'title') return;
    layout();
    // board shadow
    ctx.fillStyle = 'rgba(0,0,0,.25)';
    roundRect(ox - 6, oy - 2, cs * N + 12, cs * N + 12, 14); ctx.fill();
    ctx.fillStyle = '#3a3154';
    roundRect(ox - 6, oy - 6, cs * N + 12, cs * N + 12, 14); ctx.fill();
    for (let i = 0; i < N * N; i++) {
      const r = i / N | 0, c = i % N, x = ox + c * cs, y = oy + r * cs;
      ctx.fillStyle = '#f3eeff';
      ctx.fillRect(x, y, cs, cs);
    }
    // thin grid
    ctx.strokeStyle = 'rgba(60,40,80,.18)'; ctx.lineWidth = 1;
    ctx.beginPath();
    for (let k = 1; k < N; k++) {
      ctx.moveTo(ox + k * cs + 0.5, oy); ctx.lineTo(ox + k * cs + 0.5, oy + N * cs);
      ctx.moveTo(ox, oy + k * cs + 0.5); ctx.lineTo(ox + N * cs, oy + k * cs + 0.5);
    }
    ctx.stroke();
  }
  function roundRect(x, y, w, h, r) {
    ctx.beginPath();
    ctx.moveTo(x + r, y); ctx.arcTo(x + w, y, x + w, y + h, r); ctx.arcTo(x + w, y + h, x, y + h, r);
    ctx.arcTo(x, y + h, x, y, r); ctx.arcTo(x, y, x + w, y, r); ctx.closePath();
  }

  function loop(t) {
    draw(t);
    requestAnimationFrame(loop);
  }

  // ---------- input ----------
  startBtn.addEventListener('click', startGame);
  window.addEventListener('resize', resize);

  resize();
  requestAnimationFrame(loop);
})();
```

### 全体を (() => { ... })(); で囲む

ファイル全体を「すぐ実行される関数」で囲むと、中で作った変数がページ全体（グローバル）に漏れません。`'use strict';` は、うっかりミスをエラーとして教えてくれるモードです。

`const $ = (id) => document.getElementById(id);` は、何度も書く `document.getElementById` を短く書くための小さな関数です。`$('cv')` で Canvas の要素が取れます。

### resize() … Canvas の中身のピクセル数を決める

1. `cv.getBoundingClientRect()` で、Canvas の実際の大きさ（CSS ピクセル）を測り、`W`・`H` に入れます
2. `devicePixelRatio`（dpr）は、高精細な画面で「CSS の 1px が実際は何ドットか」を表す数です。Canvas の中身のピクセル数（`cv.width`・`cv.height`）を dpr 倍にすると、ぼやけずにくっきり描けます。大きすぎると重くなるので、`Math.min(..., 3)` で3倍までにしています

ウィンドウの大きさが変わったら（スマホを横にしたときなど）、もう一度 `resize()` を呼びます。

### layout() … マス目の大きさと位置を決める

- `N` は盤面の1辺のマスの数です。今は 5 で、ステップ5からステージが進むと大きくなります
- `size` は盤面の1辺の長さです。横幅と高さの **小さいほう** から 24px（まわりの余白）を引いて、はみ出さないようにします
- `cs`（cell size）は1マスの大きさです。`Math.floor` で整数にすると、マスの境目がにじまずにくっきりします
- `ox`・`oy` は盤面の左上の位置です。画面の幅から盤面の幅を引いて半分にすると、まん中に置けます

これで、**r 行 c 列のマスの左上は `(ox + c * cs, oy + r * cs)`** と計算できるようになりました。このゲームではずっとこの式を使います。

### マス目を1本の番号で数える

`for (let i = 0; i < N * N; i++)` のループに注目してください。5 × 5 の25マスを、左上から右へ `0, 1, 2, …, 24` と **1本の番号 i** で数えています。番号から行と列に戻すには、

- 行 `r = i / N | 0`（N で割った商。`| 0` は小数を切り捨てる書き方です）
- 列 `c = i % N`（N で割った余り）

逆に、行と列から番号を作るときは `i = r * N + c` です。盤面のデータを2次元配列ではなく **1本の配列** で持つと、コピーやループが簡単になります。

### draw() と loop() … 毎フレーム描きなおす

`draw()` の最初の `ctx.setTransform(dpr, 0, 0, dpr, 0, 0)` は「これから描くものを全部 dpr 倍する」設定です。これで、このあとは CSS ピクセルの座標のまま描けば画面にぴったり合います。

- `roundRect()` は角の丸い四角の **形（パス）** を作る自作の関数です。`arcTo` で4つの角を丸めています。少し下にずらした黒っぽい四角を先にぬって影にし、その上に盤面のわくをぬります
- マスは1つずつ `fillRect` でうすい紫にぬります（ステップ2でエリアの色に変えます）
- 細い線は、`moveTo` と `lineTo` で線を何本も **まとめて** 足してから、最後に1回だけ `stroke()` します。そのほうが速く描けます。`+ 0.5` は、1px の線がピクセルの境目でにじまないようにするための小技です

`loop()` は `draw()` を呼んだあと `requestAnimationFrame(loop)` で「次に画面を書きかえるタイミングで、もう一度 loop を呼んで」とブラウザに頼みます。これで1秒間に約60回、描きなおしが続きます。`loop` には、ブラウザが「今の時刻（ミリ秒）」を `t` として渡してくれます。

### state … ゲームの状態

`state` はゲームの状態で、`'title'`（タイトル画面）・`'play'`（プレイ中）・`'clear'`（クリア演出中）・`'over'`（ゲームオーバー）のどれかになります。今はスタートボタンで `'play'` にして、オーバーレイに `hidden` クラスをつけて隠すだけです。

> [!NOTE]
> `scoreEl`・`timeEl`・`ovTitle` などはまだ使っていませんが、先に取り出しておきます。あとのステップで使います。時間のバーもステップ7までは止まったままです。
