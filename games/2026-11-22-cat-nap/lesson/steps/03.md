## このステップのゴール

マスをタップ（クリック）するたびに、**空き → ×（ねこは寝ていない印） → ねこ → 空き** と切りかわるようにします。ねこは Canvas の図形を組み合わせて描きます。

まだルールのチェックはしません。どこにでもねこを置ける状態です。

## 盤面の状態を配列で持つ

`const COLORS = ...` の行の **下** に、ねこの毛の色を追加します。

```js:game.js
  const CAT_COLORS = ['#f4a24c', '#6b6b78', '#f2f2f2', '#2f2f36', '#d9b38c'];
```

`// ---------- state ----------` の下の1行目を **書きかえます**。

```js:game.js
  let N = 5, puzzle = null, cells = [], catColor = [];
```

`newLevel()` の `puzzle = SAMPLE;` の **下** に追加します。

```js:game.js
    cells = new Array(N * N).fill(0); // 0 empty, 1 x-mark, 2 cat
    catColor = cells.map(() => CAT_COLORS[Math.random() * CAT_COLORS.length | 0]);
```

- `cells` は、プレイヤーが置いたものを覚える配列です。`0` が空き、`1` が ×、`2` がねこです。エリアと同じく、マスの番号 i で読み書きします
- `catColor` は、そのマスにねこを置いたときの毛の色です。マスごとに最初にランダムで決めておくと、置くたびに色が変わってチカチカすることがありません
- `Math.random() * 5 | 0` は、0 以上 5 未満の小数を切り捨てて **0〜4 の整数** を作る定番の書き方です

## マスの状態を変える関数

`newLevel()` の **下**（`startGame()` の上）に追加します。

```js:game.js
  function setCell(i, v) {
    if (cells[i] === v) return;
    cells[i] = v;
  }
  function cycle(i) { setCell(i, (cells[i] + 1) % 3); }
```

- `setCell(i, v)` は「i 番目のマスを v にする」関数です。今は代入するだけですが、次のステップで「変えたらルールをチェックする」、ステップ8で「効果音を鳴らす」を足します。**状態を変える場所を1つの関数にまとめておく** と、あとから処理を足すのが楽になります
- `cycle(i)` は「次の状態へ進める」関数です。`% 3` は3で割った余りなので、`0 → 1 → 2 → 0 → …` とぐるぐる回ります

## ねこを描く

`roundRect()` の上、`function draw(t) {` の **上** に追加します。

```js:game.js
  function drawCat(x, y, s, color, bad, scale) {
    ctx.save();
    ctx.translate(x, y); ctx.scale(scale, scale);
    const dark = color === '#2f2f36' || color === '#6b6b78';
    // body (curled)
    ctx.fillStyle = bad ? '#ff6b7a' : color;
    ctx.strokeStyle = 'rgba(40,30,50,.55)'; ctx.lineWidth = s * 0.04;
    ctx.beginPath(); ctx.ellipse(0, s * 0.12, s * 0.36, s * 0.24, 0, 0, Math.PI * 2); ctx.fill(); ctx.stroke();
    // tail
    ctx.beginPath(); ctx.lineWidth = s * 0.08; ctx.strokeStyle = bad ? '#e04a5a' : color;
    ctx.arc(0, s * 0.12, s * 0.34, 0.2, 1.4); ctx.stroke();
    // head
    ctx.lineWidth = s * 0.04; ctx.strokeStyle = 'rgba(40,30,50,.55)';
    ctx.fillStyle = bad ? '#ff6b7a' : color;
    ctx.beginPath();
    ctx.moveTo(-s * 0.26, -s * 0.02);
    ctx.lineTo(-s * 0.24, -s * 0.34); ctx.lineTo(-s * 0.1, -s * 0.22);
    ctx.lineTo(s * 0.1, -s * 0.22); ctx.lineTo(s * 0.24, -s * 0.34);
    ctx.lineTo(s * 0.26, -s * 0.02);
    ctx.quadraticCurveTo(s * 0.26, s * 0.16, 0, s * 0.16);
    ctx.quadraticCurveTo(-s * 0.26, s * 0.16, -s * 0.26, -s * 0.02);
    ctx.fill(); ctx.stroke();
    // sleepy eyes
    ctx.strokeStyle = dark ? '#f5f0ff' : '#3a2f45'; ctx.lineWidth = s * 0.035; ctx.lineCap = 'round';
    ctx.beginPath(); ctx.arc(-s * 0.1, -s * 0.06, s * 0.05, 0.2, Math.PI - 0.2); ctx.stroke();
    ctx.beginPath(); ctx.arc(s * 0.1, -s * 0.06, s * 0.05, 0.2, Math.PI - 0.2); ctx.stroke();
    // nose
    ctx.fillStyle = '#ff8fa3';
    ctx.beginPath(); ctx.arc(0, s * 0.03, s * 0.025, 0, Math.PI * 2); ctx.fill();
    ctx.restore();
  }
```

ねこは、まるまった体（だ円）・しっぽ（円弧）・耳つきの頭（折れ線と曲線）・ねむそうな目（下向きの円弧）・鼻（小さな円）でできています。

- `ctx.save()` と `ctx.restore()` で囲むと、そのあいだに変えた色や線の太さ、移動・拡大の設定を、終わったら元に戻せます
- `ctx.translate(x, y)` で **原点をねこの中心に移動** してから描くので、中の座標は「中心からどれだけずれているか」だけを書けば済みます。さらに `ctx.scale(scale, scale)` で全体を拡大・縮小できます（ステップ8で、置いたときにぽよんと弾ませるのに使います）
- 座標はすべて `s`（ねこの大きさ）の何倍か、で書いています。だから、マスが大きくても小さくても同じ形のねこになります
- `ctx.ellipse(x, y, 横の半径, 縦の半径, 回転, 開始角, 終了角)` はだ円、`ctx.arc(x, y, 半径, 開始角, 終了角)` は円や円弧です。角度は **ラジアン** で、`Math.PI` が180度です。目は `0.2` から `Math.PI - 0.2` までの下半分の円弧なので、閉じた目に見えます
- `quadraticCurveTo` は、1つの「引っぱる点」を使ってなめらかな曲線を引く命令です。頭のあごの丸みに使っています
- 黒ねこ・灰色ねこのときは、目の線を白っぽくして見えるようにしています（`dark`）
- `bad` が `true` のときは赤くぬります。ルール違反のねこを目立たせるためで、次のステップで使います

## × とねこを盤面に描く

`draw()` の最後（`ctx.strokeRect(ox, oy, cs * N, cs * N);` の **下**）に追加します。

```js:game.js
    // marks & cats
    for (let i = 0; i < N * N; i++) {
      const r = i / N | 0, c = i % N, cx = ox + c * cs + cs / 2, cy = oy + r * cs + cs / 2;
      if (cells[i] === 1) {
        ctx.strokeStyle = 'rgba(70,55,95,.55)'; ctx.lineWidth = Math.max(2, cs * 0.06); ctx.lineCap = 'round';
        const d = cs * 0.14;
        ctx.beginPath(); ctx.moveTo(cx - d, cy - d); ctx.lineTo(cx + d, cy + d); ctx.moveTo(cx + d, cy - d); ctx.lineTo(cx - d, cy + d); ctx.stroke();
      } else if (cells[i] === 2) {
        drawCat(cx, cy, cs * 0.9, catColor[i], false, 1);
      }
    }
```

`cx`・`cy` はマスの **中心** です。左上の座標にマスの半分（`cs / 2`）を足しています。× は中心から左上→右下、右上→左下に2本の線を引くだけです。

## タップされたマスを調べる

`// ---------- input ----------` の **下**（`startBtn.addEventListener` の上）に追加します。

```js:game.js
  let drag = null;
  function cellAt(e) {
    const r = cv.getBoundingClientRect();
    const x = e.clientX - r.left - ox, y = e.clientY - r.top - oy;
    if (x < 0 || y < 0 || x >= cs * N || y >= cs * N) return -1;
    return (y / cs | 0) * N + (x / cs | 0);
  }
  cv.addEventListener('pointerdown', (e) => {
    if (state !== 'play') return;
    const i = cellAt(e);
    if (i < 0) return;
    e.preventDefault();
    drag = { start: i, moved: false };
  });
  const endDrag = () => {
    if (drag && !drag.moved && state === 'play') cycle(drag.start);
    drag = null;
  };
  cv.addEventListener('pointerup', endDrag);
  cv.addEventListener('pointercancel', () => { drag = null; });
```

### ポインターイベント … 指とマウスをまとめて扱う

`pointerdown`（押した）・`pointerup`（離した）・`pointercancel`（スクロールなどで中断された）は、**マウスでも指でもペンでも同じように届く** イベントです。スマホと PC で別々の処理を書かなくて済みます。

### cellAt() … 画面の位置からマスの番号へ

1. `e.clientX`・`e.clientY` は、ページの左上から見たタップの位置です
2. Canvas の左上（`r.left`・`r.top`）と盤面の左上（`ox`・`oy`）を引くと、**盤面の左上から見た位置** になります
3. 盤面の外なら `-1` を返します
4. 中なら、`cs` で割って切り捨てると行と列が分かるので、`行 * N + 列` で番号にします。ステップ1の「r 行 c 列のマスの左上は ox + c * cs」の **逆算** です

### タップは「離したとき」に反応させる

押したときにはまだ切りかえず、`drag` に「どのマスで押したか」を覚えておきます。そして指を離したとき（`endDrag`）に `cycle()` します。

こうしておくのは、ステップ6で「押したまま **なぞったら** × をまとめてつける」操作を足すためです。`moved` はそのときに使う「なぞったかどうか」の印で、今はずっと `false` です。

> [!CHECK] 動作チェック
> - マスをタップ（クリック）するたびに「空き → × → ねこ → 空き」と切りかわる
> - ねこはまるくなって寝ている絵で、毛の色がマスによってちがう
> - 盤面の外をタップしても何も起きない
> - まだルールは見ていないので、同じ行にねこを何匹置いてもそのまま（下の「ねこ 0 / 5」も変わらない）
