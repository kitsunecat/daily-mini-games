## このステップのゴール

置いたねこが **ルールを守っているか** を調べます。

- 同じ行・同じ列・同じエリアにねこが2匹以上いる、または **となり（ななめも）** にねこがいる → そのねこを **赤く** して知らせる
- ねこが N 匹そろって、どれもぶつかっていない → **クリア！**

下のメッセージには「ねこ 2 / 5」のように、いま何匹置いたかを出します。

## ぶつかっているねこを覚える変数

`// ---------- state ----------` の変数の **下** に1行追加します。

```js:game.js
  let conflicts = new Set();
```

`Set`（セット）は「同じものを2回入れても1つとして数える」入れものです。ぶつかっているねこのマス番号を入れていきます。1匹のねこが何匹とぶつかっていても、1回だけ入ります。`conflicts.has(i)` で「i 番のマスが入っているか」がすぐ分かります。

## newLevel() でリセットする

`newLevel()` 全体を、次のように **書きかえます**（最後の2行が増えます）。

```js:game.js
  function newLevel() {
    N = 5;
    puzzle = SAMPLE;
    cells = new Array(N * N).fill(0); // 0 empty, 1 x-mark, 2 cat
    catColor = cells.map(() => CAT_COLORS[Math.random() * CAT_COLORS.length | 0]);
    conflicts = new Set();
    levelEl.textContent = 'ステージ ' + level;
    updateMsg();
  }
```

## check() … ルールを調べる

`newLevel()` の **下** に追加します。

```js:game.js
  function check() {
    conflicts = new Set();
    const cats = [];
    for (let i = 0; i < N * N; i++) if (cells[i] === 2) cats.push(i);
    for (let a = 0; a < cats.length; a++) for (let b = a + 1; b < cats.length; b++) {
      const i = cats[a], j = cats[b];
      const ri = i / N | 0, ci = i % N, rj = j / N | 0, cj = j % N;
      if (ri === rj || ci === cj || puzzle.reg[i] === puzzle.reg[j] || (Math.abs(ri - rj) <= 1 && Math.abs(ci - cj) <= 1)) {
        conflicts.add(i); conflicts.add(j);
      }
    }
    updateMsg(cats.length);
    if (cats.length === N && conflicts.size === 0) win();
  }
  function updateMsg(n) {
    if (n === undefined) n = cells.filter((v) => v === 2).length;
    msgEl.textContent = conflicts.size ? 'ぶつかっているねこがいるよ' : 'ねこ ' + n + ' / ' + N;
  }

  function win() {
    state = 'clear';
    msgEl.textContent = 'クリア！';
  }
```

### 2匹ずつ、全部の組み合わせを調べる

まず、ねこがいるマスの番号を `cats` に集めます。次に、二重ループで **2匹の組み合わせを全部** 調べます。

- 内側のループを `b = a + 1` から始めると、「1匹目と2匹目」を調べたあとに「2匹目と1匹目」をもう一度調べることがなく、自分自身とくらべることもありません
- 盤面は最大でも 8 × 8 で、ねこは多くても十数匹なので、全部の組み合わせを調べても一瞬で終わります

ぶつかっている条件は4つで、どれか1つでも当てはまれば（`||`）2匹とも `conflicts` に入れます。

1. `ri === rj` … 同じ行
2. `ci === cj` … 同じ列
3. `puzzle.reg[i] === puzzle.reg[j]` … 同じエリア
4. 行の差も列の差も1以下 … となり（たて・よこ・ななめの8方向）

4つめは `Math.abs`（絶対値）を使うと、上下左右・ななめを1つの式で書けます。

### クリアの条件

「ねこがちょうど N 匹」で「ぶつかりが0」ならクリアです。N 匹いてぶつかりがなければ、各行・各列・各エリアに1匹ずつ寝ていることになります（行は N 個しかなく、同じ行に2匹はいないので、N 匹なら全部の行に1匹ずついるはずです）。

**用意した答え（`sol`）とくらべていない** ところがポイントです。ルールを満たしていれば、どんな置き方でも正解にします。

### updateMsg() … 下のメッセージ

ぶつかりがあれば注意を、なければ「ねこ 何匹 / N」を出します。`n` を渡さずに呼んだときは、その場で `cells` からねこを数えます。`filter` は条件に合うものだけを集めた新しい配列を作るので、その `length` が匹数です。

`win()` では `state` を `'clear'` にしています。タップの処理は `state !== 'play'` のときに何もしないので、クリアしたあとは盤面がさわれなくなります。

## setCell() から check() を呼ぶ

`setCell()` を **書きかえます**。

```js:game.js
  function setCell(i, v) {
    if (cells[i] === v) return;
    cells[i] = v;
    check();
  }
```

マスが変わるたびにルールを調べなおします。

## ぶつかっているねこを赤くする

`draw()` の中の `drawCat(...)` の行を **書きかえます**。

```js:game.js
        drawCat(cx, cy, cs * 0.9, catColor[i], conflicts.has(i), 1);
```

5番目の引数 `bad` に「ぶつかっているか」を渡すだけで、ステップ3で用意しておいた赤い色で描かれます。

> [!CHECK] 動作チェック
> - ねこを置くと、下のメッセージが「ねこ 1 / 5」「ねこ 2 / 5」と増える
> - 同じ行や同じ列、同じ色のエリア、またはとなり（ななめも）にねこを置くと、その2匹が赤くなり「ぶつかっているねこがいるよ」と出る。片方を取りのぞくと元にもどる
> - 答えの一例: 1行目の左はし、2行目の右から2つめ、3行目の左から2つめ、4行目の右はし、5行目のまん中。この5匹を置くとメッセージが「クリア！」になり、盤面がさわれなくなる
