## このステップのゴール

ゲームとしての「しめきり」をつけます。

- **制限時間** … 最初は 120 秒。時間のバーが減っていき、残り 15 秒で赤くなる。0 になったら **タイムアップ**
- クリアすると **時間が増える**（盤面が大きいほど多く増える）。早く解くほど **スコアのボーナス** も増える
- **ヒント** ボタン … 10 秒と引きかえに、正しい場所にねこを1匹置いてくれる
- **リセット** ボタン … 盤面のねこと × を全部消す

## 時間の決まりごと

`const COLORS = ...` の行の **上** に追加します。

```js:game.js
  const START_TIME = 120, MAX_TIME = 180, HINT_COST = 10;
```

最初の持ち時間・持ち時間の上限・ヒント1回で減る秒数です。数をコードのあちこちに直接書かず、名前をつけて1か所にまとめておくと、あとでバランスを調整するのが楽になります。

`// ---------- state ----------` の2行目を **書きかえます**。

```js:game.js
  let state = 'title', score = 0, level = 1, timeLeft = START_TIME, lastT = 0, levelStart = 0;
```

- `timeLeft` … 残り時間（秒）
- `lastT` … 前のフレームの時刻。1フレームで何秒たったかを計るのに使います
- `levelStart` … 今のステージが始まった時刻。早解きボーナスに使います

`newLevel()` の `conflicts = new Set(); cursor = -1;` の行の **下** に追加します。

```js:game.js
    levelStart = performance.now();
```

`performance.now()` は、ページを開いてからの時間をミリ秒で返します。`requestAnimationFrame` が `loop` に渡してくれる時刻と同じ物差しです。

## 時間を減らす

`loop()` を **書きかえます**。

```js:game.js
  function loop(t) {
    const dt = lastT ? Math.min(0.1, (t - lastT) / 1000) : 0;
    lastT = t;
    if (state === 'play') {
      timeLeft -= dt;
      if (timeLeft <= 0) { timeLeft = 0; gameOver(); }
    }
    timeEl.textContent = Math.ceil(timeLeft);
    fillEl.style.width = (timeLeft / MAX_TIME * 100) + '%';
    fillEl.classList.toggle('low', timeLeft < 15);
    draw(t);
    requestAnimationFrame(loop);
  }
```

### dt … 前のフレームから何秒たったか

`dt`（delta time）は「今の時刻 − 前のフレームの時刻」を秒に直したものです。毎フレーム `timeLeft` から `dt` を引けば、画面の書きかえが速い機械でも遅い機械でも、**本当の時間どおりに** 減っていきます。

- 最初のフレームは `lastT` が 0 なので、`dt` も 0 にします
- タブを裏にしていると `requestAnimationFrame` が止まり、もどったときに `dt` がとても大きくなります。`Math.min(0.1, ...)` で1フレーム 0.1 秒までにおさえて、一気に時間が減らないようにしています
- プレイ中（`'play'`）だけ減らします。クリア演出中は時間が止まります

### 時間の表示

- `Math.ceil` は小数を **切り上げ** ます。残り 0.3 秒なら「1」と表示され、「0」になったときにちょうどタイムアップになります
- バーの横幅は「残り時間 ÷ 上限」をパーセントにしたものです。上限が 180 秒なので、最初の 120 秒ではバーは 3 分の 2 くらいの長さです。クリアで時間が増えると、バーが右へのびます
- `classList.toggle('low', 条件)` は、条件が正しければクラスをつけ、まちがっていれば外します。15 秒を切るとバーが赤くなります

## タイムアップ

`startGame()` の **下** に追加します。

```js:game.js
  function gameOver() {
    state = 'over';
    ovTitle.textContent = 'タイムアップ！';
    ovText.innerHTML = 'ステージ ' + level + ' まで到達<br>スコア <b class="hl">' + score + '</b>';
    startBtn.textContent = 'もういちど';
    overlay.classList.remove('hidden');
  }
```

タイトル画面に使っていたオーバーレイの文字を書きかえて、もう一度表示します。スタートボタンは「もういちど」になり、押すとまた `startGame()` が呼ばれてリトライできます。`innerHTML` は、`<br>` や `<b>` などのタグを含んだ文字を入れるときに使います。

`startGame()` の `score = 0; level = 1;` の行を **書きかえます**。

```js:game.js
    score = 0; level = 1; timeLeft = START_TIME;
```

## クリアで時間とボーナス

`win()` を **書きかえます**。

```js:game.js
  function win() {
    state = 'clear';
    const secs = (performance.now() - levelStart) / 1000;
    const gain = N * 100 + Math.max(0, Math.round((N * 12 - secs) * 10));
    score += gain;
    scoreEl.textContent = score;
    timeLeft = Math.min(MAX_TIME, timeLeft + 15 + N * 2);
    msgEl.textContent = 'クリア！ +' + gain;
    setTimeout(() => { if (state === 'clear') { level++; newLevel(); state = 'play'; } }, 1300);
  }
```

- `secs` は、このステージにかかった秒数です
- 得点は「N × 100」に、早解きボーナスを足します。目安の時間は「N × 12 秒」（5 × 5 なら 60 秒）で、それより早かった1秒ごとに 10 点です。目安より遅いとマイナスになってしまうので、`Math.max(0, ...)` で 0 点より下がらないようにします
- 持ち時間は「15 + N × 2」秒増えます（5 × 5 なら 25 秒）。ただし `MAX_TIME` をこえないようにします

## ヒントとリセット

`cycle()` の **下** に追加します。

```js:game.js
  function hint() {
    if (state !== 'play') return;
    // find a region whose correct cell has no cat
    const todo = [];
    for (let r = 0; r < N; r++) { const i = r * N + puzzle.sol[r]; if (cells[i] !== 2) todo.push(i); }
    if (!todo.length) return;
    // remove cats that disagree with the answer first
    for (let i = 0; i < N * N; i++) if (cells[i] === 2 && puzzle.sol[i / N | 0] !== i % N) cells[i] = 0;
    const i = todo[Math.random() * todo.length | 0];
    timeLeft = Math.max(1, timeLeft - HINT_COST);
    cursor = i;
    setCell(i, 2);
  }
  function resetBoard() {
    if (state !== 'play') return;
    cells.fill(0); check();
  }
```

### hint() … 答えを1マス教える

ここで初めて、問題といっしょに作った答え `puzzle.sol` を使います。

1. 答えのマス（`r * N + sol[r]`）のうち、まだねこがいないものを `todo` に集めます
2. 答えとちがう場所にいるねこは、先に取りのぞきます。まちがったねこが残っていると、ヒントのねこまでぶつかって赤くなってしまうからです
3. `todo` からランダムに1マス選んでねこを置き、そこにカーソルを出して場所を分かりやすくします
4. 時間を 10 秒減らします。ただし、ヒントでタイムアップにならないよう 1 秒は残します

最後の1匹をヒントで置くと、`setCell()` → `check()` → `win()` と進み、そのままクリアになります。

> [!NOTE]
> 答えが複数ある問題（`generate()` の `fallback`）のときは、プレイヤーが別解のとおりに置いたねこも「答えとちがう」として取りのぞかれます。めったに起きないので、このゲームではよしとしています。

### resetBoard() … 盤面を全部消す

`cells.fill(0)` で全部のマスを空きにして、`check()` でメッセージとぶつかりの表示を更新します。

## ボタンとキーをつなぐ

`startBtn.addEventListener('click', startGame);` の **下** に追加します。

```js:game.js
  $('hintbtn').addEventListener('click', hint);
  $('clearbtn').addEventListener('click', resetBoard);
```

`keydown` の中の、X キーの処理の **後ろ** に、H キーでヒントを追加します。`} else if (e.key === 'x' || e.key === 'X') {` のブロックの終わりを、次のように **書きかえます**。

```js:game.js
    } else if (e.key === 'x' || e.key === 'X') {
      if (cursor >= 0) setCell(cursor, cells[cursor] === 1 ? 0 : 1);
    } else if (e.key === 'h' || e.key === 'H') hint();
  });
```

> [!CHECK] 動作チェック
> - スタートすると、右上の数字が 120 から1秒ずつ減り、時間のバーも短くなっていく
> - 「ヒント（-10秒）」を押すと、正しいマスにねこが1匹置かれて白いカーソルが出て、時間が 10 秒減る
> - 「リセット」で盤面のねこと × が全部消える
> - 早く解くと「クリア！ +1000」のようにボーナスつきの得点が入り、時間も増える
> - 時間が 15 秒を切るとバーが赤くなり、0 になると「タイムアップ！」とスコアが出る。「もういちど」で最初から遊べる
