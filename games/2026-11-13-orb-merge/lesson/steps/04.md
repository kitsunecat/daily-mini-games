## このステップのゴール

指をはなす（PC はクリック、Space / Enter / ↓ / S キー）と、ほしだまが **重力で落ちて** 箱の底にたまるようにします。壁と底で止まるところまで作り、玉どうしの押し合いは次のステップで作ります。

## 重力の定数と、玉の入れ物

`const COLORS = [ ... ];` の **下** に追加します。

```js:game.js
  const GRAV = 1500, SUB = 8;
```

- `GRAV` … 重力の強さ。「1秒ごとに下向きの速さが 1500 ずつ増える」という意味です
- `SUB` … 1フレームを何回に分けて計算するか（あとで説明します）

`let` の2行を、次のように **書きかえ** ます。

```js:game.js
  let balls = [], state = 'title';
  let aimX = W / 2, cur = 0, nxt = 0, cooldown = 0, dangerT = 0, idSeq = 0, time = 0;
```

- `balls` … 箱の中にあるほしだまをぜんぶ入れておく **配列**
- `cooldown` … 落としたあと、次を落とせるようになるまでの待ち時間（秒）
- `idSeq` … 玉1つ1つに配る通し番号。合体の処理で「どの玉か」を見分けるのに使います（ステップ6）

`reset()` の **最初の行に** 1行追加します。

```js:game.js
  function reset() {
    balls = []; cooldown = 0;
    cur = randLevel(); nxt = randLevel(); aimX = W / 2;
    drawNext();
  }
```

## 落とす drop()

`function clampAim(x) { ... }` の **下** に追加します。

```js:game.js
  function drop() {
    if (state !== 'play' || cooldown > 0) return;
    const r = RADII[cur];
    balls.push({ id: idSeq++, x: clampAim(aimX), y: DROP_Y, vx: 0, vy: 0, r, lv: cur, age: 0, pop: 0 });
    cur = nxt; nxt = randLevel(); cooldown = 0.45; drawNext();
  }
```

1つのほしだまを **オブジェクト** で表して `balls` に追加します。

- `x`・`y` … 中心の位置。`vx`・`vy` … 速さ（1秒に進む量）。最初は止まった状態です
- `r` … 半径、`lv` … レベル。`{ r }` は `{ r: r }` の省略形です
- `age` … 落としてからの時間、`pop` … 合体したときにふくらむ演出の強さ。どちらもあとのステップで使います

落としたら、NEXT だった `nxt` を今の `cur` にくり上げ、新しい `nxt` を決めて NEXT の表示を描き直します。`cooldown = 0.45` で、0.45 秒は次を落とせません。連打して一気に積み上げられないようにするためです。

## 物理の計算 step()

`drop()` の **下** に追加します。

```js:game.js
  function step(dt) {
    const h = dt / SUB;
    for (let s = 0; s < SUB; s++) {
      for (const b of balls) {
        b.vy += GRAV * h;
        b.x += b.vx * h; b.y += b.vy * h;
        if (b.x - b.r < LEFT) { b.x = LEFT + b.r; b.vx = Math.abs(b.vx) * 0.2; }
        if (b.x + b.r > RIGHT) { b.x = RIGHT - b.r; b.vx = -Math.abs(b.vx) * 0.2; }
        if (b.y + b.r > FLOOR) { b.y = FLOOR - b.r; b.vy = -Math.abs(b.vy) * 0.1; b.vx *= 0.98; }
      }
    }
  }
```

### 速さと位置を少しずつ進める

物を動かす基本は、次の2行です。

- **速さ += 加速度 × 時間** … `b.vy += GRAV * h` で、落ちるほど速くなります
- **位置 += 速さ × 時間** … `b.x += b.vx * h; b.y += b.vy * h`

### 壁と底で止める

円の左端は `b.x - b.r`、右端は `b.x + b.r`、下端は `b.y + b.r` です。

- 壁や底より外に出ていたら、**ちょうどくっつく位置に戻し**、速さを逆向きにします
- 逆向きにした速さに `0.2`（壁）や `0.1`（底）を掛けているので、ほとんど跳ね返らず「ぽてっ」と止まります。この数を **反発係数** といい、1 に近いほどよく弾みます
- 底に触れている間は `b.vx *= 0.98` で横の速さを少しずつ減らし、転がり続けないようにします（床の摩擦）

`Math.abs()` で必ず「内側向き」にしているのは、もしめりこんだまま次の計算が来ても、外向きに戻ってしまわないようにするためです。

### 1フレームを8回に分ける（サブステップ）

`dt`（約 1/60 秒）を `SUB` = 8 で割った `h` ずつ、同じ計算を8回くり返しています。速い玉は1回の計算で大きく動くので、まとめて動かすと **壁や他の玉をすり抜けたり、深くめりこんだり** します。細かく区切って計算すると、少しずつ動いてはぶつかりを確かめられるので、玉がたくさん積み重なっても安定します。次のステップの「押し合い」で特に効いてきます。

## ゲームループと描画に組みこむ

`loop()` の `time += dt;` の行の **下** に追加します。

```js:game.js
    if (state === 'play') { cooldown = Math.max(0, cooldown - dt); step(dt); }
```

プレイ中だけ、待ち時間を減らして物理を進めます。

`draw()` の `// aim` の部分を、次のように **書きかえ** ます（2行追加と、玉を描くループの追加）。

```js:game.js
    // aim
    if (state === 'play') {
      const ax = clampAim(aimX);
      ctx.strokeStyle = 'rgba(255,255,255,.25)'; ctx.lineWidth = 2; ctx.setLineDash([4, 6]);
      ctx.beginPath(); ctx.moveTo(ax, DROP_Y); ctx.lineTo(ax, FLOOR); ctx.stroke(); ctx.setLineDash([]);
      ctx.globalAlpha = cooldown > 0 ? 0.4 : 1;
      drawOrb(ctx, ax, DROP_Y, RADII[cur], cur);
      ctx.globalAlpha = 1;
    }
    for (const b of balls) {
      drawOrb(ctx, b.x, b.y, b.r, b.lv);
    }
```

`ctx.globalAlpha` は描く物の **不透明度**（0 で透明、1 でふつう）です。待ち時間の間は浮かんでいるほしだまを半透明にして、「まだ落とせない」ことが見た目で分かるようにします。

## 入力から drop() を呼ぶ

`pointerup` の行の最後に `drop();` を **追加** します。

```js:game.js
  cv.addEventListener('pointerup', ev => { if (!pressing) return; pressing = false; aimX = toWorld(ev); drop(); });
```

`keydown` の中、`keys[ev.key] = true;` の **下** に追加します。

```js:game.js
    if (ev.key === ' ' || ev.key === 'Enter' || ev.key === 'ArrowDown' || ev.key === 's') { ev.preventDefault(); drop(); }
```

スペースキーはページのスクロールに使われるので、`preventDefault()` で止めておきます。

> [!CHECK] 動作チェック
> - クリック（スマホは指をはなす）すると、その位置からほしだまが加速しながら落ちて、箱の底で止まる
> - 落とした直後は浮かんでいるほしだまが半透明になり、0.5 秒ほどで元に戻る。半透明の間は落とせない
> - NEXT に出ていたほしだまが、次に落とす玉になっている
> - 今はまだ玉どうしが **重なってしまう**（次のステップで直します）
