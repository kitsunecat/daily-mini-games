## このステップのゴール

落とす位置を **自分で動かせる** ようにします。スマホは指でドラッグ、PC はマウスを動かすか ←→ / A D キーで、浮かんでいるほしだまが左右に動き、真下に「ここに落ちるよ」という点線のガイドが出るようにします。

## 狙いの位置 aimX

`let cur = 0, nxt = 0, ...` の行を、次のように **書きかえ** ます。

```js:game.js
  let aimX = W / 2, cur = 0, nxt = 0, dangerT = 0, time = 0;
```

`aimX` は **狙っている x 座標** です。`reset()` の1行目も、`aimX` をまん中に戻すように **書きかえ** ます。

```js:game.js
  function reset() {
    cur = randLevel(); nxt = randLevel(); aimX = W / 2;
    drawNext();
  }
```

## 壁からはみ出さないようにする clampAim()

`function start() { ... }` の **下** に追加します。

```js:game.js
  function clampAim(x) { const r = RADII[cur]; return Math.max(LEFT + r, Math.min(RIGHT - r, x)); }
```

ほしだまの中心は、左の壁から半径ぶん内側（`LEFT + r`）より左へは行けず、右の壁から半径ぶん内側（`RIGHT - r`）より右へも行けません。`Math.max(最小, Math.min(最大, 値))` は、値を **範囲の中に収める**（クランプする）お決まりの書き方です。

半径は今のほしだま `cur` で変わるので、`aimX` そのものは書きかえず、**使うときに毎回 `clampAim(aimX)` を通す** ようにしています。小さい玉で壁ぎわを狙っていて、次に大きい玉が来ても、自動で少し内側に寄ってくれます。

## draw() の狙いを書きかえる

ステップ2で追加した `// aim` の部分を、次のように **書きかえ** ます。

```js:game.js
    // aim
    if (state === 'play') {
      const ax = clampAim(aimX);
      ctx.strokeStyle = 'rgba(255,255,255,.25)'; ctx.lineWidth = 2; ctx.setLineDash([4, 6]);
      ctx.beginPath(); ctx.moveTo(ax, DROP_Y); ctx.lineTo(ax, FLOOR); ctx.stroke(); ctx.setLineDash([]);
      drawOrb(ctx, ax, DROP_Y, RADII[cur], cur);
    }
```

ほしだまの位置から箱の底まで、うすい白の点線を引いてから、その上にほしだまを描きます。線を先に描くのは、ほしだまの下に線が隠れるようにするためです。

## 入力を受け取る

`let last = performance.now();` から始まるゲームループの **下**（`startBtn.addEventListener(...)` の上）に追加します。

```js:game.js
  // --- input ---
  function toWorld(ev) { const r = cv.getBoundingClientRect(); return (ev.clientX - r.left) / r.width * W; }
  let pressing = false;
  cv.addEventListener('pointerdown', ev => { if (state !== 'play') return; pressing = true; aimX = toWorld(ev); try { cv.setPointerCapture(ev.pointerId); } catch (e) {} ev.preventDefault(); });
  cv.addEventListener('pointermove', ev => { if (state !== 'play') return; if (pressing || ev.pointerType === 'mouse') aimX = toWorld(ev); });
  cv.addEventListener('pointerup', ev => { if (!pressing) return; pressing = false; aimX = toWorld(ev); });
  cv.addEventListener('pointercancel', () => { pressing = false; });
  const keys = {};
  window.addEventListener('keydown', ev => {
    if (state !== 'play') { if (ev.key === 'Enter' || ev.key === ' ') { ev.preventDefault(); start(); } return; }
    keys[ev.key] = true;
  });
  window.addEventListener('keyup', ev => { keys[ev.key] = false; });
  setInterval(() => {
    if (state !== 'play') return;
    if (keys.ArrowLeft || keys.a) aimX = clampAim(aimX) - 6;
    if (keys.ArrowRight || keys.d) aimX = clampAim(aimX) + 6;
  }, 16);
```

### 画面の位置をゲームの座標に直す toWorld()

マウスや指の位置 `ev.clientX` は **ページ上のピクセル** なので、そのままでは 360 幅のゲームの座標と合いません。`getBoundingClientRect()` で Canvas が画面のどこに、どの幅で表示されているかを調べ、

- `ev.clientX - r.left` … Canvas の左端から何ピクセルか
- それを `r.width` で割る … 左端が 0、右端が 1 の割合
- それに `W` を掛ける … ゲームの座標（0〜360）

と変換します。画面がどんな大きさでも正しい位置になります。

### Pointer Events でマウスとタッチをまとめて扱う

**Pointer Events**（`pointerdown` / `pointermove` / `pointerup`）は、マウス・指・ペンを同じ書き方で受け取れるイベントです。

- `pointerdown` … 押したら `pressing` を `true` にして、その位置を狙います。`setPointerCapture()` を呼ぶと、指が Canvas の外にはみ出しても `pointermove` や `pointerup` が届き続けます。`preventDefault()` はスマホでスクロールなどが起きるのを防ぎます
- `pointermove` … 押している間は狙いを動かします。マウス（`ev.pointerType === 'mouse'`）のときは、押していなくても動かすだけで狙いがついてきます
- `pointerup` … 指をはなした位置を最後の狙いにします。次のステップでここに「落とす」を足します

### キーボードは「押している間」を覚えておく

`keydown` が来たら `keys[ev.key] = true`、`keyup` で `false` にして、**今どのキーが押されているか** を `keys` オブジェクトに覚えておきます。`setInterval(..., 16)` で約 16 ミリ秒ごとに `keys` を見て、←（または A）なら左へ 6、→（または D）なら右へ 6 動かします。キーのリピート（押しっぱなしで連打される機能）に頼らないので、押した瞬間からなめらかに動きます。

先に `clampAim()` を通してから 6 を足しているのは、壁ぎわで押し続けたとき `aimX` が壁の外へどんどん離れていかないようにするためです。

タイトル画面やゲームオーバー画面のときは、Enter かスペースでスタートできるようにしてあります。

> [!CHECK] 動作チェック
> - スタート後、PC ではマウスを箱の上で左右に動かすと、ほしだまと点線のガイドがついてくる
> - ←→ や A / D キーを押している間、ほしだまがなめらかに動く
> - 箱の左右の端まで動かしても、ほしだまが壁にめりこまない
> - スマホ（または開発者ツールのデバイスモード）で、指でドラッグして動かせる
> - タイトル画面で Enter かスペースを押してもスタートできる
