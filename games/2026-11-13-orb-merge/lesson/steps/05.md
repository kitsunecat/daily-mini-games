## このステップのゴール

ほしだまどうしが **重ならずに押し合い、転がり、積み重なる** ようにします。このゲームの手ざわりを決める、いちばん大事な物理の部分です。「円と円の当たり判定」と「ぶつかったときの押し返し」を作ります。

## step() に押し合いを追加する

`step()` の中、壁と底の判定をしている `for (const b of balls) { ... }` の **閉じかっこの下**（まだ `for (let s = ...)` の中）に追加します。追加後の `step()` 全体はこうなります。

```js:game.js
  function step(dt) {
    const h = dt / SUB;
    for (let s = 0; s < SUB; s++) {
      for (const b of balls) {
        b.vy += GRAV * h;
        b.x += b.vx * h; b.y += b.vy * h;
        if (b.x - b.r < LEFT) { b.x = LEFT + b.r; b.vx = Math.abs(b.vx) * 0.2; }
        if (b.x + b.r > RIGHT) { b.x = RIGHT - b.r; b.vx = -Math.abs(b.vx) * 0.2; }
        if (b.y + b.r > FLOOR) { b.y = FLOOR - b.r; b.vy = -Math.abs(b.vy) * 0.1; b.vx *= 0.98; }
      }
      for (let i = 0; i < balls.length; i++) {
        const a = balls[i];
        for (let j = i + 1; j < balls.length; j++) {
          const b = balls[j];
          const dx = b.x - a.x, dy = b.y - a.y, rr = a.r + b.r;
          const d2 = dx * dx + dy * dy;
          if (d2 >= rr * rr) continue;
          const d = Math.sqrt(d2) || 0.001;
          const nx = dx / d, ny = dy / d, over = rr - d;
          const ma = a.r * a.r, mb = b.r * b.r, tot = ma + mb;
          a.x -= nx * over * (mb / tot); a.y -= ny * over * (mb / tot);
          b.x += nx * over * (ma / tot); b.y += ny * over * (ma / tot);
          const rv = (b.vx - a.vx) * nx + (b.vy - a.vy) * ny;
          if (rv < 0) {
            const imp = -(1.15) * rv / (1 / ma + 1 / mb);
            a.vx -= imp * nx / ma; a.vy -= imp * ny / ma;
            b.vx += imp * nx / mb; b.vy += imp * ny / mb;
            // tangential friction
            const tx = -ny, ty = nx, tv = (b.vx - a.vx) * tx + (b.vy - a.vy) * ty;
            const fi = tv * 0.05 / (1 / ma + 1 / mb);
            a.vx += fi * tx / ma; a.vy += fi * ty / ma;
            b.vx -= fi * tx / mb; b.vy -= fi * ty / mb;
          }
        }
      }
      for (const b of balls) { b.vx *= 0.999; b.vy *= 0.999; }
    }
  }
```

上から順に見ていきましょう。

### すべての組み合わせを1回ずつ調べる

`i` のループの中で `j` を **`i + 1` から** 始めると、「0と1」「0と2」「1と2」…のように、すべての2個の組を **1回ずつ** 調べられます。`j = 0` から始めると「0と1」と「1と0」を2回調べてしまい、押し返しも2倍になってしまいます。

### 円と円の当たり判定

2つの円は、**中心どうしの距離が半径の合計より小さい** とき重なっています。

- `dx`・`dy` … a から b へ向かう横と縦の差
- 距離は三平方の定理で `Math.sqrt(dx * dx + dy * dy)` ですが、平方根の計算は少し重いので、まず **2乗どうしのまま** 比べます。`d2 >= rr * rr`（距離の2乗 ≧ 半径の合計の2乗）なら離れているので `continue` で次の組へ
- 重なっているときだけ平方根を取って距離 `d` を出します。2つの中心がぴったり同じ位置だと `d` が 0 になり、次の割り算が壊れるので、`|| 0.001` で 0 を避けています

### 重なったぶんだけ押し離す

- `nx`・`ny` … a から b へ向かう **長さ1の向き**（単位ベクトル）。差を距離で割ると作れます
- `over` … どれだけ重なっているか（めりこみの深さ）

a を `-n` の向きへ、b を `+n` の向きへ動かして、重なりをなくします。このとき **重い玉ほど動きにくく** したいので、ほしだまの重さ（質量）を「面積に比例する」と考えて `ma = a.r * a.r` とし、

- a は `over × mb / (ma + mb)`、b は `over × ma / (ma + mb)` だけ動かす

と分けています。2つを足すとちょうど `over` になり、小さい玉は大きく、大きい玉は少しだけ動きます。

### 近づく速さを打ち消す（はね返り）

位置を直しただけでは、玉はまだお互いに向かって進もうとしています。

- `rv` … 2つの玉が **向き n の方向に** どれだけの速さで離れているか。速さの差と向き `n` の **内積**（`x どうしの積 + y どうしの積`）で求めます。マイナスなら近づいている途中です
- 近づいているときだけ、速さを変える量 `imp`（**撃力**、インパルス）を計算して、a と b に反対向きに加えます。重さで割っているので、軽い玉ほど大きくはね飛ばされます
- `1.15` は「1 ＋ 反発係数 0.15」です。1 だけだと「近づく速さをちょうど 0 にする」、0.15 を足すとほんの少しだけ跳ね返ります

### 横すべりの摩擦

`tx`・`ty` は向き `n` を 90 度回した、**接している面にそった向き** です。この向きの速さの差 `tv` を少し（5%）だけ打ち消すと、玉どうしがこすれ合ってすべりにくくなり、積んだ玉の山が崩れにくくなります。

### 少しずつ減速させる

最後の `b.vx *= 0.999; b.vy *= 0.999;` は空気抵抗のようなものです。ほんの少しずつ速さを減らすことで、いつまでもプルプル揺れ続けるのを防ぎます。

> [!NOTE]
> ここで書いた「重なりを直す → 近づく速さを撃力で打ち消す」は、物理エンジンでもよく使われる考え方を小さくしたものです。1回で完全には直りませんが、サブステップで8回くり返すことで、たくさん積んでも安定します。

> [!CHECK] 動作チェック
> - 落としたほしだまが、下の玉に乗ったり、すき間に転がりこんだりして **重ならずに積み重なる**
> - 大きな玉を小さな玉の上に落とすと、小さな玉が押しのけられる
> - 玉が止まったあと、いつまでも揺れ続けない
> - 同じ大きさの玉がふれ合っても、まだ合体しない（次のステップで作ります）
