## このステップのゴール

3つのファイルを用意して、ゲーム画面の土台を作ります。上に「NEXT・SCORE・BEST」の表示、まん中にゲームを描く **Canvas**（キャンバス）とその上に重ねるタイトル画面（オーバーレイ）、下にひとことヒントを置き、Canvas に **星空と箱、赤い点線** を描くところまで進めます。

完成すると、こんなゲームになります。

- 箱の上から **ほしだま** を1つずつ落として積んでいく。落とす位置はドラッグ（PC はマウスや ←→ / A D キー）で決める
- ほしだまは重力で落ち、転がったり押し合ったりする **物理パズル**
- **同じ大きさ（同じ色）どうしがふれ合うと合体** して、ひとつ大きなほしだまに進化する。ちり→すな→いし→…→たいようの全11段階
- 箱の上の **赤い線** をこえたまま止まっているとゲームオーバー。大きく合体させるほど高得点で、ベストはブラウザに保存される

- `<meta name="viewport" ...>` はスマホで画面幅に合わせて表示し、ピンチで拡大されないようにする設定です

- 書きかえる場所には `id`（`score`・`best`・`ov-title`・`ov-text`）をつけておき、JavaScript から `document.getElementById()` で取り出します
- `#overlay` はタイトル画面とゲームオーバー画面を兼ねた「ふた」です。Canvas の上に重ねて表示し、ゲーム中は隠します
- 「← 一覧」のリンク先はこのサイトのトップです。自分のフォルダで作るときは好きなページに変えてかまいません
- `<script>` を `</body>` の直前に置くと、HTML の要素がすべて読みこまれてから JavaScript が動きます

## game.js

最初の `game.js` です。

```js:game.js
(() => {
  'use strict';
  const W = 360, H = 600;
  const LEFT = 12, RIGHT = W - 12, FLOOR = H - 12, DANGER = 112, DROP_Y = 62;

  const cv = document.getElementById('cv'), ctx = cv.getContext('2d');
  const nextCv = document.getElementById('next'), nctx = nextCv.getContext('2d');
  const scoreEl = document.getElementById('score'), bestEl = document.getElementById('best');
  const overlay = document.getElementById('overlay'), ovTitle = document.getElementById('ov-title');
  const ovText = document.getElementById('ov-text'), startBtn = document.getElementById('start');
  const stage = document.getElementById('stage');

  let state = 'title';
  let dangerT = 0, time = 0;
  let scale = 1;

  function resize() {
    const sw = stage.clientWidth - 16, sh = stage.clientHeight - 8;
    scale = Math.min(sw / W, sh / H);
    const dpr = window.devicePixelRatio || 1;
    cv.style.width = Math.floor(W * scale) + 'px';
    cv.style.height = Math.floor(H * scale) + 'px';
    cv.width = Math.floor(W * scale * dpr);
    cv.height = Math.floor(H * scale * dpr);
    ctx.setTransform(scale * dpr, 0, 0, scale * dpr, 0, 0);
    draw();
  }
  window.addEventListener('resize', resize);

  function start() {
    state = 'play'; overlay.classList.add('hidden');
  }

  function draw() {
    // background
    const bg = ctx.createLinearGradient(0, 0, 0, H);
    bg.addColorStop(0, '#24184f'); bg.addColorStop(1, '#3d2a6a');
    ctx.fillStyle = bg; ctx.fillRect(0, 0, W, H);
    ctx.fillStyle = 'rgba(255,255,255,.5)';
    for (let i = 0; i < 40; i++) {
      const sx = (i * 97) % W, sy = (i * 53) % H, tw = 0.5 + 0.5 * Math.sin(time * 2 + i);
      ctx.globalAlpha = 0.2 + tw * 0.4; ctx.fillRect(sx, sy, 1.6, 1.6);
    }
    ctx.globalAlpha = 1;
    // box
    ctx.fillStyle = 'rgba(255,255,255,.06)';
    ctx.fillRect(LEFT, DANGER - 10, RIGHT - LEFT, FLOOR - DANGER + 10);
    ctx.strokeStyle = 'rgba(220,200,255,.6)'; ctx.lineWidth = 3;
    ctx.beginPath(); ctx.moveTo(LEFT - 1, DANGER - 10); ctx.lineTo(LEFT - 1, FLOOR + 1); ctx.lineTo(RIGHT + 1, FLOOR + 1); ctx.lineTo(RIGHT + 1, DANGER - 10); ctx.stroke();
    // danger line
    const flash = dangerT > 0 ? 0.5 + 0.5 * Math.sin(time * 20) : 0.5;
    ctx.strokeStyle = `rgba(255,80,90,${flash})`; ctx.lineWidth = 2; ctx.setLineDash([8, 6]);
    ctx.beginPath(); ctx.moveTo(LEFT, DANGER); ctx.lineTo(RIGHT, DANGER); ctx.stroke(); ctx.setLineDash([]);
  }

  startBtn.addEventListener('click', ev => { ev.stopPropagation(); start(); });
  overlay.addEventListener('click', () => start());

  resize();
})();
```

### 全体を `(() => { ... })();` で包む

ファイル全体を **即時実行関数** で包んでいます。中で作った変数がページ全体（グローバル）に漏れないので、名前のぶつかりを気にせずに書けます。`'use strict';` は、うっかりミス（宣言していない変数への代入など）をエラーとして教えてくれるモードです。

### 360×600 の「ゲームの座標」で考える

画面の大きさに関係なく、ゲームの世界を **幅 `W` = 360、高さ `H` = 600** の座標で考えます。箱まわりの数字もここで決めておきます。

- `LEFT`・`RIGHT` … 箱の左の壁と右の壁の x（12 と 348）
- `FLOOR` … 箱の底の y（588）
- `DANGER` … 赤い点線の y（112）。これより上に玉が残るとゲームオーバーになります（ステップ7）
- `DROP_Y` … 落とす前のほしだまを浮かべておく高さ（62）

数字を直接あちこちに書かず **名前をつけた定数** にしておくと、「箱を少し広くしたい」と思ったときに1か所直すだけで済みます。

### resize() で画面に合わせて拡大する

`resize()` は `#stage` の大きさ（`clientWidth`・`clientHeight`）を調べ、360×600 の絵が **縦横比を保ったまま** ちょうど収まる倍率 `scale` を計算します。幅で決まる倍率と高さで決まる倍率の小さいほう（`Math.min`）を使うのがポイントです。

- `cv.style.width` / `cv.style.height` は、Canvas の **見た目の大きさ**（CSS のピクセル）です
- `cv.width` / `cv.height` は、Canvas の **中身の画素数** です。ここを `devicePixelRatio`（高解像度の画面で 1 ピクセルに何倍の画素があるか）倍にしておくと、スマホでも絵がぼやけません
- `ctx.setTransform(scale * dpr, 0, 0, scale * dpr, 0, 0)` で「1 と書いたら `scale * dpr` 画素ぶん」に拡大しておきます。こうすると、描くときは **いつも 360×600 の座標で書けばよく**、画面の大きさを気にしなくて済みます
- Canvas は大きさを変えると中身が消えるので、最後に `draw()` で描き直します

### draw() で星空と箱を描く

`draw()` は、いちばん奥の物から順に塗り重ねていきます。

- **背景** … `createLinearGradient(0, 0, 0, H)` で上から下へのグラデーションを作り、画面全体を塗ります
- **星** … 40 個の小さな四角を描きます。位置は `(i * 97) % W` のように「番号に大きめの数を掛けて画面の幅で割った余り」で決めています。乱数を使わなくても、ばらばらに散らばって見え、しかも毎回同じ位置になるので星がちらつきません。`Math.sin(time * 2 + i)` で明るさを変えて **またたかせる** 準備もしてあります（`time` はステップ2から増えはじめます）
- **箱** … うっすら白い四角で中を塗り、`moveTo` → `lineTo` で「左の壁 → 底 → 右の壁」の **コの字** を1本の線で描きます。上はあいたままです
- **赤い点線** … `ctx.setLineDash([8, 6])` で「8 描いて 6 あける」点線にします。描き終わったら `setLineDash([])` で実線に戻すのを忘れないようにしましょう。`dangerT`（あふれそうになっている時間）が 0 より大きいと点滅しますが、今はずっと 0 です

### スタートの仕組み

`state` はゲームの状態で、`'title'`（タイトル画面）→ `'play'`（プレイ中）→ `'over'`（ゲームオーバー）と変わります。スタートボタンかオーバーレイのどこかを押すと `start()` が呼ばれ、`state` を `'play'` にしてオーバーレイを隠します。

ボタンの `click` で `ev.stopPropagation()` しているのは、ボタンのクリックが親の `#overlay` にも伝わって `start()` が **2回** 呼ばれるのを防ぐためです。

`nextCv` や `scoreEl` など、まだ使っていない要素も先に取り出しておきます。
