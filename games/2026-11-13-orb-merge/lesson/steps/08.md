## このステップのゴール

最後に **効果音** と、合体したときに飛び散る **パーティクル**（小さな粒）を加えて、さわって気持ちいいゲームに仕上げます。これで完成品と同じ `game.js` になります。

## Web Audio API で効果音を鳴らす

`let scale = 1;` の **下** に追加します。

```js:game.js
  // --- sound ---
  let ac = null;
  function beep(freq, dur, type = 'sine', vol = 0.12) {
    try {
      if (!ac) ac = new (window.AudioContext || window.webkitAudioContext)();
      const o = ac.createOscillator(), g = ac.createGain();
      o.type = type; o.frequency.value = freq;
      g.gain.setValueAtTime(vol, ac.currentTime);
      g.gain.exponentialRampToValueAtTime(0.001, ac.currentTime + dur);
      o.connect(g); g.connect(ac.destination);
      o.start(); o.stop(ac.currentTime + dur);
    } catch (e) {}
  }
```

**Web Audio API** を使うと、音声ファイルを用意しなくても JavaScript だけで音を作れます。

- `AudioContext` … 音を鳴らすための「音の作業場」。ブラウザは **ユーザーが画面を触るまで音を鳴らさせてくれない** ので、ページを開いたときではなく、最初に `beep()` が呼ばれたとき（スタートボタンを押したとき）に作ります
- `createOscillator()` … 決まった高さの音を出し続ける **発振器**。`frequency` が音の高さ（Hz）、`type` が音色で、`'sine'`（やわらかい）、`'triangle'`（少し明るい）、`'sawtooth'`（ジージーした音）などがあります
- `createGain()` … 音量のつまみ。`exponentialRampToValueAtTime()` で、`dur` 秒かけて音量をほぼ 0 まで下げると「ポン」と減衰する音になります
- 発振器 → 音量 → スピーカー（`ac.destination`）の順に `connect()` でつなぎ、`start()` で鳴らして `stop()` で止める時刻を予約します

`type = 'sine'` のように引数に `=` で書いた値は **デフォルト引数** で、呼ぶときに省略するとその値になります。

## パーティクルを飛び散らせる

`let balls = [], score = 0, state = 'title';` の行を、次のように **書きかえ** ます。

```js:game.js
  let balls = [], effects = [], score = 0, state = 'title';
```

`effects` は飛び散る粒を入れておく配列です。`reset()` の1行目も **書きかえ** ます。

```js:game.js
    balls = []; effects = []; score = 0; dangerT = 0; cooldown = 0;
```

`step()` 関数の **下** に、粒を作る関数を追加します。

```js:game.js
  function burst(x, y, lv, n) {
    for (let i = 0; i < n; i++) {
      const a = Math.random() * Math.PI * 2, sp = 60 + Math.random() * 180;
      effects.push({ x, y, vx: Math.cos(a) * sp, vy: Math.sin(a) * sp, life: 0.6, c: COLORS[lv][1] });
    }
  }
```

ランダムな **角度** `a`（0〜360度）と **速さ** `sp` を決め、`Math.cos(a) * sp`・`Math.sin(a) * sp` で横と縦の速さに分けます。こうすると、粒がまん中から **全方向へ放射状に** 飛び散ります。`life` は残り寿命（秒）、`c` はそのレベルの基本の色です。

`step()` の合体の部分を、`burst()` と `beep()` を呼ぶように **書きかえ** ます。

```js:game.js
          if (a.lv === b.lv) {
            merged.add(a.id); merged.add(b.id);
            const mx = (a.x + b.x) / 2, my = (a.y + b.y) / 2;
            if (a.lv === RADII.length - 1) {
              addScore(100); burst(mx, my, a.lv, 40);
            } else {
              const lv = a.lv + 1;
              born.push({ id: idSeq++, x: mx, y: my, vx: (a.vx + b.vx) / 2, vy: Math.min(a.vy, b.vy) / 2, r: RADII[lv], lv, age: 1, pop: 1 });
              addScore(TRI[lv]); burst(mx, my, lv, 10 + lv * 2);
            }
            beep(300 + a.lv * 70, 0.15, 'sine', 0.14);
            break;
          }
```

大きい玉ほど粒の数（`10 + lv * 2`）が増え、たいようどうしの合体では 40 粒の大きな花火になります。

## 粒を動かして描く

`loop()` を、粒を動かして寿命が切れたものを消すように **書きかえ** ます。

```js:game.js
  function loop(now) {
    const dt = Math.min(0.033, (now - last) / 1000); last = now; time += dt;
    if (state === 'play') { cooldown = Math.max(0, cooldown - dt); step(dt); }
    for (const e of effects) { e.x += e.vx * dt; e.y += e.vy * dt; e.vy += 300 * dt; e.life -= dt; }
    effects = effects.filter(e => e.life > 0);
    draw();
    requestAnimationFrame(loop);
  }
```

粒もほしだまと同じ「位置 += 速さ × 時間」で動かし、弱い重力（300）で少しずつ下に落ちていきます。`filter()` で寿命が残っている粒だけを残すので、配列がどんどん大きくなることはありません。粒の更新を `if (state === 'play')` の外に置いているので、ゲームオーバーの瞬間に飛んでいた粒も最後まで飛び切ります。

`draw()` の玉を描くループの **下**（「あふれそう！」の上）に追加します。

```js:game.js
    for (const e of effects) {
      ctx.globalAlpha = Math.max(0, e.life / 0.6); ctx.fillStyle = e.c;
      ctx.beginPath(); ctx.arc(e.x, e.y, 3, 0, 7); ctx.fill();
    }
    ctx.globalAlpha = 1;
```

残り寿命の割合（`e.life / 0.6`）をそのまま不透明度にするので、粒は飛びながら **すうっと消えて** いきます。描き終わったら `globalAlpha` を 1 に戻しておきましょう。

これで完成です！ ステップ1から順に作ってきた `game.js` は、完成品とまったく同じ内容になっています。

> - 合体した場所から、そのほしだまの色の粒が全方向に飛び散り、落ちながら消えていく

## 改造アイデア

> [!TIP]
> - `randLevel()` の確率を変えて、小さい玉ばかり出る「やさしいモード」や、大きめが出る「むずかしいモード」を作ってみよう
> - 合体が短い時間に続いたら「〇連鎖！」と表示して、連鎖の数に応じてボーナス点を足してみよう
> - `GRAV` や、`step()` の反発係数（`0.2`・`0.1`・`1.15`）を変えて、ふわふわ浮かぶ「月面モード」やよく弾む「スーパーボールモード」にしてみよう
> - 一度でも作ったことのあるレベルを localStorage に保存して、タイトル画面に「ほしだま図鑑」を表示してみよう
> - 一定時間ごとに箱が少しせまくなる、など時間で変わるルールを足して、エンドレスの緊張感を高めてみよう
