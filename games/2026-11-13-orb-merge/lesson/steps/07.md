## このステップのゴール

ほしだまが **赤い点線をこえたまま止まっている** とゲームオーバーにします。あふれそうになると点線が点滅して「あふれそう！」と警告を出し、ゲームオーバー画面にはスコアと「いちばん大きかったほしだま」を表示します。ベストスコアは **localStorage** に保存して、ページを閉じても残るようにします。

## ベストスコアを読みこむ

`const stage = document.getElementById('stage');` の **下** に追加します。

```js:game.js
  let best = 0;
  try { best = parseInt(localStorage.getItem('orb-merge-best') || '0', 10) || 0; } catch (e) {}
  bestEl.textContent = best;
```

**localStorage** は、ブラウザにサイトごとの小さなデータを **ずっと保存しておける** 仕組みです。

- `localStorage.getItem('名前')` で読み、`localStorage.setItem('名前', '値')` で書きます。値はいつも **文字列** です
- まだ保存していないときは `null` が返るので、`|| '0'` で `'0'` に置きかえ、`parseInt(..., 10)` で10進数の数に直します。中身がこわれていて数にならない（`NaN`）ときも、最後の `|| 0` で 0 にします
- プライベートブラウズなどで localStorage が使えないと、エラーになることがあります。`try { ... } catch (e) {}` で囲んでおけば、そのときもゲームは止まりません

## reset() で危険時間も戻す

`reset()` の1行目に `dangerT = 0;` を **追加** します。

```js:game.js
    balls = []; score = 0; dangerT = 0; cooldown = 0;
```

## ゲームオーバーの処理 gameOver()

`function start() { ... }` の **下**（`clampAim()` の上）に追加します。

```js:game.js
  function gameOver() {
    state = 'over';
    if (score > best) { best = score; try { localStorage.setItem('orb-merge-best', String(best)); } catch (e) {} }
    bestEl.textContent = best;
    let top = 0; for (const b of balls) top = Math.max(top, b.lv);
    ovTitle.textContent = 'ゲームオーバー';
    ovText.innerHTML = `スコア <b class="hl">${score}</b>（ベスト ${best}）<br>いちばん大きかったのは「${NAMES[top]}」`;
    startBtn.textContent = 'もう一度';
    overlay.classList.remove('hidden');
  }
```

- `state` を `'over'` にすると、ゲームループの `if (state === 'play')` が通らなくなり、物理が止まって玉がその場で固まります
- ベストを更新したら localStorage に保存します
- 箱に残っている玉の中から、いちばん大きいレベル `top` を探し、ステップ2で作った `NAMES` で名前を出します
- `innerHTML` は HTML として書きこむので、`<b class="hl">` で数字を黄色くできます。`` `...${score}...` `` は **テンプレート文字列** で、`${ }` の中に変数を埋めこめます
- オーバーレイを再び表示します。ボタンは「もう一度」になり、押すと `start()` → `reset()` でやり直せます

## あふれそうかを判定する

`step()` の最後、ステップ6で追加した `age` と `pop` を進めるループを、次のように **書きかえ** ます。

```js:game.js
    let danger = false;
    for (const b of balls) {
      b.age += dt; if (b.pop > 0) b.pop = Math.max(0, b.pop - dt * 4);
      if (b.age > 1.2 && b.y - b.r < DANGER && Math.abs(b.vy) < 120) danger = true;
    }
    dangerT = danger ? dangerT + dt : Math.max(0, dangerT - dt * 2);
    if (dangerT > 2.2) gameOver();
```

「玉の上端（`b.y - b.r`）が赤い線 `DANGER` より上にある」だけで判定すると、落としたばかりの玉はかならず線より上（`DROP_Y` = 62）から落ちてくるので、すぐゲームオーバーになってしまいます。そこで3つの条件をすべて満たすときだけ「危ない」とします。

- `b.age > 1.2` … 落としてから 1.2 秒以上たっている（落下中の玉は数えない）
- `b.y - b.r < DANGER` … 上端が赤い線をこえている
- `Math.abs(b.vy) < 120` … 縦にほとんど動いていない（はね上がった途中の玉は数えない）

さらに、危ない状態が **続いた時間** `dangerT` を数えます。危ない間は `dt` ずつ増え、そうでなければ2倍の速さで 0 に戻ります。`dangerT` が 2.2 秒をこえたらゲームオーバーです。一瞬はみ出しただけでは終わらず、その間に合体させて **ピンチを切りぬける** チャンスがあるのが、このゲームのおもしろいところです。

## 警告を表示する

`draw()` の最後、玉を描くループの **下** に追加します。

```js:game.js
    if (dangerT > 0.3 && state === 'play') {
      ctx.fillStyle = '#ff6b78'; ctx.font = 'bold 16px system-ui, sans-serif'; ctx.textAlign = 'center';
      ctx.fillText('あふれそう！', W / 2, DANGER - 18);
    }
```

`ctx.font` で文字の太さ・大きさ・書体を決め、`textAlign = 'center'` で `fillText()` に渡した x が文字のまん中になるようにします。ステップ1で書いた赤い点線は `dangerT > 0` のとき `Math.sin(time * 20)` で点滅するので、ここで警告が出る少し前から点線がちかちかしはじめます。

> [!CHECK] 動作チェック
> - 同じ場所にどんどん落として玉を積み上げると、赤い点線が点滅し、少しして「あふれそう！」が出る
> - そのまま2秒ほどたつと玉が止まり、「ゲームオーバー」とスコア、いちばん大きかったほしだまの名前が出る
> - 「もう一度」で箱が空になり、SCORE が 0 から再スタートする
> - ヘッダーの BEST がスコアで更新され、ページを再読み込みしても残っている
> - 落としたばかりの玉が赤い線の上を通っても、すぐにはゲームオーバーにならない
