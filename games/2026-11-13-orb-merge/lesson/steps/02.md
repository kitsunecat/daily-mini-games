## このステップのゴール

**ゲームループ** を作って星をまたたかせ、主役の **ほしだま** を描けるようにします。ほしだまは大きさが11段階あり、段階ごとに色や模様がちがいます。スタートすると箱の上に「今から落とすほしだま」が、ヘッダーの NEXT に「次のほしだま」が表示されるところまで進めます。

## ほしだまの表を作る

`const LEFT = 12, ...` の行の **下** に、3つの表（配列）を追加します。

```js:game.js
  const RADII = [13, 17, 23, 29, 36, 44, 53, 62, 72, 83, 96];
  const NAMES = ['ちり', 'すな', 'いし', 'こおり', 'つき', 'みずぼし', 'あかぼし', 'わくせい', 'わっか', 'あおぼし', 'たいよう'];
  const COLORS = [
    ['#d9d4ff', '#8c84c9'], ['#ffd0e6', '#d4729f'], ['#c9f1ff', '#4aa7d4'], ['#e8fff1', '#59c28a'],
    ['#fff6c9', '#d8b84a'], ['#bfe0ff', '#3a6fd8'], ['#ffc2a8', '#d6542e'], ['#f3dcb6', '#b07a3c'],
    ['#ffe9b3', '#c9902e'], ['#c6f0ff', '#2f8fc9'], ['#fff3a0', '#ff8a1c']
  ];
```

ほしだまの「段階」を **レベル（`lv`）** と呼び、0〜10 の番号で表します。どの表も「`lv` 番目がそのレベルの値」という並びになっています。

- `RADII[lv]` … 半径。0 番の「ちり」は 13、10 番の「たいよう」は 96 です
- `NAMES[lv]` … 名前。ゲームオーバー画面で「いちばん大きかったのは〇〇」と出すのに使います（ステップ7）
- `COLORS[lv]` … `[明るい色, 基本の色]` の2色の組。立体的に見せるグラデーションに使います

こうして **データを表にまとめておく** と、描く処理や合体の処理は「`lv` を1つ増やす」だけで次の段階に進めます。

## 変数と reset()

`let dangerT = 0, time = 0;` の行を、次のように **書きかえ** ます。

```js:game.js
  let cur = 0, nxt = 0, dangerT = 0, time = 0;
```

`cur` は今から落とすほしだまのレベル、`nxt` はその次のレベルです。

`window.addEventListener('resize', resize);` の **下** に、`randLevel()` と `reset()` を追加し、`start()` を **書きかえ** ます。

```js:game.js
  function randLevel() { const r = Math.random(); return r < 0.3 ? 0 : r < 0.55 ? 1 : r < 0.78 ? 2 : r < 0.93 ? 3 : 4; }

  function reset() {
    cur = randLevel(); nxt = randLevel();
    drawNext();
  }

  function start() {
    reset(); state = 'play'; overlay.classList.add('hidden');
  }
```

`randLevel()` は落ちてくるほしだまのレベルを **かたよりのある乱数** で決めます。`Math.random()` は 0 以上 1 未満の数を返すので、

- 0〜0.3 なら レベル0（30%）、0.3〜0.55 なら レベル1（25%）、0.55〜0.78 なら レベル2（23%）、0.78〜0.93 なら レベル3（15%）、残りが レベル4（7%）

になります。落ちてくるのは小さい5種類だけで、それより大きいほしだまは **合体でしか作れない** ようにするのがこのジャンルのお約束です。`a ? b : c ? d : e` は「三項演算子」をつなげた書き方で、`if` を何段も書くかわりに使っています。

## ほしだまを描く drawOrb()

`function start() { ... }` の **下** に、2つの関数を追加します。

```js:game.js
  function drawOrb(c, x, y, r, lv) {
    const [hi, base] = COLORS[lv];
    const g = c.createRadialGradient(x - r * 0.35, y - r * 0.4, r * 0.1, x, y, r);
    g.addColorStop(0, '#fff'); g.addColorStop(0.25, hi); g.addColorStop(1, base);
    if (lv === 10) { c.save(); c.shadowColor = '#ffb020'; c.shadowBlur = 18; }
    c.fillStyle = g; c.beginPath(); c.arc(x, y, r, 0, Math.PI * 2); c.fill();
    if (lv === 10) c.restore();
    if (lv === 8) { // ring
      c.strokeStyle = 'rgba(255,240,200,.85)'; c.lineWidth = r * 0.12;
      c.beginPath(); c.ellipse(x, y, r * 1.0, r * 0.28, -0.35, 0, Math.PI * 2); c.stroke();
    }
    if (lv === 4 || lv === 7) { // craters
      c.fillStyle = 'rgba(0,0,0,.12)';
      c.beginPath(); c.arc(x + r * 0.3, y + r * 0.2, r * 0.18, 0, 7); c.fill();
      c.beginPath(); c.arc(x - r * 0.25, y + r * 0.42, r * 0.11, 0, 7); c.fill();
    }
    // face
    c.fillStyle = 'rgba(40,20,60,.75)';
    const er = Math.max(1.4, r * 0.08);
    c.beginPath(); c.arc(x - r * 0.28, y - r * 0.02, er, 0, 7); c.arc(x + r * 0.28, y - r * 0.02, er, 0, 7); c.fill();
    c.strokeStyle = 'rgba(40,20,60,.75)'; c.lineWidth = Math.max(1, r * 0.06);
    c.beginPath(); c.arc(x, y + r * 0.12, r * 0.16, 0.15 * Math.PI, 0.85 * Math.PI); c.stroke();
  }

  function drawNext() {
    nctx.clearRect(0, 0, 64, 64);
    const r = Math.min(28, RADII[nxt] * 1.2);
    drawOrb(nctx, 32, 32, r, nxt);
  }
```

`drawOrb()` は、最初の引数 `c` に **どの Canvas に描くか**（コンテキスト）を受け取ります。こうしておくと、同じ関数でメインの Canvas（`ctx`）にもヘッダーの NEXT（`nctx`）にも描けます。

- **立体感** … `createRadialGradient(内側の円, 外側の円)` は円形のグラデーションです。内側の円を中心から **左上にずらす** ことで、左上から光が当たったように見えます。色は「白 → 明るい色 → 基本の色」の順に変えます
- **たいよう（lv 10）だけ光る** … `shadowColor` と `shadowBlur` で、塗った形のまわりにぼんやりした光をつけます。影の設定はほかの描画にも残ってしまうので、`c.save()` と `c.restore()` で前後をはさみ、たいようを塗るときだけ有効にしています
- **わっか（lv 8）は輪** … `ellipse(中心x, 中心y, 横の半径, 縦の半径, 回転, 開始角, 終了角)` で、少し傾けたつぶれた楕円を描きます
- **つき・わくせい（lv 4・7）はクレーター** … うすい黒の小さな円を2つ重ねます
- **顔** … 目は小さな円を2つ、口は `arc()` で円の下半分の一部だけ（`0.15π`〜`0.85π`）を線で描きます。大きさをすべて `r` の何倍かで書いているので、どの大きさのほしだまでも同じ顔になります

`arc()` の最後の `7` は「`Math.PI * 2`（約 6.28）より大きければ一周」という手抜きの書き方です。

`drawNext()` は小さな Canvas を `clearRect()` で消してから、まん中に次のほしだまを描きます。大きい玉が来ても枠からはみ出さないように、半径は最大 28 に抑えています。

## draw() に「今のほしだま」を追加する

`draw()` の最後、赤い点線を描いた行の **下** に追加します。

```js:game.js
    // aim
    if (state === 'play') {
      drawOrb(ctx, W / 2, DROP_Y, RADII[cur], cur);
    }
```

プレイ中だけ、箱のまん中の上（`DROP_Y`）に今のほしだまを浮かべます。

## ゲームループ

`draw()` 関数の **下**（`startBtn.addEventListener(...)` の上）に追加します。

```js:game.js
  let last = performance.now();
  function loop(now) {
    const dt = Math.min(0.033, (now - last) / 1000); last = now; time += dt;
    draw();
    requestAnimationFrame(loop);
  }
```

**`requestAnimationFrame(関数)`** は「次に画面を書きかえるタイミングで、この関数を呼んで」とブラウザに頼む命令です。`loop()` の最後で自分自身をまた頼むことで、1秒に約60回 `loop()` が呼ばれ続けます。これが **ゲームループ** です。

- 呼ばれた関数には、そのときの時刻（ミリ秒）が `now` として渡されます。前回の時刻 `last` との差を 1000 で割ると、前のフレームから何秒たったか（**`dt`**）が分かります
- `Math.min(0.033, ...)` で `dt` を最大 0.033 秒に抑えています。タブを裏に回して戻ったときなどに `dt` が何秒にもなると、玉が一気に動いて壁をすり抜けてしまうからです
- `time` に `dt` を足していくので、`draw()` の星の明るさ（`Math.sin(time * 2 + i)`）が少しずつ変わって **またたき** はじめます

最後の1行を **書きかえ** ます。

```js:game.js
  reset(); resize(); requestAnimationFrame(loop);
```

最初に `reset()` を呼んでおくので、タイトル画面のうちから NEXT にほしだまが表示されます。

> [!CHECK] 動作チェック
> - タイトル画面の後ろで、星がゆっくりまたたいている
> - ヘッダーの NEXT に、顔のついた小さなほしだまが表示されている
> - スタートを押すと、箱の上のまん中にほしだまが浮かぶ。再読み込みするたびに色や大きさが変わる
> - ためしに `drawOrb(ctx, W / 2, DROP_Y, RADII[cur], cur)` の `cur` を `8` や `10` にすると、輪のついた「わっか」や光る「たいよう」が見える（確かめたら元に戻す）
