## このステップのゴール

このゲームの主役の仕組み、**同じ大きさのほしだまがふれ合うと合体して、ひとつ大きくなる** を作ります。合体するとスコアが入り、生まれた玉が「ぽんっ」と一瞬ふくらむようにします。いちばん大きい「たいよう」どうしが合体すると、両方とも消えてボーナスです。

## スコアの表と変数

`const GRAV = 1500, SUB = 8;` の **上** に追加します。

```js:game.js
  const TRI = [1, 3, 6, 10, 15, 21, 28, 36, 45, 55, 66];
```

`TRI[lv]` は、レベル `lv` の玉が **生まれたときにもらえる点** です。1, 3, 6, 10…は **三角数**（1, 1+2, 1+2+3, …）で、大きい玉ほど点が急に増えます。小さく何度も合体するより、大きく育てたほうが得になるようにしています。

`let balls = [], state = 'title';` の行を、次のように **書きかえ** ます。

```js:game.js
  let balls = [], score = 0, state = 'title';
```

`reset()` を、スコアも 0 に戻すように **書きかえ** ます。

```js:game.js
  function reset() {
    balls = []; score = 0; cooldown = 0;
    cur = randLevel(); nxt = randLevel(); aimX = W / 2;
    scoreEl.textContent = 0; drawNext();
  }
```

`function step(dt) {` の **上** に、スコアを足す小さな関数を追加します。

```js:game.js
  function addScore(n) { score += n; scoreEl.textContent = score; }
```

点を足すたびにヘッダーの表示も書きかえるので、あちこちで `scoreEl.textContent = ...` と書かずに済みます。

## step() に合体を追加する

`step()` の、玉どうしを調べるループのあたりを書きかえます。変わる場所が多いので、`step()` 全体を載せます。

```js:game.js
  function step(dt) {
    const h = dt / SUB;
    for (let s = 0; s < SUB; s++) {
      for (const b of balls) {
        b.vy += GRAV * h;
        b.x += b.vx * h; b.y += b.vy * h;
        if (b.x - b.r < LEFT) { b.x = LEFT + b.r; b.vx = Math.abs(b.vx) * 0.2; }
        if (b.x + b.r > RIGHT) { b.x = RIGHT - b.r; b.vx = -Math.abs(b.vx) * 0.2; }
        if (b.y + b.r > FLOOR) { b.y = FLOOR - b.r; b.vy = -Math.abs(b.vy) * 0.1; b.vx *= 0.98; }
      }
      const merged = new Set(), born = [];
      for (let i = 0; i < balls.length; i++) {
        const a = balls[i];
        if (merged.has(a.id)) continue;
        for (let j = i + 1; j < balls.length; j++) {
          const b = balls[j];
          if (merged.has(b.id)) continue;
          const dx = b.x - a.x, dy = b.y - a.y, rr = a.r + b.r;
          const d2 = dx * dx + dy * dy;
          if (d2 >= rr * rr) continue;
          const d = Math.sqrt(d2) || 0.001;
          if (a.lv === b.lv) {
            merged.add(a.id); merged.add(b.id);
            const mx = (a.x + b.x) / 2, my = (a.y + b.y) / 2;
            if (a.lv === RADII.length - 1) {
              addScore(100);
            } else {
              const lv = a.lv + 1;
              born.push({ id: idSeq++, x: mx, y: my, vx: (a.vx + b.vx) / 2, vy: Math.min(a.vy, b.vy) / 2, r: RADII[lv], lv, age: 1, pop: 1 });
              addScore(TRI[lv]);
            }
            break;
          }
          const nx = dx / d, ny = dy / d, over = rr - d;
          const ma = a.r * a.r, mb = b.r * b.r, tot = ma + mb;
          a.x -= nx * over * (mb / tot); a.y -= ny * over * (mb / tot);
          b.x += nx * over * (ma / tot); b.y += ny * over * (ma / tot);
          const rv = (b.vx - a.vx) * nx + (b.vy - a.vy) * ny;
          if (rv < 0) {
            const imp = -(1.15) * rv / (1 / ma + 1 / mb);
            a.vx -= imp * nx / ma; a.vy -= imp * ny / ma;
            b.vx += imp * nx / mb; b.vy += imp * ny / mb;
            // tangential friction
            const tx = -ny, ty = nx, tv = (b.vx - a.vx) * tx + (b.vy - a.vy) * ty;
            const fi = tv * 0.05 / (1 / ma + 1 / mb);
            a.vx += fi * tx / ma; a.vy += fi * ty / ma;
            b.vx -= fi * tx / mb; b.vy -= fi * ty / mb;
          }
        }
      }
      if (merged.size) balls = balls.filter(b => !merged.has(b.id)).concat(born);
      for (const b of balls) { b.vx *= 0.999; b.vy *= 0.999; }
    }
    for (const b of balls) {
      b.age += dt; if (b.pop > 0) b.pop = Math.max(0, b.pop - dt * 4);
    }
  }
```

### 同じレベルなら、押し返すかわりに合体

重なりを見つけたあと、押し返しの計算の **前に** `if (a.lv === b.lv) { ... }` を入れました。レベルが同じなら、

1. 2つの玉の `id` を `merged`（合体して消える玉の名簿）に入れる
1. 2つのまん中の位置 `mx`・`my` を求める
1. 「たいよう」（`RADII.length - 1` ＝ 10）どうしなら、新しい玉は作らずにボーナス 100 点。それ以外なら、**レベルを1つ上げた玉** をまん中に作って `born`（新しく生まれる玉の名簿）に入れ、`TRI[lv]` 点を足す
1. `break` で `j` のループをぬける。a はもう消えることが決まったので、ほかの玉と調べる必要はありません

新しい玉の速さは2つの平均にしています。縦の速さだけ `Math.min(a.vy, b.vy) / 2` と小さめにしているのは、合体した玉が勢いよく下にめりこまないようにするためです。`pop: 1` でふくらむ演出をスタートし、`age: 1` で「落としたばかりの玉」あつかいにならないようにしています（ステップ7で使います）。

### その場で消さずに、名簿にためてからまとめて処理

ループの途中で `balls` から玉を消したり足したりすると、番号 `i`・`j` がずれて、調べ忘れや二重の処理が起きてしまいます。そこで、

- 合体する玉は `merged` に、生まれる玉は `born` にためておく
- ループの最初で `merged.has(a.id)` / `merged.has(b.id)` を確かめ、**もう合体が決まった玉は飛ばす**。こうしないと、3つの同じ玉がくっついていたとき、1つの玉が2回合体してしまいます
- 全部調べ終わってから、`filter()` で `merged` に入っている玉を取り除き、`concat(born)` で新しい玉を足す

という順にしています。**`Set`** は「同じものが1つだけ入る入れ物」で、`add()` で入れて `has()` で入っているか調べられます。配列で探すより手軽で速いので、名簿にぴったりです。

### age と pop を進める

サブステップのループの **外**（1フレームに1回）で、すべての玉の `age` に `dt` を足し、`pop` を 1 秒に 4 ずつ減らします。`pop` は 1 から 0 まで 0.25 秒で戻ります。

## draw() で合体した玉をふくらませる

`draw()` の玉を描くループを、次のように **書きかえ** ます。

```js:game.js
    for (const b of balls) {
      const r = b.r * (1 + b.pop * 0.15);
      drawOrb(ctx, b.x, b.y, r, b.lv);
    }
```

`pop` が 1 のときは 15% 大きく描き、0 に向かって元の大きさに戻ります。当たり判定に使う `b.r` は変えず、**見た目だけ** ふくらませているのがポイントです。

> [!CHECK] 動作チェック
> - 同じ色・同じ大きさのほしだまがふれ合うと、2つが消えて、ひとつ大きな玉がまん中に生まれる
> - 生まれた玉が一瞬ぽんっとふくらむ
> - 生まれた玉が、となりの同じ大きさの玉にふれると、続けて合体する（連鎖）
> - 合体するたびにヘッダーの SCORE が増え、大きい玉ができるほど増え方が大きい
> - 3つ同じ玉がくっついても、エラーにならず2つだけが合体する
