## このステップのゴール

3つのファイルを用意して、ゲーム画面の土台を作ります。上に「SCORE・BEST」、その下に「レベル・せり上がりバー・コンボ表示」、まん中にゲームを描く **Canvas**（キャンバス）とその上に重ねるタイトル画面（オーバーレイ）、いちばん下にメッセージと「せり上げ」ボタンを置きます。スタートを押すと、**よこ 8 × たて 12** の盤面のわくと、赤い点線の「天井」が出るところまで作ります。

完成すると、こんなゲームになります。

- 盤面の下のほうに、色とりどりの **キューブ** が積まれている
- となり合った **同じ色のキューブ（2個以上）** をタップすると、つながっている分がまとめてはじけて消え、上のキューブが落ちてくる
- 点数は **消した数の2乗**。大きなかたまりを育ててから消すほど高得点。続けて消すと **コンボ** で倍率アップ
- **6個以上** まとめて消すと **ばくだん** が出現。タップするとまわり 3 × 3 をまとめて消す
- 時間がたつと下から新しい列が **せり上がって** くる。キューブが天井をこえたらゲームオーバー
- ハイスコアはブラウザに保存される

## game.js

JavaScript はまず「画面の大きさに合わせて Canvas を用意し、盤面のわくを描きつづける」ところまでを書きます。

```js:game.js
(() => {
  'use strict';
  const $ = (id) => document.getElementById(id);
  const cv = $('cv'), ctx = cv.getContext('2d');
  const scoreEl = $('score'), bestEl = $('best'), levelEl = $('level'), fillEl = $('risefill'), comboEl = $('combo'), msgEl = $('msg');
  const overlay = $('overlay'), ovTitle = $('ov-title'), ovText = $('ov-text'), startBtn = $('start'), pushBtn = $('pushbtn');
  const COLS = 8, ROWS = 12;

  // ---------- state ----------
  let state = 'title';    // title | play | over

  // ---------- layout ----------
  let W = 0, H = 0, S = 0, ox = 0, oy = 0, dpr = 1;
  function resize() {
    const r = cv.getBoundingClientRect();
    dpr = Math.min(window.devicePixelRatio || 1, 2);
    W = r.width; H = r.height;
    cv.width = Math.round(W * dpr); cv.height = Math.round(H * dpr);
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
    S = Math.floor(Math.min((W - 16) / COLS, (H - 20) / (ROWS + 0.6)));
    ox = Math.round((W - S * COLS) / 2);
    oy = Math.round((H - S * ROWS) / 2) - Math.round(S * 0.2);
  }
  window.addEventListener('resize', resize);

  // ---------- game logic ----------
  function start() {
    state = 'play';
    overlay.classList.add('hidden');
    msgEl.textContent = '同じ色をまとめて消そう';
  }

  // ---------- input ----------
  startBtn.addEventListener('click', start);

  // ---------- drawing ----------
  function rr(x, y, w, h, r) {
    ctx.beginPath();
    ctx.moveTo(x + r, y); ctx.arcTo(x + w, y, x + w, y + h, r); ctx.arcTo(x + w, y + h, x, y + h, r);
    ctx.arcTo(x, y + h, x, y, r); ctx.arcTo(x, y, x + w, y, r); ctx.closePath();
  }
  function draw() {
    ctx.clearRect(0, 0, W, H);
    // board bg
    ctx.fillStyle = '#1d2e4d'; rr(ox - 6, oy - 6, S * COLS + 12, S * ROWS + 12, 12); ctx.fill();
    ctx.strokeStyle = 'rgba(255,255,255,.04)'; ctx.lineWidth = 1;
    for (let c = 1; c < COLS; c++) { ctx.beginPath(); ctx.moveTo(ox + c * S, oy); ctx.lineTo(ox + c * S, oy + ROWS * S); ctx.stroke(); }
    // ceiling line
    ctx.strokeStyle = 'rgba(255,107,122,.55)';
    ctx.lineWidth = 3; ctx.setLineDash([8, 6]);
    ctx.beginPath(); ctx.moveTo(ox - 6, oy); ctx.lineTo(ox + COLS * S + 6, oy); ctx.stroke(); ctx.setLineDash([]);
  }

  // ---------- loop ----------
  function frame() {
    draw();
    requestAnimationFrame(frame);
  }

  resize();
  requestAnimationFrame(frame);
})();
```

### 全体を (() => { ... })(); で囲む

ファイル全体を「すぐ実行される関数」で囲むと、中で作った変数がページ全体（グローバル）に漏れません。`'use strict';` は、うっかりミスをエラーとして教えてくれるモードです。

`const $ = (id) => document.getElementById(id);` は、何度も書く `document.getElementById` を短く書くための小さな関数です。`$('cv')` で Canvas の要素が取れます。`cv.getContext('2d')` で取り出した `ctx` が「絵筆」で、このあとの描画はすべて `ctx.〇〇` で行います。

`COLS = 8`・`ROWS = 12` は盤面の **列の数（よこ）** と **行の数（たて）** です。数字をコードに直接書かず、名前をつけた定数にしておくと、あとで盤面の大きさを変えたくなったときに1か所直すだけで済みます。

### resize() … Canvas の中身のピクセル数とマスの大きさを決める

1. `cv.getBoundingClientRect()` で、Canvas の実際の大きさ（CSS ピクセル）を測り、`W`・`H` に入れます
2. `devicePixelRatio`（dpr）は、高精細な画面で「CSS の 1px が実際は何ドットか」を表す数です。Canvas の中身のピクセル数（`cv.width`・`cv.height`）を dpr 倍にすると、ぼやけずにくっきり描けます。大きすぎると重くなるので、`Math.min(..., 2)` で2倍までにしています
3. `ctx.setTransform(dpr, 0, 0, dpr, 0, 0)` は「これから描くものを全部 dpr 倍する」設定です。これで、このあとは CSS ピクセルの座標のまま描けば画面にぴったり合います。`cv.width` を設定すると Canvas の設定がリセットされるので、そのすぐあとに書きます
4. `S` は **1マスの大きさ** です。横は `(W - 16) / COLS`、縦は `(H - 20) / (ROWS + 0.6)` で計算し、**小さいほう** を使えば盤面がはみ出しません。縦に `+ 0.6` マス分よけいに取っているのは、盤面の下に「次の列」をちらっと見せる場所を作るためです（ステップ2）
5. `ox`・`oy` は盤面の左上の位置です。画面の幅から盤面の幅を引いて半分にすると、まん中に置けます。`oy` は少しだけ上にずらしています

ウィンドウの大きさが変わったら（スマホを横にしたときなど）、もう一度 `resize()` を呼びます。

### draw() と frame() … 毎フレーム描きなおす

- `rr()` は角の丸い四角の **形（パス）** を作る自作の関数です。`arcTo` で4つの角を丸めています。形を作るだけなので、そのあと `ctx.fill()`（ぬる）や `ctx.stroke()`（線を引く）を呼んで初めて画面に出ます
- 盤面のわくは、盤面より 6px ずつ大きい角丸四角を紺色でぬります
- 列の区切りに、うすい縦線を7本引きます。`rgba(255,255,255,.04)` は「白を 4% だけ」の色で、目立たない線になります
- 盤面の上のふち（`y = oy`）に赤い点線を引きます。これが **天井** です。`ctx.setLineDash([8, 6])` で「8px 描いて 6px あける」点線になり、引き終わったら `setLineDash([])` で実線にもどします

`frame()` は `draw()` を呼んだあと `requestAnimationFrame(frame)` で「次に画面を書きかえるタイミングで、もう一度 frame を呼んで」とブラウザに頼みます。これで1秒間に約60回、描きなおしが続きます。

### state … ゲームの状態

`state` はゲームの状態で、`'title'`（タイトル画面）・`'play'`（プレイ中）・`'over'`（ゲームオーバー）のどれかになります。今はスタートボタンで `'play'` にして、オーバーレイに `hidden` クラスをつけて隠すだけです。
