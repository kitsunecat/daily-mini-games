## このステップのゴール

キューブを消すと **点数** が入るようにします。点数は **消した数の2乗**。続けてすばやく消すと **コンボ** になって倍率が上がります。あわせて、消えたキューブが **かけらになってはじけ飛ぶ** 演出と、取った点数が **ふわっと浮かぶ** 文字も作ります。

## 状態を追加する

`// ---------- state ----------` の `let state = ...` の **下**（`let lastT = 0;` の上）に追加します。

```js:game.js
  let score = 0, level = 1, rise = 0, popped = 0;
  let combo = 0, comboTimer = 0;
  let particles = [], floats = [];
```

- `score` は点数、`popped` は消したキューブの合計です
- `level`（レベル）と `rise`（せり上がりの進み具合）はステップ5・7で使います。先に作っておきます
- `combo` はいまのコンボ数、`comboTimer` は「あと何秒以内に消せばコンボが続くか」です
- `particles` ははじけ飛ぶかけら、`floats` は浮かぶ文字のリストです

## start() でリセットする

`start()` を次のように **書きかえ** ます（2行と `updateHud();` が増えています）。

```js:game.js
  function start() {
    cols = Array.from({ length: COLS }, () => []);
    score = 0; level = 1; rise = 0; popped = 0; combo = 0; comboTimer = 0;
    particles = []; floats = [];
    for (let i = 0; i < START_ROWS; i++) { newPreview(); pushRow(); }
    newPreview();
    state = 'play';
    overlay.classList.add('hidden');
    msgEl.textContent = '同じ色をまとめて消そう';
    updateHud();
  }
```

ゲームをやりなおすときに前回の値が残らないよう、スタートのたびに全部の状態を初期値にもどします。

## tap() に点数・コンボ・演出を足す

`tap()` を次のように **書きかえ** ます。`const n = targets.length;` から下が変わっています。

```js:game.js
  function tap(c, r) {
    if (state !== 'play') return;
    if (c < 0 || c >= COLS || r < 0 || r >= cols[c].length) return;
    const cell = cols[c][r];
    const targets = group(c, r);
    if (targets.length < 2) {
      cell.pop = 1; // wiggle
      msgEl.textContent = '1個だけでは消せないよ';
      return;
    }
    const n = targets.length;
    combo = comboTimer > 0 ? combo + 1 : 1;
    comboTimer = 1.6;
    const mult = 1 + (combo - 1) * 0.5;
    const pts = Math.round(n * n * 10 * mult);
    // particles
    for (const [cc, rr] of targets) {
      const t = cols[cc][rr];
      const x = ox + cc * S + S / 2, y = rowBottomY(t.vy) - S / 2;
      const col = PALETTE[t.k][0];
      for (let i = 0; i < 5; i++) {
        const a = Math.random() * Math.PI * 2, sp = 60 + Math.random() * 160;
        particles.push({ x, y, vx: Math.cos(a) * sp, vy: Math.sin(a) * sp - 80, life: 0.6 + Math.random() * 0.3, col, s: S * 0.18 });
      }
    }
    const fx = ox + c * S + S / 2, fy = rowBottomY(cell.vy) - S / 2;
    addFloat(fx, fy, '+' + pts, '#fff');
    // remove (mark then filter)
    const kill = new Set(targets.map(([cc, rr]) => cc * 100 + rr));
    for (let cc = 0; cc < COLS; cc++) cols[cc] = cols[cc].filter((_, rr) => !kill.has(cc * 100 + rr));
    popped += n;
    addScore(pts);
    msgEl.textContent = combo > 1 ? `${combo} コンボ！` : `${n}個 消した！`;
  }
```

### 点数とコンボのしくみ

- **コンボ**: 前に消してから `comboTimer`（1.6 秒）がまだ残っていれば `combo + 1`、切れていれば 1 から数えなおします。消すたびにタイマーを 1.6 秒にもどします
- **倍率**: 1コンボ目は 1 倍、2コンボ目は 1.5 倍、3コンボ目は 2 倍…と 0.5 ずつ増えます
- **点数**: `n * n * 10`。2個なら 40 点、4個なら 160 点、8個なら 640 点です。2個ずつ4回消すと 160 点なのに、8個まとめて消すと 640 点。**2乗** にすることで「すぐ消さずに、大きなかたまりを育ててから消す」という作戦が生まれます。数字1つでゲームの遊び方が変わる、ゲームデザインの面白いところです

### かけら（パーティクル）

消える1個ごとに、5つのかけらを作ります。

- かけらの出発点は、消えるキューブのまん中です。**消す前** に位置を計算する必要があるので、`filter` で消すより前に書きます
- `a` はランダムな向き（0〜360度をラジアンで）、`sp` はランダムな速さです。`Math.cos(a) * sp` と `Math.sin(a) * sp` で、その向きの速度を横（vx）と縦（vy）に分けます
- 縦の速度から 80 引いているのは、少し **上向き** にはじけさせるためです（Canvas は上がマイナス）
- `life` は残り寿命（秒）です。0.6〜0.9 秒で消えます

> [!NOTE]
> かけらのオブジェクトにも `vy` という名前がありますが、こちらは「縦の速度」です。キューブの `vy`（見た目の高さ）とは別ものなので気をつけてください。

## 点数を足す関数と、表示を更新する関数

`tap()` の **下** に追加します。

```js:game.js
  function addScore(p) {
    score += p;
    updateHud();
  }
  const addFloat = (x, y, text, col) => floats.push({ x, y, text, col, life: 1 });

  function updateHud() {
    scoreEl.textContent = score;
    levelEl.textContent = 'Lv ' + level;
  }
```

- 点数を足すときは、必ず `addScore()` を通すことにします。こうしておくと、ステップ7で「点数が増えたらレベルアップ」、ステップ8で「ハイスコア更新」を、この関数に足すだけで実現できます
- `updateHud()` は、画面上の数字（HUD = ヘッドアップディスプレイ）を今の値に書きかえます
- `addFloat()` は浮かぶ文字を1つ足します。寿命 `life` は 1 秒です

## かけらと文字を動かす

`frame()` を次のように **書きかえ** ます。

```js:game.js
  function frame(t) {
    const dt = Math.min(0.05, (t - lastT) / 1000 || 0); lastT = t;
    if (state === 'play') {
      if (comboTimer > 0) { comboTimer -= dt; if (comboTimer <= 0) combo = 0; }
    }
    for (const col of cols) col.forEach((cell, r) => {
      if (cell.vy > r) cell.vy = Math.max(r, cell.vy - dt * 14 * Math.max(1, cell.vy - r));
      if (cell.pop > 0) cell.pop = Math.max(0, cell.pop - dt * 4);
    });
    particles = particles.filter((p) => { p.life -= dt; p.x += p.vx * dt; p.y += p.vy * dt; p.vy += 600 * dt; return p.life > 0; });
    floats = floats.filter((f) => { f.life -= dt; f.y -= 40 * dt; return f.life > 0; });
    comboEl.textContent = combo > 1 ? `${combo} COMBO` : '';
    draw();
    requestAnimationFrame(frame);
  }
```

- コンボのタイマーを `dt` ずつ減らし、0 になったらコンボを 0 にもどします
- かけらは「位置に速度 × dt を足す」で動かし、さらに縦の速度に `600 * dt` を足します。これが **重力** で、かけらは放物線をえがいて落ちていきます
- 文字は1秒に 40px ずつ上へ動かします
- `filter` の中で寿命を減らして動かし、`return p.life > 0` で「まだ生きているものだけ残す」ようにしています。動かすのと、消えたものを取りのぞくのを1回のループでまとめてやる書き方です
- 2コンボ以上のときは、右上に「〇 COMBO」と出します

## かけらと文字を描く

`draw()` の最後（`ctx.restore();` の **下**、`draw()` の閉じかっこ `}` の上）に追加します。

```js:game.js
    // particles
    for (const p of particles) {
      ctx.globalAlpha = Math.max(0, Math.min(1, p.life * 2));
      ctx.fillStyle = p.col; ctx.fillRect(p.x - p.s / 2, p.y - p.s / 2, p.s, p.s);
    }
    ctx.globalAlpha = 1;
    ctx.textAlign = 'center'; ctx.textBaseline = 'middle';
    for (const f of floats) {
      ctx.globalAlpha = Math.min(1, f.life * 1.5);
      ctx.font = `bold ${Math.round(S * 0.5)}px system-ui, sans-serif`;
      ctx.lineWidth = 4; ctx.strokeStyle = 'rgba(0,0,0,.5)'; ctx.strokeText(f.text, f.x, f.y);
      ctx.fillStyle = f.col; ctx.fillText(f.text, f.x, f.y);
    }
    ctx.globalAlpha = 1;
```

- かけらは小さな四角です。寿命が 0.5 秒を切ると `life * 2` が 1 より小さくなり、だんだんすけて消えます
- かけらは盤面の外まで飛ぶので、`clip()` を `restore()` で解除した **あと** に描きます
- 文字は `textAlign = 'center'`・`textBaseline = 'middle'` にすると、指定した点が文字のまん中になります
- `strokeText`（ふち）を先に、`fillText`（中身）をあとに描くと、ふちどりのある読みやすい文字になります

> [!CHECK] 動作チェック
> - キューブを消すと、色つきのかけらがはじけ飛んで落ちていき、タップした場所に「+40」のような点数が浮かんで消える
> - 右上の SCORE が増える。2個で 40、3個で 90、4個で 160 点
> - 1.6 秒以内に続けて消すと、下のメッセージに「2 コンボ！」、右上に「2 COMBO」と出て、点数が 1.5 倍になる
> - しばらく消さずに待つと「COMBO」の表示が消える
