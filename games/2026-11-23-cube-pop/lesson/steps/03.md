## このステップのゴール

キューブをタップすると、**となり合った同じ色のかたまり** がまとめて消え、上にあったキューブが **すとんと落ちてくる** ようにします。1個だけのキューブをタップしたときは消さずに「ぷるっ」とゆらします。

## つながった同じ色をさがす group()

`pushRow()` の **下** に追加します。

```js:game.js
  function group(c, r) {
    const k = cols[c][r].k, seen = new Set([c * 100 + r]), out = [[c, r]];
    for (let i = 0; i < out.length; i++) {
      const [cc, rr] = out[i];
      for (const [dc, dr] of [[1, 0], [-1, 0], [0, 1], [0, -1]]) {
        const nc = cc + dc, nr = rr + dr;
        if (nc < 0 || nc >= COLS || nr < 0 || nr >= cols[nc].length) continue;
        if (cols[nc][nr].k !== k || seen.has(nc * 100 + nr)) continue;
        seen.add(nc * 100 + nr); out.push([nc, nr]);
      }
    }
    return out;
  }
```

c 列 r 段目のキューブから、上下左右に同じ色がつながっているキューブを **全部** 集めて、`[列, 段]` の組の配列で返します。

1. `out` は見つけたキューブのリストで、最初はタップしたキューブ1個だけです
2. `out` の先頭から順に1個ずつ取り出し、その上下左右の4マスを調べます
3. 盤面の外や、その列の高さより上（キューブが無い）は `continue` で飛ばします
4. 同じ色 `k` で、まだ見ていないキューブなら `out` の **後ろに足します**
5. 足したキューブも、ループが進むと順番に取り出されて、さらにその先が調べられます

`out` に足しながら同じ `out` をループで読んでいくので、かたまりが広がりきったところで自然にループが終わります。この「見つけたものを順番待ちの列に入れて、1つずつ広げていく」さがし方を **幅優先探索（BFS）** といいます。塗りつぶしツールと同じ考え方です。

`seen` は「もう見たマス」を覚えておく **Set**（重複しない値の集まり）です。`[列, 段]` の配列は Set で比べにくいので、`c * 100 + r` という1つの数にして入れています（段は 100 未満なので、ほかのマスと番号がかぶりません）。

## タップされたマスを消す tap()

`group()` の **下** に追加します。

```js:game.js
  function tap(c, r) {
    if (state !== 'play') return;
    if (c < 0 || c >= COLS || r < 0 || r >= cols[c].length) return;
    const cell = cols[c][r];
    const targets = group(c, r);
    if (targets.length < 2) {
      cell.pop = 1; // wiggle
      msgEl.textContent = '1個だけでは消せないよ';
      return;
    }
    const n = targets.length;
    // remove (mark then filter)
    const kill = new Set(targets.map(([cc, rr]) => cc * 100 + rr));
    for (let cc = 0; cc < COLS; cc++) cols[cc] = cols[cc].filter((_, rr) => !kill.has(cc * 100 + rr));
    msgEl.textContent = `${n}個 消した！`;
  }
```

- まず、タップした場所にキューブがあるかを調べます。空いているところなら何もしません
- かたまりが1個だけなら消さずに、`cell.pop = 1` にしてゆらす合図を出します
- 2個以上なら消します。ここで **一度に全部** 消すのがポイントです。1個ずつ `splice` で消すと、消したとたんに上のキューブの番号がずれて、次に消すはずだったキューブとちがうものを消してしまいます
- そこで「消すマスの番号を `kill` という Set に入れておく（印をつける）」→「各列を `filter` で作りなおして、印のついていないキューブだけ残す」という2段階にしています
- `filter((_, rr) => ...)` の `_` は「使わない引数」という意味の名前です。2つ目の引数 `rr` に、配列の何番目か（＝何段目か）が入ります

`filter` で配列を作りなおすと、消えたキューブより上のキューブは配列の番号が小さくなります。つまり **データの上ではもう落ちています**。ただし `vy`（見た目の高さ）は元のままなので、このままでは空中に浮いて見えます。次で、`vy` を本当の段までアニメーションさせます。

## タップした位置からマスを求める

`// ---------- input ----------` のすぐ **下**（`startBtn.addEventListener` の上）に追加します。

```js:game.js
  function cellAt(x, y) {
    const c = Math.floor((x - ox) / S);
    const r = Math.floor((oy + ROWS * S - y) / S);
    return { c, r };
  }
  cv.addEventListener('pointerdown', (e) => {
    e.preventDefault();
    if (state !== 'play') return;
    const rect = cv.getBoundingClientRect();
    const { c, r } = cellAt(e.clientX - rect.left, e.clientY - rect.top);
    tap(c, r);
  });
```

- **pointerdown** は、マウスのクリックでも指のタッチでも同じように届くイベントです。`click` より反応が速く、スマホでの連打にも向いています
- `e.clientX`・`e.clientY` は画面全体での位置なので、Canvas の左上 `rect.left`・`rect.top` を引いて Canvas の中の座標にします
- `cellAt()` は `rowBottomY()` の逆の計算です。列は左から `(x - ox) / S`、段は **盤面の下のふち** から上へ何マス分かを `(oy + ROWS * S - y) / S` で出し、`Math.floor` で切り捨てます
- 盤面の外をタップすると `c` や `r` がマイナスや大きすぎる数になりますが、`tap()` の最初のチェックではじかれます

## 毎フレーム、落下とゆれを進める

`// ---------- state ----------` の `let state = ...` の **下** に1行追加します。

```js:game.js
  let lastT = 0;
```

`frame()` を次のように **書きかえ** ます。

```js:game.js
  function frame(t) {
    const dt = Math.min(0.05, (t - lastT) / 1000 || 0); lastT = t;
    for (const col of cols) col.forEach((cell, r) => {
      if (cell.vy > r) cell.vy = Math.max(r, cell.vy - dt * 14 * Math.max(1, cell.vy - r));
      if (cell.pop > 0) cell.pop = Math.max(0, cell.pop - dt * 4);
    });
    draw();
    requestAnimationFrame(frame);
  }
```

- `requestAnimationFrame` は、呼び出す関数に **今の時刻（ミリ秒）** を `t` として渡してくれます。前のフレームの時刻 `lastT` との差を 1000 で割ると、前のフレームから何秒たったか `dt` が出ます
- 動きを「1フレームに〇px」ではなく「1秒に〇段」で書いて `dt` をかけると、60Hz の画面でも 120Hz の画面でも同じ速さで動きます
- `Math.min(0.05, ...)` で `dt` を最大 0.05 秒に制限します。別のタブを見ていて久しぶりにもどったときに、一気に動きすぎないようにするためです。最初のフレームは `lastT` が 0 で計算がおかしくなるので、`|| 0` で 0 にしています
- **落下**: 見た目の高さ `vy` が本当の段 `r` より上にあれば、下げていきます。1秒に 14 段の速さに、さらに「残りの距離」をかけているので、高いところから落ちるほど速く、着地の直前はゆっくりになります。`Math.max(r, ...)` で行きすぎないようにします
- **ゆれ**: `pop` を 1 から 0 まで、0.25 秒かけて減らします

## ゆれを描く

`draw()` の中で、キューブを描く `forEach` の中身を次のように **書きかえ** ます。

```js:game.js
      cols[c].forEach((cell) => {
        let sc = 1;
        if (cell.pop > 0) sc = 1 + Math.sin(cell.pop * Math.PI) * 0.15;
        drawCube(ox + c * S, rowBottomY(cell.vy) - S, cell.k, sc, 1);
      });
```

`pop` が 1 → 0 と減るあいだ、`Math.sin(pop * Math.PI)` は 0 → 1 → 0 と山の形に変わります。それを倍率にすると、キューブが一瞬 15% ふくらんで元にもどる「ぷるっ」という動きになります。

> [!CHECK] 動作チェック
> - 同じ色が2個以上つながっているキューブをタップすると、そのかたまりがまとめて消え、下のメッセージに「〇個 消した！」と出る
> - 消えたところの上にあったキューブが、すとんと落ちてすき間がつまる
> - 1個だけのキューブをタップすると、消えずにぷるっとゆれて「1個だけでは消せないよ」と出る
> - 何も無いところや盤面の外をタップしても、エラーにならない
