## このステップのゴール

最後に **効果音**、ばくだんやゲームオーバーのときの **画面のゆれ**、ブラウザに残る **ハイスコア** を入れて完成させます。ゲームオーバーの画面も、少し間をおいてから出るようにします。これで、元のゲームと同じものができあがります。

## ハイスコアを読みこむ

ファイルの先頭、`const overlay = ...` の行の **下** に追加します。

```js:game.js
  const BEST_KEY = 'cubepop-best';
```

`PALETTE` の `];` の **下**（`// ---------- state ----------` の上）に追加します。

```js:game.js
  let best = 0;
  try { best = parseInt(localStorage.getItem(BEST_KEY), 10) || 0; } catch (e) { best = 0; }
  bestEl.textContent = best;
```

- **localStorage** は、ブラウザに文字を保存しておける場所です。ページを閉じても、再読み込みしても消えません。`setItem(名前, 文字)` で保存し、`getItem(名前)` で読み出します
- `BEST_KEY` は保存するときの名前です。同じサイトのほかのゲームと重ならない名前にします
- 保存されるのは **文字** なので、`parseInt(..., 10)` で10進数の数にもどします。まだ何も保存されていないときは `null` が返り、`parseInt` の結果が `NaN` になるので、`|| 0` で 0 にします
- プライベートブラウズなど、localStorage が使えない環境ではエラーになることがあります。`try { ... } catch (e) { ... }` で囲んでおくと、エラーが起きてもゲームは止まりません

## ハイスコアを保存する

`updateHud()` を次のように **書きかえ** ます。

```js:game.js
  function updateHud() {
    scoreEl.textContent = score;
    levelEl.textContent = 'Lv ' + level;
    if (score > best) {
      best = score; bestEl.textContent = best;
      try { localStorage.setItem(BEST_KEY, String(best)); } catch (e) { /* ignore */ }
    }
  }
```

点数が変わるたびに BEST とくらべて、こえていればその場で保存します。ゲームオーバーのときだけ保存する方法もありますが、こうしておくとプレイ中にページを閉じても記録が残ります。

## 効果音を鳴らす beep()

`rowBottomY` の行の **下**（`// ---------- game logic ----------` の上）に追加します。

```js:game.js
  // ---------- audio ----------
  let actx = null;
  function beep(freq, dur, type = 'sine', vol = 0.12) {
    try {
      if (!actx) actx = new (window.AudioContext || window.webkitAudioContext)();
      const o = actx.createOscillator(), g = actx.createGain();
      o.type = type; o.frequency.value = freq;
      g.gain.setValueAtTime(vol, actx.currentTime);
      g.gain.exponentialRampToValueAtTime(0.001, actx.currentTime + dur);
      o.connect(g); g.connect(actx.destination);
      o.start(); o.stop(actx.currentTime + dur);
    } catch (e) { /* audio unavailable */ }
  }
```

音声ファイルを用意しなくても、**Web Audio API** でブラウザに音を作らせることができます。

- `AudioContext` は音を作る「工房」です。ブラウザは「ユーザーが画面を操作する前に音を鳴らす」ことを禁止しているので、最初に `beep()` が呼ばれたとき（＝スタートボタンを押したとき）に作ります
- **オシレーター**（`createOscillator`）は、決まった高さの音を出し続ける発振器です。`frequency` が音の高さ（Hz。440 が「ラ」）、`type` が音色です。`'sine'` はやわらかい音、`'triangle'` は少し明るい音、`'square'` はピコピコしたゲーム機の音、`'sawtooth'` はジリジリした音です
- **ゲイン**（`createGain`）は音量のつまみです。`exponentialRampToValueAtTime` で、`dur` 秒かけて音量を 0.001 まで下げると、「ポン」と自然に消える音になります
- `o → g → スピーカー（destination）` とつないで、`start()` で鳴らし、`stop()` で止める時刻を予約します
- 引数の `type = 'sine'` のような書き方は **デフォルト引数** です。省略したときにその値が使われます

## ゲームオーバーを仕上げる

`gameOver()` 全体を次のように **書きかえ** ます。

```js:game.js
  function gameOver() {
    state = 'over';
    shake = 14;
    beep(180, 0.5, 'sawtooth', 0.1);
    setTimeout(() => {
      ovTitle.textContent = 'ゲームオーバー';
      ovText.innerHTML = `スコア <b class="hl">${score}</b>（Lv ${level}）<br>消したキューブ ${popped} 個<br>ベスト ${best}`;
      startBtn.textContent = 'もう一度';
      overlay.classList.remove('hidden');
    }, 700);
  }
```

- 画面を大きくゆらし、低い音を鳴らします
- `setTimeout(関数, 700)` は「700 ミリ秒後に関数を1回実行する」命令です。すぐにオーバーレイを出すと、何が起きたか分からないままゲームが終わってしまいます。少し待って、天井をこえた盤面とゆれを見せてから結果を出します
- 結果にベストスコアも出します

## 画面をゆらす

`draw()` の最初を次のように **書きかえ** ます（`ctx.save();` と `translate` の2行を足します）。

```js:game.js
  function draw() {
    ctx.clearRect(0, 0, W, H);
    ctx.save();
    if (shake > 0) ctx.translate((Math.random() - 0.5) * shake, (Math.random() - 0.5) * shake);
```

`draw()` の最後、いちばん最後の `ctx.globalAlpha = 1;` の **下**（閉じかっこ `}` の上）に追加します。

```js:game.js
    ctx.restore();
```

- `ctx.translate(dx, dy)` は、このあと描くもの全部を `(dx, dy)` だけずらす命令です。毎フレームちがうランダムな量だけずらすと、画面がガタガタゆれて見えます
- 最初に `save()`、最後に `restore()` でかこんでおけば、ずらしは毎フレームちゃんと元にもどります

`frame()` の中、`floats = floats.filter(...)` の行の **下** に追加します。

```js:game.js
    if (shake > 0) shake = Math.max(0, shake - dt * 40);
```

`shake` を1秒に 40 ずつ減らします。ばくだん（10）なら 0.25 秒、ゲームオーバー（14）なら 0.35 秒でゆれがおさまります。

> [!CHECK] 動作チェック
> - スタート・消す・1個タップ・せり上がり・ばくだん・ゲームオーバーで、それぞれちがう音が鳴る（音が出ないときはマナーモードや音量を確認）
> - たくさんまとめて消すほど、高い音が鳴る
> - ばくだんを使うと画面が一瞬ゆれる。ゲームオーバーのときは大きくゆれてから、少しおくれて結果が出る
> - 右上の BEST が、スコアをこえるとその場で増えていく
> - ページを再読み込みしても BEST が残っている
> - 「もう一度」や Enter キーで、Lv 1・スコア 0 からやりなおせる

これで完成です！ 元の「ぽんぽんキューブ」と同じように遊べるはずです。

## 改造アイデア

> [!TIP] 空いた列を左につめる
> 列のキューブが全部消えると、その列は空いたままです。`tap()` の最後で `cols = cols.filter((col) => col.length > 0)` のように空の列を取りのぞき、足りない分を右に空の配列で足すと、キューブが左に寄るようになります。横にずれるアニメーションを付けたいなら、`vy` と同じ考え方で「見た目の列 vx」を持たせてみましょう。

> [!TIP] 色ごとに形を変える
> 色の見分けがつきにくい人のために、`drawCube()` で色の番号 `k` ごとに、キューブの上に ●・▲・★ などの小さなマークを描いてみましょう。だれでも遊びやすいゲームになります。

> [!TIP] いろいろなばくだん
> 10個以上消したら「同じ色を全部消す虹色ボール」が出る、のように特別なキューブを増やしてみましょう。`k` に `-2` を使い、`tap()` で `cell.k === -2` のときの `targets` の集め方を足すだけで作れます。

> [!TIP] 手数制限モード
> せり上がりをやめて、「30手で何点取れるか」を競うモードを作ってみましょう。`frame()` の `rise += ...` を止め、`tap()` で消すたびに手数を減らして、0 になったら `gameOver()` を呼びます。時間に追われず、じっくり大きなかたまりを育てるパズルになります。
