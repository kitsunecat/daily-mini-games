## このステップのゴール

盤面の下に **キューブを5段** 積んで表示します。さらに、その下に「次にせり上がってくる列」をうすく見せます。

このゲームでいちばん大事なのは、**盤面をどんなデータで持つか** です。ここでしっかり決めておくと、あとの「消す」「落ちる」「せり上がる」がとても簡単に書けます。

## 盤面は「列ごとの配列」で持つ

ふつうのマス目なら `board[行][列]` のような2次元配列にしたくなります。でもこのゲームでは、キューブが消えると **上のキューブが下に落ちて** すき間がつまります。そこで、

- `cols[c]` … c 列目に積まれたキューブを **下から順に** 入れた配列
- `cols[c][0]` がいちばん下、`cols[c][1]` がその上、…
- 列の高さは `cols[c].length`

という形にします。こうすると、キューブを消すときは配列から取りのぞくだけで、上のキューブは自動的に1つずつ下の番号にずれます。「落ちる」処理を自分で書かなくていいのです。

1個のキューブは `{ k, vy, pop }` というオブジェクトです。

- `k` … 色の番号（`PALETTE` の何番目の色か）
- `vy` … **見た目の高さ**（いま何段目に描くか）。ふだんは配列の番号と同じですが、落ちている最中は番号より大きくなります（ステップ3）
- `pop` … タップしたときに「ぷるっ」とゆれる演出用の数（ステップ3）

## 定数と色を追加する

ファイルの先頭の `const COLS = 8, ROWS = 12;` を **書きかえ**、そのすぐ下に `PALETTE` を **追加** します。

```js:game.js
  const COLS = 8, ROWS = 12, START_ROWS = 5;
  const PALETTE = [
    ['#ff6b7a', '#c93c4f'], ['#ffc94d', '#c8901a'], ['#5fd68a', '#2e9a58'],
    ['#55b6ff', '#2b74c2'], ['#b78cff', '#7a52c9'], ['#ff9ad5', '#c75a9c'],
  ];
```

- `START_ROWS` は、スタート時に積んでおく段の数です
- `PALETTE` は6色ぶんの `[明るい色, 暗い色]` の組です。キューブの上の面を明るい色、下のふちを暗い色でぬって立体っぽく見せます

## 状態と、ランダムな列を作る関数

`// ---------- state ----------` の部分を次のように **書きかえ** ます。

```js:game.js
  // ---------- state ----------
  let cols = [];          // cols[c] = array of cells from bottom; cell = { k: colorIndex, vy, pop }
  let preview = [];       // next row colors
  let state = 'title';    // title | play | over

  const numColors = () => 4;
  const randColor = () => Math.random() * numColors() | 0;
  const newPreview = () => { preview = Array.from({ length: COLS }, randColor); };
```

- `preview` は「次にせり上がってくる1列ぶん」の色の配列です。先に決めておくことで、プレイヤーに予告として見せられます
- `numColors()` は今使う色の数です。今は4色に固定し、ステップ7でレベルが上がると増えるようにします
- `Math.random() * numColors() | 0` は「0 以上 4 未満のランダムな **整数**」です。`| 0` で小数を切り捨てています
- `Array.from({ length: COLS }, randColor)` は、長さ 8 の配列を作り、それぞれの要素を `randColor()` の結果で埋めます

## 段の番号から画面の座標を出す

`window.addEventListener('resize', resize);` の **下** に追加します。

```js:game.js
  const rowBottomY = (vy) => oy + (ROWS - vy) * S;
```

キューブは「下から何段目か」で持っていますが、Canvas の y 座標は **上が 0 で下ほど大きい** ので、ひっくり返す計算が必要です。

- 盤面のいちばん下のふちは `oy + ROWS * S`
- `vy` 段目のキューブの **下のふち** は、そこから `vy * S` だけ上なので `oy + (ROWS - vy) * S`
- キューブの左上の y は、そこからさらに `S` 引いた `rowBottomY(vy) - S` です

`vy` に `-1` を入れると、盤面より1段下（＝次の列の位置）が出ます。

## 列を1段積む pushRow() とスタート処理

`start()` を **書きかえ**、その下に `pushRow()` を **追加** します。

```js:game.js
  // ---------- game logic ----------
  function start() {
    cols = Array.from({ length: COLS }, () => []);
    for (let i = 0; i < START_ROWS; i++) { newPreview(); pushRow(); }
    newPreview();
    state = 'play';
    overlay.classList.add('hidden');
    msgEl.textContent = '同じ色をまとめて消そう';
  }

  function pushRow() {
    for (let c = 0; c < COLS; c++) {
      for (const cell of cols[c]) cell.vy += 1;
      cols[c].unshift({ k: preview[c], vy: 0, pop: 0 });
    }
    newPreview();
  }
```

- `pushRow()` は「下から新しい列を1段差しこむ」関数です。各列で、
  1. いま積まれているキューブの見た目の高さ `vy` を1つずつ上げる
  2. `unshift()` で配列の **先頭（＝いちばん下）** に `preview` の色のキューブを入れる
- 差しこんだら `newPreview()` で次の予告を作りなおします
- `start()` では、まず `cols` を「空の配列が8本」にしてから、`pushRow()` を5回呼んで5段積みます
- `Array.from({ length: COLS }, () => [])` と書くのがポイントです。`new Array(8).fill([])` と書くと **8本とも同じ配列** を指してしまい、1列に足すと全部の列に足されてしまいます

## キューブを描く drawCube()

`rr()` の **下** に追加します。

```js:game.js
  function drawCube(x, y, k, scale, alpha) {
    const pad = S * 0.06, s = (S - pad * 2) * scale, cx = x + S / 2, cy = y + S / 2;
    const x0 = cx - s / 2, y0 = cy - s / 2;
    ctx.globalAlpha = alpha;
    const [base, dark] = PALETTE[k];
    ctx.fillStyle = dark; rr(x0, y0, s, s, s * 0.2); ctx.fill();
    ctx.fillStyle = base; rr(x0, y0, s, s * 0.88, s * 0.2); ctx.fill();
    ctx.fillStyle = 'rgba(255,255,255,.35)'; rr(x0 + s * 0.14, y0 + s * 0.1, s * 0.42, s * 0.16, s * 0.08); ctx.fill();
    ctx.globalAlpha = 1;
  }
```

- `(x, y)` はマスの左上、`k` は色の番号です。`scale` は大きさの倍率（ゆれる演出用）、`alpha` は不透明度（予告の列をうすく描く用）です
- マスのまわりに `pad` ぶんすき間をあけ、マスの **中心** `(cx, cy)` を基準に大きさ `s` の四角を置きます。中心を基準にしておくと、`scale` を変えたときにまん中から大きくなります
- 描き方は3枚重ねです。暗い色の角丸四角 → 上から 88% の高さで明るい色 → 左上に白い半とうめいのツヤ。下に暗い色が少しだけ見えるので、厚みのあるキューブに見えます
- `ctx.globalAlpha` はこのあと描くもの全部の不透明度です。描き終わったら必ず `1` にもどします

## draw() でキューブと予告の列を描く

`draw()` の最後（天井の点線を引いた行の **下**、`draw()` の閉じかっこ `}` の上）に追加します。

```js:game.js
    ctx.save();
    ctx.beginPath(); ctx.rect(ox - 6, 0, S * COLS + 12, oy + ROWS * S + 6); ctx.clip();
    // preview row (dim, rising from bottom)
    for (let c = 0; c < COLS; c++) drawCube(ox + c * S, rowBottomY(-1) - S, preview[c], 1, 0.35);
    for (let c = 0; c < COLS; c++) {
      cols[c].forEach((cell) => {
        drawCube(ox + c * S, rowBottomY(cell.vy) - S, cell.k, 1, 1);
      });
    }
    ctx.restore();
```

- `ctx.clip()` は「このあと描くものを、いまのパスの中だけに切りぬく」命令です。盤面の下のふち（+6px）より下は描かれなくなるので、予告の列は **上のほんの少しだけ** が盤面の下からのぞいて見えます。ステップ5でせり上がりを作ると、ここからじわじわ上がってきます
- `clip()` は元にもどす命令が無いので、`ctx.save()` で設定を保存してから使い、描き終わったら `ctx.restore()` でもどします
- 予告の列は `alpha` を `0.35` にしてうすく描きます
- キューブは列ごとに `forEach` で回し、`cell.vy` から y 座標を出して描きます

## タイトル画面の後ろにも盤面を出す

ファイルの最後の `resize();` と `requestAnimationFrame(frame);` の **間** に追加します。

```js:game.js
  resize();
  newPreview();
  cols = Array.from({ length: COLS }, () => []);
  for (let i = 0; i < START_ROWS; i++) { pushRow(); }
  requestAnimationFrame(frame);
})();
```

ページを開いた時点で盤面を作っておくと、タイトル画面のうしろにキューブがうっすら見えて、どんなゲームか伝わりやすくなります。
