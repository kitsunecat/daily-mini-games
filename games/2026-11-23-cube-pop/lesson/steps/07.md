## このステップのゴール

点数が 2500 点増えるごとに **レベルアップ** して、せり上がりが速くなり、色の数も増えるようにします。あわせて、PC で遊べるように **キーボード操作**（矢印キーでカーソルを動かして Space で消す）を作ります。

## レベルで色の数を増やす

`numColors` を **書きかえ** ます。

```js:game.js
  const numColors = () => Math.min(PALETTE.length, 4 + (level >= 4 ? 1 : 0) + (level >= 8 ? 1 : 0));
```

- 最初は4色。レベル4で5色、レベル8で6色になります
- 色が増えると同じ色がつながりにくくなるので、ぐっと難しくなります
- `条件 ? 1 : 0` は「条件が true なら 1、そうでなければ 0」という書き方（三項演算子）です
- `Math.min(PALETTE.length, ...)` で、用意した色の数（6）をこえないようにしています

ステップ5で作った `riseTime()` は、もともと `level` を使って計算しているので、レベルが上がれば自動的にせり上がりが速くなります。

## 点数が増えたらレベルアップ

`addScore()` を次のように **書きかえ** ます。

```js:game.js
  function addScore(p) {
    score += p;
    const newLevel = 1 + Math.floor(score / 2500);
    if (newLevel > level) { level = newLevel; addFloat(W / 2, oy + S * 2, `レベル ${level}！`, '#6fe3c1'); }
    updateHud();
  }
```

- 点数を 2500 で割って切り捨て、1 を足すと「今の点数ならレベルいくつか」が出ます。0〜2499 点はレベル1、2500〜4999 点はレベル2…です
- 今のレベルより上がったときだけ、盤面の上のほうに「レベル 〇！」を浮かべます
- 点数を足す場所を `addScore()` 1か所にまとめておいたので、ここに書くだけで、キューブを消したとき・せり上げボーナス・ALL CLEAR のどれでもレベルアップできます

## カーソルの状態

`// ---------- state ----------` の `let particles = [], floats = [];` の **下** に追加します。

```js:game.js
  let cursor = { c: 3, r: 0 }, showCursor = false;
```

- `cursor` はキーボードで選んでいるマスの「列 c と段 r」です
- `showCursor` はカーソルを表示するかどうかです。キーを押したら表示し、タップやクリックをしたら消します。スマホで遊んでいる人には、カーソルの白いわくは不要だからです

## せり上がったらカーソルもいっしょに上げる

`pushRow()` の中、列を差しこむ `for` ループの **下**（`newPreview();` の上）に追加します。

```js:game.js
    cursor.r = Math.min(ROWS - 1, cursor.r + 1);
```

1段せり上がると、カーソルが指していたキューブも1段上に動きます。カーソルもいっしょに1段上げておかないと、ねらっていたキューブから外れてしまいます。

> [!NOTE]
> ページを開いたときとスタートのときに5段ずつ積むので、そのたびにカーソルも上がり、ゲーム開始時のカーソルは盤面の上のほう（キューブの無いところ）にいます。最初は ↓ キーで、キューブのある段まで下ろしてから Space を押しましょう。

## タップしたらカーソルを消す

`cv.addEventListener('pointerdown', ...)` の中の `if (state !== 'play') return;` の **下** に追加します。

```js:game.js
    showCursor = false;
```

## キーボード操作

`pushBtn.addEventListener('click', manualPush);` の **下** に追加します。

```js:game.js
  window.addEventListener('keydown', (e) => {
    if (state !== 'play') {
      if (e.key === 'Enter' || e.key === ' ') { e.preventDefault(); start(); }
      return;
    }
    const k = e.key;
    if (k === 'ArrowLeft') cursor.c = Math.max(0, cursor.c - 1);
    else if (k === 'ArrowRight') cursor.c = Math.min(COLS - 1, cursor.c + 1);
    else if (k === 'ArrowUp') { if (e.shiftKey) manualPush(); else cursor.r = Math.min(ROWS - 1, cursor.r + 1); }
    else if (k === 'ArrowDown') cursor.r = Math.max(0, cursor.r - 1);
    else if (k === ' ' || k === 'Enter') tap(cursor.c, cursor.r);
    else if (k === 'p' || k === 'P') manualPush();
    else return;
    e.preventDefault();
    showCursor = true;
  });
```

- `e.key` には押したキーの名前が入ります（`'ArrowLeft'`、`' '`（スペース）、`'Enter'`、`'p'` など）
- タイトル画面やゲームオーバー画面では、Enter か Space でスタートします
- プレイ中は矢印キーでカーソルを動かします。`Math.max`・`Math.min` で盤面の外に出ないようにします。段 `r` は **下から** 数えるので、↑ で `+1`、↓ で `-1` です
- Space か Enter で、カーソルの位置を `tap()` します。マウスやタッチと **同じ `tap()` を呼ぶ** ので、消す・ばくだん・点数の処理は何も書き足さなくて済みます
- Shift + ↑ か P キーで、せり上げます
- 関係ないキーのときは `else return;` で何もせずに終わります。ゲームで使ったキーのときだけ `e.preventDefault()` で、Space でページがスクロールするなどのブラウザの動きを止めます

## カーソルを描く

`draw()` の中、`ctx.restore();`（切りぬきの解除）の **下**、`// particles` の上に追加します。

```js:game.js
    // cursor
    if (showCursor && state === 'play') {
      ctx.strokeStyle = '#fff'; ctx.lineWidth = 3;
      rr(ox + cursor.c * S + 2, rowBottomY(cursor.r) - S + 2, S - 4, S - 4, 8); ctx.stroke();
    }
```

キューブと同じ `rowBottomY()` で位置を出しているので、せり上がりで盤面が少しずつ上がっても、カーソルのわくはキューブにぴったり重なったまま動きます。

> [!CHECK] 動作チェック
> - 点数が 2500 をこえると「レベル 2！」が浮かび、左上が「Lv 2」になる。せり上がりのバーが前より速くのびる
> - レベル4になると、新しく出てくる列に紫のキューブがまざり始める
> - PC で矢印キーを押すと白いわくのカーソルが出る。↓ でキューブのある段まで下ろして Space を押すと、わくの中のキューブを消せる
> - Shift + ↑ か P キーでせり上がる。カーソルはせり上がりに合わせて同じキューブを指したまま上がる
> - マウスでクリックするとカーソルが消える
> - ゲームオーバー画面で Enter を押すとやりなおせる
