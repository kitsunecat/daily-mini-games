## このステップのゴール

時間がたつと、盤面の下から **新しい列がじわじわとせり上がって** くるようにします。キューブが天井をこえたら **ゲームオーバー** です。「せり上げ」ボタンで自分から1列足すとボーナス点、1個だけのキューブをタップするとせり上がりが進むペナルティも入れて、ゲームとして成り立たせます。

## せり上がりの考え方

`rise` は「次の列が出てくるまでの進み具合」で、0 から 1 まで増えていきます。

- 盤面全体を `rise * S` だけ **上にずらして** 描くと、キューブ全体と下の予告の列がじわじわ上がって見えます
- `rise` が 1 になったら、0 にもどして `pushRow()` で本当に1段差しこみます。ずらしが 1 段分もどるのと同時にデータが 1 段増えるので、見た目はつながったまま、なめらかに上がり続けます

## 1段にかかる時間

`const numColors = () => 4;` の **下** に追加します。

```js:game.js
  const riseTime = () => Math.max(3.2, 10 - (level - 1) * 0.7); // seconds per row
```

1段せり上がるのにかかる秒数です。レベル1では 10 秒、レベルが1つ上がるごとに 0.7 秒ずつ短くなり、3.2 秒より短くはなりません（レベルはステップ7で上がるようにします）。

## 座標の計算にずらしを入れる

`rowBottomY` を **書きかえ** ます。

```js:game.js
  const rowBottomY = (vy) => oy + (ROWS - vy) * S - rise * S;
```

`cellAt()` の2行目も、同じずらしを入れて **書きかえ** ます。

```js:game.js
    const r = Math.floor((oy + ROWS * S - rise * S - y) / S);
```

描く位置をずらしたら、タップした位置からマスを求める計算も同じだけずらさないと、見た目とちがうキューブが消えてしまいます。「描く計算」と「タップの計算」は、いつもセットで直します。

## pushRow() にゲームオーバー判定を入れる

`pushRow()` を次のように **書きかえ** ます。

```js:game.js
  function pushRow(silent) {
    for (let c = 0; c < COLS; c++) {
      for (const cell of cols[c]) cell.vy += 1;
      cols[c].unshift({ k: preview[c], vy: 0, pop: 0 });
    }
    newPreview();
    if (!silent) {
      if (cols.some((col) => col.length > ROWS)) { gameOver(); return; }
    }
  }
```

- 1段差しこんだあと、どれかの列の高さが `ROWS`（12）をこえていたらゲームオーバーです。`some()` は「1つでも条件に合うものがあれば true」を返す配列のメソッドです
- 引数 `silent` が true のときは判定をしません。スタート時に5段積むときは判定はいらないからです

`start()` の中と、ファイルの最後で `pushRow()` を呼んでいる **2か所** を、`pushRow(true)` に **書きかえ** ます。

```js:game.js
    for (let i = 0; i < START_ROWS; i++) { newPreview(); pushRow(true); }
```

```js:game.js
  for (let i = 0; i < START_ROWS; i++) { pushRow(true); }
```

## 自分でせり上げる manualPush()

`pushRow()` の **下** に追加します。

```js:game.js
  function manualPush() {
    if (state !== 'play') return;
    rise = 0;
    pushRow(false);
    if (state === 'play') { addScore(20); addFloat(W / 2, oy + ROWS * S - 10, '+20', '#6fe3c1'); }
  }
```

「せり上げ」ボタンで、待たずに1段足します。危険が増えるかわりに 20 点のボーナスです。`pushRow()` の中でゲームオーバーになったかもしれないので、`state` がまだ `'play'` のときだけ点数を足します。

`// ---------- input ----------` の `startBtn.addEventListener('click', start);` の **下** にボタンの登録を追加します。

```js:game.js
  pushBtn.addEventListener('click', manualPush);
```

## 1個タップのペナルティ

`tap()` の中の「1個だけ」のときの処理を、次のように **書きかえ** ます。

```js:game.js
    if (targets.length < 2) {
      cell.pop = 1; // wiggle
      rise = Math.min(0.999, rise + 0.08);
      msgEl.textContent = '1個だけでは消せないよ（せり上がりが進む）';
      return;
    }
```

むやみに連打されないよう、1個だけのキューブをタップすると、せり上がりが 8% 進みます。`Math.min(0.999, ...)` で 1 未満におさえ、実際に段を足すのは `frame()` にまかせます。

## ゲームオーバー

`updateHud()` の **下** に追加します。

```js:game.js
  function gameOver() {
    state = 'over';
    ovTitle.textContent = 'ゲームオーバー';
    ovText.innerHTML = `スコア <b class="hl">${score}</b>（Lv ${level}）<br>消したキューブ ${popped} 個`;
    startBtn.textContent = 'もう一度';
    overlay.classList.remove('hidden');
  }
```

タイトル画面に使ったオーバーレイの文字を書きかえて、もう一度表示します。ボタンは「もう一度」に変わり、押すと同じ `start()` が呼ばれてやりなおせます。ここで `innerHTML` を使っているのは、`<b>` や `<br>` のタグを使いたいからです（中身は自分で作った数字だけなので安全です）。

## frame() でせり上げる

`frame()` の中の `if (state === 'play') { ... }` を次のように **書きかえ** ます。

```js:game.js
    if (state === 'play') {
      rise += dt / riseTime();
      if (rise >= 1) { rise = 0; pushRow(false); }
      if (comboTimer > 0) { comboTimer -= dt; if (comboTimer <= 0) combo = 0; }
    }
```

さらに、`comboEl.textContent = ...` の行の **上** に、せり上がりバーの更新を追加します。

```js:game.js
    fillEl.style.width = (rise * 100).toFixed(1) + '%';
    fillEl.classList.toggle('danger', cols.some((col) => col.length >= ROWS - 1));
```

- `dt / riseTime()` を毎フレーム足すと、ちょうど `riseTime()` 秒で `rise` が 1 になります
- バーの横幅を `rise` に合わせて 0〜100% に変えます。`toFixed(1)` は小数点以下1けたの文字にする書き方です
- `classList.toggle('danger', 条件)` は、条件が true ならクラスを付け、false なら外します。どれかの列が天井の1段下まで来たら、バーが赤くなります

## 天井を点滅させる

`draw()` の `// board bg` の **すぐ下** に1行追加し、天井の色を決める行を **書きかえ** ます。

```js:game.js
    // board bg
    const danger = state === 'play' && cols.some((col) => col.length >= ROWS - 1);
```

```js:game.js
    ctx.strokeStyle = danger ? (Math.sin(performance.now() / 120) > 0 ? '#ff6b7a' : '#ff9aa5') : 'rgba(255,107,122,.55)';
```

`performance.now()` はページを開いてからのミリ秒です。`Math.sin(時刻 / 120)` は +1 と -1 の間を行き来するので、プラスかマイナスかで2色を切りかえると、天井の線がチカチカ点滅します。危ないときだけ目立たせる、小さいけれど大事な演出です。

> [!CHECK] 動作チェック
> - スタートすると、上のバーが少しずつのびていき、盤面全体と下の予告の列がじわじわ上がってくる
> - バーがいっぱいになると、予告していた色の列が盤面に加わり、新しい予告が出る
> - 上がっている最中にタップしても、ねらったキューブが消える（ずれない）
> - 「⬆ せり上げ」を押すとすぐ1段増えて「+20」が出る。1個だけのキューブをタップするとバーが進む
> - キューブが天井の1段下まで来ると、バーが赤くなり天井の点線が点滅する
> - 天井をこえると「ゲームオーバー」とスコアが出て、「もう一度」でやりなおせる
