## このステップのゴール

**6個以上** まとめて消すと、タップしたマスに **ばくだん** が残るようにします。ばくだんをタップすると、まわり 3 × 3 のキューブを色に関係なくまとめて消します。さらに、盤面のキューブを全部消したら **ALL CLEAR**（+1000 点）のボーナスも入れます。

## ばくだんのデータ

ばくだんも、ふつうのキューブと同じ `{ k, vy, pop }` で表します。色の番号 `k` に、色としてはありえない **`-1`** を入れたら「ばくだん」という約束にします。

こうすると、`cols` の配列のしくみ（落ちる・せり上がる・天井の判定）はそのまま使えます。新しい種類のものを足すときに、別の配列を作らず **今あるデータの形に乗せる** と、変更が少なくて済みます。

ファイルの先頭の定数を **書きかえ** ます。

```js:game.js
  const COLS = 8, ROWS = 12, START_ROWS = 5, BOMB_MIN = 6;
```

`let cols = [];` の行のコメントも、ばくだんのことが分かるように直しておきましょう（動きには関係ありません）。

```js:game.js
  let cols = [];          // cols[c] = array of cells from bottom; cell = { k: colorIndex or -1 (bomb), vy, pop }
```

## tap() をばくだんに対応させる

`tap()` 全体を次のように **書きかえ** ます。

```js:game.js
  function tap(c, r) {
    if (state !== 'play') return;
    if (c < 0 || c >= COLS || r < 0 || r >= cols[c].length) return;
    const cell = cols[c][r];
    let targets, bombMade = false;
    if (cell.k === -1) {
      targets = [];
      for (let dc = -1; dc <= 1; dc++) for (let dr = -1; dr <= 1; dr++) {
        const nc = c + dc, nr = r + dr;
        if (nc >= 0 && nc < COLS && nr >= 0 && nr < cols[nc].length) targets.push([nc, nr]);
      }
    } else {
      targets = group(c, r);
      if (targets.length < 2) {
        cell.pop = 1; // wiggle
        rise = Math.min(0.999, rise + 0.08);
        msgEl.textContent = '1個だけでは消せないよ（せり上がりが進む）';
        return;
      }
      bombMade = targets.length >= BOMB_MIN;
    }
    const n = targets.length;
    combo = comboTimer > 0 ? combo + 1 : 1;
    comboTimer = 1.6;
    const mult = 1 + (combo - 1) * 0.5;
    const pts = Math.round(n * n * 10 * mult);
    // particles
    for (const [cc, rr] of targets) {
      const t = cols[cc][rr];
      const x = ox + cc * S + S / 2, y = rowBottomY(t.vy) - S / 2;
      const col = t.k === -1 ? '#ffffff' : PALETTE[t.k][0];
      for (let i = 0; i < 5; i++) {
        const a = Math.random() * Math.PI * 2, sp = 60 + Math.random() * 160;
        particles.push({ x, y, vx: Math.cos(a) * sp, vy: Math.sin(a) * sp - 80, life: 0.6 + Math.random() * 0.3, col, s: S * 0.18 });
      }
    }
    const fx = ox + c * S + S / 2, fy = rowBottomY(cell.vy) - S / 2;
    addFloat(fx, fy, '+' + pts, '#fff');
    // remove (mark then filter), bomb replaces tapped cell
    const kill = new Set(targets.map(([cc, rr]) => cc * 100 + rr));
    if (bombMade) kill.delete(c * 100 + r), (cell.k = -1), (cell.pop = 1);
    for (let cc = 0; cc < COLS; cc++) cols[cc] = cols[cc].filter((_, rr) => !kill.has(cc * 100 + rr));
    popped += n;
    addScore(pts);
    if (bombMade) msgEl.textContent = 'ばくだん出現！タップで周りをまとめて消す';
    else msgEl.textContent = combo > 1 ? `${combo} コンボ！` : `${n}個 消した！`;
    if (cols.every((col) => col.length === 0)) {
      addScore(1000); addFloat(W / 2, oy + ROWS * S / 2, 'ALL CLEAR +1000', '#ffd36b');
    }
  }
```

変わったところを順に見ていきます。

### 消す対象 targets を2通りで決める

- タップしたのが **ばくだん**（`cell.k === -1`）なら、まわり 3 × 3 の9マスのうち、キューブがあるマスを全部 `targets` に入れます。`dc`・`dr` を -1, 0, 1 と二重ループで回すと、自分を中心とした9マスになります。盤面の端では、外にはみ出したマスを条件ではじきます
- **ふつうのキューブ** なら、今までどおり `group()` でかたまりを集めます。そして6個以上なら `bombMade = true` にします
- `targets` を `let` にして、if と else のどちらでも中身を入れられるようにしています。このあとの「点数・かけら・消す」処理は、どちらの場合も同じコードを使えます

### タップしたマスだけ残してばくだんにする

```js:game.js
    if (bombMade) kill.delete(c * 100 + r), (cell.k = -1), (cell.pop = 1);
```

`kill` には消すマスの印が入っています。ばくだんを作るときは、**タップしたマスの印だけ外して**（`kill.delete`）、そのキューブを消さずに残します。そして `k` を `-1` に書きかえてばくだんにし、`pop = 1` でぷるっとさせて登場を目立たせます。

`,`（カンマ演算子）で3つの式を1行に並べています。`{ }` で囲んで3行に分けて書いても同じ意味です。

### ALL CLEAR

`every()` は「全部が条件に合えば true」を返す配列のメソッドです。8列とも高さが 0（キューブが1つも無い）なら、1000 点のボーナスです。ばくだんで最後のキューブを吹き飛ばしたときなどに起こります。

> [!NOTE]
> ばくだんで消した数も `n` に入るので、ばくだんの点数も「消した数の2乗」です。9個まとめて消せば 810 点。端っこより、キューブにかこまれた場所でばくだんを使うほうがお得です。

## ばくだんを描く

`drawCube()` 全体を次のように **書きかえ** ます。

```js:game.js
  function drawCube(x, y, k, scale, alpha) {
    const pad = S * 0.06, s = (S - pad * 2) * scale, cx = x + S / 2, cy = y + S / 2;
    const x0 = cx - s / 2, y0 = cy - s / 2;
    ctx.globalAlpha = alpha;
    if (k === -1) {
      ctx.fillStyle = '#2a2f45'; ctx.beginPath(); ctx.arc(cx, cy + s * 0.06, s * 0.4, 0, Math.PI * 2); ctx.fill();
      ctx.fillStyle = 'rgba(255,255,255,.35)'; ctx.beginPath(); ctx.arc(cx - s * 0.13, cy - s * 0.08, s * 0.1, 0, Math.PI * 2); ctx.fill();
      ctx.strokeStyle = '#d9b38c'; ctx.lineWidth = Math.max(2, s * 0.06);
      ctx.beginPath(); ctx.moveTo(cx + s * 0.18, cy - s * 0.26); ctx.quadraticCurveTo(cx + s * 0.3, cy - s * 0.45, cx + s * 0.38, cy - s * 0.38); ctx.stroke();
      const fl = 0.7 + Math.sin(performance.now() / 70) * 0.3;
      ctx.fillStyle = '#ffd36b'; ctx.beginPath(); ctx.arc(cx + s * 0.39, cy - s * 0.4, s * 0.08 * fl + 1, 0, Math.PI * 2); ctx.fill();
    } else {
      const [base, dark] = PALETTE[k];
      ctx.fillStyle = dark; rr(x0, y0, s, s, s * 0.2); ctx.fill();
      ctx.fillStyle = base; rr(x0, y0, s, s * 0.88, s * 0.2); ctx.fill();
      ctx.fillStyle = 'rgba(255,255,255,.35)'; rr(x0 + s * 0.14, y0 + s * 0.1, s * 0.42, s * 0.16, s * 0.08); ctx.fill();
    }
    ctx.globalAlpha = 1;
  }
```

ばくだんは4つの部品でできています。

1. 黒っぽい丸（本体）。`ctx.arc(中心x, 中心y, 半径, 0, Math.PI * 2)` で円をえがきます
2. 左上の小さな白い丸（ツヤ）
3. 右上にのびる導火線。`quadraticCurveTo(制御点x, 制御点y, 終点x, 終点y)` は、制御点に引っぱられたなめらかな曲線（2次ベジェ曲線）を引きます
4. 導火線の先の火花。`Math.sin(performance.now() / 70)` で大きさを細かく変えると、パチパチと燃えているように見えます

大きさはすべて `s`（キューブの大きさ）の何倍かで書いているので、画面の大きさが変わっても形がくずれません。

> [!CHECK] 動作チェック
> - 同じ色を6個以上まとめて消すと、タップしたマスにばくだんが残り、「ばくだん出現！」と出る
> - ばくだんの導火線の先の火花がチカチカ動いている
> - ばくだんをタップすると、まわり 3 × 3 のキューブが色に関係なく白いかけらといっしょに消える
> - 盤面の端のばくだんをタップしても、エラーにならない
> - （運がよければ）キューブを全部消すと「ALL CLEAR +1000」と出る
