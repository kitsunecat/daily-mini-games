## このステップのゴール

3つのファイルを用意して、画面の土台を作ります。上に「LEVEL・SCORE・BEST」と制限時間のバー、まん中にビンを並べる **盤面**（`#board`）、その上に重ねるタイトル画面（オーバーレイ）、下に「もどす」「やり直し」ボタンを置きます。

完成すると、こんなゲームになります。

- いくつかのビンに、4色ずつのカラフルな色水が4段まで入っている
- ビンをタップして選び、別のビンをタップすると、いちばん上の色水がそそがれる
- そそげるのは **同じ色の上** か **空のビン** だけ。全部のビンを1色ずつにそろえるとクリア
- 制限時間内にクリアするとレベルアップ。時間切れでゲームオーバー

今回は Canvas を使わず、ビンも色水も **ふつうの HTML 要素（div）** で作ります。パズルのように「マス」や「段」がはっきりしたゲームは、DOM と CSS で作るとアニメーションや見た目の調整がとても楽になります。

まずは HTML です。このステップで画面の部品はすべてそろえてしまい、以降は `game.js` だけを育てていきます。

- `header` に LEVEL・SCORE・BEST の3つの数字を並べます。JavaScript から書き換えるので、数字の `b` 要素に `id` をつけています。
- `#sub` の行には、残り時間のバー `#timebar` と秒数 `#timetext` を置きます。バーの中の `#timefill` の幅を JavaScript で縮めていくと「時間が減っていく」ように見えます。
- `#board` は空っぽの入れ物です。ビンはあとで JavaScript が `div` を作って、ここに入れていきます。
- `#toast` は「クリア！」などの文字を一瞬だけ出すための場所、`#overlay` はタイトル画面とゲームオーバー画面をかねた「上にかぶせる板」です。
- `<script>` を `body` の最後に置くと、HTML の部品がすべて読み込まれてから `game.js` が動くので、`getElementById` で確実に要素を見つけられます。

ポイントをいくつか見ておきましょう。

- `#app` を `display: flex; flex-direction: column;` にして、ヘッダー・時間バー・盤面・フッターを縦に並べています。盤面の `#stage` に `flex: 1` をつけると、残りの高さを全部もらえます。
- `.tube` が1本のビンです。`border-top: none` と `border-radius: 0 0 22px 22px` で「上が開いていて底が丸い」形にしています。
- ビンの中は `flex-direction: column-reverse` です。こうすると、**あとから入れた div ほど上に積み上がる** ので、配列の順番（0番目が底）とそのまま対応させられます。
- 幅や1段の高さは `var(--tw, 46px)`・`var(--seg, 34px)` という **CSS 変数** にしてあります。ビンの本数や画面サイズに合わせて、あとで JavaScript から書きかえます。
- `.sel`（選んだビンが浮く）、`.done`（そろったビンが金色になる）、`.shake`（そそげないとき揺れる）、`.seg.new`（そそいだ色水がにゅっと伸びる）など、ゲームで使う見た目は **クラスをつけ外しするだけ** で切りかわるように用意しておきます。
- `@keyframes` はアニメーションの定義です。`fill` は `from { height: 0; }` だけを書いているので、「高さ0から本来の高さへ」伸びるアニメーションになります。

## game.js

最後に JavaScript です。このステップでは「スタートボタンを押すとタイトル画面が消える」だけを作ります。

```js:game.js
(() => {
  'use strict';

  const $ = (id) => document.getElementById(id);
  const board = $('board'), overlay = $('overlay');

  // ---------- game flow ----------
  function startGame() {
    overlay.classList.add('hide');
  }

  // ---------- input ----------
  $('start').addEventListener('click', startGame);
})();
```

- 全体を `(() => { ... })();` で囲んでいます。これは **即時実行関数** といって、中で作った変数がほかのスクリプトとぶつからないようにするおまじないです。
- `'use strict';` を書くと、変数の書きまちがいなどをエラーとして教えてくれるようになります。
- `$` は `document.getElementById` を短く書くための小さな関数です。このあと何度も使います。
- `overlay.classList.add('hide')` で `hide` クラスをつけると、CSS の `#overlay.hide { display: none; }` が効いてタイトル画面が消えます。
