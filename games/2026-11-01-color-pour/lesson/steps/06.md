## このステップのゴール

ゲームに緊張感を足します。

- レベルごとに **制限時間** を決め、残り時間をバーと秒数で表示する
- 時間切れになったら「タイムアップ！」画面を出して、もう一度遊べるようにする
- 早くクリアするほど、残り時間ぶんのボーナスが増える

時間を減らし続けるために、**ゲームループ** を作ります。

## 要素と変数を追加する

`const elToast = $('toast');` の行を、次のように **書きかえ** ます。

```js:game.js
  const elFill = $('timefill'), elTime = $('timetext'), elToast = $('toast');
```

`let playing = false, busy = false;` の行も、次のように **書きかえ** ます。

```js:game.js
  let timeMax = 60, timeLeft = 60, playing = false, lastTs = 0, busy = false;
```

- `timeMax` はそのレベルの制限時間、`timeLeft` は残り時間（どちらも秒）です。
- `lastTs` は「前のフレームの時刻」です。ゲームループで経過時間を求めるのに使います。

## レベルごとに制限時間を決める

`startLevel()` を、次のように **書きかえ** ます。

```js:game.js
  function startLevel() {
    tubes = makeLevel(level);
    sel = -1; busy = false;
    const nColors = tubes.filter((t) => t.length).length;
    timeMax = 30 + nColors * 10;
    timeLeft = timeMax;
    layout(); render(); hud();
  }
```

色水の入ったビンの数（= 色の数）を `filter` で数えて、「30秒 + 1色につき10秒」にしています。3色なら60秒、9色なら120秒です。

## スタートとゲームオーバー

`startGame()` を次のように **書きかえ**、その **下** に `gameOver()` を追加します。

```js:game.js
  function startGame() {
    level = 1; score = 0; playing = true;
    overlay.classList.add('hide');
    startLevel();
    lastTs = performance.now();
  }

  function gameOver() {
    playing = false; sel = -1;
    hud(); render();
    $('ov-title').textContent = 'タイムアップ！';
    $('ov-text').innerHTML = `レベル ${level} まで到達<br>スコア <b>${score}</b>`;
    $('start').textContent = 'もう一度あそぶ';
    overlay.classList.remove('hide');
  }
```

- `performance.now()` は、ページを開いてからの時間をミリ秒で返します。スタートした瞬間の時刻を覚えておき、タイトル画面にいた時間ぶん一気に減ってしまわないようにします。
- `gameOver()` では、同じオーバーレイの文字を書きかえて「ゲームオーバー画面」として使い回します。ボタンを押すと、また `startGame()` が呼ばれて最初から遊べます。
- `textContent` は文字をそのまま入れますが、`innerHTML` は `<br>` や `<b>` をタグとして解釈します。ここではこちらで用意した数字しか入れないので `innerHTML` を使っています。

## 残り時間をボーナスに

`clearLevel()` の `const bonus = ...` の行を、次のように **書きかえ** ます。

```js:game.js
    const bonus = 100 * level + Math.ceil(timeLeft) * 5;
```

残り1秒につき5点です。`Math.ceil` は小数を切り上げて整数にします。

## ゲームループを作る

`// ---------- input ----------` の **上** に、`loop()` を追加します。

```js:game.js
  function loop(ts) {
    const dt = Math.min(0.1, (ts - lastTs) / 1000);
    lastTs = ts;
    if (playing && !busy) {
      timeLeft -= dt;
      if (timeLeft <= 0) { timeLeft = 0; gameOver(); }
    }
    const r = timeMax ? timeLeft / timeMax : 1;
    elFill.style.width = (r * 100) + '%';
    elFill.classList.toggle('low', r < 0.25);
    elTime.textContent = Math.ceil(timeLeft);
    requestAnimationFrame(loop);
  }

```

そして、ファイルの最後の `hud();` の **下** に、ループを動かし始める1行を追加します。

```js:game.js
  requestAnimationFrame((ts) => { lastTs = ts; loop(ts); });
```

- `requestAnimationFrame(関数)` は「次に画面を描きかえる直前に、この関数を呼んで」とブラウザに頼む命令です。`loop()` の最後で自分自身をもう一度頼むことで、1秒に約60回 `loop()` が呼ばれ続けます。これがゲームループです。
- 呼ばれるときには、そのときの時刻 `ts`（ミリ秒）が渡されます。前回との差 `ts - lastTs` を 1000 で割ると、前のフレームから何秒たったか（`dt`）が分かります。画面の更新回数は機種によって違うので、「1回につき1/60秒減らす」ではなく **実際にたった時間** だけ減らすのが大事です。
- `Math.min(0.1, ...)` で、`dt` が 0.1 秒より大きくならないようにしています。別のタブを見ている間はループが止まるので、戻ってきた瞬間に何十秒も減ってしまうのを防ぎます。
- クリア演出中（`busy`）は時間を止めます。
- 残りが 25% を切ると `low` クラスでバーを赤くして、あせらせます。`classList.toggle(クラス名, 条件)` は、条件が true ならつけ、false なら外します。

> [!CHECK] 動作チェック
> - スタートすると、時間バーが少しずつ短くなり、右の秒数が 60 から減っていく
> - 残りが少なくなるとバーが赤くなる
> - クリアすると、残り時間に応じてボーナスが増える（例: 40秒残しなら +300）
> - 何もしないで待つと「タイムアップ！」画面が出て、到達レベルとスコアが表示される
> - 「もう一度あそぶ」で LEVEL 1・SCORE 0 から再スタートできる
