## このステップのゴール

ゲームの心臓部、「選んで、そそぐ」操作を作ります。

1. ビンをタップすると、そのビンが少し浮き上がる（選択中）
2. 別のビンをタップすると、選んだビンのいちばん上の色水がそそがれる
3. 同じ色が何段か続いていれば、入るぶんだけまとめてそそがれる
4. そそげないときは、タップしたビンがぷるっと揺れる

## 選択中のビンを覚える変数

`let tubes = [];` の **下** に、選択中のビンの番号を入れる変数を追加します。

```js:game.js
  let sel = -1;
```

何も選んでいないときは `-1` にしておきます。配列の番号は 0 から始まるので、「-1 = どれでもない」という決まりにすると扱いやすいです。

## パズルのルールを関数にする

`let sel = -1;` の **下** に、次のコードを追加します。

```js:game.js

  // ---------- puzzle logic ----------
  const top = (t) => t[t.length - 1];
  function runLen(t) {
    let n = 0; const c = top(t);
    for (let i = t.length - 1; i >= 0 && t[i] === c; i--) n++;
    return n;
  }
  function canPour(a, b) {
    if (a === b || !a.length || b.length >= CAP) return false;
    return !b.length || top(b) === top(a);
  }
```

- `top(t)` はビンのいちばん上の色です。配列の最後の要素なので `t[t.length - 1]` です。空のビンなら `undefined` になります。
- `runLen(t)` は「上から同じ色が何段続いているか」を数えます。上から下へ（配列の後ろから前へ）見ていき、色が変わったところで止まります。`[0, 1, 1, 1]` なら 3 です。
- `canPour(a, b)` は「ビン a からビン b へそそげるか」を `true` / `false` で返します。
  - 同じビン、a が空、b が満杯（4段）なら、そそげません。
  - それ以外は「b が空」か「b のいちばん上が a のいちばん上と同じ色」ならそそげます。

ルールを小さな関数に分けておくと、このあと「クリア判定」や「解けるかどうかの自動チェック」でも同じ関数を使い回せます。

## render() を選択とアニメーションに対応させる

`render()` 関数を、次のように **書きかえ** ます（変わったのは1行目・`el.className` の行・`t.forEach` の2行です）。

```js:game.js
  function render(pourTo = -1, pourN = 0) {
    board.innerHTML = '';
    tubes.forEach((t, i) => {
      const el = document.createElement('div');
      el.className = 'tube' + (i === sel ? ' sel' : '');
      el.dataset.i = i;
      const num = document.createElement('span');
      num.className = 'num'; num.textContent = (i + 1) % 10;
      el.appendChild(num);
      t.forEach((c, k) => {
        const s = document.createElement('div');
        s.className = 'seg' + (i === pourTo && k >= t.length - pourN ? ' new' : '');
        s.style.background = `linear-gradient(90deg, ${COLORS[c]}, ${COLORS[c]}cc)`;
        el.appendChild(s);
      });
      board.appendChild(el);
    });
  }
```

- 選択中のビンには `sel` クラスをつけます。CSS の `.tube.sel` で上に 16px 浮き上がります。
- `render(pourTo = -1, pourN = 0)` は **デフォルト引数** です。ふつうに `render()` と呼ぶと -1 と 0 が入ります。
- そそいだ直後だけ `render(そそいだ先の番号, そそいだ段数)` と呼び、そのビンの上から `pourN` 段に `new` クラスをつけます。CSS の `.seg.new` が高さ 0 から伸びるアニメーションを再生するので、色水が注がれたように見えます。

## タップの処理を追加する

`startGame()` の中の `layout(); render();` の **上** に `sel = -1;` を1行追加して、`startGame()` の **下** に `tap()` と `shake()` を追加します。

```js:game.js
  function startGame() {
    overlay.classList.add('hide');
    tubes = [
      [0, 1, 2, 0],
      [1, 2, 0, 1],
      [2, 0, 1, 2],
      [],
      [],
    ];
    sel = -1;
    layout(); render();
  }

  function tap(i) {
    if (i < 0 || i >= tubes.length) return;
    if (sel < 0) {
      if (!tubes[i].length) { shake(i); return; }
      sel = i; render(); return;
    }
    if (sel === i) { sel = -1; render(); return; }
    const a = tubes[sel], b = tubes[i];
    if (!canPour(a, b)) {
      // switch selection if tapping another pourable tube
      if (b.length) { sel = i; render(); }
      else { shake(i); }
      return;
    }
    const n = Math.min(runLen(a), CAP - b.length);
    for (let m = 0; m < n; m++) b.push(a.pop());
    sel = -1;
    render(i, n);
  }

  function shake(i) {
    const el = board.children[i];
    if (!el) return;
    el.classList.remove('shake'); void el.offsetWidth; el.classList.add('shake');
  }
```

`tap(i)` は「i 番目のビンがタップされた」ときの処理で、状況ごとに分かれています。

- **まだ何も選んでいない:** 空のビンなら揺らすだけ。色水があれば選択します。
- **選択中のビンをもう一度タップ:** 選択をやめます。
- **別のビンをタップ:** そそげるならそそぎます。そそげないけれど色水の入ったビンなら、「そっちを選び直したいんだな」と考えて選択を切りかえます。こうすると操作ミスのストレスが減ります。
- **そそぐ量:** 「上に続く同じ色の段数」と「そそぎ先の空き段数」の **小さいほう** です。`Math.min(runLen(a), CAP - b.length)` で求め、その回数だけ `a.pop()` した色を `b.push()` します。

`shake(i)` は、ビンに `shake` クラスをつけて揺らすアニメーションを再生します。同じクラスを付け直してもアニメーションは再生し直されないので、いったん外して `void el.offsetWidth;` を挟んでいます。`offsetWidth` を読むとブラウザがレイアウトを計算し直すので、「外した」ことが確定し、もう一度つけたときに最初から再生されます（よく使われる小技です）。

## タップを受け取る

`// ---------- input ----------` の **下** に、盤面のタップを受け取るコードを追加します。

```js:game.js
  board.addEventListener('pointerdown', (e) => {
    const el = e.target.closest('.tube');
    if (!el) return;
    tap(+el.dataset.i);
  });
```

- `pointerdown` は、マウスのクリックとスマホのタッチの両方で起きる **ポインターイベント** です。`click` より反応が早いので、パズルの操作が気持ちよくなります。
- ビン1本1本にイベントを付けるのではなく、親の `#board` に1つだけ付けています（**イベント委任**）。`render()` で div を作り直しても付け直す必要がありません。
- `e.target` は実際にタップされた要素です（色水の `.seg` や番号の `span` かもしれません）。`closest('.tube')` で「自分か親をさかのぼって最初に見つかった `.tube`」を探します。
- `el.dataset.i` は文字列なので、前に `+` をつけて数値に変えています。

> [!CHECK] 動作チェック
> - ビンをタップすると浮き上がり、もう一度タップすると元に戻る
> - 1本目（いちばん上が赤）を選んで、空のビン（4本目）をタップすると、赤がにゅっとそそがれる
> - 2本目（いちばん上が黄）を選んで、いちばん上が赤のビンをタップすると、そそがれずに選択が切りかわる
> - 何も選んでいないときに空のビンをタップすると、ぷるっと揺れる
> - 1本目の赤を4本目へそそいだあと、3本目の水色を1本目へそそぐと、1本目の上に水色が2段続く。その1本目を5本目（空）へそそぐと、水色が2段まとめて移る
