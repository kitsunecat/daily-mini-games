## このステップのゴール

遊びやすさを仕上げます。

- **もどす:** 1手前の状態に戻す（1レベルにつき3回まで）
- **やり直し:** そのレベルの最初の盤面に戻す（代わりに残り時間が5秒減る）
- **キーボード操作:** 数字キーでビンを選ぶ、矢印キー＋Enter でも選べる、Z でもどす、R でやり直し

## 定数・要素・変数を追加する

`const COLORS = [...]` の **下** に、もどせる回数の定数を追加します。

```js:game.js
  const UNDO_MAX = 3;
```

`const elFill = ...` の行の **下** に、フッターのボタンを追加します。

```js:game.js
  const btnUndo = $('undo'), btnReset = $('reset'), elUndoLeft = $('undoLeft');
```

`let tubes = [];` と `let level = 1, score = 0, sel = -1;` の2行を、次の2行に **書きかえ** ます。

```js:game.js
  let tubes = [], initial = [], history = [], undoLeft = UNDO_MAX;
  let level = 1, score = 0, sel = -1, cursor = 0;
```

- `initial` はレベル開始時の盤面のコピー（やり直し用）です。
- `history` は「そそぐ前の盤面」を積み重ねていく配列です。もどすときは最後のものを `pop()` で取り出します。最後に入れたものから取り出す、この使い方を **スタック** といいます。
- `cursor` はキーボードの矢印キーで動かす「カーソル」がどのビンにあるかです。

## 表示の更新

`hud()` を、次のように **書きかえ** ます。

```js:game.js
  function hud() {
    elLevel.textContent = level;
    elScore.textContent = score;
    elUndoLeft.textContent = undoLeft;
    btnUndo.disabled = !playing || !history.length || undoLeft <= 0;
    btnReset.disabled = !playing;
  }
```

ボタンの `disabled` を true にすると押せなくなり、CSS の `footer button:disabled` で半透明になります。もどせる手が無いときや回数を使い切ったときは、押せないことが見た目で分かります。

`render()` の中の `el.className = ...` の行も、カーソル表示を足して **書きかえ** ます。

```js:game.js
      el.className = 'tube' + (i === sel ? ' sel' : '') + (isDoneTube(t) ? ' done' : '') + (i === cursor && kbMode ? ' cursor' : '');
```

## ゲームの流れを書きかえる

`// ---------- game flow ----------` の **下** に、キーボードで操作中かどうかを表す変数を追加します。

```js:game.js
  let kbMode = false;

```

矢印キーを使っているときだけ点線のカーソルを出し、マウスやタッチに切りかえたら消すためのものです。

`startLevel()` の最初の2行を、次のように **書きかえ** ます。

```js:game.js
  function startLevel() {
    tubes = makeLevel(level);
    initial = tubes.map((t) => t.slice());
    history = []; undoLeft = UNDO_MAX; sel = -1; cursor = 0; busy = false;
    const nColors = tubes.filter((t) => t.length).length;
    timeMax = 30 + nColors * 10;
    timeLeft = timeMax;
    layout(); render(); hud();
  }
```

`tap()` の中の `const n = Math.min(...)` の **上** に、そそぐ前の盤面を記録する1行を追加します。

```js:game.js
    history.push(tubes.map((t) => t.slice()));
    const n = Math.min(runLen(a), CAP - b.length);
```

ステップ5と同じく、ビン1本ずつコピーしているのがポイントです。そのまま `tubes` を入れると、このあとそそいだ結果が記録のほうにも反映されてしまいます。

## もどす・やり直し

`shake()` の **下** に、`undo()` と `reset()` を追加します。

```js:game.js

  function undo() {
    if (!playing || busy || !history.length || undoLeft <= 0) return;
    tubes = history.pop(); undoLeft--; sel = -1;
    render(); hud();
  }

  function reset() {
    if (!playing || busy) return;
    tubes = initial.map((t) => t.slice());
    history = []; sel = -1;
    timeLeft = Math.max(0, timeLeft - 5);
    toast('やり直し −5秒');
    render(); hud();
  }
```

- `undo()` は、記録の最後の盤面をそのまま今の盤面にします。
- `reset()` は最初の盤面に戻します。ここでも `initial` をそのまま使わずコピーしているので、何度でもやり直せます。何回でも無料だと緊張感がないので、5秒のペナルティをつけています。

## ボタンとキーボード

`pointerdown` の処理の `tap(+el.dataset.i);` の **上** に `kbMode = false;` を足し、`$('start').addEventListener(...)` の **下** にボタンとキーボードの処理を追加します。`// ---------- input ----------` から下は、次のようになります（最後の `resize` 以降はそのままです）。

```js:game.js
  // ---------- input ----------
  board.addEventListener('pointerdown', (e) => {
    const el = e.target.closest('.tube');
    if (!el) return;
    kbMode = false;
    tap(+el.dataset.i);
  });
  $('start').addEventListener('click', startGame);
  btnUndo.addEventListener('click', undo);
  btnReset.addEventListener('click', reset);

  window.addEventListener('keydown', (e) => {
    if (!playing) {
      if (e.key === 'Enter' || e.key === ' ') { e.preventDefault(); startGame(); }
      return;
    }
    if (/^[0-9]$/.test(e.key)) {
      const i = e.key === '0' ? 9 : +e.key - 1;
      kbMode = false; tap(i); return;
    }
    if (e.key === 'ArrowRight' || e.key === 'ArrowLeft') {
      e.preventDefault(); kbMode = true;
      cursor = (cursor + (e.key === 'ArrowRight' ? 1 : -1) + tubes.length) % tubes.length;
      render(); return;
    }
    if (e.key === 'Enter' || e.key === ' ') { e.preventDefault(); kbMode = true; tap(cursor); render(); return; }
    if (e.key === 'z' || e.key === 'Z') undo();
    if (e.key === 'r' || e.key === 'R') reset();
    if (e.key === 'Escape') { sel = -1; render(); }
  });
```

- `e.key` には押されたキーの名前（`'1'`、`'ArrowRight'`、`'Enter'`、`' '`（スペース）など）が入ります。
- `/^[0-9]$/.test(e.key)` は **正規表現** で「数字1文字か」を調べています。ビンの上の番号と同じく、1〜9 が1〜9本目、0 が10本目です。
- 矢印キーのカーソル移動では `(cursor + 1 または -1 + 本数) % 本数` で、右端の次は左端、左端の前は右端へ **ぐるっと回る** ようにしています。`+ 本数` は、-1 になったとき割り算の余りがマイナスにならないようにするためです。
- `e.preventDefault()` は、スペースキーでページがスクロールするなど、ブラウザの本来の動きを止めます。
- タイトル画面やゲームオーバー画面では、Enter かスペースでスタートできます。

> [!CHECK] 動作チェック
> - 1回そそいでから「もどす」を押すと、そそぐ前に戻り、ボタンの数字が 3 → 2 に減る
> - 3回もどすと「もどす」ボタンが半透明になり、押せなくなる（次のレベルでまた 3 に戻る）
> - 「やり直し」を押すと最初の盤面に戻り、「やり直し −5秒」と出て残り時間が減る
> - PC で数字キー 1 → 4 を押すと、1本目から4本目へそそげる
> - 矢印キーを押すと点線のカーソルが出て、Enter / スペースで選択・そそぐができる。クリックするとカーソルは消える
> - Z でもどす、R でやり直し、Esc で選択解除ができる
