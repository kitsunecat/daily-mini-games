## このステップのゴール

前のステップの `makeLevel()` は、ランダムに混ぜただけなので、ときどき **解けない盤面** を作ってしまいます。遊ぶ人にとっては、がんばっても絶対にクリアできない問題ほどつらいものはありません。

そこで、盤面を作ったら **コンピューターに一度解かせてみて**、解けたものだけを出すようにします。使うのは **深さ優先探索（DFS）** という、「ためしに1手進めて、ダメなら戻って別の手を試す」を繰り返す探し方です。

## 解けるかどうか調べる関数

`function makeLevel(lv) {` の **上** に、`solvable()` を追加します。

```js:game.js
  function solvable(start) {
    const seen = new Set();
    let nodes = 0;
    const key = (ts) => ts.map((t) => t.join(',')).sort().join('|');
    function dfs(ts) {
      if (isSolved(ts)) return true;
      if (++nodes > 40000) return false;
      const k = key(ts);
      if (seen.has(k)) return false;
      seen.add(k);
      for (let i = 0; i < ts.length; i++) {
        const a = ts[i];
        if (!a.length || isDoneTube(a)) continue;
        const r = runLen(a);
        let triedEmpty = false;
        for (let j = 0; j < ts.length; j++) {
          const b = ts[j];
          if (!canPour(a, b)) continue;
          if (!b.length) {
            if (r === a.length || triedEmpty) continue; // pointless
            triedEmpty = true;
          }
          const n = Math.min(r, CAP - b.length);
          const next = ts.map((t) => t.slice());
          for (let m = 0; m < n; m++) next[j].push(next[i].pop());
          if (dfs(next)) return true;
        }
      }
      return false;
    }
    return dfs(start);
  }

```

### dfs() のしくみ

`dfs(ts)` は「盤面 `ts` からクリアまでたどり着けるか」を返す **再帰関数**（自分の中で自分を呼ぶ関数）です。

1. もうクリアしていれば `true`。
2. そうでなければ、考えられる「そそぎ方」を全部ためします。i 番目から j 番目へそそげるなら、盤面をコピーした `next` の上で実際にそそいでみて、`dfs(next)` で「その先からクリアできるか」を調べます。
3. どれか1つでも `true` が返ってくれば、この盤面は解けます。全部ダメなら `false` です。

ここで、ゲーム本番で使っている `canPour()`・`runLen()`・`isSolved()` をそのまま使い回しているのがポイントです。ルールを関数に分けておいたおかげで、「人が遊ぶルール」と「コンピューターが解くルール」が必ず同じになります。

> [!WARNING]
> 盤面をコピーするとき `ts.slice()` だけだと、外側の配列しかコピーされず、中のビン（配列）は元と同じものを指したままです。`ts.map((t) => t.slice())` のように **ビン1本ずつ** コピーしないと、ためしにそそいだつもりが元の盤面まで書きかわってしまいます。

### 速くするための工夫

何もしないと、ためす手の数はあっという間に何百万通りにもふくらみます。そこで3つの工夫をしています。

- **同じ盤面は2度調べない:** 調べた盤面を `Set` に覚えておき、また出てきたらすぐ `false` を返します。`key()` は盤面を `"0,1,2|1,1||..."` のような文字列にします。ビンの **並び順は答えに関係ない** ので、`sort()` してから繋げることで「ビンの順番が違うだけの同じ盤面」もまとめて1つとみなせます。
- **意味のない手は省く:** そろったビンからはそそぎません。また、1色しか入っていないビンを空のビンへ移しても何も変わらないので省きます（`r === a.length`）。空のビンが2本あっても、どちらへそそいでも同じなので、試すのは最初の1本だけです（`triedEmpty`）。
- **調べすぎたらあきらめる:** 40000 盤面を調べても答えが出なければ `false` にします。ゲーム開始時に何秒も固まるよりは、その盤面を捨てて作り直したほうがいいからです。

## 解ける盤面だけを出す

`makeLevel()` の中の、空のビンを足したあとの `return ts;` を、次のように **書きかえ** ます。

```js:game.js
      for (let e = 0; e < empties; e++) ts.push([]);
      if (solvable(ts)) return ts;
```

解けなければ `for` ループの次の周に進み、混ぜ直して作り直します。200 回やってもダメなら（まず起こりませんが）、最後の `return makeLevel(1);` で一番かんたんな盤面に切りかえます。

> [!CHECK] 動作チェック
> - スタートしても、レベルが変わっても、固まらずにすぐ盤面が出る
> - 何度か遊んでみて、どの盤面も工夫すれば必ずクリアできる
> - 開発者ツールの Console で、たとえば `performance.now()` を前後に挟んで測ると、1回の `makeLevel()` は一瞬（数ミリ秒〜数十ミリ秒）で終わる
