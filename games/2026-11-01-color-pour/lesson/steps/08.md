## このステップのゴール

最後の仕上げです。

- **ハイスコア（BEST）** をブラウザに保存して、次に開いたときも残るようにする
- **効果音** をつけて、操作の手ごたえを出す

これで完成品と同じゲームになります。

## ハイスコアを読み込む

`const UNDO_MAX = 3;` の **上** に、保存に使う名前を追加します。

```js:game.js
  const BEST_KEY = 'dmg-color-pour-best';
```

`const elLevel = ...` の行を、BEST の要素を足して **書きかえ** ます。

```js:game.js
  const elLevel = $('level'), elScore = $('score'), elBest = $('best');
```

`const btnUndo = ...` の行の **下** に、保存されているハイスコアを読み込むコードを追加します。

```js:game.js

  let best = 0;
  try { best = parseInt(localStorage.getItem(BEST_KEY), 10) || 0; } catch (e) {}
  elBest.textContent = best;
```

- **localStorage** は、ブラウザにちょっとしたデータを保存できるしくみです。`setItem(名前, 文字列)` で保存、`getItem(名前)` で読み出します。ページを閉じても、再読み込みしても消えません。
- 保存できるのは **文字列だけ** なので、`parseInt(..., 10)` で数値に戻します。まだ何も保存していないと `getItem` は `null` を返し、`parseInt` は `NaN` になるので、`|| 0` で 0 にしています。
- プライベートブラウズなどで localStorage が使えない環境では、エラーが起きることがあります。`try { ... } catch (e) {}` で囲んでおくと、エラーが起きてもゲームは止まりません。
- `BEST_KEY` に `dmg-color-pour-` のようにゲームごとの名前をつけておくと、同じサイトのほかのゲームと保存場所がぶつかりません。

`hud()` の `elScore.textContent = score;` の **下** に、1行追加します。

```js:game.js
    elBest.textContent = best;
```

## ゲームオーバーで保存する

`gameOver()` を、次のように **書きかえ** ます（効果音の行もここで入れてしまいます）。

```js:game.js
  function gameOver() {
    playing = false; sel = -1;
    if (score > best) {
      best = score;
      try { localStorage.setItem(BEST_KEY, String(best)); } catch (e) {}
    }
    hud(); render();
    $('ov-title').textContent = 'タイムアップ！';
    $('ov-text').innerHTML = `レベル ${level} まで到達<br>スコア <b>${score}</b>（ベスト ${best}）`;
    $('start').textContent = 'もう一度あそぶ';
    overlay.classList.remove('hide');
    beep(220, 0.3, 'sawtooth', 0.08);
  }
```

今回のスコアが今までの最高より高ければ、`best` を更新して保存します。

## 効果音を鳴らす関数

`let timeMax = ...` の行の **下** に、効果音の関数を追加します。

```js:game.js
  let audio = null;

  function beep(freq, dur = 0.08, type = 'sine', vol = 0.12) {
    try {
      if (!audio) audio = new (window.AudioContext || window.webkitAudioContext)();
      const o = audio.createOscillator(), g = audio.createGain();
      o.type = type; o.frequency.value = freq;
      g.gain.setValueAtTime(vol, audio.currentTime);
      g.gain.exponentialRampToValueAtTime(0.001, audio.currentTime + dur);
      o.connect(g); g.connect(audio.destination);
      o.start(); o.stop(audio.currentTime + dur);
    } catch (e) {}
  }
```

音声ファイルを用意しなくても、**Web Audio API** を使えば JavaScript だけで「ピッ」という音が作れます。

- `AudioContext` は音を扱うための土台です。ブラウザは「ユーザーが操作する前に音を鳴らす」ことを禁止しているので、最初に `beep()` が呼ばれた（= タップされた）ときに作ります。
- `createOscillator()` は一定の高さの音を出す **発振器** です。`frequency`（周波数、Hz）が大きいほど高い音、`type` で音色（`sine` はやわらか、`square` や `sawtooth` はビーッという硬い音、`triangle` はその中間）が変わります。
- `createGain()` は **音量つまみ** です。最初は `vol` の大きさで、`dur` 秒かけて 0.001（ほぼ無音）へなめらかに小さくすることで、「プツッ」と切れずに自然に消える音になります。
- 発振器 → 音量つまみ → スピーカー（`audio.destination`）の順につないで、`start()` で鳴らし、`stop()` で止める時刻を予約します。

## 効果音を入れる

あちこちに `beep()` を足していきます。

`startGame()` の `startLevel();` の **下** に追加:

```js:game.js
    beep(660, 0.1, 'triangle');
```

`clearLevel()` の `toast(...)` の **下** に、ドミソドの和音を少しずつずらして鳴らすファンファーレを追加:

```js:game.js
    [523, 659, 784, 1046].forEach((f, k) => setTimeout(() => beep(f, 0.12, 'triangle'), k * 90));
```

`tap()` は全体を次のように **書きかえ** ます（`beep` の行が4か所増えます）。

```js:game.js
  function tap(i) {
    if (!playing || busy || i < 0 || i >= tubes.length) return;
    if (sel < 0) {
      if (!tubes[i].length || isDoneTube(tubes[i])) { shake(i); return; }
      sel = i; beep(520, 0.05); render(); return;
    }
    if (sel === i) { sel = -1; render(); return; }
    const a = tubes[sel], b = tubes[i];
    if (!canPour(a, b)) {
      // switch selection if tapping another pourable tube
      if (b.length && !isDoneTube(b)) { sel = i; beep(520, 0.05); render(); }
      else { shake(i); }
      return;
    }
    history.push(tubes.map((t) => t.slice()));
    const n = Math.min(runLen(a), CAP - b.length);
    for (let m = 0; m < n; m++) b.push(a.pop());
    sel = -1;
    beep(300 + b.length * 90, 0.12, 'sine', 0.1);
    if (isDoneTube(b)) setTimeout(() => beep(880, 0.1, 'triangle'), 120);
    render(i, n); hud();
    if (isSolved(tubes)) clearLevel();
  }
```

そそいだときの音は `300 + b.length * 90` Hz なので、ビンがいっぱいになるほど高い音になります。本物のビンに水を注ぐと音が高くなっていくのと同じです。1本そろったときは、少し遅れて「ピン」と高い音を重ねます。

`shake()` の先頭（`const el = ...` の **上**）に、低いブザー音を追加:

```js:game.js
    beep(150, 0.08, 'square', 0.05);
```

`undo()` の `render(); hud();` の行を、次のように **書きかえ**:

```js:game.js
    beep(400, 0.06); render(); hud();
```

> [!CHECK] 動作チェック
> - ビンを選ぶと「ピッ」、そそぐと音が鳴り、ビンがいっぱいになるほど高い音になる
> - そそげないと「ブッ」と低い音、クリアするとファンファーレが鳴る
> - タイムアップ画面に「（ベスト 〇〇）」が出て、ヘッダーの BEST が更新される
> - ページを再読み込みしても BEST の数字が残っている
> - 「もう一度あそぶ」で SCORE と LEVEL は 0・1 に戻り、BEST はそのまま
> - これで完成品と同じ遊び方ができる。おつかれさまでした！

## 改造アイデア

> [!TIP]
> **ヒントボタン:** ステップ5の `solvable()` を少し改造して「最初にためした1手」を返すようにすれば、次にそそぐべきビンを光らせるヒント機能が作れます。使うたびに時間を減らすとバランスがとれます。

> [!TIP]
> **ビンを増やすアイテム:** 1レベルに1回だけ使える「空きビン追加」ボタンを作ってみましょう。`tubes.push([])` してから `layout(); render();` を呼ぶだけで、ビンが1本増えます。

> [!TIP]
> **かくれた色:** 底のほうの色水を「？」にしておき、上の色水がなくなって一番上に出てきたときに初めて色が見えるようにすると、ぐっと難しくなります。`render()` で「上の段以外は灰色で描く」ところから始めてみましょう。

> [!TIP]
> **5段のビン:** `CAP` を 5 にすると、それだけで1本に5段入るようになります。CSS の `.tube` の高さ（`* 4`）と `layout()` の計算もあわせて直してみましょう。定数にしておいたありがたみが分かるはずです。
