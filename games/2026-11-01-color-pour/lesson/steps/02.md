## このステップのゴール

ビンと色水を画面に描きます。ポイントは **「データ」と「見た目」を分ける** ことです。

- ビンの中身は、ただの **配列の配列**（`tubes`）で持つ
- `render()` 関数が、その配列を見て `div` を作り直す

こうしておくと、このあと「そそぐ」「もどす」などの処理は配列を書きかえるだけで済み、最後に `render()` を呼べば画面が追いついてきます。このステップでは、決まった並びのお試し盤面を表示します。

## 定数を追加する

`'use strict';` の **下** に、2つの定数を追加します。

```js:game.js
  const CAP = 4;
  const COLORS = ['#ff5a7a', '#ffc93c', '#4cd3ff', '#6ee07a', '#b07aff', '#ff9a3c', '#f7f7f7', '#3c6bff', '#ff7ad9', '#27b39b'];
```

- `CAP` は1本のビンに入る段数（capacity）です。4 を何度も書く代わりに名前をつけておくと、あとで「5段にしたい」と思ったときに1か所直すだけで済みます。
- `COLORS` は色水の色の一覧です。ビンの中身には色そのものではなく **色の番号（0, 1, 2…）** を入れ、表示するときだけ `COLORS[番号]` で色に変えます。番号なら「同じ色か？」を `===` で簡単に比べられます。

## ビンのデータを用意する

`const board = $('board'), overlay = $('overlay');` の **下** に、ビンの一覧を入れる変数を追加します。

```js:game.js

  let tubes = [];
```

ビン1本は「下から順に色番号を並べた配列」で表します。たとえば `[0, 1, 2, 0]` は「底から 赤・黄・水色・赤」で、**配列の最後がいちばん上** です。こうすると、いちばん上の色を取り出すのは `pop()`、上に乗せるのは `push()` と、配列の基本操作がそのまま使えます。空のビンは `[]` です。

## 描画の関数を追加する

`// ---------- game flow ----------` の **上** に、次のコードを追加します。

```js:game.js
  // ---------- rendering ----------
  function layout() {
    const n = tubes.length;
    const stage = $('stage');
    const W = stage.clientWidth - 12, H = stage.clientHeight - 12;
    const rows = n <= 6 ? 1 : 2;
    const perRow = Math.ceil(n / rows);
    const gapX = 12;
    const tw = Math.max(30, Math.min(54, (W - gapX * (perRow - 1)) / perRow));
    const rowH = (H - 26 * rows) / rows;
    const seg = Math.max(22, Math.min(40, (rowH - 30) / CAP, tw * 0.85));
    board.style.setProperty('--tw', tw + 'px');
    board.style.setProperty('--seg', seg + 'px');
    board.style.maxWidth = (perRow * tw + (perRow - 1) * gapX + 2) + 'px';
  }

  function render() {
    board.innerHTML = '';
    tubes.forEach((t, i) => {
      const el = document.createElement('div');
      el.className = 'tube';
      el.dataset.i = i;
      const num = document.createElement('span');
      num.className = 'num'; num.textContent = (i + 1) % 10;
      el.appendChild(num);
      t.forEach((c) => {
        const s = document.createElement('div');
        s.className = 'seg';
        s.style.background = `linear-gradient(90deg, ${COLORS[c]}, ${COLORS[c]}cc)`;
        el.appendChild(s);
      });
      board.appendChild(el);
    });
  }

```

### layout() … 画面に合わせた大きさを決める

- ビンが6本までなら1列、それより多ければ2列に並べます（`rows`）。1列あたりの本数 `perRow` から、ビンの幅 `tw` を「画面の横幅に収まる大きさ」で計算します。
- `Math.max(最小, Math.min(最大, 計算値))` は、値を **最小〜最大の範囲に収める** 定番の書き方です。小さすぎても大きすぎても遊びにくいので、幅は 30〜54px、1段の高さは 22〜40px に収めています。
- 決まった値は `board.style.setProperty('--tw', ...)` で **CSS 変数** に入れます。`.tube` や `.seg` の CSS が `var(--tw)`・`var(--seg)` を使っているので、これだけで全部のビンの大きさが変わります。
- `maxWidth` を「1列ぶんの幅」にしておくと、`flex-wrap` で折り返したときに、ちょうど `perRow` 本ずつで改行されます。

### render() … 配列から div を作る

- `board.innerHTML = ''` で一度中身を全部消し、`tubes` を先頭から見て `div.tube` を作り直します。毎回作り直すのは乱暴に見えますが、ビンは多くても十数本なので一瞬で終わり、「データと画面がずれる」心配がなくなります。
- `el.dataset.i = i` で、HTML に `data-i="0"` のような属性がつきます。あとでタップされたビンが何番目かを調べるのに使います。
- `num` はビンの上に出る小さな番号です。`(i + 1) % 10` で 1, 2, …, 9, 0 となり、キーボードの数字キーと対応させます（ステップ7で使います）。
- 色水1段ぶんが `div.seg` です。`linear-gradient` で左から右へ少しだけ透明にして（色コードの後ろの `cc` は不透明度 80%）、ガラスっぽいツヤを出しています。

## スタート時にお試し盤面を出す

`startGame()` 関数を、次のように **書きかえ** ます。

```js:game.js
  function startGame() {
    overlay.classList.add('hide');
    tubes = [
      [0, 1, 2, 0],
      [1, 2, 0, 1],
      [2, 0, 1, 2],
      [],
      [],
    ];
    layout(); render();
  }
```

3色×4段の色水が入ったビンが3本と、空のビンが2本です。どの色もちょうど4つずつ入っていることを確かめてみてください。

最後に、ファイルの最後の `})();` の **上** に、画面サイズが変わったときの処理を追加します。

```js:game.js

  window.addEventListener('resize', () => { if (tubes.length) { layout(); render(); } });
```

スマホを横にしたり、PC でウィンドウの大きさを変えたりしたときに、ビンの大きさを計算し直します。

> [!CHECK] 動作チェック
> - スタートすると、色水の入ったビンが3本と空のビンが2本、横一列に並ぶ
> - 1本目のビンが、下から 赤・黄・水色・赤 になっている（配列の最後が上）
> - ビンの上に 1〜5 の小さな番号が出ている
> - ブラウザの幅を変えると、ビンの大きさが合わせて変わる
