## このステップのゴール

スタートすると、盤面の一番上に **数字のついたブロック** と **緑のリング** が1列ぶん並ぶようにします。ブロックの色は数字（残り耐久）によって青〜赤に変わります。

## 変数を増やす

ファイルの先頭のほう、`let bricks = null;` の行を次のように **書きかえ** ます。

```js:game.js
  let bricks = null, pickups = [], level;
```

- `bricks` … ブロックの配列。1個は `{ c: 列, r: 段, hp: 残り耐久, max: 最初の耐久, shake: ゆれ }` というオブジェクトです（`shake` はステップ7で使います）
- `pickups` … 緑のリングの配列。`{ c: 列, r: 段, t: アニメーションのずらし }`
- `level` … いまのステージ番号。ブロックの硬さを決めるのに使います

## spawnRow() … 1列ぶんを出す

`// ---- game logic ----` の **すぐ下**（`function startGame()` の上）に追加します。

```js:game.js
  function spawnRow() {
    const cols = [0, 1, 2, 3, 4, 5, 6].sort(() => Math.random() - 0.5);
    const n = Math.min(6, 1 + Math.floor(Math.random() * (level < 4 ? 3 : 5)) + (level > 15 ? 1 : 0));
    for (let i = 0; i < n; i++) {
      const hp = Math.random() < 0.25 + Math.min(0.25, level * 0.01) ? level * 2 : level;
      bricks.push({ c: cols[i], r: 0, hp, max: hp, shake: 0 });
    }
    pickups.push({ c: cols[n], r: 0, t: Math.random() * 6 });
  }
```

1. `cols` は 0〜6 の列番号を **シャッフル** したものです。`sort` に「ランダムにプラスかマイナスを返す関数」を渡すと、並びがばらばらになります（厳密に公平なシャッフルではありませんが、ゲームにはこれで十分です）。
1. `n` はこの列に置くブロックの数です。序盤（ステージ1〜3）は 1〜3 個、それ以降は 1〜5 個、ステージ16からはさらに1個増えます。ただし最大 6 個までにして、**必ず1マスは空きを残します**。
1. シャッフルした列の先頭から `n` 個にブロックを置きます。数字（`hp`）はふつう `level` と同じで、ときどき2倍の硬いブロックが混ざります。ステージが進むほど硬いブロックの確率が上がります。
1. 残した空きのうち `cols[n]` にリングを1個置きます。ブロックは最大6個なので、`cols[n]` は必ず空いている列です。

`{ c: cols[i], r: 0, hp, max: hp, shake: 0 }` の `hp` は、`hp: hp` の省略形です。変数名とプロパティ名が同じときはこう書けます。

## startGame() を書きかえる

`function startGame()` を次のように **書きかえ** ます。

```js:game.js
  function startGame() {
    bricks = []; pickups = [];
    level = 1;
    spawnRow();
    state = 'aim';
    overlay.classList.add('hide');
  }
```

## brickRect() と brickHue()

`startGame()` の **下**、`// ---- render ----` の **上** に追加します。

```js:game.js
  function brickRect(b) {
    return { x: b.c + 0.05, y: TOP + b.r + 0.05, w: 0.9, h: 0.9 };
  }

  function brickHue(b) {
    const t = Math.min(1, b.hp / Math.max(1, level * 2));
    return 200 - t * 200;
  }
```

- `brickRect()` は、ブロックの「列・段」を盤面上の四角形（左上の x, y と幅・高さ）に変換します。マスいっぱいではなく `0.9` にして、まわりに `0.05` ずつすき間を空けています。描くときも当たり判定のときも、この関数を通して同じ四角形を使うのがポイントです。
- `brickHue()` は色相（hue）を返します。色相は色を 0〜360 の角度で表したもので、200 は青、0 は赤です。「いまのステージで一番硬いブロック（`level * 2`）に対してどれくらい硬いか」を 0〜1 の `t` にして、柔らかいほど青、硬いほど赤にしています。

## roundRect() … 角の丸い四角

`// ---- render ----` の **すぐ下**（`function draw` の上）に追加します。

```js:game.js
  function roundRect(x, y, w, h, r) {
    ctx.beginPath();
    ctx.moveTo(x + r, y); ctx.arcTo(x + w, y, x + w, y + h, r); ctx.arcTo(x + w, y + h, x, y + h, r);
    ctx.arcTo(x, y + h, x, y, r); ctx.arcTo(x, y, x + w, y, r); ctx.closePath();
  }
```

`arcTo` は「次の角に向かって進み、半径 `r` で丸く曲がる」線を引く命令です。4つの角で順に曲がると、角の丸い四角の形（パス）ができます。この関数は形を作るだけなので、呼んだあとに `ctx.fill()` で塗ります。

## リングとブロックを描く

`draw()` の最後、`if (!bricks) return;` の **下** に追加します。

```js:game.js
    // pickups
    for (const p of pickups) {
      const px = p.c + 0.5, py = TOP + p.r + 0.5, pr = 0.2 + 0.03 * Math.sin(time / 200 + p.t);
      ctx.strokeStyle = '#6ff0a0'; ctx.lineWidth = 0.06;
      ctx.beginPath(); ctx.arc(px, py, pr, 0, Math.PI * 2); ctx.stroke();
      ctx.fillStyle = '#6ff0a0';
      ctx.beginPath(); ctx.arc(px, py, 0.08, 0, Math.PI * 2); ctx.fill();
    }
    // bricks
    ctx.textAlign = 'center'; ctx.textBaseline = 'middle';
    for (const b of bricks) {
      const rc = brickRect(b);
      const hue = brickHue(b);
      ctx.fillStyle = `hsl(${hue},85%,58%)`;
      roundRect(rc.x, rc.y, rc.w, rc.h, 0.12); ctx.fill();
      ctx.fillStyle = 'rgba(0,0,0,.18)';
      ctx.fillRect(rc.x + 0.05, rc.y + rc.h - 0.12, rc.w - 0.1, 0.07);
      ctx.fillStyle = '#1a0f2e';
      ctx.font = `800 ${b.hp >= 100 ? 0.32 : 0.4}px system-ui, sans-serif`;
      ctx.fillText(b.hp, rc.x + rc.w / 2, rc.y + rc.h / 2 + 0.02);
    }
```

- リングはマスの中心（`c + 0.5`）に、輪と中心の点を描きます。半径に `Math.sin(time / 200 + p.t)` を足しているので、ふわふわと脈打ちます。`p.t` をリングごとにずらしているので、全部が同時には動きません。
- ブロックの色は `hsl(色相, 彩度, 明るさ)` で指定します。色相だけを変えれば、明るさをそろえたまま青〜赤に変えられます。
- 下のふちに少し暗い帯を重ねて、立体っぽく見せています。
- 文字の大きさも **マス単位** です。`0.4px` はとても小さく見えますが、全体を `scale` 倍に拡大しているので、ちょうどブロックに収まる大きさになります。3けたになったら少し小さくします。

> [!CHECK] 動作チェック
> - スタートすると、盤面の一番上の段に 1〜3 個のブロックと、緑のリングが1個並ぶ
> - ブロックには「1」か「2」の数字が書かれ、「1」は緑、「2」は赤で表示される（ステージが進むと、柔らかいブロックほど青っぽくなる）
> - 緑のリングがふわふわ大きさを変えている
> - 再読み込みしてスタートし直すたびに、並び方が変わる
