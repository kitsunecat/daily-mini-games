## このステップのゴール

指を離したらボールを **発射** し、壁と天井で跳ね返して、床に戻ってきたらターンを終えるようにします。ボールは何個あっても、少しずつ間をあけて同じ向きに連続発射します。最初に床に着いたボールの場所が、次の発射位置になります。

このステップではまだブロックには当たらず、すり抜けます（当たり判定は次のステップです）。

## 定数と変数を増やす

ステップ3で足した `const R = 0.14; // ball radius` の行を、次のように **書きかえ** ます。

```js:game.js
  const R = 0.14, SPEED = 0.24, GAP = 5; // ball radius, units per frame, frames between launches
```

- `SPEED` … ボールが1フレームで進む距離（マス）
- `GAP` … 次のボールを撃つまでに待つフレーム数

`let` の2行を、次のように **書きかえ** ます。

```js:game.js
  let bricks = null, pickups = [], balls = [], ballCount, launchX, nextX, level;
  let aimAng = Math.PI / 2, aiming = false, toLaunch = 0, launchTimer = 0;
```

- `balls` … 飛んでいるボールの配列。1個は `{ x, y, vx, vy, done }` で、`done` は床に戻ったかどうか
- `ballCount` … 持っているボールの数
- `nextX` … 次のターンの発射位置（最初に床に着いたボールの x）。まだ決まっていなければ `null`
- `toLaunch` … これから撃つ残りの数、`launchTimer` … 次を撃つまでの残りフレーム

## startGame()・endTurn()・fire()

`function startGame()` を **書きかえ** て、その下に `endTurn()` と `fire()` を追加します（`function brickRect` の上までがこのコードになります）。

```js:game.js
  function startGame() {
    bricks = []; pickups = []; balls = [];
    ballCount = 1; level = 1;
    launchX = BW / 2; nextX = null; aimAng = Math.PI / 2;
    spawnRow();
    state = 'aim';
    overlay.classList.add('hide');
  }

  function endTurn() {
    if (nextX != null) launchX = nextX;
    nextX = null;
    state = 'aim';
  }

  function fire() {
    if (state !== 'aim') return;
    state = 'fire';
    balls = []; toLaunch = ballCount; launchTimer = 0;
  }
```

`fire()` はボールをすぐには作らず、「これから `ballCount` 個撃つ」と予約するだけです。実際に1個ずつ出すのは、毎フレーム呼ばれる `update()` の仕事です。`endTurn()` はステップ6で、ブロックを下げる処理などを足して完成させます。

## stepBall() と update()

`function brickRect` の **下**、`function brickHue` の **上** に追加します。

```js:game.js
  function stepBall(o) {
    o.x += o.vx; o.y += o.vy;
    if (o.x < R) { o.x = R; o.vx = Math.abs(o.vx); }
    if (o.x > BW - R) { o.x = BW - R; o.vx = -Math.abs(o.vx); }
    if (o.y < R) { o.y = R; o.vy = Math.abs(o.vy); }
    // avoid near-horizontal loops
    if (Math.abs(o.vy) < SPEED * 0.12) o.vy = (o.vy < 0 ? -1 : 1) * SPEED * 0.12;
    if (o.vy > 0 && o.y >= FLOOR - R) {
      o.y = FLOOR - R; o.done = true;
      if (nextX == null) nextX = Math.max(R, Math.min(BW - R, o.x));
    }
  }

  function update() {
    if (state === 'fire') {
      if (toLaunch > 0 && --launchTimer <= 0) {
        balls.push({ x: launchX, y: FLOOR - R, vx: Math.cos(aimAng) * SPEED, vy: -Math.sin(aimAng) * SPEED, done: false });
        toLaunch--; launchTimer = GAP;
      }
      for (const o of balls) {
        if (o.done) {
          if (nextX != null) o.x += (nextX - o.x) * 0.2;
          continue;
        }
        stepBall(o);
      }
      if (toLaunch === 0 && balls.every(o => o.done)) endTurn();
    }
  }
```

### 壁で跳ね返す

`stepBall()` は、ボール1個を1歩ぶん動かす関数です。

1. 速さ（`vx`, `vy`）ぶん位置を進めます。
1. 左の壁を越えたら、位置を壁の内側に戻して、`vx` を **右向き（プラス）** にします。右の壁と天井も同じです。
1. ボールのふちが壁に触れたら跳ね返したいので、比べる相手は `0` ではなく半径 `R` です。

`vx = -vx`（向きを反対にする）ではなく `Math.abs` で **向きを決め打ち** しているのがポイントです。壁の外にはみ出したままもう一度判定されても、ボールが壁の中でガタガタ往復することがありません。

### ほぼ真横を防ぐ

ブロックに当たった角度によっては、ボールがほとんど真横に飛んで、壁と壁のあいだを延々と往復することがあります。そこで縦の速さが小さすぎるときは、最低限の値（`SPEED * 0.12`）まで引き上げます。

### 床に戻る

下向きに動いていて（`o.vy > 0`）床に着いたら、`done` にして止めます。そのターンで **最初に** 戻ったボールの x を `nextX` として覚えます。

### update() … 連続発射と、ターンの終わり

- `--launchTimer <= 0` は「1減らして、0以下になったら」という意味です。`GAP` フレームごとに1個ずつボールを作るので、ボールが一列につながって飛んでいきます。
- 床に戻ったボールは、`nextX` に向かって毎フレーム残りの距離の 20% ずつ近づきます。こうすると、すっと集まっていく動きになります。
- 全部撃ち終わって（`toLaunch === 0`）、全部が床に戻ったら（`balls.every(o => o.done)`）ターン終了です。`every` は「配列の全部が条件を満たすか」を調べるメソッドです。

## ボールと残り数を描く

`draw()` の `// balls` のところに、飛んでいるボールと「×1」のような残り数の表示を足します。`// balls` から `draw()` の最後までを次のように **書きかえ** ます。

```js:game.js
    // balls
    ctx.fillStyle = '#fff';
    if (state === 'aim' || state === 'over') {
      ctx.beginPath(); ctx.arc(launchX, FLOOR - R, R, 0, Math.PI * 2); ctx.fill();
    }
    if (state === 'fire') {
      for (const o of balls) { ctx.beginPath(); ctx.arc(o.x, o.y, R, 0, Math.PI * 2); ctx.fill(); }
      if (toLaunch > 0) { ctx.beginPath(); ctx.arc(launchX, FLOOR - R, R, 0, Math.PI * 2); ctx.fill(); }
    }
    // ball count label
    const remain = state === 'fire' ? toLaunch : ballCount;
    if (remain > 0 && state !== 'over') {
      ctx.fillStyle = '#ddd3f5'; ctx.font = '700 0.3px system-ui, sans-serif';
      const lx = Math.max(0.4, Math.min(BW - 0.4, launchX));
      ctx.fillText('×' + remain, lx, FLOOR - R - 0.4);
    }
  }
```

発射中も、まだ撃っていないボールが残っていれば発射位置にボールを描いておきます。残り数のラベルは、発射位置が端のときに画面からはみ出さないよう、x を `0.4` 〜 `BW - 0.4` に収めています。

## ゲームループと指を離したとき

`function loop(t)` の中で、`draw(t);` の **前** に `update();` を足します。

```js:game.js
  function loop(t) {
    update();
    draw(t);
    requestAnimationFrame(loop);
  }
```

`pointerup` の中の1行に `fire();` を足します。

```js:game.js
    if (aiming && state === 'aim') { aiming = false; setAimFrom(toBoard(e)); fire(); }
```

> [!CHECK] 動作チェック
> - ドラッグしてねらい、指（マウス）を離すとボールが飛んでいく
> - ボールは左右の壁と天井で跳ね返り、床に落ちると止まる（ブロックはすり抜ける）
> - ボールが止まった場所に発射位置が移り、もう一度ねらえるようになる
> - 「×1」の表示が発射位置の上についてくる

> [!TIP]
> 連続発射のようすを見たいときは、`startGame()` の `ballCount = 1;` を一時的に `ballCount = 10;` にしてみましょう。ボールが一列になって飛び、最初に着いた場所に集まっていきます。確かめたら `1` に戻してください。
