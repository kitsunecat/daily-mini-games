## このステップのゴール

盤面をドラッグして **ねらいを定める** ようにします。床の上に白いボールを置き、そこから指（マウス）の方向に、最初に壁やブロックにぶつかるあたりまでの **予測線**（点線）を描きます。

## 定数と変数を増やす

`const FLOOR = BH - 0.25;` の **下** に2行追加します。

```js:game.js
  const R = 0.14; // ball radius
  const MIN_ANG = 8 * Math.PI / 180;
```

`let bricks = null, pickups = [], level;` の行を、次の2行に **書きかえ** ます。

```js:game.js
  let bricks = null, pickups = [], launchX, level;
  let aimAng = Math.PI / 2, aiming = false;
```

- `R` … ボールの半径（マス単位）
- `MIN_ANG` … ねらえる一番浅い角度。8度です。JavaScript の角度は **ラジアン**（180度 = `Math.PI`）で表すので、度に `Math.PI / 180` をかけて変換します
- `launchX` … ボールを撃ち出す床の上の x 座標
- `aimAng` … ねらいの角度。右向きが 0、真上が `Math.PI / 2`、左向きが `Math.PI` です
- `aiming` … いまドラッグ中かどうか

## startGame() に1行足す

`startGame()` の `level = 1;` の **下** に、発射位置とねらいを初期化する行を足します。

```js:game.js
  function startGame() {
    bricks = []; pickups = [];
    level = 1;
    launchX = BW / 2; aimAng = Math.PI / 2;
    spawnRow();
    state = 'aim';
    overlay.classList.add('hide');
  }
```

最初は盤面のまん中（`BW / 2`）から、真上に向けておきます。

## predict() … 予測線の点を求める

`function brickHue` の **下**、`// ---- render ----` の **上** に追加します。

```js:game.js
  // ---- aim prediction ----
  function predict() {
    const pts = [];
    let x = launchX, y = FLOOR - R, vx = Math.cos(aimAng) * 0.12, vy = -Math.sin(aimAng) * 0.12;
    let bounces = 0;
    for (let i = 0; i < 400 && bounces < 1; i++) {
      x += vx; y += vy;
      if (x < R || x > BW - R) { vx = -vx; bounces++; }
      if (y < R) { vy = -vy; bounces++; }
      let hit = false;
      for (const b of bricks) {
        const rc = brickRect(b);
        if (x > rc.x - R && x < rc.x + rc.w + R && y > rc.y - R && y < rc.y + rc.h + R) { hit = true; break; }
      }
      if (hit) break;
      if (i % 4 === 0) pts.push([x, y]);
    }
    return pts;
  }
```

「見えないボール」を少しずつ進めて、通った場所を点として集めています。

- 角度から速さの向きを出すのが **三角関数** です。角度 `a` の方向に長さ 1 進むと、横に `Math.cos(a)`、縦に `Math.sin(a)` 動きます。Canvas は **下に行くほど y が大きい** ので、上に飛ばすには `vy` にマイナスをつけます。
- 壁か天井に1回当たったら（`bounces < 1` でなくなったら）終わり、ブロックの四角（ボールの半径ぶん広げたもの）に入っても終わりです。最後まで見せてしまうと簡単すぎるので、「最初にどこへ当たるか」だけを教えます。
- 4歩に1回だけ点を記録して、すき間のある点線にしています。

## 予測線とボールを描く

`draw()` の最後、`// bricks` の `for` ループの **下** に追加します。

```js:game.js
    // aim line
    if (state === 'aim') {
      ctx.fillStyle = aiming ? 'rgba(255,255,255,.85)' : 'rgba(255,255,255,.35)';
      for (const [x, y] of predict()) { ctx.beginPath(); ctx.arc(x, y, 0.05, 0, Math.PI * 2); ctx.fill(); }
    }
    // balls
    ctx.fillStyle = '#fff';
    if (state === 'aim' || state === 'over') {
      ctx.beginPath(); ctx.arc(launchX, FLOOR - R, R, 0, Math.PI * 2); ctx.fill();
    }
```

ドラッグ中（`aiming`）は予測線をはっきり、指を離しているときはうっすら描きます。`for (const [x, y] of ...)` は、`[x, y]` の配列を1つずつ取り出して、そのまま `x` と `y` に分けて受け取る書き方（分割代入）です。

## 入力 … Pointer Events でドラッグを受け取る

`// ---- input ----` の **すぐ下**（`startBtn.addEventListener` の上）に追加します。

```js:game.js
  function toBoard(e) {
    const r = cv.getBoundingClientRect();
    return { x: (e.clientX - r.left) / scale, y: (e.clientY - r.top) / scale };
  }
  function setAimFrom(p) {
    let dx = p.x - launchX, dy = (FLOOR - R) - p.y;
    let a = Math.atan2(dy, dx);
    if (dy < 0) a = dx < 0 ? Math.PI - MIN_ANG : MIN_ANG;
    aimAng = Math.max(MIN_ANG, Math.min(Math.PI - MIN_ANG, a));
  }
  cv.addEventListener('pointerdown', e => {
    e.preventDefault();
    if (state === 'aim') {
      aiming = true; setAimFrom(toBoard(e));
      try { cv.setPointerCapture(e.pointerId); } catch (err) {}
    }
  });
  cv.addEventListener('pointermove', e => { if (aiming && state === 'aim') setAimFrom(toBoard(e)); });
  cv.addEventListener('pointerup', e => {
    if (aiming && state === 'aim') { aiming = false; setAimFrom(toBoard(e)); }
    aiming = false;
  });
  cv.addEventListener('pointercancel', () => { aiming = false; });

```

- **Pointer Events**（`pointerdown` / `pointermove` / `pointerup`）は、マウスとタッチとペンをまとめて扱えるイベントです。スマホと PC を1つのコードで動かせます。
- `toBoard()` は、画面上のピクセル座標（`clientX`, `clientY`）を **盤面のマス座標** に直します。Canvas の左上からの距離を `scale` で割るだけです。
- `setAimFrom()` は、発射位置から指の位置へ向かう角度を `Math.atan2(縦の差, 横の差)` で求めます。`atan2` は「この向きは何ラジアン？」に答えてくれる関数で、`cos`・`sin` の逆の働きをします。ここでは上を正にしたいので、縦の差を「発射位置 − 指の位置」にしています。
- 指が床より下に来たとき（`dy < 0`）や、ほぼ真横を向いたときは、`MIN_ANG` 〜 `Math.PI - MIN_ANG` の範囲に収めます。真横に撃つとボールがいつまでも落ちてこないからです。
- `setPointerCapture` をしておくと、ドラッグ中に指が Canvas の外に出ても `pointermove` / `pointerup` が届き続けます。

> [!CHECK] 動作チェック
> - スタートすると、床のまん中に白いボールがあり、真上に向かってうっすらした点線が伸びている
> - 盤面を押してドラッグすると点線がはっきりして、指（マウス）の方向に向きが変わる
> - 点線は壁や天井に当たったところ、またはブロックの手前で止まる
> - 指を床より下に動かしても、ボールが真横より下を向くことはない
