## このステップのゴール

ボールが **ブロックに当たって跳ね返り**、当たるたびにブロックの数字が1減って、0になったら消えるようにします。当てた回数がスコアになり、ターンが終わると画面上の STAGE・SCORE・ボールの数が更新されます。

## 変数を増やす

ファイルの先頭の `let bricks = ...` の行の最後に `score` を足して **書きかえ** ます。

```js:game.js
  let bricks = null, pickups = [], balls = [], ballCount, launchX, nextX, level, score;
```

## updateHud() … 画面の数字を書きかえる

`startGame()` と `endTurn()` を **書きかえ** て、`endTurn()` の下に `updateHud()` を追加します。

```js:game.js
  function startGame() {
    bricks = []; pickups = []; balls = [];
    ballCount = 1; level = 1; score = 0;
    launchX = BW / 2; nextX = null; aimAng = Math.PI / 2;
    spawnRow();
    state = 'aim';
    overlay.classList.add('hide');
    updateHud();
  }

  function endTurn() {
    if (nextX != null) launchX = nextX;
    nextX = null;
    state = 'aim';
    updateHud();
  }

  function updateHud() {
    $('stage-no').textContent = level || 1;
    $('score').textContent = score || 0;
    $('balls').textContent = ballCount;
  }
```

HUD（ヘッドアップディスプレイ）は、ゲーム画面にかぶせて出す情報表示のことです。`textContent` に代入すると、その要素の文字が書きかわります。スコアはボールが飛んでいるあいだにもどんどん増えますが、表示の更新はターンの終わりにまとめて行います。

## hitBrick() … 当たったブロックを削る

`function brickRect` の **下**、`function stepBall` の **上** に追加します。

```js:game.js
  function hitBrick(b) {
    b.hp--; score++;
    if (b.hp <= 0) {
      bricks.splice(bricks.indexOf(b), 1);
    }
  }
```

`splice(位置, 1)` は配列から1個取り除くメソッドです。`indexOf(b)` で `b` が配列の何番目かを調べてから消しています。

## stepBall() にブロックとの当たり判定を足す

`stepBall()` の、天井の判定（`if (o.y < R) ...`）の **下**、`// avoid near-horizontal loops` の **上** に追加します。

```js:game.js
    for (let i = bricks.length - 1; i >= 0; i--) {
      const b = bricks[i], rc = brickRect(b);
      const cx = Math.max(rc.x, Math.min(o.x, rc.x + rc.w));
      const cy = Math.max(rc.y, Math.min(o.y, rc.y + rc.h));
      const dx = o.x - cx, dy = o.y - cy;
      if (dx * dx + dy * dy < R * R) {
        const penX = Math.min(Math.abs(o.x - rc.x), Math.abs(o.x - rc.x - rc.w));
        const penY = Math.min(Math.abs(o.y - rc.y), Math.abs(o.y - rc.y - rc.h));
        const inside = cx === o.x && cy === o.y;
        if ((inside && penX < penY) || (!inside && Math.abs(dx) > Math.abs(dy))) {
          o.vx = o.x < rc.x + rc.w / 2 ? -Math.abs(o.vx) : Math.abs(o.vx);
          o.x = o.x < rc.x + rc.w / 2 ? rc.x - R : rc.x + rc.w + R;
        } else {
          o.vy = o.y < rc.y + rc.h / 2 ? -Math.abs(o.vy) : Math.abs(o.vy);
          o.y = o.y < rc.y + rc.h / 2 ? rc.y - R : rc.y + rc.h + R;
        }
        hitBrick(b);
        break;
      }
    }
```

ここがこのゲームでいちばん大事な **当たり判定** です。

### 円と四角が重なっているか

1. 四角の中で、ボールの中心に **いちばん近い点** `(cx, cy)` を求めます。ボールの x を「四角の左端〜右端」の範囲に収めたものが `cx`、y を「上端〜下端」に収めたものが `cy` です（`Math.max(最小, Math.min(値, 最大))` は、値を範囲に収める定番の書き方です）。
1. その点とボールの中心の距離が半径 `R` より短ければ、重なっています。距離そのもの（平方根）を計算しなくても、**2乗どうしで比べれば** 同じ結果になります（`dx * dx + dy * dy < R * R`）。

### どちら向きに跳ね返すか

- 近い点がボールの **左右** にあれば（`|dx| > |dy|`）、ブロックの横の面に当たったので `vx` を反転し、縦の面にあれば `vy` を反転します。
- 速いボールは、まれに中心がブロックの中まで入りこんでしまいます（`inside`）。そのときは、左右と上下のどちらの面に近いか（`penX` と `penY`）で決めます。
- 反転した向きに合わせて、ボールをブロックの外側（ちょうど触れる位置）まで押し戻します。押し戻さないと、次のフレームでもまた当たってしまいます。

ブロックに当たったら `break` して、1歩で1個のブロックにしか当たらないようにしています。ブロックの配列を後ろから回しているのは、`hitBrick()` の中で配列から消しても、まだ見ていないブロックの番号がずれないようにするためです。

## update() で1フレームを2回に分けて動かす

`update()` の中の `stepBall(o);` の1行を、次のように **書きかえ** ます。

```js:game.js
        // substeps so fast balls don't tunnel
        const n = 2;
        const vx = o.vx, vy = o.vy;
        o.vx = vx / n; o.vy = vy / n;
        for (let k = 0; k < n && !o.done; k++) stepBall(o);
        o.vx *= n; o.vy *= n;
```

ボールは1フレームで `0.24` マス進みます。一度に大きく進むと、ブロックの角をかすめるような場面で **すり抜け**（トンネリング）が起きやすくなります。そこで速さを半分にして2回に分けて動かし、毎回当たり判定をしています。動かし終わったら速さを元に戻します。

> [!CHECK] 動作チェック
> - ボールがブロックに当たると跳ね返り、ブロックの数字が1減る
> - 数字が 0 になったブロックは消える
> - ブロックの横の面に当たると横に、下の面に当たると下に跳ね返る
> - ボールが床に戻ると、上の SCORE が当てた回数だけ増えている
