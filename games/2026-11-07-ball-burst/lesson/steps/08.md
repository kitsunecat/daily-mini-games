## このステップのゴール

最後の仕上げです。**ハイスコアをブラウザに保存** して BEST に表示し、ゲームオーバー画面で更新を知らせます。**効果音** を Web Audio API で鳴らし、**キーボード** でもねらって撃てるようにします。これで完成品と同じになります。

## ハイスコアを読みこむ

`let bricks = ...` の行の最後に `best = 0` を足して **書きかえ** ます。

```js:game.js
  let bricks = null, pickups = [], balls = [], ballCount, gained, launchX, nextX, level, score, best = 0;
```

`let particles = [], flashes = [];` の行の **下** に、空行をはさんで追加します。

```js:game.js
  try { best = parseInt(localStorage.getItem('ballBurstBest') || '0', 10) || 0; } catch (e) {}
  $('best').textContent = best;
```

**localStorage** は、ブラウザにちょっとした文字列を保存しておける仕組みです。ページを閉じても消えません。`getItem` で読み、`setItem` で書きます。保存されるのは文字列だけなので、`parseInt` で数値に直します。まだ何も保存されていなければ `'0'` を使います。

プライベートブラウズなど、localStorage が使えない環境ではエラーになることがあるので、`try { ... } catch (e) {}` で囲んで、失敗してもゲームは動くようにしています。

`updateHud()` に、BEST を書きかえる行を足します。

```js:game.js
  function updateHud() {
    $('stage-no').textContent = level || 1;
    $('score').textContent = score || 0;
    $('best').textContent = best;
    $('balls').textContent = ballCount + (gained ? ` (+${gained})` : '');
  }
```

## 効果音 … Web Audio API

`resize();` の行（`window.addEventListener('resize', resize);` の下）と `// ---- game logic ----` のあいだに追加します。

```js:game.js
  // ---- audio ----
  let ac = null, lastBeep = 0;
  function beep(freq, dur, type, vol) {
    try {
      if (!ac) ac = new (window.AudioContext || window.webkitAudioContext)();
      const t = ac.currentTime;
      if (t - lastBeep < 0.03) return;
      lastBeep = t;
      const o = ac.createOscillator(), g = ac.createGain();
      o.type = type || 'square'; o.frequency.value = freq;
      g.gain.setValueAtTime(vol || 0.04, t);
      g.gain.exponentialRampToValueAtTime(0.0001, t + dur);
      o.connect(g); g.connect(ac.destination);
      o.start(t); o.stop(t + dur);
    } catch (e) {}
  }
```

**Web Audio API** を使うと、音声ファイルを用意しなくても JavaScript で音を作れます。

- `AudioContext` … 音を扱うための入れ物。ブラウザは「ユーザーが操作するまで音を出さない」決まりがあるので、最初に音を鳴らすとき（＝スタートしたあと）に作ります
- `createOscillator()` … 決まった高さ（`frequency`、Hz）の音を出し続ける発振器。`type` で音色（`'square'` 四角い波・`'triangle'` 三角の波・`'sine'` なめらかな波・`'sawtooth'` のこぎりの波）を選びます
- `createGain()` … 音量つまみ。`exponentialRampToValueAtTime` で `dur` 秒かけてほぼ 0 まで下げると、「ピッ」と自然に消える音になります
- 発振器 → 音量つまみ → スピーカー（`ac.destination`）の順に `connect` でつなぎ、`start` と `stop` で鳴らす時間を決めます

ボールがたくさんあると、同じ瞬間に何十回も当たることがあります。0.03 秒以内に続けて鳴らそうとしたときは無視して（`lastBeep`）、音が割れないようにしています。

## 効果音を鳴らす場所

次の4か所に `beep(...)` を足します。

`fire()` の最後（`balls = []; ...` の **下**）に、発射の音。

```js:game.js
    beep(520, 0.08, 'triangle', 0.05);
```

`hitBrick()` は、当たったときの音と壊れたときの音を足して、次のように **書きかえ** ます。

```js:game.js
  function hitBrick(b) {
    b.hp--; b.shake = 6; score++;
    beep(300 + Math.min(900, b.max * 6) * (1 - b.hp / b.max), 0.05, 'square', 0.03);
    if (b.hp <= 0) {
      const rc = brickRect(b);
      for (let i = 0; i < 10; i++) {
        particles.push({ x: rc.x + rc.w / 2, y: rc.y + rc.h / 2, vx: (Math.random() - .5) * .25, vy: (Math.random() - .5) * .25, life: 30, hue: brickHue(b) });
      }
      bricks.splice(bricks.indexOf(b), 1);
      beep(880, 0.09, 'triangle', 0.05);
    }
  }
```

当たったときの音の高さは「どれだけ削ったか」（`1 - b.hp / b.max`）で上がっていきます。硬いブロックを削っていくと、だんだん音が高くなって「もうすぐ壊れる」のが耳で分かります。

`stepBall()` のリングの判定の中、`flashes.push(...)` の **下** に、リングを取った音。

```js:game.js
        beep(1200, 0.12, 'sine', 0.06);
```

ゲームオーバーの音は、次の `gameOver()` の書きかえに入っています。

## gameOver() でハイスコアを保存する

`function gameOver` を **書きかえ** ます。

```js:game.js
  function gameOver() {
    state = 'over';
    beep(140, 0.5, 'sawtooth', 0.06);
    let isBest = false;
    if (score > best) {
      best = score; isBest = true;
      try { localStorage.setItem('ballBurstBest', String(best)); } catch (e) {}
    }
    updateHud();
    setTimeout(() => {
      ovTitle.textContent = 'ゲームオーバー';
      ovText.innerHTML = `ステージ <b>${level}</b> ・ スコア <b>${score}</b>` + (isBest ? '<br><b class="green">ハイスコア更新！</b>' : `<br>ベスト ${best}`);
      startBtn.textContent = 'もう一度あそぶ';
      overlay.classList.remove('hide');
    }, 500);
  }
```

今回のスコアがベストを超えていたら、`best` を更新して localStorage に保存し、ゲームオーバー画面に「ハイスコア更新！」と出します。超えていなければベストの点数を見せます。

## キーボード操作

`// ---- input ----` の最後、`startBtn.addEventListener(...)` の **上** に追加します。

```js:game.js
  window.addEventListener('keydown', e => {
    if (state === 'title' || state === 'over') {
      if ((e.key === 'Enter' || e.key === ' ') && !overlay.classList.contains('hide')) { e.preventDefault(); startGame(); }
      return;
    }
    if (state === 'aim') {
      if (e.key === 'ArrowLeft') { aimAng = Math.min(Math.PI - MIN_ANG, aimAng + 0.04); e.preventDefault(); }
      if (e.key === 'ArrowRight') { aimAng = Math.max(MIN_ANG, aimAng - 0.04); e.preventDefault(); }
      if (e.key === ' ' || e.key === 'Enter' || e.key === 'ArrowUp') { e.preventDefault(); fire(); }
    } else if (state === 'fire' && (e.key === 'f' || e.key === 'F' || e.key === ' ')) {
      e.preventDefault(); fast = !fast;
    }
  });
```

- `e.key` には押されたキーの名前が入ります（`'ArrowLeft'`、`' '`（スペース）、`'Enter'` など）。
- タイトル画面とゲームオーバー画面では、Enter か Space でスタートします。ゲームオーバーの直後 0.5 秒はまだオーバーレイが出ていないので、うっかり押してもすぐには始まらないよう、オーバーレイが見えているときだけにしています。
- ねらい中は ← → で角度を少しずつ変え（角度は左回りが正なので、← で増やします）、Space / Enter / ↑ で発射。発射中は F か Space で早送りを切りかえます。
- `e.preventDefault()` で、Space でページがスクロールするなどの、ブラウザ本来の動きを止めています。

> [!CHECK] 動作チェック
> - 発射・ブロックに当たる・ブロックが壊れる・リングを取る・ゲームオーバーで、それぞれ効果音が鳴る
> - 硬いブロックを削っていくと、当たる音がだんだん高くなる
> - ゲームオーバーになると BEST が更新され、「ハイスコア更新！」と出る。再読み込みしても BEST が残っている
> - PC では ← → でねらいが動き、Space で発射、発射中に F で早送りになる
> - タイトル画面やゲームオーバー画面で Enter を押すとゲームが始まる

## 改造アイデア

> [!TIP]
> **ボーナスブロックを作る**: `spawnRow()` で、たまに `hp` が `level * 3` の金色のブロックを出し、壊したらスコアを多めに足してみましょう。色は `brickHue()` の代わりに固定の色相（45 くらい）を返すと金色になります。

> [!TIP]
> **横一列を消すアイテム**: リングとは別に、触れると同じ段のブロック全部に1ダメージを与えるアイテムを `pickups` に `kind` をつけて追加してみましょう。`stepBall()` のリングの判定で `kind` を見て処理を分けます。

> [!TIP]
> **予測線を長くする**: `predict()` の `bounces < 1` を `bounces < 2` にすると、1回跳ね返ったあとまで見えるようになり、ねらいやすい「やさしいモード」になります。

> [!TIP]
> **全部戻すボタン**: 発射中に下から上へスワイプしたら、飛んでいるボールを全部 `done` にして、すぐにターンを終える機能をつけてみましょう。`pointerdown` と `pointerup` の y 座標の差で判定できます。
