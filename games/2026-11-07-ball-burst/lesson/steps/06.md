## このステップのゴール

ターンを進めて **ゲームとして遊べる** ようにします。ターンが終わるたびにステージが1つ進み、ブロックとリングが1段下がって、上に新しい列が出ます。緑のリングにボールが触れると、次のターンからボールが1個増えます。ブロックが一番下の列まで来たらゲームオーバーです。

## 変数を増やす

`let bricks = ...` の行に `gained` を足して **書きかえ** ます。

```js:game.js
  let bricks = null, pickups = [], balls = [], ballCount, gained, launchX, nextX, level, score;
```

`gained` は、このターン中に拾ったリングの数です。ターンの途中でボールを増やすと、撃っている途中の数がずれてしまうので、ターンの終わりにまとめて足します。

`startGame()` の2行目も **書きかえ** ます。

```js:game.js
    ballCount = 1; gained = 0; level = 1; score = 0;
```

## endTurn() を完成させ、gameOver() を足す

`function endTurn()` を **書きかえ** て、その下に `gameOver()` を追加します。

```js:game.js
  function endTurn() {
    ballCount += gained; gained = 0;
    if (nextX != null) launchX = nextX;
    nextX = null;
    level++;
    for (const b of bricks) b.r++;
    for (const p of pickups) p.r++;
    pickups = pickups.filter(p => p.r < ROWS - 1);
    if (bricks.some(b => b.r >= ROWS - 1)) { gameOver(); return; }
    spawnRow();
    state = 'aim';
    updateHud();
  }

  function gameOver() {
    state = 'over';
    updateHud();
    setTimeout(() => {
      ovTitle.textContent = 'ゲームオーバー';
      ovText.innerHTML = `ステージ <b>${level}</b> ・ スコア <b>${score}</b>`;
      startBtn.textContent = 'もう一度あそぶ';
      overlay.classList.remove('hide');
    }, 500);
  }
```

1. 拾ったリングのぶんだけボールを増やします。
1. ステージを1つ進め、すべてのブロックとリングの段 `r` を1増やします。ブロックの位置は `brickRect()` が `r` から計算しているので、`r` を変えるだけで描画も当たり判定も1段下がります。
1. 一番下の列まで来たリングは拾えないので、`filter` で取り除きます。`filter` は条件を満たすものだけを残した新しい配列を返します。
1. `some` は「1つでも条件を満たすものがあるか」を調べるメソッドです。一番下の列（`ROWS - 1` 段目）に届いたブロックがあればゲームオーバーにして、`return` でそれ以降の処理をしません。
1. そうでなければ新しい列を出して、次のねらいに移ります。`level` が増えたあとに `spawnRow()` を呼ぶので、新しいブロックは前より硬くなります。

`gameOver()` では、`setTimeout` で 0.5 秒待ってからオーバーレイを出しています。最後のボールが戻った瞬間にいきなり画面が切り替わらないようにするためです。スタートボタンはそのまま `startGame()` を呼ぶので、これで **リトライ** もできます。

## updateHud() でリングの数も見せる

`updateHud()` の最後の行を **書きかえ** ます。

```js:game.js
    $('balls').textContent = ballCount + (gained ? ` (+${gained})` : '');
```

このターンでリングを拾っていれば「1 (+1)」のように表示します。

## stepBall() にリングとの当たり判定を足す

`stepBall()` の、ブロックの当たり判定の `for` ループの **下**、`// avoid near-horizontal loops` の **上** に追加します。

```js:game.js
    for (let i = pickups.length - 1; i >= 0; i--) {
      const p = pickups[i];
      const px = p.c + 0.5, py = TOP + p.r + 0.5;
      if ((o.x - px) ** 2 + (o.y - py) ** 2 < (R + 0.22) ** 2) {
        pickups.splice(i, 1); gained++;
        updateHud();
      }
    }
```

リングは **円と円の当たり判定** です。2つの円の中心の距離が、半径の合計（ボールの `R` + リングの `0.22`）より短ければ触れています。ここでも2乗どうしで比べます（`** 2` は2乗）。リングはボールを跳ね返さず、触れたら消えるだけです。

## 危険ラインを点滅させる

`draw()` の `// danger line` の下の、`ctx.strokeStyle = 'rgba(255,90,120,.25)';` の1行を、次の2行に **書きかえ** ます。

```js:game.js
    const danger = bricks && bricks.some(b => b.r >= ROWS - 2);
    ctx.strokeStyle = danger ? `rgba(255,90,120,${0.5 + 0.4 * Math.sin(time / 120)})` : 'rgba(255,90,120,.25)';
```

ブロックが危険ラインのすぐ上（あと1段でゲームオーバー）まで来たら、赤い点線の濃さを `Math.sin` でゆらして点滅させます。

> [!CHECK] 動作チェック
> - ボールが全部戻るたびに、ブロックとリングが1段下がり、上に新しい列が出る。STAGE が1つずつ増える
> - 緑のリングにボールを当てると消え、下の表示が「1 (+1)」になる。次のターンでは2個撃てる
> - ブロックが赤い点線のすぐ上まで来ると、点線が点滅する
> - ブロックが点線より下の列に来ると、少ししてから「ゲームオーバー」と、ステージとスコアが出る
> - 「もう一度あそぶ」で最初からやり直せる
