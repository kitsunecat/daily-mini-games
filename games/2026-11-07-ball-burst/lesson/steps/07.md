## このステップのゴール

ボールが増えてくると、全部戻るまで待つのがたいくつになります。そこで発射中に画面をタップすると **早送り** になるようにし、8秒たったら自動でも早送りにします。あわせて、当たったブロックがぷるっとゆれて明るくなる、壊れると破片が飛び散る、リングを取ると波紋が広がる、という **手ごたえの演出** を足します。

## 変数を増やす

`let aimAng = ...` の行を、次の2行に **書きかえ** ます。

```js:game.js
  let aimAng = Math.PI / 2, aiming = false, toLaunch = 0, launchTimer = 0, fast = false, fireFrames = 0;
  let particles = [], flashes = [];
```

- `fast` … 早送り中かどうか、`fireFrames` … 発射してから何フレームたったか
- `particles` … 壊れたブロックの破片、`flashes` … リングを取ったときの波紋

## startGame()・endTurn()・fire() でリセットする

`startGame()` の最初の3行を、次のように **書きかえ** ます。

```js:game.js
    bricks = []; pickups = []; balls = []; particles = []; flashes = [];
    ballCount = 1; gained = 0; level = 1; score = 0;
    launchX = BW / 2; nextX = null; aimAng = Math.PI / 2; fast = false;
```

`endTurn()` の `nextX = null;` の行を **書きかえ** ます。ターンが終わったら早送りも解除します。

```js:game.js
    nextX = null; fast = false;
```

`fire()` の最後の行を **書きかえ** ます。

```js:game.js
    balls = []; toLaunch = ballCount; launchTimer = 0; fireFrames = 0;
```

## hitBrick() でゆれと破片を出す

`function hitBrick` を **書きかえ** ます。

```js:game.js
  function hitBrick(b) {
    b.hp--; b.shake = 6; score++;
    if (b.hp <= 0) {
      const rc = brickRect(b);
      for (let i = 0; i < 10; i++) {
        particles.push({ x: rc.x + rc.w / 2, y: rc.y + rc.h / 2, vx: (Math.random() - .5) * .25, vy: (Math.random() - .5) * .25, life: 30, hue: brickHue(b) });
      }
      bricks.splice(bricks.indexOf(b), 1);
    }
  }
```

- 当たるたびに `shake` を 6 にします。毎フレーム1ずつ減らして、0 になるまでの6フレームだけゆらします。
- 壊れたら、ブロックのまん中から10個の **パーティクル**（小さな粒）を、ばらばらの向きに飛ばします。`life` は残りの寿命（フレーム数）、`hue` はブロックの色です。

## リングを取ったら波紋を出す

`stepBall()` のリングの判定の中、`pickups.splice(i, 1); gained++;` の **下** に1行足します。

```js:game.js
        flashes.push({ x: px, y: py, life: 20 });
```

## update() を早送りに対応させる

`function update` を、次のように **まるごと書きかえ** ます。

```js:game.js
  function update() {
    if (state === 'fire') {
      fireFrames++;
      const sub = fast || fireFrames > 60 * 8 ? 3 : 1;
      for (let s = 0; s < sub; s++) {
        if (toLaunch > 0 && --launchTimer <= 0) {
          balls.push({ x: launchX, y: FLOOR - R, vx: Math.cos(aimAng) * SPEED, vy: -Math.sin(aimAng) * SPEED, done: false });
          toLaunch--; launchTimer = GAP;
        }
        for (const o of balls) {
          if (o.done) {
            if (nextX != null) o.x += (nextX - o.x) * 0.2;
            continue;
          }
          // substeps so fast balls don't tunnel
          const n = 2;
          const vx = o.vx, vy = o.vy;
          o.vx = vx / n; o.vy = vy / n;
          for (let k = 0; k < n && !o.done; k++) stepBall(o);
          o.vx *= n; o.vy *= n;
        }
        if (toLaunch === 0 && balls.every(o => o.done)) { endTurn(); break; }
      }
    }
    if (bricks) for (const b of bricks) if (b.shake > 0) b.shake--;
    particles = particles.filter(p => { p.x += p.vx; p.y += p.vy; p.vy += 0.01; return --p.life > 0; });
    flashes = flashes.filter(f => --f.life > 0);
  }
```

- 早送りは、ボールの速さを上げるのではなく、**1フレームのうちに3フレームぶん** の処理をくり返すことで実現しています（`sub` 回のループ）。速さを変えないので、当たり判定の精度はそのままです。
- `60 * 8` は「60フレーム × 8 = 約8秒」です。それを過ぎたら自動で早送りになります。
- 途中でターンが終わったら、残りのループは回さずに `break` で抜けます。
- 後半の3行は演出の更新です。パーティクルは動かして、`p.vy += 0.01` で少しずつ下に落とし（重力）、寿命が尽きたら `filter` で配列から消します。

## draw() でゆれ・破片・波紋・早送り表示を描く

`draw()` の `// bricks` の `for` ループを、次のように **書きかえ** て、その下に破片と波紋を描くコードを追加します（`// aim line` の上まで）。

```js:game.js
    for (const b of bricks) {
      const rc = brickRect(b);
      const sh = b.shake ? (Math.random() - .5) * 0.06 : 0;
      const hue = brickHue(b);
      ctx.fillStyle = `hsl(${hue},85%,${b.shake ? 72 : 58}%)`;
      roundRect(rc.x + sh, rc.y + sh, rc.w, rc.h, 0.12); ctx.fill();
      ctx.fillStyle = 'rgba(0,0,0,.18)';
      ctx.fillRect(rc.x + sh + 0.05, rc.y + sh + rc.h - 0.12, rc.w - 0.1, 0.07);
      ctx.fillStyle = '#1a0f2e';
      ctx.font = `800 ${b.hp >= 100 ? 0.32 : 0.4}px system-ui, sans-serif`;
      ctx.fillText(b.hp, rc.x + rc.w / 2 + sh, rc.y + rc.h / 2 + sh + 0.02);
    }
    // particles
    for (const p of particles) {
      ctx.globalAlpha = p.life / 30;
      ctx.fillStyle = `hsl(${p.hue},85%,62%)`;
      ctx.fillRect(p.x - 0.05, p.y - 0.05, 0.1, 0.1);
    }
    for (const f of flashes) {
      ctx.globalAlpha = f.life / 20;
      ctx.strokeStyle = '#6ff0a0'; ctx.lineWidth = 0.05;
      ctx.beginPath(); ctx.arc(f.x, f.y, 0.2 + (20 - f.life) * 0.03, 0, Math.PI * 2); ctx.stroke();
    }
    ctx.globalAlpha = 1;
```

- ゆれている間は、描く位置を毎フレームランダムに少しずらし（`sh`）、明るさを 58% から 72% に上げます。数字も同じだけずらすのを忘れずに。
- `ctx.globalAlpha` は、これから描くものの不透明度（0〜1）です。寿命の割合を入れると、だんだん消えていく表現になります。使い終わったら必ず `1` に戻します。
- 波紋は寿命が減るほど半径を大きくして、広がりながら消えていくようにしています。

さらに、`draw()` の最後、`// ball count label` の `if` ブロックの **下** に追加します。

```js:game.js
    if (state === 'fire' && (fast || fireFrames > 60 * 8)) {
      ctx.fillStyle = 'rgba(255,211,111,.8)'; ctx.font = '700 0.32px system-ui, sans-serif';
      ctx.fillText('▶▶ 早送り', BW - 0.9, FLOOR + 0.13);
    }
```

## タップで早送りを切りかえる

`pointerdown` の処理を、次のように **書きかえ** ます。発射中に押したときは、早送りのオン・オフを切りかえます。

```js:game.js
  cv.addEventListener('pointerdown', e => {
    e.preventDefault();
    if (state === 'aim') {
      aiming = true; setAimFrom(toBoard(e));
      try { cv.setPointerCapture(e.pointerId); } catch (err) {}
    } else if (state === 'fire') {
      fast = !fast;
    }
  });
```

> [!CHECK] 動作チェック
> - ボールが当たったブロックが、一瞬明るくなってぷるっとゆれる
> - ブロックが壊れると、同じ色の破片が飛び散って消えていく
> - リングを取ると、緑の波紋が広がる
> - ボールが飛んでいる間に盤面をタップすると、右下に「▶▶ 早送り」と出て、ボールの動きが3倍速になる。もう一度タップすると元の速さに戻る
> - 放っておいても、発射から約8秒たつと自動で早送りになる
