## このステップのゴール

3つのファイルを用意して、画面の土台を作ります。上に「残り時間・サイズ・スコア・ベスト」の表示、その下にゲーム画面いっぱいの **Canvas**、さらにその上に重ねるタイトル画面（オーバーレイ）を置きます。Canvas にはまだ街はなく、まん中に仮の円を1つ描くだけです。

## index.html

まずは HTML です。このステップで画面の部品はすべてそろえてしまい、以降は `game.js` だけを育てていきます。

```html:index.html

<link rel="stylesheet" href="style.css">
</head>
<body>
<div id="app">
  <header>
    <a class="back" href="../../../../">← 一覧</a>

  </header>

      <p id="ov-text">あなたは街を動きまわる「穴」。<br>自分より小さいものを飲みこんで大きくなろう。<br>大きくなるほど、車や家、ビルまで飲みこめる！<br>制限時間は60秒。</p>

  </div>

```

- `header` に TIME・SIZE・SCORE・BEST の4つの数字を並べます。JavaScript から書き換えるので、数字の `b` 要素に `id` をつけています。
- `#stage` の中に `canvas`・`#pop`（「サイズアップ！」の文字を出す場所）・`#overlay` を **重ねて** 置きます。オーバーレイはタイトル画面とタイムアップ画面の両方に使い回します。
- 「← 一覧」のリンク先は自分の環境に合わせて変えてかまいません。
- `<script>` を `body` の最後に置くと、HTML の要素が全部できてからスクリプトが動くので、`getElementById` で確実に要素が取れます。

ポイントは次のとおりです。

- `#app` を縦方向の **Flexbox** にして、`#stage` に `flex: 1` を指定すると「ヘッダーの残り全部」がゲーム画面になります。`min-height: 0` は、中身が大きくてもはみ出さずに縮めるためのおまじないです。
- Canvas は `width: 100%; height: 100%` で `#stage` いっぱいに広げます。このゲームは盤面が正方形ではなく「街をのぞく窓」なので、画面の形に合わせて伸び縮みさせます。
- `#stage` を `position: relative`、`#overlay` を `position: absolute; inset: 0` にすると、オーバーレイが Canvas の上にぴったり重なります。`hidden` クラスをつけ外しするだけで表示を切り替えられます。
- `#pop` はふだん `opacity: 0` で見えず、`show` クラスがつくとふわっと現れます（`transition`）。`pointer-events: none` なので、上に重なっていても操作のじゃまをしません。
- `touch-action: none` は、スマホでドラッグしたときに画面がスクロールしたり拡大したりするのを防ぎます。
- `#time.low` は残り時間が少なくなったときに数字を赤くするためのスタイルです（最後のステップで使います）。

## game.js

```js:game.js
(() => {
  'use strict';

  const cv = document.getElementById('cv');
  const ctx = cv.getContext('2d');
  const stage = document.getElementById('stage');
  const overlay = document.getElementById('overlay');
  const startBtn = document.getElementById('start');

  let W = 0, H = 0, dpr = 1;

  // ---------- 画面サイズ ----------
  function resize() {
    const r = stage.getBoundingClientRect();
    dpr = Math.min(window.devicePixelRatio || 1, 2);
    W = Math.max(1, r.width);
    H = Math.max(1, r.height);
    cv.width = Math.round(W * dpr);
    cv.height = Math.round(H * dpr);
    draw();
  }
  window.addEventListener('resize', resize);

  // ---------- 描画 ----------
  function draw() {
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
    ctx.fillStyle = '#0d1a26';
    ctx.fillRect(0, 0, W, H);
    // 仮の目印：画面のまん中に円
    ctx.strokeStyle = '#4fd1ff';
    ctx.lineWidth = 3;
    ctx.beginPath();
    ctx.arc(W / 2, H / 2, 20, 0, Math.PI * 2);
    ctx.stroke();
  }

  startBtn.addEventListener('click', () => overlay.classList.add('hidden'));

  resize();
})();
```

### コード全体を `(() => { ... })();` で包む理由

これは **即時実行関数** と呼ばれる書き方です。中で宣言した変数がページ全体（グローバル）に漏れないので、ほかのスクリプトと名前がぶつかりません。`'use strict';` は、宣言し忘れた変数などのミスをエラーとして教えてくれるモードです。

### Canvas とは

`<canvas>` は JavaScript で自由に絵を描ける「キャンバス」です。`getContext('2d')` で取り出した `ctx`（コンテキスト）に `fillRect`（四角を塗る）や `arc`（円を描く）などの命令を出して描きます。座標は左上が `(0, 0)` で、右に行くほど x、**下に行くほど y が大きく** なります。

### 画面の大きさに合わせる `resize()`

- `stage.getBoundingClientRect()` で、ゲーム画面の今の幅と高さ（CSS ピクセル）を取り、`W`・`H` に入れます。以降の描画はすべてこの `W × H` の座標で考えます。
- Canvas には「CSS で見える大きさ」と「内部の画素数」（`cv.width` / `cv.height`）の2つのサイズがあります。高精細な画面では1 CSS ピクセルに複数の物理ピクセルが詰まっている（`devicePixelRatio`）ので、内部の画素数を `W × dpr` にしないと絵がぼやけます。`Math.min(..., 2)` で上限を 2 にしているのは、超高精細な端末で画素数が増えすぎて重くなるのを防ぐためです。
- `draw()` の最初の `ctx.setTransform(dpr, 0, 0, dpr, 0, 0)` で「座標を dpr 倍して描く」設定にします。これで、以降は CSS ピクセル単位の座標を指定するだけでくっきり描けます。
- Canvas の `width` を設定し直すと中身が消えるので、`resize()` の最後で `draw()` を呼んで描き直しています。

> [!CHECK] 動作チェック
> - `index.html` をブラウザで開くと、タイトル「ホールグルメ」と説明文、「タップでスタート」ボタンが表示される
