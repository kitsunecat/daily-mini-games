## このステップのゴール

画面より大きな「街（ワールド）」を用意し、芝生と道路を描きます。そして **カメラ** の考え方を入れて、「穴がいる場所を中心に、ちょうどいい大きさで街を映す」ようにします。このゲームのいちばん大事な仕組みの土台です。

## ワールドの大きさを決める

`const startBtn = ...;` の **下** に定数を追加します。

```js:game.js
  const WORLD_W = 1600, WORLD_H = 2400;
  const BLOCK = 400, ROAD = 64;
```

- `WORLD_W × WORLD_H` が街全体の大きさです。画面（スマホなら 370×750 くらい）よりずっと大きいので、全部は一度に映りません。
- `BLOCK` は道路と道路の間隔（1区画の大きさ）、`ROAD` は道路の幅です。400 ごとに道路を引くので、街は横 4 区画 × 縦 6 区画になります。

## 穴とカメラの変数

`let W = 0, H = 0, dpr = 1;` の **下** に追加します。

```js:game.js
  let hole;
  let cam = { x: 0, y: 0, zoom: 1 };
```

- `hole` はプレイヤーである「穴」の情報（位置 `x`, `y` と半径 `r`）を入れるオブジェクトです。中身は次の `reset()` で作ります。
- `cam` は **カメラ** です。`x`, `y` は「ワールドのどこを画面のまん中に映すか」、`zoom` は「どれくらい拡大して映すか」を表します。

## ゲームの初期化 `reset()` と `targetZoom()`

`// ---------- 描画 ----------` の **上** に新しいブロックを追加します。

```js:game.js
  // ---------- ゲーム進行 ----------
  function reset() {
    hole = { x: WORLD_W / 2, y: WORLD_H / 2, r: 20 };
    cam.x = hole.x; cam.y = hole.y; cam.zoom = targetZoom();
  }

  function targetZoom() {
    const short = Math.min(W, H);
    return short / (hole.r * 11 + 160);
  }
```

- 穴は街のまん中、半径 20 から始めます。カメラも同じ場所に合わせます。
- `targetZoom()` は「穴の大きさに合わせた、ちょうどいい拡大率」を計算します。画面の短いほうの辺に、ワールドの `hole.r * 11 + 160` ぶんが収まるようにしています。穴が小さいうちは狭い範囲を大きく映し、穴が大きくなるほど **ズームアウト** して広い範囲が見えるようになります（成長はステップ7で作ります）。

## draw() を書きかえる

`draw()` 関数を **まるごと** 次のものに置きかえます。仮の円は消えて、街が映ります。

```js:game.js
  function draw() {
    if (!hole) return;
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
    ctx.fillStyle = '#0d1a26';
    ctx.fillRect(0, 0, W, H);
    ctx.save();
    ctx.translate(W / 2, H / 2);
    ctx.scale(cam.zoom, cam.zoom);
    ctx.translate(-cam.x, -cam.y);

    // 地面と道路
    ctx.fillStyle = '#9ccc8a';
    ctx.fillRect(0, 0, WORLD_W, WORLD_H);
    ctx.fillStyle = '#4b5563';
    for (let x = 0; x <= WORLD_W; x += BLOCK) ctx.fillRect(x - ROAD / 2, 0, ROAD, WORLD_H);
    for (let y = 0; y <= WORLD_H; y += BLOCK) ctx.fillRect(0, y - ROAD / 2, WORLD_W, ROAD);
    ctx.strokeStyle = 'rgba(255,255,255,.55)';
    ctx.lineWidth = 3;
    ctx.setLineDash([20, 18]);
    ctx.beginPath();
    for (let x = 0; x <= WORLD_W; x += BLOCK) { ctx.moveTo(x, 0); ctx.lineTo(x, WORLD_H); }
    for (let y = 0; y <= WORLD_H; y += BLOCK) { ctx.moveTo(0, y); ctx.lineTo(WORLD_W, y); }
    ctx.stroke();
    ctx.setLineDash([]);

    ctx.restore();
  }
```

### カメラは「座標変換」の3連続

Canvas の `translate`（ずらす）・`scale`（拡大する）は、**これから描くもの全部** の座標をまとめて変換する命令です。上の3行は、下から順に読むと分かりやすくなります。

1. `translate(-cam.x, -cam.y)` … カメラが見ている点をワールドの原点 `(0, 0)` に持ってくる
2. `scale(cam.zoom, cam.zoom)` … 原点を中心に `zoom` 倍に拡大する
3. `translate(W / 2, H / 2)` … 原点を画面のまん中に持ってくる

こうしておくと、あとは「ワールドの座標」のまま `fillRect(0, 0, WORLD_W, WORLD_H)` のように描くだけで、カメラから見た位置・大きさで画面に映ります。穴や物を描くときも、画面の座標をいちいち計算する必要がありません。

`ctx.save()` と `ctx.restore()` は、変換や色の設定を「保存」して「元に戻す」ペアです。`restore()` の後は、また画面の座標（左上が原点）で描けます。

### 道路の描き方

- 縦の道路は `x = 0, 400, 800, …` の位置に、幅 `ROAD` の長い四角として描きます。中心が `x` になるよう `x - ROAD / 2` から描くのがポイントです。横の道路も同じです。
- `setLineDash([20, 18])` は「20 描いて 18 空ける」点線の設定です。道路の中央に白い点線を引いたら、`setLineDash([])` で実線に戻しておきます（戻し忘れると、この後に描く線がすべて点線になります）。

### いちばん下の呼び出し

ファイルの最後の `resize();` を、次の3行に書きかえます。

```js:game.js
  resize();
  reset();
  draw();
```

`reset()` の `targetZoom()` は画面サイズ `W`, `H` を使うので、先に `resize()` で大きさを測っておきます。`draw()` の最初の `if (!hole) return;` は、`resize()` の中から呼ばれたときにまだ穴が作られていなくてもエラーにならないようにするためです。

> [!CHECK] 動作チェック
> - タイトル画面の後ろに、芝生と道路が透けて見える
> - スタートすると、黄緑の芝生に灰色の道路が縦横に通り、道路の中央に白い点線がある街が見える
> - 画面のまん中あたりに道路の交差点が見える（街のまん中 `(800, 1200)` は道路の交差点です）
