## このステップのゴール

仮の四角だった車・バス・家・ビル・タワーを、それらしい絵に描きかえます。角の丸い四角を描く関数と、色を少し暗くする関数を作り、上から見下ろした街を完成させます。

## 車・バス・家・ビルを描く

`drawObj()` の `switch` の中の、`default:` から始まる3行（`default:` とコメントと `ctx.fillStyle = o.color; ctx.fillRect(...)`）を **削除** して、代わりに次のコードを入れます。`case 'tree':` の `break;` の後ろ、`switch` の閉じかっこ `}` の前に入る形です。

```js:game.js
      case 'car':
      case 'bus': {
        const w = s, l = s;
        ctx.fillStyle = o.color;
        roundRect(-l, -w * 0.55, l * 2, w * 1.1, s * 0.25); ctx.fill();
        ctx.fillStyle = 'rgba(30,50,70,.75)';
        if (o.kind === 'car') { ctx.fillRect(l * 0.15, -w * 0.42, l * 0.35, w * 0.84); ctx.fillRect(-l * 0.6, -w * 0.42, l * 0.3, w * 0.84); }
        else for (let k = -3; k <= 2; k++) ctx.fillRect(k * l * 0.3 + l * 0.05, -w * 0.45, l * 0.2, w * 0.18);
        break;
      }
      case 'house':
        ctx.fillStyle = '#efe6d2'; ctx.fillRect(-s, -s, s * 2, s * 2);
        ctx.fillStyle = o.color;
        ctx.beginPath(); ctx.moveTo(-s, -s); ctx.lineTo(s, -s); ctx.lineTo(0, 0); ctx.closePath(); ctx.fill();
        ctx.beginPath(); ctx.moveTo(-s, s); ctx.lineTo(s, s); ctx.lineTo(0, 0); ctx.closePath(); ctx.fill();
        ctx.fillStyle = shade(o.color, -0.2);
        ctx.beginPath(); ctx.moveTo(-s, -s); ctx.lineTo(0, 0); ctx.lineTo(-s, s); ctx.closePath(); ctx.fill();
        ctx.beginPath(); ctx.moveTo(s, -s); ctx.lineTo(0, 0); ctx.lineTo(s, s); ctx.closePath(); ctx.fill();
        break;
      case 'building':
      case 'tower': {
        ctx.fillStyle = shade(o.color, -0.25); ctx.fillRect(-s, -s, s * 2, s * 2);
        ctx.fillStyle = o.color; ctx.fillRect(-s * 0.9, -s * 0.9, s * 1.8, s * 1.8);
        ctx.fillStyle = 'rgba(180,225,255,.55)';
        const n = o.kind === 'tower' ? 5 : 3, g = (s * 1.8) / n;
        for (let a = 0; a < n; a++) for (let b = 0; b < n; b++) ctx.fillRect(-s * 0.9 + a * g + g * 0.2, -s * 0.9 + b * g + g * 0.2, g * 0.6, g * 0.6);
        break;
      }
```

### 2つの `case` をまとめる

`case 'car':` の下に何も書かずに `case 'bus':` を続けると、車でもバスでも同じ処理に進みます。中で `o.kind === 'car'` かどうかで窓の描き方だけを変えています。`case` の中で `const` を宣言するときは、`{ }` で囲んでブロックにしておくと、ほかの `case` の変数と名前がぶつかりません。

### それぞれの絵のしくみ

- **車・バス** … `l` が車体の長さの半分、`w` が幅の基準です。角の丸い四角の車体に、車は前後の窓を2枚、バスは横に並んだ6つの窓を描きます。縦の道路の車はステップ5で `rot` を 90 度にしてあるので、`drawObj` の `rotate` で自動的に縦向きになります。
- **家** … 上から見た寄棟（よせむね）屋根です。正方形を、中心 `(0, 0)` に向かう4つの三角形に分け、上下を屋根の色、左右を少し暗い色で塗ると、光が当たっているように見えて立体感が出ます。
- **ビル・タワー** … 暗い色の外枠の上に本体を重ね、窓をマス目状に並べます。窓の数はビルが 3×3、タワーが 5×5 です。`g` は1マスの大きさで、その中に 6 割の大きさの窓を置いています。

## 補助の関数 `roundRect()` と `shade()`

`drawObj()` の **下**（`draw()` の上）に追加します。

```js:game.js
  function roundRect(x, y, w, h, r) {
    ctx.beginPath();
    ctx.moveTo(x + r, y);
    ctx.arcTo(x + w, y, x + w, y + h, r);
    ctx.arcTo(x + w, y + h, x, y + h, r);
    ctx.arcTo(x, y + h, x, y, r);
    ctx.arcTo(x, y, x + w, y, r);
    ctx.closePath();
  }
  function shade(hex, amt) {
    const n = parseInt(hex.slice(1), 16);
    const f = (c) => Math.max(0, Math.min(255, Math.round(c + 255 * amt)));
    return `rgb(${f(n >> 16)},${f((n >> 8) & 255)},${f(n & 255)})`;
  }
```

### `arcTo` で角を丸める

`arcTo(x1, y1, x2, y2, r)` は「今の点から `(x1, y1)` に向かい、そこで曲がって `(x2, y2)` へ向かう線の角を、半径 `r` で丸める」命令です。4つの角で1回ずつ呼ぶと、角の丸い四角のパスができます。パスを作るだけなので、呼んだ後に `ctx.fill()` で塗ります。

### `shade()` で色を明るく・暗くする

`'#d9534f'` のような色の文字列から `#` を取って16進数として読むと、1つの数に赤・緑・青が 8 ビットずつ詰まった値になります。`>>`（右シフト）と `& 255` で赤・緑・青を取り出し、それぞれに `255 * amt` を足して 0〜255 に収めます。`amt` がマイナスなら暗く、プラスなら明るくなります。1色を決めるだけで影の色も自動で作れるので、ランダムな色の家やビルにも使えます。

> - 区画には三角の屋根を4つ組み合わせた家が建ち、外側の区画には窓がマス目に並んだビルや大きなタワーがある
