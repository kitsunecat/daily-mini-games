## このステップのゴール

街のまん中に「穴」を描き、**ゲームループ**（毎フレームの「更新 → 描画」のくり返し）を作って、矢印キーや WASD で穴を動かせるようにします。カメラが穴をなめらかに追いかけるところまで作ります。

## 状態とキー入力の変数

`let cam = ...;` の **下** に追加します。

```js:game.js
  let lastT = 0;
  const keys = {};
```

さらに `let W = 0, H = 0, dpr = 1;` の **下** に、ゲームの状態を表す変数を1行追加します。

```js:game.js
  let state = 'title';
```

- `state` は `'title'`（タイトル画面）・`'play'`（プレイ中）・`'over'`（タイムアップ）のどれかです。今どの場面かで処理を切りかえます。
- `lastT` は前のフレームの時刻、`keys` は「今押されているキー」を覚えておくオブジェクトです。

`resize()` の最後の `draw();` は、次のように書きかえます。プレイ中はゲームループが毎フレーム描くので、ここで描く必要がないからです。

```js:game.js
    if (state !== 'play') draw();
```

## スタート・更新の関数

`reset()` の **下** に `start()` を追加します。

```js:game.js
  function start() {
    reset();
    state = 'play';
    overlay.classList.add('hidden');
    lastT = performance.now();
    requestAnimationFrame(loop);
  }
```

`targetZoom()` の **下** に、1フレームぶん世界を進める `update(dt)` を追加します。

```js:game.js
  function update(dt) {
    // 入力
    let dx = 0, dy = 0;
    const kx = (keys.ArrowRight || keys.d ? 1 : 0) - (keys.ArrowLeft || keys.a ? 1 : 0);
    const ky = (keys.ArrowDown || keys.s ? 1 : 0) - (keys.ArrowUp || keys.w ? 1 : 0);
    if (kx || ky) { const l = Math.hypot(kx, ky); dx = kx / l; dy = ky / l; }
    const speed = 170 + hole.r * 1.6;
    hole.x = Math.max(hole.r * 0.5, Math.min(WORLD_W - hole.r * 0.5, hole.x + dx * speed * dt));
    hole.y = Math.max(hole.r * 0.5, Math.min(WORLD_H - hole.r * 0.5, hole.y + dy * speed * dt));

    // カメラ
    cam.x += (hole.x - cam.x) * Math.min(1, dt * 6);
    cam.y += (hole.y - cam.y) * Math.min(1, dt * 6);
    cam.zoom += (targetZoom() - cam.zoom) * Math.min(1, dt * 2);
  }
```

### 動く向きは「長さ1のベクトル」にそろえる

- `kx` は「右なら 1、左なら -1、どちらもなら 0」、`ky` は「下なら 1、上なら -1」です。`true ? 1 : 0` の引き算で短く書いています。
- そのまま使うと、ななめ移動（`kx = 1, ky = 1`）のときだけ速さが √2 倍（約1.4倍）になってしまいます。そこで `Math.hypot(kx, ky)`（ベクトルの長さ）で割って、**どの向きでも長さ 1** の向き `dx, dy` にそろえます。これを **正規化** といいます。

### 時間 `dt` をかけて動かす

`hole.x + dx * speed * dt` の `dt` は「前のフレームから何秒たったか」です。「秒速 `speed` で動く」と考えて、経過時間をかけて移動量を出します。こうすると、1秒に 60 回描く画面でも 120 回描く画面でも、同じ速さで動きます。

穴が大きくなるほど速くなるよう、速さは `170 + hole.r * 1.6` にしています。`Math.max(下限, Math.min(上限, 値))` は値を範囲内に収める **クランプ** という書き方で、穴が街の外に出ないようにしています。

### カメラは少し遅れて追いかける

`cam.x += (hole.x - cam.x) * 係数` は「目標までの残り距離の一部だけ近づく」書き方です。毎フレームくり返すと、最初は速く・近づくほどゆっくりと、なめらかに追いつきます。カメラがピタッと張りつくより、少し遅れてついてくるほうが動いている感じが出ます。ズームも同じ方法で `targetZoom()` に近づけます。

## 穴を描く

`draw()` の中、道路を描いた後の `ctx.setLineDash([]);` と `ctx.restore();` の **間** に追加します。

```js:game.js
    // 穴
    const r = hole.r;
    const grd = ctx.createRadialGradient(hole.x, hole.y, r * 0.2, hole.x, hole.y, r);
    grd.addColorStop(0, '#000');
    grd.addColorStop(0.8, '#0a0f1a');
    grd.addColorStop(1, '#1d2b45');
    ctx.fillStyle = grd;
    ctx.beginPath(); ctx.arc(hole.x, hole.y, r, 0, Math.PI * 2); ctx.fill();
    ctx.strokeStyle = '#4fd1ff';
    ctx.lineWidth = Math.max(3, r * 0.08);
    ctx.stroke();
```

`createRadialGradient` は、円の中心から外側へ色が変わる **放射状グラデーション** を作ります。中心をまっ黒、ふちを少し明るい紺にすると、地面にぽっかり開いた深い穴に見えます。最後に水色のふちどりをつけて、プレイヤーだと分かるようにします。

## ゲームループとキー入力

`draw()` の **下** に、ゲームループ `loop` を追加します。

```js:game.js
  function loop(t) {
    if (state !== 'play') { draw(); return; }
    const dt = Math.min(0.05, (t - lastT) / 1000);
    lastT = t;
    update(dt);
    draw();
    if (state === 'play') requestAnimationFrame(loop);
  }
```

続けて、キーボードの入力を受け取る処理を追加します。

```js:game.js
  // ---------- 入力 ----------
  window.addEventListener('keydown', (e) => {
    const k = e.key.length === 1 ? e.key.toLowerCase() : e.key;
    if (state !== 'play' && (k === 'Enter' || k === ' ')) { e.preventDefault(); start(); return; }
    keys[k] = true;
    if (k.startsWith('Arrow')) e.preventDefault();
  });
  window.addEventListener('keyup', (e) => {
    const k = e.key.length === 1 ? e.key.toLowerCase() : e.key;
    keys[k] = false;
  });
```

最後に、スタートボタンの行を `start()` を呼ぶように書きかえます。

```js:game.js
  startBtn.addEventListener('click', start);
```

### requestAnimationFrame とは

`requestAnimationFrame(loop)` は「次に画面を描きかえるタイミングで `loop` を呼んでね」とブラウザに頼む関数です。`loop` の最後でまた自分を頼むので、画面の書きかえに合わせて（ふつうは1秒に約60回）ずっとくり返されます。`loop` には呼ばれた時刻 `t`（ミリ秒）が渡されるので、前回との差を 1000 で割れば経過秒数 `dt` になります。

`Math.min(0.05, ...)` で `dt` の上限を 0.05 秒にしているのは、別のタブに切りかえて戻ったときなどに `dt` が何秒にもなって、穴が一気にワープするのを防ぐためです。

### キーは「押している間」を覚えておく

`keydown` で `keys[k] = true`、`keyup` で `false` にしておき、`update()` の中で `keys.ArrowRight` などを調べます。イベントが来た瞬間に動かすのではなく「押されている間ずっと動く」ようにするための定番の書き方です。

- `e.key` は `'ArrowRight'` や `'a'` のような文字列です。1文字のキーは `toLowerCase()` で小文字にそろえて、Shift や CapsLock が入っていても `keys.a` で判定できるようにしています。
- `e.preventDefault()` は、矢印キーやスペースでページがスクロールしてしまうのを止めます。
- タイトル画面では Enter かスペースでもスタートできます。

> [!CHECK] 動作チェック
> - 街のまん中に、水色のふちの黒い穴が見える
> - 「タップでスタート」または Enter キーでスタートし、矢印キー / WASD で穴が動く。ななめに動かしても速さが変わらない
> - カメラが少し遅れて穴を追いかけ、街の端では穴がそれ以上外に出ない
