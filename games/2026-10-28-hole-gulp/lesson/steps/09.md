## このステップのゴール

## ハイスコアを読みこむ

`const keys = {};` の **下** に追加します。

```js:game.js

  try { best = parseInt(localStorage.getItem(BEST_KEY), 10) || 0; } catch (e) { best = 0; }
  bestEl.textContent = best;
```

### localStorage とは

`localStorage` は、ブラウザにちょっとしたデータを **ページを閉じても消えないように** 保存できる仕組みです。`setItem(キー, 値)` で保存し、`getItem(キー)` で読み出します。値は文字列で保存されるので、読むときは `parseInt` で数に直します。初めて遊ぶときは `null` が返り、`parseInt` の結果が `NaN` になるので、`|| 0` で 0 にしています。

キーの名前は、同じサイトのほかのゲームとぶつからないよう、ゲームごとに変えておきます。プライベートブラウズなどで保存が禁止されているとエラーになることがあるので、`try` / `catch` で囲んで、保存できなくてもゲームは続けられるようにします。

## 効果音を作る

続けて、そのまま **下** に追加します。

```js:game.js

  // ---------- サウンド（Web Audio で生成） ----------
  let actx = null;
  function audio() {
    if (!actx) {
      try { actx = new (window.AudioContext || window.webkitAudioContext)(); } catch (e) { actx = null; }
    }
    if (actx && actx.state === 'suspended') actx.resume();
    return actx;
  }
  function tone(freq, dur, type = 'sine', vol = 0.12, slide = 0) {
    const a = audio();
    if (!a) return;
    const o = a.createOscillator();
    const g = a.createGain();
    o.type = type;
    o.frequency.setValueAtTime(freq, a.currentTime);
    if (slide) o.frequency.exponentialRampToValueAtTime(Math.max(40, freq * slide), a.currentTime + dur);
    g.gain.setValueAtTime(vol, a.currentTime);
    g.gain.exponentialRampToValueAtTime(0.001, a.currentTime + dur);
    o.connect(g).connect(a.destination);
    o.start();
    o.stop(a.currentTime + dur);
  }
  const gulpSound = (s) => tone(900 - Math.min(700, s * 7), 0.18, 'triangle', 0.1, 0.45);
  const levelSound = () => { tone(523, 0.12, 'square', 0.07); setTimeout(() => tone(784, 0.2, 'square', 0.07), 110); };
```

### Web Audio API で音を「合成」する

音声ファイルを用意しなくても、ブラウザの **Web Audio API** でシンプルな音を作れます。

- `AudioContext` は音の処理全体の入れ物です。ブラウザは「ユーザーが操作するまで音を鳴らせない」決まりがあるので、スタートボタンを押したときに `audio()` を呼んで作り、止まっていれば `resume()` で動かします。
- `createOscillator()` は一定の高さ（`frequency`、単位は Hz）の音を出し続ける **発振器** です。`type` で音色（`sine` はやわらかい音、`square` はピコピコしたゲーム機っぽい音、`triangle` はその中間、`sawtooth` はジリジリした音）を選びます。
- `createGain()` は音量のつまみです。`exponentialRampToValueAtTime` で音量をすっと小さくすると、「ポン」と自然に消える音になります。`slide` を指定すると高さも下がっていき、「ごくん」と落ちていく感じが出ます。
- `gulpSound(s)` は飲みこんだ物が大きいほど低い音にします。`levelSound()` はド（523Hz）→ソ（784Hz）の2音で、サイズアップを知らせます。

## スタート・タイムアップ・HUD

`start()` の **最初の行** に `audio();` を追加し、`reset()` ではスコアとレベルと一緒に残り時間も戻します。

```js:game.js
  function reset() {
    buildCity();
    hole = { x: WORLD_W / 2, y: WORLD_H / 2, r: 20, area: 400, vr: 20 };
    eating = [];
    particles = [];
    score = 0; level = 1; timeLeft = GAME_TIME;
    cam.x = hole.x; cam.y = hole.y; cam.zoom = targetZoom();
    updateHud();
  }

  function start() {
    audio();
    reset();
    state = 'play';
    overlay.classList.add('hidden');
    lastT = performance.now();
    requestAnimationFrame(loop);
  }
```

`start()` の **下** に、タイムアップの処理を追加します。

```js:game.js
  function gameOver() {
    state = 'over';
    let msg = `スコア ${score}<br>サイズ ${level}`;
    if (score > best) {
      best = score;
      try { localStorage.setItem(BEST_KEY, String(best)); } catch (e) { /* 保存できなくても続行 */ }
      bestEl.textContent = best;
      msg += '<br><b style="color:#fff36e">ハイスコア更新！</b>';
    }
    tone(330, 0.3, 'sawtooth', 0.06, 0.5);
    setTimeout(() => {
      ovTitle.textContent = 'タイムアップ！';
      ovText.innerHTML = msg;
      startBtn.textContent = 'もう一度あそぶ';
      overlay.classList.remove('hidden');
    }, 500);
  }
```

`updateHud()` には、残り時間の表示を追加します。

```js:game.js
  function updateHud() {
    timeEl.textContent = Math.ceil(timeLeft);
    timeEl.classList.toggle('low', timeLeft <= 10);
    sizeEl.textContent = level;
    scoreEl.textContent = score;
  }
```

### タイムアップからリトライまでの流れ

1. `state` を `'over'` にすると、`loop()` の最後の `if (state === 'play')` が成り立たなくなり、ゲームループが止まります。
2. ハイスコアを超えていれば `best` を更新して `localStorage` に保存し、メッセージに「ハイスコア更新！」を足します。
3. 0.5 秒待ってから、タイトル画面で使っていたオーバーレイの文字を書きかえて表示します。少し間をあけると、最後の瞬間を見届けてから結果が出るので落ち着いた印象になります。
4. ボタンの文字は「もう一度あそぶ」になりますが、押したときの処理はタイトル画面と同じ `start()` です。`reset()` が街を作り直し、穴・スコア・時間をすべて最初に戻すので、そのままリトライになります。

`Math.ceil` は小数点以下を切り上げます。残り 0.3 秒のときも「0」ではなく「1」と表示されるので、0 になった瞬間にタイムアップになって自然です。`classList.toggle('low', 条件)` は、条件が `true` ならクラスをつけ、`false` なら外します。残り 10 秒を切ると、ステップ1の CSS で数字が赤くなります。

> [!CHECK] 動作チェック
> - スタートすると TIME が 60 から減っていき、残り 10 秒を切ると赤くなる
> - 物を飲みこむと「ポン」と音が鳴り、大きな物ほど低い音になる。サイズアップでは2音のジングルが鳴る
> - 0 になると「タイムアップ！」とスコア・サイズが表示され、初回やベストを超えたときは「ハイスコア更新！」と出て BEST が更新される
> - 「もう一度あそぶ」（または Enter）で新しい街から遊び直せる。ページを再読み込みしても BEST が残っている

## 改造アイデア

> [!TIP]
> **ボーナスアイテム**: 金色に光る「時計」を街にいくつか置き、飲みこむと `timeLeft += 5` で残り時間が増えるようにしてみましょう。`KINDS` に新しい種類を足して、`drawObj` に `case` を1つ追加するだけで作れます。

> [!TIP]
> **動く車**: 歩く人と同じように、道路の車に `speed` を持たせて道路に沿って走らせてみましょう。縦の道路の車（`rot` が 90 度）は y 方向に、横の道路の車は x 方向に動かし、街の端まで来たら反対側から出てくるようにすると本物の街らしくなります。

> [!TIP]
> **ライバルの穴**: コンピューターが動かす2つ目の穴を作り、近くの小さな物へ向かって動くようにしてみましょう。自分より小さいライバルの穴を飲みこめるようにすれば、本格的な対戦ゲームになります。

> [!TIP]
> **ミニマップ**: 画面の隅に街全体を小さく描き、穴の位置を点で示してみましょう。`draw()` の最後（カメラの変換を `restore()` した後）で、ワールドの座標に `ミニマップの幅 / WORLD_W` をかけて縮めて描けば作れます。
