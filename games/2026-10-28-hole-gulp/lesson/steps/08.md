## このステップのゴール

飲みこむ瞬間を気持ちよくする演出を入れます。物がくるくる回りながら穴の中へ小さくなって消えるアニメーション、大きな物を飲みこんだときに飛び散る破片（パーティクル）、「サイズアップ！」の文字、そして街を歩きまわる人です。

## 要素と変数

`const scoreEl = ...;` の **下** に追加します。

```js:game.js
  const popEl = document.getElementById('pop');
```

`let hole, objects;` を次のように書きかえます。

```js:game.js
  let hole, objects, eating, particles;
```

- `eating` … 飲みこまれている途中の物のリスト（アニメーションが終わるまでここに入れておく）
- `particles` … 飛び散る破片のリスト

`reset()` の中、`score = 0; level = 1;` の **上** に2行追加して、ゲームを始めるたびに空にします。

```js:game.js
    eating = [];
    particles = [];
```

## 「サイズアップ！」を表示する `pop()`

`updateHud()` の **下** に追加します。

```js:game.js
  let popTimer = 0;
  function pop(text) {
    popEl.textContent = text;
    popEl.classList.add('show');
    clearTimeout(popTimer);
    popTimer = setTimeout(() => popEl.classList.remove('show'), 900);
  }
```

`show` クラスをつけると、ステップ1の CSS の `transition` で文字がふわっと現れ、0.9 秒後にクラスを外すとまた消えます。続けてサイズアップしたときに前のタイマーで早く消えてしまわないよう、`clearTimeout` で前のタイマーを取り消してから新しく設定します。

## update() に演出を足す

### 歩く人

`update()` の中、`// 飲みこみ判定` の **上** に追加します。

```js:game.js
    // 歩く人
    for (const o of objects) {
      if (o.wander === undefined) continue;
      o.wander += rand(-1.5, 1.5) * dt;
      o.x = Math.max(4, Math.min(WORLD_W - 4, o.x + Math.cos(o.wander) * 18 * dt));
      o.y = Math.max(4, Math.min(WORLD_H - 4, o.y + Math.sin(o.wander) * 18 * dt));
    }
```

ステップ5で人を置いたとき、`{ wander: ... }` として歩く向き（角度。ラジアン）を持たせておきました。`wander` を持つ物だけ、`Math.cos` と `Math.sin` で角度を x・y の向きに直して、秒速 18 で進ませます。毎フレーム角度を少しずつランダムに変えると、ふらふらと気ままに歩いているように見えます。

### 飲みこんだ物をアニメーション用のリストへ

飲みこみ判定の `if` の中を、次のように書きかえます。

```js:game.js
      if (d < hole.r - o.s * 0.35) {
        objects.splice(i, 1);
        o.t = 0;
        eating.push(o);
        score += o.value;
        hole.area += o.s * o.s * 0.55;
        if (o.s >= 22) for (let p = 0; p < 8; p++) particles.push({ x: o.x, y: o.y, vx: rand(-80, 80), vy: rand(-80, 80), life: 0.5, color: o.color });
      }
```

街の物のリスト `objects` から取り除いた物を、すぐに捨てずに `eating` に移します。`o.t` はアニメーションの進み具合で、0 から 1 まで進んだら終わりです。車以上の大きさ（`s >= 22`）なら、その物の色の破片を8個、ランダムな速度で飛ばします。

### サイズアップの文字

サイズアップの `while` の中に `pop(...)` を追加します。

```js:game.js
    while (level < LEVELS.length && hole.r >= LEVELS[level]) {
      level++;
      pop(`サイズアップ！ Lv.${level}`);
    }
```

### 飲みこみ中の物と破片を動かす

サイズアップの `while` の **下**、`// カメラ` の **上** に追加します。

```js:game.js

    // 飲みこみ中のアニメーション
    for (let i = eating.length - 1; i >= 0; i--) {
      const o = eating[i];
      o.t += dt / 0.35;
      o.x += (hole.x - o.x) * Math.min(1, dt * 8);
      o.y += (hole.y - o.y) * Math.min(1, dt * 8);
      o.rot += dt * 6;
      if (o.t >= 1) eating.splice(i, 1);
    }
    for (let i = particles.length - 1; i >= 0; i--) {
      const p = particles[i];
      p.x += p.vx * dt; p.y += p.vy * dt; p.life -= dt;
      if (p.life <= 0) particles.splice(i, 1);
    }
```

- `o.t += dt / 0.35` で、0.35 秒かけて `t` が 0 から 1 になります。その間、物は穴の中心へ引き寄せられ（カメラと同じ「残りの一部だけ近づく」書き方）、`rot` を増やしてくるくる回ります。
- 破片は速度 `vx, vy` で飛び、寿命 `life` が 0 になったら消します。どちらも途中で消すので、ステップ7と同じく **後ろから** ループします。

## 穴の中に切り抜いて描く

`draw()` の中、穴のふちを描いた `ctx.stroke();` と `// 街の物（画面内だけ）` の **間** に追加します。

```js:game.js
    // 飲みこまれ中の物（穴の中に切り抜き）
    ctx.save();
    ctx.beginPath(); ctx.arc(hole.x, hole.y, r, 0, Math.PI * 2); ctx.clip();
    for (const o of eating) {
      ctx.globalAlpha = Math.max(0, 1 - o.t);
      drawObj(o, Math.max(0.05, 1 - o.t * 0.8));
    }
    ctx.globalAlpha = 1;
    ctx.restore();

```

### clip で「穴の外にはみ出さない」ようにする

`ctx.clip()` は、直前に作ったパス（ここでは穴の円）の **内側にしか描けなくする** 命令です。大きな家が穴に落ちていくとき、穴からはみ出した部分は見えなくなるので、本当に穴へ沈んでいくように見えます。`clip` の効果は `restore()` で解除されるので、必ず `save()` と組にします。

物は `drawObj(o, 大きさの倍率)` で、`t` が進むほど小さく（ステップ5で用意した `scale` 引数）、`globalAlpha`（全体の不透明度）で薄くして描きます。描き終わったら `globalAlpha` を 1 に戻すのを忘れないようにしましょう。

## 破片を描く

`draw()` の中、街の物を描くループの閉じかっこ `}` の **下**、`ctx.restore();` の **上** に追加します。

```js:game.js
    for (const p of particles) {
      ctx.globalAlpha = Math.max(0, p.life * 2);
      ctx.fillStyle = p.color;
      ctx.fillRect(p.x - 3, p.y - 3, 6, 6);
    }
    ctx.globalAlpha = 1;
```

寿命 0.5 秒の破片は、`life * 2` で不透明度が 1 から 0 へだんだん薄くなって消えます。

> [!CHECK] 動作チェック
> - 物を飲みこむと、くるくる回りながら小さくなって穴の中へ消えていく。家などの大きな物は穴の外にはみ出さず、沈んでいくように見える
> - 車以上の物を飲みこむと、色つきの小さな破片が飛び散る
> - サイズアップすると「サイズアップ！ Lv.2」のような黄色い文字が出て、少しして消える
> - 人がふらふらと歩きまわっている
