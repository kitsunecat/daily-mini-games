## このステップのゴール

スマホでも遊べるように、画面をドラッグした方向へ穴が動く **バーチャルスティック** を作ります。指（またはマウス）を置いた場所に丸いスティックが現れ、ずらした向きと距離で進む方向と速さが決まります。

## 入力の変数

`let lastT = 0;` の **下**（`const keys = {};` の上）に追加します。

```js:game.js
  const input = { dx: 0, dy: 0, active: false, sx: 0, sy: 0 };
```

- `active` … 今ドラッグ中かどうか
- `sx, sy` … スティックの中心（指を置いた場所。画面の座標）
- `dx, dy` … スティックの倒し具合。長さが 0〜1 の向きベクトルで、`update()` でそのまま移動の向きに使います

## update() でスティックの向きを使う

`update()` の最初の行 `let dx = 0, dy = 0;` を、次のように書きかえます。

```js:game.js
    let dx = input.dx, dy = input.dy;
```

キーが押されているときは、すぐ下の `if (kx || ky) { ... }` でキーの向きに上書きされるので、キーボードとスティックのどちらでも動かせます。スティックは少しだけ倒すと `dx, dy` の長さが 1 より小さくなるので、**ゆっくり動く** こともできます。

## Pointer Events でドラッグを受け取る

`// ---------- 入力 ----------` の行の **すぐ下**（`keydown` の処理の上）に追加します。

```js:game.js
  function localPos(e) {
    const r = cv.getBoundingClientRect();
    return { x: e.clientX - r.left, y: e.clientY - r.top };
  }
  cv.addEventListener('pointerdown', (e) => {
    const p = localPos(e);
    input.active = true; input.sx = p.x; input.sy = p.y; input.dx = 0; input.dy = 0;
    try { cv.setPointerCapture(e.pointerId); } catch (err) { /* 無視 */ }
  });
  cv.addEventListener('pointermove', (e) => {
    if (!input.active) return;
    const p = localPos(e);
    let dx = p.x - input.sx, dy = p.y - input.sy;
    const l = Math.hypot(dx, dy);
    if (l > 40) { input.sx = p.x - dx / l * 40; input.sy = p.y - dy / l * 40; dx = dx / l * 40; dy = dy / l * 40; }
    const m = Math.hypot(dx, dy);
    const k = m < 6 ? 0 : Math.min(1, m / 40) / m;
    input.dx = dx * k; input.dy = dy * k;
  });
  const end = () => { input.active = false; input.dx = 0; input.dy = 0; };
  cv.addEventListener('pointerup', end);
  cv.addEventListener('pointercancel', end);
```

### Pointer Events とは

`pointerdown`（押した）・`pointermove`（動かした）・`pointerup`（離した）は、**マウスとタッチとペンをまとめて扱える** イベントです。`touchstart` と `mousedown` を別々に書かなくても、これだけでスマホとパソコンの両方に対応できます。`pointercancel` は、電話がかかってきたなどで操作が中断されたときに来るイベントです。

- `e.clientX, e.clientY` はウィンドウの左上からの位置なので、`getBoundingClientRect()` で取った Canvas の左上の位置を引いて「Canvas の中の座標」に直します（`localPos`）。
- `setPointerCapture` を呼ぶと、指が Canvas の外にはみ出しても `pointermove` が届き続けます。古いブラウザでエラーになっても困らないよう `try` で囲んでいます。

### スティックの計算

1. 指を置いた場所 `(sx, sy)` から今の指の位置までのずれ `dx, dy` を求めます。
2. ずれの長さ `l` が 40 より大きいときは、**スティックの中心を指のほうへ引っぱって** 、ずれがちょうど 40 になるようにします。こうすると、指を大きく動かして向きを変えたときにも、すぐに反対へ切りかえられます。
3. 最後に、長さ 0〜40 のずれを長さ 0〜1 の向きに変換します。長さ 6 未満は 0 にして（**デッドゾーン**）、指を置いただけで少し動いてしまうのを防ぎます。`k` は「長さ `m` のベクトルを、長さ `min(1, m/40)` にする」ための倍率です。

## スティックを描く

`draw()` の **最後**、いちばん外側の `ctx.restore();` の **後**（関数の閉じかっこ `}` の前）に追加します。

```js:game.js
    // 操作スティックの表示
    if (input.active && state === 'play') {
      ctx.strokeStyle = 'rgba(255,255,255,.4)';
      ctx.lineWidth = 2;
      ctx.beginPath(); ctx.arc(input.sx, input.sy, 40, 0, Math.PI * 2); ctx.stroke();
      ctx.fillStyle = 'rgba(255,255,255,.45)';
      ctx.beginPath(); ctx.arc(input.sx + input.dx * 40, input.sy + input.dy * 40, 14, 0, Math.PI * 2); ctx.fill();
    }
```

スティックの位置は画面の座標なので、カメラの変換を `restore()` で元に戻した **後** に描くのがポイントです。変換の中で描くと、カメラのズームや移動に合わせてスティックまで動いてしまいます。

> [!CHECK] 動作チェック
> - スタート後に画面を押したままドラッグすると、押した場所に半透明の丸と小さなつまみが現れ、ずらした方向へ穴が動く
> - 少しだけずらすとゆっくり、40px 以上ずらすと最高速で動く
> - 指（マウス）を離すとスティックが消えて穴が止まる。矢印キーでも引き続き動かせる

> [!TIP]
> パソコンでスマホの操作を試すには、開発者ツールのデバイスモード（スマホ表示）に切りかえます。マウスのドラッグでも同じように動きます。
