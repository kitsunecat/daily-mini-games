## このステップのゴール

いよいよゲームの中心、「自分より小さい物を飲みこんで大きくなる」仕組みを作ります。物が穴に入ったら消して得点を足し、穴の **面積** を増やします。穴が大きくなるとカメラがズームアウトし、サイズ（レベル）とスコアがヘッダーに表示されます。

## ヘッダーの要素と変数

`const stage = ...;` の **下** に、ヘッダーの数字の要素を2つ追加します。

```js:game.js
  const sizeEl = document.getElementById('size');
  const scoreEl = document.getElementById('score');
```

`const BLOCK = 400, ROAD = 64;` の **下**（`KINDS` の上）に、レベルの区切りを追加します。

```js:game.js
  // 穴の半径がこの値を超えるごとにサイズアップ
  const LEVELS = [0, 28, 40, 56, 78, 105, 140];
```

`let hole, objects;` の **下** に、スコアとレベルの変数を追加します。

```js:game.js
  let score = 0, level = 1;
```

## reset() と HUD の更新

`reset()` を次のように書きかえます。穴に `area`（面積）と `vr`（見た目の半径）が増えています。

```js:game.js
  function reset() {
    buildCity();
    hole = { x: WORLD_W / 2, y: WORLD_H / 2, r: 20, area: 400, vr: 20 };
    score = 0; level = 1;
    cam.x = hole.x; cam.y = hole.y; cam.zoom = targetZoom();
    updateHud();
  }
```

`start()` の **下** に、ヘッダーの数字を書きかえる関数を追加します。

```js:game.js
  function updateHud() {
    sizeEl.textContent = level;
    scoreEl.textContent = score;
  }
```

画面の上にスコアなどを表示する部分を **HUD**（ヘッドアップディスプレイ）と呼びます。数字を書きかえる処理を1つの関数にまとめておくと、どこで値が変わっても `updateHud()` を呼ぶだけで済みます。

## 飲みこみ判定と成長

`update()` の中、穴を動かす2行（`hole.x = ...` と `hole.y = ...`）の **下**、`// カメラ` の **上** に追加します。

```js:game.js

    // 飲みこみ判定
    for (let i = objects.length - 1; i >= 0; i--) {
      const o = objects[i];
      if (o.s >= hole.r * 0.92) continue;
      const d = Math.hypot(o.x - hole.x, o.y - hole.y);
      if (d < hole.r - o.s * 0.35) {
        objects.splice(i, 1);
        score += o.value;
        hole.area += o.s * o.s * 0.55;
      }
    }
    hole.r = Math.sqrt(hole.area);
    hole.vr += (hole.r - hole.vr) * Math.min(1, dt * 6);

    // サイズアップ
    while (level < LEVELS.length && hole.r >= LEVELS[level]) {
      level++;
    }
```

さらに `update()` の **最後**（`cam.zoom += ...` の行の下）に1行追加します。

```js:game.js
    updateHud();
```

### 当たり判定は「円と円の距離」

穴も物も円だと考えて、中心どうしの距離 `d` を `Math.hypot`（三平方の定理）で求めます。飲みこめる条件は2つです。

1. **物が穴より小さいこと** … `o.s < hole.r * 0.92`。同じくらいの大きさの物は飲みこめません。条件に合わない物は `continue` で次へ飛ばします。
2. **物がほぼ穴の中に入っていること** … `d < hole.r - o.s * 0.35`。物の中心が穴のふちより内側に、物の大きさの 35% ぶん以上入ったら落ちる、という判定です。ふちに少しかかっただけでは落ちないので、「穴の上に乗せて落とす」感覚になります。

### 配列を後ろから回して消す

ループの中で `splice(i, 1)` を使って要素を消すと、それより後ろの要素が1つずつ前に詰まります。前から回していると、詰まった次の要素を飛ばしてしまいます。**後ろから** `i--` で回せば、消したことでずれるのは調べ終わった要素だけなので安全です。

### 面積で成長させる

飲みこむたびに半径を足していくと、大きくなるほど成長が速すぎたり遅すぎたりします。そこで、穴の **面積** `area` に「物の大きさの2乗に比例する量」を足し、半径は `Math.sqrt(hole.area)` で求めます。大きな物ほどたくさん成長でき、小物ばかり食べていても大きくなりにくい、という自然なバランスになります。最初は半径 20 なので、面積は 20×20 = 400 から始めています。

`hole.r` は判定に使う本当の半径、`hole.vr` は見た目の半径です。`vr` をカメラと同じ方法で `r` にゆっくり近づけると、穴がふわっと広がるアニメーションになります。

### サイズアップ

`LEVELS[level]` は「次のレベルになるのに必要な半径」です。大きな物を飲みこんで一度に2段階上がることもあるので、`if` ではなく `while` で、条件を満たす限りレベルを上げ続けます。

## 見た目の半径で描く・飲みこめる物に印をつける

`draw()` の穴を描く部分の最初の行を、見た目の半径を使うように書きかえます。

```js:game.js
    const r = hole.vr;
```

続けて、街の物を描くループを次のように書きかえます。`drawObj(o);` の後ろに印を描く処理が増えています。

```js:game.js
    for (const o of objects) {
      if (Math.abs(o.x - cam.x) > vw || Math.abs(o.y - cam.y) > vh) continue;
      drawObj(o);
      // 飲みこめる物には小さな印
      if (o.s < hole.r * 0.92 && o.s >= 16) {
        ctx.fillStyle = 'rgba(79,209,255,.9)';
        ctx.beginPath(); ctx.arc(o.x, o.y - o.s - 6, 4, 0, Math.PI * 2); ctx.fill();
      }
    }
```

木より大きい物（`s >= 16`）のうち、今の穴で飲みこめる物の上に水色の点をつけます。「次はあれを狙える」と分かるので、遊ぶ人が迷いません。

> [!CHECK] 動作チェック
> - 穴をコーンや人の上に重ねると、それが消えて SCORE が増える。同じくらいの大きさの物は消えない
> - 飲みこむほど穴がふわっと大きくなり、カメラが少しずつ引いて広い範囲が見えるようになる
> - 穴の半径が 28 を超えると SIZE が 2 になる
> - 木の上には最初から水色の点が出ている。大きくなると車やバス、家の上にも点が出て、飲みこめるようになる
