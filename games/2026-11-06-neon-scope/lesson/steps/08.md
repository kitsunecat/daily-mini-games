## このステップのゴール

最後の仕上げです。**ハイスコア** をブラウザに保存して次に開いたときも残るようにし、発射音・命中音・ダメージ音などの **効果音** を、音声ファイルを使わずに JavaScript だけで鳴らします。スマホではダメージのときに短く振動させます。これで完成品と同じゲームになります。

## ハイスコアを読みこむ

要素を取る1行目を **書きかえ** て `elBest` を足し、定数の行の **上下** にハイスコアの準備を追加します。

```js:game.js
  const elLife = $('life'), elScore = $('score'), elBest = $('best'), elAmmo = $('ammo');
  const overlay = $('overlay'), ovTitle = $('ov-title'), ovText = $('ov-text'), btnStart = $('start'), toastEl = $('toast');

  const BEST_KEY = 'neon-scope-best';
  const MAX_AMMO = 6, RELOAD_TIME = 1.2, ZOOM = 3, MAX_LIFE = 3;
  let best = 0;
  try { best = parseInt(localStorage.getItem(BEST_KEY) || '0', 10) || 0; } catch (e) { best = 0; }
  elBest.textContent = best;
```

- **localStorage** は、ブラウザにちょっとしたデータを保存しておける場所です。`localStorage.setItem(キー, 値)` で保存、`localStorage.getItem(キー)` で読み出します。ページを閉じても、次に開いたときに残っています。
- 保存できるのは **文字列だけ** です。読み出した文字列を `parseInt(..., 10)` で数に直します。まだ何も保存されていないと `getItem` は `null` を返すので、`|| '0'` で `'0'` にしています。
- プライベートブラウズなど、localStorage が使えない環境ではエラーになることがあります。`try { ... } catch (e) { ... }` で囲んでおけば、エラーが出てもゲームは止まらず、ハイスコア 0 のまま遊べます。
- キーの名前 `'neon-scope-best'` は、同じサイトのほかのゲームとぶつからないよう、ゲームの名前を入れています。

`hud()` の中、`elScore.textContent = score;` の **下** に1行足します。

```js:game.js
    elScore.textContent = score;
    elBest.textContent = best;
```

## ゲームオーバーで記録を保存する

`gameOver()` を、まるごと次のように **書きかえ** ます。

```js:game.js
  function gameOver() {
    state = 'over'; aiming = false; keyAim = false;
    let rec = false;
    if (score > best) {
      best = score; rec = true;
      try { localStorage.setItem(BEST_KEY, String(best)); } catch (e) {}
    }
    hud();
    ovTitle.textContent = 'ミッション失敗';
    ovText.innerHTML = `スコア <b style="font-size:26px">${score}</b><br>${rec ? '🎉 ハイスコア更新！' : 'ベスト ' + best}`;
    btnStart.textContent = 'もう一度';
    setTimeout(() => overlay.classList.remove('hide'), 500);
  }
```

今回のスコアが記録を超えていたら `best` を更新して保存し、結果画面に「ハイスコア更新！」を出します。超えていなければ、いまのベストを出して「あと少し」と思わせます。

## Web Audio API で音を作る

`draw()` の **下**、`// ---------- game ----------` の **上** に追加します。

```js:game.js
  // ---------- audio ----------
  let ac = null;
  function audio() {
    if (!ac) { try { ac = new (window.AudioContext || window.webkitAudioContext)(); } catch (e) { ac = null; } }
    if (ac && ac.state === 'suspended') ac.resume();
  }
  function tone(freq, dur, type = 'sine', vol = 0.15, slide = 0) {
    if (!ac) return;
    const o = ac.createOscillator(), g = ac.createGain(), n = ac.currentTime;
    o.type = type; o.frequency.setValueAtTime(freq, n);
    if (slide) o.frequency.exponentialRampToValueAtTime(Math.max(30, freq + slide), n + dur);
    g.gain.setValueAtTime(vol, n); g.gain.exponentialRampToValueAtTime(0.001, n + dur);
    o.connect(g).connect(ac.destination); o.start(n); o.stop(n + dur);
  }
  function shotSound() {
    if (!ac) return;
    const n = ac.currentTime, len = 0.25;
    const buf = ac.createBuffer(1, Math.floor(ac.sampleRate * len), ac.sampleRate), d = buf.getChannelData(0);
    for (let i = 0; i < d.length; i++) d[i] = (Math.random() * 2 - 1) * Math.pow(1 - i / d.length, 3);
    const src = ac.createBufferSource(), g = ac.createGain(), f = ac.createBiquadFilter();
    f.type = 'lowpass'; f.frequency.value = 1800;
    src.buffer = buf; g.gain.value = 0.35;
    src.connect(f).connect(g).connect(ac.destination); src.start(n);
  }
```

- **Web Audio API** は、ブラウザの中で音を作って鳴らせるしくみです。音の部品（ノード）を `connect` でつないで、最後にスピーカー（`ac.destination`）につなぎます。
- `audio()` … 音を鳴らす土台の `AudioContext` を作ります。ブラウザは「ユーザーが画面をタップ・クリックしたとき」でないと音を出させてくれないので、スタートボタンやスコープを押したときに呼びます。
- `tone()` … **オシレーター**（一定の高さの音を出し続ける発振器）で「ピッ」という音を作ります。`freq` は高さ（Hz）、`type` は音色（`'sine'` やわらかい、`'square'` ピコピコ、`'triangle'` その中間、`'sawtooth'` ビリビリ）です。音量（gain）を `exponentialRampToValueAtTime` でほぼ 0 まで下げて、自然に消えるようにしています。`slide` を指定すると、音の高さもすべらせて変えられます。
- `shotSound()` … 銃声は「ピッ」ではなく「バスッ」という雑音です。そこで、ランダムな値（**ホワイトノイズ**）を 0.25 秒分つくり、だんだん小さくなるように `Math.pow(1 - i / d.length, 3)` をかけます。さらに **ローパスフィルター**（高い音をカットする）に通すと、こもった重い発射音になります。

## 音を鳴らす場所

あとは、いろいろな場所で音を鳴らすだけです。

`hurt()` を次のように **書きかえ** ます。低い音が下がっていく「ブーッ」という音と、スマホの振動です。

```js:game.js
  function hurt(msg) {
    life--; combo = 0; hurtFlash = 0.6;
    tone(110, 0.35, 'sawtooth', 0.2, -50);
    toast(msg, '#ff6b7a');
    if (navigator.vibrate) { try { navigator.vibrate(80); } catch (e) {} }
    if (life <= 0) gameOver();
  }
```

`navigator.vibrate(ミリ秒)` で端末を振動させられます。対応していない端末（iPhone や PC など）もあるので、`if (navigator.vibrate)` で確かめてから呼びます。

`fire()` の中、`ammo--; muzzle = 0.12;` の **下** に発射音を足します。

```js:game.js
    ammo--; muzzle = 0.12;
    shotSound();
```

`fire()` の中、敵に当たって `popups.push(...)` をした **下** に命中音を足します。ヘッドショットはより高い音にして、特別感を出しています。

```js:game.js
        popups.push({ x: s.x, y: s.y - 20, text: (head ? 'HEAD +' : '+') + pts, c: head ? '#ffe27a' : '#fff', life: 1 });
        tone(head ? 1320 : 880, 0.15, 'triangle', 0.18);
```

`update()` の中、リロードが終わったときに「カチッ」と鳴らします。

```js:game.js
    if (reload > 0) { reload -= dt; if (reload <= 0) { reload = 0; ammo = MAX_AMMO; tone(600, 0.08, 'square', 0.08); hud(); } }
```

`start()` の先頭と、`pointerdown` の `e.preventDefault();` の **下** に `audio();` を足します。

```js:game.js
  function start() {
    audio();
    resize();
```

```js:game.js
    e.preventDefault();
    audio();
```

> [!CHECK] 動作チェック
> - 撃つと「バスッ」と発射音、敵に当てると「ピン」、ヘッドショットはさらに高い音が鳴る
> - ダメージを受けると低い音が鳴る（Android ならブルッと振動する）
> - 弾を撃ち切ってリロードが終わると「カチッ」と鳴る
> - ゲームオーバーで記録を超えたら「🎉 ハイスコア更新！」と出て、上の BEST も更新される
> - ページを再読み込みしても BEST が残っている

## 完成！ 改造アイデア

おめでとうございます。これで完成品と同じ「ネオンスコープ」ができあがりました。ここからは自由に改造してみましょう。

> [!TIP]
> **ズーム切りかえ** … `ZOOM` を `let` にして、ダブルタップや Shift キーで 3 倍 ↔ 5 倍を切りかえられるようにしてみましょう。倍率が高いほど手ぶれも大きく見えるので、`sway()` のゆれ幅も調整すると面白くなります。

> [!TIP]
> **息止め** … スコープを開いてから 1 秒ほどは手ぶれを 0 に近づけ、そのあと逆に大きくする、という本格的なスナイパーの手ざわりを作れます。`sway()` の `k` を「スコープを開いてからの時間」で変えてみましょう。

> [!TIP]
> **人質ターゲット** … 敵と市民がくっついて並んで出てくるパターンを `spawn()` に足すと、ヘッドショットをねらう理由がはっきりします。

> [!TIP]
> **ステージ制** … 「敵を 20 人倒したらクリア」にして、ステージが進むたびに夜明け（空のグラデーションの色）を変えていくと、進んでいる実感が出ます。

> [!TIP]
> **ライフ回復アイテム** … ときどき屋上に緑の箱を出し、撃つとライフが1つ戻るようにしてみましょう。`kind` に `'item'` を増やし、`drawFigure()` と `fire()` に分岐を足すのがおすすめです。
