## このステップのゴール

このゲームのいちばんの見せ場、**スコープ** を作ります。画面を押しているあいだだけ、ねらっている場所を中心に丸い窓が開き、その中に街が3倍に拡大されて映ります。ドラッグでねらいを動かせて、スコープの中はわずかに **手ぶれ** でゆれます。まだ撃てません。

## 定数と変数

`const overlay = ...` の行の **下** に、ズーム倍率の定数を追加します。

```js:game.js
  const ZOOM = 3;
```

`let elapsed = 0, spawnTimer = 0, t = 0;` の **下** に、ねらいの変数を追加します。

```js:game.js

  // aim
  let aiming = false, aimX = 0, aimY = 0, touchOffset = 0;
```

- `aiming` … いま押していて、スコープをのぞいているか
- `aimX`, `aimY` … ねらっている場所（Canvas の左上からの px）
- `touchOffset` … スマホで指の少し上をねらうためのずらし量（あとで説明します）

`resize()` の最後、`buildCity();` の **下** に1行足して、ねらいを画面のまん中に戻します。

```js:game.js
    buildCity();
    aimX = W / 2; aimY = H / 2;
  }
```

## 手ぶれとスコープの大きさ

`draw()` の **上** に2つの関数を追加します。

```js:game.js
  function sway() {
    return {
      x: aimX + Math.sin(t * 1.3) * 2.2 + Math.sin(t * 3.1) * 0.8,
      y: aimY + Math.cos(t * 1.7) * 1.8 + Math.sin(t * 2.3) * 0.7,
    };
  }

  function scopeR() { return Math.min(W, H) * 0.24; }
```

- `sway()` は「手ぶれを足した、本当にねらっている場所」を返します。速さのちがう sin / cos を2つずつ足し合わせると、規則的に見えない、ふわふわした8の字のようなゆれになります。ゆれ幅は 3px ほどで、人の頭（半径 3）と同じくらい。**ちょうど頭をねらうと、ゆれで外れることがある** 絶妙な大きさです。
- `scopeR()` はスコープの半径です。画面の短いほうの辺の 24% にしています。

## draw() にスコープを描く

`draw()` を、まるごと次のように **書きかえ** ます。

```js:game.js
  function draw() {
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
    drawWorld();
    if (state === 'play' && aiming) {
      const s = sway(), R = scopeR();
      ctx.fillStyle = 'rgba(0,0,0,.45)'; ctx.fillRect(0, 0, W, H);
      ctx.save();
      ctx.beginPath(); ctx.arc(aimX, aimY, R, 0, Math.PI * 2); ctx.clip();
      ctx.translate(aimX, aimY); ctx.scale(ZOOM, ZOOM); ctx.translate(-s.x, -s.y);
      drawWorld();
      ctx.restore();
      const vg = ctx.createRadialGradient(aimX, aimY, R * 0.7, aimX, aimY, R);
      vg.addColorStop(0, 'rgba(0,0,0,0)'); vg.addColorStop(1, 'rgba(0,0,0,.55)');
      ctx.fillStyle = vg; ctx.beginPath(); ctx.arc(aimX, aimY, R, 0, Math.PI * 2); ctx.fill();
      ctx.strokeStyle = '#0d0d0d'; ctx.lineWidth = 6;
      ctx.beginPath(); ctx.arc(aimX, aimY, R, 0, Math.PI * 2); ctx.stroke();
      ctx.strokeStyle = 'rgba(255,60,80,.9)'; ctx.lineWidth = 1.2;
      ctx.beginPath();
      ctx.moveTo(aimX - R, aimY); ctx.lineTo(aimX - 6, aimY);
      ctx.moveTo(aimX + 6, aimY); ctx.lineTo(aimX + R, aimY);
      ctx.moveTo(aimX, aimY - R); ctx.lineTo(aimX, aimY - 6);
      ctx.moveTo(aimX, aimY + 6); ctx.lineTo(aimX, aimY + R);
      ctx.stroke();
      ctx.beginPath(); ctx.arc(aimX, aimY, 1.5, 0, Math.PI * 2); ctx.fillStyle = ctx.strokeStyle; ctx.fill();
    }
  }
```

### 拡大のしくみ（座標変換）

ここがこのゲームでいちばん大事なところです。スコープの中の拡大画像は、**同じ `drawWorld()` をもう一度、座標変換をかけて呼ぶ** だけで作っています。

1. まず画面全体を半透明の黒で暗くします（スコープの外が見えにくくなります）。
2. `ctx.arc(...)` と `ctx.clip()` で、スコープの丸の内側にしか描けないようにします。
3. `translate` → `scale` → `translate` の3つの座標変換をかけます（くわしくは下で）。
4. この状態で `drawWorld()` を呼ぶと、「`s` のまわりを3倍にした街」がスコープの中心に描かれます。
5. `ctx.restore()` で clip と変換をまとめて元に戻します。

3つの変換は、**後から書いたものから順に** 点に効いていくと考えると分かりやすいです。

- `translate(-s.x, -s.y)` … ねらっている点 `s` を原点 (0, 0) に持ってくる
- `scale(ZOOM, ZOOM)` … 原点を中心に3倍に拡大する
- `translate(aimX, aimY)` … 原点をスコープの中心に動かす

ステップ1で `drawWorld()` を分けておいたのも、空を画面より広く塗っておいたのも、このためでした。街のデータは1つなので、ターゲットが動けば拡大画面の中でもちゃんと動きます。

中心をずらしているのは `s`（手ぶれ込みの位置）で、十字線は `aimX, aimY`（指の位置）に描いています。だから十字線は止まって見え、**中の景色のほうがゆらゆら動く** という、本物のスコープらしい見え方になります。

### 飾り

- `createRadialGradient` で、丸のふちに向かって暗くなるグラデーションを重ねています（ビネット効果）。
- 太い黒い円でスコープのふちを描き、赤い十字線を描きます。十字線はまん中を 6px ずつあけて、ねらう先が線で隠れないようにしています。
- 最後に中心に小さな点を打ちます。`ctx.fillStyle = ctx.strokeStyle` で、線と同じ色にしています。

## ポインター操作でねらう

`// ---------- input ----------` の **下**、`btnStart.addEventListener(...)` の **上** に追加します。

```js:game.js
  function pos(e) {
    const r = cv.getBoundingClientRect();
    return { x: e.clientX - r.left, y: e.clientY - r.top };
  }
  function setAim(p) {
    aimX = Math.max(0, Math.min(W, p.x));
    aimY = Math.max(0, Math.min(H, p.y - touchOffset));
  }
  cv.addEventListener('pointerdown', (e) => {
    if (state !== 'play') return;
    e.preventDefault();
    touchOffset = e.pointerType === 'touch' ? Math.min(90, H * 0.12) : 0;
    aiming = true;
    try { cv.setPointerCapture(e.pointerId); } catch (err) {}
    setAim(pos(e));
  });
  cv.addEventListener('pointermove', (e) => { if (aiming) setAim(pos(e)); });
  cv.addEventListener('pointerup', (e) => { if (!aiming) return; setAim(pos(e)); aiming = false; });
  cv.addEventListener('pointercancel', () => { aiming = false; });
  cv.addEventListener('contextmenu', (e) => e.preventDefault());

```

- **Pointer Events**（`pointerdown` / `pointermove` / `pointerup`）は、マウスでも指でもペンでも同じように受け取れるイベントです。スマホと PC を1つのコードで扱えます。
- `pos(e)` は、画面全体の座標（`clientX`, `clientY`）から Canvas の左上の位置を引いて、**Canvas の中での座標** に直す関数です。
- **指の上をねらう工夫** … スマホでは、ねらう場所が自分の指で隠れてしまいます。そこでタッチのときだけ、ねらいを指の位置より `touchOffset`（最大 90px）上にずらします。`e.pointerType` を見ると `'touch'` / `'mouse'` / `'pen'` が分かります。
- `setPointerCapture()` は「このあと指が Canvas の外に出ても、離すまでこの Canvas にイベントを届けて」というお願いです。ドラッグ中に外にはみ出しても、ねらいが止まりません。
- `pointercancel` は、電話がかかってきたなどでタッチが中断されたときに届きます。そのときはスコープを閉じます。
- `contextmenu` を止めているのは、長押しや右クリックでメニューが出ないようにするためです。

`start()` の `elapsed = 0; spawnTimer = 0.6;` の行に `aiming = false;` を足しておきます。

```js:game.js
    elapsed = 0; spawnTimer = 0.6; aiming = false;
```

> [!CHECK] 動作チェック
> - スタート後、画面を押すと丸いスコープが開き、中に街が大きく映る。まわりは暗くなる
> - 押したままドラッグすると、スコープがついてきて、映る場所も変わる
> - スコープの中の景色が、ふわふわと少しゆれている
> - スマホでは、スコープが指の少し上に出る
> - 離すとスコープが閉じる
