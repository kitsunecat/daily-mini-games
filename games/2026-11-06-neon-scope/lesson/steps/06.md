## このステップのゴール

ゲームに「負け」を作ります。**市民を撃ってしまう** か、ターゲットを放っておいて **撃ち返される** とライフが1つ減り、3つなくなるとゲームオーバー。撃たれそうなターゲットの頭の上には「!」マークを点滅させて知らせます。「ヘッドショット！」などのメッセージ（トースト）と、ダメージを受けたときの赤いフラッシュ、ゲームオーバー画面から「もう一度」遊べるところまで作ります。

## 要素・定数・変数

要素を取る2行と定数の行を、次のように **書きかえ** ます。

```js:game.js
  const elLife = $('life'), elScore = $('score'), elAmmo = $('ammo');
  const overlay = $('overlay'), ovTitle = $('ov-title'), ovText = $('ov-text'), btnStart = $('start'), toastEl = $('toast');

  const MAX_AMMO = 6, RELOAD_TIME = 1.2, ZOOM = 3, MAX_LIFE = 3;
```

`let score = ...` と `let elapsed = ...` の2行を、次のように **書きかえ** ます（`life` と `hurtFlash` が増えます）。

```js:game.js
  let score = 0, life = MAX_LIFE, combo = 0, ammo = MAX_AMMO, reload = 0;
  let elapsed = 0, spawnTimer = 0, hurtFlash = 0, muzzle = 0, t = 0;
```

## 撃たれる前の「!」マーク

`drawFigure()` の中、帽子を描く行（`// cap`）の **下** に追加します。

```js:game.js
      ctx.fillRect(x - 3, y - 17.5, 6, 2); // cap
      const left = f.life;
      if (left < 1.1 && Math.floor(t * 10) % 2 === 0) {
        ctx.fillStyle = '#ffee55';
        ctx.fillRect(x - 0.8, y - 26, 1.6, 5);
        ctx.fillRect(x - 0.8, y - 20, 1.6, 1.6);
      }
```

敵の残り時間が 1.1 秒を切ったら、頭の上に黄色い「!」を描きます。`Math.floor(t * 10) % 2 === 0` は、0.1 秒ごとに true / false が切りかわる式です。これで「!」がチカチカ点滅します。プレイヤーに「次にこいつが撃ってくる」と教えて、どれを先に撃つか考えさせるための合図です。

## トーストと HUD

`function hud()` の **上** に `toast()` を追加し、`hud()` の先頭にライフの表示を1行足します。

```js:game.js
  function toast(msg, color) {
    toastEl.textContent = msg; toastEl.style.color = color || '#ffe27a';
    toastEl.classList.add('show');
    clearTimeout(toast._t); toast._t = setTimeout(() => toastEl.classList.remove('show'), 700);
  }
  function hud() {
    elLife.textContent = '♥'.repeat(Math.max(0, life)) + '♡'.repeat(Math.max(0, MAX_LIFE - life));
    elScore.textContent = score;
```

- `toast()` は、`#toast` に文字を入れて `.show` クラスをつけ、0.7 秒後に外します。出たり消えたりのアニメーションは CSS の `transition` にまかせています。
- 続けて呼ばれたとき、前の「消すタイマー」が残っていると新しいメッセージがすぐ消えてしまいます。そこで `clearTimeout` で前のタイマーを取り消してから、新しく予約し直します。タイマーの番号は、関数そのものに `toast._t` としてくっつけて覚えています（JavaScript では関数もオブジェクトなので、プロパティを持てます）。

## hurt() … ダメージを受ける

`function removeTarget(f)` の **上**（`burst()` の **下**）に追加します。

```js:game.js
  function hurt(msg) {
    life--; combo = 0; hurtFlash = 0.6;
    toast(msg, '#ff6b7a');
    if (life <= 0) gameOver();
  }
```

ライフを減らし、コンボを切り、画面を赤く光らせて、赤い文字でメッセージを出します。ライフが 0 になったらゲームオーバーです。ダメージの原因が2つ（市民を撃つ・撃たれる）あっても、この1つの関数を通すようにしておくと、あとで音や振動を足すのも1か所ですみます。

## fire() と update() から呼ぶ

`fire()` の中、敵に当たったときと市民に当たったときの部分を、次のように **書きかえ** ます。

```js:game.js
        popups.push({ x: s.x, y: s.y - 20, text: (head ? 'HEAD +' : '+') + pts, c: head ? '#ffe27a' : '#fff', life: 1 });
        if (head) toast('ヘッドショット！');
        else if (combo >= 3) toast(combo + ' コンボ！');
      } else {
        hurt('市民に命中！');
      }
```

`update()` の中、`if (muzzle > 0) muzzle -= dt;` の **下** に1行足します。

```js:game.js
    if (muzzle > 0) muzzle -= dt;
    if (hurtFlash > 0) hurtFlash -= dt;
```

`update()` の最後、人のループの中の `if (f.life <= 0) removeTarget(f);` を、次のように **書きかえ** ます。

```js:game.js
      if (f.life <= 0) {
        removeTarget(f);
        if (f.kind === 'enemy') { burst(f.x + 6, f.y - 9, '#ffee55', 6); hurt('撃たれた！'); if (state !== 'play') return; }
      }
```

敵が時間切れになったら、銃口のあたり（`f.x + 6`）に黄色い火花を出して「撃たれた！」です。市民は時間切れになっても何も起きません（そのまま帰っていきます）。

`hurt()` の中でゲームオーバーになったら、そのフレームの残りの処理はもう必要ないので `return` で抜けます。

## 赤いフラッシュ

`draw()` の最後、白いフラッシュの行の **下** に追加します。

```js:game.js
    if (muzzle > 0) { ctx.fillStyle = `rgba(255,240,200,${muzzle * 2})`; ctx.fillRect(0, 0, W, H); }
    if (hurtFlash > 0) { ctx.fillStyle = `rgba(255,30,50,${hurtFlash * 0.6})`; ctx.fillRect(0, 0, W, H); }
  }
```

## gameOver() と、もう一度遊ぶ

`start()` の中の `state = 'play'; ...` の行に `life = MAX_LIFE;` を足します。

```js:game.js
    state = 'play'; score = 0; life = MAX_LIFE; combo = 0; ammo = MAX_AMMO; reload = 0;
```

`start()` の **下** に `gameOver()` を追加します。

```js:game.js
  function gameOver() {
    state = 'over'; aiming = false;
    hud();
    ovTitle.textContent = 'ミッション失敗';
    ovText.innerHTML = `スコア <b style="font-size:26px">${score}</b>`;
    btnStart.textContent = 'もう一度';
    setTimeout(() => overlay.classList.remove('hide'), 500);
  }
```

- `state` を `'over'` にすると、`update()` は `if (state !== 'play') return;` で止まり、人も出なくなります。
- タイトル画面だったオーバーレイの文字を書きかえて、結果画面として使い回します。ボタンの文字も「もう一度」にします。ボタンを押すと、ステップ1からつないである `start()` が呼ばれ、すべてリセットされて再スタートです。
- オーバーレイを出すのを 0.5 秒だけ遅らせています。最後に撃たれた赤いフラッシュや火花が見えてから結果が出るので、「やられた」ことが伝わりやすくなります。

> [!CHECK] 動作チェック
> - 赤いターゲットを放っておくと、頭の上に「!」が点滅し、やがて「撃たれた！」と出て画面が赤く光り、LIFE の ♥ が1つ ♡ になる
> - 青い市民を撃つと「市民に命中！」でライフが減る
> - ヘッドショットで「ヘッドショット！」、3連続以上で「3 コンボ！」などのメッセージが出る
> - ライフが 0 になると「ミッション失敗」とスコアが表示され、「もう一度」でライフ・スコア・弾がリセットされて再スタートできる
