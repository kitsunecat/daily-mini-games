## このステップのゴール

街に人を出します。明るい窓から **ひょっこり顔を出す人** と、**屋上を歩き回る人** の2種類の出かたがあり、それぞれ赤いターゲット（敵）か青い市民になります。一定時間たつと引っこんで消えます。時間がたつほど、たくさん・短い時間で出てくるようにもします。

## 変数を追加する

`let stars = ...` の **下** に `targets` を、`let t = 0;` を次のように **書きかえ** ます。

```js:game.js
  let stars = [], backBldg = [], bldg = [], windows = [];
  let targets = [];
  let state = 'title';
  let elapsed = 0, spawnTimer = 0, t = 0;
```

- `targets` … いま画面にいる人（ターゲットも市民もまとめてここに入れます）
- `elapsed` … プレイ開始からの経過秒数。難しさの計算に使います
- `spawnTimer` … 次の人を出すまでの残り時間

`resize()` の中、`buildCity();` の **上** に `targets = [];` を足します。街を作り直すと窓の場所が変わるので、人もいったん全員消します。

```js:game.js
    cv.width = W * dpr; cv.height = H * dpr;
    targets = [];
    buildCity();
```

## drawFigure() … 人をドットで描く

`// ---------- drawing ----------` の **下**、`function drawWorld()` の **上** に追加します。

```js:game.js
  function drawFigure(f) {
    const x = f.x, y = f.y;
    const enemy = f.kind === 'enemy';
    ctx.fillStyle = enemy ? '#e8323c' : '#3ba3ff';
    ctx.fillRect(x - 3, y - 11, 6, 11);
    ctx.fillStyle = enemy ? '#2b0b10' : '#0d2340';
    ctx.fillRect(x - 3, y - 4, 6, 4);
    ctx.fillStyle = '#f1c9a5';
    ctx.beginPath(); ctx.arc(x, y - 14, 3, 0, Math.PI * 2); ctx.fill();
    if (enemy) {
      ctx.fillStyle = '#111';
      ctx.fillRect(x - 3, y - 17.5, 6, 2); // cap
      // gun
      ctx.fillStyle = '#222';
      ctx.fillRect(x + 2, y - 9, 6, 2);
    }
  }
```

人の座標 `(f.x, f.y)` は **足もと** です。そこから上に、体（高さ 11 の四角）、ズボン、頭（半径 3 の円）を重ねます。敵だけ黒い帽子と銃をつけて、見分けられるようにしています。

この **体の四角と頭の円の大きさ** は、ステップ5の当たり判定でそのまま使います。メモしておきましょう。

- 体 … x が `f.x - 3`〜`f.x + 3`、y が `f.y - 11`〜`f.y`
- 頭 … 中心 `(f.x, f.y - 14)`、半径 3

> [!NOTE]
> 人の大きさはたった 6 × 17px ほどです。わざと小さく作っておき、スコープで3倍に拡大して初めてしっかりねらえる、というのがこのゲームの手ざわりの中心です。

## 窓の人は「窓の形に切り抜いて」描く

`drawWorld()` の中、窓を描く `for (const w of windows) { ... }` の **下**（地面を描く行の **上**）に追加します。

```js:game.js
    // targets in windows (clipped), roof walkers free
    for (const f of targets) {
      if (f.win) {
        ctx.save();
        ctx.beginPath(); ctx.rect(f.win.x, f.win.y, f.win.w, f.win.h); ctx.clip();
        drawFigure(f);
        ctx.restore();
        ctx.fillStyle = 'rgba(40,30,20,.35)';
        ctx.fillRect(f.win.x, f.win.y + f.win.h / 2 - 0.5, f.win.w, 1);
      } else drawFigure(f);
    }
```

- `ctx.clip()` は、直前に作った形（ここでは窓の四角）の **内側にしか描けなくする** 命令です。人を窓の下から少しずつ持ち上げると、窓わくの外にはみ出した部分は描かれないので、「窓の下から顔を出す」ように見えます。
- `clip()` の効果はずっと続くので、`ctx.save()` で描画の設定を保存してから使い、描き終わったら `ctx.restore()` で元に戻します。`save` / `restore` は必ずペアで使います。
- 最後に、窓のまん中に細い横線（窓わく）を半透明で重ねています。人が窓の中にいる感じが出ます。
- `f.win` がない人（屋上の人）は、そのまま描きます。

## spawn() … 人を1人出す

`// ---------- game ----------` の **下**、`function update(dt)` の **上** に追加します。

```js:game.js
  function spawn() {
    const civ = Math.random() < Math.min(0.4, 0.2 + elapsed * 0.004);
    const kind = civ ? 'civ' : 'enemy';
    const lifeT = civ ? rand(2.5, 4.5) : Math.max(2.0, 5.2 - elapsed * 0.045) + rand(0, 0.8);
    if (Math.random() < 0.25 && bldg.length) {
      const b = bldg[Math.floor(Math.random() * bldg.length)];
      if (b.x < 4 || b.x + b.w > W - 4) return;
      targets.push({ kind, x: rand(b.x + 6, b.x + b.w - 6), y: b.top, minX: b.x + 5, maxX: b.x + b.w - 5, vx: rand(12, 26) * (Math.random() < 0.5 ? -1 : 1), life: lifeT, max: lifeT });
    } else {
      const free = windows.filter((w) => w.lit && !w.busy);
      if (!free.length) return;
      const w = free[Math.floor(Math.random() * free.length)];
      w.busy = true;
      targets.push({ kind, win: w, x: w.x + w.w / 2, y: w.y + w.h + 18, rise: 18, life: lifeT, max: lifeT, vx: 0 });
    }
  }

  function removeTarget(f) {
    if (f.win) f.win.busy = false;
    targets.splice(targets.indexOf(f), 1);
  }
```

- **市民が出る確率** は最初 20% で、時間とともに上がり、最大 40% になります。後半ほど「撃っていいか」の見きわめが大事になります。
- `life` は「あと何秒そこにいるか」です。敵は最初 5.2 秒ほどいて、時間がたつほど短くなります（最短 2 秒）。`Math.max(2.0, ...)` で下限をつけておくと、どれだけ長く遊んでも理不尽に短くなりません。
- 25% の確率で **屋上を歩く人** にします。ビルの屋上（`b.top`）に立たせ、`minX`〜`maxX` の範囲を `vx`（1秒に進む px。符号で向き）で行ったり来たりさせます。画面のはしにかかるビルはねらいにくいので出しません。
- 残りは **窓の人** です。明るくて、まだ誰もいない窓（`w.lit && !w.busy`）からランダムに1つ選び、`busy = true` にしてほかの人が重ならないようにします。足もとを窓の下ふちより 18px 下（`rise: 18`）から始めて、窓に隠れた状態でスタートします。
- `removeTarget()` は人を配列から消す関数です。窓の人なら、その窓を空き（`busy = false`）に戻します。

## update() で人を動かす

`update()` を、まるごと次のように **書きかえ** ます。

```js:game.js
  function update(dt) {
    t += dt;
    if (state !== 'play') return;
    elapsed += dt;
    spawnTimer -= dt;
    const maxActive = Math.min(7, 2 + Math.floor(elapsed / 12));
    if (spawnTimer <= 0 && targets.length < maxActive) {
      spawn();
      spawnTimer = Math.max(0.55, 1.8 - elapsed * 0.018) * rand(0.7, 1.3);
    }
    for (let i = targets.length - 1; i >= 0; i--) {
      const f = targets[i];
      f.life -= dt;
      if (f.win) {
        const goingOut = f.life < 0.25;
        f.rise = goingOut ? Math.min(18, f.rise + 80 * dt) : Math.max(0, f.rise - 80 * dt);
        f.y = f.win.y + f.win.h + f.rise;
      } else {
        f.x += f.vx * dt;
        if (f.x < f.minX || f.x > f.maxX) { f.vx *= -1; f.x = Math.max(f.minX, Math.min(f.maxX, f.x)); }
      }
      if (f.life <= 0) removeTarget(f);
    }
  }
```

- **出現タイマー** … `spawnTimer` が 0 以下になったら1人出し、次までの時間をセットし直します。間隔は最初 1.8 秒で、だんだん短く（最短 0.55 秒）。`rand(0.7, 1.3)` をかけてリズムを少しばらつかせています。
- **同時に出せる人数** `maxActive` は最初 2 人で、12 秒ごとに 1 人ずつ増え、最大 7 人です。
- **窓の人の出入り** … `rise` は「窓の下ふちからどれだけ下にいるか」です。出てきたら 1 秒に 80px の速さで 0 に近づき（顔を出す）、残り 0.25 秒になったら 18 に戻っていきます（引っこむ）。`Math.min` / `Math.max` で 0〜18 の範囲に収めています。
- **屋上の人の往復** … 範囲の外に出たら `vx` の符号を反転して、向きを変えます。
- `life` が 0 になったら消します。
- 配列を **後ろから** ループしているのは、ループ中に `splice` で要素を消しても、まだ見ていない要素の番号がずれないようにするためです。

`start()` の中、`state = 'play';` の **下** に1行足して、スタートのたびに時間とタイマーをリセットします。

```js:game.js
  function start() {
    resize();
    state = 'play';
    elapsed = 0; spawnTimer = 0.6;
    overlay.classList.add('hide');
  }
```

> [!CHECK] 動作チェック
> - スタートして少しすると、明るい窓から人が下からひょっこり顔を出し、しばらくすると引っこむ
> - ときどき屋上を左右に行ったり来たりする人も出る
> - 赤い服に帽子と銃の人（ターゲット）と、青い服の人（市民）の2種類がいる
> - しばらく遊ぶと、同時に出てくる人数がだんだん増えていく
