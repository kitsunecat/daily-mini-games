## このステップのゴール

指を離した瞬間に **撃てる** ようにします。弾が人に当たったかを調べ（当たり判定）、頭ならヘッドショット、連続ヒットならコンボでスコアを足します。当たった場所には火花のような粒（パーティクル）と得点の文字を出し、撃った瞬間は画面が白く光ります。弾は6発で、撃ち切るとリロードが入ります。

## 定数と変数

ファイルの先頭のほう、要素を取ってくる行と定数の行を次のように **書きかえ** ます（`const overlay = ...` の上に1行増え、`ZOOM` の行に定数が増えます）。

```js:game.js
  const elScore = $('score'), elAmmo = $('ammo');
  const overlay = $('overlay'), btnStart = $('start');

  const MAX_AMMO = 6, RELOAD_TIME = 1.2, ZOOM = 3;
```

`let targets = [];` から `let elapsed = ...` までの3行を、次の4行に **書きかえ** ます。

```js:game.js
  let targets = [], particles = [], popups = [];
  let state = 'title';
  let score = 0, combo = 0, ammo = MAX_AMMO, reload = 0;
  let elapsed = 0, spawnTimer = 0, muzzle = 0, t = 0;
```

- `particles` … 火花の粒、`popups` … 「+100」などの浮かび上がる文字
- `combo` … 連続で敵に当てた回数、`ammo` … 残りの弾、`reload` … リロードの残り秒数（0 ならリロード中ではない）
- `muzzle` … 撃った瞬間のフラッシュの残り時間

## hud() … 画面の数字を書きかえる

`// ---------- game ----------` の **下**、`function spawn()` の **上** に追加します。

```js:game.js
  function hud() {
    elScore.textContent = score;
    if (reload > 0) { elAmmo.textContent = 'リロード中…'; elAmmo.classList.add('reload'); }
    else { elAmmo.textContent = '●'.repeat(ammo) + '○'.repeat(MAX_AMMO - ammo); elAmmo.classList.remove('reload'); }
  }
```

HUD（ヘッドアップディスプレイ）は、ゲーム画面にかぶせて出す情報表示のことです。`'●'.repeat(ammo)` のように、文字を残り数だけくり返せば、弾の残りがひと目で分かる表示になります。

## burst() と fire() … 撃って当たりを調べる

`function removeTarget(f)` を **はさむように**、上に `burst()`、下に `fire()` を追加します。

```js:game.js
  function burst(x, y, c, n) {
    for (let i = 0; i < n; i++) particles.push({ x, y, vx: rand(-40, 40), vy: rand(-60, 10), life: rand(0.3, 0.6), max: 0.6, c });
  }

  function removeTarget(f) {
    if (f.win) f.win.busy = false;
    targets.splice(targets.indexOf(f), 1);
  }

  function fire() {
    if (state !== 'play' || reload > 0 || ammo <= 0) return;
    ammo--; muzzle = 0.12;
    const s = sway();
    let hit = null, head = false;
    for (let i = targets.length - 1; i >= 0; i--) {
      const f = targets[i];
      if (f.win && (s.x < f.win.x || s.x > f.win.x + f.win.w || s.y < f.win.y || s.y > f.win.y + f.win.h)) continue;
      const dx = s.x - f.x;
      if (Math.hypot(dx, s.y - (f.y - 14)) <= 3.8) { hit = f; head = true; break; }
      if (Math.abs(dx) <= 3.8 && s.y >= f.y - 11.5 && s.y <= f.y) { hit = f; break; }
    }
    if (hit) {
      burst(s.x, s.y, hit.kind === 'enemy' ? '#ff4d5a' : '#7cc8ff', 10);
      removeTarget(hit);
      if (hit.kind === 'enemy') {
        combo++;
        const pts = (head ? 200 : 100) + (combo - 1) * 20;
        score += pts;
        popups.push({ x: s.x, y: s.y - 20, text: (head ? 'HEAD +' : '+') + pts, c: head ? '#ffe27a' : '#fff', life: 1 });
      } else {
        combo = 0; // 市民に当てたときのペナルティはステップ6で
      }
    } else {
      combo = 0;
      burst(s.x, s.y, '#ccc', 5);
    }
    if (ammo <= 0) reload = RELOAD_TIME;
    hud();
  }
```

### 当たり判定

弾が飛んでいく様子は描かず、**撃った瞬間にねらっていた1点** に当たったかどうかだけを調べます（ヒットスキャン方式）。調べる点は、十字線の位置ではなく **手ぶれ込みの `sway()` の位置** です。スコープの中心に映っているのはこの点なので、見えているとおりに当たります。

人ごとに、次の順で調べます。

1. **窓の人なら、まず窓の中か** … 窓の人は窓わくで切り抜いて描いているので、見えていない部分（窓の下に隠れた体）には当たらないようにします。点が窓の四角の外なら、この人は飛ばします（`continue`）。
2. **頭（円）** … 頭の中心 `(f.x, f.y - 14)` と点との距離を `Math.hypot(dx, dy)`（√(dx² + dy²)）で求め、3.8 以下なら頭に命中。見た目の半径 3 より少しだけ大きくして、ほんの少し甘くしています。
3. **体（四角）** … 点の x が体の幅の中、y が体の上下の中なら命中。

ステップ3でメモした「体の四角と頭の円」が、そのまま当たり判定の形になっているのが分かります。見た目と判定を一致させると、プレイヤーは「ちゃんと当たった/外れた」と納得できます。

後ろ（あとから出た人＝手前に描かれた人）から調べ、当たったら `break` で抜けます。1発で当たるのは1人だけです。

### スコアとコンボ

敵に当たると `combo` が増え、点数は `基本点（頭 200 / 体 100）+ (combo - 1) × 20` です。外したり市民に当てたりするとコンボは 0 に戻ります。得点の文字を `popups` に入れて、当たった場所の少し上に出します。

### 弾とリロード

撃つたびに `ammo` を減らし、0 になったら `reload` に `RELOAD_TIME`（1.2 秒）を入れます。リロード中は `fire()` の最初の `if` で撃てません。

## update() に動きを足す

`update()` の先頭部分を次のように **書きかえ** ます。`t += dt;` の下にフラッシュと粒と文字の更新、`elapsed += dt;` の下にリロードの処理が入ります。`spawnTimer -= dt;` 以降はそのままです。

```js:game.js
  function update(dt) {
    t += dt;
    if (muzzle > 0) muzzle -= dt;
    for (let i = particles.length - 1; i >= 0; i--) {
      const p = particles[i]; p.life -= dt; p.x += p.vx * dt; p.y += p.vy * dt; p.vy += 120 * dt;
      if (p.life <= 0) particles.splice(i, 1);
    }
    for (let i = popups.length - 1; i >= 0; i--) { popups[i].life -= dt; popups[i].y -= 20 * dt; if (popups[i].life <= 0) popups.splice(i, 1); }
    if (state !== 'play') return;
    elapsed += dt;
    if (reload > 0) { reload -= dt; if (reload <= 0) { reload = 0; ammo = MAX_AMMO; hud(); } }
    spawnTimer -= dt;
```

- 粒は速度 `vx`, `vy` で動き、毎秒 `vy` を 120 ずつ増やして（重力）、下に落ちていきます。
- 粒と文字の更新は `if (state !== 'play') return;` より **上** に置いています。ゲームオーバーになった瞬間の火花も、最後まで動いて消えるようにするためです。
- リロードが終わったら弾を満タンに戻して、HUD を更新します。

## 描く

`drawWorld()` の最後（ネオンの線を描く行の **下**）に、粒を描く処理を足します。

```js:game.js
    ctx.fillRect(0, H - 18, W, 1.5);
    for (const p of particles) {
      ctx.globalAlpha = Math.max(0, p.life / p.max);
      ctx.fillStyle = p.c; ctx.fillRect(p.x - 1, p.y - 1, 2, 2);
    }
    ctx.globalAlpha = 1;
  }
```

粒を `drawWorld()` の中で描いておくと、スコープの中でも拡大されて見えます。

`draw()` の中、`drawWorld();` の **下**（`if (state === 'play' && aiming) {` の **上**）に、得点の文字を描く処理を足します。

```js:game.js
    drawWorld();
    for (const p of popups) {
      ctx.globalAlpha = Math.min(1, p.life * 2);
      ctx.fillStyle = p.c; ctx.font = 'bold 14px system-ui, sans-serif'; ctx.textAlign = 'center';
      ctx.fillText(p.text, p.x, p.y);
    }
    ctx.globalAlpha = 1;
```

スコープの中の十字線の色を、リロード中は灰色になるように1行 **書きかえ** ます。

```js:game.js
      ctx.strokeStyle = reload > 0 ? 'rgba(150,170,200,.8)' : 'rgba(255,60,80,.9)'; ctx.lineWidth = 1.2;
```

`draw()` の最後、スコープの中心の点を描く行の **下** に、リロードの輪とフラッシュを足します。

```js:game.js
      ctx.beginPath(); ctx.arc(aimX, aimY, 1.5, 0, Math.PI * 2); ctx.fillStyle = ctx.strokeStyle; ctx.fill();
      if (reload > 0) {
        ctx.strokeStyle = '#ffd76a'; ctx.lineWidth = 3;
        ctx.beginPath(); ctx.arc(aimX, aimY, R - 8, -Math.PI / 2, -Math.PI / 2 + Math.PI * 2 * (1 - reload / RELOAD_TIME)); ctx.stroke();
      }
    }
    if (muzzle > 0) { ctx.fillStyle = `rgba(255,240,200,${muzzle * 2})`; ctx.fillRect(0, 0, W, H); }
  }
```

- リロードの輪は、`ctx.arc` の終了角を「進み具合 × 1周」にして、12時の位置（`-Math.PI / 2`）から時計回りに伸びていく円弧です。
- フラッシュは、画面全体を薄い白で塗るだけです。`muzzle` が 0.12 → 0 に減るので、一瞬だけ光ってすっと消えます。

## 撃つタイミングをつなぐ

`pointerup` の行を **書きかえ** て、離したときに `fire()` を呼びます。

```js:game.js
  cv.addEventListener('pointerup', (e) => { if (!aiming) return; setAim(pos(e)); aiming = false; fire(); });
```

`start()` で、スコアや弾もリセットします。

```js:game.js
  function start() {
    resize();
    state = 'play'; score = 0; combo = 0; ammo = MAX_AMMO; reload = 0;
    elapsed = 0; spawnTimer = 0.6; particles = []; popups = []; aiming = false;
    overlay.classList.add('hide');
    hud();
  }
```

ファイルの最後の `resize();` を `resize(); hud();` に **書きかえ** ます。

```js:game.js
  resize(); hud();
  requestAnimationFrame(loop);
```

> [!CHECK] 動作チェック
> - スコープで赤いターゲットをねらって離すと、画面が一瞬光り、ターゲットが火花とともに消えて SCORE が増える
> - 頭に当てると「HEAD +200」、体なら「+100」と出る。続けて当てると点数が 20 ずつ増える
> - 下の弾の表示が撃つたびに ● → ○ に減り、6発撃つと「リロード中…」になってスコープに黄色い輪が出る。輪が1周すると弾が戻る
> - 窓の下に隠れている体をねらっても当たらない
