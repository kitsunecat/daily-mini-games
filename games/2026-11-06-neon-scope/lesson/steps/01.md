## このステップのゴール

3つのファイルを用意して、画面の土台を作ります。上に「LIFE・SCORE・BEST」の表示、まん中にゲームを描く **Canvas**（キャンバス）、その上に重ねるタイトル画面（オーバーレイ）、下に残りの弾の表示を置き、Canvas に夜空のグラデーションと地面を描くところまで進めます。

完成すると、こんなゲームになります。

- 夜のビル街の窓や屋上に、銃を持った **赤いターゲット** と、ふつうの **青い市民** が現れる
- 画面を押しているあいだだけ、3倍ズームの **スコープ** が開く。ドラッグでねらいを動かし、指（マウス）を離した瞬間に発射
- 頭に当てると **ヘッドショット** で 200 点、体なら 100 点。連続で当てるとコンボボーナス
- 市民を撃ったり、ターゲットを放っておいて撃ち返されたりするとライフが減る。ライフ 3 つがなくなったらゲームオーバー
- 弾は 6 発。撃ち切るとリロードが入る

- `<canvas id="cv">` が、ゲームを描く画用紙です。大きさはあとで JavaScript から画面に合わせて決めます。

- `<script>` は `</body>` の直前に置きます。HTML の要素が全部できたあとで JavaScript が動くので、`getElementById` で確実に要素を取れます。

## game.js

最後に JavaScript です。全体を `(() => { ... })();` で囲んでいます。これは **即時実行関数** といって、中で作った変数がページ全体に漏れ出さないようにする書き方です。

```js:game.js
(() => {
  'use strict';
  const cv = document.getElementById('cv');
  const ctx = cv.getContext('2d');
  const $ = (id) => document.getElementById(id);
  const overlay = $('overlay'), btnStart = $('start');

  let W = 0, H = 0, dpr = 1;
  let state = 'title';
  let t = 0;

  function resize() {
    const r = cv.getBoundingClientRect();
    dpr = Math.min(window.devicePixelRatio || 1, 2);
    W = Math.max(200, Math.round(r.width)); H = Math.max(200, Math.round(r.height));
    cv.width = W * dpr; cv.height = H * dpr;
  }

  // ---------- drawing ----------
  function drawWorld() {
    const g = ctx.createLinearGradient(0, 0, 0, H);
    g.addColorStop(0, '#060a1c'); g.addColorStop(0.6, '#1a1f48'); g.addColorStop(1, '#3a2a5c');
    ctx.fillStyle = g; ctx.fillRect(-W, -H, W * 3, H * 3);
    ctx.fillStyle = '#0a0c18'; ctx.fillRect(-W, H - 18, W * 3, H);
    ctx.fillStyle = '#ff6fd8';
    ctx.fillRect(0, H - 18, W, 1.5);
  }

  function draw() {
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
    drawWorld();
  }

  // ---------- game ----------
  function update(dt) {
    t += dt;
  }

  function start() {
    resize();
    state = 'play';
    overlay.classList.add('hide');
  }

  // ---------- input ----------
  btnStart.addEventListener('click', start);
  window.addEventListener('resize', () => { if (state !== 'play') resize(); });

  // ---------- loop ----------
  let last = performance.now();
  function loop(now) {
    const dt = Math.min(0.05, (now - last) / 1000); last = now;
    update(dt); draw();
    requestAnimationFrame(loop);
  }
  resize();
  requestAnimationFrame(loop);
})();
```

### Canvas の大きさと devicePixelRatio

`resize()` では、CSS で決まった Canvas の見た目の大きさ（`getBoundingClientRect()`）を読み取り、それを `W`, `H` として覚えます。

スマホの画面は、CSS の 1px を実際には 2〜3 個の点（物理ピクセル）で表示しています。この倍率が `devicePixelRatio`（`dpr`）です。`cv.width = W * dpr` のように **内部の解像度だけ dpr 倍** にしておき、描くときに `ctx.setTransform(dpr, 0, 0, dpr, 0, 0)` で全体を dpr 倍に拡大すると、座標は `W` × `H` のまま考えられて、表示はくっきりします。重くなりすぎないよう、dpr は最大 2 にしています。

### 描く関数を分ける

`drawWorld()` は「街そのもの」を描く関数、`draw()` は毎フレーム呼ばれる「画面全体」を描く関数です。わざわざ分けているのは、ステップ4で **スコープの中に街をもう一度、拡大して描く** ためです。いまは空のグラデーションと、地面とネオンの線だけです。

空を `ctx.fillRect(-W, -H, W * 3, H * 3)` と画面より大きく塗っているのも、スコープで拡大・移動したときにすき間ができないようにするためです。

### ゲームループ

`requestAnimationFrame(loop)` は「次に画面を描きかえるタイミングで `loop` を呼んで」とブラウザにお願いする関数です。`loop` の最後でまた自分を予約するので、1秒に約60回（画面によっては120回）くり返し呼ばれ続けます。これを **ゲームループ** と呼びます。

`loop` に渡される `now` はミリ秒単位の時刻です。前回との差を秒にしたものが `dt`（delta time）で、動きはすべて「1秒あたり〇〇」×`dt` で計算します。こうすると画面の速さに関係なく、同じ速さで動きます。タブを切り替えて戻ったときに `dt` が大きくなりすぎないよう、`Math.min(0.05, ...)` で上限をつけています。

`t` はゲーム開始からの経過時間で、星のまたたきや手ぶれなど「時間でゆれるもの」に使います。

> [!NOTE]
> `state` はゲームの状態を表す文字列です。`'title'`（タイトル画面）、`'play'`（プレイ中）、`'over'`（ゲームオーバー）の3つを使います。画面サイズが変わったときに `resize()` するのはプレイ中以外だけにしています。プレイ中に街が作り直されると、ねらっていたターゲットが消えてしまうからです。

> - スタートを押すとタイトル画面が消え、紺〜紫の夜空のグラデーションと、下にピンクのネオンの線が見える
