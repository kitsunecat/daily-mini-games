## このステップのゴール

PC で **キーボードだけ** でも遊べるようにします。矢印キーでスコープを開いてねらいを動かし、Space で撃ちます。キーボードでは押しっぱなしでねらう操作ができないので、「一度開いたスコープが開いたままになる」モードを作ります。タイトル画面やゲームオーバー画面では、Space か Enter でスタートできるようにもします。

## 変数

ねらいの変数の行を次のように **書きかえ** て、その下に `keys` を追加します。

```js:game.js
  let aiming = false, aimX = 0, aimY = 0, touchOffset = 0, keyAim = false;
  const keys = {};
```

- `keyAim` … キーボードでスコープを開いているか。`aiming`（押している間だけ true）とちがい、一度 true になるとマウスやタッチで操作するまで開いたままです。
- `keys` … いま押されているキーを覚えておくオブジェクトです。`keys.ArrowLeft` が `true` なら左キーが押されています。

## キー入力を受け取る

`cv.addEventListener('contextmenu', ...)` の **下** に追加します。

```js:game.js
  window.addEventListener('keydown', (e) => {
    if (e.key.startsWith('Arrow')) {
      keys[e.key] = true;
      if (state === 'play') keyAim = true;
      e.preventDefault();
    } else if (e.key === ' ' || e.key === 'Enter') {
      e.preventDefault();
      if (state !== 'play') { if (!overlay.classList.contains('hide')) start(); }
      else if (e.key === ' ') { if (!keyAim) keyAim = true; else fire(); }
    }
  });
  window.addEventListener('keyup', (e) => { keys[e.key] = false; });
```

- キーの名前は `e.key` で分かります。矢印キーは `'ArrowLeft'` などで、どれも `'Arrow'` で始まるので `startsWith` でまとめて判定しています。
- `keydown` で `true`、`keyup` で `false` にしておけば、`update()` の中で「いま押されているか」をいつでも調べられます。キーを押しっぱなしにしたときの `keydown` のくり返し（キーリピート）に頼らずにすみ、なめらかに動かせます。
- `e.preventDefault()` で、矢印キーや Space でページがスクロールするのを止めます。
- **Space の役割** … プレイ中でスコープが閉じていれば開き、開いていれば撃ちます。プレイ中でなければ、オーバーレイが出ているときだけ `start()` します（ゲームオーバー直後の 0.5 秒間に押しても始まらないように、`hide` を確認しています）。

## 矢印キーでねらいを動かす

`update()` の中、リロードの行の **下**（`spawnTimer -= dt;` の **上**）に追加します。

```js:game.js
    if (keyAim) {
      const sp = 200 * dt;
      if (keys.ArrowLeft) aimX -= sp; if (keys.ArrowRight) aimX += sp;
      if (keys.ArrowUp) aimY -= sp; if (keys.ArrowDown) aimY += sp;
      aimX = Math.max(0, Math.min(W, aimX)); aimY = Math.max(0, Math.min(H, aimY));
    }
```

1秒に 200px の速さでねらいを動かし、画面の外に出ないように 0〜W、0〜H の範囲に収めます。

## スコープを出す条件と、手ぶれ

`sway()` を次のように **書きかえ** ます。

```js:game.js
  function sway() {
    const k = keyAim ? 0.6 : 1;
    return {
      x: aimX + (Math.sin(t * 1.3) * 2.2 + Math.sin(t * 3.1) * 0.8) * k,
      y: aimY + (Math.cos(t * 1.7) * 1.8 + Math.sin(t * 2.3) * 0.7) * k,
    };
  }
```

キーボードは細かい調整がしにくいので、手ぶれを 60% に弱めています。操作方法によって遊びやすさが変わらないように、こうした「下駄」をはかせるのはよくある工夫です。

`draw()` の中のスコープを描く条件を **書きかえ** ます。

```js:game.js
    if (state === 'play' && (aiming || keyAim)) {
```

## 切りかえとリセット

マウスやタッチで押したら、キーボードのモードは終わりにします。`pointerdown` の中の `aiming = true;` を **書きかえ** ます。

```js:game.js
    aiming = true; keyAim = false;
```

`start()` と `gameOver()` でも `keyAim` を戻します。

```js:game.js
    elapsed = 0; spawnTimer = 0.6; particles = []; popups = []; aiming = false; keyAim = false;
```

```js:game.js
    state = 'over'; aiming = false; keyAim = false;
```

> [!CHECK] 動作チェック
> - タイトル画面で Enter か Space を押すとゲームが始まる
> - プレイ中に矢印キーを押すとスコープが開き、押している方向にねらいが動く。キーを離してもスコープは開いたまま
> - スコープが開いた状態で Space を押すと撃てる
> - マウスでクリックすると、いつもの「押している間だけ」のスコープに戻る
> - ゲームオーバー画面で Enter を押すと、もう一度遊べる
