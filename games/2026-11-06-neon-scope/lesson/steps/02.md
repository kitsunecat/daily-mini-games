## このステップのゴール

舞台になる **夜のビル街** を作ります。またたく星、月、奥のシルエットのビル、手前の窓つきビルを、毎回ランダムに組み立てて描きます。手前のビルの窓は、あとでターゲットが顔を出す「出現場所」になります。

## 街のデータを入れる変数

`let W = 0, H = 0, dpr = 1;` の **下** に1行追加します。

```js:game.js
  let stars = [], backBldg = [], bldg = [], windows = [];
```

- `stars` … 星（位置・大きさ・またたきのずれ）
- `backBldg` … 奥にある暗いシルエットのビル
- `bldg` … 手前のビル（色つき）
- `windows` … 手前のビルについている窓すべて

## buildCity() … 街をランダムに組み立てる

`let t = 0;` の **下**、`function resize()` の **上** に追加します。

```js:game.js
  // ---------- city ----------
  const rand = (a, b) => a + Math.random() * (b - a);
  function buildCity() {
    stars = [];
    for (let i = 0; i < 70; i++) stars.push({ x: Math.random() * W, y: Math.random() * H * 0.5, r: Math.random() * 1.2 + 0.3, p: Math.random() * 6 });
    backBldg = [];
    for (let x = -10; x < W + 10;) {
      const w = rand(30, 70), h = rand(H * 0.35, H * 0.7);
      backBldg.push({ x, w, top: H - h });
      x += w + rand(0, 6);
    }
    bldg = []; windows = [];
    const ground = H - 18;
    for (let x = rand(-20, 0); x < W + 10;) {
      const w = Math.round(rand(56, 96));
      const h = Math.round(rand(H * 0.28, H * 0.7));
      const b = { x: Math.round(x), w, top: ground - h, hue: rand(215, 245) };
      bldg.push(b);
      const cols = Math.floor((w - 8) / 18), rows = Math.floor((h - 26) / 28);
      const ox = b.x + (w - cols * 18) / 2 + 3;
      for (let r = 0; r < rows; r++) for (let c = 0; c < cols; c++) {
        const win = { x: ox + c * 18, y: b.top + 14 + r * 28, w: 12, h: 20, lit: Math.random() < 0.55, busy: false };
        if (win.x > 2 && win.x + win.w < W - 2 && win.y > 30) windows.push(win);
        b.wins = (b.wins || 0) + 1;
      }
      x += w + rand(4, 12);
    }
  }
```

- `rand(a, b)` は「a 以上 b 未満のランダムな数」を返す小さなお助け関数です。このあと何度も使います。
- 星は画面の上半分（`H * 0.5` まで）にばらまきます。`p` は「またたきのタイミングのずれ」で、全部の星が同時に光らないようにするためのものです。
- ビルは **左から右へ、幅を足しながら並べていく** 作り方です。`for (let x = ...; x < W + 10;)` のように3つ目の式を空にして、ループの中で `x += w + すき間` と進めています。幅がランダムでも、すき間なく画面の端まで埋まります。
- 手前のビルは高さを `H` に対する割合で決めています。画面が縦長でも横長でも、それらしいバランスになります。
- 窓は 18px おきに横に、28px おきに縦に並べます。`ox` は、窓の列がビルのまん中に来るように左端をずらした位置です。
- `lit` は「明かりがついているか」。約 55% の窓を明るくします。ターゲットは明るい窓にだけ現れます（ステップ3）。`busy` は「いま誰かがいる窓か」を表すフラグです。
- 画面のはしっこや上すぎる窓は、ねらいにくいので `windows` に入れません。

`resize()` の最後に `buildCity();` を足して、画面の大きさが決まるたびに街を作り直します。

```js:game.js
  function resize() {
    const r = cv.getBoundingClientRect();
    dpr = Math.min(window.devicePixelRatio || 1, 2);
    W = Math.max(200, Math.round(r.width)); H = Math.max(200, Math.round(r.height));
    cv.width = W * dpr; cv.height = H * dpr;
    buildCity();
  }
```

## drawWorld() で街を描く

`drawWorld()` を、まるごと次のように **書きかえ** ます。空と地面のあいだに、星・月・ビル・窓を描く処理が入りました。

```js:game.js
  function drawWorld() {
    const g = ctx.createLinearGradient(0, 0, 0, H);
    g.addColorStop(0, '#060a1c'); g.addColorStop(0.6, '#1a1f48'); g.addColorStop(1, '#3a2a5c');
    ctx.fillStyle = g; ctx.fillRect(-W, -H, W * 3, H * 3);
    for (const s of stars) {
      ctx.globalAlpha = 0.5 + 0.5 * Math.sin(t * 2 + s.p);
      ctx.fillStyle = '#fff'; ctx.fillRect(s.x, s.y, s.r, s.r);
    }
    ctx.globalAlpha = 1;
    ctx.fillStyle = '#fff4d0';
    ctx.beginPath(); ctx.arc(W * 0.8, H * 0.12, 18, 0, Math.PI * 2); ctx.fill();
    ctx.fillStyle = '#1e1b40';
    for (const b of backBldg) ctx.fillRect(b.x, b.top, b.w, H);
    for (const b of bldg) {
      ctx.fillStyle = `hsl(${b.hue},30%,13%)`;
      ctx.fillRect(b.x, b.top, b.w, H);
      ctx.fillStyle = `hsl(${b.hue},30%,20%)`;
      ctx.fillRect(b.x, b.top, b.w, 3);
    }
    for (const w of windows) {
      ctx.fillStyle = w.lit ? '#f7d58a' : '#18213d';
      ctx.fillRect(w.x, w.y, w.w, w.h);
    }
    ctx.fillStyle = '#0a0c18'; ctx.fillRect(-W, H - 18, W * 3, H);
    ctx.fillStyle = '#ff6fd8';
    ctx.fillRect(0, H - 18, W, 1.5);
  }
```

- Canvas は **後から描いたものが上に重なります**。だから「空 → 星 → 月 → 奥のビル → 手前のビル → 窓 → 地面」と、遠いものから順に描いています（画家のアルゴリズムと呼ばれる考え方です）。
- `ctx.globalAlpha` は、これから描くものの不透明度（0〜1）です。`Math.sin(t * 2 + s.p)` は時間とともに -1〜1 をなめらかに往復するので、`0.5 + 0.5 * sin(...)` で 0〜1 の明るさになり、星がゆっくりまたたきます。使い終わったら `1` に戻すのを忘れないようにしましょう。
- `ctx.arc(x, y, 半径, 開始角, 終了角)` で円を描きます。角度はラジアンで、`Math.PI * 2` が1周（360°）です。
- 手前のビルの色は `hsl(色相, 彩度, 明度)` で指定しています。色相 215〜245 は青〜紫のあたりで、ビルごとに少しずつ色が変わります。上のふちだけ明度を上げて、屋上のラインにしています。

> - ページを再読み込みすると、ビルの並びや明るい窓の場所が毎回変わる
