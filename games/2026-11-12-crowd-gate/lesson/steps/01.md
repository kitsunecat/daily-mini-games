## このステップのゴール

3つのファイルを用意して、ゲーム画面の土台を作ります。上に「人数・SCORE・BEST」の表示、まん中にゲームを描く **Canvas**（キャンバス）とその上に重ねるタイトル画面（オーバーレイ）、下にひとことヒントを置き、Canvas に **草地と砂の道路** を描くところまで進めます。

完成すると、こんなゲームになります。

- 青い仲間の群れが、まっすぐな道を **自動で前へ進み続ける**。プレイヤーはドラッグ（PC は ←→ / A D キー）で群れを **左右に動かす** だけ
- 道には2つ並んだ **数字ゲート** が次々に来る。青い **＋・×** は仲間がふえ、赤い **－・÷** はへる。どちらをくぐるかを選ぶのがこのゲームの肝
- 途中には **赤い敵の軍団** と、左右に動く **ノコギリ**。ぶつかると仲間がへる
- ステージの最後には道をふさぐ **砦**。砦の数字より人数が多ければ突破して次のステージへ
- 仲間が 0 人になったらゲームオーバー。倒した敵の数＋進んだ距離＋砦ボーナスがスコアで、ベストはブラウザに保存される

- `<meta name="viewport" ...>` はスマホで画面幅に合わせて表示し、ピンチで拡大されないようにする設定です

- `<script>` を `</body>` の直前に置くと、HTML の要素がすべて読みこまれてから JavaScript が動きます

## game.js

最初の `game.js` です。

```js:game.js
(() => {
  'use strict';
  const W = 360, H = 600;
  const ROAD_L = 30, ROAD_R = 330, MID = (ROAD_L + ROAD_R) / 2;
  const CROWD_Y = 470;

  const cv = document.getElementById('cv');
  const ctx = cv.getContext('2d');
  const stageEl = document.getElementById('stage');
  const overlay = document.getElementById('overlay');
  const ovTitle = document.getElementById('ov-title');
  const ovText = document.getElementById('ov-text');
  const startBtn = document.getElementById('start');
  const countEl = document.getElementById('count');
  const scoreEl = document.getElementById('score');
  const bestEl = document.getElementById('best');

  // ---------- canvas sizing ----------
  let scale = 1;
  function resize() {
    const r = stageEl.getBoundingClientRect();
    const availW = Math.max(100, r.width - 16), availH = Math.max(100, r.height - 8);
    const s = Math.min(availW / W, availH / H);
    const dpr = window.devicePixelRatio || 1;
    cv.style.width = Math.floor(W * s) + 'px';
    cv.style.height = Math.floor(H * s) + 'px';
    cv.width = Math.floor(W * s * dpr);
    cv.height = Math.floor(H * s * dpr);
    scale = s;
    ctx.setTransform(s * dpr, 0, 0, s * dpr, 0, 0);
  }
  window.addEventListener('resize', () => { resize(); draw(); });

  // ---------- state ----------
  let dist;

  function reset() {
    dist = 0;
  }

  // ---------- draw ----------
  function draw() {
    ctx.save();
    // ground
    ctx.fillStyle = '#5a9a4f'; ctx.fillRect(-10, -10, W + 20, H + 20);
    ctx.fillStyle = '#d9c7a3'; ctx.fillRect(ROAD_L, -10, ROAD_R - ROAD_L, H + 20);
    ctx.fillStyle = '#c4af86'; ctx.fillRect(ROAD_L - 6, -10, 6, H + 20); ctx.fillRect(ROAD_R, -10, 6, H + 20);
    // stripes
    ctx.fillStyle = 'rgba(255,255,255,.35)';
    const off = (dist || 0) % 60;
    for (let y = -60 + off; y < H; y += 60) ctx.fillRect(MID - 2, y, 4, 28);

    ctx.restore();
  }

  // ---------- flow ----------
  function start() {
    reset();
    overlay.classList.add('hidden');
  }

  // ---------- input ----------
  startBtn.addEventListener('click', start);
  overlay.addEventListener('pointerdown', e => { if (e.target === overlay) start(); });

  reset();
  resize();
  draw();
})();
```

### 全体を `(() => { ... })();` で包む

ファイル全体を **即時実行関数** で包んでいます。中で作った変数がページ全体（グローバル）に漏れないので、名前のぶつかりを気にせずに書けます。`'use strict';` は、うっかりミス（宣言していない変数への代入など）をエラーとして教えてくれるモードです。

### 360×600 の「ゲームの座標」で考える

このゲームでは、画面の大きさに関係なく、ゲームの世界を **幅 `W` = 360、高さ `H` = 600** の座標で考えます。

- `ROAD_L`・`ROAD_R` は道路の左端と右端の x、`MID` はそのまん中（180）です。あとで「群れが `MID` より左にいれば左のゲート」と判定するのに使います
- `CROWD_Y` は仲間の群れがいる高さです。群れは画面の下のほう（y = 470）に **ずっといて**、まわりの物が上から流れてくることで「前に進んでいる」ように見せます。次のステップ以降で使います

### resize() で画面に合わせて拡大する

`resize()` は `#stage` の大きさを調べ（`getBoundingClientRect()`）、360×600 の絵が **縦横比を保ったまま** ちょうど収まる倍率 `s` を計算します。幅で決まる倍率と高さで決まる倍率の小さいほう（`Math.min`）を使うのがポイントです。

- `cv.style.width` / `cv.style.height` は、Canvas の **見た目の大きさ**（CSS のピクセル）です
- `cv.width` / `cv.height` は、Canvas の **中身の画素数** です。ここを `devicePixelRatio`（高解像度の画面で 1 ピクセルに何倍の画素があるか）倍にしておくと、スマホでも絵がぼやけません
- `ctx.setTransform(s * dpr, 0, 0, s * dpr, 0, 0)` で「1 と書いたら `s * dpr` 画素ぶん」に拡大しておきます。こうすると、描くときは **いつも 360×600 の座標で書けばよく**、画面の大きさを気にしなくて済みます
- `scale` は、あとでマウスやタッチの位置をゲームの座標に直すときに使うので、変数に取っておきます

### draw() で道路を描く

`draw()` は、毎回いちばん奥の物から順に塗り重ねていきます。

- まず画面全体を草の緑で塗り、そのうえに `ROAD_L` から `ROAD_R` まで砂色の道路、両はしに少し濃いふちを描きます。`-10` や `+ 20` は、あとで画面をゆらしたときに端にすき間が見えないよう、少し大きめに塗るためです
- 道のまん中には、60 ずつ間をあけて白い線を描きます。`off`（ずらし量）は「進んだ距離 `dist` を 60 で割った余り」です。今は `dist` が 0 なので止まっていますが、次のステップで `dist` を増やすと線が流れはじめます
- 最初と最後の `ctx.save()` / `ctx.restore()` は、Canvas の設定（位置のずらしや透明度など）を「保存して、あとで元にもどす」ペアです。今は何もしていませんが、画面のゆれを入れるときに役立ちます

スタートボタンの `click` と、オーバーレイの何もないところを押したとき（`pointerdown` で `e.target === overlay`）に `start()` が呼ばれ、オーバーレイに `hidden` クラスをつけて隠します。`countEl` など、まだ使っていない要素も先に取り出しておきます。
