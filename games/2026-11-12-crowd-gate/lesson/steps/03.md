## このステップのゴール

主人公の **仲間の群れ** を登場させ、ドラッグや ←→ / A D キーで **左右になめらかに動かせる** ようにします。人数に合わせて群れの大きさが変わるように、人をきれいに並べる描き方も作ります。

## 群れの変数

`let dist, speed, t;` の行を、次のように **書きかえ** ます。

```js:game.js
  let n, px, targetX, dist, speed, t;
```

- `n` … 仲間の人数。このゲームでいちばん大事な数です
- `px` … 群れのまん中の x（今いる位置）
- `targetX` … 群れが **向かっている** x。操作で動かすのはこちらで、`px` はそれを追いかけます

## 人数から群れの半径を求める

`let n, px, ...` の行の **下**（`function reset()` の上）に追加します。

```js:game.js
  function crowdRadius(count) { return Math.min(62, 6 + 5.2 * Math.sqrt(Math.min(count, 140))); }
```

群れを円とみなしたときの **半径** です。人が平らに並ぶとき、円の面積は人数に比例するので、半径は人数の **平方根**（`Math.sqrt`）に比例します。140 人より多いときは描くのを 140 人までにするので、半径も最大 62 で止めます。この半径は、道からはみ出さないようにするときや、あとで当たり判定にも使います。

## reset() を書きかえる

```js:game.js
  function reset() {
    n = 1; px = MID; targetX = MID; dist = 0; speed = 150; t = 0;
  }
```

最初は1人だけで、道のまん中（`MID`）からスタートします。

## update() で左右に動かす

`update()` の中、`dist += speed * dt;` の **下** に5行、`if` のブロックを閉じた **あと** に1行追加します。`update()` 全体はこうなります。

```js:game.js
  function update(dt) {
    t += dt;
    if (state === 'play') {
      speed = Math.min(300, 150 + dist / 60);
      dist += speed * dt;
      const keyV = (keys.left ? -1 : 0) + (keys.right ? 1 : 0);
      if (keyV) targetX += keyV * 280 * dt;
      const r = crowdRadius(n);
      targetX = Math.max(ROAD_L + r, Math.min(ROAD_R - r, targetX));
      px += (targetX - px) * Math.min(1, dt * 14);
    }
    countEl.textContent = n;
  }
```

- `keyV` は、左キーを押していれば `-1`、右なら `1`、両方か何も押していなければ `0` になります。押しているあいだ、1秒に 280 ずつ `targetX` を動かします
- `Math.max(最小, Math.min(最大, 値))` は、値を **範囲の中に収める**（クランプする）お決まりの書き方です。群れの半径 `r` のぶんだけ内側に収めるので、群れが大きくなっても道からはみ出しません
- `px += (targetX - px) * 割合` は、目標との差を毎フレーム少しずつ縮める書き方です。遠いときは速く、近づくとゆっくりになるので、ふわっと止まる自然な動きになります。`dt * 14` を掛けているので、フレームレートが変わっても動きの速さは同じです
- 最後に、ヘッダーの「人数」の表示を `n` に書きかえます

## 人をたくさん並べて描く drawPeople()

`// ---------- draw ----------` の **すぐ下** に、2つの関数を追加します。

```js:game.js
  function drawPeople(cx, cy, count, body, head) {
    const shown = Math.min(count, 140);
    const bob = Math.sin(t * 14);
    for (let i = shown - 1; i >= 0; i--) {
      const a = i * 2.39996, rr = 5.2 * Math.sqrt(i);
      const x = cx + Math.cos(a) * rr, y = cy + Math.sin(a) * rr * 0.8 + (i % 2 ? bob : -bob) * 1.2;
      ctx.fillStyle = body;
      ctx.beginPath(); ctx.ellipse(x, y + 2, 3.6, 4.4, 0, 0, Math.PI * 2); ctx.fill();
      ctx.fillStyle = head;
      ctx.beginPath(); ctx.arc(x, y - 4, 2.8, 0, Math.PI * 2); ctx.fill();
    }
  }

  function label(text, x, y, size, color) {
    ctx.font = 'bold ' + size + 'px system-ui, sans-serif';
    ctx.textAlign = 'center'; ctx.textBaseline = 'middle';
    ctx.lineWidth = 4; ctx.strokeStyle = 'rgba(0,0,0,.55)';
    ctx.strokeText(text, x, y);
    ctx.fillStyle = color; ctx.fillText(text, x, y);
  }
```

### 黄金角で並べる

`drawPeople()` は、点 `(cx, cy)` のまわりに `count` 人を描きます。i 番目の人を置く場所は、

- 角度 `a = i × 2.39996`（ラジアン）… これは **黄金角**（約 137.5 度）です
- 中心からの距離 `rr = 5.2 × √i`

という決まりで計算します。ひまわりの種の並び方と同じで、人数が何人でも **すき間なく、かたよりなく** 円形にまとまります。距離を `√i` にしているので、外側ほど1周に多くの人が並び、密度がそろいます。`Math.cos(a) * rr`・`Math.sin(a) * rr` は、角度と距離から x・y を求める定番の計算です。y だけ `0.8` 倍して、少しななめ上から見ているように楕円につぶしています。

- 1人は「体の楕円（`ctx.ellipse`）」と「頭の円（`ctx.arc`）」の2つで描きます。`Math.PI * 2` は 360 度（1周）です
- 外側（番号の大きい人）から描くので、まん中の人がいちばん手前に来ます
- `bob = Math.sin(t * 14)` は -1〜1 をくり返す値です。偶数番と奇数番で逆向きに上下させると、みんなで **足ぶみ** しているように見えます

### 読みやすい文字 label()

`label()` は、黒いふち（`strokeText`）を描いてから中を塗る（`fillText`）ことで、どんな背景の上でも読みやすい文字を描く関数です。`textAlign = 'center'` と `textBaseline = 'middle'` で、指定した点が文字のまん中になります。

## draw() で群れを描く

`draw()` の中、白い線を描く `for` 文の **下**（`ctx.restore();` の上）に追加します。

```js:game.js
    // player crowd
    {
      const r = crowdRadius(n || 1);
      ctx.fillStyle = 'rgba(0,0,0,.15)';
      ctx.beginPath(); ctx.ellipse(px || MID, CROWD_Y + 6, r + 4, (r + 4) * 0.7, 0, 0, Math.PI * 2); ctx.fill();
      if (n > 0) drawPeople(px || MID, CROWD_Y, n, '#3a6dff', '#ffe0b8');
      label(String(n), px || MID, CROWD_Y + r + 18, 20, '#fff');
    }
```

足もとにうすい黒の楕円で **影** を描き、その上に青い仲間たち、さらに下に人数の数字を出します。`{ ... }` だけのブロックで囲むと、中の `const r` はこのブロックの中だけの変数になり、ほかの `r` とぶつかりません。

## 入力を受けつける

`// ---------- input ----------` の **すぐ下**（`startBtn.addEventListener` の上）に追加します。

```js:game.js
  const keys = { left: false, right: false };
  let dragging = false, lastPX = 0;
  function toLocalX(clientX) { return clientX / scale; }
  cv.addEventListener('pointerdown', e => {
    dragging = true; lastPX = toLocalX(e.clientX);
    try { cv.setPointerCapture(e.pointerId); } catch (err) { /* ignore */ }
    e.preventDefault();
  });
  cv.addEventListener('pointermove', e => {
    if (!dragging || state !== 'play') return;
    const x = toLocalX(e.clientX);
    targetX += (x - lastPX) * 1.3;
    lastPX = x;
    e.preventDefault();
  });
  const endDrag = () => { dragging = false; };
  cv.addEventListener('pointerup', endDrag);
  cv.addEventListener('pointercancel', endDrag);

  window.addEventListener('keydown', e => {
    const k = e.key;
    if (k === 'ArrowLeft' || k === 'a' || k === 'A') { keys.left = true; e.preventDefault(); }
    else if (k === 'ArrowRight' || k === 'd' || k === 'D') { keys.right = true; e.preventDefault(); }
    else if ((k === 'Enter' || k === ' ') && state !== 'play' && !overlay.classList.contains('hidden')) { e.preventDefault(); start(); }
  });
  window.addEventListener('keyup', e => {
    const k = e.key;
    if (k === 'ArrowLeft' || k === 'a' || k === 'A') keys.left = false;
    else if (k === 'ArrowRight' || k === 'd' || k === 'D') keys.right = false;
  });
```

### Pointer Events でドラッグ

**Pointer Events**（`pointerdown`・`pointermove`・`pointerup`）は、マウスでもタッチでもペンでも同じように使えるイベントです。

- 押したとき（`pointerdown`）に `dragging = true` にして、その位置を `lastPX` に覚えます
- 動かしたとき（`pointermove`）は、**前回からの移動量** `x - lastPX` を `targetX` に足します。指を置いた場所に瞬間移動するのではなく「指を動かしたぶんだけ動く」ので、どこを触っても操作できます。`1.3` 倍して少し大きめに動かしています
- `clientX` は画面のピクセルなので、`scale` で割ってゲームの座標に直します（`toLocalX`）
- `setPointerCapture()` を呼ぶと、指が Canvas の外に出てもイベントを受け取り続けられます
- `e.preventDefault()` は、ブラウザがもともと持っている動き（スクロールや文字選択など）を止める命令です

### キーボード

キーを **押したとき** に `keys.left` などを `true` に、**離したとき** に `false` にしておき、`update()` の中で「今押されているか」を見ます。押しっぱなしのあいだ、なめらかに動き続けられます。タイトル画面やゲームオーバー画面で Enter か Space を押すとスタートもできます。

> [!NOTE]
> `keys` は `update()` より下で宣言していますが、`update()` が最初に呼ばれるのはファイルの最後の `requestAnimationFrame(loop)` のあとなので、そのときにはもう `keys` ができています。

> [!TIP]
> 人数1人では群れらしさが分かりにくいので、試しに `reset()` の `n = 1` を `n = 50` にしてみましょう。黄金角できれいにまとまった群れが見られます。確認したら `1` にもどしておきます。

> [!CHECK] 動作チェック
> - スタートすると、道の下のほうに青い仲間が1人いて、その下に「1」と出る。上の「人数」も 1
> - ←→ キーや A D キーを押しているあいだ、群れがなめらかに左右へ動き、道の端で止まる
> - 画面をドラッグすると、指（マウス）を動かしたぶんだけ群れが動く
> - 仲間が小さく足ぶみしている
