## このステップのゴール

ゲームを動かす心臓部の **ゲームループ** を作ります。毎フレーム「状態を少し進めて（`update`）、描き直す（`draw`）」をくり返し、道のまん中の白い線が上から下へ流れて、**前へ進んでいる** ように見えるところまで進めます。進むほどスピードが上がるしくみも入れます。

## ゲームの状態を表す変数

`// ---------- state ----------` の下の `let dist;` を、次のように **書きかえ** ます。

```js:game.js
  let state = 'title';
  let dist, speed, t;
```

- `state` はゲームの状態です。`'title'`（タイトル画面）・`'play'`（プレイ中）・`'over'`（ゲームオーバー）のどれかの文字を入れます。「今どの場面か」を1つの変数で管理すると、あとで「プレイ中だけ動かす」といった分岐が書きやすくなります
- `dist` は **スタートから進んだ距離**（ゲームの座標の単位）です
- `speed` は1秒あたりに進む距離、`t` はゲームが始まってからの経過時間（秒）です。`t` はあとで群れを「ぴょこぴょこ」ゆらすのに使います

## reset() で初期値を入れる

`reset()` の中身を **書きかえ** ます。

```js:game.js
  function reset() {
    dist = 0; speed = 150; t = 0;
  }
```

## update() で状態を進める

`reset()` 関数の **下**（`// ---------- draw ----------` の上）に追加します。

```js:game.js
  // ---------- update ----------
  function update(dt) {
    t += dt;
    if (state === 'play') {
      speed = Math.min(300, 150 + dist / 60);
      dist += speed * dt;
    }
  }
```

- `dt`（delta time）は **前のフレームから何秒たったか** です。1秒に 60 回呼ばれる画面なら約 0.016、120 回なら約 0.008 になります
- `dist += speed * dt` のように「速さ × 経過時間」で動かすと、画面のなめらかさ（1秒に何回描くか）がちがうパソコンやスマホでも、**1秒で進む距離は同じ** になります
- スピードは `150 + dist / 60` で、進むほど少しずつ上がります。`Math.min(300, ...)` で 300 より速くはならないようにしています

## ゲームループ

`draw()` 関数の **下**（`// ---------- flow ----------` の上）に追加します。

```js:game.js
  // ---------- loop ----------
  let last = 0;
  function loop(ts) {
    const dt = Math.min(0.05, (ts - (last || ts)) / 1000);
    last = ts;
    update(dt);
    draw();
    requestAnimationFrame(loop);
  }
```

**`requestAnimationFrame(関数)`** は「次に画面を描きかえるタイミングで、この関数を呼んで」とブラウザに頼む命令です。`loop` の最後でもう一度自分を頼むので、画面が描きかわるたびに `loop` が呼ばれ続けます。

- 呼ばれるとき、引数 `ts` に **ページを開いてからのミリ秒** が渡されます。前回の `last` との差を 1000 で割ると、経過秒数 `dt` になります
- 最初の1回は `last` が 0 なので、`last || ts` で `ts` 自身を使い、`dt` を 0 にします
- `Math.min(0.05, ...)` で、`dt` が 0.05 秒より大きくならないようにします。別のタブを見ていてループが止まり、もどってきたときに「何秒ぶんも一気に進んで、障害物をすり抜ける」のを防ぐためです

## スタートでプレイ中にする

`start()` に `state = 'play';` の1行を追加します。

```js:game.js
  function start() {
    reset();
    state = 'play';
    overlay.classList.add('hidden');
  }
```

## ループを始める

ファイルのいちばん下にある `draw();` の行を、次のように **書きかえ** ます。

```js:game.js
  reset();
  resize();
  requestAnimationFrame(loop);
})();
```

ループの中で毎フレーム `draw()` が呼ばれるので、最初の1回を自分で呼ぶ必要はなくなりました。

> [!NOTE]
> `update()` は `state === 'play'` のときだけ `dist` を増やします。タイトル画面のあいだもループは回っていますが、道は止まったままです。こうしておくと、タイトル画面やゲームオーバー画面の後ろにも、ゲームの絵をそのまま表示しておけます。

> [!CHECK] 動作チェック
> - タイトル画面のあいだは、後ろの道路の白い線が止まっている
> - スタートを押すと、白い線が上から下へ流れはじめ、前へ進んでいるように見える
> - しばらく待つと、線の流れる速さが少しずつ上がっていく
> - Console にエラーが出ていない
