## このステップのゴール

最後の仕上げです。**スコア** を計算して上に表示し、いちばん良かったスコアを **ハイスコア** としてブラウザに保存します。ゲームオーバー画面には、スコア・突破した砦の数・倒した敵の数・到達ステージを出します。これで完成品と同じゲームになります。

## ハイスコアを読みこむ

いちばん上の `const CROWD_Y = 470;` の **下** に1行追加します。

```js:game.js
  const BEST_KEY = 'crowd-gate-best';
```

次に、`const bestEl = document.getElementById('best');` の **下**（`// ---------- canvas sizing ----------` の上）に追加します。

```js:game.js
  let best = 0;
  try { best = parseInt(localStorage.getItem(BEST_KEY), 10) || 0; } catch (e) { best = 0; }
  bestEl.textContent = best;
```

**localStorage** は、ブラウザの中に小さなデータを保存しておける場所です。ページを閉じたり再読み込みしたりしても消えません。

- `localStorage.getItem(キー)` で、そのキーに保存した文字を取り出します。まだ何も保存していなければ `null` が返ります
- 保存されるのは **文字** なので、`parseInt(..., 10)` で10進数の整数に直します。`null` や変な文字なら `NaN`（数ではない）になるので、`|| 0` で 0 にします
- キーの名前はほかのゲームとぶつからないよう、`'crowd-gate-best'` のようにゲームの名前を入れておきます
- プライベートブラウズなど、`localStorage` が使えない環境ではエラーになることがあるので、`try { ... } catch` で囲みます

## スコアの変数

`let n, px, ...` の行と、`reset()` の2行目を **書きかえ** ます。これで完成品と同じになります。

```js:game.js
  let n, px, targetX, dist, speed, objs, nextAt, plan, stage, kills, forts, score, particles, banner, shake, t;
```

```js:game.js
  function reset() {
    n = 1; px = MID; targetX = MID; dist = 0; speed = 150; objs = []; nextAt = 260;
    plan = []; stage = 1; kills = 0; forts = 0; score = 0; particles = []; banner = null; shake = 0; t = 0;
  }
```

## スコアを計算して表示する

`update()` の中、`objs = objs.filter(...)` の行の **下**（`if (state === 'play')` のブロックを閉じる `}` の上）に追加します。

```js:game.js
      score = kills + Math.floor(dist / 40) + forts * 50 * (forts + 1) / 2;
```

さらに、`update()` の最後の `countEl.textContent = n;` の **下** に追加します。

```js:game.js
    scoreEl.textContent = score;
```

スコアは3つの合計です。

- `kills` … 倒した敵の人数
- `Math.floor(dist / 40)` … 進んだ距離。40 進むごとに1点
- `forts * 50 * (forts + 1) / 2` … 砦ボーナス。1つ目の砦で +50、2つ目で +100、3つ目で +150…と、**突破するたびに大きくなる** ボーナスの合計です。50 + 100 + … + 50×forts は、1 から forts までの和 `forts × (forts + 1) / 2` の 50 倍になります。「砦を突破！ +50」「+100」のバナーの数字は、このボーナスと同じです

## ゲームオーバーで結果を出して保存する

`gameOver()` 全体を、次のように **書きかえ** ます。

```js:game.js
  function gameOver() {
    if (state !== 'play') return;
    state = 'over';
    n = 0;
    score = kills + Math.floor(dist / 40) + forts * 50 * (forts + 1) / 2;
    let isBest = false;
    if (score > best) {
      best = score; isBest = true;
      try { localStorage.setItem(BEST_KEY, String(best)); } catch (e) { /* ignore */ }
      bestEl.textContent = best;
    }
    beep(150, 0.4, 'triangle', 0.1);
    setTimeout(() => {
      ovTitle.textContent = 'ゲームオーバー';
      ovText.innerHTML = 'スコア <b class="hl">' + score + '</b>' + (isBest ? '（ハイスコア！）' : '') +
        '<br>突破した砦: ' + forts + ' ／ 倒した敵: ' + kills + '<br>到達ステージ: ' + stage;
      startBtn.textContent = 'もう一度';
      overlay.classList.remove('hidden');
    }, 700);
  }
```

- ゲームオーバーは `update()` の途中（敵にぶつかった瞬間など）で呼ばれ、そのフレームのスコア計算より前に `return` することがあります。そこで、ここでもう一度スコアを計算しておきます。砦で負けたときに足した `kills` も、ちゃんとスコアに入ります
- 今回のスコアが `best` より大きければ更新し、`localStorage.setItem(キー, 文字)` で保存して、上の BEST の表示も書きかえます
- `isBest ? '（ハイスコア！）' : ''` は **三項演算子** です。「条件 ? 真のとき : 偽のとき」で、ハイスコアのときだけ文字を足します
- `innerHTML` を使うと、`<b>` や `<br>` のタグも HTML として表示されます。ここで入れる値は、すべてゲームの中で作った数字なので安全です

> [!CHECK] 動作チェック
> - プレイ中、上の SCORE が進むにつれて少しずつ増え、敵を倒したり砦を突破したりすると大きく増える
> - ゲームオーバー画面に「スコア 〇〇」「突破した砦」「倒した敵」「到達ステージ」が出る
> - 初めてのゲームオーバーでは「（ハイスコア！）」と出て、上の BEST が今回のスコアになる
> - ページを再読み込みしても、BEST の数字が残っている
> - 前より低いスコアでは「（ハイスコア！）」が出ず、BEST も変わらない
> - 「もう一度」か Enter / Space で、人数 1・STAGE 1 からやり直せる

## 完成！ 改造してみよう

これで完成品の「ふえふえ行進」と同じものができました。ふり返ると、このゲームは「進んだ距離 `dist` と物の位置 `d` の差で画面の y を決める」「物の種類を plan の配列で並べて、少し先まで置いていく」「くぐった・ぶつかった瞬間に `used` をつけて1回だけ判定する」の組み合わせでできています。最後に、自分だけのゲームに育てる改造アイデアを紹介します。

> [!TIP]
> **新しいゲートの種類** … `goodOp()` に `{ op: '^', v: 2 }`（2乗）や、`badOp()` に「人数を半分の位置で止める」ような計算を足してみましょう。`update()` のゲートの計算と、`opText()`・`opGood()` に1行ずつ足せば動きます。

> [!TIP]
> **コインを拾う** … `spawn()` に `'coin'` の種類を足し、群れがその近くを通ったらスコアに +10 するようにしてみましょう。当たり判定は敵と同じ「縦と横を別々に比べる」やり方がそのまま使えます。`makePlan()` でゲートのあとに `'coin'` を入れれば登場します。

> [!TIP]
> **ボス戦** … 3ステージごとに、砦のかわりに左右に動く大きな敵（`'boss'`）を置いてみましょう。砦と同じく「人数が多ければ突破」にして、ボスを倒したらバナーで大きくお祝いすると盛り上がります。

> [!TIP]
> **難易度の調整** … `speed` の上限 `300`、ゲートの ＋ の数 `randi(4, 10)`、敵の強さ `rand(0.2, 0.55)`、砦の強さ `rand(0.45, 0.7)` を変えると、遊びごたえががらりと変わります。仲間の色や形を変えたいときは `drawPeople()` を書きかえましょう。
