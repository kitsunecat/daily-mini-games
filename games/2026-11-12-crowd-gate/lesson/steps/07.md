## このステップのゴール

ステージの最後に、道をふさぐ **砦** を置きます。砦の数字より仲間が多ければ、その人数を使って突破して **次のステージ** へ。足りなければゲームオーバーです。突破したときの「砦を突破！」の **バナー** と、左上の **STAGE** 表示も作ります。

## 変数をふやす

`let n, px, ...` の行と、`reset()` の2行目を **書きかえ** ます。

```js:game.js
  let n, px, targetX, dist, speed, objs, nextAt, plan, stage, kills, forts, particles, banner, shake, t;
```

```js:game.js
  function reset() {
    n = 1; px = MID; targetX = MID; dist = 0; speed = 150; objs = []; nextAt = 260;
    plan = []; stage = 1; kills = 0; forts = 0; particles = []; banner = null; shake = 0; t = 0;
  }
```

- `forts` … 突破した砦の数
- `banner` … 画面のまん中に大きく出す文字の情報。出していないときは `null` です

## 計画の最後に砦を置く

`makePlan()` の `for` 文の **あと**（`return p;` の上）に2行追加します。`makePlan()` 全体はこうなります。

```js:game.js
  function makePlan() {
    const p = [];
    const len = 5 + Math.min(stage, 4);
    for (let i = 0; i < len; i++) {
      p.push('gate');
      if (i > 0) p.push(Math.random() < 0.55 ? 'enemy' : 'saw');
    }
    p.push('gate');
    p.push('fort');
    return p;
  }
```

砦の直前にもう1つゲートを置いて、「最後のゲートで仲間をふやせるかどうか」が勝負どころになるようにしています。計画を使い切ると `ensureSpawns()` が次の計画を作るので、**砦を越えると次のステージの計画が始まる** ことになります。

## 砦を置く

`spawn()` の中、`if (kind === 'saw') { ... }` のブロックの **下** に追加します。

```js:game.js
    if (kind === 'fort') {
      const m = Math.max(8, Math.round(n * rand(0.45, 0.7) + stage * 10));
      objs.push({ kind, d, m, used: false });
      return 260;
    }
```

砦の強さ `m` は、**砦を置いた時点の人数** の 45〜70% にステージ×10 を足した数です。ここまでうまく仲間をふやせていれば突破でき、途中で減らしすぎると負けてしまう、ちょうどいい強さになります。砦のあとは間隔を 260 と広めにとって、ひと息つけるようにします。

> [!NOTE]
> 砦は画面の上の外側で作られるので、そこから砦に着くまでのあいだにも人数は変わります。最後のゲートで ×2 を引けば楽に突破でき、－ を引けば負けることもあります。

## バナーを出す関数

`burst()` 関数の **下**（`function loseMembers` の上）に追加します。

```js:game.js
  function showBanner(text, color) { banner = { text, color, life: 1.2 }; }
```

1.2 秒のあいだ表示する文字を `banner` に入れます。

## update() に砦の処理を足す

`update()` の `for` 文の中、ゲートの分岐の最後の `}` に `else if` をつなげます。

```js:game.js
            if (n <= 0) { n = 0; gameOver(); return; }
          }
        } else if (o.kind === 'fort') {
          if (!o.used && y >= CROWD_Y - 18) {
            o.used = true;
            burst(px, CROWD_Y - 30, '#ff4d5e', 30);
            if (n > o.m) {
              n -= o.m; kills += o.m; forts++;
              stage++;
              showBanner('砦を突破！ +' + (50 * forts), '#ffe066');
              beep(523, 0.12); setTimeout(() => beep(659, 0.12), 100); setTimeout(() => beep(784, 0.2), 200);
            } else {
              kills += n;
              n = 0;
              gameOver();
              return;
            }
          }
        }
      }
```

- 砦は少し手前（`CROWD_Y - 18`）で判定します。砦の絵は y より上に描くので、群れが砦の下の壁にふれたあたりで判定されるようにするためです
- 人数が砦の数より **多ければ**（同じではだめ）、砦の人数ぶん仲間がへって突破です。突破した数 `forts` と `stage` を1つ増やし、「ド・ミ・ソ」（523・659・784Hz）の3つの音を `setTimeout` でずらして鳴らします
- 足りなければ、残りの仲間ぶんだけ敵を倒してゲームオーバーです

`stage` が増えると、次の計画からゲートの数字・敵の人数・ノコギリの速さ・計画の長さが少しずつ大きくなります。それぞれの関数の中で `stage` を使っていたのは、このためです。

## バナーの寿命を減らす

`update()` の中、パーティクルの `filter` の行の **下** に追加します。

```js:game.js
    if (banner) { banner.life -= dt; if (banner.life <= 0) banner = null; }
```

## 砦・STAGE・バナーを描く

`draw()` の中、ノコギリを描く分岐の **あと** に `else if` をつなげます。

```js:game.js
        ctx.restore();
      } else if (o.kind === 'fort') {
        ctx.fillStyle = o.used ? '#8c6a55' : '#a0522d';
        ctx.fillRect(ROAD_L - 6, y - 60, ROAD_R - ROAD_L + 12, 44);
        ctx.fillStyle = o.used ? '#7a5a47' : '#7d3c1f';
        for (let x = ROAD_L - 6; x < ROAD_R + 6; x += 30) ctx.fillRect(x, y - 74, 18, 16);
        if (!o.used) {
          label('砦 ' + o.m, MID, y - 38, 26, '#ffe066');
        } else {
          label('突破', MID, y - 38, 22, '#fff');
        }
      }
    }
```

（最初の `ctx.restore();` は、ノコギリの分岐の最後の行です。）道の幅いっぱいの茶色い壁と、その上に 30 おきに並べた四角で、お城の壁のギザギザ（胸壁）を描きます。突破したあとは色をうすくして「突破」と出します。

さらに、パーティクルを描いたあとの `ctx.globalAlpha = 1;` の **下**（最後の `ctx.restore();` の上）に追加します。

```js:game.js
    if (state === 'play') {
      ctx.fillStyle = 'rgba(0,0,0,.35)';
      ctx.fillRect(8, 8, 90, 24);
      label('STAGE ' + stage, 53, 20, 14, '#fff');
    }
    if (banner) {
      ctx.globalAlpha = Math.min(1, banner.life * 2);
      label(banner.text, W / 2, 200, 28, banner.color);
      ctx.globalAlpha = 1;
    }
```

- プレイ中は、左上にうすい黒の帯と「STAGE 1」のような文字を出します
- バナーは画面の上のほう（y = 200）に大きく出します。`banner.life * 2` を不透明度にすると、残り 0.5 秒になったところから、すうっと消えていきます

> [!CHECK] 動作チェック
> - プレイ中、左上に「STAGE 1」と出ている
> - ゲートと障害物をいくつか越えると、道をふさぐ茶色い **砦** と「砦 〇〇」の数字が流れてくる
> - 砦より仲間が多いと、砦の数だけ仲間がへって「砦を突破！ +50」と出て、3つの音が鳴り、「STAGE 2」になる
> - 次のステージでは、ゲートの数字や敵の人数が少し大きくなっている
> - 砦より仲間が少ないとゲームオーバーになる
