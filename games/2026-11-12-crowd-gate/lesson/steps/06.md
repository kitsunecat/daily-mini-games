## このステップのゴール

道を横切るレールの上を、**回転しながら左右に動くノコギリ** を出します。ノコギリにかかった部分の仲間が切られてへるので、群れが大きいほどよけにくくなります。ここでは **区間どうしの重なり** を使った当たり判定と、Canvas の **回転**（`rotate`）を学びます。

## 計画にノコギリを混ぜる

`makePlan()` の中の `if (i > 0) p.push('enemy');` の行を、次のように **書きかえ** ます。

```js:game.js
      if (i > 0) p.push(Math.random() < 0.55 ? 'enemy' : 'saw');
```

ゲートとゲートのあいだの障害物が、55% の確率で敵、45% の確率でノコギリになります。

## ノコギリを置く

`spawn()` の中、`if (kind === 'enemy') { ... }` のブロックの **下** に追加します。

```js:game.js
    if (kind === 'saw') {
      const w = rand(70, 120);
      objs.push({ kind, d, w, x: rand(ROAD_L + w / 2, ROAD_R - w / 2), vx: (Math.random() < 0.5 ? -1 : 1) * rand(40, 70 + stage * 10), used: false, rot: 0 });
      return 150;
    }
```

- `w` はノコギリの **幅**（70〜120）です。幅が広いほど刃が多くなります
- `x` はノコギリのまん中の位置、`vx` は横に動く速さです。`(Math.random() < 0.5 ? -1 : 1)` で、左右どちら向きに動き出すかをランダムにします。ステージが上がるほど速くなります
- `rot` は刃の回転角度です

### 端ではね返る

`o.x` を `vx` で動かし、道の端をこえたら **端の位置にもどしてから** 向きを反対にします。もどさずに向きだけ変えると、1フレームで端の外に出すぎたとき、次のフレームでもまだ外にいて、また向きが変わって…と、端でぶるぶる震えてしまうことがあるからです。`o.rot += dt * 12` で、1秒に 12 ラジアン（約2回転）ずつ刃を回します。

### 区間の重なりで「何割かかったか」を求める

ノコギリはゲートと同じく、群れの高さに来た瞬間（`y >= CROWD_Y`）に1回だけ判定します。このとき、横方向だけを見ると

- 群れは `px - r` から `px + r` までの **区間**
- ノコギリは `o.x - o.w / 2` から `o.x + o.w / 2` までの **区間**

です。2つの区間の **重なっている部分** は、「左端の大きいほう `a`」から「右端の小さいほう `b`」までになります。`b - a` がプラスなら重なっていて、マイナスなら重なっていません。

`frac = 重なりの長さ / 群れの幅` は、**群れの何割がノコギリにかかったか** を表します。かかった割合の 6 割ぶんの仲間がへり（最低1人）、端をかすっただけなら少しだけ、まん中で受けたら大きくへります。`Math.ceil` は小数を切り上げる関数です。

### translate と rotate で「その場で回す」

Canvas の `ctx.rotate(角度)` は、**原点 (0, 0) を中心に** これから描くものを回します。そのままだと画面の左上を中心に回ってしまうので、

1. `ctx.translate(o.x, y)` で原点をノコギリのまん中に動かす
2. さらに `ctx.translate(sx, 0)` で原点を1枚の刃のまん中に動かす
3. `ctx.rotate(...)` で回してから、原点を中心に刃を描く

という順番にします。`ctx.save()` と `ctx.restore()` で囲んでおけば、刃を1枚描き終わるたびに位置と回転が元にもどります。となりの刃は逆向き（`i % 2 ? -1 : 1`）に回して、歯車がかみ合っているように見せています。

### ギザギザの刃

刃は、中心から **16 個の点** を順に線でつないだ多角形です。`ang` は 22.5 度（`Math.PI / 8`）ずつ進み、点の距離 `rr` を 15 と 9 で交互にすると、出っぱりとへこみが交互に並んだ星形になります。最後に `closePath()` で形を閉じて塗り、まん中に灰色の軸を描きます。

その前に描いている灰色の細長い四角はレール、うすい赤の四角は「ここに当たると危ない」範囲の目じるしです。

> [!CHECK] 動作チェック
> - ゲートのあいだに、敵のかわりに **灰色のレールと回転するノコギリ** が出てくることがある
> - ノコギリはレールの上を左右に動き、道の端ではね返る。となりあう刃は逆向きに回っている
> - ノコギリを完全によけると人数は変わらない
> - 群れのはしがノコギリにかかると少しだけ、まん中で受けると大きく仲間がへり、青い粒が飛びちる
