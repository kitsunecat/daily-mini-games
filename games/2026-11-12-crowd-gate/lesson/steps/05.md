## このステップのゴール

赤い **敵の軍団** を道に出します。敵は数字の人数だけいて、ぶつかると同じ人数だけ仲間がへります（相打ち）。ぶつかった瞬間に赤と青の粒が飛びちる **パーティクル** も作ります。あわせて、ゲートと敵を決まった順番で並べる **plan（計画）** のしくみを入れます。

## 変数をふやす

`let n, px, ...` の行と、`reset()` の2行目を **書きかえ** ます。

```js:game.js
  let n, px, targetX, dist, speed, objs, nextAt, plan, stage, kills, particles, shake, t;
```

```js:game.js
  function reset() {
    n = 1; px = MID; targetX = MID; dist = 0; speed = 150; objs = []; nextAt = 260;
    plan = []; stage = 1; kills = 0; particles = []; shake = 0; t = 0;
  }
```

- `plan` … これから置く物の種類を順番に入れた配列（例: `['gate', 'gate', 'enemy', ...]`）
- `kills` … 倒した敵の人数。あとでスコアに使います
- `particles` … 飛びちる粒の配列

## ステージの計画を作る makePlan()

`badOp()` 関数の **下**（`function spawn` の上）に追加します。

```js:game.js
  function makePlan() {
    const p = [];
    const len = 5 + Math.min(stage, 4);
    for (let i = 0; i < len; i++) {
      p.push('gate');
      if (i > 0) p.push('enemy');
    }
    return p;
  }
```

「ゲート → ゲート → 敵 → ゲート → 敵 → …」という並びを作ります。最初の1つ（`i === 0`）だけ敵を入れないので、まずゲートを2回くぐって仲間をふやしてから敵に出会えます。ステージが上がると `len` が大きくなり（最大 9）、1ステージが長くなります。

物の種類を **配列で先に決めておき、前から1つずつ取り出して置く** やり方にすると、「ゲートと障害物を交互に」「最後にボスを置く」といったステージの組み立てが、配列を作るだけで書けます。

## 敵を置く

`spawn()` の中、`if (kind === 'gate') { ... }` のブロックの **下**（最後の `return 150;` の上）に追加します。

```js:game.js
    if (kind === 'enemy') {
      const m = Math.max(3, Math.round(n * rand(0.2, 0.55)) + randi(0, stage * 3));
      const r = crowdRadius(m);
      objs.push({ kind, d, m, r, x: rand(ROAD_L + r, ROAD_R - r), vx: Math.random() < 0.5 ? 0 : rand(-30, 30), used: false });
      return 170;
    }
```

- `m` は敵の人数です。**今の仲間の人数の 2〜5 割ほど** にステージに応じた数を足し、最低 3 人にします。仲間が多いほど敵も強くなるので、ずっとちょうどいい手ごたえになります
- `r` は敵の群れの半径です。仲間と同じ `crowdRadius()` を使います
- `x` は道からはみ出さない範囲のランダムな位置、`vx` は横に動く速さです。半分は止まっていて、半分はゆっくり左右に動きます

## ensureSpawns() を plan から取り出すように

`ensureSpawns()` を **書きかえ** ます。

```js:game.js
  function ensureSpawns() {
    while (nextAt < dist + H) {
      if (plan.length === 0) plan = makePlan();
      const kind = plan.shift();
      nextAt += spawn(kind, nextAt);
    }
  }
```

`plan.shift()` は配列の **先頭を取り出して** 返します（配列からはなくなります）。計画を使い切ったら新しい計画を作るので、物はとぎれずに出続けます。

## パーティクルと仲間がへる処理

`ensureSpawns()` 関数の **下**（`// ---------- update ----------` の上）に追加します。

```js:game.js
  // ---------- effects ----------
  function burst(x, y, color, k) {
    for (let i = 0; i < k; i++) {
      const a = Math.random() * Math.PI * 2, s = rand(40, 180);
      particles.push({ x, y, vx: Math.cos(a) * s, vy: Math.sin(a) * s, life: rand(0.35, 0.7), color });
    }
  }

  function loseMembers(k, color) {
    k = Math.min(n, Math.max(0, Math.round(k)));
    if (k <= 0) return;
    n -= k;
    burst(px, CROWD_Y, color || '#4d7cff', Math.min(30, k + 4));
    shake = 0.2;
    if (n <= 0) gameOver();
  }
```

- **パーティクル** は、小さな粒をたくさん出して爆発や火花に見せる演出です。`burst()` は点 (x, y) から `k` 個の粒を、ランダムな向き `a` とランダムな速さ `s` で飛ばします。`Math.cos(a) * s`・`Math.sin(a) * s` で、向きと速さを x・y の速度に分けています
- それぞれの粒は `life`（残り寿命・秒）を持ち、0 になったら消します
- `loseMembers(k)` は仲間を `k` 人へらす関数です。今の人数より多くはへらせないように `Math.min(n, ...)` で収め、青い粒を飛ばして画面をゆらします。0 人になったらゲームオーバーです。このあと出てくるノコギリでも同じ関数を使います

## update() に敵の処理を足す

`update()` の `for (const o of objs) {` の中を、次のように **書きかえ** ます。`if (o.kind === 'gate') {` の前に敵の分岐を入れ、ゲートのほうは `} else if (o.kind === 'gate') {` に変えます（ゲートの中身はステップ4のままです）。

```js:game.js
      for (const o of objs) {
        const y = CROWD_Y - (o.d - dist);
        if (o.kind === 'enemy') {
          o.x += o.vx * dt;
          if (o.x < ROAD_L + o.r || o.x > ROAD_R - o.r) o.vx *= -1;
          if (!o.used && Math.abs(y - CROWD_Y) < o.r + r * 0.6 && Math.abs(o.x - px) < o.r + r * 0.8) {
            o.used = true;
            const fight = Math.min(n, o.m);
            kills += fight;
            burst(o.x, y, '#ff4d5e', Math.min(30, o.m + 4));
            beep(180, 0.15, 'sawtooth', 0.07);
            loseMembers(o.m, '#4d7cff');
            if (state !== 'play') return;
          }
        } else if (o.kind === 'gate') {
          if (!o.used && y >= CROWD_Y) {
            o.used = true;
            const g = px < MID ? o.left : o.right;
            o.chosen = px < MID ? 'L' : 'R';
            const before = n;
            if (g.op === '+') n += g.v;
            else if (g.op === 'x') n *= g.v;
            else if (g.op === '-') n -= g.v;
            else if (g.op === '÷') n = Math.floor(n / g.v);
            n = Math.min(n, 99999);
            if (n > before) { beep(660, 0.1, 'square', 0.05); setTimeout(() => beep(880, 0.1, 'square', 0.05), 70); }
            else { beep(220, 0.18, 'triangle', 0.08); shake = 0.15; }
            if (n <= 0) { n = 0; gameOver(); return; }
          }
        }
      }
```

### 敵の当たり判定

敵の群れも仲間の群れも、だいたい **円** の形です。円どうしの当たり判定はふつう「中心の距離 < 半径の和」で書きますが、ここではもっと手軽に、**縦と横を別々に** 比べています。

- 縦: `Math.abs(y - CROWD_Y) < o.r + r * 0.6`
- 横: `Math.abs(o.x - px) < o.r + r * 0.8`

`Math.abs()` は絶対値（マイナスを取った値）で、「どれだけ離れているか」になります。両方とも近ければ当たりです。仲間の半径 `r` に `0.6`・`0.8` を掛けて少し小さめにしているのは、「ふちが少しかすっただけ」で当たりにならないよう、遊ぶ人にやさしくするためです。`r` はこの `for` 文の上で、群れの位置を決めるときに求めた値をそのまま使っています。

当たったら、`o.used = true` で同じ敵と2回ぶつからないようにし、**敵の人数 `o.m` だけ仲間がへります**。倒した数 `kills` には、実際に戦えた人数（仲間が少なければその人数）を足します。`loseMembers()` の中でゲームオーバーになったら、`return` でこのフレームの処理をやめます。

敵が動く処理は、`o.x += o.vx * dt` で横に動かし、道の端に来たら `o.vx *= -1` で向きを反対にするだけです。

## パーティクルを動かす

`update()` の中、`if (state === 'play') { ... }` のブロックの **あと**（`if (shake > 0) shake -= dt;` の上）に追加します。

```js:game.js
    for (const p of particles) { p.x += p.vx * dt; p.y += p.vy * dt; p.vx *= 0.94; p.vy *= 0.94; p.life -= dt; }
    particles = particles.filter(p => p.life > 0);
```

毎フレーム速度を `0.94` 倍してだんだん遅くすると、ぱっと広がってふわっと止まる動きになります。寿命の切れた粒は `filter` で取りのぞきます。プレイ中かどうかに関係なく動かすので、ゲームオーバーの瞬間の粒もちゃんと飛びちります。

## 敵とパーティクルを描く

`draw()` の物を描く `for` 文の中、ゲートを描くブロックの閉じかっこ `}` を、次のように **つなげて** 敵の分岐を足します。

```js:game.js
          if (!dim) label(opText(g), (a + b) / 2, y - 5, 26, '#fff');
        }
      } else if (o.kind === 'enemy' && !o.used) {
        ctx.fillStyle = 'rgba(0,0,0,.15)';
        ctx.beginPath(); ctx.ellipse(o.x, y + 6, o.r + 4, (o.r + 4) * 0.7, 0, 0, Math.PI * 2); ctx.fill();
        drawPeople(o.x, y, o.m, '#e0394c', '#ffb3ba');
        label(String(o.m), o.x, y - o.r - 14, 18, '#ffd0d5');
      }
    }
```

仲間と同じ `drawPeople()` を、色だけ赤にして使います。関数にしておいたおかげで、敵の群れも1行で描けます。ぶつかった敵（`used`）は描きません。

最後に、`// player crowd` のブロックの **下**（`ctx.restore();` の上）に追加します。

```js:game.js
    for (const p of particles) {
      ctx.globalAlpha = Math.max(0, p.life * 1.6);
      ctx.fillStyle = p.color; ctx.fillRect(p.x - 2.5, p.y - 2.5, 5, 5);
    }
    ctx.globalAlpha = 1;
```

粒は小さな四角です。寿命が短くなるほど `globalAlpha`（不透明度）を下げて、すっと消えていくようにします。最後に `globalAlpha = 1` にもどすのを忘れないようにしましょう。もどさないと、そのあと描くものまでうすくなってしまいます。

> [!CHECK] 動作チェック
> - ゲートを2回くぐったあと、頭上に数字のついた **赤い軍団** が流れてくる。半分くらいの軍団はゆっくり左右に動いている
> - 赤い軍団にぶつかると、赤と青の粒が飛びちり、画面がゆれて、軍団の人数だけ仲間がへる
> - 横によければ、軍団とぶつからずに通りすぎる
> - 仲間より大きい軍団にぶつかると 0 人になり、ゲームオーバーになる
