## このステップのゴール

色がちがう乗客の行き先、**待合ベンチ（5席）** を作ります。バスと色がちがう乗客をタップするとベンチの空いている席に座り、あとで **同じ色のバスが来ると自動で乗りこみ** ます。ベンチをうまく使って、奥の乗客を掘り出していくのがこのゲームの作戦の中心です。

## ベンチの配列

`let grid = [], queue = [], bus = null;` を **書きかえ** ます。

```js:game.js
  let grid = [], bench = [], queue = [], bus = null;
```

`bench` は長さ5の配列で、席ごとに `null`（空席）か `{ color, here }` が入ります。`here` は「その乗客がもう席に着いているか」で、ステップ6で乗客が歩くようになると、席を予約してから着くまでのあいだ `false` になります。今は一瞬で座るので、いつも `true` です。

`startStage()` の `grid = s.g; queue = s.buses.slice();` の行の **下** に、ベンチを空にする1行を足します。

```js:game.js
    bench = Array(BENCH).fill(null);
```

## 色ちがいの乗客をベンチへ

`tapCell()` の `const toBus = ...` から最後までを **書きかえ** ます。関数全体はこうなります。

```js:game.js
  function tapCell(r, c) {
    if (state !== 'play' || r < 0 || r >= rows || c < 0 || c >= COLS) return;
    const v = grid[r][c];
    if (v < 0) return;
    const reach = reachableMap(grid);
    if (!reach[r][c]) return;
    const toBus = bus && bus.state === 'wait' && bus.color === v && bus.filled < CAP;
    const slot = bench.indexOf(null);
    if (!toBus && slot < 0) return;
    grid[r][c] = EMPTY;
    if (toBus) {
      bus.filled++;
      boarded(bus);
    } else {
      bench[slot] = { color: v, here: true };
    }
  }
```

`bench.indexOf(null)` は、一番左の空席の番号を返します。空席がなければ `-1` です。「バスにも乗れず、ベンチも満席」なら何もしません。それ以外は、バスに乗れるならバスへ、乗れないならベンチの空席へ座らせます。

バスが到着する前（走ってくる途中）や発車したあとにタップした乗客も、`toBus` が false になるのでベンチへ行きます。タップのタイミングにも注意が必要になるわけです。

## バスが来たらベンチから自動で乗る autoBoard()

`boarded()` の **下** に追加します。

```js:game.js
  function autoBoard() {
    for (let i = 0; i < BENCH && bus.filled < CAP; i++) {
      const s = bench[i];
      if (s && s.here && s.color === bus.color) {
        bench[i] = null;
        bus.filled++;
        boarded(bus);
      }
    }
  }
```

ベンチを左から見ていき、バスと同じ色で席に着いている乗客がいれば、席を空けてバスに乗せます。`for` の条件に `bus.filled < CAP` を入れているので、満員になったらそこで止まります。

これを、バスが止まった瞬間に呼びます。`update()` の到着の行を **書きかえ** ます。

```js:game.js
        if (bus.x >= BUS_X) { bus.x = BUS_X; bus.state = 'wait'; autoBoard(); }
```

ベンチに同じ色の乗客が3人いれば、バスは止まった瞬間に満員になってすぐ発車します。

## ベンチの乗客と使用数を描く

`draw()` の `// sidewalk / bench` の `for` ループを **書きかえ**、ループのあとに「ベンチ 〇/5」の表示を足します。

```js:game.js
    for (let i = 0; i < BENCH; i++) {
      const p = seatPos(i);
      ctx.fillStyle = '#8a5a34'; rr(p.x - 28, p.y + 4, 56, 14, 5); ctx.fill();
      ctx.fillStyle = '#a8703f'; rr(p.x - 28, p.y + 2, 56, 8, 4); ctx.fill();
      if (!bench[i]) { ctx.strokeStyle = 'rgba(80,50,20,.35)'; ctx.lineWidth = 2; ctx.setLineDash([4, 4]); rr(p.x - 20, p.y - 24, 40, 40, 10); ctx.stroke(); ctx.setLineDash([]); }
      else if (bench[i].here) person(p.x, p.y - 6, PALETTE[bench[i].color]);
    }
    const used = bench.filter(Boolean).length;
    ctx.fillStyle = used >= BENCH - 1 ? '#c0392b' : '#5b4630';
    ctx.font = 'bold 11px system-ui, sans-serif'; ctx.textAlign = 'left';
    ctx.fillText(`ベンチ ${used}/${BENCH}`, 8, 110);
```

- 空席には今までどおり点線の枠、着席している乗客がいればその色で描きます。予約済みでまだ着いていない席（`here` が false）は、枠も人も描きません
- `bench.filter(Boolean)` は「`null` ではない席だけ」を集める書き方です。その数を `ベンチ 3/5` のように左上に出し、残り1席以下になったら **赤い文字** で危険を知らせます

> [!CHECK] 動作チェック
> - バスと色ちがいの乗客をタップすると、ベンチの左の席から順に座り、「ベンチ 1/5」のように数字が増える
> - 4席以上うまると「ベンチ」の文字が赤くなる。5席すべてうまると、色ちがいの乗客はタップしても動かない
> - ベンチに座っている色のバスが来ると、止まった瞬間にベンチの乗客がバスへ乗りこみ、席が空く
