## このステップのゴール

バス停に **バスを走らせます**。`queue`（バスの列）から1台ずつバスが左から走ってきて止まり、**同じ色の乗客** をタップすると乗りこみます。3人で満員になると右へ発車し、次のバスがやって来ます。画面の下には「次のバス」の色を4台先まで表示します。

## バスの変数と座席の位置

`let grid = [], queue = [];` を **書きかえ** ます。

```js:game.js
  let grid = [], queue = [], bus = null;
```

`const seatPos = ...` の行の **下** に、バスの座席の位置を求める関数を追加します。

```js:game.js
  const busSeatPos = (i, bx) => ({ x: bx + 50 + i * 46, y: BUS_Y + 30 });
```

`bx` はバスの左端の x 座標です。バスは走って動くので、座席の位置も「バスの今の位置」を元に計算します。

## バスを呼ぶ nextBus() と、次のバスの表示

`startStage()` を **書きかえ**、その下に2つの関数を追加します。

```js:game.js
  function startStage() {
    const s = generate(level);
    grid = s.g; queue = s.buses.slice();
    bus = null;
    nextBus();
    resize();
    $('stage-no').textContent = level;
    updateNext();
  }
  function nextBus() {
    if (!queue.length) { bus = null; return; }
    bus = { color: queue.shift(), filled: 0, arrived: 0, x: -BUS_W - 20, state: 'arrive' };
    updateNext();
  }
  function updateNext() {
    $('next').innerHTML = queue.length
      ? queue.slice(0, 4).map(c => `<i style="background:${PALETTE[c]}"></i>`).join('') + (queue.length > 4 ? ` +${queue.length - 4}` : '')
      : 'なし（最後のバス）';
  }
```

バスは1つのオブジェクトで表します。

- `color` … バスの色。`queue.shift()` で列の先頭を取り出します
- `x` … 左端の位置。画面の左外（`-BUS_W - 20`）からスタートします
- `state` … `'arrive'`（走ってくる途中）→ `'wait'`（停車中、乗れる）→ `'depart'`（発車）の3つの状態
- `filled` と `arrived` … どちらも「乗った人数」ですが、`filled` は **座席を予約した人数**、`arrived` は **実際に座った人数** です。このステップでは乗客が一瞬で乗るので2つは同じ値になりますが、ステップ6で乗客がバスまで歩くようになると差が出てきます

`updateNext()` は、残りのバスの色を4台ぶん `<i>` の色見本にして並べ、5台以上あれば「+残り台数」を添えます。`map()` で HTML の文字列を作って `join('')` でつなげる書き方は、リストを表示するときによく使います。

## 同じ色の乗客だけ乗せる

`tapCell()` を **書きかえ**、その下に `boarded()` を追加します。

```js:game.js
  function tapCell(r, c) {
    if (state !== 'play' || r < 0 || r >= rows || c < 0 || c >= COLS) return;
    const v = grid[r][c];
    if (v < 0) return;
    const reach = reachableMap(grid);
    if (!reach[r][c]) return;
    const toBus = bus && bus.state === 'wait' && bus.color === v && bus.filled < CAP;
    if (!toBus) return;
    grid[r][c] = EMPTY;
    bus.filled++;
    boarded(bus);
  }

  function boarded(b) {
    b.arrived++;
    if (b.arrived >= CAP && b.state === 'wait') {
      b.state = 'depart';
    }
  }
```

`toBus` は「バスが停車中で、色が同じで、まだ席がある」ときだけ true になります。そうでなければ今は何もしません（色ちがいの乗客はステップ5でベンチに行けるようにします）。

`boarded(b)` は「乗客がバスの席に座った」ときに呼ぶ関数で、3人そろったらバスを `'depart'` にします。引数でバスを受け取るのは、ステップ6で「歩いている途中にバスが入れかわる」ことがあっても、**予約したバス** に正しく座れるようにするためです。

## バスを動かす update(dt)

`// ---------- draw ----------` の **上** に追加します。

```js:game.js
  // ---------- update ----------
  function update(dt) {
    if (bus) {
      if (bus.state === 'arrive') {
        bus.x += (BUS_X - bus.x) * Math.min(1, dt * 7) + 60 * dt;
        if (bus.x >= BUS_X) { bus.x = BUS_X; bus.state = 'wait'; }
      } else if (bus.state === 'depart') {
        bus.x += 520 * dt;
        if (bus.x > W + 20) nextBus();
      }
    }
  }
```

`dt` は「前のフレームから何秒たったか」です。動く量に `dt` をかけておくと、1秒に60回描く画面でも120回描く画面でも、**同じ速さ** で動きます。

- 到着中は、止まる位置 `BUS_X` までの残りの距離の一部ずつ近づきます。こうすると最初は速く、止まる直前にゆっくりになって、ブレーキをかけたように見えます。残りの距離だけだといつまでも着かないので、`+ 60 * dt` で少しだけ一定の速さも足しています
- 発車したら毎秒 520 の速さで右へ走り、画面の右外まで出たら `nextBus()` で次のバスを呼びます

## バスを描く drawBus()

`function person(...)` の関数の **下**（`function draw()` の上）に追加します。

```js:game.js
  function drawBus(b) {
    const x = b.x, y = BUS_Y, col = PALETTE[b.color];
    ctx.fillStyle = 'rgba(0,0,0,.3)'; rr(x + 4, y + 8, BUS_W, BUS_H, 14); ctx.fill();
    ctx.fillStyle = col; rr(x, y, BUS_W, BUS_H, 14); ctx.fill();
    ctx.fillStyle = 'rgba(0,0,0,.18)'; rr(x, y + BUS_H - 16, BUS_W, 16, [0, 0, 14, 14]); ctx.fill();
    // front window
    ctx.fillStyle = '#cfefff'; rr(x + BUS_W - 30, y + 10, 22, 32, 6); ctx.fill();
    for (let i = 0; i < CAP; i++) {
      const p = busSeatPos(i, x);
      ctx.fillStyle = '#e8f7ff'; rr(p.x - 18, p.y - 20, 36, 32, 6); ctx.fill();
      if (i < b.arrived) person(p.x, p.y - 2, col, 1, 0.75);
    }
    ctx.fillStyle = '#222';
    [x + 38, x + BUS_W - 42].forEach(wx => { ctx.beginPath(); ctx.arc(wx, y + BUS_H, 11, 0, 7); ctx.fill(); ctx.fillStyle = '#888'; ctx.beginPath(); ctx.arc(wx, y + BUS_H, 4, 0, 7); ctx.fill(); ctx.fillStyle = '#222'; });
    ctx.fillStyle = '#fff'; ctx.font = 'bold 12px system-ui, sans-serif'; ctx.textAlign = 'center';
    ctx.fillText(`${b.arrived}/${CAP}`, x + 22, y + 62);
  }
```

影 → 車体 → 下側の暗い帯 → 前の窓 → 3つの座席の窓 → タイヤ2つ → 「乗った人数/定員」の順に描きます。座席の窓には、座った人数（`arrived`）ぶんだけ乗客を 0.75 倍で描きます。`rr()` の最後の引数に `[0, 0, 14, 14]` のような配列を渡すと、「左上・右上・右下・左下」の角ごとに丸みを変えられます。

`draw()` の `ctx.fillText('BUS', W - 42, 31);` の行の **下** に、バスを描く1行を足します。

```js:game.js
    if (bus) drawBus(bus);
```

## ゲームループで時間を進める

ファイルの最後のほうの `function loop() { ... }` を **書きかえ** ます。

```js:game.js
  let last = performance.now();
  function loop(now) {
    const dt = Math.min(0.05, (now - last) / 1000); last = now;
    if (state !== 'title') update(dt);
    draw();
    requestAnimationFrame(loop);
  }
```

`requestAnimationFrame` は、呼んだ関数に **今の時刻（ミリ秒）** を渡してくれます。前回の時刻 `last` との差を 1000 で割れば、秒単位の `dt` になります。ほかのタブを見ていて戻ってきたときなどに `dt` がとても大きくなると、バスが一気にワープしてしまうので、`Math.min(0.05, ...)` で最大 0.05 秒に抑えています。

> [!CHECK] 動作チェック
> - スタートすると、左から色つきのバスが走ってきて、ブレーキをかけるように止まる
> - 画面の下に、次に来るバスの色が4台ぶんと「+6」のような残り台数が出る
> - バスと同じ色の、明るい乗客をタップすると消えて、バスの窓に乗客が座り、左下の数字が「1/3」「2/3」と増える
> - 3人乗ると右へ発車し、次のバスがやって来る。色ちがいの乗客をタップしても、まだ何も起きない
