## このステップのゴール

最後の仕上げです。**効果音** を Web Audio API で鳴らし、**キーボード** の矢印キーで乗客を選んで Space / Enter で動かせるようにします。これで完成品と同じになります。

## 効果音 … Web Audio API

`let banner = null, shake = 0;` の行を **書きかえ**、その下に `// ---------- audio ----------` を追加します。

```js:game.js
  let cursor = { r: 0, c: 0, show: false }, banner = null, shake = 0;

  // ---------- audio ----------
  let ac = null;
  function beep(f, d = 0.08, type = 'sine', v = 0.12) {
    try {
      if (!ac) ac = new (window.AudioContext || window.webkitAudioContext)();
      const o = ac.createOscillator(), g = ac.createGain();
      o.type = type; o.frequency.value = f;
      g.gain.setValueAtTime(v, ac.currentTime);
      g.gain.exponentialRampToValueAtTime(0.001, ac.currentTime + d);
      o.connect(g); g.connect(ac.destination);
      o.start(); o.stop(ac.currentTime + d);
    } catch (e) {}
  }
```

`cursor` はキーボードで選んでいるマスです（あとで使います）。

**Web Audio API** を使うと、音声ファイルを用意しなくても JavaScript で音を作れます。

- `AudioContext` … 音を扱うための入れ物。ブラウザは「ユーザーが操作するまで音を出さない」決まりがあるので、最初に音を鳴らすとき（＝スタートを押したあと）に作ります
- `createOscillator()` … 決まった高さ（周波数 `f`、単位は Hz）の音を出し続ける発振器。`type` で音色（`'sine'` はやわらかい音、`'square'` や `'sawtooth'` はブザーっぽい音、`'triangle'` はその中間）を選べます
- `createGain()` … 音量のつまみ。`exponentialRampToValueAtTime` で `d` 秒かけて音量をほぼ 0 まで下げると、「ポッ」と自然に消える短い音になります
- `o.connect(g); g.connect(ac.destination);` … 発振器 → 音量 → スピーカー、の順につなぎます

## 音を鳴らす場所

ゲームの出来事に合わせて `beep()` を足していきます。

`tapCell()` の2か所の `return` を、ブブッという低い音つきに **書きかえ** ます。

```js:game.js
    if (!reach[r][c]) { beep(140, 0.12, 'square', 0.06); shake = 0.25; return; }
```

```js:game.js
    if (!toBus && slot < 0) { beep(140, 0.12, 'square', 0.06); return; }
```

同じく `tapCell()` で、バスへ向かう `walkTo(v, path, () => boarded(b));` の **下** と、ベンチへ向かう `walkTo(...)` の **下** に1行ずつ足します。

```js:game.js
      beep(520 + seat * 120, 0.08);
```

```js:game.js
      beep(330, 0.07, 'triangle');
```

バスに乗る音は、座席番号 `seat` が進むほど高くなるので、「ド・ミ・ソ」のように盛り上がっていきます。

`boarded()` の `addScore(30, ...)` の **下** に、発車の2音を足します。

```js:game.js
      beep(660, 0.1); setTimeout(() => beep(880, 0.14), 90);
```

`checkEnd()` のクリアの `banner = { text: 'STAGE CLEAR!', t: 1.6 };` の **下** に、3音のファンファーレを足します。

```js:game.js
        beep(660, 0.12); setTimeout(() => beep(880, 0.12), 120); setTimeout(() => beep(1100, 0.2), 240);
```

`gameOver()` の `state = 'over';` の **下** に、下がっていく2音を足します。

```js:game.js
    beep(220, 0.25, 'sawtooth', 0.08); setTimeout(() => beep(160, 0.35, 'sawtooth', 0.08), 200);
```

`startGame()` の `startStage();` の **下** に1行足します。

```js:game.js
    beep(440, 0.05);
```

`update()` のバスが止まる行を **書きかえ** ます。

```js:game.js
        if (bus.x >= BUS_X) { bus.x = BUS_X; bus.state = 'wait'; beep(300, 0.06, 'triangle'); autoBoard(); }
```

## キーボードで遊べるようにする

`startStage()` の `nextBus();` の **下**（`resize();` の上）に、カーソルを左上に戻す1行を足します。

```js:game.js
    cursor = { r: 0, c: 0, show: cursor.show };
```

`show` は「カーソルを表示するか」です。キーボードで遊んでいる人には次のステージでも表示し続けるよう、今の値を引きつぎます。

`draw()` の `ctx.restore();` の **上**（広場のマスを描く `for` ループのあと）に、白い枠のカーソルを描く処理を足します。

```js:game.js
    if (cursor.show && state === 'play') {
      ctx.strokeStyle = '#fff'; ctx.lineWidth = 3;
      rr(GX + cursor.c * CELL + 2, GY + cursor.r * CELL + 2, CELL - 4, CELL - 4, 9); ctx.stroke();
    }
```

`ctx.restore()` より前に描くので、広場がゆれるときはカーソルもいっしょにゆれます。

`pointerdown` のイベントの中、`tapCell(...)` の **上** に1行足します。マウスやタッチで遊び始めたら、カーソルを隠すためです。

```js:game.js
    cursor.show = false;
```

`pointerdown` のイベントの `});` の **下** に、キー操作を追加します。

```js:game.js
  window.addEventListener('keydown', e => {
    if (state === 'title' || state === 'over') {
      if (e.key === 'Enter' || e.key === ' ') { e.preventDefault(); startGame(); }
      return;
    }
    const mv = { ArrowUp: [-1, 0], ArrowDown: [1, 0], ArrowLeft: [0, -1], ArrowRight: [0, 1] }[e.key];
    if (mv) {
      e.preventDefault(); cursor.show = true;
      cursor.r = Math.max(0, Math.min(rows - 1, cursor.r + mv[0]));
      cursor.c = Math.max(0, Math.min(COLS - 1, cursor.c + mv[1]));
    } else if (e.key === ' ' || e.key === 'Enter') {
      e.preventDefault(); cursor.show = true; tapCell(cursor.r, cursor.c);
    }
  });
```

- タイトル画面とゲームオーバー画面では、Space / Enter でスタート（リトライ）します
- `{ ArrowUp: ..., ... }[e.key]` は、押したキーの名前でオブジェクトを引いて、動く向きを取り出す書き方です。矢印キー以外なら `undefined` になります
- `Math.max(0, Math.min(最大, 値))` で、カーソルが広場の外へ出ないように止めます
- Space / Enter では、カーソルのマスに対してタップと同じ `tapCell()` を呼びます。処理を `tapCell()` にまとめておいたので、入力方法が増えてもルールは1か所だけで済みます
- `e.preventDefault()` は、Space でページがスクロールするなど、ブラウザの元の動きを止めるためです

> [!CHECK] 動作チェック
> - スタートすると短い音が鳴り、バスが止まるとポンと鳴る
> - バスに乗せると音がだんだん高くなり、発車・ステージクリア・ゲームオーバーでそれぞれちがう音が鳴る。動けない乗客をタップするとブブッと鳴る
> - PC で矢印キーを押すと広場に白い枠が出て、Space / Enter でその乗客が動く。マウスでクリックすると白い枠は消える
> - タイトル画面とゲームオーバー画面で、Space / Enter を押すとゲームが始まる

## 完成！ 改造してみよう

これで完成品の「のりあいバス」と同じものができました。最後に、自分だけのゲームに育てる改造アイデアをいくつか紹介します。

> [!TIP]
> **ベンチの席数を変える** … `BENCH = 5` を `4` にするとぐっと難しく、`6` にするとやさしくなります。`SEAT_STEP`（席の間かく）も合わせて調整しましょう。`solvable()` も同じ `BENCH` を使っているので、作られる盤面も自動でその席数でクリアできるものになります。

> [!TIP]
> **残り手数のヒント** … `reachableMap()` を使って「今のバスと同じ色で、動ける乗客」の人数を数え、`#hint` に「乗れる人: 2人」のように出すと、初心者にやさしくなります。

> [!TIP]
> **大型バス** … バスのオブジェクトに `cap` を持たせ、ときどき定員4人のバスが来るようにしてみましょう。`generate()` では、そのバスのぶんだけ乗客を4人にする必要があります。

> [!TIP]
> **ステージの記録** … ハイスコアと同じように、到達した最高ステージも `localStorage` に保存して、タイトル画面に「最高 STAGE 5」と出してみましょう。
