## このステップのゴール

遊んだ手ごたえを出す演出と、記録の保存を入れます。

- 点が入った場所に「+10」の文字を浮かべる
- 動けない乗客をタップしたら、広場をブルッとゆらして「そこは無理」と伝える
- **ハイスコア** をブラウザに保存して、BEST に表示する
- タイトル画面の後ろに、お手本の盤面とバスを描いておく

## 変数を増やす

`let grid = ...` と `let banner = null;` の2行を **書きかえ** ます。

```js:game.js
  let grid = [], bench = [], queue = [], bus = null, walkers = [], pops = [];
  let banner = null, shake = 0;
```

- `pops` … 浮かぶ「+10」の文字の配列。1つずつ `{ text, x, y, t }` を持ちます
- `shake` … 広場をゆらす残り時間（秒）

`startStage()` の `walkers = [];` を **書きかえ** ます。

```js:game.js
    walkers = []; pops = [];
```

## ハイスコアを読みこむ

`const overlay = ...` の行の **下** に、空行をはさんで追加します。

```js:game.js
  let best = 0;
  try { best = parseInt(localStorage.getItem('busBoardBest') || '0', 10) || 0; } catch (e) {}
  $('best').textContent = best;
```

**localStorage** は、ブラウザにちょっとした文字列を保存しておける仕組みです。ページを閉じても消えません。`getItem` で読み、`setItem` で書きます。保存されるのは文字列だけなので、`parseInt` で数値に直します。まだ何も保存されていなければ `'0'` を使います。

プライベートブラウズなど、localStorage が使えない環境ではエラーになることがあるので、`try { ... } catch (e) {}` で囲んで、失敗してもゲームは動くようにしています。

## addScore() を仕上げる

`addScore()` を **書きかえ** ます。

```js:game.js
  function addScore(v, x, y) {
    score += v; $('score').textContent = score;
    if (x !== undefined) pops.push({ text: '+' + v, x, y, t: 0.8 });
    if (score > best) {
      best = score; $('best').textContent = best;
      try { localStorage.setItem('busBoardBest', String(best)); } catch (e) {}
    }
  }
```

場所が渡されていれば「+点数」の文字を0.8秒間出します。スコアがハイスコアを超えたら、その場で BEST を書きかえて保存します。ゲームオーバーのときにまとめて保存するより、途中でページを閉じても記録が残るので安心です。

ゲームオーバー画面にもベストを出しましょう。`gameOver()` の `ovText.innerHTML = ...` の行を **書きかえ** ます。

```js:game.js
      ovText.innerHTML = `ベンチが満席で、もう誰も乗れない…<br>ステージ <b class="hl">${level}</b> ・ スコア <b class="hl">${score}</b><br>ベスト ${best}`;
```

## 動けない乗客をタップしたらゆらす

`tapCell()` の `if (!reach[r][c]) return;` を **書きかえ** ます。

```js:game.js
    if (!reach[r][c]) { shake = 0.25; return; }
```

## 演出を動かす

`update()` の **先頭** に2行足します。`if (banner) ...` の行をはさむように、こう並べます。

```js:game.js
  function update(dt) {
    if (shake > 0) shake -= dt;
    if (banner) { banner.t -= dt; if (banner.t <= 0) banner = null; }
    pops.forEach(p => { p.t -= dt; p.y -= 30 * dt; }); pops = pops.filter(p => p.t > 0);
```

「+10」の文字は毎秒30ずつ上へ動き、時間切れになったら配列から消します。

## 演出を描く

`draw()` の `// plaza` の部分で、広場の土台を描く行の **上** に2行足し、`// exit arrows` の **上** に1行足します。

```js:game.js
    // plaza
    const ox = shake > 0 ? Math.sin(shake * 80) * 3 : 0;
    ctx.save(); ctx.translate(ox, 0);
    ctx.fillStyle = '#2f6b45'; rr(GX - 6, GY - 6, COLS * CELL + 12, rows * CELL + 12, 12); ctx.fill();
```

```js:game.js
    ctx.restore();
    // exit arrows
```

- `ctx.translate(ox, 0)` は「これから描くものを横に `ox` だけずらす」命令です。`Math.sin(shake * 80) * 3` は、時間とともに -3〜+3 の間を細かく行ったり来たりするので、広場が左右にブルブルふるえて見えます
- `ctx.save()` で今の状態を保存し、広場を描き終わったら `ctx.restore()` で元に戻します。こうすると、ずらす効果が広場の部分だけにかかります

`draw()` の最後、`ctx.font = 'bold 16px ...'` の行の **下**（`if (banner)` の上）に、「+10」の文字を描く2行を足します。

```js:game.js
    pops.forEach(p => { ctx.globalAlpha = Math.min(1, p.t * 2); ctx.fillStyle = '#fff'; ctx.strokeStyle = 'rgba(0,0,0,.5)'; ctx.lineWidth = 3; ctx.strokeText(p.text, p.x, p.y); ctx.fillText(p.text, p.x, p.y); });
    ctx.globalAlpha = 1;
```

`strokeText` で黒っぽいふちを描いてから `fillText` で白い文字を重ねると、どんな背景の上でも読みやすい文字になります。

## タイトル画面の背景

`startBtn.addEventListener('click', startGame);` の行の **下** に、空行をはさんで追加します。

```js:game.js
  // title backdrop
  const demo = generate(2); grid = demo.g; queue = demo.buses.slice(1);
  bench = Array(BENCH).fill(null); bus = { color: demo.buses[0], filled: 0, arrived: 0, x: BUS_X, state: 'wait' };
  updateNext();
```

ページを開いた時点でステージ2ぶんの盤面を1つ作り、停車中のバスも置いておきます。タイトル画面のあいだは `update()` が動かないので、この絵がオーバーレイの後ろに止まったまま見えます。スタートすると `startStage()` が全部作り直すので、ゲームには影響しません。

> [!CHECK] 動作チェック
> - ページを開くと、タイトル画面の後ろに木のある広場とバスがうっすら見える
> - 乗客がバスに座ると、その座席の上に「+10」、発車するとバスの上に「+30」が浮かんで消える
> - 薄い（動けない）乗客をタップすると、広場が左右にブルッとゆれる
> - BEST がスコアといっしょに増え、ページを再読み込みしても BEST が残っている
