## このステップのゴール

このパズルのルールの中心、「**上の道まで通り道がある乗客だけが動ける**」を作ります。広場の空きマスをたどって、どの乗客が外に出られるかを調べ、出られる乗客は明るく、出られない乗客は薄く描きます。さらに、出られる乗客を **タップすると広場から消える** ようにします（バスに乗せるのは次のステップです）。

## 通り道の考え方

乗客が外に出られるのは、次のどちらかのときです。

- 一番上の段（`r = 0`）にいる … 目の前がもう歩道
- 上下左右のとなりに、**一番上の段までつながっている空きマス** がある

そこで、まず「一番上の段からたどれる空きマス」を全部求めてしまいます。これには **幅優先探索（BFS）** を使います。

1. 一番上の段の空きマスを、すべて「たどれる」として **キュー**（順番待ちの列）に入れる
2. キューから1マス取り出し、その上下左右のとなりを見る。空きマスで、まだ調べていなければ「たどれる」にしてキューに入れる
3. キューが空になるまで 2 をくり返す

水が一番上からしみこんでいくように、つながった空きマスに印がついていくイメージです。

## openSet() と reachableMap()

`const seatPos = ...` の行の **下** に、上下左右を表す `DIRS` を追加します。

```js:game.js
  const DIRS = [[1, 0], [-1, 0], [0, 1], [0, -1]];
```

続けて、その下（`function generate` の上）に2つの関数を追加します。

```js:game.js
  // cells open to the top road (empty cells connected to row 0)
  function openSet(g) {
    const R = g.length, seen = g.map(row => row.map(() => false)), q = [];
    for (let c = 0; c < COLS; c++) if (g[0][c] === EMPTY) { seen[0][c] = true; q.push([0, c]); }
    while (q.length) {
      const [r, c] = q.shift();
      for (const [dr, dc] of DIRS) {
        const nr = r + dr, nc = c + dc;
        if (nr < 0 || nr >= R || nc < 0 || nc >= COLS || seen[nr][nc] || g[nr][nc] !== EMPTY) continue;
        seen[nr][nc] = true; q.push([nr, nc]);
      }
    }
    return seen;
  }
  function reachableMap(g) {
    const open = openSet(g);
    return g.map((row, r) => row.map((v, c) => {
      if (v < 0) return false;
      if (r === 0) return true;
      return DIRS.some(([dr, dc]) => { const nr = r + dr, nc = c + dc; return nr >= 0 && nr < g.length && nc >= 0 && nc < COLS && open[nr][nc]; });
    }));
  }
```

- `openSet(g)` … さきほどの BFS です。`seen` は `grid` と同じ形の true / false の2次元配列で、「上の道からたどれる空きマス」が `true` になります。`q.shift()` でキューの先頭を取り出し、`q.push()` で最後に足します
- `continue` の条件は「盤面の外」「もう調べた」「空きマスではない（乗客や木）」のどれか。乗客がいるマスは通り抜けられないので、ここで止まります
- `reachableMap(g)` … 乗客ごとに「動けるか」を true / false で返します。一番上の段なら無条件で OK、それ以外は上下左右のどこかに `open` なマスがあれば OK です。`some()` は「1つでも条件を満たせば true」を返す配列のメソッドです

関数に `grid` を直接使わず、引数 `g` で盤面を受け取るようにしているのは、ステップ7で「コピーした盤面でためしに解いてみる」ときにも同じ関数を使うためです。

## 動ける乗客を目立たせる

`draw()` の `// plaza` で、土台を描く行のすぐ **下**（`for` ループの上）に追加します。

```js:game.js
    const reach = state === 'title' ? null : reachableMap(grid);
```

そして、ループの最後の `if (v >= 0) person(...)` の行を **書きかえ** ます。

```js:game.js
      if (v >= 0) {
        const ok = reach && reach[r][c];
        if (ok) { ctx.fillStyle = 'rgba(255,255,255,.14)'; rr(x + 4, y + 4, CELL - 8, CELL - 8, 8); ctx.fill(); }
        person(x + CELL / 2, y + CELL / 2 + 2, PALETTE[v], ok ? 1 : 0.62);
      }
```

動ける乗客のマスはうっすら白く光らせ、動けない乗客は透明度 `0.62` で薄く描きます。毎フレーム `reachableMap()` を計算していますが、広場は最大でも 6 × 8 = 48 マスなので、まったく問題ない軽さです。

## タップした乗客を消す tapCell()

`startGame()` の **上** に追加します。

```js:game.js
  function tapCell(r, c) {
    if (state !== 'play' || r < 0 || r >= rows || c < 0 || c >= COLS) return;
    const v = grid[r][c];
    if (v < 0) return;
    const reach = reachableMap(grid);
    if (!reach[r][c]) return;
    grid[r][c] = EMPTY;
  }
```

プレイ中でない・広場の外・乗客がいない・動けない、のどれかなら何もしません。動ける乗客なら、そのマスを `EMPTY` にします。

## タップを受け取る

`window.addEventListener('resize', resize);` の **下** に、空行をはさんで追加します。

```js:game.js
  cv.addEventListener('pointerdown', e => {
    e.preventDefault();
    const rect = cv.getBoundingClientRect();
    const x = (e.clientX - rect.left) / rect.width * W, y = (e.clientY - rect.top) / rect.height * H;
    tapCell(Math.floor((y - GY) / CELL), Math.floor((x - GX) / CELL));
  });
```

**pointerdown** は、マウスのクリックとスマホのタッチの両方で起きるイベントです。`e.clientX` / `e.clientY` は画面上のピクセル位置なので、Canvas の左上からの位置に直し、さらに見た目の幅で割って `W` をかけることで、**仮想の画面（幅 360）の座標** に変換します。あとは「広場の左上 `GX`, `GY` から何マス目か」を `Math.floor(... / CELL)` で求めれば、タップしたマスの段 `r` と列 `c` が分かります。

> [!CHECK] 動作チェック
> - スタート直後は、一番上の段の6人だけが明るく、2段目から下は薄く表示される
> - 明るい乗客をタップすると消え、その真下の乗客が明るくなる
> - 薄い乗客をタップしても何も起きない
> - 横に空きがつながっていれば、真上が乗客でふさがれていても明るくなる（たとえば1段目の左端、続けて2段目の左端を消すと、真上に人がいる2段目の左から2人目も、左どなりの空きマスを通って出られるので明るくなる）
