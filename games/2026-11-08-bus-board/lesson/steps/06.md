## このステップのゴール

今は乗客がパッと消えてパッと座るので、何が起きたのか分かりにくい状態です。そこで、タップした乗客が **広場の通り道を歩いて外へ出て、歩道を通ってバスやベンチまで歩いていく** ようにします。通り道は、ステップ3の幅優先探索を少し改造して「道順つき」で求めます。

## 道順を求める pathOut()

幅優先探索には、「**最初に見つかった道が最短の道**」という便利な性質があります。そこで、マスごとに「どのマスから来たか」を `prev` に記録しながら探索し、ゴール（一番上の段）に着いたら、その記録を逆にたどって道順を作ります。

`function reachableMap(...)` の関数の **下**（`function generate` の上）に追加します。

```js:game.js
  function pathOut(g, sr, sc) {
    const R = g.length, prev = g.map(row => row.map(() => null)), q = [[sr, sc]];
    prev[sr][sc] = [-1, -1];
    while (q.length) {
      const [r, c] = q.shift();
      if (r === 0) {
        const out = []; let cur = [r, c];
        while (cur[0] !== -1) { out.unshift(cur); cur = prev[cur[0]][cur[1]]; }
        return out;
      }
      for (const [dr, dc] of DIRS) {
        const nr = r + dr, nc = c + dc;
        if (nr < 0 || nr >= R || nc < 0 || nc >= COLS || prev[nr][nc] || g[nr][nc] !== EMPTY) continue;
        prev[nr][nc] = [r, c]; q.push([nr, nc]);
      }
    }
    return [[sr, sc]];
  }
```

- スタートは乗客のいるマス `(sr, sc)`。スタートの `prev` には「ここが始まり」の印として `[-1, -1]` を入れておきます
- `prev[nr][nc]` に値が入っていれば「もう調べた」という意味にもなるので、`seen` の配列は要りません
- 一番上の段に着いたら、`prev` を `[-1, -1]` が出るまでさかのぼり、`unshift()`（配列の先頭に足す）で並べ直すと、**スタートからゴールまでのマスの列** ができます
- 見つからなかったときは、スタートのマスだけを返します（`tapCell()` は動ける乗客にしか呼ばないので、ふつうは起きません）

## 歩く乗客 walkers

`let grid = ...` の行の最後に `walkers = []` を足して **書きかえ** ます。

```js:game.js
  let grid = [], bench = [], queue = [], bus = null, walkers = [];
```

`const seatPos = ...` の行の **上** に、マスの中心の座標を返す関数を足します。

```js:game.js
  const cellCenter = (r, c) => ({ x: GX + c * CELL + CELL / 2, y: GY + r * CELL + CELL / 2 });
```

`startStage()` の `bench = Array(BENCH).fill(null);` の **下** に1行足します。

```js:game.js
    walkers = [];
```

`updateNext()` の **下** に、歩く乗客を登録する関数を追加します。

```js:game.js
  function walkTo(color, pts, onArrive) {
    walkers.push({ color, pts, i: 0, x: pts[0].x, y: pts[0].y, onArrive });
  }
```

歩く乗客は「色」「通る点の列 `pts`」「今どの点まで来たか `i`」「今の位置 `x`, `y`」と、**着いたときに呼ぶ関数** `onArrive` を持ちます。関数を値として渡しておき、あとで呼んでもらうこの書き方を **コールバック** といいます。

## tapCell() を歩かせる版にする

`tapCell()` の `grid[r][c] = EMPTY;` から最後までを **書きかえ** ます。関数全体はこうなります。

```js:game.js
  function tapCell(r, c) {
    if (state !== 'play' || r < 0 || r >= rows || c < 0 || c >= COLS) return;
    const v = grid[r][c];
    if (v < 0) return;
    const reach = reachableMap(grid);
    if (!reach[r][c]) return;
    const toBus = bus && bus.state === 'wait' && bus.color === v && bus.filled < CAP;
    const slot = bench.indexOf(null);
    if (!toBus && slot < 0) return;
    const path = pathOut(grid, r, c).map(([pr, pc]) => cellCenter(pr, pc));
    grid[r][c] = EMPTY;
    path.push({ x: path[path.length - 1].x, y: WALK_Y });
    if (toBus) {
      const seat = bus.filled++;
      const b = bus;
      path.push({ x: busSeatPos(seat, BUS_X).x, y: WALK_Y });
      path.push(busSeatPos(seat, BUS_X));
      walkTo(v, path, () => boarded(b));
    } else {
      bench[slot] = { color: v, here: false };
      const sp = seatPos(slot);
      path.push({ x: sp.x, y: WALK_Y });
      path.push(sp);
      walkTo(v, path, () => { if (bench[slot]) bench[slot].here = true; if (bus && bus.state === 'wait') autoBoard(); });
    }
  }
```

道順は、`pathOut()` で求めたマスの列を `cellCenter()` で座標の列に直し、そこに点を足して作ります。

1. 広場の一番上のマスから、まっすぐ上の歩道（高さ `WALK_Y`）へ出る
2. 歩道を横に歩いて、行き先の真下まで行く
3. 行き先（バスの座席、またはベンチの席）へ上がる

ここで大事なのが **予約** です。乗客がバスに着くまでには少し時間がかかるので、そのあいだに別の乗客をタップされても席がかぶらないよう、タップした瞬間に `bus.filled++` で席を取っておきます（`bus.filled++` は「今の値を返してから 1 増やす」ので、`seat` には 0, 1, 2 の席番号が入ります）。実際に座るのは着いたとき、つまり `onArrive` で `boarded(b)` が呼ばれたときで、ここで `arrived` が増えて窓に乗客が描かれます。ステップ4で `filled` と `arrived` を分けておいたのはこのためです。

`const b = bus;` とバスを変数に取っておくのも同じ理由です。3人目が歩いている途中でも、着くまでは発車しないので、ちゃんと予約したバスに座れます。

ベンチへ行く場合は、席を `here: false` で予約しておき、着いたら `here = true` にします。さらに、**歩いているあいだに同じ色のバスが着いていた** かもしれないので、着いたときにも `autoBoard()` を呼んでおきます。

## ベンチからバスへも歩かせる

`autoBoard()` の `if` の中を **書きかえ** ます。

```js:game.js
  function autoBoard() {
    for (let i = 0; i < BENCH && bus.filled < CAP; i++) {
      const s = bench[i];
      if (s && s.here && s.color === bus.color) {
        bench[i] = null;
        const seat = bus.filled++;
        const b = bus, sp = seatPos(i), bp = busSeatPos(seat, BUS_X);
        walkTo(s.color, [sp, { x: sp.x, y: WALK_Y - 80 }, bp], () => boarded(b));
      }
    }
  }
```

ベンチの席から、いったん少し上（`WALK_Y - 80`）へ出て、バスの座席へ向かいます。

## 歩く乗客を動かす

`update()` の **先頭**（`if (bus) {` の上）に追加します。

```js:game.js
    const speed = 620 * dt;
    for (const w of walkers) {
      let move = speed;
      while (move > 0 && w.i < w.pts.length - 1) {
        const t = w.pts[w.i + 1], dx = t.x - w.x, dy = t.y - w.y, d = Math.hypot(dx, dy);
        if (d <= move) { w.x = t.x; w.y = t.y; w.i++; move -= d; }
        else { w.x += dx / d * move; w.y += dy / d * move; move = 0; }
      }
      if (w.i >= w.pts.length - 1 && !w.done) { w.done = true; w.onArrive(); }
    }
    walkers = walkers.filter(w => !w.done);
```

このフレームで歩ける距離 `move` を、次の点へ向かって使っていきます。

- 次の点までの距離 `d` は `Math.hypot(dx, dy)`（三平方の定理）で求めます
- 次の点に届くなら、ぴったりその点に移り、残りの `move` で **さらに次の点** へ向かいます。曲がり角で止まらずに、なめらかに歩き続けられます
- 届かないなら、向き（`dx / d`, `dy / d`）に `move` だけ進みます
- 最後の点に着いたら `onArrive()` を呼び、`done` の印をつけて `filter()` で配列から外します

## 歩く乗客を描く

`draw()` の `// exit arrows` の `for` ループの **下**（`draw()` の最後）に1行足します。

```js:game.js
    walkers.forEach(w => person(w.x, w.y, PALETTE[w.color]));
```

広場やベンチより **あと** に描くので、歩く乗客はいつも一番手前に見えます。

> [!CHECK] 動作チェック
> - 乗客をタップすると、広場の空きマスを通って上へ出て、歩道を横切り、バスの座席やベンチまで歩いていく
> - 奥の乗客は、空きマスを曲がりながら最短の道で出てくる
> - バスの窓の乗客と「〇/3」の数字は、乗客が **着いてから** 増える。3人目が着いてから発車する
> - 同じ色の乗客を素早く続けてタップしても、座席がかぶらない
