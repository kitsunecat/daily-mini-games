## このステップのゴール

3つのファイルを用意して、ゲーム画面の土台を作ります。上に「STAGE・SCORE・BEST」の表示、まん中にゲームを描く **Canvas**（キャンバス）、その上に重ねるタイトル画面（オーバーレイ）、下に「次のバス」の表示を置き、Canvas に **道路・バス停・歩道とベンチ・広場のマス目** を描くところまで進めます。

完成すると、こんなゲームになります。

- 画面の下半分は **広場**。色とりどりの乗客がマス目に並んでいる
- 画面の上には **バス停** があり、1台ずつバスがやって来る。バスと **同じ色** の乗客をタップするとバスまで歩いて乗りこみ、3人で満員になると発車する
- 色がちがう乗客をタップすると、歩道の **待合ベンチ（5席）** で待つ。同じ色のバスが来ると自動で乗りこむ
- 動けるのは、上の道まで **通り道がある乗客** だけ。前の人がどくと、うしろの人も動けるようになる
- ベンチが満席で、もう誰もバスに乗れなくなったらゲームオーバー

まずは HTML です。このステップで画面の部品はすべてそろえてしまい、以降は `game.js` だけを育てていきます。

- `<canvas id="cv">` が、ゲームを描く画用紙です。大きさはあとで JavaScript から決めます。
- 上の `#stage-no`・`#score`・`#best` と、下の `#next`（次のバスの色）は、あとのステップで JavaScript から書きかえます。
- `#overlay` はタイトル画面とゲームオーバー画面をかねるパネルです。操作説明にあるキーボード操作はステップ9で作ります。
- `<script>` は `</body>` の直前に置きます。HTML の要素が全部できたあとで JavaScript が動くので、`getElementById` で確実に要素を取れます。

## game.js

最後に JavaScript です。全体を `(() => { ... })();` で囲んでいます。これは **即時実行関数** といって、中で作った変数がページ全体に漏れ出さないようにする書き方です。

```js:game.js
(() => {
  'use strict';
  const W = 360;
  let H = 650;
  const COLS = 6, CELL = 54, GX = (W - COLS * CELL) / 2, GY = 206;
  const BENCH = 5, SEAT_X0 = 36, SEAT_STEP = 72, BENCH_Y = 136, WALK_Y = 184;
  const BUS_X = 22, BUS_Y = 14, BUS_W = 200, BUS_H = 70, CAP = 3;
  const PALETTE = ['#ff5a5f', '#3fa7ff', '#ffd23f', '#3ddc84', '#b06cff', '#ff9a3c', '#ff7ad9'];
  const WALL = -2, EMPTY = -1;

  const cv = document.getElementById('cv');
  const ctx = cv.getContext('2d');
  const $ = id => document.getElementById(id);
  const overlay = $('overlay'), ovTitle = $('ov-title'), ovText = $('ov-text'), startBtn = $('start');

  let state = 'title';
  let rows = 5;

  // ---------- helpers ----------
  const seatPos = i => ({ x: SEAT_X0 + i * SEAT_STEP, y: BENCH_Y });

  // ---------- game flow ----------
  function startGame() {
    overlay.classList.add('hide');
    state = 'play';
  }

  // ---------- draw ----------
  function rr(x, y, w, h, r) { ctx.beginPath(); ctx.roundRect ? ctx.roundRect(x, y, w, h, r) : ctx.rect(x, y, w, h); }
  function draw() {
    ctx.clearRect(0, 0, W, H);
    // road
    ctx.fillStyle = '#3b4250'; ctx.fillRect(0, 0, W, 100);
    ctx.strokeStyle = 'rgba(255,255,255,.35)'; ctx.lineWidth = 3; ctx.setLineDash([18, 14]);
    ctx.beginPath(); ctx.moveTo(0, 96); ctx.lineTo(W, 96); ctx.stroke(); ctx.setLineDash([]);
    // bus stop sign
    ctx.fillStyle = '#ddd'; ctx.fillRect(W - 44, 30, 4, 66);
    ctx.fillStyle = '#ffd84a'; ctx.beginPath(); ctx.arc(W - 42, 30, 17, 0, 7); ctx.fill();
    ctx.fillStyle = '#3a2a00'; ctx.font = 'bold 13px system-ui, sans-serif'; ctx.textAlign = 'center'; ctx.textBaseline = 'middle';
    ctx.fillText('BUS', W - 42, 31);
    // sidewalk / bench
    ctx.fillStyle = '#c9bfa8'; ctx.fillRect(0, 100, W, 102);
    ctx.fillStyle = 'rgba(0,0,0,.06)';
    for (let x = 0; x < W; x += 30) ctx.fillRect(x, 100, 1, 102);
    for (let i = 0; i < BENCH; i++) {
      const p = seatPos(i);
      ctx.fillStyle = '#8a5a34'; rr(p.x - 28, p.y + 4, 56, 14, 5); ctx.fill();
      ctx.fillStyle = '#a8703f'; rr(p.x - 28, p.y + 2, 56, 8, 4); ctx.fill();
      ctx.strokeStyle = 'rgba(80,50,20,.35)'; ctx.lineWidth = 2; ctx.setLineDash([4, 4]); rr(p.x - 20, p.y - 24, 40, 40, 10); ctx.stroke(); ctx.setLineDash([]);
    }
    // plaza
    ctx.fillStyle = '#2f6b45'; rr(GX - 6, GY - 6, COLS * CELL + 12, rows * CELL + 12, 12); ctx.fill();
    for (let r = 0; r < rows; r++) for (let c = 0; c < COLS; c++) {
      const x = GX + c * CELL, y = GY + r * CELL;
      ctx.fillStyle = (r + c) % 2 ? '#3a7d52' : '#367549'; rr(x + 2, y + 2, CELL - 4, CELL - 4, 8); ctx.fill();
    }
    // exit arrows
    ctx.fillStyle = 'rgba(80,60,30,.35)';
    for (let c = 0; c < COLS; c++) { const x = GX + c * CELL + CELL / 2; ctx.beginPath(); ctx.moveTo(x, 190); ctx.lineTo(x - 6, 198); ctx.lineTo(x + 6, 198); ctx.fill(); }
  }

  // ---------- sizing / input ----------
  function resize() {
    H = GY + rows * CELL + 22;
    const st = $('stage'), aw = st.clientWidth - 16, ah = st.clientHeight - 8;
    const s = Math.max(0.3, Math.min(aw / W, ah / H));
    const dpr = Math.min(window.devicePixelRatio || 1, 3);
    cv.style.width = Math.floor(W * s) + 'px'; cv.style.height = Math.floor(H * s) + 'px';
    cv.width = Math.floor(W * s * dpr); cv.height = Math.floor(H * s * dpr);
    ctx.setTransform(cv.width / W, 0, 0, cv.height / H, 0, 0);
  }
  window.addEventListener('resize', resize);

  startBtn.addEventListener('click', startGame);

  function loop() {
    draw();
    requestAnimationFrame(loop);
  }
  resize();
  requestAnimationFrame(loop);
})();
```

### 画面の座標と定数

このゲームは、**幅 360 の仮想の画面** に描くと決めて作ります。実際の画面の大きさは機種によってバラバラですが、あとで `resize()` がまとめて拡大・縮小してくれるので、描くときは「幅 360」のつもりで座標を書けば OK です。高さ `H` は広場の段数で変わるので `let` にしています。

上から順に、こんな配置です。

- **道路**（y = 0〜100）… バスが左から走ってきて、左寄りの `BUS_X` で止まります。`BUS_*` はバスの位置と大きさ、`CAP = 3` は定員です
- **歩道**（y = 100〜202）… 待合ベンチが `BENCH = 5` 席。席の中心は `SEAT_X0` から `SEAT_STEP` おきで、高さは `BENCH_Y` です。`WALK_Y` は乗客が歩道を横に歩くときの高さで、ステップ6で使います
- **広場**（y = `GY` = 206 から下）… 横 `COLS = 6` マス、1マス `CELL = 54`。`GX` は広場を左右中央に置くための左端の位置です

`PALETTE` は乗客とバスの色、`WALL = -2` と `EMPTY = -1` は広場のマスの中身を表す特別な値です。乗客は `0` 以上の色番号で表すので、「0 以上なら乗客、マイナスなら空きか木」とすぐ見分けられます。今はまだ使わない定数もありますが、最初にまとめて書いておくと全体の設計が見わたせます。

### resize() … 仮想の画面を実際の大きさに合わせる

`resize()` は、`#stage` の大きさを読み取り、仮想の画面（`W` × `H`）がまるごと入る倍率 `s` を求めます。横に合わせた倍率と縦に合わせた倍率の **小さいほう** を使うのがコツで、こうすると縦長の画面でも横長の画面でもはみ出しません。

スマホの画面は、CSS の 1px を実際には 2〜3 個の点（物理ピクセル）で表示しています。この倍率が `devicePixelRatio`（`dpr`）です。`cv.style.width` には見た目の大きさを、`cv.width` には **その dpr 倍** の内部解像度を入れておくと、くっきり表示されます。

最後の `ctx.setTransform(cv.width / W, 0, 0, cv.height / H, 0, 0)` で、「これから描く座標を全部この倍率で拡大してね」と Canvas に伝えます。これで `draw()` の中は仮想の座標のまま書けます。

### draw() … 背景を描く

`draw()` は、毎回 `clearRect` で画面を消してから全部を描き直します。

- `rr()` は **角の丸い四角形** のパスを作る小さな関数です。`ctx.roundRect` が使えないブラウザでは、ふつうの四角形で代用します。パスを作ったあと `ctx.fill()` で塗りつぶし、`ctx.stroke()` でふちを描きます
- **road** … 灰色の道路と、`setLineDash([18, 14])` を使った白い点線（線 18・すき間 14）
- **bus stop sign** … 黄色い丸の「BUS」の標識。`ctx.arc(x, y, 半径, 0, 7)` は円を描く命令で、最後の `7` は「2π（約 6.28）より大きければ一周」という手抜きの書き方です
- **sidewalk / bench** … 歩道と5つのベンチ。席の場所は `seatPos(i)` で計算し、空席には点線の枠を描いています
- **plaza** … 濃い緑の土台の上に、市松模様（`(r + c) % 2` で色を交互に変える）のマスを `rows` 段ぶん並べます
- **exit arrows** … 広場の一番上の列の上に、小さな三角を6つ。「ここから歩道へ出られる」という目印です

### ゲームループ

`requestAnimationFrame(loop)` は「次に画面を描きかえるタイミングで `loop` を呼んで」とブラウザにお願いする関数です。`loop` の最後でまた自分を予約するので、1秒に約60回くり返し呼ばれ続けます。これを **ゲームループ** と呼びます。

`state` はゲームの状態を表す文字列です。`'title'`（タイトル画面）、`'play'`（プレイ中）、あとで `'clear'`（ステージクリア）と `'over'`（ゲームオーバー）も使います。スタートボタンを押すと `startGame()` が呼ばれ、`'play'` になってオーバーレイが消えます。

> [!CHECK] 動作チェック
> - タイトル画面に「のりあいバス」とスタートボタンが出る
> - スタートを押すとタイトル画面が消え、上から灰色の道路と BUS の標識、ベージュの歩道と5つのベンチ、緑の広場（横6マス × 縦5段の市松模様）が見える
> - ブラウザの幅や高さを変えても、画面の比率は変わらずに中央に収まる
> - 開発者ツールの Console にエラーが出ていない
