## このステップのゴール

広場のマスに **色とりどりの乗客** を並べます。広場の中身を2次元配列 `grid` で表し、ランダムにステージを作る `generate()` と、乗客を描く `person()` を書きます。ステージ番号が上がると、広場の段数・色の数・**木**（通れないマス）が増えるようにしておきます。

## 状態の変数を増やす

`let rows = 5;` の行を、次の2行に **書きかえ** ます。

```js:game.js
  let level = 1, rows = 5;
  let grid = [], queue = [];
```

- `level` … 今のステージ番号
- `grid` … 広場の中身。`grid[r][c]` が「上から `r` 段目・左から `c` 列目」のマスで、色番号（0 以上）・`EMPTY`・`WALL` のどれかが入ります
- `queue` … これから来るバスの色の列。ステップ4で使います

## 乱数の道具

`// ---------- helpers ----------` のすぐ **下**（`const seatPos = ...` の上）に追加します。

```js:game.js
  const rnd = n => Math.floor(Math.random() * n);
  function shuffle(a) { for (let i = a.length - 1; i > 0; i--) { const j = rnd(i + 1); [a[i], a[j]] = [a[j], a[i]]; } return a; }
```

- `rnd(n)` は `0` 〜 `n - 1` の整数をランダムに返します
- `shuffle(a)` は配列をかき混ぜます。後ろから順に「自分より前（自分を含む）のどれか」と入れかえていく **フィッシャー–イェーツのシャッフル** という定番の方法で、どの並びも同じ確率で出ます。`[a[i], a[j]] = [a[j], a[i]]` は、分割代入を使った2つの値の入れかえです

## ステージを作る generate()

`const seatPos = ...` の行の **下** に、空行をはさんで追加します。

```js:game.js
  function generate(L) {
    rows = Math.min(4 + L, 8);
    const nColors = Math.min(2 + L, 7);
    const g = Array.from({ length: rows }, () => Array(COLS).fill(EMPTY));
    const nWalls = L < 2 ? 0 : Math.min(1 + Math.floor(L / 2), 6);
    for (let i = 0; i < nWalls; i++) g[1 + rnd(rows - 1)][rnd(COLS)] = WALL;
    const cells = [];
    for (let r = 0; r < rows; r++) for (let c = 0; c < COLS; c++) {
      if (g[r][c] !== WALL) cells.push({ r, c });
    }
    const n = Math.floor(cells.length / 3) * 3;
    const busCount = n / 3;
    const buses = [];
    for (let i = 0; i < busCount; i++) buses.push(i % nColors);
    shuffle(buses);
    const seq = shuffle(buses.flatMap(c => [c, c, c]));
    for (let i = 0; i < n; i++) g[cells[i].r][cells[i].c] = seq[i];
    return { g, buses };
  }
```

上から順に見ていきます。

1. ステージ `L` に合わせて段数 `rows`（ステージ1で5段、最大8段）と色の数 `nColors`（ステージ1で3色、最大7色）を決めます
2. `Array.from({ length: rows }, () => Array(COLS).fill(EMPTY))` で、全部 `EMPTY` の `rows × COLS` の2次元配列を作ります。`Array(rows).fill(Array(COLS))` と書くと **全部の段が同じ配列** を共有してしまうので、関数で1段ずつ新しく作るのがポイントです
3. ステージ2からは木（`WALL`）をいくつか置きます。一番上の段（`r = 0`）には置かないようにしています
4. 木以外のマスを `cells` に集め、3の倍数 `n` 人ぶんだけ乗客を置きます

ここがこのゲームの設計のキモです。**先にバスの列 `buses` を決めてから、その乗客を作る** ようにしています。バス1台は3人乗りなので、バス `busCount` 台ぶんの色を並べ、`flatMap(c => [c, c, c])` で「バス1台につき同じ色の乗客3人」に増やしてから、かき混ぜて広場に置きます。こうすると、どの色の乗客もちょうどバスの定員ぶんだけいることになり、「乗客が1人余って乗れない」ということが起きません。

> [!NOTE]
> この並べ方だと、たまに「奥の乗客を先に出さないと詰む」ような、クリアがとても難しい盤面ができます。ステップ7で、出口からの近さを考えて並べ、さらに **本当にクリアできるか試してから** 採用するように作り直します。

## ステージを始める startStage()

`// ---------- game flow ----------` の **下** に追加し、`startGame()` を **書きかえ** ます。

```js:game.js
  function startStage() {
    const s = generate(level);
    grid = s.g; queue = s.buses.slice();
    resize();
    $('stage-no').textContent = level;
  }
  function startGame() {
    overlay.classList.add('hide');
    state = 'play';
    startStage();
  }
```

`generate()` で段数 `rows` が変わるので、そのあと `resize()` を呼んで Canvas の高さを合わせ直します。`s.buses.slice()` は配列のコピーです。

## 乗客を描く person()

`function rr(...)` の行の **下** に追加します。

```js:game.js
  function person(x, y, color, alpha = 1, s = 1) {
    ctx.globalAlpha = alpha;
    ctx.fillStyle = 'rgba(0,0,0,.25)';
    ctx.beginPath(); ctx.ellipse(x, y + 16 * s, 13 * s, 4 * s, 0, 0, 7); ctx.fill();
    ctx.fillStyle = color;
    rr(x - 11 * s, y - 2 * s, 22 * s, 18 * s, 9 * s); ctx.fill();
    ctx.beginPath(); ctx.arc(x, y - 10 * s, 8.5 * s, 0, 7); ctx.fill();
    ctx.fillStyle = 'rgba(255,255,255,.45)';
    ctx.beginPath(); ctx.arc(x - 3 * s, y - 13 * s, 3 * s, 0, 7); ctx.fill();
    ctx.fillStyle = '#1a1a2a';
    ctx.beginPath(); ctx.arc(x - 3 * s, y - 9 * s, 1.4 * s, 0, 7); ctx.arc(x + 3 * s, y - 9 * s, 1.4 * s, 0, 7); ctx.fill();
    ctx.globalAlpha = 1;
  }
```

乗客は「足もとの影（だ円）→ 胴体（角丸四角）→ 頭（円）→ 頭のツヤ → 目2つ」を重ねて描いた、シンプルなキャラクターです。

- `alpha` は透明度（1 で不透明）。ステップ3で「まだ動けない乗客」を少し薄く描くのに使います
- `s` は大きさの倍率。ステップ4で、バスの窓の中に小さめ（0.75 倍）に描くのに使います
- `ctx.globalAlpha` は「これから描くものの透明度」なので、最後に `1` に戻しておかないと、ほかの絵まで薄くなってしまいます

## 広場に乗客と木を描く

`draw()` の `// plaza` の中の `for` ループを **書きかえ** ます。

```js:game.js
    for (let r = 0; r < rows; r++) for (let c = 0; c < COLS; c++) {
      const x = GX + c * CELL, y = GY + r * CELL, v = grid[r] ? grid[r][c] : EMPTY;
      if (v === WALL) {
        ctx.fillStyle = '#245236'; rr(x + 3, y + 3, CELL - 6, CELL - 6, 10); ctx.fill();
        ctx.fillStyle = '#4caf6a'; ctx.beginPath(); ctx.arc(x + CELL / 2, y + CELL / 2 - 3, 15, 0, 7); ctx.fill();
        ctx.fillStyle = '#6fd08a'; ctx.beginPath(); ctx.arc(x + CELL / 2 - 5, y + CELL / 2 - 8, 6, 0, 7); ctx.fill();
        continue;
      }
      ctx.fillStyle = (r + c) % 2 ? '#3a7d52' : '#367549'; rr(x + 2, y + 2, CELL - 4, CELL - 4, 8); ctx.fill();
      if (v >= 0) person(x + CELL / 2, y + CELL / 2 + 2, PALETTE[v]);
    }
```

- `grid[r] ? grid[r][c] : EMPTY` … ゲーム開始前は `grid` が空の配列なので、そのときは空きマスとして扱います
- 木のマスは、濃い緑の台の上に丸い木を描いて `continue`（このマスの処理はここで終わり）します
- それ以外は市松模様のマスを描き、乗客（`v >= 0`）がいればマスの中心に `person()` を描きます
