## このステップのゴール

ゲームとして遊べるように、**勝ち負け** をつけます。すべてのバスを送り出したら **ステージクリア** で次のステージへ、ベンチが満席でもう誰も乗れなくなったら **ゲームオーバー** です。スコアと「STAGE 〇」「STAGE CLEAR!」の大きな文字（バナー）も出します。

あわせて、ステージの作り方を見直します。ステップ2のようにただかき混ぜるだけだと、どうやってもクリアできない盤面ができてしまうことがあるので、**コンピューターがためしに解いてみて、クリアできた盤面だけを採用する** ようにします。

## スコアとバナーの変数

`let level = 1, rows = 5;` から2行を **書きかえ** ます。

```js:game.js
  let level = 1, score = 0, rows = 5;
  let grid = [], bench = [], queue = [], bus = null, walkers = [];
  let banner = null;
```

`banner` は `{ text, t }` の形で、`t` は残り表示時間（秒）です。

## クリアできるか試す solvable()

`function pathOut(...)` の関数の **下**（`function generate` の上）に追加します。

```js:game.js
  // greedy solver used to make sure a generated stage is clearable
  function solvable(g0, buses) {
    const g = g0.map(r => r.slice());
    let b = [], bi = 0, filled = 0;
    const left = () => g.some(r => r.some(v => v >= 0));
    let guard = 0;
    while (bi < buses.length && guard++ < 999) {
      const col = buses[bi];
      // bench to bus
      for (let i = 0; i < b.length && filled < CAP; i++) if (b[i] === col) { b.splice(i, 1); i--; filled++; }
      if (filled === CAP) { bi++; filled = 0; continue; }
      if (!left()) return false;
      const reach = reachableMap(g);
      let pick = null, pickScore = Infinity;
      for (let r = 0; r < g.length; r++) for (let c = 0; c < COLS; c++) {
        if (!reach[r][c]) continue;
        const v = g[r][c];
        let s = v === col ? -1 : buses.indexOf(v, bi);
        if (s < 0 && v !== col) s = 999;
        if (s < pickScore) { pickScore = s; pick = [r, c]; }
      }
      if (!pick) return false;
      const v = g[pick[0]][pick[1]]; g[pick[0]][pick[1]] = EMPTY;
      if (v === col) filled++; else { if (b.length >= BENCH) return false; b.push(v); }
      if (b.length >= BENCH && filled < CAP && !b.includes(col)) {
        const reach2 = reachableMap(g);
        if (!g.some((row, r) => row.some((x, c) => x === col && reach2[r][c]))) return false;
      }
    }
    return bi >= buses.length;
  }
```

これは、盤面のコピー `g` を使って、**かんたんな作戦で最後まで遊んでみる** 関数です。

1. 今のバスの色 `col` の乗客がベンチ（ここでは配列 `b`）にいれば、先に乗せる。3人そろったら次のバスへ
2. 動ける乗客の中から、次のルールで1人選ぶ
   - バスと同じ色なら最優先（`-1`）
   - ちがう色なら、その色のバスが **何台目に来るか**（`buses.indexOf(v, bi)`）。早く来る色ほど優先
3. 選んだ乗客を、同じ色ならバスへ、ちがえばベンチへ。ベンチがあふれたら失敗
4. ベンチが満席で、今のバスの色の乗客がベンチにも動ける場所にもいなければ失敗

このように「その場で一番よさそうな手を選ぶ」作戦を **貪欲法（どんよくほう）** といいます。人間がもっと上手に遊べばクリアできる盤面でも、この作戦で失敗すれば捨ててしまいますが、そのかわり **採用した盤面は必ずクリアできる** ことが保証されます。`guard` は、万一のバグで無限ループにならないための回数制限です。

## 出口からの近さを考えて並べる generate()

`generate()` を **まるごと書きかえ** ます。

```js:game.js
  function generate(L) {
    rows = Math.min(4 + L, 8);
    const nColors = Math.min(2 + L, 7);
    for (let tries = 0; tries < 80; tries++) {
      const g = Array.from({ length: rows }, () => Array(COLS).fill(EMPTY));
      const nWalls = L < 2 ? 0 : Math.min(1 + Math.floor(L / 2), 6);
      for (let i = 0; i < nWalls; i++) g[1 + rnd(rows - 1)][rnd(COLS)] = WALL;
      // distance from top through non-wall cells
      const dist = g.map(row => row.map(() => Infinity)), q = [];
      for (let c = 0; c < COLS; c++) if (g[0][c] !== WALL) { dist[0][c] = 0; q.push([0, c]); }
      while (q.length) {
        const [r, c] = q.shift();
        for (const [dr, dc] of DIRS) {
          const nr = r + dr, nc = c + dc;
          if (nr < 0 || nr >= rows || nc < 0 || nc >= COLS || g[nr][nc] === WALL || dist[nr][nc] !== Infinity) continue;
          dist[nr][nc] = dist[r][c] + 1; q.push([nr, nc]);
        }
      }
      const cells = [];
      for (let r = 0; r < rows; r++) for (let c = 0; c < COLS; c++) {
        if (g[r][c] === WALL) continue;
        if (dist[r][c] === Infinity) { g[r][c] = WALL; continue; }
        cells.push({ r, c, d: dist[r][c] + Math.random() * 2.2 });
      }
      cells.sort((a, b) => a.d - b.d);
      const n = Math.floor(cells.length / 3) * 3;
      const busCount = n / 3;
      const buses = [];
      for (let i = 0; i < busCount; i++) buses.push(i % nColors);
      shuffle(buses);
      const seq = buses.flatMap(c => [c, c, c]);
      const win = Math.min(5 + L, 12);
      for (let i = 0; i < seq.length; i++) {
        const j = i + rnd(Math.min(win, seq.length - i));
        [seq[i], seq[j]] = [seq[j], seq[i]];
      }
      for (let i = 0; i < n; i++) g[cells[i].r][cells[i].c] = seq[i];
      if (solvable(g, buses)) return { g, buses };
    }
    // fallback: no mixing at all
    const g = Array.from({ length: rows }, () => Array(COLS).fill(EMPTY));
    const total = Math.floor(rows * COLS / 3) * 3, buses = [];
    for (let i = 0; i < total / 3; i++) buses.push(i % nColors);
    let k = 0;
    for (let r = 0; r < rows; r++) for (let c = 0; c < COLS; c++) if (k < total) { g[r][c] = buses[Math.floor(k / 3)]; k++; }
    return { g, buses };
  }
```

ステップ2から変わったところは3つです。

- **出口からの距離** … ステップ3と同じ幅優先探索で、木をよけて一番上の段から何歩で行けるか `dist` を求めます。木に囲まれて行けないマスは、乗客を置いても出られないので木にしてしまいます。そして、距離に少しランダムな値（0〜2.2）を足した順に `cells` を並べ替えます
- **バスの順番どおりに置く** … `seq` を全部かき混ぜるのではなく、「バスの順番どおりに乗客を並べた列」を、**近く（`win` 人ぶん）の相手とだけ** 入れかえてくずします。出口に近いマスほど、早く来るバスの色の乗客になりやすいので、ほどよく遊べる盤面になります。ステージが進むと `win` が大きくなり、入れかわりが激しく（むずかしく）なります
- **試して採用** … `solvable()` が true を返した盤面だけを返します。80回試してもダメなときは、まったく混ぜない（必ず解ける）盤面を返します

## スコアを足す addScore()

`updateNext()` の **下** に追加します。

```js:game.js
  function addScore(v, x, y) {
    score += v; $('score').textContent = score;
  }
```

`x`, `y` は「どこで点が入ったか」で、ステップ8で「+10」の文字をその場所に浮かべるのに使います。今は受け取るだけです。

`boarded()` を **書きかえ** て、乗客1人につき10点、満員で発車したらさらに30点入るようにします。

```js:game.js
  function boarded(b) {
```

## クリアとゲームオーバーの判定 checkEnd()

`autoBoard()` の **下** に追加し、`startGame()` を **書きかえ** ます。

```js:game.js
  function checkEnd() {
    if (state !== 'play' || walkers.length) return;
    if (!bus) {
      if (!queue.length) {
        state = 'clear';
        addScore(100 * level, W / 2, 120);
        banner = { text: 'STAGE CLEAR!', t: 1.6 };
        setTimeout(() => { if (state === 'clear') { level++; state = 'play'; startStage(); } }, 1600);
      }
      return;
    }
    if (bus.state !== 'wait') return;
    if (bench.some(s => s && !s.here)) return;
    const full = bench.every(s => s);
    if (!full || bus.filled >= CAP) return;
    if (bench.some(s => s.color === bus.color)) return;
    const reach = reachableMap(grid);
    const can = grid.some((row, r) => row.some((v, c) => v === bus.color && reach[r][c]));
    if (!can) gameOver();
  }

  function gameOver() {
    state = 'over';
    setTimeout(() => {
      ovTitle.textContent = 'ゲームオーバー';
      ovText.innerHTML = `ベンチが満席で、もう誰も乗れない…<br>ステージ <b class="hl">${level}</b> ・ スコア <b class="hl">${score}</b>`;
      startBtn.textContent = 'もう一度';
      overlay.classList.remove('hide');
    }, 700);
  }

  function startGame() {
    overlay.classList.add('hide');
    level = 1; score = 0; $('score').textContent = 0;
    state = 'play';
    startStage();
  }
```

`checkEnd()` は毎フレーム呼んで、勝ち負けを調べます。**歩いている乗客がいるあいだは判定しない** のがポイントです。歩き終わるまでは、バスに座ったりベンチに着いたりして状況が変わるからです。

- **クリア** … バスがいなくて（最後のバスが画面の外へ出た）、`queue` も空なら、ステージクリア。ボーナス `100 × ステージ番号` 点を足し、1.6秒後に次のステージを始めます。`setTimeout(関数, ミリ秒)` は「指定した時間のあとで関数を1回呼ぶ」命令です
- **ゲームオーバー** … バスが停車中で、ベンチが全部うまっていて（着いていない予約席もない）、まだ満員でなく、ベンチにも **動ける乗客** にもバスと同じ色がいなければ、もう何をしても進めません

`gameOver()` は少し間をおいて（0.7秒）から、オーバーレイの文字とボタンを「ゲームオーバー」「もう一度」に書きかえて表示します。スタートボタンは同じ `startGame()` を呼ぶので、そのまま **リトライ** になります。`startGame()` ではステージ番号とスコアを最初に戻します。

`startStage()` の `$('stage-no').textContent = level;` の **下** に、バナーを出す1行を足します。

```js:game.js
    banner = { text: 'STAGE ' + level, t: 1.2 };
```

## 毎フレームの更新に組みこむ

`update()` の **先頭** に、バナーの残り時間を減らす1行を足します。

```js:game.js
    if (banner) { banner.t -= dt; if (banner.t <= 0) banner = null; }
```

`update()` の **最後**（`if (bus) { ... }` のあと）に、判定を呼ぶ1行を足します。

```js:game.js
    checkEnd();
```

## バナーを描く

`draw()` の最後の `walkers.forEach(...)` の行の **下** に追加します。

```js:game.js
    ctx.font = 'bold 16px system-ui, sans-serif'; ctx.textAlign = 'center';
    if (banner) {
      ctx.globalAlpha = Math.min(1, banner.t * 2);
      ctx.fillStyle = 'rgba(0,0,0,.55)'; ctx.fillRect(0, GY + rows * CELL / 2 - 30, W, 60);
      ctx.fillStyle = '#ffd84a'; ctx.font = 'bold 30px system-ui, sans-serif';
      ctx.fillText(banner.text, W / 2, GY + rows * CELL / 2 + 1);
      ctx.globalAlpha = 1;
    }
```

広場のまん中に黒い帯を敷いて、黄色い大きな文字を描きます。`Math.min(1, banner.t * 2)` で、残り0.5秒を切ると少しずつ透明になって消えていきます。最初の1行で文字の大きさと中央ぞろえを決めているのは、ステップ8で「+10」の文字をここに描くためです。
