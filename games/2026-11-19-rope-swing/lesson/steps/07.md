## このステップのゴール

ゲームの動きはもう完成しています。このステップでは「手ざわり」を良くする演出を足します。

- ロープをかける・はなす・★を取る・落ちるときに **効果音** を鳴らす
- ★を取ったときに、小さな四角が飛びちる **パーティクル** を出す
- プレイヤーのうしろに、白くうすい **軌跡** を残す

こうした演出は、まとめて「**ジュース**（ゲームフィール）」と呼ばれます。ルールは同じでも、あるとないとで遊んだときの気持ちよさが大きく変わります。

## 変数を足す

`let player, anchors, stars, camX, ...` の行の `stars,` のうしろに `particles,` を足して、次のように **書きかえます**。

```js:game.js
  let player, anchors, stars, particles, camX, rope, maxX, starCount, nextAnchorX, lastT;
```

`newGame()` の中を2か所 **書きかえます**。`anchors = []; stars = [];` の行は次のように。

```js:game.js
    anchors = []; stars = []; particles = [];
```

`player = { ... };` の行は、最後に `trail: []` を足して次のように。

```js:game.js
    player = { x: 40, y: H * 0.3, vx: 300, vy: -260, trail: [] };
```

`trail` は、プレイヤーが通ってきた位置を覚えておく配列です。

## 効果音

`// ---------- layout ----------` の **上**（`let player, ...` の行と空行のあと）に追加します。

```js:game.js
  // ---------- audio ----------
  let actx = null;
  function beep(freq, dur, type, vol, slide) {
    try {
      if (!actx) actx = new (window.AudioContext || window.webkitAudioContext)();
      if (actx.state === 'suspended') actx.resume();
      const o = actx.createOscillator(), g = actx.createGain();
      o.type = type || 'sine';
      o.frequency.setValueAtTime(freq, actx.currentTime);
      if (slide) o.frequency.exponentialRampToValueAtTime(slide, actx.currentTime + dur);
      g.gain.setValueAtTime(vol || 0.12, actx.currentTime);
      g.gain.exponentialRampToValueAtTime(0.001, actx.currentTime + dur);
      o.connect(g); g.connect(actx.destination);
      o.start(); o.stop(actx.currentTime + dur);
    } catch (e) { /* ignore */ }
  }

```

**Web Audio API** を使うと、音声ファイルなしで音を作れます。

- **オシレーター**（`createOscillator`）は、決まった高さ（`frequency`、Hz）と音色（`type`: `'sine'` やわらかい・`'square'` ピコピコ・`'triangle'` まるい・`'sawtooth'` ざらざら）の音を出す装置です
- `slide` を渡すと、`dur` 秒かけて音の高さを `slide` まで変えます。高くすれば「ピュイッ」、低くすれば「ヒュー」という音になります
- **ゲイン**（`createGain`）は音量のつまみです。`exponentialRampToValueAtTime` で `dur` 秒かけてほぼ 0 まで下げると、「ポン」と自然に消える音になります
- オシレーター → ゲイン → スピーカー（`actx.destination`）の順に `connect` でつなぎ、`start()` で鳴らして `stop()` で止めます

ブラウザは「ユーザーが画面を操作するまで音を出さない」決まりがあるので、AudioContext は最初に `beep` を呼んだとき（＝ロープをかけたとき）に作ります。`suspended`（一時停止）になっていたら `resume()` で再開します。音が出せない環境でもゲームが止まらないように、全体を `try { ... } catch` で囲んでいます。

それでは、効果音を鳴らす場所に `beep` を足していきます。

`attach()` の中の `rope = { a: bestA, ... };` の行の **下** に追加します。

```js:game.js
      beep(520, 0.08, 'triangle', 0.1, 760);
```

`release()` の中の `player.vx *= 1.04; player.vy *= 1.04;` の行の **下** に追加します。

```js:game.js
      beep(380, 0.1, 'sine', 0.07, 240);
```

`die()` の中の `running = false;` の行の **下** に追加します。

```js:game.js
    beep(300, 0.5, 'sawtooth', 0.1, 60);
```

ロープをかけると高く上がる音、はなすと下がる音、落ちたら低く長いざらざらした音になります。

## パーティクル

`release()` の閉じかっこ `}` の **下**、`function die() {` の **上** に追加します。

```js:game.js

  function burst(x, y, color, n) {
    for (let i = 0; i < n; i++) {
      const a = rand(0, 6.28), s = rand(60, 220);
      particles.push({ x, y, vx: Math.cos(a) * s, vy: Math.sin(a) * s, life: rand(0.4, 0.8), color });
    }
  }
```

`die()` の閉じかっこ `}` の **下**、`function step(dt, time) {` の **上** に追加します。

```js:game.js

  function stepParticles(dt) {
    for (const p of particles) { p.x += p.vx * dt; p.y += p.vy * dt; p.vy += 500 * dt; p.life -= dt; }
    particles = particles.filter(p => p.life > 0);
  }
```

**パーティクル** は、小さな粒をたくさん飛ばす演出です。

- `burst()` は、ランダムな向き `a`（0〜360度）とランダムな速さ `s` で、粒を `n` 個作ります。向きと速さから速度を作るのは、ステップ6の星形と同じ cos・sin の計算です
- `stepParticles()` は、粒を速度ぶん動かし、弱い重力（500）で少しずつ落とし、寿命 `life` を減らします。寿命がなくなった粒は `filter` で捨てます

プレイヤーと同じ「速度を足して位置を動かす」しくみを、粒ごとに小さく回しているだけです。

## step() に軌跡とパーティクルを足す

`step()` の中の、天井の行 `if (p.y < -H * 0.6) { ... }` の **下** に追加します。

```js:game.js
    p.trail.push({ x: p.x, y: p.y }); if (p.trail.length > 18) p.trail.shift();
```

今の位置を `trail` の最後に足し、18個を超えたら `shift()` でいちばん古いものを捨てます。いつも「最近の18個の位置」が残ります。

★を取るところを、次のように **書きかえます**（`if (!s.got && ...) { ... }` の中に2行足し、for 文のあとに `stepParticles(dt);` を足します）。

```js:game.js
    for (const s of stars) {
      s.t += dt;
      if (!s.got && Math.hypot(s.x - p.x, s.y - p.y) < 24) {
        s.got = true; starCount++;
        burst(s.x, s.y, '#ffcf4a', 14);
        beep(880, 0.12, 'square', 0.06, 1320);
      }
    }
    stepParticles(dt);
```

## draw() に軌跡とパーティクルを描く

`draw()` の中の `// rope` の `if (rope) { ... }` の閉じかっこ `}` の **下**、`// player` の **上** に追加します。

```js:game.js

    // trail
    const tr = player.trail;
    for (let i = 0; i < tr.length; i++) {
      ctx.fillStyle = 'rgba(255,255,255,' + (i / tr.length * 0.35) + ')';
      ctx.beginPath(); ctx.arc(tr[i].x, tr[i].y, 3 + i / tr.length * 7, 0, 7); ctx.fill();
    }
```

配列の前のほう（古い位置）ほど小さく・うすく、うしろ（新しい位置）ほど大きく・こく描きます。`i / tr.length` が 0〜1 の割合になるので、それを透明度と大きさにかけています。

プレイヤーを描く `if (running) { ... }` の閉じかっこ `}` の **下**、`ctx.restore();` の **上** に追加します。

```js:game.js

    // particles
    for (const p of particles) {
      ctx.globalAlpha = Math.max(0, p.life * 1.5);
      ctx.fillStyle = p.color; ctx.fillRect(p.x - 3, p.y - 3, 6, 6);
    }
    ctx.globalAlpha = 1;
```

`ctx.globalAlpha` は、これから描くものすべての不透明度（0 で透明、1 でふつう）です。寿命が少なくなるほど透明にして、ふっと消えるようにします。最後に必ず `1` に戻しておかないと、そのあとに描くトゲまで透けてしまうので注意しましょう。
