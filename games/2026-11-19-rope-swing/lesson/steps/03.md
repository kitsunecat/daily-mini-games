## このステップのゴール

ロープをかけるための **フック**（白い輪っか）を、空中に並べます。フックはプレイヤーが進むにつれて **先へ先へと自動で作られ**、うしろに置いていったものは **片づけられる** ので、どこまで行っても終わらないステージになります。

ついでに、背景に夕日と、ゆっくり流れる丘を描いて、奥行きを出します。

## 変数を足す

`let player, camX, maxX, lastT;` の行を、次のように **書きかえます**。

```js:game.js
  let player, anchors, camX, maxX, nextAnchorX, lastT;
```

- `anchors` はフックの配列です（英語でフックや支点を anchor と呼びます）
- `nextAnchorX` は「次のフックを置く x 座標」です

## rand() と addAnchor() を追加する

`// ---------- world ----------` の **下**、`function newGame() {` の **上** に追加します。

```js:game.js
  function rand(a, b) { return a + Math.random() * (b - a); }

  function addAnchor() {
    const dist = nextAnchorX / 10;
    const gap = Math.min(rand(120, 165) + dist * 0.12, 230);
    const x = nextAnchorX;
    const y = rand(H * 0.12, H * 0.42);
    anchors.push({ x, y });
    nextAnchorX += gap;
  }

```

- `rand(a, b)` は「a 以上 b 未満のランダムな小数」を返す小さな関数です。`Math.random()` は 0〜1 の数を返すので、それを `b - a` 倍して `a` を足します
- `addAnchor()` は、`nextAnchorX` の位置にフックを1つ置いて、`nextAnchorX` を次の位置まで進めます
- フックの高さ `y` は、画面の上から 12%〜42% の間でランダムです。上のほうにあるので、プレイヤーはぶら下がる形になります
- フックどうしの間隔 `gap` は 120〜165 のランダムに、**進んだ距離 × 0.12** を足しています。遠くへ行くほど間隔が広がって難しくなり、`Math.min(..., 230)` で 230 を超えないようにしています。こういう「だんだん難しくなる」しかけを **難易度カーブ** と呼びます
- `{ x, y }` は `{ x: x, y: y }` の省略形です

## newGame() でフックを用意する

`newGame()` の中の `layout();` の行の **下** に追加します。

```js:game.js
    anchors = [];
    nextAnchorX = 150;
    for (let i = 0; i < 8; i++) addAnchor();
```

ゲーム開始時に、x = 150 から8個のフックを並べておきます。`layout()` のあとに置くのは、フックの高さに画面の縦の長さ `H` を使うからです。

## step() でフックを作り足し、片づける

`step()` の中の `camX += ...` の行の **下** に追加します。

```js:game.js

    while (nextAnchorX < camX + VIEW_W * 2.5) addAnchor();
    anchors = anchors.filter(a => a.x > camX - 300);
```

- `while` の行は、「次のフックの位置が、画面の右端より 1.5 画面ぶん先」になるまでフックを作り足します。プレイヤーが進むと camX が増えるので、そのたびに新しいフックが追加されます
- `filter` は、条件に合うものだけを残した新しい配列を作るメソッドです。画面の左端より 300 以上うしろにあるフックは捨てます。捨てないと配列がどんどん大きくなり、だんだん重くなってしまいます

この「**先のぶんだけ作り、通りすぎたものは捨てる**」というやり方で、メモリをほとんど使わずに無限のステージが作れます。

## draw() に背景とフックを描く

`draw()` の中の `if (!player) return;` の行の **下** に追加します。

```js:game.js

    // sun
    ctx.fillStyle = 'rgba(255,220,150,.55)';
    ctx.beginPath(); ctx.arc(270, H * 0.62, 50, 0, 7); ctx.fill();

    // hills parallax
    ctx.fillStyle = '#2b4a6f';
    const hx = camX * 0.3;
    ctx.beginPath(); ctx.moveTo(0, H);
    for (let x = -40; x <= VIEW_W + 40; x += 20) {
      const wx = x + hx;
      ctx.lineTo(x, H - 70 - Math.sin(wx * 0.012) * 30 - Math.sin(wx * 0.031) * 14);
    }
    ctx.lineTo(VIEW_W, H); ctx.fill();
```

### パララックス（視差スクロール）

丘は translate の **外**（まだ `ctx.save()` の前）で描いていて、その代わりに `hx = camX * 0.3` だけずらしています。カメラが 100 動いても丘は 30 しか動かないので、遠くにあるように見えます。電車の窓から見ると、近くの電柱は速く、遠くの山はゆっくり流れるのと同じしかけで、**パララックス** と呼びます。

丘の形は、周期のちがう2つの `Math.sin` を足して作っています。sin の波を重ねるだけで、自然な凸凹の稜線になります。`moveTo(0, H)` で左下から始め、稜線をなぞって `lineTo(VIEW_W, H)` で右下に戻って塗ると、丘の形が塗りつぶされます。

つぎに、距離の目印の for 文の閉じかっこ `}` の **下**、`// player` の **上** に追加します。

```js:game.js

    // anchors
    for (const a of anchors) {
      ctx.lineWidth = 4;
      ctx.strokeStyle = '#e8f1ff';
      ctx.beginPath(); ctx.arc(a.x, a.y, 9, 0, 7); ctx.stroke();
      ctx.fillStyle = '#16263f'; ctx.beginPath(); ctx.arc(a.x, a.y, 4, 0, 7); ctx.fill();
    }
```

こちらは translate の **中** なので、世界の座標 `a.x` のまま描けばカメラに合わせて動きます。`stroke()` で太い白い輪を、`fill()` で中に小さな紺色の点を描いて、輪っかに見せています。

> [!CHECK] 動作チェック
> - スタートすると、画面の上のほうに白い輪っか（フック）がいくつも並んでいる
> - 画面の右下に大きな夕日がうっすらと見え、紺色の丘の稜線がある
> - キャラクターが右へ進むと、フックは画面と同じ速さで、丘はゆっくり流れる
> - まだロープはかけられないので、そのまま落ちてゲームオーバーになる
