## このステップのゴール

プレイヤー（赤い丸いキャラクター）を画面に出し、**重力** で放物線をえがいて飛ばします。プレイヤーが右へ進むと、**カメラ** が追いかけて画面がスクロールします。下のトゲに落ちたらゲームオーバーです。

まだロープはないので、スタートするとそのまま飛んで落ちるだけですが、このゲームの「動き」の基本がすべてここに入っています。

## 定数と変数を足す

`const VIEW_W = 360;` の **下** に追加します。

```js:game.js
  const G = 980;
```

`let running = false;` の **下** に追加します。

```js:game.js
  let player, camX, maxX, lastT;
```

- `G` は **重力加速度** です。「1秒ごとに下向きの速さが 980 ずつ増える」という意味です（単位は仮想座標/秒²）
- `player` はプレイヤーの位置と速度、`camX` はカメラの位置（画面の左端が世界のどこか）、`maxX` はいちばん遠くまで進んだ x 座標、`lastT` は前のフレームの時刻です

## newGame() を書きかえる

`function newGame() { ... }` を、次のように **まるごと書きかえます**。

```js:game.js
  function newGame() {
    layout();
    player = { x: 40, y: H * 0.3, vx: 300, vy: -260 };
    camX = 0; maxX = 0;
    running = true;
    overlay.classList.add('hidden');
    updateHud();
    lastT = performance.now();
    requestAnimationFrame(loop);
  }
```

プレイヤーは位置（`x`・`y`）と **速度**（`vx`・`vy`）を持つオブジェクトです。速度は「1秒あたりにどれだけ動くか」で、`vx: 300` は右へ秒速300、`vy: -260` は上へ秒速260 です。Canvas は **下に行くほど y が大きい** ので、上向きはマイナスになります。最初に右上へ投げ出すことで、ゲーム開始の瞬間に勢いがつきます。

最後の `requestAnimationFrame(loop)` は「次に画面を描きかえるタイミングで loop を呼んで」とブラウザに頼む命令です。loop の中でもう一度頼むので、1秒に約60回 loop がくり返されます（loop は下で作ります）。

## updateHud()・die()・step() を追加する

`newGame()` の閉じかっこ `}` の **下**（`// ---------- render ----------` の **上**）に追加します。

```js:game.js

  function updateHud() {
    scoreEl.textContent = Math.floor(maxX / 10);
  }

  function die() {
    running = false;
    ovTitle.textContent = 'ゲームオーバー';
    ovText.innerHTML = '距離 <b class="hl">' + Math.floor(maxX / 10) + 'm</b>';
    startBtn.textContent = 'もう一度';
    overlay.classList.remove('hidden');
  }

  function step(dt, time) {
    const p = player;
    p.vy += G * dt;
    p.vx *= (1 - 0.05 * dt);
    p.x += p.vx * dt; p.y += p.vy * dt;
    const sp = Math.hypot(p.vx, p.vy);
    if (sp > 950) { p.vx *= 950 / sp; p.vy *= 950 / sp; }
    if (p.y < -H * 0.6) { p.y = -H * 0.6; if (p.vy < 0) p.vy = 0; }

    if (p.x > maxX) maxX = p.x;
    camX += (p.x - VIEW_W * 0.35 - camX) * Math.min(1, dt * 5);

    updateHud();
    if (p.y > H - 26) die();
  }
```

### step(dt) … 時間を dt 秒すすめる

`step()` がこのゲームの物理です。`dt` は「前のフレームから何秒たったか」（約 0.016 秒）です。

1. `p.vy += G * dt` … 重力で、下向きの速さを少し増やす
2. `p.vx *= (1 - 0.05 * dt)` … 空気の抵抗で、横の速さをほんの少し減らす
3. `p.x += p.vx * dt` … 速度ぶん位置を動かす

「速度に重力を足す → 位置に速度を足す」を毎フレームくり返すだけで、ボールを投げたときのような **放物線** になります。dt をかけておくと、60fps の画面でも 120fps の画面でも同じ速さで動きます。

そのあと、2つの安全装置を入れています。

- `Math.hypot(vx, vy)` は速度の大きさ（ベクトルの長さ）です。950 を超えたら、向きはそのままで大きさだけ 950 に縮めます。速すぎて操作できなくなるのを防ぎます
- 画面のずっと上（`-H * 0.6`）より上には行けない「見えない天井」をつけます

### カメラが追いかける

`maxX` はいちばん遠くまで進んだ位置で、これを 10 で割ったものを「距離（m）」にします。

`camX` の行は、カメラを「プレイヤーが画面の左から 35% の位置に来る場所」に近づける式です。目標との差に `dt * 5` をかけた分だけ近づけるので、毎フレーム少しずつ追いつく、ふんわりとしたカメラになります。いきなり目標に合わせるとカクカクして酔いやすいので、ゲームではよく使われる書き方です。

### die() … ゲームオーバー

プレイヤーが下のトゲの高さ（`H - 26`）まで落ちたら `die()` を呼びます。`running = false` にして、オーバーレイの文字を書きかえて表示します。「もう一度」ボタンを押すと同じ `newGame()` が呼ばれ、プレイヤーとカメラが最初の位置に戻るので、そのままリトライになります。

## draw() を書きかえる

`function draw() { ... }` を **まるごと書きかえます**。

```js:game.js
  function draw() {
    ctx.setTransform(dpr * scale, 0, 0, dpr * scale, 0, 0);
    const sky = ctx.createLinearGradient(0, 0, 0, H);
    sky.addColorStop(0, '#1d3b6b'); sky.addColorStop(0.6, '#3f6fa8'); sky.addColorStop(1, '#f29e6d');
    ctx.fillStyle = sky; ctx.fillRect(0, 0, VIEW_W, H);
    if (!player) return;

    ctx.save();
    ctx.translate(-camX, 0);

    // distance markers
    ctx.fillStyle = 'rgba(255,255,255,.25)'; ctx.font = '11px sans-serif'; ctx.textAlign = 'center';
    const m0 = Math.floor(camX / 500) * 500;
    for (let mx = m0; mx < camX + VIEW_W + 500; mx += 500) {
      if (mx <= 0) continue;
      ctx.fillRect(mx - 1, H - 60, 2, 30);
      ctx.fillText((mx / 10) + 'm', mx, H - 64);
    }

    // player
    if (running) {
      ctx.save(); ctx.translate(player.x, player.y);
      ctx.rotate(Math.atan2(player.vy, player.vx) * 0.3);
      ctx.fillStyle = '#ff6b6b'; ctx.beginPath(); ctx.arc(0, 0, 12, 0, 7); ctx.fill();
      ctx.fillStyle = '#fff'; ctx.beginPath(); ctx.arc(4, -3, 4, 0, 7); ctx.fill();
      ctx.fillStyle = '#222'; ctx.beginPath(); ctx.arc(5.5, -3, 2, 0, 7); ctx.fill();
      ctx.fillStyle = '#ffcf4a'; ctx.fillRect(-12, -6, 6, 3);
      ctx.restore();
    }
    ctx.restore();

    // spikes
    ctx.fillStyle = '#3a1020'; ctx.fillRect(0, H - 14, VIEW_W, 14);
    ctx.fillStyle = '#e74c3c';
    const off = -(camX % 20);
    ctx.beginPath();
    for (let x = off - 20; x < VIEW_W + 20; x += 20) {
      ctx.moveTo(x, H - 12); ctx.lineTo(x + 10, H - 30); ctx.lineTo(x + 20, H - 12);
    }
    ctx.fill();
  }
```

### translate でカメラを作る

`ctx.save()` から `ctx.restore()` の間では、`ctx.translate(-camX, 0)` で **描く場所全体を左に camX ずらして** います。こうすると、プレイヤーや距離の目印は「世界の座標」のまま描くだけで、カメラが右に動いたように見えます。`save()` / `restore()` は、translate などの設定を一時的に変えて、あとで元に戻すための命令です。

空とトゲは translate の **外** で描いているので、カメラが動いても画面に固定されたままです。トゲは `camX % 20`（camX を 20 で割った余り）だけずらして描くことで、少ない数のトゲでも、流れていくように見せています。

### 距離の目印

`500` ごと（＝50m ごと）に細い棒と「50m」「100m」の文字を描きます。画面に映る範囲（`camX` から `camX + VIEW_W` まで）の分だけ for で回すので、何万メートル進んでも描く数は変わりません。

### プレイヤーの描き方

`ctx.translate(player.x, player.y)` でプレイヤーの位置を原点にしてから、`ctx.rotate()` で進む向きに少し傾けます。`Math.atan2(vy, vx)` は速度の向きを角度（ラジアン）で返す関数で、0.3 倍して少しだけ傾けています。原点のまわりに体（赤い円）・目（白と黒の円）・黄色いハチマキを描けば、あとは translate と rotate が位置と向きを合わせてくれます。

`ctx.arc(x, y, 半径, 0, 7)` の 7 は、本来 `Math.PI * 2`（約 6.28）と書くところを短く書いたものです。一周より少し大きくても、ちゃんと円になります。

## loop() を追加する

`draw()` の閉じかっこ `}` の **下**、`// ---------- input ----------` の **上** に追加します。

```js:game.js

  function loop(now) {
    if (!running) return;
    const dt = Math.min(0.033, (now - lastT) / 1000);
    lastT = now;
    // substeps for stable rope
    for (let i = 0; i < 3; i++) { step(dt / 3, now / 1000); if (!running) break; }
    if (running) { draw(); requestAnimationFrame(loop); }
  }
```

`now` はブラウザがくれるミリ秒単位の時刻です。前回との差を 1000 で割って秒にしたものが dt です。タブを切りかえて戻ってきたときなどに dt が大きくなりすぎると、プレイヤーが一気にワープしてしまうので、`Math.min(0.033, ...)` で最大 0.033 秒に抑えています。

さらに、1フレームの dt を **3つに分けて** `step()` を3回呼んでいます（サブステップ）。細かく刻むほど計算が正確になり、ステップ4で作るロープの動きが安定します。`now / 1000` は秒単位の時刻で、ステップ5の「動くフック」で使います。

> [!CHECK] 動作チェック
> - スタートすると、赤いキャラクターが右上へ飛び出し、放物線をえがいて落ちていく
> - キャラクターが右へ進むと画面がスクロールし、下のトゲと距離の目印が左へ流れる
> - 画面上の DIST の数字が、進んだ分だけ増える
> - トゲまで落ちると「ゲームオーバー」と距離が表示され、「もう一度」で最初からやり直せる
