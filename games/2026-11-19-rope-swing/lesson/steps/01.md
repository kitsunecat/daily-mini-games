## このステップのゴール

3つのファイルを用意して、ゲーム画面の土台を作ります。上に「DIST・★・BEST」の表示、まん中にゲームを描く **Canvas**（キャンバス）とその上に重ねるタイトル画面（オーバーレイ）、下にひとことヒントを置きます。Canvas には、まず夕焼けの空だけを描きます。

完成すると、こんなゲームになります。

- 画面を **押している間** だけ、近くのフックにロープをかけてブランコのように振れる
- **はなす** と、そのときの勢いのまま空へ飛び出す。前へ振り上がったところではなすと遠くまで飛べる
- フックは右へ右へと終わりなく続き、進んだ距離と途中で取った **★** がスコアになる
- 下のトゲに落ちたらゲームオーバー。ハイスコアはブラウザに保存される

## game.js

JavaScript はまず「画面の大きさに合わせて Canvas を用意し、空を描く」ところまでを書きます。

```js:game.js
(() => {
  'use strict';
  const VIEW_W = 360;

  const cv = document.getElementById('cv');
  const ctx = cv.getContext('2d');
  const stage = document.getElementById('stage');
  const overlay = document.getElementById('overlay');
  const ovTitle = document.getElementById('ov-title');
  const ovText = document.getElementById('ov-text');
  const startBtn = document.getElementById('start');
  const scoreEl = document.getElementById('score');
  const starsEl = document.getElementById('stars');
  const bestEl = document.getElementById('best');

  let scale = 1, H = 640, dpr = 1;
  let running = false;

  // ---------- layout ----------
  function layout() {
    const r = stage.getBoundingClientRect();
    dpr = Math.min(window.devicePixelRatio || 1, 2);
    cv.width = Math.max(1, Math.round(r.width * dpr));
    cv.height = Math.max(1, Math.round(r.height * dpr));
    scale = r.width / VIEW_W;
    H = r.height / scale;
    if (!running) draw();
  }

  // ---------- world ----------
  function newGame() {
    layout();
    running = true;
    overlay.classList.add('hidden');
  }

  // ---------- render ----------
  function draw() {
    ctx.setTransform(dpr * scale, 0, 0, dpr * scale, 0, 0);
    const sky = ctx.createLinearGradient(0, 0, 0, H);
    sky.addColorStop(0, '#1d3b6b'); sky.addColorStop(0.6, '#3f6fa8'); sky.addColorStop(1, '#f29e6d');
    ctx.fillStyle = sky; ctx.fillRect(0, 0, VIEW_W, H);
  }

  // ---------- input ----------
  startBtn.addEventListener('click', (e) => { e.stopPropagation(); newGame(); });
  window.addEventListener('resize', layout);
  layout();
})();
```

### 全体を (() => { ... })(); で囲む

ファイル全体を「すぐ実行される関数」で囲むと、中で作った変数がページ全体（グローバル）に漏れません。`'use strict';` は、うっかりミスをエラーとして教えてくれるモードです。

### 仮想の横幅 VIEW_W = 360

スマホとパソコンでは画面の大きさがまったく違います。そこでこのゲームでは「**画面の横幅はいつも 360**」と決めて、その座標で考えます。これを **仮想座標** と呼びます。実際の画面が 390px でも 520px でも、横幅 360 の世界を拡大・縮小して映すだけなので、どの画面でも同じ見た目・同じ難しさになります。

縦の長さ `H` は画面の縦横の比率で変わります。横長の画面なら H は小さく、縦長のスマホなら H は大きくなります。

### layout() … 画面の大きさから Canvas を準備する

1. `stage.getBoundingClientRect()` で、ステージの実際の大きさ（CSS ピクセル）を測ります
2. `devicePixelRatio`（dpr）は、高精細な画面で「CSS の 1px が実際は何ドットか」を表す数です。Canvas の中身のピクセル数（`cv.width`・`cv.height`）を dpr 倍にすると、ぼやけずにくっきり描けます。大きすぎると重くなるので 2 で頭打ちにしています
3. `scale = r.width / VIEW_W` が「仮想座標の 1 は、実際の何 CSS ピクセルか」です。`H = r.height / scale` で、仮想座標での縦の長さが分かります
4. ゲーム中でなければ（`!running`）、すぐ `draw()` で描き直します

### draw() … 空を描く

`ctx.setTransform(dpr * scale, 0, 0, dpr * scale, 0, 0)` は「これから描くものを全部 `dpr * scale` 倍する」という設定です。これを最初にしておけば、あとは仮想座標（横 0〜360、縦 0〜H）のまま描くだけで、画面いっぱいにぴったり映ります。

`createLinearGradient(0, 0, 0, H)` は上から下へのグラデーションを作ります。`addColorStop(位置, 色)` で、0（上）は濃い青、0.6 で明るい青、1（下）で夕焼けのオレンジにしています。`fillRect(0, 0, VIEW_W, H)` で画面全体を塗ります。

### newGame() とイベント

スタートボタンが押されたら `newGame()` を呼び、`running = true` にしてオーバーレイに `hidden` クラスをつけて隠します。`e.stopPropagation()` は、ボタンのクリックが下の要素に伝わらないようにするおまじないです（あとで画面の長押しを受け取るようになったとき、スタートと同時にロープが出ないようにするためです）。ウィンドウの大きさが変わったら `layout()` をもう一度呼びます。
