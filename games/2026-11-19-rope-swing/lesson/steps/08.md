## このステップのゴール

最後の仕上げです。

- 落ちたら、キャラクターが赤い粒になって飛びちり、少し間をおいてからゲームオーバー画面を出す
- **ハイスコア** をブラウザに保存して、BEST に表示する。記録を更新したら「ハイスコア更新！」と出す

これで完成品と同じゲームになります。

## ハイスコアを読みこむ

`'use strict';` の行の **下**（`const VIEW_W = 360;` の **上**）に追加します。

```js:game.js
  const BEST_KEY = 'dmg-rope-swing-best';
```

`const bestEl = document.getElementById('best');` の行の **下** に追加します（前に空行を入れます）。

```js:game.js

  let best = 0;
  try { best = parseInt(localStorage.getItem(BEST_KEY) || '0', 10) || 0; } catch (e) { best = 0; }
  bestEl.textContent = best;
```

**localStorage** は、ブラウザにちょっとしたデータを保存しておける場所です。ページを閉じても消えません。`getItem(キー)` で読み、`setItem(キー, 文字列)` で書きます。

- 保存できるのは文字列だけなので、`parseInt(文字列, 10)` で10進数の数に直します
- まだ保存されていなければ `null` が返るので、`|| '0'` で `'0'` にしてから読みます。うしろの `|| 0` は、万一おかしな文字列が入っていて `NaN`（数ではない）になったときの保険です
- プライベートブラウズなどで localStorage が使えないとエラーになることがあるので、`try { ... } catch` で囲んでいます

キーの名前（`'dmg-rope-swing-best'`）は、同じサイトのほかのゲームの保存データとぶつからないように、ゲームごとに変えておきます。

## 変数を足す

`let player, ...` の行の最後に `deadTimer` を足して、次のように **書きかえます**。

```js:game.js
  let player, anchors, stars, particles, camX, rope, maxX, starCount, nextAnchorX, lastT, deadTimer;
```

`newGame()` の中の `rope = null; camX = 0; maxX = 0; starCount = 0;` の行を、次のように **書きかえます**。

```js:game.js
    rope = null; camX = 0; maxX = 0; starCount = 0; deadTimer = 0;
```

## die() を仕上げる

`function die() { ... }` を **まるごと書きかえます**。

```js:game.js
  function die() {
    running = false;
    rope = null;
    burst(player.x, player.y, '#ff6b6b', 30);
    beep(300, 0.5, 'sawtooth', 0.1, 60);
    const s = score();
    let msg = '';
    if (s > best) {
      best = s; msg = '<b class="hl">ハイスコア更新！</b><br>';
      try { localStorage.setItem(BEST_KEY, String(best)); } catch (e) { /* ignore */ }
    }
    bestEl.textContent = best;
    deadTimer = 0.7;
    const t0 = performance.now();
    const fade = (now) => {
      const dt = Math.min(0.033, (now - t0) / 1000 - (0.7 - deadTimer));
      deadTimer -= dt; stepParticles(dt); draw();
      if (deadTimer > 0) requestAnimationFrame(fade);
      else {
        ovTitle.textContent = 'ゲームオーバー';
        ovText.innerHTML = msg + '距離 <b class="hl">' + Math.floor(maxX / 10) + 'm</b> ／ ★ <b class="hl">' + starCount +
          '</b><br>スコア <b class="hl">' + s + '</b>（ベスト ' + best + '）';
        startBtn.textContent = 'もう一度';
        overlay.classList.remove('hidden');
      }
    };
    requestAnimationFrame(fade);
  }
```

### 落ちた演出

`running = false` にするとメインの `loop` は止まります。そのかわりに、`fade` という小さなループを `requestAnimationFrame` で回して、**0.7秒だけ** パーティクルを動かして描き続けます。

- `rope = null` でロープを消し、`burst()` でキャラクターの位置から赤い粒を30個飛ばします
- `draw()` は `running` が false のときはキャラクターを描かないので、キャラクターがはじけて粒になったように見えます
- `deadTimer` は残り時間です。毎フレーム `dt` だけ減らし、0 になったらゲームオーバー画面を出します
- `fade` の `dt` の式は少しややこしいですが、「始まってからの経過時間 − すでに進めた時間」で、前のフレームからの時間を求めています。loop と同じように 0.033 秒で頭打ちにしています

すぐに画面が切りかわるより、一瞬「あっ、落ちた」と分かる間があると、何が起きたか理解しやすくなります。

### ハイスコアの保存

スコアを `s` に入れ、`best` より大きければ `best` を書きかえて `localStorage.setItem` で保存します。`String(best)` で文字列にしてから保存します。そのときだけ `msg` に「ハイスコア更新！」を入れて、ゲームオーバー画面の先頭に出します。

`innerHTML` は HTML として文字を入れるので、`<br>` や `<b>` が使えます。ここで入れているのは自分で計算した数字だけなので安全ですが、ユーザーが入力した文字をそのまま `innerHTML` に入れるのは危険なので避けましょう。

「もう一度」ボタン・Space / Enter で呼ばれるのはこれまでどおり `newGame()` です。newGame はプレイヤー・フック・★・パーティクル・カメラ・スコアをすべて最初に戻すので、そのままリトライになります。

> [!CHECK] 動作チェック
> - 落ちると、キャラクターが赤い粒になって飛びちり、少ししてからゲームオーバー画面が出る
> - 初めて遊んだあとは「ハイスコア更新！」と出て、上の BEST にスコアが入る
> - ページを再読み込みしても、BEST に前回までの最高スコアが残っている
> - 「もう一度」や Space / Enter で最初からあそべる
> - 完成品（このゲームのページ）と同じように遊べる

## 改造アイデア

> [!TIP] ロープの長さを変える
> `MAX_ROPE` を 200 にすると届く範囲がせまくなって難しく、350 にするとかんたんになります。`addAnchor()` の `gap` の上限（230）と合わせて調整すると、遊びごたえが変わります。

> [!TIP] 重力を変えて月面ステージ
> `G` を 500 くらいにすると、ふわっと遠くまで飛べる月面のような感覚になります。空のグラデーションの色も変えて、別のステージにしてみましょう。

> [!TIP] 一定距離ごとにボーナスフック
> 100m ごとに金色のフックを置き、つかまったら★10個分のボーナスにしてみましょう。`addAnchor()` でフックに `gold: true` を持たせ、`attach()` でつかんだときに調べるのがポイントです。

> [!TIP] つかまったときに画面をゆらす
> 動くフックにつかまったときや★を取ったときに、`draw()` の最初で `ctx.translate()` を少しだけランダムにずらすと、「画面ゆれ」の演出ができます。ゆらす時間を変数で持ち、`step()` で減らしていきましょう。
