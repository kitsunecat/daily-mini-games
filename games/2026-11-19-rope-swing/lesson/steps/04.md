## このステップのゴール

このゲームの主役、**ロープ** を作ります。画面を押している間（または Space キーを押している間）だけ、届く範囲でいちばん良いフックにロープをかけ、はなすとロープが外れます。ロープがかかっている間、プレイヤーはフックを中心に **振り子** のように動きます。

届く範囲のフックには黄色い輪が出て、どこにかかるか分かるようにします。

## 定数と変数を足す

`const G = 980;` の **下** に追加します。

```js:game.js
  const MAX_ROPE = 270;
```

`let running = false;` の行を、次のように **書きかえます**。

```js:game.js
  let running = false, holding = false;
```

`let player, anchors, camX, maxX, nextAnchorX, lastT;` の行を、次のように **書きかえます**。

```js:game.js
  let player, anchors, camX, rope, maxX, nextAnchorX, lastT;
```

- `MAX_ROPE` はロープが届く最大の長さです
- `holding` は「いま押しているかどうか」です
- `rope` は、ロープがかかっていないときは `null`、かかっているときは `{ a: フック, len: ロープの長さ }` というオブジェクトにします。ロープは「どのフックに」「どの長さで」の2つだけで表せます

`newGame()` の中の `camX = 0; maxX = 0;` の行を、次の2行に **書きかえます**。

```js:game.js
    rope = null; camX = 0; maxX = 0;
    holding = false;
```

## attach() と release() を追加する

`updateHud()` の閉じかっこ `}` の **下**、`function die() {` の **上** に追加します。

```js:game.js

  function attach() {
    if (rope || !running) return;
    let bestA = null, bestD = Infinity;
    for (const a of anchors) {
      if (a.x < player.x - 60) continue;
      const d = Math.hypot(a.x - player.x, a.y - player.y);
      if (d < MAX_ROPE && a.y < player.y + 20) {
        // prefer anchors ahead
        const w = d - (a.x > player.x ? 40 : 0);
        if (w < bestD) { bestD = w; bestA = a; }
      }
    }
    if (bestA) {
      rope = { a: bestA, len: Math.max(50, Math.hypot(bestA.x - player.x, bestA.y - player.y)) };
    }
  }
  function release() {
    if (rope) {
      rope = null;
    }
  }
```

### attach() … どのフックにかけるか

すべてのフックを調べて、いちばん良いものを1つ選びます。

1. プレイヤーより 60 以上うしろのフックは `continue` で飛ばします（うしろに戻るロープは気持ちよくないため）
2. `Math.hypot(dx, dy)` で、プレイヤーとフックの **距離** を求めます。三平方の定理 √(dx² + dy²) を計算してくれる関数です
3. 距離が `MAX_ROPE` より短く、フックがプレイヤーより（ほぼ）上にあるものだけを候補にします
4. 候補の中から「距離がいちばん短いもの」を選びます。ただし、前にあるフックは距離を 40 だけ短く見なして、**前のフックを選びやすく** しています

`bestD = Infinity`（無限大）から始めて、もっと小さい値が見つかるたびに入れかえるのは、「いちばん小さいもの探し」の定番の書き方です。

ロープの長さは「かけた瞬間の距離」です。ただし短すぎると振り子が速すぎるので、最低 50 にしています。

`release()` はロープを外すだけです。ステップ5でここに少し足します。

## step() を書きかえる

`function step(dt, time) { ... }` を **まるごと書きかえます**。

```js:game.js
  function step(dt, time) {
    if (holding && !rope) attach();
    const p = player;
    p.vy += G * dt;
    if (rope) {
      const a = rope.a;
      p.x += p.vx * dt; p.y += p.vy * dt;
      let nx = p.x - a.x, ny = p.y - a.y;
      let d = Math.hypot(nx, ny) || 1;
      if (d > rope.len) {
        nx /= d; ny /= d;
        p.x = a.x + nx * rope.len; p.y = a.y + ny * rope.len;
        const vr = p.vx * nx + p.vy * ny;
        if (vr > 0) { p.vx -= vr * nx; p.vy -= vr * ny; }
      }
    } else {
      p.vx *= (1 - 0.05 * dt);
      p.x += p.vx * dt; p.y += p.vy * dt;
    }
    const sp = Math.hypot(p.vx, p.vy);
    if (sp > 950) { p.vx *= 950 / sp; p.vy *= 950 / sp; }
    if (p.y < -H * 0.6) { p.y = -H * 0.6; if (p.vy < 0) p.vy = 0; }

    if (p.x > maxX) maxX = p.x;
    camX += (p.x - VIEW_W * 0.35 - camX) * Math.min(1, dt * 5);

    while (nextAnchorX < camX + VIEW_W * 2.5) addAnchor();
    anchors = anchors.filter(a => a.x > camX - 300 || (rope && rope.a === a));

    updateHud();
    if (p.y > H - 26) die();
  }
```

### 押しっぱなしでもロープをかける

最初の `if (holding && !rope) attach();` は、押しっぱなしのまま、届くフックが近づいてきたら自動でかける、というしかけです。押した瞬間にフックが遠くても、押し続けていれば届いたところでロープがかかります。

### 距離の拘束（ロープの物理）

重力はいつもどおりかけて、位置もいつもどおり動かします。そのうえで、`if (rope)` のときだけ、次のように **あとから直します**。

1. フックからプレイヤーへのベクトル `(nx, ny)` と、その長さ `d` を求める（`|| 1` は d が 0 のときに割り算でこわれないための保険です）
2. `d > rope.len`、つまりロープより遠くへ行ってしまったら、
3. `nx /= d; ny /= d;` で、長さ 1 の向きだけのベクトル（**単位ベクトル**）にする
4. プレイヤーを「フックからロープの長さぶん、その向きに進んだ位置」に戻す。これで、プレイヤーはフックを中心とした円の上にとどまります
5. 速度のうち、フックから **外向き** の成分 `vr` を求めて（速度と向きの **内積** `vx*nx + vy*ny` で求まります）、それを速度から引く

5 がポイントです。外へ引っぱられる速さだけを消すので、残るのは円にそった（接線方向の）速さだけになります。これで、ロープにぶら下がって **ぐるっと回る** 動きが生まれます。本物のロープと同じく、ロープより近いとき（たるんでいるとき）は何もしません。

この「まず自由に動かして、ルールに合わない分をあとで直す」方法を **拘束（コンストレイント）** と呼び、ゲームの物理でよく使われます。ステップ2で作ったサブステップ（1フレームを3回に分けて計算）は、この直しを細かく行うことで、ロープの長さがぶれないようにするためのものです。

ロープがないときは、これまでどおり空気抵抗をかけて動かします。

### ロープでつかんでいるフックは消さない

`anchors.filter` の条件に `|| (rope && rope.a === a)` を足しました。つかんでいるフックがカメラから遠く離れても、消されないようにするためです。

## draw() にロープを描く

`// anchors` から `// player` の手前までを、次のように **書きかえます**。

```js:game.js
    // anchors
    for (const a of anchors) {
      const inRange = running && !rope && Math.hypot(a.x - player.x, a.y - player.y) < MAX_ROPE && a.x > player.x - 60 && a.y < player.y + 20;
      ctx.lineWidth = 4;
      ctx.strokeStyle = '#e8f1ff';
      ctx.beginPath(); ctx.arc(a.x, a.y, 9, 0, 7); ctx.stroke();
      ctx.fillStyle = '#16263f'; ctx.beginPath(); ctx.arc(a.x, a.y, 4, 0, 7); ctx.fill();
      if (inRange) {
        ctx.strokeStyle = 'rgba(255,207,74,.5)'; ctx.lineWidth = 2;
        ctx.beginPath(); ctx.arc(a.x, a.y, 15, 0, 7); ctx.stroke();
      }
    }

    // rope
    if (rope) {
      ctx.strokeStyle = '#ffe9b0'; ctx.lineWidth = 3;
      ctx.beginPath(); ctx.moveTo(rope.a.x, rope.a.y); ctx.lineTo(player.x, player.y); ctx.stroke();
    }
```

- `inRange` は `attach()` と同じ条件で「いまロープをかけられるフックか」を調べたものです。かけられるフックのまわりに黄色い半透明の輪を描くと、プレイヤーは「いま押せばどこにかかるか」が分かります
- ロープは、フックからプレイヤーまで `moveTo` → `lineTo` で直線を引くだけです

さらに、`draw()` のいちばん最後、トゲを描く `ctx.fill();` の **下** に追加します。

```js:game.js

    // hint
    if (running && !rope && holding) {
      ctx.fillStyle = 'rgba(255,255,255,.7)'; ctx.font = '12px sans-serif'; ctx.textAlign = 'center';
      ctx.fillText('届くフックがない！', VIEW_W / 2, 24);
    }
```

押しているのにロープがかからないときに、画面の上にメッセージを出します。

## 入力を受け取る

`// ---------- input ----------` の **下** に追加します（`startBtn.addEventListener(...)` の **上**）。

```js:game.js
  function down(e) {
    if (!running) return;
    e.preventDefault();
    holding = true; attach();
  }
  function up() { holding = false; release(); }
  cv.addEventListener('pointerdown', down);
  window.addEventListener('pointerup', up);
  window.addEventListener('pointercancel', up);
  window.addEventListener('blur', up);
  window.addEventListener('keydown', (e) => {
    if (e.code === 'Space' || e.code === 'Enter' || e.code === 'ArrowUp') {
      e.preventDefault();
      if (!running) { if (!overlay.classList.contains('hidden') && !e.repeat) newGame(); return; }
      if (!e.repeat) { holding = true; attach(); }
    }
  });
  window.addEventListener('keyup', (e) => {
    if (e.code === 'Space' || e.code === 'Enter' || e.code === 'ArrowUp') up();
  });
```

### pointer イベント

**pointer イベント** は、マウス・タッチ・ペンをまとめてあつかえるイベントです。`pointerdown` で押した、`pointerup` ではなした、が分かります。

- `pointerdown` は Canvas で受け取りますが、`pointerup` は `window`（ページ全体）で受け取ります。押したまま指が Canvas の外に出てからはなしても、ちゃんと「はなした」と分かるようにするためです
- `pointercancel`（システムに操作を取られた）と `blur`（ウィンドウからフォーカスが外れた）でも「はなした」ことにします。こうしないと、押しっぱなしのまま戻らなくなることがあります
- `e.preventDefault()` は、長押しでメニューが出るなどのブラウザの動きを止めます

### キーボード

Space・Enter・↑ キーでも同じ操作ができます。キーを押しっぱなしにすると `keydown` が何度も送られてくるので、`e.repeat`（自動のくり返しかどうか）が true のものは無視します。

ゲーム中でないとき（`!running`）は、タイトル画面かゲームオーバー画面が出ていればゲームを始めます。キーボードだけでもリトライできるようになりました。

> [!CHECK] 動作チェック
> - スタート直後、届く範囲のフックのまわりに黄色い輪が出る
> - 画面を押す（または Space を押す）と、黄色い輪のフックにロープがかかり、キャラクターがブランコのように振れる
> - はなすとロープが外れ、そのときの勢いで飛んでいく
> - 押しっぱなしにしていると、届くフックに近づいたところで自動でロープがかかる
> - フックが届かないところで押すと「届くフックがない！」と表示される
> - ゲームオーバー画面で Space / Enter を押すと、もう一度始まる
