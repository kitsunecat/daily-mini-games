## このステップのゴール

フックとフックの間に、ふわふわ浮かぶ **★** を置きます。プレイヤーが★にふれると取れて、上の ★ の数が増えます。スコアは「進んだ距離（m）＋ ★ × 5」にして、DIST に表示します。

## 変数を足す

`let player, anchors, camX, rope, maxX, nextAnchorX, lastT;` の行を、次のように **書きかえます**。

```js:game.js
  let player, anchors, stars, camX, rope, maxX, starCount, nextAnchorX, lastT;
```

`stars` は★の配列、`starCount` は取った★の数です。

## ★を置く

`addAnchor()` の中の `anchors.push({ ... });` の行の **下**（`nextAnchorX += gap;` の **上**）に追加します。

```js:game.js
    // star between this and next anchor
    if (Math.random() < 0.75) {
      stars.push({ x: x + gap * rand(0.35, 0.65), y: rand(H * 0.2, H * 0.7), got: false, t: rand(0, 6) });
    }
```

- 75% の確率で、このフックと次のフックの **間**（間隔の 35%〜65% の位置）に★を置きます。フックとフックの間は、プレイヤーが飛んでいる途中に通る場所です
- 高さは画面の 20%〜70% と広めにしてあります。低い★を取るには、深く振り下ろしてからはなす、などの工夫が必要になります
- `got` は取ったかどうか、`t` はふわふわ動かすための時間です

`newGame()` の中の `anchors = [];` の行を、次のように **書きかえます**。

```js:game.js
    anchors = []; stars = [];
```

`rope = null; camX = 0; maxX = 0;` の行を、次のように **書きかえます**。

```js:game.js
    rope = null; camX = 0; maxX = 0; starCount = 0;
```

`stars = []` は、すぐ下の `addAnchor()` の for 文より **前** に必要です。addAnchor の中で `stars.push` するからです。

## スコアを計算する

`function updateHud() { ... }` を、次のように **書きかえます**（下に `score()` も足します）。

```js:game.js
  function updateHud() {
    scoreEl.textContent = score();
    starsEl.textContent = starCount;
  }
  function score() { return Math.floor(maxX / 10) + starCount * 5; }
```

スコアの計算を `score()` という関数にまとめておくと、HUD でもゲームオーバー画面でも（ステップ8ではハイスコアでも）同じ式を使えます。式を変えたくなったときも、1か所直すだけで済みます。

`die()` の中の `ovText.innerHTML = ...` の行を、次のように **書きかえます**。

```js:game.js
    ovText.innerHTML = '距離 <b class="hl">' + Math.floor(maxX / 10) + 'm</b> ／ ★ <b class="hl">' + starCount +
      '</b><br>スコア <b class="hl">' + score() + '</b>';
```

## 当たり判定

`step()` の中の `anchors = anchors.filter(...);` の行の **下** に追加します（`updateHud();` の **上**）。

```js:game.js
    stars = stars.filter(s => s.x > camX - 100);

    for (const s of stars) {
      s.t += dt;
      if (!s.got && Math.hypot(s.x - p.x, s.y - p.y) < 24) {
        s.got = true; starCount++;
      }
    }
```

うしろに置いていった★は、フックと同じように `filter` で捨てます。

**当たり判定** は「2つのものがふれたか」を調べることです。プレイヤーも★もだいたい円の形なので、**中心どうしの距離が、2つの半径を足したものより短ければ当たり** という、いちばんかんたんな「円と円」の判定を使います。プレイヤーの半径 12 と★の半径 11 を足すと 23 なので、少しおまけして 24 にしています。

取った★はすぐには配列から消さず、`got = true` にしておくだけにします。描くときと当たり判定のときに `got` の★を飛ばせば、同じことになります。

## ★を描く

`draw()` の中の `// anchors` の行の **上** に追加します（距離の目印の for 文のあと）。

```js:game.js
    // stars
    for (const s of stars) {
      if (s.got) continue;
      drawStar(s.x, s.y + Math.sin(s.t * 3) * 4, 11, 5);
    }

```

`Math.sin(s.t * 3) * 4` を y に足して、上下に 4 だけふわふわ動かします。`t` が★ごとにバラバラなので、ゆれ方もそろいません。

`draw()` の閉じかっこ `}` の **下**、`function loop(now) {` の **上** に追加します。

```js:game.js
  function drawStar(x, y, r, n) {
    ctx.fillStyle = '#ffcf4a';
    ctx.beginPath();
    for (let i = 0; i < n * 2; i++) {
      const rr = i % 2 ? r * 0.45 : r;
      const a = -Math.PI / 2 + i * Math.PI / n;
      ctx.lineTo(x + Math.cos(a) * rr, y + Math.sin(a) * rr);
    }
    ctx.closePath(); ctx.fill();
  }

```

### 星形の描き方

五芒星は「外側のとがった点」と「内側のへこんだ点」が交互に5つずつ、全部で10個の点をつないだ形です。

- `i % 2`（i を 2 で割った余り）が 0 なら外側（半径 r）、1 なら内側（半径 r × 0.45）にします
- 角度 `a` は真上（`-Math.PI / 2`）から始めて、`Math.PI / n`（36度）ずつ回します
- 円の上の点は `(x + cos(a) × 半径, y + sin(a) × 半径)` で求まります。**三角関数** を使うと、角度と半径から位置が計算できます

`n` を変えると、ほかのとがり数の星も描けます。

> [!CHECK] 動作チェック
> - フックとフックの間に、黄色い★がふわふわ浮いている
> - キャラクターが★にふれると★が消え、上の ★ の数が 1 増える
> - DIST の数字が「距離 ＋ ★ × 5」になり、★を取ると一気に 5 増える
> - ゲームオーバー画面に、距離・★の数・スコアが表示される
