## このステップのゴール

ステップ4のロープは、振るたびに少しずつ勢いがなくなってしまいます。そこで、ブランコを「こぐ」ように前へ押す力を足し、ロープをはなした瞬間にもちょっとだけ加速させて、**フックからフックへ気持ちよく渡れる** ようにします。

さらに、ある程度進むと **上下に動くオレンジ色のフック** が出てくるようにして、後半を難しくします。

## step() のロープ部分を書きかえる

`step()` の中の `if (rope) {` から `} else {` の手前までを、次のように **書きかえます**（`} else {` から下はそのままです）。

```js:game.js
    if (rope) {
      const a = rope.a;
      let nx = p.x - a.x, ny = p.y - a.y;
      let d = Math.hypot(nx, ny) || 1;
      nx /= d; ny /= d;
      // tangent toward forward (+x)
      let tx = -ny, ty = nx;
      if (tx < 0) { tx = -tx; ty = -ty; }
      if (ny > 0) { p.vx += tx * 160 * dt; p.vy += ty * 160 * dt; }
      p.x += p.vx * dt; p.y += p.vy * dt;
      nx = p.x - a.x; ny = p.y - a.y; d = Math.hypot(nx, ny) || 1;
      if (d > rope.len) {
        nx /= d; ny /= d;
        p.x = a.x + nx * rope.len; p.y = a.y + ny * rope.len;
        const vr = p.vx * nx + p.vy * ny;
        if (vr > 0) { p.vx -= vr * nx; p.vy -= vr * ny; }
      }
      // shorten slightly when anchor moves
      if (rope.len > 60) rope.len -= 10 * dt;
```

### 接線方向に「こぐ」

`nx /= d; ny /= d;` で、フックからプレイヤーへの向きを単位ベクトルにします。このベクトルを90度回すと、円の **接線**（円にそって進む向き）になります。2次元のベクトル `(x, y)` を90度回すには `(-y, x)` とするだけです。

接線は2つの向き（時計回り・反時計回り）があるので、`tx < 0` なら反対向きにして、**必ず右（前）向き** を選びます。

`if (ny > 0)`、つまりプレイヤーがフックより **下** にいるときだけ、その向きに毎秒 160 の力をかけます。ブランコを一番下あたりで前へこぐと高く上がるのと同じで、振るたびに勢いが増えていきます。フックより上まで回ったときは力をかけないので、無限に加速しつづけることはありません。

力をかけたあとで位置を動かし、もう一度フックとの距離を計算し直してから、ステップ4と同じ拘束をかけます。

### ロープを少しずつ短くする

`rope.len -= 10 * dt` で、ロープを毎秒 10 ずつ短くします（60 より短くはしません）。ロープが短くなると振り子は速く回るので、つかまっている間にじわじわ勢いがつきます。動くフックにつかまったとき、フックが下がってきてもロープが長いままにならない効果もあります。

## はなした瞬間に加速する

`release()` の中の `rope = null;` の行の **下** に追加します。

```js:game.js
      player.vx *= 1.04; player.vy *= 1.04;
```

ロープをはなした瞬間に、速度を 4% だけ大きくします。物理としては正しくありませんが、「はなした！ 飛んだ！」という手ごたえが出て、操作が気持ちよくなります。ゲームでは、こうした **ちょっとしたウソ** で遊び心地を良くすることがよくあります。

## 動くフック

`addAnchor()` の中の `anchors.push({ x, y });` の行を、次の2行に **書きかえます**。

```js:game.js
    const moving = dist > 250 && Math.random() < Math.min(0.5, (dist - 250) / 800);
    anchors.push({ x, y, baseY: y, moving, phase: rand(0, 6.28), amp: rand(25, 55) });
```

- 250m より先では、ある確率で `moving`（動くフック）にします。確率は進むほど上がり、最大 50% です
- `baseY` はもとの高さ、`amp` は上下にゆれる幅（25〜55）、`phase` はゆれ始めのずれです。全部のフックが同時に上下するとつまらないので、`phase` をランダムにしてバラバラに動かします

`step()` のいちばん最初、`if (holding && !rope) attach();` の行の **上** に追加します。

```js:game.js
    for (const a of anchors) if (a.moving) a.y = a.baseY + Math.sin(time * 1.6 + a.phase) * a.amp;
```

`time` はステップ2の loop から渡している「秒単位の時刻」です。`Math.sin` は -1〜1 の間を行ったり来たりするので、`amp` をかけて `baseY` に足すと、もとの高さを中心に上下にゆれます。`1.6` はゆれる速さです。

動いているフックにつかまっていても、ロープの拘束は毎回フックの **今の位置** から計算するので、そのまま正しく振れます。

最後に、`draw()` のフックを描くところの `ctx.strokeStyle = '#e8f1ff';` の行を、次のように **書きかえます**。

```js:game.js
      ctx.strokeStyle = a.moving ? '#ff9f43' : '#e8f1ff';
```

`条件 ? A : B` は、条件が true なら A、false なら B になる書き方（**三項演算子**）です。動くフックだけオレンジ色にして、見分けられるようにします。

> [!CHECK] 動作チェック
> - ロープにぶら下がっている間、振るたびに勢いが増えて、高く振り上がるようになる
> - 前へ振り上がったところではなすと、次のフックまで届くくらい遠くへ飛べる
> - ロープをつかんだままにしていると、フックのまわりをぐるっと回ることもある
> - 250m を過ぎたあたりから、上下にゆれるオレンジ色のフックが出てくる
