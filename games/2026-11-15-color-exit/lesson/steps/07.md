## このステップのゴール

**制限時間** を入れて、ゲームとして完成させます。残り時間のバーが減っていき、全部出すと「STAGE CLEAR!」と残り時間ボーナス、そして次のステージへ。時間切れになるとゲームオーバー画面が出て「もう一度」遊べます。

## 変数を足す

変数の2行を次のように **書きかえます**。

```js:game.js
  let level = 1, score = 0, timeLeft = 0, timeMax = 1;
```

```js:game.js
  let combo = 0, lastExit = -10, now = 0, clearTimer = 0;
```

- `timeLeft` … 残り時間（秒）。`timeMax` … そのステージの最初の持ち時間。バーの長さの計算に使います（0 で割らないように初期値は 1）
- `clearTimer` … 「STAGE CLEAR!」を表示しておく残り時間

## ステージごとの持ち時間

`generate()` の最後、`drag = null;` の **上** に1行足します。

```js:game.js
    timeMax = timeLeft = Math.round(14 + blocks.length * 4.2 + stones.length * 2);
    drag = null;
```

箱1個につき約4秒、石1個につき2秒、それに基本の14秒を足します。箱5個のステージ1なら 35 秒です。`timeMax = timeLeft = ...` のように `=` をつなげると、2つの変数に同じ値を入れられます。

## 次のステージ・ゲームオーバー・時間バー

`startGame()` の **下** に `nextLevel()` と `gameOver()` を追加し、`updateHud()` を **書きかえます**。

```js:game.js
  function nextLevel() {
    level++;
    generate();
    state = 'play';
    updateHud();
  }
  function gameOver() {
    state = 'over'; drag = null;
    updateHud();
    ovTitle.textContent = '時間切れ！';
    ovText.innerHTML = `ステージ <b class="hl">${level}</b> まで到達<br>スコア <b class="hl">${score}</b>`;
    startBtn.textContent = 'もう一度';
    setTimeout(() => overlay.classList.remove('hidden'), 500);
  }
  function updateHud() {
    $score.textContent = score; $best.textContent = best; $stageNo.textContent = level;
    const ratio = Math.max(0, timeLeft / timeMax);
    $fill.style.width = (ratio * 100) + '%';
    $fill.classList.toggle('low', timeLeft < 10);
    $ttext.textContent = Math.ceil(Math.max(0, timeLeft)) + ' 秒';
  }
```

### nextLevel()

ステージを1つ進めて新しい盤面を作り、`state` を `'play'` に戻します。

### gameOver()

`state` を `'over'` にして操作を止め、オーバーレイのタイトルと文章を書きかえます。`innerHTML` を使うと `<b>` や `<br>` などのタグも反映されます。ボタンの文字は「もう一度」にします。ボタンを押すと、ステップ1から使っている `startGame()` が呼ばれ、ステージ1からやり直しになります。

`setTimeout(..., 500)` で、オーバーレイを 0.5 秒遅らせて出しています。最後の瞬間に箱を動かしていた指が、そのままボタンを押してしまわないようにするためです。

### updateHud() の時間バー

- `timeLeft / timeMax` で残りの割合（1 → 0）を出し、`#timefill` の幅を `%` で指定します
- `classList.toggle('low', 条件)` は、条件が `true` ならクラスをつけ、`false` ならはずします。残り10秒を切るとバーが赤くなります
- 数字は `Math.ceil()`（切り上げ）で表示します。0.3 秒残っているときに「0 秒」と出ないようにするためです

## ステージクリア

`exitBlock()` の最後の2行を次のように **書きかえ**、`exitBlock()` の **下** に `stageClear()` を追加します。

```js:game.js
    if (blocks.length === 0) stageClear();
    updateHud();
  }

  function stageClear() {
    state = 'clear'; clearTimer = 1.6;
    const bonus = Math.ceil(timeLeft) * 5 * level;
    score += bonus;
    floats.push({ x: W / 2, y: H / 2 + 30, text: `残り時間ボーナス +${bonus}`, life: 1.6, big: true });
    beep(660, 0.12, 'triangle'); setTimeout(() => beep(880, 0.12, 'triangle'), 110); setTimeout(() => beep(1175, 0.2, 'triangle'), 220);
  }
```

すぐ次のステージにせず、`state` を `'clear'` にして 1.6 秒の演出をはさみます。残り時間ボーナスは `残り秒数 × 5 × ステージ` です。早くクリアするほど得点が増えるので、急ぐ理由になります。3つの音を 110 ミリ秒ずつずらして「ド・ミ・ソ」のように鳴らしています。

## 「STAGE CLEAR!」を描く

`draw()` の最後、`ctx.globalAlpha = 1;`（浮かぶ文字を描く `for` 文の後のもの）の **下** に追加します。

```js:game.js
    if (state === 'clear') {
      ctx.fillStyle = 'rgba(13,27,46,.55)'; ctx.fillRect(ox, oy, COLS * cs, ROWS * cs);
      ctx.font = 'bold 30px system-ui, sans-serif';
      ctx.lineWidth = 6; ctx.strokeStyle = '#c0392b';
      ctx.strokeText('STAGE CLEAR!', W / 2, H / 2 - 10); ctx.fillStyle = '#ffd166'; ctx.fillText('STAGE CLEAR!', W / 2, H / 2 - 10);
    }
```

盤面の上に半透明の紺色を重ねて暗くし、大きな文字を描きます。

## ゲームループで時間を進める

`loop()` の `const dt = ...` の行の **下** に追加します。

```js:game.js
    if (state === 'play') {
      timeLeft -= dt;
      if (timeLeft <= 0) { timeLeft = 0; gameOver(); }
      updateHud();
    } else if (state === 'clear') {
      clearTimer -= dt;
      if (clearTimer <= 0) nextLevel();
    }
```

`state` によって、ループでやることを変えています。

- `'play'` … 残り時間を減らし、0 以下になったら `gameOver()`。毎フレーム `updateHud()` でバーを動かします
- `'clear'` … `clearTimer` を減らし、0 以下になったら `nextLevel()`
- `'title'` と `'over'` … 何もしません。時間は止まったままです

このように **今の場面（state）でループの中身を分ける** のが、ゲーム全体の流れを作るときの基本です。

> [!CHECK] 動作チェック
> - スタートすると時間バーが右から縮んでいき、残り10秒を切ると赤くなる
> - 全部出すと盤面が暗くなって「STAGE CLEAR!」と「残り時間ボーナス +〇〇」が出て、約1.6秒後に次のステージが始まる
> - 時間切れになると「時間切れ！」と、到達ステージ・スコアが表示される
> - 「もう一度」を押すと、ステージ1・スコア0からやり直せる
