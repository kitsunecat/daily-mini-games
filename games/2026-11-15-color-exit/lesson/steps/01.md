## このステップのゴール

3つのファイルを用意して、ゲーム画面の土台を作ります。上に「STAGE・SCORE・BEST」と残り時間のバー、まん中にゲームを描く **Canvas**（キャンバス）とその上に重ねるタイトル画面（オーバーレイ）、下にひとことヒントを置き、Canvas に **6×7 マスの盤面と枠** を描くところまで進めます。

完成すると、こんなゲームになります。

- 6×7 マスの盤面に、色と形のちがう **箱**（1×1、2×1、1×3、2×2 など）が並んでいる
- 盤面の枠には色つきの **出口** がある。箱をドラッグで縦横に動かし、**同じ色の出口** にぴったり合わせてさらに押すと外へ出る
- 出口より幅の広い箱は通れない。ほかの箱や石は通りぬけられないので、出す順番を考える
- 全部出すとステージクリア。早く出すほど残り時間ボーナス、続けて出すとコンボ。時間切れでゲームオーバー

## game.js

JavaScript は、このあとのステップで少しずつ育てていきます。まずは土台です。

```js:game.js
(() => {
  'use strict';
  const COLS = 6, ROWS = 7;

  const cv = document.getElementById('cv');
  const ctx = cv.getContext('2d');
  const stageEl = document.getElementById('stage');
  const $score = document.getElementById('score');
  const $best = document.getElementById('best');
  const $stageNo = document.getElementById('stage-no');
  const $fill = document.getElementById('timefill');
  const $ttext = document.getElementById('timetext');
  const overlay = document.getElementById('overlay');
  const ovTitle = document.getElementById('ov-title');
  const ovText = document.getElementById('ov-text');
  const startBtn = document.getElementById('start');

  let state = 'title'; // title | play | clear | over
  let now = 0;
  let cs = 40, border = 14, ox = 0, oy = 0, W = 0, H = 0, dpr = 1;

  // ---------- layout ----------
  function resize() {
    const r = stageEl.getBoundingClientRect();
    const aw = r.width - 16, ah = r.height - 8;
    cs = Math.floor(Math.min(aw / (COLS + 0.8), ah / (ROWS + 0.8)));
    border = Math.max(10, Math.round(cs * 0.36));
    W = cs * COLS + border * 2; H = cs * ROWS + border * 2;
    dpr = window.devicePixelRatio || 1;
    cv.width = W * dpr; cv.height = H * dpr;
    cv.style.width = W + 'px'; cv.style.height = H + 'px';
    ox = border; oy = border;
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
  }
  window.addEventListener('resize', resize);

  // ---------- game flow ----------
  function startGame() {
    overlay.classList.add('hidden');
    state = 'play';
  }

  // ---------- input ----------
  startBtn.addEventListener('click', startGame);

  // ---------- drawing ----------
  function rr(x, y, w, h, r) {
    ctx.beginPath();
    ctx.moveTo(x + r, y); ctx.arcTo(x + w, y, x + w, y + h, r); ctx.arcTo(x + w, y + h, x, y + h, r);
    ctx.arcTo(x, y + h, x, y, r); ctx.arcTo(x, y, x + w, y, r); ctx.closePath();
  }

  function draw() {
    ctx.clearRect(0, 0, W, H);
    // frame
    ctx.fillStyle = '#3c4f6b'; rr(0, 0, W, H, border); ctx.fill();
    ctx.fillStyle = '#16263d'; ctx.fillRect(ox, oy, COLS * cs, ROWS * cs);
    for (let y = 0; y < ROWS; y++) for (let x = 0; x < COLS; x++) {
      ctx.fillStyle = (x + y) % 2 ? '#1c2f4a' : '#1a2b44';
      ctx.fillRect(ox + x * cs + 1, oy + y * cs + 1, cs - 2, cs - 2);
    }
  }

  // ---------- loop ----------
  let last = performance.now();
  function loop(t) {
    const dt = Math.min(0.05, (t - last) / 1000); last = t; now += dt;
    draw();
    requestAnimationFrame(loop);
  }

  resize();
  requestAnimationFrame(loop);
})();
```

### 全体を `(() => { ... })();` で包む

ファイル全体を **即時実行関数** で包んでいます。中で作った変数や関数が外（ほかのスクリプト）とぶつからないようにするための書き方です。`'use strict';` は書きまちがいをエラーとして教えてくれるモードです。

### マス目で考える

`COLS = 6, ROWS = 7` が盤面の大きさ（横6マス・縦7マス）です。このゲームでは、箱の位置も出口の位置もすべて **マス目の番号**（左上が `x = 0, y = 0`）で持ちます。画面のピクセルに直すのは描くときだけです。

- `cs` … 1マスの大きさ（ピクセル）。cell size の略です
- `border` … 盤面のまわりの枠の太さ。あとでここに出口を描きます
- `ox`, `oy` … 盤面の左上が Canvas のどこにあるか。枠の太さぶんだけずれます
- `W`, `H` … Canvas 全体の大きさ

マス `(x, y)` の左上のピクセルは `ox + x * cs, oy + y * cs` で求まります。この式はこれから何度も出てきます。

### resize() で画面に合わせる

`resize()` は `#stage` の大きさを調べて、盤面がちょうど収まる `cs` を決めます。

- `aw / (COLS + 0.8)` … 横幅を「6マス＋枠2本ぶん（約0.8マス）」で割ると、1マスの大きさの上限になります。縦も同じように計算し、小さいほうを使うのではみ出しません
- `cv.style.width/height` … 画面上の見た目の大きさ
- `cv.width/height` … Canvas の中身の画素数。`devicePixelRatio`（スマホなどの高解像度画面では 2〜3）を掛けて、ぼやけないようにしています
- `ctx.setTransform(dpr, 0, 0, dpr, 0, 0)` … 「これから描くものを全部 `dpr` 倍する」設定。これで描く側は見た目のピクセルのまま書けます

### rr() で角の丸い四角形

`rr(x, y, w, h, r)` は角の丸い四角形の **パス（輪郭）** を作るだけの関数です。`arcTo()` で4つの角を丸めながら一周します。塗るときは `ctx.fill()`、線を引くときは `ctx.stroke()` を後から呼びます。枠も箱も出口も、ほとんどこの関数で描きます。

### draw() で盤面を描く

まず枠全体を角丸で塗り、その内側を暗い色で塗ってから、マスを1つずつ少し小さく（`+1` と `- 2` で1ピクセルずつ内側に）塗っています。`(x + y) % 2` で色を交互に変えると、チェック柄になってマス目が見やすくなります。

### ゲームループ

`requestAnimationFrame(loop)` は「次に画面を描きかえるタイミングで `loop` を呼んで」とブラウザに頼む関数です。`loop` の最後でもう一度頼むので、1秒に約60回 `loop` が呼ばれ続けます。これが **ゲームループ** です。

- `t` はブラウザが渡してくれる現在時刻（ミリ秒）。前回との差を秒にしたものが `dt`（デルタタイム）です
- `Math.min(0.05, ...)` で、タブを切りかえて戻ってきたときなどに `dt` が大きくなりすぎないようにしています
- `now` は経過時間の合計。あとでコンボの判定に使います

毎フレーム「全部消して、全部描き直す」のが Canvas でのゲームの基本です。

### state でゲームの場面を分ける

`state` は今どの場面かを表す文字列です。`'title'`（タイトル画面）→ `'play'`（遊んでいる）→ `'clear'`（ステージクリアの演出中）→ `'over'`（ゲームオーバー）と切りかわります。今は「スタート」ボタンで `'play'` にしてオーバーレイを隠すだけです。

> [!NOTE]
> 時間バーはまだ動きません（満タンの表示に「0」と出ています）。ステップ7で動くようにします。

> [!CHECK] 動作チェック

> - ボタンを押すとタイトル画面が消えて、枠に囲まれた 6×7 マスのチェック柄の盤面が見える
