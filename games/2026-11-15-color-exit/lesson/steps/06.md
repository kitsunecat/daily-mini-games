## このステップのゴール

箱を出したときの **得点・コンボ・効果音・演出** を作ります。続けて出すとコンボで得点が増え、出口から色つきの火花が飛び散り、「+30 x2」のような文字がふわっと浮かびます。上の STAGE・SCORE・BEST の表示も動くようにします。

## 変数を足す

`const startBtn = ...;` の **下** に、ハイスコアの変数を追加します（保存はステップ9で作ります）。

```js:game.js
  let best = 0;
```

変数を次のように **書きかえます**。

```js:game.js
  let state = 'title'; // title | play | clear | over
  let level = 1, score = 0;
  let blocks = [], gates = [], stones = [], leaving = [], particles = [], floats = [];
  let combo = 0, lastExit = -10, now = 0;
  let drag = null;
  let cs = 40, border = 14, ox = 0, oy = 0, W = 0, H = 0, dpr = 1;
```

- `particles` … 飛び散る火花
- `floats` … 浮かび上がる得点の文字
- `combo` … 今のコンボ数。`lastExit` … 最後に箱を出した時刻（`now` の値）

## 効果音 beep()

`let cs = ...;` の行の **下**（`// ---------- layout ----------` の上）に追加します。

```js:game.js
  // ---------- audio ----------
  let actx = null;
  function beep(freq, dur, type = 'sine', vol = 0.12, slide = 0) {
    try {
      if (!actx) actx = new (window.AudioContext || window.webkitAudioContext)();
      const t = actx.currentTime;
      const o = actx.createOscillator(), g = actx.createGain();
      o.type = type; o.frequency.setValueAtTime(freq, t);
      if (slide) o.frequency.exponentialRampToValueAtTime(freq * slide, t + dur);
      g.gain.setValueAtTime(vol, t); g.gain.exponentialRampToValueAtTime(0.001, t + dur);
      o.connect(g).connect(actx.destination); o.start(t); o.stop(t + dur);
    } catch (e) { /* no audio */ }
  }
```

**Web Audio API** を使うと、音声ファイルなしで「ピッ」という音を作れます。

- `AudioContext` … 音を作る作業場。最初に音を鳴らすときに1回だけ作ります（ブラウザは、ユーザーが画面に触れる前に音を鳴らすことを禁止しているため、操作のあとに作るのが安全です）
- `createOscillator()` … 決まった高さ（`freq` ヘルツ）の音を出す発振器。`type` で `'sine'`（やわらかい）・`'square'`（ピコピコ）・`'triangle'`・`'sawtooth'`（ギザギザ）と音色が変わります
- `createGain()` … 音量のつまみ。`exponentialRampToValueAtTime()` で `dur` 秒かけて小さくし、音を自然に消します
- `slide` を指定すると、音の高さが `freq * slide` まで変わります。`1.5` なら上がる音、`0.4` なら下がる音です
- 全体を `try { ... } catch` で囲み、音が使えない環境でもゲームが止まらないようにしています

## HUD を書きかえる updateHud()

`startGame()` を次のように **書きかえ**、その **下** に `updateHud()` を追加します。

```js:game.js
  function startGame() {
    level = 1; score = 0; combo = 0;
    particles = []; floats = [];
    overlay.classList.add('hidden');
    generate();
    state = 'play';
    updateHud();
    beep(520, 0.12, 'triangle'); setTimeout(() => beep(780, 0.15, 'triangle'), 90);
  }
  function updateHud() {
    $score.textContent = score; $best.textContent = best; $stageNo.textContent = level;
  }
```

- スタートのたびに、ステージ・得点・コンボと、残っている火花・文字をリセットします
- スタートの音は、`setTimeout()` で 90 ミリ秒ずらして2つ鳴らし「ピロッ」と聞こえるようにしています
- `updateHud()` は、画面上の数字（HUD）を変数の値に合わせる関数です。値が変わったら呼びます

ファイルのいちばん下の `generate();` の **下** にも `updateHud();` を足します。

```js:game.js
  resize();
  generate();
  updateHud();
  requestAnimationFrame(loop);
```

## exitBlock() で得点と演出

`exitBlock()` を **関数ごと書きかえます**。

```js:game.js
  function exitBlock(b, dx, dy, g) {
    const i = blocks.indexOf(b);
    if (i < 0) return;
    blocks.splice(i, 1);
    leaving.push({ b, dx, dy, t: 0 });
    if (now - lastExit < 3) combo++; else combo = 1;
    lastExit = now;
    const pts = 10 * level * Math.min(combo, 5) + (b.w * b.h - 1) * 5;
    score += pts;
    const c = COLORS[b.color];
    const cx = ox + (b.x + b.w / 2) * cs, cy = oy + (b.y + b.h / 2) * cs;
    for (let k = 0; k < 18; k++) {
      const a = Math.random() * Math.PI * 2, sp = 60 + Math.random() * 180;
      particles.push({ x: cx, y: cy, vx: Math.cos(a) * sp + dx * 120, vy: Math.sin(a) * sp + dy * 120, life: 0.6, max: 0.6, color: c.fill });
    }
    floats.push({ x: cx, y: cy, text: '+' + pts + (combo > 1 ? `  x${Math.min(combo, 5)}` : ''), life: 1 });
    g.flash = 0.4;
    beep(440 + Math.min(combo, 6) * 90, 0.16, 'triangle', 0.13, 1.5);
    if (drag && drag.b === b) drag = null;
    if (blocks.length === 0) { level++; generate(); }
    updateHud();
  }
```

### コンボ

前に出してから **3秒以内** なら `combo` を1増やし、そうでなければ1に戻します。`lastExit` の初期値を `-10` にしているのは、最初の1個がコンボ扱いにならないようにするためです。

### 得点

`10 * level * Math.min(combo, 5) + (b.w * b.h - 1) * 5`

- ステージが進むほど、コンボが続くほど（最大5倍）高得点
- 大きい箱ほどボーナス。1×1 なら 0、2×2 なら 15 点です

### 火花（パーティクル）

箱の中心から18個の火花を飛ばします。`Math.random() * Math.PI * 2` でランダムな角度を決め、`Math.cos()`・`Math.sin()` で横と縦の速さに分けます。さらに箱が出た向き（`dx, dy`）に `120` を掛けて足すと、火花が出口の外へ向かって飛び散ります。

### 浮かぶ文字

`floats` に「+30  x2」のような文字を入れておきます。バッククォートで囲んだ **テンプレートリテラル** の中に `${...}` と書くと、式の値を文字列に埋めこめます。これを使って、コンボが2以上のときだけ倍率をつけています。

## 持ち上げた音

`pointerdown` の中の `drag = { ... };` の **下** に2行足します（イベント全体を載せます）。

```js:game.js
  cv.addEventListener('pointerdown', (e) => {
    if (state !== 'play') return;
    const p = toCell(e);
    const b = blockAt(p.x, p.y);
    if (!b) return;
    e.preventDefault();
    try { cv.setPointerCapture(e.pointerId); } catch (err) { /* ignore */ }
    drag = { b, offX: p.x - b.x, offY: p.y - b.y, id: e.pointerId };
    b.pop = 1;
    beep(330, 0.05, 'square', 0.05);
  });
```

`b.pop = 1` は「持ち上げた」という印です。今は描画には使っていないので、改造で「持ち上げた箱を少し大きく描く」などに使えます。

## 火花と文字を描いて動かす

`draw()` の、出ていく箱を描く `for` 文の **下** に追加します。

```js:game.js
    // particles
    for (const p of particles) {
      ctx.globalAlpha = Math.max(0, p.life / p.max);
      ctx.fillStyle = p.color; ctx.fillRect(p.x - 3, p.y - 3, 6, 6);
    }
    ctx.globalAlpha = 1;
    ctx.textAlign = 'center'; ctx.textBaseline = 'middle';
    for (const f of floats) {
      ctx.globalAlpha = Math.min(1, f.life * 2);
      ctx.font = `bold ${f.big ? 18 : 16}px system-ui, sans-serif`;
      ctx.lineWidth = 4; ctx.strokeStyle = 'rgba(0,0,0,.6)';
      ctx.strokeText(f.text, f.x, f.y); ctx.fillStyle = '#ffe28a'; ctx.fillText(f.text, f.x, f.y);
    }
    ctx.globalAlpha = 1;
```

- 火花は、残りの寿命の割合（`p.life / p.max`）を透明度にして、だんだん消えるようにしています
- 文字は `strokeText()` で黒いふちを描いてから `fillText()` で黄色く塗ると、どんな背景の上でも読みやすくなります
- `textAlign = 'center'` と `textBaseline = 'middle'` で、`(x, y)` が文字のまん中になります
- `f.big` は次のステップで使う「大きい文字」の印です

`loop()` の、出口の光を減らす行（`for (const g of gates) ...`）の **下** に追加します。

```js:game.js
    for (const p of particles) { p.x += p.vx * dt; p.y += p.vy * dt; p.vy += 300 * dt; p.life -= dt; }
    particles = particles.filter(p => p.life > 0);
    for (const f of floats) { f.y -= 30 * dt; f.life -= dt; }
    floats = floats.filter(f => f.life > 0);
```

火花は速さ（`vx, vy`）のぶん動かし、`p.vy += 300 * dt` で下向きに加速させて **重力** で落ちていくように見せます。文字は1秒に30ピクセルずつ上へ動かします。寿命が尽きたものは `filter()` で取りのぞきます。

> [!CHECK] 動作チェック
> - 箱をつかむと「ポッ」、出口から出すと「ピュン」と音が鳴る
> - 箱を出すと、出口の外へ向かって色つきの火花が飛び散り、「+10」のような文字が浮かんで消える
> - 3秒以内に続けて出すと「x2」「x3」とコンボがつき、音も高くなる。SCORE の数字が増える
> - 全部出すと STAGE の数字が1増える
