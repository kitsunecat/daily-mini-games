## このステップのゴール

最後の仕上げとして、**ハイスコアをブラウザに保存** します。ページを閉じても BEST の記録が残り、記録を更新したらゲームオーバー画面で「ハイスコア更新！」と知らせます。これで完成品と同じゲームになります。

## 保存用の名前を決める

`const SHAPES = [...];` の **下** に追加します。

```js:game.js
  const BEST_KEY = 'color-exit-best';
```

## 起動時にハイスコアを読みこむ

ステップ6で足した `let best = 0;` を次のように **書きかえます**。

```js:game.js
  let best = 0;
  try { best = parseInt(localStorage.getItem(BEST_KEY), 10) || 0; } catch (e) { best = 0; }
  $best.textContent = best;
```

### localStorage

**localStorage** は、ブラウザにちょっとしたデータを保存しておける場所です。ページを閉じても、次に開いたときに残っています。

- `localStorage.setItem(名前, 値)` で保存、`localStorage.getItem(名前)` で読み出し
- 保存できるのは **文字列だけ** です。読み出した値は `parseInt(..., 10)` で数に直します
- まだ保存していないと `getItem()` は `null` を返し、`parseInt(null)` は `NaN`（数ではない）になります。`|| 0` で、その場合は 0 にしています
- ブラウザの設定（プライベートモードなど）によっては localStorage が使えずエラーになることがあるので、`try { ... } catch` で囲んでいます

名前（キー）は同じサイトのほかのゲームとぶつからないよう、ゲームの名前を入れたものにしています。

## ゲームオーバーで記録を更新する

`gameOver()` を **関数ごと書きかえます**。

```js:game.js
  function gameOver() {
    state = 'over'; drag = null;
    let newBest = false;
    if (score > best) {
      best = score; newBest = true;
      try { localStorage.setItem(BEST_KEY, String(best)); } catch (e) { /* ignore */ }
    }
    updateHud();
    beep(300, 0.4, 'sawtooth', 0.1, 0.4);
    ovTitle.textContent = '時間切れ！';
    ovText.innerHTML = `ステージ <b class="hl">${level}</b> まで到達<br>スコア <b class="hl">${score}</b>` +
      (newBest ? '<br>ハイスコア更新！' : `<br>ハイスコア ${best}`);
    startBtn.textContent = 'もう一度';
    setTimeout(() => overlay.classList.remove('hidden'), 500);
  }
```

- 今回のスコアが `best` より大きければ、`best` を更新して localStorage に保存し、`newBest` を `true` にします
- `String(best)` で数を文字列に直してから保存しています
- 下がっていく「ブーン」という音（`'sawtooth'` で `slide` が `0.4`）で、時間切れを知らせます
- 最後の行の `(newBest ? A : B)` は **条件演算子** です。記録更新なら「ハイスコア更新！」、そうでなければ今のハイスコアを文章の最後に足します

これで、このゲームの完成です！ ゲーム本体の `game.js` と見比べてみてください。同じ内容になっているはずです。

> [!CHECK] 動作チェック
> - 箱を出して得点してから時間切れになると、「ハイスコア更新！」と表示され、BEST の数字がスコアと同じになる
> - ページを再読み込みしても、BEST の数字が残っている
> - 前の記録に届かなかったときは「ハイスコア 〇〇」と表示される

## 改造アイデア

> [!TIP]
> **盤面を広げる**: `COLS` と `ROWS` を 7×8 などに変えてみましょう。`resize()` も `generate()` もこの2つの定数から計算しているので、それだけで大きな盤面になります。箱の目標数（`Math.min(4 + level, 14)`）も増やすと歯ごたえが出ます。

> [!TIP]
> **新しい形の箱**: `SHAPES` に `[3, 2]` や `[2, 3]` を足すと、大きな箱が出てきます。出口の幅の上限（今は3マス）を4にすると、もっと大きな箱も出せるようになります。

> [!TIP]
> **手数を数える**: `tryMove()` が `true` を返した回数を数えて、ステージクリア時に「〇手でクリア」と表示してみましょう。少ない手数ほどボーナスにすると、パズルらしさが増します。

> [!TIP]
> **持ち上げ演出**: ステップ6で用意した `b.pop` を使い、つかんだ瞬間だけ箱を少し大きく描いて、ループで `pop` を 0 に戻していくと「ぷにっ」とした手ざわりになります。

> [!TIP]
> **ひと休みボタン**: `state` に `'pause'` を足して、P キーで時間を止められるようにしてみましょう。ループの `if (state === 'play')` に入らなくなるだけで、時間は止まります。
