## このステップのゴール

PC で **キーボードだけでも遊べる** ようにします。Tab（または Q・E）で箱を選ぶと白い枠がつき、矢印キー（または WASD）で1マスずつ動かせます。Enter / Space でスタートやリトライもできるようにします。

## 選んでいる箱を覚える

`let drag = null;` を次のように **書きかえます**。

```js:game.js
  let drag = null, selected = -1, showSel = false;
```

- `selected` … キーボードで選んでいる箱が、`blocks` 配列の何番目か。`-1` は「まだ選んでいない」
- `showSel` … 白い選択枠を見せるかどうか。マウスや指で遊んでいる人には枠はいらないので、キーを押したときだけ `true` にします

`generate()` の最後の `drag = null;` を次のように **書きかえます**。新しいステージでは選択を取り消します。

```js:game.js
    selected = -1; drag = null;
```

`exitBlock()` の `if (drag && drag.b === b) drag = null;` の **下** に1行足します。

```js:game.js
    if (selected >= blocks.length) selected = blocks.length - 1;
```

箱を配列から取りのぞくと、配列が1つ短くなります。選んでいた番号が配列の外になってしまったら、最後の箱を選び直します。

`pointerdown` の中、`b.pop = 1;` の **上** に1行足します。

```js:game.js
    selected = blocks.indexOf(b); showSel = false;
```

マウスや指でつかんだ箱を選択中にしておくと、そのあとキーボードに持ちかえたときにその箱から続けられます。

## キー入力

`cv.addEventListener('pointercancel', endDrag);` の **下** に追加します。

```js:game.js
  window.addEventListener('keydown', (e) => {
    if (state === 'title' || state === 'over') {
      if ((e.key === 'Enter' || e.key === ' ') && !overlay.classList.contains('hidden')) { e.preventDefault(); startGame(); }
      return;
    }
    if (state !== 'play' || !blocks.length) return;
    const k = e.key;
    if (k === 'Tab' || k === 'e' || k === 'E' || k === 'q' || k === 'Q') {
      e.preventDefault();
      const dir = (k === 'q' || k === 'Q' || (k === 'Tab' && e.shiftKey)) ? -1 : 1;
      selected = selected < 0 ? 0 : (selected + dir + blocks.length) % blocks.length;
      showSel = true;
      beep(300, 0.04, 'square', 0.04);
      return;
    }
    const dirs = { ArrowLeft: [-1, 0], ArrowRight: [1, 0], ArrowUp: [0, -1], ArrowDown: [0, 1], a: [-1, 0], d: [1, 0], w: [0, -1], s: [0, 1] };
    if (dirs[k]) {
      e.preventDefault();
      if (selected < 0) selected = 0;
      showSel = true;
      const b = blocks[selected];
      if (b && !tryMove(b, dirs[k][0], dirs[k][1])) beep(140, 0.06, 'square', 0.04);
    }
  });
```

### keydown イベント

キーを押すと `keydown` イベントが起き、`e.key` に押したキーの名前（`'ArrowLeft'`・`'Enter'`・`' '`（スペース）・`'q'` など）が入っています。`window` に登録しているので、どこにフォーカスがあっても受け取れます。

### タイトル画面とゲームオーバー画面

Enter か Space で `startGame()` します。`!overlay.classList.contains('hidden')` で「オーバーレイが見えているとき」に限っているので、ゲームオーバーの直後（0.5 秒の待ち時間）に押してもすぐには始まりません。

`e.preventDefault()` はブラウザが元々するふるまいを止める命令です。Space でページがスクロールしたり、Tab でフォーカスがボタンに移ったりするのを防いでいます。

### 箱を選ぶ

- Tab・E なら次の箱、Shift+Tab・Q なら前の箱を選びます
- `(selected + dir + blocks.length) % blocks.length` は、番号を **ぐるっと一周させる** 計算です。最後の次は 0 番、0 番の前は最後になります。`+ blocks.length` は、`-1` になったとき `%` の結果がマイナスにならないようにするためです

### 箱を動かす

`dirs` は「キーの名前 → 動かす向き」の対応表です。`dirs[k]` で向きを引けるので、`if` 文を8個並べずにすみます。動かすのはステップ3で作った `tryMove()` そのままです。出口の前で押せば、ちゃんと外へ出ます。動けなかったときは低い「ブッ」という音で知らせます。

## 選択枠を描く

`draw()` の `if (drag) drawBlock(...);` の **下** に追加します。

```js:game.js
    if (showSel && blocks[selected] && state === 'play') {
      const b = blocks[selected];
      ctx.strokeStyle = '#fff'; ctx.lineWidth = 3;
      rr(ox + b.dx * cs + 2, oy + b.dy * cs + 2, b.w * cs - 4, b.h * cs - 4, cs * 0.2); ctx.stroke();
    }
```

選んでいる箱の描く位置（`dx, dy`）に合わせて、白い角丸の線を引きます。`dx, dy` を使うので、枠も箱と一緒になめらかに動きます。

> [!CHECK] 動作チェック
> - タイトル画面で Enter（または Space）を押すとゲームが始まる
> - Tab を押すと箱に白い枠がつき、押すたびに次の箱へ移る。Q で前の箱に戻る
> - 矢印キーで選んだ箱が1マスずつ動き、ぶつかると「ブッ」と鳴る。出口の前でその方向へ押すと外へ出る
> - マウスで箱をつかむと白い枠が消える
> - ゲームオーバー画面で Enter を押すとやり直せる
