## このステップのゴール

ゲームの中心ルール「**同じ色の出口にぴったり合った箱は、外へ押し出せる**」を作ります。出口より幅の広い箱や、色のちがう箱は出られません。出た箱はすべるように消え、出口が白く光ります。

## 出口に合っているかを調べる gateFor()

`function fits(...) {...}` の **下** に追加します。

```js:game.js
  // gate on the given side that matches the block's color and lines up with it
  function gateFor(b, x, y, side) {
    for (const g of gates) {
      if (g.color !== b.color || g.side !== side) continue;
      if (side === 'L' && x === 0 && y >= g.start && y + b.h <= g.start + g.len) return g;
      if (side === 'R' && x + b.w === COLS && y >= g.start && y + b.h <= g.start + g.len) return g;
      if (side === 'T' && y === 0 && x >= g.start && x + b.w <= g.start + g.len) return g;
      if (side === 'B' && y + b.h === ROWS && x >= g.start && x + b.w <= g.start + g.len) return g;
    }
    return null;
  }
```

「箱 `b` が `(x, y)` にあるとき、`side` の辺から外へ出られる出口があるか」を調べ、あればその出口を、なければ `null` を返します。条件は3つです。

1. 出口の色と箱の色が同じ（`g.color !== b.color` なら次の出口へ）
2. 箱がその辺にくっついている。左なら `x === 0`、右なら `x + b.w === COLS`（箱の右端が盤面の右端）
3. 箱の幅が出口の中に **全部おさまっている**。左右の辺なら、箱の上端 `y` が出口の上端 `g.start` 以上で、箱の下端 `y + b.h` が出口の下端 `g.start + g.len` 以下

3つめの条件のおかげで、「出口より幅の広い箱は通れない」「ずれていると通れない」というルールが自然に表せます。たとえば幅2の出口に縦3マスの箱は、どこに置いても条件を満たしません。

## tryMove() で外へ押し出す

`tryMove()` を **関数ごと書きかえます**。

```js:game.js
  function tryMove(b, dx, dy) {
    const nx = b.x + dx, ny = b.y + dy;
    if (nx < 0 || ny < 0 || nx + b.w > COLS || ny + b.h > ROWS) {
      const side = nx < 0 ? 'L' : nx + b.w > COLS ? 'R' : ny < 0 ? 'T' : 'B';
      const g = gateFor(b, b.x, b.y, side);
      if (g) { exitBlock(b, dx, dy, g); return 'exit'; }
      return false;
    }
    if (!fits(buildOcc(b), nx, ny, b.w, b.h)) return false;
    b.x = nx; b.y = ny;
    return true;
  }
```

盤面からはみ出しそうになったとき、すぐに `false` を返すのではなく、

1. どの辺からはみ出そうとしたか（`side`）を調べる。`nx < 0` なら左、`nx + b.w > COLS` なら右…という順です
2. **今の位置** `b.x, b.y` で、その辺に合う出口があるか `gateFor()` で調べる
3. あれば `exitBlock()` で箱を外へ出し、`'exit'` という文字列を返す

`true`・`false` に加えて `'exit'` を返すのは、呼んだ側で「動いた」と「外へ出た」を区別するためです。

## 箱を外へ出す exitBlock()

変数の `let blocks = [], gates = [];` を次のように **書きかえます**。

```js:game.js
  let blocks = [], gates = [], leaving = [];
```

`tryMove()` の **下** に追加します。

```js:game.js
  function exitBlock(b, dx, dy, g) {
    const i = blocks.indexOf(b);
    if (i < 0) return;
    blocks.splice(i, 1);
    leaving.push({ b, dx, dy, t: 0 });
    g.flash = 0.4;
    if (drag && drag.b === b) drag = null;
    if (blocks.length === 0) generate();
  }
```

- `blocks.splice(i, 1)` で、箱を配列から取りのぞきます。これでもう当たり判定にも入りません
- 消える演出のために、`leaving`（出ていく途中の箱）に「どの箱か」「どっち向きに出たか（`dx, dy`）」「経過時間 `t`」を入れておきます
- `g.flash = 0.4` で、出口を 0.4 秒だけ白く光らせます
- ドラッグ中の箱が出ていったら、`drag` を空にします
- 全部出したら、とりあえず `generate()` でお手本の盤面を作り直します（ステップ7で「ステージクリア」に変えます）

## stepToward() を出口に対応させる

`stepToward()` を **関数ごと書きかえます**。

```js:game.js
  function stepToward(b, tx, ty) {
    for (let n = 0; n < 24; n++) {
      if (!blocks.includes(b)) return;
      const ddx = tx - b.x, ddy = ty - b.y;
      if (ddx === 0 && ddy === 0) return;
      const ax = [Math.sign(ddx), 0], ay = [0, Math.sign(ddy)];
      const first = Math.abs(ddx) >= Math.abs(ddy) ? ax : ay;
      const second = first === ax ? ay : ax;
      let r = false;
      if (first[0] || first[1]) r = tryMove(b, first[0], first[1]);
      if (r === 'exit') return;
      if (!r && (second[0] || second[1])) r = tryMove(b, second[0], second[1]);
      if (r === 'exit' || !r) return;
    }
  }
```

足したのは3か所です。箱が外へ出たら（`'exit'`）、それ以上動かそうとせずにすぐ終わります。また、ループの先頭の `if (!blocks.includes(b)) return;` で、もう盤面にない箱を動かさないようにしています。

## 出ていく箱と光る出口を描く

`draw()` の出口を塗る2行目（`ctx.fillStyle = c.fill; ...`）を次のように **書きかえます**。

```js:game.js
      ctx.fillStyle = g.flash > 0 ? '#ffffff' : c.fill; rr(x + 2, y + 2, w - 4, h - 4, 3); ctx.fill();
```

`draw()` の `if (drag) drawBlock(...);` の **下** に追加します。

```js:game.js
    for (const l of leaving) {
      const d = l.t * 6;
      drawBlock(l.b, l.b.dx + l.dx * d, l.b.dy + l.dy * d, Math.max(0, 1 - l.t * 3), false);
    }
```

出ていく箱は、出た向きに1秒あたり6マスの速さで進めながら、透明度 `alpha` を `1 - t * 3` で下げていきます。約0.33秒で見えなくなります。

最後に `loop()` の、箱をなめらかに動かす `for` 文の **下** に追加します。

```js:game.js
    for (const l of leaving) l.t += dt;
    leaving = leaving.filter(l => l.t < 0.4);
    for (const g of gates) if (g.flash > 0) g.flash -= dt;
```

`filter()` は条件に合う要素だけを残した **新しい配列** を返します。0.4 秒たった箱は `leaving` から消えます。

> [!CHECK] 動作チェック
> - 赤い縦長の箱を左へ引っぱると、左の赤い出口から外へすべり出て消え、出口が一瞬白く光る
> - 青い縦長の箱を右下へ動かし、右の青い出口（下の3マス）にぴったり合わせてさらに右へ押すと外へ出る。出口からずれた位置では出られない
> - 黄色の箱を上の黄色い出口から出すには、先に上の緑の箱をどかす必要がある
> - 5つ全部出すと、お手本の盤面がもう一度並ぶ
