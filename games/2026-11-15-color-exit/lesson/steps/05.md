## このステップのゴール

お手本の盤面をやめて、**毎回ちがうステージを自動で作る** ようにします。ステージが進むほど色・箱・石（動かせないじゃま物）が増えて難しくなります。大事なのは、**どの箱も必ず出口までたどり着ける** ように作ることです。

## 準備

`const COLORS = [...];` の **下** に、箱の形の一覧を追加します。`[横, 縦]` のマス数です。

```js:game.js
  const SHAPES = [[1, 1], [2, 1], [1, 2], [3, 1], [1, 3], [2, 2]];
```

変数を次のように **書きかえます**（`level` の行を足し、`blocks` の行に `stones` を足します）。

```js:game.js
  let state = 'title'; // title | play | clear | over
  let level = 1;
  let blocks = [], gates = [], stones = [], leaving = [];
  let now = 0;
```

`// ---------- level generation ----------` の **すぐ下** に、2つの小さな道具を追加します。

```js:game.js
  const rnd = (n) => Math.floor(Math.random() * n);
  function sideLen(side) { return side === 'L' || side === 'R' ? ROWS : COLS; }
```

- `rnd(n)` … 0 から `n - 1` までの整数をランダムに返します
- `sideLen(side)` … その辺が何マスあるか。左右の辺なら縦の7、上下の辺なら横の6です

石も「ふさがっているマス」なので、`buildOcc()` の、全部 `false` の表を作る `for` 文の **下** に1行足します。

```js:game.js
    for (let y = 0; y < ROWS; y++) occ.push(new Array(COLS).fill(false));
    for (const s of stones) occ[s.y][s.x] = true;
```

## 出口までたどり着けるか canEscape()

`gateFor()` の **下** に追加します。

```js:game.js
  function canEscape(b, occ) {
    const seen = new Set(), q = [[b.x, b.y]];
    seen.add(b.x + ',' + b.y);
    while (q.length) {
      const [x, y] = q.shift();
      for (const s of ['L', 'R', 'T', 'B']) if (gateFor(b, x, y, s)) return true;
      for (const [dx, dy] of [[1, 0], [-1, 0], [0, 1], [0, -1]]) {
        const nx = x + dx, ny = y + dy, k = nx + ',' + ny;
        if (!seen.has(k) && fits(occ, nx, ny, b.w, b.h)) { seen.add(k); q.push([nx, ny]); }
      }
    }
    return false;
  }
```

ランダムに箱を置くと、「出口より大きくて出られない」「石に囲まれて動けない」箱ができてしまうことがあります。そこで、置く前に **その箱だけで出口までたどり着けるか** を調べます。

使っているのは **幅優先探索（BFS）** という方法です。

1. 箱の今の位置を「調べる予定のリスト」`q` に入れる
2. リストの先頭を取り出し（`q.shift()`）、そこが出口に合っていれば `true`
3. 合っていなければ、上下左右に1マスずつ動かした位置のうち、**置けて**、**まだ調べていない** 位置をリストの最後に足す
4. リストが空になるまで続けて、見つからなければ `false`

`seen` は調べた位置を覚えておく `Set`（重複しない集まり）です。`'3,4'` のような文字列にして入れています。これがないと、同じ場所を行ったり来たりして終わらなくなります。

> [!NOTE]
> ほかの箱は「動かない」ものとして調べています。ほかの箱をどかせば通れる場合もあるので、実際の遊びでは「どれから出すか」を考える楽しさが残ります。

## generate() を本物にする

`generate()` を **関数ごと書きかえます**。

```js:game.js
  function generate() {
    gates = []; stones = []; blocks = []; leaving = [];
    const nColors = Math.min(2 + level, 5);
    const order = [0, 1, 2, 3, 4].sort(() => Math.random() - 0.5).slice(0, nColors);
    const sides = ['L', 'R', 'T', 'B'].sort(() => Math.random() - 0.5);
    order.forEach((color, i) => {
      for (let t = 0; t < 50; t++) {
        const side = t < 10 ? sides[i % 4] : sides[rnd(4)];
        const r = Math.random();
        const len = level <= 2 ? (r < 0.5 ? 2 : 3) : (r < 0.2 ? 1 : r < 0.75 ? 2 : 3);
        const start = rnd(sideLen(side) - len + 1);
        const clash = gates.some(g => g.side === side && start < g.start + g.len + 1 && g.start < start + len + 1);
        if (!clash) { gates.push({ side, start, len, color }); break; }
      }
    });
    const nStones = level >= 3 ? Math.min(Math.floor((level - 1) / 2), 5) : 0;
    for (let t = 0; t < 100 && stones.length < nStones; t++) {
      const x = rnd(COLS), y = rnd(ROWS);
      if (!stones.some(s => s.x === x && s.y === y)) stones.push({ x, y });
    }
    const target = Math.min(4 + level, 14);
    for (let t = 0; t < 1500 && blocks.length < target; t++) {
      const g = gates[rnd(gates.length)];
      const vertical = g.side === 'L' || g.side === 'R';
      const options = SHAPES.filter(([w, h]) => (vertical ? h : w) <= g.len);
      const [w, h] = options[rnd(options.length)];
      const b = { x: rnd(COLS - w + 1), y: rnd(ROWS - h + 1), w, h, color: g.color };
      const occ = buildOcc(null);
      if (!fits(occ, b.x, b.y, w, h)) continue;
      if (!canEscape(b, occ)) continue;
      // prefer blocks that are not trivially sitting in front of their gate (after the first few)
      if (blocks.length > 2 && ['L', 'R', 'T', 'B'].some(s => gateFor(b, b.x, b.y, s)) && Math.random() < 0.7) continue;
      b.dx = b.x; b.dy = b.y; b.pop = 0;
      blocks.push(b);
    }
    drag = null;
  }
```

上から順に、4つのことをしています。

### 1. 出口を作る

- 色の数は `Math.min(2 + level, 5)`。ステージ1は3色、ステージ3からは5色です
- `[0, 1, 2, 3, 4].sort(() => Math.random() - 0.5)` は配列を **ざっくりシャッフル** する短い書き方です。先頭から必要な数だけ `slice()` で取ります
- 最初の10回は `sides[i % 4]` で、色ごとにちがう辺を使うようにしています。出口が1つの辺にかたまらないための工夫です
- 出口の幅 `len` は、ステージ1〜2は2か3マス、ステージ3からは1マスの細い出口も出てきます
- `clash` は、同じ辺のほかの出口と **重なる・くっつく** かどうかです。`+ 1` で1マス以上のすき間をあけています。重なったら、50回までやり直します

### 2. 石を置く

ステージ3から石が出てきます（`(level - 1) / 2` を切り捨て、最大5個）。同じマスに2つ置かないように `some()` で確かめています。

### 3. 箱を置く

目標の数は `4 + level` 個（最大14個）。最大1500回、次のことをくり返します。

1. ランダムに出口を1つ選び、その色の箱にする
2. `SHAPES` から、その出口を **通れる形** だけを `filter()` で選ぶ。左右の出口なら縦の長さ、上下の出口なら横の長さが `g.len` 以下の形です
3. ランダムな位置に置けなければ（`fits`）やり直し
4. 出口までたどり着けなければ（`canEscape`）やり直し
5. 4つめ以降は、**最初から出口の前にいる箱** を7割の確率でやり直し。置いてすぐ押すだけで出せる箱ばかりだと、簡単すぎるからです

`continue` は「この回の残りを飛ばして、次の回へ進む」という命令です。

`b.pop` は箱を持ち上げたときの印です（次のステップで使います）。

### 4. 後かたづけ

最後に `drag = null;` でドラッグを取り消します。

## スタートで新しいステージを作る

`startGame()` を次のように **書きかえます**。

```js:game.js
  function startGame() {
    level = 1;
    overlay.classList.add('hidden');
    generate();
    state = 'play';
  }
```

`exitBlock()` の最後の行も、全部出したら次のステージへ進むように **書きかえます**。

```js:game.js
    if (blocks.length === 0) { level++; generate(); }
```

## 石を描く

`draw()` の `// blocks` の **上** に追加します。

```js:game.js
    // stones
    for (const s of stones) {
      const x = ox + s.x * cs + cs * 0.06, y = oy + s.y * cs + cs * 0.06, w = cs * 0.88;
      ctx.fillStyle = '#5a6475'; rr(x, y + cs * 0.05, w, w, cs * 0.14); ctx.fill();
      ctx.fillStyle = '#7d889b'; rr(x, y, w, w - cs * 0.05, cs * 0.14); ctx.fill();
      ctx.strokeStyle = 'rgba(0,0,0,.25)'; ctx.lineWidth = 2;
      ctx.beginPath(); ctx.moveTo(x + w * 0.3, y + w * 0.3); ctx.lineTo(x + w * 0.7, y + w * 0.7);
      ctx.moveTo(x + w * 0.7, y + w * 0.3); ctx.lineTo(x + w * 0.3, y + w * 0.7); ctx.stroke();
    }
```

灰色の角丸の四角に、×じるしの線を引いて「動かせないもの」に見せています。`moveTo()` と `lineTo()` を2組続けてから `stroke()` を1回呼ぶと、2本の線をまとめて引けます。

> [!CHECK] 動作チェック
> - 再読み込みするたびに、出口と箱の並びが変わる（ステージ1は3色・箱5個）
> - 出口より幅の広い箱は出てこない。どの箱も、まわりの箱をどかせば同じ色の出口へたどり着ける位置にある
> - 全部出すと新しい盤面になり、色と箱が増えていく。3面目から灰色の石が出てくる（ステージ番号の表示は次のステップで作ります）
