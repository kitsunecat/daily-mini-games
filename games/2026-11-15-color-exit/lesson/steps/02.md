## このステップのゴール

盤面の枠に **色つきの出口**、盤面の中に **色つきの箱** を描きます。まだ動かせませんが、まずは「お手本の盤面」を手で書いて、データと見た目の対応をつかみましょう。

## 色と記号を決める

`const COLS = 6, ROWS = 7;` の **下** に追加します。

```js:game.js
  const COLORS = [
    { fill: '#ff5d6c', dark: '#b8303f', name: 'circle' },
    { fill: '#4da3ff', dark: '#2061b0', name: 'square' },
    { fill: '#ffd23f', dark: '#b98c00', name: 'triangle' },
    { fill: '#43d17a', dark: '#1d8a48', name: 'diamond' },
    { fill: '#b07cff', dark: '#6d3fc0', name: 'star' },
  ];
```

1色ごとに「明るい色（`fill`）」「影の色（`dark`）」「記号の名前（`name`）」をまとめたオブジェクトです。箱や出口は **色の番号**（0〜4）だけを持ち、描くときに `COLORS[番号]` で色を引きます。色ごとに ●■▲◆★ の記号も変えるのは、色の見分けがつきにくい人でも遊べるようにするためです。

## 箱と出口のデータ

`let state = 'title';` の **下** に1行追加します。

```js:game.js
  let blocks = [], gates = [];
```

そして `window.addEventListener('resize', resize);` の **下** に、お手本の盤面を作る `generate()` を追加します。

```js:game.js
  // ---------- level generation ----------
  function generate() {
    gates = [
      { side: 'L', start: 1, len: 2, color: 0 },
      { side: 'R', start: 4, len: 3, color: 1 },
      { side: 'T', start: 2, len: 2, color: 2 },
      { side: 'B', start: 0, len: 3, color: 3 },
    ];
    blocks = [
      { x: 1, y: 1, w: 1, h: 2, color: 0 },
      { x: 4, y: 2, w: 1, h: 3, color: 1 },
      { x: 0, y: 3, w: 2, h: 1, color: 2 },
      { x: 2, y: 0, w: 3, h: 1, color: 3 },
      { x: 5, y: 0, w: 1, h: 1, color: 3 },
    ];
    for (const b of blocks) { b.dx = b.x; b.dy = b.y; }
  }
```

### 出口（gate）

出口は `{ side, start, len, color }` で表します。

- `side` … どの辺にあるか。`'L'`（左）・`'R'`（右）・`'T'`（上）・`'B'`（下）
- `start` … その辺の何マス目から始まるか（左右の辺なら上から、上下の辺なら左から数える）
- `len` … 何マスぶんの幅があるか
- `color` … 色の番号

たとえば `{ side: 'L', start: 1, len: 2, color: 0 }` は「左の辺の、上から1〜2マス目にある赤い出口」です。

### 箱（block）

箱は `{ x, y, w, h, color }` で表します。`x, y` は箱の **左上のマス**、`w, h` は横と縦に何マスあるかです。`{ x: 4, y: 2, w: 1, h: 3, color: 1 }` は「(4, 2) から下に3マスぶん伸びる青い箱」になります。

最後の `b.dx = b.x; b.dy = b.y;` は **描くときの位置** です。今は `x, y` と同じですが、次のステップで「マスの位置（`x, y`）はすぐ変わり、見た目の位置（`dx, dy`）はそれを追いかけてなめらかに動く」という仕組みに使います。

> [!NOTE]
> この `generate()` は練習用です。ステップ5で、ランダムにステージを作る本物の `generate()` に書きかえます。

## 記号を描く symbol()

`function rr(...) {...}` の **下** に追加します。

```js:game.js
  function symbol(name, x, y, s, color) {
    ctx.fillStyle = color;
    ctx.beginPath();
    if (name === 'circle') ctx.arc(x, y, s, 0, Math.PI * 2);
    else if (name === 'square') ctx.rect(x - s * 0.85, y - s * 0.85, s * 1.7, s * 1.7);
    else if (name === 'triangle') { ctx.moveTo(x, y - s); ctx.lineTo(x + s, y + s * 0.8); ctx.lineTo(x - s, y + s * 0.8); }
    else if (name === 'diamond') { ctx.moveTo(x, y - s * 1.1); ctx.lineTo(x + s, y); ctx.lineTo(x, y + s * 1.1); ctx.lineTo(x - s, y); }
    else {
      for (let i = 0; i < 10; i++) {
        const a = -Math.PI / 2 + i * Math.PI / 5, r = i % 2 ? s * 0.45 : s * 1.1;
        ctx.lineTo(x + Math.cos(a) * r, y + Math.sin(a) * r);
      }
    }
    ctx.closePath(); ctx.fill();
  }
```

`(x, y)` を中心に、大きさ `s` の記号を描きます。円は `arc()`、四角は `rect()`、三角とひし形は `moveTo()` と `lineTo()` で頂点を順につないでいます。星は、外側の点（半径 `s * 1.1`）と内側の点（半径 `s * 0.45`）を交互に10個、36度（`Math.PI / 5`）ずつ回しながらつないで作ります。

## 箱を描く drawBlock()

`symbol()` の **下** に追加します。

```js:game.js
  function drawBlock(b, px, py, alpha, lifted) {
    const c = COLORS[b.color];
    const pad = cs * 0.06, x = ox + px * cs + pad, y = oy + py * cs + pad;
    const w = b.w * cs - pad * 2, h = b.h * cs - pad * 2, r = cs * 0.18;
    ctx.save();
    ctx.globalAlpha = alpha;
    if (lifted) { ctx.shadowColor = 'rgba(0,0,0,.5)'; ctx.shadowBlur = 14; ctx.shadowOffsetY = 6; }
    ctx.fillStyle = c.dark; rr(x, y + cs * 0.06, w, h, r); ctx.fill();
    ctx.shadowColor = 'transparent';
    ctx.fillStyle = c.fill; rr(x, y, w, h - cs * 0.04, r); ctx.fill();
    ctx.fillStyle = 'rgba(255,255,255,.28)'; rr(x + cs * 0.1, y + cs * 0.07, w - cs * 0.2, cs * 0.16, cs * 0.08); ctx.fill();
    for (let j = 0; j < b.h; j++) for (let i = 0; i < b.w; i++) {
      symbol(c.name, ox + (px + i + 0.5) * cs, oy + (py + j + 0.52) * cs, cs * 0.16, 'rgba(255,255,255,.75)');
    }
    ctx.restore();
  }
```

- `px, py` は描く位置（マス単位）。`ox + px * cs` でピクセルに直します。`pad` ぶん内側に縮めて、となりの箱とすき間を作っています
- 影の色（`c.dark`）を少し下にずらして塗り、その上に明るい色を塗ると、厚みのあるボタンのような見た目になります。上のほうの白い半透明の帯はツヤです
- 最後に、箱のマスの数だけ記号を描きます。2×2 の箱なら記号が4つ並びます
- `alpha`（透明度）と `lifted`（持ち上げ中か）は、あとのステップで使います。`ctx.save()` と `ctx.restore()` で囲むと、途中で変えた透明度や影の設定が、この関数の外に残りません

## 出口の位置を求める gateRect()

`drawBlock()` の **下** に追加します。

```js:game.js
  function gateRect(g) {
    const t = border, p = 3;
    if (g.side === 'L') return [0, oy + g.start * cs + p, t, g.len * cs - p * 2];
    if (g.side === 'R') return [ox + COLS * cs, oy + g.start * cs + p, t, g.len * cs - p * 2];
    if (g.side === 'T') return [ox + g.start * cs + p, 0, g.len * cs - p * 2, t];
    return [ox + g.start * cs + p, oy + ROWS * cs, g.len * cs - p * 2, t];
  }
```

出口は盤面の外側、枠の部分に描きます。左の辺なら x は 0 から枠の太さ（`border`）まで、y は `start` マス目から `len` マスぶんです。`[x, y, 幅, 高さ]` の配列で返し、描く側で `const [x, y, w, h] = gateRect(g);` のように **分割代入** で受け取ります。`p = 3` は出口どうしがくっついて見えないようにする余白です。

## draw() で出口と箱を描く

`draw()` の中、マス目を描く `for` 文の **下** に追加します。

```js:game.js
    // gates
    for (const g of gates) {
      const c = COLORS[g.color];
      const [x, y, w, h] = gateRect(g);
      ctx.fillStyle = c.dark; rr(x, y, w, h, 4); ctx.fill();
      ctx.fillStyle = c.fill; rr(x + 2, y + 2, w - 4, h - 4, 3); ctx.fill();
      const vertical = g.side === 'L' || g.side === 'R';
      for (let i = 0; i < g.len; i++) {
        const sx = vertical ? x + w / 2 : ox + (g.start + i + 0.5) * cs;
        const sy = vertical ? oy + (g.start + i + 0.5) * cs : y + h / 2;
        symbol(c.name, sx, sy, border * 0.26, 'rgba(0,0,0,.35)');
      }
    }
    // blocks
    for (const b of blocks) drawBlock(b, b.dx, b.dy, 1, false);
```

出口の中には、出口の幅（`len`）の数だけ記号を並べます。「この出口は何マスぶんの幅か」がひと目で分かるようにするためです。

最後に `resize();` の **下** に `generate();` を足して、ページを開いたときにお手本の盤面を作ります。

```js:game.js
  resize();
  generate();
  requestAnimationFrame(loop);
```

> [!CHECK] 動作チェック
> - 枠の左に赤、右に青、上に黄、下に緑の出口が見える。出口の中に、幅のマス数だけ記号（● ■ ▲ ◆）が並んでいる
> - 盤面に、赤の縦長・青の縦長・黄の横長・緑の横長・緑の小さい箱の5つが並んでいる
> - 箱の記号の数が、箱のマスの数と同じになっている
