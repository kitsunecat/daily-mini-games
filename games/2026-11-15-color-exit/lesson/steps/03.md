## このステップのゴール

箱を **ドラッグで縦横に動かせる** ようにします。ほかの箱や盤面の端にぶつかったら止まり、動いた箱は **すっと吸いつくように** マスへおさまります。

## マスが空いているかを調べる

まず「どのマスがふさがっているか」を表にする関数を作ります。`// ---------- level generation ----------` の **下**（`generate()` の上）に追加します。

```js:game.js
  function buildOcc(except) {
    const occ = [];
    for (let y = 0; y < ROWS; y++) occ.push(new Array(COLS).fill(false));
    for (const b of blocks) {
      if (b === except) continue;
      for (let y = 0; y < b.h; y++) for (let x = 0; x < b.w; x++) occ[b.y + y][b.x + x] = true;
    }
    return occ;
  }
  function fits(occ, x, y, w, h) {
    if (x < 0 || y < 0 || x + w > COLS || y + h > ROWS) return false;
    for (let j = 0; j < h; j++) for (let i = 0; i < w; i++) if (occ[y + j][x + i]) return false;
    return true;
  }
```

### buildOcc() … ふさがっているマスの表

`occ` は **2次元配列** です。`occ[y][x]` が `true` ならそのマスはふさがっています。まず全部 `false` の 7行×6列の表を作り、それぞれの箱が占めるマスに `true` を書きこみます。

引数の `except` には「表に入れない箱」を渡します。箱を動かすときは、**動かす箱そのもの** を除いた表で調べないと、自分自身にぶつかって動けなくなってしまうからです。

### fits() … そこに置けるか

「左上が `(x, y)` で、大きさ `w × h` の箱を置けるか」を調べます。

1. 盤面からはみ出すなら置けない
2. 箱が重なるマスを全部調べて、1つでも `true`（ふさがっている）があれば置けない

このように **マス目の表で当たり判定をする** と、ピクセル単位で四角形の重なりを計算するより、ずっと簡単で確実になります。

## 箱を1マス動かす

変数に、ドラッグ中の情報を入れる `drag` を追加します。`let now = 0;` の **下** です。

```js:game.js
  let drag = null;
```

`generate()` の最後（`for (const b of blocks) ...` の行の下）にも `drag = null;` を足して、盤面を作り直したらドラッグを取り消すようにします。

```js:game.js
    for (const b of blocks) { b.dx = b.x; b.dy = b.y; }
    drag = null;
  }
```

次に、`startGame()` の **下**（`// ---------- input ----------` の上）に追加します。

```js:game.js
  // ---------- moving ----------
  function tryMove(b, dx, dy) {
    const nx = b.x + dx, ny = b.y + dy;
    if (nx < 0 || ny < 0 || nx + b.w > COLS || ny + b.h > ROWS) return false;
    if (!fits(buildOcc(b), nx, ny, b.w, b.h)) return false;
    b.x = nx; b.y = ny;
    return true;
  }

  function stepToward(b, tx, ty) {
    for (let n = 0; n < 24; n++) {
      const ddx = tx - b.x, ddy = ty - b.y;
      if (ddx === 0 && ddy === 0) return;
      const ax = [Math.sign(ddx), 0], ay = [0, Math.sign(ddy)];
      const first = Math.abs(ddx) >= Math.abs(ddy) ? ax : ay;
      const second = first === ax ? ay : ax;
      let r = false;
      if (first[0] || first[1]) r = tryMove(b, first[0], first[1]);
      if (!r && (second[0] || second[1])) r = tryMove(b, second[0], second[1]);
      if (!r) return;
    }
  }
```

### tryMove() … 1マスだけ動かす

`(dx, dy)` は動かす向きで、`(1, 0)` なら右、`(0, -1)` なら上です。盤面からはみ出すなら `false`、ほかの箱にぶつかるなら `false`、置けるなら `x, y` を書きかえて `true` を返します。出口から外へ出す処理は、次のステップでここに足します。

### stepToward() … 指の位置まで1マスずつ近づける

ドラッグ中に指が一気に3マス先へ動いても、箱を **ワープ** させてはいけません。間にほかの箱があったらすり抜けてしまうからです。そこで、目的のマス `(tx, ty)` に向かって **1マスずつ** `tryMove()` を呼び、ぶつかったところで止めます。

- `Math.sign()` は数の符号（`1`・`-1`・`0`）を返します。これで「右へ」「左へ」の向きが分かります
- 横と縦のうち **ずれが大きいほう** を先に試し（`first`）、だめならもう一方（`second`）を試します。ななめにドラッグしても、角を回りこむように動いてくれます
- どちらも動けなければ、そこで終わりです。`n < 24` は念のための回数の上限です

## ドラッグの入力

`// ---------- input ----------` の **下**（`startBtn.addEventListener(...)` の上）に追加します。

```js:game.js
  function toCell(e) {
    const r = cv.getBoundingClientRect();
    return { x: (e.clientX - r.left - ox) / cs, y: (e.clientY - r.top - oy) / cs };
  }
  function blockAt(px, py) {
    const cx = Math.floor(px), cy = Math.floor(py);
    return blocks.find(b => cx >= b.x && cx < b.x + b.w && cy >= b.y && cy < b.y + b.h);
  }
  cv.addEventListener('pointerdown', (e) => {
    if (state !== 'play') return;
    const p = toCell(e);
    const b = blockAt(p.x, p.y);
    if (!b) return;
    e.preventDefault();
    try { cv.setPointerCapture(e.pointerId); } catch (err) { /* ignore */ }
    drag = { b, offX: p.x - b.x, offY: p.y - b.y, id: e.pointerId };
  });
  cv.addEventListener('pointermove', (e) => {
    if (!drag || state !== 'play' || e.pointerId !== drag.id) return;
    const p = toCell(e);
    stepToward(drag.b, Math.round(p.x - drag.offX), Math.round(p.y - drag.offY));
  });
  const endDrag = (e) => { if (drag && e.pointerId === drag.id) drag = null; };
  cv.addEventListener('pointerup', endDrag);
  cv.addEventListener('pointercancel', endDrag);
```

### toCell() … 画面の座標をマスの座標に

`getBoundingClientRect()` で Canvas の画面上の位置を調べ、指の位置から引くと Canvas の中の座標になります。さらに盤面のずれ（`ox, oy`）を引いて `cs` で割ると、**マス単位の座標**（例: `2.4, 3.7`）になります。`Math.floor()` で切り捨てれば、何マス目かが分かります（`blockAt()` がそうしています）。

### Pointer Events

`pointerdown`（押した）・`pointermove`（動かした）・`pointerup`（離した）は、マウスでも指でもペンでも同じように使える **Pointer Events** です。

- `pointerdown` … 押したところに箱があれば、`drag` に「どの箱か」「箱の左上から何マスずれたところをつかんだか（`offX, offY`）」「どの指か（`id`）」を覚えます
- `setPointerCapture()` … 指が Canvas の外に出ても `pointermove` を受け取り続ける設定です。箱を出口の外まで引っぱる操作に必要になります
- `pointermove` … 指の位置からつかんだずれを引いて `Math.round()` で四捨五入すると「箱の左上を置きたいマス」になります。そこへ `stepToward()` で近づけます
- `pointerup` / `pointercancel` … 指を離したら `drag` を空にします。`e.pointerId === drag.id` を確かめるのは、2本目の指で操作がまざらないようにするためです

## 持ち上げた箱を手前に描く

`draw()` の `// blocks` の行を次のように **書きかえます**。

```js:game.js
    // blocks
    for (const b of blocks) if (!drag || drag.b !== b) drawBlock(b, b.dx, b.dy, 1, false);
    if (drag) drawBlock(drag.b, drag.b.dx, drag.b.dy, 1, true);
```

ドラッグ中の箱だけは最後に、`lifted` を `true` にして影つきで描きます。後から描いたものが手前に見えるので、持ち上げているように見えます。

## なめらかに動かす

`loop()` の `const dt = ...` の行の **下** に追加します。

```js:game.js
    const k = 1 - Math.pow(0.0005, dt);
    for (const b of blocks) { b.dx += (b.x - b.dx) * k; b.dy += (b.y - b.dy) * k; }
```

箱のマスの位置 `x, y` は1マス単位でパッと変わりますが、描く位置 `dx, dy` は毎フレーム「残りの距離の `k` 倍」だけ近づけます。近いほどゆっくりになるので、**ぴたっと吸いつく** ような動きになります。

`k` を `dt` から計算しているのは、画面の書きかえ回数（60Hz・120Hz など）がちがっても同じ速さにするためです。`Math.pow(0.0005, dt)` は「1秒後には残りの距離が 0.0005 倍（ほぼ 0）になる」という意味です。

> [!CHECK] 動作チェック
> - 「スタート」を押してから箱をドラッグすると、縦横に動き、影がついて持ち上がって見える
> - ほかの箱や盤面の端にぶつかると、それ以上進まない（すり抜けない）
> - 赤い箱を右へ1マス動かすと、すっとなめらかに移動してマスにおさまる
> - 左の赤い出口へ引っぱっても、まだ外には出ない（次のステップで出られるようにします）
