## このステップのゴール

Canvas に 8×8 の盤面を描きます。スマホでもPCでも画面サイズに合わせて盤面の大きさを計算し、高解像度ディスプレイでもくっきり表示されるようにします。あわせて、毎フレーム描き直す「ゲームループ」を用意します。

## 盤面のデータを用意する

まず `playing` の宣言を次のように書き換えて、盤面を入れる `board` と、画面の寸法をまとめる `layout` を用意します。

```js:game.js
  let board, playing = false;
  let layout = {};
```

`start()` の中で盤面を作ります。

```js:game.js
  function start() {
    board = Array.from({ length: N }, () => Array(N).fill(null));
    playing = true;
    overlay.classList.add('hidden');
  }
```

`board` は **2次元配列** です。`board[r][c]` が「r 行目・c 列目のマス」で、空なら `null`、ブロックがあればその色（`'#ff6b6b'` のような文字列）を入れます。色そのものを入れておくと、置いたブロックの色をそのまま描けて便利です。

> [!WARNING]
> `Array(N).fill(Array(N).fill(null))` と書くと、8行すべてが **同じ1つの配列** を指してしまい、1マス変えると縦一列が全部変わります。`Array.from` で行ごとに新しい配列を作るのが正解です。

## 画面サイズに合わせてレイアウトを計算する

`// ---- game logic ----` の **上** に、`resize` 関数を追加します。

```js:game.js
  // ---- layout ----
  function resize() {
    const rect = cv.getBoundingClientRect();
    const dpr = window.devicePixelRatio || 1;
    cv.width = Math.round(rect.width * dpr);
    cv.height = Math.round(rect.height * dpr);
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
    const W = rect.width, H = rect.height;
    const pad = 14;
    // board takes width, tray needs ~ board*0.42 below
    const boardSize = Math.min(W - pad * 2, (H - pad * 3) / 1.45);
    const cell = boardSize / N;
    const bx = (W - boardSize) / 2;
    const by = pad;
    const trayY = by + boardSize + pad;
    const trayH = Math.max(H - trayY - pad, cell * 3);
    layout = { W, H, cell, bx, by, boardSize, trayY, trayH, mini: cell * 0.55 };
    draw();
  }
```

Canvas には「CSS 上の見た目の大きさ」と「中身のピクセル数（`cv.width` / `cv.height`）」の2つのサイズがあります。

- `getBoundingClientRect()` で見た目の大きさ（CSS ピクセル）を取得します。
- `devicePixelRatio`（dpr）は「CSS の1ピクセルが実際の画面の何ピクセルか」。スマホだと 2〜3 が普通です。中身のピクセル数を dpr 倍にしないと、絵がぼやけます。
- `ctx.setTransform(dpr, ...)` で描画全体を dpr 倍に拡大しておくと、以後は CSS ピクセルの座標のまま描けます。

レイアウトの考え方は「盤面は横幅いっぱい、ただし下にブロック置き場（トレイ）の分を残す」です。盤面の高さを 1 としたとき、トレイを含めて約 1.45 倍の高さが必要なので、`(H - pad * 3) / 1.45` と横幅の小さいほうを盤面サイズにしています。

- `cell` … 1マスの大きさ
- `bx`, `by` … 盤面の左上の座標（`bx` は左右中央寄せ）
- `trayY`, `trayH` … 盤面の下にあるトレイの位置と高さ（次のステップで使います）
- `mini` … トレイに並べるときの小さいブロックのサイズ（次のステップで使います）

最後の行で `startBtn` のイベント登録の下に、ウィンドウサイズが変わったら計算し直す登録を足します。

```js:game.js
  startBtn.addEventListener('click', start);
  window.addEventListener('resize', resize);
```

## ブロックと盤面を描く

ファイルの末尾 `})();` の **直前** に、描画の関数を追加します。

```js:game.js
  // ---- drawing ----
  function block(x, y, s, color, alpha = 1) {
    ctx.globalAlpha = alpha;
    const g = 2;
    ctx.fillStyle = color;
    roundRect(x + g / 2, y + g / 2, s - g, s - g, s * 0.18);
    ctx.fill();
    ctx.fillStyle = 'rgba(255,255,255,0.28)';
    roundRect(x + s * 0.15, y + s * 0.12, s * 0.7, s * 0.2, s * 0.08);
    ctx.fill();
    ctx.globalAlpha = 1;
  }
  function roundRect(x, y, w, h, r) {
    ctx.beginPath();
    ctx.moveTo(x + r, y);
    ctx.arcTo(x + w, y, x + w, y + h, r);
    ctx.arcTo(x + w, y + h, x, y + h, r);
    ctx.arcTo(x, y + h, x, y, r);
    ctx.arcTo(x, y, x + w, y, r);
    ctx.closePath();
  }

  function draw() {
    const { W, H, cell, bx, by, boardSize } = layout;
    if (!W) return;
    ctx.clearRect(0, 0, W, H);

    // board bg
    ctx.fillStyle = '#262b52';
    roundRect(bx - 6, by - 6, boardSize + 12, boardSize + 12, 12);
    ctx.fill();
    for (let r = 0; r < N; r++) {
      for (let c = 0; c < N; c++) {
        const x = bx + c * cell, y = by + r * cell;
        if (board && board[r][c]) block(x, y, cell, board[r][c]);
        else {
          ctx.fillStyle = '#323868';
          roundRect(x + 2, y + 2, cell - 4, cell - 4, cell * 0.15);
          ctx.fill();
        }
      }
    }
  }

  function loop() {
    draw();
    requestAnimationFrame(loop);
  }

  resize();
  requestAnimationFrame(loop);
```

- `roundRect` は角の丸い四角形の「形（パス）」を作る関数です。`arcTo` で角を丸めながら4辺をたどります。形を作ったあと `ctx.fill()` で塗ります。
- `block` は1個のブロックを描く関数です。少し小さめの角丸四角を色で塗り、上のほうに白い半透明の帯を重ねて「ツヤ」を出しています。`alpha` で全体の透明度を変えられるので、あとで「置く場所の予告（ゴースト）」や「消えるアニメーション」にも使い回します。
- `draw` は画面を1枚まるごと描く関数です。毎回 `clearRect` で消してから、盤面の背景 → 各マスの順に描きます。マス `(r, c)` の左上は `bx + c * cell, by + r * cell` です。
- `const { W, H, ... } = layout;` は **分割代入** で、`layout.W` などを短い名前で取り出しています。

### requestAnimationFrame とゲームループ

`requestAnimationFrame(loop)` は「次に画面を描き替えるタイミング（だいたい1秒に60回）で `loop` を呼んで」というお願いです。`loop` の中でまた自分を予約するので、`draw()` が延々と呼ばれ続けます。これを **ゲームループ** と呼びます。データ（`board` など）を書き換えるだけで、次のフレームで自動的に画面に反映されるようになります。

> [!CHECK] 動作チェック
> ページを再読み込みしてスタートを押します。
> - 画面上部に、紺色の背景に 8×8 のマス目が描かれている（スタート前もオーバーレイの奥にうっすら見える）
> - ウィンドウの幅や高さを変えると、盤面の大きさが追従する
> - スマホやズームした状態でもマス目の線がぼやけない

> [!TIP]
> `start()` の最後に一時的に `board[3][3] = '#4dabf7';` と書くと、そのマスに青いブロックが描かれます。`block` 関数の見た目を確かめたら消しておきましょう。
