## このステップのゴール

トレイのブロックを指やマウスでつかんで、盤面の上まで動かせるようにします。まだ「置く」処理は無いので、離すとトレイに戻ります。

## ドラッグの状態を持つ

`let board, tray, playing = false;` の **下** に、ドラッグ中の情報を入れる変数を追加します。

```js:game.js
  let drag = null;       // { idx, x, y, offY }
```

ドラッグしていないときは `null`、ドラッグ中は「何番目のピースか（`idx`）」「いまの指の位置（`x`, `y`）」「指からどれだけ上にずらして表示するか（`offY`）」を持つオブジェクトにします。

## ポインターイベント

`traySlot` 関数の **下** に、次のコードをまとめて追加します。

```js:game.js
  function pieceAtTray(x, y) {
    for (let i = 0; i < 3; i++) {
      const s = traySlot(i);
      if (tray[i] && x >= s.x && x < s.x + s.w && y >= s.y && y < s.y + s.h) return i;
    }
    return -1;
  }

  // top-left cell where dragged piece would snap
  function dragTarget() {
    if (!drag) return null;
    const p = tray[drag.idx];
    const { bx, by, cell } = layout;
    const px = drag.x - (p.cols * cell) / 2;
    const py = drag.y - drag.offY - (p.rows * cell) / 2;
    const c = Math.round((px - bx) / cell);
    const r = Math.round((py - by) / cell);
    return { r, c, px, py };
  }

  function pos(e) {
    const rect = cv.getBoundingClientRect();
    return { x: e.clientX - rect.left, y: e.clientY - rect.top };
  }

  cv.addEventListener('pointerdown', e => {
    if (!playing) return;
    const { x, y } = pos(e);
    const i = pieceAtTray(x, y);
    if (i < 0) return;
    e.preventDefault();
    try { cv.setPointerCapture(e.pointerId); } catch (err) { /* ignore */ }
    drag = { idx: i, x, y, offY: e.pointerType === 'mouse' ? 0 : layout.cell * 1.6 };
  });
  cv.addEventListener('pointermove', e => {
    if (!drag) return;
    const { x, y } = pos(e);
    drag.x = x; drag.y = y;
  });
  function endDrag() {
    if (!drag) return;
    drag = null;
  }
  cv.addEventListener('pointerup', endDrag);
  cv.addEventListener('pointercancel', () => { drag = null; });
```

### Pointer Events

`pointerdown` / `pointermove` / `pointerup` は **Pointer Events** と呼ばれるイベントで、マウス・タッチ・ペンをまとめて同じコードで扱えます。マウス用（`mousedown`）とタッチ用（`touchstart`）を別々に書かなくて済むのが利点です。

- `pos(e)` … イベントの `clientX/Y` は「ページ全体」での座標なので、Canvas の左上を引いて **Canvas 内の座標** に直します。
- `pieceAtTray(x, y)` … 押した位置がトレイのどの区画か調べ、ピースがあればその番号、無ければ `-1` を返します。四角形の中にあるかは `x >= 左 && x < 右 && y >= 上 && y < 下` で判定します。
- `setPointerCapture` … 指が Canvas の外に出ても `pointermove` / `pointerup` を受け取り続けるための指定です。
- `offY` … タッチ操作では、ピースが指に隠れて見えなくなります。そこで指より 1.6 マスぶん上に表示します。マウスなら隠れないので 0 です。
- `pointercancel` … 電話の着信などで操作が中断されたときに呼ばれます。ドラッグを取り消しておきます。

### dragTarget の計算

`dragTarget()` は「いまピースを離したら、盤面のどのマスに左上がくるか」を計算します。

1. 指の位置からピースの幅・高さの半分を引いて、ピースの左上の座標 `px`, `py` を求める（指がピースの中心にくるようにするため）。
2. 盤面の左上 `bx`, `by` からの距離をマスの大きさで割り、`Math.round` で一番近いマスに **スナップ** させる。

`px`, `py` は描画用、`r`, `c` は次のステップで「置く」ときに使います。

## 開始時にドラッグをリセット

`start()` の `refillTray();` の下に1行足します。

```js:game.js
    refillTray();
    drag = null;
```

## ドラッグ中のピースを描く

`draw()` のトレイのループで、ドラッグ中のピースはトレイに描かないようにします。

```js:game.js
      if (!p || (drag && drag.idx === i)) continue;
```

そして `draw()` の **最後**（トレイのループの後）に、ドラッグ中のピースを盤面と同じ大きさで描きます。

```js:game.js
    // dragged piece
    if (drag) {
      const p = tray[drag.idx];
      const t = dragTarget();
      for (const [dr, dc] of p.shape) block(t.px + dc * cell, t.py + dr * cell, cell, p.color, 0.95);
    }
```

あとから描いたものが上に重なるので、ドラッグ中のピースは最後に描きます。ゲームループで毎フレーム `draw()` しているので、`pointermove` で `drag.x / drag.y` を書き換えるだけでピースが指についてきます。

> [!CHECK] 動作チェック
> スタートしてから試します。
> - トレイのブロックを押すと、盤面と同じ大きさになって指（マウス）についてくる
> - スマホでは指の少し上にブロックが表示される
> - 離すとブロックはトレイに戻る（まだ置けません）
> - トレイの何も無いところや盤面を押しても何も起きない
