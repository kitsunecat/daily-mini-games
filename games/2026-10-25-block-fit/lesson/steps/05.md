## このステップのゴール

ドラッグしたブロックを盤面に置けるようにします。はみ出す場所や、ほかのブロックと重なる場所には置けません。置ける場所の上では、どこに入るかを半透明の「ゴースト」で予告します。3つとも置いたら、新しい3つが補充されます。

## 置けるかどうかを調べる：canPlace

`randomPiece` の **下**（`refillTray` の上）に追加します。

```js:game.js
  function canPlace(piece, r, c) {
    for (const [dr, dc] of piece.shape) {
      const rr = r + dr, cc = c + dc;
      if (rr < 0 || cc < 0 || rr >= N || cc >= N || board[rr][cc]) return false;
    }
    return true;
  }
```

ピースの左上を `(r, c)` に合わせたとき、形の各マスは盤面の `(r + dr, c + dc)` にきます。そのどれか1つでも

- 盤面の外（0 未満、または N 以上）
- すでにブロックがあるマス（`board[rr][cc]` が `null` 以外）

なら置けません。これがこのゲームの **当たり判定** です。動くもの同士の距離を測るのではなく、マス目のデータを1つずつ調べるだけなのでシンプルです。

## 盤面に置く：place

`refillTray` の **下** に追加します。

```js:game.js
  function place(idx, r, c) {
    const piece = tray[idx];
    for (const [dr, dc] of piece.shape) board[r + dr][c + dc] = piece.color;
    tray[idx] = null;

    if (tray.every(p => !p)) refillTray();
  }
```

- 形の各マスに、ピースの色を書き込みます。描画は `board` を見ているので、これだけで盤面にブロックが現れます。
- 使ったピースはトレイから消すため `null` にします。トレイの描画は `if (!p ...) continue;` で空の区画を飛ばすので、その区画は空っぽに見えます。
- `tray.every(p => !p)` は「3つ全部が空か？」。全部使い切ったら次の3つを補充します。

## 離したときに置く

`dragTarget()` の `return` を、置けるかどうか（`ok`）も返すように書き換えます。

```js:game.js
  // top-left cell where dragged piece would snap
  function dragTarget() {
    if (!drag) return null;
    const p = tray[drag.idx];
    const { bx, by, cell } = layout;
    const px = drag.x - (p.cols * cell) / 2;
    const py = drag.y - drag.offY - (p.rows * cell) / 2;
    const c = Math.round((px - bx) / cell);
    const r = Math.round((py - by) / cell);
    return { r, c, ok: canPlace(p, r, c), px, py };
  }
```

`endDrag()` で、置ける場所なら `place` を呼びます。

```js:game.js
  function endDrag() {
    if (!drag) return;
    const t = dragTarget();
    if (t && t.ok && playing) place(drag.idx, t.r, t.c);
    drag = null;
  }
```

置けない場所で離した場合は何もしないので、ピースはトレイに戻ります。

## ゴーストで置き場所を予告する

`draw()` の `if (!board) return;` の **すぐ下**（`// tray` の上）に追加します。

```js:game.js
    // ghost preview
    let ghost = null;
    if (drag) {
      const t = dragTarget();
      if (t.ok) ghost = { piece: tray[drag.idx], r: t.r, c: t.c, ok: true };
    }
    if (ghost) {
      for (const [dr, dc] of ghost.piece.shape) {
        const x = bx + (ghost.c + dc) * cell, y = by + (ghost.r + dr) * cell;
        if (ghost.ok) block(x, y, cell, ghost.piece.color, 0.4);
        else { ctx.fillStyle = 'rgba(255,60,60,0.45)'; roundRect(x + 2, y + 2, cell - 4, cell - 4, cell * 0.15); ctx.fill(); }
      }
    }
```

置ける場所の上にいるときだけ、ピースの色を透明度 0.4 で盤面のマスにぴったり描きます。指で持っているピースは「指の位置」に、ゴーストは「スナップしたマス」に描かれるので、どこに入るのかがひと目で分かります。

`ok: false` のときに赤く描く分岐もここで書いておきます。ドラッグでは置けないときにゴーストを出さないので今は使われませんが、最後のステップのキーボード操作で「ここには置けない」を赤で示すのに使います。

> [!CHECK] 動作チェック
> - ブロックを盤面の上に持っていくと、入るマスに半透明のゴーストが出る
> - 離すとそのマスにブロックが置かれ、トレイのその区画が空になる
> - 盤面からはみ出す位置や、ほかのブロックと重なる位置ではゴーストが出ず、離してもトレイに戻る
> - 3つとも置くと、新しい3つが補充される
