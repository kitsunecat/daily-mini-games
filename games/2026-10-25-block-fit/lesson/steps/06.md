## このステップのゴール

縦か横の列がブロックで埋まったら、その列を消します。消すときに白く光ってしぼむアニメーションと、獲得点数がふわっと浮かぶ表示を付け、スコアとコンボを数えます。

## スコア・コンボ・演出用の状態

状態の宣言を次のように書き換え・追加します。

```js:game.js
  let board, tray, score, combo, playing = false;
  let drag = null;       // { idx, x, y, offY }
  let flashes = [];      // { r, c, t }
  let popups = [];       // { text, x, y, t }
```

- `score` … 現在のスコア
- `combo` … 何回連続で列を消したか
- `flashes` … 消えたマスの光るアニメーション用のリスト
- `popups` … 「+20」のような浮かぶ文字のリスト

アニメーション用のリストには「始まった時刻 `t`」を入れておき、描画のたびに「始まってから何ミリ秒たったか」で見た目を決めます。

## place に列消しとスコアを足す

`place()` 全体を次のように書き換えます。

```js:game.js
  function place(idx, r, c) {
    const piece = tray[idx];
    for (const [dr, dc] of piece.shape) board[r + dr][c + dc] = piece.color;
    tray[idx] = null;
    let gained = piece.shape.length;

    const fullRows = [], fullCols = [];
    for (let i = 0; i < N; i++) {
      if (board[i].every(v => v)) fullRows.push(i);
      if (board.every(row => row[i])) fullCols.push(i);
    }
    const lines = fullRows.length + fullCols.length;
    if (lines > 0) {
      combo++;
      const now = performance.now();
      for (const rr of fullRows) for (let cc = 0; cc < N; cc++) { flashes.push({ r: rr, c: cc, color: board[rr][cc], t: now }); }
      for (const cc of fullCols) for (let rr = 0; rr < N; rr++) { flashes.push({ r: rr, c: cc, color: board[rr][cc], t: now }); }
      for (const rr of fullRows) for (let cc = 0; cc < N; cc++) board[rr][cc] = null;
      for (const cc of fullCols) for (let rr = 0; rr < N; rr++) board[rr][cc] = null;
      const bonus = lines * 10 * lines * combo;
      gained += bonus;
      const { bx, by, cell } = layout;
      popups.push({
        text: (combo > 1 ? `COMBO x${combo}  ` : '') + `+${bonus}`,
        x: bx + (c + piece.cols / 2) * cell,
        y: by + (r + piece.rows / 2) * cell,
        t: now,
      });
    } else {
      combo = 0;
    }
    score += gained;
    scoreEl.textContent = score;

    if (tray.every(p => !p)) refillTray();
  }
```

### そろった列の見つけ方

- 横の行 `i` がそろっている … `board[i].every(v => v)`（その行の全マスが空でない）
- 縦の列 `i` がそろっている … `board.every(row => row[i])`（全部の行の `i` 番目が空でない）

`every` は「配列の全要素が条件を満たすか」を調べるメソッドです。1つのループで行と列を両方チェックしています。

### 先に全部調べてから消す

そろった行と列を **全部見つけてから** まとめて消しているのがポイントです。もし行を見つけた瞬間に消してしまうと、その行と交差していた列が「そろっていない」ことになり、縦横同時消しができなくなります。

### 点数の計算

- 置いたブロックのマス数がそのまま点数（`gained = piece.shape.length`）
- 列を消したら `lines * 10 * lines * combo` のボーナス。1列なら 10 点、2列同時なら 40 点、3列同時なら 90 点と、**同時に消すほど大きく** 増えます。さらに連続で消すと `combo` 倍
- 列を消せなかった手では `combo` が 0 に戻ります

点数の文字は、置いたピースの中心あたり（`c + piece.cols / 2` 列目、`r + piece.rows / 2` 行目）に出します。テンプレートリテラル（`` `+${bonus}` ``）で文字列の中に値を埋め込んでいます。

`performance.now()` はページを開いてからの経過ミリ秒を返す、アニメーションの時間計測に向いた時計です。

## start で初期化する

`start()` の `drag = null;` の行を、スコアと演出もリセットするように書き換えます。

```js:game.js
  function start() {
    board = Array.from({ length: N }, () => Array(N).fill(null));
    refillTray();
    score = 0; combo = 0;
    scoreEl.textContent = 0;
    flashes = []; popups = []; drag = null;
    playing = true;
    overlay.classList.add('hidden');
  }
```

## 光る演出と浮かぶ文字を描く

`draw()` のゴーストの描画の **後**、`// tray` の **前** に追加します。

```js:game.js
    // flashes
    const now = performance.now();
    flashes = flashes.filter(f => now - f.t < 350);
    for (const f of flashes) {
      const k = (now - f.t) / 350;
      const s = cell * (1 - k * 0.6);
      const x = bx + f.c * cell + (cell - s) / 2, y = by + f.r * cell + (cell - s) / 2;
      block(x, y, s, '#ffffff', 1 - k);
    }
```

さらに `draw()` の **最後**（ドラッグ中のピースの後）に追加します。

```js:game.js
    // popups
    popups = popups.filter(p => now - p.t < 900);
    ctx.textAlign = 'center';
    ctx.font = `bold ${Math.round(cell * 0.5)}px system-ui, sans-serif`;
    for (const p of popups) {
      const k = (now - p.t) / 900;
      ctx.globalAlpha = 1 - k;
      ctx.fillStyle = '#fff';
      ctx.strokeStyle = '#1b1f3a';
      ctx.lineWidth = 4;
      ctx.strokeText(p.text, p.x, p.y - k * 40);
      ctx.fillText(p.text, p.x, p.y - k * 40);
      ctx.globalAlpha = 1;
    }
```

どちらも同じパターンでアニメーションしています。

1. `filter` で、寿命（350ms / 900ms）を過ぎたものをリストから取り除く
2. 経過時間を寿命で割った `k`（0 → 1 に増える進み具合）を求める
3. `k` を使って大きさ・位置・透明度を決める（光るマスは 1 → 0.4 倍にしぼみながら消え、文字は 40px 上に昇りながら消える）

「経過時間から見た目を計算する」形にしておくと、フレームの間隔が多少ぶれても動きの速さが変わりません。文字は `strokeText`（ふち）→ `fillText`（中身）の順に描くと、背景が何色でも読みやすくなります。

> [!CHECK] 動作チェック
> - ブロックを置くと、そのマス数だけ SCORE が増える
> - 横1行（または縦1列）を埋めると、その列が白く光って消え、「+10」が浮かんで消える
> - 続けて次の手でも列を消すと「COMBO x2  +20」のようにコンボが表示される
> - 縦と横が同時にそろうと、両方とも消える
