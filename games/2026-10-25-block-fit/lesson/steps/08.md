## このステップのゴール

最後の仕上げとして、PC 向けのキーボード操作（1〜3 で選択・矢印で移動・Enter で配置）と、Web Audio API による効果音を加えます。これで完成品と同じゲームになります。

## キーボード選択の状態

`let drag = null;` の **下** に追加します。

```js:game.js
  let kbSel = null;      // { idx, r, c }
```

キーボードで操作中のピース番号 `idx` と、置こうとしている左上のマス `r`, `c` を持ちます。

`start()` の初期化の行にも `kbSel = null;` を足します。

```js:game.js
    flashes = []; popups = []; drag = null; kbSel = null;
```

ドラッグを始めたらキーボード選択は解除します。`pointerdown` の中、`drag = { ... }` の **直前** に1行足します。

```js:game.js
    try { cv.setPointerCapture(e.pointerId); } catch (err) { /* ignore */ }
    kbSel = null;
    drag = { idx: i, x, y, offY: e.pointerType === 'mouse' ? 0 : layout.cell * 1.6 };
```

## keydown イベント

`cv.addEventListener('pointercancel', ...)` の行の **下** に追加します。

```js:game.js
  window.addEventListener('keydown', e => {
    if (!playing) {
      if ((e.key === 'Enter' || e.key === ' ') && !overlay.classList.contains('hidden')) { e.preventDefault(); start(); }
      return;
    }
    if (['1', '2', '3'].includes(e.key)) {
      const i = Number(e.key) - 1;
      if (tray[i]) kbSel = { idx: i, r: kbSel ? kbSel.r : 0, c: kbSel ? kbSel.c : 0 };
      return;
    }
    if (!kbSel) {
      if (e.key.startsWith('Arrow') || e.key === 'Enter') {
        const i = tray.findIndex(p => p);
        if (i >= 0) kbSel = { idx: i, r: 0, c: 0 };
      }
      return;
    }
    const p = tray[kbSel.idx];
    const moves = { ArrowUp: [-1, 0], ArrowDown: [1, 0], ArrowLeft: [0, -1], ArrowRight: [0, 1] };
    if (moves[e.key]) {
      e.preventDefault();
      kbSel.r = Math.max(0, Math.min(N - p.rows, kbSel.r + moves[e.key][0]));
      kbSel.c = Math.max(0, Math.min(N - p.cols, kbSel.c + moves[e.key][1]));
    } else if (e.key === 'Enter' || e.key === ' ') {
      e.preventDefault();
      if (canPlace(p, kbSel.r, kbSel.c)) {
        place(kbSel.idx, kbSel.r, kbSel.c);
        const next = tray.findIndex(q => q);
        kbSel = playing && next >= 0 ? { idx: next, r: kbSel.r, c: kbSel.c } : null;
        if (kbSel) {
          const q = tray[kbSel.idx];
          kbSel.r = Math.min(kbSel.r, N - q.rows);
          kbSel.c = Math.min(kbSel.c, N - q.cols);
        }
      } else beep(120, 0.08);
    } else if (e.key === 'Escape') kbSel = null;
  });
```

`e.key` には押されたキーの名前（`'1'`、`'ArrowUp'`、`'Enter'`、`' '` など）が入ります。上から順に見ていきましょう。

1. ゲーム中でないとき … オーバーレイが出ていれば Enter / スペースでスタート（リトライ）します。
2. `1`〜`3` … そのピースを選びます。すでに選択中なら位置はそのまま引き継ぎます。
3. 何も選んでいないとき … 矢印か Enter で、残っている最初のピースを左上に選びます。`findIndex` は条件に合う最初の要素の番号（無ければ -1）を返します。
4. 矢印キー … `moves` の表から移動量を引き、`Math.max(0, Math.min(最大, 値))` で盤面の中に収めます（**クランプ** と呼ばれる定番の書き方）。ピースが右や下にはみ出さないよう、最大値は `N - p.rows` / `N - p.cols` です。
5. Enter / スペース … 置ければ置いて、次に残っているピースを自動で選び直します。置けなければ低い音を鳴らします。
6. Escape … 選択を解除します。

`e.preventDefault()` は、矢印キーやスペースでページがスクロールしてしまうのを止めるためです。

## キーボード選択を描く

`draw()` のゴーストの部分で、`if (drag) { ... }` の後ろに `else if` をつなげます。

```js:game.js
    // ghost preview
    let ghost = null;
    if (drag) {
      const t = dragTarget();
      if (t.ok) ghost = { piece: tray[drag.idx], r: t.r, c: t.c, ok: true };
    } else if (kbSel) {
      const p = tray[kbSel.idx];
      ghost = { piece: p, r: kbSel.r, c: kbSel.c, ok: canPlace(p, kbSel.r, kbSel.c) };
    }
```

キーボードでは置けない場所にも移動できるので、`ok` が `false` のときはステップ5で用意した赤いゴーストが表示されます。

選んでいるピースがトレイのどれか分かるように、トレイのループの中、ブロックを描く行の **下** に黄色い枠を足します。

```js:game.js
      for (const [dr, dc] of p.shape) block(ox + dc * sz, oy + dr * sz, sz, usable ? p.color : '#555a7a');
      if (kbSel && kbSel.idx === i) {
        ctx.strokeStyle = '#ffd43b';
        ctx.lineWidth = 2;
        roundRect(s.x + 6, s.y, s.w - 12, Math.min(s.h, sz * 5 + 20), 10);
        ctx.stroke();
      }
```

`roundRect` で作った形を `fill()` ではなく `stroke()` すると、枠線だけが描かれます。

## 効果音：Web Audio API

`let layout = {};` の **下** に追加します。

```js:game.js
  // ---- audio ----
  let ac = null;
  function beep(freq, dur, type = 'square', vol = 0.06) {
    try {
      if (!ac) ac = new (window.AudioContext || window.webkitAudioContext)();
      const o = ac.createOscillator();
      const g = ac.createGain();
      o.type = type;
      o.frequency.value = freq;
      g.gain.setValueAtTime(vol, ac.currentTime);
      g.gain.exponentialRampToValueAtTime(0.0001, ac.currentTime + dur);
      o.connect(g).connect(ac.destination);
      o.start();
      o.stop(ac.currentTime + dur);
    } catch (e) { /* no audio */ }
  }
```

**Web Audio API** を使うと、音声ファイルを用意しなくてもブラウザの中で音を作れます。

- `AudioContext` … 音を扱う全体の入れ物。ブラウザは「ユーザーが操作するまで音を鳴らさない」決まりがあるので、最初に音を鳴らすとき（＝スタートボタンを押したとき）に作ります。
- `Oscillator`（発振器）… `freq` Hz の音を出します。`type` で波の形（`square` はピコピコ、`triangle` は柔らかい、`sawtooth` はざらっとした音）を選べます。
- `Gain` … 音量。`exponentialRampToValueAtTime` で `dur` 秒かけて音量をほぼ 0 まで下げると、「ポン」と自然に消える音になります。
- `o.connect(g).connect(ac.destination)` … 発振器 → 音量 → スピーカー の順につなぎます。

## 効果音を鳴らす

`beep` を各所から呼びます。

`place()` の中、`popups.push({ ... });` の **直後**（列を消したとき）に、和音を少しずつずらして鳴らします。消した列が多いほど音が増えます。

```js:game.js
      [523, 659, 784, 1047].slice(0, Math.min(4, lines + 1)).forEach((f, i) => setTimeout(() => beep(f, 0.15, 'triangle', 0.08), i * 60));
```

同じく `place()` の `else` の中（列を消さなかったとき）に、置いた音を足します。

```js:game.js
    } else {
      combo = 0;
      beep(220, 0.06);
    }
```

`start()` の最後（`overlay.classList.add('hidden');` の下）にスタート音を足します。

```js:game.js
    beep(660, 0.1, 'triangle');
```

`gameOver()` の中、`ovTitle.textContent = ...` の **直前** にゲームオーバー音を足します。

```js:game.js
    beep(180, 0.4, 'sawtooth', 0.05);
```

> [!CHECK] 動作チェック
> PC のブラウザで試します。
> - タイトル画面で Enter を押すとスタートする（スタート音が鳴る）
> - 矢印キーを押すと、トレイの1つ目に黄色い枠が付き、盤面にゴーストが出る。矢印で動かせて、盤面の外には出ない
> - ほかのブロックと重なる位置ではゴーストが赤くなり、Enter を押すと低い音が鳴って置けない
> - 置ける位置で Enter を押すと置かれ、次のピースが自動で選ばれる。`2` や `3` で選ぶピースを切り替えられる
> - 列を消すと和音、ゲームオーバーで低い音が鳴る
> - ゲームオーバー画面で Enter を押すとリトライできる

> [!TIP] 改造アイデア
> - `N` を 10 にして、10×10 の盤面で遊んでみる（`resize` の計算はそのまま使えます）
> - `SHAPES` に新しい形（十字形や大きな L 字など）を追加する。座標のリストを1行足すだけです
> - 盤面が空っぽになったら「ALL CLEAR +300」のような特別ボーナスを付ける（`place` で列を消した後に `board.every(row => row.every(v => !v))` を調べる）
> - ピースを回転できるボタンを付ける。`[r, c]` を `[c, rows - 1 - r]` に変換すると 90 度回転できます
> - 連続でコンボが続いている間、盤面の背景色を少しずつ明るくして盛り上げる
