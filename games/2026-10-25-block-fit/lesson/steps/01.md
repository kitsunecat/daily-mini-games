## このステップのゴール

ゲームを入れる3つのファイルを用意し、ヘッダー（スコア表示）・ゲーム画面・タイトル画面（オーバーレイ）の「入れ物」を作ります。スタートボタンを押すとタイトル画面が消えるところまで進めましょう。

## ファイルを用意する

好きな場所に `block-fit` というフォルダを作り、中に次の3つの空ファイルを作ります。

- `index.html` … 画面の部品（HTML）
- `style.css` … 見た目（CSS）
- `game.js` … ゲームの動き（JavaScript）

## index.html

```html:index.html
<!DOCTYPE html>
<html lang="ja">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1, user-scalable=no">
<title>ブロックはめ</title>
<link rel="stylesheet" href="style.css">
</head>
<body>
<div id="app">
  <header>
    <a class="back" href="../../../../">← 一覧</a>
    <div class="stat"><span>SCORE</span><b id="score">0</b></div>
    <div class="stat"><span>BEST</span><b id="best">0</b></div>
  </header>
  <div id="stage">
    <canvas id="cv"></canvas>
    <div id="overlay">
      <h1 id="ov-title">ブロックはめ</h1>
      <p id="ov-text">下のブロックをドラッグして盤面に置こう。<br>縦か横の列がそろうと消えるよ。<br>置ける場所がなくなったら終了！</p>
      <p class="keys">PC: マウスでドラッグ ／ 1〜3で選択・矢印で移動・Enterで配置</p>
      <button id="start">タップでスタート</button>
    </div>
  </div>
</div>
<script src="game.js"></script>
</body>
</html>
```

画面は大きく3つに分かれています。

- `header` … 左に「戻る」リンク、右に SCORE と BEST。数字を JavaScript から書き換えるので `id="score"` `id="best"` を付けています。
- `canvas#cv` … 盤面やブロックはすべてここに **Canvas（キャンバス）** で描きます。Canvas は JavaScript で図形や文字を自由に描ける「お絵かき用の板」です。
- `#overlay` … タイトルやゲームオーバーを表示する半透明の板。Canvas の上に重ねて表示します。

`viewport` の `user-scalable=no` は、スマホでドラッグ中に画面が拡大されてしまうのを防ぐためです。`<script>` を `body` の最後に置くと、HTML の部品が全部できてから JavaScript が動くので `getElementById` で確実に要素を取れます。


ポイントは次のとおりです。

- `#app` を `display: flex; flex-direction: column;` にして、ヘッダーの下の `#stage` に `flex: 1` を指定すると、**残りの高さを全部** ゲーム画面に使えます。`min-height: 0` は中身が大きくてもはみ出さないためのおまじないです。
- `#stage` を `position: relative`、`#overlay` を `position: absolute; inset: 0;` にすると、オーバーレイがゲーム画面にぴったり重なります。
- `touch-action: none` と `user-select: none` で、スマホのスクロールや文字選択がドラッグ操作の邪魔をしないようにします。
- `.hidden` クラスを付けるとオーバーレイが消えます。表示の切り替えはこのクラスの付け外しで行います。

## game.js

```js:game.js
(() => {
  const N = 8;

  const cv = document.getElementById('cv');
  const ctx = cv.getContext('2d');
  const scoreEl = document.getElementById('score');
  const bestEl = document.getElementById('best');
  const overlay = document.getElementById('overlay');
  const ovTitle = document.getElementById('ov-title');
  const ovText = document.getElementById('ov-text');
  const startBtn = document.getElementById('start');

  let playing = false;

  // ---- game logic ----
  function start() {
    playing = true;
    overlay.classList.add('hidden');
  }

  startBtn.addEventListener('click', start);
})();
```

全体を `(() => { ... })();` で囲んでいます。これは **即時関数** と呼ばれる書き方で、中で作った変数がページ全体（グローバル）に漏れ出さないようにします。

- `N = 8` は盤面のマス数（8×8）です。数字を直接あちこちに書かず定数にしておくと、あとで盤面サイズを変えるのが簡単になります。
- `cv.getContext('2d')` で、Canvas に描くための道具（コンテキスト）を取り出します。以後の描画はすべて `ctx` を通して行います。
- `addEventListener('click', start)` は「ボタンがクリックされたら `start` を呼んで」という **イベント** の登録です。
- `playing` は「いまゲーム中かどうか」を表すフラグで、あとで操作を受け付けるかの判断に使います。
