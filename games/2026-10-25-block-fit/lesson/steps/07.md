## このステップのゴール

トレイのどのピースも盤面に置けなくなったらゲームオーバーにします。最高スコア（BEST）をブラウザに保存して、ページを閉じても残るようにし、「もう一度あそぶ」でリトライできるようにします。

## どこかに置けるか：fitsAnywhere

`canPlace` の **下** に追加します。

```js:game.js
  function fitsAnywhere(piece) {
    for (let r = 0; r < N; r++) for (let c = 0; c < N; c++) if (canPlace(piece, r, c)) return true;
    return false;
  }
```

盤面の 64 マスすべてを左上の候補として `canPlace` を試し、1か所でも置ければ `true` です。「総当たり」ですが、8×8 なら一瞬で終わるので工夫はいりません。

## ゲームオーバーの判定

`place()` の最後、`if (tray.every(p => !p)) refillTray();` の **下** に追加します。

```js:game.js
    if (tray.every(p => !p)) refillTray();
    if (!tray.some(p => p && fitsAnywhere(p))) {
      setTimeout(gameOver, 500);
      playing = false;
    }
```

`some` は「1つでも条件を満たすか」を調べるメソッドです。残っているピースの **どれも** どこにも置けなければゲームオーバー。補充の **後** に調べるのが大事で、そうしないと「3つ使い切った直後」に空のトレイを見て終了してしまいます。

すぐにオーバーレイを出すと、最後に置いたブロックや列が消える演出が見えないので、`setTimeout` で 0.5 秒待ってから `gameOver` を呼びます。そのあいだに操作されないよう、`playing` は先に `false` にしておきます（`pointerdown` は `if (!playing) return;` で弾かれます）。

## ハイスコアを保存する：localStorage

`const startBtn = ...` の行の **下**（状態の宣言 `let board, ...` の上）に追加します。

```js:game.js
  const BEST_KEY = 'daily-mini-games:block-fit:best';
  let best = 0;
  try { best = parseInt(localStorage.getItem(BEST_KEY), 10) || 0; } catch (e) { best = 0; }
  bestEl.textContent = best;
```

**localStorage** は、ブラウザにちょっとした文字列を保存できる仕組みです。`setItem(キー, 値)` で保存、`getItem(キー)` で読み出しでき、ページを閉じても消えません。

- 値は文字列で保存されるので、`parseInt(..., 10)` で数値に戻します。まだ保存していなければ `getItem` は `null` を返し、`parseInt` は `NaN` になるので、`|| 0` で 0 にします。
- キーは同じサイトのほかのゲームとぶつからないよう、ゲーム名を含めた長めの名前にしています。
- プライベートブラウズなどで localStorage が使えないとエラーになることがあるので、`try { ... } catch` で囲み、保存できなくてもゲーム自体は動くようにしています。

## gameOver 関数

`start()` の **下** に追加します。

```js:game.js
  function gameOver() {
    let newBest = false;
    if (score > best) {
      best = score; newBest = true;
      try { localStorage.setItem(BEST_KEY, String(best)); } catch (e) { /* ignore */ }
      bestEl.textContent = best;
    }
    ovTitle.textContent = 'ゲームオーバー';
    ovText.innerHTML = `スコア <b>${score}</b>${newBest ? '<br>ハイスコア更新！' : `<br>ベスト ${best}`}`;
    startBtn.textContent = 'もう一度あそぶ';
    overlay.classList.remove('hidden');
  }
```

- ベストを超えていたら保存して、BEST の表示も更新します。
- タイトル画面で使っていたオーバーレイの文字を書き換えて、ゲームオーバー画面として使い回します。`.hidden` を外せば再び表示されます。
- ボタンの文字は「もう一度あそぶ」に変わりますが、押したときの処理は同じ `start()` です。`start()` は盤面・トレイ・スコアをすべて最初の状態に戻すように書いてあるので、そのままリトライになります。

## 置けないピースを灰色にする

`draw()` のトレイのループで、ブロックを描く行を次の2行に書き換えます。

```js:game.js
      const usable = fitsAnywhere(p);
      for (const [dr, dc] of p.shape) block(ox + dc * sz, oy + dr * sz, sz, usable ? p.color : '#555a7a');
```

どこにも置けないピースは灰色で描かれるので、プレイヤーは「このピースはもう使えない」と気づけます。毎フレーム `fitsAnywhere` を3回呼んでいますが、64 マス × 数マスの計算なので軽いものです。

> [!CHECK] 動作チェック
> - 盤面が混んできて、置けないピースがトレイで灰色になる
> - 3つとも置けなくなると、少しして「ゲームオーバー」とスコアが表示される
> - 初回は「ハイスコア更新！」と出て、右上の BEST が更新される
> - 「もう一度あそぶ」で空の盤面から再スタートし、SCORE が 0 に戻る
> - ページを再読み込みしても BEST の数字が残っている

> [!TIP]
> ゲームオーバーを早く確かめたいときは、`start()` の中で `board` を作った直後に `for (let r = 0; r < 7; r++) for (let c = 0; c < 7; c++) board[r][c] = '#555a7a';` のように盤面をほぼ埋めておくと便利です。確認したら消しましょう。
