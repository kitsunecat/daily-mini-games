## このステップのゴール

いよいよパズルの中心です。くっつけたあわと **同じ色が3つ以上つながったら消し**、消えたことで **天井から切りはなされたあわをまとめて落とします**。消えたあわは火花になってはじけ、落ちるあわは重力で下へ落ちていきます。点数も入るようにします。

どちらの処理も、**幅優先探索（BFS）** という同じ考え方で作ります。

## 変数を書きかえる

変数の2行を、次のように **書きかえ** ます。

```js:game.js
  let rows, cur, next, shot, angle, score, numColors, running = false;
  let particles = [], aiming = false, lastT = 0;
```

`score` は点数、`particles` は火花や落ちていくあわなど、**演出用の小さな粒** の一覧です。

## 空の段を取りのぞく関数

`pickColor()` 関数の **下** に、次の1行の関数を追加します。

```js:game.js
  function trimRows() { while (rows.length && rows[rows.length - 1].cells.every((v) => v < 0)) rows.pop(); }
```

あわを消すと、下のほうに空っぽの段が残ることがあります。`every` は配列の **全部が** 条件を満たすと `true` を返すので、「最後の段が全部空」の間、`pop()` で取りのぞきます。

## start() とスコア表示・メッセージ

`start()` を、次のように **書きかえ**、その **下** に `updateHud()` と `showToast()` を追加します。

```js:game.js
  function start() {
    score = 0; numColors = 4;
    particles = []; shot = null; angle = -Math.PI / 2;
    fillStart();
    cur = pickColor(); next = pickColor();
    running = true;
    overlay.classList.add('hide');
    updateHud();
  }

  function updateHud() {
    scoreEl.textContent = score;
  }

  let toastTimer = 0;
  function showToast(t) {
    toast.textContent = t; toast.classList.add('show');
    clearTimeout(toastTimer); toastTimer = setTimeout(() => toast.classList.remove('show'), 900);
  }
```

- `updateHud()` は、画面上部の表示（HUD）を最新にする関数です。ステップ6で「あと何発」の表示もここに足します。
- `showToast()` は `#toast` に文字を入れて `show` クラスをつけ、0.9秒後に外します。続けて呼ばれたときに前のタイマーで早く消えないよう、`clearTimeout` で前の予約を取り消してから予約し直します。

## くっついたら判定する

`snap()` の最後の `rows[sr].cells[sc] = col;` の **下** に、次の1行を追加します。

```js:game.js
    resolve(sr, sc, col);
```

そして `snap()` 関数の **下** に、次の2つの関数を追加します。

```js:game.js

  function resolve(r, c, col) {
    // 同じ色の塊
    const group = [[r, c]], seen = new Set([r + ',' + c]);
    for (let i = 0; i < group.length; i++) {
      for (const [a, b] of neighbors(group[i][0], group[i][1])) {
        const k = a + ',' + b;
        if (!seen.has(k) && rows[a].cells[b] === col) { seen.add(k); group.push([a, b]); }
      }
    }
    let popped = 0, dropped = 0;
    if (group.length >= 3) {
      for (const [a, b] of group) {
        burst(cellX(rows[a], b), cellY(a), rows[a].cells[b]);
        rows[a].cells[b] = -1; popped++;
      }
      // 天井につながっていないあわを落とす
      const keep = new Set(), q = [];
      if (rows.length) rows[0].cells.forEach((v, i) => { if (v >= 0) { keep.add('0,' + i); q.push([0, i]); } });
      for (let i = 0; i < q.length; i++) {
        for (const [a, b] of neighbors(q[i][0], q[i][1])) {
          const k = a + ',' + b;
          if (!keep.has(k) && rows[a].cells[b] >= 0) { keep.add(k); q.push([a, b]); }
        }
      }
      rows.forEach((row, a) => row.cells.forEach((v, b) => {
        if (v >= 0 && !keep.has(a + ',' + b)) {
          particles.push({ x: cellX(row, b), y: cellY(a), vx: (Math.random() - 0.5) * 120, vy: -60 - Math.random() * 80, col: v, life: 2, fall: true });
          row.cells[b] = -1; dropped++;
        }
      }));
      const gain = popped * 10 + dropped * 20 * (dropped >= 5 ? 2 : 1);
      score += gain;
      if (dropped >= 3) showToast(`${dropped}こ落とした！ +${gain}`);
      else if (popped >= 6) showToast(`ナイス！ +${gain}`);
    }
    trimRows();
    updateHud();
  }

  function burst(x, y, col) {
    for (let i = 0; i < 6; i++) {
      const a = Math.random() * Math.PI * 2, s = 60 + Math.random() * 140;
      particles.push({ x, y, vx: Math.cos(a) * s, vy: Math.sin(a) * s, col, life: 0.45, spark: true });
    }
  }
```

### 幅優先探索（BFS）で同じ色の塊を見つける

`group` は「見つけた同じ色のマス」のリストで、最初はくっつけたマス1つだけです。

1. `group` の先頭から順に、そのマスの **となり**（`neighbors`）を調べる
2. となりが同じ色で、まだ見ていなければ `group` の最後に追加する
3. `group` の最後まで調べ終わったら完了

`for` ループの途中で `group` に追加しているので、追加したマスも順番に調べられ、つながっている同じ色がどこまでも見つかります。これが **幅優先探索** です。近いマスから順に、波紋のように広がって探していきます。

`seen` は「もう見たマス」を覚えておく `Set` です。`'2,3'` のように「段,番号」の文字列にして入れます（配列 `[2, 3]` は毎回別物あつかいになり、`Set` で比べられないため）。これがないと同じマスを何度も追加して、ずっと終わらなくなります。

### ぶら下がったあわを落とす

同じ色の塊を消したら、今度は **天井につながっているあわ** を探します。これも同じ形の BFS です。

- スタート地点は、0段目（天井）にあるすべてのあわ
- となりにあわがあれば、どんどん `keep`（残すもの）に追加
- 最後に盤面全体を見て、`keep` に入っていないあわ ＝ **天井から切りはなされたあわ** を落とす

「落とすものを探す」より「残すものを探して、それ以外を落とす」ほうが、ずっとかんたんに書けるのがポイントです。

### 点数

消したあわは1個10点、落としたあわは1個20点、5個以上いっぺんに落とすと落とした分が2倍です。ぶら下げて一気に落とすほうがお得なので、奥をねらう楽しさが生まれます。大きく消したときは `showToast` でメッセージを出します。

### パーティクル（粒）

- `burst()` は、消えたあわの位置から6個の火花をランダムな向き・速さで飛ばします（`spark: true`、寿命0.45秒）。
- 落ちるあわは、少し上向き・左右ランダムな速度をもった粒にします（`fall: true`、寿命2秒）。

粒はどれも `{ x, y, vx, vy, col, life }` という同じ形のオブジェクトなので、まとめて動かして、まとめて描けます。

## 粒を動かす

`update()` の、`if (shot) { … }` のブロックの **下**（関数の最後の `}` の上）に、次のコードを追加します。

```js:game.js
    for (const p of particles) {
      p.life -= dt;
      p.x += p.vx * dt; p.y += p.vy * dt;
      if (p.fall) p.vy += 900 * dt; else { p.vx *= 0.92; p.vy *= 0.92; }
    }
    particles = particles.filter((p) => p.life > 0 && p.y < H + 40);
```

- 落ちるあわは、毎フレーム下向きの速度を足して **重力** を表現します（加速度 900px/s²）。最初に少し上向きに飛ぶので、ふわっと浮いてから落ちていきます。
- 火花は速度を毎フレーム0.92倍にして、すぐに減速させます。
- 寿命が切れたもの、画面の下へ消えたものは `filter` で取りのぞきます。

## 粒を描く

`draw()` の `if (shot) drawBubble(shot.x, shot.y, shot.col);` の行の **下** に、次のコードを追加します。

```js:game.js

    for (const p of particles) {
      if (p.spark) {
        ctx.globalAlpha = Math.max(0, p.life / 0.45);
        ctx.fillStyle = COLORS[p.col].c;
        ctx.beginPath(); ctx.arc(p.x, p.y, 3.5, 0, Math.PI * 2); ctx.fill();
        ctx.globalAlpha = 1;
      } else drawBubble(p.x, p.y, p.col, R - 1, 0.9);
    }
```

火花は残り寿命に合わせて `globalAlpha` を下げ、だんだん薄くなって消えるようにします。落ちるあわは少しだけ透かして描きます。

## ループとタイトル画面

`loop()` の `if (running) update(dt);` を、次のように **書きかえ** ます。

```js:game.js
    if (running || particles.length) update(dt);
```

ゲームオーバーになったあとも、残っている粒が最後まで落ちきるようにするためです。

ファイル末尾のタイトル画面用の行を、次の2行に **書きかえ** ます。

```js:game.js
  numColors = 4; fillStart(); cur = 0; next = 1; angle = -Math.PI / 2; score = 0;
  updateHud();
```

> [!CHECK] 動作チェック
> - 同じ色のあわが2つ並んでいるところに同じ色を撃ちこむと、3つがパチンとはじけて火花が散る
> - 2つ以下しかつながらないときは、そのままくっつく
> - あわを消したことで天井から切りはなされたあわが、ふわっと浮いてから下へ落ちていく
> - 消すと SCORE が増える（1個10点、落としたあわは1個20点）
> - 3個以上落とすと「〇こ落とした！」、6個以上消すと「ナイス！」と表示される
