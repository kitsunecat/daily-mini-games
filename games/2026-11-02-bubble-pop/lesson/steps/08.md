## このステップのゴール

最後の仕上げです。

- いちばん良かった点数（ハイスコア）を **localStorage** に保存して、ページを閉じても残るようにする
- **Web Audio API** で、発射・消去・ミス・ゲームオーバーの効果音を鳴らす

これで完成品と同じゲームになります。

## ハイスコアを読みこむ

`COLORS` の配列の `];` の行の **下** に、保存に使う名前を追加します。

```js:game.js
  const BEST_KEY = 'bubble-pop-best';
```

変数の2行を、次のように **書きかえ**、その **下** にハイスコアを読みこむ2行を追加します。

```js:game.js
  let rows, cur, next, shot, angle, score, best = 0, misses, shotsPerRow, numColors, running = false;
  let particles = [], aiming = false, lastT = 0, shake = 0, totalShots = 0;

  try { best = parseInt(localStorage.getItem(BEST_KEY), 10) || 0; } catch (e) { best = 0; }
  bestEl.textContent = best;
```

- `localStorage` は、ブラウザにサイトごとの小さなデータを保存できるしくみです。`setItem(名前, 文字列)` で保存、`getItem(名前)` で読み出せます。ページを閉じても残ります。
- 保存されるのは **文字列** なので、`parseInt(…, 10)` で10進数の数に直します。まだ保存されていないときは `null` になり、`parseInt` が `NaN` を返すので、`|| 0` で 0 にします。
- プライベートブラウズなど、ブラウザの設定によっては localStorage を使うとエラーになることがあります。`try { … } catch (e) { … }` で囲んでおくと、エラーが起きてもゲームは止まりません。

## ゲームオーバーで保存する

`gameOver()` を、次のように **書きかえ** ます。

```js:game.js
  function gameOver() {
    running = false; shot = null;
    let msg = `スコア ${score}`;
    if (score > best) {
      best = score; msg += '<br>ハイスコア更新！';
      try { localStorage.setItem(BEST_KEY, String(best)); } catch (e) { /* ignore */ }
    }
    bestEl.textContent = best;
    ovTitle.textContent = 'ゲームオーバー';
    ovText.innerHTML = msg;
    startBtn.textContent = 'もう一度';
    overlay.classList.remove('hide');
    beep(180, 0.4, 'sawtooth');
  }
```

今回の点数がこれまでの最高より高ければ、`best` を更新して保存し、メッセージに「ハイスコア更新！」を足します。`beep` はこのあと作る効果音の関数です。

## 効果音の関数

`startBtn.addEventListener(…)` の行を、次のように **書きかえ**、その **下** に音のセクションを追加します。

```js:game.js
  startBtn.addEventListener('click', () => { ensureAudio(); start(); });

  // ---------- 音 ----------
  let ac = null;
  function ensureAudio() {
    if (ac) return;
    try { ac = new (window.AudioContext || window.webkitAudioContext)(); } catch (e) { ac = null; }
  }
  function beep(freq, dur, type) {
    if (!ac) return;
    try {
      const o = ac.createOscillator(), g = ac.createGain();
      o.type = type; o.frequency.value = freq;
      g.gain.setValueAtTime(0.08, ac.currentTime);
      g.gain.exponentialRampToValueAtTime(0.001, ac.currentTime + dur);
      o.connect(g).connect(ac.destination);
      o.start(); o.stop(ac.currentTime + dur);
    } catch (e) { /* ignore */ }
  }
```

### Web Audio API のしくみ

音声ファイルを用意しなくても、プログラムで音を作れます。

- `AudioContext` は音を作る「スタジオ」です。ブラウザは **ユーザーが画面を操作するまで音を出させてくれない** ので、スタートボタンやタップのときに `ensureAudio()` で作ります。古い Safari 向けに `webkitAudioContext` も試しています。
- `createOscillator()` は、決まった高さ（周波数 `freq`、単位 Hz）の音を出し続ける発振器です。`type` で音色を選びます（`'sine'` はやわらかい、`'square'` はピコピコ、`'sawtooth'` はジリジリ、`'triangle'` はその中間）。
- `createGain()` は音量のつまみです。`exponentialRampToValueAtTime` で、`dur` 秒かけて音量をほぼ 0 まで下げ、「ポン」と消える音にします。
- 発振器 → 音量 → スピーカー（`ac.destination`）とつないで、`start()` で鳴らし、`stop()` で止めます。

## 効果音を鳴らす

次の場所に `beep(…)` を1行ずつ追加します。

`fire()` の `totalShots++;` の **下** に（発射音）:

```js:game.js
    beep(520, 0.06, 'triangle');
```

`swap()` の `[cur, next] = [next, cur];` の **下** に（入れかえ音）:

```js:game.js
    beep(700, 0.05, 'sine');
```

`resolve()` の `score += gain;` の **下** に（消えた音。たくさん消すほど高い音）:

```js:game.js
      beep(660 + Math.min(popped + dropped, 12) * 40, 0.12, 'sine');
```

`resolve()` の `misses++;` の **下** に（ミスの音）:

```js:game.js
      beep(300, 0.05, 'square');
```

## 操作したときに音の準備をする

`pointerdown` のイベントの中、`e.preventDefault();` の **下** に、次の1行を追加します。

```js:game.js
    ensureAudio();
```

`keydown` のイベントの中、ゲーム中でないときの行を、次のように **書きかえ** ます。

```js:game.js
      if (e.key === 'Enter' || e.key === ' ') { e.preventDefault(); ensureAudio(); start(); }
```

> [!CHECK] 動作チェック
> - 発射すると「ポッ」、あわが消えると「ピン」と鳴り、たくさん消すほど高い音になる
> - 消せないショットでは短い「ブッ」、入れかえでは高い「ピッ」と鳴る
> - ゲームオーバーで低い「ジー」という音が鳴り、点数が最高なら「ハイスコア更新！」と出て、BEST が更新される
> - ページを再読み込みしても BEST の数字が残っている
> - 「もう一度」で SCORE は 0 に戻り、BEST はそのまま
> - これで完成品と同じ遊び方ができる。おつかれさまでした！

## 改造アイデア

> [!TIP]
> **特別なあわ:** たまに「虹色のあわ」が発射台に来るようにして、くっついたら **どの色ともつながる** ようにしてみましょう。`resolve()` の塊さがしで「同じ色」の条件を少しゆるめるだけで作れます。

> [!TIP]
> **爆弾あわ:** くっついたマスの `neighbors()` を全部消す「爆弾」を作ってみましょう。消したあとに、ステップ5の「ぶら下がったあわを落とす」処理をそのまま呼べば、連鎖して落ちる気持ちよさが生まれます。

> [!TIP]
> **ステージ制:** `fillStart()` の代わりに、あらかじめ文字列で描いた盤面（例: `'RRGGB…'`）を読みこむ関数を作れば、ハートの形や顔の形など、決まった並びのステージを遊べるようになります。全部消したら次のステージへ進みましょう。

> [!TIP]
> **ガイドを短く:** `drawGuide()` の `dist < 900` を `dist < 250` にすると、ガイドが途中で切れて難しくなります。点数が上がるほど短くしていくのも面白い調整です。
