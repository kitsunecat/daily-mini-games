## このステップのゴール

ゲームに「せまってくる緊張感」と「終わり」をつけます。

- 消せないショット（ミス）が決まった回数たまると、天井から新しい段が押し出され、盤面全体が1段下がる
- 残りの回数を、画面上部に丸い点で表示する
- あわがデッドラインをこえたらゲームオーバー
- 全部消したらボーナス。点数が上がると色が増え、撃つほど段が下がるまでの回数が減る

## 変数を書きかえる

変数の2行を、次のように **書きかえ** ます。

```js:game.js
  let rows, cur, next, shot, angle, score, misses, shotsPerRow, numColors, running = false;
  let particles = [], aiming = false, lastT = 0, shake = 0, totalShots = 0;
```

- `misses` は消せなかったショットの数、`shotsPerRow` は「何回ミスしたら段が下がるか」です。
- `shake` は画面をゆらす残り時間、`totalShots` はこれまでに撃った数です。

## 段を押し出す関数

`fillStart()` 関数の **下** に、次の関数を追加します。

```js:game.js

  function pushRow() {
    const off = rows.length ? !rows[0].off : false;
    const row = makeRow(off, true);
    for (let c = 1; c < row.cells.length; c++) if (Math.random() < 0.4) row.cells[c] = row.cells[c - 1];
    rows.unshift(row);
    shake = 0.25;
  }
```

- `unshift()` は配列の **先頭に** 要素を追加します。0段目に新しい段が入るので、これまでの段は番号が1つずつ増え、画面上では全体が1段下がります。あわの位置を1つずつ動かす必要はありません。
- 新しい段のずれ方は、今の0段目と逆にします。こうしないと、ずれた並びがかみ合わなくなります。
- 40% の確率で左どなりと同じ色にして、消しやすい塊を作ります。
- `shake = 0.25` で、0.25秒間画面をゆらします。

## start() とゲームオーバー

`start()` の1行目を、次のように **書きかえ** ます。

```js:game.js
    score = 0; misses = 0; shotsPerRow = 6; numColors = 4; totalShots = 0;
```

`start()` の **下**、`updateHud()` の **上** に、`gameOver()` を追加します。

```js:game.js

  function gameOver() {
    running = false; shot = null;
    let msg = `スコア ${score}`;
    ovTitle.textContent = 'ゲームオーバー';
    ovText.innerHTML = msg;
    startBtn.textContent = 'もう一度';
    overlay.classList.remove('hide');
  }
```

タイトル画面に使っていたオーバーレイを、文字を入れかえて再利用します。`hide` クラスを外せば、また表示されます。ボタンを押すと `start()` が呼ばれるので、そのままリトライになります。`msg` を `let` にしているのは、ステップ8でハイスコアの文を足すためです。

## 残りの回数を表示する

`updateHud()` を、次のように **書きかえ** ます。

```js:game.js
  function updateHud() {
    scoreEl.textContent = score;
    let h = '';
    for (let i = 0; i < shotsPerRow; i++) h += `<i class="${i < shotsPerRow - misses ? '' : 'used'}"></i>`;
    shotsEl.innerHTML = h;
  }
```

`shotsPerRow` 個の `<i>` 要素を作り、使ってしまった分（右から `misses` 個）に `used` クラスをつけます。CSS で `#shots i` は光る丸、`used` は暗い丸になるように用意してあります。

## 撃った数を数える

`fire()` の `cur = next; next = pickColor();` の **下** に、次の1行を追加します。

```js:game.js
    totalShots++;
```

## resolve() の後半を書きかえる

`resolve()` の `else if (popped >= 6) showToast(…);` の行より **下**、関数の終わりまでを、次のように **書きかえ** ます。

```js:game.js
      else if (popped >= 6) showToast(`ナイス！ +${gain}`);
    } else {
      misses++;
    }
    trimRows();

    // すべて消えたらボーナス
    if (!rows.length) {
      score += 500;
      showToast('ぜんぶ消した！ +500');
      for (let i = 0; i < 4; i++) pushRow();
      misses = 0;
    }

    if (misses >= shotsPerRow) {
      pushRow();
      misses = 0;
    }
    // 難易度
    numColors = Math.min(COLORS.length, 4 + Math.floor(score / 1500));
    shotsPerRow = Math.max(3, 6 - Math.floor(totalShots / 40));
    misses = Math.min(misses, shotsPerRow - 1);

    // 手持ちの色が盤面から消えていたら入れかえる
    const on = colorsOnBoard();
    if (on.length) {
      if (!on.includes(cur)) cur = pickColor();
      if (!on.includes(next)) next = pickColor();
    }
    updateHud();
    for (let a = DEAD_ROW + 1; a < rows.length; a++) {
      if (rows[a].cells.some((v) => v >= 0)) { gameOver(); return; }
    }
  }
```

上から順に見ていきます。

- **ミス**: 3つそろわなかったら `misses` を1増やします。
- **全消しボーナス**: `trimRows()` で空の段を取りのぞいた結果、段が1つもなければ全部消せたということです。500点を足し、新しく4段を押し出して続行します。
- **段が下がる**: ミスが `shotsPerRow` に達したら `pushRow()` してカウントをリセットします。
- **難易度**: 1500点ごとに色を1つ増やし（最大6色）、40発撃つごとに段が下がるまでの回数を1減らします（最低3回）。回数が減ったときに `misses` がはみ出さないよう、`shotsPerRow - 1` 以下に収めます。
- **手持ちの色の入れかえ**: ある色を盤面から全部消したのに、発射台にその色が残っていると、どこにも消せません。盤面にない色なら選び直します。`includes` は配列にその値が入っているかを調べます。
- **ゲームオーバー判定**: 番号 `DEAD_ROW + 1`（15段目）から下の段に1つでもあわがあれば、デッドラインをこえたのでゲームオーバーです。14段目（番号13）まではセーフです。

## 画面をゆらす

`update()` の最後、`particles = particles.filter(…);` の行の **下** に、次の1行を追加します。

```js:game.js
    if (shake > 0) shake -= dt;
```

`draw()` の `ctx.clearRect(0, 0, W, H);` の行の **下** に、次の1行を追加します。

```js:game.js
    if (shake > 0) ctx.translate(0, Math.sin(shake * 60) * 3);
```

`ctx.translate(dx, dy)` は、このあと描くものすべてを (dx, dy) だけずらします。`Math.sin` は -1〜1 を行ったり来たりするので、時間とともに上下に ±3px ゆれます。`draw()` の最初に `ctx.save()`、最後に `ctx.restore()` を書いておいたので、ずらしは次のフレームに持ちこされません。

## タイトル画面

ファイル末尾のタイトル画面用の行を、次のように **書きかえ** ます。

```js:game.js
  numColors = 4; fillStart(); cur = 0; next = 1; angle = -Math.PI / 2; misses = 0; shotsPerRow = 6; score = 0;
```

> [!CHECK] 動作チェック
> - 画面上部の「あと ●●●●●● 発で段が下がる」に、光る丸が6個並ぶ
> - あわを消せないショットを撃つたびに、丸が1つずつ暗くなる（消せたときは減らない）
> - 6回ミスすると、画面がゆれて天井から新しい段が出てきて、全体が1段下がり、丸が全部光る状態に戻る
> - あわがピンクの点線より下まで来ると「ゲームオーバー」とスコアが表示される
> - 「もう一度」を押すと、新しい盤面で SCORE 0 からやり直せる
