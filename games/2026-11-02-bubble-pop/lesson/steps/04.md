## このステップのゴール

指をはなすと、発射台のあわがガイドの方向へ飛んでいき、壁ではね返り、天井やほかのあわにぶつかったところで **いちばん近い空きマスにピタッとくっつく** ようにします。発射台には「いまのあわ」と「つぎのあわ」を表示します。

## 定数を追加する

`const SX = W / 2, SY = H - 46;` の行の **下** に、次の2行を追加します。

```js:game.js
  const NX = SX - 70, NY = H - 30;           // 次のあわ
  const SPEED = 900;                         // px/s
```

`NX`, `NY` は「つぎのあわ」を表示する位置、`SPEED` は弾の速さ（1秒に900px）です。

## 変数を書きかえる

変数の2行を、次のように **書きかえ** ます。

```js:game.js
  let rows, cur, next, shot, angle, numColors, running = false;
  let aiming = false, lastT = 0;
```

- `cur` はいま発射台にあるあわの色、`next` はつぎのあわの色です。
- `shot` は飛んでいる弾です。`{ x, y, vx, vy, col }`（位置・速度・色）を持ち、飛んでいないときは `null` にします。
- `lastT` は前のフレームの時刻で、フレーム間の経過時間を計算するのに使います。

## となりのマスを調べる関数

`randColor()` の行の **下** に、次の2つの関数を追加します。

```js:game.js

  function ensureRow(r) {
    while (rows.length <= r) rows.push(makeRow(rows.length ? !rows[rows.length - 1].off : false, false));
  }
  function neighbors(r, c) {
    const row = rows[r];
    const list = [[r, c - 1], [r, c + 1]];
    const d = row.off ? [c, c + 1] : [c - 1, c];
    for (const rr of [r - 1, r + 1]) for (const cc of d) list.push([rr, cc]);
    return list.filter(([rr, cc]) => rr >= 0 && rr < rows.length && cc >= 0 && cc < rowLen(rows[rr]));
  }
```

### ensureRow … 段を足りるまで増やす

あわは盤面のいちばん下の段よりさらに下にくっつくことがあります。`ensureRow(r)` は、r 段目まで空の段を追加して、配列の外を読まないようにします。新しい段は、1つ上の段と逆のずれ方（`!…off`）にします。

### neighbors … 六角形グリッドのとなり

六角形のマスには **となりが6つ** あります。左右の2つはかんたんで `c - 1` と `c + 1` です。上下の段は、ずれ方によって番号が変わります。

- ずれていない段の c 番目のあわから見ると、上下の段（ずれた段）では `c - 1` と `c` がとなり
- ずれた段の c 番目のあわから見ると、上下の段（ずれていない段）では `c` と `c + 1` がとなり

紙に丸を描いて確かめてみると、すぐ納得できます。最後に `filter` で、盤面の外を指している組を取りのぞきます。

## 発射台の色を選ぶ関数

`fillStart()` 関数の **下** に、次の2つの関数を追加します。

```js:game.js

  function colorsOnBoard() {
    const s = new Set();
    for (const row of rows) for (const v of row.cells) if (v >= 0) s.add(v);
    return [...s];
  }
  function pickColor() {
    const on = colorsOnBoard();
    if (!on.length) return randColor();
    return on[Math.floor(Math.random() * on.length)];
  }
```

- `colorsOnBoard()` は、いま盤面に残っている色の一覧を返します。`Set` は **同じ値を1つしか持たない入れ物** なので、全マスの色を入れていくと、重複のない色の一覧ができます。`[...s]` で配列に直します。
- `pickColor()` は、発射台に置く色を **盤面に残っている色の中から** 選びます。盤面にない色を渡されると、どこにも消せず困ってしまうからです。

## start() と発射の関数

`start()` を、次のように **書きかえ**、その **下** に `fire()` を追加します。

```js:game.js
  function start() {
    numColors = 4;
    shot = null; angle = -Math.PI / 2;
    fillStart();
    cur = pickColor(); next = pickColor();
    running = true;
    overlay.classList.add('hide');
  }

  function fire() {
    if (!running || shot) return;
    shot = { x: SX, y: SY, vx: Math.cos(angle) * SPEED, vy: Math.sin(angle) * SPEED, col: cur };
    cur = next; next = pickColor();
  }
```

`fire()` は、弾がまだ飛んでいないときだけ、発射台の位置から `angle` の向きに `SPEED` の速さの弾を作ります。発射台には `next` を繰り上げ、新しい `next` を選びます。

## 空きマスにくっつける

`collides()` 関数の **下** に、次の関数を追加します。

```js:game.js

  function snap(x, y, col) {
    let r = Math.max(0, Math.round((y - R) / RH));
    ensureRow(r + 1);
    // 近くの空きセルの中から一番近いものを選ぶ
    let bestCell = null, bd = Infinity;
    for (let rr = Math.max(0, r - 1); rr <= r + 1; rr++) {
      const row = rows[rr];
      for (let c = 0; c < row.cells.length; c++) {
        if (row.cells[c] >= 0) continue;
        const attached = rr === 0 || neighbors(rr, c).some(([a, b]) => rows[a].cells[b] >= 0);
        if (!attached) continue;
        const dx = cellX(row, c) - x, dy = cellY(rr) - y, d = dx * dx + dy * dy;
        if (d < bd) { bd = d; bestCell = [rr, c]; }
      }
    }
    if (!bestCell) bestCell = [r, Math.max(0, Math.min(rowLen(rows[r]) - 1, Math.round((x - R - (rows[r].off ? R : 0)) / D)))];
    const [sr, sc] = bestCell;
    rows[sr].cells[sc] = col;
  }
```

弾がぶつかった位置 (x, y) は、ちょうどマスの中心とは限りません。そこで「近くのマスのうち、置けるもので一番近いところ」を探して、そこに色を書きこみます。

- `Math.round((y - R) / RH)` で、いちばん近い段の番号を求め、その前後1段を調べます。
- 置けるマスの条件は「空いている」かつ「天井（0段目）か、となりにあわがある」です。宙に浮いたマスにくっつくのを防ぎます。`some` は配列の中に条件を満たすものが **1つでもあれば `true`** を返します。
- 距離は当たり判定と同じく、2乗のまま比べます。`bd = Infinity`（無限大）から始めると、最初に見つけたマスが必ず「一番近い」になります。
- 万一どこも見つからなかったときのために、x 座標から列の番号を逆算した位置を使う予備の処理も入れています。

## 弾を動かす update()

`snap()` の **下** に、新しいセクションを追加します。

```js:game.js

  // ---------- 更新 ----------
  function update(dt) {
    if (shot) {
      const steps = Math.ceil((SPEED * dt) / 6);
      for (let i = 0; i < steps && shot; i++) {
        shot.x += (shot.vx * dt) / steps;
        shot.y += (shot.vy * dt) / steps;
        if (shot.x < R) { shot.x = R; shot.vx = Math.abs(shot.vx); }
        if (shot.x > W - R) { shot.x = W - R; shot.vx = -Math.abs(shot.vx); }
        if (collides(shot.x, shot.y)) { const s = shot; shot = null; snap(s.x, s.y, s.col); }
      }
    }
  }
```

- `dt` は前のフレームからの経過時間（秒）です。**速度 × dt** だけ進めると、パソコンが速くても遅くても、1秒あたりに進む距離が同じになります。
- 900px/s で 1/60 秒進むと 1フレームで15px。あわの半径20px に近く、一気に進めると細いすき間を **すり抜けて** しまいます。そこで1フレームの移動を `steps` 回（1回6px 以下）に分けて、少しずつ進めては当たり判定をしています。
- 壁では `Math.abs` を使って「左の壁なら必ず右向き、右の壁なら必ず左向き」にします。単に符号を反転するより、壁にめりこんだまま往復するバグが起きません。
- ぶつかったら `shot` を `null` にして、`snap()` で盤面にくっつけます。

## 描画とループを書きかえる

`drawGuide()` の1行目を、次のように **書きかえ** ます（弾が飛んでいる間はガイドを消す）。

```js:game.js
    if (shot || !running) return;
```

`draw()` の `// 発射台` の `ctx.arc(SX, SY, R + 10, …)` の行の **下**、`ctx.restore();` の **上** に、次のコードを追加します。

```js:game.js
    if (cur != null) drawBubble(SX, SY, cur);
    if (next != null) {
      ctx.fillStyle = 'rgba(255,255,255,.5)'; ctx.font = '11px system-ui, sans-serif'; ctx.textAlign = 'center';
      ctx.fillText('つぎ', NX, NY - 20);
      drawBubble(NX, NY, next, R * 0.7);
    }
    if (shot) drawBubble(shot.x, shot.y, shot.col);
```

つぎのあわは `R * 0.7` と小さめに描き、上に「つぎ」と文字を添えます。`fillText` で Canvas に文字を書けます。

`loop()` 関数を、次のように **書きかえ** ます。

```js:game.js
  function loop(t) {
    const dt = Math.min(0.033, (t - lastT) / 1000 || 0);
    lastT = t;
    if (running) update(dt);
    draw();
    requestAnimationFrame(loop);
  }
```

`requestAnimationFrame` は呼び出すときに **今の時刻（ミリ秒）** を `t` として渡してくれます。前回との差を1000で割れば秒になります。別のタブを見ていて戻ってきたときなどに `dt` が大きくなりすぎないよう、最大 0.033秒（約30fps ぶん）に制限しています。最初のフレームは計算できず `NaN` になるので、`|| 0` で 0 にしています。

## 指をはなしたら発射

`release` 関数の `aimAt(toLocal(e));` の **下** に、次の1行を追加します。

```js:game.js
    fire();
```

最後に、ファイル末尾のタイトル画面用の行を、次のように **書きかえ** ます。

```js:game.js
  numColors = 4; fillStart(); cur = 0; next = 1; angle = -Math.PI / 2;
```

> [!CHECK] 動作チェック
> - 発射台に色つきのあわが、その左下に小さな「つぎ」のあわが表示される
> - 指をはなす（クリックする）と、あわがガイドの方向へ飛び、壁ではね返る
> - あわは天井やほかのあわにぶつかると、ずれた並びにぴったりはまってくっつく
> - 発射するたびに「つぎ」のあわが発射台に来て、新しい「つぎ」が出る
> - あわはまだ消えない。デッドラインをこえてもゲームは続く（ステップ5・6で作ります）
