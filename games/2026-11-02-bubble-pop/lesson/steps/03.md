## このステップのゴール

マウスや指でねらいを決めると、発射台から点線のガイドが伸びるようにします。ガイドは左右の壁ではね返り、あわにぶつかったところで止まります。

ここで、このゲームでいちばん大事な **当たり判定**（`collides`）も作ります。ガイド線も、次のステップで飛ばす弾も、同じ関数で「ぶつかったか」を調べます。

## 変数を追加する

`let rows, numColors, running = false;` を、次の2行に **書きかえ** ます。

```js:game.js
  let rows, angle, numColors, running = false;
  let aiming = false;
```

- `angle` は発射する向き（ラジアン）です。Canvas は y が下向きなので、**真上は `-Math.PI / 2`**（-90度）、右は `0`、左は `-Math.PI` になります。上方向はすべてマイナスの角度です。
- `aiming` は「いま指（マウス）でねらっている最中か」です。

## start() でねらいをリセットする

`start()` を、次のように **書きかえ** ます。

```js:game.js
  function start() {
    numColors = 4;
    angle = -Math.PI / 2;
    fillStart();
    running = true;
    overlay.classList.add('hide');
  }
```

## 当たり判定を追加する

`start()` の **下** に、次の関数を追加します。

```js:game.js

  function collides(x, y) {
    if (y <= R) return true;
    const r0 = Math.max(0, Math.floor((y - R) / RH) - 1);
    for (let r = r0; r < Math.min(rows.length, r0 + 3); r++) {
      const row = rows[r];
      for (let c = 0; c < row.cells.length; c++) {
        if (row.cells[c] < 0) continue;
        const dx = cellX(row, c) - x, dy = cellY(r) - y;
        if (dx * dx + dy * dy < (D * 0.86) ** 2) return true;
      }
    }
    return false;
  }
```

「中心が (x, y) のあわを置いたら、天井か、ほかのあわにぶつかるか？」を返す関数です。

- **天井**: 中心の y が `R` 以下なら、天井にくっついたことにします。
- **円どうしの当たり判定**: 2つの円は「中心どうしの距離 < 半径の合計」のとき重なります。距離は三平方の定理 `√(dx² + dy²)` ですが、平方根は計算が重いので **両辺を2乗したまま比べる** のが定番です（`dx * dx + dy * dy < 距離の2乗`）。
- 半径の合計は本来 `D`（40px）ですが、`D * 0.86` と少し小さめにしています。こうすると、あわとあわの細いすき間を弾がすり抜けやすくなり、ねらった奥まで届きやすくなります。遊びやすさのための調整です。
- 盤面ぜんぶを調べるとムダが多いので、`(y - R) / RH` で「いま何段目あたりにいるか」を計算し、**その前後の3段だけ** を調べます。

## ガイド線を描く関数を追加する

`shade()` 関数の **下**、`function draw()` の **上** に、次の関数を追加します。

```js:game.js

  function drawGuide() {
    if (!running) return;
    let x = SX, y = SY, vx = Math.cos(angle), vy = Math.sin(angle);
    ctx.fillStyle = 'rgba(255,255,255,.55)';
    let dist = 0;
    for (let i = 0; i < 260 && dist < 900; i++) {
      x += vx * 5; y += vy * 5; dist += 5;
      if (x < R) { x = R; vx = -vx; }
      if (x > W - R) { x = W - R; vx = -vx; }
      if (collides(x, y)) break;
      if (i % 4 === 0) { ctx.beginPath(); ctx.arc(x, y, 2.2, 0, Math.PI * 2); ctx.fill(); }
    }
  }
```

- `Math.cos(angle)` と `Math.sin(angle)` は、角度 `angle` の方向を向いた **長さ1の矢印**（x 成分と y 成分）になります。これを5倍ずつ足していくと、その方向へ5px ずつ進めます。
- 左右の壁（中心が `R` より左、`W - R` より右）に来たら、`vx` の符号を反転させて **はね返り** を表現します。
- 1歩ごとに `collides` で調べ、ぶつかったらそこで止めます。点は4歩に1回（20px おき）だけ描いて、点線に見せます。
- 実際に弾を飛ばす前に「同じルールで小さな玉を進めてみる」ので、ガイドの通りに弾が飛びます。

`draw()` の、あわを描く `if (rows) rows.forEach(...)` の行の **下** に、次の1行を追加します。

```js:game.js

    drawGuide();
```

## ねらいの操作を追加する

`// ---------- 入力 ----------` の **下**、`startBtn.addEventListener` の **上** に、次のコードを追加します。

```js:game.js
  function toLocal(e) {
    const rect = cv.getBoundingClientRect();
    return { x: ((e.clientX - rect.left) / rect.width) * W, y: ((e.clientY - rect.top) / rect.height) * H };
  }
  function aimAt(p) {
    let a = Math.atan2(p.y - SY, p.x - SX);
    if (a > 0) a = p.x < SX ? -Math.PI + 0.12 : -0.12;    // 下側をさしたら端に寄せる
    angle = Math.max(-Math.PI + 0.12, Math.min(-0.12, a));
  }

  cv.addEventListener('pointerdown', (e) => {
    if (!running) return;
    e.preventDefault();
    const p = toLocal(e);
    aiming = true;
    try { cv.setPointerCapture(e.pointerId); } catch (err) { /* ignore */ }
    aimAt(p);
  });
  cv.addEventListener('pointermove', (e) => {
    if (!running) return;
    const p = toLocal(e);
    if (aiming || e.pointerType === 'mouse') { if (p.y < SY - 10 || aiming) aimAt(p); }
  });
  const release = (e) => {
    if (!aiming) return;
    aiming = false;
    aimAt(toLocal(e));
  };
  cv.addEventListener('pointerup', release);
  cv.addEventListener('pointercancel', () => { aiming = false; });

```

### toLocal … 画面の座標を Canvas の座標へ

Canvas は CSS で拡大・縮小されているので、マウスの位置（`clientX`, `clientY`）をそのまま使うとずれてしまいます。`getBoundingClientRect()` で Canvas が画面のどこに、どの大きさで表示されているかを調べ、「左端から何割の位置か」× `W` で、ゲーム内の 360×600 の座標に直します。

### aimAt … 指した場所に向ける

- `Math.atan2(dy, dx)` は、発射台からその点への **向き（角度）** を返す関数です。
- 真横や下向きに撃てると困るので、角度を `-π + 0.12`（左ななめ下ぎりぎり）〜 `-0.12`（右ななめ下ぎりぎり）の範囲に収めます。`a > 0` は「発射台より下をさした」場合で、左右どちらに近いかで端の角度にします。

### Pointer Events

`pointerdown` / `pointermove` / `pointerup` は、**マウスでも指でもペンでも同じように届く** イベントです。マウス用とタッチ用に別々のコードを書かなくて済みます。

- `pointerdown` で `aiming = true` にしてねらい始めます。`setPointerCapture` を呼ぶと、指が Canvas の外に出ても `pointerup` がこの Canvas に届くようになります。
- `pointermove` では、ねらっている最中なら向きを更新します。マウス（`pointerType === 'mouse'`）の場合はボタンを押していなくても、カーソルの動きでねらいが動くようにしています。
- `pointerup`（指をはなした）で、ねらいを確定します。次のステップで、ここから弾を発射します。
- `pointercancel` は、電話の着信などで操作が中断されたときに届きます。

## タイトル画面のねらいも決めておく

ファイルの最後の `numColors = 4; fillStart();` の行を、次のように **書きかえ** ます。

```js:game.js
  numColors = 4; fillStart(); angle = -Math.PI / 2;
```

> [!CHECK] 動作チェック
> - スタートすると、発射台から真上に白い点線が伸び、あわに当たったところで止まる
> - PC ではマウスを動かすだけで、スマホでは画面をなぞると、点線の向きが変わる
> - 点線を左右の壁に向けると、壁ではね返って反対側へ伸びる
> - 発射台より下をさしても、真横より下には向かない
> - スマホでなぞってもページがスクロールしない
