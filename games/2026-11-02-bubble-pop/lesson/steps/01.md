## このステップのゴール

3つのファイルを用意して、画面の土台を作ります。上に「SCORE・BEST」と「あと〇発で段が下がる」の表示、まん中にゲームを描く **Canvas**（キャンバス）、その上に重ねるタイトル画面（オーバーレイ）を置きます。

完成すると、こんなゲームになります。

- 画面の上のほうに、6色のあわが六角形にずれながらぎっしり並んでいる
- 画面をなぞってねらいを決め、指をはなすと下の発射台からあわが飛ぶ。左右の壁ではね返る
- 同じ色が3つ以上つながるとパチンと消え、天井から切りはなされたあわはまとめて落ちてボーナス
- 消せないショットが続くと天井が1段下がり、あわが下の線をこえたらゲームオーバー

あわの数が多く、弾がなめらかに動くゲームなので、今回は **Canvas** に絵を描く方式で作ります。Canvas は「ピクセルの画用紙」で、JavaScript から円や線を描きこみます。毎フレーム全体を消して描き直すことで、動きを表現します。

- `<canvas id="cv" width="360" height="600">` が、ゲームを描く画用紙です。`width` / `height` は **描画用の解像度** で、ゲームの中ではずっとこの 360×600 の座標で考えます。画面上の表示サイズは CSS で別に決めます。

- `<script>` は `</body>` の直前に置きます。HTML の要素が全部できたあとで JavaScript が動くので、`getElementById` で確実に要素を取れます。

## game.js

最後に JavaScript です。まずは「Canvas を用意して、毎フレーム描き直す」いちばん小さな形を作ります。

```js:game.js
(() => {
  'use strict';
  const W = 360, H = 600, R = 20;
  const SX = W / 2, SY = H - 46;             // 発射台

  const cv = document.getElementById('cv');
  const ctx = cv.getContext('2d');
  const $ = (id) => document.getElementById(id);
  const scoreEl = $('score'), bestEl = $('best'), shotsEl = $('shots');
  const overlay = $('overlay'), ovTitle = $('ov-title'), ovText = $('ov-text'), startBtn = $('start'), toast = $('toast');

  let running = false;

  // ---------- 進行 ----------
  function start() {
    running = true;
    overlay.classList.add('hide');
  }

  // ---------- 描画 ----------
  function draw() {
    ctx.save();
    ctx.clearRect(0, 0, W, H);

    // 発射台
    ctx.fillStyle = 'rgba(255,255,255,.08)';
    ctx.beginPath(); ctx.arc(SX, SY, R + 10, 0, Math.PI * 2); ctx.fill();
    ctx.restore();
  }

  function loop() {
    draw();
    requestAnimationFrame(loop);
  }

  // ---------- 入力 ----------
  startBtn.addEventListener('click', () => { start(); });

  requestAnimationFrame(loop);
})();
```

### 全体を `(() => { ... })();` で包む

ファイル全体をアロー関数で包んで、その場で呼び出しています（即時実行関数）。こうすると中で作った変数がページ全体に漏れず、ほかのスクリプトと名前がぶつかりません。`'use strict';` は、うっかりミス（宣言していない変数への代入など）をエラーとして教えてくれるモードです。

### 定数と要素の取得

- `W`, `H` は Canvas の幅と高さ、`R` はあわの半径（20px）です。数字をそのまま書かずに名前をつけておくと、あとで調整するとき1か所直すだけで済みます。
- `SX`, `SY` は発射台の中心の座標です。Canvas の座標は **左上が (0, 0)**、右に行くほど x が、**下に行くほど y が大きく** なります。
- `cv.getContext('2d')` で、Canvas に絵を描くための道具（コンテキスト）を取り出します。以降の描画はすべて `ctx.〇〇()` で行います。
- `$` は `document.getElementById` を短く書くための小さな関数です。このゲームで使う画面の要素は、ここでまとめて取っておきます（まだ使わないものもあります）。

### draw() … 1枚の絵を描く

- `ctx.clearRect(0, 0, W, H)` で前のフレームの絵を全部消します。
- 円を描くときは `beginPath()` → `arc(中心x, 中心y, 半径, 開始角, 終了角)` → `fill()` の順です。角度はラジアンで、`Math.PI * 2` が1周（360度）です。
- `ctx.save()` と `ctx.restore()` は、色や位置ずらしなどの **描画の設定を保存して元に戻す** 命令です。ステップ6で画面をゆらすときに役立ちます。

### loop() … アニメーションのしくみ

`requestAnimationFrame(loop)` は「次に画面を描きかえるタイミングで `loop` を呼んで」とブラウザに頼む命令です。`loop` の最後でまた自分を予約するので、1秒に約60回 `draw()` がくり返されます。これがゲームの心臓部、**ゲームループ** です。

### start() … ゲーム開始

`running` は「いまゲーム中か」を表すフラグです。スタートボタンが押されたら `true` にして、オーバーレイに `hide` クラスをつけて隠します。ボタンのイベントをアロー関数 `() => { start(); }` で書いているのは、ステップ8でここに音の準備を足すためです。
