## このステップのゴール

天井にぎっしり並んだあわを描きます。バブルシューターのあわは、きっちりした碁盤の目ではなく、**1段ごとに半分ずれて** 並んでいます（六角形グリッド）。こうすると上下の段のあわがすき間にはまりこみ、すき間なく詰まって見えます。

このステップでは、

- 段（row）の配列で盤面を持つ
- 「何段目の何番目」から「画面のどこ」を計算する
- グラデーションと記号で、つやつやのあわを描く

ところまで作ります。

## 定数を書きかえる

`const W = 360, H = 600, R = 20;` の行を、次の4行に **書きかえ** ます（`SX` の行はそのまま残します）。

```js:game.js
  const W = 360, H = 600, R = 20, D = R * 2, COLS = 9;
  const RH = R * Math.sqrt(3);
  const DEAD_ROW = 13;                       // 14段目に入ったらアウト
  const DEAD_Y = R + DEAD_ROW * RH + R + 2;
```

続けて、`const SX = W / 2, SY = H - 46;` の行の **下** に、あわの色の一覧を追加します。

```js:game.js
  const COLORS = [
    { c: '#ff5f7e', g: 'heart' },
    { c: '#ffc94a', g: 'star' },
    { c: '#4fd6a0', g: 'leaf' },
    { c: '#5ab0ff', g: 'drop' },
    { c: '#b98cff', g: 'moon' },
    { c: '#ff9a4a', g: 'dot' },
  ];
```

- `D` はあわの直径、`COLS` は1段に並ぶ最大の数（360 ÷ 40 = 9個）です。
- `RH` は **段と段の縦の間隔** です。ずれて並んだ円がぴったり接するとき、中心どうしは正三角形を作ります。1辺が `D`（= 2R）の正三角形の高さは `2R × √3 / 2 = R√3` なので、段の間隔は `R * Math.sqrt(3)`（約34.6px）になります。直径の40pxより少しつまるので、上下の段がすき間にはまりこみます。
- `DEAD_ROW` と `DEAD_Y` はゲームオーバーの線です。14段目（番号13）より下にあわが来たらアウトにする予定で、`DEAD_Y` はその線を引く y 座標です。
- `COLORS` の `c` は色、`g` はあわに描く記号の名前です。盤面には色そのものではなく **色の番号（0〜5）** を入れます。番号なら「同じ色か？」を `===` で比べるだけで済みます。色だけでなく記号も変えておくと、色の見分けがつきにくい人にも遊びやすくなります。

## 盤面の変数を追加する

`let running = false;` を、次のように **書きかえ** ます。

```js:game.js
  let rows, numColors, running = false;
```

- `rows` は盤面です。**段の配列** で、1段は `{ off: true/false, cells: [色番号, 色番号, …] }` というオブジェクトです。空のマスは `-1` で表します。
- `off` は「この段は半分右にずれているか」です。ずれた段は右端に入りきらないので、マスが1つ少ない8個になります。
- `numColors` は、いま使う色の数です。最初は4色で、ステップ6で点数に応じて増やします。

## グリッドの関数を追加する

`// ---------- 進行 ----------` の **上** に、次のコードを追加します。

```js:game.js
  // ---------- グリッド ----------
  const rowLen = (row) => (row.off ? COLS - 1 : COLS);
  const cellX = (row, c) => R + c * D + (row.off ? R : 0);
  const cellY = (r) => R + r * RH;

  function makeRow(off, fill) {
    const row = { off, cells: [] };
    for (let c = 0; c < rowLen(row); c++) row.cells.push(fill ? randColor() : -1);
    return row;
  }
  function randColor() { return Math.floor(Math.random() * numColors); }

  function fillStart() {
    rows = [];
    for (let r = 0; r < 7; r++) {
      const row = makeRow(r % 2 === 1, false);
      for (let c = 0; c < rowLen(row); c++) {
        // 近くの色を引きつぐと塊ができて遊びやすい
        let col = randColor();
        if (Math.random() < 0.3 && c > 0) col = row.cells[c - 1];
        else if (Math.random() < 0.25 && r > 0) col = rows[r - 1].cells[Math.min(c, rowLen(rows[r - 1]) - 1)];
        row.cells[c] = col;
      }
      rows.push(row);
    }
  }

```

### マスの番号から座標へ

- `rowLen(row)` … その段のマスの数。ずれた段は8、そうでなければ9です。
- `cellX(row, c)` … c 番目のマスの中心の x 座標。左端のあわの中心は `R`、そこから直径 `D` ずつ右へ進み、ずれた段ならさらに `R`（半分）右へずらします。
- `cellY(r)` … r 段目の中心の y 座標。いちばん上の段の中心は `R`、そこから `RH` ずつ下がります。

「データは番号で持ち、描くときだけ座標に直す」のがポイントです。こうしておくと、あとで「となりのマス」や「同じ色の塊」を調べるときに、番号だけで考えられます。

### makeRow と fillStart

- `makeRow(off, fill)` は1段ぶんのオブジェクトを作ります。`fill` が `true` ならランダムな色、`false` なら空（`-1`）で埋めます。`{ off, cells: [] }` は `{ off: off, cells: [] }` の省略形です。
- `fillStart()` は、ゲーム開始時の7段の盤面を作ります。奇数段（`r % 2 === 1`）を「ずれた段」にして、交互にずらします。
- 完全にランダムだと同じ色がバラバラになって消しにくいので、30% の確率で **左どなりの色**、25% の確率で **上の段の色** を引きつぎます。こうすると同じ色の塊ができやすく、遊びやすい盤面になります。

## start() を書きかえる

`start()` 関数を、次のように **書きかえ** ます。

```js:game.js
  function start() {
    numColors = 4;
    fillStart();
    running = true;
    overlay.classList.add('hide');
  }
```

スタートするたびに新しい盤面を作ります。

## あわを描く関数を追加する

`// ---------- 描画 ----------` の **下**、`function draw()` の **上** に、次のコードを追加します。

```js:game.js
  function drawGlyph(x, y, g, s) {
    ctx.fillStyle = 'rgba(255,255,255,.55)';
    ctx.beginPath();
    switch (g) {
      case 'heart':
        ctx.moveTo(x, y + s * 0.6);
        ctx.bezierCurveTo(x - s * 1.2, y - s * 0.2, x - s * 0.5, y - s, x, y - s * 0.35);
        ctx.bezierCurveTo(x + s * 0.5, y - s, x + s * 1.2, y - s * 0.2, x, y + s * 0.6);
        break;
      case 'star':
        for (let i = 0; i < 10; i++) {
          const a = -Math.PI / 2 + (i * Math.PI) / 5, rr = i % 2 ? s * 0.4 : s * 0.9;
          ctx.lineTo(x + Math.cos(a) * rr, y + Math.sin(a) * rr);
        }
        break;
      case 'leaf':
        ctx.ellipse(x, y, s * 0.45, s * 0.85, Math.PI / 4, 0, Math.PI * 2);
        break;
      case 'drop':
        ctx.moveTo(x, y - s * 0.9);
        ctx.quadraticCurveTo(x + s * 0.8, y + s * 0.1, x, y + s * 0.7);
        ctx.quadraticCurveTo(x - s * 0.8, y + s * 0.1, x, y - s * 0.9);
        break;
      case 'moon':
        ctx.arc(x, y, s * 0.75, Math.PI * 0.3, Math.PI * 1.7);
        ctx.arc(x + s * 0.35, y, s * 0.55, Math.PI * 1.6, Math.PI * 0.4, true);
        break;
      default:
        ctx.arc(x, y, s * 0.4, 0, Math.PI * 2);
    }
    ctx.fill();
  }

  function drawBubble(x, y, col, rad = R - 1, alpha = 1) {
    const k = COLORS[col];
    ctx.globalAlpha = alpha;
    const g = ctx.createRadialGradient(x - rad * 0.35, y - rad * 0.4, rad * 0.1, x, y, rad);
    g.addColorStop(0, '#fff');
    g.addColorStop(0.25, k.c);
    g.addColorStop(1, shade(k.c));
    ctx.fillStyle = g;
    ctx.beginPath(); ctx.arc(x, y, rad, 0, Math.PI * 2); ctx.fill();
    drawGlyph(x + rad * 0.1, y + rad * 0.12, k.g, rad * 0.42);
    ctx.globalAlpha = 1;
  }
  const shadeCache = {};
  function shade(hex) {
    if (shadeCache[hex]) return shadeCache[hex];
    const n = parseInt(hex.slice(1), 16);
    const f = (v) => Math.floor(v * 0.55);
    return (shadeCache[hex] = `rgb(${f(n >> 16)},${f((n >> 8) & 255)},${f(n & 255)})`);
  }

```

### drawBubble … つやつやのあわ

- `createRadialGradient(x1, y1, r1, x2, y2, r2)` は **円形のグラデーション** を作ります。中心を左上に少しずらした小さな円から、あわ全体の円に向かって「白 → あわの色 → 暗い色」と変化させると、光が当たった立体的な玉に見えます。
- `rad = R - 1` のように引数に `=` で値を書くと、省略されたときの **デフォルト値** になります。半径を1px小さくして、となりのあわとの間にほんの少しすき間を作っています。
- `globalAlpha` は描くものの不透明度です。ステップ5で落ちていくあわを少し透かして描くときに使います。描き終わったら `1` に戻すのを忘れないようにします。

### shade … 暗い色を作る

`'#ff5f7e'` のような色の文字列を `parseInt(…, 16)` で1つの数にし、ビット演算で赤・緑・青を取り出します（`n >> 16` が赤、`(n >> 8) & 255` が緑、`n & 255` が青）。それぞれを 0.55 倍すると、同じ色合いの暗い色になります。毎フレーム何十回も計算するので、一度作った結果は `shadeCache` に覚えておきます（キャッシュ）。

### drawGlyph … あわの記号

ハート・星・葉っぱ・しずく・月・点を、Canvas のパス命令で描きます。

- `moveTo` でペンを置き、`lineTo` で直線、`quadraticCurveTo` / `bezierCurveTo` で曲線を引きます。ベジェ曲線は「途中で引っぱられる点（制御点）」を指定して、なめらかなカーブを作るしくみです。
- 星は、外側の点（半径大）と内側の点（半径小）を交互に10個つないでいます。
- 月は、大きな円弧と、少し右にずらした小さな円弧を **逆回り**（最後の引数 `true`）でつないで、三日月の形を切り抜いています。

## draw() を書きかえる

`draw()` の `ctx.clearRect(0, 0, W, H);` の **下**、`// 発射台` の **上** に、次のコードを追加します。

```js:game.js

    // デッドライン
    ctx.strokeStyle = 'rgba(255,95,126,.55)';
    ctx.setLineDash([8, 6]); ctx.lineWidth = 2;
    ctx.beginPath(); ctx.moveTo(0, DEAD_Y); ctx.lineTo(W, DEAD_Y); ctx.stroke();
    ctx.setLineDash([]);

    if (rows) rows.forEach((row, r) => row.cells.forEach((v, c) => { if (v >= 0) drawBubble(cellX(row, c), cellY(r), v); }));
```

- `setLineDash([8, 6])` で「8px 描いて 6px あける」点線になります。使い終わったら `setLineDash([])` で実線に戻します。
- 盤面は `rows.forEach` で段ごと、`row.cells.forEach` でマスごとに見て、空でない（`v >= 0`）マスだけあわを描きます。

## タイトル画面にも盤面を出す

ファイルの最後、`requestAnimationFrame(loop);` の **上** に、次の2行を追加します。

```js:game.js
  // タイトル画面用に盤面を用意しておく
  numColors = 4; fillStart();
```

タイトル画面の後ろにも盤面が透けて見えるように、最初に一度盤面を作っておきます。
