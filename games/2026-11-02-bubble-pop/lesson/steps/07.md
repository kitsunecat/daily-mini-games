## このステップのゴール

遊びやすさを上げる操作を2つ足します。

- 発射台か「つぎ」のあわをタップすると、**いまのあわと、つぎのあわを入れかえ** られる
- PC では **キーボード** でも遊べる（←→ でねらい、Space で発射、X で入れかえ、Enter でスタート）

## 入れかえの関数

`fire()` 関数の **下** に、次の関数を追加します。

```js:game.js

  function swap() {
    if (!running || shot) return;
    [cur, next] = [next, cur];
  }
```

`[cur, next] = [next, cur];` は **分割代入** を使った入れかえの書き方です。右側で `[next の値, cur の値]` という配列を作り、それを左側の `cur` と `next` に順番に代入します。一時的な変数を用意しなくても、1行で2つの値を交換できます。

弾が飛んでいる間は入れかえられないようにしています（飛んでいる弾の色は変わらないので、紛らわしくならないように）。

## 入れかえのヒントを描く

`draw()` の `drawBubble(NX, NY, next, R * 0.7);` の行の **下** に、次の1行を追加します。

```js:game.js
      ctx.fillText('⇄ タップで入れかえ', SX + 82, SY + 30);
```

## タップで入れかえる

`aimAt()` 関数の **下** に、次の1行を追加します。

```js:game.js
  const onSwapZone = (p) => Math.hypot(p.x - SX, p.y - SY) < R + 12 || Math.hypot(p.x - NX, p.y - NY) < R + 6;
```

`Math.hypot(dx, dy)` は `√(dx² + dy²)`、つまり2点間の距離を計算してくれる関数です。発射台のまわり、または「つぎ」のあわのまわりの円の中をさしているかを調べます。ここでは1回しか計算しないので、読みやすさを優先して `hypot` を使っています。

`pointerdown` のイベントの中、`const p = toLocal(e);` の **下** に、次の1行を追加します。

```js:game.js
    if (onSwapZone(p)) { swap(); aiming = false; return; }
```

入れかえの場所をタップしたときは、ねらいを始めずに `return` で処理を終えます。`aiming` が `false` のままなので、指をはなしても発射されません。

## キーボード操作

`startBtn.addEventListener(…)` の行の **上** に、次のコードを追加します。

```js:game.js
  window.addEventListener('keydown', (e) => {
    if (!running) {
      if (e.key === 'Enter' || e.key === ' ') { e.preventDefault(); start(); }
      return;
    }
    if (e.key === 'ArrowLeft') { angle = Math.max(-Math.PI + 0.12, angle - 0.05); e.preventDefault(); }
    else if (e.key === 'ArrowRight') { angle = Math.min(-0.12, angle + 0.05); e.preventDefault(); }
    else if (e.key === ' ' || e.key === 'ArrowUp' || e.key === 'Enter') { fire(); e.preventDefault(); }
    else if (e.key === 'x' || e.key === 'X' || e.key === 'Shift') swap();
  });

```

- `e.key` には押されたキーの名前が入ります（`'ArrowLeft'`、`' '`（スペース）、`'Enter'`、`'x'` など）。
- ゲーム中でないとき（タイトル画面・ゲームオーバー画面）は、Enter か Space でスタートします。
- ←→ は角度を 0.05 ラジアン（約3度）ずつ動かし、マウスのときと同じ範囲に収めます。
- `e.preventDefault()` で、矢印キーやスペースでページがスクロールするのを止めます。

> [!CHECK] 動作チェック
> - 発射台の右下に「⇄ タップで入れかえ」と表示される
> - 発射台のあわ、または「つぎ」のあわをタップ（クリック）すると、2つの色が入れかわり、発射はされない
> - それ以外の場所をなぞって指をはなすと、これまでどおり発射される
> - PC で ←→ キーを押すとガイドの向きが少しずつ変わり、Space（または ↑・Enter）で発射、X で入れかえができる
> - タイトル画面やゲームオーバー画面で Enter を押すと、ゲームが始まる
