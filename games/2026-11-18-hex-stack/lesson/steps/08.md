## このステップのゴール

最後に、ゲームとしての仕上げをします。

- 盤面が全部うまったら **ゲームオーバー** にして、スコアを表示する
- 「もう一度あそぶ」ボタンや Enter / Space キーで **リトライ** できる
- **ハイスコア** をブラウザに保存して、次に開いたときも BEST に表示する
- 置いたとき・タイルが着地したとき・消えたときに **効果音** を鳴らす

これで完成品と同じゲームになります。

## ハイスコアを読みこむ

まず定数の `const RADIUS = 2;` の **下** に追加します。

```js:game.js
  const BEST_KEY = 'hex-stack-best';
```

次に、`let score = 0, level = 1, cleared = 0, goal = 30;` の **下** に追加します。

```js:game.js
  let best = 0;
```

最後に、`let toasts = [];` の **下**、`// ---------- board ----------` の **上** に追加します（前後に空行を入れます）。

```js:game.js
  try { best = parseInt(localStorage.getItem(BEST_KEY) || '0', 10) || 0; } catch (e) { best = 0; }
  elBest.textContent = best;
```

**localStorage** は、ブラウザにちょっとしたデータを保存しておける場所です。ページを閉じても消えません。`getItem(キー)` で読み、`setItem(キー, 文字列)` で書きます。保存できるのは文字列だけなので、`parseInt` で数に直します。まだ保存されていなければ `null` が返るので、`|| '0'` で `'0'` にしてから読みます。プライベートブラウズなどで localStorage が使えないとエラーになることがあるので、`try { ... } catch` で囲んでいます。

キーの名前（`'hex-stack-best'`）は、同じサイトのほかのゲームの保存データとぶつからないように、ゲームごとに変えておきます。

## 効果音

`function loop(now) { ... }` の行の **下**、`// ---------- logic ----------` の **上** に追加します。

```js:game.js
  // ---------- sound ----------
  let ac = null;
  function beep(freq, dur, type, vol) {
    try {
      if (!ac) ac = new (window.AudioContext || window.webkitAudioContext)();
      const o = ac.createOscillator(), g = ac.createGain();
      o.type = type || 'sine'; o.frequency.value = freq;
      g.gain.setValueAtTime(vol || 0.06, ac.currentTime);
      g.gain.exponentialRampToValueAtTime(0.0001, ac.currentTime + dur);
      o.connect(g); g.connect(ac.destination); o.start(); o.stop(ac.currentTime + dur);
    } catch (e) { /* no audio */ }
  }

```

**Web Audio API** を使うと、音声ファイルなしで音を作れます。

- **オシレーター**（`createOscillator`）は、決まった高さ（`frequency`、Hz）と音色（`type`: `'sine'` やわらかい・`'square'` ピコピコ・`'triangle'` まるい・`'sawtooth'` ざらざら）の音を出し続ける装置です
- **ゲイン**（`createGain`）は音量のつまみです。`exponentialRampToValueAtTime` で `dur` 秒かけてほぼ 0 まで下げると、「ポン」と自然に消える音になります
- オシレーター → ゲイン → スピーカー（`destination`）の順に `connect` でつなぎ、`start()` して `dur` 秒後に `stop()` します

ブラウザは「ユーザーが画面を操作するまで音を出さない」決まりになっているので、`AudioContext` は最初に音を鳴らすとき（山をさわったとき）に作ります。

## 効果音を鳴らす場所

4か所に足します。

1つ目。`transfer()` の中の `done:` の行を、次のように **書きかえます**。タイルが着地するたびに、山が高くなるほど高い音で「ポッ」と鳴ります。

```js:game.js
          done: () => { dst.pending--; dst.stack.push(col); beep(500 + dst.stack.length * 25, .05, 'triangle', .03); res(); }
```

2つ目。`tryClear()` の `toasts.push(...)` の行の **下** に追加します。消えたときに2つの音を少しずらして「ピロン」と鳴らします。

```js:game.js
    beep(880, .15, 'square', .05); setTimeout(() => beep(1320, .2, 'square', .04), 90);
```

3つ目。`place()` の `drag = null;` の **下** に追加します。

```js:game.js
    beep(330, .08, 'sine', .06);
```

4つ目。`pointerdown` の中、`try { cv.setPointerCapture(...) } ...` の行の **下** に追加します。山をつかんだときの小さな音です。

```js:game.js
      beep(600, .04, 'sine', .04);
```

## ゲームオーバーの判定

`place()` を次のように **書きかえます**（最後に1行増えます。3つ目の効果音も入っています）。

```js:game.js
  async function place(i, cell) {
    if (busy || !tray[i] || cell.stack.length) return;
    busy = true;
    cell.stack = tray[i];
    tray[i] = null;
    selected = null;
    drag = null;
    beep(330, .08, 'sine', .06);
    updateHud();
    await resolve(cell);
    refillTray();
    updateHud();
    busy = false;
    if (cells.every(c => c.stack.length)) gameOver();
  }
```

連鎖が全部終わったあとで、すべてのマスに山があれば、もう置ける場所がないのでゲームオーバーです。連鎖で消えてマスが空くこともあるので、`resolve()` を待ってから調べるのが大事です。

## ハイスコアを保存する

`updateHud()` を次のように **書きかえます**。

```js:game.js
  function updateHud() {
    elScore.textContent = score;
    elLevel.textContent = level;
    elGoal.textContent = Math.max(0, goal - cleared) + '枚';
    elFree.textContent = cells.filter(c => !c.stack.length).length;
    if (score > best) {
      best = score;
      elBest.textContent = best;
      try { localStorage.setItem(BEST_KEY, String(best)); } catch (e) { /* ignore */ }
    }
  }
```

スコアがハイスコアを超えたら、その場で BEST を書きかえて保存します。ゲームオーバーのときだけ保存するより、途中でページを閉じてしまっても記録が残るので安心です。

## ゲームオーバー画面

`newGame()` の閉じかっこ `}` の **下**、`// ---------- input ----------` の **上** に追加します。

```js:game.js
  function gameOver() {
    playing = false;
    beep(220, .3, 'sawtooth', .05); setTimeout(() => beep(150, .4, 'sawtooth', .05), 200);
    ovTitle.textContent = 'ゲームオーバー';
    ovText.innerHTML = `盤面がいっぱいになりました。<br>スコア <b class="hl">${score}</b>（レベル ${level}）<br>ハイスコア <b class="hl">${best}</b>`;
    startBtn.textContent = 'もう一度あそぶ';
    overlay.classList.remove('hidden');
  }

```

`playing = false` にして操作を止め、タイトル画面と同じオーバーレイの文字を書きかえて表示します。ボタンの文字を「もう一度あそぶ」にしますが、押したときに呼ばれるのは同じ `newGame()` です。newGame は盤面・トレイ・スコア・演出をすべて最初の状態に戻すので、そのままリトライになります。

`innerHTML` は HTML として文字を入れるので、`<br>` や `<b>` が使えます。ここで入れているのは自分で作った数字だけなので安全ですが、ユーザーが入力した文字をそのまま `innerHTML` に入れるのは危険なので避けましょう。

## Enter / Space でスタート

`keydown` の中の `if (!playing) return;` の行を、次のように **書きかえます**。

```js:game.js
    if (!playing) {
      if (e.key === 'Enter' || e.key === ' ') { e.preventDefault(); newGame(); }
      return;
    }
```

タイトル画面やゲームオーバー画面で Enter か Space を押すと、ボタンを押したのと同じようにゲームが始まります。

> [!CHECK] 動作チェック
> - 山をつかむ・置く・タイルが着地する・消えるときに、それぞれ効果音が鳴る
> - 盤面がすべてうまると「ゲームオーバー」の画面が出て、スコア・レベル・ハイスコアが表示される
> - 「もう一度あそぶ」か Enter / Space で、盤面が空になって最初からあそべる
> - ページを再読み込みしても、BEST に前回までの最高スコアが残っている
> - 完成品（このゲームのページ）と同じように遊べる

## 改造アイデア

> [!TIP] 消える枚数を変える
> `CLEAR_N` を 8 にするとかんたんに、12 にするとむずかしくなります。てっぺんの数字の色を「あと何枚で消えるか」で変えると、狙いやすくなります。

> [!TIP] 盤面を広げる
> `RADIUS` を 3 にすると、37マスの大きな盤面になります。`layout()` の `S` の計算と `boardH`（中心の列のマス数 `2 * RADIUS + 1` を使う）も合わせて直してみましょう。

> [!TIP] 山を捨てられるゴミ箱
> トレイの横に「ゴミ箱」を作り、1ゲームに3回まで、いらない山を捨てられるようにしてみましょう。ドラッグの `endDrag()` で、ゴミ箱の上で離したかを調べるのがポイントです。

> [!TIP] つぎの山を予告する
> 次に補充される3つの山を先に作っておき、トレイの上に小さく表示すると、先を読んだ戦略が立てられるようになります。
