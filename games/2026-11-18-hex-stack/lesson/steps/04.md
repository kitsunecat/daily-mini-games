## このステップのゴール

下のトレイに山を3つ並べ、**山をタップ → 空きマスをタップ** で盤面に置けるようにします。3つとも置き終わったら、新しい山が3つ補充されます。PC では 1〜3 キーでも山を選べます。上の「空きマス」の数も動かします。

## トレイの変数

`let cells = [];` の **下** に追加します。

```js:game.js
  let tray = [null, null, null];
  let selected = null;
  let busy = false;
```

- `tray` はトレイの3つの山です。置いて空になった場所は `null` にします
- `selected` は今選んでいるトレイの番号（0〜2）。何も選んでいなければ `null` です
- `busy` は「タイルが飛んでいる最中で、操作を受けつけない」ことを表すフラグです。ステップ6で使います

## トレイを補充する

`randStack()` の **下** に追加します（`// ---------- layout ----------` の上の空行より前です）。

```js:game.js
  function refillTray() {
    if (tray.every(t => t === null)) tray = [randStack(), randStack(), randStack()];
  }
```

`every()` は「配列の全部が条件を満たすか」を調べるメソッドです。3つとも `null`（全部置き終わった）のときだけ、新しい山を3つ作ります。

## トレイの位置

`layout()` の **下**、`function thick(s)` の **上** に追加します。

```js:game.js
  function trayPos(i) { return { x: W / 2 + (i - 1) * Math.min(W * 0.3, S * 3.2), y: trayY }; }
```

i = 0, 1, 2 のとき `(i - 1)` は -1, 0, 1 になるので、まん中の山は画面の中央、左右の山はそこから同じ間隔だけ離れた位置になります。間隔は画面幅の 30% か S の 3.2 倍の小さいほうです。

## 選んでいるときは空きマスを光らせる

`draw()` の `// board base` の中、`let fill = 'rgba(255,255,255,.08)';` の **下** に1行追加します。

```js:game.js
      if (!c.stack.length && !c.pending && selected !== null && !busy) fill = 'rgba(198,182,255,.18)';
```

山を選んでいる間は、空きマス（山が無く、タイルが飛んできている途中でもないマス）を薄い紫色にして、「ここに置ける」と分かるようにします。

## トレイの山を描く

`draw()` の最後、`roundRect(W / 2 - tw / 2, ...); ctx.fill();` の行の **下**（`draw()` の閉じかっこ `}` の上）に追加します。

```js:game.js
    for (let i = 0; i < 3; i++) {
      const p = trayPos(i);
      if (selected === i) {
        hexPath(p.x, p.y + 2, S * 1.05);
        ctx.strokeStyle = '#ffd166'; ctx.lineWidth = 3; ctx.stroke();
      }
      if (!tray[i]) continue;
      drawStack(tray[i], p.x, p.y, S * 0.85, false);
    }
```

選んでいる山には、足もとに黄色い六角形のわくを描きます。トレイの山は盤面より少し小さく（`S * 0.85`）描き、数字のラベルは出しません。

## 置く処理と HUD の更新

`// ---------- logic ----------` の **すぐ下**（`function newGame() {` の **上**）に追加します。

```js:game.js
  function place(i, cell) {
    if (busy || !tray[i] || cell.stack.length) return;
    cell.stack = tray[i];
    tray[i] = null;
    selected = null;
    refillTray();
    updateHud();
  }

  function updateHud() {
    elScore.textContent = score;
    elLevel.textContent = level;
    elGoal.textContent = Math.max(0, goal - cleared) + '枚';
    elFree.textContent = cells.filter(c => !c.stack.length).length;
  }

```

- `place(i, cell)` は、トレイの i 番目の山をマス `cell` に置きます。操作中・トレイが空・マスがうまっている、のどれかなら何もしません。山の配列をそのままマスに移し、トレイ側は `null` にします
- `updateHud()` は画面上の数字（HUD）を今の値に合わせます。空きマスの数は `filter()` で空のマスだけ集めて数えます

## newGame() にトレイの準備を足す

`newGame()` を次のように **書きかえます**（3か所増えています）。

```js:game.js
  function newGame() {
    score = 0; level = 1; cleared = 0; goal = 30;
    selected = null; busy = false;
    for (const c of cells) { c.stack = []; c.pending = 0; }
    // a few starter stacks
    const empty = cells.slice().sort(() => Math.random() - .5);
    for (let k = 0; k < 3; k++) {
      const st = randStack();
      empty[k].stack = st.slice(0, Math.max(1, st.length - 1));
    }
    tray = [null, null, null];
    refillTray();
    playing = true;
    overlay.classList.add('hidden');
    updateHud();
  }
```

## タップとキーの入力

`// ---------- input ----------` の **すぐ下**（`startBtn.addEventListener(...)` の **上**）に追加します。

```js:game.js
  function pickCell(x, y) {
    let bestC = null, bd = Infinity;
    for (const c of cells) {
      const d = Math.hypot(c.x - x, c.y - y);
      if (d < bd) { bd = d; bestC = c; }
    }
    return bd < S * 0.95 ? bestC : null;
  }
  function pickTray(x, y) {
    for (let i = 0; i < 3; i++) {
      const p = trayPos(i);
      if (Math.abs(x - p.x) < S * 1.4 && y > p.y - S * 2.2 && y < p.y + S * 1.1) return i;
    }
    return -1;
  }
  function pos(e) {
    const r = cv.getBoundingClientRect();
    return { x: e.clientX - r.left, y: e.clientY - r.top };
  }

  cv.addEventListener('pointerdown', (e) => {
    if (!playing || busy) return;
    e.preventDefault();
    const p = pos(e);
    const ti = pickTray(p.x, p.y);
    if (ti >= 0 && tray[ti]) {
      selected = ti;
      return;
    }
    const c = pickCell(p.x, p.y);
    if (c && selected !== null && !c.stack.length) place(selected, c);
  });

  window.addEventListener('keydown', (e) => {
    if (!playing) return;
    if (['1', '2', '3'].includes(e.key)) {
      const i = +e.key - 1;
      if (tray[i]) selected = i;
    }
  });

```

### どのマスがタップされた？（当たり判定）

六角形の中に点が入っているかをきちんと調べるのは少し大変です。そこで `pickCell()` では、**いちばん近いマスの中心** を探し、その距離が S の 0.95 倍より近ければそのマスとみなします。`Math.hypot(dx, dy)` は2点の距離（√(dx² + dy²)）です。六角形はほぼ円に近い形なので、この方法で十分に自然に選べます。

`pickTray()` はトレイの山の範囲を四角形で調べます。山は上に積み上がるので、上方向（`S * 2.2`）を広めに取っています。

### pointer イベント

`pointerdown` は、マウスのクリックとスマホのタッチの **両方** で起きるイベントです。`pos(e)` で、画面全体の座標（`clientX`・`clientY`）から Canvas の左上を引いて、Canvas の中の座標に直します。

- トレイの山の上で押されたら、その山を選びます
- それ以外の場所なら、押された場所のマスを調べ、山を選んでいて、しかも空きマスなら `place()` で置きます

`e.preventDefault()` は、ブラウザがもともと持っている動き（テキスト選択など）を止めます。

### キーボード

`keydown` で 1〜3 キーが押されたら、その番号の山を選びます。`+e.key` は文字列 `'2'` を数の 2 に変える書き方です。

> [!CHECK] 動作チェック
> - スタートすると、下のトレイに山が3つ並ぶ
> - トレイの山をタップすると、足もとに黄色いわくが出て、盤面の空きマスが薄い紫色になる
> - そのまま空きマスをタップすると、山がそのマスに移り、「空きマス」の数が1つ減る
> - 3つとも置くと、トレイに新しい山が3つ出てくる
> - PC では 1〜3 キーでも山を選べる
> - まだ、となりに同じ色があってもタイルは集まりません（ステップ6で作ります）
