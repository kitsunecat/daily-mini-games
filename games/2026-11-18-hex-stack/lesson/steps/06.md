## このステップのゴール

いよいよゲームの心臓部です。山を置いたとき、**となりの山とてっぺんの色が同じなら、その色のタイルが1枚ずつ弧をえがいて飛び、1つの山に集まる** ようにします。集まった先でまた同じ色のとなりがあれば、さらに集まります（連鎖）。

ここでは、時間のかかる処理を順番に書ける **async / await** と、ためた仕事を順に片づける **キュー** を使います。

## 飛んでいるタイルの入れ物

`let score = 0, level = 1, ...` の行の **下** に追加します。

```js:game.js
  let flights = [];
```

飛んでいる途中のタイル1枚ごとに、出発地点・到着地点・色・出発時刻などを入れたオブジェクトをここにためます。

## 1色だけの山かどうか

`topRun()` の **下** に追加します。

```js:game.js
  const pure = (st) => st.length > 0 && topRun(st) === st.length;
```

「てっぺんの同じ色のかたまり」が山全体と同じ長さなら、その山は **1色だけ** です。あとで「どちらの山に集めるか」を決めるのに使います。

## 飛んでいるタイルを描く

`draw()` の `// stacks, back-to-front` の2行の **下**、空行のあとに追加します（`// tray` の **上** です。下にも空行を1つ入れます）。

```js:game.js
    // flights
    for (let i = flights.length - 1; i >= 0; i--) {
      const f = flights[i];
      const t = Math.min(1, (now - f.t0) / f.dur);
      if (t < 0) continue;
      const e = t < .5 ? 2 * t * t : 1 - Math.pow(-2 * t + 2, 2) / 2;
      const x = f.x0 + (f.x1 - f.x0) * e;
      const y = f.y0 + (f.y1 - f.y0) * e - Math.sin(Math.PI * t) * S * 1.2;
      drawTile(x, y, S, f.col);
      if (t >= 1) { f.done(); flights.splice(i, 1); }
    }

```

- `t` は「どれだけ進んだか」を 0〜1 で表した数です。（今の時刻 − 出発時刻）÷ 飛ぶ時間 で求め、1 で頭打ちにします
- `e` は **イージング** です。t をそのまま使うと一定の速さで動きますが、この式（ease-in-out）を通すと「ゆっくり出発 → 速く → ゆっくり到着」になり、自然に見えます
- 出発地点から到着地点へ e の割合だけ進めた位置に、`Math.sin(Math.PI * t)` ぶん **上にふくらませる** と、放物線のような弧をえがいて飛びます。sin は t = 0 と 1 で 0、t = 0.5 でいちばん大きく（1）なります
- 到着したら（`t >= 1`）、`f.done()` を呼んで「着いたよ」と知らせ、配列から取りのぞきます。とちゅうで `splice` で取りのぞいても番号がずれないように、配列は **後ろから** 回しています

## 待つための sleep と、タイルを移す transfer

`// ---------- logic ----------` の **すぐ下**（`function place(...)` の **上**）に追加します。

```js:game.js
  const sleep = (ms) => new Promise(r => setTimeout(r, ms));

  async function transfer(src, dst) {
    const n = topRun(src.stack);
    const col = top(src.stack);
    const th = thick(S);
    const jobs = [];
    for (let k = 0; k < n; k++) {
      src.stack.pop();
      const fromH = src.stack.length;
      const toH = dst.stack.length + dst.pending;
      dst.pending++;
      jobs.push(new Promise(res => {
        flights.push({
          x0: src.x, y0: src.y - fromH * th, x1: dst.x, y1: dst.y - toH * th, col,
          t0: performance.now(), dur: 200,
          done: () => { dst.pending--; dst.stack.push(col); res(); }
        });
      }));
      await sleep(45);
    }
    await Promise.all(jobs);
  }

```

### Promise と async / await

**Promise**（プロミス）は「あとで終わる仕事」を表すオブジェクトです。`new Promise(res => { ... })` の `res` を呼んだときに「終わった」ことになります。

`async` をつけた関数の中では、`await Promise` と書くと、その仕事が終わるまで **関数の続きを一時停止** できます。そのあいだも画面の描画（`requestAnimationFrame`）は止まらずに動きつづけるので、アニメーションを待ちながら順番に処理を書けます。

- `sleep(ms)` は `setTimeout` を Promise にしたもので、`await sleep(45)` と書くと 45 ミリ秒待ちます
- `Promise.all(jobs)` は「配列の Promise が **全部** 終わるまで待つ」Promise です

### transfer(src, dst) … てっぺんの同じ色を全部移す

`src`（移す元）のてっぺんの同じ色のかたまり `n` 枚を、1枚ずつ `dst`（移す先）へ飛ばします。

1. 元の山から `pop()` で1枚取り、その高さを出発地点にします
2. 到着地点の高さは「先の山の枚数 + **すでに飛んできている途中の枚数**（`pending`）」です。pending を数えないと、何枚も同時に飛んでいるときに全部同じ高さに着地してしまいます
3. タイルが着いたら（`done`）、pending を減らして本当に山に `push` し、その Promise を終わらせます
4. 45 ミリ秒ずつずらして次のタイルを出発させると、パラパラと連なって飛んでいきます
5. 最後に、全部のタイルが着くまで待ちます

## 連鎖を解決する resolve

`transfer()` の **下** に追加します。

```js:game.js
  async function resolve(start) {
    const queue = [start];
    let guard = 0;
    while (queue.length && guard++ < 400) {
      const c = queue.shift();
      if (!c.stack.length) continue;
      const col = top(c.stack);
      const ns = neighbors(c).filter(n => n.stack.length && top(n.stack) === col);
      if (!ns.length) continue;
      let target = c, sources = ns;
      if (ns.length === 1 && pure(c.stack) && !pure(ns[0].stack)) { target = ns[0]; sources = [c]; }
      for (const s of sources) {
        if (!s.stack.length || top(s.stack) !== col) continue;
        await transfer(s, target);
        queue.push(s);
      }
      queue.push(target);
    }
  }

```

`queue`（キュー）は「あとで調べるマス」の行列です。`shift()` で先頭から1つ取り出し、調べた結果また調べ直したいマスは `push()` で最後に並べます。行列が空になったら連鎖はおしまいです。

1つのマス `c` について、

1. `c` のてっぺんと **同じ色のてっぺんを持つとなりの山**（`ns`）を集めます。無ければ何もしません
2. ふつうは `c` を集める先（`target`）にして、となりの山から `c` へタイルを集めます
3. ただし、同じ色のとなりが1つだけで、`c` が1色だけの山、相手が何色かまざった山のときは、**向きを逆にして** `c` のタイルを相手へ送ります。1色だけの山を空にしてマスを空けたほうが、プレイヤーに有利だからです
4. タイルを渡した山は、てっぺんに別の色が出てきて、新しい組み合わせができているかもしれません。だから `queue` に入れて調べ直します。集めた先 `target` も、さらに集められるかもしれないので調べ直します

`guard` は「万一のバグで無限ループにならないように」400回で打ち切るための安全装置です。

## place() を async にする

`place()` を次のように **書きかえます**。

```js:game.js
  async function place(i, cell) {
    if (busy || !tray[i] || cell.stack.length) return;
    busy = true;
    cell.stack = tray[i];
    tray[i] = null;
    selected = null;
    drag = null;
    updateHud();
    await resolve(cell);
    refillTray();
    updateHud();
    busy = false;
  }
```

置いたらすぐ `busy = true` にして、タイルが飛んでいる間は新しい操作を受けつけないようにします（`pointerdown` の最初で `busy` を見ていました）。`await resolve(cell)` で連鎖が全部終わるのを待ってから、トレイを補充し、`busy` を戻します。

## newGame() で飛んでいるタイルを消す

`newGame()` の `selected = null; drag = null; busy = false;` の行の **下** に追加します。

```js:game.js
    flights = [];
```

> [!CHECK] 動作チェック
> - となりの山とてっぺんの色が同じになるように山を置くと、その色のタイルが1枚ずつ弧をえがいて飛び、1つの山に集まる
> - てっぺんの数字が、集まった枚数に増える
> - タイルを渡した山の下から別の色が出てきて、そのとなりにも同じ色があれば、続けて集まる（連鎖）
> - タイルが飛んでいる間は、トレイの山をさわっても反応しない
> - まだ、10枚以上そろっても消えません（ステップ7で作ります）
