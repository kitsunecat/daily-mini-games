## このステップのゴール

タップ2回だけでなく、**トレイの山を指でつかんで、マスまでドラッグ** して置けるようにします。ドラッグ中は山が指の少し上についてきて、置こうとしているマスが黄色く光ります。

## ドラッグの状態

`let selected = null;` の **下** に追加します。

```js:game.js
  let drag = null;
```

ドラッグしていないときは `null`、ドラッグ中は次のようなオブジェクトを入れます。

- `i` … どのトレイの山をつかんでいるか
- `x`・`y` … 今の指の位置
- `sx`・`sy` … 押しはじめた位置
- `moved` … 押しはじめた位置から 10px 以上動いたか。動いていなければ「ただのタップ」とみなします

## 指の下にあるマスを調べる

`drawStack()` の **下**、`function draw(now) {` の **上** に追加します。

```js:game.js
  function hoverCell() {
    if (!drag || !drag.moved) return null;
    return pickCell(drag.x, drag.y - S * 0.6);
  }

```

ドラッグ中の山は、指でかくれないように **指より S × 0.6 だけ上** に描きます。そのため、置き先のマスも同じだけ上の位置で調べます。見た目と判定の位置をそろえておくのがポイントです。

## ドラッグ中の見た目

`draw()` を3か所書きかえます。

1つ目。`ctx.clearRect(0, 0, W, H);` の **下** に追加します。

```js:game.js
    const hc = hoverCell();
```

2つ目。`// board base` の中、紫色にする `if` の行の **下** に追加します。

```js:game.js
      if (c === hc && !c.stack.length) fill = 'rgba(255,209,102,.45)';
```

3つ目。`// tray` の `for` を、次のように **書きかえて**、その下にドラッグ中の山を描く処理を足します（`draw()` の閉じかっこ `}` の上まで）。

```js:game.js
    for (let i = 0; i < 3; i++) {
      const p = trayPos(i);
      if (selected === i) {
        hexPath(p.x, p.y + 2, S * 1.05);
        ctx.strokeStyle = '#ffd166'; ctx.lineWidth = 3; ctx.stroke();
      }
      if (!tray[i]) continue;
      if (drag && drag.i === i && drag.moved) continue;
      drawStack(tray[i], p.x, p.y, S * 0.85, false);
    }
    if (drag && drag.moved && tray[drag.i]) {
      drawStack(tray[drag.i], drag.x, drag.y - S * 0.6, S, false);
    }
```

ドラッグしている山はトレイの場所には描かず（`continue` で飛ばす）、かわりに指の上に盤面と同じ大きさ `S` で描きます。

## 置いたらドラッグを終わらせる

`place()` の `selected = null;` の **下** に1行追加します。

```js:game.js
    drag = null;
```

`newGame()` の `selected = null; busy = false;` の行も、次のように **書きかえます**。

```js:game.js
    selected = null; drag = null; busy = false;
```

## pointer イベントでドラッグする

`pointerdown` の中、`selected = ti;` の **下** に2行追加します。

```js:game.js
      drag = { i: ti, x: p.x, y: p.y, sx: p.x, sy: p.y, moved: false };
      try { cv.setPointerCapture(e.pointerId); } catch (err) { /* ignore */ }
```

`setPointerCapture()` は「この指（ポインター）のイベントは、Canvas の外に出ても Canvas に送ってね」という命令です。ドラッグ中に指が Canvas の外まで行っても、`pointermove`・`pointerup` を受け取りつづけられます。

続けて、`pointerdown` の `});` の **下**（`window.addEventListener('keydown', ...)` の **上**）に追加します。

```js:game.js
  cv.addEventListener('pointermove', (e) => {
    if (!drag) return;
    const p = pos(e);
    drag.x = p.x; drag.y = p.y;
    if (Math.hypot(p.x - drag.sx, p.y - drag.sy) > 10) drag.moved = true;
  });
  const endDrag = () => {
    if (!drag) return;
    const d = drag;
    if (d.moved) {
      const c = pickCell(d.x, d.y - S * 0.6);
      drag = null;
      if (c && !c.stack.length) { place(d.i, c); return; }
    }
    drag = null;
  };
  cv.addEventListener('pointerup', endDrag);
  cv.addEventListener('pointercancel', () => { drag = null; });
```

- `pointermove` で指の位置を追いかけ、押しはじめから 10px 以上動いたら `moved = true` にします。少しの指のブレでドラッグ扱いにならないようにするためです
- 指を離したとき（`pointerup`）、ドラッグしていて、指の上のマスが空いていればそこに置きます。置けない場所なら `drag = null` にするだけなので、山はトレイに戻ります
- 動かさずに離した場合（ただのタップ）は、`selected` だけが残ります。そのあと空きマスをタップすれば、ステップ4と同じように置けます
- `pointercancel` は、電話の着信などで操作が中断されたときに起きます。ドラッグを取り消しておきます

> [!CHECK] 動作チェック
> - トレイの山を押したまま動かすと、山が指（マウス）の少し上についてくる
> - 空きマスの上まで持っていくと、そのマスが黄色く光る
> - そこで離すと山がそのマスに置かれ、「空きマス」が1つ減る
> - 山があるマスや盤面の外で離すと、山はトレイに戻る
> - ステップ4の「タップしてからタップ」でも、今までどおり置ける
