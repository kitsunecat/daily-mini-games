## このステップのゴール

3つのファイルを用意して、ゲーム画面の土台を作ります。上に「LEVEL・SCORE・BEST」と「次のレベルまで・空きマス」の表示、まん中にゲームを描く **Canvas**（キャンバス）とその上に重ねるタイトル画面（オーバーレイ）、下にひとことヒントを置きます。Canvas には、あとで山を並べる「トレイ」の台だけを描いておきます。

完成すると、こんなゲームになります。

- 盤面は **六角形のマス** が19個集まった、大きな六角形
- 下のトレイに、色つきの六角タイルが何枚か重なった **山** が3つ並ぶ。山をタップしてから空きマスをタップ（またはドラッグ）すると、盤面に置ける
- 置いた山と、となりの山の **いちばん上の色** が同じなら、その色のタイルがまとめて飛んで1つの山に集まる。集まった先でまた同じことが起きる（連鎖）
- 1つの山のてっぺんに同じ色が **10枚** 以上そろうと、その色が消えて得点
- 盤面が全部うまって置けなくなったらゲームオーバー

## game.js

JavaScript はまず「画面の大きさに合わせて Canvas を用意し、毎フレーム描く」ところまでを書きます。

```js:game.js
(() => {
  'use strict';

  const COLORS = ['#ff5d73', '#ffd166', '#4cd18a', '#4aa8ff', '#b07cff', '#ff9a3c', '#3fe0d0'];
  const CLEAR_N = 10;
  const RADIUS = 2;
  const SQ3 = Math.sqrt(3);

  const cv = document.getElementById('cv');
  const ctx = cv.getContext('2d');
  const stage = document.getElementById('stage');
  const $ = (id) => document.getElementById(id);
  const elLevel = $('level'), elScore = $('score'), elBest = $('best'), elGoal = $('goal'), elFree = $('free');
  const overlay = $('overlay'), ovTitle = $('ov-title'), ovText = $('ov-text'), startBtn = $('start');

  let W = 0, H = 0, S = 30, DPR = 1, boardCX = 0, boardCY = 0, trayY = 0;
  let cells = [];
  let playing = false;

  // ---------- layout ----------
  function layout() {
    const r = stage.getBoundingClientRect();
    W = Math.max(200, Math.floor(r.width));
    H = Math.max(260, Math.floor(r.height));
    DPR = Math.min(window.devicePixelRatio || 1, 3);
    cv.width = W * DPR; cv.height = H * DPR;
    cv.style.width = W + 'px'; cv.style.height = H + 'px';
    ctx.setTransform(DPR, 0, 0, DPR, 0, 0);
    S = Math.min(W / 8.4, H / 13.6, 46);
    boardCX = W / 2;
    const boardH = 5 * SQ3 * S;
    const trayH = 3.4 * S;
    const total = boardH + 1.6 * S + trayH;
    const top0 = (H - total) / 2 + 1.6 * S;
    boardCY = top0 + boardH / 2;
    trayY = top0 + boardH + trayH * 0.62;
    for (const c of cells) {
      c.x = boardCX + S * 1.5 * c.q;
      c.y = boardCY + S * SQ3 * (c.r + c.q / 2);
    }
  }

  // ---------- drawing ----------
  function draw(now) {
    ctx.clearRect(0, 0, W, H);
    // tray
    ctx.fillStyle = 'rgba(255,255,255,.06)';
    const tw = Math.min(W - 16, S * 10);
    roundRect(W / 2 - tw / 2, trayY - S * 2.3, tw, S * 3.3, 16); ctx.fill();
  }
  function roundRect(x, y, w, h, r) {
    ctx.beginPath();
    ctx.moveTo(x + r, y); ctx.arcTo(x + w, y, x + w, y + h, r); ctx.arcTo(x + w, y + h, x, y + h, r);
    ctx.arcTo(x, y + h, x, y, r); ctx.arcTo(x, y, x + w, y, r); ctx.closePath();
  }

  function loop(now) { draw(now); requestAnimationFrame(loop); }

  // ---------- logic ----------
  function newGame() {
    playing = true;
    overlay.classList.add('hidden');
  }

  // ---------- input ----------
  startBtn.addEventListener('click', newGame);
  window.addEventListener('resize', layout);

  layout();
  requestAnimationFrame(loop);
})();
```

### 全体を (() => { ... })(); で囲む

ファイル全体を「すぐ実行される関数」で囲むと、中で作った変数がページ全体（グローバル）に漏れません。`'use strict';` は、うっかりミスをエラーとして教えてくれるモードです。

### 定数

- `COLORS` はタイルの色です。タイルの色は **この配列の番号**（0〜6）で持ちます。色の文字列をそのまま持つより、比べるのも保存するのもかんたんです
- `CLEAR_N` は「何枚そろったら消えるか」（10枚）、`RADIUS` は盤面の大きさ（中心から2マス）です。ステップ2・7で使います
- `SQ3` は √3（約 1.732）です。六角形の計算に何度も出てくるので、先に作っておきます

### $ と要素の取り出し

`const $ = (id) => document.getElementById(id);` は、長い `document.getElementById` を `$('level')` と短く書くための小さな関数です。HUD（スコアなどの表示）の要素は最初にまとめて取り出しておきます。

### layout() … 画面の大きさから、すべての位置を決める

ステージの大きさを `getBoundingClientRect()` で測り、Canvas をその大きさにします。

`devicePixelRatio`（DPR）は、スマホなどの高精細な画面で「CSS の1ピクセルが実際は何ドットか」を表す数です。Canvas の **中身のピクセル数**（`cv.width`）は DPR 倍にして、**見た目の大きさ**（`cv.style.width`）は CSS ピクセルのままにすると、ぼやけずにくっきり描けます。`ctx.setTransform(DPR, 0, 0, DPR, 0, 0)` で座標を DPR 倍しておけば、描くときは CSS ピクセルのまま考えられます。

`S` は **六角形1マスの半径**（中心から角までの長さ）です。このゲームのあらゆる大きさは S を基準にします。横幅なら8.4個分、縦なら13.6個分が入る大きさで、46px で頭打ちにしています。

そのあと、盤面の高さ `boardH` とトレイの高さ `trayH` を足して、全体が画面のまん中に来るように **盤面の中心** `boardCX`・`boardCY` と **トレイの中心の高さ** `trayY` を決めます。最後の `for (const c of cells)` は各マスの画面上の位置を決める部分で、ステップ2で説明します（今は `cells` が空なので何もしません）。

### draw() と loop()

`draw()` はまず `clearRect` で画面を消し、トレイの台（角の丸い半透明の四角）を描きます。`roundRect()` は `arcTo()` を4回使って角の丸い四角の「形（パス）」を作る関数で、そのあと `ctx.fill()` で塗ります。

`requestAnimationFrame(loop)` は「次に画面を描きかえるタイミングで loop を呼んで」とブラウザに頼む命令です。loop の最後でもう一度頼むので、1秒に約60回 draw がくり返されます。引数 `now` はミリ秒単位の時刻で、ステップ6のアニメーションで使います。

### newGame() とイベント

スタートボタンが押されたら `newGame()` で `playing = true` にして、オーバーレイに `hidden` クラスをつけて隠します。ウィンドウの大きさが変わったら `layout()` をもう一度呼んで、位置を計算し直します。
