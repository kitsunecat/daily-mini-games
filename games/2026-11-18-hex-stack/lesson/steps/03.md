## このステップのゴール

色つきの六角タイルを重ねた **山** を、ランダムに作って盤面に描きます。スタートすると、盤面のどこかに最初の山が3つ置かれるようにします。

## 山は「色番号の配列」

山はとてもシンプルに、**下から順に色番号を並べた配列** で表します。

- `[0, 0, 3]` … 下から「赤・赤・青」。いちばん上（てっぺん）は青
- 配列の **最後の要素がてっぺん** です。タイルを積むときは `push()`、てっぺんから取るときは `pop()` を使います

このように「最後に入れたものから取り出す」入れ物を **スタック** と呼びます。マスの `stack` という名前はここから来ています。

## スコアとレベルの変数

`let playing = false;` の **下** に追加します。

```js:game.js
  let score = 0, level = 1, cleared = 0, goal = 30;
```

`level` は山の色の数を決めるのに今すぐ使います。`score`（得点）・`cleared`（消したタイルの合計）・`goal`（次のレベルに必要な枚数）はステップ7で使います。

## てっぺんを調べる関数と、山を作る関数

ステップ2で書いた `neighbors()` の **下**、`// ---------- layout ----------` の **上** に追加します。

```js:game.js
  const top = (st) => st[st.length - 1];
  function topRun(st) {
    if (!st.length) return 0;
    const t = top(st); let n = 0;
    for (let i = st.length - 1; i >= 0 && st[i] === t; i--) n++;
    return n;
  }

  function numColors() { return Math.min(3 + level, COLORS.length); }
  function randStack() {
    const nc = numColors();
    const size = 2 + Math.floor(Math.random() * (level < 3 ? 4 : 5)); // 2..5 (later 2..6)
    const runs = Math.random() < 0.35 ? 1 : (Math.random() < 0.75 ? 2 : 3);
    const st = [];
    let prev = -1;
    let remain = size;
    for (let k = 0; k < runs && remain > 0; k++) {
      let col;
      do { col = Math.floor(Math.random() * nc); } while (col === prev);
      prev = col;
      const len = k === runs - 1 ? remain : Math.max(1, Math.floor(Math.random() * (remain - (runs - 1 - k))) + 1);
      for (let i = 0; i < len; i++) st.push(col);
      remain -= len;
    }
    return st;
  }

```

- `top(st)` は山のてっぺんの色番号です。空の山なら `undefined` になります
- `topRun(st)` は「てっぺんから同じ色が何枚続いているか」を数えます。`[0, 3, 3, 3]` なら 3 です。このゲームでは **動くのも、消えるのも、てっぺんの同じ色のかたまり** なので、この関数がとても大事です
- `numColors()` は使う色の数です。レベル1では4色、レベルが上がるごとに1色ずつ増え、7色で頭打ちになります
- `randStack()` は、ランダムな山を1つ作ります
  - `size` は山の枚数（レベル1〜2は 2〜5枚、それ以降は 2〜6枚）
  - `runs` は「色のかたまり」がいくつあるか。35% で1色だけの山、残りのうち 75% で2色、それ以外は3色の山になります
  - となりのかたまりが同じ色にならないよう、`do { ... } while (col === prev)` で前と違う色が出るまで引き直します
  - `len` はそのかたまりの枚数です。最後のかたまりは残り全部、それ以外は「あとのかたまりに最低1枚ずつ残せる」範囲でランダムに決めます

## タイルの厚みと影の色

`layout()` の閉じかっこ `}` の **下**（`// ---------- drawing ----------` の **上**）に追加します。

```js:game.js
  function thick(s) { return s * 0.14; }
```

タイル1枚の「厚み」を、六角形の大きさ `s` の 14% にします。山はタイルを1枚ごとに `thick` ぶん上にずらして描くことで、積み重なって見えるようにします。

## タイルと山を描く関数

`hexPath()` の **下**（`function draw(now) {` の **上**）に追加します。

```js:game.js
  function shade(hex, f) {
    const n = parseInt(hex.slice(1), 16);
    let r = (n >> 16) & 255, g = (n >> 8) & 255, b = n & 255;
    r = Math.round(r * f); g = Math.round(g * f); b = Math.round(b * f);
    return `rgb(${Math.min(255, r)},${Math.min(255, g)},${Math.min(255, b)})`;
  }
  function drawTile(x, y, s, col, alpha) {
    const th = thick(s);
    ctx.globalAlpha = alpha == null ? 1 : alpha;
    hexPath(x, y + th, s * 0.9);
    ctx.fillStyle = shade(COLORS[col], 0.6); ctx.fill();
    hexPath(x, y, s * 0.9);
    ctx.fillStyle = COLORS[col]; ctx.fill();
    ctx.strokeStyle = 'rgba(255,255,255,.35)'; ctx.lineWidth = 1; ctx.stroke();
    ctx.globalAlpha = 1;
  }
  function drawStack(st, x, y, s, label) {
    const th = thick(s);
    for (let i = 0; i < st.length; i++) drawTile(x, y - i * th, s, st[i]);
    if (label && st.length) {
      const ty = y - (st.length - 1) * th;
      ctx.fillStyle = 'rgba(0,0,0,.55)';
      ctx.font = `700 ${Math.round(s * 0.5)}px system-ui, sans-serif`;
      ctx.textAlign = 'center'; ctx.textBaseline = 'middle';
      ctx.fillText(String(topRun(st)), x, ty + 1);
    }
  }
```

- `shade(hex, f)` は `'#ff5d73'` のような色を、明るさ `f` 倍にした色を返します。`'ff5d73'` を16進数として数にし、`>>`（ビットをずらす）と `& 255`（下の8ビットだけ取り出す）で赤・緑・青の3つに分けています
- `drawTile()` はタイル1枚を描きます。まず厚みのぶん下にずらした **暗い色（60%）** の六角形を塗り、その上に **元の色** の六角形を重ねると、側面が見えて厚みのあるタイルに見えます。`alpha` は透明度で、ステップ7で消えるタイルをフェードアウトさせるのに使います（省略すると 1）
- `drawStack()` は山の下のタイルから順に、`thick` ずつ上にずらして描きます。あとから描いたものが上に重なるので、配列の順番どおりに描けば正しく積み上がります。`label` が true のときは、てっぺんに `topRun()` の数（てっぺんの同じ色が何枚か）を書きます

## 盤面の山を描く

`draw()` の `// board base` の `for` の閉じかっこ `}` の **すぐ下** に追加します（`// tray` の上の空行より前です）。

```js:game.js
    // stacks, back-to-front
    const order = cells.slice().sort((a, b) => a.y - b.y);
    for (const c of order) if (c.stack.length) drawStack(c.stack, c.x, c.y, S, true);
```

山は上に高くのびるので、手前（画面の下のほう）の山が奥の山に重なって見えるべきです。そこで、マスを `y`（画面の縦位置）の小さい順、つまり **奥から手前の順** に並べかえてから描きます。この「奥から順に描く」方法を **画家のアルゴリズム** と呼びます。`cells.slice()` でコピーしてから並べかえるのは、元の `cells` の順番を変えないためです。

## スタート時に山を3つ置く

`newGame()` を次のように **書きかえます**。

```js:game.js
  function newGame() {
    score = 0; level = 1; cleared = 0; goal = 30;
    for (const c of cells) { c.stack = []; c.pending = 0; }
    // a few starter stacks
    const empty = cells.slice().sort(() => Math.random() - .5);
    for (let k = 0; k < 3; k++) {
      const st = randStack();
      empty[k].stack = st.slice(0, Math.max(1, st.length - 1));
    }
    playing = true;
    overlay.classList.add('hidden');
  }
```

まず全部のマスを空にします。次に `sort(() => Math.random() - .5)` でマスの並びを適当にまぜ、先頭の3マスにランダムな山を置きます（このまぜ方はかたよりがありますが、ゲームのお手軽なシャッフルとしては十分です）。最初の山は `slice(0, 長さ - 1)` で1枚だけ減らして、少し低めにしています。

> [!CHECK] 動作チェック
> - スタートすると、盤面のどこか3か所に、色つきのタイルが重なった山が出る
> - 山のてっぺんに、てっぺんと同じ色が何枚続いているかの数字が書かれている
> - 手前の山が奥の山に重なって、立体的に見える
> - ページを再読み込みしてスタートするたびに、山の場所と色が変わる
