## このステップのゴール

六角形のマスを19個並べて、大きな六角形の盤面を描きます。六角形のマス目を扱うときに便利な **アキシャル座標**（q, r の2つの数で場所を表す方法）と、「となりのマス」の求め方を学びます。

## 六角形のマス目を (q, r) で表す

四角いマス目なら (x, y) で表せますが、六角形のマス目は列がジグザグにずれるので、そのままだと計算がややこしくなります。そこで、このゲームでは **アキシャル座標** を使います。

- `q` は「右へ何列目か」（左がマイナス、右がプラス）
- `r` は「同じ列の中で下へ何段目か」。ただし q が1増えるごとに、列が半マス下にずれる

こうすると、どのマスから見ても **となりの6マスは、(q, r) に決まった6通りの差を足すだけ** で求められます。

- 右上 `(+1, -1)`、右下 `(+1, 0)`、上 `(0, -1)`、下 `(0, +1)`、左上 `(-1, 0)`、左下 `(-1, +1)`

もう1つ便利なのが、「中心からの距離」が `|q|`・`|r|`・`|q + r|` のうちいちばん大きいもの、という性質です。中心から2マス以内のマスだけを集めれば、ちょうど六角形の盤面（1 + 6 + 12 = 19マス）になります。

## 盤面を作る

`let playing = false;` の行の **下** に、空行をはさんで `// ---------- board ----------` の見出しごと追加します（`// ---------- layout ----------` の **上** です）。

```js:game.js
  // ---------- board ----------
  function buildBoard() {
    cells = [];
    for (let q = -RADIUS; q <= RADIUS; q++) {
      for (let r = -RADIUS; r <= RADIUS; r++) {
        if (Math.abs(q + r) > RADIUS) continue;
        cells.push({ q, r, x: 0, y: 0, stack: [], pending: 0 });
      }
    }
    layout();
  }
  function cellAt(q, r) { return cells.find(c => c.q === q && c.r === r); }
  const DIRS = [[1, 0], [1, -1], [0, -1], [-1, 0], [-1, 1], [0, 1]];
  function neighbors(c) {
    const out = [];
    for (const [dq, dr] of DIRS) { const n = cellAt(c.q + dq, c.r + dr); if (n) out.push(n); }
    return out;
  }
```

- `buildBoard()` は q と r をそれぞれ -2〜2 で回し、`|q + r|` が2より大きいもの（盤面の外の角）を `continue` で飛ばします。q と r は -2〜2 の範囲なので、残りの1つ `|q + r|` だけ調べれば十分です
- マス1つは `{ q, r, x, y, stack, pending }` というオブジェクトです。`x`・`y` は画面上の中心の位置（`layout()` で決める）、`stack` はそのマスに積まれたタイルの山（ステップ3）、`pending` は「今こちらへ飛んできている途中のタイルの数」（ステップ6）です
- `{ q, r }` は `{ q: q, r: r }` の省略形です
- `cellAt(q, r)` は座標からマスを探します。盤面の外なら `undefined` が返ります
- `neighbors(c)` は `DIRS` の6方向を足して、盤面の中にあるとなりのマスだけを配列で返します。`for (const [dq, dr] of DIRS)` は、`[1, 0]` のような2つ組をそれぞれ `dq`・`dr` に取り出す書き方（分割代入）です。neighbors はステップ6の「集める」処理で使います

## (q, r) から画面の位置へ

ステップ1で書いた `layout()` の最後の部分を見てみましょう。

```js:game.js
    for (const c of cells) {
      c.x = boardCX + S * 1.5 * c.q;
      c.y = boardCY + S * SQ3 * (c.r + c.q / 2);
    }
```

このゲームの六角形は「角が左右を向いた」向き（平らな辺が上下）です。この向きでは、

- 列（q）が1つ右にずれると、中心は横に **1.5 × S** 動く
- 同じ列で r が1つ下がると、中心は縦に **√3 × S** 動く
- さらに列が1つ右にずれるごとに、縦に半マス（√3 × S ÷ 2）下がる。これが `c.q / 2` の部分です

ステップ1で盤面の高さを `5 * SQ3 * S`（5マス分）にしていたのは、中心の列に縦に5マス並ぶからです。

## 六角形を描く

`// ---------- drawing ----------` の **すぐ下**（`function draw(now) {` の **上**）に追加します。

```js:game.js
  function hexPath(x, y, s) {
    ctx.beginPath();
    for (let i = 0; i < 6; i++) {
      const a = Math.PI / 3 * i;
      const px = x + s * Math.cos(a), py = y + s * Math.sin(a) * 0.92;
      if (i === 0) ctx.moveTo(px, py); else ctx.lineTo(px, py);
    }
    ctx.closePath();
  }

```

円の上を 60°（`Math.PI / 3` ラジアン）ずつ回りながら6つの角の位置を `cos`・`sin` で求め、線でつないで六角形の形（パス）を作ります。角度 0 から始めるので、最初の角は真右、つまり「角が左右を向いた」六角形になります。

縦方向に `0.92` を掛けているのは、ほんの少しだけ上下につぶして、斜め上から見下ろしたような立体感を出すためです。

## 盤面を描く

`draw()` の `ctx.clearRect(0, 0, W, H);` の **下**、`// tray` の **上** に追加します。

```js:game.js
    // board base
    for (const c of cells) {
      hexPath(c.x, c.y + 4, S * 0.97);
      ctx.fillStyle = 'rgba(0,0,0,.28)'; ctx.fill();
      hexPath(c.x, c.y, S * 0.97);
      let fill = 'rgba(255,255,255,.08)';
      ctx.fillStyle = fill; ctx.fill();
      ctx.strokeStyle = 'rgba(255,255,255,.12)'; ctx.lineWidth = 1.5; ctx.stroke();
    }

```

1マスごとに、まず4px 下にずらした黒っぽい六角形（影）を塗り、その上に半透明の白い六角形と線を重ねます。マスの大きさを `S * 0.97` と少しだけ小さくして、マスどうしの間にすき間を作っています。`fill` を `let` にしてあるのは、ステップ4・5で「置けるマス」の色を変えるためです。

## 最初に盤面を作る

ファイルのいちばん下の `layout();` を `buildBoard();` に **書きかえます**（buildBoard の中で layout も呼ばれます）。

```js:game.js
  buildBoard();
  requestAnimationFrame(loop);
})();
```
