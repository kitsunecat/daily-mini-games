## このステップのゴール

1つの山のてっぺんに同じ色が **10枚以上** そろったら、そのタイルがふわっと消えて得点が入るようにします。消した枚数がたまるとレベルが上がり、色の数が増えていきます。得点やレベルアップは、その場に浮かぶ文字（トースト）で知らせます。

## 消える演出と文字の入れ物

`let flights = [];` の **下** に追加します。

```js:game.js
  let pops = [];
  let toasts = [];
```

- `pops` … 消えていくタイル1枚ずつの演出
- `toasts` … 「+10」「LEVEL 2!」のような、浮かんで消える文字

## 消える演出を描く

`draw()` の `// flights` の `for` の閉じかっこ `}` の **すぐ下** に追加します（その下の空行と `// tray` より前です）。

```js:game.js
    // pops
    for (let i = pops.length - 1; i >= 0; i--) {
      const p = pops[i];
      const t = (now - p.t0) / 450;
      if (t >= 1) { pops.splice(i, 1); continue; }
      if (t < 0) continue;
      drawTile(p.x, p.y - t * S * 1.4, S * (1 + t * 0.3), p.col, 1 - t);
    }
```

0.45 秒かけて、タイルを **上へ浮かせながら、少し大きくしながら、だんだん透明に** します。ステップ3で `drawTile()` に用意しておいた `alpha`（透明度）をここで使います。`t < 0` のあいだ（まだ出番が来ていない）は描きません。これは次の `tryClear()` で、1枚ずつ出番をずらすためです。

## 浮かぶ文字を描く

`draw()` の最後、ドラッグ中の山を描く `if` の閉じかっこ `}` の **下**（`draw()` の閉じかっこ `}` の上）に、空行をはさんで追加します。

```js:game.js
    // toasts
    for (let i = toasts.length - 1; i >= 0; i--) {
      const t = toasts[i];
      const k = (now - t.t0) / t.dur;
      if (k >= 1) { toasts.splice(i, 1); continue; }
      ctx.globalAlpha = k < .8 ? 1 : (1 - k) / .2;
      ctx.font = `800 ${t.size}px system-ui, sans-serif`;
      ctx.textAlign = 'center'; ctx.textBaseline = 'middle';
      ctx.lineWidth = 5; ctx.strokeStyle = 'rgba(30,20,60,.9)';
      ctx.strokeText(t.text, t.x, t.y - k * 30);
      ctx.fillStyle = t.color; ctx.fillText(t.text, t.x, t.y - k * 30);
      ctx.globalAlpha = 1;
    }
```

文字は最後に描くので、いちばん手前に出ます。表示時間 `dur` のうち、最初の 80% ははっきり、残り 20% でスッと透明になりながら、30px 上へ浮かんでいきます。`strokeText` で太いふちどりを先に描いてから `fillText` で色を塗ると、どんな背景の上でも読みやすい文字になります。

## そろったら消す tryClear と、レベルアップ

`transfer()` の **下**、`async function resolve(start) {` の **上** に追加します。

```js:game.js
  function tryClear(c) {
    const n = topRun(c.stack);
    if (n < CLEAR_N) return false;
    const col = top(c.stack);
    const th = thick(S);
    const now = performance.now();
    for (let k = 0; k < n; k++) {
      c.stack.pop();
      pops.push({ x: c.x, y: c.y - c.stack.length * th, col, t0: now + k * 25 });
    }
    const gained = n * level;
    score += gained;
    cleared += n;
    toasts.push({ text: '+' + gained, x: c.x, y: c.y - S, color: COLORS[col], size: Math.round(S * 0.7), t0: now, dur: 900 });
    while (cleared >= goal) levelUp();
    updateHud();
    return true;
  }

  function levelUp() {
    level++;
    goal += 20 + level * 10;
    toasts.push({ text: 'LEVEL ' + level + '!', x: W / 2, y: boardCY, color: '#ffd166', size: Math.round(S * 1.0), t0: performance.now(), dur: 1400 });
  }

```

- `tryClear(c)` は、マス `c` のてっぺんの同じ色が `CLEAR_N`（10）枚以上なら、その **かたまり全部** を消して `true` を返します。10枚より多くそろっていたら、多いぶんもまとめて消えます
- 消すタイルは1枚ずつ `pops` に入れます。出番を `k * 25` ミリ秒ずつずらすので、上から順にパラパラと消えていきます
- 得点は「消した枚数 × レベル」。レベルが上がるほど1枚の価値が上がります
- `cleared`（消した合計枚数）が `goal` に届いたら `levelUp()` します。一度にたくさん消して2レベルぶん届くこともあるので、`if` ではなく `while` にしています
- 次の目標は「20 + 新しいレベル × 10」枚ずつ増えます（30 → 80 → 140 → …）。レベルが上がると `numColors()` が大きくなり、新しい山に使われる色が増えて、むずかしくなります

## resolve() で消す

`resolve()` を次のように **書きかえます**。変わったのは2か所です。

```js:game.js
  async function resolve(start) {
    const queue = [start];
    let guard = 0;
    while (queue.length && guard++ < 400) {
      const c = queue.shift();
      if (!c.stack.length) continue;
      const col = top(c.stack);
      const ns = neighbors(c).filter(n => n.stack.length && top(n.stack) === col);
      if (!ns.length) {
        if (tryClear(c)) {
          await sleep(320);
          queue.push(c, ...neighbors(c));
        }
        continue;
      }
      let target = c, sources = ns;
      if (ns.length === 1 && pure(c.stack) && !pure(ns[0].stack)) { target = ns[0]; sources = [c]; }
      for (const s of sources) {
        if (!s.stack.length || top(s.stack) !== col) continue;
        await transfer(s, target);
        queue.push(s);
      }
      queue.push(target);
    }
    for (const c of cells) if (tryClear(c)) await sleep(320);
  }
```

- 同じ色のとなりがもう無い（これ以上集まらない）マスで、10枚そろっているか調べます。消えたら、消える演出のあいだ 0.32 秒待ってから、**そのマスととなりのマス全部** をキューに入れて調べ直します。消えたことで下から別の色が出てきて、となりと新しくつながるかもしれないからです（`...` は配列を1つずつばらして渡す **スプレッド構文** です）
- 集めている途中で消すと、「もっと集まるはずだったタイル」が取り残されてしまいます。だから **集めきってから** 消すようにしています
- 最後に念のため、全部のマスをもう一度調べて、そろっている山があれば消します

> [!CHECK] 動作チェック
> - 同じ色を集めて、てっぺんの数字が10以上になると、その色のタイルが上から順にふわっと消える
> - 消えた場所に「+10」のような得点が浮かび、SCORE が増える
> - 「次のレベルまで」の枚数が、消した枚数だけ減る
> - 30枚消すと「LEVEL 2!」と表示され、LEVEL が 2 になり、得点が1枚2点になる
> - まだ、盤面がうまってもゲームオーバーになりません（ステップ8で作ります）
