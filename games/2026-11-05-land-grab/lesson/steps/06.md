## このステップのゴール

フィールドに3人の敵（あか・みどり・オレンジ）を出して、**自分で考えて陣地を広げる** ように動かします。敵も自分と同じ `step()` で動くので、線を引いて陣地に戻れば、ちゃんと陣地が増えます。

敵の頭の中（AI）は、むずかしい計算ではなく「**行き先（target）を決めて、そこに近づく向きを選ぶ**」というシンプルなルールでできています。

## 敵をフィールドに置く

`reset()` の `ents.push(p); claimSquare(p, p.x, p.y);` の **次の行** に追加します。

```js:game.js
    const starts = [[7, 7, 1], [N - 8, 8, 2], [8, N - 16, 0]];
    for (let i = 0; i < 3; i++) {
      const [x, y, d] = starts[i];
      const b = makeEnt(i + 2, x, y, d, true);
      ents.push(b); claimSquare(b, x, y);
    }
```

`starts` は敵3人の「x, y, 最初の向き」です。id は 2・3・4 なので、`ents[id - 1]` でその id のキャラを取り出せる、という関係になっています（ステップ7で使います）。

`makeEnt()` の最後の引数 `bot` を `true` にすると、`interval` が 0.135 秒になり、自分（0.115 秒）より少しだけゆっくり動きます。これで、がんばれば敵に追いつけるくらいの難しさになります。

## nearestOwn() と think() … 敵の頭の中

`step()` の **下**、`// ---------- loop ----------` の **上** に追加します。

```js:game.js
  // ---------- bot brain ----------
  function nearestOwn(e) {
    let bd = 1e9, bx = e.x, by = e.y;
    for (let i = 0; i < owner.length; i++) {
      if (owner[i] !== e.id) continue;
      const x = i % N, y = (i / N) | 0, d = Math.abs(x - e.x) + Math.abs(y - e.y);
      if (d < bd) { bd = d; bx = x; by = y; }
    }
    return [bx, by];
  }

  function think(e) {
    const here = owner[idx(e.x, e.y)] === e.id;
    if (e.path.length >= e.maxTrail) e.target = nearestOwn(e);
    else if (here && !e.path.length && (!e.target || (e.target[0] === e.x && e.target[1] === e.y) || owner[idx(e.target[0], e.target[1])] === e.id)) {
      const a = Math.random() * Math.PI * 2, r = 4 + Math.random() * 6;
      e.target = [Math.max(0, Math.min(N - 1, Math.round(e.x + Math.cos(a) * r))),
                  Math.max(0, Math.min(N - 1, Math.round(e.y + Math.sin(a) * r)))];
      e.maxTrail = 6 + Math.floor(Math.random() * 12);
    } else if (!here && e.target && e.target[0] === e.x && e.target[1] === e.y) {
      e.target = nearestOwn(e);
    }
    if (!e.target) e.target = nearestOwn(e);

    let bestD = -1, bestS = 1e9;
    for (let d = 0; d < 4; d++) {
      if (d === (e.dir + 2) % 4 && e.path.length) continue;
      const nx = e.x + DIRS[d][0], ny = e.y + DIRS[d][1];
      if (!inb(nx, ny) || trail[idx(nx, ny)] === e.id) continue;
      let s = Math.abs(nx - e.target[0]) + Math.abs(ny - e.target[1]) + Math.random() * 1.6;
      if (d === e.dir) s -= 0.4;
      if (s < bestS) { bestS = s; bestD = d; }
    }
    if (bestD >= 0) e.next = bestD;
  }
```

### マンハッタン距離

`Math.abs(x1 - x2) + Math.abs(y1 - y2)` は、マス目を縦横にしか動けないときの距離で、**マンハッタン距離** と呼びます（碁盤の目の街を歩く距離、という意味です）。このゲームのキャラは斜めに動けないので、この距離がぴったりです。

`nearestOwn(e)` は、全マスの中から自分の陣地で、いちばん近いマスを探して返します。「家に帰る」ときの行き先です。

### think() の前半 … 行き先を決める

`think()` は、敵が1マス進む **直前に毎回** 呼ばれ、「次にどっちへ曲がるか（`e.next`）」を決めます。前半は行き先 `e.target` の決め方です。

1. **線が長くなりすぎた**（`maxTrail` マス以上）… 危ないので一番近い自分の陣地へ帰る
2. **陣地の中にいて、行き先がない・着いた・行き先が陣地の中になった** … 新しい行き先を決める。いまの場所から、ランダムな向き（角度 `a`）に 4〜10 マス（`r`）離れた場所を選びます。`Math.cos(a)` と `Math.sin(a)` で、角度を x と y のずれに直しています。フィールドの外にはみ出さないよう `Math.max(0, Math.min(N - 1, …))` で範囲内におさえます（この形を **クランプ** と呼びます）。今回はどこまで線をのばすか（`maxTrail`）も 6〜17 マスでランダムに決めます
3. **陣地の外で、行き先に着いた** … 陣地へ帰る

1 → 2 → 3 と出かけて帰ってくるので、敵はくり返し「出かけて、四角く囲んで、陣地を広げる」動きをします。

### think() の後半 … 向きを選ぶ

4つの向きそれぞれについて「その向きに1マス進んだら、行き先までの距離はいくつか」をスコア `s` にして、**一番小さい向き** を選びます。

- 線があるときの真後ろ、壁の外、**自分の線があるマス** は候補から外します。自分の線にぶつかって自滅しないためです
- スコアに `Math.random() * 1.6` を足して、少しだけゆらぎを入れます。毎回きっちり同じ道を通ると機械っぽいので、ジグザグに進んだり回り道をしたりして、自然な動きになります
- いまと同じ向きなら `0.4` 引いて、まっすぐ進みやすくします。くねくね曲がりすぎないためです

## やられた敵は、少しして復活

`kill()` の `end('dead');` の行を、次のように **書きかえ** ます。

```js:game.js
  function kill(e, by) {
    if (!e.alive) return;
    e.alive = false;
    for (const i of e.path) if (trail[i] === e.id) trail[i] = 0;
    e.path = [];
    if (e.bot) {
      for (let i = 0; i < owner.length; i++) if (owner[i] === e.id) owner[i] = 0;
      e.respawn = 2.5;
    } else {
      end('dead');
    }
  }
```

敵がやられたら、陣地を全部なくして、2.5 秒後に復活する予約（`respawn`）をします。自分がやられたときだけ、ゲームオーバーです。

`makeEnt()` の **下** に、復活する場所を探す `spawnSpot()` を追加します。

```js:game.js
  function spawnSpot() {
    for (let tries = 0; tries < 200; tries++) {
      const x = 3 + Math.floor(Math.random() * (N - 6)), y = 3 + Math.floor(Math.random() * (N - 6));
      let ok = true;
      for (let yy = y - 2; yy <= y + 2 && ok; yy++)
        for (let xx = x - 2; xx <= x + 2; xx++)
          if (owner[idx(xx, yy)] || trail[idx(xx, yy)]) { ok = false; break; }
      if (ok && !ents.some(e => e.alive && Math.abs(e.x - x) + Math.abs(e.y - y) < 6)) return [x, y];
    }
    return [3 + Math.floor(Math.random() * (N - 6)), 3 + Math.floor(Math.random() * (N - 6))];
  }
```

ランダムな場所を選んで、「まわり 5 × 5 マスにだれの陣地も線もなく、近く（6 マス以内）にだれもいない」ならそこに決めます。ダメならやり直し、を最大 200 回。それでも見つからなければ（フィールドがほとんど埋まっているとき）、しかたなくランダムな場所にします。このように「条件に合うまでランダムに選び直す」方法は、手軽で便利です。

## update() で敵を動かす

`update()` の `if (!e.alive) continue;` の1行を、次のように **書きかえ** ます。

```js:game.js
      if (!e.alive) {
        if (e.bot) {
          e.respawn -= dt;
          if (e.respawn <= 0) {
            const [x, y] = spawnSpot();
            Object.assign(e, { x, y, px: x, py: y, alive: true, path: [], target: null, acc: 0 });
            claimSquare(e, x, y);
          }
        }
        continue;
      }
```

さらに `while` の中、`step(e);` の **上** に1行足します。

```js:game.js
      while (e.alive && e.acc >= e.interval && state === 'play') {
        e.acc -= e.interval;
        if (e.bot) think(e);
        step(e);
      }
```

- やられている敵は、`respawn` を `dt` ずつ減らし、0 になったら復活させます。`Object.assign(e, {...})` は、オブジェクト `e` のプロパティをまとめて書きかえる命令です。
- 敵は1マス進む前に `think()` で向きを決めます。あとは自分とまったく同じ `step()` を通るので、線を引くのも囲むのも、同じルールで動きます。

> [!NOTE]
> このステップではまだ、だれかの線をほかのキャラが横切っても何も起きません。線が上書きされて見た目が少しおかしくなることがありますが、ステップ7で「線を切られたらアウト」にすると直ります。

> [!CHECK] 動作チェック
> - スタートすると、フィールドの3か所に赤・緑・オレンジの陣地と敵がいて、それぞれ動き出す
> - 敵が陣地から出て線を引き、ぐるっと回って戻ると、敵の陣地が広がる
> - 敵は自分の線にぶつからないように、陣地へ帰っていく
> - 自分は今までどおり動かせて、自分の線にぶつかるとやられる
