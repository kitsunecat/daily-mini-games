## このステップのゴール

ゲームに「終わり」を作ります。

- 引いている途中の自分の線にぶつかったら **アウト**
- 90 秒の **制限時間** があり、0 になったらタイムアップ
- 終わったら結果（陣地の %）を出し、「もう一度」で何回でも遊べる

## 定数と変数を足す

ファイルの先頭のほうを、次のように **書きかえ** ます（`ROUND` の行を追加、`elTime` / `ovTitle` / `ovText` を追加しています）。

```js:game.js
  const N = 40;                 // grid size (N x N)
  const ROUND = 90;             // seconds
  const cv = document.getElementById('cv');
  const ctx = cv.getContext('2d');
  const $ = (id) => document.getElementById(id);
  const elTime = $('time'), elScore = $('score');
  const overlay = $('overlay'), ovTitle = $('ov-title'), ovText = $('ov-text'), btnStart = $('start');
```

`let owner, ...` の行も **書きかえ** て、残り時間 `timeLeft` を足します。

```js:game.js
  let owner, trail, ents, state = 'title', timeLeft = ROUND, lastT = 0;
```

`reset()` の `updateHud();` の **上** に `timeLeft = ROUND;` を足し、`updateHud()` で残り時間も表示します。

```js:game.js
  function reset() {
    owner = new Uint8Array(N * N);
    trail = new Uint8Array(N * N);
    ents = [];
    const p = makeEnt(1, N >> 1, N - 8, 0, false);
    ents.push(p); claimSquare(p, p.x, p.y);
    timeLeft = ROUND;
    updateHud();
  }
```

```js:game.js
  function updateHud() {
    elTime.textContent = Math.ceil(timeLeft);
    elScore.textContent = percent(1).toFixed(1) + '%';
  }
```

`Math.ceil` は小数点以下の切り上げです。残り 0.3 秒のときも「0」ではなく「1」と表示されるので、「0 になった瞬間に終わる」感じになります。

## end() … ゲームの終わり

`start()` の **下**、`const percent = ...` の **上** に追加します。

```js:game.js
  function end(reason) {
    state = 'over';
    const pct = percent(1);
    ovTitle.textContent = reason === 'time' ? 'タイムアップ！' : 'やられた！';
    ovText.innerHTML = `あなたの陣地は <b style="font-size:22px">${pct.toFixed(1)}%</b>`;
    btnStart.textContent = 'もう一度';
    overlay.classList.remove('hide');
  }
```

- `state` を `'over'` にすると、`frame()` が `update()` を呼ばなくなるので、キャラが止まります。
- 終わった理由 `reason` が `'time'` ならタイムアップ、`'dead'` ならやられた、と見出しを変えます。
- タイトル画面に使っていたオーバーレイを、文章とボタンの文字だけ書きかえて **結果画面として使い回し** ます。`innerHTML` を使うと、文字列の中に `<b>` タグを入れて太字にできます。
- ボタンやオーバーレイ、Enter キーは `start()` につながったままなので、押せばそのまま次のゲームが始まります。`start()` の中で `reset()` しているので、フィールドも時間も最初の状態に戻ります。

## kill() … やられたときの処理

`// ---------- core rules ----------` の **下**、`capture()` の **上** に追加します。

```js:game.js
  function kill(e, by) {
    if (!e.alive) return;
    e.alive = false;
    for (const i of e.path) if (trail[i] === e.id) trail[i] = 0;
    e.path = [];
    end('dead');
  }
```

`e` がやられたキャラ、`by` がやったキャラの id です（ステップ7で「自分が倒したときだけメッセージを出す」のに使います）。やられたら、引いていた線を消してから `end('dead')` を呼びます。最初の `if (!e.alive) return;` は、同じキャラが2回やられる処理を防ぐ安全装置です。

## step() で「自分の線にぶつかったら」

`step()` の `const t = trail[i];` の **次の行** に1行足します。

```js:game.js
    const i = idx(nx, ny);
    const t = trail[i];
    if (t === e.id) { kill(e, e.id); return; }
    e.x = nx; e.y = ny;
```

進む先のマスに **自分の** 線があったら、やられて終わりです。

## update() に制限時間を入れる

`update()` を、次の内容に **まるごと書きかえ** ます。

```js:game.js
  function update(dt) {
    timeLeft -= dt;
    if (timeLeft <= 0) { timeLeft = 0; updateHud(); end('time'); return; }
    for (const e of ents) {
      if (!e.alive) continue;
      e.acc += dt;
      while (e.alive && e.acc >= e.interval && state === 'play') {
        e.acc -= e.interval;
        step(e);
      }
      if (state !== 'play') return;
    }
    updateHud();
  }
```

- 毎フレーム `dt` 秒ずつ `timeLeft` を減らし、0 以下になったら `end('time')` で終わります。
- `while` の条件に `e.alive` と `state === 'play'` を足しています。1フレームで2マス分進む途中にやられてゲームが終わったら、そこで止めるためです。
- やられていないキャラだけ動かす `if (!e.alive) continue;` は、ステップ6で敵がやられたときにも役立ちます。

> [!CHECK] 動作チェック
> - TIME が 90 から1秒ずつ減っていく
> - 陣地の外で自分の線に重なるように曲がると「やられた！」と出て、そのときの陣地の % が表示される
> - 90 秒たつと「タイムアップ！」になる（確認するときは `ROUND` を一時的に 10 にすると楽です）
> - 「もう一度」を押すと、フィールドと時間が元に戻って、また遊べる
