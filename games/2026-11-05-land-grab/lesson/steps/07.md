## このステップのゴール

陣取りゲームらしい **かけひき** を作ります。

- だれかの線（引いている途中）を横切ると、その線の持ち主がアウト。自分が敵の線を横切れば敵を倒せるし、敵に自分の線を横切られたらやられる
- 線を引いている最中の敵を、自分の陣地で囲みこんでも倒せる
- 陣地を全部とられた敵もアウト
- 敵は、近くにある自分の線をねらってきたり、自分が近づくとあわてて家に帰ったりする
- 敵を倒したら「あかをたおした！」と表示する

## 線を横切ったら、線の持ち主がアウト

`step()` の、ステップ5で足した `if (t === e.id) ...` の行の **次の行** に1行足します。

```js:game.js
    const t = trail[i];
    if (t === e.id) { kill(e, e.id); return; }
    if (t) { const o = ents[t - 1]; kill(o, e.id); }
    e.x = nx; e.y = ny;
```

進む先のマスにだれかの線があり（`t` が 0 でない）、それが自分の線でなければ、その線の持ち主 `ents[t - 1]` を倒します。id が 1〜4、`ents` の番号が 0〜3 なので、1 を引けばその id のキャラが取れます。

これだけで「自分が敵の線を横切る」も「敵が自分の線を横切る」も両方動きます。自分も敵も同じ `step()` を通るからです。ルールを全キャラ共通にしておくと、こういうところで得をします。

## 囲まれた敵と、陣地のない敵

`capture()` の最後（`gained` を数える `for` ループの **下**）に追加します。

```js:game.js
    // an enemy whose head got enclosed loses
    for (const o of ents) {
      if (o !== e && o.alive && owner[idx(o.x, o.y)] === e.id && o.path.length) kill(o, e.id);
    }
    // a bot left without land is out
    for (const o of ents) if (o.bot && o.alive && countOwned(o.id) === 0) kill(o, e.id);
```

- **囲まれた敵** … 囲んだあとで、ほかのキャラの頭があるマスが `e` の陣地になっていて、しかもそのキャラが線を引いている最中なら、倒します。線を引いている途中のキャラを、陣地ごと飲みこんだイメージです。
- **陣地のない敵** … 囲みで陣地を全部とられてしまった敵は、帰る場所がないのでアウトです。

## 敵を少しずる賢くする

`think()` の最初の2行を、次のように **書きかえ** ます（`const here = ...` の行はそのまま。その下の `if (e.path.length >= e.maxTrail) ...` の1行が、下のコードの `const p` 〜 `else if (... || danger)` に置きかわります）。

```js:game.js
  function think(e) {
    const here = owner[idx(e.x, e.y)] === e.id;
    const p = ents[0];
    // hunt: player's trail close by
    let hunt = null;
    if (p.alive && p.path.length && Math.random() < 0.35) {
      for (const i of p.path) {
        const x = i % N, y = (i / N) | 0;
        if (Math.abs(x - e.x) + Math.abs(y - e.y) <= 4) { hunt = [x, y]; break; }
      }
    }
    // danger: player head near my trail -> go home
    let danger = false;
    if (e.path.length && p.alive) {
      for (const i of e.path) {
        const x = i % N, y = (i / N) | 0;
        if (Math.abs(x - p.x) + Math.abs(y - p.y) <= 3) { danger = true; break; }
      }
    }

```

`else if (here && ...` から下は、ステップ6のままです。

- **hunt（ねらう）** … 自分（プレイヤー）が線を引いていて、その線のマスが4マス以内にあったら、そのマスを行き先にします。ただし毎回ではなく、35% の確率（`Math.random() < 0.35`）だけ。`think()` は1マスごとに呼ばれるので、近くにいるとかなりの確率でねらわれますが、必ずではないところがポイントです。
- **danger（あぶない）** … 敵が線を引いている最中に、自分の頭が敵の線から3マス以内に近づいたら、急いで家に帰ります。
- 優先順位は **ねらう ＞ 帰る ＞ 新しい行き先 ＞ …** です。`if` / `else if` を並べる順番が、そのまま判断の優先順位になります。

> [!TIP]
> 確率や距離（0.35、4、3）を変えるだけで、敵の性格がガラッと変わります。0.35 を 0.8 にすると、かなりしつこく追いかけてくるようになります。

> [!CHECK] 動作チェック
> - 線を引いている敵の線を横切ると、敵が消えて「〇〇をたおした！」と表示され、2.5 秒ほどで別の場所に復活する
> - 自分が線を引いている最中に敵に横切られると「やられた！」になる
> - 自分が線を引いて敵の近くを通ると、敵が線をねらってくることがある
> - 線を引いている敵ごと陣地で囲むと、その敵を倒せる
