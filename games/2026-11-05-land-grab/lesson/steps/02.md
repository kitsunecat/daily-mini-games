## このステップのゴール

フィールドの「どのマスが誰の陣地か」をデータとして持ち、それを Canvas に描きます。最後に、自分のキャラ（青い四角に目がついたもの）を陣地のまん中に置きます。まだ動きません。

## 定数とデータ

`const overlay = ...` の行の **下** に、向きと色の定数を追加します。

```js:game.js
  const DIRS = [[0, -1], [1, 0], [0, 1], [-1, 0]]; // up right down left
  const PALETTE = [
    null,
    { head: '#3a63e6', land: '#9db6ff', trail: 'rgba(58,99,230,.55)', name: 'あなた' },
    { head: '#e2484f', land: '#ffaaa8', trail: 'rgba(226,72,79,.55)', name: 'あか' },
    { head: '#17a57f', land: '#94e2c6', trail: 'rgba(23,165,127,.55)', name: 'みどり' },
    { head: '#e8901a', land: '#ffd08f', trail: 'rgba(232,144,26,.55)', name: 'オレンジ' },
  ];
```

そのすぐ下の `let state = ...` の行を、次のように **書きかえ** ます。

```js:game.js
  let owner, trail, ents, state = 'title', lastT = 0;
```

- `DIRS` は4つの向きを「x をいくつ、y をいくつ動かすか」で表した配列です。**0 = 上、1 = 右、2 = 下、3 = 左** と、時計回りに番号をつけています。この並びにしておくと、`(d + 2) % 4` で **反対向き** が計算できます（上 0 ↔ 下 2、右 1 ↔ 左 3）。ステップ4で使います。
- `PALETTE` はキャラごとの色です。キャラには **1〜4 の番号（id）** をつけ、`PALETTE[id]` で色を引きます。0番が `null` なのは、マスの値 0 を「だれのものでもない」に使いたいからです。
- `owner` … 各マスの持ち主の id（0 ならだれのものでもない）
- `trail` … 各マスに引かれている線の持ち主の id（ステップ4で使います）
- `ents` … キャラ（entity）の配列

## grid helpers … マス目のお助け関数

`window.addEventListener('resize', ...)` の行の **下** に追加します。

```js:game.js
  // ---------- grid helpers ----------
  const idx = (x, y) => y * N + x;
  const inb = (x, y) => x >= 0 && y >= 0 && x < N && y < N;

  function claimSquare(e, cx, cy) {
    for (let y = cy - 1; y <= cy + 1; y++)
      for (let x = cx - 1; x <= cx + 1; x++)
        if (inb(x, y)) { owner[idx(x, y)] = e.id; trail[idx(x, y)] = 0; }
  }

  function makeEnt(id, x, y, dir, bot) {
    return { id, x, y, px: x, py: y, dir, next: dir, alive: true, path: [], bot,
      acc: 0, interval: bot ? 0.135 : 0.115, respawn: 0, target: null, maxTrail: 8 };
  }
```

### 1次元配列でマス目を持つ

40 × 40 のマス目は2次元配列（`owner[y][x]`）でも作れますが、このゲームでは **長さ 1600 の1次元配列** にしています。マス `(x, y)` は `y * N + x` 番目、という約束です。それを計算するのが `idx(x, y)` です。逆に番号 `i` から座標に戻すときは `x = i % N`、`y = (i / N) | 0`（割り算して小数点以下を切り捨て）です。

1次元にしておくと、「全マスを調べる」が `for (let i = 0; i < owner.length; i++)` の1重ループで書け、マスの番号を1つの数としてリストに入れやすくなります（ステップ4の線や囲み判定で活躍します）。

`inb(x, y)` は「その座標がフィールドの中か（in bounds）」を調べます。

### claimSquare() と makeEnt()

- `claimSquare(e, cx, cy)` は、`(cx, cy)` を中心とする 3 × 3 マスをキャラ `e` の陣地にします。スタート地点の小さな陣地づくりに使います。
- `makeEnt()` はキャラのデータを1つ作ります。いま使うのは `id`・`x`・`y`（いるマス）・`dir`（向いている向き）だけです。ほかのプロパティは、あとのステップで順に使います。
  - `px`, `py`, `next`, `acc`, `interval` … 移動（ステップ3）
  - `path` … 引いている線（ステップ4）
  - `alive` … 生きているか（ステップ5）
  - `bot`, `respawn`, `target`, `maxTrail` … 敵の動き（ステップ6）

## reset() とスタート

`// ---------- game flow ----------` の **下**、`function start()` の **上** に `reset()` を追加します。

```js:game.js
  function reset() {
    owner = new Uint8Array(N * N);
    trail = new Uint8Array(N * N);
    ents = [];
    const p = makeEnt(1, N >> 1, N - 8, 0, false);
    ents.push(p); claimSquare(p, p.x, p.y);
  }
```

`start()` の `resize();` の **次の行** に `reset();` を足します。

```js:game.js
  function start() {
    resize();
    reset();
    state = 'play';
    overlay.classList.add('hide');
    lastT = performance.now();
  }
```

さらにファイルの最後のほう、`resize();` の **次の行** にも `reset();` を足します（タイトル画面の後ろにもフィールドが見えるように）。

```js:game.js
  resize();
  reset();
  requestAnimationFrame((t) => { lastT = t; frame(t); });
```

- `Uint8Array` は「0〜255 の整数だけを入れられる配列」です。作った時点で全部 0 になっているので、「全マスだれのものでもない」状態から始められます。普通の配列より軽くて速いのも利点です。
- 自分は id 1、場所は横のまん中（`N >> 1` は `N / 2` の切り捨てと同じ）、下から 8 マス目、向きは 0（上）です。

## draw() を書きかえる

`draw()` を、次の内容に **まるごと書きかえ** ます。その下に `roundRect()` も追加します。

```js:game.js
  function draw() {
    if (!owner) { ctx.fillStyle = '#f4f1ea'; ctx.fillRect(0, 0, S, S); return; }
    ctx.fillStyle = '#f4f1ea';
    ctx.fillRect(0, 0, S, S);
    ctx.strokeStyle = 'rgba(0,0,0,.05)';
    ctx.lineWidth = 1;
    ctx.beginPath();
    for (let k = 1; k < N; k++) {
      ctx.moveTo(k * C, 0); ctx.lineTo(k * C, S);
      ctx.moveTo(0, k * C); ctx.lineTo(S, k * C);
    }
    ctx.stroke();
    // land
    for (let y = 0; y < N; y++) for (let x = 0; x < N; x++) {
      const o = owner[idx(x, y)];
      if (o) { ctx.fillStyle = PALETTE[o].land; ctx.fillRect(x * C, y * C, C + 0.5, C + 0.5); }
    }
    // land edge shading
    for (let y = 0; y < N - 1; y++) for (let x = 0; x < N; x++) {
      const o = owner[idx(x, y)];
      if (o && owner[idx(x, y + 1)] !== o) { ctx.fillStyle = PALETTE[o].head; ctx.globalAlpha = 0.35; ctx.fillRect(x * C, y * C + C * 0.75, C + 0.5, C * 0.25); ctx.globalAlpha = 1; }
    }
    // heads
    for (const e of ents) {
      if (!e.alive) continue;
      const hx = e.x * C, hy = e.y * C;
      const pad = -C * 0.15, sz = C - pad * 2;
      ctx.fillStyle = 'rgba(0,0,0,.25)';
      roundRect(hx + pad, hy + pad + C * 0.2, sz, sz, C * 0.3); ctx.fill();
      ctx.fillStyle = PALETTE[e.id].head;
      roundRect(hx + pad, hy + pad, sz, sz, C * 0.3); ctx.fill();
      if (!e.bot) { ctx.strokeStyle = '#fff'; ctx.lineWidth = Math.max(1.5, C * 0.18); ctx.stroke(); }
      // eyes looking in direction
      const [dx, dy] = DIRS[e.dir];
      ctx.fillStyle = '#fff';
      const cx = hx + C / 2 + dx * C * 0.15, cy = hy + C / 2 + dy * C * 0.15;
      const ox = dy !== 0 ? C * 0.22 : 0, oy = dx !== 0 ? C * 0.22 : 0;
      ctx.beginPath(); ctx.arc(cx - ox, cy - oy, C * 0.14, 0, 7); ctx.arc(cx + ox, cy + oy, C * 0.14, 0, 7); ctx.fill();
    }
  }

  function roundRect(x, y, w, h, r) {
    ctx.beginPath();
    ctx.moveTo(x + r, y);
    ctx.arcTo(x + w, y, x + w, y + h, r);
    ctx.arcTo(x + w, y + h, x, y + h, r);
    ctx.arcTo(x, y + h, x, y, r);
    ctx.arcTo(x, y, x + w, y, r);
    ctx.closePath();
  }
```

描く順番は **背景 → 陣地 → 陣地のふち → キャラ** です。Canvas はあとから描いたものが上に重なるので、奥のものから順に描きます。

- **陣地（land）** … 全マスを見て、持ち主がいれば `PALETTE[o].land` の色でぬります。幅を `C + 0.5` と少し大きめにしているのは、となりのマスとの間に細いすき間（線）が見えないようにするためです。
- **陣地のふち（edge shading）** … 「自分の下のマスが違う持ち主」のマスだけ、下側 1/4 を濃い色でうすくぬります。陣地が少し盛り上がった板のように見えます。`globalAlpha` は不透明度で、ぬり終わったら必ず 1 に戻します。
- **キャラ（heads）** … `pad` をマイナスにして、1マスより少し大きく描いています。まず `C * 0.2` だけ下にずらした黒い半透明の四角（影）を描き、その上に本体を描きます。自分（`bot` でないキャラ）には白いふちどりをつけて、敵と見分けやすくします。
- **目** … 向いている向き `DIRS[e.dir]` の方へ少しずらした位置に、白い丸を2つ描きます。上下を向いているときは目を横に、左右を向いているときは縦に並べます（`ox` / `oy`）。`arc(..., 0, 7)` の 7 は「2π（約 6.28）より大きければ一周」という手抜きです。
- `roundRect()` は角の丸い四角の **形（パス）** を作る関数です。`arcTo` は「角に向かって線を引き、半径 `r` で丸く曲がる」命令で、4つの角を順にたどっています。

> [!NOTE]
> 最初の `if (!owner)` は、`reset()` がまだ呼ばれていないときに `owner[...]` を読んでエラーにならないようにする安全装置です。
