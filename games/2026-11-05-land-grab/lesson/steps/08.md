## このステップのゴール

最後の仕上げです。

- いちばん広く取れた陣地の % を **ハイスコア** としてブラウザに保存し、次に開いたときも表示する
- スタート・陣地を囲んだとき・敵を倒したとき・ゲームが終わったときに **効果音** を鳴らす

これで完成品と同じゲームになります。

## ハイスコアを localStorage に保存する

ファイルの上のほう、`const elTime = ...` の行に `elBest` を足します。

```js:game.js
  const elTime = $('time'), elScore = $('score'), elBest = $('best');
```

`let owner, ...` の行を **書きかえ** て `best = 0` を足し、その下に2行追加します。

```js:game.js
  let owner, trail, ents, state = 'title', timeLeft = ROUND, lastT = 0, best = 0, toastTimer = 0;
  try { best = parseFloat(localStorage.getItem('land-grab-best')) || 0; } catch (e) { best = 0; }
  elBest.textContent = best.toFixed(1) + '%';
```

`end()` を、次の内容に **まるごと書きかえ** ます。

```js:game.js
  function end(reason) {
    state = 'over';
    const pct = percent(1);
    let rec = '';
    if (pct > best) {
      best = pct;
      try { localStorage.setItem('land-grab-best', String(best)); } catch (e) { /* ignore */ }
      rec = '<br><b style="color:#ffe27a">ハイスコア更新！</b>';
    }
    elBest.textContent = best.toFixed(1) + '%';
    ovTitle.textContent = reason === 'time' ? 'タイムアップ！' : 'やられた！';
    ovText.innerHTML = `あなたの陣地は <b style="font-size:22px">${pct.toFixed(1)}%</b>${rec}<br>ベスト ${best.toFixed(1)}%`;
    btnStart.textContent = 'もう一度';
    overlay.classList.remove('hide');
    beep(reason === 'time' ? 660 : 180, 0.4, reason === 'time' ? 'triangle' : 'sawtooth');
  }
```

**localStorage** は、ブラウザにちょっとしたデータを保存しておける場所です。ページを閉じても、次に開いたときに残っています。

- `localStorage.setItem('キー', '値')` で保存、`localStorage.getItem('キー')` で読み出し。保存できるのは **文字列だけ** なので、`String(best)` で文字列にして保存し、読み出すときは `parseFloat` で小数に戻します。
- まだ一度も保存していないときは `getItem` が `null` を返し、`parseFloat(null)` は `NaN`（数ではない）になります。`|| 0` で、そのときは 0 にしています。
- キーの名前 `'land-grab-best'` は、同じサイトのほかのゲームとぶつからないように、ゲームごとに違う名前にします。
- プライベートブラウズなどで localStorage が使えないと、エラーが出ることがあります。`try { … } catch (e) { … }` で囲んでおけば、保存できなくてもゲームは止まりません。

最後の行の `beep(...)` は、次の「効果音」で作る関数です。タイムアップなら明るい音、やられたなら低くて濁った音にしています。

## 効果音 … Web Audio API

`window.addEventListener('resize', ...)` の行の **下**、`// ---------- grid helpers ----------` の **上** に追加します。

```js:game.js
  // ---------- audio ----------
  let ac = null;
  function beep(freq, dur, type = 'sine', vol = 0.08) {
    try {
      if (!ac) ac = new (window.AudioContext || window.webkitAudioContext)();
      const o = ac.createOscillator(), g = ac.createGain();
      o.type = type; o.frequency.value = freq;
      g.gain.setValueAtTime(vol, ac.currentTime);
      g.gain.exponentialRampToValueAtTime(0.0001, ac.currentTime + dur);
      o.connect(g); g.connect(ac.destination);
      o.start(); o.stop(ac.currentTime + dur);
    } catch (e) { /* ignore */ }
  }
```

**Web Audio API** を使うと、音声ファイルを用意しなくても、JavaScript で音を作れます。

- `AudioContext` は音を作るための作業場です。ブラウザは「ユーザーが画面を触る前に音を鳴らす」ことを禁止しているので、最初に `beep()` が呼ばれたとき（＝スタートボタンを押したとき）に作ります。
- `createOscillator()` は、決まった高さ（`frequency`、単位はヘルツ）の音を出し続ける発振器です。`type` で音色を選べます（`sine` やわらかい、`triangle` 少し明るい、`square` ピコピコ、`sawtooth` ジージー）。
- `createGain()` は音量のつまみです。`exponentialRampToValueAtTime` で、`dur` 秒かけて音量をほぼ 0 まで下げます。これで「ピッ」と自然に消える音になります。
- 発振器 → 音量 → スピーカー（`ac.destination`）の順に `connect` でつないで、`start()` で鳴らし、`stop()` で止める時刻を予約します。

## 効果音を鳴らす場所

次の3か所に `beep()` を足します。

`start()` の `overlay.classList.add('hide');` の **次の行**:

```js:game.js
  function start() {
    resize();
    reset();
    state = 'play';
    overlay.classList.add('hide');
    beep(520, 0.12, 'triangle');
    lastT = performance.now();
  }
```

`kill()` の `showToast` の行を、次のように **書きかえ**:

```js:game.js
      if (by === 1) { showToast(`${PALETTE[e.id].name}をたおした！`); beep(880, 0.2, 'square', 0.06); }
```

`capture()` のいちばん最後（「陣地のない敵」の `for` の **下**）:

```js:game.js
    if (e.id === 1) beep(440 + Math.min(gained, 120) * 4, 0.18, 'triangle');
```

囲んだときの音は、新しく取れたマスの数 `gained` が多いほど高くなります（最大 120 マス分）。大きく囲めたときほど気持ちのいい音が鳴るので、「もっと広く囲みたい」と思わせる小さな工夫です。敵の囲みでは鳴らさないよう、`e.id === 1`（自分）のときだけにしています。

> [!CHECK] 動作チェック
> - スタートすると「ピッ」と音が鳴る
> - 陣地を囲むと音が鳴り、大きく囲むほど音が高い
> - 敵を倒すと「ピコッ」と鳴る
> - ゲームが終わると結果画面に「ベスト」が出て、記録を超えたら「ハイスコア更新！」と表示される
> - ページを再読み込みしても、上の BEST にハイスコアが残っている

## 改造アイデア

完成おめでとうございます！ ここからは自由に改造してみましょう。

> [!TIP]
> **フィールドの広さを変える** … `N` を 30 や 60 に変えるだけで、マスの大きさも自動で変わります。広くしたら、敵の数や `ROUND` も調整してみましょう。

> [!TIP]
> **敵を増やす** … `PALETTE` に色を足し、`reset()` の `starts` に場所を足して、`for` の回数を増やします。id と `ents` の番号の関係（`ents[id - 1]`）がくずれないように注意しましょう。

> [!TIP]
> **スピードアップ** … 陣地が 20% を超えたら自分の `interval` を少し短くする、残り 30 秒で敵が速くなる、など。`update()` の中で `ents[0].interval` を書きかえれば変えられます。

> [!TIP]
> **アイテム** … ランダムなマスに星を置き、取ると数秒間だけ線が無敵になる、など。`step()` で進んだ先のマスを調べるところに足すのがおすすめです。

> [!TIP]
> **目標モード** … 時間制限のかわりに「50% 取ったらクリア」にして、クリアまでの秒数を競うモードにしても楽しいです。
