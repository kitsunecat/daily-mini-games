## このステップのゴール

キャラを **一定のリズムで1マスずつ** 進ませ、スワイプや矢印キーで向きを変えられるようにします。マスからマスへ「カクッ」とワープするのではなく、間をなめらかに動いて見えるようにもします。

## マス単位の移動と「タイマーためこみ」

このゲームのキャラは、ピクセル単位ではなく **マス単位** で動きます。自分は 0.115 秒ごと（`interval`）に1マス進みます。でも `frame()` が呼ばれる間隔は画面によって 1/60 秒だったり 1/120 秒だったりします。

そこで、キャラごとに `acc`（accumulator＝ためこみ）という時間の貯金箱を持たせます。毎フレーム `dt` を足していき、`interval` 以上たまったら1マス進めて、その分を引きます。こうすると画面の速さに関係なく、きっちり同じリズムで進みます。

## step() と update()

`start()` の **下** に追加します。

```js:game.js
  // ---------- core rules ----------
  function step(e) {
    e.dir = e.next;
    const [dx, dy] = DIRS[e.dir];
    const nx = e.x + dx, ny = e.y + dy;
    e.px = e.x; e.py = e.y;
    if (!inb(nx, ny)) return; // walls stop you
    e.x = nx; e.y = ny;
  }

  // ---------- loop ----------
  function update(dt) {
    for (const e of ents) {
      e.acc += dt;
      while (e.acc >= e.interval) {
        e.acc -= e.interval;
        step(e);
      }
    }
  }
```

もともとあった `// ---------- loop ----------` の見出しコメント（`draw()` のすぐ上）は消して、`update()` の上の1つだけにしておきましょう。

- `step(e)` は「キャラ `e` を1マス進める」関数で、このゲームのルールの中心です。この先のステップでどんどん中身が増えていきます。
- `next` は「次に曲がりたい向き」です。キーを押した瞬間に `dir` を変えるのではなく、いったん `next` に予約しておき、**マスを進むタイミングで** `dir` に反映します。マス目の上をきっちり曲がれるのはこのためです。
- 進む前の場所を `px`, `py`（previous）に覚えておきます。あとでなめらかに描くのに使います。
- 進む先がフィールドの外（`inb` が false）なら、進まずにその場で止まります。壁にぶつかってもアウトにはなりません。
- `update()` の `while` が「タイマーためこみ」です。`if` ではなく `while` なのは、処理が重くて `dt` が大きくなったときに、2マス分たまっていれば2回進めるためです。

`frame()` の `draw();` の **上** に1行足して、プレイ中だけ `update()` を呼ぶようにします。

```js:game.js
  function frame(t) {
    const dt = Math.min(0.05, (t - lastT) / 1000);
    lastT = t;
    if (state === 'play') update(dt);
    draw();
    requestAnimationFrame(frame);
  }
```

## なめらかに描く（補間）

`draw()` の `// heads` の中の、`const hx = e.x * C, hy = e.y * C;` の1行を、次の2行に **書きかえ** ます。

```js:game.js
      const f = state === 'play' ? Math.min(1, e.acc / e.interval) : 1;
      const hx = (e.px + (e.x - e.px) * f) * C, hy = (e.py + (e.y - e.py) * f) * C;
```

`e.acc / e.interval` は「次の1マスまでの時間のうち、どれだけ進んだか」を 0〜1 で表した値です。これを `f` として、**前のマス（px, py）から今のマス（x, y）までを f の割合だけ進んだ位置** に描きます。このように2つの値の間を割合で埋めることを **線形補間**（lerp）と呼びます。

データ上はマス単位でカクカク動いているのに、見た目はスーッと動いて見えます。ゲームの「ルール」と「見た目」を分けて考えるのがポイントです。

## 入力 … キーボードとスワイプ

`// ---------- input ----------` の **下**、`btnStart.addEventListener(...)` の **上** に追加します。

```js:game.js
  function turn(d) {
    if (state !== 'play') return;
    const p = ents[0];
    p.next = d;
  }
  const KEYS = { ArrowUp: 0, KeyW: 0, ArrowRight: 1, KeyD: 1, ArrowDown: 2, KeyS: 2, ArrowLeft: 3, KeyA: 3 };
  window.addEventListener('keydown', (ev) => {
    if (ev.code in KEYS) { turn(KEYS[ev.code]); ev.preventDefault(); }
    else if ((ev.code === 'Enter' || ev.code === 'Space') && state !== 'play') { start(); ev.preventDefault(); }
  });

  let sx = 0, sy = 0, down = false;
  const SW = 22;
  window.addEventListener('pointerdown', (ev) => {
    if (ev.target.closest && ev.target.closest('a,button')) return;
    down = true; sx = ev.clientX; sy = ev.clientY;
  });
  window.addEventListener('pointermove', (ev) => {
    if (!down) return;
    const dx = ev.clientX - sx, dy = ev.clientY - sy;
    if (Math.abs(dx) < SW && Math.abs(dy) < SW) return;
    turn(Math.abs(dx) > Math.abs(dy) ? (dx > 0 ? 1 : 3) : (dy > 0 ? 2 : 0));
    sx = ev.clientX; sy = ev.clientY; // keep swiping to turn again
  });
  const up = () => { down = false; };
  window.addEventListener('pointerup', up);
  window.addEventListener('pointercancel', up);
```

- `turn(d)` が「向き `d` に曲がりたい」をまとめて受け付ける関数です。キーでもスワイプでも、最後はここを呼びます。自分は `ents[0]`（最初に入れたキャラ）です。
- `KEYS` は「どのキーがどの向きか」の対応表です。`ev.code` はキーボード上の **位置** を表す名前（`KeyW` など）なので、日本語入力中でも同じように動きます。`ev.code in KEYS` で対応表にあるキーかどうかを調べます。`preventDefault()` で、矢印キーやスペースでページがスクロールするのを止めます。
- Enter / Space はタイトル画面やゲームオーバー画面でのスタートに使います。

### Pointer Events でスワイプを読み取る

`pointerdown` / `pointermove` / `pointerup` は **Pointer Events** といって、マウスでも指でもペンでも同じように受け取れるイベントです。

1. 押した瞬間（`pointerdown`）の位置を `sx`, `sy` に覚える
2. 動かしている間（`pointermove`）、覚えた位置からのずれ `dx`, `dy` を計算する
3. ずれが `SW`（22 ピクセル）未満なら、まだ何もしない（指のふるえを無視）
4. 横のずれの方が大きければ左右、縦の方が大きければ上下に曲がる
5. 曲がったら、その場所を新しい基準にする。指をはなさずに「→ ↑ ←」とスワイプし続けるだけで、何回でも曲がれます

`ev.target.closest('a,button')` は、「← 一覧」のリンクやスタートボタンを押したときはスワイプとして扱わない、というチェックです。

> [!CHECK] 動作チェック
> - スタートすると、青いキャラが上へスーッと進み、上の壁で止まる
> - 矢印キー（または WASD）で向きを変えられ、目の向きも変わる
> - スマホ幅の画面で、画面のどこをスワイプしても向きが変わる（開発者ツールのデバイスモードでも確認できます）
> - まだ線は引かれず、陣地も増えません
