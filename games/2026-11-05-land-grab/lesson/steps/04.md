## このステップのゴール

いよいよこのゲームの中心、**線を引いて囲む** しくみです。

- 自分の陣地の外に出ると、通ったマスに線が残る
- 陣地に戻ってくると、線のマスと、線と陣地でぐるっと囲んだ内側が、まるごと自分の陣地になる
- 上の「陣地」に、フィールド全体の何 % を持っているかを表示する

## 陣地の割合を数える

まず、ファイルの上のほう、`const overlay = ...` の行の **上** に1行足します。

```js:game.js
  const elScore = $('score');
```

`claimSquare()` の **下** に `countOwned()` を追加します。

```js:game.js
  function countOwned(id) {
    let c = 0;
    for (let i = 0; i < owner.length; i++) if (owner[i] === id) c++;
    return c;
  }
```

`start()` の **下**（`// ---------- core rules ----------` の上）に追加します。

```js:game.js
  const percent = (id) => countOwned(id) / (N * N) * 100;

  function updateHud() {
    elScore.textContent = percent(1).toFixed(1) + '%';
  }
```

- `countOwned(id)` は、持ち主が `id` のマスを数えます。1次元配列なので1重ループで済みます。
- `percent(id)` で「全 1600 マスのうち何 %」に直し、`toFixed(1)` で小数点以下1けたの文字列にして表示します（例: `0.6%`）。
- `updateHud()` は、画面上の数字（HUD）をまとめて書きかえる関数です。ステップ5で残り時間も足します。

`reset()` の最後（`ents.push(p); ...` の次の行）と、`update()` の最後（`for` ループが終わった後）に、それぞれ `updateHud();` を足します。

```js:game.js
  function reset() {
    owner = new Uint8Array(N * N);
    trail = new Uint8Array(N * N);
    ents = [];
    const p = makeEnt(1, N >> 1, N - 8, 0, false);
    ents.push(p); claimSquare(p, p.x, p.y);
    updateHud();
  }
```

```js:game.js
  function update(dt) {
    for (const e of ents) {
      e.acc += dt;
      while (e.acc >= e.interval) {
        e.acc -= e.interval;
        step(e);
      }
    }
    updateHud();
  }
```

## step() で線を引く

`step()` を、次の内容に **まるごと書きかえ** ます。

```js:game.js
  function step(e) {
    if ((e.next + 2) % 4 !== e.dir || e.path.length === 0) e.dir = e.next;
    const [dx, dy] = DIRS[e.dir];
    const nx = e.x + dx, ny = e.y + dy;
    e.px = e.x; e.py = e.y;
    if (!inb(nx, ny)) return; // walls stop you
    const i = idx(nx, ny);
    const t = trail[i];
    e.x = nx; e.y = ny;
    if (owner[i] === e.id) {
      if (e.path.length) capture(e);
    } else {
      trail[i] = e.id;
      e.path.push(i);
    }
  }
```

進んだ先のマス `i` について、

- **自分の陣地なら** … 線を引いている途中（`e.path.length` が 1 以上）なら、陣地に帰ってきたということなので `capture(e)` で囲みを確定します
- **陣地の外なら** … `trail[i]` に自分の id を書いて線を残し、`e.path` にそのマスの番号を追加します

`e.path` は「いま引いている線のマス番号のリスト」です。`trail` 配列だけでも線は表せますが、リストも持っておくと、線を消したり陣地に変えたりするときに、1600 マス全部を調べずに線のマスだけを処理できます。

`const t = trail[i];` は、進む先にだれの線があるかを読んでいます。ステップ5で「自分の線にぶつかったらアウト」に使います。

### Uターン禁止

1行目は「線を引いている最中に、真後ろ（反対向き）へは曲がらない」というルールです。真後ろに曲がると、すぐ自分の線にぶつかってしまうからです。ステップ2で決めた番号の並びのおかげで、反対向きは `(e.next + 2) % 4` で求められます。陣地の中にいる（線がない）ときは、自由にUターンできます。

## capture() … 囲んだ場所を陣地にする

`// ---------- core rules ----------` の **下**、`step()` の **上** に追加します。

```js:game.js
  function capture(e) {
    for (const i of e.path) { owner[i] = e.id; if (trail[i] === e.id) trail[i] = 0; }
    e.path = [];
    // flood from the border through cells not owned by e; anything unreached is enclosed
    const seen = new Uint8Array(N * N);
    const q = [];
    for (let k = 0; k < N; k++) {
      for (const [x, y] of [[k, 0], [k, N - 1], [0, k], [N - 1, k]]) {
        const i = idx(x, y);
        if (!seen[i] && owner[i] !== e.id) { seen[i] = 1; q.push(i); }
      }
    }
    while (q.length) {
      const i = q.pop(), x = i % N, y = (i / N) | 0;
      for (const [dx, dy] of DIRS) {
        const nx = x + dx, ny = y + dy;
        if (!inb(nx, ny)) continue;
        const j = idx(nx, ny);
        if (!seen[j] && owner[j] !== e.id) { seen[j] = 1; q.push(j); }
      }
    }
    let gained = 0;
    for (let i = 0; i < owner.length; i++) {
      if (!seen[i] && owner[i] !== e.id) { owner[i] = e.id; gained++; }
    }
  }
```

### 「囲まれている」をどう判定する？

線のマスを陣地にするのは簡単です（最初の `for`）。むずかしいのは「線と陣地で囲まれた **内側**」を見つけることです。

ここでは発想を逆にします。**フィールドのふち（外周）から、自分の陣地をよけて水を流す** と考えます。

1. 外周のマスのうち、自分の陣地でないものを全部「水が来た（`seen`）」にして、リスト `q` に入れる
2. `q` から1つ取り出し、その上下左右のマスで、まだ水が来ていない・自分の陣地でないマスに水を広げて、`q` に入れる
3. `q` が空になるまでくり返す
4. 最後まで **水が届かなかったマス** は、自分の陣地にぐるっと囲まれている。そこを全部自分の陣地にする

このように、となりへとなりへと広げていく探索を **フラッドフィル**（塗りつぶし）と呼びます。ペイントソフトの「バケツツール」と同じしくみです。`q.pop()` で最後に入れたものから取り出しているので、これは深さ優先探索（DFS）ですが、全部たどるのが目的なので順番はどちらでもかまいません。

`gained` は、今回の囲みで新しく取れたマスの数です。ステップ8で効果音の高さに使います。

> [!NOTE]
> 敵の陣地も、自分の陣地で囲めば自分のものになります。水は敵の陣地の上も流れるので、囲まれた内側にある敵の陣地にも水が届かず、自分の陣地に変わります。

## 線を描く

`draw()` の `// land edge shading` のループの **下**、`// heads` の **上** に追加します。

```js:game.js
    // trails
    for (let y = 0; y < N; y++) for (let x = 0; x < N; x++) {
      const t = trail[idx(x, y)];
      if (t) { ctx.fillStyle = PALETTE[t].trail; ctx.fillRect(x * C + C * 0.15, y * C + C * 0.15, C * 0.7, C * 0.7); }
    }
```

線は、マスより少し小さい（`0.7` 倍）半透明の四角で描きます。陣地とは見た目をはっきり変えて「まだ自分のものではない、弱いところ」だと分かるようにしています。

## turn() にもUターン禁止を

`turn()` の `const p = ents[0];` の **次の行** に1行足します。

```js:game.js
  function turn(d) {
    if (state !== 'play') return;
    const p = ents[0];
    if ((d + 2) % 4 === p.dir && p.path.length) return; // no instant U-turn into own line
    p.next = d;
  }
```

`step()` 側でも禁止していますが、こちらでも弾いておくと、「真後ろを押した」せいで直前に押した正しい向きの予約が消えてしまうのを防げます。

> [!CHECK] 動作チェック
> - 陣地から出ると、通ったマスに青い半透明の線が残る
> - 陣地の外では真後ろに曲がれない（陣地の中ではUターンできる）
> - ぐるっと回って陣地に戻ると、線と内側が青い陣地に変わり、上の「陣地」の % が増える
> - 自分の線に重なっても、まだアウトにはならない（ステップ5で作ります）
