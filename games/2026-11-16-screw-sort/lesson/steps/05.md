## このステップのゴール

箱の下に **5マスのトレイ** を作ります。どちらの箱とも色が合わないねじは、トレイの空いているマスへ飛んでいきます。トレイにあるねじは、同じ色の箱が出てくると **自動で箱へ移ります**。

トレイが全部うまって、もう箱に入れられるねじが無くなったら **ゲームオーバー** です。これでゲームとして遊べるようになります。

## トレイの入れ物

`let boxes = [];` の行の **下** に追加します。

```js:game.js
  let tray = [];           // 長さ TRAY_SIZE、screw or null
```

`genLevel()` の1行目の **下** に、トレイを空にする行を足します。`new Array(5).fill(null)` は `[null, null, null, null, null]` を作ります。

```js:game.js
    planks = []; screws = []; flyers = [];
    tray = new Array(TRAY_SIZE).fill(null);
```

## トレイの位置と、トレイから箱へ移す処理

`boxRect()` の **下** に `traySlotPos()` を、`fillBoxes()` を書きかえて、その下に `pullFromTray()` を追加します。

```js:game.js
  function traySlotPos(i) {
    const sw = 56;
    const x0 = (W - sw * TRAY_SIZE) / 2;
    return { x: x0 + sw * i + sw / 2, y: TRAY_Y + TRAY_H / 2 };
  }

  function fillBoxes() {
    for (let i = 0; i < 2; i++) {
      if (!boxes[i] && boxQueue.length) {
        boxes[i] = { color: boxQueue.shift(), slots: [null, null, null], t: 0, leaving: false, enter: 1 };
        // トレイから合うねじを移す
        pullFromTray(i);
      }
    }
  }

  function pullFromTray(bi) {
    const b = boxes[bi];
    if (!b) return;
    for (let i = 0; i < TRAY_SIZE; i++) {
      const s = tray[i];
      if (s && s.color === b.color) {
        const si = b.slots.indexOf(null);
        if (si < 0) break;
        tray[i] = null;
        b.slots[si] = s;
        const to = boxSlotPos(bi, si);
        launch(s, s.x, s.y, to.x, to.y, () => onArriveBox(bi));
      }
    }
  }
```

- `traySlotPos(i)` は、幅 56 のマスを5つ、画面の真ん中に並べたときの `i` 番目の中心です
- 新しい箱が出てきたら、すぐに `pullFromTray()` を呼びます。トレイを左から見ていき、箱と同じ色のねじがあれば、トレイから外して箱の空き穴へ飛ばします。箱がいっぱいになったら `break` でやめます

> [!NOTE]
> トレイのねじの位置 `s.x, s.y` は、トレイへ飛んだときの `launch()` でトレイのマスの位置になっています。だから `launch(s, s.x, s.y, ...)` と書くだけで、トレイから箱へ飛ばせます。

## 合う箱が無いねじはトレイへ

`pickScrew()` を書きかえます。

```js:game.js
  function pickScrew(s) {
    // 箱へ
    let bi = -1, si = -1;
    for (let i = 0; i < 2; i++) {
      const b = boxes[i];
      if (b && !b.leaving && b.color === s.color) {
        const k = b.slots.indexOf(null);
        if (k >= 0) { bi = i; si = k; break; }
      }
    }
    if (bi < 0 && tray.indexOf(null) < 0) { shake = { s, t: 0 }; return; }
    removeFromPlank(s);
    if (bi >= 0) {
      boxes[bi].slots[si] = s;
      const to = boxSlotPos(bi, si);
      launch(s, s.x, s.y, to.x, to.y, () => onArriveBox(bi));
    } else {
      const ti = tray.indexOf(null);
      tray[ti] = s;
      const to = traySlotPos(ti);
      launch(s, s.x, s.y, to.x, to.y, () => { s.where = 'tray'; checkStuck(); });
    }
  }
```

- ふるえて外れないのは「合う箱が無く、**しかもトレイもいっぱい**」のときだけになりました
- 合う箱があれば今までどおり箱へ、無ければトレイの最初の空きマス `tray.indexOf(null)` を予約して、そこへ飛ばします
- トレイに着いたら `where` を `'tray'` にして、詰んでいないかを調べます

## 詰みの判定とゲームオーバー

`removeFromPlank()` の **下** に `checkStuck()` を追加します。

```js:game.js
  function checkStuck() {
    if (state !== 'play') return;
    if (tray.indexOf(null) >= 0) return;
    if (flyers.length) return;
    // 箱に入れられるねじが盤面にあるか
    const ok = boardScrews().some(s => !isCovered(s) && boxes.some(b => b && !b.leaving && b.color === s.color && b.slots.indexOf(null) >= 0));
    const leavingSoon = boxes.some(b => b && b.leaving);
    if (!ok && !leavingSoon) gameOver();
  }
```

ゲームオーバーになるのは、次の全部がそろったときです。

1. プレイ中で、トレイに空きが無い
2. 飛んでいる途中のねじが無い（着いたあとに状況が変わるかもしれないので、全部着くまで待ちます）
3. 盤面に「外せて（`!isCovered(s)`）、しかも今の箱のどちらかに入れられる」ねじが1本も無い
4. 出ていく途中の箱が無い（箱が入れ替われば、トレイのねじが移れるかもしれないので待ちます）

`some()` は「1つでも条件に合えば `true`」を返す配列のメソッドです。2つ重ねて「箱に合うねじが1本でもあるか」を1行で調べています。

`onArriveBox()` の `if (full) { ... }` に `else` を足して、箱がいっぱいにならなかったときにも調べるようにします。

```js:game.js
  function onArriveBox(bi) {
    const b = boxes[bi];
    if (!b || b.leaving) return;
    const full = b.slots.every(x => x && x.where === 'box');
    if (full) {
      b.leaving = true; b.t = 0;
    } else {
      checkStuck();
    }
  }
```

`update(dt)` の箱の処理で、新しい箱が入ってから少し待って（0.4 秒）もう一度調べます。トレイから箱へ移るねじが飛び終わるのを待つためです。

```js:game.js
        if (b.t > 0.45) {
          boxes[i] = null;
          fillBoxes();
          if (state === 'play') setTimeout(checkStuck, 400);
        }
```

`startGame()` の **下** に `gameOver()` を追加します。

```js:game.js
  function gameOver() {
    state = 'over';
    setTimeout(() => {
      ovTitle.textContent = 'ゲームオーバー';
      ovText.innerHTML = 'トレイがいっぱいで動けなくなった！<br>LEVEL <b class="hl">' + level + '</b>　SCORE <b class="hl">' + score + '</b>';
      startBtn.textContent = 'もう一度';
      overlay.classList.remove('hidden');
    }, 700);
  }
```

`state` を `'over'` にしてタップを受けつけないようにし、0.7 秒あけてからオーバーレイの文字を書きかえて表示します。ボタンの文字は「もう一度」になり、押すと `startGame()` でレベル1からやり直せます。`setTimeout()` で少し待つのは、最後のねじが飛び終わるのを見せてから画面を切りかえるためです。

## トレイを描く

`draw()` の「次の箱」を描く `for` の **下**（`// 落ちる板・飛ぶねじ` の上）に追加します。

```js:game.js
    // トレイ
    const full = tray.filter(Boolean).length;
    ctx.fillStyle = full >= TRAY_SIZE - 1 ? 'rgba(255,80,80,.22)' : 'rgba(0,0,0,.28)';
    roundRect(traySlotPos(0).x - 28, TRAY_Y, 56 * TRAY_SIZE, TRAY_H, 14); ctx.fill();
    for (let i = 0; i < TRAY_SIZE; i++) {
      const p = traySlotPos(i);
      ctx.fillStyle = 'rgba(255,255,255,.1)';
      ctx.beginPath(); ctx.arc(p.x, p.y, SR + 3, 0, Math.PI * 2); ctx.fill();
      const s = tray[i];
      if (s && s.where === 'tray') drawScrew(s, s.x, s.y, false);
    }
```

`tray.filter(Boolean)` は `null` を取り除くので、その長さがトレイに入っているねじの数です。残り1マス以下になったらトレイを **赤っぽく** して、危ないことを知らせます。

> [!CHECK] 動作チェック
> - 箱の下に5つの丸いマスが並んだトレイが表示される
> - 箱と色が合わないねじをタップすると、トレイの空きマスへ飛んでいく。4本以上たまるとトレイが赤っぽくなる
> - トレイにあるねじと同じ色の箱が出てくると、そのねじが自動で箱へ飛んでいく
> - 合わないねじばかり外してトレイを満杯にし、箱に入れられるねじが盤面に無くなると、「ゲームオーバー」の画面が出る
> - 「もう一度」を押すと、新しい盤面でレベル1から始まる
