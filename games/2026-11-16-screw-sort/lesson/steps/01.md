## このステップのゴール

3つのファイルを用意して、ゲーム画面の土台を作ります。上に「LEVEL・SCORE・BEST」、まん中にゲームを描く **Canvas**（キャンバス）とその上に重ねるタイトル画面（オーバーレイ）、下にひとことヒントを置き、Canvas に **点々もようの盤面** を描くところまで進めます。

完成すると、こんなゲームになります。

- 盤面には、色つきの **ねじ** で留められた木の **板** が何枚も重なっている
- ねじをタップすると外れて、画面上の **同じ色の箱** へ飛んでいく。箱は3本でいっぱいになり、次の色の箱と入れ替わる
- 合う箱がないねじは、5マスの **トレイ** に置かれる。トレイの中のねじは、同じ色の箱が来ると自動で移る
- ねじが全部外れた板は落ちて、下に隠れていたねじが外せるようになる。上に板が重なっているねじは外せない
- トレイがあふれて動けなくなったらゲームオーバー。全部のねじを箱に入れるとレベルクリア

- `<script>` を `</body>` の直前に置くと、HTML の要素がすべて読みこまれてから JavaScript が動きます

## game.js

最初の `game.js` です。定数、要素の取り出し、Canvas の大きさ合わせ、ゲームループまでを書きます。

```js:game.js
(() => {
  'use strict';

  // ---- 定数 ----
  const W = 360, H = 640;              // 論理サイズ
  const BOX_Y = 14, BOX_H = 64;        // 箱エリア
  const TRAY_Y = 96, TRAY_H = 44;      // トレイ
  const TRAY_SIZE = 5;
  const BOARD = { x: 14, y: 156, w: W - 28, h: H - 170 };
  const SR = 11;                       // ねじ半径
  const PLANK_W = 34;
  const COLORS = [
    { name: 'red', c: '#ff5a5f', d: '#b8282d' },
    { name: 'blue', c: '#4ea8ff', d: '#1d64b5' },
    { name: 'yellow', c: '#ffd23f', d: '#b8901a' },
    { name: 'green', c: '#5ad17a', d: '#24863f' },
    { name: 'purple', c: '#b07cff', d: '#6a3cc0' },
    { name: 'orange', c: '#ff9a3c', d: '#b8601a' },
    { name: 'pink', c: '#ff7ac8', d: '#b83a86' },
  ];
  const WOODS = ['#e8b97a', '#d9a066', '#f0c992', '#cf9a5f', '#e3ad73'];

  // ---- DOM ----
  const cv = document.getElementById('cv');
  const ctx = cv.getContext('2d');
  const stageEl = document.getElementById('stage');
  const overlay = document.getElementById('overlay');
  const ovTitle = document.getElementById('ov-title');
  const ovText = document.getElementById('ov-text');
  const startBtn = document.getElementById('start');
  const levelEl = document.getElementById('level');
  const scoreEl = document.getElementById('score');
  const bestEl = document.getElementById('best');

  let scale = 1;
  function resize() {
    const r = stageEl.getBoundingClientRect();
    const availW = Math.max(100, r.width - 16), availH = Math.max(100, r.height - 8);
    scale = Math.min(availW / W, availH / H);
    const dpr = window.devicePixelRatio || 1;
    cv.style.width = Math.floor(W * scale) + 'px';
    cv.style.height = Math.floor(H * scale) + 'px';
    cv.width = Math.floor(W * scale * dpr);
    cv.height = Math.floor(H * scale * dpr);
    ctx.setTransform(scale * dpr, 0, 0, scale * dpr, 0, 0);
  }
  window.addEventListener('resize', resize);

  // ---- 状態 ----
  let state = 'title';     // title | play | clear | over
  let level = 1, score = 0;

  function startGame() {
    level = 1; score = 0;
    overlay.classList.add('hidden');
    state = 'play';
    updateHud();
  }
  startBtn.addEventListener('click', startGame);

  function updateHud() {
    levelEl.textContent = level;
    scoreEl.textContent = score;
  }

  // ---- 更新 ----
  function update(dt) {
    // ステップ3から動きを足していく
  }

  // ---- 描画 ----
  function roundRect(x, y, w, h, r) {
    ctx.beginPath();
    ctx.moveTo(x + r, y); ctx.arcTo(x + w, y, x + w, y + h, r); ctx.arcTo(x + w, y + h, x, y + h, r);
    ctx.arcTo(x, y + h, x, y, r); ctx.arcTo(x, y, x + w, y, r); ctx.closePath();
  }

  function draw() {
    ctx.clearRect(0, 0, W, H);
    // 盤面背景
    ctx.fillStyle = 'rgba(255,255,255,.06)';
    roundRect(BOARD.x - 6, BOARD.y - 6, BOARD.w + 12, BOARD.h + 12, 16); ctx.fill();
    ctx.fillStyle = 'rgba(255,255,255,.08)';
    for (let gx = BOARD.x + 12; gx < BOARD.x + BOARD.w; gx += 28)
      for (let gy = BOARD.y + 12; gy < BOARD.y + BOARD.h; gy += 28) { ctx.beginPath(); ctx.arc(gx, gy, 1.4, 0, Math.PI * 2); ctx.fill(); }
  }

  let lastT = performance.now();
  function loop(now) {
    const dt = Math.min(0.05, (now - lastT) / 1000);
    lastT = now;
    update(dt);
    draw();
    requestAnimationFrame(loop);
  }

  resize();
  requestAnimationFrame(loop);
})();
```

### 全体を `(() => { ... })();` で包む

関数をその場で呼び出す書き方（即時実行関数）です。中で作った変数や関数が外にもれないので、ほかのスクリプトと名前がぶつかりません。`'use strict';` は、うっかりミス（宣言していない変数への代入など）をエラーにしてくれる「厳しめモード」です。

### 論理サイズ 360×640 で考える

画面の大きさはスマホと PC でばらばらです。そこで、ゲームの中では **いつも横 360・縦 640 の世界** だと考えて座標を決めます（`W`・`H`）。上から順に、箱のエリア（`BOX_Y`）、トレイ（`TRAY_Y`）、板を並べる盤面（`BOARD`）と場所を決めておきます。`COLORS` はねじと箱の色で、`c` が明るい色、`d` が影の暗い色です。`WOODS` は板の木の色です。

### resize() … Canvas をくっきり表示する

1. `#stage` の大きさを調べて、360×640 がはみ出さずに入る倍率 `scale` を求めます
2. Canvas の **見た目の大きさ**（`cv.style.width`）と、**中の画素数**（`cv.width`）は別物です。高解像度の画面（`devicePixelRatio` が 2 や 3）でもぼやけないように、画素数は `dpr` 倍にします
3. `ctx.setTransform()` で「これから描く座標を `scale * dpr` 倍する」と設定します。これで、あとは 360×640 の座標のまま描くだけで画面いっぱいに表示されます

### ゲームループ

`requestAnimationFrame(loop)` は「次に画面を描きかえるタイミングで `loop` を呼んで」というお願いです。`loop` の最後でもう一度お願いするので、1秒に約60回 `update()`（動かす）と `draw()`（描く）がくり返されます。

`dt` は前のフレームからの経過時間（秒）です。動きを「1フレームに何ピクセル」ではなく「1秒に何ピクセル」で書けるので、画面の速さがちがうパソコンでも同じ速さで動きます。タブを切りかえて戻ったときに大きく飛ばないよう、`Math.min(0.05, ...)` で上限をつけています。

### state … いまどの場面か

`state` には `'title'`（タイトル）・`'play'`（プレイ中）・`'clear'`（クリア演出中）・`'over'`（ゲームオーバー）のどれかが入ります。いまは「スタート」ボタンで `startGame()` を呼び、オーバーレイを隠して `'play'` にするだけです。

### roundRect() … 角丸の四角形

`arcTo()` を4回使って角の丸い四角形の形（パス）を作ります。塗るのは呼び出した側で `ctx.fill()` します。箱・トレイ・板など、このゲームのほとんどの部品で使います。
