## このステップのゴール

いよいよ完成です。ねじを全部箱に入れたら **「CLEAR!」とボーナス** を出して、板と色が増えた **次のレベル** へ進みます。さらに、一番よかったスコアを **ハイスコアとしてブラウザに保存** し、PC では Enter / Space キーでもスタートできるようにします。

## ハイスコアを読みこむ

`// ---- 定数 ----` の `const PLANK_W = 34;` の **下** に、保存に使う名前（キー）を追加します。

```js:game.js
  const BEST_KEY = 'daily-mini-games:screw-sort:best';
```

`window.addEventListener('resize', resize);` の **下**（`// ---- 音 ----` の上）に追加します。

```js:game.js
  // ---- 保存 ----
  let best = 0;
  try { best = parseInt(localStorage.getItem(BEST_KEY), 10) || 0; } catch (e) { best = 0; }
  function saveBest() {
    if (score > best) {
      best = score;
      try { localStorage.setItem(BEST_KEY, String(best)); } catch (e) { /* ignore */ }
    }
    bestEl.textContent = best;
  }
  bestEl.textContent = best;
```

### localStorage

`localStorage` は、ブラウザの中に **文字列を保存しておける場所** です。ページを閉じたり再読み込みしたりしても消えません。

- `localStorage.setItem(キー, 値)` で保存、`localStorage.getItem(キー)` で読み出します。値は文字列なので、`String(best)` で文字列にして保存し、`parseInt(..., 10)` で数に戻します
- まだ一度も保存していないと `getItem()` は `null` を返し、`parseInt(null)` は `NaN` になります。`|| 0` で、そのときは 0 にします
- キーには、同じサイトのほかのゲームと混ざらないよう `daily-mini-games:screw-sort:best` のように長めの名前をつけています
- プライベートブラウズなどで保存が禁止されているとエラーになることがあるので、`try { ... } catch` で包んでいます

`saveBest()` は、今のスコアがハイスコアより大きいときだけ保存して、BEST の表示を更新します。

`updateHud()` にも1行足して、プレイ中にハイスコアを超えたら BEST の数字もいっしょに増えていくようにします。

```js:game.js
  function updateHud() {
    levelEl.textContent = level;
    scoreEl.textContent = score;
    if (score > best) bestEl.textContent = score;
  }
```

## レベルクリアと次のレベル

`let combo = 0, comboT = 0;` の **下** に、場面が変わってからの時間を数える変数を足します。

```js:game.js
  let stateT = 0;
```

`startGame()` の **下** に `nextLevel()` を追加します。レベルを1つ上げて、新しい盤面を作り直すだけです。`genLevel()` は `level` から板の枚数と色の数を決めているので、これだけで難しくなっていきます。

```js:game.js
  function nextLevel() {
    level++;
    genLevel();
    state = 'play';
    updateHud();
  }
```

`update(dt)` の **最初** に `stateT += dt;` を、**最後** にクリア判定を足します。全体はこうなります。

```js:game.js
  function update(dt) {
    stateT += dt;
    for (let i = flyers.length - 1; i >= 0; i--) {
      const f = flyers[i];
      f.t += dt / f.dur;
      const t = Math.min(1, f.t), e = 1 - Math.pow(1 - t, 3);
      f.s.x = f.fx + (f.tx - f.fx) * e;
      f.s.y = f.fy + (f.ty - f.fy) * e - Math.sin(t * Math.PI) * 30;
      f.s.spin = (f.s.spin || 0) + dt * 18;
      if (t >= 1) {
        f.s.x = f.tx; f.s.y = f.ty;
        flyers.splice(i, 1);
        if (f.ty < TRAY_Y) f.s.where = 'box';
        f.done && f.done();
      }
    }
    for (const p of planks) {
      if (!p.falling) continue;
      p.vy += 900 * dt; p.cy += p.vy * dt; p.ang += p.vr * dt;
      p.alpha = Math.max(0, p.alpha - dt * 0.8);
    }
    planks = planks.filter(p => !(p.falling && p.cy > H + 200));
    for (let i = 0; i < 2; i++) {
      const b = boxes[i];
      if (!b) continue;
      if (b.enter > 0) b.enter = Math.max(0, b.enter - dt * 4);
      if (b.leaving) {
        b.t += dt;
        if (b.t > 0.45) {
          for (let k = 0; k < 10; k++) particles.push({ x: boxRect(i).x + 75, y: BOX_Y + 32, vx: rand(-120, 120), vy: rand(-160, 40), t: 0, c: COLORS[b.color].c });
          boxes[i] = null;
          fillBoxes();
          if (state === 'play') setTimeout(checkStuck, 400);
        }
      }
    }
    for (const p of particles) { p.t += dt; p.x += p.vx * dt; p.y += p.vy * dt; p.vy += 400 * dt; }
    particles = particles.filter(p => p.t < 0.8);
    for (const p of popups) { p.t += dt; p.y -= 30 * dt; }
    popups = popups.filter(p => p.t < 0.9);
    if (shake) { shake.t += dt; if (shake.t > 0.3) shake = null; }
    if (comboT > 0) { comboT -= dt; if (comboT <= 0) combo = 0; }

    // クリア判定
    if (state === 'play' && screws.length && screws.every(s => s.where === 'box') && !flyers.length && boxes.every(b => !b)) {
      state = 'clear'; stateT = 0;
      const bonus = 100 + level * 20;
      score += bonus;
      addPopup(W / 2, H / 2, 'CLEAR! +' + bonus);
      beep(784, 0.12, 'triangle', 0.08); setTimeout(() => beep(988, 0.12, 'triangle', 0.08), 120); setTimeout(() => beep(1319, 0.2, 'triangle', 0.08), 240);
      updateHud(); saveBest();
    }
    if (state === 'clear' && stateT > 1.4) nextLevel();
  }
```

### クリア判定

次の全部がそろったらクリアです。

1. プレイ中で、ねじが1本以上ある
2. **すべてのねじ** の `where` が `'box'`（`every()` は「全部が条件に合えば `true`」を返します）
3. 飛んでいる途中のねじが無い
4. 最後の箱が出ていき終わって、`boxes` が両方とも空（`null`）になっている

クリアしたら `state` を `'clear'` にし、`stateT` を 0 に戻します。レベルが高いほど大きいボーナス（`100 + level * 20`）を足し、画面の真ん中に大きな「CLEAR!」を出して、ド・ミ・ソのように上がっていく3つの音を鳴らします。

`'clear'` の間は `tap()` が何もしないので、盤面を触ることはできません。1.4 秒たったら `nextLevel()` で次のレベルが始まります。

## ゲームオーバー画面とキー操作

`gameOver()` で、ハイスコアを保存してから、画面に BEST も表示するようにします。

```js:game.js
  function gameOver() {
    state = 'over';
    saveBest();
    beep(220, 0.3, 'sawtooth', 0.06); setTimeout(() => beep(150, 0.4, 'sawtooth', 0.06), 200);
    setTimeout(() => {
      ovTitle.textContent = 'ゲームオーバー';
      ovText.innerHTML = 'トレイがいっぱいで動けなくなった！<br>LEVEL <b class="hl">' + level + '</b>　SCORE <b class="hl">' + score + '</b><br>BEST ' + best;
      startBtn.textContent = 'もう一度';
      overlay.classList.remove('hidden');
    }, 700);
  }
```

`startBtn.addEventListener('click', startGame);` の **下** に、キーボードでスタートできる処理を足します。

```js:game.js
  startBtn.addEventListener('click', startGame);
  window.addEventListener('keydown', e => {
    if ((e.key === 'Enter' || e.key === ' ') && !overlay.classList.contains('hidden')) { e.preventDefault(); startGame(); }
  });
```

オーバーレイが表示されているとき（タイトル画面とゲームオーバー画面）だけ反応します。`e.preventDefault()` で、Space キーでページがスクロールするのを止めます。

## 改造アイデア

> [!TIP]
> **トレイの広さを変える**: `TRAY_SIZE` を 4 にするとぐっと難しく、6 にするとやさしくなります。`traySlotPos()` も描画も `TRAY_SIZE` から計算しているので、定数1つで変えられます（7以上にするときは、マスの幅 `sw` を小さくしましょう）。

> [!TIP]
> **箱を3つにする**: `boxes` は「2」という数で回しています。`for (let i = 0; i < 2; i++)` と箱の幅 `bw = 150` を変えて、3つの箱が並ぶようにしてみましょう。同時に入れられる色が増えて、遊び方が変わります。

> [!TIP]
> **外せないねじを暗くする**: `drawScrew()` には、使っていない `dim` という引数があります。`drawPlank()` の中で `drawScrew(s, x, s.y, isCovered(s))` とすると、上に板がかぶっているねじが暗く表示されて、見分けやすくなります。

> [!TIP]
> **ヒント機能**: `checkStuck()` の中の「箱に入れられるねじがあるか」の条件を使って、H キーを押したら入れられるねじを1本だけ光らせる（`shake` でふるわせるだけでも OK）ヒントを作ってみましょう。

> [!TIP]
> **元にもどす**: 直前に外したねじと、その行き先（箱かトレイか）を覚えておけば、1手だけ戻す「アンドゥ」が作れます。板が落ちていたら、`falling` を `false` に戻して位置も元に戻すのがポイントです。
