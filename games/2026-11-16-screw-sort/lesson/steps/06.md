## このステップのゴール

いまの色の配り方は完全にランダムなので、トレイをうまく使っても **どうやっても解けない盤面** ができることがあります。そこで「ねじを外せる順番」を先に決めて、その順番どおりに色を配ることで、**解ける道すじが必ずある** ステージを作ります。そのうえで少しだけ色と箱の順番を入れかえて、考えがいのある難しさにします。

## 外せる順番はどう決まる？

板は `layer` の大きい順に上に重なっています。すると、

- 一番上の板（`layer` が最大）のねじは、上に何もかぶっていないので **いつでも外せる**
- その板のねじを全部外すと板が落ちるので、2番目の板の上には何も無くなり、**そのねじも全部外せる**
- …と続けると、**上の板から順に外していけば、すべてのねじを必ず外せる**

ことが分かります。つまり「上の板から順に並べたねじの列」は、かならず実行できる外し方の1つです。

この列の先頭から3本ずつに同じ色を配り、箱もその色の順番で出てくるようにすれば、列のとおりに外すだけで **トレイを1度も使わずに** クリアできます。

## genLevel() の色の配り方を書きかえる

`genLevel()` の `planks.forEach((p, i) => { p.layer = i; });` より下を、次のように書きかえます。

```js:game.js
    planks.forEach((p, i) => { p.layer = i; });

    // 解ける順（上の板から）にねじを並べ、3本ずつ色を割り当てる
    const order = [];
    for (let i = planks.length - 1; i >= 0; i--) {
      const p = planks[i];
      const s = shuffle(p.pts.slice());
      s.forEach(pt => order.push({ pt, plank: p }));
    }
    const triples = total / 3;
    const colorSeq = [];
    let last = -1;
    for (let i = 0; i < triples; i++) {
      let c;
      do { c = Math.floor(Math.random() * nColors); } while (c === last && nColors > 1 && Math.random() < 0.7);
      colorSeq.push(c); last = c;
    }
    const screwColors = [];
    colorSeq.forEach(c => { screwColors.push(c, c, c); });
    // 窓の中で少し混ぜて難しくする
    const win = Math.min(6 + level * 3, 40);
    for (let i = 0; i < screwColors.length; i++) {
      const j = Math.min(screwColors.length - 1, i + Math.floor(Math.random() * win));
      [screwColors[i], screwColors[j]] = [screwColors[j], screwColors[i]];
    }
    order.forEach((o, i) => {
      const s = { x: o.pt.x, y: o.pt.y, plank: o.plank, color: screwColors[i], where: 'board' };
      o.plank.screws.push(s);
      screws.push(s);
    });
    boxQueue = colorSeq.slice();
    // 箱の順番も少し入れ替える（レベルが上がるほど大きく）
    const bw = Math.min(1 + Math.floor(level / 2), 5);
    for (let i = 0; i < boxQueue.length; i++) {
      const j = Math.min(boxQueue.length - 1, i + Math.floor(Math.random() * (bw + 1)));
      [boxQueue[i], boxQueue[j]] = [boxQueue[j], boxQueue[i]];
    }
    boxes = [];
    fillBoxes();
  }
```

### 上の板から順にねじを並べる

`for` を `planks.length - 1` から 0 へ **逆向き** に回して、上の板から順に `order` へ入れます。同じ板の中のねじは、どれから外してもよいので `shuffle()` でまぜておきます（`slice()` でコピーしてからまぜるのは、`p.pts` の順番を変えないためです）。

`colorSeq` の作り方は今までと同じです。`screwColors` は「`colorSeq` の色を3つずつ並べた列」なので、このままなら `order` の先頭から3本ずつが同じ色になります。

### 窓の中でだけ混ぜる

このままでは簡単すぎるので、`screwColors` を少し混ぜます。ただし全体を `shuffle()` すると、また解けない盤面ができてしまいます。そこで、`i` 番目の色を **`i` から `win` 個先まで** の中の1つとだけ入れかえます。

- 入れかえは近いところどうしでしか起きないので、「すぐ外せるねじの色」と「いまの箱の色」はだいたい合っていて、ずれた分は **5マスのトレイ** で吸収できます
- `win` は `level` とともに大きくなり（最大 40）、レベルが上がるほど、先のほうの色が手前に来て難しくなります

### 箱の順番も少しだけ入れかえる

`boxQueue` も同じ考え方で、`bw + 1` 個先までの中で入れかえます。`bw` はレベル1・2では1、レベルが上がると最大5まで広がります。箱の順番がずれると、「いま外せるねじ」と「いまの箱」が合わなくなり、トレイを使って順番を調整する必要が出てきます。

> [!NOTE]
> 混ぜる幅を小さくしておくのが大事なポイントです。ランダムに **少しだけ** くずすことで、「解ける道すじ」はほぼ残したまま、毎回ちがう手ごたえのパズルになります。絶対に解けることを保証したいときは、作った盤面を実際に解いてみる探索（深さ優先探索など）を足す方法もあります。

> [!CHECK] 動作チェック
> - スタートすると、一番上の板（ほかの板の下に隠れていない板）のねじの色と、出ている箱の色がだいたい合っている
> - 上の板から順にねじを外していくと、トレイをあまり使わずに全部のねじを箱に入れられる
> - 何度か新しい盤面で遊んでみて、手詰まりの盤面がほとんど出なくなったことを確かめる
