## このステップのゴール

盤面に、いろいろな向きの **木の板** を重ねて並べ、それぞれの板を **色つきのねじ** で留めた絵を描きます。再読み込みするたびに、ちがう並び方になるようにします。

## 板とねじの入れ物を用意する

`// ---- 状態 ----` の `let level = 1, score = 0;` の **下** に追加します。

```js:game.js
  let planks = [];         // {cx,cy,len,ang,layer,color,screws:[], falling, vy, vr, alpha}
  let screws = [];         // {x,y,plank,color,where:'board'|'fly'|'box'|'tray', ...}

  function rand(a, b) { return a + Math.random() * (b - a); }
  function shuffle(a) { for (let i = a.length - 1; i > 0; i--) { const j = Math.floor(Math.random() * (i + 1)); [a[i], a[j]] = [a[j], a[i]]; } return a; }

  // 板の上の点の座標
  function plankPoint(p, t) {
    return { x: p.cx + Math.cos(p.ang) * t, y: p.cy + Math.sin(p.ang) * t };
  }
```

- **板**（plank）は「中心 `cx, cy`」「長さ `len`」「向き `ang`（ラジアン）」「重なり順 `layer`」を持つオブジェクトにします。`layer` が大きいほど上にある板です
- **ねじ**（screw）は「位置 `x, y`」「留めている板 `plank`」「色の番号 `color`」と、いまどこにいるかを表す `where` を持ちます。最初はみんな `'board'`（盤面の上）です。あとで `'fly'`（飛んでいる）・`'box'`（箱の中）・`'tray'`（トレイの上）に変わっていきます
- `rand(a, b)` は a 以上 b 未満のランダムな小数、`shuffle(a)` は配列をまぜる関数（フィッシャー–イェーツのシャッフル）です

### plankPoint() … 板の上の点

板の中心から、板の向きに沿って `t` だけ進んだ点の座標を返します。`Math.cos(ang)` と `Math.sin(ang)` は「その向きに1進んだら x と y がどれだけ動くか」を表すので、`t` 倍して中心に足せば板の上の点になります。`t` がマイナスなら反対側の端に向かいます。

## レベルを作る genLevel()

`plankPoint()` の **下** に追加します。少し長いですが、上から順に読んでいきましょう。

```js:game.js
  // ---- レベル生成 ----
  function genLevel() {
    planks = []; screws = [];
    const nColors = Math.min(3 + Math.floor((level - 1) / 2), COLORS.length);
    const nPlanks = Math.min(4 + Math.floor(level * 1.5), 15);
    const angles = [0, Math.PI / 2, Math.PI / 6, -Math.PI / 6, Math.PI / 4, -Math.PI / 4, Math.PI / 3, -Math.PI / 3];
    const allPts = [];
    let tries = 0;
    while (planks.length < nPlanks && tries < 3000) {
      tries++;
      const len = rand(110, 210);
      const ang = angles[Math.floor(Math.random() * angles.length)];
      const hx = Math.abs(Math.cos(ang)) * len / 2 + PLANK_W / 2;
      const hy = Math.abs(Math.sin(ang)) * len / 2 + PLANK_W / 2;
      if (hx * 2 > BOARD.w || hy * 2 > BOARD.h) continue;
      let cx = rand(BOARD.x + hx, BOARD.x + BOARD.w - hx);
      let cy = rand(BOARD.y + hy, BOARD.y + BOARD.h - hy);
      // 2枚目以降はなるべく既存の板に重ねる
      if (planks.length >= 2 && Math.random() < 0.6 && tries < 2000) {
        const base = planks[Math.floor(Math.random() * planks.length)];
        cx = Math.min(BOARD.x + BOARD.w - hx, Math.max(BOARD.x + hx, base.cx + rand(-100, 100)));
        cy = Math.min(BOARD.y + BOARD.h - hy, Math.max(BOARD.y + hy, base.cy + rand(-100, 100)));
      }
      const p = { cx, cy, len, ang, layer: planks.length, wood: WOODS[planks.length % WOODS.length], screws: [], falling: false, vy: 0, vr: 0, alpha: 1 };
      const m = 16;
      const ts = len > 165 ? [-len / 2 + m, 0, len / 2 - m] : [-len / 2 + m, len / 2 - m];
      const pts = ts.map(t => plankPoint(p, t));
      // ほかのねじと近すぎないこと
      if (pts.some(a => allPts.some(b => Math.hypot(a.x - b.x, a.y - b.y) < SR * 2 + 8))) continue;
      // 既存の板の大半と重なりすぎない程度に（少しは重ねる）
      pts.forEach(pt => allPts.push(pt));
      p.pts = pts;
      planks.push(p);
    }
    // ねじ総数を3の倍数に調整（端数は最後の板から削る）
    let total = planks.reduce((s, p) => s + p.pts.length, 0);
    let k = planks.length - 1;
    while (total % 3 !== 0 && k >= 0) {
      if (planks[k].pts.length === 3) { planks[k].pts.splice(1, 1); total--; }
      k--;
    }
    k = planks.length - 1;
    while (total % 3 !== 0 && k >= 0) {
      // 2本の板を1本にはしない：かわりに板を除く
      total -= planks[k].pts.length; planks.splice(k, 1); k--;
    }
    planks.forEach((p, i) => { p.layer = i; });

    // ねじの位置を並べ、3本ずつ色を割り当てる（いまはランダム）
    const order = [];
    planks.forEach(p => p.pts.forEach(pt => order.push({ pt, plank: p })));
    const triples = total / 3;
    const colorSeq = [];
    let last = -1;
    for (let i = 0; i < triples; i++) {
      let c;
      do { c = Math.floor(Math.random() * nColors); } while (c === last && nColors > 1 && Math.random() < 0.7);
      colorSeq.push(c); last = c;
    }
    const screwColors = [];
    colorSeq.forEach(c => { screwColors.push(c, c, c); });
    shuffle(screwColors);
    order.forEach((o, i) => {
      const s = { x: o.pt.x, y: o.pt.y, plank: o.plank, color: screwColors[i], where: 'board' };
      o.plank.screws.push(s);
      screws.push(s);
    });
  }
```

### 板を1枚ずつ置いてみる

`while` の中で「ランダムに板を作って、条件に合えば採用」を、目標の枚数 `nPlanks` になるまでくり返します。

1. 長さ `len` と向き `ang` をランダムに決めます。向きは `angles` に用意した 0°・90°・±30°・±45°・±60° から選びます
2. `hx`・`hy` は、回転した板が横と縦にどれだけ広がるか（半分の幅）です。これを使って、板が盤面からはみ出さない範囲に中心を置きます
3. 3枚目からは 60% の確率で、すでにある板の近くに置きます。こうすると板がよく **重なり**、パズルらしくなります
4. ねじを留める位置 `pts` を決めます。端から 16 のところに2本、長い板は真ん中にもう1本です
5. ほかの板のねじと近すぎる（重なって見える）ときは `continue` で捨てて、やり直します

うまく置けない場合に無限ループにならないよう、`tries < 3000` で試す回数に上限をつけています。

### ねじの数を3の倍数にする

このゲームの箱は **3本でいっぱい** になります。ねじの総数が3の倍数でないと、最後に半端なねじが残ってしまいます。そこで、上の板から順に「3本留めの板の真ん中のねじ」を減らし、それでも合わなければ板ごと取り除いて調整します。最後に `layer` を 0, 1, 2… と振り直します。

### 色を配る

1. `triples`（3本組の数）だけ色を選んで `colorSeq` に並べます。同じ色が続きすぎないよう、前と同じ色ならある程度の確率で選び直します
2. 色を3つずつ `screwColors` に入れて、`shuffle()` でまぜます
3. ねじの位置 `order` と1つずつ組にして、ねじのオブジェクトを作ります。ねじは留めている板の `screws` と、全体の `screws` の両方に入れておきます

`nColors`（色の種類）と `nPlanks`（板の枚数）は `level` から計算しているので、レベルが上がるほど難しくなります。

> [!NOTE]
> いまの色の配り方は完全にランダムなので、ときどき **解けない並び** になります。ステップ6で「解ける順番を考えた配り方」に直します。

## 板とねじを描く

`roundRect()` の **下** に、ねじと板を描く関数を追加します。

```js:game.js
  function drawScrew(s, x, y, dim) {
    const col = COLORS[s.color];
    ctx.save();
    ctx.translate(x, y);
    ctx.fillStyle = 'rgba(0,0,0,.25)';
    ctx.beginPath(); ctx.arc(1.5, 2.5, SR, 0, Math.PI * 2); ctx.fill();
    ctx.fillStyle = col.d;
    ctx.beginPath(); ctx.arc(0, 0, SR, 0, Math.PI * 2); ctx.fill();
    ctx.fillStyle = col.c;
    ctx.beginPath(); ctx.arc(-0.8, -0.8, SR - 2.2, 0, Math.PI * 2); ctx.fill();
    ctx.rotate((s.spin || 0) + s.color);
    ctx.strokeStyle = col.d; ctx.lineWidth = 2.6; ctx.lineCap = 'round';
    ctx.beginPath(); ctx.moveTo(-5, 0); ctx.lineTo(5, 0); ctx.moveTo(0, -5); ctx.lineTo(0, 5); ctx.stroke();
    ctx.restore();
    if (dim) {
      ctx.fillStyle = 'rgba(0,0,0,.35)';
      ctx.beginPath(); ctx.arc(x, y, SR, 0, Math.PI * 2); ctx.fill();
    }
  }

  function drawPlank(p) {
    ctx.save();
    ctx.globalAlpha = p.alpha * 0.9;
    ctx.translate(p.cx, p.cy);
    ctx.rotate(p.ang);
    const l = p.len, w = PLANK_W;
    ctx.fillStyle = 'rgba(0,0,0,.25)';
    roundRect(-l / 2 + 2, -w / 2 + 4, l, w, w / 2); ctx.fill();
    ctx.fillStyle = p.wood;
    roundRect(-l / 2, -w / 2, l, w, w / 2); ctx.fill();
    ctx.strokeStyle = 'rgba(120,70,30,.55)'; ctx.lineWidth = 2;
    ctx.stroke();
    // 木目
    ctx.strokeStyle = 'rgba(150,90,40,.25)'; ctx.lineWidth = 1.2;
    for (let k = -1; k <= 1; k++) {
      ctx.beginPath(); ctx.moveTo(-l / 2 + 18, k * 8); ctx.bezierCurveTo(-l / 6, k * 8 + 3, l / 6, k * 8 - 3, l / 2 - 18, k * 8); ctx.stroke();
    }
    ctx.restore();
    // 穴
    ctx.save();
    ctx.globalAlpha = p.alpha;
    for (const pt of p.pts) {
      const has = p.screws.some(s => s.where === 'board' && s.x === pt.x && s.y === pt.y);
      if (!has && !p.falling) {
        ctx.fillStyle = 'rgba(60,35,20,.75)';
        ctx.beginPath(); ctx.arc(pt.x, pt.y, SR - 3, 0, Math.PI * 2); ctx.fill();
      }
    }
    ctx.restore();
    // ねじ
    for (const s of p.screws) {
      if (s.where !== 'board') continue;
      drawScrew(s, s.x, s.y, false);
    }
  }
```

### translate と rotate

Canvas の `ctx.translate(x, y)` は「原点（0, 0）を (x, y) に動かす」、`ctx.rotate(角度)` は「座標軸を回す」命令です。ななめの板を描くとき、角の座標を自分で計算するのは大変ですが、**板の中心に原点を動かして、板の向きに回してから**、横長の角丸四角形を `(-l/2, -w/2)` から描けば、勝手にななめになります。

`ctx.save()` と `ctx.restore()` で、移動・回転・透明度の設定を元に戻します。これを忘れると、次に描くものまで回ってしまいます。

### 板の描き方

- 少しずらした黒い半透明の四角で **影** を描いてから、木の色で本体を塗り、ふちを線で描きます
- `bezierCurveTo()` でゆるい曲線を3本引いて **木目** にしています
- ねじが外れた位置には、こげ茶の丸で **穴** を描きます。ねじがまだ盤面にあるかどうかを `p.screws.some(...)` で調べています

### ねじの描き方

影 → 暗い色の丸 → 少し小さい明るい色の丸、と重ねて立体的に見せ、最後に `rotate()` してから十字の溝を描きます。`s.color` を角度に足しているので、色ごとに溝の向きが少しずつちがって見えます（`s.spin` はステップ4で飛ぶときに回すための値です）。

## 板を下から順に描く

`draw()` の最後（点々もようを描く `for` の下）に追加します。

```js:game.js
    // 板（下から）
    const sorted = planks.slice().sort((a, b) => a.layer - b.layer);
    for (const p of sorted) if (!p.falling) drawPlank(p);
```

Canvas は **あとから描いたものが上に重なる** ので、`layer` の小さい（下にある）板から順に描きます。`slice()` でコピーしてから並べかえているのは、元の `planks` の順番を変えないためです。

最後に、タイトル画面の後ろにも盤面が見えるよう、ファイルの一番下を次のようにし、`startGame()` の `overlay.classList.add('hidden');` の **下** にも `genLevel();` を足します。

```js:game.js
  resize();
  genLevel();   // タイトル背景用
  requestAnimationFrame(loop);
})();
```

```js:game.js
  function startGame() {
    level = 1; score = 0;
    overlay.classList.add('hidden');
    genLevel();
    state = 'play';
    updateHud();
  }
```

> - タイトル画面の後ろに、木の板とねじがうっすら見える
> - スタートすると、いろいろな向きの板が重なって並び、それぞれの板が2本か3本の色つきねじで留められている
> - 再読み込みやスタートのたびに、並び方と色が変わる
> - 色は3色（赤・青・黄）で、どの色のねじも3の倍数本ある
