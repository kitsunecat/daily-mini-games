## このステップのゴール

ねじを **タップ（クリック）で外せる** ようにします。上に別の板がかぶっているねじは外せず、ぷるぷるふるえます。留めているねじが全部外れた板は、くるっと回りながら **下へ落ちて** 消え、その下にあったねじが外せるようになります。

外したねじは、いまはその場で消えるだけです（ステップ4で箱へ飛ばします）。

## ふるえるねじの入れ物

`// ---- 状態 ----` の `let screws = [];` の行の **下** に追加します。外せないねじをタップしたとき、「どのねじを・いつからふるわせるか」をここに入れます。

```js:game.js
  let shake = null;        // {screw, t}
```

## 回転した板の中に点があるか

`plankPoint()` の **下** に追加します。

```js:game.js
  function inPlank(p, x, y, pad) {
    const dx = x - p.cx, dy = y - p.cy;
    const c = Math.cos(-p.ang), s = Math.sin(-p.ang);
    const lx = dx * c - dy * s, ly = dx * s + dy * c;
    return Math.abs(lx) <= p.len / 2 + pad && Math.abs(ly) <= PLANK_W / 2 + pad;
  }
```

板はななめに回っているので、「x が左右の端の間にあるか」のような単純な比べ方はできません。そこで逆に、**点のほうを板の向きと反対に回して**、板がまっすぐ横向きだったときの座標 `lx, ly` に直します。

1. `dx, dy` … 板の中心から見た点の位置
2. `-p.ang` だけ回転させる計算（回転の公式 `x' = x·cos − y·sin`、`y' = x·sin + y·cos`）で、`lx`（板の長さ方向）と `ly`（板の幅方向）を求めます
3. あとは `|lx|` が長さの半分以内、`|ly|` が幅の半分以内かを調べるだけです

`pad` はゆとりの幅で、少し外側まで「中」とみなしたいときに使います。

## 上に板がかぶっているか

`genLevel()` の **下** に追加します。

```js:game.js
  function isCovered(s) {
    const p = s.plank;
    for (const q of planks) {
      if (q.falling || q.layer <= p.layer) continue;
      if (inPlank(q, s.x, s.y, SR * 0.4)) return true;
    }
    return false;
  }

  function boardScrews() { return screws.filter(s => s.where === 'board'); }
```

`isCovered(s)` は、ねじ `s` を留めている板より **上の板**（`layer` が大きい板）のどれかが、ねじの位置にかぶっていれば `true` を返します。落ちている途中の板は数えません。`SR * 0.4` のゆとりをつけて、板のふちがねじの頭に少しでもかかっていれば「かぶっている」とします。

`boardScrews()` は、まだ盤面に残っているねじだけを集めて返す関数です。

## タップでねじを選んで外す

`boardScrews()` の **下** に追加します。

```js:game.js
  // ---- 入力 ----
  function tap(x, y) {
    if (state !== 'play') return;
    let bestS = null, bestD = 22;
    for (const s of boardScrews()) {
      const d = Math.hypot(s.x - x, s.y - y);
      if (d < bestD) { bestD = d; bestS = s; }
    }
    if (!bestS) return;
    // 重なっている候補があれば、外せる方を優先
    if (isCovered(bestS)) {
      const alt = boardScrews().filter(s => Math.hypot(s.x - x, s.y - y) < 22 && !isCovered(s));
      if (alt.length) bestS = alt[0];
      else { shake = { s: bestS, t: 0 }; return; }
    }
    pickScrew(bestS);
  }

  function pickScrew(s) {
    // いまは外したねじは消えるだけ（ステップ4で箱へ飛ばす）
    removeFromPlank(s);
  }

  function removeFromPlank(s) {
    const p = s.plank;
    s.where = 'fly';
    if (p.screws.every(x => x.where !== 'board')) {
      p.falling = true; p.vy = -60; p.vr = rand(-2, 2);
    }
  }

  function pos(e) {
    const r = cv.getBoundingClientRect();
    return { x: (e.clientX - r.left) / r.width * W, y: (e.clientY - r.top) / r.height * H };
  }
  cv.addEventListener('pointerdown', e => { e.preventDefault(); const p = pos(e); tap(p.x, p.y); });
```

### Pointer Events と座標の変換

`pointerdown` は、マウスのクリックでも指のタッチでも同じように届くイベントです。`e.clientX, e.clientY` は **画面上のピクセル** なので、`pos()` で Canvas の左上からの位置に直し、表示サイズで割ってから 360×640 の論理座標に戻します。`e.preventDefault()` で、スマホでタップしたときの余計な動き（ダブルタップでの拡大など）を止めます。

### tap() … どのねじを外すか

1. タップした点から **22 以内** にある盤面のねじのうち、一番近いものを選びます。ねじの半径（11）より広めにして、指でも押しやすくしています
2. そのねじに板がかぶっていたら、近くにある **外せるねじ** を代わりに探します。重なって見えるところをタップしたとき、上のねじが選ばれるようにするためです
3. 外せるねじが無ければ、`shake` に「どのねじを、いつからふるわせるか」を入れて終わります

### removeFromPlank() … 板から外す

ねじの `where` を `'fly'` にして盤面から外します。その板のねじがもう1本も盤面に無ければ、板を落とします。`p.falling = true` にし、少し上向きの速さ `vy = -60` と、ランダムな回転の速さ `vr` を与えます。

`pickScrew()` はいまは `removeFromPlank()` を呼ぶだけです。次のステップで、ここに「箱へ飛ばす」処理を書きます。

## 板を落とし、ねじをふるわせる

`update(dt)` の中身を書きかえます。

```js:game.js
  function update(dt) {
    for (const p of planks) {
      if (!p.falling) continue;
      p.vy += 900 * dt; p.cy += p.vy * dt; p.ang += p.vr * dt;
      p.alpha = Math.max(0, p.alpha - dt * 0.8);
    }
    planks = planks.filter(p => !(p.falling && p.cy > H + 200));
    if (shake) { shake.t += dt; if (shake.t > 0.3) shake = null; }
  }
```

- 落ちている板は、毎フレーム **重力** で下向きの速さ `vy` が増え（`900 * dt`）、その速さで `cy` が動きます。同時に `ang` を回し、`alpha`（不透明度）を下げてだんだん消していきます
- 画面の下まで落ちた板は `filter()` で配列から取り除きます
- `shake.t` を進め、0.3 秒たったら `null` に戻してふるえを止めます

`drawPlank()` の最後の「ねじ」の `for` を、ふるえを足した形に書きかえます。

```js:game.js
    // ねじ
    for (const s of p.screws) {
      if (s.where !== 'board') continue;
      let x = s.x;
      if (shake && shake.s === s) x += Math.sin(shake.t * 60) * 3;
      drawScrew(s, x, s.y, false);
    }
```

`Math.sin(shake.t * 60) * 3` は時間とともに −3 〜 +3 を細かく行き来するので、ねじが左右にぷるぷるふるえて見えます。

`draw()` の最後（板を描く `for` の下）に、落ちている板を描く処理を追加します。ほかの部品より **上** に描きたいので、`draw()` の一番最後に置きます。

```js:game.js
    // 落ちる板
    for (const p of planks) if (p.falling) drawPlank(p);
```

`state` には `'play'` 以外の値もあるので、`tap()` の最初の `if (state !== 'play') return;` で、タイトル画面の後ろの盤面は触れないようにしています。

> [!CHECK] 動作チェック
> - 上に何も重なっていないねじをタップすると、ねじが消えて、こげ茶の穴が残る
> - 別の板の下に隠れているねじをタップすると、ねじがぷるぷるふるえて外れない
> - 板のねじを全部外すと、板が少しはね上がってから回りながら落ちて消え、下にあったねじが外せるようになる
