## このステップのゴール

遊んだ手ごたえを出す仕上げです。ねじを箱に入れたり板を落としたりすると **点数** が入り、続けて箱に入れると **コンボ** で点数が増えます。さらに **効果音**、ねじの上に浮かぶ **「+10」の文字**、箱がいっぱいになったときに飛び散る **紙ふぶき（パーティクル）** を足します。

## 効果音 beep()

`window.addEventListener('resize', resize);` の **下**（`// ---- 状態 ----` の上）に追加します。

```js:game.js
  // ---- 音 ----
  function beep(freq, dur, type, vol) {
    try {
      if (!ac) ac = new (window.AudioContext || window.webkitAudioContext)();
      const o = ac.createOscillator(), g = ac.createGain();
      o.type = type || 'square';
      o.frequency.value = freq;
      g.gain.setValueAtTime(vol || 0.06, ac.currentTime);
      g.gain.exponentialRampToValueAtTime(0.0001, ac.currentTime + dur);
      o.connect(g); g.connect(ac.destination);
      o.start(); o.stop(ac.currentTime + dur);
    } catch (e) { /* ignore */ }
  }
```

**Web Audio API** を使うと、音声ファイルを用意しなくてもブラウザの中で音を作れます。

- `AudioContext` は音を鳴らすための「ミキサー」です。ブラウザは **ユーザーが画面を操作するまで音を鳴らさせない** ので、最初に `beep()` が呼ばれたとき（＝タップしたとき）に作ります。古い Safari 向けに `webkitAudioContext` も試します
- `createOscillator()` は「ピー」という一定の高さの音を出す発振器です。`type` で音色（`'square'` 矩形波はピコピコ、`'triangle'` 三角波はやわらか、`'sawtooth'` のこぎり波はブザーっぽい）、`frequency` で高さ（Hz）を決めます
- `createGain()` は音量つまみです。`exponentialRampToValueAtTime()` で `dur` 秒かけて音量をほぼ 0 まで下げると、「ポッ」と自然に消える音になります
- 音が鳴らせない環境でもゲームが止まらないよう、全体を `try { ... } catch` で包んでいます

## 点数を入れる

`pickScrew()` を書きかえます。

```js:game.js
  function pickScrew(s) {
    // 箱へ
    let bi = -1, si = -1;
    for (let i = 0; i < 2; i++) {
      const b = boxes[i];
      if (b && !b.leaving && b.color === s.color) {
        const k = b.slots.indexOf(null);
        if (k >= 0) { bi = i; si = k; break; }
      }
    }
    if (bi < 0 && tray.indexOf(null) < 0) { shake = { s, t: 0 }; beep(140, 0.12, 'sawtooth', 0.05); return; }
    removeFromPlank(s);
    if (bi >= 0) {
      boxes[bi].slots[si] = s;
      const to = boxSlotPos(bi, si);
      combo++; comboT = 1.6;
      const gain = 10 + Math.min(combo - 1, 10) * 2;
      score += gain;
      addPopup(s.x, s.y - 14, '+' + gain + (combo > 1 ? ' x' + combo : ''));
      beep(520 + Math.min(combo, 10) * 40, 0.08, 'square', 0.05);
      launch(s, s.x, s.y, to.x, to.y, () => onArriveBox(bi));
    } else {
      const ti = tray.indexOf(null);
      tray[ti] = s;
      combo = 0;
      score += 2;
      const to = traySlotPos(ti);
      beep(330, 0.08, 'square', 0.04);
      launch(s, s.x, s.y, to.x, to.y, () => { s.where = 'tray'; checkStuck(); });
    }
    updateHud();
  }
```

- 箱へ入れると **10点**。続けて箱へ入れるたびに `combo` が増え、2点ずつ上乗せされます（上乗せは最大 +20 まで）。2コンボ目からは「+12 x2」のように表示します
- `comboT` はコンボが続く残り時間です。1.6 秒以内に次のねじを箱へ入れないと、コンボが切れます
- トレイへ置いたときは **2点** だけで、コンボは 0 に戻ります
- 箱へ入れる音は、コンボが増えるほど高くなります（`520 + combo * 40` Hz）。耳でもコンボが分かると気持ちいいです

`onArriveBox()` の、箱がいっぱいになったところに **50点** と音を足します。

```js:game.js
  function onArriveBox(bi) {
    const b = boxes[bi];
    if (!b || b.leaving) return;
    const full = b.slots.every(x => x && x.where === 'box');
    if (full) {
      b.leaving = true; b.t = 0;
      score += 50; addPopup(boxRect(bi).x + 75, BOX_Y + 30, '+50');
      beep(880, 0.12, 'triangle', 0.08); setTimeout(() => beep(1175, 0.15, 'triangle', 0.08), 90);
      updateHud();
    } else {
      checkStuck();
    }
  }
```

`removeFromPlank()` の、板が落ちるところに **5点** と音を足します。`setTimeout()` で 0.06 秒ずらしているのは、ねじを外す音と重ならないようにするためです。

```js:game.js
  function removeFromPlank(s) {
    const p = s.plank;
    s.where = 'fly';
    if (p.screws.every(x => x.where !== 'board')) {
      p.falling = true; p.vy = -60; p.vr = rand(-2, 2);
      score += 5;
      setTimeout(() => beep(200, 0.18, 'triangle', 0.06), 60);
    }
  }
```

`tap()` と `pickScrew()` で、ねじがふるえて外れないときの2か所に、ブザーの音を足します（`pickScrew()` のほうは上の全体のコードに入っています）。

## 演出を動かす

`update(dt)` の箱の処理で、箱が消える瞬間に、その箱の色の紙ふぶきを10個出します。

```js:game.js
        if (b.t > 0.45) {
          for (let k = 0; k < 10; k++) particles.push({ x: boxRect(i).x + 75, y: BOX_Y + 32, vx: rand(-120, 120), vy: rand(-160, 40), t: 0, c: COLORS[b.color].c });
          boxes[i] = null;
```

`update(dt)` の最後の `if (shake) ...` の行の **上** に、紙ふぶきと浮かぶ文字を動かす処理を、**下** にコンボの残り時間を減らす処理を足します。

```js:game.js
    for (const p of particles) { p.t += dt; p.x += p.vx * dt; p.y += p.vy * dt; p.vy += 400 * dt; }
    particles = particles.filter(p => p.t < 0.8);
    for (const p of popups) { p.t += dt; p.y -= 30 * dt; }
    popups = popups.filter(p => p.t < 0.9);
    if (shake) { shake.t += dt; if (shake.t > 0.3) shake = null; }
    if (comboT > 0) { comboT -= dt; if (comboT <= 0) combo = 0; }
  }
```

- 紙ふぶきは、ランダムな向きの速さで飛び出し、重力（`400 * dt`）で落ちながら 0.8 秒で消えます
- 浮かぶ文字は、1秒に 30 ずつ上へ動きながら 0.9 秒で消えます

## 演出を描く

`draw()` の一番最後（飛ぶねじを描く行の下）に追加します。

```js:game.js
    for (const p of particles) {
      ctx.globalAlpha = 1 - p.t / 0.8;
      ctx.fillStyle = p.c; ctx.fillRect(p.x - 3, p.y - 3, 6, 6);
    }
    ctx.globalAlpha = 1;
    ctx.textAlign = 'center';
    for (const p of popups) {
      ctx.globalAlpha = 1 - p.t / 0.9;
      ctx.font = 'bold ' + (p.text.startsWith('CLEAR') ? 28 : 15) + 'px system-ui, sans-serif';
      ctx.lineWidth = 4; ctx.strokeStyle = 'rgba(0,0,0,.6)'; ctx.strokeText(p.text, p.x, p.y);
      ctx.fillStyle = '#ffe17a'; ctx.fillText(p.text, p.x, p.y);
    }
    ctx.globalAlpha = 1;
```

- `globalAlpha` を時間とともに 1 → 0 にして、だんだん透明にします。描き終わったら必ず 1 に戻します
- 文字は先に `strokeText()` で太い黒いふちを描いてから `fillText()` で中を塗ると、どんな背景の上でも読みやすくなります
- 「CLEAR!」で始まる文字だけ大きくしているのは、次のステップでレベルクリアの表示に使うためです

> [!CHECK] 動作チェック
> - ねじを箱へ入れると音が鳴り、ねじの上に「+10」が浮かんで、SCORE が増える
> - 続けてすばやく箱へ入れると「+12 x2」「+14 x3」…とコンボになり、音がだんだん高くなる
> - トレイへ置くとコンボが切れ、SCORE は2点だけ増える
> - 箱が3本でいっぱいになると「+50」が出て、箱の色の紙ふぶきが飛び散る
> - 外せないねじをタップすると「ブッ」というブザー音が鳴る
