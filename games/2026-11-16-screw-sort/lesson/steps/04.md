## このステップのゴール

画面の上に **2つの色つきの箱** を出し、外したねじが **同じ色の箱へ弧をえがいて飛んでいく** ようにします。箱は3本でいっぱいになると上へ飛んで消え、次の色の箱が入ってきます。箱の左下には、このあと来る箱の色も小さく並べます。

合う箱が無いねじは、いまはふるえて外れません（次のステップでトレイに置けるようにします）。

## 箱の列と、飛んでいるねじ

`// ---- 状態 ----` の `let screws = [];` の行の **下** に追加します。

```js:game.js
  let boxQueue = [];       // 色インデックスの列
  let boxes = [];          // 表示中の箱 {color, filled, leaving, t, slotScrews:[]}
  let flyers = [];         // 飛んでいるねじ
```

- `boxQueue` は **これから出てくる箱の色の列（キュー）** です。先頭から順に取り出して使います
- `boxes` は画面に出ている2つの箱です。`boxes[0]` が左、`boxes[1]` が右で、空いているところは `null` にします
- `flyers` は飛んでいる途中のねじの一覧です

`genLevel()` の1行目で `flyers` も空にします。

```js:game.js
    planks = []; screws = []; flyers = [];
```

`genLevel()` の最後（`order.forEach(...)` の下）に、箱の列を作って最初の2箱を出す処理を足します。色の列 `colorSeq` は3本組ごとの色なので、そのまま箱の順番として使えます。

```js:game.js
    order.forEach((o, i) => {
      const s = { x: o.pt.x, y: o.pt.y, plank: o.plank, color: screwColors[i], where: 'board' };
      o.plank.screws.push(s);
      screws.push(s);
    });
    boxQueue = colorSeq.slice();
    boxes = [];
    fillBoxes();
  }
```

## 箱の位置と、箱を補充する関数

`genLevel()` の **下**（`isCovered()` の上）に追加します。

```js:game.js
  function boxSlotPos(bi, si) {
    const bw = 150, gap = 20;
    const x0 = (W - (bw * 2 + gap)) / 2 + bi * (bw + gap);
    return { x: x0 + 30 + si * 45, y: BOX_Y + 38 };
  }
  function boxRect(bi) {
    const bw = 150, gap = 20;
    return { x: (W - (bw * 2 + gap)) / 2 + bi * (bw + gap), y: BOX_Y, w: bw, h: BOX_H };
  }

  function fillBoxes() {
    for (let i = 0; i < 2; i++) {
      if (!boxes[i] && boxQueue.length) {
        boxes[i] = { color: boxQueue.shift(), slots: [null, null, null], t: 0, leaving: false, enter: 1 };
      }
    }
  }

  function launch(s, fx, fy, tx, ty, done) {
    s.where = 'fly';
    flyers.push({ s, fx, fy, tx, ty, t: 0, dur: 0.28, done });
  }

  function onArriveBox(bi) {
    const b = boxes[bi];
    if (!b || b.leaving) return;
    const full = b.slots.every(x => x && x.where === 'box');
    if (full) {
      b.leaving = true; b.t = 0;
    }
  }
```

- `boxRect(bi)` は箱 `bi`（0 か 1）の四角形、`boxSlotPos(bi, si)` はその箱の中の `si` 番目（0〜2）の穴の中心です。幅 150 の箱を間 20 あけて2つ、画面の真ん中に並べています
- `fillBoxes()` は、空いている場所があって列に箱が残っていれば、`boxQueue.shift()`（先頭を取り出す）で新しい箱を出します。箱は `slots`（3つの穴に入ったねじ）、`leaving`（いっぱいになって出ていく途中か）、`t`（出ていく演出の経過時間）、`enter`（入ってくる演出の残り。1 → 0）を持ちます
- `launch()` は、ねじを (fx, fy) から (tx, ty) まで 0.28 秒で飛ばす予約をします。着いたときに呼んでほしい関数を `done` に渡せるようにしておくと、「箱に着いたらいっぱいか調べる」のような続きの処理を簡単に書けます
- `onArriveBox()` は、ねじが箱に着いたときに呼ばれます。3つの穴が全部 **着いたねじ**（`where === 'box'`）で埋まっていたら、箱を出ていく状態にします

> [!NOTE]
> `b.slots[si] = s` は、ねじを飛ばし **始めた瞬間** に入れます。着くまで待つと、同じ穴に2本目のねじを向かわせてしまうからです。そのかわり「いっぱいか」は、`where === 'box'` で **着いたかどうか** まで確かめています。

## 外したねじを箱へ飛ばす

`pickScrew()` を書きかえます。

```js:game.js
  function pickScrew(s) {
    // 箱へ
    let bi = -1, si = -1;
    for (let i = 0; i < 2; i++) {
      const b = boxes[i];
      if (b && !b.leaving && b.color === s.color) {
        const k = b.slots.indexOf(null);
        if (k >= 0) { bi = i; si = k; break; }
      }
    }
    if (bi < 0) { shake = { s, t: 0 }; return; }
    removeFromPlank(s);
    boxes[bi].slots[si] = s;
    const to = boxSlotPos(bi, si);
    launch(s, s.x, s.y, to.x, to.y, () => onArriveBox(bi));
  }
```

1. 2つの箱のうち、出ていく途中でなく、ねじと同じ色で、空いている穴がある箱を探します。`indexOf(null)` は最初の空き穴の番号で、無ければ `-1` です
2. 合う箱が無ければ、いまはふるわせて終わりです
3. 見つかったら、板から外し、穴を予約して、その穴へ向けて `launch()` します

## 飛ぶ動きと、箱の入れ替え

`update(dt)` の **最初** に、飛んでいるねじを動かす処理を足します。

```js:game.js
  function update(dt) {
    for (let i = flyers.length - 1; i >= 0; i--) {
      const f = flyers[i];
      f.t += dt / f.dur;
      const t = Math.min(1, f.t), e = 1 - Math.pow(1 - t, 3);
      f.s.x = f.fx + (f.tx - f.fx) * e;
      f.s.y = f.fy + (f.ty - f.fy) * e - Math.sin(t * Math.PI) * 30;
      f.s.spin = (f.s.spin || 0) + dt * 18;
      if (t >= 1) {
        f.s.x = f.tx; f.s.y = f.ty;
        flyers.splice(i, 1);
        if (f.ty < TRAY_Y) f.s.where = 'box';
        f.done && f.done();
      }
    }
```

- `t` は 0（出発）から 1（到着）まで進む「進みぐあい」です。`dt / f.dur` ずつ足すと、ちょうど `dur` 秒で 1 になります
- `e = 1 - (1 - t)^3` は **イージング**（動きの緩急）です。最初は速く、着く直前にゆっくりになるので、すっと吸いこまれるように見えます
- `Math.sin(t * Math.PI)` は 0 → 1 → 0 と山なりに変わるので、それを y から引くと **上にふくらんだ弧** をえがいて飛びます
- 着いたら配列から取り除き、行き先が箱（トレイより上）なら `where` を `'box'` にして `done()` を呼びます
- 途中で `splice()` で消しても大丈夫なよう、配列を **後ろから** 回しています

同じ `update(dt)` の、`planks = planks.filter(...)` の行の **下** に、箱の演出を進める処理を足します。

```js:game.js
    for (let i = 0; i < 2; i++) {
      const b = boxes[i];
      if (!b) continue;
      if (b.enter > 0) b.enter = Math.max(0, b.enter - dt * 4);
      if (b.leaving) {
        b.t += dt;
        if (b.t > 0.45) {
          boxes[i] = null;
          fillBoxes();
        }
      }
    }
```

出ていく箱は 0.45 秒たったら `null` にして、`fillBoxes()` で次の箱を入れます。

## 箱と飛ぶねじを描く

`draw()` の最後の `// 落ちる板` の **上** に、箱と「次の箱」を描く処理を追加します。そして `// 落ちる板` のところを、飛んでいるねじも描くように書きかえます。

```js:game.js
    // 箱
    for (let i = 0; i < 2; i++) {
      const r = boxRect(i);
      const b = boxes[i];
      if (!b) {
        ctx.strokeStyle = 'rgba(255,255,255,.18)'; ctx.setLineDash([6, 6]); ctx.lineWidth = 2;
        roundRect(r.x, r.y, r.w, r.h, 12); ctx.stroke(); ctx.setLineDash([]);
        continue;
      }
      const col = COLORS[b.color];
      ctx.save();
      let oy = -b.enter * 60, sc = 1;
      if (b.leaving) { oy = -Math.max(0, b.t - 0.15) * 260; sc = 1 + Math.min(b.t, 0.15); }
      ctx.translate(r.x + r.w / 2, r.y + r.h / 2 + oy);
      ctx.scale(sc, sc);
      ctx.globalAlpha = b.leaving ? Math.max(0, 1 - b.t * 2) : 1 - b.enter;
      ctx.fillStyle = col.d;
      roundRect(-r.w / 2, -r.h / 2 + 4, r.w, r.h, 12); ctx.fill();
      ctx.fillStyle = col.c;
      roundRect(-r.w / 2, -r.h / 2, r.w, r.h, 12); ctx.fill();
      ctx.fillStyle = 'rgba(255,255,255,.25)';
      roundRect(-r.w / 2 + 6, -r.h / 2 + 4, r.w - 12, 10, 5); ctx.fill();
      for (let k = 0; k < 3; k++) {
        const sp = boxSlotPos(i, k);
        ctx.fillStyle = 'rgba(0,0,0,.3)';
        ctx.beginPath(); ctx.arc(sp.x - r.x - r.w / 2, sp.y - r.y - r.h / 2, SR + 1, 0, Math.PI * 2); ctx.fill();
      }
      ctx.restore();
      if (!b.leaving) for (const s of b.slots) if (s && s.where === 'box') drawScrew(s, s.x, s.y + oy, false);
    }
    // 次の箱
    ctx.fillStyle = 'rgba(255,255,255,.6)'; ctx.font = '11px system-ui, sans-serif'; ctx.textAlign = 'right';
    ctx.fillText('のこり ' + boxQueue.length + ' 箱', W - 16, BOX_Y + BOX_H + 13);
    ctx.textAlign = 'left';
    for (let k = 0; k < Math.min(5, boxQueue.length); k++) {
      ctx.fillStyle = COLORS[boxQueue[k]].c;
      roundRect(16 + k * 18, BOX_Y + BOX_H + 4, 14, 9, 3); ctx.fill();
    }

    // 落ちる板・飛ぶねじ
    for (const p of planks) if (p.falling) drawPlank(p);
    for (const f of flyers) drawScrew(f.s, f.s.x, f.s.y, false);
  }
```

- 箱が無い場所には、`setLineDash([6, 6])` で **点線の枠** を描きます。使い終わったら `setLineDash([])` で元の実線に戻します
- 箱は中心に `translate()` してから描くので、`ctx.scale()` で大きくしたり、`oy` で上下にずらしたりが簡単です。入ってくるときは上から下りてきながら現れ（`enter`）、出ていくときは一瞬ふくらんでから上へ飛んで消えます（`leaving`）
- 穴の位置 `sp` は画面全体の座標なので、箱の中心を原点にした座標に直すために `r.x + r.w / 2` などを引いています
- 「次の箱」は、`boxQueue` の先頭5つの色を小さな四角で並べ、右に残りの数を書きます

> [!CHECK] 動作チェック
> - 画面の上に色つきの箱が2つ出ていて、左下に次の箱の色が並び、右に「のこり 〇 箱」と出る
> - 箱と同じ色のねじをタップすると、くるくる回りながら弧をえがいて箱の穴へ飛んでいく
> - 箱に3本入ると、箱がふくらんで上へ飛んで消え、次の色の箱が上から下りてくる
> - どちらの箱とも色が合わないねじをタップすると、ふるえて外れない
