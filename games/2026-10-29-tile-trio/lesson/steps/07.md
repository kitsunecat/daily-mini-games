## このステップのゴール

ゲームとしての「終わり」を作ります。盤面を全部消したら **ステージクリア** でボーナス点が入り、タイルの多い次のステージへ進みます。トレイが7枚でいっぱいになったら **ゲームオーバー** で、オーバーレイに結果を出して「もう一度」遊べるようにします。トレイが残り少なくなったら、赤く点滅して危険を知らせます。

## 部品と状態を追加する

`const startBtn = document.getElementById('start');` の **上** に追加します。

```js:game.js
  const ovTitle = document.getElementById('ov-title');
  const ovText = document.getElementById('ov-text');
```

`let state = ...` の行と、その下の `let stage = ...` の行を次のように書きかえ、`endTimer` を足します。

```js:game.js
  let state = 'title'; // title | play | over
  let stage = 1, score = 0, combo = 0, lastMatch = 0;
  let endTimer = 0;
```

ゲームの状態は次の4つになります。

- `'title'` … タイトル画面
- `'play'` … プレイ中（タイルを取れる）
- `'ending'` … ゲームオーバーやクリアが決まり、演出を待っている短い間（タイルは取れない）
- `'over'` … ゲームオーバー画面

`pointerdown` は `state !== 'play'` のときは何もしないので、`'ending'` や `'over'` の間は自動的にタップを受けつけなくなります。このように **状態を1つの変数で管理** しておくと、「今は何ができるか」をかんたんに切りかえられます。

## 終わりを判定する

`pickTile()` の最後の `updateHud();` の **下** に追加し、そのあとに `stageClear()` と `gameOver()` の2つの関数を追加します。

```js:game.js
    updateHud();

    const alive = tray.filter((it) => !it.dieAt).length;
    if (alive >= TRAY_SIZE) {
      state = 'ending';
      endTimer = setTimeout(gameOver, 500);
    } else if (tiles.length === 0) {
      state = 'ending';
      endTimer = setTimeout(stageClear, 600);
    }
  }

  function stageClear() {
    score += 300 * stage;
    stage++;
    state = 'play';
    beginStage();
    showToast('CLEAR! +' + 300 * (stage - 1));
    setTimeout(() => showToast('STAGE ' + stage), 1000);
  }

  function gameOver() {
    state = 'over';
    updateHud();
    ovTitle.textContent = 'トレイがいっぱい！';
    ovText.innerHTML = 'ステージ ' + stage + ' まで進みました<br>スコア <b>' + score + '</b>';
    startBtn.textContent = 'もう一度';
    overlay.classList.remove('hidden');
  }
```

### 判定のポイント

- トレイの中で **消える予定でない** タイル（`alive`）が7枚になったらゲームオーバーです。3つそろって消える予定のタイルは数えないので、7枚目でちょうど3つそろったときはセーフになります。
- 盤面のタイル（`tiles`）が0枚になったらステージクリアです。
- どちらも `setTimeout` で少し待ってから処理します。すぐに画面を切りかえると、最後のタイルがトレイへ飛んでいく様子や消える演出が見えないからです。待っている間は `state = 'ending'` にして、続けてタップされないようにしています。

### stageClear() と gameOver()

- `stageClear()` は `300 × ステージ番号` のボーナスを足してから `stage` を1つ進め、`beginStage()` で次の盤面を作ります。`buildStage(n)` はステージ番号が大きいほどタイルと絵柄の種類が増えるので、自然にむずかしくなっていきます。
- 「CLEAR! +300」を出したあと、1秒後に「STAGE 2」を出します。`beginStage()` の中でも「STAGE 2」を出していますが、すぐに CLEAR! で上書きされるので、こうして時間差でもう一度出しています。
- `gameOver()` はオーバーレイの見出しと本文を書きかえて表示します。ボタンの文字も「もう一度」にします。ボタンを押すと、これまでと同じ `startGame()` が呼ばれ、ステージ1から始め直します。
- `innerHTML` を使うと `<br>` や `<b>` のようなタグも反映されます。ここに入るのは自分で計算した数字だけなので安全です（ユーザーが入力した文字を `innerHTML` に入れるのは危険なので避けましょう）。

## 仮のストッパーを外す

`pointerdown` の中の、次の1行を **消し** ます。もうトレイがいっぱいになったらゲームオーバーになるので不要です。

```js:game.js
    if (tray.filter((it) => !it.dieAt).length >= TRAY_SIZE) return; // 仮：トレイが満杯なら取らない
```

## トレイがピンチのときに点滅させる

`render()` の中で、トレイのマスを描く `for` 文の **下**（`// 消える組をはずしてポップへ` の上）に追加します。

```js:game.js
    const alive = tray.filter((it) => !it.dieAt).length;
    if (alive >= TRAY_SIZE - 2 && state === 'play') {
      ctx.strokeStyle = 'rgba(255,90,90,' + (0.5 + 0.4 * Math.sin(now / 120)) + ')';
      ctx.lineWidth = 3;
      roundRect(PAD * 0.6, ty, W - PAD * 1.2, T * 1.25, T * 0.25); ctx.stroke();
    }
```

トレイが残り2マス以下になったら、トレイのまわりに赤い枠を描きます。`Math.sin(now / 120)` は時間とともに -1〜1 を行き来する値なので、枠の不透明度が 0.1〜0.9 の間でゆっくり変わり、点滅して見えます。`requestAnimationFrame` が渡してくれる `now` の使いどころです。

> [!CHECK] 動作チェック
> - トレイに5枚以上たまると、トレイのまわりが赤く点滅する
> - トレイが7枚でいっぱいになると、少し間をおいて「トレイがいっぱい！」と、進んだステージ・スコアが表示される
> - 「もう一度」を押すと、ステージ1・スコア0から新しい盤面で始まる
> - 盤面を全部消すと「CLEAR! +300」が出てスコアが増え、続いて「STAGE 2」が出て、タイルの多い盤面になる
