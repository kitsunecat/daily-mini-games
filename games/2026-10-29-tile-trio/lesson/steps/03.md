## このステップのゴール

タイルを **4段** に積み重ねた盤面を作ります。上の段のタイルは下の段と半マスずつずれて重なり、上に何かが乗っているタイルは暗く表示されます。タイルの置き方はランダムで、ページを読みこむたびに違う盤面になります。

## 半マス単位の座標で「置ける場所」を用意する

`const COLS = 6, ROWS = 7;` の行の **下**（`// 絵柄（色と描画関数）` の上）に追加します。

```js:game.js
  // 各段の候補位置（半マス単位、タイルは 2x2 を占める）
  const LAYER_SLOTS = [
    grid(0, 10, 0, 12),
    grid(1, 9, 1, 11),
    grid(2, 8, 2, 10),
    grid(3, 7, 3, 9),
  ];
  function grid(x0, x1, y0, y1) {
    const out = [];
    for (let y = y0; y <= y1; y += 2) for (let x = x0; x <= x1; x += 2) out.push({ x, y });
    return out;
  }
```

### なぜ「半マス単位」なのか

このゲームでは、上の段のタイルが下の段のタイルに **半分ずつ重なる** のが特徴です。そこで座標を「マス」ではなく「半マス」で数えます。タイル1枚は半マス単位で横2・縦2を占めるので、x が 0 のタイルと x が 2 のタイルはぴったり隣どうし、x が 1 のタイルは2枚の間にまたがって乗ります。

- `grid(x0, x1, y0, y1)` は、x0〜x1・y0〜y1 の範囲に **2つおき**（＝1マスおき）に並んだ位置のリストを作ります。
- 1段目は `grid(0, 10, 0, 12)` で、横 6 × 縦 7 = 42 か所。盤面いっぱいに敷きつめられる位置です。
- 2段目は 1 ずつずらした `grid(1, 9, 1, 11)` で、1段目の4枚の角が集まる場所の上に乗ります。3段目・4段目もさらに半マスずつずれて、だんだん小さいピラミッドになります。

## 状態とタイルの中心座標

`let T = 50, W = 0, H = 0, PAD = 0, dpr = 1;` の **下** に追加します。

```js:game.js
  let tiles = [];      // { x, y, layer, type, shake }
```

盤面のタイルは `{ x, y, layer, type, shake }` というオブジェクトの配列で持ちます。`x`・`y` は半マス単位の位置、`layer` は段（0 が1段目）、`type` は絵柄の番号です。`shake` はステップ4で「取れないタイルをタップしたときにゆらす」ために使います。

`function slotCenter(i) {` の **上** に、タイルの中心座標を求める関数を追加します。

```js:game.js
  function tileCenter(t) {
    return { x: PAD + (t.x + 1) * T / 2, y: PAD + (t.y + 1) * T / 2 - t.layer * T * 0.07 };
  }
```

- 半マス単位の `t.x` を `T / 2` 倍するとピクセルになります。`+ 1` は、タイルが2つ分の幅を持つので、その **まん中**（1半マス目）を中心にするためです。
- `- t.layer * T * 0.07` で、上の段ほど少しだけ上に持ち上げて描きます。これだけで「積み重なっている」立体感が出ます。

## 盤面を作る

`// ---- 入力 ----` の **上** に、新しいブロックを追加します。

```js:game.js
  // ---- ステージ生成 ----
  const overlaps = (a, b) => Math.abs(a.x - b.x) < 2 && Math.abs(a.y - b.y) < 2;
  function isBlocked(t) {
    for (const o of tiles) if (o.layer > t.layer && overlaps(o, t)) return true;
    return false;
  }
  function shuffled(arr) {
    const a = arr.slice();
    for (let i = a.length - 1; i > 0; i--) { const j = Math.random() * (i + 1) | 0; [a[i], a[j]] = [a[j], a[i]]; }
    return a;
  }

  function buildStage(n) {
    const total = Math.min(27 + (n - 1) * 9, 66);
    const typeCount = Math.min(4 + n, TYPES.length);
    const ratios = [0.42, 0.3, 0.18, 0.1];
    const placed = [];
    let left = total;
    for (let L = 0; L < LAYER_SLOTS.length && left > 0; L++) {
      const want = L === LAYER_SLOTS.length - 1 ? left : Math.min(left, Math.round(total * ratios[L]));
      let cands = shuffled(LAYER_SLOTS[L]);
      if (L > 0) cands = cands.filter((s) => placed.some((p) => p.layer === L - 1 && overlaps(p, s)));
      const take = cands.slice(0, want);
      take.forEach((s) => placed.push({ x: s.x, y: s.y, layer: L, type: -1, shake: 0 }));
      left -= take.length;
    }
    // 端数は1段目から足りない分を補う
    if (left > 0) {
      const used = new Set(placed.filter((p) => p.layer === 0).map((p) => p.x + ',' + p.y));
      for (const s of shuffled(LAYER_SLOTS[0])) {
        if (left <= 0) break;
        if (!used.has(s.x + ',' + s.y)) { placed.push({ x: s.x, y: s.y, layer: 0, type: -1, shake: 0 }); left--; }
      }
    }
    // 数を3の倍数にそろえる
    while (placed.length % 3) placed.pop();
    tiles = placed;
    assignTypes(typeCount);
  }

  // 仮：絵柄をランダムに割り当てる（ステップ6で「必ず解ける」割り当てに置きかえる）
  function assignTypes(typeCount) {
    tiles.forEach((t) => { t.type = Math.random() * typeCount | 0; });
  }
```

### 重なりと「取れるかどうか」の判定

- `overlaps(a, b)` は、2枚のタイルが重なっているかを調べます。どちらも半マス単位で 2×2 の大きさなので、x の差と y の差が **どちらも 2 未満** なら重なっています。
- `isBlocked(t)` は、`t` より **上の段** に、`t` と重なっているタイルが1枚でもあれば `true`（取れない）を返します。パズルのルールの中心になる、とても大事な関数です。

### 配列をシャッフルする `shuffled()`

うしろから順に「自分を含めた前のどれか」と入れかえていく、**フィッシャー–イェーツのシャッフル** という定番の方法です。どの並び順も同じ確率で出てきます。`arr.slice()` でコピーしてから入れかえるので、元の配列はこわしません。`Math.random() * (i + 1) | 0` の `| 0` は、小数を切り捨てて整数にする短い書き方です。

### `buildStage(n)` の流れ

1. ステージ番号 `n` から、タイルの枚数 `total`（27枚から9枚ずつ増えて最大66枚）と、使う絵柄の種類 `typeCount` を決めます。
2. `ratios` の割合で、各段に何枚置くかを決めます（1段目に 42%、2段目に 30%…）。
3. 候補位置をシャッフルして先頭から必要な数だけ使います。2段目より上は、`filter` で **1つ下の段のタイルと重なる位置だけ** に絞ります。これで、何もない所に浮いたタイルができなくなります。
4. 上の段に置ききれなかった枚数は、1段目のあいている位置で補います。
5. 3枚ずつそろえて消すゲームなので、`while (placed.length % 3) placed.pop();` で枚数を **3の倍数** にします。
6. 最後に `assignTypes()` で絵柄を割り当てます。今は仮に、ランダムな絵柄を1枚ずつ配るだけです（そのため、3枚そろわない絵柄が出ることがあります）。ステップ6で「必ず解ける」割り当てに置きかえます。

## 盤面を描く

`render()` の中の、ステップ2で入れた **仮のコードを2か所とも消し**、`// 仮の目印：盤面になる範囲` の4行もあわせて、次のように書きかえます。`render()` 全体はこうなります。

```js:game.js
  function render() {
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
    ctx.clearRect(0, 0, W, H);

    // 盤面（下の段から順に描く）
    const order = tiles.slice().sort((a, b) => a.layer - b.layer || a.y - b.y || a.x - b.x);
    for (const t of order) {
      const c = tileCenter(t);
      drawTile(c.x, c.y, T, t.type, isBlocked(t));
    }

    // トレイ
    const ty = trayY();
    ctx.fillStyle = '#0c2422';
    roundRect(PAD * 0.6, ty, W - PAD * 1.2, T * 1.25, T * 0.25); ctx.fill();
    ctx.fillStyle = 'rgba(255,255,255,.06)';
    for (let i = 0; i < TRAY_SIZE; i++) {
      const c = slotCenter(i);
      roundRect(c.x - slotW() * 0.44, c.y - slotW() * 0.44, slotW() * 0.88, slotW() * 0.88, T * 0.12); ctx.fill();
    }
  }
```

- 重なったタイルは **下の段から順に** 描かないと、下のタイルが上のタイルを隠してしまいます。そこで `sort` で「段 → y → x」の順に並べかえてから描きます。`a.layer - b.layer || a.y - b.y || ...` は、段が同じ（差が 0）なら次の条件で比べる、という書き方です。
- `tiles.slice()` でコピーしてから並べかえるので、元の `tiles` の順番は変わりません。
- `isBlocked(t)` の結果を `drawTile()` の `dim` に渡して、取れないタイルを暗くします。

最後に、ファイルの最後の `resize();` と `render();` の **間** に `buildStage(1);` を足します。

```js:game.js
  resize();
  buildStage(1);
  render();
```

> [!CHECK] 動作チェック
> - スタートすると、たくさんのタイルが段になって積み重なった盤面が見える
> - 上に別のタイルが少しでも重なっているタイルは暗く、何も乗っていないタイルは明るく表示される
> - ページを再読み込みするたびに、タイルの並び方と絵柄が変わる

> [!NOTE]
> 開発者ツールの Console で確かめたいときは、`buildStage(1);` の下に一時的に `console.log(tiles.length, tiles);` と書いてみましょう。1ステージ目は 27 枚になっているはずです。
