## このステップのゴール

今の盤面は絵柄をランダムに配っているので、「2枚しかない絵柄」が残ったり、どうやっても解けない配置になったりします。このステップでは、**どのステージも必ず全部消せる** ように絵柄を割り当てる方法を作ります。コードは短いですが、パズルゲーム作りでよく使う大事な考え方です。

## 発想：答えを先に作ってから、問題にする

「ランダムに作った盤面が解けるかどうか調べる」のは、とても大変です。そこで逆に考えます。

1. まず絵柄のことは忘れて、タイルの **形（位置と段）だけ** の盤面を作る（これはステップ3でできています）。
2. その盤面で、ルールどおりに「上に何も乗っていないタイル」を1枚ずつ取っていく **取り方を1つ** シミュレーションする。
3. 取った順に3枚ずつ組にして、組ごとに **同じ絵柄** を割り当てる。

こうすると、少なくとも「シミュレーションしたとおりの順に取れば、必ず3枚ずつそろって全部消える」盤面になります。プレイヤーがその順番を見つけられるかどうかが、パズルの面白さになるわけです。

## assignTypes() を置きかえる

ステップ3で書いた仮の `assignTypes()`（コメントの行もふくめて4行）を消して、次のコードに **置きかえ** ます。

```js:game.js
  // 取れる順番を1つシミュレーションし、その順で3枚ずつ同じ絵柄を割り当てる（必ず解ける配置になる）
  function assignTypes(typeCount) {
    const rest = tiles.slice();
    const order = [];
    const saved = tiles;
    while (rest.length) {
      tiles = rest;
      const free = rest.filter((t) => !isBlocked(t));
      const pick = free[Math.random() * free.length | 0];
      order.push(pick);
      rest.splice(rest.indexOf(pick), 1);
    }
    tiles = saved;
    const triples = order.length / 3;
    const types = shuffled(Array.from({ length: triples }, (_, i) => i % typeCount));
    for (let i = 0; i < triples; i++) for (let k = 0; k < 3; k++) order[i * 3 + k].type = types[i];
  }
```

### コードの流れ

- `rest` は「まだ取っていないタイル」のコピーです。ここから1枚ずつ取りのぞきながら、取った順番を `order` に記録していきます。
- `isBlocked()` は `tiles` の中を見て判定する関数です。そこで、シミュレーション中だけ `tiles = rest;` として「残っているタイルだけの盤面」で判定させ、終わったら `tiles = saved;` で元に戻しています。
- `free` は、今取れるタイル（上に何も乗っていないタイル）のリストです。その中から **ランダムに1枚** 選ぶので、毎回ちがう取り方になり、ちがう絵柄の配置になります。上の段から取るほど下の段が取れるようになるので、`free` が空になることはありません。
- `triples` は組の数（タイルの枚数 ÷ 3）です。`i % typeCount` で絵柄の番号を順番に配り、`shuffled()` で組の並びをまぜます。これで、どの絵柄もだいたい同じくらいの組数になります。
- 最後の二重ループで、`order` の 0〜2 番目に1組目の絵柄、3〜5 番目に2組目の絵柄…と割り当てます。`order` の中身は `tiles` のタイルと **同じオブジェクト** なので、`order[...].type` を書きかえると盤面のタイルの絵柄も変わります。

> [!NOTE]
> 「必ず解ける」のは、**正しい順番で取れば** という意味です。トレイは7マスしかないので、何も考えずに取っているとトレイがいっぱいになります。どの絵柄を先に集めるかを考えるのが、このゲームの面白いところです。

> [!CHECK] 動作チェック
> - スタートして盤面の絵柄を数えると、どの絵柄も **3の倍数** の枚数になっている
> - トレイがいっぱいにならないよう考えながら取っていくと、盤面のタイルを全部消せる（全部消しても、まだ何も起きない）
> - 再読み込みするたびに、ちがう絵柄の配置になる
