## このステップのゴール

最後の仕上げです。**ハイスコア** をブラウザに保存して、次に開いたときも BEST に表示されるようにします。タイルを取る・そろう・クリア・ゲームオーバーなどの場面に、ファイルを用意せずに作る **効果音** をつけます。PC 向けに、Enter キーでスタート、S キーでシャッフルできるようにもします。これで完成品と同じ「タイルトリオ」になります。

## ハイスコアを保存する

`const scoreEl = document.getElementById('score');` の **下** に追加します。

```js:game.js
  const bestEl = document.getElementById('best');
```

`const TRAY_SIZE = 7;` の **上** に、保存に使う名前（キー）を追加します。

```js:game.js
  const BEST_KEY = 'tile-trio-best';
```

`let stage = ...` の行に `best = 0` を足します。

```js:game.js
  let stage = 1, score = 0, best = 0, combo = 0, lastMatch = 0, shuffles = 1;
```

`let endTimer = 0;` の **下** に、保存してあるハイスコアを読みこむ処理を追加します。

```js:game.js
  try { best = parseInt(localStorage.getItem(BEST_KEY), 10) || 0; } catch (e) { best = 0; }
  bestEl.textContent = best;
```

`updateHud()` に、スコアがベストを超えたら保存する処理を足します。

```js:game.js
  function updateHud() {
    scoreEl.textContent = score;
    stageNoEl.textContent = stage;
    shuffleLeftEl.textContent = shuffles;
    shuffleBtn.disabled = state !== 'play' || shuffles <= 0;
    if (score > best) {
      best = score;
      bestEl.textContent = best;
      try { localStorage.setItem(BEST_KEY, String(best)); } catch (e) { /* 保存できなくても続行 */ }
    }
  }
```

### localStorage とは

`localStorage` は、ブラウザにちょっとしたデータを保存しておける場所です。`setItem(キー, 値)` で保存し、`getItem(キー)` で読み出します。ページを閉じたり再読み込みしたりしても消えません。

- 保存できるのは **文字列だけ** なので、保存するときは `String(best)`、読み出すときは `parseInt(..., 10)` で数に直します。まだ何も保存されていないときは `getItem` が `null` を返し、`parseInt` は `NaN` になるので、`|| 0` で 0 にしています。
- キーの名前は、同じサイトのほかのゲームとぶつからないように、ゲームの名前を入れておきます。
- プライベートブラウズなど、保存が禁止されている環境ではエラーになることがあります。`try { ... } catch (e) { ... }` で囲んでおくと、保存できなくてもゲームは止まらずに続けられます。

## 効果音を鳴らす `beep()`

ハイスコアを読みこむ処理の **下**（`// ---- レイアウト ----` の上）に追加します。

```js:game.js
  // ---- 音 ----
  let audio = null;
  function beep(freq, dur, type = 'sine', vol = 0.12, slide = 0) {
    try {
      if (!audio) audio = new (window.AudioContext || window.webkitAudioContext)();
      const t = audio.currentTime;
      const o = audio.createOscillator(), g = audio.createGain();
      o.type = type;
      o.frequency.setValueAtTime(freq, t);
      if (slide) o.frequency.exponentialRampToValueAtTime(freq * slide, t + dur);
      g.gain.setValueAtTime(vol, t);
      g.gain.exponentialRampToValueAtTime(0.001, t + dur);
      o.connect(g).connect(audio.destination);
      o.start(t); o.stop(t + dur);
    } catch (e) { /* 音が出せない環境は無視 */ }
  }
```

### Web Audio API

音のファイルを用意しなくても、ブラウザの **Web Audio API** で音を作れます。

- `AudioContext` は音の作業場です。最初に `beep()` が呼ばれたときに1回だけ作ります。ブラウザは「ユーザーが操作する前に音を鳴らす」ことを禁止しているので、タップやクリックをきっかけに作るのが確実です。
- `createOscillator()` は、決まった高さ（`freq` ヘルツ）の音を出し続ける **発振器** です。`type` で音色（`'sine'` はやわらかい音、`'square'` や `'sawtooth'` はゲーム機っぽい音、`'triangle'` はその中間）を選べます。
- `createGain()` は **音量つまみ** です。`exponentialRampToValueAtTime` で、`dur` 秒かけて音量を 0.001 まで下げ、「ポン」と自然に消える音にしています。
- `slide` を指定すると、音の高さも `dur` 秒かけて `slide` 倍に変わります。2 なら上がる音、0.5 なら下がる音になります。
- 発振器 → 音量つまみ → スピーカー（`audio.destination`）の順に `connect` でつなぎ、`start` と `stop` で鳴らす時間を決めます。

## いろいろな場面で鳴らす

次の場所に `beep(...)` を1行ずつ足します。

`startGame()` の最後（`overlay.classList.add('hidden');` の下）に、スタートの音を足します。

```js:game.js
  function startGame() {
    stage = 1; score = 0; combo = 0;
    state = 'play';
    beginStage();
    overlay.classList.add('hidden');
    beep(520, 0.12, 'triangle'); beep(780, 0.16, 'triangle', 0.08);
  }
```

`pickTile()` の中の `tray.splice(idx, 0, ...);` の **下** に、タイルを取った音を足します。

```js:game.js
    beep(660 + Math.random() * 80, 0.07, 'square', 0.05);
```

同じく `pickTile()` の中の、`if (combo >= 2) showToast(...);` の **下** に、そろったときの音を足します。消える演出に合わせて、少し遅らせて鳴らしています。

```js:game.js
      setTimeout(() => { beep(880, 0.1, 'triangle', 0.1); beep(1320, 0.18, 'triangle', 0.07); }, 180);
```

`stageClear()` の `state = 'play';` の **下** に、ドミソのジングルを足します。`setTimeout` で 0.11 秒ずつずらして鳴らすと、和音ではなくメロディーになります。

```js:game.js
    beep(523, 0.12, 'triangle'); setTimeout(() => beep(659, 0.12, 'triangle'), 110); setTimeout(() => beep(784, 0.25, 'triangle'), 220);
```

`gameOver()` を次のように書きかえます。下がっていく低い音を鳴らし、結果にベストも表示します。

```js:game.js
  function gameOver() {
    state = 'over';
    updateHud();
    beep(330, 0.35, 'sawtooth', 0.08, 0.5);
    ovTitle.textContent = 'トレイがいっぱい！';
    ovText.innerHTML = 'ステージ ' + stage + ' まで進みました<br>スコア <b>' + score + '</b>（ベスト ' + best + '）';
    startBtn.textContent = 'もう一度';
    overlay.classList.remove('hidden');
  }
```

`doShuffle()` の `tiles.forEach(...)` の **下** に、上がっていく音を足します。

```js:game.js
    beep(400, 0.25, 'triangle', 0.08, 2);
```

`pointerdown` の中の、取れないタイルをタップしたときの行を書きかえ、低い「ブッ」という音を鳴らします。

```js:game.js
    if (isBlocked(t)) { t.shake = 1; beep(160, 0.08, 'square', 0.04); return; }
```

## キーボードで操作する

`shuffleBtn.addEventListener('click', doShuffle);` の **下** に追加します。

```js:game.js
  window.addEventListener('keydown', (e) => {
    if (e.key === 'Enter' && (state === 'title' || state === 'over')) startGame();
    else if (e.key === 's' || e.key === 'S') doShuffle();
  });
```

`keydown` はキーを押したときのイベントで、`e.key` に押したキーの名前が入ります。Enter はタイトル画面とゲームオーバー画面のときだけスタートに使い、S キーはいつでも `doShuffle()` を呼びます（プレイ中でなければ `doShuffle()` の最初の `if` で何もせずに終わります）。

> [!CHECK] 動作チェック
> - タイルを取ると「ピッ」、3つそろうと「キラン」、暗いタイルをタップすると「ブッ」と鳴る
> - ステージクリアでドミソのジングル、ゲームオーバーで下がっていく音が鳴る
> - ゲームオーバー画面に「（ベスト 〇〇）」と表示され、スコアがベストを超えると BEST の数字も増える
> - ページを再読み込みしても BEST の数字が残っている
> - PC では Enter キーでスタート・もう一度、S キーでシャッフルできる

これで完成です！ 完成品の「タイルトリオ」と同じように遊べるはずです。

## 改造アイデア

> [!TIP]
> **元に戻すボタン**: 最後にトレイへ入れたタイルを1枚だけ盤面に戻す「↩ もどす」ボタンを作ってみましょう。`pickTile()` で取ったタイルのオブジェクト（`x`・`y`・`layer`・`type`）を変数に覚えておき、ボタンが押されたらトレイから取りのぞいて `tiles.push()` で戻せば作れます。シャッフルと同じように、ステージごとの回数制限をつけると面白くなります。

> [!TIP]
> **残り枚数の表示**: 盤面に残っている絵柄ごとの枚数を、画面の上に小さく表示してみましょう。`tiles` を絵柄の番号ごとに数えるだけで作れます。あと何枚でそろうかが分かると、作戦が立てやすくなります。

> [!TIP]
> **新しい絵柄**: `TYPES` に11番目の絵柄（たとえば `poly(6, ...)` の六角形や、`star(4, ...)` のきらめき）を足して、`buildStage()` の `typeCount` の上限を増やしてみましょう。種類が多いほど、トレイの7マスのやりくりがむずかしくなります。

> [!TIP]
> **段の形を変える**: `LAYER_SLOTS` の範囲や段の数を変えると、まったくちがう形の盤面になります。たとえば5段目に `grid(4, 6, 4, 8)` を足すと、より高いピラミッドになります（`ratios` にも5段目の割合を足しましょう）。
