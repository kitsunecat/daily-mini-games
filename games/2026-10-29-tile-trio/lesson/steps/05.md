## このステップのゴール

トレイに同じ絵柄が **3つそろったら消える** ようにします。消えるときは少しだけ間をおいて、ふくらみながら消える演出と、まわりに飛び散る光の粒を出します。消すたびにスコアが入り、続けてすばやく消すと **コンボ** で得点が増えます。画面上の STAGE・SCORE の表示と、「STAGE 1」「2 COMBO!」の文字（トースト）も動かします。

## 画面の部品と状態を追加する

`const startBtn = document.getElementById('start');` の **下** に追加します。

```js:game.js
  const scoreEl = document.getElementById('score');
  const stageNoEl = document.getElementById('stage-no');
  const toast = document.getElementById('toast');
```

`// ---- 状態 ----` の下の、`let tiles = [];` から `let state = ...` までを次のように書きかえます（`pops` の行と、`stage` からの行が増えます）。

```js:game.js
  let tiles = [];      // { x, y, layer, type, shake }
  let tray = [];       // { type, x, y, dieAt }
  let pops = [];       // { type, x, y, t }
  let state = 'title'; // title | play
  let stage = 1, score = 0, combo = 0, lastMatch = 0;
```

- `pops` は「消えていく途中のタイル」の配列です。`t` は演出の進み具合（0 → 1）です。
- `stage` は今のステージ番号、`score` はスコア、`combo` は連続して消した回数、`lastMatch` は最後に消した時刻です。

## スタートとステージ開始を分ける

`// ---- 進行 ----` の下の `startGame()` を、次のように **書きかえ** ます。

```js:game.js
  function startGame() {
    stage = 1; score = 0; combo = 0;
    state = 'play';
    beginStage();
    overlay.classList.add('hidden');
  }
  function beginStage() {
    tray = []; pops = [];
    buildStage(stage);
    updateHud();
    showToast('STAGE ' + stage);
  }
  function updateHud() {
    scoreEl.textContent = score;
    stageNoEl.textContent = stage;
  }
  let toastTimer = 0;
  function showToast(text) {
    toast.textContent = text;
    toast.classList.add('show');
    clearTimeout(toastTimer);
    toastTimer = setTimeout(() => toast.classList.remove('show'), 900);
  }
```

- `startGame()` は「ゲームを最初から始める」処理で、スコアやステージ番号を 1 に戻します。
- `beginStage()` は「今の `stage` の盤面を始める」処理です。ステップ7でステージクリアしたときにも、この関数を呼んで次のステージを始めます。
- `updateHud()` は、画面上の数字（HUD）を今の値に合わせます。数字が変わったら必ずこれを呼ぶ、と決めておくと表示し忘れがなくなります。
- `showToast()` は `#toast` に文字を入れて `show` クラスをつけ、0.9 秒後に外します。`clearTimeout(toastTimer)` で前のタイマーを止めているので、続けて呼んでも前の文字が途中で消えてしまうことはありません。

## 3つそろったら消す

`pickTile()` の最後、`tray.splice(idx, 0, ...);` の行の **下** に追加します。`pickTile()` 全体はこうなります。

```js:game.js
  function pickTile(t) {
    const from = tileCenter(t);
    tiles.splice(tiles.indexOf(t), 1);
    // 同じ絵柄の後ろに差しこむ
    let idx = tray.length;
    for (let i = tray.length - 1; i >= 0; i--) if (tray[i].type === t.type && !tray[i].dieAt) { idx = i + 1; break; }
    tray.splice(idx, 0, { type: t.type, x: from.x, y: from.y, dieAt: 0 });

    const same = tray.filter((it) => it.type === t.type && !it.dieAt);
    const now = performance.now();
    if (same.length >= 3) {
      same.slice(0, 3).forEach((it) => { it.dieAt = now + 200; });
      combo = now - lastMatch < 2500 ? combo + 1 : 1;
      lastMatch = now;
      score += 100 * combo;
      if (combo >= 2) showToast(combo + ' COMBO!');
    }
    updateHud();
  }
```

- `filter` で、トレイの中から **今取ったタイルと同じ絵柄で、まだ消える予定でないもの** を集めます。3枚以上あれば、先頭の3枚に `dieAt`（消える時刻）をつけます。
- すぐに配列から消さず、`performance.now() + 200` という **0.2 秒後の時刻** を入れておくのがポイントです。3枚目がトレイまで飛んでいく様子を見せてから消すと、何がそろったのかが分かりやすくなります。実際に取りのぞくのは描画のほう（後述）です。
- `performance.now()` はページを開いてからの時間（ミリ秒）で、`requestAnimationFrame` が `render(now)` に渡してくれる `now` と同じものさしです。
- 前回そろえてから 2.5 秒以内なら `combo` を 1 増やし、そうでなければ 1 に戻します。得点は `100 × combo` なので、テンポよく消すほど高得点になります。

`pointerdown` の中の仮のストッパーは、消える予定のタイルを数えないように書きかえます。

```js:game.js
    if (tray.filter((it) => !it.dieAt).length >= TRAY_SIZE) return; // 仮：トレイが満杯なら取らない
```

## 消える演出を描く

`render()` の中で、トレイのタイルを描く `const sw = slotW();` の行の **上** に追加します。

```js:game.js
    // 消える組をはずしてポップへ
    for (let i = tray.length - 1; i >= 0; i--) {
      const it = tray[i];
      if (it.dieAt && now >= it.dieAt) { pops.push({ type: it.type, x: it.x, y: it.y, t: 0 }); tray.splice(i, 1); }
    }
```

`dieAt` の時刻を過ぎたタイルを、トレイから `pops` へ移します。ループ中に `splice` で要素を消すときは、**うしろから** 回すのがコツです。前から回すと、消したところで番号がずれて次の要素を飛ばしてしまいます。トレイから消えると、残りのタイルは前のアニメーションの仕組みで自動的に左へつめて動きます。

トレイのタイルを描く `tray.forEach(...)` の **下**（`requestAnimationFrame(render);` の上）に追加します。

```js:game.js
    // ポップ演出
    pops = pops.filter((p) => p.t < 1);
    for (const p of pops) {
      p.t += 0.06;
      ctx.save();
      ctx.globalAlpha = 1 - p.t;
      ctx.translate(p.x, p.y);
      ctx.scale(1 + p.t * 0.6, 1 + p.t * 0.6);
      drawTile(0, 0, sw * 0.95, p.type, false);
      ctx.restore();
      ctx.save();
      ctx.globalAlpha = 1 - p.t;
      ctx.fillStyle = '#ffe27a';
      for (let k = 0; k < 6; k++) {
        const a = k * Math.PI / 3;
        ctx.beginPath();
        ctx.arc(p.x + Math.cos(a) * sw * p.t, p.y + Math.sin(a) * sw * p.t, 3, 0, Math.PI * 2);
        ctx.fill();
      }
      ctx.restore();
    }
```

- `p.t` を毎フレーム 0.06 ずつ増やし、1 になったら `filter` で配列から取りのぞきます。
- `ctx.globalAlpha` は、そのあとに描くものすべての **不透明度** です。`1 - p.t` にすると、だんだん透明になって消えていきます。
- `ctx.scale()` で少しずつ大きくしながら描くと、ふくらんで消えるように見えます。`save()` と `restore()` で、透明度や拡大がほかの描画に影響しないようにしています。
- 6方向（60度ずつ）に小さな黄色い粒を描き、`p.t` が進むほど中心から遠くへ動かしています。
