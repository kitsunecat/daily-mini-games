## このステップのゴール

いよいよタイルを取れるようにします。何も乗っていないタイルをタップすると、タイルが **すーっと動いて** 下のトレイに入ります。トレイでは同じ絵柄が隣どうしに並ぶように差しこみます。上に何か乗っているタイルをタップすると、ぷるぷるとゆれて「取れないよ」と知らせます。

ここから、画面を毎フレーム描き直す **ゲームループ** に切りかえます。

## トレイと状態を用意する

`let tiles = [];` の行の **下** に追加します。

```js:game.js
  let tray = [];       // { type, x, y, dieAt }
  let state = 'title'; // title | play
```

- `tray` はトレイに入ったタイルの配列です。`x`・`y` は「今画面のどこに描いているか」（ピクセル）で、アニメーションに使います。`dieAt` は次のステップで「消える時刻」を入れるために使います。今は常に `0` です。
- `state` はゲームの状態です。`'title'`（タイトル画面）のあいだはタップを受けつけず、`'play'`（プレイ中）だけタイルを取れるようにします。

## ゲームの進行：スタートとタイルを取る処理

`// ---- 入力 ----` の **上** に、新しいブロックを追加します。

```js:game.js
  // ---- 進行 ----
  function startGame() {
    state = 'play';
    tray = [];
    buildStage(1);
    overlay.classList.add('hidden');
  }

  function pickTile(t) {
    const from = tileCenter(t);
    tiles.splice(tiles.indexOf(t), 1);
    // 同じ絵柄の後ろに差しこむ
    let idx = tray.length;
    for (let i = tray.length - 1; i >= 0; i--) if (tray[i].type === t.type && !tray[i].dieAt) { idx = i + 1; break; }
    tray.splice(idx, 0, { type: t.type, x: from.x, y: from.y, dieAt: 0 });
  }
```

- `startGame()` は、状態を `'play'` にし、トレイを空にして盤面を作り直し、オーバーレイを隠します。
- `pickTile(t)` は、タイル `t` を盤面からトレイへ移します。`tiles.splice(tiles.indexOf(t), 1)` で配列から取りのぞき、`tray.splice(idx, 0, ...)` で `idx` 番目に **差しこみ** ます。`splice(位置, 0, 値)` は「何も消さずに値を入れる」使い方です。
- トレイを **うしろから** 見ていき、同じ絵柄が見つかったらその直後を差しこみ位置にします。見つからなければいちばん最後（`tray.length`）です。こうすると同じ絵柄がいつも隣どうしに集まり、3つそろったかどうかが目で見て分かりやすくなります。
- トレイのタイルの最初の `x`・`y` は、盤面にあったときの中心座標（`from`）にしておきます。ここからトレイのマスまで動かすのは、描画のほうで行います。

## タップでタイルを選ぶ

`// ---- 入力 ----` の下にある2行（`startBtn.addEventListener(...)` と `window.addEventListener('resize', ...)`）を、次のように **書きかえ** ます。

```js:game.js
  // ---- 入力 ----
  function hitTest(px, py) {
    let hit = null;
    for (const t of tiles) {
      const c = tileCenter(t);
      if (Math.abs(px - c.x) <= T / 2 && Math.abs(py - c.y) <= T / 2) {
        if (!hit || t.layer > hit.layer) hit = t;
      }
    }
    return hit;
  }
  cv.addEventListener('pointerdown', (e) => {
    e.preventDefault();
    if (state !== 'play') return;
    if (tray.length >= TRAY_SIZE) return; // 仮：トレイが満杯なら取らない
    const r = cv.getBoundingClientRect();
    const t = hitTest(e.clientX - r.left, e.clientY - r.top);
    if (!t) return;
    if (isBlocked(t)) { t.shake = 1; return; }
    pickTile(t);
  });
  startBtn.addEventListener('click', startGame);
  window.addEventListener('resize', resize);
```

### いちばん上のタイルを探す `hitTest()`

タップした点 `(px, py)` が、タイルの中心から上下左右とも `T / 2` 以内なら、そのタイルの上をタップしたことになります。タイルは重なっているので、当てはまるタイルが何枚もあることがあります。その中から **いちばん上の段** のものを選ぶのがポイントです。

### Pointer Events

`pointerdown` は、マウスのクリックでも指のタッチでも同じように届くイベントです。PC とスマホの両方を1つのコードで扱えます。

- `e.clientX`・`e.clientY` は画面全体での位置なので、`cv.getBoundingClientRect()` で取った Canvas の左上の位置を引いて、**Canvas の中での座標** に直します。CSS ピクセル単位なので、`T` で計算した座標とそのまま比べられます。
- 選んだタイルが `isBlocked()` なら、`shake = 1` にしてゆらすだけで取りません。
- `if (tray.length >= TRAY_SIZE) return;` は、トレイが7枚でいっぱいになったら取れなくする **仮のストッパー** です。ステップ7で「ゲームオーバー」に置きかえます。
- ウィンドウの大きさが変わったときは、もう `resize()` だけで大丈夫です。このあと毎フレーム描き直すようになるからです。

## 毎フレーム描き直すゲームループ

`render()` を次のように変えます。まず1行目を `now` を受け取る形に書きかえます。

```js:game.js
  function render(now) {
```

盤面を描く `for` 文の中身を、ゆれる処理つきに **書きかえ** ます。

```js:game.js
    for (const t of order) {
      const c = tileCenter(t);
      let dx = 0;
      if (t.shake > 0) { dx = Math.sin(t.shake * 30) * T * 0.06 * t.shake; t.shake = Math.max(0, t.shake - 0.06); }
      drawTile(c.x + dx, c.y, T, t.type, isBlocked(t));
    }
```

トレイのマスを描く `for` 文の **下**（`render()` の最後）に、トレイのタイルを描く処理と `requestAnimationFrame` を追加します。

```js:game.js
    const sw = slotW();
    tray.forEach((it, i) => {
      const c = slotCenter(i);
      it.x += (c.x - it.x) * 0.3;
      it.y += (c.y - it.y) * 0.3;
      drawTile(it.x, it.y, sw * 0.95, it.type, false);
    });

    requestAnimationFrame(render);
  }
```

最後に、ファイルの最後の3行を次のように書きかえます。

```js:game.js
  // タイトル画面の背景にも盤面を見せる
  resize();
  buildStage(1);
  requestAnimationFrame(render);
```

### requestAnimationFrame とは

`requestAnimationFrame(render)` は「次に画面を書きかえるタイミングで `render` を呼んでね」とブラウザにたのむ命令です。`render()` の最後で毎回たのみ直すことで、1秒に約60回 `render()` が呼ばれ続けます。これが **ゲームループ** です。呼ばれるときには、ページを開いてからの時間（ミリ秒）が引数 `now` に入ってきます（次のステップから使います）。

### すーっと動く仕組み

トレイのタイルは、毎フレーム「今の位置」から「行き先のマスの中心」へ、残りの距離の **30%** だけ近づけています（`it.x += (c.x - it.x) * 0.3`）。近づくほど1回に動く量が小さくなるので、最初は速く、最後はふわっと止まる自然な動きになります。トレイの途中にタイルが差しこまれたときも、うしろのタイルの行き先が1マスずれるので、自動的に横へすべって場所をあけてくれます。

### ゆれる仕組み

`shake` は 1 から始まり、毎フレーム 0.06 ずつ減って 0 になります。`Math.sin(t.shake * 30)` で左右に行ったり来たりする値を作り、`* t.shake` をかけて、だんだんゆれが小さくなるようにしています。

> [!CHECK] 動作チェック
> - スタートして明るいタイルをタップすると、タイルがすーっと動いてトレイに入る
> - 同じ絵柄のタイルを取ると、トレイの中で前に取った同じ絵柄のすぐ右に入り、うしろのタイルが右へずれる
> - 暗いタイルをタップすると、取れずにぷるぷるゆれる
> - 上のタイルを取ると、その下にあったタイルが明るくなって取れるようになる
> - トレイが7枚になると、それ以上は取れない（まだ消えたりゲームオーバーになったりはしない）
