## このステップのゴール

ゲームの主役のタイルを描きます。クリーム色の牌に、色と形の違う **10種類の絵柄**（丸・三角・星・葉っぱ・ひし形・ハート・花・四角・月・十字）をのせます。取れないタイルを暗くする表示も、ここで作っておきます。まずは盤面に10種類を並べ、トレイにも小さいタイルを3枚置いて見た目を確かめます。

## 絵柄を「色と描画関数」の表にまとめる

`const COLS = 6, ROWS = 7;` の行の **下** に追加します。

```js:game.js
  // 絵柄（色と描画関数）
  const TYPES = [
    { c: '#e5484d', draw: (r) => { ctx.beginPath(); ctx.arc(0, 0, r, 0, Math.PI * 2); ctx.fill(); } },
    { c: '#f08c2b', draw: (r) => { poly(3, r * 1.15, -Math.PI / 2, 0.22 * r); } },
    { c: '#e8b500', draw: (r) => { star(5, r * 1.1, r * 0.48); } },
    { c: '#3aa45c', draw: (r) => { ctx.save(); ctx.rotate(-Math.PI / 4); ctx.beginPath(); ctx.ellipse(0, 0, r * 1.1, r * 0.55, 0, 0, Math.PI * 2); ctx.fill(); ctx.restore(); } },
    { c: '#2f7de1', draw: (r) => { poly(4, r * 1.15, -Math.PI / 2, 0); } },
    { c: '#9b5de5', draw: (r) => { heart(r); } },
    { c: '#e05fa8', draw: (r) => { for (let i = 0; i < 5; i++) { const a = i * Math.PI * 2 / 5 - Math.PI / 2; ctx.beginPath(); ctx.arc(Math.cos(a) * r * 0.55, Math.sin(a) * r * 0.55, r * 0.42, 0, Math.PI * 2); ctx.fill(); } ctx.fillStyle = '#ffe27a'; ctx.beginPath(); ctx.arc(0, 0, r * 0.3, 0, Math.PI * 2); ctx.fill(); } },
    { c: '#16a3a3', draw: (r) => { roundRect(-r * 0.85, -r * 0.85, r * 1.7, r * 1.7, r * 0.3); ctx.fill(); } },
    { c: '#a0673a', draw: (r) => { ctx.beginPath(); ctx.arc(0, 0, r, Math.PI * 0.25, Math.PI * 1.75, false); ctx.arc(r * 0.45, -r * 0.1, r * 0.75, Math.PI * 1.6, Math.PI * 0.4, true); ctx.closePath(); ctx.fill(); } },
    { c: '#2c3e8f', draw: (r) => { const w = r * 0.62; ctx.fillRect(-w / 2, -r, w, r * 2); ctx.fillRect(-r, -w / 2, r * 2, w); } },
  ];
  function poly(n, r, rot, round) {
    ctx.beginPath();
    for (let i = 0; i < n; i++) {
      const a = rot + i * Math.PI * 2 / n;
      const x = Math.cos(a) * r, y = Math.sin(a) * r;
      if (i === 0) ctx.moveTo(x, y); else ctx.lineTo(x, y);
    }
    ctx.closePath();
    if (round) { ctx.lineJoin = 'round'; ctx.lineWidth = round; ctx.strokeStyle = ctx.fillStyle; ctx.stroke(); }
    ctx.fill();
  }
  function star(n, ro, ri) {
    ctx.beginPath();
    for (let i = 0; i < n * 2; i++) {
      const a = -Math.PI / 2 + i * Math.PI / n;
      const r = i % 2 ? ri : ro;
      ctx.lineTo(Math.cos(a) * r, Math.sin(a) * r);
    }
    ctx.closePath();
    ctx.fill();
  }
  function heart(r) {
    ctx.beginPath();
    ctx.moveTo(0, r * 0.95);
    ctx.bezierCurveTo(-r * 1.4, 0, -r * 0.9, -r * 1.2, 0, -r * 0.45);
    ctx.bezierCurveTo(r * 0.9, -r * 1.2, r * 1.4, 0, 0, r * 0.95);
    ctx.fill();
  }
```

- `TYPES` は配列で、1つの要素が1種類の絵柄です。`c` が色、`draw` が「中心 `(0, 0)`・大きさ `r` で形を描く関数」です。タイルの種類はこの配列の **番号**（0〜9）で表すので、「同じ絵柄か」は番号を比べるだけで分かります。
- 関数を値としてオブジェクトに入れておくと、あとで `TYPES[type].draw(r)` と書くだけで、種類ごとの描き方を `if` や `switch` で分けずに呼び出せます。
- どの絵柄も **原点 `(0, 0)` を中心** に描いています。描く場所へは、このあと `ctx.translate()` で原点ごと動かします。

形ごとのポイントです。

- `poly(n, r, rot, round)` は正 n 角形です。円周上の点を `Math.cos`・`Math.sin` で求めて `lineTo` で結びます。三角形は `round` を指定して、同じ色の太い線を `lineJoin = 'round'` で重ね、角を丸くしています。
- `star(n, ro, ri)` は星形です。外側の半径 `ro` と内側の半径 `ri` を交互に使って `n * 2` 個の点を結びます。
- `heart(r)` は `bezierCurveTo`（ベジェ曲線）を左右2本つないだハートです。
- 葉っぱは `ctx.rotate()` で45度傾けた `ellipse`（だ円）です。`save()` と `restore()` で回転をその場だけにしています。
- 花は5つの円と黄色い中心、十字は2本の長方形、月は2つの円弧をつないだ形です。

## タイルを描く `drawTile()`

`// ---- 描画 ----` の行の **すぐ下**（`function render()` の上）に追加します。

```js:game.js
  function drawTile(cx, cy, size, type, dim) {
    const s = size * 0.94;
    ctx.save();
    ctx.translate(cx, cy);
    ctx.fillStyle = 'rgba(0,0,0,.28)';
    roundRect(-s / 2, -s / 2 + size * 0.07, s, s, s * 0.18); ctx.fill();
    ctx.fillStyle = '#c9b48a';
    roundRect(-s / 2, -s / 2 + size * 0.035, s, s, s * 0.18); ctx.fill();
    ctx.fillStyle = '#fff8e8';
    roundRect(-s / 2, -s / 2, s, s, s * 0.18); ctx.fill();
    ctx.fillStyle = TYPES[type].c;
    TYPES[type].draw(s * 0.28);
    if (dim) {
      ctx.fillStyle = 'rgba(20,40,38,.5)';
      roundRect(-s / 2, -s / 2, s, s + size * 0.035, s * 0.18); ctx.fill();
    }
    ctx.restore();
  }
```

- `ctx.save()` → `ctx.translate(cx, cy)` で原点をタイルの中心に動かしてから描き、最後に `ctx.restore()` で元に戻します。こうすると、タイルの中の部品はすべて「中心からの距離」で書けて、どこに置くタイルでも同じコードで描けます。
- 1枚のタイルは、影（半透明の黒）→ 側面（茶色）→ 表面（クリーム色）の順に、少しずつ上にずらした角丸の四角を3枚重ねています。これだけで厚みのある牌のように見えます。
- 絵柄の大きさは `s * 0.28` です。タイルの大きさ `size` を変えれば、絵柄も一緒に拡大・縮小されます。トレイの小さなタイルも同じ関数で描けます。
- `dim` が `true` のときは、上から半透明の暗い色をかぶせます。上に別のタイルが乗っていて「まだ取れない」タイルに使います。

## 試しに並べてみる

```js:game.js
    // 仮：10種類のタイルを並べて表示（暗いタイルは「取れない」表示の見本）
```
