## このステップのゴール

下の「🔀 シャッフル」ボタンを動かします。押すと、盤面に残っているタイルの **絵柄だけ** がまぜなおされ、タイルがぷるっとゆれます。ステージごとに1回だけ使える「お助け」で、残り回数はボタンの数字に表示し、使い切ったらボタンを薄くして押せなくします。

## 部品と状態を追加する

`const scoreEl = document.getElementById('score');` の **上** に追加します。

```js:game.js
  const shuffleBtn = document.getElementById('shuffle');
  const shuffleLeftEl = document.getElementById('shuffle-left');
```

`let stage = ...` の行の最後に、シャッフルの残り回数 `shuffles` を足します。

```js:game.js
  let stage = 1, score = 0, combo = 0, lastMatch = 0, shuffles = 1;
```

## ステージごとに回数を戻し、表示する

`beginStage()` の1行目に `shuffles = 1;` を足し、`updateHud()` にボタンの表示を足します。

```js:game.js
  function beginStage() {
    tray = []; pops = []; shuffles = 1;
    buildStage(stage);
    updateHud();
    showToast('STAGE ' + stage);
  }
  function updateHud() {
    scoreEl.textContent = score;
    stageNoEl.textContent = stage;
    shuffleLeftEl.textContent = shuffles;
    shuffleBtn.disabled = state !== 'play' || shuffles <= 0;
  }
```

- `shuffleBtn.disabled` に `true` を入れると、ボタンが押せなくなり、CSS の `#shuffle:disabled` のスタイル（薄い表示）になります。
- プレイ中でないとき（タイトル画面やゲームオーバー中）と、残り回数が0のときに押せなくしています。`updateHud()` は状態が変わるたびに呼ばれるので、ボタンの見た目もいつも正しく保たれます。

## シャッフルする関数

`gameOver()` の **下** に追加します。

```js:game.js
  function doShuffle() {
    if (state !== 'play' || shuffles <= 0 || tiles.length === 0) return;
    shuffles--;
    const types = shuffled(tiles.map((t) => t.type));
    tiles.forEach((t, i) => { t.type = types[i]; t.shake = 1; });
    updateHud();
  }
```

- 盤面のタイルの絵柄だけを `map` で取り出して配列にし、`shuffled()` でまぜてから、もう一度順番に配りなおします。**位置と段はそのまま** で、絵柄だけが入れかわります。
- 絵柄の枚数そのものは変わらないので、どの絵柄も「盤面とトレイを合わせて3の倍数」のままです。ただし、ステップ6で作った「必ず解ける順番」はまぜた時点でくずれるので、シャッフルは運だめしのお助けになります。
- `t.shake = 1` で全部のタイルをゆらして、「まぜた」ことが目で分かるようにしています。ステップ4で作った「取れないタイルをゆらす」仕組みをそのまま使い回しています。
- 最初の `if` で、プレイ中でない・回数がない・盤面が空、のどれかなら何もせずに終わります。ボタンは押せなくしてありますが、次のステップでキーボードからも呼ぶので、関数の中でもしっかり確かめておきます。

## ボタンにつなぐ

`startBtn.addEventListener('click', startGame);` の **下** に追加します。

```js:game.js
  shuffleBtn.addEventListener('click', doShuffle);
```

最後に、ファイルの最後の `buildStage(1);` の **下** に `updateHud();` を足します。タイトル画面のうちから、ボタンが正しく「押せない」状態で表示されるようにするためです。

```js:game.js
  // タイトル画面の背景にも盤面を見せる
  resize();
  buildStage(1);
  updateHud();
  requestAnimationFrame(render);
```

> [!CHECK] 動作チェック
> - タイトル画面では、シャッフルボタンが薄く表示されている
> - スタートするとボタンが押せるようになり、押すと盤面の絵柄がいれかわってタイルがゆれる
> - 1回使うとボタンの数字が 0 になり、薄くなって押せなくなる
> - 次のステージに進むと、また 1 回使えるようになる
