## このステップのゴール

3つのファイルを用意して、画面の土台を作ります。上に「ステージ・スコア・ベスト」の表示、まん中にゲーム盤の **Canvas**、その上に重ねるタイトル画面（オーバーレイ）、いちばん下にシャッフルボタンを置きます。Canvas にはまだタイルはなく、盤面になる範囲の枠と、下の **トレイ**（7マス）だけを描きます。

## index.html

まずは HTML です。このステップで画面の部品はすべてそろえてしまい、以降は `game.js` だけを育てていきます。


- `header` に STAGE・SCORE・BEST の3つの数字を並べます。JavaScript から書き換えるので、数字の `b` 要素に `id` をつけています。
- `#stage` の中に `canvas`・`#toast`（「STAGE 2」「3 COMBO!」などの文字を一瞬出す場所）・`#overlay` を **重ねて** 置きます。オーバーレイはタイトル画面とゲームオーバー画面の両方に使い回します。
- `footer` のシャッフルボタンは、ステップ8で動くようにします。それまでは押しても何も起きません。
- 「← 一覧」のリンク先は自分の環境に合わせて変えてかまいません。
- `<script>` を `body` の最後に置くと、HTML の要素が全部できてからスクリプトが動くので、`getElementById` で確実に要素が取れます。

ポイントは次のとおりです。

- `#app` を縦方向の **Flexbox** にして、`#stage` に `flex: 1` を指定すると「ヘッダーとフッターを除いた残り全部」がゲーム画面になります。`min-height: 0` は、中身が大きくてもはみ出さずに縮めるためのおまじないです。
- `#stage` 自身も Flexbox にして `align-items: center; justify-content: center;` で Canvas を上下左右のまん中に置きます。Canvas の大きさは CSS ではなく JavaScript で決めます（このあと説明します）。
- `#stage` を `position: relative`、`#overlay` を `position: absolute; inset: 6px 8px` にすると、オーバーレイが Canvas のあたりにぴったり重なります。`hidden` クラスをつけ外しするだけで表示を切り替えられます。
- `#toast` はふだん `opacity: 0` で見えず、`show` クラスがつくとふわっと現れます（`transition`）。`pointer-events: none` なので、上に重なっていてもタップのじゃまをしません。
- `touch-action: none` と `user-select: none` は、スマホで連続タップしたときに画面が拡大されたり、文字が選択されたりするのを防ぎます。
- `#shuffle:disabled` は、シャッフルを使い切ったときにボタンを薄くするためのスタイルです。

## game.js

```js:game.js
(() => {
  'use strict';

  const cv = document.getElementById('cv');
  const ctx = cv.getContext('2d');
  const stageEl = document.getElementById('stage');
  const overlay = document.getElementById('overlay');
  const startBtn = document.getElementById('start');

  const TRAY_SIZE = 7;
  const COLS = 6, ROWS = 7; // 1段目のマス数（座標は半マス単位）

  function roundRect(x, y, w, h, r) {
    ctx.beginPath();
    ctx.moveTo(x + r, y);
    ctx.arcTo(x + w, y, x + w, y + h, r);
    ctx.arcTo(x + w, y + h, x, y + h, r);
    ctx.arcTo(x, y + h, x, y, r);
    ctx.arcTo(x, y, x + w, y, r);
    ctx.closePath();
  }

  // ---- 状態 ----
  let T = 50, W = 0, H = 0, PAD = 0, dpr = 1;

  // ---- レイアウト ----
  function resize() {
    const r = stageEl.getBoundingClientRect();
    const aw = r.width - 16, ah = r.height - 12;
    T = Math.max(20, Math.min(aw / 6.5, ah / 9.15));
    PAD = T * 0.25;
    W = Math.floor(T * 6.5); H = Math.floor(T * 9.15);
    dpr = window.devicePixelRatio || 1;
    cv.style.width = W + 'px'; cv.style.height = H + 'px';
    cv.width = Math.floor(W * dpr); cv.height = Math.floor(H * dpr);
  }
  const trayY = () => PAD + ROWS * T + T * 0.4;
  const slotW = () => (W - PAD * 2) / TRAY_SIZE;
  function slotCenter(i) {
    return { x: PAD + slotW() * (i + 0.5), y: trayY() + T * 0.62 };
  }

  // ---- 入力 ----
  startBtn.addEventListener('click', () => overlay.classList.add('hidden'));
  window.addEventListener('resize', () => { resize(); render(); });

  // ---- 描画 ----
  function render() {
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
    ctx.clearRect(0, 0, W, H);

    // 仮の目印：盤面になる範囲
    ctx.strokeStyle = 'rgba(255,255,255,.25)';
    ctx.lineWidth = 2;
    ctx.strokeRect(PAD, PAD, COLS * T, ROWS * T);

    // トレイ
    const ty = trayY();
    ctx.fillStyle = '#0c2422';
    roundRect(PAD * 0.6, ty, W - PAD * 1.2, T * 1.25, T * 0.25); ctx.fill();
    ctx.fillStyle = 'rgba(255,255,255,.06)';
    for (let i = 0; i < TRAY_SIZE; i++) {
      const c = slotCenter(i);
      roundRect(c.x - slotW() * 0.44, c.y - slotW() * 0.44, slotW() * 0.88, slotW() * 0.88, T * 0.12); ctx.fill();
    }
  }

  resize();
  render();
})();
```

### コード全体を `(() => { ... })();` で包む理由

これは **即時実行関数** と呼ばれる書き方です。中で宣言した変数がページ全体（グローバル）に漏れないので、ほかのスクリプトと名前がぶつかりません。`'use strict';` は、宣言し忘れた変数などのミスをエラーとして教えてくれるモードです。

### Canvas とは

`<canvas>` は JavaScript で自由に絵を描ける「キャンバス」です。`getContext('2d')` で取り出した `ctx`（コンテキスト）に `fillRect`（四角を塗る）や `arc`（円を描く）などの命令を出して描きます。座標は左上が `(0, 0)` で、右に行くほど x、**下に行くほど y が大きく** なります。

### マスの大きさ `T` を決める `resize()`

このゲームでは、タイル1枚の大きさ（1マス）を `T` ピクセルとして、盤面もトレイもすべて `T` を基準に配置します。

- 盤面は横 6 マス（`COLS`）× 縦 7 マス（`ROWS`）。左右の余白とトレイの分を足して、Canvas 全体を **横 6.5 マス × 縦 9.15 マス** の大きさにします。
- `#stage` の幅と高さ（`getBoundingClientRect()`）から、「横に 6.5 マス入る大きさ」と「縦に 9.15 マス入る大きさ」の **小さいほう** を `T` にします。こうすると、縦長のスマホでも横長の PC でも、盤面全体がはみ出さずに収まります。
- Canvas には「CSS で見える大きさ」（`cv.style.width`）と「内部の画素数」（`cv.width`）の2つのサイズがあります。高精細な画面では1 CSS ピクセルに複数の物理ピクセルが詰まっている（`devicePixelRatio`）ので、内部の画素数を `W × dpr` にしないと絵がぼやけます。
- `render()` の最初の `ctx.setTransform(dpr, 0, 0, dpr, 0, 0)` で「座標を dpr 倍して描く」設定にします。これで、以降は CSS ピクセル単位の座標を指定するだけでくっきり描けます。
- Canvas の大きさを変えると中身が消えるので、ウィンドウの大きさが変わったら `resize()` のあとに `render()` で描き直しています。

### 位置を計算する小さな関数

- `trayY()` は、トレイの上端の y 座標です。盤面（`ROWS * T`）の下に少しすき間をあけた位置になります。
- `slotW()` はトレイ1マスの幅、`slotCenter(i)` は左から `i` 番目（0 から数える）のマスの中心座標です。
- `T` や `W` は `resize()` で変わるので、定数ではなく **毎回計算する関数** にしておくのがコツです。

### 角の丸い四角 `roundRect()`

`arcTo` は「角を丸めながら次の辺へ進む」命令です。4つの角で `arcTo` を使うと角丸の四角形の **パス**（輪郭）ができます。`roundRect()` はパスを作るだけなので、呼んだあとに `ctx.fill()`（塗る）や `ctx.stroke()`（線を引く）で実際に描きます。タイルもトレイもこの関数で描いていきます。
