## このステップのゴール

世界を **「行」の集まり** としてデータで表し、草地・道路・川がランダムに並ぶ地形を作って描きます。草地には通れない **木** も生やします。まだ車や丸太は出ませんが、スタートを押すたびに新しい地形ができるようになります。

## 行のデータを作る

`// ---------- world ----------` の下の `let camBottom = 0;` を、次のように **書きかえ** ます。

```js:game.js
  // ---------- world ----------
  const rand = (a, b) => a + Math.random() * (b - a);
  let rows, genRow, seg, camBottom;

  function makeRow(r) {
    if (r < 5) return { type: 'grass', trees: r === 0 ? new Set([0, 8]) : new Set() };
    if (seg.left <= 0) {
      const opts = seg.type === 'grass' ? ['road', 'river', 'road'] : ['grass'];
      seg.type = opts[Math.floor(Math.random() * opts.length)];
      const diff = Math.min(1, r / 160);
      seg.left = seg.type === 'grass' ? 1 + Math.floor(Math.random() * 2)
        : seg.type === 'road' ? 1 + Math.floor(Math.random() * (2 + diff * 3))
          : 1 + Math.floor(Math.random() * (2 + diff * 2));
    }
    seg.left--;
    const diff = Math.min(1, r / 160);
    if (seg.type === 'grass') {
      const trees = new Set();
      const n = Math.floor(rand(0, 3 + diff * 2));
      for (let i = 0; i < n; i++) trees.add(Math.floor(Math.random() * COLS));
      return { type: 'grass', trees };
    }
    const dir = Math.random() < 0.5 ? -1 : 1;
    const items = [];
    if (seg.type === 'road') return { type: 'road', dir, items };
    return { type: 'river', dir, items };
  }

  function ensureRows() {
    while (genRow < camBottom + viewRows + 3) { rows.set(genRow, makeRow(genRow)); genRow++; }
    for (const k of rows.keys()) if (k < camBottom - 3) rows.delete(k);
  }

  function reset() {
    rows = new Map(); genRow = 0; seg = { type: 'grass', left: 0 };
    camBottom = 0;
    ensureRows();
  }
```

### 1行 = 1つのオブジェクト

1つの行は `{ type: 'grass', trees }` や `{ type: 'road', dir, items }` のようなオブジェクトです。

- `type` … `'grass'`（草地）・`'road'`（道路）・`'river'`（川）のどれか
- `trees` … 草地で木が生えている列の番号の集まり。**Set** は「同じ値を1つしか持たない集まり」で、`trees.has(3)` のように「3列目に木があるか」をすばやく調べられます
- `dir` … 道路の車や川の丸太が流れる向き（右 `1`・左 `-1`）
- `items` … その行を流れる車や丸太の配列。今は空っぽで、ステップ6・7で中身を作ります

### Map で行番号から行を引く

行はどこまでも続くので、配列ではなく **Map** に「行番号 → 行のデータ」の形でしまいます。`rows.get(12)` で 12 行目を取り出し、`rows.delete(3)` で消せます。行番号がいくら大きくなっても困りません。

### 地形は「かたまり」で作る

道路が1行ずつバラバラに出るより、2〜3車線の道路や幅のある川が続いたほうが「わたる」感じが出ます。そこで `seg`（segment）に **今作っているかたまりの種類 `type` と残り行数 `left`** を覚えておきます。

- `left` が 0 になったら次のかたまりを選びます。草地の次は道路か川（道路が2倍出やすい）、道路や川の次は必ず草地にして、ひと息つける場所を作ります
- `diff` は難しさで、行番号 `r` が 0 のとき 0、160 行目以降は 1 になります。先へ進むほど道路や川が長くなり、木も増えます
- スタート付近（`r < 5`）は木の少ない草地にし、0 行目だけ両端に木を置いています

### 必要なぶんだけ作って、いらない行は捨てる

`ensureRows()` は、画面の上の端より 3 行先まで行を作り（`genRow` は次に作る行番号）、画面の下より 3 行以上うしろの行を消します。こうすると、どれだけ進んでもメモリに置く行は 20 行ほどで済みます。`reset()` は Map と `seg` を作り直して、最初の行を用意します。

## スタートで地形を作り直す

`start()` を、次のように **書きかえ** ます。

```js:game.js
  function start() {
    reset();
    overlay.classList.add('hidden');
    draw();
  }
```

## 行の種類ごとに描く

`// ---------- draw ----------` の `const sy = ...` の行より下を、次のように **書きかえ** ます（`draw()` と最後の3行も変わります）。

```js:game.js
  function drawRow(r, row) {
    const y = sy(r);
    if (row.type === 'grass') {
      ctx.fillStyle = r % 2 ? '#86d073' : '#7cc86a'; ctx.fillRect(0, y, W, CS + 1);
      for (const c of row.trees) {
        const x = c * CS;
        ctx.fillStyle = 'rgba(0,0,0,.15)'; ctx.beginPath(); ctx.ellipse(x + CS * 0.55, y + CS * 0.8, CS * 0.36, CS * 0.14, 0, 0, 7); ctx.fill();
        ctx.fillStyle = '#8b5a2b'; ctx.fillRect(x + CS * 0.43, y + CS * 0.5, CS * 0.14, CS * 0.32);
        ctx.fillStyle = '#2f8f3a'; ctx.beginPath(); ctx.arc(x + CS / 2, y + CS * 0.42, CS * 0.34, 0, 7); ctx.fill();
        ctx.fillStyle = '#45ad4e'; ctx.beginPath(); ctx.arc(x + CS * 0.42, y + CS * 0.34, CS * 0.18, 0, 7); ctx.fill();
      }
    } else if (row.type === 'road') {
      ctx.fillStyle = '#4b5060'; ctx.fillRect(0, y, W, CS + 1);
      const below = rows.get(r - 1);
      if (below && below.type === 'road') {
        ctx.fillStyle = 'rgba(255,255,255,.55)';
        for (let x = CS * 0.2; x < W; x += CS * 1.2) ctx.fillRect(x, y + CS - 1.5, CS * 0.6, 3);
      }
    } else {
      ctx.fillStyle = '#3d9be0'; ctx.fillRect(0, y, W, CS + 1);
    }
  }

  function draw() {
    if (!rows || !CS) return;
    ctx.clearRect(0, 0, W, H);
    const r0 = Math.floor(camBottom) - 1, r1 = Math.ceil(camBottom + viewRows) + 1;
    for (let r = r0; r <= r1; r++) { const row = rows.get(r); if (row) drawRow(r, row); }
  }

  reset();
  window.addEventListener('resize', resize);
  resize();
```

- `drawRow(r, row)` は1行ぶんを描く関数です。`y = sy(r)` で行の上端を求め、種類ごとに塗り分けます
- **木** は、影（うすい黒のだ円）→ 幹（茶色の四角）→ 葉っぱ（緑の円）→ ハイライト（明るい緑の小さな円）の順に重ねて描きます。`ctx.arc(x, y, 半径, 0, 7)` の `7` は「2π（約 6.28）より大きい角度」で、円を一周描くための手抜きの書き方です。`ctx.ellipse()` はだ円版の `arc` です
- **道路** は灰色に塗り、すぐ下の行も道路なら境目に白い点線（車線）を引きます。`rows.get(r - 1)` で下の行を調べています
- **川** は今は青く塗るだけです
- `draw()` は Map から行を取り出して `drawRow()` を呼びます。最初に `rows` が無いときは何もしません
- ファイルの最後で `reset()` を呼び、ページを開いた時点でタイトル画面のうしろに地形が見えるようにします

> [!CHECK] 動作チェック
> - タイトル画面のうしろに、草地・灰色の道路・青い川が並んでいるのがうっすら見える
> - スタートを押すと、下の 5 行は草地で、いちばん下の行の両端に木が生えている
> - 道路が2行以上続くところには白い車線が引かれている
> - ページを再読み込みするたびに、地形が変わる
