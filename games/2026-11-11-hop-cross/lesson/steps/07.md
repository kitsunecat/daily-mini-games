## このステップのゴール

川に **丸太** を流し、ひよこが丸太に乗ると **いっしょに流される** ようにします。丸太のない水に着地したら「川に落ちた」、丸太ごと画面の外まで流されたら「流された」でアウトです。川には波の模様も描きます。

## 経過時間の変数

`let rows, ...` の行と、`reset()` の中の `camBottom = 0; ...` の行を、それぞれ次のように **書きかえ** ます。

```js:game.js
  let rows, genRow, seg, player, camBottom, score, state, deadTimer, deathReason, elapsed;
```

```js:game.js
    camBottom = 0; score = 0; elapsed = 0; deadTimer = 0; deathReason = '';
```

`elapsed` はプレイを始めてからの経過秒数です。川の波を動かすのに使います。

## 川に丸太を並べる

`makeRow()` の最後の1行 `return { type: 'river', dir, items };` を、次のように **書きかえ** ます。

```js:game.js
    const speed = rand(0.8, 1.5) * (1 + diff * 0.6);
    while (pos < COLS + 1) {
      const w = Math.floor(rand(2, 3.99 - diff));
      items.push({ x: pos, w });
      pos += w + rand(1.2, 2.6 + diff);
    }
    return { type: 'river', dir, speed, items, span: Math.max(pos - START, COLS + 4) };
```

道路の車とほとんど同じ作りです。丸太は `{ x, w }`（左端の位置と長さ）で、長さは 2〜3 マス。先へ進むほど丸太が短くなり（`3.99 - diff`）、すき間が広くなって（`2.6 + diff`）難しくなります。

`span` も同じように計算するので、ステップ6で作った `laneMove()` が **そのまま丸太にも使えます**。`update()` ですでに「草地以外の行」を動かしているので、追加の作業はいりません。

## 丸太に乗る・川に落ちる

`update()` の、`if (state !== 'play') return;` から道路の当たり判定の前までを、次のように **書きかえ** ます（`elapsed += dt;` の1行と、`if (player.hop === 0 && ...` のかたまりが増えます）。

```js:game.js
    if (state !== 'play') return;
    elapsed += dt;

    if (player.hop > 0) player.hop = Math.max(0, player.hop - dt);
    const row = rows.get(player.row);
    if (player.hop === 0 && row && row.type === 'river') {
      const log = row.items.find(it => player.x >= it.x - 0.1 && player.x <= it.x + it.w + 0.1);
      if (!log) return die('water');
      player.x += row.dir * row.speed * dt;
      if (player.x < 0.1 || player.x > COLS - 0.1) return die('drift');
    }
    if (row && row.type === 'road' && player.hop < HOP_T * 0.5) {
```

- 川の判定は **着地しているとき**（`hop === 0`）だけ行います。ジャンプ中は空中なので、水の上を飛びこえられます
- `items.find(...)` は、条件を満たす最初の丸太を返します（無ければ `undefined`）。ひよこの中心 `player.x` が丸太の左端から右端のあいだ（左右 0.1 マスずつおまけ）にあれば、丸太に乗っています
- 丸太が無ければ `die('water')` で川に落ちます
- 乗っているときは、ひよこの `x` に **丸太と同じ速さ** を足して、いっしょに流します。`laneMove()` と同じ `row.dir * row.speed * dt` なので、丸太の上でぴったり止まって見えます
- 流されて画面の端まで行ったら `die('drift')` です

ステップ3の `tryMove()` で「川の行では x をマスのまん中にそろえない」ようにしたのを思い出してください。丸太の上は流れているので、ひよこはマスの半端な位置にいます。川の中で左右に動くときは、そこから1マスずつずれます。そして陸に上がると、またマスのまん中にそろいます。

## 川に波と丸太を描く

`drawRow()` の最後、川を青く塗る行の **下** に追加します。

```js:game.js
      ctx.strokeStyle = 'rgba(255,255,255,.25)'; ctx.lineWidth = 2;
      const off = ((elapsed * row.speed * row.dir * 20) % 40 + 40) % 40;
      for (let x = -40 + off; x < W; x += 40) {
        ctx.beginPath(); ctx.moveTo(x, y + CS * 0.5); ctx.quadraticCurveTo(x + 8, y + CS * 0.38, x + 16, y + CS * 0.5); ctx.stroke();
      }
      for (const it of row.items) {
        const x = it.x * CS, w = it.w * CS;
        ctx.fillStyle = '#7a4a22'; rr(x + 2, y + CS * 0.14, w - 4, CS * 0.72, CS * 0.2); ctx.fill();
        ctx.fillStyle = '#9c6532'; rr(x + 4, y + CS * 0.2, w - 8, CS * 0.3, CS * 0.12); ctx.fill();
        ctx.fillStyle = '#c99561'; ctx.beginPath(); ctx.ellipse(x + 6, y + CS / 2, CS * 0.09, CS * 0.3, 0, 0, 7); ctx.fill();
      }
```

### 流れる波

波は 40 ピクセルおきに描いた小さな山（`quadraticCurveTo()` で引く2次ベジェ曲線）です。全部を `off` だけ横にずらして描き、`off` を時間とともに変えると、波が流れて見えます。

- `elapsed * row.speed * row.dir * 20` は、経過時間に応じてどんどん大きく（左向きなら小さく）なる数です
- `% 40` で 40 で割った余りにすると、0〜40 の範囲をくり返します。ただし JavaScript の `%` はマイナスの数だとマイナスの余りを返すので、`+ 40` してもう一度 `% 40` し、必ず 0〜40 に収めています
- 40 ピクセルずれると元と同じ模様になるので、つなぎ目は見えません

丸太は、こげ茶の本体 → 明るい茶色の木目 → 左端の切り口（だ円）の順に描きます。

## 川に落ちたらすうっと消える

`drawPlayer()` の、ステップ6で足した `if (state === 'dying' && deathReason === 'car') ...` の行の **下** に追加します。

```js:game.js
    if (state === 'dying' && deathReason === 'water') ctx.globalAlpha = Math.max(0, deadTimer / 0.7);
```

`ctx.globalAlpha` は、このあと描くものの **不透明度**（1 がくっきり、0 が透明）です。やられ中の残り時間 `deadTimer` に合わせて 1 から 0 に下げるので、ひよこが水に沈むように消えていきます。`ctx.restore()` で元に戻るので、ほかの絵には影響しません。

> [!CHECK] 動作チェック
> - 川に丸太が流れ、白い波の模様も同じ向きに流れている
> - 丸太に跳び乗ると、ひよこが丸太といっしょに流される。丸太の上でも左右に動ける
> - 丸太のない水に着地すると「ポチャーン」と音がしてひよこが消えていき、「川に落ちちゃった…」でゲームオーバーになる
> - 丸太に乗ったまま画面の端まで流されると「丸太ごと流されちゃった…」でゲームオーバーになる
> - 川から草地に上がると、ひよこがマスのまん中にそろう
