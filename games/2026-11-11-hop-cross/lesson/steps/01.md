## このステップのゴール

3つのファイルを用意して、ゲーム画面の土台を作ります。上に「SCORE・BEST」の表示、まん中にゲームを描く **Canvas**（キャンバス）とその上に重ねるタイトル画面（オーバーレイ）、下にひとことヒントを置き、Canvas に **しま模様の草地** を描くところまで進めます。

完成すると、こんなゲームになります。

- 上から見た世界に、横 9 マスの「行」が下から上へどこまでも続いている。行の種類は **草地・道路・川** の3つ
- ひよこはタップ（PC は矢印キー / WASD）で **1マスずつぴょこんとジャンプ** して進む。スワイプで左右・後ろにも動ける
- 道路では左右から **車やトラック** が走ってくる。ぶつかったらアウト
- 川は流れる **丸太** に乗ってわたる。水に落ちたり、丸太ごと画面の外へ流されたらアウト
- 草地の **木** は通れない。画面はじわじわ前へ進むので、もたもたして **画面の下に置いていかれて** もアウト
- 進んだ最高の行数がスコアで、ベストはブラウザに保存される

- `<script>` を `</body>` の直前に置くと、HTML の要素がすべて読みこまれてから JavaScript が動きます

## game.js

最初の `game.js` です。

```js:game.js
(() => {
  'use strict';
  const COLS = 9;

  const cv = document.getElementById('cv');
  const ctx = cv.getContext('2d');
  const stage = document.getElementById('stage');
  const overlay = document.getElementById('overlay');
  const ovTitle = document.getElementById('ov-title');
  const ovText = document.getElementById('ov-text');
  const startBtn = document.getElementById('start');
  const scoreEl = document.getElementById('score');
  const bestEl = document.getElementById('best');

  let W = 0, H = 0, CS = 0, DPR = 1, viewRows = 14;
  function resize() {
    const r = stage.getBoundingClientRect();
    const availW = Math.max(200, r.width - 16), availH = Math.max(260, r.height - 8);
    W = Math.floor(Math.min(availW, availH * 0.62));
    H = Math.floor(Math.min(availH, W * 1.9));
    CS = W / COLS;
    viewRows = H / CS;
    DPR = Math.min(window.devicePixelRatio || 1, 2);
    cv.style.width = W + 'px'; cv.style.height = H + 'px';
    cv.width = Math.round(W * DPR); cv.height = Math.round(H * DPR);
    ctx.setTransform(DPR, 0, 0, DPR, 0, 0);
    draw();
  }

  // ---------- world ----------
  let camBottom = 0;

  // ---------- input ----------
  startBtn.addEventListener('click', start);
  overlay.addEventListener('pointerdown', e => { if (e.target !== startBtn) { e.preventDefault(); start(); } });

  function start() {
    overlay.classList.add('hidden');
  }

  // ---------- draw ----------
  const sy = r => H - (r - camBottom + 1) * CS; // top y of row r

  function draw() {
    if (!CS) return;
    ctx.clearRect(0, 0, W, H);
    const r0 = Math.floor(camBottom) - 1, r1 = Math.ceil(camBottom + viewRows) + 1;
    for (let r = r0; r <= r1; r++) {
      ctx.fillStyle = r % 2 ? '#86d073' : '#7cc86a'; ctx.fillRect(0, sy(r), W, CS + 1);
    }
  }

  window.addEventListener('resize', resize);
  resize();
})();
```

### 全体を `(() => { ... })();` で包む

ファイル全体を **即時実行関数** で包んでいます。中で作った変数がページ全体（グローバル）に漏れないので、名前のぶつかりを気にせずに書けます。`'use strict';` は、うっかりミス（宣言していない変数への代入など）をエラーとして教えてくれるモードです。

### マス目で考える

このゲームの世界は **横 `COLS` = 9 マス** の「行」を、下から上へ積み重ねたものです。

- 横の位置は **マス単位の x**（左端が 0、右端が 9）で表します
- 縦の位置は **行番号 r** で表します。スタート地点が 0 で、**上へ進むほど番号が大きく** なります
- `CS`（cell size）は1マスが画面上で何ピクセルかです。マス単位の値に `CS` を掛けるとピクセルになります

ゲームの計算はすべてマス単位で行い、描くときだけピクセルに直します。こうしておくと、画面の大きさが変わってもゲームの中身は何も変わりません。

### resize() で画面に合わせる

`resize()` は `#stage` の大きさを調べ（`getBoundingClientRect()`）、縦長の Canvas の幅 `W`・高さ `H` を決めます。幅は高さの 0.62 倍まで、高さは幅の 1.9 倍までにして、極端に細長くならないようにしています。

- `CS = W / COLS` で、横 9 マスがちょうど幅いっぱいになります
- `viewRows = H / CS` は、画面に何行ぶん見えるかです
- `devicePixelRatio` は高解像度の画面で 1 ピクセルに何倍の画素があるかを表す数です。Canvas の **中身の画素数**（`cv.width`）だけを DPR 倍にし、**見た目の大きさ**（`cv.style.width`）はそのままにすると、絵がぼやけません。`ctx.setTransform(DPR, 0, 0, DPR, 0, 0)` で「1 と書いたら DPR 画素ぶん」に拡大しておくので、描くときは DPR を気にしなくて済みます

### 行番号を画面の y に変える sy()

Canvas の y は **下へいくほど大きく** なりますが、行番号は **上へいくほど大きく** なります。向きが逆なので、変換する小さな関数 `sy(r)` を用意します。

- `camBottom` は「画面のいちばん下に見えている行番号」です。カメラの位置だと思ってください。今は 0 で固定です
- `sy(r)` は行 `r` の **上端の y** を返します。行 0 は `H - CS`（いちばん下の1マス）、行 1 はその1マス上…となります
- あとで `camBottom` を少しずつ増やすと、すべての行が下へずれて「画面が前へ進む」ように見えます

### draw()

`draw()` は、画面に見えている行（`r0` から `r1`）を1行ずつ塗ります。`r % 2` で偶数行と奇数行の色を変えて、しま模様の草地にしています。`fillRect` の高さを `CS + 1` にしているのは、小数のピクセルで行と行のあいだにすき間が見えないようにするためです。

スタートボタンの `click` と、オーバーレイのどこかを押したとき（`pointerdown`）に `start()` が呼ばれ、オーバーレイに `hidden` クラスをつけて隠します。`ovTitle` などまだ使っていない要素も、先に取り出しておきます。

> [!CHECK] 動作チェック
> - タイトル画面に「ぴょこぴょこ横断」とスタートボタンが出る
> - スタートを押すか、オーバーレイのどこかを押すとタイトル画面が消え、緑のしま模様の草地が見える
> - ブラウザの幅や高さを変えても、縦長の画面が中央に収まる
> - 開発者ツールの Console にエラーが出ていない
