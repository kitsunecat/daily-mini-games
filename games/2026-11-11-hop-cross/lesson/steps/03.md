## このステップのゴール

主人公の **ひよこ** を登場させ、矢印キー / WASD で **1マスずつジャンプ** させます。そのために、毎フレーム「状態を進めて描き直す」**ゲームループ**、キーボード入力、ジャンプのアニメーション、効果音を鳴らす小さな関数を用意します。

## ジャンプの長さ

いちばん上の `const COLS = 9;` の **下** に追加します。

```js:game.js
  const HOP_T = 0.13;        // hop duration (s)
```

1回のジャンプにかける時間（秒）です。0.13 秒で次のマスに着地します。

## 効果音の関数

`resize()` 関数の **下**（`// ---------- world ----------` の上）に追加します。

```js:game.js
  // ---------- audio ----------
  let ac = null;
  function beep(freq, dur, type = 'square', vol = 0.06, slide = 0) {
    try {
      if (!ac) ac = new (window.AudioContext || window.webkitAudioContext)();
      const t = ac.currentTime;
      const o = ac.createOscillator(), g = ac.createGain();
      o.type = type; o.frequency.setValueAtTime(freq, t);
      if (slide) o.frequency.exponentialRampToValueAtTime(Math.max(40, freq + slide), t + dur);
      g.gain.setValueAtTime(vol, t); g.gain.exponentialRampToValueAtTime(0.0001, t + dur);
      o.connect(g); g.connect(ac.destination); o.start(t); o.stop(t + dur + 0.02);
    } catch (e) { /* ignore */ }
  }
```

**Web Audio API** を使って、音のファイルなしで「ピッ」という音を作ります。

- `AudioContext` は音を作る工場のようなものです。ブラウザは「ユーザーが操作するまで音を出さない」決まりなので、最初に鳴らすとき（スタートを押したとき）に作ります
- `createOscillator()` は一定の高さの音を出し続ける発振器、`createGain()` は音量のつまみです。`freq` が音の高さ（Hz）、`type` が音色（`'sine'`・`'square'`・`'triangle'`・`'sawtooth'`）です
- `slide` を指定すると、`dur` 秒かけて音の高さを `freq + slide` まで変えます。上げると「ピョン」、下げると「ボヨーン」という感じになります
- 音量を `exponentialRampToValueAtTime()` でほぼ 0 まで下げると、「プツッ」と切れずに自然に消えます
- 引数の `type = 'square'` のような書き方は **デフォルト引数** で、省略したときに使われる値です
- 全体を `try { ... } catch` で囲み、音が使えない環境でもゲームが止まらないようにしています

## ひよこのデータ

`let rows, genRow, seg, camBottom;` の行を、次のように **書きかえ** ます。

```js:game.js
  let rows, genRow, seg, player, camBottom, state;
```

`reset()` の中の `rows = new Map(); ...` の行の **下** に、ひよこを作る1行を追加します。

```js:game.js
    player = { x: 4.5, row: 1, fx: 4.5, fr: 1, hop: 0, face: 0 };
```

- `x` … 横の位置（マス単位）。マスのまん中は `4.5` のように **0.5 のつく数** になります。9 マスのちょうどまん中が 4.5 です
- `row` … いる行の番号。行 1 からスタートします
- `fx`・`fr` … ジャンプを **始めた場所**（from x / from row）。アニメーションで使います
- `hop` … ジャンプの残り時間。0 なら着地しています
- `face` … 向いている方向（左 `-1`・正面 `0`・右 `1`）。目の位置を少しずらすのに使います
- `state` はゲームの状態で、`'title'`（タイトル画面）・`'play'`（プレイ中）などの文字を入れます

## 1マス動かす tryMove()

`// ---------- input ----------` の **すぐ下** に追加します。

```js:game.js
  function tryMove(dx, dr) {
    if (state !== 'play' || player.hop > 0) return;
    const tr = player.row + dr;
    const row = rows.get(tr);
    if (!row) return;
    let tx = player.x + dx;
    if (row.type !== 'river') tx = Math.floor(tx) + 0.5;
    if (tx < 0.3 || tx > COLS - 0.3) return;
    if (row.type === 'grass' && row.trees.has(Math.floor(tx))) { player.face = dx; return; }
    player.fx = player.x; player.fr = player.row;
    player.x = tx; player.row = tr; player.hop = HOP_T; player.face = dx;
    beep(520 + dr * 80, 0.06, 'square', 0.04, 200);
  }
```

`dx` は横に何マス、`dr` は縦に何行動くかです（前へは `tryMove(0, 1)`、左へは `tryMove(-1, 0)`）。上から順に「動けない理由」を調べ、ひとつでも当てはまったら `return` でやめます。

1. プレイ中でない、またはジャンプの途中なら動かない。ジャンプ中に次の入力を受けつけないことで、1マスずつの動きになります
2. 行き先の行（`tr` = target row）がまだ作られていなければ動かない
3. 行き先が川 **以外** なら、x をマスのまん中（`Math.floor(tx) + 0.5`）にそろえる。川では丸太といっしょに流されて x が半端になるので、陸に上がったときにマスに戻すためです
4. 画面の左右の外に出るなら動かない
5. 草地で、行き先のマス（`Math.floor(tx)` 列目）に木があれば動かない。向きだけ変えます

動けるときは、今の位置を `fx`・`fr` に覚えてから行き先に書きかえ、`hop` にジャンプ時間を入れて音を鳴らします。**位置はすぐに行き先へ変わり**、見た目だけを `hop` を使ってあとから追いつかせる、という作りです。

## キーボード入力

`tryMove()` の **下** に追加します。

```js:game.js
  window.addEventListener('keydown', e => {
    const k = e.key;
    if (state !== 'play') {
      if (k === 'Enter' || k === ' ') { e.preventDefault(); start(); }
      return;
    }
    if (k === 'ArrowUp' || k === 'w' || k === 'W' || k === ' ') tryMove(0, 1);
    else if (k === 'ArrowDown' || k === 's' || k === 'S') tryMove(0, -1);
    else if (k === 'ArrowLeft' || k === 'a' || k === 'A') tryMove(-1, 0);
    else if (k === 'ArrowRight' || k === 'd' || k === 'D') tryMove(1, 0);
    else return;
    e.preventDefault();
  });
```

- `keydown` はキーが押されたときに呼ばれるイベントです。`e.key` に押したキーの名前（`'ArrowUp'`、`'w'`、スペースなら `' '`）が入ります
- このゲームは「押したら1マス」なので、押しっぱなしを覚えておく必要はありません。押されたその場で `tryMove()` を呼びます
- プレイ中でないときは、Enter か Space でスタートできるようにしています
- 使ったキーだけ `e.preventDefault()` で、矢印キーやスペースでページがスクロールするのを止めます。ほかのキーは `else return;` で何もしません

## スタートとゲームループの更新

`start()` を、次のように **書きかえ** ます。さらにその **下** に `update()` を追加します。

```js:game.js
  function start() {
    reset();
    state = 'play';
    overlay.classList.add('hidden');
    beep(660, 0.08, 'triangle', 0.05, 300);
  }

  // ---------- update ----------
  function update(dt) {
    if (state !== 'play') return;

    if (player.hop > 0) player.hop = Math.max(0, player.hop - dt);
  }
```

`update(dt)` は、ゲームの時間を `dt` 秒ぶん進める関数です。今はジャンプの残り時間 `hop` を減らすだけです。`Math.max(0, ...)` で、マイナスにならずにぴったり 0 で止まるようにしています。

## ひよこを描く

`function draw() {` の **上** に追加します。

```js:game.js
  function drawPlayer() {
    let px = player.x, pr = player.row, lift = 0;
    if (player.hop > 0) {
      const t = 1 - player.hop / HOP_T;
      px = player.fx + (player.x - player.fx) * t;
      pr = player.fr + (player.row - player.fr) * t;
      lift = Math.sin(t * Math.PI) * CS * 0.35;
    }
    const cx = px * CS, cy = sy(pr) + CS * 0.55;
    ctx.save();
    ctx.fillStyle = 'rgba(0,0,0,.2)';
    ctx.beginPath(); ctx.ellipse(cx, cy + CS * 0.28, CS * 0.3, CS * 0.1, 0, 0, 7); ctx.fill();
    ctx.translate(cx, cy - lift);
    ctx.fillStyle = '#fff6c9';
    ctx.beginPath(); ctx.ellipse(0, 0, CS * 0.3, CS * 0.3, 0, 0, 7); ctx.fill();
    ctx.fillStyle = '#ffd84a';
    ctx.beginPath(); ctx.ellipse(-player.face * CS * 0.05, CS * 0.05, CS * 0.16, CS * 0.12, 0, 0, 7); ctx.fill();
    ctx.fillStyle = '#ff6f3c';
    ctx.beginPath(); ctx.moveTo(-CS * 0.06, -CS * 0.28); ctx.lineTo(CS * 0.02, -CS * 0.42); ctx.lineTo(CS * 0.08, -CS * 0.27); ctx.fill();
    ctx.fillStyle = '#2b2b2b';
    const ex = player.face * CS * 0.06;
    ctx.beginPath(); ctx.arc(ex - CS * 0.1, -CS * 0.06, CS * 0.04, 0, 7); ctx.arc(ex + CS * 0.1, -CS * 0.06, CS * 0.04, 0, 7); ctx.fill();
    ctx.fillStyle = '#ff9a2e';
    ctx.beginPath(); ctx.moveTo(ex - CS * 0.06, CS * 0.0); ctx.lineTo(ex + CS * 0.06, CS * 0.0); ctx.lineTo(ex, CS * 0.08); ctx.fill();
    ctx.restore();
  }
```

### ジャンプのアニメーション

`t = 1 - hop / HOP_T` は、ジャンプの **進み具合** です。跳んだ瞬間は 0、着地で 1 になります。

- `fx + (x - fx) * t` は、出発点から行き先までを `t` の割合で進んだ位置です。この計算を **線形補間**（lerp）といい、アニメーションでよく使います。行 `pr` も同じように補間するので、行と行の間（例えば 1.5 行目）にも描けます
- `Math.sin(t * Math.PI)` は、`t` が 0 → 0.5 → 1 と進むと 0 → 1 → 0 と山なりに変わります。これに `CS * 0.35` を掛けた `lift` だけ上に持ち上げると、ぴょこんと跳ねて見えます。影は持ち上げないので、地面から離れた感じが出ます

### translate で「ひよこの中心」を原点にする

`ctx.translate(cx, cy - lift)` で座標の原点をひよこの中心に動かすと、体・羽・とさか・目・くちばしを「中心から見た位置」で書けます。`ctx.save()` と `ctx.restore()` で、translate の効果をこの関数の中だけに閉じこめています。

- 体はクリーム色の円、羽は黄色のだ円、とさかは赤い三角、目は黒い小さな円2つ、くちばしはオレンジの三角です
- `face` に合わせて目とくちばし（`ex`）は向いている方へ、羽は反対へ少しずらすので、左右を向いたように見えます

## draw() にひよこを足してループを回す

`draw()` の最後（行を描く `for` の **下**）に `drawPlayer();` を足し、ファイルの最後の3行を、次のように **書きかえ** ます。

```js:game.js
    for (let r = r0; r <= r1; r++) { const row = rows.get(r); if (row) drawRow(r, row); }
    drawPlayer();
  }

  let last = 0;
  function loop(t) {
    const dt = Math.min(0.05, (t - last) / 1000 || 0); last = t;
    update(dt); draw();
    requestAnimationFrame(loop);
  }

  state = 'title';
  reset();
  window.addEventListener('resize', resize);
  resize();
  requestAnimationFrame(loop);
```

### requestAnimationFrame と dt

`requestAnimationFrame(loop)` は「次に画面を描きかえるタイミングで `loop` を呼んでね」とブラウザに頼む関数です。`loop` の最後でまた頼むので、1秒に約60回（画面によっては120回）`loop` が呼ばれ続けます。これが **ゲームループ** です。

- ブラウザは `loop` に今の時刻 `t`（ミリ秒）を渡してくれます。前回との差を 1000 で割ると、前のフレームから何秒たったか（`dt`）が分かります
- 動きを「1フレームに何マス」ではなく「1秒に何マス × dt」で計算すると、60Hz の画面でも 120Hz の画面でも同じ速さになります
- `Math.min(0.05, ...)` は、別のタブを見ていて久しぶりに戻ったときに `dt` が大きくなりすぎてワープしないようにする安全装置です。最初の1回は `last` が 0 なので、`|| 0` で 0 にしています
