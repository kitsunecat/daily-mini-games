## このステップのゴール

ひよこが前へ進むと **カメラが追いかけて画面がスクロール** し、行が上にどんどん作られて、どこまでも進めるようにします。あわせて **進んだ最高の行数をスコア** として表示します。

## スコアの変数

`let rows, genRow, seg, player, camBottom, state;` の行を、次のように **書きかえ** ます。

```js:game.js
  let rows, genRow, seg, player, camBottom, score, state;
```

`reset()` の中の `camBottom = 0;` の行を、次の2行に **書きかえ** ます。

```js:game.js
    camBottom = 0; score = 0;
    scoreEl.textContent = 0;
```

スタートのたびにスコアを 0 に戻し、上の SCORE の表示も 0 にします。

## 前へ進んだらスコアを更新

`tryMove()` の最後、`beep(520 + dr * 80, ...);` の行の **下** に追加します。

```js:game.js
    if (tr - 1 > score) { score = tr - 1; scoreEl.textContent = score; }
```

ひよこは行 1 からスタートするので、「今の行 − 1」が進んだ行数です。**今までの最高より先に進んだときだけ** スコアを増やすので、後ろに下がってからまた前へ進んでも、スコアは水増しされません。

## カメラで追いかける

`update()` の `if (player.hop > 0) ...` の行の **下** に追加します。`update()` 全体はこうなります。

```js:game.js
  function update(dt) {
    if (state !== 'play') return;

    if (player.hop > 0) player.hop = Math.max(0, player.hop - dt);

    // camera
    const target = player.row - 3;
    if (target > camBottom) camBottom += (target - camBottom) * Math.min(1, dt * 4);
    ensureRows();
  }
```

### なめらかに追いかける

カメラの目標 `target` は「ひよこが下から 3 行目あたりに見える位置」です。`camBottom = target` といきなり合わせるとガクッと動くので、**目標までの距離の一部だけ** を毎フレーム近づけます。

- `(target - camBottom) * dt * 4` は、1秒あたり「残りの距離の4倍」の速さで近づく、という意味です。遠いときは速く、近づくほどゆっくりになるので、ふわっと止まります
- `Math.min(1, ...)` は、`dt` が大きいときに目標を通り過ぎないようにするためです
- `target > camBottom` のときだけ動かすので、ひよこが後ろへ下がっても **カメラは戻りません**。後ろに下がりすぎるとひよこが画面の下に隠れますが、これはステップ8で「置いていかれた」ゲームオーバーにします

`camBottom` が小数のまま増えていくので、`sy()` で計算される y もなめらかに変わり、すべての行がすーっと下へ流れて見えます。ステップ1で作った `sy()` と `draw()` の `r0`・`r1` が、ここで効いてきます。

### 行を作り足す

最後の `ensureRows()` で、カメラが進んだぶんだけ上に新しい行を作り、うしろの行を捨てます。これで、どこまでも続く道ができました。

> [!CHECK] 動作チェック
> - 前へ進むと、画面がなめらかにスクロールしてひよこを追いかける
> - どこまで進んでも、上に新しい草地・道路・川が出てくる
> - SCORE が進んだ行数だけ増える。後ろに下がっても減らず、同じ行に戻っても増えない
> - 後ろに下がっても画面は戻らない
> - もう一度スタートすると（ページの再読み込みでも可）、SCORE が 0 に戻る
