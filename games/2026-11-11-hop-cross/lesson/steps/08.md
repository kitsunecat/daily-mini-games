## このステップのゴール

最後の仕上げです。**画面がじわじわ前へ進み**、もたもたして画面の下に置いていかれたらアウトにします。スタート直後の操作ガイドと、画面の下の「危ないよ」の赤いグラデーションも描きます。さらに **ハイスコア（BEST）をブラウザに保存** して、ゲームオーバー画面に「ベスト更新！」を出します。これで完成品の「ぴょこぴょこ横断」と同じものになります。

## localStorage でハイスコアを読みこむ

`const HOP_T = ...` の行の **下** に追加します。

```js:game.js
  const BEST_KEY = 'hop-cross-best';
```

`const bestEl = ...` の行の **下** に追加します。

```js:game.js
  let best = 0;
  try { best = parseInt(localStorage.getItem(BEST_KEY), 10) || 0; } catch (e) { best = 0; }
  bestEl.textContent = best;
```

**localStorage** は、ブラウザにちょっとした文字を保存しておける場所です。ページを閉じても、次に開いたときに残っています。

- `localStorage.getItem(キー)` で読み、`localStorage.setItem(キー, 文字)` で書きます。保存できるのは **文字だけ** なので、読むときに `parseInt(..., 10)` で数に直します
- まだ何も保存されていないと `getItem` は `null` を返し、`parseInt` は `NaN`（数ではない）になります。`|| 0` で、そのときは 0 にします
- プライベートブラウズなどで localStorage が使えないとエラーになることがあるので、`try` で囲んでいます
- キーの名前は、ほかのゲームと混ざらないように `'hop-cross-best'` のようにゲームごとに変えておきましょう

## 動き出したかどうか

`let rows, ...` の行と、`reset()` の中の `camBottom = 0; ...` の行を、それぞれ次のように **書きかえ** ます。

```js:game.js
  let rows, genRow, seg, player, camBottom, score, state, deadTimer, deathReason, elapsed, started;
```

```js:game.js
    camBottom = 0; score = 0; elapsed = 0; started = false; deadTimer = 0; deathReason = '';
```

`tryMove()` の `player.x = tx; player.row = tr; ...` の行の **下** に追加します。

```js:game.js
    started = true;
```

`started` は「最初の1歩を踏み出したか」です。スタートした瞬間から画面が動き出すと、操作を確かめる前に置いていかれてしまうので、**最初のジャンプまでは画面を止めて** おきます。

## 画面をじわじわ進める

`update()` の `// camera` のところを、次のように **書きかえ** ます（2行増えます）。

```js:game.js
    // camera
    const target = player.row - 3;
    if (target > camBottom) camBottom += (target - camBottom) * Math.min(1, dt * 4);
    if (started) camBottom += (0.22 + Math.min(score / 250, 0.45)) * dt;
    if (player.row + 0.5 < camBottom && player.hop === 0) return die('behind');
    ensureRows();
```

- 動き出したら、ひよこを追いかけるのとは別に、**毎秒 0.22 行** ずつカメラを前へ進めます。スコアが上がるほど速くなり、スコア 112 あたりで最大の毎秒 0.67 行になります
- ひよこの行のまん中（`row + 0.5`）が画面の下の端（`camBottom`）より下になったら、置いていかれたのでアウトです。ジャンプ中は判定しないので、ぎりぎりで前に跳べば助かります
- 木にふさがれて回り道をしたり、車を待ったりしているあいだも画面は進むので、「立ち止まって考える時間」に緊張感が生まれます

## ベストを保存してゲームオーバー画面に出す

`gameOver()` を、次のように **書きかえ** ます。

```js:game.js
  function gameOver() {
    state = 'over';
    let isNew = false;
    if (score > best) {
      best = score; isNew = true; bestEl.textContent = best;
      try { localStorage.setItem(BEST_KEY, String(best)); } catch (e) { /* ignore */ }
    }
    const msg = { car: '車にぶつかった！', water: '川に落ちちゃった…', drift: '丸太ごと流されちゃった…', behind: '置いていかれちゃった…' }[deathReason] || '';
    ovTitle.textContent = 'ゲームオーバー';
    ovText.innerHTML = `${msg}<br>スコア <b class="hl">${score}</b>${isNew ? '　<b class="hl">ベスト更新！</b>' : ''}<br>ベスト ${best}`;
    startBtn.textContent = 'もう一度';
    overlay.classList.remove('hidden');
  }
```

今回のスコアがベストを超えていたら、`best` を更新して上の BEST の表示を書きかえ、`localStorage` に保存します。`isNew` が `true` のときだけ、テンプレート文字列の中の `? :`（三項演算子）で「ベスト更新！」を足します。

## 危険ゾーンと操作ガイドを描く

`draw()` の最後、`drawPlayer();` の **下** に追加します。`draw()` 全体はこうなります。

```js:game.js
  function draw() {
    if (!rows || !CS) return;
    ctx.clearRect(0, 0, W, H);
    const r0 = Math.floor(camBottom) - 1, r1 = Math.ceil(camBottom + viewRows) + 1;
    for (let r = r0; r <= r1; r++) { const row = rows.get(r); if (row) drawRow(r, row); }
    drawPlayer();
    if (state === 'play' && started) {
      // danger edge at bottom
      const g = ctx.createLinearGradient(0, H - CS * 0.8, 0, H);
      g.addColorStop(0, 'rgba(255,60,60,0)'); g.addColorStop(1, 'rgba(255,60,60,.35)');
      ctx.fillStyle = g; ctx.fillRect(0, H - CS * 0.8, W, CS * 0.8);
    }
    if (state === 'play' && !started) {
      ctx.fillStyle = 'rgba(0,0,0,.45)'; rr(W / 2 - 92, H * 0.38, 184, 34, 17); ctx.fill();
      ctx.fillStyle = '#fff'; ctx.font = 'bold 15px system-ui, sans-serif'; ctx.textAlign = 'center'; ctx.textBaseline = 'middle';
      ctx.fillText('タップで前にジャンプ！', W / 2, H * 0.38 + 17);
    }
  }
```

- `createLinearGradient(x0, y0, x1, y1)` は、2点のあいだで色がなめらかに変わる **グラデーション** を作ります。`addColorStop()` で、上は透明・下はうすい赤にして、画面の下の端を赤くにじませます。「ここより下に行くと危ない」ことが、説明なしで伝わります
- 動き出す前は、画面のまん中に角丸の黒い帯と「タップで前にジャンプ！」の文字を出します。`textAlign = 'center'` と `textBaseline = 'middle'` で、指定した点が文字のまん中になります

> [!CHECK] 動作チェック
> - スタート直後は「タップで前にジャンプ！」が出ていて、画面は止まっている
> - 最初にジャンプするとガイドが消え、画面の下が赤くにじみ、画面がじわじわ前へ進み始める
> - じっとしていたり後ろに下がったりして画面の下に隠れると、「置いていかれちゃった…」でゲームオーバーになる
> - 初めてのゲームオーバーでは「ベスト更新！」と出て、上の BEST が今回のスコアになる
> - 前より低いスコアで終わると「ベスト 〇〇」と前の記録が出る
> - ページを再読み込みしても、BEST の数字が残っている
> - タイトル画面やゲームオーバー画面で Enter か Space を押してもスタートできる

## 完成！ 改造してみよう

これで完成品の「ぴょこぴょこ横断」と同じものができました。ふり返ると、このゲームは「世界を行のデータで表して、必要なぶんだけ作る」「位置はすぐ変えて、見た目だけ補間で追いかける」「流れる物はループする車線で動かす」「重なりは区間どうしで比べる」の組み合わせでできています。最後に、自分だけのゲームに育てる改造アイデアを紹介します。

> [!TIP]
> **コインを拾う** … 草地の行にときどき `coin: 列番号` を持たせ、ひよこがそのマスに着地したらスコアに +5 してコインを消してみましょう。`tryMove()` で着地先の行を調べれば作れます。描くのは `drawRow()` の草地の部分に黄色い円を足すだけです。

> [!TIP]
> **線路と電車** … 新しい行の種類 `'rail'` を作り、ふだんは何も走らないかわりに、ときどき画面の幅より長い電車がものすごい速さで通りすぎるようにします。通る少し前に線路の端を赤く点滅させると、緊張感のある見せ場になります。`laneMove()` と当たり判定は道路のものがそのまま使えます。

> [!TIP]
> **スイレンの葉** … 川の行のなかに、丸太のかわりに **動かない** 葉っぱが並ぶ種類を作ってみましょう。`speed` を 0 にして、`w` を 1 にするだけで、マスを選んで跳びうつる別の遊びになります。

> [!TIP]
> **難易度の調整** … `makeRow()` の `r / 160`（難しさが最大になる行数）、車の速さ `rand(1.3, 2.4)`、画面が進む速さ `0.22` や `score / 250` を変えると、遊びごたえががらりと変わります。キャラクターの見た目を変えたいときは `drawPlayer()` を書きかえましょう。
