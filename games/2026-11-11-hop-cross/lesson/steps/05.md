## このステップのゴール

スマホでも遊べるように、**タップで前へ、スワイプで左右・後ろへ** 動けるようにします。マウスでも同じように、クリックやドラッグで操作できます。

## Pointer Events でタップとスワイプを見分ける

`tryMove()` の **下**、`window.addEventListener('keydown', ...)` の **上** に追加します。

```js:game.js
  let ptr = null;
  cv.addEventListener('pointerdown', e => { ptr = { x: e.clientX, y: e.clientY }; e.preventDefault(); });
  window.addEventListener('pointerup', e => {
    if (!ptr) return;
    const dx = e.clientX - ptr.x, dy = e.clientY - ptr.y; ptr = null;
    if (Math.hypot(dx, dy) < 24) tryMove(0, 1);
    else if (Math.abs(dx) > Math.abs(dy)) tryMove(dx > 0 ? 1 : -1, 0);
    else tryMove(0, dy < 0 ? 1 : -1);
  });
  window.addEventListener('pointercancel', () => { ptr = null; });
```

### Pointer Events とは

**Pointer Events** は、マウス・指（タッチ）・ペンをまとめて同じ書き方で扱えるイベントです。

- `pointerdown` … 押した（指が触れた）とき
- `pointerup` … 離したとき
- `pointercancel` … 電話がかかってきたなど、途中で操作が取り消されたとき

`e.clientX`・`e.clientY` には、そのときの画面上の位置（ピクセル）が入っています。

### 押した場所と離した場所の差で判定する

1. `pointerdown` で押した位置を `ptr` に覚えます。`e.preventDefault()` で、長押しのメニューやテキスト選択などブラウザの動きを止めます
2. `pointerup` で、離した位置との差 `dx`・`dy` を計算します
3. `Math.hypot(dx, dy)` は2点間の距離（√(dx² + dy²)）です。**24 ピクセル未満ならタップ** とみなして前へ進みます
4. それより長ければスワイプです。`dx` と `dy` の **大きいほう** の向きに動きます。横が大きければ左右、縦が大きければ上下です。画面の y は下へいくほど大きいので、`dy < 0`（上へスワイプ）が前進、`dy > 0`（下へスワイプ）が後退です

`pointerdown` は Canvas（`cv`）で受け取り、`pointerup` は `window` で受け取っています。Canvas の上で押して、指が Canvas の外まで滑ってから離しても、スワイプとして認識できるようにするためです。押していないときに離されたら（`ptr` が `null`）何もしません。

> [!NOTE]
> 「離したとき」に判定するので、スワイプの向きが確実に分かります。そのかわり、押した瞬間ではなく指を離した瞬間にジャンプします。素早くタップを連打すれば、テンポよく進めます。

> [!CHECK] 動作チェック
> - Canvas をクリック（タップ）すると、ひよこが前へ1マス進む
> - 左右にドラッグ（スワイプ）すると左右へ、下へドラッグすると後ろへ、上へドラッグすると前へ動く
> - 開発者ツールのデバイスモード（スマホ表示）でも同じように操作できる
> - キーボードの操作もこれまでどおり使える
