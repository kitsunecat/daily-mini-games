## このステップのゴール

道路に **車とトラック** を走らせ、ひよこがぶつかったら **ゲームオーバー** にします。画面の端から出た車は反対側からまた出てくる「ループする車線」の作り方と、マス単位の **当たり判定** がこのステップの中心です。

## 定数を足す

`const COLS = 9;` の **下** に追加します。

```js:game.js
  const START = -3;          // lane wrap start (cells)
```

`const rand = ...` の行の **下** に、車の色の一覧を追加します。

```js:game.js
  const CAR_COLORS = ['#e94b3c', '#3b82f6', '#f59e0b', '#a855f7', '#10b981', '#f472b6'];
```

## 状態の変数を足す

`let rows, ...` の行と、`reset()` の中の `camBottom = 0; score = 0;` の行を、それぞれ次のように **書きかえ** ます。

```js:game.js
  let rows, genRow, seg, player, camBottom, score, state, deadTimer, deathReason;
```

```js:game.js
    camBottom = 0; score = 0; deadTimer = 0; deathReason = '';
```

- `deadTimer` … ぶつかってからゲームオーバー画面を出すまでの残り時間
- `deathReason` … アウトになった理由（`'car'` など）。画面に出すメッセージや、やられたときの見た目を変えるのに使います

## 道路に車を並べる

`makeRow()` の後半、`const items = [];` から `if (seg.type === 'road') return ...;` までを、次のように **書きかえ** ます。`makeRow()` の最後はこうなります。

```js:game.js
    const dir = Math.random() < 0.5 ? -1 : 1;
    const items = [];
    let pos = START + rand(0, 1.5);
    if (seg.type === 'road') {
      const speed = rand(1.3, 2.4) * (1 + diff * 0.9);
      const truck = Math.random() < 0.3;
      while (pos < COLS + 1) {
        const w = truck ? 2 : 1;
        items.push({ x: pos, w, c: CAR_COLORS[Math.floor(Math.random() * CAR_COLORS.length)] });
        pos += w + rand(2.2 - diff * 0.6, 4.5 - diff);
      }
      return { type: 'road', dir, speed, items, span: Math.max(pos - START, COLS + 4) };
    }
    return { type: 'river', dir, items };
  }
```

- 1台の車は `{ x, w, c }` です。`x` は車の **左端** の位置（マス単位）、`w` は長さ（普通の車は 1 マス、トラックは 2 マス）、`c` は色です
- `speed` は1秒に何マス進むかです。`diff`（難しさ）が上がると最大で約 1.9 倍になります。同じ車線の車はみんな同じ速さなので、追い越しやぶつかり合いは起きません
- 30% の確率で、その車線は全部トラックになります
- 画面の左外 `START`（-3 マス）から右外 `COLS + 1` まで、ランダムなすき間をあけながら車を並べます。先へ進むほどすき間がせまくなります
- `span` は **車線1周の長さ** です。最後の車のうしろまでの長さで、画面の幅より短くならないようにしています

## 車線を動かす laneMove()

`// ---------- update ----------` の **すぐ下**（`update()` の上）に追加します。

```js:game.js
  function laneMove(row, dt) {
    const v = row.dir * row.speed * dt;
    for (const it of row.items) {
      it.x += v;
      if (it.x >= START + row.span) it.x -= row.span;
      else if (it.x < START) it.x += row.span;
    }
  }
```

### ループする車線

車線を、長さ `span` の **輪っか** だと考えます。`START` から `START + span` までの区間を流れていき、右端を超えたら `span` だけ引いて左端に戻し、左端を超えたら `span` だけ足して右端に戻します。

`span` は画面の幅より長いので、ワープする瞬間は必ず画面の外です。プレイヤーには、車が次々と途切れずに流れてくるように見えます。車を作ったり消したりしなくていいので、とてもシンプルです。

## ゲームオーバーの流れ

`start()` の **下** に追加します。

```js:game.js
  function die(reason) {
    if (state !== 'play') return;
    state = 'dying'; deadTimer = 0.7; deathReason = reason;
    if (reason === 'water') beep(300, 0.4, 'sine', 0.08, -220);
    else beep(160, 0.3, 'sawtooth', 0.07, -80);
  }

  function gameOver() {
    state = 'over';
    const msg = { car: '車にぶつかった！', water: '川に落ちちゃった…', drift: '丸太ごと流されちゃった…', behind: '置いていかれちゃった…' }[deathReason] || '';
    ovTitle.textContent = 'ゲームオーバー';
    ovText.innerHTML = `${msg}<br>スコア <b class="hl">${score}</b>`;
    startBtn.textContent = 'もう一度';
    overlay.classList.remove('hidden');
  }
```

ゲームの状態 `state` は `'title'` → `'play'` → `'dying'` → `'over'` → （もう一度）`'play'` と移り変わります。

- `die(reason)` はアウトになった瞬間に呼びます。すぐに画面を切りかえず、`'dying'`（やられ中）にして 0.7 秒だけ待ち、やられた様子を見せます。理由によって音を変えています（川の音はステップ7で使います）
- `gameOver()` は 0.7 秒たったら呼ばれ、オーバーレイの文字を書きかえて表示します
- `msg` は、理由の文字をキーにしたオブジェクトから、メッセージを1つ取り出す書き方です。`if` をいくつも並べるよりすっきり書けます
- `` `...${score}...` `` は **テンプレート文字列** です。`${}` の中に変数を埋めこめます

`startBtn` のクリックやオーバーレイのタップで `start()` が呼ばれるのは、ステップ1から変わりません。`start()` が `reset()` を呼ぶので、そのままリトライになります。

## update() で車を動かし、ぶつかったか調べる

`update()` を、次のように **書きかえ** ます。

```js:game.js
  function update(dt) {
    if (state === 'play' || state === 'dying') {
      for (const row of rows.values()) if (row.type !== 'grass') laneMove(row, dt);
    }
    if (state === 'dying') {
      deadTimer -= dt;
      if (deadTimer <= 0) gameOver();
      return;
    }
    if (state !== 'play') return;

    if (player.hop > 0) player.hop = Math.max(0, player.hop - dt);
    const row = rows.get(player.row);
    if (row && row.type === 'road' && player.hop < HOP_T * 0.5) {
      const px = player.hop > 0 ? player.fx + (player.x - player.fx) * (1 - player.hop / HOP_T) : player.x;
      if (row.items.some(it => px + 0.32 > it.x + 0.05 && px - 0.32 < it.x + it.w - 0.05)) return die('car');
    }

    // camera
    const target = player.row - 3;
    if (target > camBottom) camBottom += (target - camBottom) * Math.min(1, dt * 4);
    ensureRows();
  }
```

- 草地以外の行（道路と、ステップ7からは川も）を `laneMove()` で動かします。やられ中も車は走り続けます
- やられ中は `deadTimer` を減らし、0 になったら `gameOver()` を呼んで、それ以降の処理はしません

### 当たり判定

ひよこがいる行が道路なら、その行の車と重なっていないか調べます。

- ひよこの体を **幅 0.64 マス**（中心 `px` から左右に 0.32）、車を **左右 0.05 ずつ小さめ** の四角だと考えます。横方向だけ比べればいいのは、同じ行にいることがもう分かっているからです
- 2つの区間 [a1, a2] と [b1, b2] が重なる条件は `a2 > b1 && a1 < b2` です。これは「片方が完全に左にある」でも「完全に右にある」でもない、という意味です。ゲームでとてもよく使う形なので覚えておきましょう
- `items.some(...)` は、配列の中に条件を満たすものが **1つでもあれば** `true` を返します
- ジャンプ中は、`hop` が半分を過ぎて（`hop < HOP_T * 0.5`）着地に近づいてから判定します。また位置は補間した `px` を使います。跳び出した瞬間に行き先の車に当たったことにならないようにするためです
- 当たり判定は少し **プレイヤーに甘く** しておくと、「今のはかすっただけ！」という理不尽さが減ります

## 角丸の四角を描く rr()

`const sy = ...` の行の **下** に追加します。

```js:game.js
  function rr(x, y, w, h, r) {
    ctx.beginPath(); ctx.moveTo(x + r, y); ctx.arcTo(x + w, y, x + w, y + h, r); ctx.arcTo(x + w, y + h, x, y + h, r);
    ctx.arcTo(x, y + h, x, y, r); ctx.arcTo(x, y, x + w, y, r); ctx.closePath();
  }
```

**角の丸い四角形** の形（パス）を作る道具です。`arcTo()` で4つの角を半径 `r` で丸めながら一周します。作った形は、このあと `ctx.fill()` で塗ります。

## 車を描く

`drawRow()` の道路の部分、白い車線を引く `if (below && ...) { ... }` の **下** に追加します。

```js:game.js
      for (const it of row.items) {
        const x = it.x * CS, w = it.w * CS;
        ctx.fillStyle = 'rgba(0,0,0,.25)'; rr(x + 3, y + CS * 0.22, w - 4, CS * 0.68, 6); ctx.fill();
        ctx.fillStyle = it.c; rr(x + 2, y + CS * 0.14, w - 4, CS * 0.68, 7); ctx.fill();
        ctx.fillStyle = 'rgba(220,240,255,.85)';
        const wx = row.dir > 0 ? x + w - CS * 0.42 : x + CS * 0.16;
        rr(wx, y + CS * 0.24, CS * 0.26, CS * 0.48, 3); ctx.fill();
        ctx.fillStyle = '#ffe27a';
        const hx = row.dir > 0 ? x + w - 5 : x + 2;
        ctx.fillRect(hx, y + CS * 0.2, 3, CS * 0.12); ctx.fillRect(hx, y + CS * 0.64, 3, CS * 0.12);
      }
```

影 → 車体 → フロントガラス → ヘッドライトの順に描きます。フロントガラス（`wx`）とヘッドライト（`hx`）は、`row.dir` を見て **進む向きの前側** に置くので、車がちゃんと前を向いて走っているように見えます。

## やられたらぺしゃんこに

`drawPlayer()` の `ctx.save();` の **下** に2行を追加します。

```js:game.js
    let squash = 1;
    if (state === 'dying' && deathReason === 'car') squash = 0.35;
```

さらに `ctx.translate(cx, cy - lift);` の **下** に1行を追加します。

```js:game.js
    ctx.scale(1 + (1 - squash) * 0.6, squash);
```

`ctx.scale(横の倍率, 縦の倍率)` で、このあと描くひよこを伸び縮みさせます。車にぶつかったときは縦を 0.35 倍につぶし、横を少し広げて、ぺしゃんこになったように見せます。ふだんは `squash` が 1 なので、`scale(1, 1)` で何も変わりません。translate のあとに scale するので、ひよこの中心を基準に縮みます。

> [!CHECK] 動作チェック
> - スタートすると、道路を色とりどりの車やトラックが左右に走っている。車は進む向きにライトがついている
> - 画面の端から出た車は、しばらくすると反対側からまた出てくる
> - 車にぶつかると「ブッ」と音がしてひよこがぺしゃんこになり、少しして「ゲームオーバー / 車にぶつかった！ / スコア」が出る
> - 「もう一度」を押すと、新しい地形でやり直せる
> - 車の前を横切ってジャンプしても、着地の前にかすっただけならセーフになる
> - 川はまだただの地面です（次のステップで丸太を流します）
