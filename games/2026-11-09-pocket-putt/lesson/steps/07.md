## このステップのゴール

5ホール目から、コースを **左右に往復する赤い壁** を出します。転がっているボールは動く壁で跳ね返り、止まっているボールは壁に押されます。タイミングを見て打つ、という新しい遊びが加わります。

## 円がどの四角形とも重なっていないか

`overlap()` の **下** に追加します。

```js:game.js
  function circleRectFree(cx, cy, r, rects) {
    return rects.every(q => {
      const nx = Math.max(q.x, Math.min(cx, q.x + q.w)), ny = Math.max(q.y, Math.min(cy, q.y + q.h));
      return (cx - nx) ** 2 + (cy - ny) ** 2 > r * r;
    });
  }
```

ステップ5の `collideRect()` の前半と同じ「いちばん近い点」の計算で、円が四角形に重なっていないかを調べます。`every` は「全部の要素が条件を満たせば `true`」です。`** 2` は2乗の書き方です。

## 動く壁を置く

`makeCourse()` の池の行（`if (n >= 4) place('water', ...)`）の **下** に追加します。

```js:game.js
    if (n >= 5) {
      const count = n >= 9 ? 2 : 1;
      for (let i = 0; i < count; i++) {
        const w = rnd(60, 90), y = rnd(170, 400);
        const m = { x: M, y, w, h: 14, min: M, max: W - M - w, speed: rnd(50, 90) * (Math.random() < .5 ? -1 : 1) };
        if (all.some(k => overlap(k, { x: M, y: y - 10, w: W - 2 * M, h: 34 }))) continue;
        m.x = rnd(m.min, m.max); c.movers.push(m); all.push({ x: M, y: y - 10, w: W - 2 * M, h: 34 });
      }
    }
```

- 動く壁は5ホール目から1枚、9ホール目からは2枚です
- 壁のデータには、ふつうの `x, y, w, h` に加えて、動ける範囲 `min`〜`max` と、速さ `speed`（1秒に何ピクセル。マイナスなら左向き）を持たせます。`Math.random() < .5 ? -1 : 1` で、最初に動く向きを半々で決めます
- 動く壁は左右のはしからはしまで動くので、**横一列ぶん**（`x: M` から幅 `W - 2 * M`）を予約して、ほかの障害物と重ならないか調べます。重なっていたら、その壁はあきらめます（`continue`）
- 置けたら、横一列ぶんを `all` に入れておきます。こうすると、9ホール目からの2枚目の動く壁が、1枚目と同じ高さに重なることがありません

## 壁を動かす

`step()` の `time += dt;` の **下** に追加します。

```js:game.js
    for (const m of course ? course.movers : []) {
      m.x += m.speed * dt;
      if (m.x < m.min) { m.x = m.min; m.speed *= -1; }
      if (m.x > m.max) { m.x = m.max; m.speed *= -1; }
    }
```

位置に「速さ × 時間」を足し、はしまで行ったら `speed *= -1` で向きを反対にします。これで左右に往復します。この処理は `state` に関係なく毎フレーム動くので、タイトル画面やカップイン中も壁は動き続けます。

## 止まっているボールを押す

`step()` の `if (state === 'sink') { ... }` と `if (state !== 'roll') return;` の **あいだ** に追加します。

```js:game.js
    if (state === 'aim' && course) {   // 止まっているボールを動く壁が押す
      for (const m of course.movers) if (collideRect(m, 0)) { ball.vx = ball.vy = 0; }
      ball.x = Math.max(M + BALL_R, Math.min(W - M - BALL_R, ball.x));
    }
```

狙っているあいだにボールが動く壁と重なったら、`collideRect()` で壁の外へ押し出します。反射は要らないので `bounce` は 0、速度も 0 のままにします。押されてコースの外に出ないよう、最後に x を外枠の内側にクランプしています。

## 転がっているボールとの当たり判定

サブステップの中、壁の判定の行の **下** に1行追加します。

```js:game.js
      for (const m of course.movers) collideRect(m, 0.9);
```

そして `collideRect()` の最後、`return true;` の **すぐ上** に1行追加します。

```js:game.js
    if (q.speed && state === 'roll') { ball.vx += q.speed * 0.1; }
```

ボールが当たった四角形が `speed` を持っている（＝動く壁）なら、その動きの向きに少しだけボールを流します。動いている壁に当たったときに、ちょっと「はじかれた」感じが出ます。

## 壁の上で止まらないように

`endRoll()` の **最初** に追加します。

```js:game.js
    // 動く壁に重なって止まったら少しずらす
    if (!circleRectFree(ball.x, ball.y, BALL_R, course.movers)) ball.y += BALL_R * 2.5;
```

まれに、ボールが止まった瞬間に動く壁と重なっていることがあります。そのままだと次のフレームで押し出されるのですが、念のため少し下へずらしておきます。

## 動く壁を描く

`draw()` の、木の壁を描く行の **下** に1行追加します。

```js:game.js
      for (const m of course.movers) wallRect(m, '#e46b5f', '#a63a32');
```

ステップ5で `wallRect()` の色を引数にしておいたので、赤い色を渡すだけで描けます。

> [!CHECK] 動作チェック
> - 5ホール目から、赤い壁が左右に往復する（9ホール目からは2枚）
> - 転がっているボールが赤い壁に当たると跳ね返る
> - 止まっているボールに赤い壁が来ると、ボールが押される
