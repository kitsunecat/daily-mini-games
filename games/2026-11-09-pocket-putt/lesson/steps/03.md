## このステップのゴール

いよいよボールを打ちます。画面を **ドラッグして離す** と、引っぱった向きと反対へボールが転がり、だんだん遅くなって止まるようにします。狙っているあいだは、打つ方向の点線と強さのバーを表示します。外枠に当たったら跳ね返ります。

## 照準の変数

`const ball = { ... };` の **下** に追加します。

```js:game.js
  let aim = { active: false, sx: 0, sy: 0, dx: 0, dy: 0 };
```

`aim` はドラッグの情報です。`active` はドラッグ中かどうか、`sx, sy` は押しはじめた場所、`dx, dy` は今指（マウス）がある場所です。

## 画面の座標をコースの座標になおす

`// ---------- 入力 ----------` の **すぐ下**（`ui.start.addEventListener` の上）に追加します。

```js:game.js
  function toLogical(e) {
    const r = cv.getBoundingClientRect();
    return { x: (e.clientX - r.left) / r.width * W, y: (e.clientY - r.top) / r.height * H };
  }
  cv.addEventListener('pointerdown', e => {
    if (state !== 'aim') return;
    e.preventDefault();
    const p = toLogical(e);
    aim = { active: true, sx: p.x, sy: p.y, dx: p.x, dy: p.y };
    try { cv.setPointerCapture(e.pointerId); } catch (err) { /* noop */ }
  });
  cv.addEventListener('pointermove', e => {
    if (!aim.active) return;
    const p = toLogical(e); aim.dx = p.x; aim.dy = p.y;
  });
  function release() {
    if (!aim.active) return;
    const a = currentAim(); aim.active = false;
    if (a && a.ok && a.power > 0.06) shoot(a.dx, a.dy, a.power);
  }
  cv.addEventListener('pointerup', release);
  cv.addEventListener('pointercancel', () => { aim.active = false; });

```

- **Pointer Events**（`pointerdown` / `pointermove` / `pointerup`）は、マウスとタッチの両方をまとめて扱えるイベントです。スマホでも PC でも同じコードで動きます
- `e.clientX, e.clientY` は **ブラウザの画面上** の位置です。`getBoundingClientRect()` で Canvas の位置と大きさを取り、「Canvas の左上から何割の場所か」を求めて `W`・`H` をかけると、**仮想の画面（360 × 600）の座標** になります。描くときと同じ座標で考えられるようになるのがポイントです
- `setPointerCapture` は「指が Canvas の外に出ても、離すまでこの Canvas にイベントを送って」というお願いです。大きく引っぱって画面のはしまで行っても、ちゃんと打てます
- 引っぱりが短すぎるとき（`a.power > 0.06` でないとき）は打ちません。うっかりタップしただけで打ってしまうのを防ぎます
- このゲームでは **画面のどこからドラッグしてもよい** ことにしています。ボールを正確に触らなくていいので、スマホでも狙いやすくなります

## 打つ … shoot()

`updateHud()` の **下** に追加します。

```js:game.js
  function shoot(dx, dy, power) {
    if (state !== 'aim' || balls <= 0) return;
    const len = Math.hypot(dx, dy) || 1;
    const sp = Math.pow(power, 1.6) * MAX_SPEED; // 弱いパットを細かく調整できるように
    ball.vx = dx / len * sp; ball.vy = dy / len * sp;
    ball.lastX = ball.x; ball.lastY = ball.y;
    balls--; strokes++;
    state = 'roll';
    updateHud();
  }
```

- `(dx, dy)` は打つ向き、`power` は 0〜1 の強さです
- `Math.hypot(dx, dy)` は矢印の長さ（√(dx² + dy²)）です。`dx / len, dy / len` で **長さ 1 の向きだけの矢印**（単位ベクトル）になり、それに速さ `sp` をかけると速度になります
- `Math.pow(power, 1.6)` は power の 1.6 乗です。0.5 なら約 0.33 になるので、**弱い打球ほど細かく** 調整できます。グリーン上の短いパットを打ちやすくする工夫です
- 打った場所を `lastX, lastY` に覚えておき、残り打数を1減らし、このホールの打数を1増やして、状態を `'roll'` にします

## 転がす … step()

`step()` を **まるごと書きかえ**、その下に `endRoll()` を追加します。

```js:game.js
  function step(dt) {
    time += dt;
    if (state !== 'roll') return;

    const sub = 6, h = dt / sub;
    for (let i = 0; i < sub; i++) {
      const k = Math.exp(-0.95 * h);               // 指数減衰
      ball.vx *= k; ball.vy *= k;
      const sp = Math.hypot(ball.vx, ball.vy);
      if (sp > 0) {                                  // 一定の転がり抵抗
        const dec = Math.min(sp, 70 * h);
        ball.vx -= ball.vx / sp * dec; ball.vy -= ball.vy / sp * dec;
      }
      ball.x += ball.vx * h; ball.y += ball.vy * h;

      // 外枠
      if (ball.x < M + BALL_R) { ball.x = M + BALL_R; ball.vx = Math.abs(ball.vx) * 0.8; }
      if (ball.x > W - M - BALL_R) { ball.x = W - M - BALL_R; ball.vx = -Math.abs(ball.vx) * 0.8; }
      if (ball.y < M + BALL_R) { ball.y = M + BALL_R; ball.vy = Math.abs(ball.vy) * 0.8; }
      if (ball.y > H - M - BALL_R) { ball.y = H - M - BALL_R; ball.vy = -Math.abs(ball.vy) * 0.8; }
    }
    if (Math.hypot(ball.vx, ball.vy) < 6) { ball.vx = ball.vy = 0; endRoll(); }
  }

  function endRoll() {
    state = 'aim';
  }
```

### 位置 = 位置 + 速度 × 時間

いちばん大事なのは `ball.x += ball.vx * h` の行です。速度は「1秒に何ピクセル進むか」なので、それに経過時間をかければ、その間に進んだ距離になります。

### サブステップ

1フレーム（約 1/60 秒）をさらに **6つに分けて**（`sub = 6`、`h = dt / 6`）少しずつ動かしています。強く打つとボールは1フレームで15ピクセル以上進むので、一気に動かすと細い壁をすり抜けたり、カップの上を飛びこえたりしてしまいます。細かく刻めば、そういう取りこぼしが減ります。

### 摩擦（だんだん遅くなる）

摩擦は2種類を組み合わせています。

- **指数減衰** … `Math.exp(-0.95 * h)` は 1 より少し小さい数です。毎回速度にかけると、速いときほど大きく減ります。`exp` を使うと、サブステップの分け方を変えても減り方が同じになります
- **一定の転がり抵抗** … 速さに関係なく、1秒あたり 70 ずつ減らします。指数減衰だけだと、遅くなったボールがいつまでもじわじわ転がり続けるので、最後にピタッと止めるための仕上げです。`Math.min(sp, ...)` で、減らしすぎて逆向きに動き出さないようにしています

速さが 6 未満になったら止まったとみなし、`endRoll()` で狙う状態にもどします。

### 外枠で跳ね返る

ボールの中心が「外枠の内側から半径ぶん」より外に出たら、位置を内側にもどし、その方向の速度を **反対向き** にします。`Math.abs()`（絶対値）を使って「左の壁なら必ず右向き」と決めているので、壁にめりこんだまま向きが行ったり来たりすることがありません。`* 0.8` は、跳ね返るたびに少し勢いが落ちる分です。

## 照準を描く

`draw()` の旗の `ctx.fillText(...)` の **下**（`if (course) { ... }` の閉じかっこの手前）に1行追加します。

```js:game.js

      if (state === 'aim') drawAim();
```

そして `draw()` の **下** に、`currentAim()` と `drawAim()` を追加します。

```js:game.js
  function currentAim() {
    if (aim.active) {
      const dx = aim.sx - aim.dx, dy = aim.sy - aim.dy, len = Math.hypot(dx, dy);
      return { dx, dy, power: Math.min(1, len / MAX_PULL), ok: len > 8 };
    }
    return null;
  }

  function drawAim() {
    const a = currentAim();
    if (!a) {
      // 待機中のガイド
      const p = 0.5 + 0.5 * Math.sin(time * 4);
      ctx.strokeStyle = `rgba(255,255,255,${0.3 + p * 0.4})`; ctx.lineWidth = 2;
      ctx.beginPath(); ctx.arc(ball.x, ball.y, BALL_R + 6 + p * 4, 0, Math.PI * 2); ctx.stroke();
      return;
    }
    if (!a.ok) return;
    const len = Math.hypot(a.dx, a.dy) || 1, ux = a.dx / len, uy = a.dy / len;
    const L = 30 + a.power * 150;
    const col = a.power < 0.5 ? `rgb(${Math.round(120 + a.power * 270)},230,90)` : `rgb(255,${Math.round(230 - (a.power - 0.5) * 360)},70)`;
    ctx.fillStyle = col;
    for (let d = BALL_R + 8; d < L; d += 11) {
      ctx.globalAlpha = 1 - d / (L + 30);
      ctx.beginPath(); ctx.arc(ball.x + ux * d, ball.y + uy * d, 3, 0, Math.PI * 2); ctx.fill();
    }
    ctx.globalAlpha = 1;
    // 引っぱり側の線
    ctx.strokeStyle = 'rgba(255,255,255,.5)'; ctx.lineWidth = 2;
    ctx.beginPath(); ctx.moveTo(ball.x, ball.y); ctx.lineTo(ball.x - ux * a.power * 50, ball.y - uy * a.power * 50); ctx.stroke();
    // パワーバー
    const bx = W - M - 14, by = H - M - 110;
    ctx.fillStyle = 'rgba(0,0,0,.35)'; rrect(bx, by, 8, 100, 4); ctx.fill();
    ctx.fillStyle = col; rrect(bx, by + 100 * (1 - a.power), 8, 100 * a.power, 4); ctx.fill();
  }
```

- `currentAim()` は、今のドラッグから「打つ向き・強さ」を計算します。**押しはじめた場所 − 今の場所** なので、下に引っぱると上向きになります。これがパチンコ（スリングショット）式の操作です。引っぱりの長さを `MAX_PULL`（150）で割った値が強さで、`Math.min(1, ...)` で 1 を超えないようにします。8 ピクセル未満なら `ok: false` で、まだ照準を出しません
- ドラッグしていないときは、ボールのまわりに **ふくらんだり縮んだりする白い輪** を描いて「ここを打つよ」と知らせます
- 打つ向きには点を並べます。強いほど点の列が長くなり（`L`）、先へ行くほど `globalAlpha`（透明度）を下げてうすくしています
- 色は強さで変わります。弱いと黄緑、強くなるにつれてオレンジ〜赤です。`rgb()` の数字を計算で作っています
- 反対側には「引っぱっているゴム」のような白い線、右下には **パワーバー** を描きます

> [!NOTE]
> このステップでは、残り打数が 0 になるとそれ以上打てなくなり、止まったままになります。ゲームオーバーの処理はステップ8で作ります。

> [!CHECK] 動作チェック
> - 狙う状態のとき、ボールのまわりで白い輪がふわふわ動く
> - 画面のどこかを押して下へ引っぱると、ボールから上へ点線がのび、右下のパワーバーが伸びる。引っぱるほど点線が長く、色が黄緑→赤に変わる
> - 離すとボールが転がり、だんだん遅くなって止まる。外枠に当たると跳ね返る
> - 打つたびに「残り打数」が1減り、「今の打数」が1増える
