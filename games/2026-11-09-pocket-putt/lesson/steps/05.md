## このステップのゴール

コースに **木の壁** を置き、ボールが壁に当たったら跳ね返るようにします。ここがこのゲームでいちばん大事な「円と四角形の当たり判定」と「反射」です。壁はホールが進むほど増え、4ホール目からは縦長の壁も出てきます。

## 四角形どうしの重なり

`let time = 0, sinkT = 0;` の **下**（`makeCourse()` の上）に追加します。

```js:game.js

  function overlap(a, b, pad = 0) {
    return a.x < b.x + b.w + pad && a.x + a.w + pad > b.x && a.y < b.y + b.h + pad && a.y + a.h + pad > b.y;
  }
```

`{ x, y, w, h }`（左上の位置と幅・高さ）で表した2つの四角形が重なっているかを調べます。「a の左はしが b の右はしより左」かつ「a の右はしが b の左はしより右」…と、横と縦の両方で重なっていれば重なりです。いわゆる **AABB の判定** です。`pad` を足すと、少しすき間をあけて判定できます。

## 壁をランダムに置く

`makeCourse()` の `c.cup = ...` の行と `c.par = ...` の行の **あいだ** に追加します。

```js:game.js
    const keepOut = [
      { x: c.tee.x - 34, y: c.tee.y - 34, w: 68, h: 68 },
      { x: c.cup.x - 30, y: c.cup.y - 30, w: 60, h: 60 },
    ];
    const all = [];
    function place(kind, count, wMin, wMax, hMin, hMax) {
      for (let i = 0, tries = 0; i < count && tries < 200; tries++) {
        const w = rnd(wMin, wMax), h = rnd(hMin, hMax);
        const r = { x: rnd(M, W - M - w), y: rnd(M + 30, H - M - 90 - h), w, h };
        if (keepOut.some(k => overlap(k, r))) continue;
        if (all.some(k => overlap(k, r, 18))) continue;
        all.push(r); c[kind].push(r); i++;
      }
    }
    const lv = Math.min(n, 12);
    place('walls', 1 + Math.floor(lv / 2), 50, 150, 14, 22);
    if (n >= 2) place('walls', Math.floor(lv / 4), 14, 22, 60, 130);
```

- `keepOut` は「ここには何も置かない」場所です。ティーとカップのまわりに障害物があると、打てなかったり入れられなかったりするので、先に予約しておきます
- `place()` は、`kind`（`'walls'` など）の障害物を `count` 個、ランダムな大きさ・位置で置こうとする関数です。置いてはいけない場所に重なったら `continue` でやりなおします。これを **試行錯誤法**（とりあえず置いてみて、ダメなら引き直す）と呼びます
- `all` には、これまでに置いた障害物を全部ためておきます。`overlap(k, r, 18)` で 18 ピクセルのすき間を空けるので、障害物どうしがくっついて「通れない」場所ができにくくなります
- `tries < 200` は、どうしても置けないときに無限ループにならないための上限です
- 置く数は `lv`（ホール番号、最大 12）で決めます。横長の壁は 1 ホール目で 1 枚、2 ホールごとに 1 枚ずつ増えます。縦長の壁は `n >= 2` から判定しますが、`Math.floor(lv / 4)` なので実際に出てくるのは 4 ホール目からで、4 ホールごとに 1 枚ずつ増えます
- 関数の中に関数（`place`）を書くと、外側の変数 `c`・`all`・`keepOut` をそのまま使えます。これを **クロージャ** と呼びます

## 円と四角形の当たり判定

`// ---------- 物理 ----------` の **すぐ下**（`step()` の上）に追加します。

```js:game.js
  function collideRect(q, bounce) {
    const nx = Math.max(q.x, Math.min(ball.x, q.x + q.w)), ny = Math.max(q.y, Math.min(ball.y, q.y + q.h));
    let dx = ball.x - nx, dy = ball.y - ny, d2 = dx * dx + dy * dy;
    if (d2 >= BALL_R * BALL_R) return false;
    let d = Math.sqrt(d2);
    if (d < 1e-6) { // 中心が中に入った：一番近い辺へ押し出す
      const opts = [[ball.x - q.x, -1, 0], [q.x + q.w - ball.x, 1, 0], [ball.y - q.y, 0, -1], [q.y + q.h - ball.y, 0, 1]];
      opts.sort((a, b) => a[0] - b[0]);
      dx = opts[0][1]; dy = opts[0][2]; d = 1;
      ball.x += dx * (opts[0][0] + BALL_R); ball.y += dy * (opts[0][0] + BALL_R);
    } else {
      dx /= d; dy /= d;
      ball.x = nx + dx * BALL_R; ball.y = ny + dy * BALL_R;
    }
    const vn = ball.vx * dx + ball.vy * dy;
    if (vn < 0) {
      ball.vx -= (1 + bounce) * vn * dx; ball.vy -= (1 + bounce) * vn * dy;
    }
    return true;
  }

```

順番に見ていきます。

1. **いちばん近い点を求める** … `Math.min(ball.x, q.x + q.w)` で右はしより右に出ないように、`Math.max(q.x, ...)` で左はしより左に出ないようにすると、`nx` は「四角形の中で、ボールの中心にいちばん近い点」の x 座標になります。y も同じです。この「はさみこみ」を **クランプ** と呼びます
2. **距離をくらべる** … ボールの中心からその点までの距離が半径 `BALL_R` 以上なら、当たっていません。平方根の計算は少し重いので、2乗どうし（`d2` と `BALL_R * BALL_R`）でくらべています
3. **押し出す** … 当たっていたら、`(dx, dy)` を長さ 1 にして「壁からボールへ向かう向き」（**法線**）にします。ボールをその向きに、ちょうど半径ぶん離れた場所まで押しもどします。四角形の角に当たったときは法線がななめになるので、角でも自然に跳ね返ります
4. **中心がめりこんだとき** … 速すぎて中心が壁の中に入ってしまうと、いちばん近い点がボールの中心そのものになり、向きが決められません。そのときは上下左右の辺までの距離をくらべ、いちばん近い辺から外へ押し出します
5. **反射** … `vn = ball.vx * dx + ball.vy * dy` は **内積** で、速度のうち「法線の向きの成分」です。マイナスなら壁に向かって進んでいます。その成分を `(1 + bounce)` 倍だけ引くと、法線方向の速度だけが反対向きになり、壁にそった方向の速度はそのまま残ります。`bounce` が 1 なら勢いを失わない反射、0.8 なら少し弱まります

> [!NOTE]
> 内積を使った反射は、「壁がどんな向きでも同じ式で跳ね返せる」のが強みです。外枠のように上下左右だけなら `vx` や `vy` の符号を変えるだけで済みますが、角に当たったときのななめの跳ね返りもこの式なら自然に計算できます。

## 壁を描く

`rrect()` の **下** に `wallRect()` を追加します。

```js:game.js
  function wallRect(q, col1, col2) {
    ctx.fillStyle = 'rgba(0,0,0,.25)'; rrect(q.x + 2, q.y + 4, q.w, q.h, 5); ctx.fill();
    const g = ctx.createLinearGradient(0, q.y, 0, q.y + q.h); g.addColorStop(0, col1); g.addColorStop(1, col2);
    ctx.fillStyle = g; rrect(q.x, q.y, q.w, q.h, 5); ctx.fill();
    ctx.strokeStyle = 'rgba(255,255,255,.25)'; ctx.lineWidth = 1.5;
    ctx.beginPath(); ctx.moveTo(q.x + 4, q.y + 2.5); ctx.lineTo(q.x + q.w - 4, q.y + 2.5); ctx.stroke();
  }
```

影 → 上から下へのグラデーション（`createLinearGradient`）→ 上のふちのハイライト、の3つを重ねると、少し盛り上がった木の板に見えます。色を引数にしておいたのは、ステップ7で赤い「動く壁」にも使い回すためです。

そして `draw()` の、カップの黒い穴を描く行の **下** に1行追加します。

```js:game.js
      for (const w of course.walls) wallRect(w, '#c98a4f', '#8d5528');
```

> [!CHECK] 動作チェック
> - 1ホール目に横長の木の壁が1枚、ホールが進むと壁が増え、4ホール目からは縦長の壁も出る
> - タイトル画面のうしろのコースにも壁が見える
> - ボールが壁に当たると跳ね返る。壁の角に当たると、ななめに跳ね返る
> - 壁がティーやカップの上に重なることはない
