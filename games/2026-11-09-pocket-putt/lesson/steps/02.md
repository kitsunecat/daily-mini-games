## このステップのゴール

コースに **ティー（打つ場所）・カップ・旗・ボール** を置きます。ゲームの数値（ホール番号・残り打数・スコアなど）を変数で持ち、ホールを始めるたびにカップの位置をランダムに決めて、上下の表示（HUD）に数字を出します。

## 乱数の道具

`const ui = { ... };` の **下** に追加します。

```js:game.js
  // ---------- 乱数 ----------
  const rnd = (a, b) => a + Math.random() * (b - a);
  const rint = (a, b) => Math.floor(rnd(a, b + 1));
```

`Math.random()` は 0 以上 1 未満の数を返します。`rnd(a, b)` はそれを「a 以上 b 未満の小数」に広げたもの、`rint(a, b)` は「a 以上 b 以下の整数」です。このゲームでは主に `rnd` を使います（`rint` は改造用の道具として置いておきます）。

## 状態の変数をふやす

`// ---------- 状態 ----------` の変数を、次のように **書きかえ** ます。

```js:game.js
  // ---------- 状態 ----------
  let state = 'title';   // title | aim | roll | sink | over
  let hole = 1, balls = START_BALLS, score = 0, strokes = 0, par = 2;
  let course = null;
  const ball = { x: 0, y: 0, vx: 0, vy: 0, lastX: 0, lastY: 0, scale: 1 };
  let time = 0;
```

- `hole` … 今のホール番号、`balls` … 残り打数、`score` … スコア、`strokes` … このホールで打った数、`par` … このホールの規定打数
- `ball` … ボールの情報をひとまとめにしたオブジェクトです。`x, y` が位置、`vx, vy` が速度（1秒に何ピクセル動くか）、`lastX, lastY` は最後に打った場所（池に落ちたときに戻る場所。ステップ6）、`scale` はカップに吸いこまれるときに小さくするための大きさ（ステップ4）です

## コースを作る・ホールを始める

`let time = 0;` の **下** に、`makeCourse()`・`startHole()` を追加し、`newGame()` を **書きかえ**、`updateHud()` を追加します。

```js:game.js
  function makeCourse(n) {
    const c = { walls: [], water: [], sand: [], movers: [] };
    c.tee = { x: rnd(M + 50, W - M - 50), y: H - M - 50 };
    c.cup = { x: rnd(M + 40, W - M - 40), y: rnd(M + 50, M + 120) };
    c.par = 2 + (n >= 3 ? 1 : 0);
    return c;
  }

  function startHole() {
    course = makeCourse(hole);
    par = course.par; strokes = 0;
    ball.x = ball.lastX = course.tee.x; ball.y = ball.lastY = course.tee.y;
    ball.vx = ball.vy = 0; ball.scale = 1;
    state = 'aim';
    updateHud();
  }

  function newGame() {
    hole = 1; balls = START_BALLS; score = 0;
    ui.overlay.classList.add('hide');
    startHole();
  }

  function updateHud() {
    ui.hole.textContent = hole; ui.balls.textContent = balls; ui.score.textContent = score;
    ui.par.textContent = 'PAR ' + par; ui.strokes.textContent = '今の打数 ' + strokes;
  }
```

- `makeCourse(n)` は、n 番目のホールの **コースのデータ** を作って返します。`walls`（壁）・`water`（池）・`sand`（砂）・`movers`（動く壁）は今は空の配列で、ステップ5〜7で中身を入れていきます
- ティーは下のほう（`y = H - M - 50`）で左右はランダム、カップは上のほうでランダムな場所です。左右の端に寄りすぎないよう、範囲を `M + 40` などで内側にしぼっています
- パーは 1〜2 ホール目が 2、3 ホール目からは 3 です
- `startHole()` はコースを作り、ボールをティーに置いて、狙う状態（`'aim'`）にします。`ball.x = ball.lastX = course.tee.x` のように `=` をつなげると、右から順に同じ値がまとめて入ります
- `newGame()` はゲーム全体の数値をリセットしてから最初のホールを始めます
- `updateHud()` は、変数の値を HTML の表示に書き写す関数です。数値が変わったら、そのたびにこれを呼ぶようにします

## 描く

`draw()` の、芝生の `for` 文と `ctx.restore();` の **あいだ** に追加します。

```js:game.js
    if (course) {
      // ティー
      ctx.fillStyle = 'rgba(255,255,255,.18)';
      ctx.beginPath(); ctx.arc(course.tee.x, course.tee.y, 16, 0, Math.PI * 2); ctx.fill();
      // カップ
      const c = course.cup;
      ctx.fillStyle = '#2a7a3c'; ctx.beginPath(); ctx.arc(c.x, c.y, CUP_R + 5, 0, Math.PI * 2); ctx.fill();
      ctx.fillStyle = '#111'; ctx.beginPath(); ctx.arc(c.x, c.y, CUP_R, 0, Math.PI * 2); ctx.fill();
      // ボール
      if (ball.scale > 0) {
        ctx.fillStyle = 'rgba(0,0,0,.3)';
        ctx.beginPath(); ctx.arc(ball.x + 2, ball.y + 3, BALL_R * ball.scale, 0, Math.PI * 2); ctx.fill();
        const g = ctx.createRadialGradient(ball.x - 2, ball.y - 2, 1, ball.x, ball.y, BALL_R);
        g.addColorStop(0, '#fff'); g.addColorStop(1, '#cfd6dc');
        ctx.fillStyle = g; ctx.beginPath(); ctx.arc(ball.x, ball.y, BALL_R * ball.scale, 0, Math.PI * 2); ctx.fill();
      }
      // 旗
      ctx.strokeStyle = '#eee'; ctx.lineWidth = 2;
      ctx.beginPath(); ctx.moveTo(c.x, c.y); ctx.lineTo(c.x, c.y - 42); ctx.stroke();
      const wave = Math.sin(time * 4) * 3;
      ctx.fillStyle = '#ff5a4f';
      ctx.beginPath(); ctx.moveTo(c.x, c.y - 42); ctx.lineTo(c.x + 24, c.y - 35 + wave); ctx.lineTo(c.x, c.y - 28); ctx.fill();
      ctx.fillStyle = '#fff'; ctx.font = 'bold 9px system-ui'; ctx.textAlign = 'center';
      ctx.fillText(hole, c.x + 9, c.y - 32 + wave / 2);
    }
```

- `ctx.arc(x, y, 半径, 0, Math.PI * 2)` は円を描く命令です。最後の2つは「何度から何度まで」で、`0` から `Math.PI * 2`（ラジアンで 360°）なら一周です
- **カップ** は、少し濃い緑の円の上に黒い穴を重ねて、ふちを表しています
- **ボール** は、右下に少しずらした半透明の黒い円（影）を先に描き、その上に白いボールを描きます。`createRadialGradient` は **円形のグラデーション** で、左上を白、ふちを灰色にすると立体的な球に見えます
- **旗** の三角形の先は `Math.sin(time * 4) * 3` で上下に3ピクセルゆれます。`time` が増えると `sin` が -1〜1 をくり返すので、旗がはためいて見えます。旗にはホール番号も書きます
- 描く順番が大事です。あとから描いたものが上に重なるので、「ティー → カップ → ボール → 旗」の順にしています

## タイトル画面の背景

`resize();` の **下**（`let last = ...` の上）に追加します。

```js:game.js
  // タイトル背景用のコース
  course = makeCourse(4);
  ball.x = course.tee.x; ball.y = course.tee.y;
```

タイトル画面のうしろに、4ホール目くらいのコースを1つ置いておきます。今は旗とボールしかありませんが、ステップ5〜6で壁・砂・池を作ると、ここにも自動で出てくるようになります。

> [!CHECK] 動作チェック
> - タイトル画面のうしろに、旗の立ったカップとボールがうっすら見える。旗はゆらゆらはためく
> - スタートを押すと、下のティーにボール、上のほうにカップがある。再読み込みするたびにカップとティーの位置が変わる
> - 上の表示が「HOLE 1・残り打数 10・SCORE 0」、下に「PAR 2・今の打数 0」と出る
