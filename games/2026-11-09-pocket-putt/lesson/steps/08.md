## このステップのゴール

残り打数が 0 になったら **ゲームオーバー** にして、結果を表示します。いちばん良かったスコアを **localStorage** に保存し、次に開いたときも BEST に出るようにします。「もう一度」ボタンでリトライできるようにして、ゲームとして一周できる形に仕上げます。

## ハイスコアを読みこむ

`const ui = { ... };` の **下**（`// ---------- 乱数 ----------` の上）に追加します。

```js:game.js

  let best = 0;
  try { best = parseInt(localStorage.getItem(BEST_KEY), 10) || 0; } catch (e) { best = 0; }
  ui.best.textContent = best;
```

**localStorage** は、ブラウザにちょっとしたデータを保存しておける場所です。ページを閉じても消えません。

- `localStorage.getItem(名前)` で読み出します。保存されているのは **文字列** なので、`parseInt(…, 10)` で10進数の整数にします。まだ保存されていないと `null` が返り、`parseInt` は `NaN`（数ではない）になるので、`|| 0` で 0 にします
- プライベートブラウズなど、localStorage が使えない環境ではエラーになることがあります。`try { … } catch (e) { … }` で囲んでおくと、エラーが起きてもゲームは止まらずに続けられます

## 残り打数が少ないと赤く

`updateHud()` の最後（閉じかっこの手前）に1行追加します。

```js:game.js
    ui.balls.style.color = balls <= 2 ? '#ff8a7a' : '';
```

残り打数が 2 以下になったら数字を赤くして、ピンチを知らせます。`''`（空文字）を入れると、CSS で決めた元の色にもどります。

## ゲームオーバー

`onSink()` の **下** に追加します。

```js:game.js
  function gameOver() {
    state = 'over';
    let isBest = false;
    if (score > best) {
      best = score; isBest = true;
      try { localStorage.setItem(BEST_KEY, String(best)); } catch (e) { /* 保存できなくても続行 */ }
    }
    ui.best.textContent = best;
    ui.title.textContent = 'ゲームオーバー';
    ui.text.innerHTML = `ホール ${hole} で打ち切り<br>スコア <b class="hl">${score}</b>${isBest ? '<br><b class="hl">ハイスコア更新！</b>' : ''}<br>ベスト ${best}`;
    ui.start.textContent = 'もう一度';
    ui.overlay.classList.remove('hide');
  }
```

- 今回のスコアがベストより大きければ更新し、`localStorage.setItem(名前, 文字列)` で保存します
- タイトル画面に使っていたオーバーレイを、そのまま **結果画面** として使い回します。見出し・本文・ボタンの文字を書きかえて、`.hide` を外せば表示されます
- 本文は `` ` `` で囲む **テンプレート文字列** で作っています。`${ }` の中に変数や式を書くと、その値が埋めこまれます。ハイスコアを更新したときだけ「ハイスコア更新！」を足すのに、`? :`（三項演算子）を使っています
- 「もう一度」ボタンは、ステップ1から `newGame()` につながっています。`newGame()` は数値をリセットして1ホール目から始めるので、そのままリトライになります

## 打ち切りの判定

`endRoll()` の、`state = 'aim';` の **上** に1行追加します。

```js:game.js
    if (balls <= 0) { state = 'over-wait'; setTimeout(gameOver, 500); return; }
```

ボールが止まったとき（池ポチャのときも `endRoll()` を通ります）に残り打数が 0 以下なら、ゲームオーバーです。すぐに結果画面を出すと何が起きたか分かりにくいので、`'over-wait'` という「待ち」の状態にして 0.5 秒後に `gameOver()` を呼びます。`'over-wait'` のあいだは `'aim'` ではないので、ドラッグしても打てません。

最後の1打でカップインしたときは、`onSink()` が残り打数をもどしてくれるので、ゲームオーバーにはならずに次のホールへ進めます。ぎりぎりで入れたときの気持ちよさは、このしくみから生まれます。

> [!CHECK] 動作チェック
> - 残り打数が 2 以下になると、数字が赤くなる
> - 残り打数が 0 でボールが止まると、少しして「ゲームオーバー」画面が出て、到達ホール・スコア・ベストが表示される
> - スコアがベストを超えたら「ハイスコア更新！」と出て、上の BEST も変わる
> - 「もう一度」を押すと HOLE 1・残り打数 10・SCORE 0 からやりなおせる
> - ページを再読み込みしても、BEST の数字が残っている
