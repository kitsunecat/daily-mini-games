## このステップのゴール

ボールが **カップに入る** ようにします。速すぎるとカップの上を通りすぎ、ちょうどいい速さなら吸いこまれます。カップインしたら「バーディー！ +160」のような一言を出し、スコアを足して、残り打数を **パー − 1** 打もどし、次のホールへ進みます。

## 変数をひとつ追加

`let time = 0;` を **書きかえ** ます。

```js:game.js
  let time = 0, sinkT = 0;
```

`sinkT` は、カップに吸いこまれはじめてからの時間です。

## トースト（一言メッセージ）

`updateHud()` の **下**（`shoot()` の上）に追加します。

```js:game.js
  let toastTimer = 0;
  function toast(msg) {
    ui.toast.textContent = msg; ui.toast.classList.add('show');
    clearTimeout(toastTimer); toastTimer = setTimeout(() => ui.toast.classList.remove('show'), 1100);
  }
```

`#toast` に文字を入れて `.show` クラスをつけると、CSS の `transition` でふわっと出てきます。`setTimeout` で 1.1 秒後にクラスを外すと、またふわっと消えます。続けて呼ばれたときは `clearTimeout` で前の「消す予約」を取り消すので、新しいメッセージがすぐ消えてしまうことはありません。

## カップインの処理

`shoot()` の **下** に、`sinkName()` と `onSink()` を追加します。

```js:game.js
  function sinkName(s, p) {
    if (s === 1) return 'ホールインワン！';
    const d = s - p;
    return { '-3': 'アルバトロス！', '-2': 'イーグル！', '-1': 'バーディー！', '0': 'パー', '1': 'ボギー', '2': 'ダブルボギー' }[d] || (d < 0 ? 'すごい！' : 'カップイン');
  }

  function onSink() {
    state = 'sink'; sinkT = 0;
    const refund = par - 1 + (strokes === 1 ? 2 : 0);
    balls += refund;
    const pts = Math.max(20, 100 + (par - strokes) * 60) + (strokes === 1 ? 200 : 0);
    score += pts;
    toast(sinkName(strokes, par) + ' +' + pts);
    updateHud();
    setTimeout(() => { hole++; startHole(); }, 1300);
  }
```

- `sinkName()` は、打数とパーの差からゴルフの呼び名を返します。オブジェクトのキーに差の数（`-1` など）を使い、`{ ... }[d]` でその場で引いています。表にない差（もっと大きなボギーなど）は `undefined` になるので、`||` のうしろの言葉を使います
- **残り打数のもどし**（`refund`）がこのゲームの肝です。カップインすると `par - 1` 打もどります。パー 2 のホールを2打で入れると、2打使って1打もどるので **差し引き 1 打減る**。1打（バーディー）で入れれば **減らない**。ホールインワンならさらに +2 で得をします。上手に入れるほど長く遊べるしくみです
- **スコア** は、パーちょうどで 100 点、1打少ないごとに +60、多いごとに −60（最低 20 点）。ホールインワンはさらに +200 です
- `state = 'sink'` にしてボールが吸いこまれる演出を見せ、1.3 秒後に `hole++` して次のホールを始めます

## カップの判定と吸いこみの演出

`step()` を2か所変えます。まず、`time += dt;` と `if (state !== 'roll') return;` の **あいだ** に追加します。

```js:game.js

    if (state === 'sink') {
      sinkT += dt;
      ball.x += (course.cup.x - ball.x) * Math.min(1, dt * 12);
      ball.y += (course.cup.y - ball.y) * Math.min(1, dt * 12);
      ball.scale = Math.max(0, 1 - sinkT * 3);
      return;
    }
```

カップインしたあとは、ボールをカップの中心へ **毎フレーム残りの距離の一定割合ずつ** 近づけます。最初は速く、近づくほどゆっくりになる、なめらかな動きになります。同時に `scale` を 1 から 0 へ小さくすると、穴に落ちていくように見えます（`draw()` はステップ2から `BALL_R * ball.scale` で描いています）。

次に、サブステップの `for` の中、**外枠の4行の下** に追加します。

```js:game.js

      // カップ
      const cdx = course.cup.x - ball.x, cdy = course.cup.y - ball.y, cd = Math.hypot(cdx, cdy);
      const v = Math.hypot(ball.vx, ball.vy);
      if (cd < CUP_R) {
        if (v < 430) { onSink(); return; }
        ball.vx += cdx / cd * 900 * h; ball.vy += cdy / cd * 900 * h; // ふちで少し曲がる
      }
```

- **円と点の当たり判定** です。ボールの中心とカップの中心の距離 `cd` が、カップの半径 `CUP_R` より小さければ、ボールはカップの上にあります
- そのときボールの速さ `v` が 430 未満なら **カップイン**。速すぎるときは入らずに通りすぎますが、カップの中心の方向へ少しだけ速度を足して、ふちで軌道が曲がるようにしています。本物のゴルフの「カップに蹴られる」感じです
- `onSink()` のあとはすぐ `return` して、このフレームの残りの計算をやめます

> [!CHECK] 動作チェック
> - ちょうどいい強さでカップに向かって打つと、ボールがカップの中心へ吸いこまれて小さくなり、「パー +100」「バーディー +160」などの一言が出る
> - スコアが増え、残り打数が「パー − 1」打もどる（ホールインワンはさらに +2）
> - 少したつと HOLE が 2 になり、新しいカップの位置で次のホールが始まる
> - 強すぎるとカップの上を通りすぎ、ふちで少し曲がる
