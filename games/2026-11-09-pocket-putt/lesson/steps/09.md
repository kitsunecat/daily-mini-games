## このステップのゴール

最後の仕上げです。**効果音** を Web Audio API で鳴らし、PC の **キーボード** で向きと強さを決めて打てるようにします。これで完成品と同じになります。

## 効果音 … Web Audio API

`ui.best.textContent = best;` の **下**（`// ---------- 乱数 ----------` の上）に追加します。

```js:game.js

  // ---------- 音 ----------
  let ac = null;
  function audio() {
    if (!ac) { try { ac = new (window.AudioContext || window.webkitAudioContext)(); } catch (e) { ac = null; } }
    if (ac && ac.state === 'suspended') ac.resume();
    return ac;
  }
  function tone(freq, dur, type = 'sine', vol = 0.15, slide = 0) {
    const a = audio(); if (!a) return;
    const o = a.createOscillator(), g = a.createGain();
    o.type = type; o.frequency.value = freq;
    if (slide) o.frequency.exponentialRampToValueAtTime(Math.max(40, freq + slide), a.currentTime + dur);
    g.gain.setValueAtTime(vol, a.currentTime);
    g.gain.exponentialRampToValueAtTime(0.001, a.currentTime + dur);
    o.connect(g).connect(a.destination); o.start(); o.stop(a.currentTime + dur);
  }
  function noise(dur, vol = 0.2) {
    const a = audio(); if (!a) return;
    const buf = a.createBuffer(1, a.sampleRate * dur, a.sampleRate), d = buf.getChannelData(0);
    for (let i = 0; i < d.length; i++) d[i] = (Math.random() * 2 - 1) * (1 - i / d.length);
    const s = a.createBufferSource(), g = a.createGain(), f = a.createBiquadFilter();
    f.type = 'lowpass'; f.frequency.value = 900;
    s.buffer = buf; g.gain.value = vol; s.connect(f).connect(g).connect(a.destination); s.start();
  }
  const sfx = {
    hit: p => tone(300 + p * 500, 0.08, 'triangle', 0.2),
    wall: () => tone(180, 0.05, 'square', 0.06),
    cup: () => { tone(520, 0.12, 'sine', 0.2); setTimeout(() => tone(780, 0.18, 'sine', 0.2), 110); },
    splash: () => noise(0.4, 0.25),
    over: () => tone(330, 0.5, 'sawtooth', 0.1, -200),
  };
```

**Web Audio API** を使うと、音声ファイルを用意しなくても JavaScript で音を作れます。

- `audio()` … 音を扱う入れ物 `AudioContext` を、最初に必要になったときに1つだけ作ります。ブラウザには「ユーザーが操作するまで音を出さない」決まりがあり、止まった状態（`'suspended'`）で作られることがあるので、`resume()` で動かします。スタートボタンやドラッグのときに `audio()` を呼んでおくのはこのためです
- `tone()` … **発振器**（`createOscillator`）で決まった高さ `freq`（Hz）の音を出し、**音量のつまみ**（`createGain`）を `dur` 秒かけて 0 近くまで下げて、「ポッ」と消える短い音にします。`type` は音色で、`'sine'` はやわらかく、`'square'` や `'sawtooth'` はブザーっぽく、`'triangle'` はその中間です。`slide` を指定すると音の高さもすべらせられます（ゲームオーバーの「ヒュ〜ン」と下がる音）
- `noise()` … ランダムな数をならべた音のデータ（**ホワイトノイズ**）を作り、うしろほど小さくして、`lowpass`（高い音をカットする）フィルターを通します。「ザバッ」という水しぶきの音になります
- `o.connect(g).connect(a.destination)` … 発振器 → 音量 → スピーカー、の順につなぎます
- `sfx` に、ゲームの出来事ごとの音をまとめておきます。打つ音 `hit` は強さ `p` が大きいほど高い音になります。カップインは2つの音を少しずらして鳴らす「ポン・ピン」です

## 音を鳴らす場所

ゲームの出来事に合わせて `sfx` を呼びます。次の場所をそれぞれ **書きかえ** ます。

`newGame()` … オーバーレイを消す行の下に `audio();` を足します。

```js:game.js
  function newGame() {
    hole = 1; balls = START_BALLS; score = 0;
    ui.overlay.classList.add('hide');
    audio();
    startHole();
  }
```

`shoot()` … `state = 'roll';` の下に、打つ音を足します。

```js:game.js
    state = 'roll';
    sfx.hit(power);
    updateHud();
```

`onSink()` … 最初の行の下に、カップインの音を足します。

```js:game.js
    state = 'sink'; sinkT = 0;
    sfx.cup();
```

`gameOver()` … 最初の行を書きかえます。

```js:game.js
    state = 'over'; sfx.over();
```

`collideRect()` … 反射の `if (vn < 0) { ... }` の中に1行足します。ある程度の勢いで当たったときだけ「コッ」と鳴らし、ゆっくり触れただけのときは鳴らしません。

```js:game.js
    if (vn < 0) {
      ball.vx -= (1 + bounce) * vn * dx; ball.vy -= (1 + bounce) * vn * dy;
      if (-vn > 60) sfx.wall();
    }
```

`step()` … 外枠の4行の最後に `sfx.wall();` を足し、池の判定の `ripples.push(...)` の下に `sfx.splash();` を足します。

```js:game.js
      // 外枠
      if (ball.x < M + BALL_R) { ball.x = M + BALL_R; ball.vx = Math.abs(ball.vx) * 0.8; sfx.wall(); }
      if (ball.x > W - M - BALL_R) { ball.x = W - M - BALL_R; ball.vx = -Math.abs(ball.vx) * 0.8; sfx.wall(); }
      if (ball.y < M + BALL_R) { ball.y = M + BALL_R; ball.vy = Math.abs(ball.vy) * 0.8; sfx.wall(); }
      if (ball.y > H - M - BALL_R) { ball.y = H - M - BALL_R; ball.vy = -Math.abs(ball.vy) * 0.8; sfx.wall(); }
```


## キーボードで狙う

PC では、矢印キーで向きと強さを決めて Space で打てるようにします。まず、`let aim = { ... };` の **下** に変数を追加します。

```js:game.js
  let keyAim = { angle: -Math.PI / 2, power: 0.5, shown: false };
```

`angle` は打つ向きの角度（ラジアン）です。Canvas は下に行くほど y が大きいので、`-Math.PI / 2`（−90°）が **真上** になります。`shown` は、キーボードの照準を表示しているかどうかです。

`startHole()` の、`ball.vx = ball.vy = 0; ball.scale = 1;` の **下** に1行追加します。

```js:game.js
    keyAim.angle = Math.atan2(course.cup.y - ball.y, course.cup.x - ball.x);
```

`Math.atan2(y, x)` は、(x, y) の向きの角度を返します。ボールからカップへの向きを最初の向きにしておくと、まっすぐ狙えるホールではそのまま打てます。

`currentAim()` の、`if (aim.active) { ... }` の **下**（`return null;` の上）に1行追加します。

```js:game.js
    if (keyAim.shown) return { dx: Math.cos(keyAim.angle), dy: Math.sin(keyAim.angle), power: keyAim.power, ok: true };
```

角度から向きを作るには、`Math.cos(角度)` が x、`Math.sin(角度)` が y です。これでドラッグのときと同じ形の照準データになるので、`drawAim()` はそのまま使えます。

`pointerdown` の中を2か所 **書きかえ** ます。ドラッグを始めたら音を準備し、キーボードの照準は消します。

```js:game.js
  cv.addEventListener('pointerdown', e => {
    if (state !== 'aim') return;
    e.preventDefault(); audio();
    const p = toLogical(e);
    aim = { active: true, sx: p.x, sy: p.y, dx: p.x, dy: p.y };
    keyAim.shown = false;
    try { cv.setPointerCapture(e.pointerId); } catch (err) { /* noop */ }
  });
```

最後に、`cv.addEventListener('pointercancel', ...)` の **下** にキー操作を追加します。

```js:game.js

  window.addEventListener('keydown', e => {
    if (state === 'title' || state === 'over') {
      if (e.key === 'Enter' || e.key === ' ') { e.preventDefault(); newGame(); }
      return;
    }
    if (state !== 'aim') return;
    const k = e.key;
    if (k === 'ArrowLeft') { keyAim.angle -= e.shiftKey ? 0.12 : 0.04; keyAim.shown = true; e.preventDefault(); }
    else if (k === 'ArrowRight') { keyAim.angle += e.shiftKey ? 0.12 : 0.04; keyAim.shown = true; e.preventDefault(); }
    else if (k === 'ArrowUp') { keyAim.power = Math.min(1, keyAim.power + 0.05); keyAim.shown = true; e.preventDefault(); }
    else if (k === 'ArrowDown') { keyAim.power = Math.max(0.08, keyAim.power - 0.05); keyAim.shown = true; e.preventDefault(); }
    else if (k === ' ' || k === 'Enter') {
      e.preventDefault();
      if (!keyAim.shown) { keyAim.shown = true; return; }
      shoot(Math.cos(keyAim.angle), Math.sin(keyAim.angle), keyAim.power);
    }
  });
```

- タイトル画面とゲームオーバー画面では、Space / Enter でスタート（リトライ）します
- ← → で向きを回します。Shift を押しながらだと3倍速く回ります。↑ ↓ で強さを 0.05 ずつ変えます
- Space / Enter は、照準が出ていなければまず照準を出し、出ていれば打ちます。いきなり打ってしまわないための一手間です
- `e.preventDefault()` は、矢印キーや Space でページがスクロールするなど、ブラウザの元の動きを止めるためです
- 打つ処理は、ドラッグと同じ `shoot()` を呼ぶだけです。入力方法が増えても、ルールは1か所にまとまっています

> [!CHECK] 動作チェック
> - 打つと「コッ」と音が鳴り、強く打つほど音が高い。壁や外枠に勢いよく当たると小さな音が鳴る
> - カップインで「ポン・ピン」、池ポチャで「ザバッ」、ゲームオーバーで下がる音が鳴る
> - PC で ← → を押すと点線の照準が出て向きが変わり、↑ ↓ で強さ（パワーバー）が変わる。Space / Enter で打てる
> - マウスでドラッグを始めると、キーボードの照準は消える
> - タイトル画面とゲームオーバー画面で、Space / Enter を押すとゲームが始まる

## 完成！ 改造してみよう

これで完成品の「ポケットパター」と同じものができました。最後に、自分だけのゲームに育てる改造アイデアをいくつか紹介します。

> [!TIP]
> **予測線を出す** … `drawAim()` の点線は、今はまっすぐのびるだけです。`ball` のコピーを作って `step()` と同じ計算を数十回だけ先に進め、壁で跳ね返った最初の1回ぶんまで点を打つと、バンクショットの練習モードになります（全部見せると簡単になりすぎるので、1回ぶんまでがおすすめ）。

> [!TIP]
> **新しい地形「ブースター」** … `makeCourse()` に `boost` の配列を足し、`place('boost', ...)` で置いて、`step()` で `inRect()` がその上にあるときだけ `ball.vy -= 600 * h` のように一方向へ加速させてみましょう。描くときに矢印を入れると分かりやすくなります。

> [!TIP]
> **ホールごとのスコアカード** … `onSink()` で `strokes - par` を配列にためておき、ゲームオーバー画面に「+1 / 0 / −1 …」と並べて表示すると、本物のゴルフのスコアカードのようになります。

> [!TIP]
> **難易度の調整** … `START_BALLS` を増やすとやさしく、`onSink()` の `refund` を `par - 2` にするとぐっと難しくなります。`MAX_SPEED` や砂の摩擦（3.2 と 260）を変えると、ボールの転がり方の手ざわりが大きく変わります。
