## このステップのゴール

コースに **砂（バンカー）** と **池** を置きます。砂の上ではボールがぐっと止まりやすくなり、池に入ると水しぶきの輪が広がって、**1打罰** で打った場所にもどされます。3ホール目から砂、4ホール目から池が出てきます。

## 波紋の変数

`let time = 0, sinkT = 0;` を **書きかえ** ます。

```js:game.js
  let ripples = [], time = 0, sinkT = 0;
```

`ripples` は、池ポチャのときに広がる **波紋の輪** のリストです。1つ1つは `{ x, y, t }`（場所と、出てからの時間）です。

## 砂と池を置く

`makeCourse()` の縦長の壁の行の **下** に2行を足し、`c.par = ...` の行を **書きかえ** ます。

```js:game.js
    if (n >= 2) place('walls', Math.floor(lv / 4), 14, 22, 60, 130);
    if (n >= 3) place('sand', 1 + Math.floor(lv / 5), 60, 110, 40, 70);
    if (n >= 4) place('water', 1 + Math.floor(lv / 6), 60, 120, 36, 60);
    c.par = 2 + (n >= 3 ? 1 : 0) + (n >= 7 && c.water.length + c.walls.length >= 6 ? 1 : 0);
```

ステップ5で作った `place()` を、種類と大きさを変えて呼ぶだけです。障害物どうしが重ならないしくみもそのまま使えます。パーは、7ホール目以降で池と壁が合わせて6つ以上ある難しいコースだと、さらに +1 されて 4 になります。

## 点が四角形の中にあるか

`// ---------- 物理 ----------` の **すぐ下**（`collideRect()` の上）に追加します。

```js:game.js
  function inRect(x, y, r) { return x > r.x && x < r.x + r.w && y > r.y && y < r.y + r.h; }

```

ボールの **中心** が四角形の中にあるかを調べます。壁はボールのふちが触れたら当たりにしましたが、砂や池は「中心が入ったら」にしています。ふちが少しかすっただけで池ポチャになると、理不尽に感じるからです。

## 波紋を進める

`step()` の `time += dt;` の **下** に1行追加します。

```js:game.js
    ripples = ripples.filter(r => (r.t += dt) < 0.8);
```

`filter` は、条件を満たす要素だけを残した新しい配列を作ります。ここでは各波紋の `t` を進めながら、0.8 秒たったものを取りのぞいています。

## 砂の上では止まりやすく

サブステップの中、摩擦の部分（`const k = ...` から `const dec = ...` まで）を **書きかえ** ます。

```js:game.js
      const inSand = course.sand.some(s => inRect(ball.x, ball.y, s));
      const fr = inSand ? 3.2 : 0.95;               // 指数減衰
      const k = Math.exp(-fr * h);
      ball.vx *= k; ball.vy *= k;
      const sp = Math.hypot(ball.vx, ball.vy);
      if (sp > 0) {                                  // 一定の転がり抵抗
        const dec = Math.min(sp, (inSand ? 260 : 70) * h);
```

`some` は「どれか1つでも条件を満たせば `true`」を返す配列のメソッドです。ボールがどれかの砂の上にあれば、指数減衰を 0.95 → 3.2、転がり抵抗を 70 → 260 に強めます。砂を越えて打ちたいときは、強めに打つ必要があります。

## 池ポチャ

サブステップの中、`// カップ` の判定の **下**（`for` の閉じかっこの手前）に追加します。

```js:game.js

      // 池
      if (course.water.some(wt => inRect(ball.x, ball.y, wt))) {
        ripples.push({ x: ball.x, y: ball.y, t: 0 });
        ball.x = ball.lastX; ball.y = ball.lastY; ball.vx = ball.vy = 0;
        balls--; strokes++;
        toast('池ポチャ！ 1打罰');
        updateHud();
        endRoll();
        return;
      }
```

ボールの中心が池に入ったら、その場所に波紋を出し、ボールを **最後に打った場所**（ステップ3の `shoot()` で覚えておいた `lastX, lastY`）へもどします。罰として残り打数を1減らし、このホールの打数も1増やします。

## 砂・池・波紋を描く

`draw()` の `if (course) {` の **すぐ下**（`// ティー` の上）に追加します。

```js:game.js
      for (const s of course.sand) {
        ctx.fillStyle = '#e8d39a'; rrect(s.x, s.y, s.w, s.h, 18); ctx.fill();
        ctx.fillStyle = 'rgba(160,120,60,.35)';
        for (let i = 0; i < s.w * s.h / 120; i++) {
          const px = s.x + 6 + ((i * 37) % (s.w - 12)), py = s.y + 6 + ((i * 53) % (s.h - 12));
          ctx.fillRect(px, py, 2, 2);
        }
      }
      for (const wt of course.water) {
        ctx.fillStyle = '#2d7fd0'; rrect(wt.x, wt.y, wt.w, wt.h, 16); ctx.fill();
        ctx.strokeStyle = 'rgba(255,255,255,.35)'; ctx.lineWidth = 2;
        for (let j = 0; j < 2; j++) {
          const yy = wt.y + wt.h * (0.35 + j * 0.3);
          ctx.beginPath();
          for (let xx = wt.x + 12; xx < wt.x + wt.w - 12; xx += 4) {
            const y2 = yy + Math.sin(xx * 0.15 + time * 3 + j) * 2;
            xx === wt.x + 12 ? ctx.moveTo(xx, y2) : ctx.lineTo(xx, y2);
          }
          ctx.stroke();
        }
      }
```

- **砂** … 角を大きく丸めた砂色の四角に、小さな点を散らします。点の場所に `Math.random()` を使うと、毎フレーム点が動いてチカチカしてしまいます。そこで `(i * 37) % 幅` のように **かけ算と割り算のあまり** で、ばらばらに見えるけれど毎回同じ場所を計算しています
- **池** … 青い角丸四角に、白い波線を2本。x を 4 ずつ進めながら `Math.sin(xx * 0.15 + time * 3 + j)` で y をゆらし、点を線でつないでいます。`time` が入っているので波が流れるように動きます。最初の点だけ `moveTo`、あとは `lineTo` です

さらに、壁を描く行（`for (const w of course.walls) wallRect(...)`）の **下** に、波紋を描く処理を追加します。

```js:game.js
      for (const r of ripples) {
        ctx.strokeStyle = `rgba(255,255,255,${1 - r.t / 0.8})`; ctx.lineWidth = 2;
        ctx.beginPath(); ctx.arc(r.x, r.y, 6 + r.t * 30, 0, Math.PI * 2); ctx.stroke();
      }
```

時間 `t` がたつほど半径を大きく、色をうすくすると、水面に広がる輪になります。
