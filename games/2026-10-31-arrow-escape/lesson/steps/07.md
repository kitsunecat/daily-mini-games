## このステップのゴール

マウスやタッチが無くても遊べるように、**キーボード操作** を加えます。

- 矢印キーを押すと、盤面のまん中に白い枠（**カーソル**）が出る。もう一度矢印キーを押すとカーソルが動く
- Space か Enter で、カーソルのあるブロックをタップしたのと同じことが起きる
- タイトル画面やゲームオーバー画面では、Space / Enter でスタートできる

## カーソルの変数を追加する

`let state = 'title'; // title | play | clear | over` の **下** に追加します。

```js:game.js
  let cursor = null; // キーボード用 {r, c}
```

最初は `null`（カーソルなし）にしておき、矢印キーが押されたときに初めて表示します。タッチだけで遊ぶ人には余計な枠が見えないようにするためです。

## 盤面が変わったらカーソルをまん中に戻す

`generate()` の最後、`movers = [];` の **下** に追加します。

```js:game.js
    if (cursor) cursor = { r: Math.floor(N / 2), c: Math.floor(N / 2) };
```

レベルが上がって盤面が大きくなったとき、カーソルが変な位置に残らないよう、まん中に戻します。キーボードを使っていない人（`cursor` が `null`）にはそのままです。

## キー入力を受け取る

`startBtn.addEventListener('click', start);` の **上** に追加します。

```js:game.js
  window.addEventListener('keydown', (e) => {
    if (state !== 'play') {
      if ((e.key === 'Enter' || e.key === ' ') && state !== 'clear') { e.preventDefault(); start(); }
      return;
    }
    const map = { ArrowUp: 0, ArrowRight: 1, ArrowDown: 2, ArrowLeft: 3 };
    if (e.key in map) {
      e.preventDefault();
      if (!cursor) cursor = { r: Math.floor(N / 2), c: Math.floor(N / 2) };
      else {
        const d = map[e.key];
        cursor.r = Math.max(0, Math.min(N - 1, cursor.r + DY[d]));
        cursor.c = Math.max(0, Math.min(N - 1, cursor.c + DX[d]));
      }
    } else if ((e.key === ' ' || e.key === 'Enter') && cursor) {
      e.preventDefault();
      tapCell(cursor.r, cursor.c);
    }
  });
```

- `keydown` イベントの `e.key` には、押されたキーの名前（`'ArrowUp'`、`'Enter'`、スペースなら `' '`）が入ります。
- 遊んでいないとき（タイトル・ゲームオーバー）は、Space / Enter で `start()`。ただしクリア演出中（`'clear'`）に押すと最初からやり直しになってしまうので除外しています。
- `map` は「キーの名前 → 向きの番号」の対応表です。`e.key in map` で「矢印キーかどうか」を調べ、ステップ2の `DX` / `DY` をそのまま使ってカーソルを動かします。**同じ向きの表をいろいろな場所で使い回せる** のが、向きを数字にしたうれしさです。
- `Math.max(0, Math.min(N - 1, 値))` は、値を **0〜N-1 の範囲に収める**（はみ出したら端で止める）定番の書き方です。
- `e.preventDefault()` で、矢印キーや Space でページがスクロールするのを止めます。
- 決定は `tapCell()` を呼ぶだけです。タップとキーボードが同じ関数を通るので、得点やぶつかる判定を2回書かずに済みます。

## カーソルを描く

`draw()` の「飛んでいくブロック」の `for` ループの **下**、`ctx.restore();` の **上** に追加します。

```js:game.js
    // キーボードカーソル
    if (cursor && state === 'play') {
      ctx.strokeStyle = '#fff';
      ctx.lineWidth = 3;
      roundRect(b.x + cursor.c * b.cell + 1, b.y + cursor.r * b.cell + 1, b.cell - 2, b.cell - 2, b.cell * 0.18);
      ctx.stroke();
    }
```

`roundRect()` で作ったパスを、今度は `fill()` ではなく `stroke()` で **線だけ** 描きます。同じパスの関数を「塗り」にも「枠線」にも使えます。

> [!CHECK] 動作チェック
> - タイトル画面で Enter（または Space）を押すとゲームが始まる
> - 矢印キーを押すと、盤面のまん中に白い角丸の枠が出る。続けて矢印キーを押すと枠が動き、盤面の端で止まる
> - Space か Enter で、枠のあるブロックが飛んでいく（ぶつかる場合はハートが減る）
> - ゲームオーバー画面でも Enter でリトライできる
> - マウスやタッチだけで遊んでいるときは、白い枠は出ない
