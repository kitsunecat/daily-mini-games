## このステップのゴール

3つのファイルを用意して、画面の土台を作ります。上に「LEVEL・SCORE・BEST」とハート・制限時間のバー、まん中にゲーム画面の **Canvas**、その上に重ねるタイトル画面（オーバーレイ）を置きます。Canvas にはまだ **5×5 のマス目** だけを描きます。

完成すると、こんなゲームになります。

- 盤面に「上・右・下・左」のやじるしが描かれたブロックが並んでいる
- ブロックをタップすると、やじるしの向きへまっすぐ飛んでいき、盤面から消える
- 進む先にほかのブロックがあるとぶつかって戻り、ハートが1つ減る
- 盤面を空っぽにするとレベルクリア。時間内に早く片付けるほどボーナスが増える

- `header` に LEVEL・SCORE・BEST の3つの数字を並べます。JavaScript から書き換えるので、数字の `b` 要素に `id` をつけています。

- 「← 一覧」のリンク先は自分の環境に合わせて変えてかまいません。
- `<script>` を `body` の最後に置くと、HTML の要素が全部できてからスクリプトが動くので、`getElementById` で確実に要素が取れます。

- `touch-action: none` と `user-select: none` は、スマホで連打したときに画面が拡大されたり文字が選択されたりするのを防ぎます。

## game.js

```js:game.js
(() => {
  const cv = document.getElementById('cv');
  const ctx = cv.getContext('2d');
  const $ = (id) => document.getElementById(id);
  const overlay = $('overlay'), startBtn = $('start');

  let N = 5;
  let W = 0, H = 0, dpr = 1;

  // ---- レイアウト ----
  function resize() {
    const rect = cv.getBoundingClientRect();
    dpr = Math.min(window.devicePixelRatio || 1, 2);
    W = rect.width; H = rect.height;
    cv.width = Math.round(W * dpr); cv.height = Math.round(H * dpr);
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
  }
  function board() {
    const size = Math.min(W, H) * 0.92;
    const cell = size / N;
    return { x: (W - size) / 2, y: (H - size) / 2, size, cell };
  }

  // ---- 描画 ----
  function roundRect(x, y, w, h, r) {
    ctx.beginPath();
    ctx.moveTo(x + r, y);
    ctx.arcTo(x + w, y, x + w, y + h, r);
    ctx.arcTo(x + w, y + h, x, y + h, r);
    ctx.arcTo(x, y + h, x, y, r);
    ctx.arcTo(x, y, x + w, y, r);
    ctx.closePath();
  }
  function draw() {
    ctx.clearRect(0, 0, W, H);
    if (!W) return;
    const b = board();
    // マス目
    for (let r = 0; r < N; r++) for (let c = 0; c < N; c++) {
      ctx.fillStyle = (r + c) % 2 ? 'rgba(255,255,255,.05)' : 'rgba(255,255,255,.09)';
      roundRect(b.x + c * b.cell + 2, b.y + r * b.cell + 2, b.cell - 4, b.cell - 4, b.cell * 0.14);
      ctx.fill();
    }
  }

  startBtn.addEventListener('click', () => overlay.classList.add('hidden'));
  window.addEventListener('resize', () => { resize(); draw(); });
  resize();
  draw();
})();
```

### コード全体を `(() => { ... })();` で包む理由

これは **即時実行関数** と呼ばれる書き方です。中で宣言した変数がページ全体（グローバル）に漏れないので、ほかのスクリプトと名前がぶつかりません。`$` は `document.getElementById` を短く書くための小さな関数です。

### Canvas とは

`<canvas>` は JavaScript で自由に絵を描ける「キャンバス」です。`getContext('2d')` で取り出した `ctx`（コンテキスト）に `fill`（塗る）や `stroke`（線を引く）などの命令を出して描きます。座標は左上が `(0, 0)` で、右に行くほど x、**下に行くほど y が大きく** なります。

### 大きさを決める `resize()`

- `cv.getBoundingClientRect()` で、CSS によって決まった Canvas の見た目の大きさ（幅 `W`・高さ `H`）を調べます。
- Canvas には「CSS で見える大きさ」と「内部の画素数」（`cv.width` / `cv.height`）の2つのサイズがあります。高精細な画面では1 CSS ピクセルに複数の物理ピクセルが詰まっている（`devicePixelRatio`）ので、内部の画素数を `W × dpr` にしないと絵がぼやけます。重くなりすぎないように、`dpr` は最大2にしています。
- `ctx.setTransform(dpr, 0, 0, dpr, 0, 0)` で「座標を dpr 倍して描く」設定にします。これで、以降は CSS ピクセル単位の座標を指定するだけでくっきり描けます。

### 盤面の位置と大きさを返す `board()`

盤面は正方形です。Canvas の幅と高さの **小さいほう** の 92% を一辺 `size` にし、それを `N` 等分したものが1マスの大きさ `cell` です。左上の位置 `x, y` は「余った分の半分」にすると、盤面が画面のまん中に来ます。

描画でも、あとで作るタップの判定でも、この `board()` を呼んで同じ数字を使います。**見た目と判定で同じ計算を使う** ことで、「見えている場所」と「タップできる場所」がずれなくなります。

### 角丸の四角を描く `roundRect()`

`ctx.arcTo(x1, y1, x2, y2, r)` は「今いる点から (x1, y1) に向かい、(x2, y2) の方向へ曲がる角を、半径 r で丸める」命令です。四隅でこれを4回くり返すと角丸の四角形の **パス**（輪郭）ができます。パスを作っただけでは何も描かれないので、使う側で `ctx.fill()` を呼んで塗ります。

### マス目を描く `draw()`

- `ctx.clearRect()` で前の絵を消してから描きます。`if (!W) return;` は、まだ大きさが決まっていないときに何もしないための安全策です。
- 2重の `for` で `N × N` 個のマスを描きます。`(r + c) % 2` で行と列の和が奇数か偶数かを見て、**市松模様** のように明るさを少し変えています。
- マスは `+2` / `-4` して少し小さく描き、マスとマスの間にすき間を作っています。
- Canvas の大きさを変えると中身が消えるので、ウィンドウの大きさが変わったら `resize()` のあとに `draw()` で描き直しています。

> [!CHECK] 動作チェック
> - `index.html` をブラウザで開くと、タイトル「やじるしエスケープ」と説明文、「タップでスタート」ボタンが表示される
> - ボタンを押すとオーバーレイが消え、画面のまん中に 5×5 の市松模様のマス目が見える
> - ウィンドウの大きさを変えても、マス目が正方形のまま画面のまん中に描き直される

> [!NOTE]
> ヘッダーの数字やハートの行は、まだ JavaScript から何も書き込んでいないので「1・0・0」のままで、ハートも表示されません。これからのステップで少しずつ動き出します。
