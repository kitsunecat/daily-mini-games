## このステップのゴール

最後の仕上げです。

- **ハイスコア** をブラウザに保存して、次に開いたときも BEST に表示する
- **効果音** をつける（飛ばしたとき・ぶつかったとき・クリア・時間切れ・スタート）
- ゲームオーバー画面で、ハイスコアを更新したら「🎉 ハイスコア更新！」と出す

これで完成品と同じゲームになります。

## ハイスコアを読み込む

ファイルの上の `const scoreEl = $('score'), levelEl = $('level');` を、`bestEl` を足して **書きかえ** ます。

```js:game.js
  const scoreEl = $('score'), bestEl = $('best'), levelEl = $('level');
```

`const MAX_LIVES = 3;` の **下** に追加します。

```js:game.js
  const BEST_KEY = 'arrow-escape-best';

  let best = 0;
  try { best = parseInt(localStorage.getItem(BEST_KEY), 10) || 0; } catch (e) {}
  bestEl.textContent = best;
```

- **localStorage** は、ブラウザにちょっとした文字列を保存しておける場所です。ページを閉じても残ります。`setItem(キー, 値)` で保存、`getItem(キー)` で読み込みです。
- 保存されるのは **文字列** なので、`parseInt(..., 10)` で数に直します。まだ何も保存されていないと `getItem` は `null` を返し、`parseInt` の結果は `NaN` になるので、`|| 0` で 0 にしています。
- キーの名前は、同じサイトのほかのゲームとぶつからないようにゲームごとに変えます。
- プライベートブラウズなど、localStorage が使えない環境ではエラーになることがあるので、`try { ... } catch (e) {}` で包んで、エラーでもゲームは止まらないようにしています。

## 効果音の関数を追加する

`let W = 0, H = 0, dpr = 1;` の **下** に追加します。

```js:game.js
  // ---- 効果音（Web Audio） ----
  let actx = null;
  function beep(freq, dur, type = 'sine', vol = 0.12, slide = 0) {
    try {
      if (!actx) actx = new (window.AudioContext || window.webkitAudioContext)();
      const t = actx.currentTime;
      const o = actx.createOscillator(), g = actx.createGain();
      o.type = type;
      o.frequency.setValueAtTime(freq, t);
      if (slide) o.frequency.exponentialRampToValueAtTime(freq * slide, t + dur);
      g.gain.setValueAtTime(vol, t);
      g.gain.exponentialRampToValueAtTime(0.001, t + dur);
      o.connect(g).connect(actx.destination);
      o.start(t); o.stop(t + dur);
    } catch (e) {}
  }
```

**Web Audio API** を使うと、音声ファイルを用意しなくても、その場で音を作って鳴らせます。

- `AudioContext` は音を扱うための土台です。ブラウザは「ユーザーが何か操作するまで音を鳴らさない」決まりがあるので、最初に音を鳴らすとき（＝最初のタップやクリックのあと）に作ります。
- `createOscillator()` は一定の高さの音を出し続ける **発振器** です。`frequency` が音の高さ（Hz）、`type` が音色です（`'sine'` はやわらかい音、`'triangle'` は少し明るい音、`'square'` や `'sawtooth'` はビーッという固い音）。
- `createGain()` は **音量つまみ** です。`exponentialRampToValueAtTime` で `dur` 秒かけて音量をほぼ0まで下げると、「ポン」と自然に消える音になります。
- `slide` を指定すると、音の高さも `dur` 秒かけて `freq × slide` まで変わります。1より大きいと上がる音（ヒュン）、小さいと下がる音（ブーン）になります。
- 発振器 → 音量つまみ → スピーカー（`actx.destination`）の順に `connect` でつないで、`start` / `stop` で鳴らす時間を決めます。

## 効果音を鳴らす

次の5か所に、`beep(...)` の1行を **追加** します。

`tapCell()` の、飛んでいけるとき（`if (isEmpty()) levelClear();` の **上**）:

```js:game.js
      beep(520 + Math.random() * 80, 0.12, 'triangle', 0.1, 1.8);
```

`tapCell()` の、ぶつかったとき（`shake = 8;` の **下**）:

```js:game.js
      beep(140, 0.25, 'square', 0.08, 0.6);
```

`start()` の最後（`updateHud();` の **下**）:

```js:game.js
    beep(660, 0.1, 'triangle');
```

`levelClear()` の `burst();` の **下**:

```js:game.js
    [660, 880, 1100].forEach((f, i) => setTimeout(() => beep(f, 0.15, 'triangle', 0.1), i * 90));
```

`update(dt)` の時間切れの処理（`shake = 8;` の **下**）:

```js:game.js
        beep(110, 0.35, 'sawtooth', 0.07, 0.5);
```

- 飛ばす音は高さを毎回少しランダムにずらし（`Math.random() * 80`）、上がる音にしています。同じ音のくり返しより、ずっと気持ちよく聞こえます。
- ぶつかった音と時間切れの音は、低く下がっていく固い音で「失敗」を伝えます。
- クリアの音は、ド・ミ・ソのように少しずつ高い3つの音を 0.09 秒ずつずらして鳴らし、ファンファーレのようにしています。

## ハイスコアを保存・表示する

`gameOver()` を次のように **まるごと書きかえ** ます。

```js:game.js
  function gameOver() {
    state = 'over';
    let isBest = false;
    if (score > best) {
      best = score; isBest = true;
      try { localStorage.setItem(BEST_KEY, String(best)); } catch (e) {}
    }
    updateHud();
    setTimeout(() => {
      ovTitle.textContent = 'ゲームオーバー';
      ovText.innerHTML = `LEVEL ${level} まで到達<br>スコア <b>${score}</b>${isBest ? '<br>🎉 ハイスコア更新！' : ''}`;
      startBtn.textContent = 'もう一度';
      overlay.classList.remove('hidden');
    }, 700);
  }
```

`updateHud()` の `scoreEl.textContent = score;` の **下** に、BEST の表示を追加します。

```js:game.js
    bestEl.textContent = Math.max(best, score);
```

- ゲームオーバーになった時点でスコアが今までの最高より高ければ、`best` を更新して localStorage に保存します。
- `${isBest ? '...' : ''}` は **三項演算子** です。「条件 ? 真のとき : 偽のとき」で、ハイスコアのときだけメッセージを足しています。
- BEST の表示に `Math.max(best, score)` を使うと、プレイ中に最高記録を超えた瞬間から BEST の数字も一緒に増えていき、盛り上がります。

> [!CHECK] 動作チェック
> - ブロックを飛ばすと「ヒュン」と上がる音、ぶつかると「ブッ」と低い音、クリアするとファンファーレが鳴る
> - ゲームオーバーになると、今までの最高より高ければ「🎉 ハイスコア更新！」と表示され、BEST がそのスコアになる
> - ページを再読み込みしても、BEST の数字が残っている
> - 「もう一度」で SCORE と LEVEL が 0・1 に戻り、BEST はそのまま
> - これで完成品と同じ遊び方ができる。おつかれさまでした！

## 改造アイデア

> [!TIP]
> **ヒント機能:** 一定時間タップしなかったら、今すぐ飛ばせるブロックを1つ点滅させてみましょう。ステップ5の `pathClear(grid, r, c, t.dir)` で、飛ばせるブロックはすぐ見つかります。

> [!TIP]
> **動かせない壁ブロック:** `{ wall: true }` のような、タップできず飛ばない灰色のブロックを盤面に混ぜると、一気にパズルが難しくなります。`generate()` の「解いてみて直す」部分で、壁は取り除かないように扱うのを忘れずに。

> [!TIP]
> **連続ボーナス:** ぶつからずに続けて飛ばした回数を数えて、5回、10回…と続くほど1つあたりの得点を増やしてみましょう。ぶつかったら0に戻します。`showToast()` で「5連続！」と出すと気持ちいいです。

> [!TIP]
> **手数チャレンジ:** 制限時間の代わりに「ハート3つで全レベルを何手でクリアできるか」を競うモードを作ってみましょう。`update()` の時間切れ処理を止めて、`tapCell()` で手数を数えます。
