## このステップのゴール

ゲームとしての「目標」と「緊張感」を加えます。

- ブロックを1つ飛ばすごとに **10点**
- 盤面を空っぽにすると **レベルクリア**。残り時間に応じたボーナスが入り、ハートが1つ回復して、次のレベルへ
- 上の **時間バー** が減っていき、0になるとハートが1つ減る
- クリアしたときに「LEVEL 1 クリア！ +170」のような文字（トースト）と、色とりどりの紙吹雪（パーティクル）を出す

## 要素と変数を追加する

ファイルの上の要素を取る3行を、次の4行に **書きかえ** ます。

```js:game.js
  const scoreEl = $('score'), levelEl = $('level');
  const livesEl = $('lives'), timeFill = $('timefill');
  const overlay = $('overlay'), ovTitle = $('ov-title'), ovText = $('ov-text');
  const startBtn = $('start'), toast = $('toast');
```

変数の宣言も、次のように **書きかえ** ます（`let shake = 0;` と `let W = 0, ...` の行はそのまま残します）。

```js:game.js
  let N = 5, grid = [], movers = [], particles = [];
  let level = 1, score = 0, lives = MAX_LIVES;
  let timeLimit = 30, timeLeft = 30;
  let state = 'title'; // title | play | clear | over
```

- `particles` は紙吹雪のリスト、`timeLimit` はそのレベルの制限時間、`timeLeft` は残り時間（秒）です。
- `state` に `'clear'` が増えます。クリアして次の盤面が出るまでの1.2秒間です。この間はタップも時間切れも起きないようにします。

## 制限時間を決める

`generate()` の最後、`movers = [];` の **上** に追加します。

```js:game.js
    timeLimit = Math.round(10 + count * 1.6);
    timeLeft = timeLimit;
```

ブロック1つあたり 1.6 秒＋10秒です。ブロックが多い盤面ほど時間に余裕があります。

## 飛ばしたら得点、空になったらクリア

`tapCell()` の `if (!blocked) { ... }` の中、`movers.push(...)` の **下** に追加します。

```js:game.js
      score += 10;
      updateHud();
      if (isEmpty()) levelClear();
```

続いて、`cellAt()` 関数の **上** に、盤面が空かどうかを調べる関数を追加します。

```js:game.js
  function isEmpty() {
    for (const row of grid) for (const t of row) if (t) return false;
    return true;
  }
```

1つでもブロックが見つかったらすぐ `false` を返し、最後まで見つからなければ `true` です。

## 進行の関数を書きかえ・追加する

`start()` から `updateHud()` の終わりまでを、次のように **まるごと書きかえ** ます（`levelClear()`・`showToast()`・`burst()` が新しく増えます）。

```js:game.js
  function start() {
    level = 1; score = 0; lives = MAX_LIVES;
    particles = [];
    generate();
    state = 'play';
    overlay.classList.add('hidden');
    updateHud();
  }
  function levelClear() {
    state = 'clear';
    const bonus = Math.ceil(timeLeft) * 5 + level * 20;
    score += bonus;
    if (lives < MAX_LIVES) lives++;
    updateHud();
    showToast(`LEVEL ${level} クリア！ +${bonus}`);
    burst();
    setTimeout(() => {
      if (state !== 'clear') return;
      level++;
      generate();
      state = 'play';
      updateHud();
    }, 1200);
  }
  function gameOver() {
    state = 'over';
    setTimeout(() => {
      ovTitle.textContent = 'ゲームオーバー';
      ovText.innerHTML = `LEVEL ${level} まで到達<br>スコア <b>${score}</b>`;
      startBtn.textContent = 'もう一度';
      overlay.classList.remove('hidden');
    }, 700);
  }
  function updateHud() {
    scoreEl.textContent = score;
    levelEl.textContent = level;
    let h = '';
    for (let i = 0; i < MAX_LIVES; i++) h += `<span class="${i < lives ? '' : 'off'}">❤️</span>`;
    livesEl.innerHTML = h;
  }
  let toastTimer = 0;
  function showToast(text) {
    toast.textContent = text;
    toast.classList.add('show');
    clearTimeout(toastTimer);
    toastTimer = setTimeout(() => toast.classList.remove('show'), 1000);
  }
  function burst() {
    for (let i = 0; i < 40; i++) {
      const a = Math.random() * Math.PI * 2, s = 2 + Math.random() * 5;
      particles.push({ x: W / 2, y: H / 2, vx: Math.cos(a) * s, vy: Math.sin(a) * s, life: 1, col: COLORS[i % 4] });
    }
  }
```

- **ボーナス:** 残り秒数（切り上げ）×5点 ＋ レベル×20点。早く解くほど得をします。
- **次のレベルへ:** `setTimeout` で 1.2 秒待ってから `level++` して新しい盤面を作ります。待っている間にゲームオーバーなどで状態が変わっていたら何もしないよう、最初に `state !== 'clear'` を確かめています。
- **`` `LEVEL ${level} クリア！` ``** のようにバッククォートで囲んだ文字列は **テンプレートリテラル** で、`${...}` の中に変数や式を埋め込めます。
- **トースト:** `show` クラスをつけて文字を出し、1秒後に外します。続けて呼ばれたときに前のタイマーで早く消えないよう、`clearTimeout` で前の予約を取り消してから予約し直します。
- **紙吹雪:** 画面のまん中から、ランダムな角度 `a` とランダムな速さ `s` で40個の四角を飛ばします。`Math.cos(a)`・`Math.sin(a)` で「角度 a の方向に長さ1」の x・y が求まるので、`s` をかければその方向の速度になります。

## 時間と紙吹雪を動かす

`update(dt)` 関数を、次のように **まるごと書きかえ** ます。

```js:game.js
  function update(dt) {
    if (state === 'play') {
      timeLeft -= dt;
      if (timeLeft <= 0) {
        lives--;
        shake = 8;
        showToast('時間切れ！ ハート -1');
        timeLeft = timeLimit * 0.5;
        updateHud();
        if (lives <= 0) { timeLeft = 0; gameOver(); }
      }
    }
    timeFill.style.width = `${Math.max(0, timeLeft / timeLimit) * 100}%`;
    for (const m of movers) m.t += dt;
    movers = movers.filter((m) => m.t < 0.6);
    for (const row of grid) for (const t of row) {
      if (!t) continue;
      if (t.bump) { t.bump.t += dt; if (t.bump.t > 0.35) t.bump = null; }
      if (t.flash > 0) t.flash -= dt * 2.5;
    }
    for (const p of particles) { p.x += p.vx; p.y += p.vy; p.vy += 0.12; p.life -= dt * 1.2; }
    particles = particles.filter((p) => p.life > 0);
    shake *= 0.85;
  }
```

- 遊んでいる間だけ `timeLeft` を `dt` ずつ減らします。0 になったらハートを1つ減らし、すぐゲームオーバーにはせず **制限時間の半分をもう一度** 与えます。
- 時間バーは、残りの割合 `timeLeft / timeLimit` を `%` にして `#timefill` の `width` に入れるだけです。CSS のグラデーションのおかげで、減るにつれて緑から黄色の部分が目立ってきます。
- 紙吹雪は、位置に速度を足し、`p.vy += 0.12` で下向きに少しずつ加速させて（重力）、`life` が 0 になったら消します。

## 紙吹雪を描く

`draw()` の最後、`ctx.restore();` の **下** に追加します。

```js:game.js
    for (const p of particles) {
      ctx.globalAlpha = Math.max(0, p.life);
      ctx.fillStyle = p.col;
      ctx.fillRect(p.x - 4, p.y - 4, 8, 8);
    }
    ctx.globalAlpha = 1;
```

`ctx.restore()` の **あと** に描くのは、画面の揺れ（`translate`）の影響を受けないようにするためです。

> [!CHECK] 動作チェック
> - スタートすると上の時間バーが右から左へだんだん短くなる
> - ブロックを飛ばすたびに SCORE が 10 ずつ増える
> - 盤面を空にすると「LEVEL 1 クリア！ +〇〇」と出て紙吹雪が飛び、1.2秒後に LEVEL が 2 になって新しい盤面が出る。ハートが減っていれば1つ回復する
> - しばらく何もしないで待つと「時間切れ！ ハート -1」と出て、時間バーが半分から再スタートする
> - ゲームオーバー画面に、到達したレベルとスコアが表示される
