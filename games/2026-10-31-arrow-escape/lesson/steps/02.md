## このステップのゴール

盤面にランダムな向きの **やじるしブロック** を並べて描きます。ここで、このゲームの心臓部になる2つの考え方が出てきます。

- 盤面を **2次元配列** `grid` で持つ（`grid[行][列]` にブロックが入っているか、`null`＝空か）
- 「上・右・下・左」を **0〜3 の数字** で表し、`DX` / `DY` という配列で「1マス進むと x と y がいくつ変わるか」を引けるようにする

## 定数を追加する

`const overlay = $('overlay'), startBtn = $('start');` の **下** に、向きと色の定数を追加します。

```js:game.js
  // 0:上 1:右 2:下 3:左
  const DX = [0, 1, 0, -1], DY = [-1, 0, 1, 0];
  const COLORS = ['#ff7a7a', '#ffc75a', '#5ee0b5', '#6ab8ff'];
  const SHADES = ['#c94f5a', '#c9923a', '#2f9c7b', '#3d82c4'];
```

- 向き `d` が 1（右）なら `DX[1] = 1, DY[1] = 0` なので「x が1増える＝右へ1マス」。向き 0（上）なら `DY[0] = -1` で「y が1減る＝上へ1マス」です。Canvas と同じく **下が y のプラス方向** なので、上が `-1` になる点に注意しましょう。
- こうしておくと「右なら…、上なら…」と `if` を4つ書く代わりに、`x + DX[d]` の1行で4方向すべてを扱えます。
- `COLORS` はブロックの表の色、`SHADES` は少し暗い「側面（影）」の色です。どちらも向きの番号で引くので、**同じ向きのブロックは同じ色** になり、パッと見て向きが分かります。

## 盤面の変数と `generate()` を追加する

`let N = 5;` の行を、`grid` を足して次のように **書きかえ** ます。

```js:game.js
  let N = 5, grid = [];
```

続いて `// ---- レイアウト ----` の **上** に、盤面を作る関数を追加します。

```js:game.js
  // ---- 盤面生成（仮） ----
  function generate() {
    grid = Array.from({ length: N }, () => Array(N).fill(null));
    for (let r = 0; r < N; r++) for (let c = 0; c < N; c++) {
      if (Math.random() < 0.6) grid[r][c] = { dir: Math.floor(Math.random() * 4) };
    }
  }
```

- `Array.from({ length: N }, () => Array(N).fill(null))` は「中身が全部 `null` の行を N 本持った配列」、つまり **N×N の空の盤面** を作ります。
- `Array(N).fill(null)` を1つ作って N 回使い回すと、全部の行が **同じ配列** を指してしまい、1マス変えると全行が変わるバグになります。`Array.from` の関数の中で毎回新しく作るのがポイントです。
- 各マスに 60% の確率でブロックを置きます。ブロックは `{ dir: 向き }` というオブジェクトにしておきます。あとで「ぶつかったときの揺れ」などの情報も同じオブジェクトに持たせられるからです。
- 名前に「仮」とつけたとおり、この並べ方だと **解けない盤面** ができることがあります。ステップ5でちゃんとしたものに作り直します。

## ブロックを描く `drawTile()`

`roundRect()` 関数の **下** に追加します。

```js:game.js
  function drawTile(cx, cy, s, dir, alpha, flash) {
    const pad = s * 0.08, w = s - pad * 2;
    ctx.globalAlpha = alpha;
    ctx.fillStyle = SHADES[dir];
    roundRect(cx - w / 2, cy - w / 2 + s * 0.05, w, w, s * 0.18); ctx.fill();
    ctx.fillStyle = flash > 0 ? '#ff4d4d' : COLORS[dir];
    roundRect(cx - w / 2, cy - w / 2, w, w, s * 0.18); ctx.fill();
    // やじるし
    ctx.save();
    ctx.translate(cx, cy);
    ctx.rotate(dir * Math.PI / 2);
    ctx.fillStyle = '#fff';
    const a = w * 0.3;
    ctx.beginPath();
    ctx.moveTo(0, -a);
    ctx.lineTo(a * 0.85, -a * 0.05);
    ctx.lineTo(a * 0.3, -a * 0.05);
    ctx.lineTo(a * 0.3, a);
    ctx.lineTo(-a * 0.3, a);
    ctx.lineTo(-a * 0.3, -a * 0.05);
    ctx.lineTo(-a * 0.85, -a * 0.05);
    ctx.closePath();
    ctx.fill();
    ctx.restore();
    ctx.globalAlpha = 1;
  }
```

引数は「中心の座標 `cx, cy`」「マスの大きさ `s`」「向き `dir`」「不透明度 `alpha`」「赤く光らせるか `flash`」です。`alpha` と `flash` はあとのステップ（飛んでいくときに薄くする・ぶつかったときに赤くする）で使うので、今は `1` と `0` を渡します。

- **立体感の出し方:** まず暗い色（`SHADES`）の四角を少し **下にずらして** 描き、その上に明るい色の四角を重ねます。下にはみ出た暗い部分が「ブロックの側面」に見えます。
- **やじるしの描き方:** やじるしは「上向き」の形だけを用意し、向きに合わせて回転させます。
  - `ctx.translate(cx, cy)` で座標の原点をブロックの中心に動かします。
  - `ctx.rotate(角度)` で座標全体を回します。角度は **ラジアン**（180° が `Math.PI`）で、`dir * Math.PI / 2` は向き1で 90°、2で 180°、3で 270° です。Canvas の回転は時計回りなので、上向きの形が右・下・左を向きます。
  - `moveTo` / `lineTo` で、原点を中心にした上向きのやじるし（三角の頭＋四角い軸）を7つの点で描きます。
- `ctx.save()` と `ctx.restore()` は、`translate` や `rotate` をしたあと **元の状態に戻す** ためのペアです。これを忘れると次のブロックが回った座標で描かれてしまいます。

## `draw()` でブロックを描く

`draw()` の「マス目」の `for` ループの **下**（関数の閉じカッコ `}` の手前）に追加します。

```js:game.js
    // ブロック
    for (let r = 0; r < N; r++) for (let c = 0; c < N; c++) {
      const t = grid[r][c];
      if (!t) continue;
      drawTile(b.x + (c + 0.5) * b.cell, b.y + (r + 0.5) * b.cell, b.cell, t.dir, 1, 0);
    }
```

`c` 列目のマスの中心は「盤面の左端 + (c + 0.5) マス分」です。行 `r` が y、列 `c` が x に対応することに注意しましょう。

## 最初に盤面を作る

ファイルの最後の初期化部分を、`generate()` を足して次のように **書きかえ** ます。

```js:game.js
  startBtn.addEventListener('click', () => overlay.classList.add('hidden'));
  window.addEventListener('resize', () => { resize(); draw(); });
  resize();
  generate();
  draw();
```

> [!CHECK] 動作チェック
> - スタートすると、マス目の上に赤・黄・緑・青のブロックが並び、それぞれに白いやじるしが描かれている
> - 赤は上、黄は右、緑は下、青は左を向いている
> - ブロックの下側に少し暗い色の「側面」が見え、立体的に見える
> - 再読み込みするたびに、並び方と向きが変わる
