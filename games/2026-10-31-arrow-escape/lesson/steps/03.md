## このステップのゴール

ブロックをタップすると、やじるしの向きへ **まっすぐ飛んでいって消える** ようにします。そのために次の3つを作ります。

- タップした位置から「何行何列のマスか」を求める
- やじるしの先を1マスずつたどって、ほかのブロックが無いか（飛んでいけるか）を調べる
- `requestAnimationFrame` を使った **ゲームループ** で、飛んでいくブロックを毎フレーム動かす

ぶつかる場合の処理は次のステップで作ります。このステップでは、ぶつかるブロックをタップしても何も起きません。

## 変数を追加する

`let N = 5, grid = [];` の行を、次の2行に **書きかえ** ます。

```js:game.js
  let N = 5, grid = [], movers = [];
  let state = 'title'; // title | play
```

- `movers` は「いま飛んでいる途中のブロック」のリストです。盤面 `grid` からはすぐ消してしまい、見た目のアニメーションだけをこちらで管理します。
- `state` はゲームの状態です。タイトル画面中は `'title'`、遊んでいる間は `'play'` にして、タイトル画面でうっかり盤面をタップしても反応しないようにします。

## タップの処理を追加する

`// ---- 描画 ----` の **上** に、次のコードをまとめて追加します。

```js:game.js
  // ---- 操作 ----
  function tapCell(r, c) {
    if (state !== 'play') return;
    const t = grid[r] && grid[r][c];
    if (!t) return;
    const d = t.dir;
    // 進める距離を調べる
    let x = c + DX[d], y = r + DY[d], dist = 0, blocked = false;
    while (x >= 0 && y >= 0 && x < N && y < N) {
      if (grid[y][x]) { blocked = true; break; }
      x += DX[d]; y += DY[d]; dist++;
    }
    if (!blocked) {
      grid[r][c] = null;
      movers.push({ r, c, dir: d, t: 0, dist: dist + 6 });
    }
  }
  function cellAt(px, py) {
    const b = board();
    const c = Math.floor((px - b.x) / b.cell), r = Math.floor((py - b.y) / b.cell);
    if (r < 0 || c < 0 || r >= N || c >= N) return null;
    return { r, c };
  }

  cv.addEventListener('pointerdown', (e) => {
    e.preventDefault();
    const rect = cv.getBoundingClientRect();
    const hit = cellAt(e.clientX - rect.left, e.clientY - rect.top);
    if (hit) tapCell(hit.r, hit.c);
  });
  startBtn.addEventListener('click', start);

  // ---- 進行 ----
  function start() {
    generate();
    state = 'play';
    overlay.classList.add('hidden');
  }
```

### やじるしの先をたどる `tapCell()`

このゲームでいちばん大事な判定です。

1. まず「隣のマス」`(x, y) = (c + DX[d], r + DY[d])` から調べ始めます。
2. `while` の条件 `x >= 0 && y >= 0 && x < N && y < N` は「まだ盤面の中にいるあいだ」という意味です。
3. そのマスにブロックがあれば `blocked = true` にしてループを抜けます。無ければもう1マス先へ進み、空いていたマスの数 `dist` を数えます。
4. 盤面の外に出るまで何もぶつからなければ、飛んでいけます。`grid[r][c] = null` で盤面から消し、`movers` にアニメーション用の情報を追加します。

`dist + 6` は「何マスぶん飛ぶか」です。盤面の端までの距離に6マス足して、画面の外まで飛んでいくように見せています。

`const t = grid[r] && grid[r][c];` の `&&` は、`grid[r]` が無いとき（範囲外）にエラーにせず `undefined` を返すための書き方です。

### タップ位置からマスを求める `cellAt()`

`pointerdown` イベントの `e.clientX / e.clientY` は **ページ全体での座標** なので、Canvas の左上の位置（`getBoundingClientRect()`）を引いて「Canvas の中での座標」に直します。そこから盤面の左上 `b.x, b.y` を引いて1マスの大きさで割り、`Math.floor` で切り捨てれば列 `c` と行 `r` が分かります。盤面の外なら `null` を返します。

**Pointer Events**（`pointerdown`）は、マウスのクリックとスマホのタッチを同じように扱えるイベントです。`e.preventDefault()` で、タッチしたときのスクロールなどブラウザの余計な動きを止めています。

### `start()` を用意する

スタートボタンは、これまでの「オーバーレイを消すだけ」から `start()` を呼ぶように変えます。`start()` で新しい盤面を作ってから `state` を `'play'` にします。関数宣言（`function start() {...}`）は、ファイルのあとの方に書いても前の行から呼べます（**巻き上げ**）。

## ゲームループを作る

`draw()` 関数の **上** に、次の2つの関数を追加します。

```js:game.js
  let last = performance.now();
  function frame(now) {
    const dt = Math.min(0.05, (now - last) / 1000);
    last = now;
    update(dt);
    draw();
    requestAnimationFrame(frame);
  }
  function update(dt) {
    for (const m of movers) m.t += dt;
    movers = movers.filter((m) => m.t < 0.6);
  }
```

- `requestAnimationFrame(frame)` は「次に画面を描きかえるタイミングで `frame` を呼んで」というお願いです。`frame` の最後でまた自分を予約するので、1秒に約60回 `update`（動かす）→ `draw`（描く）がくり返されます。これが **ゲームループ** です。
- `frame` には「今の時刻（ミリ秒）」が渡されます。前回との差を秒に直したものが `dt`（デルタタイム）です。動きを `dt` に合わせて計算すると、パソコンの速さに関係なく同じ速さで動きます。別のタブに切り替えて戻ったときなどに `dt` が大きくなりすぎないよう、最大 0.05 秒に抑えています。
- `update` では、飛んでいるブロックの経過時間 `m.t` を増やし、`filter` で 0.6 秒たったものをリストから取り除きます。

## 飛んでいくブロックを描く

`draw()` の「ブロック」の `for` ループの **下** に追加します。

```js:game.js
    // 飛んでいくブロック
    for (const m of movers) {
      const p = m.t / 0.6;
      const k = (p * p) * m.dist * b.cell;
      drawTile(b.x + (m.c + 0.5) * b.cell + DX[m.dir] * k, b.y + (m.r + 0.5) * b.cell + DY[m.dir] * k, b.cell, m.dir, 1 - p, 0);
    }
```

- `p` は 0 から 1 まで進む「進み具合」です。
- 進んだ距離 `k` を `p` ではなく `p * p` に比例させると、最初はゆっくり、だんだん速く飛んでいきます（**イージング**）。勢いよく発射された感じが出ます。
- 元の位置から、向き `DX` / `DY` の方向へ `k` だけずらして描きます。`alpha` に `1 - p` を渡して、飛びながら薄くしていきます。

## 初期化をゲームループに切りかえる

ファイルの最後の初期化部分を、次のように **書きかえ** ます。スタートボタンのイベントは上で登録したので、ここからは消します。

```js:game.js
  window.addEventListener('resize', resize);
  resize();
  generate();
  requestAnimationFrame(frame);
```

毎フレーム `draw()` が呼ばれるようになったので、`resize` のあとに自分で `draw()` を呼ぶ必要はもうありません。

> [!CHECK] 動作チェック
> - スタート前に盤面をタップしても何も起きない
> - スタートしてから、やじるしの先が空いている（盤面の端まで何も無い）ブロックをタップすると、その向きにだんだん速くなりながら飛んでいき、薄くなって消える
> - やじるしの先にほかのブロックがあるブロックをタップしても、まだ何も起きない
> - 飛ばしてできたすき間を使って、ほかのブロックも飛ばせるようになる
