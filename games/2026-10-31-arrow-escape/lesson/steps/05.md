## このステップのゴール

パズルゲームでいちばん困るのは「どうやっても解けない問題」が出ることです。このステップでは、ランダムに並べたあと **コンピューターが実際に解いてみて、詰まったらブロックの向きを直す** ことで、**必ず解ける盤面** を作ります。あわせて、レベルが上がるほど盤面が大きく、ブロックがぎっしりになるようにします。

## 考え方

ブロックを1つ取り除いても、ほかのブロックの道が **ふさがることはありません**（空きマスが増えるだけ）。ということは、「今すぐ飛ばせるブロックを、全部まとめて取り除く」をくり返していけば、取り除ける順番が見つかるかどうかを確かめられます。

1. 今すぐ飛ばせる（やじるしの先が盤面の端まで空いている）ブロックを全部探して、取り除く
2. 1つも無ければ「詰まった」状態。残っているブロックの中から、**向きを変えれば飛ばせるもの** を1つ探して、その向きに直す
3. 全部なくなるまで 1〜2 をくり返す

2 で向きを直したブロックは、その時点で必ず飛ばせるので、毎回少なくとも1つはブロックが減っていきます。だからこのくり返しは必ず終わり、終わったときには「解ける順番」が1つ見つかっている、というしくみです。

> [!NOTE]
> 詰まったとき、残っているブロックのうち **外側にあるもの** は、少なくとも盤面の外側を向けば必ず飛ばせます。なので 2 で「向きを変えれば飛ばせるもの」が見つからない、ということはありません。

## レベルの変数を追加する

`let lives = MAX_LIVES;` の行を、次のように **書きかえ** ます。

```js:game.js
  let level = 1, lives = MAX_LIVES;
```

`start()` の1行目も、レベルを1に戻すように **書きかえ** ます。

```js:game.js
  function start() {
    level = 1; lives = MAX_LIVES;
```

## 盤面生成を作り直す

`// ---- 盤面生成（仮） ----` から `generate()` 関数の終わりまでを **削除** して、次のコードに **置きかえ** ます。

```js:game.js
  // ---- 盤面生成：必ず解ける配置をつくる ----
  function pathClear(g, r, c, d) {
    let x = c + DX[d], y = r + DY[d];
    while (x >= 0 && y >= 0 && x < N && y < N) {
      if (g[y][x]) return false;
      x += DX[d]; y += DY[d];
    }
    return true;
  }
  function shuffle(a) {
    for (let i = a.length - 1; i > 0; i--) {
      const j = Math.floor(Math.random() * (i + 1));
      [a[i], a[j]] = [a[j], a[i]];
    }
    return a;
  }
  function generate() {
    N = Math.min(8, 4 + Math.ceil(level / 2));
    const fill = Math.min(0.92, 0.5 + level * 0.06);
    grid = Array.from({ length: N }, () => Array(N).fill(null));
    const cells = [];
    for (let r = 0; r < N; r++) for (let c = 0; c < N; c++) cells.push([r, c]);
    shuffle(cells);
    const count = Math.max(6, Math.round(N * N * fill));
    for (let i = 0; i < count; i++) {
      const [r, c] = cells[i];
      grid[r][c] = { dir: Math.floor(Math.random() * 4) };
    }
    // 取り除ける順番を貪欲にたどり、詰まったら向きを直す
    const sim = grid.map((row) => row.map((t) => t));
    let left = count;
    while (left > 0) {
      const free = [];
      for (let r = 0; r < N; r++) for (let c = 0; c < N; c++) {
        const t = sim[r][c];
        if (t && pathClear(sim, r, c, t.dir)) free.push([r, c]);
      }
      if (free.length) {
        for (const [r, c] of free) { sim[r][c] = null; left--; }
        continue;
      }
      const rest = [];
      for (let r = 0; r < N; r++) for (let c = 0; c < N; c++) if (sim[r][c]) rest.push([r, c]);
      shuffle(rest);
      for (const [r, c] of rest) {
        const ok = [0, 1, 2, 3].filter((d) => pathClear(sim, r, c, d));
        if (ok.length) { sim[r][c].dir = ok[Math.floor(Math.random() * ok.length)]; break; }
      }
    }
    movers = [];
  }
```

### `pathClear()` — 道が空いているか

ステップ3の `tapCell()` で書いた「やじるしの先をたどる」ループと同じ考え方です。ただし、本物の `grid` ではなく **引数で渡した盤面 `g`** を調べ、向き `d` も引数で受け取ります。これで「シミュレーション用の盤面」や「もしこの向きだったら」も調べられます。

### `shuffle()` — 配列をランダムに並べかえる

**フィッシャー–イェーツのシャッフル** と呼ばれる定番の方法です。後ろから順に、「自分を含めた前のどれか」と入れかえていきます。`[a[i], a[j]] = [a[j], a[i]]` は **分割代入** を使った入れかえの書き方です。

### `generate()` — 3つのパート

1. **大きさと量を決める:** `N` はレベル1〜2で5、3〜4で6…と増えて、最大8マス。`fill`（ブロックで埋める割合）もレベルごとに 6% ずつ増えて、最大 92% です。
2. **ランダムに置く:** 全マスの座標を `cells` に集めてシャッフルし、先頭から `count` 個にブロックを置きます。「確率で置く」と違って、ブロックの数をぴったり決められます。
3. **解いてみて直す:** 上の「考え方」をそのままコードにしたものです。
   - `sim` は解くとき用の盤面のコピーです。`grid.map((row) => row.map((t) => t))` は **行の配列は新しく作り、中のブロックのオブジェクトは同じものを指す** コピーです。なので `sim[r][c] = null` としても本物の `grid` は消えませんが、`sim[r][c].dir = ...` で向きを直すと **本物の `grid` のブロックの向きも直ります**。この性質をうまく使っています。
   - `free` に今すぐ飛ばせるブロックを集め、あれば全部取り除いて `continue` で次の周へ。
   - 無ければ残りのブロックをシャッフルして順に見ていき、`[0, 1, 2, 3].filter(...)` で「飛ばせる向き」を集めます。見つかったらその中からランダムに選んで向きを直し、`break` で探すのをやめます。

最後に `movers = []` で、前の盤面で飛んでいる途中のブロックが残らないようにしています。

> [!CHECK] 動作チェック
> - スタートすると 5×5 の盤面に、前より多めのブロックが並んでいる
> - 何度遊んでも、ぶつからない順番を見つければ **必ず全部のブロックを飛ばせる**（まだ盤面が空になっても何も起きない。次のステップで作る）
> - レベルによる変化を試したいときは、`start()` の `level = 1;` を一時的に `level = 5;` にして再読み込みすると、7×7 のぎっしりした盤面になる（試したら元に戻す）

> [!WARNING]
> `while (left > 0)` のような「条件が成り立つあいだずっと回る」ループは、中で `left` が減らないとブラウザが固まってしまいます。書き写すときは `left--` や `break` の位置を見比べて確かめましょう。
