## このステップのゴール

やじるしの先にほかのブロックがあるとき、タップしたブロックが **ぶつかるところまで進んで、跳ね返って戻る** ようにします。ぶつかるとブロックが赤く光り、画面が揺れて、**ハートが1つ減ります**。ハートが0になったらゲームオーバーです。

## 要素と定数・変数を追加する

ファイルの上の `const overlay = $('overlay'), startBtn = $('start');` の行を、次の3行に **書きかえ** ます。

```js:game.js
  const livesEl = $('lives');
  const overlay = $('overlay'), ovTitle = $('ov-title'), ovText = $('ov-text');
  const startBtn = $('start');
```

ゲームオーバー画面でオーバーレイの見出しと文章を書きかえるので、`ov-title` と `ov-text` も取っておきます。

`const SHADES = [...]` の **下** に、ハートの最大数を追加します。

```js:game.js
  const MAX_LIVES = 3;
```

`let state = 'title'; // title | play` の行を、次の3行に **書きかえ** ます。

```js:game.js
  let lives = MAX_LIVES;
  let state = 'title'; // title | play | over
  let shake = 0;
```

`shake` は画面の揺れの強さです。ぶつかったときに 8 にして、毎フレーム少しずつ小さくしていきます。

## ぶつかったときの処理

`tapCell()` の最後の `if (!blocked) { ... }` に、`else` を **追加** します。

```js:game.js
    if (!blocked) {
      grid[r][c] = null;
      movers.push({ r, c, dir: d, t: 0, dist: dist + 6 });
    } else {
      t.bump = { t: 0, dist: dist + 0.25 };
      t.flash = 1;
      lives--;
      shake = 8;
      updateHud();
      if (lives <= 0) gameOver();
    }
```

- ブロック自身のオブジェクト `t` に、アニメーション用の情報を書き込みます。`bump` は「ぶつかって戻る動き」で、`dist + 0.25` は「空いているマスの数＋ちょっとめり込む」距離です。前のステップで数えておいた `dist` がここで役に立ちます。
- `flash` は赤く光る強さで、1 から 0 に向かって減らしていきます。
- ブロックは盤面から消えず、同じ場所に残ります。

## ハート表示とゲームオーバー

`start()` 関数を次のように **書きかえ** て、その **下** に `gameOver()` と `updateHud()` を追加します。

```js:game.js
  function start() {
    lives = MAX_LIVES;
    generate();
    state = 'play';
    overlay.classList.add('hidden');
    updateHud();
  }
  function gameOver() {
    state = 'over';
    setTimeout(() => {
      ovTitle.textContent = 'ゲームオーバー';
      ovText.innerHTML = 'ハートがなくなってしまった…';
      startBtn.textContent = 'もう一度';
      overlay.classList.remove('hidden');
    }, 700);
  }
  function updateHud() {
    let h = '';
    for (let i = 0; i < MAX_LIVES; i++) h += `<span class="${i < lives ? '' : 'off'}">❤️</span>`;
    livesEl.innerHTML = h;
  }
```

- `updateHud()` は画面上の表示（**HUD**）を今の状態にそろえる関数です。ハートを `MAX_LIVES` 個並べ、残っていない分には `off` クラスをつけて薄くします（CSS の `#lives .off`）。
- `gameOver()` では `state` を `'over'` にしてタップを受け付けなくし、`setTimeout` で 0.7 秒待ってからオーバーレイを出します。すぐに出すと、最後にぶつかった動きが見えないからです。
- ボタンの文字を「もう一度」に変えておけば、同じボタンでリトライできます。`start()` でハートを満タンに戻しているので、何度でも遊べます。

## 揺れと光を動かす

`update(dt)` 関数の最後（`movers = movers.filter(...)` の **下**）に追加します。

```js:game.js
    for (const row of grid) for (const t of row) {
      if (!t) continue;
      if (t.bump) { t.bump.t += dt; if (t.bump.t > 0.35) t.bump = null; }
      if (t.flash > 0) t.flash -= dt * 2.5;
    }
    shake *= 0.85;
```

- `bump` は 0.35 秒たったら `null` に戻して終わりにします。
- `flash` は1秒に 2.5 ずつ減るので、約0.4秒で赤い光が消えます。
- `shake *= 0.85` のように **毎フレーム一定の割合をかける** と、最初は大きく、だんだん小さくなってすっと止まる自然な減り方になります。

## 揺れ・跳ね返り・光を描く

`draw()` 関数を、次のように **まるごと書きかえ** ます。

```js:game.js
  function draw() {
    ctx.clearRect(0, 0, W, H);
    if (!W) return;
    const b = board();
    ctx.save();
    if (shake > 0.3) ctx.translate((Math.random() - 0.5) * shake, (Math.random() - 0.5) * shake);
    // マス目
    for (let r = 0; r < N; r++) for (let c = 0; c < N; c++) {
      ctx.fillStyle = (r + c) % 2 ? 'rgba(255,255,255,.05)' : 'rgba(255,255,255,.09)';
      roundRect(b.x + c * b.cell + 2, b.y + r * b.cell + 2, b.cell - 4, b.cell - 4, b.cell * 0.14);
      ctx.fill();
    }
    // ブロック
    for (let r = 0; r < N; r++) for (let c = 0; c < N; c++) {
      const t = grid[r][c];
      if (!t) continue;
      let ox = 0, oy = 0;
      if (t.bump) {
        const p = t.bump.t / 0.35;
        const k = Math.sin(Math.min(1, p) * Math.PI) * t.bump.dist * b.cell;
        ox = DX[t.dir] * k; oy = DY[t.dir] * k;
      }
      drawTile(b.x + (c + 0.5) * b.cell + ox, b.y + (r + 0.5) * b.cell + oy, b.cell, t.dir, 1, t.flash || 0);
    }
    // 飛んでいくブロック
    for (const m of movers) {
      const p = m.t / 0.6;
      const k = (p * p) * m.dist * b.cell;
      drawTile(b.x + (m.c + 0.5) * b.cell + DX[m.dir] * k, b.y + (m.r + 0.5) * b.cell + DY[m.dir] * k, b.cell, m.dir, 1 - p, 0);
    }
    ctx.restore();
  }
```

変わったところは3つです。

- **画面の揺れ:** `ctx.save()` のあと、`shake` が残っていれば `translate` で盤面全体をランダムに少しずらします。最後の `ctx.restore()` で元に戻します。
- **跳ね返り:** `Math.sin(p * Math.PI)` は、`p` が 0 → 0.5 → 1 と進むと 0 → 1 → 0 と変わります。これに距離をかけると「前に進んで、戻ってくる」動きを1行で表せます。
- **赤い光:** `drawTile` の最後の引数に `t.flash || 0` を渡します。`flash` が 0 より大きいあいだ、ステップ2で用意しておいた赤色 `#ff4d4d` で塗られます。

## 初期化でハートを表示する

ファイルの最後の `generate();` の **下** に `updateHud();` を追加します。

```js:game.js
  resize();
  generate();
  updateHud();
  requestAnimationFrame(frame);
```

> [!CHECK] 動作チェック
> - タイトル画面の時点で、左上にハートが3つ並んでいる
> - やじるしの先にほかのブロックがあるブロックをタップすると、ぶつかるところまで進んで戻り、赤く光って画面が揺れる。ハートが1つ薄くなる
> - 3回ぶつかると、少しして「ゲームオーバー」の画面が出る。「もう一度」でハートが3つに戻って新しい盤面で遊べる
> - 何度か遊ぶと、**どのブロックも飛ばせない盤面** に出会うことがある（向かい合ったやじるしなど）。これを次のステップで直す

> [!TIP]
> 解けない盤面をわざと作って確かめたいときは、`generate()` の確率 `0.6` を `0.9` にすると、ブロックがぎっしり並んで詰まりやすくなります。確かめたら元に戻しておきましょう。
