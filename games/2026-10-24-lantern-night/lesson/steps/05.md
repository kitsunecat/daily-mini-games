## このステップのゴール

影にぶつかるとキツネの HP が減り、0 になるとゲームオーバーになるようにします。画面上部に HP バーと「夜明けまで」の残り時間を出す **HUD**（ヘッドアップディスプレイ）も作ります。

## HUD の HTML

`index.html` の `<canvas id="game"></canvas>` の **下** に追加します。

```html:index.html
  <div id="hud" class="hidden">
    <div id="xpbar"><div id="xpfill"></div></div>
    <div class="hudrow">
      <div class="hp"><div id="hpfill"></div><span id="hptext">100</span></div>
      <div id="timer">夜明けまで 5:00</div>
      <div class="stat">Lv<b id="lv">1</b></div>
      <div class="stat">撃破<b id="kills">0</b></div>
    </div>
    <div id="banner"></div>
  </div>
```

上から経験値バー（`#xpbar`）、HP バー・残り時間・レベル・撃破数の横並び、そして画面中央に大きく出すお知らせ（`#banner`）です。経験値・レベル・撃破数・お知らせはあとのステップで動かします。最初は `hidden` にしておき、ゲーム開始で表示します。

文字やバーのような **UI は HTML/CSS で、ゲームの世界は Canvas で** と分けると、文字のにじみやレイアウトを気にせず済み、作りやすくなります。

## 定数と状態

`game.js` の定数に、夜明けまでの秒数を足します。

```js:game.js
  const WORLD = 3200;        // ワールドの一辺
  const RUN_TIME = 300;      // 夜明けまでの秒数
  const MAX_ENEMIES = 280;
```

状態の宣言と `reset()` を次のように書き換えます。

```js:game.js
  let state = 'title'; // title / play / over
  let P, enemies, texts;
  let t, spawnAcc, shake;

  function reset() {
    P = {
      x: WORLD / 2, y: WORLD / 2, r: 16, hp: 100, maxHp: 100, baseSpeed: 165, inv: 0,
      face: 1, walk: 0,
    };
    enemies = []; texts = [];
    t = 0; spawnAcc = 0;
    shake = 0;
  }
```

- `hp` / `maxHp` は体力、`inv` は **無敵時間** の残り秒数です。
- `texts` は「-8」のように飛び出すダメージ数字の配列、`shake` は画面の揺れの残り時間です。

## ダメージの処理

`pickType` 関数の下、`// ---------- 更新 ----------` の **上** に追加します（`// ---------- 生成 ----------` の続きになります）。

```js:game.js
  function addText(x, y, str, color) {
    if (texts.length > 70) texts.shift();
    texts.push({ x, y, str, color, life: 0.7 });
  }

  // ---------- ダメージ ----------
  function hurtPlayer(dmg) {
    if (P.inv > 0) return;
    P.hp -= dmg;
    P.inv = 0.75;
    shake = 0.25;
    addText(P.x, P.y - 26, '-' + dmg, '#ff7b7b');
    if (P.hp <= 0) { P.hp = 0; endGame(false); }
  }
```

### 無敵時間

敵に触れている間ずっとダメージを受けると、毎フレーム（1秒60回）HP が減って一瞬で負けてしまいます。そこでダメージを受けたら 0.75 秒の **無敵時間** を設け、その間は `hurtPlayer` が何もしないようにします。アクションゲームではおなじみのしくみです。

`addText` は飛び出す文字を追加します。70 個を超えたら古いものから捨てて、増えすぎないようにしています。

## update に当たり判定を足す

`update` の中を3か所変えます。

1つ目: 先頭の `t += dt;` の **下** に、揺れを減らす行を足します。

```js:game.js
    t += dt;
    if (shake > 0) shake -= dt;
```

2つ目: `if (P.moving) P.walk += dt * 10;` の **下** に、無敵時間を減らす行を足します。

```js:game.js
    if (P.moving) P.walk += dt * 10;
    if (P.inv > 0) P.inv -= dt;
```

3つ目: 「敵の移動」ループの最後（`e.y += vy * dt;` の **下**）に、ぶつかったかの判定を足します。

```js:game.js
      e.x += vx * dt;
      e.y += vy * dt;
      if (d < e.r + P.r - 4) hurtPlayer(e.dmg);
      if (state !== 'play') return;
    }
```

### 円どうしの当たり判定

キツネも影も「円」として扱います。2つの円は、**中心どうしの距離が半径の和より小さい** とき重なっています。`d` はすでに計算してあるキツネとの距離なので、`d < e.r + P.r` で判定できます。`- 4` は少しだけ判定を甘くして「かすっただけ」で当たらないようにする調整です。

`hurtPlayer` の中でゲームオーバーになることがあるので、そのあとは `return` で `update` を抜けます。

最後に、`update` の末尾（押し合いループの **下**、関数を閉じる `}` の前）に追加します。

```js:game.js
    for (const tx of texts) { tx.life -= dt; tx.y -= 40 * dt; }
    texts = texts.filter((tx) => tx.life > 0);

    if (t >= RUN_TIME) { endGame(true); return; }
```

ダメージ数字は少しずつ上に移動しながら寿命 `life` が減り、0 になったら `filter` で配列から取り除きます。「寿命を減らして、尽きたら filter で消す」は、このあと弾やエフェクトでも何度も使うパターンです。`t` が `RUN_TIME`（300秒）に達したら夜明け、つまりクリアです。

## ゲーム開始・終了

`startGame` を書き換え、その下に `endGame` と `fmt` を追加します。

```js:game.js
  function startGame() {
    reset();
    hideOverlays();
    $('hud').classList.remove('hidden');
    state = 'play';
  }
  function endGame(cleared) {
    state = 'over';
    joy.active = false;
    setTimeout(() => $('title').classList.remove('hidden'), cleared ? 300 : 700);
  }
  function fmt(s) {
    s = Math.max(0, Math.ceil(s));
    return Math.floor(s / 60) + ':' + String(s % 60).padStart(2, '0');
  }
```

- `endGame` はいったん仮の作りで、少し待ってからタイトル画面に戻すだけです。ステップ12でリザルト画面に差し替えます。`setTimeout` で一拍おくと、やられた瞬間が見えてから画面が切り替わります。
- `fmt` は秒数を `4:05` の形に直します。`padStart(2, '0')` で1桁の秒を `05` のように0埋めします。

## 描画: 点滅・揺れ・ダメージ数字

`drawPlayer` の1行目の **下** に、無敵中の点滅を足します。

```js:game.js
    const x = P.x, y = P.y, f = P.face;
    if (P.inv > 0 && Math.floor(P.inv * 20) % 2) return;
```

`P.inv * 20` の整数部分が奇数のときは描かずに帰るので、1秒に10回の速さで点滅します。

`render()` のカメラ計算の **下** に、画面の揺れを足します。

```js:game.js
    let camX = P.x - vw / 2, camY = P.y - vh / 2;
    if (shake > 0) { camX += rand(-5, 5) * shake * 4; camY += rand(-5, 5) * shake * 4; }
```

カメラ位置を少しランダムにずらすだけで画面が揺れます。`shake` が減るにつれて揺れも小さくなります。

`render()` の `for (const e of list) drawEyes(e);` の **下** に、ダメージ数字の描画を足します。

```js:game.js

    // ダメージ数字
    ctx.font = 'bold 13px sans-serif';
    ctx.textAlign = 'center'; ctx.textBaseline = 'middle';
    for (const tx of texts) {
      ctx.globalAlpha = clamp(tx.life * 2, 0, 1);
      ctx.fillStyle = '#000';
      ctx.fillText(tx.str, tx.x + 1, tx.y + 1);
      ctx.fillStyle = tx.color;
      ctx.fillText(tx.str, tx.x, tx.y);
    }
    ctx.globalAlpha = 1;
```

黒で1ピクセルずらして描いてから色付きで重ねると、どんな背景でも読みやすい影付き文字になります。`globalAlpha` で寿命の最後の 0.5 秒にふわっと消えます。

## HUD を更新する

`// ---------- ループ ----------` の **上** に追加します。

```js:game.js
  // ---------- HUD ----------
  const hudCache = {};
  function setText(id, v) { if (hudCache[id] !== v) { hudCache[id] = v; $(id).textContent = v; } }
  function updateHud() {
    $('hpfill').style.width = (P.hp / P.maxHp * 100) + '%';
    setText('hptext', Math.ceil(P.hp) + ' / ' + P.maxHp);
    setText('timer', '夜明けまで ' + fmt(RUN_TIME - t));
  }
```

`setText` は **前回と同じ文字なら書き換えない** 関数です。DOM の書き換えは Canvas の描画よりずっと重いので、毎フレーム同じ文字を入れ直さないよう、前回の値を `hudCache` に覚えておきます。

最後に `frame` の中、`render();` の **下** に1行足します。

```js:game.js
    render();
    if (state !== 'title') updateHud();
```

> [!CHECK] 動作チェック
> 再読み込みして「はじめる」を押します。
> - 画面上部に HP バー「100 / 100」と「夜明けまで 4:59」が表示され、時間が減っていく
> - 影にぶつかると赤い「-8」が飛び出し、画面が揺れ、キツネが点滅して HP バーが減る
> - 点滅中は続けてダメージを受けない
> - HP が 0 になると少し後にタイトル画面に戻り、「はじめる」でまた最初から遊べる
