## このステップのゴール

キツネが一番近い影に向かって **光の弾を自動で撃つ** ようにします。弾が当たると影は白く光ってノックバックし、体力が尽きると火花を散らして消えます。撃破数も数えます。

## 弾の性能表

`ETYPES` の **上** に追加します。

```js:game.js
  const BOLT = { count: [0, 1, 2, 2, 2, 3, 3], dmg: [0, 15, 15, 21, 21, 24, 28], cd: [0, .7, .66, .62, .58, .54, .4] };
```

ひかり弾の「レベルごとの性能」を配列で持たせた表です。`count` は一度に撃つ数、`dmg` はダメージ、`cd` は次に撃てるまでの秒数（クールダウン）。`BOLT.dmg[2]` がレベル2のダメージ、という引き方をします。0番目はレベル0（未取得）用のダミーです。いまはレベル1しか使いませんが、ステップ8のレベルアップでそのまま強くできます。

## 状態の追加

状態の宣言と `reset()` を次のように書き換えます。

```js:game.js
  let P, enemies, bullets, effects, texts;
  let t, kills, score, spawnAcc, shake;

  function reset() {
    P = {
      x: WORLD / 2, y: WORLD / 2, r: 16, hp: 100, maxHp: 100, baseSpeed: 165, inv: 0,
      face: 1, walk: 0,
      lv: { bolt: 1 },
      boltCd: 0.5,
    };
    enemies = []; bullets = []; effects = []; texts = [];
    t = 0; kills = 0; score = 0; spawnAcc = 0;
    shake = 0;
  }
```

- `P.lv` は強化ごとのレベルをまとめたオブジェクトです。最初からひかり弾はレベル1。
- `P.boltCd` は次の発射までの残り秒数。ゲーム開始 0.5 秒後に最初の1発を撃ちます。
- `bullets` は飛んでいる弾、`effects` は火花などの演出、`kills` は撃破数、`score` は得点です。

## 火花の演出

`addText` 関数の **下** に追加します。

```js:game.js
  function burst(x, y, color, n) {
    for (let i = 0; i < n; i++) {
      const a = rand(0, TAU), s = rand(40, 180);
      effects.push({ kind: 'spark', x, y, vx: Math.cos(a) * s, vy: Math.sin(a) * s, life: rand(0.25, 0.55), color });
    }
  }
```

ランダムな向き・速さ・寿命の小さな粒を `n` 個まき散らします。こうした小さな粒をたくさん使う演出を **パーティクル** と呼びます。

## 敵にダメージを与える

`// ---------- ダメージ ----------` の **すぐ下**（`hurtPlayer` の上）に追加します。

```js:game.js
  function hitEnemy(e, dmg, kx, ky, kb) {
    if (e.dead) return;
    dmg = Math.round(dmg);
    e.hp -= dmg;
    e.flash = 0.1;
    const res = e.type === 'brute' ? 0.35 : 1;
    const l = Math.hypot(kx, ky) || 1;
    e.kx += kx / l * kb * res;
    e.ky += ky / l * kb * res;
    addText(e.x + rand(-6, 6), e.y - e.r, String(dmg), '#fff');
    if (e.hp <= 0) killEnemy(e);
  }
  function killEnemy(e) {
    e.dead = true;
    kills++;
    score += e.score;
    burst(e.x, e.y, e.type === 'wisp' ? '#7ff3e0' : '#b28cff', 7);
  }
```

`hitEnemy(敵, ダメージ, 押す向きx, 押す向きy, 押す強さ)` は、すべての攻撃が共通で使う関数です。弾でも、あとで作る灯火や月光の波でも、この関数を呼ぶだけで「体力を減らす・白く光らせる・ノックバック・ダメージ数字・倒したら消す」が全部そろいます。

- **ノックバック**: 押す向きを長さ1にそろえ、強さ `kb` を掛けて `e.kx, e.ky` に足します。大きな影（brute）は `res = 0.35` で押されにくくしています。
- **倒したとき**: すぐに配列から消さず、`e.dead = true` と印を付けるだけにします。ループの途中で配列から要素を消すと、次の要素を飛ばすなどの不具合が起きやすいからです。印の付いた敵は、`update` の最後でまとめて取り除きます。

## 武器: 一番近い敵を狙う

`// ---------- 更新 ----------` の **上** に追加します。

```js:game.js
  // ---------- 武器 ----------
  function nearestEnemies(n, range) {
    const r2 = range * range;
    const list = [];
    for (const e of enemies) {
      if (e.dead) continue;
      const d = (e.x - P.x) ** 2 + (e.y - P.y) ** 2;
      if (d < r2) list.push([d, e]);
    }
    list.sort((a, b) => a[0] - b[0]);
    return list.slice(0, n).map((v) => v[1]);
  }

  function updateWeapons(dt) {
    const L = P.lv;
    // ひかり弾
    P.boltCd -= dt;
    if (P.boltCd <= 0) {
      const n = BOLT.count[L.bolt];
      const targets = nearestEnemies(n, 560);
      if (targets.length) {
        for (let i = 0; i < n; i++) {
          const tg = targets[i % targets.length];
          let a = Math.atan2(tg.y - P.y, tg.x - P.x);
          if (i >= targets.length) a += (i % 2 ? 0.25 : -0.25);
          bullets.push({ x: P.x, y: P.y - 6, vx: Math.cos(a) * 480, vy: Math.sin(a) * 480, dmg: BOLT.dmg[L.bolt], pierce: L.bolt >= 4 ? 3 : 1, life: 1.3, hit: [] });
        }
        P.boltCd = BOLT.cd[L.bolt];
      } else P.boltCd = 0.1;
    }
  }
```

- `nearestEnemies(n, range)` は、距離 `range` 以内の敵を近い順に最大 `n` 体返します。`[距離の2乗, 敵]` の組を作って `sort` で並べ、先頭から取り出しています。
- **クールダウン**: `boltCd` を毎フレーム `dt` ずつ減らし、0 以下になったら撃って、また `BOLT.cd` の秒数に戻します。狙える敵がいなければ 0.1 秒後にもう一度探します。
- **狙う向き**: `Math.atan2(dy, dx)` は、向きベクトルから **角度** を求める関数です。角度 `a` から `Math.cos(a) * 480, Math.sin(a) * 480` で「その向きに秒速 480」の速度が作れます。
- 敵の数より弾が多いときは、同じ敵に角度を少し（0.25 ラジアン）ずらして撃ちます。
- `pierce` は貫通できる回数、`hit` はすでに当たった敵のリスト（同じ敵に2回当たらないように）、`life` は弾の寿命です。

## update に組み込む

「敵の移動」ループを、`updateWeapons` の呼び出しを含めて次のように書き換えます（`// 敵の移動` の上の行から、ループの閉じ `}` まで）。

```js:game.js
    updateWeapons(dt);

    // 敵の移動
    for (const e of enemies) {
      if (e.dead) continue;
      const dx = P.x - e.x, dy = P.y - e.y;
      const d = Math.hypot(dx, dy) || 1;
      let vx = dx / d * e.spd, vy = dy / d * e.spd;
      if (e.type === 'bat') {
        const w = Math.sin(t * 6 + e.ph) * 60;
        vx += -dy / d * w; vy += dx / d * w;
      }
      e.x += (vx + e.kx) * dt;
      e.y += (vy + e.ky) * dt;
      const decay = Math.pow(0.02, dt);
      e.kx *= decay; e.ky *= decay;
      if (e.flash > 0) e.flash -= dt;
      if (d < e.r + P.r - 4) hurtPlayer(e.dmg);
      if (state !== 'play') return;
    }
```

ノックバックの勢い `kx, ky` を移動に足し、毎フレーム減衰させます。`Math.pow(0.02, dt)` は「1秒たつと 2% まで減る」という減り方を、フレームレートに関係なく実現する書き方です（0.5秒なら √0.02 ≒ 14% になります）。

次に、`update` の後半、`for (const tx of texts)` の行の **上** に追加します。

```js:game.js
    // 弾
    for (const b of bullets) {
      b.x += b.vx * dt; b.y += b.vy * dt; b.life -= dt;
      for (const e of enemies) {
        if (e.dead || b.hit.includes(e)) continue;
        const rr = e.r + 6;
        if ((e.x - b.x) ** 2 + (e.y - b.y) ** 2 < rr * rr) {
          b.hit.push(e);
          hitEnemy(e, b.dmg, b.vx, b.vy, 120);
          if (--b.pierce <= 0) { b.life = 0; break; }
        }
      }
    }
    bullets = bullets.filter((b) => b.life > 0);

    enemies = enemies.filter((e) => !e.dead);
    for (const fx of effects) {
      fx.life -= dt;
      if (fx.kind === 'spark') { fx.x += fx.vx * dt; fx.y += fx.vy * dt; fx.vx *= 0.92; fx.vy *= 0.92; }
    }
    effects = effects.filter((fx) => fx.life > 0);
```

弾と敵の当たり判定も円どうしです（弾の半径を 6 としています）。当たったら弾の進む向き `b.vx, b.vy` に敵を押し、貫通回数を1減らして、0 になったら寿命を 0 にして消します。`enemies.filter((e) => !e.dead)` で、倒された敵をここでまとめて取り除きます。

## 弾と火花を描く

`render()` の `for (const e of list) drawEyes(e);` の **下**（ダメージ数字の上）に追加します。

```js:game.js
    ctx.globalCompositeOperation = 'lighter';
    for (const b of bullets) {
      ctx.fillStyle = 'rgba(255,220,120,.35)';
      ctx.beginPath(); ctx.arc(b.x - b.vx * 0.02, b.y - b.vy * 0.02, 5, 0, TAU); ctx.fill();
      ctx.fillStyle = '#fff4c2';
      ctx.beginPath(); ctx.arc(b.x, b.y, 4.5, 0, TAU); ctx.fill();
    }
    for (const fx of effects) {
      if (fx.kind === 'spark') {
        ctx.globalAlpha = clamp(fx.life * 2, 0, 1);
        ctx.fillStyle = fx.color;
        ctx.fillRect(fx.x - 2, fx.y - 2, 4, 4);
      }
    }
    ctx.globalAlpha = 1;
    ctx.globalCompositeOperation = 'source-over';
```

`globalCompositeOperation = 'lighter'` は **加算合成** です。重ねて描くほど明るくなるので、光の弾や火花が「光っている」ように見えます。使い終わったら必ず通常の `'source-over'` に戻します。弾は少し後ろ（速度の逆向き）に薄い円をもう1つ描いて、尾を引いているように見せています。

## 撃破数を表示する

`updateHud` の最後に1行足します。

```js:game.js
    setText('timer', '夜明けまで ' + fmt(RUN_TIME - t));
    setText('kills', String(kills));
```

> [!CHECK] 動作チェック
> 再読み込みして「はじめる」を押します。
> - 影が近づくと、キツネから白く光る弾が自動で飛んでいく
> - 当たった影は一瞬白く光って少し押し戻され、白いダメージ数字「15」が出る
> - 序盤の blob は1発で、紫の火花を散らして消える。右上の「撃破」の数字が増える
> - 大きな影（brute）は何発も当てないと倒れず、押し戻されにくい（110秒を過ぎると出ます）
