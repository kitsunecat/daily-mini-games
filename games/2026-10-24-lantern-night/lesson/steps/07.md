## このステップのゴール

倒した影が **光のかけら**（経験値）を落とし、近づくと吸い寄せられて拾えるようにします。経験値がたまるとレベルが上がり、画面上部の経験値バーとレベル表示が動きます。ときどき回復のハートも落ちます。

## 必要経験値と状態

状態の宣言を書き換え、その下に `xpNeed` 関数を追加します。

```js:game.js
  let P, enemies, bullets, gems, effects, texts;
  let t, kills, score, spawnAcc, pendingLevels, shake;

  function xpNeed(lv) { return Math.floor(3 + lv * 2.5 + lv * lv * 0.55); }
```

`xpNeed(lv)` は「レベル `lv` から次に上がるのに必要な経験値」です。レベル1→2 は 6、レベル5→6 は 29、レベル10→11 は 83 と、だんだん上がりにくくなります。`lv * lv` の項（2乗）が効いて、後半ほど急に増えるのがポイントです。

`reset()` の中を次のように変えます。

```js:game.js
    P = {
      x: WORLD / 2, y: WORLD / 2, r: 16, hp: 100, maxHp: 100, baseSpeed: 165, inv: 0,
      level: 1, xp: 0, next: xpNeed(1), face: 1, walk: 0,
      lv: { bolt: 1 },
      boltCd: 0.5,
    };
    enemies = []; bullets = []; gems = []; effects = []; texts = [];
    t = 0; kills = 0; score = 0; spawnAcc = 0;
    pendingLevels = 0; shake = 0;
```

`level`（いまのレベル）、`xp`（たまった経験値）、`next`（次のレベルまでに必要な量）を足しました。`gems` は地面に落ちているかけら、`pendingLevels` は「まだ強化を選んでいないレベルアップの回数」で、次のステップで使います。

`const speed = ...` の **下** に、かけらを吸い寄せる範囲を返す関数を足します。

```js:game.js
  const magnet = () => 95;
```

## 倒した敵がかけらを落とす

`killEnemy` の最後に2行足します。

```js:game.js
  function killEnemy(e) {
    e.dead = true;
    kills++;
    score += e.score;
    burst(e.x, e.y, e.type === 'wisp' ? '#7ff3e0' : '#b28cff', 7);
    gems.push({ x: e.x, y: e.y, v: e.xp, kind: 'gem' });
    if (Math.random() < 0.012) gems.push({ x: e.x + 8, y: e.y, v: 25, kind: 'heart' });
  }
```

かけらは `v`（価値）と `kind`（`'gem'` か `'heart'`）を持ちます。1.2% の確率で HP を 25 回復するハートも落とします。

## かけらを拾う

`update` の中、`bullets = bullets.filter(...)` の行の **下**（`enemies = enemies.filter(...)` の上）に追加します。

```js:game.js
    // かけら
    const mg = magnet(), mg2 = mg * mg;
    for (const g of gems) {
      const dx = P.x - g.x, dy = P.y - g.y, d2 = dx * dx + dy * dy;
      if (d2 < mg2 || g.pull) {
        g.pull = true;
        const d = Math.sqrt(d2) || 1;
        g.spd = (g.spd || 120) + dt * 900;
        g.x += dx / d * g.spd * dt; g.y += dy / d * g.spd * dt;
        if (d < P.r + 6) {
          g.got = true;
          if (g.kind === 'heart') {
            P.hp = Math.min(P.maxHp, P.hp + g.v);
            addText(P.x, P.y - 30, '+' + g.v, '#7dffb0');
          } else gainXp(g.v);
        }
      }
    }
    gems = gems.filter((g) => !g.got);
    if (gems.length > 400) {
      // 遠くのかけらはまとめる
      const far = gems.splice(0, 100);
      const sum = far.reduce((s, g) => s + (g.kind === 'gem' ? g.v : 0), 0);
      gems.push({ x: far[0].x, y: far[0].y, v: sum, kind: 'gem' });
    }
```

- **吸い寄せ**: キツネから `magnet()`（95 ピクセル）以内に入ったかけらには `pull` の印を付け、以後はキツネに向かって飛んできます。`g.spd` は毎秒 900 ずつ加速するので、逃げても必ず追いつきます。
- キツネのすぐそば（`P.r + 6` 以内）まで来たら拾ったことにします。ハートは HP を回復（`Math.min` で最大 HP を超えないように）、かけらは `gainXp` で経験値にします。
- **数の上限**: かけらが 400 個を超えたら、古い 100 個を1つの大きなかけらにまとめます。価値の合計は変わらないので損はせず、描画や計算が重くなるのを防げます。`reduce` は配列の合計を出すときによく使うメソッドです。

## 経験値とレベルアップ

`update` 関数の **下** に追加します。

```js:game.js
  function gainXp(v) {
    P.xp += v;
    while (P.xp >= P.next) {
      P.xp -= P.next;
      P.level++;
      P.next = xpNeed(P.level);
      pendingLevels++;
    }
  }
```

`if` ではなく `while` にしているのは、大きなかけらを拾って一度に2レベル以上上がる場合もあるからです。あふれた分の経験値は次のレベルに持ち越します。

## かけらを描く

`render()` の `const inView = ...` の行の **下**（`// 敵（y順）` の上）に追加します。

```js:game.js

    // かけら
    for (const g of gems) {
      if (!inView(g.x, g.y, 20)) continue;
      if (g.kind === 'heart') {
        ctx.fillStyle = '#ff6b8a';
        ctx.font = 'bold 18px sans-serif'; ctx.textAlign = 'center'; ctx.textBaseline = 'middle';
        ctx.fillText('♥', g.x, g.y);
      } else {
        const s = g.v >= 5 ? 7 : g.v >= 2 ? 5.5 : 4.5;
        ctx.fillStyle = g.v >= 5 ? '#9c8bff' : g.v >= 2 ? '#5affc8' : '#5ad1ff';
        ctx.beginPath();
        ctx.moveTo(g.x, g.y - s); ctx.lineTo(g.x + s * 0.7, g.y); ctx.lineTo(g.x, g.y + s); ctx.lineTo(g.x - s * 0.7, g.y);
        ctx.fill();
      }
    }
```

かけらは4つの点を結んだひし形です。価値が大きいほど大きく、色も青 → 緑 → 紫と変えて、見ただけで分かるようにしています。敵より先に描くので、地面に落ちているように見えます。

## HUD に経験値とレベルを出す

`updateHud` に2行足します。

```js:game.js
  function updateHud() {
    $('hpfill').style.width = (P.hp / P.maxHp * 100) + '%';
    $('xpfill').style.width = (P.xp / P.next * 100) + '%';
    setText('hptext', Math.ceil(P.hp) + ' / ' + P.maxHp);
    setText('timer', '夜明けまで ' + fmt(RUN_TIME - t));
    setText('lv', String(P.level));
    setText('kills', String(kills));
  }
```

> [!CHECK] 動作チェック
> 再読み込みして「はじめる」を押します。
> - 影を倒すと、その場所に青いひし形のかけらが落ちる
> - キツネが近づくと、かけらが加速しながら吸い寄せられて消える
> - 画面最上部の経験値バーが伸び、いっぱいになると「Lv」の数字が 2 に増えてバーが空に戻る
> - まれに落ちるピンクの ♥ を拾うと、緑の「+25」が出て HP が回復する
