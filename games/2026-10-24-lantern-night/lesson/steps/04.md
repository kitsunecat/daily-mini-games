## このステップのゴール

画面の外から **影（敵）** がわらわらと現れて、キツネを追いかけてくるようにします。影は4種類。時間がたつほど数が増え、新しい種類が混ざってきます。

## 定数と敵の種類

`WORLD` の下に、同時に出せる敵の上限を足します。

```js:game.js
  const WORLD = 3200;        // ワールドの一辺
  const MAX_ENEMIES = 280;
```

`resize();` の下、`// ---------- 状態 ----------` の **上** に、敵の種類表を追加します。

```js:game.js
  const ETYPES = {
    blob:  { hp: 12, spd: 52, r: 14, dmg: 8, xp: 1, score: 10 },
    bat:   { hp: 9, spd: 98, r: 11, dmg: 6, xp: 1, score: 12 },
    wisp:  { hp: 26, spd: 66, r: 13, dmg: 12, xp: 2, score: 20 },
    brute: { hp: 80, spd: 36, r: 24, dmg: 20, xp: 5, score: 50 },
  };
```

`hp`（体力）、`spd`（速さ）、`r`（半径）、`dmg`（ぶつかったときのダメージ）、`xp`（倒すと落とす経験値）、`score` を種類ごとにまとめた **データの表** です。「ぷよぷよした影（blob）」「すばやいコウモリ（bat）」「固めの鬼火（wisp）」「大きくて硬い影（brute）」で、数字を変えるだけでゲームバランスを調整できます。

## 状態に敵の配列を足す

状態の宣言と `reset()` を次のように書き換えます。

```js:game.js
  // ---------- 状態 ----------
  let state = 'title'; // title / play
  let P, enemies;
  let t, spawnAcc;

  function reset() {
    P = {
      x: WORLD / 2, y: WORLD / 2, r: 16, baseSpeed: 165,
      face: 1, walk: 0,
    };
    enemies = [];
    t = 0; spawnAcc = 0;
  }
```

敵は何百体も出るので、1体ずつ変数を作らず **配列 `enemies`** に入れて、`for...of` でまとめて動かします。`spawnAcc` は出現のタイミングを計るための「貯金」です（後述）。

## 敵を生み出す関数

`inputVec` 関数の下、`// ---------- 更新 ----------` の **上** に追加します。

```js:game.js
  // ---------- 生成 ----------
  function spawnEnemy(type, x, y) {
    const d = ETYPES[type];
    const hpMul = 1 + t / 100;
    enemies.push({
      type, x, y, r: d.r, hp: d.hp * hpMul, maxHp: d.hp * hpMul, spd: d.spd * (1 + t / 900),
      dmg: d.dmg, xp: d.xp, score: d.score, flash: 0, kx: 0, ky: 0, ph: rand(0, TAU), oh: 0, dead: false,
    });
  }
  function viewRadius() { return Math.hypot(W, H) / 2 / zoom; }
  function spawnRing(type) {
    const a = rand(0, TAU), d = viewRadius() + rand(30, 90);
    spawnEnemy(type, clamp(P.x + Math.cos(a) * d, 20, WORLD - 20), clamp(P.y + Math.sin(a) * d, 20, WORLD - 20));
  }
  function pickType() {
    const r = Math.random();
    if (t > 110 && r < 0.09) return 'brute';
    if (t > 90 && r < 0.3) return 'wisp';
    if (t > 35 && r < 0.55) return 'bat';
    return 'blob';
  }
```

- `spawnEnemy` は種類表から敵オブジェクトを作って `enemies` に追加します。`hpMul` で、時間がたつほど体力と速さが少しずつ上がります（100秒で体力2倍）。
- オブジェクトには、あとのステップで使うものも先に入れておきます。`flash`（攻撃が当たって白く光る残り時間）、`kx, ky`（ノックバックの勢い）、`ph`（アニメーションの位相を個体ごとにずらす値）、`oh`（灯火の連続ヒット防止）、`dead`（倒されたか）です。
- `spawnRing` は、キツネから見て **画面のちょうど外側** の円周上のランダムな場所に敵を出します。`viewRadius()` は画面の対角線の半分（中心から画面の角までの距離）なので、それより 30〜90 ピクセル遠くに出せば、突然目の前に湧くことはありません。角度 `a` から位置を出す `Math.cos(a) * d`, `Math.sin(a) * d` は、円周上の点を求める定番の式です。
- `pickType` は時間に応じて出す種類を選びます。35秒を過ぎるとコウモリ、90秒で鬼火、110秒で大きな影が混ざり始めます。

## update で出現させ、追いかけさせる

`update` の最後（`if (P.moving) P.walk += dt * 10;` の **下**）に追加します。

```js:game.js
    // 出現
    spawnAcc += dt * (0.8 + t / 24);
    while (spawnAcc >= 1) {
      spawnAcc -= 1;
      if (enemies.length < MAX_ENEMIES) spawnRing(pickType());
    }

    // 敵の移動
    for (const e of enemies) {
      const dx = P.x - e.x, dy = P.y - e.y;
      const d = Math.hypot(dx, dy) || 1;
      let vx = dx / d * e.spd, vy = dy / d * e.spd;
      if (e.type === 'bat') {
        const w = Math.sin(t * 6 + e.ph) * 60;
        vx += -dy / d * w; vy += dx / d * w;
      }
      e.x += vx * dt;
      e.y += vy * dt;
    }
    // 押し合い（重なり防止）
    for (let i = 0; i < enemies.length; i++) {
      const a = enemies[i];
      for (let j = i + 1; j < enemies.length; j++) {
        const b = enemies[j];
        const dx = b.x - a.x, rr = a.r + b.r;
        if (dx > rr || dx < -rr) continue;
        const dy = b.y - a.y;
        if (dy > rr || dy < -rr) continue;
        const d2 = dx * dx + dy * dy;
        if (d2 < rr * rr && d2 > 0.01) {
          const d = Math.sqrt(d2), push = (rr - d) * 0.5;
          const ux = dx / d, uy = dy / d;
          a.x -= ux * push * 0.5; a.y -= uy * push * 0.5;
          b.x += ux * push * 0.5; b.y += uy * push * 0.5;
        }
      }
    }
```

### 出現の管理: 「貯金」方式

「1秒に何体出すか」を `0.8 + t / 24` で決めています。最初は1秒に約0.8体、1分後には約3.3体、4分後には約10体です。毎フレーム `出現ペース × dt` を `spawnAcc` に貯め、1を超えるたびに1体出して1を引きます。こうすると、出現ペースが小数でもフレームレートが違っても、平均してぴったりのペースで敵が出ます。

### 追いかける動き

キツネへの向き `(dx, dy)` を距離 `d` で割ると長さ 1 の向きになり、それに速さを掛けたものが速度です。コウモリだけは、進む向きに垂直な成分 `(-dy, dx)` を `sin` で揺らして、ジグザグに飛ばしています。`|| 1` はキツネと重なって `d` が 0 になったとき、0 で割らないための保険です。

### 押し合い

何もしないと、敵が1点に重なって1匹に見えてしまいます。そこで2体ずつ調べ、半径の和 `rr` より近ければ互いを押し離します。

- 全ペアを調べると数百体で数万回の計算になります。そこで、まず `dx` だけ、次に `dy` だけで「明らかに遠い」組み合わせを先に除外しています（重い `Math.sqrt` は本当に重なっているときだけ）。
- 距離の比較は `d2 < rr * rr` のように **2乗のまま** 行うのが定番です。平方根を取らなくても大小関係は変わりません。

## 敵を描く

`drawPlayer` 関数の下、`function render() {` の **上** に2つの関数を追加します。

```js:game.js
  function drawEnemy(e) {
    ctx.save();
    ctx.translate(e.x, e.y);
    const flash = e.flash > 0;
    const wob = Math.sin(t * 5 + e.ph);
    ctx.fillStyle = 'rgba(0,0,0,.3)';
    ctx.beginPath(); ctx.ellipse(0, e.r * 0.9, e.r * 0.9, e.r * 0.3, 0, 0, TAU); ctx.fill();
    if (e.type === 'blob') {
      ctx.fillStyle = flash ? '#fff' : '#4b2f7a';
      ctx.beginPath(); ctx.ellipse(0, 0, e.r * (1 + wob * 0.06), e.r * (1 - wob * 0.06), 0, 0, TAU); ctx.fill();
      ctx.fillStyle = flash ? '#fff' : '#5e3d94';
      ctx.beginPath(); ctx.arc(-4, -5, e.r * 0.45, 0, TAU); ctx.fill();
    } else if (e.type === 'bat') {
      const flap = Math.sin(t * 18 + e.ph) * 0.6;
      ctx.fillStyle = flash ? '#fff' : '#2d2248';
      for (const s of [-1, 1]) {
        ctx.beginPath();
        ctx.moveTo(0, 0);
        ctx.quadraticCurveTo(s * 16, -10 - flap * 10, s * 22, -2 + flap * 6);
        ctx.quadraticCurveTo(s * 12, 0, s * 4, 5);
        ctx.fill();
      }
      ctx.beginPath(); ctx.arc(0, 0, 8, 0, TAU); ctx.fill();
    } else if (e.type === 'wisp') {
      ctx.globalAlpha = 0.85;
      ctx.fillStyle = flash ? '#fff' : '#2e8f8a';
      ctx.beginPath();
      ctx.arc(0, -2, e.r, Math.PI, 0);
      for (let i = 0; i <= 4; i++) ctx.lineTo(e.r - i * e.r / 2, e.r + (i % 2 ? -4 : 3) + wob * 2);
      ctx.fill();
      ctx.globalAlpha = 1;
    } else if (e.type === 'brute') {
      ctx.fillStyle = flash ? '#fff' : '#3c3a4f';
      ctx.beginPath(); ctx.roundRect ? ctx.roundRect(-e.r, -e.r, e.r * 2, e.r * 2, 9) : ctx.rect(-e.r, -e.r, e.r * 2, e.r * 2); ctx.fill();
      ctx.fillStyle = flash ? '#fff' : '#52506a';
      ctx.fillRect(-e.r + 5, -e.r + 5, e.r * 0.8, e.r * 0.5);
    }
    ctx.restore();
  }

  function drawEyes(e) {
    const s = e.type === 'brute' ? 1.6 : 1;
    const col = e.type === 'brute' ? '#ff5050' : e.type === 'wisp' ? '#c8fff6' : '#ffe14d';
    const dx = clamp((P.x - e.x) * 0.02, -2, 2) * s, dy = e.type === 'bat' ? -1 : -3 * s;
    ctx.fillStyle = col;
    ctx.shadowColor = col; ctx.shadowBlur = 8;
    ctx.beginPath();
    ctx.arc(e.x - 4 * s + dx, e.y + dy, 2.2 * s, 0, TAU);
    ctx.arc(e.x + 4 * s + dx, e.y + dy, 2.2 * s, 0, TAU);
    ctx.fill();
    ctx.shadowBlur = 0;
  }
```

- `drawEnemy` は種類ごとに形を変えて描きます。`wob`（`sin` で -1〜1 に揺れる値）で blob をぷるぷる伸び縮みさせ、`flap` でコウモリの羽をはばたかせています。`quadraticCurveTo` は曲線を描く命令です。
- `flash ? '#fff' : 色` は、攻撃が当たった直後だけ白く光らせるための書き方です（ステップ6で使います）。
- 目は `drawEyes` で別に描きます。ステップ10で「暗闇の上に目だけ光らせる」ために分けておきます。目は `dx` で少しだけキツネの方を見ます。

## render で敵を描く

`render()` の中、`drawGround(camX, camY, vw, vh);` から `drawPlayer();` までを次のように書き換えます。

```js:game.js
    drawGround(camX, camY, vw, vh);

    const inView = (x, y, m) => x > camX - m && x < camX + vw + m && y > camY - m && y < camY + vh + m;

    // 敵（y順）→ プレイヤーは常に手前
    const list = enemies.filter((e) => inView(e.x, e.y, e.r + 30));
    list.sort((a, b) => a.y - b.y);
    for (const e of list) drawEnemy(e);
    drawPlayer();

    // 光るもの
    for (const e of list) drawEyes(e);
```

- `inView` は「画面に（余白 `m` を含めて）映っているか」を調べる関数です。画面外の敵は描かないことで、数百体いても軽く保てます。
- `y` の小さい順（画面の上から）に並べて描くと、下にいる敵が手前に重なり、奥行きが出ます。
