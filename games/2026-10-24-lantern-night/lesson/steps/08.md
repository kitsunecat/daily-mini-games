## このステップのゴール

レベルが上がるとゲームが止まり、**3つの強化から1つを選ぶ** 画面が出るようにします。ひかり弾の強化と、攻撃力・移動速度・最大HP・拾う範囲・自然回復・攻撃間隔の6つの強化を作ります。

## レベルアップ画面の HTML

`index.html` のタイトル画面（`<div id="title" ...>` のかたまり）の閉じタグの **下** に追加します。

```html:index.html
  <div id="levelup" class="overlay hidden">
    <div class="panel wide">
      <h2>レベルアップ！</h2>
      <p class="sub">強化をひとつ選ぼう（1 / 2 / 3 キーでも選択可）</p>
      <div id="cards"></div>
    </div>
  </div>
```

`#cards` の中身（3枚のカード）は、毎回 JavaScript で作ります。

## 強化の定義

`game.js` の `const BOLT = ...` の **上** に追加します。

```js:game.js
  // ---------- 強化の定義 ----------
  const UPGRADES = {
    bolt: {
      name: 'ひかり弾', icon: '✦', max: 6,
      desc: ['', '近くの影へ光の弾を自動で撃つ', '弾が 2 発になる', 'ダメージアップ', '弾が 3 体まで貫通する', '弾が 3 発になる', '連射速度が大きく上がる'],
    },
    power: { name: '灯の力', icon: '💪', max: 5, desc: ['', 'すべての攻撃力 +15%'] },
    swift: { name: '身軽な足', icon: '👟', max: 5, desc: ['', '移動速度 +10%'] },
    heart: { name: 'ぬくもり', icon: '❤', max: 5, desc: ['', '最大HP +20 して 20 回復'] },
    magnet: { name: '引き寄せ', icon: '🧲', max: 4, desc: ['', 'かけらを拾う範囲 +40%'] },
    regen: { name: '焚き火の加護', icon: '♨', max: 5, desc: ['', '毎秒 HP が 0.5 回復'] },
    haste: { name: '早撃ち', icon: '⏱', max: 5, desc: ['', '攻撃の間隔 -8%'] },
  };
  const WEAPONS = ['bolt'];
```

強化を **データ** として定義しておくと、カードの表示も選択の処理も、この表を見るだけの共通コードで書けます。新しい強化を足したくなっても、ここに1行増やして効果の計算を足すだけです。

- `max` は最大レベル、`desc[n]` は「レベル n になったときの説明」です。ひかり弾はレベルごとに説明が違い、ほかの強化は毎回同じなので `desc[1]` だけを持たせています。
- `WEAPONS` は武器（攻撃手段）の一覧です。次のステップで3つ増やします。

状態のコメントも更新しておきます。

```js:game.js
  let state = 'title'; // title / play / levelup / over
```

`reset()` の中の `lv` を、すべての強化のレベルを持つように書き換えます。

```js:game.js
      lv: { bolt: 1, power: 0, swift: 0, heart: 0, magnet: 0, regen: 0, haste: 0 },
```

## 強化の効果を計算する

`const speed = ...` と `const magnet = ...` の2行を、次の4行に置き換えます。

```js:game.js
  const dmgMul = () => 1 + P.lv.power * 0.15;
  const cdMul = () => 1 - P.lv.haste * 0.08;
  const speed = () => P.baseSpeed * (1 + P.lv.swift * 0.1);
  const magnet = () => 95 * (1 + P.lv.magnet * 0.4);
```

ステップ3で `speed()` を関数にしておいたおかげで、ここを変えるだけで移動速度の強化が効きます。`dmgMul` は攻撃力の倍率、`cdMul` はクールダウン（攻撃の間隔）の倍率です。

これらを使う場所を2か所変えます。`hitEnemy` の中:

```js:game.js
    dmg = Math.round(dmg * dmgMul());
```

`updateWeapons` のひかり弾の中:

```js:game.js
        P.boltCd = BOLT.cd[L.bolt] * cdMul();
```

自然回復は `update` の、`if (P.inv > 0) P.inv -= dt;` の **下** に足します。

```js:game.js
    if (P.lv.regen) P.hp = Math.min(P.maxHp, P.hp + P.lv.regen * 0.5 * dt);
```

## レベルアップ画面を開く・選ぶ

`update` の最後、`if (t >= RUN_TIME) ...` の **下** に1行足します。

```js:game.js
    if (t >= RUN_TIME) { endGame(true); return; }
    if (pendingLevels > 0) openLevelUp();
  }
```

`gainXp` 関数の下、`// ---------- 画面遷移 ----------` の **上** に追加します。

```js:game.js
  // ---------- レベルアップ ----------
  function openLevelUp() {
    state = 'levelup';
    joy.active = false;
    let pool = Object.keys(UPGRADES).filter((k) => P.lv[k] < UPGRADES[k].max);
    // 未取得の武器を少し出やすくする
    const weighted = [];
    for (const k of pool) {
      weighted.push(k);
      if (WEAPONS.includes(k) && P.lv[k] === 0) weighted.push(k);
    }
    const picks = [];
    while (picks.length < 3 && weighted.length) {
      const k = weighted[Math.floor(Math.random() * weighted.length)];
      if (!picks.includes(k)) picks.push(k);
      for (let i = weighted.length - 1; i >= 0; i--) if (weighted[i] === k) weighted.splice(i, 1);
    }
    const cards = $('cards');
    cards.innerHTML = '';
    if (!picks.length) picks.push('meal');
    picks.forEach((k, i) => {
      const btn = document.createElement('button');
      btn.className = 'card';
      if (k === 'meal') {
        btn.innerHTML = '<div class="ic">🍠</div><div class="nm">焼きいも</div><div class="lvl">回復</div><div class="ds">HP を 40 回復し、スコア +200</div>';
      } else {
        const u = UPGRADES[k], next = P.lv[k] + 1;
        const ds = u.desc[next] || u.desc[1];
        const lvl = P.lv[k] === 0 ? '<span class="new">NEW!</span>' : `Lv ${P.lv[k]} → ${next}`;
        btn.innerHTML = `<div class="ic">${u.icon}</div><div class="nm">${i + 1}. ${u.name}</div><div class="lvl">${lvl}</div><div class="ds">${ds}</div>`;
      }
      btn.addEventListener('click', () => chooseUpgrade(k));
      cards.appendChild(btn);
    });
    $('levelup').classList.remove('hidden');
  }

  function chooseUpgrade(k) {
    if (state !== 'levelup') return;
    if (k === 'meal') { P.hp = Math.min(P.maxHp, P.hp + 40); score += 200; }
    else {
      P.lv[k]++;
      if (k === 'heart') { P.maxHp += 20; P.hp = Math.min(P.maxHp, P.hp + 20); }
    }
    pendingLevels--;
    $('levelup').classList.add('hidden');
    state = 'play';
    if (pendingLevels > 0) openLevelUp();
  }
```

### ゲームを止めるしくみ

`openLevelUp` で `state` を `'levelup'` にすると、`frame` は `state === 'play'` のときしか `update` を呼ばないので、**それだけでゲーム全体が止まります**（描画は続くので画面は見えたまま）。ステップ1で `state` を用意した効果がここで出てきます。

### 候補を3つ選ぶ（重み付きの抽選）

1. `pool` … まだ最大レベルに達していない強化の一覧です。
2. `weighted` … 抽選用の箱。まだ持っていない武器は **2回** 入れて、出やすくしています。これが「重み付き抽選」の簡単な作り方です。
3. 箱からランダムに1つ取り出し、同じ名前のものを箱から全部取り除く、を3回繰り返すと、重複しない3つが選べます。
4. すべての強化が最大レベルなら、代わりに「焼きいも」（回復＋スコア）を出します。

カードは `document.createElement('button')` で作り、`innerHTML` で中身を入れ、クリックしたら `chooseUpgrade(k)` を呼ぶようにします。テンプレートリテラル（`` `...${式}...` ``）を使うと、HTML に値を埋め込むのが楽です。

`chooseUpgrade` は、選んだ強化のレベルを1上げて（「ぬくもり」なら最大 HP も増やして）画面を閉じ、ゲームを再開します。一度に2レベル以上上がっていたら、続けてもう一度レベルアップ画面を開きます。

## キーボードで選ぶ・画面を隠す

`keydown` の処理の最後（`preventDefault` の行の **下**）に追加します。

```js:game.js
    if (state === 'levelup' && ['1', '2', '3'].includes(k)) {
      const btn = $('cards').children[Number(k) - 1];
      if (btn) btn.click();
    }
```

カードの `click()` を呼べば、マウスで押したのと同じ処理が動きます。

`hideOverlays` の配列に `'levelup'` を足します。

```js:game.js
    for (const id of ['title', 'levelup']) $(id).classList.add('hidden');
```

> [!CHECK] 動作チェック
> 再読み込みして「はじめる」を押し、かけらを集めます。
> - 経験値バーがいっぱいになるとゲームが止まり、「レベルアップ！」と3枚のカードが出る
> - カードをクリック（または 1 / 2 / 3 キー）で選ぶと、画面が閉じてゲームが再開する
> - 「ひかり弾」を選ぶと「Lv 1 → 2」と表示され、選んだあとは弾が 2 発ずつ飛ぶ
> - 「身軽な足」で足が速くなる、「引き寄せ」でかけらを遠くから拾える、など効果が目で分かる
> - スマホ幅ではカードが縦に並ぶ
