## このステップのゴール

ゲームを入れる3つのファイルを用意し、ゲーム画面になる `canvas` と、タイトル画面（オーバーレイ）の「入れ物」を作ります。「はじめる」ボタンを押すとタイトル画面が消えるところまで進めましょう。

## ファイルを用意する

好きな場所に `lantern-night` というフォルダを作り、中に次の3つの空ファイルを作ります。

- `index.html` … 画面の部品（HTML）
- `style.css` … 見た目（CSS）
- `game.js` … ゲームの動き（JavaScript）

## index.html

```html:index.html
<!doctype html>
<html lang="ja">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width,initial-scale=1,maximum-scale=1,user-scalable=no,viewport-fit=cover">
  <title>ランタン守りの夜</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <canvas id="game"></canvas>

  <div id="title" class="overlay">
    <div class="panel">
      <div class="logo">🏮</div>
      <h1>ランタン守りの夜</h1>
      <p class="sub">夜明けまで 5 分。影の群れから生き延びろ！</p>
      <ul class="howto">
        <li><b>移動</b>：WASD / 矢印キー、またはスマホは画面をドラッグ</li>
        <li><b>攻撃</b>：自動。近くの影に光の弾を撃つ</li>
        <li><b>成長</b>：青い光のかけらを集めてレベルアップ。3 つの強化から 1 つを選ぶ</li>
        <li><b>4:00</b> に大きな影が出現。<b>5:00</b> の夜明けまで生き残ればクリア</li>
      </ul>
      <button class="btn primary" id="startBtn">はじめる</button>
      <a class="back" href="../../../../">← ゲーム一覧へ</a>
    </div>
  </div>

  <script src="game.js"></script>
</body>
</html>
```

画面は2つの層でできています。

- `canvas#game` … 地面・キツネ・影（敵）・弾など、ゲームの中身はすべてここに **Canvas（キャンバス）** で描きます。Canvas は JavaScript から図形や文字を自由に描ける「お絵かき用の板」です。
- `#title` … タイトル画面。`class="overlay"` を付けた板を Canvas の上に重ねて表示します。あとでレベルアップ画面・一時停止画面・リザルト画面も同じしくみで追加します。

`viewport` の `user-scalable=no` はスマホでドラッグしたときに画面が拡大されるのを防ぐため、`viewport-fit=cover` はノッチのある iPhone でも画面いっぱいに表示するための指定です。`<script>` を `body` の最後に置くと、HTML の部品が全部できてから JavaScript が動くので、`getElementById` で確実に要素を取れます。

ポイントは次のとおりです。

- `html, body` の `overflow: hidden` と、`canvas` の `width: 100vw; height: 100vh;` で、Canvas を画面いっぱいに広げ、スクロールバーが出ないようにします。
- `touch-action: none` は、スマホで Canvas をドラッグしたときにページがスクロールしたり拡大したりしないようにする指定です。ステップ3のタッチ操作で効いてきます。
- `.overlay` は `position: fixed; inset: 0;` で画面全体を覆い、`display: flex` で中の `.panel` を上下左右の中央に置きます。
- `.hidden` クラスを付けると要素が消えます。画面の切り替えはすべて **このクラスの付け外し** で行います。`!important` を付けているのは、`.overlay` の `display: flex` より確実に優先させるためです。

## game.js

```js:game.js
// ランタン守りの夜 — 夜明けまで生き延びるサバイバー系アクション
(() => {
  'use strict';

  const canvas = document.getElementById('game');
  const ctx = canvas.getContext('2d');
  const $ = (id) => document.getElementById(id);

  const clamp = (v, a, b) => (v < a ? a : v > b ? b : v);
  const rand = (a, b) => a + Math.random() * (b - a);
  const TAU = Math.PI * 2;

  let W = 0, H = 0, DPR = 1, zoom = 1;
  function resize() {
    DPR = Math.min(window.devicePixelRatio || 1, 2);
    W = window.innerWidth;
    H = window.innerHeight;
    canvas.width = Math.round(W * DPR);
    canvas.height = Math.round(H * DPR);
    zoom = clamp(Math.min(W, H) / 620, 0.55, 1.25);
  }
  window.addEventListener('resize', resize);
  resize();

  // ---------- 状態 ----------
  let state = 'title'; // title / play

  // ---------- 画面遷移 ----------
  function hideOverlays() {
    for (const id of ['title']) $(id).classList.add('hidden');
  }
  function startGame() {
    hideOverlays();
    state = 'play';
  }

  $('startBtn').addEventListener('click', startGame);
})();
```

全体を `(() => { ... })();` で囲んでいます。これは **即時関数** と呼ばれる書き方で、中で作った変数がページ全体（グローバル）に漏れ出さないようにします。`'use strict';` は、うっかりミス（宣言していない変数への代入など）をエラーとして教えてもらうためのおまじないです。

- `canvas.getContext('2d')` で、Canvas に描くための道具（**コンテキスト**）を取り出します。以後の描画はすべて `ctx` を通して行います。
- `$` は `document.getElementById` の短縮形です。何度も使うので短い名前を付けました。
- `clamp(v, a, b)` は値を `a`〜`b` の範囲に収める関数、`rand(a, b)` は `a`〜`b` のランダムな小数を返す関数、`TAU` は円一周ぶんの角度（2π）です。どれもこの先あちこちで使います。

### resize と高解像度対応

`resize()` は画面サイズに合わせて Canvas の大きさを決めます。

- `W` と `H` は CSS 上の画面サイズ（ピクセル）です。
- `DPR`（devicePixelRatio）は「CSS の1ピクセルが実際には何ドットか」を表します。スマホでは 2〜3 のことが多く、Canvas の中身を `W × DPR` ドットで作っておくと、くっきり描けます。重くなりすぎないよう最大 2 に抑えています。
- `zoom` は画面の小ささに合わせてゲーム世界を縮小・拡大する倍率です。スマホでも PC でも、だいたい同じ広さが見えるようにします。

`window.addEventListener('resize', resize)` で、ウィンドウの大きさが変わるたびに計算し直します。

### 状態（state）

`state` は「いまゲームがどの場面にいるか」を表す文字列です。最初は `'title'`、はじめるボタンを押すと `'play'` になります。完成版では `title / play / levelup / pause / over` の5つを使い分けます。画面ごとに「何を受け付けて、何を動かすか」をこの変数1つで判断できるので、場面の多いゲームでも混乱しにくくなります。

`hideOverlays()` はオーバーレイを全部隠す関数です。いまは `title` だけですが、画面が増えたらこの配列に足していきます。
