## このステップのゴール

ゲームに山場を作ります。

- 1分ごとに、影の群れが **ぐるっと輪になって** 一斉に襲ってくる
- 4:00 に **大きな影（ボス）** が現れる。HP バー付きで、倒すと大量のかけらを落とす
- 「影の群れが囲んできた！」のような **お知らせ（バナー）** を画面中央に出す

## 定数とボスのデータ

定数に、ボスが出る時刻を足します。

```js:game.js
  const RUN_TIME = 300;      // 夜明けまでの秒数
  const BOSS_TIME = 240;     // 大きな影が出る時刻
```

`ETYPES` の `brute` の **下** に、ボスを追加します。

```js:game.js
    boss:  { hp: 2600, spd: 46, r: 56, dmg: 28, xp: 60, score: 3000 },
```

体力 2600、半径 56 と、ほかの影とはけた違いの強さです。

## 状態の追加

状態の宣言の2行目と、`reset()` の中の2行を書き換えます。

```js:game.js
  let t, kills, score, spawnAcc, nextWave, bossSpawned, pendingLevels, shake, bannerTimer;
```

```js:game.js
    t = 0; kills = 0; score = 0; spawnAcc = 0; nextWave = 60; bossSpawned = false;
    pendingLevels = 0; shake = 0; bannerTimer = 0;
```

`nextWave` は次の群れが来る時刻（60秒、120秒、180秒）、`bossSpawned` はボスをもう出したか、`bannerTimer` はお知らせを表示しておく残り秒数です。

## ボスは時間で強くならない

`spawnEnemy` の中の2か所を変えます。

```js:game.js
    const hpMul = type === 'boss' ? 1 : 1 + t / 100;
    enemies.push({
      type, x, y, r: d.r, hp: d.hp * hpMul, maxHp: d.hp * hpMul, spd: d.spd * (type === 'boss' ? 1 : 1 + t / 900),
```

ふつうの影は時間とともに強くなりますが、ボスまで強くなると 240 秒時点で体力が 3.4 倍になってしまうので、ボスだけは表の数値そのままにします。

## お知らせ（バナー）

`burst` 関数の **下** に追加します。

```js:game.js
  function showBanner(msg) {
    const b = $('banner');
    b.textContent = msg;
    b.classList.add('show');
    bannerTimer = 2.6;
  }
```

ステップ5で作った `#banner` に文字を入れて `show` クラスを付けると、CSS の `transition` でふわっと現れます。2.6 秒たったら `update` の中で `show` を外して消します。

## ボスの手ごたえ

`hitEnemy` の `res`（ノックバックの効きやすさ）の行を書き換えます。

```js:game.js
    const res = e.type === 'boss' ? 0.05 : e.type === 'brute' ? 0.35 : 1;
```

ボスはほとんど押し戻されません。

`killEnemy` 全体を次のように書き換えます。

```js:game.js
  function killEnemy(e) {
    e.dead = true;
    kills++;
    score += e.score;
    burst(e.x, e.y, e.type === 'wisp' ? '#7ff3e0' : '#b28cff', e.type === 'boss' ? 40 : 7);
    if (e.type === 'boss') {
      for (let i = 0; i < 20; i++) gems.push({ x: e.x + rand(-60, 60), y: e.y + rand(-60, 60), v: 3, kind: 'gem' });
      gems.push({ x: e.x, y: e.y, v: 60, kind: 'heart' });
      showBanner('大きな影をたおした！');
      shake = 0.6;
    } else {
      gems.push({ x: e.x, y: e.y, v: e.xp, kind: 'gem' });
      if (Math.random() < 0.012) gems.push({ x: e.x + 8, y: e.y, v: 25, kind: 'heart' });
    }
  }
```

ボスを倒すと、火花を40個散らし、かけら20個と大きな回復ハート（HP +60）をばらまき、画面を揺らしてお知らせを出します。がんばったごほうびが目に見えると、達成感が大きくなります。

## 群れとボスを出現させる

`update` の先頭、`t += dt;` の **下** に、お知らせを消す処理を足します。

```js:game.js
    t += dt;
    if (bannerTimer > 0) { bannerTimer -= dt; if (bannerTimer <= 0) $('banner').classList.remove('show'); }
    if (shake > 0) shake -= dt;
```

「出現」の `while` ループの **下**（`updateWeapons(dt);` の上）に追加します。

```js:game.js
    if (t >= nextWave && nextWave < BOSS_TIME) {
      const n = 22, d = viewRadius() * 0.85;
      const type = nextWave >= 180 ? 'wisp' : nextWave >= 120 ? 'bat' : 'blob';
      for (let i = 0; i < n; i++) {
        const a = i * TAU / n;
        spawnEnemy(type, clamp(P.x + Math.cos(a) * d, 20, WORLD - 20), clamp(P.y + Math.sin(a) * d, 20, WORLD - 20));
      }
      showBanner('影の群れが囲んできた！');
      nextWave += 60;
    }
    if (!bossSpawned && t >= BOSS_TIME) {
      bossSpawned = true;
      spawnRing('boss');
      showBanner('大きな影が現れた！');
      shake = 0.5;
    }
```

### 時間で起きるイベントの管理

ふだんの出現（ステップ4）とは別に、**決まった時刻に1回だけ起きるイベント** を管理しています。

- **群れ**: `t` が `nextWave` を超えたら群れを出し、`nextWave` を 60 秒先に進めます。こうすれば同じ群れが2回出ることはありません。キツネを中心に、22 体を角度 `TAU / 22` ずつずらして円形に並べるので、「囲まれた！」という感じが出ます。60秒は blob、120秒はコウモリ、180秒は鬼火の群れです。
- **ボス**: `bossSpawned` というフラグで「もう出したか」を覚え、1回だけ出します。

「次のイベント時刻」や「済んだかどうか」の変数を持ち、それを `reset()` で初期化しておくのが、時間で進むゲームを作るときの基本です。

## ボスは押し合いでも動かない

「押し合い」ループの中の、押し離す2行を次の3行に置き換えます。

```js:game.js
          const wa = a.type === 'boss' ? 0.05 : 0.5, wb = b.type === 'boss' ? 0.05 : 0.5;
          a.x -= ux * push * wa; a.y -= uy * push * wa;
          b.x += ux * push * wb; b.y += uy * push * wb;
```

ボスはほとんど動かず、まわりの小さな影のほうが押しのけられます。重さの違いが表現できました。

## 開始時のお知らせ

`startGame` を次のように書き換えます。

```js:game.js
  function startGame() {
    reset();
    hideOverlays();
    $('hud').classList.remove('hidden');
    $('banner').classList.remove('show');
```

前のゲームのお知らせが残っていたら消してから、開始のメッセージを出します。

## ボスを描く

`drawEnemy` の `brute` の描画のあと、`ctx.restore();` の **上** に `else if` を足します。

```js:game.js
    } else if (e.type === 'brute') {
      ctx.fillStyle = flash ? '#fff' : '#3c3a4f';
      ctx.beginPath(); ctx.roundRect ? ctx.roundRect(-e.r, -e.r, e.r * 2, e.r * 2, 9) : ctx.rect(-e.r, -e.r, e.r * 2, e.r * 2); ctx.fill();
      ctx.fillStyle = flash ? '#fff' : '#52506a';
      ctx.fillRect(-e.r + 5, -e.r + 5, e.r * 0.8, e.r * 0.5);
    } else if (e.type === 'boss') {
      ctx.fillStyle = flash ? '#fff' : '#24133f';
      ctx.beginPath();
      for (let i = 0; i < 14; i++) {
        const a = i * TAU / 14, rr = e.r * (i % 2 ? 0.85 : 1.08) + Math.sin(t * 3 + i) * 3;
        ctx.lineTo(Math.cos(a) * rr, Math.sin(a) * rr);
      }
      ctx.fill();
      ctx.fillStyle = flash ? '#fff' : '#3a1f63';
      ctx.beginPath(); ctx.arc(0, 0, e.r * 0.7, 0, TAU); ctx.fill();
    }
    ctx.restore();
```

円周上の14個の点を、半径を「大・小・大・小…」と交互に変えながら結ぶと、ギザギザのトゲのある形になります。半径に `sin` で小さな揺れを足して、うごめいているように見せています。

`drawEyes` の最初の2行も、ボスに対応させます。

```js:game.js
    const s = e.type === 'boss' ? 3 : e.type === 'brute' ? 1.6 : 1;
    const col = e.type === 'brute' || e.type === 'boss' ? '#ff5050' : e.type === 'wisp' ? '#c8fff6' : '#ffe14d';
```

ボスの目は3倍の大きさで、赤く光ります。

最後に `render()` の中、`ctx.globalCompositeOperation = 'source-over';` の **下**（`// ダメージ数字` の上）に、ボスの HP バーを追加します。

```js:game.js

    // ボスのHPバー
    for (const e of list) {
      if (e.type !== 'boss') continue;
      ctx.fillStyle = 'rgba(0,0,0,.6)';
      ctx.fillRect(e.x - 50, e.y - e.r - 20, 100, 8);
      ctx.fillStyle = '#ff5050';
      ctx.fillRect(e.x - 50, e.y - e.r - 20, 100 * clamp(e.hp / e.maxHp, 0, 1), 8);
    }
```

黒い枠の上に、残り体力の割合だけ赤い四角を重ねます。HUD のバーと同じ考え方を Canvas で描いたものです。

> [!TIP]
> ボスを早く見たいときは、確認のあいだだけ `BOSS_TIME` を `20` にすると、20秒でボスが出てきます（群れは `nextWave < BOSS_TIME` の間しか来なくなるので、確認が終わったら 240 に戻しましょう）。
