## このステップのゴール

画面全体を **夜の闇** で覆い、キツネのランタンのまわりだけが明るく照らされるようにします。影たちの目は闇の中でも光って見え、最後の1分は空がだんだん白んで夜明けが近づきます。このゲームの雰囲気を決める、いちばん「絵」として効くステップです。

## 夜明けの進み具合

`hash` 関数の **下** に追加します。

```js:game.js
  function dawn() { return clamp((t - (RUN_TIME - 60)) / 60, 0, 1); }
```

残り60秒（240秒時点）までは 0、そこから 300 秒に向けて 0 → 1 に増える値です。「進み具合を 0〜1 の数にしておく」と、色や暗さを `0のときの値 + 進み具合 × 変化量` の形で簡単に変えられます。

## 地面の色を夜明けに合わせる

`drawGround` の先頭の `ctx.fillStyle = 'rgb(20,30,46)';` の1行を、次の3行に置き換えます。

```js:game.js
    const dw = dawn();
    const r = Math.round(20 + dw * 40), g = Math.round(30 + dw * 30), b = Math.round(46 + dw * 30);
    ctx.fillStyle = `rgb(${r},${g},${b})`;
```

夜明けが近づくにつれて、地面の色が紺色から少し明るい青緑に変わります。

## 闇とランタンの明かりを描く

`render()` の中、`drawPlayer();` から `for (const e of list) drawEyes(e);` までを次のように書き換えます。

```js:game.js
    drawPlayer();

    // 暗闇（ランタンの明かり）
    ctx.setTransform(DPR, 0, 0, DPR, 0, 0);
    const sx = (P.x - camX) * zoom, sy = (P.y - camY) * zoom;
    const dark = 0.78 * (1 - dawn() * 0.85);
    const flick = 1 + Math.sin(t * 9) * 0.015 + Math.sin(t * 23) * 0.01;
    const grad = ctx.createRadialGradient(sx, sy, 60 * zoom * flick, sx, sy, Math.max(W, H) * 0.62);
    grad.addColorStop(0, 'rgba(4,6,20,0)');
    grad.addColorStop(0.35, `rgba(4,6,20,${dark * 0.45})`);
    grad.addColorStop(1, `rgba(4,6,20,${dark})`);
    ctx.fillStyle = grad;
    ctx.fillRect(0, 0, W, H);
    const warm = ctx.createRadialGradient(sx, sy, 0, sx, sy, 140 * zoom);
    warm.addColorStop(0, 'rgba(255,190,90,.16)');
    warm.addColorStop(1, 'rgba(255,190,90,0)');
    ctx.fillStyle = warm;
    ctx.fillRect(0, 0, W, H);
    if (dawn() > 0) {
      ctx.fillStyle = `rgba(255,170,120,${dawn() * 0.18})`;
      ctx.fillRect(0, 0, W, H);
    }

    // 光るもの（暗闇の上に描く）
    toWorld();
    for (const e of list) drawEyes(e);
```

### 闇の作り方: 半透明のグラデーションを重ねる

「明かりで照らす」というと難しそうですが、やっていることは **ふつうに全部描いたあとで、画面全体に半透明の黒を重ねる** だけです。

1. `setTransform(DPR, 0, 0, DPR, 0, 0)` で画面の座標に切り替え、キツネの画面上の位置 `sx, sy` を求めます（ワールド座標からカメラ位置を引いてズームを掛ける）。
2. キツネを中心にした `createRadialGradient`（放射状グラデーション）を作ります。中心近くは透明、外に行くほど濃い紺色にし、それで画面全体を塗ります。これでランタンのまわりだけ明るく見えます。
3. その上に、オレンジ色のごく薄いグラデーションを重ね、ランタンの **暖かい光** を表現します。
4. 夜明けが近づくと、闇を薄く（`dark` を小さく）して、画面全体にうっすら朝焼けの色をかぶせます。

`flick` は `sin` を2つ足した、小さく不規則に揺れる値です。明るい範囲がほんの少し揺らぐことで、炎がゆらめいているように見えます。

### 描く順番が見た目を決める

Canvas は **あとから描いたものが上に重なる** ので、順番がとても大事です。

1. 地面・かけら・敵・キツネ（闇の **下** に描くので、遠くのものは暗く沈む）
2. 闇
3. 敵の目・弾・灯火・流れ星・エフェクト・ダメージ数字（闇の **上** に描くので、遠くでも光って見える）

ステップ4で目を `drawEyes` として分けておいたのは、ここで「体は闇に沈むのに、目だけ光って見える」ようにするためでした。闇を描いたあとは `toWorld()` でワールド座標に戻してから続きを描きます。

> [!CHECK] 動作チェック
> 再読み込みして「はじめる」を押します。
> - 画面の外側が暗くなり、キツネのまわりだけがランタンで明るく照らされている。明かりがかすかに揺らいでいる
> - 暗がりの影たちは姿がよく見えないが、黄色い目だけが光っている
> - 弾・灯火・火花・ダメージ数字は闇の上でもくっきり見える
> - タイトル画面の後ろも夜の雰囲気になっている

> [!TIP]
> 夜明けの様子をすぐ確かめたいときは、確認のあいだだけ `reset()` の `t = 0` を `t = 250` にしてみましょう。開始してすぐ闇が薄くなり、空が朝焼け色に染まります（確認したら 0 に戻します）。
