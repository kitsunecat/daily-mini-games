## このステップのゴール

ゲームとして仕上げます。

- **一時停止**（ボタン・P / Esc キー・タブを切り替えたとき）と、持っている強化の一覧
- **リザルト画面**（生存時間・撃破数・レベル・スコア）
- **ハイスコアの保存**（localStorage）と、タイトル画面への表示
- Enter / スペースキーで開始・リトライ

このステップが終わると、完成品と同じゲームになります。

## ハイスコアの保存（localStorage）

`game.js` の定数の最後（`MAX_ENEMIES` の下）に、保存用の名前を足します。

```js:game.js
  const MAX_ENEMIES = 280;
  const BEST_KEY = 'lantern-night-best';
```

`resize();` の **下** に、読み込みと保存の関数を追加します。

```js:game.js
  function loadBest() {
    try { return Number(localStorage.getItem(BEST_KEY)) || 0; } catch (e) { return 0; }
  }
  function saveBest(v) {
    try { localStorage.setItem(BEST_KEY, String(v)); } catch (e) { /* 保存できない環境は無視 */ }
  }
```

**localStorage** は、ブラウザにちょっとしたデータを保存しておける場所です。ページを閉じても残るので、ハイスコアの保存にぴったりです。

- 保存できるのは文字列だけなので、`String(v)` で文字にして保存し、読むときは `Number(...)` で数に戻します。まだ何も保存されていないと `getItem` は `null` を返し、`Number(null)` は 0 になります。`|| 0` は念のための保険です。
- プライベートブラウズなどでは localStorage が使えずエラーになることがあります。`try { ... } catch` で囲み、保存できなくてもゲームが止まらないようにしています。
- `BEST_KEY` は保存場所の名前です。ほかのゲームと混ざらないよう、ゲームごとに違う名前にします。

状態のコメントを更新し、状態の宣言の **下** にハイスコアの変数を足します。

```js:game.js
  let state = 'title'; // title / play / levelup / pause / over
  let P, enemies, bullets, gems, effects, texts, stars;
  let t, kills, score, spawnAcc, nextWave, bossSpawned, pendingLevels, shake, bannerTimer;
  let best = loadBest();
```

`best` は `reset()` で初期化しないことに注意してください。ゲームをやり直してもハイスコアは残ります。

## キー操作をまとめる

`keydown` の中の、レベルアップ用の `if` を、次の `if ... else if` の連なりに置き換えます。

```js:game.js
    if (state === 'title' && (k === 'enter' || k === ' ')) startGame();
    else if (state === 'over' && (k === 'enter' || k === ' ')) startGame();
    else if ((k === 'p' || k === 'escape') && state === 'play') pauseGame();
    else if ((k === 'p' || k === 'escape') && state === 'pause') resumeGame();
    else if (state === 'levelup' && ['1', '2', '3'].includes(k)) {
      const btn = $('cards').children[Number(k) - 1];
      if (btn) btn.click();
    }
```

同じキーでも、`state` によって意味が変わります（P キーはプレイ中なら一時停止、一時停止中なら再開）。`else if` でつないでいるのは、一時停止した直後に同じキーで再開されてしまう、といった「1回の入力で2つの処理が動く」事故を防ぐためです。

## 一時停止

`hideOverlays` の配列を全部の画面にします。

```js:game.js
    for (const id of ['title', 'levelup', 'pause', 'result']) $(id).classList.add('hidden');
```

`startGame` 関数の **下** に、一時停止と再開を追加します。

```js:game.js
  function pauseGame() {
    if (state !== 'play') return;
    state = 'pause';
    joy.active = false;
    const owned = $('owned');
    owned.innerHTML = '';
    for (const k of Object.keys(UPGRADES)) {
      if (!P.lv[k]) continue;
      const s = document.createElement('span');
      s.textContent = `${UPGRADES[k].icon} ${UPGRADES[k].name} Lv${P.lv[k]}`;
      owned.appendChild(s);
    }
    $('pause').classList.remove('hidden');
  }
  function resumeGame() {
    if (state !== 'pause') return;
    $('pause').classList.add('hidden');
    state = 'play';
  }
```

レベルアップ画面と同じく、`state` を `'pause'` にするだけでゲームは止まります。一時停止画面には、いま持っている強化（レベル 1 以上のもの）を「🔥 まわる灯火 Lv2」のように並べ、作戦を考えられるようにしています。

## リザルト画面

`endGame` 全体を次のように書き換えます。

```js:game.js
  function endGame(cleared) {
    state = 'over';
    joy.active = false;
    const final = score + Math.floor(t) * 5 + P.level * 50 + (cleared ? 5000 : 0);
    const isNew = final > best;
    if (isNew) { best = final; saveBest(best); }
    $('resultTitle').textContent = cleared ? '🌅 夜明けだ！' : '力尽きた…';
    $('resultSub').textContent = cleared ? 'ランタンの灯を守り抜いた！ クリアボーナス +5000' : '灯が消えてしまった。強化の組み合わせを変えて再挑戦！';
    $('rTime').textContent = fmt(Math.min(t, RUN_TIME));
    $('rKills').textContent = kills;
    $('rLevel').textContent = P.level;
    $('rScore').textContent = final.toLocaleString();
    $('bestResult').textContent = best.toLocaleString();
    $('newRecord').classList.toggle('hidden', !isNew);
    $('levelup').classList.add('hidden');
    setTimeout(() => $('result').classList.remove('hidden'), cleared ? 300 : 700);
  }
```

- 最終スコアは「倒した敵の得点 ＋ 生き残った秒数 × 5 ＋ レベル × 50 ＋ クリアなら 5000」です。倒すことと生き延びることの両方が評価されます。
- 前のハイスコアを超えたら `best` を更新して `saveBest` で保存し、「ハイスコア更新！」を表示します。`classList.toggle('hidden', !isNew)` は「第2引数が true なら付ける、false なら外す」という書き方です。
- `toLocaleString()` で `12345` を `12,345` のように3けた区切りにします。

## ボタンとタブ切り替え

`$('startBtn').addEventListener(...)` の **下** に追加します。

```js:game.js
  $('retryBtn').addEventListener('click', startGame);
  $('restartBtn').addEventListener('click', startGame);
  $('resumeBtn').addEventListener('click', resumeGame);
  $('pauseBtn').addEventListener('click', pauseGame);
  document.addEventListener('visibilitychange', () => { if (document.hidden) pauseGame(); });
  $('bestTitle').textContent = best.toLocaleString();
```

- `visibilitychange` は、タブを切り替えたりスマホでホーム画面に戻ったりして、ページが見えなくなったときに呼ばれます。そのとき自動で一時停止するので、戻ってきたら影に囲まれてやられていた、ということがありません。
- 最後の行で、タイトル画面にハイスコアを表示します。

> [!CHECK] 動作チェック
> 再読み込みします。
> - タイトル画面に「ハイスコア：0」が出ている。Enter かスペースでも開始できる
> - プレイ中に右上の「II」ボタン（または P / Esc）で一時停止し、持っている強化の一覧が出る。「再開する」や P で続きから、「最初からやり直す」で最初から
> - 別のタブに切り替えて戻ると、一時停止画面になっている
> - やられると「力尽きた…」のリザルト画面に生存時間・撃破数・レベル・スコアが出て、初回は「★ ハイスコア更新！ ★」が表示される
> - 「もう一度あそぶ」（または Enter）で再挑戦でき、再読み込みしてもタイトルのハイスコアが残っている
> - 5:00 まで生き残ると「🌅 夜明けだ！」とクリアボーナス付きのリザルトが出る

## 完成！ 改造してみよう

おつかれさまでした。これで「ランタン守りの夜」の完成品と同じゲームができあがりました。数値の表やデータの形にしてある部分が多いので、少し書き換えるだけで遊び心地が大きく変わります。

> [!TIP]
> **新しい強化を作る**: `UPGRADES` に「ランタンの輝き（明るい範囲が広がる）」を足し、`render()` の闇のグラデーションの内側の半径 `60 * zoom * flick` にレベルを掛けてみましょう。`P.lv` にも同じ名前を 0 で足すのを忘れずに。

> [!TIP]
> **新しい影を作る**: `ETYPES` に「分裂する影」を足し、`killEnemy` でその種類のときだけ `spawnEnemy` を2回呼んで小さな blob を出してみましょう。`pickType` と `drawEnemy` にも分岐を足します。

> [!TIP]
> **難易度を選べるようにする**: タイトル画面に「やさしい / ふつう / むずかしい」のボタンを置き、出現ペースの式 `0.8 + t / 24` や `hpMul` に難易度の倍率を掛けてみましょう。ハイスコアは `BEST_KEY + 難易度` のように保存場所を分けると公平です。

> [!TIP]
> **効果音を付ける**: Web Audio API の `OscillatorNode` で、弾を撃つ「ピッ」やレベルアップの「ポロン」を鳴らしてみましょう。鳴らしすぎるとうるさいので、弾の音は 0.1 秒に1回までにするなどの工夫がいります。
