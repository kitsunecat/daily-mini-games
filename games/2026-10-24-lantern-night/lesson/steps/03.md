## このステップのゴール

キーボード（WASD / 矢印キー）と、スマホの **仮想スティック**（画面をドラッグ）でキツネを動かせるようにします。キツネが動くとカメラが追いかけ、草原がスクロールします。

## 移動の速さを持たせる

`reset()` の中の `P = { ... }` の1行目に `baseSpeed: 165` を足します。

```js:game.js
    P = {
      x: WORLD / 2, y: WORLD / 2, r: 16, baseSpeed: 165,
      face: 1, walk: 0,
    };
```

そして `reset();` の **すぐ下** に、速さを返す関数を追加します。

```js:game.js
  const speed = () => P.baseSpeed;
```

いまは `baseSpeed` をそのまま返すだけですが、あとで「身軽な足」という強化を取ると速くなるようにします。速さを使う場所で直接 `P.baseSpeed` と書かず、関数を1つ通しておくと、そのときに書き換えるのが1か所で済みます。

## 入力を受け取る

`speed` の下（`// ---------- 更新 ----------` の **上**）に、入力のコードをまとめて追加します。

```js:game.js
  // ---------- 入力 ----------
  const keys = new Set();
  const joy = { active: false, id: null, ox: 0, oy: 0, x: 0, y: 0 };

  window.addEventListener('keydown', (e) => {
    const k = e.key.toLowerCase();
    keys.add(k);
    if (['arrowup', 'arrowdown', 'arrowleft', 'arrowright', ' '].includes(k)) e.preventDefault();
  });
  window.addEventListener('keyup', (e) => keys.delete(e.key.toLowerCase()));
  window.addEventListener('blur', () => keys.clear());

  canvas.addEventListener('pointerdown', (e) => {
    if (state !== 'play') return;
    joy.active = true; joy.id = e.pointerId;
    joy.ox = joy.x = e.clientX; joy.oy = joy.y = e.clientY;
    canvas.setPointerCapture(e.pointerId);
  });
  canvas.addEventListener('pointermove', (e) => {
    if (!joy.active || e.pointerId !== joy.id) return;
    joy.x = e.clientX; joy.y = e.clientY;
  });
  const endJoy = (e) => { if (e.pointerId === joy.id) { joy.active = false; joy.id = null; } };
  canvas.addEventListener('pointerup', endJoy);
  canvas.addEventListener('pointercancel', endJoy);

  function inputVec() {
    let mx = 0, my = 0;
    if (keys.has('a') || keys.has('arrowleft')) mx -= 1;
    if (keys.has('d') || keys.has('arrowright')) mx += 1;
    if (keys.has('w') || keys.has('arrowup')) my -= 1;
    if (keys.has('s') || keys.has('arrowdown')) my += 1;
    if (joy.active) {
      const dx = joy.x - joy.ox, dy = joy.y - joy.oy;
      const len = Math.hypot(dx, dy);
      if (len > 6) { const m = Math.min(1, len / 50); mx = dx / len * m; my = dy / len * m; }
    }
    const l = Math.hypot(mx, my);
    if (l > 1) { mx /= l; my /= l; }
    return [mx, my];
  }
```

### キーボード: 「押されているキー」を覚えておく

`keydown` のたびにキャラを動かすと、キーリピートの速さに左右されてガクガクします。そこで **いま押されているキーの集合** `keys`（`Set`）を持ち、`keydown` で追加、`keyup` で削除します。動かすのはゲームループの中で `keys` を見て行います。

- `e.key.toLowerCase()` で、Shift やCapsLockの状態に関係なく `'a'` や `'arrowleft'` として扱えます。
- 矢印キーとスペースは、ページがスクロールしないよう `preventDefault()` で既定の動作を止めます。
- `blur`（ウィンドウからフォーカスが外れた）ときは全部クリアします。キーを押したまま別のウィンドウに移ると `keyup` が届かず、押しっぱなし扱いになるのを防ぐためです。

### 仮想スティック: Pointer Events

`pointerdown` / `pointermove` / `pointerup` は **Pointer Events** と呼ばれるイベントで、マウスとタッチを同じコードで扱えます。

- 指を置いた場所 `ox, oy` がスティックの中心、いまの指の位置 `x, y` との差がスティックの傾きです。
- `pointerId` を覚えておき、同じ指の動きだけを見ます（2本目の指で誤作動しないように）。
- `setPointerCapture` で、指が Canvas の外に出ても `pointermove` / `pointerup` を受け取り続けます。
- `pointercancel` は、着信などで操作が中断されたときに呼ばれます。

### inputVec: 入力を「向きと強さ」にまとめる

`inputVec()` はキーボードとスティックの入力を、`[mx, my]`（それぞれ -1〜1）という1つの **ベクトル** にまとめて返します。

- `Math.hypot(dx, dy)` は √(dx² + dy²)、つまり2点間の距離です。
- スティックは 6 ピクセル未満の小さなブレを無視し、50 ピクセル傾けたら最大速度になります。`dx / len` は「長さ 1 の向き」で、それに強さ `m` を掛けています。
- 最後の `if (l > 1)` が大事です。右と上を同時に押すと `(1, -1)` で長さが約 1.41 になり、斜め移動だけ速くなってしまいます。長さが 1 を超えたら割って 1 にそろえます（これを **正規化** と言います）。

## update でキツネを動かす

`update` 関数全体を次のように書き換えます。

```js:game.js
  function update(dt) {
    t += dt;

    // プレイヤー
    const [mx, my] = inputVec();
    const sp = speed();
    P.x = clamp(P.x + mx * sp * dt, P.r, WORLD - P.r);
    P.y = clamp(P.y + my * sp * dt, P.r, WORLD - P.r);
    if (mx > 0.1) P.face = 1; else if (mx < -0.1) P.face = -1;
    P.moving = Math.abs(mx) + Math.abs(my) > 0.1;
    if (P.moving) P.walk += dt * 10;
  }
```

- 位置は「向き × 速さ × dt」だけ進めます。`clamp` でワールドの外に出ないようにしています。
- 左右の入力があれば `face` を切り替えます。
- `P.moving` は動いているかどうか。`drawPlayer` はこれを見て、歩いているときだけキツネを上下に弾ませます（`bob`）。

## スティックを描く

`render()` の最後、`drawPlayer();` の **下** に追加します。

```js:game.js
    // 仮想スティック
    ctx.setTransform(DPR, 0, 0, DPR, 0, 0);
    if (joy.active && state === 'play') {
      ctx.strokeStyle = 'rgba(255,255,255,.35)'; ctx.lineWidth = 2;
      ctx.beginPath(); ctx.arc(joy.ox, joy.oy, 50, 0, TAU); ctx.stroke();
      const dx = joy.x - joy.ox, dy = joy.y - joy.oy, l = Math.hypot(dx, dy), m = Math.min(l, 50);
      ctx.fillStyle = 'rgba(255,214,120,.5)';
      ctx.beginPath(); ctx.arc(joy.ox + (l ? dx / l * m : 0), joy.oy + (l ? dy / l * m : 0), 20, 0, TAU); ctx.fill();
    }
```

スティックはワールドではなく **画面** に固定して描きたいので、`setTransform(DPR, 0, 0, DPR, 0, 0)` でカメラのずれとズームを外しています（高解像度対応の `DPR` だけ残します）。こうすると `clientX/Y`（画面の座標）をそのまま使って描けます。

> [!CHECK] 動作チェック
> 再読み込みして「はじめる」を押します。
> - WASD または矢印キーでキツネが動き、草原がスクロールする。斜め移動も同じ速さ
> - 左に動くとキツネが左を向き、歩いている間はぴょこぴょこ弾む
> - スマホ（または開発者ツールのデバイスモード）で画面をドラッグすると、半透明の円とつまみが出てその方向に動く
> - ずっと同じ方向に進むと、ワールドの端で止まり、外側は暗い森になっている
