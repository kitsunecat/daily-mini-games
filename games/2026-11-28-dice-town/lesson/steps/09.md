## このステップのゴール

サイコロが 0 になったら **ゲームオーバー画面** を出し、★ の数・残りコイン・周回数を表示します。いちばん多かった ★ の数を **ハイスコア（BEST）** としてブラウザに保存し、「もう一度あそぶ」でリトライできるようにして、ゲームを完成させます。

## ハイスコアを読みこむ

`const ui = { ... };` の **下**（`const START_DICE = 40;` の上）に追加します。

```js:game.js
  const BEST_KEY = 'dice-town-best';
```

`// ---- 状態 ----` の **下**（`const S = { ... };` の上）に追加します。

```js:game.js
  let best = 0;
  try { best = parseInt(localStorage.getItem(BEST_KEY), 10) || 0; } catch (e) { best = 0; }
  ui.best.textContent = best;

```

### localStorage

**localStorage** は、ブラウザにちょっとしたデータを保存しておける場所です。ページを閉じても、次に開いたときに残っています。

- `localStorage.setItem(キー, 文字)` で保存、`localStorage.getItem(キー)` で読み出し
- 保存できるのは **文字だけ** です。読み出した文字は `parseInt(..., 10)` で数に直します。まだ保存していないときは `null` が返り、`parseInt` は `NaN` になるので、`|| 0` で 0 にします
- キーの名前はほかのゲームとぶつからないように、`dice-town-best` のようにゲーム名を入れておきます
- プライベートブラウズなどで使えない環境もあるので、`try { ... } catch` で囲んでおきます

## ゲームオーバー：gameOver()

`start()` の **下** に追加します。

```js:game.js

  function gameOver() {
    S.playing = false;
    let isNew = false;
    if (S.stars > best) { best = S.stars; isNew = true; try { localStorage.setItem(BEST_KEY, String(best)); } catch (e) { /* 保存できなくても続行 */ } }
    ui.best.textContent = best;
    ui.ovTitle.textContent = 'サイコロ切れ！';
    ui.ovText.innerHTML = `タウンの★ <b class="hl" style="font-size:28px">${S.stars}</b><br>` +
      `のこりコイン ${S.coins}・${S.laps} 周<br>` + (isNew ? '<b class="hl">ハイスコア更新！</b>' : `ベスト ★${best}`) +
      '<br><small>コツ：🎲マスや GO の手前で ×3 にすると効率アップ</small>';
    ui.start.textContent = 'もう一度あそぶ';
    ui.overlay.classList.remove('hidden');
    setMsg('おつかれさま！');
    updateUI();
  }
```

- 今回の ★ がベストより多ければ、ベストを更新して保存します
- タイトル画面と同じオーバーレイを使い、見出し・本文・ボタンの文字だけ書きかえて **ゲームオーバー画面** にします。本文は `<b>` や `<br>` を入れたいので `innerHTML` を使います。ここに入るのはゲームの中で作った数字だけなので安全です
- ボタンは `start` につながったままなので、「もう一度あそぶ」を押すと `start()` が呼ばれ、`Object.assign` ですべての値が初期値に戻って新しいゲームが始まります。これがリトライのしくみです

## サイコロが尽きたら呼ぶ

`roll()` の最後の行を、次のように **書きかえます**。

```js:game.js
    if (S.dice <= 0) { await wait(700); gameOver(); }
```

最後のマスの効果を 0.7 秒見せてから、ゲームオーバー画面を出します。🎲マスやゾロ目でサイコロが増えた場合は 0 にならないので、そのまま続けられます。

## ゲームオーバー後もコマを残す

`draw()` の `// コマ` の下の `if (S.playing) {` を、次のように **書きかえます**。

```js:game.js
    if (S.playing || S.dice === 0) {
```

ゲームオーバーになると `S.playing` は `false` になりますが、サイコロが 0 のときはコマを描き続けて、最後に止まった場所がオーバーレイの後ろに見えるようにします。

これで完成です！ 完成品と同じゲームになりました。

> [!CHECK] 動作チェック
> - サイコロを使いきると、少し待ってから「サイコロ切れ！」の画面が出て、★ の数・のこりコイン・周回数が表示される
> - 初めてのプレイ（★1 以上）では「ハイスコア更新！」と出て、上の BEST が ★ の数になる
> - 「もう一度あそぶ」を押すと、🪙50・🎲40・★0 から新しいゲームが始まる
> - ページを再読み込みしても BEST の数字が残っている
> - （試すなら `START_DICE` を 3 にすると、すぐにゲームオーバーを確かめられます）

## 改造アイデア

> [!TIP]
> **盤を変える**：`TILES` の並びや `v` の数字を書きかえるだけで、まったく違う盤になります。🎲マスを増やすと長く遊べ、アライグマを増やすとスリル満点に。マスの数を変えるときは `POS` の作り方（外周のマス数）も合わせて変えましょう。

> [!TIP]
> **新しいマスを作る**：たとえば「ジャンプ台：5 マス先へワープ」や「ルーレット：コインが 2倍 か 半分」など。`tileLabel()` に見た目、`landOn()` に `case` を1つずつ足すだけです。`warpTo()` や `moveSteps()` も使い回せます。

> [!TIP]
> **建物に効果をつける**：🏪 を建てたら GO ボーナス 2倍、🏫 を建てたら税金が半分……のように、`TOWN` の絵文字ごとに特別な効果をつけると、建てる順番を考える楽しさが加わります。

> [!TIP]
> **バランス調整**：`buildCost()` の 1.38 や `payRate()` の 0.15、`START_DICE` の 40 を変えて、★ がいくつまで届くか試してみましょう。数字を少し変えるだけで、遊びごたえが大きく変わります。
