## このステップのゴール

音声ファイルを使わずに、ブラウザの **Web Audio API** でピコピコした効果音を作ります。コマが1マス進むたびの「ポッ」、サイコロが転がる「カラカラ」、スタートの「ピン」を鳴らします。コインや建設の音もここでまとめて用意しておき、あとのステップで使います。

## 効果音を作る：beep() と sfx

`TILES.forEach((tile) => { ... });`（数字のマスに色を配る行）の **下**、`// ---- 状態 ----` の **上** に追加します。

```js:game.js
  // ---- 効果音（Web Audio） ----
  let actx = null;
  function beep(freq, dur = 0.08, type = 'square', vol = 0.06, delay = 0) {
    try {
      if (!actx) actx = new (window.AudioContext || window.webkitAudioContext)();
      const t = actx.currentTime + delay;
      const o = actx.createOscillator(), g = actx.createGain();
      o.type = type; o.frequency.setValueAtTime(freq, t);
      g.gain.setValueAtTime(vol, t); g.gain.exponentialRampToValueAtTime(0.0001, t + dur);
      o.connect(g); g.connect(actx.destination); o.start(t); o.stop(t + dur + 0.02);
    } catch (e) { /* 音が出なくても続行 */ }
  }
  const sfx = {
    step: () => beep(660, 0.04, 'triangle', 0.05),
    coin: () => { beep(988, 0.07, 'square', 0.05); beep(1319, 0.12, 'square', 0.05, 0.07); },
    bad: () => { beep(220, 0.15, 'sawtooth', 0.05); beep(160, 0.2, 'sawtooth', 0.05, 0.12); },
    build: () => [523, 659, 784, 1047].forEach((f, i) => beep(f, 0.12, 'triangle', 0.07, i * 0.08)),
    dice: () => beep(300 + Math.random() * 300, 0.03, 'square', 0.03),
  };

```

### Web Audio のしくみ

Web Audio は、音の部品を **線でつなぐ** ように組み立てます。

1. `AudioContext` … 音を鳴らすための作業場。1つ作って使い回します
2. `createOscillator()` … 決まった高さ（周波数 `freq`、単位 Hz）の音を出し続ける発振器。`type` で音色を選びます。`square`（矩形波）はピコピコ、`triangle`（三角波）はやわらかい音、`sawtooth`（のこぎり波）はジリジリした音です
3. `createGain()` … 音量つまみ。`exponentialRampToValueAtTime` で、`dur` 秒かけて音量をほぼ 0 まで下げると、「ポン」と自然に消える音になります
4. `o.connect(g); g.connect(actx.destination);` で「発振器 → 音量つまみ → スピーカー」とつなぎ、`start` / `stop` で鳴らす時間を決めます

- `delay` を使うと、少し遅れて鳴らせます。`sfx.coin` は高い音を2つずらして「ピロン」、`sfx.build` はドミソドの4音を順に鳴らしてファンファーレにしています
- `sfx.dice` は毎回高さをランダムにして、転がっている感じを出しています
- ブラウザは「ユーザーが画面を操作するまで音を出さない」決まりがあります。`actx` を最初の `beep()` のとき（＝ボタンを押したとき）に作っているのはそのためです
- 音が出せない環境でもゲームが止まらないように、全体を `try { ... } catch` で囲んでいます

## 鳴らす場所を足す

`moveSteps()` を次のように **書きかえます**（`sfx.step();` が増えました）。

```js:game.js
  async function moveSteps(n) {
    for (let s = 0; s < n; s++) {
      const from = tileCenter(S.pos);
      S.pos = (S.pos + 1) % TILES.length;
      const to = tileCenter(S.pos);
      sfx.step();
      await tween(130, (k) => {
        S.tokenX = from[0] + (to[0] - from[0]) * k; S.tokenY = from[1] + (to[1] - from[1]) * k;
        S.hop = Math.sin(k * Math.PI);
      });
      S.hop = 0;
    }
  }
```

`roll()` の中の、サイコロを転がす `for` の中身を次のように **書きかえます**。

```js:game.js
    for (let i = 0; i < 9; i++) {
      S.faces = [1 + Math.floor(Math.random() * 6), 1 + Math.floor(Math.random() * 6)];
      sfx.dice(); await wait(45 + i * 6);
    }
```

`start()` の中、`setMsg('「ふる！」でサイコロをふろう');` の **下** に追加します。

```js:game.js
    beep(784, 0.1, 'triangle', 0.06);
```

> [!CHECK] 動作チェック
> - スタートを押すと「ピン」と鳴る
> - 「ふる！」でサイコロが転がる間「カラカラ」と高さの違う短い音が鳴り、コマが1マス進むたびに「ポッ」と鳴る
> - 音が出なくても（端末をマナーモードにしていても）ゲームは今までどおり動き、Console にエラーが出ない
