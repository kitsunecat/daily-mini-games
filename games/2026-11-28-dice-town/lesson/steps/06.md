## このステップのゴール

止まったマスによって **コインが増えたり減ったり** するようにします。数字のマス・GO・金庫・🎲マス・税金・アライグマの効果を作り、GO を **通過** したときのボーナスと、**ゾロ目** でサイコロが増えるルールも入れます。コインが増えると「+60🪙」のような文字がふわっと浮かび、上のコイン表示がポンとふくらみます。

## 状態を増やす

`const S = { ... };` を次のように **書きかえます**。これで完成品と同じ形になります。

```js:game.js
  const S = {
    playing: false, busy: false, coins: 0, dice: 0, stars: 0, mult: 1, pos: 0,
    tokenX: 0, tokenY: 0, hop: 0, faces: [1, 1], rolling: false, floats: [], laps: 0,
  };
```

- `coins` … 持っているコイン
- `stars` … 建てたタウンの数（★）。スコアになります。建てるのはステップ8ですが、次の `payRate()` で使うので先に用意します
- `floats` … 画面に浮かんでいる文字（「+60🪙」など）のリスト
- `laps` … 盤を何周したか

`const S = { ... };` の **下** に追加します。

```js:game.js

  const payRate = () => 1 + 0.15 * S.stars;
```

`payRate()` は **収入の倍率** です。★ が1つ増えるごとに、マスでもらえるコインが 15% ずつ増えます。今は ★0 なので 1 倍です。

## 数字がふくらむ演出：bump()

`function setMsg(t) { ... }` の **下** に追加します。

```js:game.js
  function bump(el) { el.parentNode.classList.remove('bump'); void el.offsetWidth; el.parentNode.classList.add('bump'); }
```

`el` は数字の `<b>` で、その親の `.pill` に `bump` クラスをつけると、CSS のアニメーションが1回再生されます。

CSS のアニメーションは「同じクラスをもう一度つけても」再生されません。そこで、一度外して、`void el.offsetWidth`（要素の幅を読むだけの何もしない文）でブラウザに「いったん外れた状態」を計算させてから、もう一度つけます。連続でコインが増えても毎回ポンとふくらみます。

`updateUI()` を次のように **書きかえます**（コインの行が増えました）。

```js:game.js
  function updateUI() {
    ui.coins.textContent = S.coins;
    ui.dice.textContent = S.dice;
    const can = S.playing && !S.busy;
    ui.roll.disabled = !can || S.dice < 1;
  }
```

## 浮かぶ文字

`draw()` の最後、`// コマ` の `if (S.playing) { ... }` の **下**（`draw()` の最後の `}` の上）に追加します。

```js:game.js

    // 浮かぶ文字
    S.floats.forEach((f) => {
      ctx.globalAlpha = Math.max(0, f.life);
      ctx.font = `bold ${cell * 0.32}px sans-serif`;
      ctx.lineWidth = 4; ctx.strokeStyle = 'rgba(0,0,0,.6)';
      ctx.strokeText(f.text, f.x, f.y); ctx.fillStyle = f.color; ctx.fillText(f.text, f.x, f.y);
    });
    ctx.globalAlpha = 1;
```

`ctx.globalAlpha` は描くものの不透明度（0〜1）です。`life` が減るほど薄くなります。先に黒い太線で `strokeText`（ふち取り）してから `fillText` で塗ると、どんな背景の上でも文字が読みやすくなります。描き終わったら `globalAlpha` を 1 に戻すのを忘れずに。

`loop()` を丸ごと **書きかえます**。

```js:game.js
  let last = performance.now();
  function loop(now) {
    const dt = Math.min(0.05, (now - last) / 1000); last = now;
    S.floats.forEach((f) => { f.y -= 34 * dt; f.life -= dt * 0.8; });
    S.floats = S.floats.filter((f) => f.life > 0);
    draw();
    requestAnimationFrame(loop);
  }

  function float(text, color) {
    S.floats.push({ text, color, x: S.tokenX, y: S.tokenY - cell * 0.5, life: 1.2 });
  }
```

- `requestAnimationFrame` は呼ぶ関数に **今の時刻（ミリ秒）** を渡してくれます。前のフレームとの差を秒に直したものが `dt`（デルタタイム）です。動きを「1秒あたり 34px 上へ」のように `dt` をかけて書くと、パソコンの速さが違っても同じ速さで動きます。タブを切りかえて戻ったときに一気に飛ばないよう、最大 0.05 秒に抑えています
- `filter` で `life` が 0 以下になった文字をリストから取り除きます
- `float(text, color)` は、コマの少し上に文字を1つ出す関数です

## コインとサイコロを増減する

`// ---- 進行 ----` の **下**（`moveSteps()` の上）に追加します。

```js:game.js
  function addCoins(n, label) {
    S.coins = Math.max(0, S.coins + n);
    float((n >= 0 ? '+' : '') + n + '🪙', n >= 0 ? '#ffe27a' : '#ff8a8a');
    bump(ui.coins);
    if (label) setMsg(label);
    (n >= 0 ? sfx.coin : sfx.bad)();
  }
  function addDice(n, label) {
    S.dice += n; float('+' + n + '🎲', '#9fe7ff'); bump(ui.dice); setMsg(label); sfx.coin();
  }

```

- `addCoins` は増えるときも減るときも使います。`Math.max(0, ...)` でコインがマイナスにならないようにし、増えたら黄色の「+〇🪙」と「ピロン」、減ったら赤い「-〇🪙」と「ブブー」を出します
- `(n >= 0 ? sfx.coin : sfx.bad)();` は、条件で選んだ関数をその場で呼ぶ書き方です

## GO の通過ボーナス

`moveSteps()` の `for` の中、`S.hop = 0;` の **下** に1行追加します。

```js:game.js
      if (S.pos === 0 && s < n - 1) { S.laps++; addCoins(Math.round(60 * S.mult * payRate()), 'GO 通過ボーナス！'); }
```

GO（0番）に来たとき、それが **最後の1歩でなければ**（`s < n - 1`）「通過」です。GO にぴったり止まったときは、次の `landOn()` でもっと大きなボーナスを出すので、ここでは数えません。

## 止まったマスの効果：landOn()

`moveSteps()` の **下**（`roll()` の上）に追加します。

```js:game.js
  async function landOn() {
    const tile = TILES[S.pos], m = S.mult, pr = payRate();
    switch (tile.t) {
      case 'go': S.laps++; addCoins(Math.round(120 * m * pr), 'GO にぴったり！ボーナス大'); break;
      case 'prop': addCoins(Math.round(tile.v * m * pr), m > 1 ? `×${m} でコインゲット！` : 'コインゲット！'); break;
      case 'bonus': addCoins(Math.round(150 * m * pr), '金庫マス！ごっそりコイン'); break;
      case 'dice': addDice(2 * m, `サイコロ +${2 * m}！`); break;
      case 'tax': {
        const lose = Math.round(S.coins * 0.15);
        if (lose > 0) addCoins(-lose, '税金マス…コインが15%へった'); else setMsg('税金マス…でも払うコインがなかった');
        break;
      }
      case 'thief': {
        const lose = Math.round(S.coins * 0.3);
        if (lose > 0) addCoins(-lose, 'アライグマにコインを持っていかれた！'); else setMsg('アライグマ…何もとられなかった');
        break;
      }
      case 'chance': setMsg('チャンスマス！（中身はステップ7で作ります）'); break;
    }
  }

```

- ここでも **switch 文** でマスの種類ごとに分けます。`tileLabel()` と違って `return` しないので、各 `case` の最後に `break` が必要です。忘れると次の `case` まで続けて実行されてしまいます
- もらえる量は「基本の数 × 倍率 `m` × 収入倍率 `pr`」です。`Math.round` で整数にします
- 税金とアライグマは「持っているコインの 15% / 30%」を失います。割合にしておくと、たくさん持っているほど痛い＝ためこみすぎず建てよう、という作戦が生まれます
- `case 'tax': { ... }` のように `{ }` で囲むと、その中だけで使える `const lose` を作れます
- `async` をつけているのは、ステップ7のチャンスマスで `await` を使うためです

## roll() と start() をつなぐ

`roll()` の中、`await moveSteps(a + b);` の **下** に2行追加します。

```js:game.js
    await landOn();
    if (a === b) { await wait(250); addDice(S.mult, `ゾロ目！サイコロ +${S.mult}`); }
```

マスの効果のあと、2つの目が同じ（ゾロ目）ならサイコロが増えます。

`start()` の中の `Object.assign(...)` の行を、次のように **書きかえます**。

```js:game.js
    Object.assign(S, { playing: true, busy: false, coins: 50, dice: START_DICE, stars: 0, mult: 1, pos: 0, floats: [], laps: 0, faces: [1, 1] });
```

コイン 50 枚を持ってスタートします。

> [!CHECK] 動作チェック
> - スタートすると 🪙 が **50** になる
> - 数字のマスに止まると、コマの上に黄色い「+30🪙」などが浮かんで消え、「ピロン」と鳴って 🪙 がふくらみながら増える
> - 🎲マスに止まると水色の「+2🎲」が出て、サイコロが 2 増える
> - 税金・アライグマのマスではコインが減り、赤い「-〇🪙」と低い音が出る
> - GO を通りすぎると「GO 通過ボーナス！」で +60🪙、ぴったり止まると +120🪙
> - ゾロ目が出ると「ゾロ目！サイコロ +1」
> - ？のマスでは「チャンスマス！（中身はステップ7で作ります）」と出る
