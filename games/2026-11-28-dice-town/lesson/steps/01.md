## このステップのゴール

3つのファイルを用意して、ゲーム画面の土台を作ります。上に「← 一覧・STARS・BEST」、その下にコインとサイコロの残り数、まん中に盤を描く **Canvas**、その上に重ねるタイトル画面（オーバーレイ）、いちばん下にメッセージと3つのボタン（倍率・ふる！・建てる）を置きます。スタートを押すとタイトル画面が消えるところまで作ります。

完成すると、こんなゲームになります。

- 6×6 の盤の **外周 20 マス** を、サイコロ2つの合計だけ進んでぐるぐる回る
- 数字のマスに止まるとその数だけ **コイン** がもらえる。**GO** の通過や **金庫（💰）** でボーナス、**🎲マス** や **ゾロ目** でサイコロが増える
- **税金** と **アライグマ** のマスではコインが減る。**？（チャンス）** は何が起きるか運しだい
- 集めたコインで **タウンを建てる** と ★ が1つ増え、マスでもらえるコインもアップする
- **×2・×3** にするとサイコロを多く使うかわりに、もらえる量も2倍・3倍
- サイコロが 0 になったら終了。**★ の数がスコア**


- `<meta name="viewport" ...>` はスマホで画面幅に合わせて表示し、ピンチで拡大されないようにする設定です
- JavaScript から書きかえる場所には `id`（`score`・`best`・`coins`・`dice`・`msg`・`cost`・`ov-title`・`ov-text` など）をつけておきます
- `<canvas id="cv">` がゲームの絵を描く場所です。盤・コマ・サイコロ・タウンはすべてここに JavaScript で描きます
- コインやサイコロの数（`#hud`）とボタン（`#controls`）は Canvas の外の **ふつうの HTML** です。数字やボタンは HTML で作ったほうが、くっきり読みやすく、押せる・押せないの切りかえもかんたんです
- `#overlay` はタイトル画面とゲームオーバー画面を兼ねた「ふた」で、盤の上に重ねて表示します
- ボタンには `type="button"` をつけておきます。フォームの中でなくても、意図しない送信動作を防ぐ習慣です
- 「← 一覧」のリンク先はこのサイトのトップです。自分のフォルダで作るときは好きなページに変えてかまいません
- `<script>` を `</body>` の直前に置くと、HTML の要素がすべて読みこまれてから JavaScript が動きます

- `.pill.bump` と `@keyframes bump` は、コインやサイコロの数が変わったときに一瞬ふくらむ演出です（ステップ6で使います）

- `#controls button:disabled` で、押せないボタンを半透明にします。ボタンの `disabled` を JavaScript で切りかえるだけで見た目も変わります
- `env(safe-area-inset-bottom)` は、iPhone の画面下のバーにボタンが隠れないようにするための余白です

## game.js

JavaScript はまず「スタートでタイトル画面を消す」だけを書きます。あとで使う要素も、ここでまとめて取り出しておきます。

```js:game.js
(() => {
  'use strict';
  const $ = (id) => document.getElementById(id);
  const cv = $('cv'), ctx = cv.getContext('2d');
  const stage = $('stage');
  const ui = {
    score: $('score'), best: $('best'), coins: $('coins'), dice: $('dice'), msg: $('msg'),
    mult: $('mult'), roll: $('roll'), build: $('build'), cost: $('cost'),
    overlay: $('overlay'), ovTitle: $('ov-title'), ovText: $('ov-text'), start: $('start'),
  };

  // ---- 状態 ----
  const S = { playing: false, busy: false };

  function setMsg(t) { ui.msg.textContent = t; }

  // ---- 進行 ----
  function start() {
    Object.assign(S, { playing: true, busy: false });
    ui.overlay.classList.add('hidden');
    setMsg('「ふる！」でサイコロをふろう');
  }

  ui.start.addEventListener('click', start);
  window.addEventListener('keydown', (e) => {
    if (e.repeat) return;
    if (!S.playing) { if (e.key === 'Enter' || e.key === ' ') { e.preventDefault(); if (!ui.overlay.classList.contains('hidden')) start(); } return; }
  });
})();
```

### 全体を (() => { ... })(); で囲む

ファイル全体を「すぐ実行される関数」で囲むと、中で作った変数がページ全体（グローバル）に漏れません。`'use strict';` は、うっかりミスをエラーとして教えてくれるモードです。

- `const $ = (id) => document.getElementById(id);` は、何度も書く `document.getElementById` を短く書くための小さな関数です
- `cv` は Canvas の要素、`ctx` は Canvas に絵を描くための **2D コンテキスト**（ペンのようなもの）です。ステップ2から使います
- `ui` は、書きかえる HTML 要素をまとめたオブジェクトです。`ui.msg`・`ui.roll` のように名前で取り出せるので、あとのコードが読みやすくなります

### 状態は S にまとめる

`S`（State の S）は、ゲームの状態をまとめて持つオブジェクトです。今は2つだけです。

- `playing` … プレイ中なら `true`
- `busy` … サイコロを転がしたりコマが動いたりしている最中なら `true`。動いている間にボタンを連打されないようにするために使います

このあと、コイン・サイコロの数・コマの位置などを、すべてこの `S` に足していきます。

### start() とスタートの受け付け

- `start()` はゲームを始める関数です。`Object.assign(S, { ... })` は、`S` の中の値をまとめて上書きします。「始めるたびに初期値に戻す」ための書き方で、項目が増えてもこの1行に足すだけで済みます
- オーバーレイに `hidden` クラスをつけて隠し、メッセージを書きかえます
- キーボードでは Enter か Space でスタートできます。`e.repeat` はキーを押しっぱなしにしたときの連続入力なので無視します。`e.preventDefault()` は、Space でページがスクロールするなどのブラウザの動きを止めるためのものです

> [!NOTE]
> 関数は `// ---- 状態 ----` や `// ---- 進行 ----` のような見出しコメントで区切っていきます。このあと「〇〇の **下** に追加」「〇〇を **書きかえる**」という指示が出てくるので、見出しを目印にして正しい場所に入れましょう。

> [!CHECK] 動作チェック
> - 深い緑の画面に、黄色の「サイコロすごろくタウン」とルール説明、黄色の「タップでスタート」ボタンが出る
> - 上に「← 一覧」・STARS 0・BEST 0、その下に 🪙 0 と 🎲 0 が並んでいる
> - 下に「×1」「ふる！」「建てる 🪙100」の3つのボタンがある（まだ押しても何も起きません）
> - スタートを押すとタイトル画面が消え、下のメッセージが「「ふる！」でサイコロをふろう」に変わる。まん中は何もない状態でOK
> - 開発者ツールの Console にエラーが出ていない
