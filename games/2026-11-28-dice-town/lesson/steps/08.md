## このステップのゴール

このゲームの作戦の部分を作ります。

- **建てる** … コインを払ってタウンを建てると ★ が1つ増え、芝生の上に家や木が並ぶ。マスでもらえるコインも 15% ずつ増える。そのかわり、次に建てる値段はどんどん高くなる
- **倍率** … ×1 → ×2 → ×3 と切りかえると、1回にサイコロを 2個・3個使うかわりに、もらえるコインやサイコロも 2倍・3倍になる

## タウンの絵文字と建設コスト

`TILES.forEach((tile) => { ... });` の **下**（`// ---- 効果音` の上）に追加します。

```js:game.js
  const TOWN = ['🏠', '🌳', '🏡', '⛲', '🏪', '🌷', '🏫', '🎡', '🏬', '🗼', '🏰', '🎢', '🏟️', '🚀'];

```

建てるたびに、この順番で絵文字が増えていきます。

`const payRate = ...` の **上** に追加します。

```js:game.js
  const buildCost = () => Math.round(100 * Math.pow(1.38, S.stars) / 10) * 10;
```

建設コストは「100 × 1.38 の ★乗」です。`Math.pow(1.38, n)` は 1.38 を n 回かけた数なので、100 → 140 → 190 → 260 → 360 … と、建てるほど **かけ算で** 高くなります。最後に 10 で割って丸めてから 10 をかけ、きりのいい 10 の倍数にしています。

> [!NOTE]
> 収入（`payRate`）は ★ ごとに **足し算** で 15% ずつ増えるのに、コストは **かけ算** で 38% ずつ増えます。最初は建てるほど得をしますが、だんだん割に合わなくなっていく……この2つの式のバランスが、このゲームの「いつまで建て続けるか」の駆け引きを作っています。

## updateUI() を完成させる

`updateUI()` を丸ごと **書きかえます**。

```js:game.js
  function updateUI() {
    ui.score.textContent = S.stars;
    ui.coins.textContent = S.coins;
    ui.dice.textContent = S.dice;
    ui.cost.textContent = '🪙' + buildCost();
    ui.mult.textContent = '×' + S.mult;
    ui.mult.className = S.mult > 1 ? 'x' + S.mult : '';
    const can = S.playing && !S.busy;
    ui.roll.disabled = !can || S.dice < 1;
    ui.mult.disabled = !can;
    const canBuild = can && S.coins >= buildCost();
    ui.build.disabled = !canBuild;
    ui.build.classList.toggle('ready', canBuild);
  }
```

- STARS に ★ の数、建てるボタンに次の値段を出します
- 倍率ボタンには `x2`・`x3` クラスをつけて色を変えます（×1 のときはクラスなし）
- 建てるボタンは、コインが足りているときだけ押せるようにし、`ready` クラスで光らせます。`classList.toggle('ready', canBuild)` は、2つめの値が `true` ならクラスをつけ、`false` なら外します

## マスの数字を収入倍率に合わせる

`tileLabel()` の `default:` の行を、次のように **書きかえます**。

```js:game.js
      default: return [String(Math.round(tile.v * payRate())), '#fffaf0', '#2b4a3a'];
```

★ が増えると、盤に書かれた数字も実際にもらえる量に合わせて大きくなります。

## タウンを描く

`draw()` の中、`ctx.textAlign = 'center'; ctx.textBaseline = 'middle';` の **下**（`// サイコロ` の上）に追加します。

```js:game.js
    // タウン
    const n = Math.min(S.stars, 12);
    ctx.font = `${cell * 0.55}px sans-serif`; ctx.fillStyle = '#000';
    for (let i = 0; i < n; i++) {
      const gx = i % 4, gy = Math.floor(i / 4);
      ctx.fillText(TOWN[i % TOWN.length], cell * (1.5 + gx), cell * (2.05 + gy * 0.72));
    }
    if (S.stars > 12) {
      ctx.font = `bold ${cell * 0.28}px sans-serif`; ctx.fillStyle = '#fff';
      ctx.fillText('ほか +' + (S.stars - 12), cell * 4.35, cell * 4.45);
    }
    // タウン名・レベル
    ctx.fillStyle = 'rgba(0,0,0,.25)'; roundRect(cell * 1.6, cell * 1.12, cell * 2.8, cell * 0.5, 10); ctx.fill();
    ctx.fillStyle = '#fff'; ctx.font = `bold ${cell * 0.26}px sans-serif`;
    ctx.fillText(`タウン ★${S.stars}  収入×${payRate().toFixed(2)}`, cell * 3, cell * 1.37);

```

- 建物は **4列 × 3段** に並べます。i 番目の建物の列は `i % 4`（4で割った余り：0,1,2,3,0,1,…）、段は `Math.floor(i / 4)`（4で割った商：0,0,0,0,1,1,…）です。1列の並びを、余りと商で「折り返す」定番の書き方です
- 芝生に入りきるのは 12 個までなので、それより多いときは右下に「ほか +〇」と書きます
- 芝生の上のほうに、半透明の帯で「タウン ★3 収入×1.45」のような情報を出します。`toFixed(2)` は小数点以下2けたの文字にする関数です

## 倍率をサイコロの数に合わせる

`roll()` を丸ごと **書きかえます**（2か所に `S.mult` を調整する行が増えました）。

```js:game.js
  async function roll() {
    if (!S.playing || S.busy || S.dice < 1) return;
    if (S.mult > S.dice) S.mult = S.dice;
    S.busy = true; S.dice -= S.mult; updateUI();
    S.rolling = true;
    for (let i = 0; i < 9; i++) {
      S.faces = [1 + Math.floor(Math.random() * 6), 1 + Math.floor(Math.random() * 6)];
      sfx.dice(); await wait(45 + i * 6);
    }
    S.rolling = false;
    const a = 1 + Math.floor(Math.random() * 6), b = 1 + Math.floor(Math.random() * 6);
    S.faces = [a, b];
    setMsg(`${a} + ${b} = ${a + b} マス！`);
    await wait(220);
    await moveSteps(a + b);
    await landOn();
    if (a === b) { await wait(250); addDice(S.mult, `ゾロ目！サイコロ +${S.mult}`); }
    S.busy = false;
    if (S.mult > S.dice && S.dice > 0) S.mult = S.dice;
    updateUI();
    if (S.dice <= 0) setMsg('サイコロがなくなった！');
  }
```

- ふる前に、倍率が残りのサイコロより大きければ下げます（サイコロ 2 個で ×3 はできません）
- ふり終わったあとも同じように調整しておくと、ボタンの表示が「本当に使える倍率」になります。サイコロが 0 のときは倍率を変えません

## 建てる：build() と 倍率の切りかえ：cycleMult()

`roll()` の **下**（`start()` の上）に追加します。

```js:game.js
  function build() {
    if (!S.playing || S.busy) return;
    const c = buildCost();
    if (S.coins < c) return;
    S.coins -= c; S.stars++;
    sfx.build(); bump(ui.coins);
    S.floats.push({ text: '★+1 ' + TOWN[(S.stars - 1) % TOWN.length], color: '#fff', x: size / 2, y: size / 2, life: 1.4 });
    setMsg(`タウンが育った！ マスのコインが ×${payRate().toFixed(2)} に`);
    updateUI();
  }

  function cycleMult() {
    if (!S.playing || S.busy) return;
    let m = S.mult + 1; if (m > 3) m = 1;
    if (m > S.dice) m = 1;
    S.mult = m; beep(440 + m * 120, 0.06, 'triangle', 0.05);
    setMsg(m === 1 ? '倍率 ×1：サイコロ1個で1回' : `倍率 ×${m}：サイコロ${m}個使って、もらえる量 ${m} 倍`);
    updateUI();
  }

```

- `build()` は、コインが足りていれば払って ★ を増やし、ファンファーレを鳴らして、盤のまん中に「★+1 🏠」を浮かべます。`float()` はコマの上に出す関数なので、ここでは `S.floats` に直接入れて位置を盤の中心にしています
- `cycleMult()` は 1 → 2 → 3 → 1 … と順にまわします。残りのサイコロが足りない倍率は飛ばして 1 に戻ります。倍率が高いほど高い音にしています
- どちらも、サイコロが動いている間（`S.busy`）は何もしません

## ボタンとキーをつなぐ

`ui.roll.addEventListener('click', roll);` の **下** に追加します。

```js:game.js
  ui.build.addEventListener('click', build);
  ui.mult.addEventListener('click', cycleMult);
```

`window.addEventListener('keydown', ...)` を、次のように **書きかえます**（M と B の2行が増えました）。

```js:game.js
  window.addEventListener('keydown', (e) => {
    if (e.repeat) return;
    if (!S.playing) { if (e.key === 'Enter' || e.key === ' ') { e.preventDefault(); if (!ui.overlay.classList.contains('hidden')) start(); } return; }
    if (e.key === ' ' || e.key === 'Enter') { e.preventDefault(); roll(); }
    else if (e.key === 'm' || e.key === 'M') cycleMult();
    else if (e.key === 'b' || e.key === 'B') build();
  });
```

> [!TIP]
> ×3 にするとサイコロは早くなくなりますが、🎲マスに止まれば +6、ゾロ目なら +3 とサイコロも 3 倍で返ってきます。「GO や 🎲マスの少し手前にいるときだけ ×3」のように、盤を見て倍率を変えるのがコツです。

> [!CHECK] 動作チェック
> - 芝生の上に「タウン ★0 収入×1.00」の帯が出る
> - コインが 100 以上たまると「建てる」ボタンが光って押せるようになり、押すとファンファーレと「★+1 🏠」が出て、STARS が 1、芝生に 🏠 が建つ
> - 建てたあとはボタンの値段が 🪙140 に上がり、盤の数字のマスの数字も少し大きくなる（20 → 23 など）
> - 「×1」ボタン（または M キー）で ×2（オレンジ）→ ×3（赤）→ ×1 と切りかわる
> - ×3 でふると 🎲 が 3 減り、もらえるコインが 3 倍になる
> - B キーでも建てられる
