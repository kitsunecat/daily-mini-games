## このステップのゴール

GO のマスに赤いコマを置き、「ふる！」を押すとサイコロ2つぶんのマス数だけ、**1マスずつぴょんぴょん跳ねながら** 進むようにします。ここで、このゲームの心臓部である **Promise と async / await** を使った「待ってから次へ」の書き方を覚えます。

## 状態にコマの位置を足す

`// ---- 状態 ----` の下の `const S = ...` を、次のように **書きかえます**。

```js:game.js
  const S = {
    playing: false, busy: false, pos: 0,
    tokenX: 0, tokenY: 0, hop: 0,
  };
```

- `pos` … コマがいるマスの番号（0〜19）。0 は GO です
- `tokenX`・`tokenY` … コマを **描く** 位置（ピクセル）。移動中はマスとマスの間の中途半端な位置にもなるので、`pos` とは別に持ちます
- `hop` … ジャンプの高さ（0〜1）。0 なら地面、1 ならいちばん高い所です

## 画面サイズが変わったらコマも合わせる

`resize()` を次のように **書きかえます**（最後の2行が増えました）。

```js:game.js
  function resize() {
    const r = stage.getBoundingClientRect();
    size = Math.max(200, Math.floor(Math.min(r.width - 12, r.height - 4)));
    dpr = Math.min(window.devicePixelRatio || 1, 2);
    cv.width = size * dpr; cv.height = size * dpr;
    cv.style.width = size + 'px'; cv.style.height = size + 'px';
    cell = size / 6;
    const [cx, cy] = tileCenter(S.pos);
    S.tokenX = cx; S.tokenY = cy;
  }
```

`cell` が変わるとマスの座標も変わるので、コマを今のマスの中心に置きなおします。

## コマと今いるマスを描く

`draw()` の `TILES.forEach((tile, i) => { ... });` の中、`if (tile.t === 'prop') { ... } else { ... }` の **下**（`});` の直前）に1行追加します。

```js:game.js
      if (i === S.pos && S.playing) { ctx.lineWidth = 3; ctx.strokeStyle = '#ffe27a'; roundRect(x, y, w, w, 8); ctx.stroke(); }
```

コマのいるマスを黄色いふちで囲みます。

続けて、`TILES.forEach(...)` が終わった `});` の **下**（`draw()` の最後の `}` の上）に追加します。

```js:game.js

    // コマ
    if (S.playing) {
      const tx = S.tokenX, ty = S.tokenY - S.hop * cell * 0.35;
      ctx.fillStyle = 'rgba(0,0,0,.25)';
      ctx.beginPath(); ctx.ellipse(S.tokenX, S.tokenY + cell * 0.22, cell * 0.2 * (1 - S.hop * 0.3), cell * 0.07, 0, 0, Math.PI * 2); ctx.fill();
      ctx.fillStyle = '#e8384f'; ctx.strokeStyle = '#fff'; ctx.lineWidth = 2.5;
      ctx.beginPath();
      ctx.moveTo(tx - cell * 0.17, ty + cell * 0.2); ctx.lineTo(tx + cell * 0.17, ty + cell * 0.2);
      ctx.lineTo(tx + cell * 0.08, ty - cell * 0.02); ctx.lineTo(tx - cell * 0.08, ty - cell * 0.02); ctx.closePath();
      ctx.fill(); ctx.stroke();
      ctx.beginPath(); ctx.arc(tx, ty - cell * 0.12, cell * 0.13, 0, Math.PI * 2); ctx.fill(); ctx.stroke();
    }
```

- コマは「台形の胴体」と「丸い頭」の2つの図形です。`moveTo` / `lineTo` で4つの角を結んだのが胴体、`arc` で描いた円が頭です
- `ty = S.tokenY - S.hop * cell * 0.35` で、`hop` が大きいほどコマを **上に** ずらします（Canvas は下に行くほど y が大きいので、引き算で上）
- 影（`ellipse` の楕円）は地面に置いたまま、ジャンプが高いほど少し小さくします。これだけで「跳んでいる」感じがぐっと出ます

## 「待つ」を作る：wait() と tween()

`function loop() { ... }` の **下** に追加します。

```js:game.js

  const wait = (ms) => new Promise((res) => setTimeout(res, ms));
  function tween(ms, fn) {
    return new Promise((res) => {
      const t0 = performance.now();
      const step = (now) => { const k = Math.min(1, (now - t0) / ms); fn(k); if (k < 1) requestAnimationFrame(step); else res(); };
      requestAnimationFrame(step);
    });
  }
```

### Promise は「あとで終わる約束」

すごろくの1手は「サイコロを転がす → 1マス進む → また1マス進む → … → マスの効果」と、**前のことが終わってから次** の連続です。これを `setTimeout` のコールバックで書くと、入れ子が深くなって読めなくなります。

そこで **Promise** を使います。Promise は「いつか終わる処理」を表すもので、終わったときに `res()` を呼ぶ約束になっています。

- `wait(ms)` … ms ミリ秒たったら終わる Promise
- `tween(ms, fn)` … ms ミリ秒かけて、`k` を 0 から 1 まで進めながら毎フレーム `fn(k)` を呼び、1 になったら終わる Promise。**tween**（トゥイーン）は「間（between）を埋める」アニメーションのことです

`async` をつけた関数の中では、Promise の前に `await` と書くと「それが終わるまで待ってから次の行へ」進みます。これで、時間のかかる手順も上から順番に書けます。

## 1マスずつ進む：moveSteps()

`// ---- 進行 ----` の **下**（`function start()` の上）に追加します。

```js:game.js
  async function moveSteps(n) {
    for (let s = 0; s < n; s++) {
      const from = tileCenter(S.pos);
      S.pos = (S.pos + 1) % TILES.length;
      const to = tileCenter(S.pos);
      await tween(130, (k) => {
        S.tokenX = from[0] + (to[0] - from[0]) * k; S.tokenY = from[1] + (to[1] - from[1]) * k;
        S.hop = Math.sin(k * Math.PI);
      });
      S.hop = 0;
    }
  }

  async function roll() {
    if (!S.playing || S.busy) return;
    S.busy = true;
    const a = 1 + Math.floor(Math.random() * 6), b = 1 + Math.floor(Math.random() * 6);
    setMsg(`${a} + ${b} = ${a + b} マス！`);
    await moveSteps(a + b);
    S.busy = false;
  }
```

### moveSteps(n)

- `S.pos = (S.pos + 1) % TILES.length;` で次のマスへ。`%` は割り算の余りなので、19 の次は 20 ではなく **0（GO）** に戻ります。これで盤をぐるぐる回れます
- 1マスごとに `tween(130, ...)` で 0.13 秒かけて動かします。`from + (to - from) * k` は、k=0 で出発点、k=1 で到着点、その間はまっすぐ結んだ線の上、という **線形補間** の式です
- `Math.sin(k * Math.PI)` は、k が 0 → 0.5 → 1 と進むと 0 → 1 → 0 と山なりに変わります。これを `hop` に入れるだけで、ぴょんと跳ねる動きになります
- `for` の中で `await` しているので、1マス動き終わってから次のマスへ進みます

### roll()（仮）

- 今はサイコロの絵を出さずに、1〜6 の乱数を2つ作って合計だけ進みます。`Math.floor(Math.random() * 6)` は 0〜5 の整数なので、1 を足して 1〜6 にします
- 動いている間は `S.busy = true` にして、関数の最初の `if` で2回目の「ふる！」を受け付けないようにします。`await moveSteps(...)` が終わってから `false` に戻します

## start() とボタン

`start()` を次のように **書きかえます**。

```js:game.js
  function start() {
    Object.assign(S, { playing: true, busy: false, pos: 0 });
    const [x, y] = tileCenter(0); S.tokenX = x; S.tokenY = y;
    ui.overlay.classList.add('hidden');
    setMsg('「ふる！」でサイコロをふろう');
  }
```

始めるたびにコマを GO（0番）に置きます。

`ui.start.addEventListener('click', start);` の **下** に追加します。

```js:game.js
  ui.roll.addEventListener('click', roll);
```

`window.addEventListener('keydown', ...)` の中、`if (!S.playing) { ... }` の **下** に追加します。

```js:game.js
    if (e.key === ' ' || e.key === 'Enter') { e.preventDefault(); roll(); }
```

プレイ中は Space / Enter でもサイコロをふれます。

> [!CHECK] 動作チェック
> - スタートすると、右下の GO に赤いコマが立ち、GO のマスが黄色いふちで囲まれる
> - 「ふる！」を押すと「3 + 5 = 8 マス！」のようなメッセージが出て、コマがその数だけ **1マスずつ跳ねながら** 反時計回りに進む
> - 動いている間に「ふる！」を連打しても、動きが重なったり飛んだりしない
> - 何回かふって 20 マスを超えると、GO を通って2周目に入る
> - PC では Space / Enter キーでもふれる
