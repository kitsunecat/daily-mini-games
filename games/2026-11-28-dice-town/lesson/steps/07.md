## このステップのゴール

「？」の **チャンスマス** を作ります。止まると、宝くじ・サイコロを拾う・GO へワープ・3マス進む・財布を落とす、のどれかが **確率で** 起きます。GO へは、コマが大きく弧をえがいて **ひとっ飛び** でワープします。

## ひとっ飛びで移動する：warpTo()

`moveSteps()` の **下**（`landOn()` の上）に追加します。

```js:game.js
  async function warpTo(i) {
    const from = [S.tokenX, S.tokenY]; S.pos = i; const to = tileCenter(i);
    await tween(350, (k) => { S.tokenX = from[0] + (to[0] - from[0]) * k; S.tokenY = from[1] + (to[1] - from[1]) * k; S.hop = Math.sin(k * Math.PI) * 1.5; });
    S.hop = 0;
  }

```

`moveSteps()` と同じ `tween` ですが、1マスずつではなく **今の位置から目的のマスへ直接** 0.35 秒で飛びます。`hop` を 1.5 倍にして、いつもより高く跳ばせています。`tween` を一度作っておいたおかげで、新しい動きもほんの数行で書けます。

## チャンスの中身：chance()

`landOn()` の **下**（`roll()` の上）に追加します。

```js:game.js
  async function chance(m, pr) {
    const r = Math.random();
    if (r < 0.3) addCoins(Math.round(90 * m * pr), 'チャンス：宝くじが当たった！');
    else if (r < 0.5) addDice(1 + m, `チャンス：サイコロを ${1 + m} 個ひろった`);
    else if (r < 0.65) {
      setMsg('チャンス：GO へワープ！'); await wait(300); await warpTo(0);
      S.laps++; addCoins(Math.round(120 * m * pr), 'GO へワープしてボーナス！');
    } else if (r < 0.82) {
      setMsg('チャンス：3 マスすすむ'); await wait(300); await moveSteps(3); await landOn();
    } else {
      const lose = Math.round(S.coins * 0.1);
      if (lose > 0) addCoins(-lose, 'チャンス：財布を落とした…'); else setMsg('チャンス：財布を落としたけど空っぽだった');
    }
  }

```

### 確率で分ける

`Math.random()` は 0 以上 1 未満の数をランダムに返します。この数を **小さいほうから順に区切る** と、確率を決められます。

1. `0 〜 0.3` … 30% で宝くじ（+90🪙）
2. `0.3 〜 0.5` … 20% でサイコロを拾う
3. `0.5 〜 0.65` … 15% で GO へワープ
4. `0.65 〜 0.82` … 17% で 3 マス進む
5. `0.82 〜 1` … 18% で財布を落とす（コインの 10% を失う）

`if` / `else if` は上から順に調べて最初に当てはまったものだけを実行するので、`r < 0.5` の行は「0.3 以上 0.5 未満」という意味になります。数字を変えるだけで、良いことと悪いことの割合を調整できます。

### 3マス進んだら、また landOn()

「3 マス進む」では、進んだ先のマスの効果も起きるように、もう一度 `landOn()` を呼びます。`landOn()` の中から呼ばれた `chance()` が、また `landOn()` を呼ぶ形です（**再帰** と呼びます）。進んだ先がまた ？ なら、もう一度チャンスが起きます。

すべて `await` でつないでいるので、ワープや移動のアニメーションが終わってからコインが増え、そのあとで `roll()` に戻って「ふる！」が押せるようになります。

## landOn() から呼ぶ

`landOn()` の中の `case 'chance': ...` の行を、次のように **書きかえます**。

```js:game.js
      case 'chance': await chance(m, pr); break;
```

> [!CHECK] 動作チェック
> - ？ のマスに止まると「チャンス：〜」というメッセージが出て、何かが起きる（何回か試してみましょう）
> - 「GO へワープ！」では、コマが大きく弧をえがいて GO まで飛び、+120🪙 もらえる
> - 「3 マスすすむ」では、コマが 3 マス進み、進んだ先のマスの効果も起きる
> - チャンスの動きが終わるまで「ふる！」は押せず、終わると押せるようになる
