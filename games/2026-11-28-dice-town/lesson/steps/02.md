## このステップのゴール

Canvas に、まん中の芝生と外周 20 マスの盤を描きます。数字のマス（色の帯つき）、GO・？・税・🎲・💰・🦝 のマスが、右下の GO から反時計回りに並べば完成です。画面の大きさが変わっても、盤がステージにぴったり収まるようにします。

## マスの種類を配列で書く：TILES

`const ui = { ... };` の **下** に追加します。

```js:game.js
  // ---- 盤（6x6 の外周 20 マス。右下 GO から反時計回り） ----
  const TILES = [
    { t: 'go' }, { t: 'prop', v: 20 }, { t: 'chance' }, { t: 'prop', v: 30 }, { t: 'tax' },
    { t: 'dice' }, { t: 'prop', v: 40 }, { t: 'prop', v: 45 }, { t: 'chance' }, { t: 'prop', v: 55 },
    { t: 'bonus' }, { t: 'prop', v: 60 }, { t: 'thief' }, { t: 'prop', v: 70 }, { t: 'chance' },
    { t: 'dice' }, { t: 'prop', v: 80 }, { t: 'tax' }, { t: 'prop', v: 100 }, { t: 'chance' },
  ];
  const PROP_COLORS = ['#7fd3ff', '#7fd3ff', '#9fe07a', '#9fe07a', '#9fe07a', '#ffb36b', '#ffb36b', '#ff8fb1', '#ff8fb1', '#c9a0ff'];
  const POS = [];
  for (let i = 0; i <= 5; i++) POS.push([5 - i, 5]);
  for (let r = 4; r >= 0; r--) POS.push([0, r]);
  for (let c = 1; c <= 5; c++) POS.push([c, 0]);
  for (let r = 1; r <= 4; r++) POS.push([5, r]);
  let propIdx = 0;
  TILES.forEach((tile) => { if (tile.t === 'prop') tile.color = PROP_COLORS[propIdx++]; });
```

### マスの「中身」と「場所」を分ける

すごろくの盤は、**何のマスか**（中身）と **画面のどこにあるか**（場所）の2つの情報でできています。この2つを別々の配列にして、同じ番号どうしを組み合わせます。

- `TILES[i]` … i 番目のマスの中身。`t` は種類（`go`・`prop`＝数字のマス・`chance`・`tax`・`dice`・`bonus`・`thief`）、`v` は数字のマスでもらえるコインです。奥に行くほど `v` が大きくなるようにしています
- `POS[i]` … i 番目のマスの場所。盤を 6×6 のマス目と考えて、`[列, 行]`（0〜5）で表します

### 外周を4つの辺に分けて並べる

6×6 の外周はちょうど 20 マスです（6 + 4 + 5 + 5）。右下 `[5, 5]` をスタートにして、反時計回りに4つの `for` で並べます。

1. 下の辺：右から左へ `[5,5] → [0,5]`（6マス）
2. 左の辺：下から上へ `[0,4] → [0,0]`（5マス）
3. 上の辺：左から右へ `[1,0] → [5,0]`（5マス）
4. 右の辺：上から下へ `[5,1] → [5,4]`（4マス）

最後の `[5,4]` の次は、配列の先頭 `[5,5]`（GO）に戻ります。こうしておくと「1マス進む」は番号に 1 を足して 20 で割った余りを取るだけになります（ステップ3）。

`PROP_COLORS` は数字のマスの帯の色です。`forEach` で数字のマスだけに順番に色を配り、`tile.color` に入れておきます。

## Canvas の大きさを合わせる：resize()

`function setMsg(t) { ... }` の **下** に追加します。

```js:game.js
  // ---- 描画 ----
  let size = 300, cell = 50, dpr = 1;
  function resize() {
    const r = stage.getBoundingClientRect();
    size = Math.max(200, Math.floor(Math.min(r.width - 12, r.height - 4)));
    dpr = Math.min(window.devicePixelRatio || 1, 2);
    cv.width = size * dpr; cv.height = size * dpr;
    cv.style.width = size + 'px'; cv.style.height = size + 'px';
    cell = size / 6;
  }
  function tileCenter(i) { const [c, r] = POS[i]; return [(c + 0.5) * cell, (r + 0.5) * cell]; }

  function roundRect(x, y, w, h, rad) {
    ctx.beginPath(); ctx.moveTo(x + rad, y); ctx.arcTo(x + w, y, x + w, y + h, rad);
    ctx.arcTo(x + w, y + h, x, y + h, rad); ctx.arcTo(x, y + h, x, y, rad); ctx.arcTo(x, y, x + w, y, rad); ctx.closePath();
  }
```

- `stage.getBoundingClientRect()` でステージの今の幅と高さを調べ、**小さいほう** を盤の一辺 `size` にします。盤は正方形なので、縦長のスマホでも横長の PC でもはみ出しません
- Canvas には「見た目の大きさ」（`cv.style.width`）と「中の画素数」（`cv.width`）の2つがあります。`devicePixelRatio`（スマホなら 2〜3）をかけた画素数にしておくと、高解像度の画面でもくっきり描けます。重くなりすぎないよう最大 2 倍にしています
- `cell = size / 6` が1マスの大きさです。以降の描画はすべて `cell` を単位にするので、画面サイズが変わっても形が崩れません
- `tileCenter(i)` は i 番目のマスの **中心の座標** を返します。列・行に 0.5 を足すと、マスの左上ではなく中心になります
- `roundRect()` は角の丸い四角形の「形」を作る関数です。`arcTo` で4つの角を丸めながら1周します。塗る（`fill`）か線を引く（`stroke`）かは呼んだ側で決めます

## マスの見た目：tileLabel()

`roundRect()` の **下** に追加します。

```js:game.js
  function tileLabel(tile) {
    switch (tile.t) {
      case 'go': return ['GO', '#ffcc33', '#3a2a00'];
      case 'chance': return ['?', '#ffffff', '#d23c6c'];
      case 'tax': return ['税', '#5a5f73', '#fff'];
      case 'dice': return ['🎲', '#ffe8b0', '#000'];
      case 'bonus': return ['💰', '#fff3b0', '#000'];
      case 'thief': return ['🦝', '#3b3f52', '#fff'];
      default: return [String(tile.v), '#fffaf0', '#2b4a3a'];
    }
  }
```

マスの種類ごとに `[文字, 背景色, 文字色]` を返します。**switch 文** は「この値が 〇〇 なら…」をたくさん並べるときに便利な書き方です。`return` するとそこで関数が終わるので、`break` は要りません。どれにも当てはまらない数字のマスは `default` で、もらえるコインの数を文字にします。

## 盤を描く：draw() とループ

`tileLabel()` の **下** に追加します。

```js:game.js
  function draw() {
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
    ctx.clearRect(0, 0, size, size);
    // 中央の芝生
    roundRect(cell, cell, cell * 4, cell * 4, 10); ctx.fillStyle = '#4fae6e'; ctx.fill();
    ctx.fillStyle = 'rgba(255,255,255,.07)';
    for (let i = 0; i < 8; i++) ctx.fillRect(cell + i * cell / 2, cell, cell / 4, cell * 4);

    ctx.textAlign = 'center'; ctx.textBaseline = 'middle';
    // マス
    TILES.forEach((tile, i) => {
      const [c, r] = POS[i];
      const x = c * cell + 2, y = r * cell + 2, w = cell - 4;
      const [label, bg, fg] = tileLabel(tile);
      roundRect(x, y, w, w, 8); ctx.fillStyle = bg; ctx.fill();
      if (tile.t === 'prop') {
        ctx.save(); roundRect(x, y, w, w, 8); ctx.clip();
        ctx.fillStyle = tile.color; ctx.fillRect(x, y, w, w * 0.28); ctx.restore();
        ctx.fillStyle = fg; ctx.font = `bold ${cell * 0.26}px sans-serif`;
        ctx.fillText(label, x + w / 2, y + w * 0.62);
        ctx.font = `${cell * 0.16}px sans-serif`; ctx.fillText('🪙', x + w / 2, y + w * 0.86);
      } else {
        ctx.fillStyle = fg; ctx.font = `bold ${cell * (label.length > 1 && tile.t === 'go' ? 0.34 : 0.4)}px sans-serif`;
        ctx.fillText(label, x + w / 2, y + w / 2 + 1);
      }
    });
  }

  function loop() {
    draw();
    requestAnimationFrame(loop);
  }
```

### draw() の流れ

- `ctx.setTransform(dpr, 0, 0, dpr, 0, 0)` は「これから描くものを全部 dpr 倍する」設定です。これで、中の画素数が2倍でも、座標は見た目どおりの `size` で考えられます
- `clearRect` で前の絵を消してから、毎回 **全部描き直します**。Canvas は描いた絵を覚えていないので、動くゲームでは「消す → 描く」を毎フレームくり返すのが基本です
- まん中の 4×4 マスぶん（`cell` から `cell * 4` の大きさ）に芝生を塗り、うすい白の縦じまを8本重ねます
- `textAlign = 'center'` と `textBaseline = 'middle'` で、`fillText` に渡した座標が **文字のまん中** になります
- 各マスは、マス目より少し小さい（四方に 2px のすき間）角丸の四角です
- 数字のマスは上の 28% に色の帯をつけます。`ctx.save()` → `clip()`（角丸の形で切り抜き）→ 帯を塗る → `ctx.restore()` とすると、帯の角もマスの丸みに合わせて切れます。`save` / `restore` で切り抜きを元に戻すのを忘れないようにしましょう

### requestAnimationFrame

`requestAnimationFrame(loop)` は「次に画面を描きかえるタイミングで `loop` を呼んで」とブラウザに頼む関数です。`loop` の中でまた自分を頼むので、1秒に約60回 `draw()` がくり返されます。今は止まった絵ですが、次のステップからコマが動きだします。

## 起動する

ファイルのいちばん下、`window.addEventListener('keydown', ...)` の **下**（`})();` の上）に追加します。

```js:game.js
  window.addEventListener('resize', resize);
  resize();
  requestAnimationFrame(loop);
```

最初に一度 `resize()` で大きさを合わせてから、ループを始めます。ウィンドウの大きさが変わったとき（スマホを横にしたときなど）も `resize()` を呼びなおします。
