## このステップのゴール

5列 × 7段の盤面と、数字ブロックを描きます。数字ごとに色が変わる、ぷっくりした角丸のブロックです。このステップではまだ操作できないので、お試しとして盤面にいくつかブロックを並べて、見た目を確認します。

## 盤面の大きさを決める

`const W = 360, H = 560;` の行の **下** に追加します。

```js:game.js
  const COLS = 5, ROWS = 7, CELL = 64;
  const GX = (W - COLS * CELL) / 2, GY = 92;
```

- `COLS` は列の数、`ROWS` は段の数、`CELL` は1マスの大きさ（ピクセル）です。
- `GX`, `GY` は盤面の左上の位置です。盤面の幅は `COLS * CELL = 320` なので、`(W - 320) / 2 = 20` で左右がちょうどまん中になります。上には次のブロックを浮かべる場所をあけるため、`GY = 92` にしています。

## grid と blocks … 盤面のデータ

`let state = 'title';` の行の **上** に追加します。

```js:game.js
  let grid, blocks;
```

このゲームでは、盤面を2つの形で持ちます。

- `grid` … **2次元配列**。`grid[列][段]` で、そのマスにあるブロック（なければ `null`）を取り出せます。段は **下から** 0, 1, 2… と数えます。ブロックは下から積み上がるので、こうしておくと「この列の高さ」が数えやすくなります。
- `blocks` … 画面に出ているブロックを全部ならべた、ふつうの配列。描くときはこちらを順番に描きます。

同じブロックを2か所から指すのは、`grid` が「どこに何があるか（ルール）」、`blocks` が「何を描くか（見た目）」と役わりが分かれているからです。ステップ5で、合体して消えていくブロックを「grid からはもう消えたけど、まだ見えている」状態にするときに、この分け方が役に立ちます。

## helpers … 便利な小さな関数

`let state = 'title';` の行の **下** に追加します。

```js:game.js
  // ---------- helpers ----------
  const cellX = (c) => GX + c * CELL;
  const cellY = (r) => GY + (ROWS - 1 - r) * CELL;
  const exp2 = (v) => Math.round(Math.log2(v));
  function color(v) {
    const e = exp2(v);
    const hue = (200 + e * 41) % 360;
    const light = e > 10 ? 48 : 56;
    return { fill: `hsl(${hue},72%,${light}%)`, dark: `hsl(${hue},70%,${light - 18}%)` };
  }
  function label(v) {
    if (v < 10000) return String(v);
    if (v < 1e6) return Math.floor(v / 1000) + 'K';
    return Math.floor(v / 1e6) + 'M';
  }
```

### cellX() / cellY() … マス目から画面の座標へ

`cellX(c)` は c 列目のマスの **左端** の x 座標、`cellY(r)` は r 段目のマスの **上端** の y 座標です。段は下から数えるので、`ROWS - 1 - r` で上下をひっくり返してから `CELL` 倍しています（r = 0 がいちばん下の段）。

### exp2() … 2の何乗か

このゲームの数字はすべて 2, 4, 8, 16 … と **2のべき乗** です。`Math.log2(v)` で「2の何乗か」が分かります（`Math.log2(8)` は 3）。小数の誤差が出ないよう `Math.round` で整数にしています。

### color() … 数字ごとの色

色は **HSL**（色相 Hue・彩度 Saturation・明るさ Lightness）で作っています。色相は 0〜360 の角度で、0 が赤、120 が緑、240 が青です。数字が2倍になるたびに色相を 41 度ずつずらすので、となりの数字どうしははっきりちがう色になります。

- `fill` … ブロックの表の色
- `dark` … 同じ色相で暗くした色。ブロックの下の「厚み」に使います

### label() … 大きな数字を短く

ブロックに入る文字は4けたくらいまでです。10000 以上は `16K`、100万以上は `1M` のように短くします。

## ブロックを作る関数と reset()

`// ---------- game ----------` の行の **下**（`function start()` の上）に追加します。

```js:game.js
  function makeBlock(v, c, r) {
    const b = { v, c, r, x: cellX(c), y: cellY(r) };
    blocks.push(b);
    return b;
  }
  function reset() {
    grid = Array.from({ length: COLS }, () => Array(ROWS).fill(null));
    blocks = [];
    // お試し: いろいろな数字のブロックを並べてみる（ステップ3で消します）
    for (let c = 0; c < COLS; c++) grid[c][0] = makeBlock(2 ** (c + 1), c, 0);
    grid[1][1] = makeBlock(64, 1, 1);
    grid[2][1] = makeBlock(1024, 2, 1);
    grid[2][2] = makeBlock(16384, 2, 2);
  }
```

- `makeBlock(v, c, r)` は、数字 `v` を持ったブロックを c 列 r 段に作って `blocks` に入れます。`x, y` は描く位置です。ステップ4ではこの `x, y` を少しずつ動かして、落ちてくるように見せます。
- `reset()` は、ゲームを始めるたびに盤面を空っぽにする関数です。`Array.from({ length: COLS }, () => Array(ROWS).fill(null))` で「長さ7の `null` の配列」を5つ作ります。`Array(COLS).fill(Array(ROWS))` と書くと **5列が同じ1つの配列を共有してしまう** ので、`Array.from` で列ごとに新しく作るのがポイントです。
- 「お試し」の部分は見た目を確認するためだけのものです。ステップ3で消します。

## 角の丸い四角とブロックを描く

`function draw()` を、次のように **書きかえ** ます。`draw()` の **上** に `roundRect()` と `drawBlock()` も追加します。

```js:game.js
  function roundRect(x, y, w, h, r) {
    ctx.beginPath();
    ctx.moveTo(x + r, y);
    ctx.arcTo(x + w, y, x + w, y + h, r);
    ctx.arcTo(x + w, y + h, x, y + h, r);
    ctx.arcTo(x, y + h, x, y, r);
    ctx.arcTo(x, y, x + w, y, r);
    ctx.closePath();
  }
  function drawBlock(v, x, y, scale = 1, alpha = 1) {
    const s = (CELL - 6) * scale;
    const cx = x + CELL / 2, cy = y + CELL / 2;
    const col = color(v);
    ctx.globalAlpha = Math.max(0, alpha);
    roundRect(cx - s / 2, cy - s / 2 + 3, s, s, 12 * scale);
    ctx.fillStyle = col.dark; ctx.fill();
    roundRect(cx - s / 2, cy - s / 2, s, s - 2, 12 * scale);
    ctx.fillStyle = col.fill; ctx.fill();
    ctx.fillStyle = 'rgba(255,255,255,.18)';
    roundRect(cx - s / 2 + 5, cy - s / 2 + 4, s - 10, s * 0.28, 8 * scale); ctx.fill();
    const t = label(v);
    const fs = (t.length <= 2 ? 28 : t.length === 3 ? 24 : 19) * scale;
    ctx.font = `800 ${fs}px system-ui, sans-serif`;
    ctx.textAlign = 'center'; ctx.textBaseline = 'middle';
    ctx.fillStyle = 'rgba(0,0,0,.25)';
    ctx.fillText(t, cx, cy + 2);
    ctx.fillStyle = '#fff';
    ctx.fillText(t, cx, cy);
    ctx.globalAlpha = 1;
  }

  function draw() {
    ctx.clearRect(0, 0, W, H);
    // board
    roundRect(GX - 6, GY - 6, COLS * CELL + 12, ROWS * CELL + 12, 14);
    ctx.fillStyle = 'rgba(0,0,0,.28)'; ctx.fill();
    for (let c = 0; c < COLS; c++) {
      for (let r = 0; r < ROWS; r++) {
        roundRect(cellX(c) + 4, cellY(r) + 4, CELL - 8, CELL - 8, 10);
        ctx.fillStyle = 'rgba(255,255,255,.035)'; ctx.fill();
      }
    }
    // danger line
    ctx.strokeStyle = 'rgba(255,120,120,.35)';
    ctx.setLineDash([6, 6]); ctx.lineWidth = 2;
    ctx.beginPath(); ctx.moveTo(GX, GY - 3); ctx.lineTo(GX + COLS * CELL, GY - 3); ctx.stroke();
    ctx.setLineDash([]);
    // blocks
    for (const b of blocks) drawBlock(b.v, b.x, b.y);
  }
```

### roundRect() … 角丸の四角の「形」を作る

`arcTo(x1, y1, x2, y2, r)` は、今いる点から `(x1, y1)` に向かう線と、`(x1, y1)` から `(x2, y2)` に向かう線を、半径 `r` の円弧でなめらかにつなぐ命令です。これを4つの角でくり返すと、角の丸い四角の **形（パス）** ができます。

`roundRect()` は形を作るだけで、色はぬりません。呼んだあとに `ctx.fillStyle = …; ctx.fill();` でぬります。

### drawBlock() … ぷっくりしたブロック

1つのブロックを、3回に分けて重ねぬりしています。

1. 少し下にずらした **暗い色** の四角（ブロックの厚み）
2. その上に **表の色** の四角
3. 上のほうに **半とうめいの白** の細い四角（光の反射）

文字は、`label()` の長さで大きさを変えます（2けたまでは 28px、3けたは 24px、4けたは 19px）。少し下にずらした **うすい黒** の文字を先に描いてから白い文字を重ねると、影がついて読みやすくなります。

`scale`（大きさの倍率）と `alpha`（不透明度）は、ステップ5で「ポンとふくらむ」「すうっと消える」演出に使います。`scale = 1` のように書くと、引数を省略したときの値（デフォルト引数）になります。

`ctx.globalAlpha` は、これから描くもの全部の不透明度です。最後に `1` に戻しておかないと、ほかの絵までうすくなってしまうので注意しましょう。

### draw() … 盤面を描く

- 盤面全体を、少し大きめの **うすい黒の角丸** でかこみます。
- 二重の `for` で全マスに、ほとんど見えないくらいうすい白の角丸を描いて、マス目を見せます。
- 盤面の上のふちに **赤い点線** を引きます。`setLineDash([6, 6])` で「6px 描いて 6px あける」点線になります。使ったら `setLineDash([])` で実線に戻します。ここより上に積めない、という目安の線です。
- 最後に `blocks` を全部描きます。

## reset() を呼ぶ

ファイルのいちばん下、`requestAnimationFrame(frame);` の **上** に追加します。

```js:game.js
  reset();
```

`grid` と `blocks` は `reset()` で作られるので、ゲームループを始める前に一度呼んでおきます。

> [!CHECK] 動作チェック
> - 5列 × 7段のうすいマス目と、上のふちの赤い点線が見える
> - いちばん下の段に 2, 4, 8, 16, 32 のブロックが並び、それぞれちがう色になっている
> - 64 と 1024 と、`16K` と書かれたブロックが積まれている。数字の長さに合わせて文字の大きさが変わっている
> - スタートを押しても、まだ何も操作できなくてOK
