## このステップのゴール

3つのファイルを用意して、画面の土台を作ります。上に「NEXT・MAX・SCORE・BEST」の表示、まん中にゲームを描く **Canvas**（キャンバス）、その上に重ねるタイトル画面（オーバーレイ）を置きます。

完成すると、こんなゲームになります。

- 5列 × 7段の盤面の上に、次に落とす数字ブロックが浮かんでいる
- 列をタップ（または ←→ で選んで Space）すると、その列にブロックが落ちる
- 同じ数字が上下左右でとなり合うと合体して2倍に。3つ以上まとめてくっつくと一気に4倍・8倍になる
- 合体したあとブロックが落ちて、また合体すると **連鎖**。どの列にも置けなくなったらゲームオーバー

ブロックがなめらかに落ちたり、ふくらんだりするゲームなので、**Canvas** に絵を描く方式で作ります。Canvas は「ピクセルの画用紙」で、JavaScript から四角や文字を描きこみます。毎フレーム全体を消して描き直すことで、動きを表現します。

まずは HTML です。このステップで画面の部品はすべてそろえてしまい、以降は `game.js` だけを育てていきます。

```html:index.html
    <div id="toast"></div>

```

- `<canvas id="cv" width="360" height="560">` が、ゲームを描く画用紙です。ゲームの中ではずっとこの **360×560 の座標** で考えます。画面上の表示サイズは CSS で別に決めます。
- 上の `#next`（次のブロック）、`#maxv`（いちばん大きな数字）、`#score`、`#best` は、ステップ6・8で JavaScript から書きかえます。`#next` には `chip` クラスをつけて、数字の色の小さなチップとして表示します。
- `#toast` は「3 れんさ！」などを一瞬だけ表示するメッセージ、`#overlay` はタイトル画面とゲームオーバー画面をかねるパネルです。
- `<script>` は `</body>` の直前に置きます。HTML の要素が全部できたあとで JavaScript が動くので、`getElementById` で確実に要素を取れます。

## game.js

最後に JavaScript です。まずは「Canvas を用意して、毎フレーム描き直す」いちばん小さな形を作ります。

```js:game.js
(() => {
  'use strict';
  const $ = (id) => document.getElementById(id);
  const cv = $('cv');
  const ctx = cv.getContext('2d');
  const W = 360, H = 560;

  let state = 'title'; // title | ready | busy | over

  // ---------- game ----------
  function start() {
    $('overlay').classList.add('hide');
    state = 'ready';
  }

  // ---------- loop ----------
  let last = performance.now();
  function frame(now) {
    const dt = Math.min(0.05, (now - last) / 1000);
    last = now;
    draw();
    requestAnimationFrame(frame);
  }

  function draw() {
    ctx.clearRect(0, 0, W, H);
    ctx.fillStyle = 'rgba(255,255,255,.55)';
    ctx.font = '14px system-ui, sans-serif';
    ctx.textAlign = 'center';
    ctx.fillText('ここに盤面を描いていくよ', W / 2, H / 2);
  }

  // ---------- input ----------
  $('start').addEventListener('click', (e) => { e.stopPropagation(); start(); });

  requestAnimationFrame(frame);
})();
```

### 全体を `(() => { ... })();` で包む

ファイル全体をアロー関数で包んで、その場で呼び出しています（即時実行関数）。こうすると中で作った変数がページ全体に漏れず、ほかのスクリプトと名前がぶつかりません。`'use strict';` は、うっかりミス（宣言していない変数への代入など）をエラーとして教えてくれるモードです。

### 要素の取得

- `$` は `document.getElementById` を短く書くための小さな関数です。`$('cv')` のように使います。
- `cv.getContext('2d')` で、Canvas に絵を描くための道具（コンテキスト）を取り出します。以降の描画はすべて `ctx.〇〇()` で行います。
- `W` と `H` は Canvas の幅と高さです。数字を直接書かずに名前をつけておくと、あとで読みやすくなります。

### state … いまどの場面か

`state` は、ゲームがいまどの場面にいるかを表す文字列です。

- `'title'` … タイトル画面
- `'ready'` … プレイ中で、ブロックを落とせる状態
- `'busy'` … ブロックが落ちたり合体したりしている最中で、次を落とせない状態（ステップ4）
- `'over'` … ゲームオーバー（ステップ7）

「場面ごとにできることを変える」のは、ゲームづくりでよく使う考え方です（**状態遷移**）。

### frame() と dt … ゲームループ

`requestAnimationFrame(frame)` は「次に画面を描きかえるタイミングで `frame` を呼んで」とブラウザに頼む命令です。`frame` の最後でまた自分を予約するので、1秒に約60回 `draw()` がくり返されます。これが **ゲームループ** です。

`frame` には、そのときの時刻（ミリ秒）が `now` として渡されます。前回との差を秒に直したものが `dt`（デルタタイム）です。ステップ4で「1秒に何ピクセル動くか × `dt`」でブロックを動かすときに使います。こうすると、60fps の画面でも120fps の画面でも同じ速さになります。タブを切りかえて戻ったときに `dt` が大きくなりすぎてワープしないよう、`Math.min(0.05, …)` で上限をつけています。

`draw()` では、まず `clearRect` で画面全体を消してから描きます。いまは目印の文字だけです。

### スタートボタン

ボタンが押されたら `start()` でオーバーレイを隠し、`state` を `'ready'` にします。`e.stopPropagation()` は、このクリックが後ろの画面（ステップ3でタップ＝ブロックを落とす、にします）まで伝わらないようにする命令です。

> - 「タップでスタート」を押すとタイトル画面が消え、紺色のゲーム画面のまん中に「ここに盤面を描いていくよ」と出る
> - 画面の幅を変えても、ゲーム画面が縦長のまま収まる
> - 上の NEXT・MAX・SCORE・BEST はまだ動かなくてOK（ステップ6・8で作ります）
