## このステップのゴール

最後の仕上げです。**ハイスコア（BEST）** をブラウザに保存して、ページを閉じても残るようにします。さらに、置く・合体する・置けない・ゲームオーバーで **効果音** が鳴るようにして、完成品と同じ「かさねてポン」にします。

## ハイスコアを保存する

`const PREVIEW_Y = 22;` の行の **下** に追加します。

```js:game.js
  const BEST_KEY = 'dmg-number-drop-best';
```

`let grid, blocks, …` の行を、次のように **書きかえ** ます。

```js:game.js
  let grid, blocks, score, best = 0, maxV, cur, next, selCol = 2;
```

`let waiters = [];` の行の **下** に追加します。

```js:game.js
  let audio = null;

  try { best = parseInt(localStorage.getItem(BEST_KEY), 10) || 0; } catch (e) { best = 0; }
  $('best').textContent = best;
```

`updateHud()` の最後（閉じかっこ `}` の直前）に追加します。

```js:game.js
    if (score > best) {
      best = score;
      $('best').textContent = best;
      try { localStorage.setItem(BEST_KEY, String(best)); } catch (e) { /* ignore */ }
    }
```

### localStorage

**localStorage** は、ブラウザがサイトごとに用意してくれる小さな保存場所です。`setItem(名前, 文字列)` で保存し、`getItem(名前)` で取り出します。ページを再読み込みしても、ブラウザを閉じても残ります。

- 保存できるのは文字列だけなので、`String(best)` で文字にして保存し、取り出すときは `parseInt(…, 10)` で数字に戻します。まだ何も保存していないときは `getItem` が `null` を返し、`parseInt` が `NaN` になるので、`|| 0` で 0 にしています。
- 名前（`BEST_KEY`）には、ほかのゲームとぶつからないよう、ゲームごとにちがう名前をつけます。
- ブラウザの設定によっては localStorage が使えず、エラーになることがあります。`try { … } catch (e) { … }` でかこんでおくと、エラーになってもゲームは止まりません。

スコアが変わるたびに `updateHud()` が呼ばれるので、そこで BEST をこえたかを調べて、こえていたらすぐに保存します。

ゲームオーバー画面にも BEST を出しましょう。`gameOver()` の中の `$('ov-text').innerHTML = …` の行を、次のように **書きかえ** ます。

```js:game.js
    $('ov-text').innerHTML = `スコア <b>${score}</b><br>いちばん大きな数字 <b>${label(maxV)}</b><br>ベスト ${best}`;
```

## 効果音を作る beep()

`settled()` の行の **下**（`// ---------- UI ----------` の上）に追加します。

```js:game.js
  // ---------- sound ----------
  function beep(freq, dur = 0.12, type = 'triangle', vol = 0.12) {
    try {
      if (!audio) audio = new (window.AudioContext || window.webkitAudioContext)();
      if (audio.state === 'suspended') audio.resume();
      const t = audio.currentTime;
      const o = audio.createOscillator(), g = audio.createGain();
      o.type = type; o.frequency.setValueAtTime(freq, t);
      o.frequency.exponentialRampToValueAtTime(freq * 1.5, t + dur);
      g.gain.setValueAtTime(vol, t);
      g.gain.exponentialRampToValueAtTime(0.001, t + dur);
      o.connect(g).connect(audio.destination);
      o.start(t); o.stop(t + dur + 0.02);
    } catch (e) { /* ignore */ }
  }
```

### Web Audio API

音のファイルを用意しなくても、**Web Audio API** を使えばブラウザの中で音を作れます。

- `AudioContext` … 音を作るための作業台。最初に音を鳴らすときに1つだけ作ります。ブラウザは「ユーザーが操作するまで音を出さない」決まりがあるので、タップやキー入力のあとに作る（または `resume()` で起こす）のがポイントです。
- `createOscillator()` … 「ピー」という一定の音（波）を出す部品。`type` で音色（`'sine'` やわらか・`'triangle'` まるい・`'square'` ピコピコ・`'sawtooth'` ギザギザ）、`frequency` で高さ（Hz）を決めます。
- `createGain()` … 音量をつまみで調整する部品。

`o.connect(g).connect(audio.destination)` で「発振器 → 音量 → スピーカー」とつなぎ、`start` / `stop` で鳴らす時間を決めます。`exponentialRampToValueAtTime` で、鳴っている間に **音の高さを 1.5 倍に上げながら、音量を 0 近くまで下げる** と、「ピュッ」と短くはずむ音になります。

## 効果音を鳴らす

それぞれの場所に1行ずつ足していきます。

`start()` の `state = 'ready';` の **下**（スタート）:

```js:game.js
    beep(520, 0.1);
```

`gameOver()` の `state = 'over';` の **下**（ブーッという低い音）:

```js:game.js
    beep(180, 0.5, 'sawtooth', 0.1);
```

`drop()` の中は、3か所です。満杯の列で置けないときの行を、次のように **書きかえ** ます。

```js:game.js
      if (top.v !== cur) { shake = 0.3; beep(140, 0.12, 'square', 0.06); return; }
```

満杯の列のいちばん上と合体したとき、`top.v *= 2; …` の行の **下**:

```js:game.js
      beep(300 + exp2(top.v) * 40, 0.14);
```

ブロックが落ちて止まったとき、`else` の中の `await settled();` の **下**（コトッという小さな音）:

```js:game.js
      beep(240, 0.05, 'sine', 0.08);
```

`resolve()` の中、`flash = 0.15;` の行の **下**（合体）:

```js:game.js
      beep(300 + exp2(b.v) * 40 + combo * 30, 0.16);
```

合体の音は、できた数字が大きいほど（`exp2(b.v)`）、連鎖が続くほど（`combo`）高くなります。連鎖するたびに音が上がっていくと、気持ちよさがぐっと増します。

> [!CHECK] 動作チェック
> - スタート・ブロックが止まる・合体・置けない・ゲームオーバーで、それぞれちがう音が鳴る。連鎖すると合体の音がだんだん高くなる
> - スコアが BEST をこえると、上の BEST もいっしょに増える。ゲームオーバー画面に「ベスト」が出る
> - ページを再読み込みしても、BEST の数字が残っている
> - 完成品の「かさねてポン」と同じように遊べる

## 改造アイデア

> [!TIP]
> **列の数・段の数を変える**: `COLS` を 6 に、`ROWS` を 8 にするだけで、盤面が広くなってやさしくなります。`GX` と Canvas の大きさも合わせて調整してみましょう。数字キーの `'5'` も `String(COLS)` にしておくと便利です。

> [!TIP]
> **ハンマーアイテム**: 1回だけ好きなブロックを1つこわせる「ハンマー」ボタンを付けてみましょう。こわしたら `grid` から消して `gravity()` → `resolve()` を呼べば、落ちたブロックの連鎖もそのまま起きます。

> [!TIP]
> **次の数字を2つ先まで見せる**: `next` を配列にして、NEXT の表示を2つにすると、もっと作戦を立てやすくなります。

> [!TIP]
> **目標モード**: 「2048 を作ったらクリア」「30手で何点取れるか」のようなルールを足すと、ちがう遊び方ができます。手数は `drop()` が1回終わるたびに数えましょう。
