## このステップのゴール

ゲームらしくするために、**スコア** を付けます。上の表示に「次の次に来るブロック（NEXT）」と「いちばん大きな数字（MAX）」も出します。連鎖したときは「3 れんさ！」、64 以上の新記録を作ったときは「128 たっせい！」と大きく表示し、合体の瞬間に画面がピカッと光るようにします。

## 変数を足す

`let grid, blocks, maxV, cur, selCol = 2;` の行を、次のように **書きかえ** ます。その **下**（`let state` の下）に `flash` も足します。

```js:game.js
  let grid, blocks, score, maxV, cur, next, selCol = 2;
  let state = 'title'; // title | ready | busy | over
  let flash = 0;
```

- `score` … スコア
- `next` … 次の次に落とすブロックの数字（`cur` の次）。先が見えると「どこに置こうか」と作戦を立てられます
- `flash` … 画面を白く光らせる残り時間（秒）

## 表示を書きかえる関数

`settled()` の行の **下**（`// ---------- game ----------` の上）に追加します。

```js:game.js
  // ---------- UI ----------
  let toastTimer = 0;
  function toast(text) {
    const el = $('toast');
    el.textContent = text;
    el.classList.add('show');
    clearTimeout(toastTimer);
    toastTimer = setTimeout(() => el.classList.remove('show'), 900);
  }
  function updateHud() {
    $('score').textContent = score;
    $('maxv').textContent = label(maxV);
    const n = $('next');
    n.textContent = label(next);
    n.style.background = color(next).fill;
  }
```

### toast() … 一瞬だけ出るメッセージ

`#toast` に文字を入れて `.show` クラスをつけると、CSS の `transition` でふわっと出てきます。0.9 秒後に `.show` を外すと、ふわっと消えます。

続けて呼ばれたときのために、前のタイマーを `clearTimeout` で取り消してから新しく予約しています。こうしないと、前のタイマーが新しいメッセージを早く消してしまいます。

### updateHud() … 上の表示を更新

HUD（ヘッドアップディスプレイ）は、ゲーム画面の上に重ねて出す情報のことです。スコア、MAX、NEXT を書きかえます。NEXT のチップの背景は、ブロックと同じ `color(next).fill` にして、ひと目で何が来るか分かるようにします。

## reset() と drop() を書きかえる

`reset()` を、次のように **書きかえ** ます。

```js:game.js
  function reset() {
    grid = Array.from({ length: COLS }, () => Array(ROWS).fill(null));
    blocks = [];
    score = 0; maxV = 2;
    cur = randValue(); next = randValue();
    updateHud();
  }
```

`drop()` の中の `cur = randValue();` の行を、次の3行に **書きかえ** ます。

```js:game.js
    maxV = Math.max(maxV, ...blocks.map((x) => x.v));
    cur = next; next = randValue();
    updateHud();
```

- 合体が全部終わったあとで、盤面でいちばん大きな数字を `maxV` にします。`...blocks.map((x) => x.v)` は、全ブロックの数字の配列を `Math.max(…)` の引数としてばらばらに渡す書き方（スプレッド構文）です。`maxV` が大きくなると、`randValue()` で落ちてくる数字の上限も上がります。
- `cur = next; next = randValue();` で、NEXT に見えていた数字が手持ちになり、新しい NEXT を決めます。

## resolve() にスコアと演出を足す

`resolve()` 全体を、次のように **書きかえ** ます。

```js:game.js
  async function resolve(active) {
    let combo = 0;
    const prevMax = maxV;
    while (active.length) {
      const b = active.pop();
      if (b.dying) continue;
      const nb = [];
      for (const [dc, dr] of [[-1, 0], [1, 0], [0, -1], [0, 1]]) {
        const c = b.c + dc, r = b.r + dr;
        if (c < 0 || c >= COLS || r < 0 || r >= ROWS) continue;
        const o = grid[c][r];
        if (o && o.v === b.v) nb.push(o);
      }
      if (!nb.length) continue;
      combo++;
      for (const o of nb) {
        grid[o.c][o.r] = null;
        o.dying = true; o.tx = b.tx; o.ty = b.ty;
      }
      b.v *= 2 ** nb.length;
      b.pop = 1;
      score += b.v * combo;
      flash = 0.15;
      updateHud();
      await sleep(160);
      const moved = gravity();
      await settled();
      active.push(...moved, b);
    }
    if (combo >= 2) toast(`${combo} れんさ！`);
    const m = Math.max(...blocks.map((x) => x.v));
    if (m > prevMax && m >= 64) setTimeout(() => toast(`${label(m)} たっせい！`), combo >= 2 ? 600 : 0);
  }
```

- `combo` は、1回の `drop()` の中で何回合体したかです。1回目の合体は ×1、2回目（連鎖）は ×2、3回目は ×3 … と、**合体してできた数字 × 連鎖の数** を足します。連鎖させるほど一気にスコアがのびるので、ねらう楽しさが生まれます。
- 合体するたびに `flash = 0.15` にして、画面を一瞬光らせます。
- 最後に、2回以上合体していたら「〇 れんさ！」を出します。
- `prevMax` は、合体を始める前の `maxV` です。盤面のいちばん大きな数字がそれをこえて、しかも 64 以上なら「〇〇 たっせい！」を出します。連鎖のメッセージと重ならないよう、連鎖したときは 0.6 秒おくらせています。

## 画面を光らせる

`frame()` の中、`if (!moving && waiters.length) …` の行の **下** に追加します。

```js:game.js
    if (flash > 0) flash = Math.max(0, flash - dt);
```

`draw()` の最後（閉じかっこ `}` の直前）に追加します。

```js:game.js
    if (flash > 0) { ctx.fillStyle = `rgba(255,255,255,${flash * 0.6})`; ctx.fillRect(0, 0, W, H); }
```

画面全体に半とうめいの白い四角を重ねます。`flash` が 0.15 → 0 に減っていくので、不透明度は 0.09 → 0 と、ほんの一瞬だけピカッと光ります。

> [!CHECK] 動作チェック
> - スタートすると、上の NEXT に次の次の数字が、その数字の色のチップで出る。ブロックを落とすたびに、NEXT に見えていた数字が浮かんでくる
> - 合体すると SCORE が増え、画面が一瞬白く光る
> - 連鎖すると「2 れんさ！」などが出て、スコアが大きく増える
> - MAX に盤面でいちばん大きな数字が出る。64 以上の新しい数字を作ると「64 たっせい！」と出る
> - 大きな数字ができると、落ちてくる数字にも 16 や 32 がまざるようになる
