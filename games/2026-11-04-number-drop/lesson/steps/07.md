## このステップのゴール

ゲームの終わりを作ります。満杯の列にも、**いちばん上と同じ数字なら** 落として合体できるようにし、ちがう数字なら画面をぷるっとゆらして「置けないよ」と知らせます。そして、どの列にも置けなくなったら **ゲームオーバー**。「もう一度」で何度でも遊べるようにします。

## 画面ゆれの変数

`let flash = 0;` の行を、次のように **書きかえ** ます。

```js:game.js
  let shake = 0, flash = 0;
```

`shake` は、画面をゆらす残り時間（秒）です。

## 満杯の列のルール

`drop()` 全体を、次のように **書きかえ** ます。

```js:game.js
  async function drop(c) {
    if (state !== 'ready') return;
    const h = height(c);
    let b;
    if (h >= ROWS) {
      const top = grid[c][ROWS - 1];
      if (top.v !== cur) { shake = 0.3; return; }
      state = 'busy';
      top.v *= 2; top.pop = 1; score += top.v;
      b = top;
    } else {
      state = 'busy';
      b = makeBlock(cur, c, h, PREVIEW_Y);
      grid[c][h] = b;
      await settled();
    }
    await resolve([b]);
    maxV = Math.max(maxV, ...blocks.map((x) => x.v));
    cur = next; next = randValue();
    updateHud();
    if (!canPlace(cur)) { gameOver(); return; }
    state = 'ready';
  }
```

満杯の列（`h >= ROWS`）を選んだときの動きが増えました。

- いちばん上のブロック `grid[c][ROWS - 1]` の数字が手持ちと **ちがう** なら、`shake = 0.3` で画面をゆらして終わります。`state` は `'ready'` のままなので、すぐに別の列を選べます。
- **同じ** なら、新しいブロックは作らずに、いちばん上のブロックをその場で2倍にします（落としたブロックが吸いこまれたあつかい）。そのまま `resolve()` に渡すので、2倍になった数字がとなりと合体する連鎖も起きます。

どちらの場合も、最後に合体を調べるブロックを `b` に入れておき、共通の `await resolve([b]);` に進みます。

そして、次の手持ち `cur` が決まったあとで `canPlace(cur)` を調べ、置ける列が1つもなければ `gameOver()` を呼んで終わります。

## canPlace() と gameOver()

`start()` の **下**（`drop()` の上）に追加します。

```js:game.js
  function canPlace(v) {
    for (let c = 0; c < COLS; c++) {
      const h = height(c);
      if (h < ROWS || grid[c][ROWS - 1].v === v) return true;
    }
    return false;
  }
  function gameOver() {
    state = 'over';
    $('ov-title').textContent = 'ゲームオーバー';
    $('ov-text').innerHTML = `スコア <b>${score}</b><br>いちばん大きな数字 <b>${label(maxV)}</b>`;
    $('start').textContent = 'もう一度';
    setTimeout(() => $('overlay').classList.remove('hide'), 500);
  }
```

### canPlace() … まだ置ける？

5つの列のうち、1つでも「まだすき間がある」か「いちばん上が `v` と同じ」なら置けます。全部ダメなら `false` です。

満杯の列でも同じ数字なら置けるので、**ギリギリまであきらめなくていい** のがこのゲームのおもしろいところです。

### gameOver() … 終わりの画面

- `state = 'over'` にして、操作を受けつけないようにします。`draw()` の選んでいる列の帯も消えます。
- タイトル画面と同じオーバーレイを使い回して、見出しと本文を「ゲームオーバー」と結果に書きかえます。本文には `<b>` で太字を入れたいので、`textContent` ではなく `innerHTML` を使います。
- ボタンの文字を「もう一度」にします。ボタンを押すと `start()` → `reset()` で、盤面もスコアも最初からになります。
- 最後に置いたブロックが見えるよう、0.5 秒おいてからオーバーレイを出します。

## 画面をゆらす

`frame()` の中、`if (flash > 0) flash = …` の行の **上** に追加します。

```js:game.js
    if (shake > 0) shake = Math.max(0, shake - dt);
```

`draw()` の最初の部分、`ctx.clearRect(0, 0, W, H);` の **下** に追加します。

```js:game.js
    ctx.save();
    if (shake > 0) ctx.translate(Math.sin(shake * 80) * 5 * (shake / 0.3), 0);
```

`draw()` の最後、`if (flash > 0) { … }` の行の **上**（プレビューを描く `if (state === 'ready') { … }` の閉じかっこの下）に追加します。

```js:game.js
    ctx.restore();
```

### save / translate / restore

- `ctx.translate(x, 0)` は「これから描くものを全部、右に x ずらす」命令です。盤面もブロックもまとめて横にずれます。
- ずらす量は `Math.sin(shake * 80) * 5 * (shake / 0.3)` です。`Math.sin` で左右に細かくゆれ、`shake / 0.3` で、時間がたつほどゆれが小さくなっていきます。
- `ctx.save()` で「今の設定」を保存し、`ctx.restore()` で元に戻します。こうしておくと、ずらしたのは盤面だけで、そのあとに描く白いフラッシュはずれません。

## オーバーレイをタップしてもスタート

`$('start').addEventListener(…);` の行の **下** に追加します。

```js:game.js
  $('overlay').addEventListener('pointerdown', (e) => {
    if (e.target.id !== 'start' && state !== 'busy') start();
  });
```

ボタンの外（オーバーレイのどこか）をタップしてもスタートできるようにします。ボタン自体のタップはボタンの `click` で処理するので、`e.target.id !== 'start'` で二重に呼ばれないようにしています。

> [!CHECK] 動作チェック
> - 7個積んだ列に、いちばん上とちがう数字を落とそうとすると、画面がぷるっとゆれて置けない
> - いちばん上と同じ数字なら、満杯の列でも落とせて、いちばん上が2倍になる
> - どの列にも置けなくなると、少しおいて「ゲームオーバー」とスコア・いちばん大きな数字が出る
> - 「もう一度」（またはオーバーレイのどこか、Enter）で、盤面とスコアが最初からになる
