## このステップのゴール

ブロックが、浮かんでいる場所から **すうっと落ちて** マスに収まるようにします。落ちている間は次のブロックを落とせないようにし、「動きが止まるまで待つ」しくみを **Promise** で作ります。このしくみは、次のステップの連鎖でも大活躍します。

## 「今いる位置」と「行きたい位置」

`makeBlock()` を、次のように **書きかえ** ます。

```js:game.js
  function makeBlock(v, c, r, y) {
    const b = { v, c, r, x: cellX(c), y: y == null ? cellY(r) : y, tx: cellX(c), ty: cellY(r) };
    blocks.push(b);
    return b;
  }
```

ブロックに、新しく `tx, ty`（target ＝ 行きたい位置）を持たせました。

- `x, y` … いま画面に描いている位置
- `tx, ty` … 本当はいるべきマスの位置

毎フレーム `x, y` を `tx, ty` に少しずつ近づければ、ブロックが動いて見えます。ルール上は「もう c 列 r 段にある」けれど、見た目はまだ落ちている途中、という状態を作れるわけです。

4つ目の引数 `y` を渡すと、最初の y 座標をそこにできます（渡さなければ、最初からマスの位置）。`y == null` は、`y` が `undefined` か `null` のときに `true` になる書き方です。

## 待っている人のリスト

`let state = 'title';` の行の **下** に追加します。

```js:game.js
  let waiters = [];
```

`randValue()` の **下** に追加します。

```js:game.js
  function settled() { return new Promise((res) => waiters.push(res)); }
```

### Promise … 「あとで終わる」約束

**Promise** は「いまはまだ終わっていないけど、あとで終わったら知らせるね」という約束を表すものです。`new Promise((res) => { … })` の `res` は「終わったよ」と知らせる関数で、これを呼ぶと約束が果たされます。

`settled()` は、`res` をすぐには呼ばずに `waiters`（待っている人のリスト）に入れておくだけです。あとでゲームループが「全部のブロックが止まった」と気づいたときに、リストの `res` をまとめて呼びます。こうすると、`settled()` は「**ブロックの動きが全部止まったら果たされる約束**」になります。

## ゲームループでブロックを動かす

`frame()` を、次のように **書きかえ** ます。

```js:game.js
  function frame(now) {
    const dt = Math.min(0.05, (now - last) / 1000);
    last = now;
    let moving = false;
    for (const b of blocks) {
      const sp = 1600 * dt;
      const dx = b.tx - b.x, dy = b.ty - b.y;
      const d = Math.hypot(dx, dy);
      if (d > 0.5) {
        const k = Math.min(1, sp / d);
        b.x += dx * k; b.y += dy * k;
        moving = true;
      } else { b.x = b.tx; b.y = b.ty; }
    }
    if (!moving && waiters.length) { const ws = waiters; waiters = []; ws.forEach((f) => f()); }
    draw();
    requestAnimationFrame(frame);
  }
```

- 1秒に 1600 ピクセルの速さ（`sp = 1600 * dt` がこのフレームで進める距離）で、`tx, ty` に向かってまっすぐ進みます。
- `Math.hypot(dx, dy)` は、`(dx, dy)` の長さ（2点の距離）です。三平方の定理 `√(dx² + dy²)` を計算してくれます。
- `k = Math.min(1, sp / d)` は「残りの距離のうち、何割進むか」です。残りが進める距離より短ければ `k = 1` になり、ぴったり目的地で止まります（行きすぎない）。
- 残りが 0.5 ピクセル以下なら、目的地にぴったり合わせて「止まっている」とします。
- 1つでも動いているブロックがあれば `moving = true`。**全部止まっていて**、待っている人がいれば、`waiters` を空にしてから全員の `res` を呼びます。先に空にしておくのは、呼ばれた先でまた `settled()` されても、正しく次の回で待てるようにするためです。

## drop() を async にする

`drop()` を、次のように **書きかえ** ます。

```js:game.js
  async function drop(c) {
    if (state !== 'ready') return;
    const h = height(c);
    if (h >= ROWS) return;
    state = 'busy';
    const b = makeBlock(cur, c, h, PREVIEW_Y);
    grid[c][h] = b;
    await settled();
    cur = randValue();
    state = 'ready';
  }
```

### async / await

`async function` の中では、`await 約束` と書くと「その約束が果たされるまで、ここで一時停止」できます。止まっている間もブラウザは動き続ける（ゲームループも回る）ので、画面が固まることはありません。

流れはこうなります。

1. `state = 'busy'` にして、ほかの操作を受けつけないようにする（`drop()` の最初の `if` ではじかれる）
2. ブロックを `PREVIEW_Y`（浮かんでいた高さ）に作る。`grid` にはもう入れておく
3. `await settled()` … ゲームループがブロックを落とし終わるまで待つ
4. 次の数字にして、`state = 'ready'` に戻す

`await` を使わずに同じことをしようとすると、「落ち終わったら呼ばれる関数」を渡して、その中にまた次の処理を書いて…と入れ子が深くなっていきます。`await` なら、上から下へ **書いた順に** 読めるのが大きな利点です。

> [!NOTE]
> `busy` の間は `draw()` の `if (state === 'ready')` が成り立たないので、浮かんでいるブロックと点線は消えます。落ちていくブロックだけが見えるので、「いま手に持っていたものが落ちた」と分かりやすくなります。

> [!CHECK] 動作チェック
> - 列を選ぶと、浮かんでいたブロックがその列をすうっと落ちて、マスにぴたっと止まる
> - 落ちている間に連打しても、2つ目は落ちない。止まると次のブロックが浮かぶ
> - 高く積んだ列ほど、落ちる距離が短く早く止まる
