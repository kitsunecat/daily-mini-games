## このステップのゴール

いよいよこのゲームの中心、**合体** です。置いたブロックの上下左右に同じ数字があれば、それを吸いこんで2倍に。3つ以上まとめてくっついていれば一気に4倍・8倍になります。合体してできたすき間にはブロックが落ちてきて、そこでまた合体すれば **連鎖** です。

## 演出用のプロパティ

`makeBlock()` の1行目を、次のように **書きかえ** ます（最後に `pop`, `dying`, `alpha` を足しただけです）。

```js:game.js
    const b = { v, c, r, x: cellX(c), y: y == null ? cellY(r) : y, tx: cellX(c), ty: cellY(r), pop: 0, dying: false, alpha: 1 };
```

- `pop` … 合体した直後に 1 にして、少しずつ 0 に戻す値。この間ブロックを「ポン」とふくらませます
- `dying` … 吸いこまれて消えていく途中なら `true`
- `alpha` … 不透明度。消えていくブロックを、だんだんとうめいにします

## 少し待つ sleep()

`settled()` の行の **上** に追加します。

```js:game.js
  function sleep(ms) { return new Promise((res) => setTimeout(res, ms)); }
```

`setTimeout` を Promise にしたものです。`await sleep(160)` と書くと、160 ミリ秒だけ一時停止できます。

## resolve() … 合体と連鎖

`drop()` の **下** に追加します。

```js:game.js
  async function resolve(active) {
    while (active.length) {
      const b = active.pop();
      if (b.dying) continue;
      const nb = [];
      for (const [dc, dr] of [[-1, 0], [1, 0], [0, -1], [0, 1]]) {
        const c = b.c + dc, r = b.r + dr;
        if (c < 0 || c >= COLS || r < 0 || r >= ROWS) continue;
        const o = grid[c][r];
        if (o && o.v === b.v) nb.push(o);
      }
      if (!nb.length) continue;
      for (const o of nb) {
        grid[o.c][o.r] = null;
        o.dying = true; o.tx = b.tx; o.ty = b.ty;
      }
      b.v *= 2 ** nb.length;
      b.pop = 1;
      await sleep(160);
      const moved = gravity();
      await settled();
      active.push(...moved, b);
    }
  }
```

`active` は「合体するかどうか調べたいブロック」のリストです。最初は今置いたブロック1つだけが入っています。リストが空になるまで、1つずつ取り出して調べます。

1. **消えかけ（`dying`）のブロックは飛ばす**。もう盤面にはないからです。
2. **上下左右のとなりを調べる**。`[[-1, 0], [1, 0], [0, -1], [0, 1]]` は「左・右・下・上」に1マスずれる量です。盤面の外ははみ出さないよう `continue` で飛ばし、同じ数字のブロックを `nb`（neighbors ＝ となり）に集めます。
3. となりに同じ数字がなければ、このブロックはおしまい。
4. **となりを吸いこむ**。となりのブロックを `grid` から消し（`null`）、`dying = true` にして、行き先（`tx, ty`）を今のブロックの位置にします。こうすると、ゲームループの中で「吸いこまれるように動きながら消えていく」ようになります。
5. **数字を大きくする**。となりが1つなら 2倍、2つなら 4倍、3つなら 8倍 … なので、`2 ** nb.length` 倍です。2つの 4 にはさまれた 4 なら、4 × 4 = 16 になります。
6. 少し待ってから（`await sleep(160)`）**重力** をかけ、落ちたブロックが止まるまで待ちます（`await settled()`）。
7. **落ちたブロックと、大きくなったブロック自身を、もう一度調べるリストに入れる**。大きくなった数字が、また別のとなりと同じになっているかもしれないからです。これが連鎖のしくみです。

`grid` からはすぐに消すけれど、`blocks` にはしばらく残しておく。ステップ2で役わりを分けておいたおかげで、「ルール上はもうないけど、まだ見えている」ブロックが作れました。

## gravity() … すき間をつめる

`resolve()` の **下** に追加します。

```js:game.js
  function gravity() {
    const moved = [];
    for (let c = 0; c < COLS; c++) {
      let w = 0;
      for (let r = 0; r < ROWS; r++) {
        const b = grid[c][r];
        if (!b) continue;
        if (r !== w) {
          grid[c][w] = b; grid[c][r] = null;
          b.r = w; b.ty = cellY(w);
          moved.push(b);
        }
        w++;
      }
    }
    return moved;
  }
```

列ごとに、下の段から順に見ていきます。`w`（write ＝ 書きこむ位置）は「次にブロックを置くべき段」です。

- ブロックが見つかったら、`w` の段に移します。すでに `w` の段にいれば何もしません。
- 移したブロックは、段の番号 `r` と行き先 `ty` を新しくして、`moved` に入れます。
- 1個置くたびに `w` を1つ上げます。

これで、すき間の上にあったブロックが全部下につまります。`ty` を変えただけなので、見た目はゲームループの中で自然に落ちていきます。

## drop() から resolve() を呼ぶ

`drop()` の `await settled();` の行の **下** に追加します。


## ゲームループと描画に演出を足す

`frame()` の中の `for (const b of blocks) { … }` から `if (!moving …` の行の上までを、次のように **書きかえ** ます。

```js:game.js
    for (const b of blocks) {
      const sp = 1600 * dt;
      const dx = b.tx - b.x, dy = b.ty - b.y;
      const d = Math.hypot(dx, dy);
      if (b.dying) {
        b.alpha -= dt * 7;
        if (d > 0.5) { const k = Math.min(1, (900 * dt) / d); b.x += dx * k; b.y += dy * k; }
        moving = true;
      } else if (d > 0.5) {
        const k = Math.min(1, sp / d);
        b.x += dx * k; b.y += dy * k;
        moving = true;
      } else { b.x = b.tx; b.y = b.ty; }
      if (b.pop > 0) b.pop = Math.max(0, b.pop - dt * 5);
    }
    blocks = blocks.filter((b) => !(b.dying && b.alpha <= 0));
```

- 消えかけのブロックは、`alpha` を1秒に 7 ずつ減らし（約 0.14 秒で消える）、少しゆっくり（1秒に 900 ピクセル）合体先へ吸いこまれていきます。消えている間は `moving = true` なので、`settled()` は消え終わるまで待ってくれます。
- `pop` は1秒に 5 ずつ 0 に近づけます（0.2 秒でもとどおり）。
- `filter` で、消え終わった（`alpha` が 0 以下の）ブロックを `blocks` から取りのぞきます。

`draw()` の中の `for (const b of blocks) drawBlock(b.v, b.x, b.y);` を、次のように **書きかえ** ます。

```js:game.js
    for (const b of blocks) if (b.dying) drawBlock(b.v, b.x, b.y, 0.9, b.alpha);
    for (const b of blocks) if (!b.dying) drawBlock(b.v, b.x, b.y, 1 + Math.sin(b.pop * Math.PI) * 0.12);
```

- 消えかけのブロックを **先に** 描くので、合体先のブロックの下にもぐりこむように見えます。少し小さく（0.9 倍）、`alpha` でうすくします。
- ふつうのブロックは `1 + Math.sin(b.pop * Math.PI) * 0.12` 倍の大きさで描きます。`pop` が 1 → 0 に減る間に `Math.sin(pop × π)` は 0 → 1 → 0 と山なりに変わるので、**一瞬ふくらんで戻る**「ポン」という動きになります。

> [!CHECK] 動作チェック
> - 2 の上に 2 を落とすと、上の 2 が吸いこまれて 4 になる。横どうしでも合体する
> - 2つの 4 の間（または上）に 4 を落とすと、まとめて吸いこんで一気に 16 になる
> - 合体してできたすき間に、上のブロックが落ちてくる。落ちた先でまた同じ数字ととなり合えば、続けて合体する（連鎖）
> - 合体したブロックが一瞬ポンとふくらむ
> - 上の SCORE などはまだ動かなくてOK（次のステップで作ります）
