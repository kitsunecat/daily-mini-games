## このステップのゴール

盤面の上に「次に落とすブロック」を浮かべ、クリック・タップ・キーボードで列を選んで、その列のいちばん上の空きマスにブロックを置けるようにします。アニメーションは次のステップで付けるので、ここではパッと置かれるだけです。

## 定数と変数を足す

`const GX = …` の行の **下** に追加します。

```js:game.js
  const PREVIEW_Y = 22;
```

`PREVIEW_Y` は、次のブロックを浮かべておく高さ（y 座標）です。

`let grid, blocks;` の行を、次のように **書きかえ** ます。

```js:game.js
  let grid, blocks, maxV, cur, selCol = 2;
```

- `maxV` … 盤面に出たいちばん大きな数字。落ちてくる数字の種類を決めるのに使います（ステップ6で更新します）
- `cur` … いま手に持っている（次に落とす）ブロックの数字
- `selCol` … いま選んでいる列。最初はまん中の 2 列目（0 から数えるので、5列のまん中）です

## 列の高さと、落ちてくる数字

`label()` の **下**（`// ---------- game ----------` の上）に追加します。

```js:game.js
  function height(c) {
    let h = 0;
    while (h < ROWS && grid[c][h]) h++;
    return h;
  }
  function randValue() {
    const top = Math.max(3, Math.min(8, exp2(maxV) - 2));
    // smaller numbers more often
    let total = 0;
    const ws = [];
    for (let e = 1; e <= top; e++) { const w = 1 / e; ws.push(w); total += w; }
    let r = Math.random() * total;
    for (let i = 0; i < ws.length; i++) { r -= ws[i]; if (r <= 0) return 2 ** (i + 1); }
    return 2;
  }
```

### height() … 列の高さ

c 列目に、下から何個ブロックが積まれているかを数えます。下（段 0）から順に見て、空きマスが見つかったところで止めます。**高さ = 次にブロックが入る段の番号** になっているのがポイントです。たとえば3個積まれていれば、次は段 3（4段目）に入ります。

### randValue() … 小さい数字ほど出やすく

落ちてくる数字は、2, 4, 8 … の中からランダムに選びます。ただし、まったく同じ確率だと大きな数字ばかり来て合体しにくいので、**重み** をつけています。

- `2 ** e`（2 の e 乗）に、重み `1 / e` をつけます。2 は重み 1、4 は 1/2、8 は 1/3 … と、大きい数字ほど出にくくなります。
- 重みを全部足した `total` の中で `Math.random() * total` の位置を決め、そこから重みを順に引いていって、0 以下になったものを選びます。「長さのちがう棒を並べて、ランダムな場所に針を刺す」イメージです。
- 出てくる数字の上限 `top` は、`maxV` が大きくなるほど上がります（最低でも 8 まで、最高で 256 まで）。盤面に大きな数字ができると、落ちてくる数字も少しずつ大きくなるしくみです。

## reset() と start() を書きかえる

`reset()` の「お試し」の5行を消して、次のように **書きかえ** ます。`start()` の先頭にも `reset();` を足します。

```js:game.js
  function reset() {
    grid = Array.from({ length: COLS }, () => Array(ROWS).fill(null));
    blocks = [];
    maxV = 2;
    cur = randValue();
  }
  function start() {
    reset();
    $('overlay').classList.add('hide');
    state = 'ready';
  }
```

スタートするたびに盤面を空にして、最初のブロックを決めます。

## drop() … ブロックを置く

`start()` の **下** に追加します。

```js:game.js
  function drop(c) {
    if (state !== 'ready') return;
    const h = height(c);
    if (h >= ROWS) return;
    const b = makeBlock(cur, c, h);
    grid[c][h] = b;
    cur = randValue();
  }
```

- `state` が `'ready'` のときだけ置けます（タイトル画面では置けない）。
- `height(c)` が `ROWS`（7）以上なら、その列は満杯なので何もしません（ステップ7で、ここに特別なルールを足します）。
- 空いていれば、`grid` の `[c][h]` にブロックを入れ、手持ちを次の数字にします。

## 選んでいる列と、次のブロックを描く

`draw()` の中、`for (let c = 0; c < COLS; c++) {` の行の **すぐ下** に追加します。

```js:game.js
      if (c === selCol && state !== 'title' && state !== 'over') {
        ctx.fillStyle = 'rgba(126,224,255,.10)';
        ctx.fillRect(cellX(c), GY, CELL, ROWS * CELL);
      }
```

選んでいる列に、うすい水色の帯を引きます。

さらに、`draw()` の最後、`for (const b of blocks) drawBlock(b.v, b.x, b.y);` の **下** に追加します。

```js:game.js
    // preview
    if (state === 'ready') {
      const px = cellX(selCol);
      const h = height(selCol);
      const ly = h >= ROWS ? GY : cellY(h);
      ctx.strokeStyle = 'rgba(255,255,255,.25)'; ctx.lineWidth = 2;
      ctx.setLineDash([4, 6]);
      ctx.beginPath(); ctx.moveTo(px + CELL / 2, PREVIEW_Y + CELL); ctx.lineTo(px + CELL / 2, ly + 4); ctx.stroke();
      ctx.setLineDash([]);
      drawBlock(cur, px, PREVIEW_Y, 0.92 + Math.sin(performance.now() / 250) * 0.03);
    }
```

- 選んでいる列の上（`PREVIEW_Y`）に、手持ちのブロックを描きます。
- そこから「落ちる先」まで、点線を引きます。`ly` は落ちる先のマスの上端です。列が満杯のときは盤面の上のふちまでにします。
- 大きさに `Math.sin(performance.now() / 250) * 0.03` を足しているので、ブロックがゆっくり **ふわふわ** ふくらんだりちぢんだりします。`Math.sin` は -1〜1 を行ったり来たりする波なので、時間を入れると「くり返す動き」が簡単に作れます。

## 入力 … マウス・タッチ・キーボード

`// ---------- input ----------` の行の **下**（`$('start')…` の上）に追加します。

```js:game.js
  function colFromEvent(e) {
    const rect = cv.getBoundingClientRect();
    const x = ((e.clientX - rect.left) / rect.width) * W;
    return Math.max(0, Math.min(COLS - 1, Math.floor((x - GX) / CELL)));
  }
  cv.addEventListener('pointerdown', (e) => {
    e.preventDefault();
    if (state !== 'ready') return;
    selCol = colFromEvent(e);
    drop(selCol);
  });
  cv.addEventListener('pointermove', (e) => {
    if (e.pointerType === 'mouse') selCol = colFromEvent(e);
  });
```

`$('start').addEventListener(…);` の行の **下** に、キーボードのイベントを追加します。

```js:game.js
  window.addEventListener('keydown', (e) => {
    if (!$('overlay').classList.contains('hide')) {
      if (e.key === 'Enter' || e.key === ' ') { e.preventDefault(); start(); }
      return;
    }
    if (e.key === 'ArrowLeft') { selCol = Math.max(0, selCol - 1); e.preventDefault(); }
    else if (e.key === 'ArrowRight') { selCol = Math.min(COLS - 1, selCol + 1); e.preventDefault(); }
    else if (e.key === ' ' || e.key === 'ArrowDown') { e.preventDefault(); drop(selCol); }
    else if (e.key >= '1' && e.key <= '5') { selCol = +e.key - 1; drop(selCol); }
  });
```

### colFromEvent() … クリックした場所から列を出す

`e.clientX` は、クリック（タップ）した場所の **画面上の** x 座標です。Canvas は CSS で拡大・縮小されているので、そのままではゲームの座標（360×560）と合いません。

1. `getBoundingClientRect()` で、Canvas が画面のどこに、どの大きさで表示されているかを取ります。
2. `(e.clientX - rect.left) / rect.width` で「Canvas の左端から何割の位置か」（0〜1）を出し、`W` 倍してゲームの座標に直します。
3. 盤面の左端 `GX` を引いて `CELL` で割り、`Math.floor` で切り捨てると列の番号になります。盤面の外をクリックしても、`Math.max` / `Math.min` で 0〜4 の中に収めます。

### Pointer Events

`pointerdown` / `pointermove` は、マウス・タッチ・ペンを **まとめて** 扱えるイベントです（Pointer Events）。

- `pointerdown` … 押した列を選んで、すぐ落とします。`e.preventDefault()` で、スマホのタップ後に出るよけいな動き（マウスイベントのまね）を止めます。
- `pointermove` … マウスのときだけ（`e.pointerType === 'mouse'`）、カーソルのある列を選びます。タッチのときは指が離れているので使いません。

### キーボード

- タイトル画面（オーバーレイが出ている）ときは、Enter か Space でスタートします。
- プレイ中は ←→ で列を選び、Space か ↓ で落とします。数字キー 1〜5 で「その列に直接落とす」こともできます。
- `e.preventDefault()` で、矢印キーや Space でページがスクロールするのを止めます。

> [!NOTE]
> `e.key >= '1' && e.key <= '5'` は文字どうしの比較です。'1'〜'5' の1文字なら、この条件で数字キーだけを選べます。`+e.key` は文字を数字に変える書き方です（`+'3'` は 3）。

> [!CHECK] 動作チェック
> - スタートすると、盤面の上に数字ブロックが1つふわふわ浮かび、選んでいる列が水色になる
> - マウスを動かすと、選んでいる列とブロックがついてくる
> - クリック・タップした列の、いちばん下の空きマスにブロックがパッと置かれる。置くたびに次の数字（2, 4, 8 のどれか）に変わる
> - ←→ で列を選んで Space / ↓、または 1〜5 キーでも置ける
> - 7個積んだ列にはもう置けない。同じ数字がとなり合ってもまだ合体しなくてOK（ステップ5で作ります）
