## このステップのゴール

3つのファイルを用意して、ゲーム画面の土台を作ります。上に「← 一覧・SCORE・BEST」、その下に「スター3つ」と「スピード表示」、まん中にタイルを描く **Canvas** とその上に重ねるタイトル画面（オーバーレイ）、いちばん下にメッセージを置きます。スタートを押すとタイトル画面が消えるところまで作ります。

完成すると、こんなゲームになります。

- 画面は **4本のレーン**。上から **黒いタイル** が流れてくる
- **いちばん下のタイルから順に** タップする。タップするたびにメロディーが1音ずつ鳴る
- タイルの無い列をタップする（空振り）か、タイルが画面の下まで流れてしまう（見逃し）と **ゲームオーバー**
- ときどき出てくる **長いタイル** は押したままにすると、長押しボーナス
- 叩くほど少しずつ **速く** なる。40枚ごとに **スター** が1つ光る
- ハイスコアはブラウザに保存される。PC では D・F・J・K キーでも遊べる

## index.html

HTML はこのステップで完成させます。以降のステップでは触りません。

```html:index.html
<!DOCTYPE html>
<html lang="ja">
<head>

<link rel="stylesheet" href="style.css">
</head>
<body>
<div id="app">
  <header>
    <a class="back" href="../../../../">← 一覧</a>
    <div class="stat"><span>SCORE</span><b id="score">0</b></div>
    <div class="stat"><span>BEST</span><b id="best">0</b></div>
  </header>
  <div id="info">
    <div id="stars"><i></i><i></i><i></i></div>
    <div id="speed">x1.0</div>
  </div>
  <div id="stage">
    <canvas id="cv"></canvas>
    <div id="overlay">
      <h1 id="ov-title">ほしふるけんばん</h1>
      <p id="ov-text">上から落ちてくる<b class="hl">黒いタイル</b>を、<br>いちばん下のものから順にタップしよう。<br>タップするたびにメロディーが鳴るよ。<br><b class="hl">長いタイル</b>は押したままでボーナス。<br>何もない列をタップするか、<br>タイルを見逃すとゲームオーバー。</p>

    </div>
  </div>
  <div id="bar"><div id="msg">音を鳴らしながらタイルを追いかけよう</div></div>
</div>
<script src="game.js"></script>
</body>
</html>
```

- `<meta name="viewport" ...>` はスマホで画面幅に合わせて表示し、ピンチで拡大されないようにする設定です
- JavaScript から書きかえる場所には `id`（`score`・`best`・`speed`・`msg`・`ov-title`・`ov-text` など）をつけておきます
- `#stars` の中の3つの `<i>` は星のマークです。CSS で星形に切り抜き、`on` クラスがつくと黄色く光ります
- `<canvas id="cv">` がゲームの絵を描く場所です。タイルや背景はすべてここに JavaScript で描きます
- `#overlay` はタイトル画面とゲームオーバー画面を兼ねた「ふた」で、Canvas の上に重ねて表示します
- 「← 一覧」のリンク先はこのサイトのトップです。自分のフォルダで作るときは好きなページに変えてかまいません
- `<script>` を `</body>` の直前に置くと、HTML の要素がすべて読みこまれてから JavaScript が動きます

ポイントをいくつか見ておきましょう。

- `#app` を `display: flex; flex-direction: column;` にして、ヘッダー・情報行・ステージ・メッセージを縦に積みます。`#stage` だけ `flex: 1` なので、残りの高さを全部もらいます。`min-height: 0` は、中身が大きくても親からはみ出さないようにするおまじないです
- `#cv` は `width: 100%; height: 100%` で `#stage` いっぱいに広げます。Canvas の **中の解像度** はステップ2で JavaScript から合わせます
- `touch-action: none` は、スマホで画面をさわったときにスクロールやズームが起きないようにする設定です。音楽ゲームでは連打するので大事です
- `user-select: none` は、連打したときに文字が選択されて青くなるのを防ぎます
- `#stars i` の `clip-path: polygon(...)` は、四角い要素を **星形に切り抜く** 指定です。10個の点をつないで星にしています
- `#stage` は `position: relative`、`#overlay` は `position: absolute; inset: 0` なので、オーバーレイはステージにぴったり重なります
- `#overlay.hidden { display: none; }` のように、クラスを1つ付けるだけで表示を切りかえられるようにしておきます

## game.js

JavaScript はまず「スタートボタンでタイトル画面を消す」だけを書きます。

```js:game.js
(() => {
  'use strict';
  const $ = (id) => document.getElementById(id);
  const msgEl = $('msg');
  const overlay = $('overlay'), startBtn = $('start');

  startBtn.addEventListener('click', start);

  function msg(s) { msgEl.textContent = s; }

  function start() {
    overlay.classList.add('hidden');
    msg('いちばん下のタイルからタップ！');
  }
})();
```

### 全体を (() => { ... })(); で囲む

ファイル全体を「すぐ実行される関数」で囲むと、中で作った変数がページ全体（グローバル）に漏れません。`'use strict';` は、うっかりミスをエラーとして教えてくれるモードです。

`const $ = (id) => document.getElementById(id);` は、何度も書く `document.getElementById` を短く書くための小さな関数です。`$('msg')` でメッセージの要素が取れます。何度も使う要素（`msgEl`・`overlay`・`startBtn`）は最初に取り出して変数に入れておきます。

### msg() と start()

- `msg(s)` は下のメッセージを書きかえる関数です
- `start()` はゲームを始める関数です。今はオーバーレイに `hidden` クラスをつけて隠し、メッセージを出すだけです。ここに少しずつ処理を足していきます
- `startBtn.addEventListener('click', start)` で、ボタンが押されたら `start` を呼ぶように登録します

> [!NOTE]
> `start` と `msg` は `addEventListener` の行より **下** で定義していますが、`function 名前() {}` の形で書いた関数は、ファイルの中のどこからでも呼べます（巻き上げ）。

> [!CHECK] 動作チェック
> - 紺色の画面に「ほしふるけんばん」とルール説明、黄色い「タップでスタート」ボタンが出る
> - 上に「← 一覧」・SCORE 0・BEST 0、その下にグレーの星3つと「x1.0」が並んでいる
> - ボタンを押すとタイトル画面が消え、下のメッセージが「いちばん下のタイルからタップ！」に変わる（ステージはまだ何も描かれていない）
> - 開発者ツールの Console にエラーが出ていない
