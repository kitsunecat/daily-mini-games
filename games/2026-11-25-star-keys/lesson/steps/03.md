## このステップのゴール

ゲームの主役、**黒いタイル** を作って並べます。タイルは「何レーン目か」と「下から何行目か」だけを覚えておき、画面上の位置は **スクロール量** から計算します。このしくみが、次のステップでタイルを流すときのカギになります。最初のタイルには「START」と書きます。

## 譜面の考え方

ピアノタイル系のゲームは、**1行に1枚** タイルがあり、それが下から順に並んだ「譜面」を上から下へ流していきます。

- 各タイルは `lane`（0〜3。左から何レーン目か）と `row`（0, 1, 2, …。下から何行目か）を持つ
- 譜面全体を下にずらす量を `scroll`（ピクセル）で表す。`scroll` が増えるほど、タイルは下に流れる

すると、タイルの **下端の y 座標** は次の式で求まります。

- `下端の y = H - (row × rowH - scroll)`

`row = 0`・`scroll = 0` なら下端は `H`（画面のいちばん下）。`row` が1増えると1行分上に、`scroll` が増えると下にずれます。**タイル1枚1枚を動かさなくても、`scroll` を1つ増やすだけで全部が流れる** のがポイントです。

## 変数を追加する

`let W = 0, ...` の行の **下** に追加します。

```js:game.js
  let tiles = [], nextRow = 0, scroll = 0;
  let state = 'title';
```

- `tiles` … タイルの配列。`tiles[0]` がいちばん下のタイル
- `nextRow` … 次に作るタイルの行番号
- `state` … ゲームの状態。`'title'`（タイトル画面）→ `'play'`（プレイ中）のように切りかえます

## resize() に1行足す

画面サイズが変わると `rowH` が変わるので、`scroll` も同じ割合でのばしておかないとタイルの位置がずれます。`resize()` を次のように書きかえます。

```js:game.js
  function resize() {
    const r = cv.getBoundingClientRect();
    dpr = Math.min(window.devicePixelRatio || 1, 2);
    const oldRowH = rowH;
    W = Math.max(1, r.width); H = Math.max(1, r.height);
    cv.width = Math.round(W * dpr); cv.height = Math.round(H * dpr);
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
    laneW = W / LANES; rowH = H / ROWS;
    if (oldRowH > 0) scroll = scroll / oldRowH * rowH;
    bgStars = Array.from({ length: 40 }, () => ({ x: Math.random() * W, y: Math.random() * H, r: Math.random() * 1.4 + 0.3, p: Math.random() * 6 }));
    draw();
  }
```

## タイルを作る関数

`window.addEventListener('resize', resize);` の **下** に追加します。

```js:game.js
  // ---------- tiles ----------
  function addRow() {
    const prev = tiles[tiles.length - 1];
    let lane;
    do { lane = Math.floor(Math.random() * LANES); } while (prev && lane === prev.lane && Math.random() < 0.7);
    const len = 1;
    tiles.push({ lane, row: nextRow, len, st: 'pending' });
    nextRow += len;
  }
  // 画面上の y（タイル下端）
  const tileBottom = (t) => H - (t.row * rowH - scroll);
  const tileTop = (t) => tileBottom(t) - t.len * rowH;

  function reset() {
    tiles = []; nextRow = 0;
    scroll = -rowH * 0.6; // 最初のタイルが下から少し上に見える
    while (nextRow < ROWS + 3) addRow();
    tiles[0].start = true;
  }
```

### addRow()

- `Math.floor(Math.random() * LANES)` で 0〜3 のレーンをランダムに選びます
- `do { ... } while (条件)` は「まず1回やって、条件が true の間くり返す」ループです。ここでは **ひとつ前と同じレーンになったら、70% の確率で選びなおす** ようにしています。同じレーンが続きすぎると単調なので、少しだけ減らす工夫です
- `len` はタイルの長さ（何行分か）です。今は全部 1 ですが、ステップ8で長いタイル（2行分）を作ります
- `st` はタイルの状態で、`'pending'`（まだ叩いていない）から始まります
- `{ lane, row: nextRow, ... }` の `lane` は `lane: lane` の省略形です

### tileBottom() と tileTop()

さきほどの式そのままです。上端は下端から `len` 行分だけ上（y が小さい）になります。`const 名前 = (t) => 式;` は、式の結果をそのまま返す短い関数（アロー関数）です。

### reset()

ゲーム開始時にタイルを作りなおします。画面に見えるのは4行ですが、少し余分に `ROWS + 3` 行（7枚）作っておきます。`scroll` をマイナスにしているのは、最初のタイルが画面の下ぎりぎりではなく、**少し上** に見えるようにするためです（`scroll` がマイナスだと、タイルは上にずれます）。最初のタイルには `start = true` の印をつけます。

## スタートで reset() を呼ぶ

`start()` を書きかえます。

```js:game.js
  function start() {
    reset();
    state = 'play';
    overlay.classList.add('hidden');
    msg('いちばん下のタイルからタップ！');
    draw();
  }
```

## 角の丸い四角を描く roundRect()

Canvas には角の丸い四角を描く命令が古いブラウザには無いので、自分で作ります。`function draw(now)` の **上** に追加します。

```js:game.js
  function roundRect(x, y, w, h, r) {
    ctx.beginPath();
    ctx.moveTo(x + r, y);
    ctx.arcTo(x + w, y, x + w, y + h, r);
    ctx.arcTo(x + w, y + h, x, y + h, r);
    ctx.arcTo(x, y + h, x, y, r);
    ctx.arcTo(x, y, x + w, y, r);
    ctx.closePath();
  }
```

`arcTo(x1, y1, x2, y2, r)` は「(x1, y1) の角を、半径 `r` で丸めながら (x2, y2) の方へ曲がる」命令です。4つの角で順に使うと、角の丸い四角の形（パス）ができます。ぬるのは呼んだ側で `ctx.fill()` します。

## draw() でタイルを描く

`draw()` の最後、レーン線を描く `for` の **下**（`draw()` の閉じかっこ `}` の直前）に追加します。

```js:game.js
    // タイル
    const pad = 2;
    for (const t of tiles) {
      const y0 = tileTop(t), y1 = tileBottom(t);
      if (y1 < -2 || y0 > H + 2) continue;
      const x = t.lane * laneW + pad, w = laneW - pad * 2, h = y1 - y0 - pad * 2;
      const tg = ctx.createLinearGradient(0, y0, 0, y1);
      tg.addColorStop(0, '#2b2f55'); tg.addColorStop(1, '#14172e');
      ctx.fillStyle = tg;
      roundRect(x, y0 + pad, w, h, 6); ctx.fill();
      if (t.start && state === 'play' && t.st === 'pending') {
        ctx.fillStyle = '#ffd56b';
        ctx.font = 'bold 15px system-ui, sans-serif';
        ctx.textAlign = 'center'; ctx.textBaseline = 'middle';
        ctx.fillText('START', t.lane * laneW + laneW / 2, (y0 + y1) / 2);
      }
    }
```

- 画面の外（下端が画面より上、または上端が画面より下）のタイルは `continue` で描かずに飛ばします
- `pad`（2px）ずつ内側に縮めて描くと、となりのタイルとのあいだにすき間ができて見やすくなります
- タイルごとに上から下への紺色のグラデーションでぬって、少し立体感を出しています
- `textAlign = 'center'` と `textBaseline = 'middle'` にすると、`fillText` で指定した点が **文字のまん中** になります

最後に、ファイルの終わりを次のようにします。

```js:game.js
  resize();
  reset();
  draw();
})();
```

> - 再読み込みしてスタートするたびに、タイルの並びが変わる
