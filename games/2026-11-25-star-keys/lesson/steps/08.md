## このステップのゴール

ときどき **2行分の長いタイル** が出てくるようにします。長いタイルは押したら **そのまま押し続け**、タイルの中の黄色いバーが上までのびたら成功です。押していた長さに応じて最大 **+4 のボーナス** が入り、「+4」の文字がふわっと浮かびます。途中で離しても失敗にはなりませんが、ボーナスは少なくなります。

## 長押しの考え方

「押した」は `pointerdown` / `keydown`、「離した」は `pointerup` / `keyup` で分かります。ただし2本指で同時に遊ぶこともあるので、**どの指（どのキー）がどのタイルを押しているか** を覚えておく必要があります。そのために **Map** を使います。

`Map` は「キー → 値」の組を覚えておく入れ物で、オブジェクトに似ていますが、`set(キー, 値)`・`get(キー)`・`delete(キー)`・`clear()` で出し入れします。ここではキーに `'p' + 指の番号` や `'k' + キーの文字` を、値に押しているタイルを入れます。ステップ5から `press()` に渡していた `id` が、ここで役に立ちます。

## 変数を追加する

`let effects = [], bgStars = [];` の **下** に追加します。

```js:game.js
  const holds = new Map(); // pointerId/key -> tile
```

`reset()` の `failInfo = null;` の行を書きかえて、長押しの記録も空にします。

```js:game.js
    holds.clear(); failInfo = null;
```

## 長いタイルを作る

`addRow()` を書きかえます。

```js:game.js
  function addRow() {
    const prev = tiles[tiles.length - 1];
    let lane;
    do { lane = Math.floor(Math.random() * LANES); } while (prev && lane === prev.lane && Math.random() < 0.7);
    const canLong = hits > 8 || nextRow > 10;
    const len = canLong && Math.random() < 0.16 ? 2 : 1;
    tiles.push({ lane, row: nextRow, len, st: 'pending', prog: 0, holdStart: 0, flash: 0 });
    nextRow += len;
  }
```

- 始まってすぐは長いタイルを出さず、少し進んでから（`canLong`）16% の確率で長さ 2 にします
- 長さ 2 のタイルは2行分の高さを使うので、`nextRow += len` で次のタイルを2行上に置きます。`tileTop()` も最初から `len` を使って書いてあるので、そのまま2行分の高さで描かれます
- `prog` は長押しの進み具合（0〜1）、`holdStart` は押し始めたときの `scroll` の値です

## press() で長押しを始める

`press()` の中、`hits++;` から `score += 1;` までを書きかえます。

```js:game.js
    hits++;
    if (t.len > 1) {
      t.st = 'holding'; t.holdStart = scroll; t.prog = 0;
      holds.set(id, t);
      score += 1;
    } else {
      t.st = 'hit'; t.flash = 1;
      score += 1;
    }
    playNote(t.len > 1);
```

長いタイルは状態を `'holding'`（押している最中）にして、どの指で押したかを `holds` に記録します。`playNote(true)` で音も長くのばします。

`'holding'` は `'pending'` ではないので、`lowestPending()` はもう次のタイルを返します。**長いタイルを押しながら、別の指で次のタイルを叩く** こともできます。

## 離したときの処理

`press()` の閉じかっこの **下** に追加します。

```js:game.js
  function release(id) {
    const t = holds.get(id);
    if (!t) return;
    holds.delete(id);
    if (t.st === 'holding') finishHold(t);
  }
  function finishHold(t) {
    t.st = 'hit';
    const bonus = Math.floor(t.prog * 4);
    if (bonus > 0) {
      score += bonus;
      effects.push({ x: (t.lane + 0.5) * laneW, y: tileTop(t) + 20, r: 0, a: 1, text: '+' + bonus });
    }
    if (t.prog >= 1) playNote(false);
    updateHud();
  }
```

- `release(id)` は、離した指（キー）が長いタイルを押していたら、その長押しを終わらせます
- `finishHold(t)` は長押しの終わりの処理です。進み具合 `prog` に 4 をかけて切り捨てた数をボーナスにします（最後まで押せば +4）。ボーナスがあれば、文字のエフェクト（`text` つき）を足します。最後まで押しきったら、ごほうびにもう1音鳴らします

## 離すイベントを登録する

`pointerdown` の登録の **下** に追加します。

```js:game.js
  const up = (e) => release('p' + e.pointerId);
  cv.addEventListener('pointerup', up);
  cv.addEventListener('pointercancel', up);
```

`pointercancel` は、電話がかかってきたときなど、ブラウザの都合で指の追跡が打ち切られたときに届きます。これも「離した」あつかいにしておかないと、長押しが終わらなくなります。

`keydown` の登録の **下** に追加します。

```js:game.js
  window.addEventListener('keyup', (e) => release('k' + e.key.toLowerCase()));
```

## update() で長押しを進める

`update()` の中、`flash` を減らしている `for` を書きかえます。

```js:game.js
      // 長押しの進行
      for (const t of tiles) {
        if (t.st === 'holding') {
          t.prog = Math.min(1, (scroll - t.holdStart) / ((t.len - 0.6) * rowH));
          if (t.prog >= 1) {
            for (const [k, v] of holds) if (v === t) holds.delete(k);
            finishHold(t);
          }
        }
        if (t.flash > 0) t.flash = Math.max(0, t.flash - dt * 3);
      }
```

押し始めてから譜面が進んだ量（`scroll - t.holdStart`）を、「タイルの長さ − 0.6 行分」で割って進み具合にします。長さ 2 のタイルなら、1.4 行分流れたら 100% です。最後まで行ったら、`holds` からそのタイルを消して（`for (const [k, v] of holds)` は Map の中身をキーと値の組で1つずつ取り出す書き方です）、指を離すのを待たずに `finishHold()` します。

エフェクトの更新の行も書きかえて、文字のエフェクトは上へ浮かぶようにします。

```js:game.js
    for (const f of effects) { f.r += dt * 120; f.a -= dt * 2; if (f.text) f.y -= dt * 40; }
```

## draw() で長いタイルと文字を描く

タイルを描く `for` の中、`roundRect(x, y0 + pad, w, h, 6); ctx.fill();`（黒いタイルをぬる行）の **下** に追加します。

```js:game.js
      if (t.len > 1) {
        // 長いタイル：中央のライン＋進行バー
        ctx.fillStyle = 'rgba(255,213,107,.35)';
        ctx.fillRect(t.lane * laneW + laneW / 2 - 3, y0 + 18, 6, h - 30);
        if (t.st === 'holding') {
          const ph = (h - 30) * t.prog;
          ctx.fillStyle = '#ffd56b';
          ctx.fillRect(t.lane * laneW + laneW / 2 - 4, y1 - pad - 12 - ph, 8, ph);
        }
        ctx.fillStyle = '#ffd56b';
        ctx.beginPath(); ctx.arc(t.lane * laneW + laneW / 2, y0 + 16, 7, 0, Math.PI * 2); ctx.fill();
      }
```

長いタイルのまん中に、うすい黄色の線と、上端の丸い目印を描きます。押している間は、下から `prog` の割合だけ濃い黄色のバーをのばします。

エフェクトを描く `for` の中を書きかえて、文字のエフェクトにも対応します。

```js:game.js
    for (const f of effects) {
      ctx.globalAlpha = Math.max(0, f.a);
      if (f.text) {
        ctx.fillStyle = '#d9a21b';
        ctx.font = 'bold 20px system-ui, sans-serif';
        ctx.textAlign = 'center'; ctx.textBaseline = 'middle';
        ctx.fillText(f.text, f.x, f.y);
      } else {
        ctx.strokeStyle = '#ffd56b'; ctx.lineWidth = 3;
        ctx.beginPath(); ctx.arc(f.x, f.y, f.r, 0, Math.PI * 2); ctx.stroke();
      }
    }
```

> [!CHECK] 動作チェック
> - 10枚ほど叩くと、ときどき2行分の高さで、まん中に黄色い線と丸の目印がある長いタイルが出てくる
> - 長いタイルを押し続けると黄色いバーが下からのび、上までのびると「+4」が浮かんで、もう1音鳴る
> - 途中で離すと、そこまでの分だけボーナスが入る（すぐ離すとボーナスなし）
> - 長いタイルを押したまま、別の指（別のキー）で次のタイルも叩ける
