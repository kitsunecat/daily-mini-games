## このステップのゴール

**ゲームループ** を作って、タイルを上から下へ流します。流れて画面の下に消えたタイルを片づけ、上には新しいタイルを補充して、**終わりのない譜面** にします。右上のスピード表示「x1.0」も JavaScript から書くようにします。

## 変数を追加・変更する

`const msgEl = $('msg');` を書きかえて、スピード表示の要素も取り出します。

```js:game.js
  const speedEl = $('speed'), msgEl = $('msg');
```

`let tiles = ...` と `let state = ...` の2行を書きかえます。

```js:game.js
  let tiles = [], nextRow = 0, scroll = 0, speed = 0;
  let state = 'title', lastT = 0;
```

- `speed` … 1秒間に何行分流れるか。`1.5` なら1秒で1.5行（タイル1.5枚分）下に進みます
- `lastT` … 前のフレームの時刻。次のフレームとの差（経過時間）を求めるのに使います

## reset() と updateHud()

`reset()` を書きかえて、その **下** に `updateHud()` を追加します。

```js:game.js
  function reset() {
    tiles = []; nextRow = 0;
    scroll = -rowH * 0.6; // 最初のタイルが下から少し上に見える
    speed = 1.5;
    while (nextRow < ROWS + 3) addRow();
    tiles[0].start = true;
    updateHud();
  }

  function updateHud() {
    speedEl.textContent = 'x' + (speed / 1.5).toFixed(1);
  }
```

`updateHud()` は画面上部の表示（HUD）をまとめて書きかえる関数です。最初の速さ 1.5 を「x1.0」として、何倍になったかを表示します。`toFixed(1)` は小数点以下1けたの文字列にするメソッドです。

## start() を書きかえる

`draw();` の行を消して、かわりに `lastT = performance.now();` を入れます。

```js:game.js
  function start() {
    reset();
    state = 'play';
    overlay.classList.add('hidden');
    msg('いちばん下のタイルからタップ！');
    lastT = performance.now();
  }
```

`performance.now()` は、ページを開いてからの時間をミリ秒（1/1000 秒）で返します。スタートした瞬間の時刻を覚えておき、最初のフレームでいきなり大きく進まないようにします。

## update() でタイルを流す

`start()` の **下** に追加します。

```js:game.js
  // ---------- loop ----------
  function update(dt) {
    if (state === 'play') {
      scroll += speed * rowH * dt;
      // 画面外を削除・補充
      while (tiles.length && tileTop(tiles[0]) > H + rowH && tiles[0].st !== 'pending') tiles.shift();
      while (tileBottom(tiles[tiles.length - 1]) > -rowH * 2) addRow();
    }
  }
```

### 経過時間 dt で進める

`dt` は前のフレームからの経過時間（秒）です。`scroll` を「速さ × 1行の高さ × 経過時間」だけ増やすと、**1秒あたり `speed` 行** 進みます。

フレームごとに決まった量（たとえば 5px）ずつ進めると、画面の書きかえ回数が多い端末（120Hz のスマホなど）では2倍速く流れてしまいます。経過時間をかけておけば、どんな端末でも同じ速さになります。

### 片づけと補充

- `tiles.shift()` は配列の **先頭** を取りのぞくメソッドです。いちばん下のタイルが画面の下にすっかり出て（上端が `H + rowH` より下）、しかも叩き終わっていれば消します。`st !== 'pending'` の条件は、ステップ6の「見逃し判定」で、まだ叩いていないタイルを消さないためです
- いちばん上のタイル（配列の最後）の下端が、画面の上から2行分より下まで来たら、`addRow()` で上に新しいタイルを足します。画面の上にいつも数枚の「控え」があるので、とぎれずに流れます

> [!NOTE]
> このステップではまだ叩けないので、タイルはどれも `'pending'` のままです。そのため下に流れたタイルは片づけられずに配列に残りますが、画面の外は描かないので見た目は問題ありません。ステップ5で叩けるようにすると、ちゃんと片づくようになります。

## loop() でくり返す

`draw()` の **下** に `loop()` を追加し、ファイルの最後を書きかえます。

```js:game.js
  function loop(now) {
    const dt = Math.min(0.05, (now - lastT) / 1000 || 0);
    lastT = now;
    update(dt);
    draw(now);
    requestAnimationFrame(loop);
  }

  resize();
  reset();
  requestAnimationFrame((t) => { lastT = t; loop(t); });
})();
```

### requestAnimationFrame

`requestAnimationFrame(関数)` は「次に画面を書きかえる直前に、この関数を呼んで」とブラウザにたのむ命令です。`loop()` の最後で自分自身をまたたのむので、1秒に約60回（画面のなめらかさに合わせて）`loop()` が呼ばれつづけます。呼ばれるときに、そのときの時刻 `now` が渡されます。

- `(now - lastT) / 1000` で、前のフレームからの経過時間を秒にします
- `Math.min(0.05, ...)` で、最大 0.05 秒に制限します。ほかのタブを見ていてループが止まっていたあとに戻ると、経過時間が何秒にもなってタイルが一気にワープしてしまうからです
- `|| 0` は、計算結果が `NaN`（数ではない）になったときに 0 にする保険です

`draw(now)` に時刻を渡すようになったので、背景の星もちらちらまたたき始めます。

> [!CHECK] 動作チェック
> - タイトル画面の後ろで、背景の星がゆっくりまたたいている
> - スタートを押すと、START のタイルを先頭にタイルが上から下へ一定の速さで流れていく
> - 流れても上からタイルがとぎれずに補充される
> - 右上の表示は「x1.0」のまま
