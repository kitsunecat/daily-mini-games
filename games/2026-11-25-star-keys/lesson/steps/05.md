## このステップのゴール

タイルを **叩けるように** します。スマホではレーンをタップ、PC ではクリックか **D・F・J・K** キーで叩きます。叩けるのは **いちばん下のまだ叩いていないタイル** だけ。正しく叩くとタイルがうすい色に変わり、黄色い輪が広がり、スコアが増え、少しずつ速くなります。

## 定数と変数を追加する

`const ROWS = 4; // visible rows` の **下** に、キーとレーンの対応表を追加します。

```js:game.js
  const KEYS = { d: 0, f: 1, j: 2, k: 3 };
```

D が左から1本目（0）、F が2本目……です。キーボードのホームポジションに指を置いたまま押せる4つのキーを選んでいます。

`const speedEl = ...` の行と、`let` の行を書きかえます。

```js:game.js
  const scoreEl = $('score'), speedEl = $('speed'), msgEl = $('msg');
```

```js:game.js
  let tiles = [], nextRow = 0, scroll = 0, speed = 0, score = 0, hits = 0;
  let state = 'title', lastT = 0;
  let effects = [], bgStars = [];
```

- `score` … 得点。`hits` … 叩いたタイルの枚数（スピードやスターの計算に使います）
- `effects` … 叩いたときに広がる輪などのエフェクトの配列

## タイルに flash を足す

`addRow()` の `tiles.push(...)` の行を書きかえます。

```js:game.js
    tiles.push({ lane, row: nextRow, len, st: 'pending', flash: 0 });
```

`flash` は叩いた直後に明るく光らせるための値（1 → 0 へ減っていく）です。

## いちばん下の未処理タイルを探す

`const tileTop = ...` の **下** に追加します。

```js:game.js
  function lowestPending() {
    for (const t of tiles) if (t.st === 'pending') return t;
    return null;
  }
```

`tiles` は下から順に並んでいるので、前から見ていって最初に見つかった `'pending'` のタイルが「いちばん下の、まだ叩いていないタイル」です。

## reset() と updateHud() を書きかえる

`reset()` の1行目と、`updateHud()` を書きかえます。

```js:game.js
    tiles = []; nextRow = 0; score = 0; hits = 0; effects = [];
```

```js:game.js
  function updateHud() {
    scoreEl.textContent = score;
    speedEl.textContent = 'x' + (speed / 1.5).toFixed(1);
  }
```

## 入力の処理

`startBtn.addEventListener('click', start);` の **上** に追加します。

```js:game.js
  // ---------- input ----------
  function press(lane, id) {
    if (state !== 'play') return;
    const t = lowestPending();
    if (!t) return;
    if (t.lane !== lane || tileTop(t) > H) {
      // 空振り（ステップ6でゲームオーバーにする）
      return;
    }
    hits++;
    t.st = 'hit'; t.flash = 1;
    score += 1;
    effects.push({ x: (lane + 0.5) * laneW, y: (tileBottom(t) + tileTop(t)) / 2, r: 10, a: 1 });
    // 加速
    speed = Math.min(6.5, 1.5 + hits * 0.035);
    updateHud();
  }

  function laneFromX(clientX) {
    const r = cv.getBoundingClientRect();
    return Math.max(0, Math.min(LANES - 1, Math.floor((clientX - r.left) / laneW)));
  }
  cv.addEventListener('pointerdown', (e) => {
    e.preventDefault();
    if (state !== 'play') return;
    try { cv.setPointerCapture(e.pointerId); } catch (err) { /* ignore */ }
    press(laneFromX(e.clientX), 'p' + e.pointerId);
  });

  window.addEventListener('keydown', (e) => {
    const k = e.key.toLowerCase();
    if (state !== 'play') return;
    if (k in KEYS) {
      e.preventDefault();
      if (!e.repeat) press(KEYS[k], 'k' + k);
    }
  });
```

### press(lane, id) … 叩いたときの判定

タップでもキーでも、最後はこの `press()` を呼びます。入力のしかたがちがっても **判定は1か所** にまとめておくと、あとで直すのが楽です。

1. いちばん下の未処理タイル `t` を探す
2. 叩いたレーンが `t` のレーンとちがえば **空振り**。今は何もせず `return` します（ステップ6でゲームオーバーにします）
3. 正しければ、`t.st = 'hit'` にしてスコアと `hits` を増やし、タイルのまん中にエフェクトの輪を1つ足す
4. `speed = Math.min(6.5, 1.5 + hits * 0.035)` で、1枚叩くごとに少しずつ速くする。`Math.min` で最大 6.5 までにおさえます

「画面の上の方にあるタイル」でも、いちばん下の未処理タイルなら叩けます。逆に `tileTop(t) > H`（タイルがもう画面の下に出てしまった）なら空振り扱いです。

2つ目の引数 `id` は「どの指・どのキーで押したか」の名前です。今は使いませんが、ステップ8の長押しで「離したのはどの指か」を知るために使います。

### pointer イベント

`pointerdown` はマウスのクリック・指のタッチ・ペンを **まとめて** 受け取れるイベントです。

- `e.clientX` は押した場所の x 座標（ページの左端から）。`getBoundingClientRect()` で Canvas の左端を引いて Canvas の中の x にし、`laneW` で割って切り捨てれば、レーン番号（0〜3）になります
- `e.preventDefault()` は、スマホでタップしたときの拡大やマウスの文字選択など、ブラウザがもともとやる動作を止めます
- `setPointerCapture` は「この指を離すまで、指が Canvas の外に出てもイベントをこっちに送って」という設定です。ステップ8の長押しで、指を離したことを確実に受け取るために入れておきます
- `e.pointerId` は指ごとにちがう番号です。2本指で同時に押すとちがう番号になります

### キーボード

- `e.key.toLowerCase()` で、Shift や CapsLock が入っていても小文字で比べられるようにします
- `k in KEYS` は「`KEYS` に `k` という名前があるか」を調べる書き方です
- キーを押しっぱなしにすると `keydown` がくり返し届きます。そのときは `e.repeat` が `true` なので、無視して連打あつかいにならないようにします

## update() と draw() を書きかえる

`update()` の `scroll += ...` の行の **下** に、光を弱めていく処理を足します。

```js:game.js
      scroll += speed * rowH * dt;
      for (const t of tiles) {
        if (t.flash > 0) t.flash = Math.max(0, t.flash - dt * 3);
      }
```

`update()` の最後（`if (state === 'play') { ... }` の閉じかっこの **下**）に、エフェクトを動かす処理を足します。

```js:game.js
    for (const f of effects) { f.r += dt * 120; f.a -= dt * 2; }
    effects = effects.filter((f) => f.a > 0);
```

輪の半径 `r` を1秒に 120px ずつ広げ、不透明度 `a` を1秒に 2 ずつ減らします（0.5 秒で消える）。`filter` で、見えなくなったエフェクトを配列から取りのぞきます。

`draw()` のタイルを描く `for` の中、`const x = ...` の行の **下** に、叩いたタイルの描き方を足します。

```js:game.js
      const x = t.lane * laneW + pad, w = laneW - pad * 2, h = y1 - y0 - pad * 2;
      if (t.st === 'hit') {
        ctx.fillStyle = `rgba(150,160,220,${0.25 + t.flash * 0.5})`;
        roundRect(x, y0 + pad, w, h, 6); ctx.fill();
        continue;
      }
```

叩いたタイルはうすい青紫でぬり、`continue` でその先（黒いタイルの描画）を飛ばします。叩いた直後は `flash` が 1 なので不透明度 0.75、だんだん 0.25 まで薄くなります。

`draw()` の最後、タイルの `for` の閉じかっこの **下** に、エフェクトの描画を足します。

```js:game.js
    // エフェクト
    for (const f of effects) {
      ctx.globalAlpha = Math.max(0, f.a);
      ctx.strokeStyle = '#ffd56b'; ctx.lineWidth = 3;
      ctx.beginPath(); ctx.arc(f.x, f.y, f.r, 0, Math.PI * 2); ctx.stroke();
    }
    ctx.globalAlpha = 1;
```

> - SCORE が 1 ずつ増え、何枚か叩くと右上の表示が「x1.1」「x1.2」…と増えて流れが速くなる
> - ちがうレーンを押しても、今はまだ何も起きない
> - 叩かずに見逃しても、今はそのまま流れていく
