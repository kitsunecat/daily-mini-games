## このステップのゴール

タイルを叩くたびに **メロディーが1音ずつ鳴る** ようにします。音声ファイルは使わず、ブラウザの **Web Audio API** で音をその場で作ります。あらかじめ用意したメロディーの音を順番に鳴らすので、テンポよく叩けば1曲を弾いているような気分になれます。ミスしたときには「ブー」という音も鳴らします。

## メロディーを数字で書く

`const KEYS = ...` の **下** に追加します。

```js:game.js
  // オリジナルのメロディー（MIDI ノート番号）。和音の根音を添えて鳴らす
  const MELODY = [
    72, 74, 76, 79, 76, 74, 72, 67, 69, 72, 74, 76, 74, 72, 69, 67,
    65, 67, 69, 72, 69, 67, 65, 64, 62, 64, 65, 67, 69, 71, 72, 74,
    76, 79, 81, 79, 76, 74, 76, 72, 74, 76, 74, 72, 71, 69, 71, 72,
    69, 72, 76, 74, 72, 69, 67, 64, 65, 69, 72, 71, 67, 71, 74, 72,
  ];
  const BASS = [48, 48, 45, 45, 41, 41, 43, 43, 48, 48, 45, 45, 41, 43, 48, 48];
```

音の高さは **MIDI ノート番号** という数字で書いています。ピアノの鍵盤に通し番号をふったもので、**60 がまん中のド**、1 増えるごとに半音（となりの鍵盤）上がります。

- 60 ド、62 レ、64 ミ、65 ファ、67 ソ、69 ラ、71 シ、72 高いド
- 12 増えると1オクターブ上（72 は 60 の1オクターブ上のド）

`MELODY` は64音の主旋律、`BASS` は低い伴奏の音です。

## 変数を追加する

`let tiles = ...` の行の最後に `noteIdx` を足します。次に鳴らすのが `MELODY` の何番目かを数えます。

```js:game.js
  let tiles = [], nextRow = 0, scroll = 0, speed = 0, score = 0, hits = 0, noteIdx = 0;
```

`reset()` の1行目にも `noteIdx = 0;` を足して、毎回曲の頭から鳴らします。

```js:game.js
    tiles = []; nextRow = 0; score = 0; hits = 0; noteIdx = 0; effects = [];
```

## 音を鳴らす関数

`let effects = [], bgStars = [];` の **下** に追加します。

```js:game.js
  // ---------- audio ----------
  let ac = null;
  function audio() {
    if (!ac) {
      try { ac = new (window.AudioContext || window.webkitAudioContext)(); } catch (e) { ac = null; }
    }
    if (ac && ac.state === 'suspended') ac.resume();
    return ac;
  }
  const freq = (m) => 440 * Math.pow(2, (m - 69) / 12);
  function tone(m, dur, vol, type) {
    const a = audio();
    if (!a) return null;
    const t = a.currentTime;
    const o = a.createOscillator(), o2 = a.createOscillator(), g = a.createGain();
    o.type = type || 'triangle'; o2.type = 'sine';
    o.frequency.value = freq(m); o2.frequency.value = freq(m) * 2;
    const g2 = a.createGain(); g2.gain.value = 0.25;
    o.connect(g); o2.connect(g2); g2.connect(g); g.connect(a.destination);
    g.gain.setValueAtTime(0.0001, t);
    g.gain.exponentialRampToValueAtTime(vol, t + 0.01);
    g.gain.exponentialRampToValueAtTime(0.0001, t + dur);
    o.start(t); o2.start(t); o.stop(t + dur + 0.05); o2.stop(t + dur + 0.05);
    return g;
  }
  function playNote(long) {
    const m = MELODY[noteIdx % MELODY.length];
    tone(m, long ? 1.4 : 0.7, 0.28);
    if (noteIdx % 2 === 0) tone(BASS[(noteIdx / 4 | 0) % BASS.length], 1.0, 0.14, 'sine');
    noteIdx++;
  }
  function playFail() {
    tone(40, 0.6, 0.3, 'sawtooth');
    tone(41, 0.6, 0.2, 'sawtooth');
  }
```

### AudioContext … 音の作業台

Web Audio API では、まず `AudioContext`（音の作業台）を1つ作り、その上で「音を出す部品」と「音量を変える部品」をケーブルでつなぐように組み立てます。

ブラウザは、**ユーザーがタップやクリックをする前に音を鳴らすことを禁止** しています。そこで `audio()` は、最初に呼ばれたときに作業台を作り、止まっている（`'suspended'`）ときは `resume()` で動かします。スタートボタンを押したときに一度呼んでおけば、そのあとは音が鳴らせます。古い Safari のために `webkitAudioContext` も試し、どちらも無い環境では `null` のまま（音なし）で遊べるようにしています。

### freq() … ノート番号を周波数に

MIDI の 69 番（ラ）は 440Hz と決まっていて、半音上がるごとに周波数が 2 の 12 乗根倍（約 1.059 倍）になります。12 半音でちょうど 2 倍、つまり1オクターブ上です。これを式にしたのが `440 * Math.pow(2, (m - 69) / 12)` です。

### tone() … 1音を鳴らす

- `createOscillator()` は一定の高さの音を出し続ける部品（発振器）です。`type` で音色を選びます。`'sine'`（サイン波）は丸くやわらかい音、`'triangle'`（三角波）は少しオルゴールっぽい音、`'sawtooth'`（のこぎり波）はジーッという硬い音です
- 1オクターブ上（周波数 2 倍）のサイン波 `o2` を小さめ（0.25 倍）に重ねて、音に明るさを足しています
- `createGain()` は音量のつまみです。`o → g → スピーカー（a.destination）` とつなぎます
- `exponentialRampToValueAtTime` で、0.01 秒でぱっと大きくして、`dur` 秒かけてすーっと小さくします。ピアノのように「ポーン」と減衰する音になります（指数カーブは 0 にできないので、0 のかわりに 0.0001 を使います）
- `o.start(t)` で鳴らし始め、`o.stop(...)` で止める時刻を予約します。止めた発振器は自動で片づけられます

### playNote() … 次の音を鳴らす

`MELODY[noteIdx % MELODY.length]` で次の音を選びます。`%`（割った余り）を使うので、64音を鳴らし終わるとまた最初にもどってループします。2音に1回、低い伴奏の音（`BASS`）も重ねます。`noteIdx / 4 | 0` は「4 で割って小数を切り捨て」で、4音ごとに伴奏の音が1つ進みます。引数 `long` が `true` なら音を長くのばします（ステップ8の長いタイル用）。

### playFail() … ミスの音

とても低い音（40 と 41）を、のこぎり波で同時に鳴らします。半音ちがいの音を重ねると、にごった「ブー」という音になります。

## 音を鳴らすタイミング

`press()` の中、`score += 1;` の **下** に足します。

```js:game.js
    score += 1;
    playNote(t.len > 1);
```

`start()` の1行目に `audio();` を足して、スタートボタンを押した瞬間に音の作業台を準備します。

```js:game.js
  function start() {
    audio();
    reset();
```

`fail()` に `playFail();` を足します。

```js:game.js
  function fail(info) {
    state = 'fail';
    failInfo = info; failTimer = 0;
    playFail();
  }
```

> [!CHECK] 動作チェック
> - タイルを叩くたびに「ポーン」と音が鳴り、続けて叩くとメロディーになっている（音が出ないときはマナーモードや音量を確認）
> - 2音に1回、低い伴奏の音が重なる
> - 空振りや見逃しのときに「ブー」という低い音が鳴る
> - 「もう一度」で始めると、メロディーが最初から鳴る
