## このステップのゴール

ゲームの絵を描く **Canvas（キャンバス）** を準備して、うすい紫の背景・ちらちらした小さな星・4本のレーンを分ける線を描きます。スマホの高解像度画面でもぼやけないように描くコツと、画面サイズが変わったときに描きなおすしくみも作ります。

## Canvas とは

`<canvas>` は、JavaScript から絵を描ける「お絵かき用の板」です。`cv.getContext('2d')` で取り出した **コンテキスト**（ここでは `ctx`）に、「この色で四角をぬって」「ここに丸を描いて」と命令して絵を描きます。

- `ctx.fillStyle = '色'` → ぬりつぶす色を決める
- `ctx.fillRect(x, y, 幅, 高さ)` → 四角をぬる
- `ctx.beginPath()` → `ctx.arc(x, y, 半径, 0, Math.PI * 2)` → `ctx.fill()` → 丸をぬる
- `ctx.moveTo(x, y)` → `ctx.lineTo(x, y)` → `ctx.stroke()` → 線を引く

座標は **左上が (0, 0)**、右に行くほど x が、**下に行くほど y が大きく** なります。

## 定数と変数を追加する

`'use strict';` の **下** に、レーン数と画面に見える行数を追加します。

```js:game.js
  const LANES = 4;
  const ROWS = 4; // visible rows
```

`const $ = ...` の行の **下** を、次のように書きかえます（`cv` と `ctx` を足します）。

```js:game.js
  const $ = (id) => document.getElementById(id);
  const cv = $('cv');
  const ctx = cv.getContext('2d');
  const msgEl = $('msg');
  const overlay = $('overlay'), startBtn = $('start');

  let W = 0, H = 0, dpr = 1, laneW = 0, rowH = 0;
  let bgStars = [];
```

- `W`・`H` は Canvas の見た目の幅と高さ（CSS ピクセル）です
- `laneW` は1レーンの幅、`rowH` は1行（タイル1枚分）の高さです。画面を **横に4つ・縦に4つ** に区切るので、`laneW = W / 4`、`rowH = H / 4` になります
- `bgStars` は背景にちらす小さな星の配列です

## resize() で Canvas の大きさを合わせる

`let bgStars = [];` の **下** に追加します。

```js:game.js
  // ---------- layout ----------
  function resize() {
    const r = cv.getBoundingClientRect();
    dpr = Math.min(window.devicePixelRatio || 1, 2);
    W = Math.max(1, r.width); H = Math.max(1, r.height);
    cv.width = Math.round(W * dpr); cv.height = Math.round(H * dpr);
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
    laneW = W / LANES; rowH = H / ROWS;
    bgStars = Array.from({ length: 40 }, () => ({ x: Math.random() * W, y: Math.random() * H, r: Math.random() * 1.4 + 0.3, p: Math.random() * 6 }));
    draw();
  }
  window.addEventListener('resize', resize);
```

### 見た目の大きさと、中の解像度

Canvas には大きさが2つあります。

- **見た目の大きさ** … CSS で決まる。今回は `#stage` いっぱい
- **中の解像度** … `cv.width`・`cv.height` で決まる。何ピクセルの絵を描くか

この2つがずれていると、絵が引きのばされてぼやけます。そこで `getBoundingClientRect()` で見た目の大きさを測り、中の解像度をそれに合わせます。

さらにスマホの画面は、CSS の 1 ピクセルに実際の画素が 2〜3 個つまっています。この倍率が `window.devicePixelRatio`（`dpr`）です。中の解像度を `W * dpr` にして、`ctx.setTransform(dpr, 0, 0, dpr, 0, 0)` で「全部 `dpr` 倍して描く」と設定しておくと、**座標は CSS ピクセルのまま考えられて、しかもくっきり** 描けます。大きすぎると重くなるので、`Math.min(..., 2)` で最大 2 倍にしています。

### 背景の星

`Array.from({ length: 40 }, () => ({ ... }))` は「40個の要素を持つ配列を、関数の返す値で作る」書き方です。星ごとに位置 `x`・`y`、半径 `r`、ちらちらのタイミングをずらすための `p`（位相）をランダムに決めています。

`window.addEventListener('resize', resize)` で、画面の向きを変えたりウィンドウの大きさを変えたときにも測りなおします。

## draw() で背景とレーンを描く

`function start() { ... }` の **下** に追加し、ファイルのいちばん最後 `})();` の **直前** に `resize();` を足します。

```js:game.js
  function draw(now) {
    const time = (now || 0) / 1000;
    // 背景
    const g = ctx.createLinearGradient(0, 0, 0, H);
    g.addColorStop(0, '#2a2f6b'); g.addColorStop(1, '#f0e9ff');
    ctx.fillStyle = '#f4f1ff';
    ctx.fillRect(0, 0, W, H);
    ctx.globalAlpha = 0.18; ctx.fillStyle = g; ctx.fillRect(0, 0, W, H); ctx.globalAlpha = 1;
    for (const s of bgStars) {
      ctx.globalAlpha = 0.25 + 0.2 * Math.sin(time * 2 + s.p);
      ctx.fillStyle = '#7b86d8';
      ctx.beginPath(); ctx.arc(s.x, s.y, s.r, 0, Math.PI * 2); ctx.fill();
    }
    ctx.globalAlpha = 1;
    // レーン線
    ctx.strokeStyle = 'rgba(90,100,170,.25)'; ctx.lineWidth = 1;
    for (let i = 1; i < LANES; i++) {
      ctx.beginPath(); ctx.moveTo(i * laneW + 0.5, 0); ctx.lineTo(i * laneW + 0.5, H); ctx.stroke();
    }
  }

  resize();
})();
```

- `createLinearGradient(0, 0, 0, H)` は上から下へのグラデーションです。うすい紫でぬったうえに、`globalAlpha = 0.18`（不透明度 18%）で重ねて、上がほんのり暗い空にしています
- `globalAlpha` は「このあと描くものの不透明度」です。使い終わったら **必ず 1 にもどします**。もどし忘れると、あとで描くものが全部うすくなります
- 星の不透明度は `Math.sin(time * 2 + s.p)` で時間とともに上下させます。星ごとに `p` がちがうので、ばらばらにまたたきます（このステップでは `now` を渡していないので止まっています。ステップ4で動き出します）
- レーン線の x 座標に `+ 0.5` しているのは、1 ピクセルの線を画素のちょうどまん中に置いて、にじまずくっきり見せるためです

> [!CHECK] 動作チェック
> - スタートを押すと、うすい紫の背景に小さな星が散らばり、縦線で4つのレーンに区切られている
> - ブラウザの幅を変えたり、スマホを横にしたりしても、線がレーンの境目に描きなおされる
> - Console にエラーが出ていない
