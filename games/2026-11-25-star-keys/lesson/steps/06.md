## このステップのゴール

ミスをしたら **ゲームオーバー** にします。ミスは2種類です。

- **空振り** … タイルの無いレーン（いちばん下のタイルとちがうレーン）を押した。押した場所が赤く点滅する
- **見逃し** … いちばん下のタイルを叩かないまま、画面の下まで流してしまった。譜面が少し **巻きもどって**、見逃したタイルが赤く点滅する

どちらも1秒ほど「どこでミスしたか」を見せてから、ゲームオーバー画面を出します。「もう一度」で何回でも遊びなおせます。

## 変数を追加・変更する

`const overlay = ...` の行と、`let state = ...` の行を書きかえます。

```js:game.js
  const overlay = $('overlay'), ovTitle = $('ov-title'), ovText = $('ov-text'), startBtn = $('start');
```

```js:game.js
  let state = 'title', lastT = 0, failInfo = null, failTimer = 0;
```

- `failInfo` … どんなミスをしたかの記録。空振りなら `{ lane, y, miss: true }`（押した場所）、見逃しなら `{ tile }`（見逃したタイル）を入れます
- `failTimer` … ミスしてからの経過時間（秒）。点滅とゲームオーバーまでの待ち時間に使います

ゲームの状態 `state` は、`'title'` → `'play'` → `'fail'`（ミスを見せている1秒間）→ `'over'`（ゲームオーバー画面）と進みます。

`reset()` の1行目の **下** に1行足します。

```js:game.js
    tiles = []; nextRow = 0; score = 0; hits = 0; effects = [];
    failInfo = null;
```

## press() の空振りを書きかえる

`press()` の中、空振りのところを書きかえます。

```js:game.js
    if (t.lane !== lane || tileTop(t) > H) {
      // 空振り
      fail({ lane, y: Math.min(H - rowH, Math.max(0, tileBottom(t) - rowH)), miss: true });
      return;
    }
```

空振りした場所を赤くするために、押したレーンと y 座標を記録します。y は「いちばん下のタイルと同じ高さ」にして、`Math.max(0, ...)` と `Math.min(H - rowH, ...)` で画面の中におさめます。こうすると「ここにあるタイルを押すべきだった」のと同じ高さに赤い四角が出ます。

## fail() と gameOver()

`start()` の **下** に追加します。

```js:game.js
  function fail(info) {
    state = 'fail';
    failInfo = info; failTimer = 0;
  }

  function gameOver() {
    state = 'over';
    ovTitle.textContent = 'ゲームオーバー';
    ovText.innerHTML = `スコア <b class="hl">${score}</b><br>タップしたタイル ${hits} 枚`;
    startBtn.textContent = 'もう一度';
    overlay.classList.remove('hidden');
  }
```

- `fail()` はすぐにゲームオーバー画面を出さず、状態を `'fail'` にしてミスの情報を覚えるだけです。1秒後に `update()` から `gameOver()` を呼びます
- `gameOver()` はタイトル画面と同じオーバーレイを使い回して、見出し・本文・ボタンの文字を書きかえてから表示します。`innerHTML` を使うと `<b>` や `<br>` のタグも反映されます
- ボタンは同じ `start()` を呼ぶので、`reset()` で全部作りなおして最初から遊べます

## update() に見逃し判定とミス演出を足す

`update()` 全体を次のようにします。

```js:game.js
  function update(dt) {
    if (state === 'play') {
      scroll += speed * rowH * dt;
      for (const t of tiles) {
        if (t.flash > 0) t.flash = Math.max(0, t.flash - dt * 3);
      }
      // 見逃し
      const lp = lowestPending();
      if (lp && tileBottom(lp) > H + 2) {
        fail({ tile: lp });
      }
      // 画面外を削除・補充
      while (tiles.length && tileTop(tiles[0]) > H + rowH && tiles[0].st !== 'pending') tiles.shift();
      while (tileBottom(tiles[tiles.length - 1]) > -rowH * 2) addRow();
    } else if (state === 'fail') {
      failTimer += dt;
      if (failInfo.tile) {
        // 見逃したタイルが見える位置まで戻す
        const target = failInfo.tile.row * rowH + failInfo.tile.len * rowH - rowH * 1.1;
        scroll += (target - scroll) * Math.min(1, dt * 10);
      }
      if (failTimer > 1.0) gameOver();
    }
    for (const f of effects) { f.r += dt * 120; f.a -= dt * 2; }
    effects = effects.filter((f) => f.a > 0);
  }
```

### 見逃し判定

いちばん下の未処理タイルの **下端が画面の下より下**（`H + 2`）に出たら見逃しです。たった2行で書けるのは、「判定するのはいちばん下の1枚だけ」と決めているおかげです。

### 巻きもどし

見逃したタイルは画面の外に出かかっているので、そのままでは見えません。そこで `scroll` を「見逃したタイルの上端が、画面の下から 1.1 行分のところに来る値」（`target`）へ近づけます。

`scroll += (target - scroll) * Math.min(1, dt * 10)` は「残りの距離の一定割合ずつ近づく」書き方で、最初は速く、目標に近づくほどゆっくりになる、なめらかな動きになります。

## draw() に赤い点滅を足す

タイルを描く `for` の中を書きかえます。`const x = ...` の行から `ctx.fillStyle = tg;` の行までを、次のようにします。

```js:game.js
      const x = t.lane * laneW + pad, w = laneW - pad * 2, h = y1 - y0 - pad * 2;
      const missed = failInfo && failInfo.tile === t;
      if (t.st === 'hit') {
        ctx.fillStyle = `rgba(150,160,220,${0.25 + t.flash * 0.5})`;
        roundRect(x, y0 + pad, w, h, 6); ctx.fill();
        continue;
      }
      const blink = missed && Math.floor(failTimer * 8) % 2 === 0;
      const tg = ctx.createLinearGradient(0, y0, 0, y1);
      if (blink) { tg.addColorStop(0, '#ff5a6e'); tg.addColorStop(1, '#c42c46'); }
      else { tg.addColorStop(0, '#2b2f55'); tg.addColorStop(1, '#14172e'); }
      ctx.fillStyle = tg;
```

`Math.floor(failTimer * 8) % 2 === 0` は、1/8 秒ごとに `true` と `false` が入れかわる式です。見逃したタイルを、赤と黒で点滅させます。

タイルの `for` の **下**、`// エフェクト` の **上** に、空振りの表示を足します。

```js:game.js
    // 空振り表示
    if (failInfo && failInfo.miss && state !== 'play') {
      const blink = Math.floor(failTimer * 8) % 2 === 0;
      if (blink || state === 'over') {
        ctx.fillStyle = 'rgba(255,90,110,.85)';
        roundRect(failInfo.lane * laneW + pad, failInfo.y + pad, laneW - pad * 2, rowH - pad * 2, 6); ctx.fill();
      }
    }
```

空振りした場所に赤い四角を点滅させます。ゲームオーバー画面になったら（`state === 'over'`）点けっぱなしにして、オーバーレイの後ろにうっすら見えるようにします。

> [!CHECK] 動作チェック
> - プレイ中にタイルの無いレーンを押すと、押した場所が赤く点滅し、約1秒後に「ゲームオーバー」とスコア・叩いた枚数が出る
> - タイルを叩かずに流すと、譜面が少し巻きもどって見逃したタイルが赤く点滅し、約1秒後にゲームオーバーになる
> - 「もう一度」を押すと、SCORE 0・x1.0 の新しい譜面で始まる
