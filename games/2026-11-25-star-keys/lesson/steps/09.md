## このステップのゴール

ゲームとして仕上げます。

- 40枚叩くごとに、左上の **スター** が1つずつ光る（最大3つ）
- **ハイスコア** をブラウザに保存して、BEST に表示する。更新したらゲームオーバー画面に「ベスト更新！」
- ゲームオーバー画面に、獲得したスターを ★☆ で表示する
- PC では Enter / スペースキーでもスタート・リトライできる
- ミスしたときにスマホを短く振動させる

これで完成品の「ほしふるけんばん」と同じになります。

## 定数と変数を追加する

`const KEYS = ...` の **下** に、ハイスコアを保存する名前を追加します。

```js:game.js
  const BEST_KEY = 'star-keys-best';
```

`const scoreEl = ...` の行を書きかえ、`const overlay = ...` の行の **下** にスターの要素を取り出す行を足します。

```js:game.js
  const scoreEl = $('score'), bestEl = $('best'), speedEl = $('speed'), msgEl = $('msg');
  const overlay = $('overlay'), ovTitle = $('ov-title'), ovText = $('ov-text'), startBtn = $('start');
  const starEls = [...document.querySelectorAll('#stars i')];
```

`querySelectorAll` は条件に合う要素を全部返します。返ってくるのは配列に似た「NodeList」なので、`[...]`（スプレッド構文）で本物の配列にしておきます。

`let state = ...` の行に `best` を足します。

```js:game.js
  let state = 'title', best = 0, lastT = 0, failInfo = null, failTimer = 0;
```

`const holds = new Map(); ...` の行の **下** に、保存されたハイスコアを読みこむ処理を足します。

```js:game.js
  try { best = parseInt(localStorage.getItem(BEST_KEY), 10) || 0; } catch (e) { best = 0; }
  bestEl.textContent = best;
```

### localStorage

`localStorage` は、ブラウザにちょっとしたデータを **ページを閉じても残る** 形で保存できるしくみです。

- `localStorage.setItem('名前', '文字列')` で保存
- `localStorage.getItem('名前')` で読み出し。まだ保存していなければ `null`

保存できるのは文字列だけなので、読み出したら `parseInt(..., 10)` で数に直します。`null` を `parseInt` すると `NaN` になるので、`|| 0` で 0 にします。プライベートブラウズなどで `localStorage` が使えないとエラーになることがあるので、`try { ... } catch (e) { ... }` で包んで、エラーでもゲームが止まらないようにします。

## スターを光らせる

`updateHud()` を書きかえます。

```js:game.js
  function updateHud() {
    scoreEl.textContent = score;
    speedEl.textContent = 'x' + (speed / 1.5).toFixed(1);
    const stars = Math.min(3, Math.floor(hits / 40));
    starEls.forEach((s, i) => s.classList.toggle('on', i < stars));
  }
```

`classList.toggle('on', 条件)` は、条件が `true` ならクラスをつけ、`false` なら外します。スターが2つなら、0番目と1番目の星にだけ `on` がつき、CSS で黄色く光ります。

`press()` の中、`speed = Math.min(...)` の行の **下** に、スターを取ったときのメッセージを足します。

```js:game.js
    speed = Math.min(6.5, 1.5 + hits * 0.035);
    if (hits > 0 && hits % 40 === 0 && hits <= 120) msg('★ スター獲得！ どんどん速くなるよ');
```

## Enter / スペースでスタート

`keydown` の中の `if (state !== 'play') return;` を書きかえます。

```js:game.js
    if (state !== 'play') {
      if ((k === 'enter' || k === ' ') && !overlay.classList.contains('hidden')) { e.preventDefault(); start(); }
      return;
    }
```

オーバーレイが出ている（タイトル画面かゲームオーバー画面）ときだけ、Enter かスペースで `start()` します。`e.key` はスペースキーのとき `' '`（空白1文字）になります。`'fail'` の1秒間はオーバーレイが出ていないので、うっかり連打してもすぐにはリトライされません。

## ミスで振動させる

`fail()` の最後に1行足します。

```js:game.js
  function fail(info) {
    state = 'fail';
    failInfo = info; failTimer = 0;
    playFail();
    if (navigator.vibrate) { try { navigator.vibrate(120); } catch (e) { /* ignore */ } }
  }
```

`navigator.vibrate(ミリ秒)` で端末を振動させます。対応していないブラウザ（iPhone の Safari や PC など）では `navigator.vibrate` が無いので、`if` で確かめてから呼びます。

## gameOver() を仕上げる

`gameOver()` 全体を次のようにします。

```js:game.js
  function gameOver() {
    state = 'over';
    let isBest = false;
    if (score > best) {
      best = score; isBest = true;
      try { localStorage.setItem(BEST_KEY, String(best)); } catch (e) { /* ignore */ }
      bestEl.textContent = best;
    }
    ovTitle.textContent = 'ゲームオーバー';
    const stars = Math.min(3, Math.floor(hits / 40));
    ovText.innerHTML = `スコア <b class="hl">${score}</b>${isBest ? '（ベスト更新！）' : ''}<br>` +
      `タップしたタイル ${hits} 枚 / スター ${'★'.repeat(stars)}${'☆'.repeat(3 - stars)}`;
    startBtn.textContent = 'もう一度';
    overlay.classList.remove('hidden');
    msg('ベスト: ' + best);
  }
```

- スコアがハイスコアをこえたら、`best` を更新して `localStorage` に保存し、BEST の表示も書きかえます
- `条件 ? A : B` は「条件が true なら A、そうでなければ B」という式です。ベストを更新したときだけ「（ベスト更新！）」を足します
- `'★'.repeat(n)` は文字を n 回くり返した文字列を作ります。取ったスターを ★、取れなかったスターを ☆ で並べます

> [!CHECK] 動作チェック
> - 40枚叩くと左上の星が1つ黄色く光り、「★ スター獲得！ どんどん速くなるよ」と出る
> - ゲームオーバーになると、スコア・叩いた枚数・★☆ が表示され、初回は「（ベスト更新！）」がつく。右上の BEST も更新される
> - ページを再読み込みしても BEST が残っている
> - PC ではタイトル画面やゲームオーバー画面で Enter かスペースを押すとスタートできる
> - Android のスマホでは、ミスしたときにブルッと振動する

これで完成です！ 元の「ほしふるけんばん」と同じように遊べるはずです。

## 改造アイデア

> [!TIP] 自分の好きな曲を弾く
> `MELODY` の数字を書きかえれば、好きなメロディーになります。60 がド、62 がレ、64 がミ……と、白い鍵盤は 2・2・1・2・2・2・1 ずつ増えます。音の長さも配列に入れて、長い音のところだけ長いタイルにすると、もっと「弾いている」感じになります。

> [!TIP] 1行に2枚のタイル（和音）
> ときどき同じ行に2枚のタイルを置き、両方を同時に押すと成功にしてみましょう。`lowestPending()` を「いちばん下の行のタイル全部」を返すように変えて、全部叩いたら次の行へ進むようにします。2つの音を重ねて鳴らすと和音になります。

> [!TIP] 制限時間モード
> 30 秒で何枚叩けるかを競うモードを作ってみましょう。`update()` で残り時間を減らし、0 になったら `gameOver()` を呼びます。スピードは一定にして、正確さと速さの勝負にするのもおすすめです。

> [!TIP] 叩くタイミングの判定
> 今はタイルが画面のどこにあっても叩けます。画面の下の方に「判定ライン」を描き、ラインに近いほど高得点（PERFECT / GOOD）にすると、リズムゲームらしさが増します。`tileBottom(t)` とラインの距離で判定できます。
