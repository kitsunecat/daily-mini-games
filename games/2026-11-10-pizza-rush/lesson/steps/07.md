## このステップのゴール

稼いだコインで **お店を育てる** しくみを作ります。床に点線の **強化パネル** を置き、コインが足りているときに店長がパネルの上に 0.6 秒立ち続けると、コインを払って強化できます。

- 左の「スピード」… 店長の足が速くなる（3段階）
- 右の「持てる数」… 一度に運べる枚数が 3 → 5 → 7 → 9 枚に増える（3段階）
- かまどの前の「かまど」… カギのかかったかまどが使えるようになる（2台）

## 定数

`const OVEN_Y = 528;` の **下** に追加します。

```js:game.js
  const OVEN_X = [70, 180, 290];
  const OVEN_Y = 528;
  const PAD_Y = 330;
  const SPEED_COST = [30, 70, 140];
  const CAP_COST = [40, 90, 180];
  const OVEN_COST = [0, 50, 120];
  const BAKE_TIME = 2.3, OVEN_MAX = 6, MAX_MISS = 3;
```

- `PAD_Y` は左右の強化パネルの y 座標です（キッチンのまん中あたり）
- `SPEED_COST`・`CAP_COST` は強化1回ごとの値段で、配列の長さが最大レベルになります。今のレベルを番号にして `SPEED_COST[S.p.speedLv]` と取り出します
- `OVEN_COST` はかまど1台ごとの値段です。`[0]`（左のかまど）は最初から使えるので使いません

## パネルの状態と値段

`newState()` の `xferT: 0,` の **下** に `pads` を追加し、`speed()` の **下** に `padCost()` を追加します。

```js:game.js
  function newState() {
    return {
      t: 0, coins: 0, score: 0, miss: 0,
      p: { x: 180, y: 300, stack: 0, speedLv: 0, capLv: 0, face: 1, bob: 0 },
      ovens: OVEN_X.map((x, i) => ({ x, open: i === 0, count: 1, timer: 0 })),
      slots: [null, null, null],
      leaving: [],
      spawnT: 1.2,
      xferT: 0,
      pads: [
        { kind: 'speed', x: 70, y: PAD_Y, w: 70, h: 56, hold: 0 },
        { kind: 'cap', x: 290, y: PAD_Y, w: 70, h: 56, hold: 0 },
        { kind: 'oven', idx: 1, x: OVEN_X[1], y: OVEN_Y - 40, w: 70, h: 40, hold: 0 },
        { kind: 'oven', idx: 2, x: OVEN_X[2], y: OVEN_Y - 40, w: 70, h: 40, hold: 0 },
      ],
      floats: [],
    };
  }
  const cap = () => 3 + S.p.capLv * 2;
  const speed = () => 125 + S.p.speedLv * 28;

  function padCost(pd) {
    if (pd.kind === 'speed') return S.p.speedLv < SPEED_COST.length ? SPEED_COST[S.p.speedLv] : null;
    if (pd.kind === 'cap') return S.p.capLv < CAP_COST.length ? CAP_COST[S.p.capLv] : null;
    return S.ovens[pd.idx].open ? null : OVEN_COST[pd.idx];
  }
```

- パネル1枚は `kind`（種類）・中心の `x, y`・大きさ `w, h`・乗っている時間 `hold` を持ちます。かまどのパネルは `idx` でどのかまどかを覚え、かまどの少し上（`OVEN_Y - 40`）に置きます
- `padCost(pd)` はそのパネルの **今の値段** を返します。もう強化できない（最大レベル・かまどが開いている）ときは `null` を返します。「値段がない」ことを `null` で表しておくと、あとで `cost !== null` だけで「まだ買えるか」を判断できます

## 乗って買う

`update()` の `// transfers` の **下**、`// customers` の **上** に追加します。

```js:game.js
      S.xferT = did ? 0.14 : 0;
    }

    // pads
    S.pads.forEach((pd) => {
      const cost = padCost(pd);
      const inside = Math.abs(p.x - pd.x) < pd.w / 2 && Math.abs(p.y - pd.y) < pd.h / 2 + 6;
      if (cost !== null && inside && S.coins >= cost) {
        pd.hold += dt;
        if (pd.hold >= 0.6) {
          pd.hold = 0;
          S.coins -= cost;
          if (pd.kind === 'speed') { p.speedLv++; float(pd.x, pd.y - 30, 'スピードUP!', '#2a7de1'); }
          else if (pd.kind === 'cap') { p.capLv++; float(pd.x, pd.y - 30, `${cap()}枚持てる!`, '#2a7de1'); }
          else { S.ovens[pd.idx].open = true; S.ovens[pd.idx].count = 1; float(pd.x, pd.y - 30, 'かまど追加!', '#2a7de1'); }
          beep(880, 0.1, 'triangle'); setTimeout(() => beep(1175, 0.14, 'triangle'), 90);
          hud();
        }
      } else pd.hold = Math.max(0, pd.hold - dt * 2);
    });

```

- `inside` はパネルの四角の中にいるかの判定です。中心からの x の差が幅の半分未満、y の差が高さの半分（＋少しのおまけ）未満なら中です
- 値段があって、中にいて、コインが足りていれば `hold` を増やします。0.6 秒たまったら買います
- **すぐに買わずに少し待つ** のは、通りがかっただけでうっかり買ってしまわないためです。外に出ると `hold` は 2 倍の速さで減っていきます（`Math.max(0, ...)` で 0 より下にはしません）
- 買ったらコインを引き、種類ごとにレベルを上げたりかまどを開けたりします。`speed()` と `cap()` はレベルから計算しているので、レベルを1上げるだけで歩く速さと持てる数が変わります
- かまどを開けたときは `count = 1` にして、すぐに1枚取れるようにしています

> [!NOTE]
> 強化に使うのは `coins` で、`score` は減りません。スコアは「稼いだ合計」なので、強化してお店を回すほどスコアも伸びていきます。

## パネルを描く

`drawFloor()` の **下** に `drawPads()` を追加します。

```js:game.js
  function drawPads() {
    S.pads.forEach((pd) => {
      const cost = padCost(pd);
      if (pd.kind === 'oven') return;
      const x = pd.x - pd.w / 2, y = pd.y - pd.h / 2;
      const can = cost !== null && S.coins >= cost;
      ctx.fillStyle = cost === null ? 'rgba(120,120,120,.25)' : can ? 'rgba(46,140,255,.30)' : 'rgba(46,140,255,.14)';
      rr(x, y, pd.w, pd.h, 10); ctx.fill();
      ctx.setLineDash([6, 4]); ctx.lineWidth = 2;
      ctx.strokeStyle = cost === null ? '#999' : '#2a7de1'; rr(x, y, pd.w, pd.h, 10); ctx.stroke(); ctx.setLineDash([]);
      text(pd.kind === 'speed' ? 'スピード' : '持てる数', pd.x, pd.y - 12, 12, '#1d4f8f');
      text(cost === null ? 'MAX' : `${cost}`, pd.x, pd.y + 8, 15, can ? '#0f5fc2' : '#8b5b52');
      if (pd.hold > 0) {
        ctx.strokeStyle = '#ffb400'; ctx.lineWidth = 4;
        ctx.beginPath(); ctx.arc(pd.x, pd.y, 30, -Math.PI / 2, -Math.PI / 2 + Math.PI * 2 * (pd.hold / 0.6)); ctx.stroke();
      }
    });
  }
```

- 色で状態を伝えます。買える（コインが足りる）ときは濃い青、足りないときはうすい青、最大レベルは灰色で「MAX」です。値段の文字も、買えるときは青、買えないときは茶色にします
- `ctx.setLineDash([6, 4])` で 6 ピクセル線・4 ピクセルすきまの **点線** になります。描き終わったら `setLineDash([])` で実線に戻します
- 乗っているあいだは、オレンジの円弧を 12 時の位置（`-Math.PI / 2`）から時計回りにのばして、あとどれくらいで買えるかを見せます
- かまどのパネルは、カギのかかったかまどと一緒に `drawOvens()` で描くので、ここでは `return` で飛ばします

`drawOvens()` のカギのかかったかまどの部分（`if (!o.open) { ... }`）を **書きかえ** ます。

```js:game.js
  function drawOvens() {
    S.ovens.forEach((o, i) => {
      const x = o.x - 40, y = OVEN_Y;
      if (!o.open) {
        const pd = S.pads.find((q) => q.kind === 'oven' && q.idx === i);
        const cost = OVEN_COST[i];
        const can = S.coins >= cost;
        ctx.fillStyle = 'rgba(0,0,0,.12)'; rr(x, y, 80, 62, 10); ctx.fill();
        ctx.fillStyle = can ? 'rgba(46,140,255,.30)' : 'rgba(46,140,255,.14)';
        rr(pd.x - pd.w / 2, pd.y - pd.h / 2, pd.w, pd.h, 10); ctx.fill();
        ctx.setLineDash([6, 4]); ctx.lineWidth = 2; ctx.strokeStyle = '#2a7de1';
        rr(pd.x - pd.w / 2, pd.y - pd.h / 2, pd.w, pd.h, 10); ctx.stroke(); ctx.setLineDash([]);
        text('かまど', pd.x, pd.y - 8, 11, '#1d4f8f');
        text(`${cost}`, pd.x, pd.y + 9, 14, can ? '#0f5fc2' : '#8b5b52');
        text('🔒', o.x, y + 32, 20, '#555');
        if (pd.hold > 0) {
          ctx.strokeStyle = '#ffb400'; ctx.lineWidth = 4;
          ctx.beginPath(); ctx.arc(pd.x, pd.y, 24, -Math.PI / 2, -Math.PI / 2 + Math.PI * 2 * (pd.hold / 0.6)); ctx.stroke();
        }
        return;
      }
```

`S.pads.find(...)` で、このかまどに対応するパネルを探します。`find()` は条件に合う最初の要素を返す配列のメソッドです。描き方は左右のパネルと同じです。

最後に `draw()` の `drawFloor();` の **下** に `drawPads();` を追加します。

```js:game.js
  function draw() {
    if (!S) S = newState();
    ctx.clearRect(0, 0, W, H);
    drawFloor();
    drawPads();
    drawOvens();
```
