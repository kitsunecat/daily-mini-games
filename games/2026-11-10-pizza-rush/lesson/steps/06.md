## このステップのゴール

お客さんに **我慢ゲージ** をつけます。待っているあいだにゲージが減っていき、なくなるとお客さんは「もう帰る!」と怒って帰ってしまいます。これが **ミス** で、3回ミスすると **閉店（ゲームオーバー）** です。ゲームオーバー画面には営業時間と売り上げを出し、「もう一度」で何度でも遊べるようにします。

## 定数と状態

`const BAKE_TIME = ...` の行を **書きかえ** ます。

```js:game.js
  const BAKE_TIME = 2.3, OVEN_MAX = 6, MAX_MISS = 3;
```

`newState()` の最初の行に `miss: 0,` を足します。

```js:game.js
    return {
      t: 0, coins: 0, score: 0, miss: 0,
```

## ゲームオーバーとミスの表示

`btn.addEventListener('click', start);` の **下** に `gameOver()` を追加し、`hud()` を **書きかえ** ます。

```js:game.js
  function gameOver() {
    running = false;
    joy.on = false;
    hud();
    beep(220, 0.4, 'sawtooth', 0.05);
    ovTitle.textContent = '閉店！';
    ovText.innerHTML = `営業時間 <b class="hl">${Math.floor(S.t)}秒</b><br>売り上げ <b class="hl">${S.score}</b> コイン`;
    btn.textContent = 'もう一度';
    overlay.classList.remove('hidden');
  }

  function hud() {
    elCoins.textContent = S.coins;
    elScore.textContent = S.score;
    elMiss.textContent = '×'.repeat(S.miss) + '○'.repeat(Math.max(0, MAX_MISS - S.miss));
  }
```

- `gameOver()` は `running = false` にしてゲームループを止め、ジョイスティックも解除します
- タイトル画面だったオーバーレイの見出しと本文を書きかえて「閉店！」の画面にし、ボタンの文字を「もう一度」に変えてから表示します。ボタンを押すと、同じ `start()` が `S = newState()` で全部を作り直すので、そのままリトライになります
- `innerHTML` に入れる文字の中では `${...}` で変数を埋めこめます（**テンプレートリテラル**、バッククォート `` ` `` で囲んだ文字列）。`Math.floor()` で秒数の小数を切り捨てています
- ミスの表示は、`'×'.repeat(S.miss)` でミスの数だけ ×、残りを ○ にします。1回ミスすると「×○○」です

## 我慢ゲージを減らす

`update()` の `// customers` で、`'walk'` の `if` ブロックの閉じかっこに `else if` をつなげます。`// customers` から `update()` の終わりまでを載せます。

```js:game.js
    // customers
    S.slots.forEach((c, i) => {
      if (!c) return;
      if (c.state === 'walk') {
        const dx = c.tx - c.x, dy = c.ty - c.y, d = Math.hypot(dx, dy);
        const v = 160 * dt;
        if (d <= v) { c.x = c.tx; c.y = c.ty; c.state = 'wait'; }
        else { c.x += dx / d * v; c.y += dy / d * v; }
      } else if (c.state === 'wait') {
        c.pat -= dt;
        if (c.pat <= 0) {
          S.slots[i] = null;
          c.state = 'angry';
          S.leaving.push(c);
          S.miss++;
          float(c.x, c.y - 40, 'もう帰る!', '#e0402e');
          beep(180, 0.3, 'sawtooth', 0.05);
          hud();
          if (S.miss >= MAX_MISS) { gameOver(); }
        }
      }
    });
    S.leaving = S.leaving.filter((c) => {
      c.y -= 130 * dt; c.x += (c.x < W / 2 ? -1 : 1) * 60 * dt;
      return c.y > -40;
    });

    S.floats = S.floats.filter((f) => { f.life -= dt * 0.9; f.y -= 30 * dt; return f.life > 0; });
  }
```

- 待っているあいだ `c.pat` を `dt` ずつ減らし、0 以下になったら怒って帰ります
- カウンターの場所を空け、状態を `'angry'` にして `leaving` に移すところは、満足して帰るとき（`serve()`）と同じ流れです。`drawCustomer()` は `'angry'` のとき体を赤くしてへの字口にするよう、ステップ5で書いてあります
- `S.miss` をふやして `hud()` で表示を更新し、`MAX_MISS`（3）に届いたら `gameOver()` を呼びます

> [!NOTE]
> 我慢が減ると、`serve()` のチップ（`5 × 枚数 × 残りの割合`）も少なくなります。ステップ5で書いた計算が、ここで初めて意味を持ちます。

## 我慢ゲージを描く

`drawCustomer()` の吹き出しの `if (c.state === 'wait') { ... }` の中、残り枚数の `text(...)` の **下** に追加します。

```js:game.js
    if (c.state === 'wait') {
      // bubble
      ctx.fillStyle = '#fff'; rr(x - 24, y - 58, 48, 26, 8); ctx.fill();
      ctx.beginPath(); ctx.moveTo(x - 5, y - 33); ctx.lineTo(x + 5, y - 33); ctx.lineTo(x, y - 27); ctx.fill();
      pizza(x - 10, y - 45, 8, false);
      text(`${c.want - c.got}`, x + 10, y - 45, 15, '#5a2a12');
      // patience bar
      const f = Math.max(0, c.pat / c.max);
      ctx.fillStyle = 'rgba(0,0,0,.35)'; rr(x - 20, y - 66, 40, 5, 2.5); ctx.fill();
      ctx.fillStyle = f > 0.5 ? '#3cc35a' : f > 0.25 ? '#f0b623' : '#e0402e';
      rr(x - 20, y - 66, 40 * f, 5, 2.5); ctx.fill();
    }
  }
```

吹き出しの上に細いバーを描きます。残りの割合 `f` が 5 割より上なら緑、2.5 割より上なら黄色、それ以下は赤です。`条件 ? A : 条件2 ? B : C` のように **三項演算子** をつなげると、3段階の色分けを1行で書けます。

> [!CHECK] 動作チェック
> - 待っているお客さんの吹き出しの上に緑のバーが出て、だんだん短くなる。黄色 → 赤と色が変わり、残り3割を切ると口がへの字になる
> - バーがなくなると、お客さんが赤くなって「もう帰る!」と出て帰り、上のミスが「×○○」になる
> - 早く届けるほど、もらえるコインが多い（チップ）
> - 3人帰らせると「閉店！」の画面になり、営業時間と売り上げが出る。「もう一度」で最初から遊べる
