## このステップのゴール

画面の下に **かまど** を置き、時間がたつと **ピザが1枚ずつ焼けて台の上に積み上がる** ようにします。店長がかまどの前まで行くと、焼けたピザを **自動で1枚ずつ受け取り**、手もとに積み重ねて運べるようにします。

かまどは3台ありますが、最初に使えるのは左の1台だけです。残りの2台はカギがかかっていて、ステップ7でコインを払って開けられるようにします。

## 定数と状態をふやす

`const OVEN_Y = 528;` の **下** に1行追加します。

```js:game.js
  const OVEN_X = [70, 180, 290];
  const OVEN_Y = 528;
  const BAKE_TIME = 2.3, OVEN_MAX = 6;
```

`BAKE_TIME` は1枚焼くのにかかる秒数、`OVEN_MAX` は台の上に置いておける最大の枚数です。

`newState()` を **書きかえ**、その下に `cap()` を追加します。

```js:game.js
  function newState() {
    return {
      t: 0,
      p: { x: 180, y: 300, stack: 0, speedLv: 0, capLv: 0, face: 1, bob: 0 },
      ovens: OVEN_X.map((x, i) => ({ x, open: i === 0, count: 1, timer: 0 })),
      xferT: 0,
    };
  }
  const cap = () => 3 + S.p.capLv * 2;
  const speed = () => 125 + S.p.speedLv * 28;
```

- 店長に `stack`（今持っている枚数）と `capLv`（持てる枚数のレベル）を足しました。`cap()` が「最大何枚持てるか」を返します。最初は 3 枚で、レベルが上がるたびに 2 枚ずつ増えます（ステップ7）
- `ovens` は3台のかまどの配列です。`OVEN_X.map(...)` で x 座標の配列からかまどのオブジェクトの配列を作っています。`open` は使えるかどうか（`i === 0`、つまり左の1台だけ `true`）、`count` は台の上の枚数、`timer` は焼き具合の秒数です。`({ x, ... })` の `x` は `x: x` の省略形です
- `xferT` は受け渡しの間隔をあけるためのタイマーです（transfer＝受け渡し）

## 焼く・受け取る

`update()` の最後、`if (ml > 0.1) { ... }` の行の **下** に追加します。

```js:game.js
    if (ml > 0.1) { p.bob += dt * 12; if (Math.abs(mx) > 0.1) p.face = mx > 0 ? 1 : -1; }

    // ovens bake
    S.ovens.forEach((o) => {
      if (!o.open) return;
      if (o.count < OVEN_MAX) {
        o.timer += dt;
        if (o.timer >= BAKE_TIME) { o.timer = 0; o.count++; }
      } else o.timer = 0;
    });

    // transfers
    S.xferT -= dt;
    if (S.xferT <= 0) {
      let did = false;
      // pick up from oven
      if (p.y > OVEN_Y - 90) {
        for (const o of S.ovens) {
          if (o.open && o.count > 0 && Math.abs(p.x - o.x) < 46 && p.stack < cap()) {
            o.count--; p.stack++; did = true; beep(520 + p.stack * 40, 0.06, 'square', 0.03);
            break;
          }
        }
      }
      S.xferT = did ? 0.14 : 0;
    }
  }
```

### かまどが焼く

使えるかまど（`o.open`）は、台の上が満杯でなければ `timer` に `dt` を足していき、`BAKE_TIME` を超えたら1枚ふやしてタイマーを 0 に戻します。満杯のあいだは焼くのをお休みします。

### 近づくだけで受け取る

このゲームでは **ボタンを押さず、近くに立つだけで自動で受け渡し** をします。

- 店長の y がかまどの近く（`OVEN_Y - 90` より下）で、x の差が 46 ピクセル未満なら「かまどの前にいる」と判定します。円や四角の当たり判定より単純な、**x と y の距離をそれぞれ比べるだけの判定** で十分です
- 条件がそろったら台の `count` を1減らし、店長の `stack` を1ふやします。`break` で1枚受け取ったらループを抜けます
- 受け取るたびに `beep()` を鳴らします。`520 + p.stack * 40` で、積むほど音が高くなっていきます
- 毎フレーム受け取ると一瞬で全部取れてしまうので、1枚受け取ったら `xferT = 0.14` にして **0.14 秒は次を受け取らない** ようにしています。何もしなかったフレームは `0` のままなので、近づいた瞬間にすぐ1枚目を受け取れます

## ピザと文字を描く道具

`rr()` の **下** に、ピザと文字を描く関数を追加します。

```js:game.js
  function pizza(x, y, r, flat) {
    ctx.save(); ctx.translate(x, y); if (flat) ctx.scale(1, 0.45);
    ctx.fillStyle = '#d98b3a'; ctx.beginPath(); ctx.arc(0, 0, r, 0, Math.PI * 2); ctx.fill();
    ctx.fillStyle = '#ffd25e'; ctx.beginPath(); ctx.arc(0, 0, r * 0.78, 0, Math.PI * 2); ctx.fill();
    ctx.fillStyle = '#d2382b';
    [[0.35, 0.2], [-0.3, 0.3], [0.05, -0.4], [-0.25, -0.2], [0.4, -0.25]].forEach(([a, b]) => {
      ctx.beginPath(); ctx.arc(a * r, b * r, r * 0.14, 0, Math.PI * 2); ctx.fill();
    });
    ctx.restore();
  }
  function text(t, x, y, size, color, align) {
    ctx.font = `bold ${size}px system-ui, -apple-system, "Hiragino Sans", sans-serif`;
    ctx.textAlign = align || 'center'; ctx.textBaseline = 'middle';
    ctx.fillStyle = color; ctx.fillText(t, x, y);
  }
```

- `pizza()` は、生地（茶色）→ チーズ（黄色）→ トマト5つ（赤）を重ねて円で描きます。トマトの位置は「半径の何倍か」で書いてあるので、大きなピザも小さなピザも同じ形になります
- `ctx.save()` → `ctx.translate(x, y)` で原点をピザの中心に動かし、描き終わったら `ctx.restore()` で元に戻します。`flat` のときは `ctx.scale(1, 0.45)` で縦につぶし、**ななめ上から見た平たいピザ** にします。積み重ねたときにそれらしく見えます
- `text()` は太字の文字を、指定した位置に **中央そろえ** で描く道具です。`textBaseline = 'middle'` で、y 座標が文字の縦のまん中になります

## かまどを描く

`drawFloor()` の **下** に `drawOvens()` を追加します。

```js:game.js
  function drawOvens() {
    S.ovens.forEach((o, i) => {
      const x = o.x - 40, y = OVEN_Y;
      if (!o.open) {
        ctx.fillStyle = 'rgba(0,0,0,.12)'; rr(x, y, 80, 62, 10); ctx.fill();
        text('🔒', o.x, y + 32, 20, '#555');
        return;
      }
      // dome oven
      ctx.fillStyle = '#8c4a2f'; rr(x, y + 10, 80, 54, 8); ctx.fill();
      ctx.fillStyle = '#b5623d'; ctx.beginPath(); ctx.ellipse(o.x, y + 18, 40, 28, 0, Math.PI, 0); ctx.fill();
      ctx.fillStyle = '#2a1208'; ctx.beginPath(); ctx.ellipse(o.x, y + 34, 20, 16, 0, Math.PI, 0); ctx.fill();
      ctx.fillRect(o.x - 20, y + 34, 40, 8);
      const glow = 0.5 + 0.5 * Math.sin(S.t * 6 + i);
      ctx.fillStyle = `rgba(255,${120 + glow * 60 | 0},40,.9)`; ctx.beginPath(); ctx.ellipse(o.x, y + 38, 13, 6, 0, 0, Math.PI * 2); ctx.fill();
      // bake progress
      ctx.fillStyle = 'rgba(0,0,0,.35)'; rr(x + 10, y + 52, 60, 6, 3); ctx.fill();
      if (o.count < OVEN_MAX) { ctx.fillStyle = '#ffcf3d'; rr(x + 10, y + 52, 60 * (o.timer / BAKE_TIME), 6, 3); ctx.fill(); }
      // table with stack
      ctx.fillStyle = '#c9a274'; rr(o.x - 30, y - 18, 60, 22, 5); ctx.fill();
      for (let k = 0; k < o.count; k++) pizza(o.x, y - 4 - k * 5, 18, true);
    });
  }
```

- カギのかかったかまどは、うすい影と 🔒 だけを描いて `return` します（`forEach` の中の `return` は「この1台は終わり、次へ」という意味です）
- 使えるかまどは、レンガの台・ドーム（半だ円）・黒い焼き口・中の火の順に描きます。`ctx.ellipse(x, y, 横半径, 縦半径, 回転, 開始角, 終了角)` で `Math.PI` から `0` まで描くと、上半分のだ円（ドーム）になります
- 火の色は `Math.sin(S.t * 6 + i)` で時間とともに明るさが変わり、ゆらゆら燃えて見えます。`| 0` は小数を切り捨てて整数にする書き方です
- 焼き口の下の黄色いバーが焼き具合（`timer / BAKE_TIME`）です
- かまどの上の台には、`count` 枚のピザを 5 ピクセルずつ上にずらして積み重ねます

## 運んでいるピザを描く

`drawPlayer()` の最後（目を描く行の **下**）に追加します。

```js:game.js
    ctx.fillStyle = '#222';
    ctx.beginPath(); ctx.arc(p.x - 4 + p.face * 2, p.y - 14 + b, 1.8, 0, Math.PI * 2); ctx.arc(p.x + 4 + p.face * 2, p.y - 14 + b, 1.8, 0, Math.PI * 2); ctx.fill();
    // carried stack (in front, above hands)
    for (let k = 0; k < p.stack; k++) pizza(p.x + p.face * 16, p.y + 4 + b - k * 5, 13, true);
    if (p.stack >= cap()) text('MAX', p.x + p.face * 16, p.y - 8 + b - p.stack * 5, 10, '#d2382b');
  }
```

ピザを店長の向いている側（`p.face * 16`）に、5 ピクセルずつ上へずらして積みます。持てる上限に達したら、てっぺんに赤い「MAX」を出します。

最後に `draw()` の `drawFloor();` の **下** に `drawOvens();` を追加します。

```js:game.js
  function draw() {
    if (!S) S = newState();
    ctx.clearRect(0, 0, W, H);
    drawFloor();
    drawOvens();
    // counter front edge over customers' legs
    ctx.fillStyle = '#7a3e1f'; rr(24, COUNTER_Y + 10, W - 48, COUNTER_H - 10, 4); ctx.fill();
    drawPlayer();
    drawJoy();
  }
```
