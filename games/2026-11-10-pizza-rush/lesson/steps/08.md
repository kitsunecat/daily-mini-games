## このステップのゴール

最後の仕上げです。**ハイスコア（BEST）をブラウザに保存** して、ページを閉じても残るようにし、ゲームオーバー画面に「ハイスコア更新！」を出します。さらに PC では **Enter / Space キーでスタート・リトライ** できるようにします。これで完成品の「かまどピザラッシュ」と同じものになります。

## localStorage でハイスコアを読みこむ

`const overlay = ...` の行の **下** に追加します。

```js:game.js
  const elCoins = $('coins'), elScore = $('score'), elBest = $('best'), elMiss = $('miss');
  const overlay = $('overlay'), ovTitle = $('ov-title'), ovText = $('ov-text'), btn = $('start');
  const BEST_KEY = 'pizza-rush-best';

  let best = 0;
  try { best = parseInt(localStorage.getItem(BEST_KEY), 10) || 0; } catch (e) { best = 0; }
  elBest.textContent = best;

  // ---------- layout ----------
```

**localStorage** は、ブラウザにちょっとしたデータを保存できるしくみです。`localStorage.setItem(キー, 値)` で保存、`localStorage.getItem(キー)` で読み出します。同じサイトなら、ページを閉じても、ブラウザを再起動しても残ります。

- キーの名前（`'pizza-rush-best'`）は、ほかのゲームの保存データとぶつからないように、ゲームごとに違う名前にします
- 保存できるのは **文字列だけ** です。読み出した値は `parseInt(..., 10)` で整数に直します。まだ何も保存されていないと `null` が返り、`parseInt` は `NaN` になるので、`|| 0` で 0 にします
- プライベートブラウズなど、localStorage が使えない環境ではエラーになることがあるので、`try { ... } catch` で囲んでおきます

## ゲームオーバーで保存する

`gameOver()` と `hud()` を **書きかえ** ます。

```js:game.js
  function gameOver() {
    running = false;
    joy.on = false;
    let rec = false;
    if (S.score > best) {
      best = S.score; rec = true;
      try { localStorage.setItem(BEST_KEY, String(best)); } catch (e) { /* ignore */ }
    }
    hud();
    beep(220, 0.4, 'sawtooth', 0.05);
    ovTitle.textContent = '閉店！';
    ovText.innerHTML = `営業時間 <b class="hl">${Math.floor(S.t)}秒</b><br>売り上げ <b class="hl">${S.score}</b> コイン` +
      (rec ? '<br><b class="hl">ハイスコア更新！</b>' : `<br>ベスト ${best}`);
    btn.textContent = 'もう一度';
    overlay.classList.remove('hidden');
  }

  function hud() {
    elCoins.textContent = S.coins;
    elScore.textContent = S.score;
    elBest.textContent = Math.max(best, S.score);
    elMiss.textContent = '×'.repeat(S.miss) + '○'.repeat(Math.max(0, MAX_MISS - S.miss));
  }
```

- 今回のスコアがベストより大きければ、`best` を更新して `localStorage` に保存し、`rec`（記録更新）を `true` にします。`String(best)` で数値を文字列にしてから保存します
- ゲームオーバー画面の本文の最後に、記録を更新したら「ハイスコア更新！」、そうでなければ今のベストを付け足します
- `hud()` の BEST は `Math.max(best, S.score)` にしているので、プレイ中にベストを超えると、その場で BEST の数字も一緒に増えていきます

## キーボードでスタート

`keydown` のイベントの中に1行追加します。

```js:game.js
  const keys = {};
  const joy = { on: false, id: null, ox: 0, oy: 0, dx: 0, dy: 0 };
  addEventListener('keydown', (e) => {
    keys[e.key.toLowerCase()] = true;
    if (['arrowup', 'arrowdown', 'arrowleft', 'arrowright', ' '].includes(e.key.toLowerCase())) e.preventDefault();
    if (!running && (e.key === 'Enter' || e.key === ' ')) start();
  });
  addEventListener('keyup', (e) => { keys[e.key.toLowerCase()] = false; });
```

ゲーム中でないとき（タイトル画面・ゲームオーバー画面）に Enter か Space を押すと `start()` を呼びます。`e.key` は Space キーのとき `' '`（半角スペース1文字）です。

> [!CHECK] 動作チェック
> - タイトル画面で Enter か Space を押すとゲームが始まる
> - 閉店すると、初回は「ハイスコア更新！」と出て、上の BEST が今回のスコアになる
> - もう一度遊んで前より低いスコアで閉店すると「ベスト 〇〇」と前の記録が出る
> - ページを再読み込みしても、BEST の数字が残っている
> - プレイ中にベストを超えると、SCORE と一緒に BEST の数字も増えていく

## 完成！ 改造してみよう

これで完成品の「かまどピザラッシュ」と同じものができました。ふり返ると、このゲームは「近くにいたら自動で1つ受け渡す」「タイマーを dt で増やし減らしする」「状態（`'walk'` → `'wait'` → `'happy'` / `'angry'`）で動きと見た目を切りかえる」の組み合わせでできています。最後に、自分だけのお店に育てる改造アイデアを紹介します。

> [!TIP]
> **ドリンクメニューを追加** … かまどの横にドリンクサーバーを置き、お客さんの注文に `drink` を足してみましょう。店長の `stack` を `pizza` と `drink` の2種類に分け、吹き出しに両方の残り数を出すと、運ぶ順番を考える楽しさが生まれます。

> [!TIP]
> **アルバイトを雇う** … 新しい強化パネル「アルバイト」を作り、買うとかまどとカウンターのあいだを自動で往復するキャラクターを出します。中身は店長と同じ `x, y, stack` を持つオブジェクトで、目的地に向かって歩く処理はお客さんの `'walk'` と同じ書き方で作れます。

> [!TIP]
> **VIP のお客さん** … `spawn()` でたまに金色の VIP を出し、注文が多くて我慢が短いかわりに代金を2倍にしてみましょう。`COLORS` の代わりに `'#e0b020'` を使い、`serve()` で `pay` を2倍にするだけで作れます。

> [!TIP]
> **難易度の調整** … `spawn()` の我慢時間（`21 - S.t * 0.05`）や `update()` のお客さんの間隔（`5.2 - S.t * 0.03`）、`BAKE_TIME` を変えると、忙しさががらりと変わります。強化パネルの値段（`SPEED_COST` など）を安くすると、お店がどんどん大きくなる爽快なゲームになります。
