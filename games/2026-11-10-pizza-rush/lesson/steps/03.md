## このステップのゴール

スマホでも遊べるように、**画面のどこでも指を置いてスライドすると、その方向へ歩く**「仮想ジョイスティック」を作ります。PC ではマウスのドラッグでも同じように動きます。指を置いた場所に円が出て、指の位置に合わせてつまみが動きます。

## Pointer Events

マウス・タッチ・ペンの操作は、**Pointer Events**（`pointerdown`・`pointermove`・`pointerup`）でまとめて受け取れます。マウス用とタッチ用に別々のコードを書かなくて済むので便利です。

`// ---------- input ----------` の `const keys = {};` の **下** に1行、`keyup` の行の **下** に残りを追加します。

```js:game.js
  // ---------- input ----------
  const keys = {};
  const joy = { on: false, id: null, ox: 0, oy: 0, dx: 0, dy: 0 };
  addEventListener('keydown', (e) => {
    keys[e.key.toLowerCase()] = true;
    if (['arrowup', 'arrowdown', 'arrowleft', 'arrowright', ' '].includes(e.key.toLowerCase())) e.preventDefault();
  });
  addEventListener('keyup', (e) => { keys[e.key.toLowerCase()] = false; });
  function toLocal(e) {
    const r = cv.getBoundingClientRect();
    return { x: (e.clientX - r.left) * W / r.width, y: (e.clientY - r.top) * H / r.height };
  }
  cv.addEventListener('pointerdown', (e) => {
    if (!running) return;
    const q = toLocal(e);
    joy.on = true; joy.id = e.pointerId; joy.ox = q.x; joy.oy = q.y; joy.dx = 0; joy.dy = 0;
    try { cv.setPointerCapture(e.pointerId); } catch (err) { /* ignore */ }
  });
  cv.addEventListener('pointermove', (e) => {
    if (!joy.on || e.pointerId !== joy.id) return;
    const q = toLocal(e);
    joy.dx = q.x - joy.ox; joy.dy = q.y - joy.oy;
  });
  const endJoy = (e) => { if (e.pointerId === joy.id) { joy.on = false; joy.dx = joy.dy = 0; } };
  cv.addEventListener('pointerup', endJoy);
  cv.addEventListener('pointercancel', endJoy);
```

- `joy` はジョイスティックの状態です。`on` が指を置いているか、`id` がどの指か、`ox, oy` が指を置いた場所（円の中心）、`dx, dy` がそこから今の指までのずれです
- `toLocal(e)` は、画面上の座標（`clientX`・`clientY`）を、ゲームの仮想座標（360×600）に変換します。`getBoundingClientRect()` で Canvas が画面のどこにどの大きさで表示されているかを調べ、割り算で縮尺を合わせます
- `pointerdown` で指を置いた場所を記録し、`pointermove` でずれを更新し、`pointerup`（指を離した）・`pointercancel`（電話がかかってきたなどで中断）で終わります
- `e.pointerId` は指ごとの番号です。2本目の指が触れても、最初の指だけを追いかけるようにしています
- `setPointerCapture()` を呼ぶと、指が Canvas の外にはみ出しても `pointermove` が届き続けます
- `if (!running) return;` で、タイトル画面のあいだは反応しないようにしています

## ずれを移動の向きに変える

`update()` の `// move player` で、キーの判定の **下**（`const ml = ...` の **上**）に追加します。

```js:game.js
    // move player
    let mx = 0, my = 0;
    if (keys['arrowleft'] || keys['a']) mx -= 1;
    if (keys['arrowright'] || keys['d']) mx += 1;
    if (keys['arrowup'] || keys['w']) my -= 1;
    if (keys['arrowdown'] || keys['s']) my += 1;
    if (joy.on) {
      const len = Math.hypot(joy.dx, joy.dy);
      if (len > 6) { const k = Math.min(1, len / 40); mx += joy.dx / len * k; my += joy.dy / len * k; }
    }
    const ml = Math.hypot(mx, my);
    if (ml > 1) { mx /= ml; my /= ml; }
```

- ずれの長さ `len` が 6 ピクセル以下のときは動きません（**デッドゾーン**）。指を置いただけで少し動いてしまうのを防ぎます
- `joy.dx / len` と `joy.dy / len` は「長さ 1 の向き」です。それに `k`（ずれ 40 ピクセルで 1 になる強さ）を掛けているので、**少しだけスライドすればゆっくり、大きくスライドすれば最高速** になります
- そのあとの正規化（`ml > 1` なら割る）はキーボードと共通です。キーとジョイスティックを同時に使っても速くなりすぎません

## ジョイスティックを描く

`drawPlayer()` の **下** に `drawJoy()` を追加し、`draw()` の最後で呼びます。

```js:game.js
  function drawJoy() {
    if (!joy.on) return;
    ctx.strokeStyle = 'rgba(0,0,0,.25)'; ctx.lineWidth = 3;
    ctx.beginPath(); ctx.arc(joy.ox, joy.oy, 40, 0, Math.PI * 2); ctx.stroke();
    const len = Math.hypot(joy.dx, joy.dy), k = len > 40 ? 40 / len : 1;
    ctx.fillStyle = 'rgba(0,0,0,.25)';
    ctx.beginPath(); ctx.arc(joy.ox + joy.dx * k, joy.oy + joy.dy * k, 16, 0, Math.PI * 2); ctx.fill();
  }

  function draw() {
    if (!S) S = newState();
    ctx.clearRect(0, 0, W, H);
    drawFloor();
    // counter front edge over customers' legs
    ctx.fillStyle = '#7a3e1f'; rr(24, COUNTER_Y + 10, W - 48, COUNTER_H - 10, 4); ctx.fill();
    drawPlayer();
    drawJoy();
  }
```

- 外側の円は指を置いた場所（半径 40）、内側のつまみは指の位置です
- 指が円の外まで出たときは `k = 40 / len` を掛けて、つまみを円のふちで止めます
- ジョイスティックはいちばん手前に見えてほしいので、`draw()` の最後に描きます

> [!CHECK] 動作チェック
> - スタート後、Canvas の上でマウスをドラッグ（スマホなら指でスライド）すると、押した場所にうすい円が出て、つまみが指についてくる
> - スライドした方向へ店長が歩く。少しだけずらすとゆっくり、大きくずらすと速く歩く
> - 指を離すと円が消えて店長が止まる
> - 開発者ツールのデバイスモード（スマホ表示）でも、ページがスクロールせずに操作できる
