## このステップのゴール

3つのファイルを用意して、ゲーム画面の土台を作ります。上に「コイン・SCORE・BEST・ミス」の表示、まん中にゲームを描く **Canvas**（キャンバス）とその上に重ねるタイトル画面（オーバーレイ）、下にひとことヒントを置き、Canvas に **お店の床（道路・キッチンのタイル・カウンター）** を描くところまで進めます。

完成すると、こんなゲームになります。

- 上から見たピザ屋さん。上が道路とカウンター、下にピザを焼く **かまど** が並んでいる
- 指でスライド（PC は矢印キー / WASD）すると **店長** が歩く。かまどの前に立つと焼きたてピザを **自動で受け取り**、頭の上に積み重ねて運ぶ
- カウンターに来たお客さんの吹き出しに **注文の枚数** が出る。前まで行くと自動で手渡し、全部届けるとコインがもらえる。早いほどチップが増える
- 床の **強化パネル** にコインを払って乗ると、足の速さ・持てる枚数・かまどの数が増える
- 我慢ゲージが切れて怒って帰るお客さんが **3人** になったら閉店（ゲームオーバー）。稼いだコインの合計がスコアで、ベストは保存される

## game.js（土台）

最初の `game.js` です。全体を `(() => { ... })();` で包んで、変数がほかのスクリプトとぶつからないようにしています（**即時関数** と呼びます）。`'use strict';` は、うっかりミスをエラーとして教えてくれるモードです。

```js:game.js
(() => {
  'use strict';
  const W = 360, H = 600;
  const cv = document.getElementById('cv');
  const ctx = cv.getContext('2d');
  const stage = document.getElementById('stage');
  const $ = (id) => document.getElementById(id);
  const elCoins = $('coins'), elScore = $('score'), elBest = $('best'), elMiss = $('miss');
  const overlay = $('overlay'), ovTitle = $('ov-title'), ovText = $('ov-text'), btn = $('start');

  // ---------- layout ----------
  const COUNTER_Y = 120, COUNTER_H = 26;
  const SLOTS = [90, 180, 270];
  const OVEN_X = [70, 180, 290];
  const OVEN_Y = 528;

  // ---------- state ----------
  let running = false;

  // ---------- sizing ----------
  function resize() {
    const r = stage.getBoundingClientRect();
    const s = Math.max(0.3, Math.min((r.width - 16) / W, (r.height - 8) / H));
    const dpr = Math.min(window.devicePixelRatio || 1, 3);
    cv.style.width = Math.floor(W * s) + 'px';
    cv.style.height = Math.floor(H * s) + 'px';
    cv.width = Math.floor(W * s * dpr);
    cv.height = Math.floor(H * s * dpr);
    ctx.setTransform(cv.width / W, 0, 0, cv.height / H, 0, 0);
    if (!running) draw();
  }
  addEventListener('resize', resize);

  // ---------- game flow ----------
  function start() {
    running = true;
    overlay.classList.add('hidden');
  }
  btn.addEventListener('click', start);

  // ---------- drawing ----------
  function rr(x, y, w, h, r) {
    ctx.beginPath();
    ctx.moveTo(x + r, y); ctx.arcTo(x + w, y, x + w, y + h, r); ctx.arcTo(x + w, y + h, x, y + h, r);
    ctx.arcTo(x, y + h, x, y, r); ctx.arcTo(x, y, x + w, y, r); ctx.closePath();
  }

  function drawFloor() {
    // street
    ctx.fillStyle = '#9fb3c4'; ctx.fillRect(0, 0, W, COUNTER_Y);
    ctx.fillStyle = '#b2c4d3';
    for (let x = 0; x < W; x += 40) ctx.fillRect(x, 0, 20, COUNTER_Y);
    // kitchen tiles
    for (let y = COUNTER_Y; y < H; y += 30) {
      for (let x = 0; x < W; x += 30) {
        ctx.fillStyle = ((x + y) / 30) % 2 === 0 ? '#f1e2c6' : '#e5cfa9';
        ctx.fillRect(x, y, 30, 30);
      }
    }
    // counter
    ctx.fillStyle = '#7a3e1f'; rr(24, COUNTER_Y, W - 48, COUNTER_H, 6); ctx.fill();
    ctx.fillStyle = '#a65a2e'; rr(24, COUNTER_Y, W - 48, 10, 5); ctx.fill();
    SLOTS.forEach((x) => { ctx.fillStyle = 'rgba(255,255,255,.18)'; rr(x - 30, COUNTER_Y + 13, 60, 9, 4); ctx.fill(); });
    // serve zone hint
    ctx.fillStyle = 'rgba(255,190,80,.18)';
    ctx.fillRect(30, COUNTER_Y + COUNTER_H, W - 60, 48);
  }

  function draw() {
    ctx.clearRect(0, 0, W, H);
    drawFloor();
    // counter front edge over customers' legs
    ctx.fillStyle = '#7a3e1f'; rr(24, COUNTER_Y + 10, W - 48, COUNTER_H - 10, 4); ctx.fill();
  }

  resize();
})();
```

### 仮想の画面サイズ

ゲームの中の座標は、いつも **幅 360・高さ 600** の「仮想の画面」で考えます（`W`・`H`）。スマホでも PC でも同じ座標でゲームを作れるので、計算がとても楽になります。

`resize()` は、`#stage` の大きさに収まる倍率 `s` を計算し、Canvas の **見た目の大きさ**（`cv.style.width`）と **中身の画素数**（`cv.width`）を決めます。`devicePixelRatio` は高解像度の画面で何倍の画素があるかを表す数で、これを掛けると文字や線がぼやけません。最後の `ctx.setTransform(...)` で「仮想の 360×600 で描いたものが、ちょうど Canvas いっぱいに拡大される」ように設定します。

### お店のレイアウト

`// ---------- layout ----------` には、お店の配置を数値でまとめています。

- `COUNTER_Y`・`COUNTER_H` … カウンターの上端の y 座標と厚み。これより上が道路で、お客さんはここに並びます
- `SLOTS` … お客さんが立つ3か所の x 座標
- `OVEN_X`・`OVEN_Y` … 3台のかまどの x 座標と、かまどの上端の y 座標（ステップ4で使います）

数字を直接あちこちに書かず名前をつけておくと、「カウンターを少し下げたい」ときに1か所直すだけで済みます。

### 描く

- `rr()` は **角の丸い四角形** の形（パス）を作る道具です。`arcTo()` で4つの角を丸めながら一周します。作った形は `ctx.fill()` で塗ったり `ctx.stroke()` で線を引いたりします
- `drawFloor()` は、道路（2色のしま）・キッチンのタイル（市松模様）・カウンター・カウンター前の「手渡しゾーン」（うすいオレンジ）を描きます。市松模様は `(x + y) / 30` が偶数か奇数かで色を交互に変えています
- `draw()` は1枚の絵を描く関数です。最後にカウンターの **手前のふち** だけをもう一度描いているのは、あとでお客さんを描いたときに、足もとがカウンターに隠れて「カウンターの向こうに立っている」ように見せるためです

スタートボタンの `click` で `start()` が呼ばれ、オーバーレイに `hidden` クラスをつけて隠します。
