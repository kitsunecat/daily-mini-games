## このステップのゴール

店長をキッチンに登場させ、**矢印キー / WASD で歩かせます**。そのために、ゲームの状態をまとめたオブジェクト `S`、毎フレーム「状態を進めて描き直す」**ゲームループ**、キーボード入力の受け取り、効果音を鳴らす小さな関数を用意します。

## 効果音の関数

`// ---------- layout ----------` の定数の **下** に追加します。

```js:game.js
  // ---------- audio ----------
  let actx = null;
  function beep(freq, dur, type, vol) {
    try {
      if (!actx) actx = new (window.AudioContext || window.webkitAudioContext)();
      const o = actx.createOscillator(), g = actx.createGain();
      o.type = type || 'sine'; o.frequency.value = freq;
      g.gain.setValueAtTime(vol || 0.06, actx.currentTime);
      g.gain.exponentialRampToValueAtTime(0.0001, actx.currentTime + dur);
      o.connect(g); g.connect(actx.destination);
      o.start(); o.stop(actx.currentTime + dur);
    } catch (e) { /* no audio */ }
  }
```

**Web Audio API** を使って、ファイルなしで「ピッ」という音を作ります。

- `AudioContext` は音を作る工場のようなものです。ブラウザは「ユーザーが操作するまで音を出さない」決まりなので、最初に鳴らすとき（スタートボタンを押したあと）に作ります
- `createOscillator()` は一定の高さの音を出し続ける発振器、`createGain()` は音量のつまみです。`freq` が音の高さ（Hz）、`type` が音色（`'sine'`・`'square'`・`'triangle'`・`'sawtooth'`）です
- `exponentialRampToValueAtTime()` で音量を `dur` 秒かけてほぼ 0 まで下げると、「プツッ」と切れずに自然に消えます
- 全体を `try { ... } catch` で囲んでいるのは、音が使えない環境でもゲームが止まらないようにするためです

## ゲームの状態

`// ---------- state ----------` を、次のように **書きかえ** ます。

```js:game.js
  // ---------- state ----------
  let S = null, running = false, last = 0;

  function newState() {
    return {
      t: 0,
      p: { x: 180, y: 300, speedLv: 0, face: 1, bob: 0 },
    };
  }
  const speed = () => 125 + S.p.speedLv * 28;
```

- ゲーム中に変わる値は、ぜんぶ `newState()` が返すオブジェクト `S` に入れます。リトライするときは `S = newState()` と作り直すだけで、すべてが初期状態に戻ります
- `t` はゲーム開始からの経過秒数です
- `p` は店長（player）です。`x, y` が位置、`speedLv` が足の速さのレベル（ステップ7で上がります）、`face` が向き（右 `1`・左 `-1`）、`bob` は歩くときに体を上下に揺らすためのカウンターです
- `speed()` は「1秒に何ピクセル歩けるか」を返す小さな関数です。レベルが上がるたびに 28 ずつ速くなります
- `last` は前のフレームの時刻です（ゲームループで使います）

## キーボード入力

`const speed = ...` の **下** に追加します。

```js:game.js
  // ---------- input ----------
  const keys = {};
  addEventListener('keydown', (e) => {
    keys[e.key.toLowerCase()] = true;
    if (['arrowup', 'arrowdown', 'arrowleft', 'arrowright', ' '].includes(e.key.toLowerCase())) e.preventDefault();
  });
  addEventListener('keyup', (e) => { keys[e.key.toLowerCase()] = false; });
```

キーが押されたら `keys['arrowleft'] = true`、離されたら `false` にして、**今どのキーが押されているか** を表にしておきます。動かす処理（あとで書く `update()`）は、この表を見るだけで済みます。`e.key` は `'ArrowLeft'` や `'a'` / `'A'` のように大文字小文字がまちまちなので、`toLowerCase()` でそろえています。

`e.preventDefault()` は、矢印キーや Space でページがスクロールしてしまうのを止めます。

## start() とゲームループ

`function start() { ... }` を **書きかえ**、`btn.addEventListener('click', start);` の **下** に `update()` を追加します。

```js:game.js
  // ---------- game flow ----------
  function start() {
    S = newState();
    running = true;
    overlay.classList.add('hidden');
    beep(660, 0.12, 'triangle');
    last = performance.now();
    requestAnimationFrame(loop);
  }
  btn.addEventListener('click', start);

  function update(dt) {
    S.t += dt;
    const p = S.p;

    // move player
    let mx = 0, my = 0;
    if (keys['arrowleft'] || keys['a']) mx -= 1;
    if (keys['arrowright'] || keys['d']) mx += 1;
    if (keys['arrowup'] || keys['w']) my -= 1;
    if (keys['arrowdown'] || keys['s']) my += 1;
    const ml = Math.hypot(mx, my);
    if (ml > 1) { mx /= ml; my /= ml; }
    p.x += mx * speed() * dt;
    p.y += my * speed() * dt;
```

### requestAnimationFrame と dt

`requestAnimationFrame(loop)` は、「次に画面を描き直すタイミングで `loop` を呼んで」とブラウザに頼む関数です。だいたい 1 秒に 60 回呼ばれます。`loop` の中でまた `requestAnimationFrame(loop)` を呼ぶと、ずっと繰り返す **ゲームループ** になります（このあと `draw()` の下に書きます）。

ただし、呼ばれる間隔は画面や端末によって違います。そこで前のフレームからの経過秒数 `dt` を測り、「速さ × dt」だけ動かします。こうすると 60Hz の画面でも 120Hz の画面でも、1秒で進む距離は同じになります。

### 店長を動かす

- 押されているキーから、左右 `mx`・上下 `my` を -1〜1 で決めます
- 斜めは `mx = 1, my = 1` だと長さが √2（約1.41）になり、まっすぐより速くなってしまいます。`Math.hypot(mx, my)` で長さを測り、1 より長ければ割って **長さ 1 にそろえます**（正規化）
- `p.x = Math.max(32, Math.min(W - 32, p.x))` は、値を「32 以上 W−32 以下」に **閉じこめる**（クランプする）書き方です。上はカウンターの手前、下はかまどの手前までしか歩けません
- 動いているあいだは `bob` を増やし、横に動いたら `face` で向きを変えます

## 店長を描く

`drawFloor()` の **下** に `drawPlayer()` を追加し、`draw()` を **書きかえ**、その下に `loop()` を追加します。

```js:game.js
  function drawPlayer() {
    const p = S.p, b = Math.sin(p.bob) * 1.5;
    ctx.fillStyle = 'rgba(0,0,0,.18)'; ctx.beginPath(); ctx.ellipse(p.x, p.y + 16, 16, 5, 0, 0, Math.PI * 2); ctx.fill();
    ctx.fillStyle = '#fff'; rr(p.x - 14, p.y - 4 + b, 28, 22, 9); ctx.fill();
    ctx.fillStyle = '#d2382b'; ctx.fillRect(p.x - 14, p.y + 6 + b, 28, 4);
    ctx.fillStyle = '#f2c9a0'; ctx.beginPath(); ctx.arc(p.x, p.y - 14 + b, 12, 0, Math.PI * 2); ctx.fill();
    // chef hat
    ctx.fillStyle = '#fff';
    ctx.beginPath(); ctx.arc(p.x - 6, p.y - 28 + b, 7, 0, Math.PI * 2); ctx.arc(p.x + 6, p.y - 28 + b, 7, 0, Math.PI * 2); ctx.arc(p.x, p.y - 32 + b, 8, 0, Math.PI * 2); ctx.fill();
    ctx.fillRect(p.x - 10, p.y - 26 + b, 20, 6);
    ctx.fillStyle = '#222';
    ctx.beginPath(); ctx.arc(p.x - 4 + p.face * 2, p.y - 14 + b, 1.8, 0, Math.PI * 2); ctx.arc(p.x + 4 + p.face * 2, p.y - 14 + b, 1.8, 0, Math.PI * 2); ctx.fill();
  }

  function draw() {
    if (!S) S = newState();
    ctx.clearRect(0, 0, W, H);
    drawFloor();
    // counter front edge over customers' legs
    ctx.fillStyle = '#7a3e1f'; rr(24, COUNTER_Y + 10, W - 48, COUNTER_H - 10, 4); ctx.fill();
    drawPlayer();
  }

  function loop(now) {
    if (!running) { draw(); return; }
    const dt = Math.min(0.05, (now - last) / 1000);
    last = now;
    update(dt);
    draw();
    if (running) requestAnimationFrame(loop);
    else draw();
  }
```

- 店長は「影（だ円）→ 白いコックコート → 赤いエプロンのライン → 顔 → コック帽 → 目」の順に重ねて描きます。あとから描いたものが上に重なります
- `b = Math.sin(p.bob) * 1.5` は、`bob` が増えると -1.5〜1.5 を行ったり来たりする値です。体の y 座標に足すと、歩くたびにぴょこぴょこ揺れます
- 目の位置に `p.face * 2` を足しているので、向いている方向に目が寄ります
- `draw()` の最初の `if (!S) S = newState();` は、スタート前（タイトル画面の後ろ）にも店長を描けるようにするためです
- `loop()` は `running` が `false` になったら次のフレームを頼まずに止まります。`dt` を最大 0.05 秒に制限しているのは、タブを裏に回して戻ったときに `dt` が何秒にもなって、店長が一気にワープするのを防ぐためです

> [!CHECK] 動作チェック
> - タイトル画面の後ろに、コック帽の店長が見える
> - スタートを押すと「ピッ」と音が鳴り、矢印キーや WASD で店長が歩く。歩くと体が小さく揺れる
> - 左に歩くと目が左に、右に歩くと目が右に寄る
> - 斜めに歩いても速くなりすぎない。カウンターの手前やかまどの位置（画面下の方）より先には行けない
