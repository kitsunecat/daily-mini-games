## このステップのゴール

道路から **お客さんがやって来て、カウンターの3か所のどこかに並び**、吹き出しで「ピザを何枚ほしいか」を見せるようにします。ピザを持った店長がお客さんの前に行くと **自動で1枚ずつ手渡し**、注文の枚数をそろえるとコインがもらえて、お客さんはにっこり笑って帰っていきます。もらったコインは画面の上に「+25」のように浮かび上がります。

## 状態をふやす

`newState()` を **書きかえ** ます。

```js:game.js
  function newState() {
    return {
      t: 0, coins: 0, score: 0,
      p: { x: 180, y: 300, stack: 0, speedLv: 0, capLv: 0, face: 1, bob: 0 },
      ovens: OVEN_X.map((x, i) => ({ x, open: i === 0, count: 1, timer: 0 })),
      slots: [null, null, null],
      leaving: [],
      spawnT: 1.2,
      xferT: 0,
      floats: [],
    };
  }
```

- `coins` は今持っているコイン（ステップ7で使うと減ります）、`score` は稼いだコインの合計です
- `slots` はカウンターの3か所に並んでいるお客さんです。空いている場所は `null` にします
- `leaving` は帰っていく途中のお客さんの配列です。カウンターの場所はすぐ空けたいけれど、歩いて去る姿は描きたいので、別の配列に移します
- `spawnT` は次のお客さんが来るまでの秒数、`floats` は浮かび上がる文字（「+25」など）の配列です

## 表示の更新・お客さんを呼ぶ

`start()` の `beep(...)` の **下** に `hud();` を1行足し、`btn.addEventListener('click', start);` の **下** に3つの関数を追加します。

```js:game.js
  function start() {
    S = newState();
    running = true;
    overlay.classList.add('hidden');
    beep(660, 0.12, 'triangle');
    hud();
    last = performance.now();
    requestAnimationFrame(loop);
  }
  btn.addEventListener('click', start);

  function hud() {
    elCoins.textContent = S.coins;
    elScore.textContent = S.score;
  }

  function float(x, y, text, color) { S.floats.push({ x, y, text, color, life: 1 }); }

  const COLORS = ['#3d7be0', '#36a66b', '#c84fb0', '#e08a2a', '#5a5ad6', '#1f9fa6', '#d0475a'];
  function spawn() {
    const free = [];
    S.slots.forEach((c, i) => { if (!c) free.push(i); });
    if (!free.length) return false;
    const i = free[Math.floor(Math.random() * free.length)];
    const lvl = Math.min(3, Math.floor(S.t / 35));
    const want = 1 + Math.floor(Math.random() * (lvl + 1));
    const pat = Math.max(11, 21 - S.t * 0.05) + want * 2;
    S.slots[i] = {
      x: Math.random() < 0.5 ? -20 : W + 20, y: 40 + Math.random() * 30, tx: SLOTS[i], ty: 96,
      want, got: 0, pat, max: pat, state: 'walk',
      color: COLORS[Math.floor(Math.random() * COLORS.length)],
    };
    return true;
  }
```

- `hud()` は、`S` の数値を画面上の HTML に書き写す関数です。数値が変わったらそのたびに呼びます。毎フレーム書きかえるより、変わったときだけ書きかえるほうがむだがありません
- `float()` は浮かび上がる文字を1つ追加します。`life` は 1 から始まり、0 になったら消えます
- `spawn()` はお客さんを1人呼びます
  - 空いている場所の番号を `free` に集め、空きがなければ `false` を返します。空きがあればその中からランダムに1つ選びます
  - `lvl` は経過時間で上がるレベルです（35 秒ごとに 1、最大 3）。注文枚数 `want` は「1〜lvl+1 枚」なので、最初は1枚だけ、時間がたつと最大4枚の注文が来ます
  - `pat` は **我慢できる秒数** です。最初は約 21 秒で、時間とともに短くなり（最短 11 秒）、注文が多いほど少し長めにしています。`max` に最初の値を覚えておき、残りの割合を出すのに使います（ステップ6）
  - お客さんは画面の左か右の外（`-20` か `W + 20`）から登場し、`tx, ty`（自分の場所）まで歩きます。`state` は `'walk'`（歩いてくる）→ `'wait'`（待つ）→ `'happy'`（満足して帰る）と変わっていきます

## お客さんの出現と移動

`update()` の `const p = S.p;` の **下** に、お客さんを呼ぶ処理を追加します。

```js:game.js
  function update(dt) {
    S.t += dt;
    const p = S.p;

    // spawn
    S.spawnT -= dt;
    if (S.spawnT <= 0) {
      if (spawn()) S.spawnT = Math.max(1.7, 5.2 - S.t * 0.03) * (0.75 + Math.random() * 0.5);
      else S.spawnT = 0.5;
    }

```

`spawnT` を減らしていき、0 以下になったら1人呼びます。次に来るまでの間隔は、最初は約 5 秒で時間とともに短くなり（最短 1.7 秒）、`0.75 + Math.random() * 0.5` を掛けて毎回 0.75〜1.25 倍にばらつかせます。満席で呼べなかったときは 0.5 秒後にもう一度試します。

次に、`// transfers` の受け取り（`// pick up from oven`）の `if` ブロックの **下**、`S.xferT = ...` の **上** に手渡しを追加し、`update()` の最後にお客さんと浮かぶ文字の動きを追加します。`// transfers` から `update()` の終わりまでを載せます。

```js:game.js
    // transfers
    S.xferT -= dt;
    if (S.xferT <= 0) {
      let did = false;
      // pick up from oven
      if (p.y > OVEN_Y - 90) {
        for (const o of S.ovens) {
          if (o.open && o.count > 0 && Math.abs(p.x - o.x) < 46 && p.stack < cap()) {
            o.count--; p.stack++; did = true; beep(520 + p.stack * 40, 0.06, 'square', 0.03);
            break;
          }
        }
      }
      // serve
      if (!did && p.stack > 0 && p.y < COUNTER_Y + COUNTER_H + 52) {
        for (const c of S.slots) {
          if (c && c.state === 'wait' && Math.abs(p.x - c.x) < 48 && c.got < c.want) {
            c.got++; p.stack--; did = true; beep(780, 0.06, 'triangle', 0.04);
            if (c.got >= c.want) serve(c);
            break;
          }
        }
      }
      S.xferT = did ? 0.14 : 0;
    }

    // customers
    S.slots.forEach((c, i) => {
      if (!c) return;
      if (c.state === 'walk') {
        const dx = c.tx - c.x, dy = c.ty - c.y, d = Math.hypot(dx, dy);
        const v = 160 * dt;
        if (d <= v) { c.x = c.tx; c.y = c.ty; c.state = 'wait'; }
        else { c.x += dx / d * v; c.y += dy / d * v; }
      }
    });
    S.leaving = S.leaving.filter((c) => {
      c.y -= 130 * dt; c.x += (c.x < W / 2 ? -1 : 1) * 60 * dt;
      return c.y > -40;
    });

    S.floats = S.floats.filter((f) => { f.life -= dt * 0.9; f.y -= 30 * dt; return f.life > 0; });
  }
```

### 手渡し

- 受け取りと同じく「近くにいたら自動で1枚」です。ピザを持っていて（`p.stack > 0`）、手渡しゾーン（カウンターの手前、床のうすいオレンジの帯）にいて、待っているお客さんとの x の差が 48 未満なら、`got` を1ふやして `stack` を1減らします
- `!did &&` がついているので、同じフレームで受け取りと手渡しが両方起きることはありません
- 注文の枚数がそろったら（`c.got >= c.want`）`serve(c)` を呼びます

### お客さんの動き

- `'walk'` のお客さんは、目的地 `tx, ty` に向かって 1 秒に 160 ピクセル進みます。`dx / d` と `dy / d` は目的地への「長さ 1 の向き」です。残りの距離 `d` が1フレームで進む距離 `v` 以下になったら、ぴったり目的地に置いて `'wait'` にします（行きすぎて行ったり来たりするのを防ぐため）
- `leaving` のお客さんは上に歩きながら、画面の左右の近いほうへそれていきます。`filter()` は、`true` を返した要素だけを残した新しい配列を作るので、画面の外（`y <= -40`）に出たお客さんは自動的に配列から消えます
- 浮かぶ文字も同じしくみで、上に動きながら `life` を減らし、0 になったら消します

## 代金を受け取る

`update()` の **下** に `serve()` を追加します。

```js:game.js
  function serve(c) {
    const tip = Math.floor(5 * c.want * (c.pat / c.max));
    const pay = c.want * 10 + tip;
    S.coins += pay; S.score += pay;
    float(c.x, c.y - 40, `+${pay}`, '#d18a00');
    beep(988, 0.08, 'square', 0.04); setTimeout(() => beep(1319, 0.12, 'square', 0.04), 70);
    const i = S.slots.indexOf(c);
    if (i >= 0) S.slots[i] = null;
    c.state = 'happy';
    S.leaving.push(c);
    hud();
  }
```

- 代金は「1枚 10 コイン × 枚数」に **チップ** を足したものです。チップは `5 × 枚数 × 残りの我慢の割合`。早く届けるほど多くもらえます（今は我慢が減らないので、いつも満額です）
- `S.slots.indexOf(c)` でそのお客さんの場所を探して `null` にし、カウンターを空けます。お客さんは `'happy'` にして `leaving` に移します
- `setTimeout(() => beep(...), 70)` は、0.07 秒後にもう1つ高い音を鳴らして「チャリン」という2音にしています

## お客さんを描く

`drawOvens()` の **下** に `drawCustomer()` を追加します。

```js:game.js
  function drawCustomer(c) {
    const bob = c.state === 'walk' || c.state === 'happy' || c.state === 'angry' ? Math.sin(S.t * 14) * 2 : 0;
    const x = c.x, y = c.y + bob;
    ctx.fillStyle = 'rgba(0,0,0,.15)'; ctx.beginPath(); ctx.ellipse(c.x, c.y + 18, 16, 5, 0, 0, Math.PI * 2); ctx.fill();
    ctx.fillStyle = c.state === 'angry' ? '#c93b2c' : c.color; rr(x - 14, y - 4, 28, 22, 9); ctx.fill();
    ctx.fillStyle = '#f2c9a0'; ctx.beginPath(); ctx.arc(x, y - 14, 12, 0, Math.PI * 2); ctx.fill();
    ctx.fillStyle = '#222';
    ctx.beginPath(); ctx.arc(x - 4, y - 15, 1.8, 0, Math.PI * 2); ctx.arc(x + 4, y - 15, 1.8, 0, Math.PI * 2); ctx.fill();
    ctx.strokeStyle = '#222'; ctx.lineWidth = 1.6; ctx.beginPath();
    if (c.state === 'happy') ctx.arc(x, y - 11, 4, 0.15 * Math.PI, 0.85 * Math.PI);
    else if (c.state === 'angry' || (c.state === 'wait' && c.pat / c.max < 0.3)) ctx.arc(x, y - 6, 4, 1.15 * Math.PI, 1.85 * Math.PI);
    else { ctx.moveTo(x - 3, y - 9); ctx.lineTo(x + 3, y - 9); }
    ctx.stroke();
    if (c.state === 'wait') {
      // bubble
      ctx.fillStyle = '#fff'; rr(x - 24, y - 58, 48, 26, 8); ctx.fill();
      ctx.beginPath(); ctx.moveTo(x - 5, y - 33); ctx.lineTo(x + 5, y - 33); ctx.lineTo(x, y - 27); ctx.fill();
      pizza(x - 10, y - 45, 8, false);
      text(`${c.want - c.got}`, x + 10, y - 45, 15, '#5a2a12');
    }
  }
```

- 歩いているあいだは `Math.sin(S.t * 14) * 2` で上下に揺らします。影だけは揺らさずに `c.y` の位置に描くので、ぴょこぴょこ歩いているように見えます
- 口は状態で変わります。`'happy'` は下向きの弧（にっこり）、怒っている・我慢が残り3割を切ったときは上向きの弧（への字）、それ以外はまっすぐな線です。`ctx.arc()` の開始角と終了角で弧の向きを決めています（Canvas の角度は右が 0 で、**時計回り** に増えます）
- 待っているあいだは白い吹き出しを出し、ピザの絵と **残りの枚数**（`want - got`）を描きます

最後に `draw()` を **書きかえ** ます。

```js:game.js
  function draw() {
    if (!S) S = newState();
    ctx.clearRect(0, 0, W, H);
    drawFloor();
    drawOvens();
    S.leaving.forEach(drawCustomer);
    S.slots.forEach((c) => c && drawCustomer(c));
    // counter front edge over customers' legs
    ctx.fillStyle = '#7a3e1f'; rr(24, COUNTER_Y + 10, W - 48, COUNTER_H - 10, 4); ctx.fill();
    drawPlayer();
    S.floats.forEach((f) => {
      ctx.globalAlpha = Math.max(0, Math.min(1, f.life * 1.5));
      text(f.text, f.x + 1, f.y + 1, 16, 'rgba(0,0,0,.35)');
      text(f.text, f.x, f.y, 16, f.color);
      ctx.globalAlpha = 1;
    });
    drawJoy();
  }
```

- お客さんはかまどの後、カウンターの手前のふちの **前** に描きます。こうするとステップ1で用意したとおり、足もとがカウンターに隠れます
- 浮かぶ文字は `ctx.globalAlpha`（全体の不透明度）で、消える直前にだんだん透明にします。1 ピクセルずらして黒っぽい文字を先に描くと、影つきの読みやすい文字になります。描き終わったら `globalAlpha = 1` に戻すのを忘れずに

> [!CHECK] 動作チェック
> - スタートしてしばらくすると、道路の左右からお客さんが歩いてきて、カウンターの3か所のどこかで止まる
> - 止まったお客さんの上に吹き出しが出て、ほしい枚数が表示される（最初はほとんど1枚）
> - ピザを持ってお客さんの前（カウンター手前のオレンジの帯）に行くと、1枚ずつ手渡されて吹き出しの数字が減る
> - 注文がそろうと「チャリン」と鳴って「+15」が浮かび上がり、上のコインと SCORE が増え、お客さんがにっこりして帰っていく
