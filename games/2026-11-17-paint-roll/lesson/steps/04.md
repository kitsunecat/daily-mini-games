## このステップのゴール

ボールが一瞬でワープするのをやめて、1秒に16マスの速さで **ころころ転がる** ようにします。転がりながら、通過したマスから順番に色がぬられていきます。転がっている途中に次のキーを押したら、止まった直後にその向きへ転がる「先行入力」にも対応し、迷路の上に **ぬった割合のバー** も出します。

## アニメーション用の変数

`let start = { x: 0, y: 0 };` の **下** に追加します。

```js:game.js
  let anim = null; // {dx,dy,tx,ty,t,dist}
  let queued = null;
```

- `anim` は「いま転がっている最中の情報」です。転がっていないときは `null` です
- `queued` は、転がっている途中に押された次の向き（先行入力）です

`loadLevel()` の `paint(sx, sy);` の **下** に、迷路を読みこみ直したときに転がり途中の情報を消す1行を足します。

```js:game.js
    anim = null; queued = null;
```

## tryMove() を書きかえて、finishMove() を足す

`tryMove()` を **まるごと書きかえ**、そのすぐ **下** に `finishMove()` を追加します。

```js:game.js
  function tryMove(name) {
    if (state !== 'play') return;
    if (anim) { queued = name; return; }
    const [dx, dy] = DIRS[name];
    const [ex, ey] = slide(grid, W, H, ball.x, ball.y, dx, dy);
    if (ex === ball.x && ey === ball.y) return;
    const dist = Math.abs(ex - ball.x) + Math.abs(ey - ball.y);
    anim = { dx, dy, sx: ball.x, sy: ball.y, tx: ex, ty: ey, t: 0, dist };
  }

  function finishMove() {
    ball.x = anim.tx; ball.y = anim.ty; ball.px = ball.x; ball.py = ball.y;
    const a = anim; anim = null;
    if (paintedCount >= toPaint) { levelClear(); return; }
    if (queued) { const q = queued; queued = null; tryMove(q); }
    void a;
  }
```

### 移動を「予約」して、少しずつ進める

`tryMove()` ではもう `ball` を動かしません。`slide()` で **止まる場所だけ** 先に計算し（今回は `cb` を渡さないのでぬりません）、`anim` に「出発地 `sx, sy`」「向き `dx, dy`」「到着地 `tx, ty`」「進むマス数 `dist`」「これまでに進んだ量 `t`」をまとめて入れます。実際に動かすのは、毎フレーム呼ばれる `loop()` の仕事です。

`dist` は縦か横の一方にしか進まないので、x の差と y の差の絶対値を足せば求まります。

### 転がっている途中の入力

`anim` があるときに `tryMove()` が呼ばれたら、向きを `queued` に覚えておくだけにします。`finishMove()`（到着したとき）にクリアでなければ、覚えておいた向きで `tryMove()` を呼び直します。こうすると、テンポよくキーを連打しても入力が消えません。

`const a = anim;` と `void a;` は、到着前の `anim` を取っておくための行です。完成品ではこの値を使っていませんが、「直前の移動の向き」を使った改造をしたいときに便利です。

## loop() で転がす

`loop()` の `const dt = ...; lastT = t;` の行の **下** に追加します。

```js:game.js
    if (anim) {
      const speed = 16; // cells per second
      anim.t += dt * speed;
      const d = Math.min(anim.t, anim.dist);
      ball.px = anim.sx + anim.dx * d; ball.py = anim.sy + anim.dy * d;
      const passed = Math.floor(d + 0.5);
      for (let k = 1; k <= passed; k++) paint(anim.sx + anim.dx * k, anim.sy + anim.dy * k);
      if (anim.t >= anim.dist) finishMove();
    }
```

- `anim.t` は「これまでに進んだマス数」で、毎フレーム `dt * speed` ずつ増えます。dt は秒なので、1秒で 16 マス進みます。60fps でも 120fps でも同じ速さになるのが、dt を使ういちばんの理由です
- `d` は `dist` を超えないように頭打ちにした進んだ量です。描く位置 `px, py` は「出発地 + 向き × d」なので、2.5 マス目のような **小数の位置** になり、なめらかに見えます
- `passed` はボールの中心がマスの真ん中を越えたマスの数です（`+ 0.5` して切り捨てると四捨五入になります）。1マス目から `passed` マス目までを `paint()` します。すでにぬったマスは `paint()` の中で無視されるので、毎フレーム同じマスを呼んでも大丈夫です
- 到着したら `finishMove()` で、マスの位置を確定させます

## ぬった割合のバー

`draw()` の、ボールを描いた行の **下**（`if (flash > 0) {` の **上**）に追加します。

```js:game.js
    // progress bar
    const prog = toPaint ? paintedCount / toPaint : 0;
    ctx.fillStyle = 'rgba(0,0,0,0.3)';
    ctx.fillRect(cell * 0.3, cell * 0.35, gw - cell * 0.6, cell * 0.22);
    ctx.fillStyle = `hsl(${hue},85%,65%)`;
    ctx.fillRect(cell * 0.3, cell * 0.35, (gw - cell * 0.6) * prog, cell * 0.22);
```

迷路のいちばん上の行は必ず壁なので、そこにバーを重ねます。暗い下地を描いてから、`prog`（0〜1）の割合だけ色を重ねます。

> [!CHECK] 動作チェック
> - キーを押すと、ボールが壁までころころ転がり、通過したマスから順番に色がぬられていく
> - 迷路の上のバーが、ぬった床の割合だけ伸びる
> - 転がっている途中に次のキーを押すと、止まったあとすぐその向きに転がる
> - ステップ3と同じ順番で床を全部ぬると、バーが端まで伸びて「CLEAR!」が出る
