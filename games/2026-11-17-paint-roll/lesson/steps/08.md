## このステップのゴール

最後に、ゲームを気持ちよく遊べるように仕上げます。

- ぬったマスとクリアボーナスで **スコア** が増える
- **効果音**（Web Audio API）と、止まったときやクリアのときに飛び散る **パーティクル**
- **ハイスコア** をブラウザに保存して、次に開いたときも BEST に表示する
- ゲームオーバー画面にスコアを表示し、Enter / Space キーでもスタートできる

これで完成品と同じゲームになります。

## ハイスコアを読みこむ

`const overlay = ...` の行の **下**、`const DIRS = ...` の **上** に追加します。

```js:game.js
  const BEST_KEY = 'paint-roll-best';
  let best = 0;
  try { best = parseInt(localStorage.getItem(BEST_KEY), 10) || 0; } catch (e) { best = 0; }
  elBest.textContent = best;
```

**localStorage** は、ブラウザにちょっとしたデータを保存しておける場所です。ページを閉じても消えません。`getItem(キー)` で読み、`setItem(キー, 文字列)` で書きます。保存できるのは文字列だけなので、`parseInt` で数に直します。まだ保存されていないと `null` が返り、`parseInt` の結果は `NaN` になるので、`|| 0` で 0 にします。プライベートブラウズなどで localStorage が使えないとエラーになることがあるので、`try { ... } catch` で囲んでいます。

## 効果音

`let flash = 0;` の **下**、`// ---------- level generation ----------` の **上** に追加します。

```js:game.js
  // ---------- audio ----------
  let actx = null;
  function beep(freq, dur, type = 'sine', vol = 0.08) {
    try {
      if (!actx) actx = new (window.AudioContext || window.webkitAudioContext)();
      const o = actx.createOscillator(), g = actx.createGain();
      o.type = type; o.frequency.value = freq;
      g.gain.setValueAtTime(vol, actx.currentTime);
      g.gain.exponentialRampToValueAtTime(0.0001, actx.currentTime + dur);
      o.connect(g); g.connect(actx.destination);
      o.start(); o.stop(actx.currentTime + dur);
    } catch (e) { /* audio unavailable */ }
  }
```

**Web Audio API** を使うと、音声ファイルなしで音を作れます。

- **オシレーター**（`createOscillator`）は、決まった高さ（`frequency`、Hz）と音色（`type`: `'sine'` やわらかい・`'square'` ピコピコ・`'triangle'` まるい・`'sawtooth'` ざらざら）の音を出し続ける装置です
- **ゲイン**（`createGain`）は音量のつまみです。`exponentialRampToValueAtTime` で `dur` 秒かけてほぼ 0 まで下げると、「ポン」と自然に消える音になります
- オシレーター → ゲイン → スピーカー（`destination`）の順に `connect` でつなぎ、`start()` して `dur` 秒後に `stop()` します

ブラウザは「ユーザーが画面を操作するまで音を出さない」決まりになっているので、`AudioContext` は最初に音を鳴らすとき（スタートボタンを押したとき）に作ります。

## ぬったマスでスコアを増やす

`paint()` の `painted[i] = 1; paintedCount++;` の **下** に1行追加します。

```js:game.js
  function paint(x, y) {
    const i = y * W + x;
    if (!painted[i]) {
      painted[i] = 1; paintedCount++;
      if (state === 'play') { score += 1; }
      return true;
    }
    return false;
  }
```

タイトル画面のうしろで見本の迷路を読みこむときには点が入らないよう、プレイ中だけ足します。

## 音と点数とパーティクルを足す

ゲームの流れの関数に、少しずつ追加していきます。

`startGame()` の最後（`loadLevel(true);` の **下**）に、スタートの音を足します。

```js:game.js
    beep(520, 0.12, 'triangle');
```

`tryMove()` の、動けなかったときの行を **書きかえ**、`anim = { ... };` の **下** に転がる音を足します。

```js:game.js
    if (ex === ball.x && ey === ball.y) { beep(140, 0.06, 'square', 0.04); return; }
    movesLeft--;
    const dist = Math.abs(ex - ball.x) + Math.abs(ey - ball.y);
    anim = { dx, dy, sx: ball.x, sy: ball.y, tx: ex, ty: ey, t: 0, dist };
    beep(300 + dist * 30, 0.08, 'sine', 0.05);
    updateHud();
```

壁にぶつかって動けないときは低い「ブッ」、転がるときは **遠くまで転がるほど高い音** にしています。

`finishMove()` の `const a = anim; anim = null;` の **下** に、止まった場所で粒を飛ばす1行を足します。

```js:game.js
    burst(ball.x, ball.y, 6);
```

`levelClear()` を **書きかえ** て、ボーナス点・たくさんの粒・3音のファンファーレを足します。

```js:game.js
  function levelClear() {
    const bonus = 100 + movesLeft * 20 + level * 10;
    score += bonus;
    state = 'clear';
    flash = 1;
    for (let i = 0; i < 40; i++) burst(1 + rnd(W - 2), 1 + rnd(H - 2), 1);
    [660, 880, 1100].forEach((f, i) => setTimeout(() => beep(f, 0.15, 'triangle'), i * 90));
    updateHud();
    setTimeout(() => {
      if (state !== 'clear') return;
      level++; state = 'play'; loadLevel(true);
    }, 1100);
  }
```

ボーナスは「100 + 残った手数 × 20 + レベル × 10」です。**少ない手数でクリアするほど高得点** になるので、ただ解くだけでなく、最短ルートを探す楽しみが生まれます。3つの音を `setTimeout` で 90 ミリ秒ずつずらして鳴らすと、「ド・ミ・ソ」のような上がっていく音になります。

`loseLife()` の `lives--;` の **下** に、失敗の音を足します。

```js:game.js
    beep(180, 0.25, 'sawtooth', 0.06);
```

## ゲームオーバーでハイスコアを保存

`gameOver()` を **まるごと書きかえ** ます。

```js:game.js
  function gameOver() {
    state = 'over';
    updateHud();
    let newBest = false;
    if (score > best) {
      best = score; newBest = true;
      try { localStorage.setItem(BEST_KEY, String(best)); } catch (e) { /* ignore */ }
    }
    elBest.textContent = best;
    ovTitle.textContent = 'ゲームオーバー';
    ovText.innerHTML = `レベル <b class="hl">${level}</b> まで到達<br>スコア <b class="hl">${score}</b>${newBest ? '<br>🎉 ハイスコア更新！' : ''}`;
    startBtn.textContent = 'もう一度あそぶ';
    overlay.classList.remove('hidden');
  }
```

今回のスコアがハイスコアを超えていたら、`best` を更新して localStorage に保存します。テンプレート文字列 `` `...${式}...` `` の中で `? :`（三項演算子）を使い、更新したときだけ「🎉 ハイスコア更新！」の1行を足しています。

`updateHud()` を **書きかえ** て、スコアと、プレイ中にハイスコアを超えたときの BEST も表示します。

```js:game.js
  function updateHud() {
    elLevel.textContent = level;
    elScore.textContent = score;
    elMoves.textContent = Math.max(0, movesLeft);
    elLives.textContent = '♥'.repeat(Math.max(0, lives)) + '♡'.repeat(Math.max(0, 3 - lives));
    if (score > best && state !== 'title') elBest.textContent = score;
  }
```

## パーティクル

`updateHud()` の **下**、`// ---------- render ----------` の **上** に追加します。

```js:game.js
  // ---------- particles ----------
  function burst(x, y, n) {
    for (let i = 0; i < n; i++) {
      const a = Math.random() * Math.PI * 2, sp = 1 + Math.random() * 3;
      particles.push({ x: x + 0.5, y: y + 0.5, vx: Math.cos(a) * sp, vy: Math.sin(a) * sp, life: 0.6 + Math.random() * 0.4 });
    }
  }
```

マス (x, y) の中心から、ランダムな向き `a`（ラジアン）とランダムな速さ `sp` で飛び出す粒を `n` 個作ります。`Math.cos(a)`・`Math.sin(a)` で向きを x と y の速さに分けます。位置と速さは **マス単位** で持っているので、描くときに `cell` をかけます。`life` は残りの寿命です。

`draw()` の、ボールを描いた行の **下**（`// progress bar` の **上**）に、粒を描く処理を追加します。

```js:game.js
    // particles
    for (const p of particles) {
      ctx.globalAlpha = Math.max(0, p.life);
      ctx.fillStyle = `hsl(${hue},90%,70%)`;
      ctx.beginPath(); ctx.arc(p.x * cell, p.y * cell, cell * 0.08, 0, Math.PI * 2); ctx.fill();
    }
    ctx.globalAlpha = 1;
```

寿命が短くなるほど透明にします。

`loop()` を、次のように **書きかえ** ます。`if (anim) { ... }` の中に2行、その下に2行が増えています。

```js:game.js
  function loop(t) {
    const dt = Math.min(0.05, (t - lastT) / 1000); lastT = t;
    if (anim) {
      const speed = 16; // cells per second
      anim.t += dt * speed;
      const d = Math.min(anim.t, anim.dist);
      ball.px = anim.sx + anim.dx * d; ball.py = anim.sy + anim.dy * d;
      const passed = Math.floor(d + 0.5);
      for (let k = 1; k <= passed; k++) paint(anim.sx + anim.dx * k, anim.sy + anim.dy * k);
      elScore.textContent = score;
      if (score > best) elBest.textContent = score;
      if (anim.t >= anim.dist) finishMove();
    }
    for (const p of particles) { p.x += p.vx * dt; p.y += p.vy * dt; p.vx *= 0.92; p.vy *= 0.92; p.life -= dt * 1.5; }
    particles = particles.filter((p) => p.life > 0);
    if (flash > 0) flash = Math.max(0, flash - dt * 0.9);
    if (toast) { toast.t -= dt; if (toast.t <= 0) toast = null; }
    if (grid) draw();
    requestAnimationFrame(loop);
  }
```

- 転がりながらマスをぬるたびにスコアが増えるので、そのつど SCORE の表示も書きかえます
- 粒は「位置 += 速さ × dt」で動かし、速さに 0.92 をかけて少しずつ減速させます。寿命が尽きた粒は `filter` で配列から取りのぞきます

## Enter / Space キーでスタート

`keydown` の中の `if (state !== 'play') return;` を、次のように **書きかえ** ます。

```js:game.js
    if (state !== 'play') {
      if ((k === 'Enter' || k === ' ') && (state === 'title' || state === 'over')) { e.preventDefault(); startGame(); }
      return;
    }
```

タイトル画面とゲームオーバー画面のときだけ、Enter か Space でスタートできます。`e.preventDefault()` で、Space キーでページがスクロールするのを止めます。

これで、このゲームの完成です！ ゲーム本体の `game.js` と見比べてみてください。同じ内容になっているはずです。

> [!CHECK] 動作チェック
> - スタートすると「ポン」と音が鳴り、転がるたびに音が鳴る（遠くまで転がるほど高い音）
> - 転がってぬるたびに SCORE が1ずつ増え、止まった場所から小さな粒が飛び散る
> - クリアすると3音のファンファーレが鳴り、迷路じゅうに粒が散って、ボーナス点（レベル1なら 110 + 残り手数 × 20）が入る
> - ゲームオーバー画面に「スコア」が表示され、ハイスコアを超えていれば「🎉 ハイスコア更新！」と出る
> - ページを再読み込みしても BEST の数字が残っている
> - タイトル画面やゲームオーバー画面で Enter か Space を押すとスタートできる

## 改造アイデア

> [!TIP]
> **転がる速さを変える**: `loop()` の `const speed = 16;` を 8 にするとのんびり、30 にするとキビキビ転がります。手数の多いレベルでは速いほうが遊びやすいかもしれません。

> [!TIP]
> **難しさを調整する**: `loadLevel()` の手数のおまけ `Math.max(2, 6 - Math.floor(level / 3))` を `Math.max(0, ...)` にすると、高いレベルでは「最短手数ぴったり」でしか解けない、上級者向けの迷路になります。

> [!TIP]
> **残り手数の星評価**: クリアしたときの `movesLeft` を使って、「おまけを1手も使わなければ ★★★、半分なら ★★」のような評価を CLEAR! の下に出してみましょう。

> [!TIP]
> **アンドゥ（1手もどす）**: `tryMove()` で `anim` を作るときに、ボールの位置と `painted` のコピー（`painted.slice()`）、`paintedCount`、`movesLeft` を配列に積んでおけば、U キーで1手前に戻せます。

> [!TIP]
> **床の種類を増やす**: `grid` の値を「1 = ふつうの床」「2 = 氷（止まれず通りぬける）」「3 = 止まる床」のように増やして、`slide()` の止まる条件を変えると、新しいギミックが作れます。生成側の「答えをなぞる」処理も同じ `slide()` を使っているので、床の種類を生成時に決めてから `slide()` でなぞるようにすれば、ルールを変えても解ける迷路を作れます。
