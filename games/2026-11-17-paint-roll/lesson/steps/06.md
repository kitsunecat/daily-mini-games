## このステップのゴール

仮の迷路をやめて、**毎回ちがう迷路を自動で作る** ようにします。ただランダムに床を置くと、ボールが絶対に届かない床ができて「解けない迷路」になってしまいます。そこで、**ボールを実際に転がしながら迷路を掘る** ことで、必ず全部ぬれる迷路を作ります。クリアするとレベルが上がり、迷路が大きくなってぬる色も変わります。

## 定数を入れかえる

`MAP` の配列（コメントの行もふくめて）を **消して**、`DIRS` の **下** に2行追加します。

```js:game.js
  const DIRS = { up: [0, -1], down: [0, 1], left: [-1, 0], right: [1, 0] };
  const DIR_LIST = Object.values(DIRS);
  const HUES = [330, 200, 45, 140, 270, 15, 175, 300];
```

- `DIR_LIST` は `DIRS` の値だけを並べた配列 `[[0,-1],[0,1],[-1,0],[1,0]]` です。ランダムに向きを選ぶのに使います
- `HUES` はレベルごとにぬる色の色相です。ピンク・水色・黄色・緑…と順番に変わります

## rnd() と generate()

`// ---------- level generation ----------` の見出しのすぐ **下**（`slide()` の **上**）に `rnd()` を追加します。

```js:game.js
  function rnd(n) { return Math.floor(Math.random() * n); }
```

0 以上 n 未満の整数をランダムに返します。`rnd(4)` なら 0・1・2・3 のどれかです。

続けて、`slide()` の **下** に `generate()` を追加します。少し長いので、あとで3つに分けて説明します。

```js:game.js
  function generate(lv) {
    const iw = Math.min(5 + Math.floor((lv - 1) / 2), 9);
    const ih = Math.min(6 + Math.floor((lv - 1) / 2), 12);
    const w = iw + 2, h = ih + 2;
    const steps = Math.min(5 + lv * 2, 26);
    let bestLv = null, bestVal = -1;
    for (let attempt = 0; attempt < 60; attempt++) {
      const g = new Uint8Array(w * h);
      const sx = 1 + rnd(iw), sy = 1 + rnd(ih);
      g[sy * w + sx] = 1;
      let x = sx, y = sy, last = null;
      const seq = [];
      for (let s = 0; s < steps; s++) {
        let d;
        do { d = DIR_LIST[rnd(4)]; } while (last && d[0] === -last[0] && d[1] === -last[1]);
        const len = 1 + rnd(Math.max(2, Math.floor(Math.max(iw, ih) * 0.7)));
        let cx = x, cy = y;
        for (let k = 0; k < len; k++) {
          const nx = cx + d[0], ny = cy + d[1];
          if (nx < 1 || ny < 1 || nx > iw || ny > ih) break;
          cx = nx; cy = ny; g[cy * w + cx] = 1;
        }
        const [ex, ey] = slide(g, w, h, x, y, d[0], d[1]);
        if (ex === x && ey === y) continue;
        x = ex; y = ey; last = d; seq.push(d);
      }
      // replay on final grid: only the cells the ball actually rolls over stay as floor
      const p = new Uint8Array(w * h);
      p[sy * w + sx] = 1;
      let rx = sx, ry = sy, moves = 0;
      for (const d of seq) {
        const [ex, ey] = slide(g, w, h, rx, ry, d[0], d[1], (cx, cy) => { p[cy * w + cx] = 1; });
        if (ex !== rx || ey !== ry) moves++;
        rx = ex; ry = ey;
      }
      let count = 0;
      for (let i = 0; i < p.length; i++) count += p[i];
      const val = count + moves * 3;
      if (count >= Math.min(iw * ih * 0.45, 8 + lv * 4) && moves >= 3 && val > bestVal) {
        bestVal = val; bestLv = { w, h, g: p, sx, sy, moves, count };
      }
    }
    if (!bestLv) return generate(Math.max(1, lv - 1));
    return bestLv;
  }
```

### ① 大きさと手数を決める

- `iw`・`ih` は床を置ける内側の大きさです。レベル1は 5×6 マスで、2レベルごとに1マスずつ広がり、9×12 で止まります。まわりを壁で1マスずつ囲むので、迷路全体は `w = iw + 2`、`h = ih + 2` です
- `steps` は「何回ボールを転がしながら掘るか」です。レベルが上がるほど増えます

### ② ボールを転がしながら掘る

まっ黒（全部壁）の迷路 `g` から始めて、ランダムなスタート地点だけ床にします。そして `steps` 回、次のことをくり返します。

1. ランダムな向き `d` を選ぶ。ただし直前の逆向き（来た道をもどるだけの動き）は選ばない
2. その向きに、ランダムな長さ `len` だけ床を **掘る**（`g` を 1 にする）。内側からはみ出しそうなら、そこでやめる
3. 掘った迷路の上で、ボールを `slide()` で **本当に転がして**、止まる場所 `ex, ey` を求める
4. 動けたら、ボールをそこに進め、向きを `seq`（手順の記録）に追加する

掘った道の先が壁なら、ボールはちょうど掘った端で止まります。でも、たまたま先に別の床がつながっていると、もっと先まで転がってしまいます。そこで「掘った長さ」ではなく、**slide() で計算した本当の止まる場所** を使うのがポイントです。

### ③ 答えをなぞって、通らない床を消す

掘っている途中で道がつながったりすると、「掘ったけれどボールが一度も通らない床」ができることがあります。そんな床があると、絶対にぬれないので解けません。

そこで、完成した迷路 `g` の上で、記録しておいた手順 `seq` をもう一度スタートから **なぞり直し**、ボールが通ったマスだけを新しい迷路 `p` の床にします（`slide()` の `cb` で `p` に 1 を書きます）。通った床だけを残すので、`seq` の手順で必ず全部ぬれる迷路になります。

`p` は `g` より床が少なくなるだけなので、`p` の上でも `seq` の手順は同じように動きます（止まる場所の先は、もともと `g` で壁か外だったからです）。

### 60回作って、いちばんよいものを選ぶ

ランダムなので、床が少なすぎる迷路や、すぐ終わる迷路もできます。そこで60回作ってみて、

- 床の数 `count` が十分ある（内側の 45%、または `8 + lv * 4` マス以上）
- 動いた回数 `moves` が3回以上

という条件を満たすものの中から、「床の数 + 手数 × 3」がいちばん大きいものを選びます。1つも条件を満たさなかったら、1つ下のレベルの設定でやり直します。

返す値 `{ w, h, g: p, sx, sy, moves, count }` の `moves` は「この迷路を解ける手数」です。ステップ7で手数の上限を決めるのに使います。

## loadLevel() を書きかえる

`loadLevel()` を **まるごと書きかえ** ます。

```js:game.js
  function loadLevel(fresh) {
    if (fresh || !loadLevel.cache) loadLevel.cache = generate(level);
    const L = loadLevel.cache;
    W = L.w; H = L.h; grid = L.g;
    painted = new Uint8Array(W * H);
    toPaint = L.count; paintedCount = 0;
    start = { x: L.sx, y: L.sy };
    ball = { x: L.sx, y: L.sy, px: L.sx, py: L.sy };
    paint(L.sx, L.sy);
    anim = null; queued = null;
    hue = HUES[(level - 1) % HUES.length];
    resize();
    updateHud();
  }
```

- 引数 `fresh` が `true` なら新しい迷路を作ります。`false` なら、前に作った迷路（`loadLevel.cache`）を使い回します。ステップ7の「やり直し」で、同じ迷路にもう一度挑戦するためです。関数もオブジェクトなので、`loadLevel.cache` のように **関数自身にプロパティ** を持たせることができます
- レベルに合わせて `hue` を変えるので、ボールとぬる色がレベルごとに変わります
- 最後に `updateHud()` で、画面上の LEVEL などを書きかえます

## ゲームの流れを直す

`startGame()` の `overlay.classList.add('hidden');` の **下** に1行足して、スタートのたびに新しい迷路を作ります。

```js:game.js
  function startGame() {
    level = 1; score = 0; lives = 3;
    state = 'play';
    overlay.classList.add('hidden');
    loadLevel(true);
  }
```

`levelClear()` を **書きかえ** て、次のレベルへ進むようにします。そのすぐ **下** に `updateHud()` も追加します。

```js:game.js
  function levelClear() {
    state = 'clear';
    flash = 1;
    updateHud();
    setTimeout(() => {
      if (state !== 'clear') return;
      level++; state = 'play'; loadLevel(true);
    }, 1100);
  }

  function updateHud() {
    elLevel.textContent = level;
  }
```

`updateHud()` は「画面上の数字を、今の変数の値に合わせる」関数です。今は LEVEL だけですが、ステップ7・8で手数・ライフ・スコアを足していきます。

最後に、いちばん下の `level = 1; loadLevel();` を **書きかえ** ます。

```js:game.js
  level = 1; loadLevel(true);
```

> [!CHECK] 動作チェック
> - 再読み込みするたびに、ちがう形の迷路が出てくる
> - どの迷路も、うまく順番を考えれば床を全部ぬれる（行き止まりのような、どうやっても届かない床が無い）
> - クリアすると LEVEL が 2 になり、ボールとぬる色が水色に変わる
> - レベルが上がるにつれて、迷路が少しずつ大きくなる
