## このステップのゴール

3つのファイルを用意して、ゲーム画面の土台を作ります。上に「LEVEL・SCORE・BEST」と「手数のこり・ライフ・やり直しボタン」、まん中にゲームを描く **Canvas**（キャンバス）とその上に重ねるタイトル画面（オーバーレイ）、下にひとことヒントを置き、Canvas に迷路の「わく」を描くところまで進めます。

完成すると、こんなゲームになります。

- 迷路の上にボールが1つ。上下左右にスワイプ（PC は矢印キーかドラッグ）すると、ボールは **壁にぶつかるまで止まらずに** 転がる
- ボールが通った床には色がぬられる。迷路の床を **全部ぬる** とレベルクリア
- 1レベルで使える **手数** には限りがあり、使い切るとライフが1つ減ってやり直し。ライフが0でゲームオーバー
- 迷路は毎回自動で作られ、レベルが上がるほど大きく、複雑になる

## game.js

JavaScript はまず「画面の大きさに合わせて Canvas を用意し、毎フレーム描く」ところまでを書きます。

```js:game.js
(() => {
  'use strict';
  const cv = document.getElementById('cv');
  const ctx = cv.getContext('2d');
  const stage = document.getElementById('stage');
  const $ = (id) => document.getElementById(id);
  const elLevel = $('level'), elScore = $('score'), elBest = $('best'), elMoves = $('moves'), elLives = $('lives');
  const overlay = $('overlay'), ovTitle = $('ov-title'), ovText = $('ov-text'), startBtn = $('start');

  // ---------- state ----------
  let state = 'title'; // title | play | clear | over
  let level = 1, score = 0, lives = 3;
  let W = 0, H = 0, grid = null, painted = null, toPaint = 0, paintedCount = 0;
  let hue = 330;
  let cell = 30, ox = 0, oy = 0;

  // ---------- game flow ----------
  function startGame() {
    level = 1; score = 0; lives = 3;
    state = 'play';
    overlay.classList.add('hidden');
  }

  // ---------- render ----------
  function resize() {
    const r = stage.getBoundingClientRect();
    const aw = Math.max(100, r.width - 16), ah = Math.max(100, r.height - 12);
    const gw = W || 7, gh = H || 8;
    cell = Math.floor(Math.min(aw / gw, ah / gh, 56));
    const dpr = window.devicePixelRatio || 1;
    cv.width = gw * cell * dpr; cv.height = gh * cell * dpr;
    cv.style.width = gw * cell + 'px'; cv.style.height = gh * cell + 'px';
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
  }

  function roundRect(x, y, w, h, r) {
    ctx.beginPath();
    ctx.moveTo(x + r, y);
    ctx.arcTo(x + w, y, x + w, y + h, r);
    ctx.arcTo(x + w, y + h, x, y + h, r);
    ctx.arcTo(x, y + h, x, y, r);
    ctx.arcTo(x, y, x + w, y, r);
    ctx.closePath();
  }

  function draw() {
    // 仮の draw（ステップ2で書きかえる）
    const gw = (W || 7) * cell, gh = (H || 8) * cell;
    ctx.clearRect(0, 0, gw, gh);
    ctx.fillStyle = '#1d4e63';
    roundRect(0, 0, gw, gh, cell * 0.3); ctx.fill();
  }

  // ---------- loop ----------
  let lastT = performance.now();
  function loop(t) {
    const dt = Math.min(0.05, (t - lastT) / 1000); lastT = t;
    draw();
    requestAnimationFrame(loop);
  }

  // ---------- input ----------
  startBtn.addEventListener('click', startGame);
  window.addEventListener('resize', () => { resize(); });

  resize();
  requestAnimationFrame(loop);
})();
```

### 全体を (() => { ... })(); で囲む

ファイル全体を「すぐ実行される関数」で囲むと、中で作った変数がページ全体（グローバル）に漏れません。`'use strict';` は、うっかりミスをエラーとして教えてくれるモードです。

### $ と要素の取り出し

`const $ = (id) => document.getElementById(id);` は、長い `document.getElementById` を `$('level')` と短く書くための小さな関数です。HUD（スコアなどの表示）の要素は最初にまとめて取り出しておきます。`elScore` などはステップ7・8で使います。

### 状態（state）の変数

- `state` はゲームの今の場面です。`'title'`（タイトル）→ `'play'`（プレイ中）→ `'clear'`（クリア演出中）→ `'over'`（ゲームオーバー）と変わります
- `W`・`H` は迷路のマス数（横・縦）、`grid` は迷路そのもの、`painted` はぬったマスの記録です。ステップ2で中身を入れます
- `hue` はぬる色の **色相**（0〜360 の色の角度）です。`hsl(330, 80%, 62%)` のように使います
- `cell` は1マスの大きさ（ピクセル）です。`ox`・`oy` はこのゲームでは使いませんが、完成品に合わせて置いてあります

### resize() … マスの大きさを決める

ステージの大きさを `getBoundingClientRect()` で測り、迷路（横 `gw` マス × 縦 `gh` マス）がはみ出さない最大のマスの大きさ `cell` を求めます。大きすぎないよう 56px で頭打ちにしています。迷路がまだ無いうちは 7×8 マスとして計算します（`W || 7` は「W が 0 なら 7」という意味です）。

`devicePixelRatio`（dpr）は、スマホなどの高精細な画面で「CSS の1ピクセルが実際は何ドットか」を表す数です。Canvas の **中身のピクセル数** は dpr 倍にして、**見た目の大きさ**（`style.width`）は CSS ピクセルのままにすると、ぼやけずにくっきり描けます。`ctx.setTransform(dpr, 0, 0, dpr, 0, 0)` で座標を dpr 倍しておけば、描くときは CSS ピクセルのまま考えられます。

### roundRect() … 角の丸い四角

`arcTo()` を4回使って、角の丸い四角の「形（パス）」を作る関数です。このあと `ctx.fill()` で塗ります。床のタイルや迷路のわくなど、何度も使います。

### loop() … 毎フレームの処理

`requestAnimationFrame(loop)` は「次に画面を描きかえるタイミングで loop を呼んで」とブラウザに頼む命令です。loop の最後でもう一度頼むので、1秒に約60回 loop がくり返されます。引数 `t` はミリ秒単位の時刻で、前回との差から **経過時間 dt**（秒）を求めています。dt はステップ4のアニメーションで使います。タブを切りかえて戻ったときに大きくなりすぎないよう、0.05 秒で頭打ちにしています。
