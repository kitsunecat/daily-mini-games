## このステップのゴール

スマホでは **スワイプ**、PC では **マウスでドラッグ** して、ボールを転がせるようにします。指（マウス）を動かした向きのうち、縦と横の大きいほうを採用します。

## スワイプの判定

`// ---------- input ----------` の見出しのすぐ **下**（`keydown` の **上**）に追加します。

```js:game.js
  let touchStart = null;
  function onDown(x, y) { touchStart = { x, y }; }
  function onUp(x, y) {
    if (!touchStart) return;
    const dx = x - touchStart.x, dy = y - touchStart.y;
    touchStart = null;
    if (Math.max(Math.abs(dx), Math.abs(dy)) < 20) return;
    if (Math.abs(dx) > Math.abs(dy)) tryMove(dx > 0 ? 'right' : 'left');
    else tryMove(dy > 0 ? 'down' : 'up');
  }
  stage.addEventListener('pointerdown', (e) => { if (state === 'play') { onDown(e.clientX, e.clientY); } });
  window.addEventListener('pointerup', (e) => onUp(e.clientX, e.clientY));
  window.addEventListener('pointercancel', () => { touchStart = null; });
  // also handle swipe mid-drag for snappier feel
  window.addEventListener('pointermove', (e) => {
    if (!touchStart) return;
    const dx = e.clientX - touchStart.x, dy = e.clientY - touchStart.y;
    if (Math.max(Math.abs(dx), Math.abs(dy)) >= 40) onUp(e.clientX, e.clientY);
  });
```

### pointer イベント

`pointerdown`・`pointermove`・`pointerup` は、**マウスでもタッチでもペンでも同じように届く** イベントです。`mousedown` と `touchstart` を別々に書かなくてすみます。`e.clientX`・`e.clientY` は、画面の左上からの指（マウス）の位置です。

### 向きの決め方

1. 押した瞬間の位置を `touchStart` に覚えます（`onDown`）
2. 離した位置との差 `dx`・`dy` を計算します（`onUp`）
3. 動きが 20px 未満なら、ただのタップとみなして何もしません
4. 横の動き `|dx|` のほうが大きければ左右、そうでなければ上下に転がします

ななめにスワイプしても、大きいほうの向きに決まるので、操作がぶれにくくなります。

### 指を離す前に反応させる

`pointermove` で、動かした量が 40px を超えたら、離すのを待たずに `onUp()` を呼んでいます。`onUp()` の中で `touchStart = null` にするので、1回のスワイプで2回動くことはありません。指を離す前にボールが動き出すので、ぐっと気持ちよく操作できます。

### 押し始めはステージの上だけ

`pointerdown` は `stage`（迷路のまわり）にだけ登録しています。上の「やり直し」ボタンを押したときにスワイプとまちがえないためです。一方、`pointerup` と `pointermove` は `window` に登録して、指がステージの外に出ても最後まで追いかけます。`pointercancel` は、電話の着信などで操作が中断されたときに届くので、覚えていた位置を消しておきます。

> [!CHECK] 動作チェック
> - PC でステージの上をマウスで右にドラッグすると、ボールが右に転がる
> - 少しクリックしただけ（20px 未満）では動かない
> - スマホ（または開発者ツールのデバイスモード）で上下左右にスワイプすると、その向きに転がる
> - ななめにスワイプしても、大きく動かしたほうの向きに転がる
