## このステップのゴール

手で書いた小さな迷路を読みこみ、**壁・床・ボール** を Canvas に描きます。スタート地点の床だけは、最初から色がぬられた状態にします。迷路の自動生成はステップ6で作るので、それまではこの「仮の迷路」で遊びます。

## 仮の迷路を文字で書く

`const overlay = ...` の行の **下** に追加します。

```js:game.js
  // 仮の迷路（# が壁、. が床、S がスタート。ステップ6で自動生成に置きかえる）
  const MAP = [
    '#######',
    '#S...##',
    '#.##..#',
    '#.#...#',
    '#.#.#.#',
    '#...#.#',
    '##....#',
    '#######',
  ];
```

文字列の配列にすると、迷路の形が目で見て分かります。いちばん外側は必ず壁（`#`）で囲んでおきます。こうすると「迷路の外に出る」心配をしなくてすみます。

## ボールの変数を足す

`// ---------- state ----------` の `let W = 0, H = 0, ...` の行の **下** に追加します。

```js:game.js
  let ball = { x: 0, y: 0, px: 0, py: 0 };
  let start = { x: 0, y: 0 };
```

- `ball.x`・`ball.y` は、ボールがいる **マス** の位置（整数）です
- `ball.px`・`ball.py` は、**描くときの** 位置です。今はマスの位置と同じですが、ステップ4で転がっている途中の 2.5 マス目のような小数になります
- `start` はスタート地点です

## loadLevel() と paint()

`let cell = 30, ox = 0, oy = 0;` の **下**、`// ---------- game flow ----------` の **上** に、新しい見出しと2つの関数を追加します。

```js:game.js
  // ---------- level generation ----------
  function loadLevel() {
    H = MAP.length; W = MAP[0].length;
    grid = new Uint8Array(W * H);
    let sx = 1, sy = 1, count = 0;
    for (let y = 0; y < H; y++) for (let x = 0; x < W; x++) {
      const ch = MAP[y][x];
      if (ch !== '#') { grid[y * W + x] = 1; count++; }
      if (ch === 'S') { sx = x; sy = y; }
    }
    painted = new Uint8Array(W * H);
    toPaint = count; paintedCount = 0;
    start = { x: sx, y: sy };
    ball = { x: sx, y: sy, px: sx, py: sy };
    paint(sx, sy);
    resize();
  }

  function paint(x, y) {
    const i = y * W + x;
    if (!painted[i]) {
      painted[i] = 1; paintedCount++;
      return true;
    }
    return false;
  }
```

### マス目を1次元の配列で持つ

迷路は「縦 H 行 × 横 W 列」の表ですが、ここでは長さ `W * H` の **1本の配列** で持ちます。(x, y) のマスは `y * W + x` 番目です。たとえば W = 7 なら、(0, 0) は 0 番、(1, 0) は 1 番、(0, 1) は 7 番になります。1行ずつ横に並べて、つなげたイメージです。

`Uint8Array` は 0〜255 の整数だけを入れられる配列で、作った時点で全部 0 になっています。`grid` は「床なら 1、壁なら 0」、`painted` は「ぬってあれば 1」です。

### 床の数を数えておく

`toPaint` は「ぬる必要がある床の数」、`paintedCount` は「いまぬってある床の数」です。この2つが等しくなったらクリアです。毎回全部のマスを数え直さなくてすむように、数を持っておきます。

### paint() はぬれたら true を返す

すでにぬってあるマスは数えないように、`painted[i]` を確かめてから 1 にします。新しくぬれたときだけ `true` を返すので、あとで「新しくぬれたら点数を足す」ような使い方ができます。

## draw() を書きかえる

ステップ1の仮の `draw()` を、まるごと **書きかえ** ます。

```js:game.js
  function draw() {
    const gw = W * cell, gh = H * cell;
    ctx.clearRect(0, 0, gw, gh);
    // walls background
    ctx.fillStyle = '#1d4e63';
    roundRect(0, 0, gw, gh, cell * 0.3); ctx.fill();
    // wall pattern
    ctx.fillStyle = 'rgba(255,255,255,0.04)';
    for (let y = 0; y < H; y++) for (let x = 0; x < W; x++) {
      if (!grid[y * W + x] && (x + y) % 2 === 0) ctx.fillRect(x * cell, y * cell, cell, cell);
    }
    const pad = Math.max(1, cell * 0.04);
    for (let y = 0; y < H; y++) for (let x = 0; x < W; x++) {
      const i = y * W + x;
      if (!grid[i]) continue;
      ctx.fillStyle = painted[i] ? `hsl(${hue},80%,62%)` : '#e9eef1';
      roundRect(x * cell + pad, y * cell + pad, cell - pad * 2, cell - pad * 2, cell * 0.18);
      ctx.fill();
      if (painted[i]) {
        ctx.fillStyle = 'rgba(255,255,255,0.18)';
        ctx.fillRect(x * cell + pad * 2, y * cell + pad * 2, cell - pad * 4, (cell - pad * 4) * 0.3);
      }
    }
    // ball
    const bx = (ball.px + 0.5) * cell, by = (ball.py + 0.5) * cell, br = cell * 0.36;
    ctx.fillStyle = 'rgba(0,0,0,0.25)';
    ctx.beginPath(); ctx.ellipse(bx, by + br * 0.75, br * 0.85, br * 0.3, 0, 0, Math.PI * 2); ctx.fill();
    const grad = ctx.createRadialGradient(bx - br * 0.35, by - br * 0.4, br * 0.1, bx, by, br);
    grad.addColorStop(0, `hsl(${hue},100%,85%)`);
    grad.addColorStop(1, `hsl(${hue},75%,42%)`);
    ctx.fillStyle = grad;
    ctx.beginPath(); ctx.arc(bx, by, br, 0, Math.PI * 2); ctx.fill();
  }
```

- まず全体を壁の色でぬり、そのうえで壁のマスに市松もよう（`(x + y) % 2 === 0` のマスだけ少し明るく）をつけます
- 床のマスは、ぬってあれば `hsl(hue, 80%, 62%)` の色、まだなら白っぽい灰色で、少し内側（`pad`）に角の丸いタイルとして描きます。ぬったタイルの上部には半透明の白をのせて、ぷっくりした光沢を出しています
- マス (x, y) の左上の座標は `(x * cell, y * cell)`、マスの中心は `((x + 0.5) * cell, (y + 0.5) * cell)` です
- ボールは、影（つぶれただ円 `ellipse`）→ 本体（円 `arc`）の順に描きます。`createRadialGradient` は円形のグラデーションで、左上を明るくすると立体的な球に見えます

## 迷路を読みこんでから描く

`// ---------- loop ----------` の `loop()` の中の `draw();` を、次のように **書きかえ** ます。

```js:game.js
    if (grid) draw();
```

迷路がまだ無い（`grid` が `null`）ときに描こうとしてエラーにならないようにします。

いちばん下の部分も **書きかえ** ます。`window.addEventListener('resize', ...)` から最後までを、次のようにします。

```js:game.js
  window.addEventListener('resize', () => { if (grid) resize(); });

  // title background: show a sample level
  level = 1; loadLevel();
  requestAnimationFrame(loop);
})();
```

`loadLevel()` の最後で `resize()` を呼ぶので、ここで直接 `resize()` を呼ぶ必要はなくなりました。タイトル画面の後ろにも、迷路がうっすら見えるようになります。

> [!CHECK] 動作チェック
> - タイトル画面のうしろに迷路が透けて見える
> - 「タップでスタート」を押すと、白い床と暗い壁の迷路、左上にピンクのボールが表示される
> - ボールがいるスタートのマスだけ、ピンクにぬられている
> - `MAP` の `.` を `#` に変えたり、`S` の位置を変えたりすると、そのとおりの迷路になる
