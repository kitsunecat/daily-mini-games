## このステップのゴール

矢印キー（または WASD）を押すと、ボールが **壁にぶつかるまで** 一気に進み、通った床に色がぬられるようにします。床を全部ぬったら「CLEAR!」と表示して、迷路を最初からやり直します。このステップではボールはワープするように一瞬で移動し、ステップ4でころころ転がるようにします。

## 向きの表

`MAP` の配列の **下** に追加します。

```js:game.js
  const DIRS = { up: [0, -1], down: [0, 1], left: [-1, 0], right: [1, 0] };
```

向きの名前と「1マス進むと x と y がいくつ変わるか」の対応表です。Canvas の y は **下向きが正** なので、上は `[0, -1]` です。

## クリア演出用の変数

`let cell = 30, ox = 0, oy = 0;` の **下** に追加します。

```js:game.js
  let flash = 0;
```

クリアした瞬間に 1 にして、少しずつ 0 に戻していく「光りぐあい」です。

## slide() … 壁にぶつかるまで進む

`// ---------- level generation ----------` の見出しのすぐ **下**（`loadLevel()` の **上**）に追加します。このゲームでいちばん大事な関数です。

```js:game.js
  function slide(g, w, h, x, y, dx, dy, cb) {
    while (true) {
      const nx = x + dx, ny = y + dy;
      if (nx < 0 || ny < 0 || nx >= w || ny >= h || !g[ny * w + nx]) break;
      x = nx; y = ny;
      if (cb) cb(x, y);
    }
    return [x, y];
  }
```

1. 今いる (x, y) から、向き (dx, dy) に1マス先 (nx, ny) を調べます
2. そこが迷路の外か、壁（`g[...]` が 0）なら、そこで止まります（`break`）
3. 床なら1マス進み、`cb`（コールバック）が渡されていれば、そのマスの座標で呼びます
4. 最後に止まった場所を `[x, y]` の配列で返します

迷路 `g` と大きさ `w`・`h` を **引数で受け取る** のがポイントです。グローバルの `grid` を直接使わないので、ステップ6で「まだ作りかけの迷路」に対しても同じ関数を使えます。`cb` は「通ったマスごとにしたいこと」を外から渡すしくみで、ここではマスをぬるのに使います。

## tryMove() と levelClear()

`// ---------- game flow ----------` の `startGame()` の **下** に追加します。

```js:game.js
  function tryMove(name) {
    if (state !== 'play') return;
    const [dx, dy] = DIRS[name];
    const [ex, ey] = slide(grid, W, H, ball.x, ball.y, dx, dy, (x, y) => paint(x, y));
    if (ex === ball.x && ey === ball.y) return;
    // いまは一瞬でワープ（ステップ4でころころ転がす）
    ball.x = ex; ball.y = ey; ball.px = ex; ball.py = ey;
    if (paintedCount >= toPaint) levelClear();
  }

  function levelClear() {
    state = 'clear';
    flash = 1;
    setTimeout(() => {
      if (state !== 'clear') return;
      state = 'play'; loadLevel();
    }, 1100);
  }
```

- `const [dx, dy] = DIRS[name];` は **分割代入** です。配列の 0 番目を `dx`、1 番目を `dy` に入れます
- `slide()` の `cb` に `(x, y) => paint(x, y)` を渡して、通ったマスをぬります
- 止まる場所が今と同じ（すぐ隣が壁）なら、何もしません
- 床を全部ぬったら `levelClear()` へ。`setTimeout(関数, 1100)` で 1.1 秒後に迷路を読みこみ直します。待っている間に別の場面に変わっていたら何もしないよう、`state` を確かめています

## CLEAR! を描く

`draw()` の最後、ボールを描く `ctx.beginPath(); ctx.arc(bx, by, br, ...); ctx.fill();` の行の **下** に追加します。

```js:game.js
    if (flash > 0) {
      ctx.fillStyle = `rgba(255,255,255,${flash * 0.35})`;
      ctx.fillRect(0, 0, gw, gh);
      ctx.fillStyle = `rgba(255,255,255,${Math.min(1, flash * 2)})`;
      ctx.font = `bold ${Math.floor(cell * 0.9)}px system-ui, sans-serif`;
      ctx.textAlign = 'center'; ctx.textBaseline = 'middle';
      ctx.fillText('CLEAR!', gw / 2, gh / 2);
    }
```

`flash` が大きいほど白く光らせます。文字は `flash * 2` を 1 で頭打ちにしているので、しばらくはっきり見えてから消えていきます。`textAlign = 'center'` と `textBaseline = 'middle'` で、文字の中心を (gw/2, gh/2) に合わせます。

`loop()` の `if (grid) draw();` の **上** に、flash を減らす1行を足します。

```js:game.js
    if (flash > 0) flash = Math.max(0, flash - dt * 0.9);
```

`dt`（経過時間）をかけるので、パソコンの速さにかかわらず約1.1秒で 0 に戻ります。

## キーボードで動かす

`// ---------- input ----------` の見出しのすぐ **下** に追加します。

```js:game.js
  window.addEventListener('keydown', (e) => {
    const k = e.key;
    if (state !== 'play') return;
    const map = { ArrowUp: 'up', w: 'up', W: 'up', ArrowDown: 'down', s: 'down', S: 'down', ArrowLeft: 'left', a: 'left', A: 'left', ArrowRight: 'right', d: 'right', D: 'right' };
    if (map[k]) { e.preventDefault(); tryMove(map[k]); }
  });
```

`e.key` には押したキーの名前（`'ArrowUp'` や `'w'`）が入ります。対応表 `map` で向きの名前に変えて `tryMove()` に渡します。`e.preventDefault()` は、矢印キーでページがスクロールするのを止めます。

> [!CHECK] 動作チェック
> - スタート後、→ キーを押すと、ボールが右へ壁の手前まで一気に移動し、通った床がピンクになる
> - すぐ隣が壁の方向のキーを押しても、何も起きない
> - ↓ ↑ → ↓ → ↑ ↓ ← ↑ → ↑ の順に押すと、全部の床がぬれて「CLEAR!」が光り、約1秒後に迷路がスタートの状態に戻る
