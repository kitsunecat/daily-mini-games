## このステップのゴール

このままでは何回でも転がせるので、考えなくてもいつかは解けてしまいます。そこで、1レベルで使える **手数** に上限をつけます。手数を使い切ったらライフが1つ減って同じ迷路をやり直し、ライフが0になったらゲームオーバーです。行きづまったときに自分でやり直せる **「やり直し」ボタン**（R キー）も作ります。

## 手数の変数

`let start = { x: 0, y: 0 };` の **下** に追加します。

```js:game.js
  let movesLeft = 0, moveLimit = 0;
```

`moveLimit` はそのレベルの手数の上限、`movesLeft` はのこりの手数です。

## 手数の上限を決める

`loadLevel()` の `paint(L.sx, L.sy);` の **下** に2行追加します。

```js:game.js
    moveLimit = L.moves + Math.max(2, 6 - Math.floor(level / 3));
    movesLeft = moveLimit;
```

`L.moves` は、迷路を作ったときにボールが動いた回数、つまり「この手数あれば必ず解ける」という数です。そこに **おまけ** を足して上限にします。おまけはレベル1〜2で6手、レベルが3上がるごとに1手ずつ減り、最低でも2手は残します。レベルが上がるほど、むだな動きが許されなくなります。

## 転がるたびに手数を減らす

`tryMove()` を、次のように **書きかえ** ます（`movesLeft--;` と `updateHud();` の2行が増えています）。

```js:game.js
  function tryMove(name) {
    if (state !== 'play') return;
    if (anim) { queued = name; return; }
    const [dx, dy] = DIRS[name];
    const [ex, ey] = slide(grid, W, H, ball.x, ball.y, dx, dy);
    if (ex === ball.x && ey === ball.y) return;
    movesLeft--;
    const dist = Math.abs(ex - ball.x) + Math.abs(ey - ball.y);
    anim = { dx, dy, sx: ball.x, sy: ball.y, tx: ex, ty: ey, t: 0, dist };
    updateHud();
  }
```

壁にぶつかって動けなかったときは `return` するので、手数は減りません。

`finishMove()` の `if (paintedCount >= toPaint) { levelClear(); return; }` の **下** に1行追加します。

```js:game.js
    if (movesLeft <= 0) { loseLife(); return; }
```

先にクリアを調べるので、**最後の1手でぬりきった** ときはちゃんとクリアになります。

## ライフ・ゲームオーバー・お知らせ表示

`levelClear()` の **下**、`updateHud()` の **上** に追加します。

```js:game.js
  function loseLife(manual) {
    lives--;
    if (lives <= 0) { gameOver(); return; }
    loadLevel(false);
    showToast(manual ? 'やり直し！' : '手数切れ！');
  }

  function gameOver() {
    state = 'over';
    updateHud();
    ovTitle.textContent = 'ゲームオーバー';
    ovText.innerHTML = `レベル <b class="hl">${level}</b> まで到達`;
    startBtn.textContent = 'もう一度あそぶ';
    overlay.classList.remove('hidden');
  }

  let toast = null;
  function showToast(text) { toast = { text, t: 1.2 }; }
```

- `loseLife()` は `loadLevel(false)` で **同じ迷路** を最初から読みこみ直します（ステップ6の `cache` がここで役に立ちます）。引数 `manual` は「自分でやり直したか」で、お知らせの文字を変えます
- `gameOver()` はタイトル画面のオーバーレイを使い回して、見出しと文章、ボタンの文字を書きかえてから表示します。ボタンを押すと `startGame()` が呼ばれるので、そのままもう一度遊べます
- **トースト**（toast）は、画面に少しの間だけ出るお知らせです。`t` は残り時間（秒）です

`updateHud()` を **書きかえ** て、手数とライフも表示します。

```js:game.js
  function updateHud() {
    elLevel.textContent = level;
    elMoves.textContent = Math.max(0, movesLeft);
    elLives.textContent = '♥'.repeat(Math.max(0, lives)) + '♡'.repeat(Math.max(0, 3 - lives));
  }
```

`'♥'.repeat(2)` は `'♥♥'` のように、文字列をくり返した文字列を作ります。残りのライフを ♥、失ったライフを ♡ で表します。

## トーストを描いて消す

`draw()` の `if (flash > 0) { ... }` のブロックの **下**（`draw()` の最後）に追加します。

```js:game.js
    if (toast) {
      ctx.globalAlpha = Math.min(1, toast.t * 2);
      ctx.fillStyle = 'rgba(0,0,0,0.6)';
      roundRect(gw / 2 - cell * 2.4, gh / 2 - cell * 0.6, cell * 4.8, cell * 1.2, cell * 0.3); ctx.fill();
      ctx.fillStyle = '#ffd166';
      ctx.font = `bold ${Math.floor(cell * 0.55)}px system-ui, sans-serif`;
      ctx.textAlign = 'center'; ctx.textBaseline = 'middle';
      ctx.fillText(toast.text, gw / 2, gh / 2);
      ctx.globalAlpha = 1;
    }
```

`ctx.globalAlpha` は、これから描くもの全部の不透明度です。残り時間が 0.5 秒を切ると、だんだん透明になって消えます。描き終わったら必ず 1 に戻しておきます。

`loop()` の `if (flash > 0) flash = ...;` の行の **下** に追加します。

```js:game.js
    if (toast) { toast.t -= dt; if (toast.t <= 0) toast = null; }
```

## やり直しボタンと R キー

`keydown` の中の `if (map[k]) { ... }` の行の **下** に、R キーの処理を足します。

```js:game.js
    if (map[k]) { e.preventDefault(); tryMove(map[k]); }
    else if (k === 'r' || k === 'R') retry();
  });
```

`keydown` の処理全体（`});`）の **下**、`startBtn.addEventListener(...)` の **上** に追加します。

```js:game.js
  function retry() {
    if (state !== 'play' || anim) return;
    if (paintedCount <= 1 && movesLeft === moveLimit) return;
    loseLife(true);
  }
  $('retry').addEventListener('click', retry);
```

やり直しは **ライフを1つ使う** ルールにしています。ただし、まだ1手も動かしていないときは、やり直しても意味がないので何もしません。転がっている最中も受けつけません。

> [!CHECK] 動作チェック
> - スタートすると「手数のこり」に数字が出て、転がるたびに1つ減る（壁にぶつかって動けないときは減らない）
> - 手数を使い切ると「手数切れ！」と表示され、♥ が1つ ♡ になって同じ迷路の最初からになる
> - 1手以上動かしてから「やり直し」ボタン（または R キー）を押すと「やり直し！」と出て、♥ が1つ減る
> - ♥ が全部なくなると「ゲームオーバー」の画面になり、「もう一度あそぶ」でレベル1から始められる
