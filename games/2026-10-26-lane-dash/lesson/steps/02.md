## このステップのゴール

「奥に行くほど小さく見える」 **遠近法（透視投影）** の計算を作り、地平線へ向かって細くなる3レーンの道路を描きます。あわせて遠くのビル群ともやも描いて、奥行きのある背景を完成させます。

## ゲームの世界の座標を決める

このゲームでは、画面のピクセルとは別に、ゲームの中の「世界の座標」を使います。

- `x` … 左右。真ん中のレーンが 0、左右のレーンが `-LANE_GAP` と `+LANE_GAP`
- `y` … 高さ。地面が 0 で、上に行くほど大きい
- `z` … 奥行き。プレイヤーの位置が 0 で、前方（奥）に行くほど大きい

障害物やコインは「どのレーンの、どれだけ前にあるか」で管理し、描くときだけ画面のピクセルに変換します。こうしておくと、当たり判定などのゲームの計算がとても単純になります。

ファイルの先頭、`'use strict';` の下に定数を2つ足します。

```js:game.js
  const LANE_GAP = 2.2;      // レーンの間隔（ワールド単位）
  const DEPTH = 28;          // 遠近感の強さ
```

## 投影の関数 `proj()`

`const horizon = () => H * 0.3;` の行を、次のブロックに **置き換えます**。

```js:game.js
  // ---------- 投影 ----------
  const horizon = () => H * 0.3;
  const groundY = () => H * 0.86;
  const unitPx = () => Math.min(W, H * 0.6) * 0.3 / LANE_GAP;
  function proj(x, y, z) {
    const t = 1 / (1 + Math.max(z, -DEPTH * 0.4) / DEPTH);
    return {
      x: W / 2 + x * unitPx() * t,
      y: horizon() + (groundY() - horizon()) * t - y * unitPx() * t,
      s: t,
    };
  }
```

`proj(x, y, z)` は世界の座標を受け取り、画面上の位置 `{ x, y }` と、その場所での縮尺 `s` を返します。

- `t = 1 / (1 + z / DEPTH)` が遠近法の心臓部です。`z = 0`（プレイヤーの足元）で `t = 1`、`z = DEPTH`（28 先）で `t = 0.5`、さらに遠くなるほど 0 に近づきます。**距離が倍になると見た目の大きさは約半分** という、現実の見え方に近い縮み方です。
- 画面の x は「画面中央 + 世界の x × 1単位のピクセル数 × t」。遠いものほど中央に寄っていきます。
- 画面の y は、`t = 1` のとき `groundY()`（画面下の方）、`t → 0` のとき `horizon()`（地平線）になるよう線形に補間しています。高さ `y` があるものは、その分だけ上にずらします（遠いほど小さく）。
- `unitPx()` は「足元で世界の1単位が何ピクセルか」です。画面の幅と高さの小さい方を基準にしているので、縦長でも横長でもバランスよく収まります。
- `Math.max(z, -DEPTH * 0.4)` は、プレイヤーより後ろ（z がマイナス）のものを描くときに、分母が 0 や負になって絵が反転するのを防ぐための安全装置です。

## ビル群のデータを作る

ビルの位置や高さはランダムに決めますが、毎フレーム変わるとチカチカするので、画面サイズが決まったときに1回だけ作って配列に入れておきます。`let W = 0, H = 0, dpr = 1;` の下に変数を足し、

```js:game.js
  let skyline = [];
```

`resize()` の最後（`ctx.setTransform(...)` の下）に追加します。

```js:game.js
    skyline = [];
    let x = -10;
    while (x < W + 10) {
      const w = 18 + Math.random() * 34;
      skyline.push({ x, w, h: 20 + Math.random() * 70, lit: Math.random() });
      x += w + 2;
    }
```

画面の左端から右端まで、幅 18〜52px のビルをすき間 2px で並べていきます。`lit` は窓に明かりをつけるかどうかを決める乱数です。

## 道路・レーン線・もやを描く

`draw()` 全体を次のように書き換えます。空と地面はステップ1と同じで、間にビル群、地面の後に道路とレーン線、最後にもやが増えています。

```js:game.js
  // ---------- 描画 ----------
  function draw() {
    if (!W) return;
    const hz = horizon(), gy = groundY();

    // 空
    const sky = ctx.createLinearGradient(0, 0, 0, hz);
    sky.addColorStop(0, '#1a1145');
    sky.addColorStop(1, '#ff7aa8');
    ctx.fillStyle = sky;
    ctx.fillRect(0, 0, W, hz + 1);
    ctx.fillStyle = 'rgba(255,230,160,0.9)';
    ctx.beginPath();
    ctx.arc(W * 0.78, hz * 0.45, Math.min(W, H) * 0.06, 0, Math.PI * 2);
    ctx.fill();

    // ビル群
    skyline.forEach((b) => {
      ctx.fillStyle = '#2a1d55';
      ctx.fillRect(b.x, hz - b.h, b.w, b.h);
      if (b.lit > 0.4) {
        ctx.fillStyle = 'rgba(255,224,120,0.55)';
        for (let yy = hz - b.h + 6; yy < hz - 6; yy += 10) {
          for (let xx = b.x + 4; xx < b.x + b.w - 4; xx += 8) {
            if (((xx * 7 + yy * 3) | 0) % 5 < 2) ctx.fillRect(xx, yy, 3, 4);
          }
        }
      }
    });

    // 地面
    ctx.fillStyle = '#1e2a3a';
    ctx.fillRect(0, hz, W, H - hz);
    const farL = proj(-LANE_GAP * 1.6, 0, 400), farR = proj(LANE_GAP * 1.6, 0, 400);
    const nearL = proj(-LANE_GAP * 1.6, 0, -6), nearR = proj(LANE_GAP * 1.6, 0, -6);
    ctx.fillStyle = '#3a3f58';
    ctx.beginPath();
    ctx.moveTo(farL.x, farL.y); ctx.lineTo(farR.x, farR.y);
    ctx.lineTo(nearR.x, nearR.y); ctx.lineTo(nearL.x, nearL.y);
    ctx.closePath();
    ctx.fill();

    // レーン線
    ctx.strokeStyle = 'rgba(120,240,255,0.55)';
    ctx.lineWidth = 2;
    [-0.5, 0.5].forEach((k) => {
      const f = proj(k * LANE_GAP, 0, 400), n = proj(k * LANE_GAP, 0, -6);
      ctx.beginPath(); ctx.moveTo(f.x, f.y); ctx.lineTo(n.x, n.y); ctx.stroke();
    });

    // 遠景フォグ
    const fog = ctx.createLinearGradient(0, hz, 0, hz + (gy - hz) * 0.25);
    fog.addColorStop(0, 'rgba(255,122,168,0.55)');
    fog.addColorStop(1, 'rgba(255,122,168,0)');
    ctx.fillStyle = fog;
    ctx.fillRect(0, hz, W, (gy - hz) * 0.25);
  }
```

- **道路** は、世界の座標で「左右 ±3.5、奥行き 400 先から 6 手前まで」の長方形です。4つの角を `proj()` で画面に変換し、`moveTo` / `lineTo` でつないで塗ると、自動的に台形（奥がすぼまった形）になります。これが投影の便利なところです。
- **レーン線** は、レーンとレーンのちょうど間（`x = ±0.5 × LANE_GAP`）に、奥から手前まで引いた直線です。
- 窓の明かりの `((xx * 7 + yy * 3) | 0) % 5 < 2` は、座標から計算した「ばらばらに見える規則」です。`Math.random()` を使うと毎フレーム点滅してしまうので、位置だけで決まる式にしています（`| 0` は小数を切り捨てて整数にする書き方です）。
- **もや（フォグ）** は地平線のあたりをピンク色の半透明グラデーションで覆うだけですが、遠くのものが自然に空に溶け込んで見えます。

> [!CHECK] 動作チェック
> - スタートを押すと、地平線に向かって細くなる道路と、それを3つに分ける水色の2本の線が見える
> - 地平線の上にビルのシルエットが並び、いくつかのビルには窓の明かりがついている
> - 地平線のあたりがピンク色にかすんでいる
> - 再読み込みするたびにビルの並びが変わる

> [!TIP]
> `DEPTH` を 10 や 60 に変えて見え方を比べてみましょう。小さいほど遠近感が強く（急に縮む）、大きいほど望遠レンズのような平たい見た目になります。
