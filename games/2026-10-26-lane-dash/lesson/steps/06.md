## このステップのゴール

3種類の障害物（ジャンプでこえる **柵**、スライディングでくぐる **LOW ゲート**、横によけるしかない **コンテナ**）を奥から次々に流します。まだ当たり判定はないので、ぶつかってもすり抜けます。

## 障害物のデータ

先頭の定数に、障害物が出現する奥行きを足します。

```js:game.js
  const SPAWN_Z = 75;        // 障害物が出現する距離
```

状態の変数に `objects`（画面にある障害物の配列）と `nextSpawn`（次の列を出すまでの残り距離）を足します。

```js:game.js
  let player, objects, dist, speed, nextSpawn, lastTime;
```

`reset()` で初期化します。`player = ...` の下と `speed = 13;` の下にそれぞれ1行足し、次の形にします。

```js:game.js
  function reset() {
    player = { lane: 0, x: 0, y: 0, vy: 0, slide: 0, run: 0 };
    objects = [];
    dist = 0;
    speed = 13;
    nextSpawn = 12;
    updateHud();
  }
```

1つの障害物は `{ type, lane, z, len }` というオブジェクトです。`type` は `'fence'`・`'gate'`・`'box'` のどれか、`lane` は -1〜1、`z` は手前の面の奥行き、`len` は奥行き方向の長さ（コンテナだけ長い）です。

## 1列ぶんの障害物を作る

`// ---------- 操作 ----------` の **上** に追加します。

```js:game.js
  // ---------- 障害物の生成 ----------
  function spawnRow(z) {
    const lanes = [-1, 0, 1];
    const blocked = Math.random() < 0.35 ? 2 : 1;
    shuffle(lanes);
    const used = lanes.slice(0, blocked);
    let boxes = 0;
    used.forEach((lane) => {
      const r = Math.random();
      let type = r < 0.38 ? 'fence' : r < 0.68 ? 'gate' : 'box';
      if (type === 'box' && boxes >= 1 && blocked === 2) type = 'fence';
      if (type === 'box') boxes++;
      const len = type === 'box' ? 6 + Math.random() * 6 : 0.5;
      objects.push({ type, lane, z, len });
    });
  }
  function shuffle(a) {
    for (let i = a.length - 1; i > 0; i--) {
      const j = Math.floor(Math.random() * (i + 1));
      [a[i], a[j]] = [a[j], a[i]];
    }
  }
```

**必ずクリアできる列にする** のがポイントです。

- 1列でふさぐレーンは 1つ（65%）か 2つ（35%）。3レーン全部はふさがないので、どこか1本は必ず空いています。
- レーンの配列をシャッフルして先頭から `blocked` 個を使えば、「重ならないランダムなレーン」を簡単に選べます。`shuffle` は **Fisher–Yates（フィッシャー–イェーツ）** という偏りのないシャッフルの定番アルゴリズムです。`[a[i], a[j]] = [a[j], a[i]]` は分割代入で2つの値を入れ替える書き方です。
- 2レーンふさぐ列でコンテナが2つになると、空いたレーンへ移動するのが間に合わなくなりやすいので、2つ目は柵に変えています。
- 種類は柵 38%・ゲート 30%・コンテナ 32%。コンテナの長さは 6〜12 のランダムです。

`start()` で、最初の列を少し先（45）に置いておきます。`state = 'play';` の **下** に1行足します。

```js:game.js
    spawnRow(45);
```

## 障害物を動かす

プレイヤーは z = 0 から動かず、**世界のほうが手前に流れてくる** 作りです。`update()` の `player.slide = ...` の行の **下** から、`updateHud();` の **上** までを次のようにします。

```js:game.js
    objects.forEach((o) => { o.z -= dz; });

    nextSpawn -= dz;
    if (nextSpawn <= 0) {
      spawnRow(SPAWN_Z);
      nextSpawn = Math.max(13, 24 - dist / 120) + Math.random() * 8;
    }

    objects = objects.filter((o) => o.z + (o.len || 0) > -6);
```

- すべての障害物の `z` を、このフレームで進んだ距離 `dz` だけ減らします。
- 進んだ距離で `nextSpawn` を減らし、0 以下になったら奥（`SPAWN_Z`）に新しい列を出します。次の列までの間隔は最初 24〜32 で、走るほど縮み、最短 13〜21 になります。速さと合わせて、だんだん忙しくなっていきます。
- 後ろへ通り過ぎた（奥の端が -6 より手前に来た）ものは `filter` で配列から取り除きます。消さないと配列がどんどん大きくなって重くなってしまいます。

## 障害物を描く

`drawPlayer()` 関数の **上** に追加します。

```js:game.js
  function drawObstacle(o) {
    const x = o.lane * LANE_GAP, hw = LANE_GAP * 0.42;
    if (o.z + o.len < -5) return;
    const zf = Math.max(o.z, -5);
    if (o.type === 'box') {
      const h = 2.6;
      const fl = proj(x - hw, 0, zf), fr = proj(x + hw, 0, zf);
      const tl = proj(x - hw, h, zf), tr = proj(x + hw, h, zf);
      const bl = proj(x - hw, h, o.z + o.len), br = proj(x + hw, h, o.z + o.len);
      const sl = proj(x - hw, 0, o.z + o.len), sr = proj(x + hw, 0, o.z + o.len);
      // 側面
      ctx.fillStyle = '#8a3a2e';
      const side = x < 0 ? [fr, tr, br, sr] : x > 0 ? [fl, tl, bl, sl] : null;
      if (side) poly(side);
      // 上面
      ctx.fillStyle = '#e8775a';
      poly([tl, tr, br, bl]);
      // 正面
      ctx.fillStyle = '#c94f3a';
      ctx.fillRect(tl.x, tl.y, tr.x - tl.x, fl.y - tl.y);
      ctx.strokeStyle = 'rgba(0,0,0,0.25)';
      ctx.lineWidth = Math.max(1, 2 * fl.s);
      for (let i = 1; i < 5; i++) {
        const xx = tl.x + (tr.x - tl.x) * i / 5;
        ctx.beginPath(); ctx.moveTo(xx, tl.y + 3); ctx.lineTo(xx, fl.y - 3); ctx.stroke();
      }
    } else if (o.type === 'fence') {
      const h = 0.8;
      const a = proj(x - hw, h, zf), b = proj(x + hw, 0, zf);
      const w = b.x - a.x, hh = b.y - a.y;
      ctx.fillStyle = '#f2c94c';
      ctx.fillRect(a.x, a.y, w, hh * 0.35);
      ctx.fillStyle = '#2b2b2b';
      for (let i = 0; i < 4; i++) ctx.fillRect(a.x + w * (i * 0.25 + 0.04), a.y, w * 0.1, hh * 0.35);
      ctx.fillStyle = '#9aa0b5';
      ctx.fillRect(a.x + w * 0.08, a.y + hh * 0.35, w * 0.08, hh * 0.65);
      ctx.fillRect(a.x + w * 0.84, a.y + hh * 0.35, w * 0.08, hh * 0.65);
    } else if (o.type === 'gate') {
      const top = 2.8, low = 1.1;
      const a = proj(x - hw, top, zf), b = proj(x + hw, 0, zf), c = proj(x, low, zf);
      const w = b.x - a.x;
      ctx.fillStyle = '#6c7390';
      ctx.fillRect(a.x, a.y, w * 0.09, b.y - a.y);
      ctx.fillRect(b.x - w * 0.09, a.y, w * 0.09, b.y - a.y);
      ctx.fillStyle = '#5ff0c8';
      ctx.fillRect(a.x, c.y - (c.y - a.y) * 0.55, w, (c.y - a.y) * 0.55);
      ctx.fillStyle = '#0d3b36';
      ctx.font = `bold ${Math.max(8, 30 * c.s)}px system-ui`;
      ctx.textAlign = 'center';
      ctx.textBaseline = 'middle';
      ctx.fillText('▼ LOW', x === 0 ? W / 2 : (a.x + b.x) / 2, c.y - (c.y - a.y) * 0.27);
    }
  }
```

`roundRect()` 関数の **上** に、多角形を塗る小さな関数も足します。

```js:game.js
  function poly(pts) {
    ctx.beginPath();
    ctx.moveTo(pts[0].x, pts[0].y);
    for (let i = 1; i < pts.length; i++) ctx.lineTo(pts[i].x, pts[i].y);
    ctx.closePath();
    ctx.fill();
  }
```

- どの障害物も「世界の座標で角の位置を決めて `proj()` で画面に変換し、塗る」という同じ考え方です。幅は左右 `hw`（レーン幅の 42%）です。
- **柵** は高さ 0.8 の黄色と黒のしましまの板と、2本の脚です。
- **ゲート** は高さ 2.8 の2本の柱と、高さ 1.1〜2.8 の間に浮かぶ横板です。横板の下はすき間なので、低くなればくぐれる、という見た目になっています。
- **コンテナ** は立体の箱です。手前の面・上の面・横の面の3つを描きます。上の面と横の面は奥の角も投影するので、遠近法どおりに奥へすぼまります。左のレーンにあるときは右側面が、右のレーンにあるときは左側面が見えるので、`x` の符号で描く側面を選んでいます（中央のレーンでは側面は見えません）。
- `zf = Math.max(o.z, -5)` は、プレイヤーより後ろへ大きくはみ出した部分を描かないための制限です。

## 奥から順に描く（画家のアルゴリズム）

Canvas は後から描いたものが上になるので、**遠いものから先に描く** 必要があります。手前の柵が奥のコンテナに隠れてしまったら変ですよね。これを「画家のアルゴリズム」と呼びます。

`draw()` の中の

```js:game.js
    drawPlayer();
```

を次のように **置き換えます**。

```js:game.js
    // 奥から順に描く
    const list = objects.filter((o) => o.z < SPAWN_Z + 10).slice();
    list.push({ type: 'player', z: 0.01 });
    list.sort((a, b) => (b.z + (b.len || 0) * 0.5) - (a.z + (a.len || 0) * 0.5));
    list.forEach((o) => {
      if (o.type === 'player') drawPlayer();
      else drawObstacle(o);
    });
```

障害物の一覧に「プレイヤー」という目印を混ぜてから、奥行き（長いものは真ん中の位置）が **大きい順** に並べ替えて描きます。こうすると、プレイヤーの後ろに抜けていったコンテナはプレイヤーの手前に、まだ前方にあるものは後ろに、正しく重なります。

> [!CHECK] 動作チェック
> - スタートすると、奥から柵・LOW ゲート・赤いコンテナが次々に流れてくる
> - 近づくほど大きくなり、左右のレーンのコンテナは内側の側面が見える
> - 1列で3レーンすべてがふさがることはない
> - 障害物にぶつかってもまだすり抜ける（当たり判定は次のステップ）
> - 長く走ると、障害物の来る間隔と速さが少しずつ縮まっていく
