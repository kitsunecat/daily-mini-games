## このステップのゴール

コインを並べて集められるようにし、障害物との **当たり判定** を入れます。ぶつかったら少し間をおいてゲームオーバー画面を出し、「もう一度」でリトライできるようにします。これで遊べるゲームになります。

## 必要な要素と変数

要素の取得に、コイン数とオーバーレイの文字を足します。`const scoreEl = ...` の下に

```js:game.js
  const coinsEl = document.getElementById('coins');
```

`const overlay = ...` の下に

```js:game.js
  const ovTitle = document.getElementById('ov-title');
  const ovText = document.getElementById('ov-text');
```

状態の変数に `coins`（集めた枚数）と `crashT`（ぶつかってからゲームオーバー画面を出すまでの残り時間）を足します。

```js:game.js
  let player, objects, dist, speed, coins, nextSpawn, lastTime, crashT;
```

`reset()` も2行増やします。

```js:game.js
  function reset() {
    player = { lane: 0, x: 0, y: 0, vy: 0, slide: 0, run: 0 };
    objects = [];
    dist = 0;
    speed = 13;
    coins = 0;
    nextSpawn = 12;
    crashT = 0;
    updateHud();
  }
```

## コインを並べる

コインも障害物と同じ `objects` 配列に `{ type: 'coin', lane, z, y }` として入れます。`spawnRow()` を次のように書き換えます（増えたのは `free` の行と、2か所のコインの処理です）。

```js:game.js
  function spawnRow(z) {
    const lanes = [-1, 0, 1];
    const blocked = Math.random() < 0.35 ? 2 : 1;
    shuffle(lanes);
    const used = lanes.slice(0, blocked);
    const free = lanes.slice(blocked);
    let boxes = 0;
    used.forEach((lane) => {
      const r = Math.random();
      let type = r < 0.38 ? 'fence' : r < 0.68 ? 'gate' : 'box';
      if (type === 'box' && boxes >= 1 && blocked === 2) type = 'fence';
      if (type === 'box') boxes++;
      const len = type === 'box' ? 6 + Math.random() * 6 : 0.5;
      objects.push({ type, lane, z, len });
      if (type === 'fence' && Math.random() < 0.6) {
        // フェンスの上にアーチ状のコイン
        for (let i = 0; i < 5; i++) {
          const k = (i - 2) / 2;
          objects.push({ type: 'coin', lane, z: z + k * 2.2, y: 2.4 - k * k * 1.2 });
        }
      }
    });
    if (free.length && Math.random() < 0.7) {
      const lane = free[Math.floor(Math.random() * free.length)];
      const n = 4 + Math.floor(Math.random() * 4);
      for (let i = 0; i < n; i++) objects.push({ type: 'coin', lane, z: z - 4 + i * 2.2, y: 0.8 });
    }
  }
```

- 柵の上には、60% の確率で5枚のコインを **アーチ状** に並べます。`k` は -1, -0.5, 0, 0.5, 1 と変わり、高さ `2.4 - k * k * 1.2` は真ん中が一番高い放物線になります。ジャンプの軌道に沿って並ぶので「跳んだらごほうび」という誘導になります。
- 空いているレーンには、70% の確率で 4〜7 枚のコインを一直線に並べます。「こっちに逃げると得」という道しるべです。

## コインを描く

`drawPlayer()` の **上** に追加します。

```js:game.js
  function drawCoin(o) {
    if (o.z < -5) return;
    const p = proj(o.lane * LANE_GAP, o.y, o.z);
    const r = 0.38 * unitPx() * p.s;
    const sq = Math.abs(Math.cos((dist + o.z) * 0.4));
    ctx.fillStyle = '#ffd23f';
    ctx.beginPath();
    ctx.ellipse(p.x, p.y, Math.max(1, r * (0.35 + 0.65 * sq)), r, 0, 0, Math.PI * 2);
    ctx.fill();
    ctx.fillStyle = '#fff3b0';
    ctx.beginPath();
    ctx.ellipse(p.x - r * 0.15 * sq, p.y - r * 0.2, Math.max(0.5, r * 0.3 * sq), r * 0.35, 0, 0, Math.PI * 2);
    ctx.fill();
  }
```

`ellipse`（楕円）の横幅を `cos` で伸び縮みさせると、コインがくるくる回っているように見えます。`p.s`（縮尺）を半径に掛けて、遠くのコインほど小さく描きます。

描く順番の `list.forEach` の中にもコインを足します。

```js:game.js
    list.forEach((o) => {
      if (o.type === 'player') drawPlayer();
      else if (o.type === 'coin') drawCoin(o);
      else drawObstacle(o);
    });
```

## 当たり判定

`update()` の、`objects = objects.filter(...)` の行を次のように **置き換えます**。

```js:game.js
    const px = player.x;
    for (const o of objects) {
      if (o.hit) continue;
      if (Math.abs(o.lane - px) > 0.45) continue;
      const front = o.z, back = o.z + (o.len || 0.4);
      if (back < -0.4 || front > 0.4) continue;
      if (o.type === 'coin') {
        if (Math.abs((o.y || 0.8) - (player.y + 0.8)) < 1.3) {
          o.hit = true;
          coins++;
        }
        continue;
      }
      const sliding = player.slide > 0 && player.y < 0.3;
      if (o.type === 'fence' && player.y < 0.9) return gameOver();
      if (o.type === 'gate' && !sliding) return gameOver();
      if (o.type === 'box') return gameOver();
    }
    objects = objects.filter((o) => !o.hit && o.z + (o.len || 0) > -6);
```

世界の座標で管理しているおかげで、3D の見た目なのに当たり判定は **数の比較だけ** で書けます。

1. **左右**: プレイヤーの見た目の位置 `player.x` とレーンの差が 0.45 より大きければ別のレーンなので無視。レーン移動の途中で、まだ半分も動いていなければ元のレーン扱いになります。
2. **奥行き**: 障害物の手前 `front` から奥 `back` の範囲が、プレイヤーの前後 ±0.4 と重なっていなければ無視。コンテナは `len` が長いので、横を並走している間ずっと判定されます。
3. **高さ・姿勢**: 種類ごとに「よけられているか」を調べます。柵は高さ 0.9 以上にいればセーフ（柵の高さは 0.8）、ゲートはスライディング中ならセーフ、コンテナは同じレーンにいたら必ずアウトです。
4. **コイン**: プレイヤーの体の中心（足元 + 0.8）とコインの高さが 1.3 以内なら取得。`hit = true` の印をつけ、最後の `filter` で取り除きます。

`return gameOver();` は、ぶつかった時点で `update()` を抜けて、それ以降の処理（次の障害物の判定など）をしないための書き方です。

## ゲームオーバーとリトライ

`calcScore` と `updateHud` を、次のブロックに **置き換えます**。

```js:game.js
  function gameOver() {
    state = 'crash';
    crashT = 0.8;
    updateHud();
  }

  function showGameOver() {
    state = 'over';
    const score = calcScore();
    ovTitle.textContent = 'ゲームオーバー';
    ovText.innerHTML = `走った距離 <b>${Math.floor(dist)} m</b>　コイン <b>${coins}</b><br>スコア <b>${score}</b>`;
    startBtn.textContent = 'もう一度';
    overlay.classList.remove('hidden');
  }

  const calcScore = () => Math.floor(dist) + coins * 10;
  function updateHud() {
    scoreEl.textContent = calcScore();
    coinsEl.textContent = coins;
  }
```

- ぶつかってすぐに画面を覆うと何が起きたか分からないので、いったん `'crash'` 状態にして 0.8 秒止め、そのあと `showGameOver()` で結果を出します。
- スコアは「距離 + コイン × 10」。コインを集める意味が出てきます。
- オーバーレイの文字とボタンを書き換えて再表示するだけで、タイトル画面をゲームオーバー画面として使い回せます。ボタンはもともと `start()` を呼ぶので、そのままリトライボタンになります。
- `${...}` を含む `` ` `` で囲んだ文字列は **テンプレートリテラル** です。文字列の中に変数の値を埋め込めます。

`update()` の先頭（`if (state !== 'play') return;` の **上**）に、クラッシュ中の処理を足します。

```js:game.js
    if (state === 'crash') {
      crashT -= dt;
      if (crashT <= 0) showGameOver();
      return;
    }
```

最後に、`keydown` のスタート処理を、クラッシュ中は受け付けないように変えます。ぶつかった瞬間に Space を押していて、結果を見る前に次のゲームが始まってしまうのを防ぐためです。

```js:game.js
      if (k === 'Enter' || k === ' ') { e.preventDefault(); if (state !== 'crash') start(); }
```

> [!CHECK] 動作チェック
> - 金色のコインがくるくる回りながら流れてきて、触れると COIN が増え、SCORE が 10 増える
> - 柵の上のアーチ状のコインは、ジャンプすると取れる
> - 柵にジャンプせずに当たる、ゲートにスライディングせずに当たる、コンテナに当たると、その場で止まる
> - 止まってから約0.8秒後に「ゲームオーバー」と距離・コイン・スコアが表示される
> - 「もう一度」ボタン（または Enter / Space）でスコアが 0 に戻って最初から走れる
