## このステップのゴール

↑ でジャンプ、↓ でスライディングができるようにします。重力を使った放物線のジャンプと、時間で終わるスライディングを作り、スマホ向けにスワイプ・タップ操作も対応させます。

## 定数を足す

ファイル先頭の定数（`DEPTH` の下）に追加します。

```js:game.js
  const GRAVITY = 32;
  const JUMP_V = 12;
  const SLIDE_TIME = 0.6;
```

## ジャンプとスライディングの関数

`move()` 関数の **下** に追加します。

```js:game.js
  function jump() {
    if (state !== 'play') return;
    if (player.y <= 0.001) {
      player.vy = JUMP_V;
      player.slide = 0;
    }
  }
  function slide() {
    if (state !== 'play') return;
    if (player.y > 0.001) player.vy = -JUMP_V * 1.4; // 空中なら急降下
    player.slide = SLIDE_TIME;
  }
```

- `player.y` は高さ、`player.vy` は **上向きの速さ**（1秒あたりに上がる量）です。ジャンプは「上向きの速さを与える」だけで、高さを直接変えません。
- 地面にいるとき（`y` がほぼ 0）だけジャンプできるので、空中で連打しても二段ジャンプにはなりません。小数の計算はぴったり 0 にならないことがあるので `<= 0.001` と少し余裕を持たせています。
- `player.slide` はスライディングの **残り時間**（秒）です。0.6 を入れ、時間とともに減らして 0 になったら終わり、という作りです。
- 空中でスライディングすると、強い下向きの速さを与えて急降下します。ジャンプ後すぐに低いゲートをくぐりたいときに便利な操作です。

## 物理の更新

`update()` の `player.x += ...` の行の **下** に追加します。

```js:game.js
    player.vy -= GRAVITY * dt;
    player.y = Math.max(0, player.y + player.vy * dt);
    if (player.y === 0 && player.vy < 0) player.vy = 0;
    player.slide = Math.max(0, player.slide - dt);
```

これがいちばんシンプルな重力の計算です。

1. 速さから毎秒 `GRAVITY` ずつ引く（だんだん上昇が弱まり、やがて落ち始める）
2. 高さに「速さ × 経過時間」を足す
3. 地面（0）より下には行かないようにし、着地したら速さを 0 に戻す

上向きの速さ 12、重力 32 だと、最高点の高さは 12² ÷ (2 × 32) ≒ 2.25、滞空時間は約 0.75 秒になります。次のステップで出てくる柵（高さ 0.8）を余裕で飛び越せる高さです。

`player.slide` は毎フレーム `dt` ずつ減り、0 で止まります。

## キー操作を足す

`keydown` の中の、`'ArrowRight'` の行の **下** に2行追加します。

```js:game.js
    else if (k === 'ArrowUp' || k === 'w' || k === 'W' || k === ' ') jump();
    else if (k === 'ArrowDown' || k === 's' || k === 'S') slide();
```

Space はタイトル画面ではスタート、プレイ中はジャンプとして働きます（`state` で先に分岐しているからです）。

## スワイプとタップ

`keydown` の処理の **下**、`startBtn.addEventListener(...)` の **上** に追加します。

```js:game.js
  let touch = null;
  cv.addEventListener('pointerdown', (e) => {
    touch = { x: e.clientX, y: e.clientY, done: false };
  });
  cv.addEventListener('pointermove', (e) => {
    if (!touch || touch.done) return;
    const dx = e.clientX - touch.x, dy = e.clientY - touch.y;
    if (Math.hypot(dx, dy) < 28) return;
    touch.done = true;
    if (Math.abs(dx) > Math.abs(dy)) move(dx > 0 ? 1 : -1);
    else if (dy < 0) jump();
    else slide();
  });
  const endTouch = (e) => {
    if (touch && !touch.done && state === 'play') {
      // 短いタップは左右半分でレーン移動
      const r = cv.getBoundingClientRect();
      move(e.clientX - r.left < W / 2 ? -1 : 1);
    }
    touch = null;
  };
  cv.addEventListener('pointerup', endTouch);
  cv.addEventListener('pointercancel', () => { touch = null; });
```

- **Pointer Events**（`pointerdown` / `pointermove` / `pointerup`）は、マウスとタッチの両方を同じコードで扱えるイベントです。
- 指を置いた位置を覚えておき、そこから 28px 以上動いたら **スワイプ** と判定します（`Math.hypot(dx, dy)` は2点間の距離）。横の動きが大きければ左右移動、縦なら上でジャンプ・下でスライディングです。
- `touch.done = true` にして、1回のスワイプで何度も反応しないようにしています。
- ほとんど動かさずに指を離したら **タップ** とみなし、画面の左半分なら左へ、右半分なら右へ移動します。
- `pointercancel` は着信などでタッチが中断されたときに呼ばれます。記録を捨てておかないと、次の操作で誤判定することがあります。

> [!CHECK] 動作チェック
> - ↑（W / Space）で放物線を描いてジャンプし、影は地面に残って小さくなる
> - 空中では脚の動きと体の弾みが止まる。空中でもう一度 ↑ を押しても二段ジャンプしない
> - ↓（S）で体が低く横長になり、約0.6秒で元に戻る
> - ジャンプ中に ↓ を押すと急降下してそのままスライディングする
> - 開発者ツールのデバイスモード（スマホ表示）で、スワイプやタップでも同じ操作ができる
