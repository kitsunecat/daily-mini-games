## このステップのゴール

3つのファイルを用意して、画面の土台を作ります。上にスコア表示、その下にゲームを描く **Canvas**、さらにその上に重ねるタイトル画面（オーバーレイ）を置き、Canvas には夕焼けの空と地面を描きます。

## index.html

まずは HTML です。このステップで画面の部品はすべてそろえてしまい、以降は `game.js` を育てていきます。

```html:index.html

<head>

<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1, user-scalable=no">
<title>レーンダッシュ</title>
<link rel="stylesheet" href="style.css">
</head>
<body>
<div id="app">
  <header>
    <a class="back" href="../../../../">← 一覧</a>
    <div class="stat"><span>COIN</span><b id="coins">0</b></div>
    <div class="stat"><span>SCORE</span><b id="score">0</b></div>
    <div class="stat"><span>BEST</span><b id="best">0</b></div>
  </header>
  <div id="stage">
    <canvas id="cv"></canvas>
    <div id="overlay">
      <h1 id="ov-title">レーンダッシュ</h1>
      <p id="ov-text">3本のレーンを走り続けよう。<br>スワイプで左右に移動、上でジャンプ、下でスライディング。<br>柵はジャンプ、ゲートはスライディング、<br>コンテナは横によけてね。コインも集めよう！</p>

      <button id="start">タップでスタート</button>
    </div>
  </div>
</div>
<script src="game.js"></script>
</body>
</html>
```

- `header` にコイン数・スコア・ベストの3つの数字を並べます。JavaScript から書き換えるので、数字の `b` 要素に `id` をつけています。
- `#stage` の中に `canvas` と `#overlay` を **重ねて** 置きます。オーバーレイはタイトル画面とゲームオーバー画面の両方に使い回します。
- 「← 一覧」のリンク先は自分の環境に合わせて変えてかまいません。
- `<script>` を `body` の最後に置くと、HTML の要素が全部できてからスクリプトが動くので `getElementById` で確実に要素が取れます。

ポイントは3つです。

- `#app` を縦方向の **Flexbox** にして、`#stage` に `flex: 1` を指定すると「ヘッダーの残り全部」がゲーム画面になります。`min-height: 0` は、中身が大きくてもはみ出さずに縮めるためのおまじないです。
- `#stage` を `position: relative`、`#overlay` を `position: absolute; inset: 0` にすると、オーバーレイが Canvas の上にぴったり重なります。`hidden` クラスをつけ外しするだけで表示を切り替えられます。
- `touch-action: none` はスマホでスワイプしたときに画面がスクロールしたり拡大したりするのを防ぎます。スワイプ操作のゲームには必須です。

## game.js

```js:game.js
(() => {
  'use strict';

  const cv = document.getElementById('cv');
  const ctx = cv.getContext('2d');
  const overlay = document.getElementById('overlay');
  const startBtn = document.getElementById('start');

  let W = 0, H = 0, dpr = 1;

  // ---------- 画面サイズ ----------
  function resize() {
    const r = cv.getBoundingClientRect();
    dpr = Math.min(window.devicePixelRatio || 1, 2);
    W = r.width; H = r.height;
    cv.width = Math.round(W * dpr);
    cv.height = Math.round(H * dpr);
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
  }
  window.addEventListener('resize', () => { resize(); draw(); });

  const horizon = () => H * 0.3;

  // ---------- 描画 ----------
  function draw() {
    if (!W) return;
    const hz = horizon();

    // 空
    const sky = ctx.createLinearGradient(0, 0, 0, hz);
    sky.addColorStop(0, '#1a1145');
    sky.addColorStop(1, '#ff7aa8');
    ctx.fillStyle = sky;
    ctx.fillRect(0, 0, W, hz + 1);
    ctx.fillStyle = 'rgba(255,230,160,0.9)';
    ctx.beginPath();
    ctx.arc(W * 0.78, hz * 0.45, Math.min(W, H) * 0.06, 0, Math.PI * 2);
    ctx.fill();

    // 地面
    ctx.fillStyle = '#1e2a3a';
    ctx.fillRect(0, hz, W, H - hz);
  }

  startBtn.addEventListener('click', () => { overlay.classList.add('hidden'); });

  resize();
  draw();
})();
```

### コード全体を `(() => { ... })();` で包む理由

これは **即時実行関数** と呼ばれる書き方です。中で宣言した変数がページ全体（グローバル）に漏れないので、ほかのスクリプトと名前がぶつかりません。`'use strict';` は、宣言し忘れた変数などのミスをエラーとして教えてくれるモードです。

### Canvas とは

`<canvas>` は JavaScript で自由に絵を描ける「キャンバス」です。`getContext('2d')` で取り出した `ctx`（コンテキスト）に `fillRect`（四角を塗る）や `arc`（円を描く）などの命令を出して描きます。座標は左上が `(0, 0)` で、右に行くほど x、**下に行くほど y が大きく** なります。

### くっきり描くための `resize()`

Canvas には「CSS で見えている大きさ」と「内部の画素数（`cv.width` / `cv.height`）」の2つのサイズがあります。スマホなどの高精細な画面では、1 CSS ピクセルに 2〜3 個の物理ピクセルが詰まっている（`devicePixelRatio`）ので、内部の画素数を表示サイズ × `dpr` にしないとぼやけてしまいます。

そのうえで `ctx.setTransform(dpr, 0, 0, dpr, 0, 0)` を呼ぶと、以降は CSS ピクセル単位（`W` × `H`）で座標を指定するだけで自動的に拡大して描かれます。`dpr` を最大 2 に抑えているのは、画素数が増えすぎて重くなるのを防ぐためです。

### 空と地面

- `horizon()` は地平線の y 座標（画面の上から 30% の位置）を返す小さな関数です。画面サイズが変わっても計算し直せるよう、値ではなく関数にしています。
- `createLinearGradient(x0, y0, x1, y1)` で作ったグラデーションを `fillStyle` に入れると、色が上から下へなめらかに変わる四角が塗れます。
- `beginPath()` → `arc(中心x, 中心y, 半径, 開始角, 終了角)` → `fill()` で円（夕日）を描きます。角度はラジアンで、`Math.PI * 2` が1周です。

ボタンを押したらオーバーレイに `hidden` クラスをつけて隠すだけ、の仮の処理も入れておきます。

> [!CHECK] 動作チェック
> - `index.html` をブラウザで開くと、タイトル「レーンダッシュ」と説明文、「タップでスタート」ボタンが表示される
> - ボタンを押すとオーバーレイが消え、紫からピンクへの夕焼け空・黄色い夕日・紺色の地面が見える
> - ウィンドウの大きさを変えても絵がぼやけたり伸びたりしない
