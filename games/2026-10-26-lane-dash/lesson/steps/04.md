## このステップのゴール

道路の上に走るキャラクター（オレンジのパーカーを着たキツネっぽい子）を描き、キーボードの ←→ で3本のレーンを行き来できるようにします。

## レーンの移動

`startBtn.addEventListener(...)` の行の **上** に、操作のブロックを追加します。

```js:game.js
  // ---------- 操作 ----------
  function move(dir) {
    if (state !== 'play') return;
    const n = Math.max(-1, Math.min(1, player.lane + dir));
    if (n !== player.lane) player.lane = n;
  }

  window.addEventListener('keydown', (e) => {
    const k = e.key;
    if (state !== 'play') {
      if (k === 'Enter' || k === ' ') { e.preventDefault(); start(); }
      return;
    }
    if (k === 'ArrowLeft' || k === 'a' || k === 'A') move(-1);
    else if (k === 'ArrowRight' || k === 'd' || k === 'D') move(1);
    else return;
    e.preventDefault();
  });
```

- レーンは `-1`（左）・`0`（中央）・`1`（右）の3つの数字で表します。`move(-1)` で左へ、`move(1)` で右へ。`Math.max(-1, Math.min(1, 値))` は値を -1〜1 の範囲に収める（**クランプ** する）定番の書き方で、端のレーンからさらに外へは出られません。
- **keydown イベント** はキーが押されたときに呼ばれ、`e.key` に押されたキーの名前（`'ArrowLeft'` や `'a'` など）が入っています。
- プレイ中でないときは Enter / Space でスタートできるようにしています。
- `e.preventDefault()` は、矢印キーや Space でページがスクロールするというブラウザ標準の動きを止めます。ゲームで使うキーのときだけ呼ぶよう、関係ないキーは `else return;` で先に抜けています。

## なめらかに横移動する

`player.lane` は一瞬で切り替わりますが、見た目まで瞬間移動すると不自然です。そこで「見た目の位置」`player.x` を、毎フレーム少しずつ `lane` に近づけます。`update()` の `player.run += dz;` の **下** に追加します。

```js:game.js
    player.x += (player.lane - player.x) * Math.min(1, dt * 14);
```

「目標との差 × 割合」を足すと、離れているときは速く、近づくほどゆっくりになる、気持ちのよい動き（イージング）になります。`dt` を掛けているので、フレームレートが違っても動きの速さは同じです。

## キャラクターを描く

`draw()` 関数の **後ろ**（閉じカッコ `}` の下）に、2つの関数を追加します。

```js:game.js
  function drawPlayer() {
    const px = player.x * LANE_GAP;
    const g = proj(px, 0, 0);
    const u = unitPx();
    // 影
    ctx.fillStyle = 'rgba(0,0,0,0.35)';
    ctx.beginPath();
    ctx.ellipse(g.x, g.y, u * 0.55 / (1 + player.y * 0.2), u * 0.16, 0, 0, Math.PI * 2);
    ctx.fill();

    const sliding = player.slide > 0 && player.y < 0.3;
    const base = proj(px, player.y, 0);
    const bob = player.y > 0 || sliding ? 0 : Math.abs(Math.sin(player.run * 1.4)) * u * 0.08;
    const bodyH = sliding ? u * 0.7 : u * 1.5;
    const bodyW = sliding ? u * 1.1 : u * 0.8;
    const by = base.y - bob;

    // 脚
    if (!sliding) {
      const sw = Math.sin(player.run * 1.4) * u * 0.18;
      ctx.fillStyle = '#2c3e8f';
      ctx.fillRect(base.x - u * 0.25 + sw, by - u * 0.45, u * 0.18, u * 0.45);
      ctx.fillRect(base.x + u * 0.07 - sw, by - u * 0.45, u * 0.18, u * 0.45);
    }
    // 胴体
    ctx.fillStyle = '#ff8a3d';
    roundRect(base.x - bodyW / 2, by - bodyH, bodyW, bodyH * (sliding ? 1 : 0.72), u * 0.25);
    ctx.fill();
    // パーカーの帽子と顔
    const hx = sliding ? base.x + bodyW * 0.25 : base.x;
    const hy = sliding ? by - bodyH * 0.6 : by - bodyH * 0.9;
    ctx.fillStyle = '#ffe1c2';
    ctx.beginPath(); ctx.arc(hx, hy, u * 0.32, 0, Math.PI * 2); ctx.fill();
    ctx.fillStyle = '#ff8a3d';
    ctx.beginPath(); ctx.arc(hx, hy - u * 0.05, u * 0.34, Math.PI, Math.PI * 2); ctx.fill();
    // 耳
    ctx.beginPath();
    ctx.moveTo(hx - u * 0.32, hy - u * 0.12); ctx.lineTo(hx - u * 0.22, hy - u * 0.58); ctx.lineTo(hx - u * 0.05, hy - u * 0.3);
    ctx.moveTo(hx + u * 0.32, hy - u * 0.12); ctx.lineTo(hx + u * 0.22, hy - u * 0.58); ctx.lineTo(hx + u * 0.05, hy - u * 0.3);
    ctx.fill();
    // リュック
    ctx.fillStyle = '#5ff0c8';
    roundRect(base.x - bodyW * 0.32, by - bodyH * (sliding ? 0.9 : 0.68), bodyW * 0.64, bodyH * (sliding ? 0.5 : 0.36), u * 0.1);
    ctx.fill();
  }

  function roundRect(x, y, w, h, r) {
    r = Math.min(r, w / 2, h / 2);
    ctx.beginPath();
    ctx.moveTo(x + r, y);
    ctx.arcTo(x + w, y, x + w, y + h, r);
    ctx.arcTo(x + w, y + h, x, y + h, r);
    ctx.arcTo(x, y + h, x, y, r);
    ctx.arcTo(x, y, x + w, y, r);
    ctx.closePath();
  }
```

長く見えますが、やっていることは「影 → 脚 → 胴体 → 顔と帽子 → 耳 → リュック」を順に重ねて描いているだけです。

- プレイヤーは常に `z = 0`（足元）にいるので、`proj(px, 0, 0)` で地面の位置 `g`、`proj(px, player.y, 0)` で体の基準位置 `base` を求めます。**影だけはジャンプしても地面に残る** ので、影と体で別々に投影しています。
- 大きさはすべて `u`（1単位のピクセル数）の何倍、で決めています。画面サイズが変わってもキャラの比率が崩れません。
- `Math.sin(player.run * 1.4)` は走った距離に合わせて -1〜1 を行ったり来たりする値です。脚を前後に振る量 `sw` と、体が上下に弾む量 `bob` に使っています。速く走るほど脚の動きも速くなります。
- `sliding`（スライディング中か）に応じて体を低く横長にしています。スライディングはステップ5で作りますが、描き分けは先に入れておきます。
- `roundRect` は角の丸い四角形の「形」だけを作る自作関数です。`arcTo` で四隅を丸めながら一周します。塗るのは呼び出したあとの `ctx.fill()` です。

## 描く順番に組み込む

`draw()` の中、`// レーン線` のブロックの **下**、`// 遠景フォグ` の **上** に追加します。

```js:game.js
    if (!player) return;

    drawPlayer();
```

Canvas は後から描いたものが上に重なるので、「背景 → キャラ → もや」の順番にしています。

> [!CHECK] 動作チェック
> - タイトル画面の後ろに、道路の中央に立つキャラクターが見える
> - スタートすると脚を動かしながら走り、体が小さく上下に弾む
> - ← → キー（または A / D）でレーンを移動でき、すっと滑らかに横へ動く
> - 左端・右端のレーンからさらに外へは出られない
> - ページを再読み込みして、ボタンではなく Enter や Space でもスタートできる
