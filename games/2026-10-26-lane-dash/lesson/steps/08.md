## このステップのゴール

最後の仕上げです。ハイスコアを **localStorage** に保存して次に開いたときも残るようにし、**Web Audio API** の効果音、ぶつかったときの赤いフラッシュ、タイトル画面の背景に障害物を並べる演出を加えて、完成品と同じゲームにします。

## ハイスコアの保存

ファイル先頭の定数の **一番上** に、保存に使うキーの名前を足します。

```js:game.js
  const BEST_KEY = 'lane-dash-best';
```

要素の取得に `bestEl` を足します（`const coinsEl = ...` の下）。

```js:game.js
  const bestEl = document.getElementById('best');
```

`let W = 0, H = 0, dpr = 1;` の **下** で、保存済みのベストを読み込みます。

```js:game.js
  let best = 0;
  try { best = parseInt(localStorage.getItem(BEST_KEY), 10) || 0; } catch (e) { best = 0; }
  bestEl.textContent = best;
```

**localStorage** はブラウザに文字列を保存しておける小さな倉庫です。`setItem(キー, 値)` で保存、`getItem(キー)` で取り出せ、ページを閉じても消えません。

- 値は文字列で保存されるので、`parseInt(..., 10)` で数値に戻します。まだ保存されていないと `null` が返り、`parseInt` は `NaN` になるので、`|| 0` で 0 にしています。
- プライベートブラウズなど、localStorage が使えない環境ではエラーになることがあります。`try { ... } catch (e) { ... }` で囲んでおくと、エラーが起きてもゲームは止まらずに続けられます。

`updateHud()` にベストの表示を足します。

```js:game.js
  function updateHud() {
    scoreEl.textContent = calcScore();
    coinsEl.textContent = coins;
    bestEl.textContent = best;
  }
```

## 効果音

`let skyline = [];` の **下** に、サウンドのブロックを追加します。

```js:game.js
  // ---------- サウンド ----------
  let ac = null;
  function beep(freq, dur, type, vol, slide) {
    if (!ac) return;
    try {
      const t = ac.currentTime;
      const o = ac.createOscillator();
      const g = ac.createGain();
      o.type = type || 'square';
      o.frequency.setValueAtTime(freq, t);
      if (slide) o.frequency.exponentialRampToValueAtTime(slide, t + dur);
      g.gain.setValueAtTime(vol || 0.08, t);
      g.gain.exponentialRampToValueAtTime(0.001, t + dur);
      o.connect(g).connect(ac.destination);
      o.start(t);
      o.stop(t + dur);
    } catch (e) { /* ignore */ }
  }
  function initAudio() {
    if (ac) return;
    try { ac = new (window.AudioContext || window.webkitAudioContext)(); } catch (e) { ac = null; }
  }
```

**Web Audio API** を使うと、音声ファイルを用意しなくてもプログラムで音を作れます。

- `OscillatorNode`（発振器）が音のもとです。`frequency` が音の高さ（Hz）、`type` が音色（`'square'` はピコピコ、`'triangle'` はやわらか、`'sawtooth'` はジリジリした音）です。
- `GainNode` は音量のつまみです。音量を `dur` 秒かけて 0 近くまで下げると、「ピッ」と自然に消える音になります。
- `slide` を指定すると、音の高さが `dur` 秒かけて別の高さへ変わります。ジャンプの「ピュイッ」（上がる）や、クラッシュの「ブーン」（下がる）に使います。
- ブラウザは、ユーザーが一度も操作していないページで勝手に音を出すことを禁止しています。そのため `AudioContext` は、スタートボタンを押したときに `initAudio()` で作ります。

`start()` の先頭で `initAudio()` を呼びます。あわせて、`start()` 全体は次の形になります。

```js:game.js
  function start() {
    initAudio();
    reset();
    state = 'play';
    spawnRow(45);
    overlay.classList.add('hidden');
    lastTime = performance.now();
  }
```

各操作に音をつけます。`move()` の最後の行を

```js:game.js
    if (n !== player.lane) { player.lane = n; beep(520, 0.06, 'triangle', 0.05); }
```

に変え、`jump()` の `player.slide = 0;` の下に

```js:game.js
      beep(380, 0.15, 'square', 0.05, 760);
```

`slide()` の `player.slide = SLIDE_TIME;` の下に

```js:game.js
    beep(300, 0.12, 'triangle', 0.05, 150);
```

`update()` の当たり判定で、コインを取ったとき（`coins++;` の下）に

```js:game.js
          beep(1200, 0.08, 'square', 0.04, 1800);
```

を追加します。

## ぶつかったときの演出とベスト更新

状態の変数に `flash`（赤いフラッシュの濃さ）を足し、

```js:game.js
  let player, objects, dist, speed, coins, nextSpawn, lastTime, crashT, flash;
```

`reset()` の `crashT = 0;` の下に `flash = 0;` を足します。

`gameOver()` と `showGameOver()` を次のように書き換えます。

```js:game.js
  function gameOver() {
    state = 'crash';
    crashT = 0.8;
    flash = 1;
    beep(180, 0.5, 'sawtooth', 0.12, 50);
    const score = calcScore();
    if (score > best) {
      best = score;
      try { localStorage.setItem(BEST_KEY, String(best)); } catch (e) { /* ignore */ }
    }
    updateHud();
  }

  function showGameOver() {
    state = 'over';
    const score = calcScore();
    ovTitle.textContent = 'ゲームオーバー';
    ovText.innerHTML = `走った距離 <b>${Math.floor(dist)} m</b>　コイン <b>${coins}</b><br>スコア <b>${score}</b>` +
      (score >= best && score > 0 ? '<br>🎉 ハイスコア更新！' : `<br>ベスト ${best}`);
    startBtn.textContent = 'もう一度';
    overlay.classList.remove('hidden');
  }
```

- ぶつかった瞬間にベストと比べ、上回っていれば `best` を更新して localStorage に保存します。
- ゲームオーバー画面では、今回のスコアがベストと同じ（＝今まさに更新した）なら「ハイスコア更新！」、そうでなければベストの値を表示します。

`update()` のクラッシュ中の処理で、フラッシュを薄くしていきます。

```js:game.js
    if (state === 'crash') {
      crashT -= dt;
      flash = Math.max(0, flash - dt * 2);
      if (crashT <= 0) showGameOver();
      return;
    }
```

`draw()` の一番最後（遠景フォグを塗った下）に、画面全体を赤く塗る処理を足します。

```js:game.js
    if (flash > 0) {
      ctx.fillStyle = `rgba(255,80,80,${flash * 0.5})`;
      ctx.fillRect(0, 0, W, H);
    }
```

`flash` は 1 から 0.5 秒かけて 0 になるので、「ドン！」と赤く光ってすっと消える演出になります。

## タイトル画面の演出

最後に、ファイル末尾の `reset();` と `requestAnimationFrame(loop);` の **間** に追加します。

```js:game.js
  // タイトル画面用に少し障害物を並べておく
  spawnRow(25); spawnRow(50); spawnRow(75);
```

タイトル画面の後ろに障害物やコインが見えていると、どんなゲームかがひと目で伝わります。`start()` の中の `reset()` で `objects` は空に戻るので、プレイには影響しません。

> [!CHECK] 動作チェック
> - タイトル画面の後ろに柵・ゲート・コンテナ・コインが並んで見える
> - スタート後、レーン移動・ジャンプ・スライディング・コイン取得でそれぞれ違う効果音が鳴る
> - ぶつかると低い音とともに画面が赤く光り、すぐに薄れていく
> - 初回のゲームオーバーでは「ハイスコア更新！」が出て、右上の BEST がスコアと同じ値になる
> - ベストより低いスコアで終わると「ベスト 〇〇」と表示される
> - ページを再読み込みしても BEST の値が残っている
