## このステップのゴール

ボールを登場させて、**重力** で落ちては床で跳ね返る「ポンポン」という動きを作ります。そのために、1秒間に約60回、状態を進めて描き直す **ゲームループ** を作ります。床はまだ仮のもので、ステップ3でリングに置きかえます。

## 定数と変数を追加する

`const startBtn = ...` の **下** に、ボールの動きを決める定数を追加し、`let W = 0, ...` の行の **下** に変数を2行足します。

```js:game.js
  const GRAVITY = 1500;
  const BOUNCE = 560;
  const MAX_FALL = 900;
  const BALL_R = 11;
  const FLOOR_Y = 200; // 仮の床（ステップ5で消す）

  let W = 0, H = 0, dpr = 1, R = 120, RY = 38;
  let state = 'title';
  let ball, camY, lastT;
```

- `GRAVITY` は重力の強さで「1秒あたりに速さがどれだけ増えるか」（ピクセル/秒²）です。
- `BOUNCE` は跳ね返ったときの上向きの速さ、`MAX_FALL` は落ちる速さの上限、`BALL_R` はボールの半径です。
- `state` はゲームの状態で、`'title'`（タイトル画面）・`'play'`（プレイ中）・`'over'`（ゲームオーバー）の3つを使います。
- `camY` は **カメラ** の位置です。今はずっと 0 ですが、ステップ5でボールが下へ落ちていくのをカメラが追いかけるようにします。

> [!NOTE]
> このゲームでは、y 座標を「塔のてっぺんからの深さ」として扱います。ボールやリングは **ワールド座標**（塔の上での位置）を持ち、画面に描くときに `y - camY` で画面上の位置に直します。こうしておくと、カメラを動かすだけで画面全体をスクロールできます。

## `reset()` と `update(dt)` を追加する

`resize()` 関数の **下** に、2つの関数を追加します。

```js:game.js
  function reset() {
    camY = 0;
    ball = { y: 120, vy: 0, squash: 0 };
  }

  function update(dt) {
    ball.vy = Math.min(ball.vy + GRAVITY * dt, MAX_FALL);
    const prevY = ball.y;
    let newY = ball.y + ball.vy * dt;
    ball.squash = Math.max(0, ball.squash - dt * 5);

    if (prevY <= FLOOR_Y && newY >= FLOOR_Y) {
      newY = FLOOR_Y;
      ball.vy = -BOUNCE;
      ball.squash = 1;
    }
    ball.y = newY;
  }
```

### 重力で落ちるしくみ

`dt` は「前のフレームから何秒たったか」です（60fps なら約 0.0167 秒）。

1. 速さ `vy` に `GRAVITY * dt` を足す → だんだん速く落ちるようになる（`MAX_FALL` で頭打ち）
2. 位置 `y` に `vy * dt` を足す → 速さのぶんだけ進む

この2行だけで、ボールは本物っぽく加速しながら落ちます。`dt` をかけておくと、画面の更新が速いパソコンでも遅いスマホでも、同じ速さで動きます。

### 床を「通りすぎたか」で判定する

`ball.y` は **ボールの下端** の位置です。`prevY <= FLOOR_Y && newY >= FLOOR_Y` は「前のフレームでは床より上にいて、今回のフレームで床の位置をまたいだ」という意味です。`newY === FLOOR_Y` のようにぴったり一致を調べると、1フレームで何ピクセルも進むので素通りしてしまいます。**またいだかどうか** で調べるのが、すり抜けを防ぐコツです。

床をまたいだら、位置を床の上にそろえ、速さを上向き（マイナス）の `-BOUNCE` にします。これで「ポン」と跳ね返ります。

### つぶれ具合 `squash`

跳ね返った瞬間に `squash` を 1 にして、毎フレーム少しずつ 0 に戻します。描くときにこの値を使って、ボールを横に広げて縦につぶします。小さな演出ですが、「弾んでいる」感じがぐっと強くなります。

## `draw()` にボールを描く

`draw()` の柱を描くコード（`ctx.fillRect(W / 2 - pw, 0, pw * 2, H);`）の **下** に、仮の床とボールを追加します。

```js:game.js
    // 仮の床
    ctx.fillStyle = '#6fd3ff';
    ctx.fillRect(W / 2 - R, FLOOR_Y - camY, R * 2, 4);

    // ボール
    const bx = W / 2;
    const by = ball.y - camY - BALL_R;
    const sq = ball.squash * 0.35;
    ctx.save();
    ctx.translate(bx, by + BALL_R * sq);
    ctx.scale(1 + sq, 1 - sq);
    ctx.fillStyle = '#ffd84d';
    ctx.beginPath();
    ctx.arc(0, 0, BALL_R, 0, Math.PI * 2);
    ctx.fill();
    ctx.fillStyle = 'rgba(255,255,255,.7)';
    ctx.beginPath();
    ctx.arc(-BALL_R * 0.35, -BALL_R * 0.35, BALL_R * 0.3, 0, Math.PI * 2);
    ctx.fill();
    ctx.restore();
```

- ボールは常に画面の横まん中（`W / 2`）にいます。動くのは y だけです。`ball.y` は下端なので、中心は `BALL_R` だけ上になります。
- `ctx.translate(x, y)` は「座標の原点をそこへ動かす」、`ctx.scale(sx, sy)` は「それ以降の描画を拡大・縮小する」命令です。原点をボールの中心に移してから `scale(1 + sq, 1 - sq)` すると、ボールが横に広がって縦につぶれます。つぶれたぶん下端が浮かないように、中心を `BALL_R * sq` だけ下げています。
- `ctx.save()` で今の設定を保存し、`ctx.restore()` で元に戻します。こうしないと、このあと描くものまで拡大・縮小されてしまいます。
- 左上の白い小さな円は **ハイライト** です。これだけでツヤのある球に見えます。

## ゲームループと `start()`

ファイルの最後の部分を、次のように **書きかえ** ます。`startBtn.addEventListener(...)` の行から最後の `})();` までを置きかえてください。

```js:game.js
  function loop(t) {
    const dt = Math.min(0.033, (t - lastT) / 1000 || 0);
    lastT = t;
    if (state === 'play') update(dt);
    draw();
    requestAnimationFrame(loop);
  }

  function start() {
    reset();
    state = 'play';
    overlay.classList.add('hidden');
  }

  startBtn.addEventListener('click', start);
  window.addEventListener('resize', resize);

  resize();
  reset();
  requestAnimationFrame(loop);
})();
```

### `requestAnimationFrame` とは

`requestAnimationFrame(loop)` は「次に画面を描きかえるタイミングで `loop` を呼んで」とブラウザにお願いする命令です。`loop` の最後でもう一度お願いするので、`loop` は画面の更新に合わせて（ふつう1秒に60回）呼ばれ続けます。これがゲームループです。

- `loop` には、ページを開いてからの時間 `t`（ミリ秒）が渡されます。前回との差を 1000 で割ると、秒単位の `dt` になります。
- 最初の1回は `lastT` が空なので計算結果が `NaN` になります。`|| 0` で 0 にしています。
- `Math.min(0.033, ...)` で `dt` の上限を決めています。タブを裏に回して戻ったときなどに `dt` が大きくなりすぎると、ボールが床を何枚もすり抜けてしまうからです。
- プレイ中だけ `update()` で状態を進め、`draw()` は毎回呼びます。毎フレーム描き直すので、`resize` イベントでは `resize()` を呼ぶだけでよくなりました。

> [!CHECK] 動作チェック
> - 「タップでスタート」を押すと、ボールが水色の仮の床の上でポンポン跳ね続ける
> - 床に当たった瞬間、ボールが少し横につぶれる
> - スタートを押す前は、ボールは空中で止まっている
