## このステップのゴール

このゲームのいちばんの気持ちよさ、**コンボ** と **スマッシュ** を作ります。

- 床に当たらずに続けて落ちた段数が **コンボ** になり、コンボが増えるほど1段あたりの点数も増える
- 3段続けて落ちるとボールがオレンジに燃え、次に当たった床を（赤い床でも！）**突き破る**。突き破るとボーナス +5 点
- 突き破ったリングは破片になって飛び散る

## 要素と変数を追加する

`const startBtn = ...` の **下** に、トースト（一瞬出る文字）の要素を取る1行を足します。

```js:game.js
  const toastEl = document.getElementById('toast');
```

`let` の行に `combo` と `particles` を足します。

```js:game.js
  let rings, ball, camY, rot, score, combo, particles, nextIndex, keyDir, lastT;
```

`reset()` の `score = 0;` の **下** に2行足します。

```js:game.js
    score = 0;
    combo = 0;
    particles = [];
```

## トーストと破片の関数

`frontSlot()` 関数の **下**（`addScore()` の上）に追加します。

```js:game.js
  let toastTimer = 0;
  function toast(msg) {
    toastEl.textContent = msg;
    toastEl.classList.add('show');
    clearTimeout(toastTimer);
    toastTimer = setTimeout(() => toastEl.classList.remove('show'), 600);
  }

  function burst(y, color, n) {
    for (let i = 0; i < n; i++) {
      const a = Math.random() * Math.PI * 2;
      const sp = 120 + Math.random() * 260;
      particles.push({ x: W / 2 + Math.cos(a) * R * 0.6, y, vx: Math.cos(a) * sp, vy: Math.sin(a) * sp * 0.5 - 150, life: 0.7, color });
    }
  }
```

### `toast(msg)`

`#toast` に文字を入れて `show` クラスをつけると、CSS の `transition` でふわっと現れます。0.6秒後に `show` を外して消します。

続けて呼ばれたときのために、前の `setTimeout` を `clearTimeout()` で取り消しています。こうしないと、前のタイマーが新しい文字を早く消してしまいます。

### `burst(y, color, n)` と **パーティクル**

小さな四角をたくさん飛び散らせる演出を **パーティクル** と呼びます。1つ1つの破片は「位置 `x, y`・速さ `vx, vy`・残り時間 `life`・色」を持つオブジェクトで、`particles` 配列に入れておきます。

- ランダムな向き `a` とランダムな速さ `sp` を決め、`Math.cos(a)`・`Math.sin(a)` で x 方向と y 方向の速さに分けます。こうすると、破片が全方向に飛び散ります。
- y 方向の速さは半分にして、さらに `- 150` で少し上向きにしています。リングが平べったい楕円なので、横に広く、少し上にはじけるほうが自然に見えます。
- 破片の y は **画面上の位置**（`r.y - camY`）で入れています。破片は一瞬で消えるので、カメラの動きに合わせなくても気になりません。

## `update(dt)` にコンボとスマッシュを入れる

`update(dt)` 関数全体を、次のように **書きかえ** ます。

```js:game.js
  function update(dt) {
    if (keyDir) rot += keyDir * 3.2 * dt;

    ball.vy = Math.min(ball.vy + GRAVITY * dt, MAX_FALL);
    const prevY = ball.y;
    let newY = ball.y + ball.vy * dt;
    ball.squash = Math.max(0, ball.squash - dt * 5);

    for (const r of rings) {
      if (r.broken || r.passed) continue;
      if (prevY <= r.y && newY >= r.y) {
        const type = r.types[frontSlot()];
        if (type === 'gap') {
          r.passed = true;
          combo++;
          addScore(combo);
          if (combo === 3) toast('スマッシュ準備OK!');
          continue;
        }
        if (combo >= 3) {
          r.broken = true;
          burst(r.y - camY, COLORS[type][0], 26);
          addScore(5);
          toast('スマッシュ! +5');
          combo = 0;
          newY = r.y;
          ball.vy = -BOUNCE;
          ball.squash = 1;
          break;
        }
        if (type === 'danger') {
          newY = r.y;
          ball.y = newY;
          gameOver();
          return;
        }
        combo = 0;
        newY = r.y;
        ball.vy = -BOUNCE;
        ball.squash = 1;
        break;
      }
    }
    ball.y = newY;

    const target = ball.y - H * 0.35;
    if (target > camY) camY += (target - camY) * Math.min(1, dt * 8);
    ensureRings();

    for (const p of particles) {
      p.x += p.vx * dt; p.y += p.vy * dt; p.vy += 900 * dt; p.life -= dt;
    }
    particles = particles.filter(p => p.life > 0);
  }
```

変わったのは次の4か所です。

1. **すき間を通ったとき**: `combo` を1増やし、`addScore(combo)` でコンボの数だけ点数を足します（1段目 +1、2段目 +2、3段目 +3…）。ちょうど3コンボになったら「スマッシュ準備OK!」と知らせます。
2. **燃えている状態で床に当たったとき**（`combo >= 3`）: 床の種類に関係なく、そのリングに `broken = true` をつけて破片を飛ばし、+5 点。コンボを0に戻して、ふつうの床と同じように跳ね返ります。この判定を **赤い床の判定より前** に書いているので、赤い床でも突き破れます。
3. **ふつうの床で跳ね返ったとき**: `combo = 0` でコンボが途切れます。
4. **最後**: パーティクルを動かします。位置に速さを足し、`vy` に重力を足し、`life` を減らします。`filter()` で `life` が残っているものだけを残すと、消えた破片が配列から取りのぞかれます。

`broken` になったリングは、ステップ3で書いた `rings.filter(r => !r.broken)` によって描かれなくなり、判定のループでも最初の `if` で飛ばされます。

## `draw()` に燃えるボールとパーティクルを描く

`draw()` の `// ボール` から関数の最後までを、次のように **書きかえ** ます。

```js:game.js
    // ボール
    const bx = W / 2;
    const by = ball.y - camY - BALL_R;
    const sq = ball.squash * 0.35;
    ctx.save();
    ctx.translate(bx, by + BALL_R * sq);
    ctx.scale(1 + sq, 1 - sq);
    ctx.fillStyle = combo >= 3 ? '#ff9a3c' : '#ffd84d';
    ctx.beginPath();
    ctx.arc(0, 0, BALL_R, 0, Math.PI * 2);
    ctx.fill();
    ctx.fillStyle = 'rgba(255,255,255,.7)';
    ctx.beginPath();
    ctx.arc(-BALL_R * 0.35, -BALL_R * 0.35, BALL_R * 0.3, 0, Math.PI * 2);
    ctx.fill();
    ctx.restore();
    if (combo >= 3 && state === 'play') {
      ctx.strokeStyle = 'rgba(255,154,60,.5)';
      ctx.lineWidth = 3;
      ctx.beginPath();
      ctx.arc(bx, by, BALL_R + 6, 0, Math.PI * 2);
      ctx.stroke();
    }

    for (const p of particles) {
      ctx.globalAlpha = Math.max(0, p.life / 0.7);
      ctx.fillStyle = p.color;
      ctx.fillRect(p.x - 4, p.y - 4, 8, 8);
    }
    ctx.globalAlpha = 1;

    if (state === 'play' && combo > 0) {
      ctx.fillStyle = 'rgba(255,255,255,.85)';
      ctx.font = 'bold 16px system-ui, sans-serif';
      ctx.textAlign = 'left';
      ctx.fillText('COMBO ' + combo, 12, 24);
    }
  }
```

- ボールの色を、3コンボ以上ならオレンジ（`#ff9a3c`）にします。さらにまわりにうっすらオレンジの輪を描いて、燃えているように見せます。
- パーティクルは `ctx.globalAlpha`（全体の不透明度）を `life` に合わせて下げながら描くので、だんだん薄くなって消えていきます。描き終わったら `globalAlpha` を1に戻すのを忘れずに。
- プレイ中にコンボが1以上あれば、左上に「COMBO 〇」と表示します。`fillText()` は Canvas に文字を描く命令です。

> [!CHECK] 動作チェック
> - すき間を続けて落ちると、左上に「COMBO 1」「COMBO 2」…と出て、スコアが 1, 3, 6… と増えていく
> - 3段続けて落ちると「スマッシュ準備OK!」と出て、ボールがオレンジになる
> - その状態で床に当たると、リングが破片になって飛び散り、「スマッシュ! +5」と出る。赤い床でもゲームオーバーにならない
> - ふつうの床で跳ねると、COMBO の表示が消える
