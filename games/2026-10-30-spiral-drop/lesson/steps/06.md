## このステップのゴール

ゲームに緊張感を足します。リングに **赤い床**（`danger`）を混ぜ、ボールが赤い床に当たったら **ゲームオーバー** にします。ゲームオーバー画面には、スコアと「もう一度」ボタンを出します。

## 要素の取得を整える

ファイルの最初の `getElementById` の部分を、次のように **書きかえ** ます。ゲームオーバー画面の文字を書きかえるため、`ov-title` と `ov-text` も取っておきます。

```js:game.js
  const cv = document.getElementById('cv');
  const ctx = cv.getContext('2d');
  const scoreEl = document.getElementById('score');
  const overlay = document.getElementById('overlay');
  const ovTitle = document.getElementById('ov-title');
  const ovText = document.getElementById('ov-text');
  const startBtn = document.getElementById('start');
```

## 赤い床を混ぜる

`makeRing(i)` 関数全体を、次のように **書きかえ** ます。すき間を作る `for` の **下** に、赤い床を置く処理が増えています。

```js:game.js
  function makeRing(i) {
    const types = new Array(SLOTS).fill('safe');
    if (i === 0) {
      // 最初のリングは、すき間をボールの真下から少し離す
      types[6] = types[7] = 'gap';
      return { y: 200 + i * SPACING, types, passed: false, broken: false };
    }
    const gapLen = i < 10 ? 3 : 2;
    const g0 = Math.floor(Math.random() * SLOTS);
    for (let k = 0; k < gapLen; k++) types[(g0 + k) % SLOTS] = 'gap';
    const dangerCount = Math.min(5, Math.floor((i + 2) / 4));
    let placed = 0, tries = 0;
    while (placed < dangerCount && tries < 50) {
      tries++;
      const k = Math.floor(Math.random() * SLOTS);
      if (types[k] !== 'safe') continue;
      // すき間のすぐ隣は避けて、少しだけ優しくする
      if (types[(k + 1) % SLOTS] === 'gap' || types[(k + SLOTS - 1) % SLOTS] === 'gap') continue;
      types[k] = 'danger';
      placed++;
    }
    return { y: 200 + i * SPACING, types, passed: false, broken: false };
  }
```

- 赤い床の数 `dangerCount` は、段数 `i` が増えるほど多くなります。1段目は0個、2段目から1個、6段目から2個…と増えて、最大5個です。下へ行くほどむずかしくなるしかけです。
- ランダムに選んだスロットが `'safe'` のときだけ赤くします。すでにすき間や赤い床になっていたら `continue` で選び直します。
- **すき間のすぐ隣は赤くしない** ようにしています。すき間の隣が赤いと、ちょっと回しすぎただけでゲームオーバーになって理不尽に感じるからです。
- 条件に合うスロットが見つからないと無限ループになってしまうので、`tries` で50回までに制限しています。ランダムで何かを探すときの、大事な安全装置です。

赤い床の色は、ステップ3で `COLORS.danger` に用意してあるので、`drawRingPart()` はそのままで赤く描かれます。

## 赤い床に当たったらゲームオーバー

`update(dt)` の当たり判定のループの中、すき間のときの `if (type === 'gap') { ... }` の **下** に、赤い床のときの処理を追加します。

```js:game.js
        if (type === 'gap') {
          r.passed = true;
          addScore(1);
          continue;
        }
        if (type === 'danger') {
          newY = r.y;
          ball.y = newY;
          gameOver();
          return;
        }
        newY = r.y;
        ball.vy = -BOUNCE;
        ball.squash = 1;
        break;
```

ボールを床の上にそろえてから `gameOver()` を呼び、`return` で `update()` をすぐに終わらせます。`return` しないと、このあとのカメラの処理などが動いてしまいます。

## `gameOver()` を追加する

`start()` 関数の **下** に追加します。

```js:game.js
  function gameOver() {
    state = 'over';
    const msg = 'スコア ' + score;
    ovTitle.textContent = 'ゲームオーバー';
    ovText.innerHTML = msg + '<br>赤い床に当たっちゃった…';
    startBtn.textContent = 'もう一度';
    setTimeout(() => overlay.classList.remove('hidden'), 400);
  }
```

- `state` を `'over'` にすると、`loop()` の `if (state === 'play')` が成り立たなくなり、`update()` が呼ばれなくなります。ボールはその場で止まりますが、`draw()` は呼ばれ続けるので、画面はそのまま見えています。
- オーバーレイのタイトル・本文・ボタンの文字を書きかえて、タイトル画面をゲームオーバー画面として使い回します。`<br>` で改行したいので、本文は `textContent` ではなく `innerHTML` で入れています。
- `setTimeout(関数, 400)` で、0.4秒待ってからオーバーレイを出します。どこでぶつかったかを一瞬見せてから画面を切りかえると、プレイヤーが納得しやすくなります。
- 「もう一度」ボタンには、ステップ2で `start` をつないであるので、押すと `reset()` から新しいゲームが始まります。

> [!CHECK] 動作チェック
> - 2段目より下のリングに、赤い床がまざっている。下へ行くほど赤い床が増える
> - 赤い床の上にボールが落ちると、ボールが止まり、少しあとに「ゲームオーバー」「スコア 〇」の画面が出る
> - 「もう一度」ボタン（または Enter キー）で、スコア0から新しい塔で遊び直せる
