## このステップのゴール

3つのファイルを用意して、画面の土台を作ります。上に「スコア・ベスト」の表示、まん中にゲーム画面の **Canvas**、その上に重ねるタイトル画面（オーバーレイ）を置きます。Canvas にはまだ塔の **柱** だけを描きます。

完成すると、こんなゲームになります。

- ボールは自動でポンポン跳ね続ける
- プレイヤーは左右にドラッグして、柱のまわりの **リング（床）** を回す
- リングのすき間がボールの真下に来ると、ボールが下の段へ落ちる
- 赤い床に当たるとゲームオーバー。3段続けて落ちるとボールが燃えて、次の床を突き破れる

## index.html

まずは HTML です。このステップで画面の部品はすべてそろえてしまい、以降は `game.js` だけを育てていきます。

```html:index.html
<body>

```

- `header` に SCORE・BEST の2つの数字を並べます。JavaScript から書き換えるので、数字の `b` 要素に `id` をつけています。
- `#stage` の中に `canvas`・`#toast`（「スマッシュ!」などの文字を一瞬出す場所）・`#overlay` を **重ねて** 置きます。オーバーレイはタイトル画面とゲームオーバー画面の両方に使い回します。
- 「← 一覧」のリンク先は自分の環境に合わせて変えてかまいません。
- `<script>` を `body` の最後に置くと、HTML の要素が全部できてからスクリプトが動くので、`getElementById` で確実に要素が取れます。

ポイントは次のとおりです。

- `#app` を縦方向の **Flexbox** にして、`#stage` に `flex: 1` を指定すると「ヘッダーを除いた残り全部」がゲーム画面になります。`min-height: 0` は、中身が大きくてもはみ出さずに縮めるためのおまじないです。
- `canvas` は `width: 100%; height: 100%;` で `#stage` いっぱいに広げます。背景のグラデーションも CSS でつけているので、JavaScript で背景を塗る必要はありません。
- `#stage` を `position: relative`、`#overlay` を `position: absolute; inset: 0 8px 10px` にすると、オーバーレイが Canvas にぴったり重なります。`hidden` クラスをつけ外しするだけで表示を切り替えられます。
- `#toast` はふだん `opacity: 0` で見えず、`show` クラスがつくとふわっと現れます（`transition`）。`pointer-events: none` なので、上に重なっていてもドラッグのじゃまをしません。
- `touch-action: none` は、スマホでドラッグしたときに画面がスクロールしたり拡大されたりするのを防ぎます。このゲームはドラッグで操作するので、とても大事な指定です。

## game.js

```js:game.js
(() => {
  'use strict';
  const cv = document.getElementById('cv');
  const ctx = cv.getContext('2d');
  const overlay = document.getElementById('overlay');
  const startBtn = document.getElementById('start');

  let W = 0, H = 0, dpr = 1, R = 120, RY = 38;

  function resize() {
    const rect = cv.getBoundingClientRect();
    dpr = Math.min(window.devicePixelRatio || 1, 2);
    W = rect.width; H = rect.height;
    cv.width = Math.round(W * dpr);
    cv.height = Math.round(H * dpr);
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
    R = Math.min(W * 0.38, 160);
    RY = R * 0.3;
  }

  function draw() {
    ctx.clearRect(0, 0, W, H);

    // 柱
    const pw = Math.max(16, R * 0.16);
    const grad = ctx.createLinearGradient(W / 2 - pw, 0, W / 2 + pw, 0);
    grad.addColorStop(0, '#5b49c9');
    grad.addColorStop(0.5, '#9d8cff');
    grad.addColorStop(1, '#4a3aa8');
    ctx.fillStyle = grad;
    ctx.fillRect(W / 2 - pw, 0, pw * 2, H);
  }

  startBtn.addEventListener('click', () => overlay.classList.add('hidden'));
  window.addEventListener('resize', () => { resize(); draw(); });

  resize();
  draw();
})();
```

### コード全体を `(() => { ... })();` で包む理由

これは **即時実行関数** と呼ばれる書き方です。中で宣言した変数がページ全体（グローバル）に漏れないので、ほかのスクリプトと名前がぶつかりません。`'use strict';` は、宣言し忘れた変数などのミスをエラーとして教えてくれるモードです。

### Canvas とは

`<canvas>` は JavaScript で自由に絵を描ける「キャンバス」です。`getContext('2d')` で取り出した `ctx`（コンテキスト）に `fillRect`（四角を塗る）や `arc`（円を描く）などの命令を出して描きます。座標は左上が `(0, 0)` で、右に行くほど x、**下に行くほど y が大きく** なります。

### 大きさを決める `resize()`

- `cv.getBoundingClientRect()` で、CSS によって決まった Canvas の見た目の大きさ（幅 `W`・高さ `H`）を調べます。
- Canvas には「CSS で見える大きさ」と「内部の画素数」（`cv.width` / `cv.height`）の2つのサイズがあります。高精細な画面では1 CSS ピクセルに複数の物理ピクセルが詰まっている（`devicePixelRatio`）ので、内部の画素数を `W × dpr` にしないと絵がぼやけます。重くなりすぎないように、`dpr` は最大2にしています。
- `ctx.setTransform(dpr, 0, 0, dpr, 0, 0)` で「座標を dpr 倍して描く」設定にします。これで、以降は CSS ピクセル単位の座標を指定するだけでくっきり描けます。
- `R` はリングの横の半径、`RY` は縦の半径です。リングは真上から少し斜めに見下ろした円なので、画面では **横長の楕円** に見えます。縦の半径を横の 0.3 倍にすると、ほどよく立体的に見えます。画面幅の 38%（最大160px）を半径にして、スマホでも PC でも収まるようにしています。

### 柱を描く `draw()`

- `ctx.clearRect()` で前の絵を消してから描きます。
- `createLinearGradient(x0, y0, x1, y1)` は、2点のあいだで色が変わる **グラデーション** を作ります。柱の左端から右端に向かって「暗い紫 → 明るい紫 → 暗い紫」と変えると、丸い円柱に光が当たっているように見えます。
- 柱の太さ `pw` も `R` をもとに決めるので、画面の大きさが変わっても全体のバランスが崩れません。
- Canvas の大きさを変えると中身が消えるので、ウィンドウの大きさが変わったら `resize()` のあとに `draw()` で描き直しています。
