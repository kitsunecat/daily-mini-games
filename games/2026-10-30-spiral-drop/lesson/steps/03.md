## このステップのゴール

柱のまわりに、ゲームの主役である **リング**（床）を何段も並べます。リングは12個の **スロット**（扇形の区切り）でできていて、ところどころに **すき間** があります。リングの奥側は柱のうしろに、手前側は柱の前に描いて、立体的な塔に見せます。

ボールはまだ仮の床（y = 200）で跳ねていますが、いちばん上のリングもちょうど y = 200 にあるので、リングの上で跳ねているように見えます。

## 定数と変数を追加する

ファイルの上のほうの定数を、次のように **書きかえ** ます（`const GRAVITY = 1500;` の上に3行、`BALL_R` の下に `COLORS` を足します）。

```js:game.js
  const SLOTS = 12;
  const SLOT_ANG = Math.PI * 2 / SLOTS;
  const SPACING = 130;
  const GRAVITY = 1500;
  const BOUNCE = 560;
  const MAX_FALL = 900;
  const BALL_R = 11;
  const COLORS = {
    safe: ['#6fd3ff', '#2e7fb8'],
    danger: ['#ff4f6a', '#a3203a'],
  };
  const FLOOR_Y = 200; // 仮の床（ステップ5で消す）
```

- `SLOTS` はリング1周のスロット数、`SLOT_ANG` は1スロットぶんの角度です。JavaScript の角度は **ラジアン** で、1周が `Math.PI * 2`（約 6.28）です。12で割ると、1スロットは 30° ぶんになります。
- `SPACING` はリングどうしの上下の間かくです。
- `COLORS` はスロットの種類ごとの色で、`[表面の色, 側面の色]` の組になっています。`safe` は水色のふつうの床、`danger` は赤い床（ステップ6で使います）です。

`let` の行も、`rings`・`rot`・`nextIndex` を足して書きかえます。

```js:game.js
  let rings, ball, camY, rot, nextIndex, lastT;
```

- `rings` はリングの配列、`rot` は塔の回転角度（ラジアン）、`nextIndex` は「次に作るリングが何段目か」です。

## リングを作る `makeRing(i)`

`resize()` 関数の **下** に追加します。

```js:game.js
  function makeRing(i) {
    const types = new Array(SLOTS).fill('safe');
    if (i === 0) {
      // 最初のリングは、すき間をボールの真下から少し離す
      types[6] = types[7] = 'gap';
      return { y: 200 + i * SPACING, types, passed: false, broken: false };
    }
    const gapLen = i < 10 ? 3 : 2;
    const g0 = Math.floor(Math.random() * SLOTS);
    for (let k = 0; k < gapLen; k++) types[(g0 + k) % SLOTS] = 'gap';
    return { y: 200 + i * SPACING, types, passed: false, broken: false };
  }
```

- リング1つは、`y`（ワールド座標での高さ）と `types`（12スロットそれぞれの種類を入れた配列）を持つオブジェクトです。`passed`（もう通りすぎた）と `broken`（壊れた）はあとのステップで使います。
- `new Array(SLOTS).fill('safe')` で「12個ぜんぶ `'safe'`」の配列を作り、すき間にしたいスロットだけ `'gap'` に書きかえます。
- すき間の始まり `g0` をランダムに決め、そこから3つ（10段目からは2つ）を `'gap'` にします。`(g0 + k) % SLOTS` の `%`（割り算の余り）を使うと、11番の次が0番に戻るので、すき間がリングの継ぎ目をまたいでも正しく作れます。
- 最初のリング（`i === 0`）だけは、すき間の場所を固定しています。スタート直後にいきなり落ちてしまわないように、ボールの真下から離しておくためです。

## `reset()` と `ensureRings()`

`reset()` を次のように **書きかえ**、その **下** に `ensureRings()` を追加します。

```js:game.js
  function reset() {
    rings = [];
    nextIndex = 0;
    rot = 0;
    camY = 0;
    ball = { y: 120, vy: 0, squash: 0 };
    ensureRings();
  }

  function ensureRings() {
    while (nextIndex === 0 || rings[rings.length - 1].y < camY + H + 300) {
      rings.push(makeRing(nextIndex++));
    }
    while (rings.length && rings[0].y < camY - 200) rings.shift();
  }
```

このゲームの塔は **どこまでも続き** ます。でも、無限にリングを作っておくことはできません。そこで `ensureRings()` で次の2つを行います。

- いちばん下のリングが「画面の下端（`camY + H`）より300px下」に届くまで、新しいリングを足す
- 画面の上に200px以上はみ出したリングは、`shift()` で配列の先頭から捨てる

こうすると、配列にはいつも画面のまわりのリングだけが入っていて、何百段落ちても重くなりません。今はカメラが動かないので最初の数段だけですが、ステップ5でカメラが動くようになると、この関数が活躍します。

## リングを描く `drawRingPart(r, front)`

`update()` 関数の **下** に追加します。少し長いですが、このゲームでいちばん面白いところです。

```js:game.js
  function drawRingPart(r, front) {
    const cy = r.y - camY - RY;
    if (cy < -RY * 3 || cy > H + RY * 3) return;
    const lw = Math.max(12, R * 0.13);
    for (let pass = 0; pass < 2; pass++) {
      ctx.lineWidth = lw;
      ctx.lineCap = 'butt';
      for (let k = 0; k < SLOTS; k++) {
        const type = r.types[k];
        if (type === 'gap') continue;
        const col = COLORS[type][pass === 0 ? 1 : 0];
        const a0 = k * SLOT_ANG + rot;
        // 1スロットを3分割して、手前/奥を判定
        for (let s = 0; s < 3; s++) {
          const b0 = a0 + s * SLOT_ANG / 3;
          const b1 = b0 + SLOT_ANG / 3 + 0.01;
          const isFront = Math.sin((b0 + b1) / 2) > 0;
          if (isFront !== front) continue;
          ctx.strokeStyle = col;
          ctx.beginPath();
          ctx.ellipse(W / 2, cy + (pass === 0 ? lw * 0.6 : 0), R, RY, 0, b0, b1);
          ctx.stroke();
        }
      }
    }
  }
```

### 楕円の弧でスロットを描く

`ctx.ellipse(cx, cy, rx, ry, 回転, 開始角, 終了角)` は、楕円の一部（弧）のパスを作る命令です。これを太い線（`lineWidth`）で `stroke()` すると、ドーナツの一部のような帯になります。

- スロット `k` は、角度 `k * SLOT_ANG + rot` から始まります。全スロットの角度に `rot` を足すので、`rot` を変えるだけで塔全体が回って見えます。
- `'gap'` のスロットは描かずに飛ばすだけで、すき間になります。
- 楕円の中心 `cy` は `r.y - camY - RY` にしています。楕円の **いちばん手前（下端）** がちょうど `r.y` になるので、ボールの下端 `ball.y` と比べるだけで当たり判定ができます。
- 画面の外にあるリングは、最初の `if` で描かずに終わらせます。

### 手前と奥を描き分ける

Canvas の角度は「右が 0、**時計回り** に増える」ので、角度の `sin` がプラスなら楕円の下半分、つまり **手前側** です。描く順番を「リングの奥側 → 柱 → リングの手前側」にすれば、奥側が柱に隠れて立体的に見えます。

ただ、1スロット（30°）の中で手前と奥が切りかわることもあるので、スロットを3つに分けて、それぞれのまん中の角度で手前か奥かを決めています。終わりの角度に `0.01` 足しているのは、分けた部分のあいだに細いすき間が見えないようにするためです。

### 厚みを出す2回塗り

`pass` が 0 のときは **側面の色**（暗い色）で少し下にずらして描き、`pass` が 1 のときに **表面の色** で本来の位置に描きます。下に暗い帯がのぞくので、リングに厚みがあるように見えます。

## `draw()` を書きかえる

`draw()` 関数全体を、次のように **書きかえ** ます。仮の床の線は消して、リングを描くようにします。

```js:game.js
  function draw() {
    ctx.clearRect(0, 0, W, H);
    const visible = rings.filter(r => !r.broken);
    for (const r of visible) drawRingPart(r, false);

    // 柱
    const pw = Math.max(16, R * 0.16);
    const grad = ctx.createLinearGradient(W / 2 - pw, 0, W / 2 + pw, 0);
    grad.addColorStop(0, '#5b49c9');
    grad.addColorStop(0.5, '#9d8cff');
    grad.addColorStop(1, '#4a3aa8');
    ctx.fillStyle = grad;
    ctx.fillRect(W / 2 - pw, 0, pw * 2, H);

    for (const r of visible) drawRingPart(r, true);

    // ボール
    const bx = W / 2;
    const by = ball.y - camY - BALL_R;
    const sq = ball.squash * 0.35;
    ctx.save();
    ctx.translate(bx, by + BALL_R * sq);
    ctx.scale(1 + sq, 1 - sq);
    ctx.fillStyle = '#ffd84d';
    ctx.beginPath();
    ctx.arc(0, 0, BALL_R, 0, Math.PI * 2);
    ctx.fill();
    ctx.fillStyle = 'rgba(255,255,255,.7)';
    ctx.beginPath();
    ctx.arc(-BALL_R * 0.35, -BALL_R * 0.35, BALL_R * 0.3, 0, Math.PI * 2);
    ctx.fill();
    ctx.restore();
  }
```

- `rings.filter(r => !r.broken)` は、壊れていないリングだけを集めた配列を作ります。リングが壊れるのはステップ7からですが、先に書いておきます。
- 描く順番が「奥 → 柱 → 手前 → ボール」になっていることを確認しましょう。

> [!CHECK] 動作チェック
> - 柱のまわりに、水色のリングが画面の下まで何段も並んでいる
> - リングの奥側は柱に隠れ、手前側は柱の前に描かれている。下側に暗い色の厚みが見える
> - リングごとに、ランダムな場所にすき間がある（再読み込みすると変わる）
> - スタートすると、ボールがいちばん上のリングの上で跳ね続ける
