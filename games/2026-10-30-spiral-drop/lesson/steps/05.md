## このステップのゴール

いよいよゲームらしくなります。ボールがリングの位置まで落ちてきたとき、**ボールの真下のスロット** がすき間なら下の段へ落ち、床なら跳ね返るようにします。落ちていくボールを **カメラ** が追いかけ、通りぬけた段の数がスコアになります。仮の床はここで卒業です。

## 定数と変数を整える

1. ファイルの上の `const ctx = cv.getContext('2d');` の **下** に、スコアを表示する要素を取る1行を足します。
2. `const FLOOR_Y = 200; ...` の行は **削除** します。
3. `let` の行に `score` を足します。

```js:game.js
  const ctx = cv.getContext('2d');
  const scoreEl = document.getElementById('score');
```

```js:game.js
  let rings, ball, camY, rot, score, nextIndex, keyDir, lastT;
```

`reset()` は、スコアを 0 に戻す処理を足して次のように **書きかえ** ます。

```js:game.js
  function reset() {
    rings = [];
    nextIndex = 0;
    rot = 0;
    camY = 0;
    score = 0;
    keyDir = 0;
    ball = { y: 120, vy: 0, squash: 0 };
    ensureRings();
    scoreEl.textContent = 0;
  }
```

## ボールの真下のスロットを調べる `frontSlot()`

`ensureRings()` 関数の **下** に、2つの関数を追加します。

```js:game.js
  function frontSlot() {
    const a = ((Math.PI / 2 - rot) % (Math.PI * 2) + Math.PI * 2) % (Math.PI * 2);
    return Math.floor(a / SLOT_ANG) % SLOTS;
  }

  function addScore(n) {
    score += n;
    scoreEl.textContent = score;
  }
```

ボールは柱のすぐ手前、つまり楕円の **いちばん手前** の真上で跳ねています。楕円のいちばん手前は角度 `Math.PI / 2`（90°、真下方向）です。

スロット `k` は角度 `k * SLOT_ANG + rot` から始まるので、「`Math.PI / 2` の位置にあるのは何番のスロットか」は、`(Math.PI / 2 - rot) / SLOT_ANG` を切り捨てれば分かります。

ただし `rot` はドラッグでいくらでも大きく（マイナスにも）なるので、角度を 0〜2π の範囲に直す必要があります。JavaScript の `%` はマイナスの数に使うと答えもマイナスになるので、`(x % 2π + 2π) % 2π` という書き方で、必ず 0 以上 2π 未満にしています。これは角度を扱うときによく使うテクニックです。

`addScore(n)` は、スコアを増やして画面の表示も書きかえる小さな関数です。

## `update(dt)` に当たり判定とカメラを入れる

`update(dt)` 関数全体を、次のように **書きかえ** ます。

```js:game.js
  function update(dt) {
    if (keyDir) rot += keyDir * 3.2 * dt;

    ball.vy = Math.min(ball.vy + GRAVITY * dt, MAX_FALL);
    const prevY = ball.y;
    let newY = ball.y + ball.vy * dt;
    ball.squash = Math.max(0, ball.squash - dt * 5);

    for (const r of rings) {
      if (r.broken || r.passed) continue;
      if (prevY <= r.y && newY >= r.y) {
        const type = r.types[frontSlot()];
        if (type === 'gap') {
          r.passed = true;
          addScore(1);
          continue;
        }
        newY = r.y;
        ball.vy = -BOUNCE;
        ball.squash = 1;
        break;
      }
    }
    ball.y = newY;

    const target = ball.y - H * 0.35;
    if (target > camY) camY += (target - camY) * Math.min(1, dt * 8);
    ensureRings();
  }
```

### リングとの当たり判定

ステップ2の仮の床と同じく「前のフレームではリングより上、今回はリングより下」をまたいだかどうかで調べます。ちがうのは、すべてのリングについて調べることと、**またいだ瞬間にボールの真下のスロットの種類を見る** ことです。

- すき間（`'gap'`）なら、そのリングに `passed = true` の印をつけ、スコアを1増やして `continue` します。`continue` で次のリングの判定に進むので、1フレームで2段ぶん落ちても正しく判定できます。
- 床なら、ボールをリングの上にそろえて跳ね返し、`break` でループを抜けます。
- 一度通りぬけたリングは、`passed` を見て判定から外します。ボールが跳ね上がったときに、通りぬけたリングに下から当たらないようにするためです。

### カメラがボールを追いかける

ボールが画面の上から 35% の位置に来るように、カメラの目標位置 `target` を決めます。

- `camY += (target - camY) * Math.min(1, dt * 8)` は、「目標との差の一部だけ近づく」書き方です。毎フレーム少しずつ近づくので、カメラがふわっとなめらかについてきます。
- `if (target > camY)` で、カメラは **下にしか動かない** ようにしています。ボールが跳ねるたびに画面が上下にゆれると、目が疲れてしまうからです。
- カメラが動いたら `ensureRings()` を呼んで、下に新しいリングを足し、上の古いリングを捨てます。

> [!CHECK] 動作チェック
> - ドラッグやキーでリングを回し、すき間をボールの真下に合わせると、ボールが下の段へ落ちる
> - 落ちるたびに SCORE が1ずつ増える
> - ボールが落ちていくと画面がなめらかに下へスクロールし、新しいリングがどんどん出てくる
> - すき間のない場所では、これまでどおり跳ね返る
