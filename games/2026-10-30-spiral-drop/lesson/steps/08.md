## このステップのゴール

最後の仕上げです。

- **ハイスコア** をブラウザに保存して、再読み込みしても BEST が残るようにする
- **効果音** をつけて、跳ねる・落ちる・突き破る・ゲームオーバーの手ごたえを出す

これで完成品の「らせんドロップ」と同じになります。

## 要素と定数を追加する

`const scoreEl = ...` の **下** に1行、`const SLOTS = 12;` の **上** に1行足します。

```js:game.js
  const bestEl = document.getElementById('best');
```

```js:game.js
  const BEST_KEY = 'spiral-drop-best';
```

## ハイスコアの読みこみと効果音の関数

`let rings, ball, ...` の行の **下** に追加します。

```js:game.js
  let best = 0;
  try { best = Number(localStorage.getItem(BEST_KEY)) || 0; } catch (e) { best = 0; }
  bestEl.textContent = best;

  // ---- sound ----
  let actx = null;
  function beep(freq, dur, type = 'sine', vol = 0.15) {
    try {
      if (!actx) actx = new (window.AudioContext || window.webkitAudioContext)();
      const o = actx.createOscillator();
      const g = actx.createGain();
      o.type = type;
      o.frequency.value = freq;
      g.gain.setValueAtTime(vol, actx.currentTime);
      g.gain.exponentialRampToValueAtTime(0.001, actx.currentTime + dur);
      o.connect(g).connect(actx.destination);
      o.start();
      o.stop(actx.currentTime + dur);
    } catch (e) { /* 音が出なくても遊べる */ }
  }
```

### `localStorage` でハイスコアを保存する

`localStorage` は、ブラウザにちょっとしたデータを保存できるしくみです。ページを閉じたり再読み込みしたりしても消えません。

- `localStorage.getItem(キー)` で読み出し、`localStorage.setItem(キー, 文字列)` で保存します。保存できるのは **文字列だけ** なので、読み出したら `Number()` で数に直します。まだ何も保存されていないときは `null` が返り、`Number(null)` は 0 になります。
- キーは `'spiral-drop-best'` のように、ゲームごとにちがう名前にしておきます。同じサイトのほかのゲームと保存場所がぶつからないようにするためです。
- プライベートブラウズなどで `localStorage` が使えないと、エラーになることがあります。`try ... catch` で囲んでおけば、保存できなくてもゲームは遊べます。

### Web Audio API で効果音を鳴らす

音声ファイルを用意しなくても、**Web Audio API** を使えば JavaScript だけで「ピッ」という音を作れます。

- `AudioContext` は音を作る作業場です。最初の1回だけ作って `actx` に覚えておきます。ブラウザは「ユーザーが操作するまで音を出さない」決まりなので、スタートボタンを押したあと（最初に `beep()` が呼ばれたとき）に作るのがちょうどよいタイミングです。
- `createOscillator()` は一定の高さの音を出す **発振器** です。`frequency` が音の高さ（Hz）、`type` が音色で、`'sine'`（やわらかい）・`'triangle'`（少し明るい）・`'square'`（ピコピコ）・`'sawtooth'`（ザラッとした）を使い分けています。
- `createGain()` は音量のつまみです。`exponentialRampToValueAtTime()` で音量を `dur` 秒かけて小さくすると、「ポン」と自然に消える音になります。
- `o.connect(g).connect(actx.destination)` で「発振器 → 音量 → スピーカー」とつなぎ、`start()` で鳴らし始め、`stop()` で止める時刻を予約します。

## `update(dt)` に効果音を入れる

`update(dt)` 関数を、次のように **書きかえ** ます（`beep(...)` の行が3つ増えています）。

```js:game.js
  function update(dt) {
    if (keyDir) rot += keyDir * 3.2 * dt;

    ball.vy = Math.min(ball.vy + GRAVITY * dt, MAX_FALL);
    const prevY = ball.y;
    let newY = ball.y + ball.vy * dt;
    ball.squash = Math.max(0, ball.squash - dt * 5);

    for (const r of rings) {
      if (r.broken || r.passed) continue;
      if (prevY <= r.y && newY >= r.y) {
        const type = r.types[frontSlot()];
        if (type === 'gap') {
          r.passed = true;
          combo++;
          addScore(combo);
          beep(500 + combo * 80, 0.08, 'triangle', 0.08);
          if (combo === 3) toast('スマッシュ準備OK!');
          continue;
        }
        if (combo >= 3) {
          r.broken = true;
          burst(r.y - camY, COLORS[type][0], 26);
          addScore(5);
          toast('スマッシュ! +5');
          beep(180, 0.2, 'square', 0.12);
          combo = 0;
          newY = r.y;
          ball.vy = -BOUNCE;
          ball.squash = 1;
          break;
        }
        if (type === 'danger') {
          newY = r.y;
          ball.y = newY;
          gameOver();
          return;
        }
        combo = 0;
        newY = r.y;
        ball.vy = -BOUNCE;
        ball.squash = 1;
        beep(320, 0.06, 'sine', 0.1);
        break;
      }
    }
    ball.y = newY;

    const target = ball.y - H * 0.35;
    if (target > camY) camY += (target - camY) * Math.min(1, dt * 8);
    ensureRings();

    for (const p of particles) {
      p.x += p.vx * dt; p.y += p.vy * dt; p.vy += 900 * dt; p.life -= dt;
    }
    particles = particles.filter(p => p.life > 0);
  }
```

- すき間を通るたびに、コンボが増えるほど高い音（`500 + combo * 80` Hz）が鳴ります。音が上がっていくと、連続で落ちる気持ちよさが増します。
- 突き破ったときは低い `'square'` の音、ふつうに跳ねたときは小さな `'sine'` の音です。

## `start()` と `gameOver()` を仕上げる

`start()` と `gameOver()` を、次のように **書きかえ** ます。

```js:game.js
  function start() {
    reset();
    state = 'play';
    overlay.classList.add('hidden');
    beep(660, 0.1, 'triangle', 0.1);
  }

  function gameOver() {
    state = 'over';
    beep(140, 0.4, 'sawtooth', 0.12);
    let msg = 'スコア ' + score;
    if (score > best) {
      best = score;
      try { localStorage.setItem(BEST_KEY, String(best)); } catch (e) { /* 保存できなくても続行 */ }
      bestEl.textContent = best;
      msg += '<br>ハイスコア更新！';
    }
    ovTitle.textContent = 'ゲームオーバー';
    ovText.innerHTML = msg + '<br>赤い床に当たっちゃった…';
    startBtn.textContent = 'もう一度';
    setTimeout(() => overlay.classList.remove('hidden'), 400);
  }
```

- スタート時とゲームオーバー時にも音を鳴らします。
- ゲームオーバーのとき、スコアがベストを超えていたら `best` を更新し、`localStorage` に保存して、BEST の表示も書きかえます。メッセージに「ハイスコア更新！」を足すので、`msg` は `const` から `let` に変えています。

> [!CHECK] 動作チェック
> - スタート・跳ねる・すき間を落ちる・突き破る・ゲームオーバーのそれぞれで効果音が鳴る。コンボが続くと落ちる音がだんだん高くなる
> - ベストを超えるスコアでゲームオーバーになると「ハイスコア更新！」と出て、右上の BEST が更新される
> - ページを再読み込みしても BEST の数字が残っている

これで完成です！ 完成品の「らせんドロップ」と同じように遊べるはずです。

## 改造アイデア

> [!TIP]
> **リングの色をステージごとに変える**: 10段ごとに `COLORS.safe` の色を変えたり、`canvas` の背景のグラデーションを JavaScript から書きかえたりすると、深く潜っている感じが出ます。`makeRing(i)` でリングに色の番号を持たせて、`drawRingPart()` でその色を使うと、段ごとに色が変わる塔も作れます。

> [!TIP]
> **回る床**: ある段数より下では、リングごとに `spin` という速さを持たせて、`update()` でそのリングだけ少しずつ回してみましょう。`drawRingPart()` と `frontSlot()` で使う角度を `rot + r.spin` にすれば作れます。タイミングを見て落ちる、新しい遊びになります。

> [!TIP]
> **ゴールの床**: 50段目に虹色のゴールのリングを置き、そこに着いたらステージクリアにしてみましょう。`makeRing(i)` で `i === 50` のときに特別な種類 `'goal'` を作り、当たり判定で `'goal'` ならクリア画面を出します。

> [!TIP]
> **スマッシュのはしご**: 今はスマッシュで突き破るとコンボが0に戻ります。突き破ってもコンボを残すようにすると、何段も一気に突き破れる爽快なモードになります。そのぶん、赤い床を増やしてバランスを取ってみましょう。
