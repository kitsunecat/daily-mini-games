## このステップのゴール

塔を回せるようにします。スマホやマウスでは **左右にドラッグ**、PC では **← → キー** で回します。Enter キーでスタートできるようにもします。

## 変数 `keyDir` を追加する

`let` の行に `keyDir` を足します。

```js:game.js
  let rings, ball, camY, rot, nextIndex, keyDir, lastT;
```

`reset()` の `camY = 0;` の **下** に1行足します。

```js:game.js
    camY = 0;
    keyDir = 0;
```

`keyDir` は「今どちらのキーが押されているか」で、← なら `1`、→ なら `-1`、どちらも押されていなければ `0` です。

## `update(dt)` の最初でキー入力を反映する

`update(dt)` 関数の **いちばん最初** に1行足します。

```js:game.js
  function update(dt) {
    if (keyDir) rot += keyDir * 3.2 * dt;

    ball.vy = Math.min(ball.vy + GRAVITY * dt, MAX_FALL);
```

キーを押しているあいだ、1秒あたり 3.2 ラジアン（約半周）の速さで回ります。キーの「押した瞬間」ではなく「押している状態」を変数に覚えておき、毎フレーム `dt` をかけて回すのがポイントです。こうすると、キーのリピート間かくに関係なく、なめらかに回ります。

> [!NOTE]
> ← キーで `rot` が **増える** と、手前側のスロットが左へ動いて見えます。Canvas の角度は時計回りに増えるので、楕円の手前側（下半分）では、角度が増えると右から左へ進むからです。

## 入力の処理を追加する

ファイルの最後のほうの `startBtn.addEventListener('click', start);` の **上** に、入力の処理を追加します。

```js:game.js
  // ---- input ----
  let dragging = false, lastX = 0;
  cv.addEventListener('pointerdown', e => {
    dragging = true;
    lastX = e.clientX;
    try { cv.setPointerCapture(e.pointerId); } catch (err) { /* ignore */ }
  });
  cv.addEventListener('pointermove', e => {
    if (!dragging) return;
    const dx = e.clientX - lastX;
    lastX = e.clientX;
    rot -= dx * (2.4 / Math.max(200, W));
  });
  const endDrag = () => { dragging = false; };
  cv.addEventListener('pointerup', endDrag);
  cv.addEventListener('pointercancel', endDrag);

  window.addEventListener('keydown', e => {
    if (e.key === 'ArrowLeft') { keyDir = 1; e.preventDefault(); }
    else if (e.key === 'ArrowRight') { keyDir = -1; e.preventDefault(); }
    else if (e.key === 'Enter' && state !== 'play') start();
  });
  window.addEventListener('keyup', e => {
    if ((e.key === 'ArrowLeft' && keyDir === 1) || (e.key === 'ArrowRight' && keyDir === -1)) keyDir = 0;
  });
```

### Pointer Events でドラッグを作る

**Pointer Events**（`pointerdown` / `pointermove` / `pointerup`）は、マウス・タッチ・ペンをまとめて扱えるイベントです。これを使えば、PC とスマホで別々のコードを書く必要がありません。

- `pointerdown` で「ドラッグ中」にして、そのときの x 座標を `lastX` に覚えます。
- `pointermove` では、前回からの移動量 `dx` を計算し、そのぶん `rot` を変えます。指を右へ動かしたら手前のスロットも右へ動いてほしいので、`rot` から **引いて** います。
- 移動量に `2.4 / Math.max(200, W)` をかけているので、画面の端から端までドラッグすると約 2.4 ラジアン（約140°）回ります。画面幅で割っておくと、小さいスマホでも大きい PC でも同じくらいの手ごたえになります。
- `setPointerCapture()` を使うと、指が Canvas の外に出てもイベントを受け取り続けられます。古いブラウザで失敗してもゲームが止まらないように、`try ... catch` で囲んでいます。
- `pointercancel` は、電話がかかってきたときなどにタッチが中断されたときのイベントです。これでもドラッグを終わらせます。

ドラッグはプレイ中かどうかに関係なく効くので、タイトル画面の裏でも塔を回してみられます。

### キーボード

- `keydown` でキーが押されたら `keyDir` をセットし、`keyup` で離されたら 0 に戻します。
- `keyup` で「離したキーが、今 `keyDir` に入っている向きと同じか」を調べているのは、← を押したまま → を押して、← を離したときに → の回転が止まらないようにするためです。
- `e.preventDefault()` は、矢印キーでページがスクロールするのを止めます。
- Enter は、プレイ中でなければ `start()` を呼びます。

> [!CHECK] 動作チェック
> - Canvas の上を左右にドラッグすると、リングがいっせいに回る。指を動かした方向に手前側のリングが動く
> - PC では ← → キーを押しているあいだ、なめらかに回り続ける
> - タイトル画面で Enter キーを押すとスタートする
> - ボールはまだ、すき間の上に来ても落ちない（次のステップで作ります）
