## このステップのゴール

手ざわりをよくする **パーティクル**（小さな粒）の演出を足します。

- 刺さったとき、木くずがパラパラ散る
- 星を取ったとき、金色の粒がパッと広がる
- ステージクリアで、まとが木片になって **はじけ飛び**、刺さっていたダーツもくるくる回りながら飛んでいく
- 最初の1本を投げる前は、画面の下に「タップで投げる」と出す

## パーティクルの配列

`let bounce = null; // {x,y,vx,vy,a,va}` の行の **下** に追加します。

```js:game.js
  let parts = [];
```

パーティクル1つは、次のようなオブジェクトです。

- `x, y` … 位置、`vx, vy` … 速度
- `life` … のこりの寿命（秒）。0 になったら消す
- `c` … 色、`s` … 大きさ
- `g` … 1 なら強い重力（重い木片）、なければ弱い重力（ふわっと舞う粒）
- `dart`, `va` … これがあるときは、四角ではなく **ダーツ** を描く（向き・回る速さ）

`start()` の中の `bounce = null; rot = 0;` を、次のように **書きかえ** ます。

```js:game.js
    parts = []; bounce = null; rot = 0;
```

## onHit() で粒を出す

`onHit()` の中、`addScore(1);` の **下** に追加します。

```js:game.js
    for (let i = 0; i < 5; i++) parts.push({ x: CX, y: CY + R, vx: (Math.random() - 0.5) * 160, vy: Math.random() * 120 + 40, life: 0.4, c: '#d9a066', s: 3 });
```

まとの真下（刺さった場所）から、左右ランダム・少し下向きの速さで、木の色の小さな粒を5つ出します。

星を取ったときの `stars.splice(si, 1); addScore(5);` の行の **下** に追加します。

```js:game.js
      for (let i = 0; i < 14; i++) parts.push({ x: CX, y: CY + R + 10, vx: (Math.random() - 0.5) * 320, vy: (Math.random() - 0.5) * 320, life: 0.6, c: '#ffd36b', s: 4 });
```

こちらは上下左右すべての方向へ、金色の粒を14個。

## clearStage() でまとをはじけさせる

`clearStage()` を、次のように **書きかえ** ます。

```js:game.js
  function clearStage() {
    state = 'clear'; wheelAlive = false; timer = 1.1;
    addScore(stage * 5);
    for (let i = 0; i < 40; i++) {
      const a = Math.random() * Math.PI * 2, sp = 120 + Math.random() * 260;
      parts.push({ x: CX + Math.cos(a) * R * 0.6, y: CY + Math.sin(a) * R * 0.6, vx: Math.cos(a) * sp, vy: Math.sin(a) * sp - 80, life: 1, c: i % 3 ? '#b77b45' : '#ffcf8a', s: 6 + Math.random() * 6, g: 1 });
    }
    // stuck darts fly off too
    stuck.forEach((s) => {
      const a = s + rot;
      parts.push({ x: CX + Math.cos(a) * (R + 20), y: CY + Math.sin(a) * (R + 20), vx: Math.cos(a) * 260, vy: Math.sin(a) * 260 - 100, life: 1, dart: a, va: (Math.random() - 0.5) * 14, g: 1 });
    });
    stuck = [];
    showToast('CLEAR! +' + stage * 5);
  }
```

- 木片は、ランダムな角度 `a` の方向に、中心から外へ向かう速さ（`Math.cos(a) * sp`, `Math.sin(a) * sp`）で飛ばします。**放射状に飛び散る** 動きは、この「角度 → cos / sin」の形でいつも作れます。`- 80` で少し上向きに持ち上げると、はじけた感じが出ます
- 刺さっていたダーツも、それぞれの向きのまま外へ飛ばします。`dart: a` を持たせておくと、描くときにダーツの絵になります

## update() で粒を動かす

`update(dt)` の中、`if (bounce) { … }` のブロックの **下** に追加します。

```js:game.js
    parts.forEach((p) => {
      p.x += p.vx * dt; p.y += p.vy * dt; p.vy += (p.g ? 900 : 300) * dt; p.life -= dt;
      if (p.dart !== undefined) p.dart += p.va * dt;
    });
    parts = parts.filter((p) => p.life > 0);
```

ステップ5の「はじかれたダーツ」と同じ、速度と重力の計算です。寿命が切れた粒は `filter` で配列から取りのぞきます。こうしないと粒がたまり続けて、どんどん重くなってしまいます。

> [!NOTE]
> `p.dart !== undefined` と書いているのは、ダーツの向きが **0** のこともあるからです。`if (p.dart)` だと 0 は「なし」あつかいになってしまいます。

## draw() で粒を描く・ヒントを出す

`draw()` の中、`if (wheelAlive) { … }` のブロックの **下**、`// flying dart` の **上** に追加します。

```js:game.js
    // particles
    parts.forEach((p) => {
      ctx.globalAlpha = Math.max(0, Math.min(1, p.life * 2));
      if (p.dart !== undefined) drawDart(p.x, p.y, p.dart);
      else { ctx.fillStyle = p.c; ctx.fillRect(p.x - p.s / 2, p.y - p.s / 2, p.s, p.s); }
    });
    ctx.globalAlpha = 1;
```

`globalAlpha` は、このあと描くものの **不透明度**（0 で透明、1 で不透明）です。寿命が 0.5 秒を切ると `life * 2` が 1 より小さくなっていき、粒がだんだんうすくなって消えます。最後に 1 に戻すのを忘れないようにしましょう。

`draw()` の最後、外側の `ctx.restore();` の **下** に追加します。

```js:game.js

    // hint
    if (state === 'play' && stuck.length === 0 && left === total) {
      ctx.fillStyle = 'rgba(255,255,255,.55)'; ctx.font = '14px system-ui, sans-serif'; ctx.textAlign = 'center';
      ctx.fillText('タップで投げる', CX, H - 20);
    }
```

まだ1本も投げていなくて、じゃまダーツもない（＝ステージ1の最初）ときだけ、操作のヒントを出します。画面ゆれの影響を受けないよう、`restore()` のあとに描いています。

> [!CHECK] 動作チェック
> - スタート直後、画面の下に「タップで投げる」と出て、1本投げると消える
> - 刺さるたびに木くずが少し散る。星を取ると金色の粒が広がる
> - ステージクリアで、まとが木片になってはじけ、刺さっていたダーツもくるくる回りながら飛んでいく
