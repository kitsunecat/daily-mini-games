## このステップのゴール

「持っているダーツを全部刺したらステージクリア」という、ゲームの目標を作ります。

- 上の「のこり」に、持っているダーツの本数を棒で表示する
- 全部刺すとまとが消えて「CLEAR!」とボーナス点。少しおいて次のステージへ
- ステージが進むと、ダーツの本数・最初から刺さっているダーツ（じゃまもの）・回る速さが増える
- 5ステージごとに **BOSS STAGE**（まとのまん中が赤くなり、ダーツが1本多い）

## 変数をまとめて書きかえる

`let state = 'title'; …` から `let shake = 0, timer = 0;` までを、次のように **書きかえ** ます。

```js:game.js
  let state = 'title'; // title | play | clear | over
  let score = 0, stage = 1;
  let rot = 0, t = 0, spinBase = 1.6;
  let stuck = [];   // local angles of darts in the wheel
  let left = 0, total = 0;
  let flying = null; // {y}
  let bounce = null; // {x,y,vx,vy,a,va}
  let wheelAlive = true, shake = 0, timer = 0, ready = 0;
```

- `stage` … いまのステージ番号
- `total` … このステージで持っているダーツの本数、`left` … のこりの本数
- `wheelAlive` … まとがあるか。クリアの瞬間にまとがはじけて消えるので、その間は `false` にします
- `ready` … ステージ開始直後、次のダーツが下からせり上がってくる時間（秒）。この間は投げられません

## setupStage() … ステージの準備

`spinSpeed()` の **上** に追加します。

```js:game.js
  function setupStage() {
    const boss = stage % 5 === 0;
    total = Math.min(5 + stage, 11) + (boss ? 1 : 0);
    left = total;
    stuck = [];
    const pre = Math.min(stage - 1, 5);
    for (let i = 0; i < pre; i++) {
      let a, tries = 0;
      do { a = Math.random() * Math.PI * 2; tries++; } while (tries < 50 && stuck.some((s) => angDiff(s, a) < 0.6));
      stuck.push(a);
    }
    spinBase = (1.4 + Math.min(stage, 12) * 0.12) * (Math.random() < 0.5 ? 1 : -1);
    t = 0; wheelAlive = true; flying = null; ready = 0.25;
    stageEl.textContent = stage;
    renderDarts();
    showToast(boss ? 'BOSS STAGE!' : 'STAGE ' + stage);
  }
```

- `stage % 5 === 0` … 5, 10, 15 … のときにボス
- 本数は「5 + ステージ」で、11本で頭打ち（`Math.min`）。ボスはさらに +1
- `pre` は最初から刺さっているじゃまダーツの数です。ステージ1は0本、2なら1本 … 最大5本
- じゃまダーツどうしが近すぎるとすき間がなくなって投げられなくなるので、**やり直しの do-while** を使っています。ランダムな角度を選び、すでにあるダーツと 0.6 ラジアン以上はなれていなければ選び直します。運悪くずっと見つからないと止まらなくなるので、50回でやめます（`tries < 50`）
- 回る速さはステージごとに少しずつ上がり（12ステージで頭打ち）、`Math.random() < 0.5 ? 1 : -1` で **右回りか左回りかもランダム** にします

## のこりの表示と、一瞬だけ出るメッセージ

`spinSpeed()` の **下** に追加します。

```js:game.js
  function renderDarts() {
    let h = '';
    for (let i = 0; i < total; i++) h += '<i class="' + (i < total - left ? 'used' : '') + '"></i>';
    dartsEl.innerHTML = h;
  }

  let toastTimer = 0;
  function showToast(msg) {
    toast.textContent = msg; toast.classList.add('show');
    clearTimeout(toastTimer);
    toastTimer = setTimeout(() => toast.classList.remove('show'), 800);
  }
```

- `renderDarts()` は、`total` 本の `<i>` を並べます。使った本数（`total - left`）ぶんは `used` クラスで暗くなります（見た目は style.css で作ってあります）
- `showToast()` は、`show` クラスをつけて 0.8 秒後に外します。続けて呼ばれたとき前のタイマーが残っていると早く消えてしまうので、`clearTimeout` で前の予約を取り消してから新しく予約します

## start() と throwDart() を書きかえる

`start()` と `throwDart()` を、次のように **書きかえ** ます。

```js:game.js
  function start() {
    score = 0; stage = 1; scoreEl.textContent = 0;
    bounce = null; rot = 0;
    overlay.classList.add('hide');
    state = 'play';
    setupStage();
  }

  function throwDart() {
    if (state !== 'play' || flying || left <= 0 || ready > 0 || !wheelAlive) return;
    left--; renderDarts();
    flying = { y: THROW_Y };
  }
```

`stuck = []` は `setupStage()` がやるので、`start()` からは消しました。投げられない条件も増えています（のこりが0本、せり上がり中、まとがないとき）。

## クリアの判定

`onHit()` の最後、`addScore(1);` の **下** に1行追加し、`onHit()` の **下** に `clearStage()` を追加します。

```js:game.js
    if (left === 0) clearStage();
  }

  function clearStage() {
    state = 'clear'; wheelAlive = false; timer = 1.1;
    addScore(stage * 5);
    stuck = [];
    showToast('CLEAR! +' + stage * 5);
  }
```

最後の1本が刺さったらクリアです。ステージ番号 × 5 点のボーナスをもらい、まとを消して、1.1 秒の演出時間に入ります。

`showOver()` の `ovText.innerHTML = …` の行を、次のように **書きかえ** ます。

```js:game.js
    ovText.innerHTML = 'ステージ ' + stage + ' まで到達<br>スコア <b>' + score + '</b>';
```

## update() でせり上がりと次のステージ

`update(dt)` の中、`t += dt;` の **下** に1行追加します。

```js:game.js
    if (ready > 0) ready -= dt;
```

`if (shake > 0) shake -= dt;` の **下** に1行追加します。

```js:game.js
    if (state === 'clear') { timer -= dt; if (timer <= 0) { stage++; state = 'play'; setupStage(); } }
```

クリアの演出時間が終わったら、ステージを1つ進めて `setupStage()` を呼び、プレイに戻します。`'play' → 'clear' → 'play' …` と、`state` が場面をぐるぐる回していくのが分かりますね。

## draw() を書きかえる

まとがないときは描かないように、刺さったダーツとまとを `if (wheelAlive) { … }` で囲みます。ボスのときはまん中の色を赤くし、かまえのダーツを「せり上がり」させます。`draw()` を **まるごと書きかえ** ます。

```js:game.js
  function draw() {
    ctx.clearRect(0, 0, W, H);
    ctx.save();
    if (shake > 0) ctx.translate((Math.random() - 0.5) * 8, (Math.random() - 0.5) * 8);

    if (wheelAlive) {
      // stuck darts (behind wheel face edge)
      stuck.forEach((s) => {
        const a = s + rot;
        drawDart(CX + Math.cos(a) * (R - EMBED), CY + Math.sin(a) * (R - EMBED), a);
      });
      // wheel
      ctx.save(); ctx.translate(CX, CY); ctx.rotate(rot);
      const g = ctx.createRadialGradient(0, 0, 10, 0, 0, R);
      g.addColorStop(0, '#e0a86a'); g.addColorStop(1, '#9c6334');
      ctx.fillStyle = g; ctx.beginPath(); ctx.arc(0, 0, R, 0, Math.PI * 2); ctx.fill();
      ctx.strokeStyle = 'rgba(80,40,15,.45)'; ctx.lineWidth = 2;
      [0.75, 0.5, 0.25].forEach((k) => { ctx.beginPath(); ctx.arc(0, 0, R * k, 0, Math.PI * 2); ctx.stroke(); });
      ctx.strokeStyle = 'rgba(80,40,15,.3)';
      for (let i = 0; i < 8; i++) { const a = i * Math.PI / 4; ctx.beginPath(); ctx.moveTo(0, 0); ctx.lineTo(Math.cos(a) * R, Math.sin(a) * R); ctx.stroke(); }
      ctx.fillStyle = stage % 5 === 0 ? '#ff5a7a' : '#ff8fc8';
      ctx.beginPath(); ctx.arc(0, 0, 12, 0, Math.PI * 2); ctx.fill();
      ctx.strokeStyle = '#5a3416'; ctx.lineWidth = 4; ctx.beginPath(); ctx.arc(0, 0, R - 2, 0, Math.PI * 2); ctx.stroke();
      ctx.restore();
    }

    // flying dart (tip up)
    if (flying) drawDart(CX, flying.y - DART_LEN / 2, Math.PI / 2);
    if (bounce) drawDart(bounce.x, bounce.y, Math.PI / 2 + bounce.a);

    // ready dart
    if (state === 'play' && !flying && left > 0 && wheelAlive) {
      drawDart(CX, THROW_Y - DART_LEN / 2 + (ready > 0 ? ready * 120 : 0), Math.PI / 2);
    }
    ctx.restore();
  }
```

- かまえのダーツは `ready * 120` だけ下にずらして描きます。`ready` が 0.25 → 0 に減っていくので、30px 下から元の位置へスッと上がってきます
- `left > 0 && wheelAlive` の条件で、のこりがないときやクリア演出中はかまえのダーツを出しません

## タイトル画面の表示を直す

`// title preview` の下の行を、次のように **書きかえ** ます。

```js:game.js
  stuck = [0.3, 2.2, 4.1]; total = 0; left = 0;
```

タイトル画面では「のこり」に何も表示しないので、本数は 0 にしておきます。

> [!CHECK] 動作チェック
> - スタートすると「STAGE 1」と出て、「のこり」に黄色い棒が6本並ぶ。投げるたびに1本ずつ暗くなる
> - 6本全部刺すと、まとが消えて「CLEAR! +5」。少しすると「STAGE 2」になり、じゃまダーツが1本刺さった状態で始まる
> - ステージによって回る向きが変わることがある
> - ゲームオーバー画面に「ステージ 〇 まで到達」と出る
