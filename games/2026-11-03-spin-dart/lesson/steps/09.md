## このステップのゴール

最後の仕上げです。

- いちばん良かった点数（ハイスコア）を **localStorage** に保存して、ページを閉じても BEST に残るようにする
- **Web Audio API** で、投げる・刺さる・星・クリア・アウトの効果音を鳴らす

これで完成品と同じゲームになります。

## ハイスコアを読みこむ

`const HIT_GAP = 0.16, STAR_GAP = 0.22;` の行の **下** に、保存に使う名前を追加します。

```js:game.js
  const BEST_KEY = 'daily-mini-games:spin-dart:best';
```

`ctx.setTransform(dpr, 0, 0, dpr, 0, 0);` の行の **下** に追加します。

```js:game.js

  let best = 0;
  try { best = parseInt(localStorage.getItem(BEST_KEY), 10) || 0; } catch (e) { best = 0; }
  bestEl.textContent = best;
```

- `localStorage` は、ブラウザにサイトごとの小さなデータを保存できるしくみです。`setItem(名前, 文字列)` で保存、`getItem(名前)` で読み出せます。ページを閉じても残ります
- 同じサイトのほかのゲームと名前がぶつからないよう、`daily-mini-games:spin-dart:best` のように区切って名前をつけています
- 保存されるのは **文字列** なので、`parseInt(…, 10)` で10進数の数に直します。まだ保存されていないときは `null` になり、`parseInt` が `NaN` を返すので、`|| 0` で 0 にします
- プライベートブラウズなど、設定によっては localStorage を使うとエラーになることがあります。`try { … } catch (e) { … }` で囲んでおくと、エラーが起きてもゲームは止まりません

## ゲームオーバーで保存する

`gameOver()` を、次のように **書きかえ** ます。

```js:game.js
  function gameOver() {
    state = 'over'; timer = 0.9;
    if (score > best) {
      best = score; bestEl.textContent = best;
      try { localStorage.setItem(BEST_KEY, String(best)); } catch (e) { /* ignore */ }
    }
  }
```

`showOver()` の `ovText.innerHTML = …` の行を、ベストも出すように **書きかえ** ます。

```js:game.js
    ovText.innerHTML = 'ステージ ' + stage + ' まで到達<br>スコア <b>' + score + '</b>　ベスト <b>' + best + '</b>';
```

## 効果音の関数

さっき足した `bestEl.textContent = best;` の行の **下** に追加します。

```js:game.js

  // ---- audio ----
  let ac = null;
  function beep(freq, dur, type, vol) {
    try {
      if (!ac) ac = new (window.AudioContext || window.webkitAudioContext)();
      const o = ac.createOscillator(), g = ac.createGain();
      o.type = type || 'square'; o.frequency.value = freq;
      g.gain.setValueAtTime(vol || 0.08, ac.currentTime);
      g.gain.exponentialRampToValueAtTime(0.0001, ac.currentTime + dur);
      o.connect(g); g.connect(ac.destination);
      o.start(); o.stop(ac.currentTime + dur);
    } catch (e) { /* ignore */ }
  }
```

**Web Audio API** を使うと、音のファイルを用意しなくても、JavaScript だけで「ピッ」「ブーッ」という音を作れます。

- `AudioContext` … 音を作る作業場。最初に `beep()` が呼ばれたときに1回だけ作ります。ブラウザは **ユーザーがタップやキーを押したあと** でないと音を出させてくれないので、最初の音は「投げた瞬間」（＝タップの中）で作られるようにしています
- `createOscillator()` … 決まった高さの音を出し続ける発振器。`frequency` が音の高さ（Hz）、`type` が音色（`'square'` はピコピコ、`'triangle'` はやわらかめ、`'sawtooth'` はジャリッとした音）
- `createGain()` … 音量のつまみ。`exponentialRampToValueAtTime` で、`dur` 秒かけて音量をほぼ 0 まで下げると、「ポン」と自然に消える音になります
- 発振器 → 音量 → スピーカー（`ac.destination`）とつないで、`start()` で鳴らし、`stop()` で止める時刻を予約します

## 音を鳴らす

それぞれの場所に1行ずつ足していきます。

`throwDart()` の `flying = { y: THROW_Y };` の **下**（シュッ）:

```js:game.js
    beep(520, 0.05, 'triangle', 0.05);
```

`onHit()` のアウトのとき、`flying = null; shake = 0.3;` の **下**（ブーッ）:

```js:game.js
      beep(140, 0.35, 'sawtooth', 0.1);
```

`onHit()` の、ふつうに刺さったときの `addScore(1);` の **下**（トンッ）:

```js:game.js
    beep(300, 0.06, 'square', 0.06);
```

星を取ったときの `stars.splice(si, 1); addScore(5);` の **下**（キラリン）:

```js:game.js
      beep(880, 0.12, 'triangle', 0.08); setTimeout(() => beep(1320, 0.12, 'triangle', 0.06), 70);
```

`clearStage()` の `stuck = [];` の **下**（ピロン）:

```js:game.js
    beep(660, 0.1, 'square', 0.07); setTimeout(() => beep(990, 0.18, 'square', 0.07), 90);
```

星とクリアの音は、`setTimeout` で少しおくれて **高い音** をもう1つ鳴らしています。2つの音が上がっていくと、「うれしい」感じの音になります。

> [!CHECK] 動作チェック
> - 投げる・刺さる・星を取る・クリア・アウトで、それぞれちがう音が鳴る
> - ゲームオーバー画面に「ベスト」が出て、上の BEST の数字も更新される
> - ページを再読み込みしても、BEST の数字が残っている
> - 完成品の「くるくるダーツ」と同じように遊べる

## 改造アイデア

> [!TIP]
> **りんごを置く**: 星のかわりに、取るとコインが増える「りんご」を置いて、コインでダーツの色を変えられるようにしてみましょう。コインの枚数も localStorage に保存できます。

> [!TIP]
> **まとの形を変える**: `R` をステージごとに変えたり、ボスのときだけ大きなまとにしたりすると、刺せるすき間の広さが変わって難しさが変わります。`HIT_GAP` は角度なので、まとが大きいほど実際のすき間は広くなることに注目です。

> [!TIP]
> **新しい回り方**: `spinSpeed()` に `pattern === 3` を足して、「1秒ごとにピタッと止まる」（`Math.floor(t) % 2` を使う）など、自分だけの回り方を作ってみましょう。

> [!TIP]
> **連続ボーナス**: 星を連続で取ったら点数が倍になる、ステージをノーミスでクリアしたら +10 点、のようなコンボを足すと、もっとねらいたくなるゲームになります。
