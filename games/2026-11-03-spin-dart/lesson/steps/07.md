## このステップのゴール

ゲームに「ねらう楽しさ」と「変化」を足します。

- まとのふちに **星** をうかべ、星の真下に刺すと +5 点のボーナス
- ステージ3からは、回る速さが **速くなったり遅くなったり** する
- ボスステージでは、速くなって、遅くなって、**逆回転まで** する

## 星の当たりのはば

`const HIT_GAP = 0.16;` の行を、次のように **書きかえ** ます。

```js:game.js
  const HIT_GAP = 0.16, STAR_GAP = 0.22;
```

星はダーツより少し広め（約13度）にして、ねらいやすくしています。

## 変数を2つ足す

`let rot = 0, t = 0, spinBase = 1.6;` と、その下の `let stuck = [];` の行を、次のように **書きかえ** ます。

```js:game.js
  let rot = 0, t = 0, spinBase = 1.6, pattern = 0;
  let stuck = [];   // local angles of darts in the wheel
  let stars = [];   // local angles of bonus stars
```

- `pattern` … 回り方の種類（0: 一定、1: ゆらゆら、2: ボス）
- `stars` … 星の位置。刺さったダーツと同じく、**まとから見た角度** だけを持ちます

## setupStage() に星と回り方を足す

`setupStage()` の中を3か所変えます。

1. `stuck = [];` を `stuck = []; stars = [];` に **書きかえ** る
2. じゃまダーツを置く `for` ループの **下** に、星を置くコードを追加する
3. `spinBase = …` の行の **下** に、`pattern` を決める1行を追加する

変更後の `setupStage()` 全体はこうなります。

```js:game.js
  function setupStage() {
    const boss = stage % 5 === 0;
    total = Math.min(5 + stage, 11) + (boss ? 1 : 0);
    left = total;
    stuck = []; stars = [];
    const pre = Math.min(stage - 1, 5);
    for (let i = 0; i < pre; i++) {
      let a, tries = 0;
      do { a = Math.random() * Math.PI * 2; tries++; } while (tries < 50 && stuck.some((s) => angDiff(s, a) < 0.6));
      stuck.push(a);
    }
    const ns = Math.random() < 0.3 ? 2 : 1;
    for (let i = 0; i < ns; i++) {
      let a, tries = 0;
      do { a = Math.random() * Math.PI * 2; tries++; } while (tries < 50 && (stuck.concat(stars)).some((s) => angDiff(s, a) < 0.5));
      stars.push(a);
    }
    spinBase = (1.4 + Math.min(stage, 12) * 0.12) * (Math.random() < 0.5 ? 1 : -1);
    pattern = boss ? 2 : (stage >= 3 ? (stage % 2) : 0);
    t = 0; wheelAlive = true; flying = null; ready = 0.25;
    stageEl.textContent = stage;
    renderDarts();
    showToast(boss ? 'BOSS STAGE!' : 'STAGE ' + stage);
  }
```

- 星は 30% の確率で2個、それ以外は1個。じゃまダーツの上に星があると取れないので、`stuck.concat(stars)`（じゃまダーツと星を合わせた配列）のどれとも 0.5 ラジアン以上はなれた場所を選びます
- `pattern` は、ボスなら 2、ステージ3以上なら `stage % 2`（奇数ステージは 1 でゆらゆら、偶数は 0 で一定）、ステージ1・2は 0 です

## spinSpeed() … 回り方に変化をつける

`spinSpeed()` を、次のように **書きかえ** ます。

```js:game.js
  function spinSpeed() {
    if (pattern === 0) return spinBase;
    if (pattern === 1) return spinBase * (1 + 0.6 * Math.sin(t * 1.7));
    // boss: speeds up, slows, reverses
    return spinBase * 1.2 * Math.sin(t * 0.9) + spinBase * 0.35 * Math.sin(t * 3.1);
  }
```

`Math.sin()` は、-1 と 1 の間をなめらかに行ったり来たりする波です。経過時間 `t` を入れると、時間とともに速さが波打ちます。

- パターン1 … `1 + 0.6 * sin` は 0.4〜1.6 の間をゆれるので、「速い・遅い」をくり返します。向きは変わりません
- ボス … `sin` は **マイナスにもなる** ので、回る向きが反転します。速さのちがう2つの波（0.9 と 3.1）を足すと、規則が読みにくい、いやらしい動きになります

ステップ2で `spinSpeed()` という関数にしておいたので、`update()` は1文字も変えずに回り方だけを差しかえられました。

## onHit() で星を取る

`onHit()` の中、`addScore(1);` の **下**（`if (left === 0) clearStage();` の **上**）に追加します。

```js:game.js
    const si = stars.findIndex((s) => angDiff(s, local) < STAR_GAP);
    if (si >= 0) {
      stars.splice(si, 1); addScore(5);
      showToast('+5 ★');
    }
```

`findIndex` は、条件に合う最初の要素の **番号** を返します（なければ -1）。見つかったら `splice(番号, 1)` で配列からその星を1つ取りのぞき、5点を足します。

星はまとのふちの **外側** にうかんでいますが、判定は角度だけなので、星の真下に刺されば取れます。

## drawStar() … 星の形

`drawDart()` の **下**、`draw()` の **上** に追加します。

```js:game.js
  function drawStar(x, y, r) {
    ctx.beginPath();
    for (let i = 0; i < 10; i++) {
      const a = -Math.PI / 2 + i * Math.PI / 5, rr = i % 2 ? r * 0.45 : r;
      ctx.lineTo(x + Math.cos(a) * rr, y + Math.sin(a) * rr);
    }
    ctx.closePath(); ctx.fill();
  }
```

5つのとがった星は、**10個の点** を「外・内・外・内…」と交互につないだ形です。真上（`-Math.PI / 2`）から始めて 36度（`Math.PI / 5`）ずつ回りながら、偶数番目は半径 `r`、奇数番目は `r * 0.45` の点を打ちます。

## draw() で星を描く

`draw()` の中、`if (wheelAlive) {` の **すぐ下**（`// stuck darts` の上）に追加します。

```js:game.js
      // stars on rim
      stars.forEach((s) => {
        const a = s + rot;
        const x = CX + Math.cos(a) * (R + 14), y = CY + Math.sin(a) * (R + 14);
        ctx.fillStyle = '#ffd36b'; ctx.shadowColor = '#ffd36b'; ctx.shadowBlur = 10;
        drawStar(x, y, 11); ctx.shadowBlur = 0;
      });
```

ダーツと同じく「まとから見た角度 + `rot`」で今の向きを出し、ふちの 14px 外側に描きます。`shadowBlur` で同じ色の影をぼかすと、光っているように見えます。ほかの絵まで光らないよう、描いたらすぐ 0 に戻します。
