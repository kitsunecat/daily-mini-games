## このステップのゴール

すでに刺さっているダーツに当たったら **アウト** にします。はじかれたダーツがくるくる回りながら落ちていき、画面がゆれて、少しおいてからゲームオーバー画面が出ます。「もう一度」で何度でも遊べるようにします。

## 当たりのはば

`const THROW_Y = 520, THROW_SPEED = 2000;` の行の **下** に追加します。

```js:game.js
  const HIT_GAP = 0.16;
```

2本のダーツの角度の差が 0.16 ラジアン（約9度）より小さければ「ぶつかった」とします。大きくすると難しく、小さくするとやさしくなります。

## 変数と「角度の差」を出す関数

`let flying = null; // {y}` から `const norm = …` までを、次のように **書きかえ** ます。

```js:game.js
  let flying = null; // {y}
  let bounce = null; // {x,y,vx,vy,a,va}
  let shake = 0, timer = 0;

  const norm = (a) => { a %= Math.PI * 2; return a < 0 ? a + Math.PI * 2 : a; };
  const angDiff = (a, b) => { const d = Math.abs(norm(a) - norm(b)); return Math.min(d, Math.PI * 2 - d); };
```

- `bounce` … はじかれて落ちていくダーツ。位置 `x, y`、速度 `vx, vy`、向き `a`、回転の速さ `va` を持ちます
- `shake` … 画面をゆらす残り時間（秒）
- `timer` … 「ゲームオーバー画面を出すまで」などの待ち時間（秒）

### angDiff() … 角度の差は「近い回り方」で

角度 0.1 と 6.2 は、数字の差だと 6.1 ですが、1周が約 6.28 なので、実際には **となりどうし**（差は約 0.18）です。そこで、ふつうの差 `d` と「反対回りの差」`2π - d` の **小さいほう** を、本当の角度の差とします。円の上のものを比べるときに、とてもよく使う計算です。

## start() でリセット

`start()` の中の `stuck = []; rot = 0;` を、次のように **書きかえ** ます。

```js:game.js
    stuck = []; bounce = null; rot = 0;
```

## onHit() に当たり判定を足す

`onHit()` を、次のように **書きかえ**、その **下** に `gameOver()` と `showOver()` を追加します。

```js:game.js
  function onHit() {
    const local = norm(Math.PI / 2 - rot);
    if (stuck.some((s) => angDiff(s, local) < HIT_GAP)) {
      // fail
      bounce = { x: CX, y: CY + R + DART_LEN / 2, vx: (Math.random() - 0.5) * 200, vy: 380, a: 0, va: (Math.random() < 0.5 ? -1 : 1) * 12 };
      flying = null; shake = 0.3;
      gameOver();
      return;
    }
    stuck.push(local); flying = null; shake = 0.08;
    addScore(1);
  }

  function gameOver() {
    state = 'over'; timer = 0.9;
  }

  function showOver() {
    ovTitle.textContent = 'ゲームオーバー';
    ovText.innerHTML = 'スコア <b>' + score + '</b>';
    startBtn.textContent = 'もう一度';
    overlay.classList.remove('hide');
  }
```

- `stuck.some(…)` は、配列の中に **1つでも条件に合うものがあれば** `true` を返します。「刺さっているダーツのどれかと角度が近い」ならアウトです
- このゲームの当たり判定は、x・y の距離ではなく **角度の差だけ** で決まります。ダーツはいつも同じ場所（まとの真下）に刺さるので、比べるのは角度だけで十分なのです
- アウトのときは、はじかれたダーツを `bounce` に入れます。下向きの速さ `vy: 380` と、左右どちらかにランダムな速さ、くるくる回る速さ `va` をつけます
- 刺さったときも `shake = 0.08` と、ほんの少しだけゆらすと、「トンッ」という手ごたえが出ます
- `gameOver()` ではすぐ画面を出さず、`timer = 0.9` 秒待ちます。落ちていくダーツを見せてから結果を出すためです

## update() で落とす・ゆれを減らす・待つ

`update(dt)` の最後、`if (flying) { … }` のブロックの **下** に追加します。

```js:game.js
    if (bounce) {
      bounce.vy += 1400 * dt; bounce.x += bounce.vx * dt; bounce.y += bounce.vy * dt; bounce.a += bounce.va * dt;
      if (bounce.y > H + 80) bounce = null;
    }
    if (shake > 0) shake -= dt;
    if (state === 'over' && timer > 0) { timer -= dt; if (timer <= 0) showOver(); }
```

### 重力のしくみ

`vy += 1400 * dt`（速度に重力を足す）→ `y += vy * dt`（位置に速度を足す）、を毎フレームくり返すと、だんだん速く落ちる **放物線の動き** になります。画面の下まで落ちたら `null` にして消します。

`state === 'over'` の間も `update()` の `rot += …` は動いているので、ゲームオーバーになってもまとは回り続けます。

## draw() でゆらす・落ちるダーツを描く

`draw()` の外側の `ctx.save();` の **下** に1行追加します。

```js:game.js
    if (shake > 0) ctx.translate((Math.random() - 0.5) * 8, (Math.random() - 0.5) * 8);
```

毎フレーム、上下左右に最大 4px ずつランダムにずらすと、画面がガタガタゆれて見えます。最後の `ctx.restore()` で元に戻るので、ゆれるのはこの中で描いたものだけです。

`if (flying) drawDart(…);` の行の **下** に追加します。

```js:game.js
    if (bounce) drawDart(bounce.x, bounce.y, Math.PI / 2 + bounce.a);
```

> [!CHECK] 動作チェック
> - タイミングをずらしながら投げると刺さっていくが、すでに刺さっているダーツに当たると、ダーツがくるくる回りながら下に落ちていき、画面がゆれる
> - 1秒弱して「ゲームオーバー」とスコアが表示される
> - 「もう一度」（または Enter）で、空のまと・スコア 0 から遊び直せる
> - 普通に刺さったときも、画面がほんの少し「トンッ」とゆれる
