## このステップのゴール

飛んだダーツが **まとに刺さり、まとといっしょに回る** ようにします。刺さるたびに SCORE が 1 点ずつ増えます。タイトル画面では、最初から3本刺さったまとが回っているようにします。

このゲームでいちばん大事な考え方、「**まとから見た角度**」が出てきます。

## 変数と角度をそろえる関数

`let flying = null; // {y}` の行を、次のように **書きかえ** ます（上に2行、下に1行足します）。

```js:game.js
  let score = 0;
  let stuck = [];   // local angles of darts in the wheel
  let flying = null; // {y}

  const norm = (a) => { a %= Math.PI * 2; return a < 0 ? a + Math.PI * 2 : a; };
```

- `score` … 点数
- `stuck` … 刺さっているダーツの **角度** の配列。座標ではなく角度だけを持つのがコツです（このあと説明します）
- `norm(a)` … 角度を **0 以上 2π 未満** にそろえる関数。`rot` は回り続けるのでどんどん大きく（逆回転ならマイナスに）なりますが、角度は 2π ごとに同じ向きなので、`%`（割ったあまり）で1周の中に戻します。JavaScript の `%` はマイナスの数だとマイナスを返すので、そのときは 2π を足します

## 点数を足す関数と、スタート時のリセット

`start()` を、次のように **書きかえ**、その **上** に `addScore()` を追加します。

```js:game.js
  function addScore(n) { score += n; scoreEl.textContent = score; }

  function start() {
    score = 0; scoreEl.textContent = 0;
    stuck = []; rot = 0;
    overlay.classList.add('hide');
    state = 'play';
  }
```

点数を変えるときは必ず `addScore()` を通すことにすると、「変数は増えたのに画面の数字が変わらない」というミスを防げます。

## onHit() … 刺さった瞬間

`onHit()` を、次のように **書きかえ** ます。

```js:game.js
  function onHit() {
    const local = norm(Math.PI / 2 - rot);
    stuck.push(local); flying = null;
    addScore(1);
  }
```

### 「まとから見た角度」とは

ダーツはいつも **まとの真下** に刺さります。画面から見ると、その場所の角度は `Math.PI / 2`（真下）です。

でも、まとは回っています。まとに描いた模様から見ると、「真下」は回った分だけずれた場所です。まとが `rot` だけ回っているなら、まとの上での角度は `Math.PI / 2 - rot` になります。これを `stuck` に入れておけば、あとは

- 画面での角度 = まとから見た角度 + `rot`

で、いつでも今の位置が分かります。まとが回るたびにダーツの座標を計算し直す必要はなく、**角度を1つ持っておくだけ** で、ダーツはまとといっしょに回ってくれます。

## draw() で刺さったダーツを描く

`draw()` の中、外側の `ctx.save();` の **下**、`// wheel` の **上** に追加します。

```js:game.js
    // stuck darts (behind wheel face edge)
    stuck.forEach((s) => {
      const a = s + rot;
      drawDart(CX + Math.cos(a) * (R - EMBED), CY + Math.sin(a) * (R - EMBED), a);
    });
```

- 画面での角度 `a` の方向に、中心から `R - EMBED` 進んだ点が、ダーツの先端です（cos / sin で角度と距離から座標を出す、ステップ2と同じ計算）
- `drawDart()` の3つ目の引数は「先端から羽根へ向かう角度」でした。刺さったダーツの羽根は **中心から外向き** なので、そのまま `a` を渡せば OK です
- まとより **先に** 描くのがポイントです。あとからまとを上にぬるので、めりこんだ先端の部分がまとの下にかくれ、「刺さっている」ように見えます

## タイトル画面のおためし表示

`requestAnimationFrame(loop);`（ファイルの下のほう、`// ---- input ----` の上）の **上** に追加します。

```js:game.js
  // title preview
  stuck = [0.3, 2.2, 4.1];
```

タイトル画面で何も刺さっていないまとが回っているだけだと、どんなゲームか分かりにくいので、3本刺しておきます。スタートすると `start()` で `stuck = []` になって空のまとから始まります。
