## このステップのゴール

画面の上のほうに **木のまと** を描いて、くるくる回します。年輪のような同心円と、8本の放射線、まん中のピンクの点があるまとです。タイトル画面の後ろでも回り続けるようにします。

## まとの位置と大きさ

`const W = 360, H = 600;` の行の **下** に追加します。

```js:game.js
  const CX = 180, CY = 220, R = 74;
```

`CX`, `CY` はまとの中心、`R` は半径です。Canvas の座標は **左上が (0, 0)** で、右に行くほど x が、**下に行くほど y が大きく** なります。360 の半分の 180 が横のまん中、220 は上から少し下がった位置です。

## 回転の角度を持つ変数

`let state = 'title'; …` の行の **下** に追加します。

```js:game.js
  let rot = 0, t = 0, spinBase = 1.6;

  function spinSpeed() {
    return spinBase;
  }
```

- `rot` … まとがいま何ラジアン回っているか
- `t` … ステージが始まってからの経過時間（秒）。ステップ7で回り方に変化をつけるときに使います
- `spinBase` … 基本の回転の速さ（1秒あたりのラジアン）
- `spinSpeed()` … 「いまの回転の速さ」を返す関数。今は `spinBase` をそのまま返すだけですが、ステップ7で「速くなったり遅くなったり」をここに書き足します

角度の単位は **ラジアン** です。1周（360度）が `Math.PI * 2`（約6.28）なので、1.6 ラジアン/秒は「4秒弱で1周」くらいの速さです。

## update() で回す

`update(dt)` の中身を、次のように **書きかえ** ます。

```js:game.js
  function update(dt) {
    t += dt;
    if (state === 'play' || state === 'over' || state === 'title') rot += spinSpeed() * dt;
  }
```

「速さ × 経過時間」を毎フレーム `rot` に足していくだけで、なめらかに回ります。ステップ6で作るステージクリアの演出中（`'clear'`）だけは回さないので、回す場面を3つ並べて書いています。

## draw() でまとを描く

`draw()` を、次のように **まるごと書きかえ** ます。

```js:game.js
  function draw() {
    ctx.clearRect(0, 0, W, H);
    ctx.save();

    // wheel
    ctx.save(); ctx.translate(CX, CY); ctx.rotate(rot);
    const g = ctx.createRadialGradient(0, 0, 10, 0, 0, R);
    g.addColorStop(0, '#e0a86a'); g.addColorStop(1, '#9c6334');
    ctx.fillStyle = g; ctx.beginPath(); ctx.arc(0, 0, R, 0, Math.PI * 2); ctx.fill();
    ctx.strokeStyle = 'rgba(80,40,15,.45)'; ctx.lineWidth = 2;
    [0.75, 0.5, 0.25].forEach((k) => { ctx.beginPath(); ctx.arc(0, 0, R * k, 0, Math.PI * 2); ctx.stroke(); });
    ctx.strokeStyle = 'rgba(80,40,15,.3)';
    for (let i = 0; i < 8; i++) { const a = i * Math.PI / 4; ctx.beginPath(); ctx.moveTo(0, 0); ctx.lineTo(Math.cos(a) * R, Math.sin(a) * R); ctx.stroke(); }
    ctx.fillStyle = '#ff8fc8';
    ctx.beginPath(); ctx.arc(0, 0, 12, 0, Math.PI * 2); ctx.fill();
    ctx.strokeStyle = '#5a3416'; ctx.lineWidth = 4; ctx.beginPath(); ctx.arc(0, 0, R - 2, 0, Math.PI * 2); ctx.stroke();
    ctx.restore();

    ctx.restore();
  }
```

### translate と rotate … 紙ごと回す

まとを回すとき、模様の点を1つずつ計算して動かすのは大変です。そこで、**画用紙のほうを動かして回す** という考え方を使います。

- `ctx.translate(CX, CY)` … 座標の原点 (0, 0) を、まとの中心に移す
- `ctx.rotate(rot)` … そこを中心に、座標全体を `rot` ラジアン回す

このあとは「(0, 0) を中心に、回っていないまと」を描くだけで、画面には回ったまとが出ます。描き終わったら `ctx.restore()` で、移動と回転をなかったことにします。

### save と restore

`ctx.save()` は、いまの描画の設定（色・線の太さ・移動・回転など）を保存し、`ctx.restore()` で保存したときに戻します。入れ子にでき、内側の `save`〜`restore` がまとの回転用、外側はステップ5で「画面をゆらす」ときに使います。

### まとの模様

- `createRadialGradient(0, 0, 10, 0, 0, R)` … 中心から外へ向かう **円形グラデーション**。中が明るく外が濃い茶色で、木の丸太らしく見えます
- `arc(x, y, 半径, 開始角, 終了角)` … 円。`fill()` でぬり、`stroke()` で線だけを描きます。`[0.75, 0.5, 0.25].forEach(…)` で、半径を変えた円を3つ描いて年輪にしています
- 放射線は、角度 `a` の方向へ半径 `R` ぶん進んだ点 `(Math.cos(a) * R, Math.sin(a) * R)` まで線を引いています。**「角度と距離から座標を出す」cos / sin** は、このゲームでずっと使う計算です

> [!NOTE]
> Canvas では、角度 0 が **右向き**、角度が増えると **時計回り** に回ります（y が下向きのため）。つまり `Math.PI / 2`（90度）は **真下** です。ステップ4でこれが大事になります。
