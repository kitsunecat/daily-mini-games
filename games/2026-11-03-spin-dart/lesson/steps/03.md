## このステップのゴール

下にダーツを1本かまえて、**タップ・クリック・Space キー** で上へ投げられるようにします。ダーツがまとのふちまで届いたら、いったん消えるところまで作ります（刺さるのはステップ4）。

## ダーツの大きさと投げる速さ

`const CX = 180, CY = 220, R = 74;` の行の **下** に追加します。

```js:game.js
  const DART_LEN = 64, EMBED = 14;
  const THROW_Y = 520, THROW_SPEED = 2000;
```

- `DART_LEN` … ダーツの長さ（先端から羽根の端まで）
- `EMBED` … まとに **めりこむ深さ**。先端がふちから 14px 中に入ったところで止めます
- `THROW_Y` … かまえているダーツの **まん中** の y 座標
- `THROW_SPEED` … 飛ぶ速さ（1秒に 2000px）。かなり速くして「投げた瞬間に刺さる」感じにします

## 飛んでいるダーツの変数

`let rot = 0, t = 0, spinBase = 1.6;` の行の **下** に追加します。

```js:game.js
  let flying = null; // {y}
```

飛んでいるダーツがないときは `null`、飛んでいる間は `{ y: ダーツのまん中の y 座標 }` というオブジェクトを入れます。ダーツはいつも横のまん中（`CX`）をまっすぐ上に飛ぶので、持っておくのは y だけで十分です。

## throwDart() と onHit()

`start()` の **下** に追加します。

```js:game.js
  function throwDart() {
    if (state !== 'play' || flying) return;
    flying = { y: THROW_Y };
  }

  function onHit() {
    flying = null; // ステップ4で「刺さる」ようにする
  }
```

`throwDart()` の最初の行は **ガード節** です。「プレイ中でない」「もう1本飛んでいる」ときは何もせずに `return` します。こうしておくと、連打しても1本ずつしか飛びません。

## update() で飛ばす

`update(dt)` の最後（`rot += …` の行の **下**）に追加します。

```js:game.js
    if (flying) {
      flying.y -= THROW_SPEED * dt;
      if (flying.y - DART_LEN / 2 <= CY + R - EMBED) onHit();
    }
```

y を減らすと上に進みます。`flying.y` はダーツのまん中なので、**先端は `flying.y - DART_LEN / 2`** です。先端が、まとの一番下のふち（`CY + R`）より `EMBED` だけ上（まとの中）に入ったら `onHit()` を呼びます。1フレームで 2000 × 0.016 ≒ 33px も進むので、「ちょうど等しくなったら」ではなく `<=`（こえたら）で判定するのがポイントです。

## drawDart() … ダーツを描く関数

`update()` の **下**、`draw()` の **上** に追加します。

```js:game.js
  function drawDart(x, y, angle) {
    // angle: direction from tip to tail. Tip at (x,y).
    ctx.save(); ctx.translate(x, y); ctx.rotate(angle);
    // shaft along +x
    ctx.fillStyle = '#e8e8f0'; ctx.fillRect(0, -2, DART_LEN * 0.65, 4);
    ctx.fillStyle = '#9aa0b5'; ctx.beginPath(); ctx.moveTo(-2, 0); ctx.lineTo(10, -3.5); ctx.lineTo(10, 3.5); ctx.closePath(); ctx.fill();
    ctx.fillStyle = '#ff6fae'; ctx.fillRect(DART_LEN * 0.4, -3.5, DART_LEN * 0.22, 7);
    ctx.fillStyle = '#ffd36b';
    ctx.beginPath(); ctx.moveTo(DART_LEN * 0.65, 0); ctx.lineTo(DART_LEN, -10); ctx.lineTo(DART_LEN * 0.92, 0); ctx.lineTo(DART_LEN, 10); ctx.closePath(); ctx.fill();
    ctx.restore();
  }
```

ダーツは「**先端の座標** `(x, y)`」と「**先端から羽根へ向かう角度** `angle`」で描きます。まとと同じく `translate` と `rotate` で紙を動かし、その中では **先端を (0, 0)、羽根を +x 方向（右）** に置いた横向きのダーツを描いています。

- 銀色の細い四角 … 軸（シャフト）
- 先の三角 … 針
- ピンクの四角 … 持ち手
- 黄色の矢羽根 … `moveTo` / `lineTo` で4つの点をつないだ形

角度に `Math.PI / 2`（真下）を渡せば「先端が上、羽根が下」、つまり上に向かって飛ぶダーツになります。こうして **どの向きでも同じ関数で描ける** ようにしておくと、ステップ4で「まとに刺さって回るダーツ」もこの関数1つで描けます。

## draw() にダーツを足す

`draw()` の中、まとを描き終わった `ctx.restore();`（内側のほう）の **下**、最後の `ctx.restore();` の **上** に追加します。

```js:game.js
    // flying dart (tip up)
    if (flying) drawDart(CX, flying.y - DART_LEN / 2, Math.PI / 2);

    // ready dart
    if (state === 'play' && !flying) {
      drawDart(CX, THROW_Y - DART_LEN / 2, Math.PI / 2);
    }
```

先端の位置として `y - DART_LEN / 2` を渡しているので、ダーツのまん中がちょうど `y` にきます。`update()` の判定も同じ「先端 = `y - DART_LEN / 2`」で計算しているので、見た目と判定がそろいます。

## 入力 … タップ・クリック・キー

ファイルの最後、`startBtn.addEventListener(…)` の行の **下** に追加します。

```js:game.js
  $('stage').addEventListener('pointerdown', (e) => {
    if (e.target === startBtn) return;
    if (state === 'play') { e.preventDefault(); throwDart(); }
  });
  window.addEventListener('keydown', (e) => {
    if (e.code === 'Space') { e.preventDefault(); if (state === 'play') throwDart(); }
    if (e.code === 'Enter' && !overlay.classList.contains('hide')) { e.preventDefault(); start(); }
  });
```

- `pointerdown` は **Pointer Events** の1つで、マウスのボタンを押したときも、指で画面にふれたときも同じように届きます。`click` より早く反応するので、タイミングゲームに向いています
- Canvas だけでなく `#stage` 全体にイベントをつけて、まわりの余白をタップしても投げられるようにしています。スタートボタンを押したときは投げないよう、最初の行で除外します
- `e.preventDefault()` は、ブラウザが本来やる動き（Space でページをスクロール、タップでの選択など）を止めます
- `e.code` はキーの種類です。Enter はタイトル画面（オーバーレイが見えているとき）だけスタートにします

> [!CHECK] 動作チェック
> - スタートすると、画面の下に、先端を上に向けたダーツが1本かまえている
> - 画面をタップ（PC はクリックか Space）すると、ダーツが一瞬でまとのふちまで飛んで消え、すぐ次のダーツが現れる
> - タイトル画面で Enter を押してもスタートできる
