## このステップのゴール

3重のリングと、そこに並ぶ **8個×3本＝24個の色玉** を描きます。玉の色はランダムに決め、データ（配列）として持っておきます。まん中には回転の向きを表す矢印つきの「ハブ」も描きます。

ゲームづくりでは「**データ**（どこに何色の玉があるか）」と「**見た目**（それをどう描くか）」を分けて考えるのが大事です。このステップでそのデータの形を決めます。

## 変数を追加する

`let W = 0, H = 0, ...` の行と `let state = ...` の行を、次の4行に **書きかえます**。

```js:game.js
  let W = 0, H = 0, DPR = 1, cx = 0, cy = 0, R = 0;
  let grid = [];       // grid[ring][sector] = color index
  let state = 'title'; // title | play | over
  let score = 0, moves = START_MOVES, nColors = 4, chain = 0;
```

### grid … 盤面を2次元配列で持つ

`grid` は **配列の中に配列が入った「2次元配列」** です。`grid[リング番号][区画番号]` で、その場所の玉の **色番号**（`COLORS` の何番目か）が取り出せます。

- `grid[0]` … 内側のリングの8個（例: `[2, 0, 3, 1, 1, 0, 2, 3]`）
- `grid[2][5]` … 外側のリングの5番目の区画にある玉の色番号

色そのもの（`'#ff5a6e'` など）ではなく番号で持っておくと、「同じ色か？」を `===` で簡単に比べられます。

`score`（スコア）・`moves`（残り手数）・`nColors`（今使う色の数）・`chain`（連鎖の回数）もここでまとめて用意しておきます。使うのはあとのステップです。

## リングの大きさと盤面を作る関数

`window.addEventListener('resize', resize);` の行の **下** に追加します。

```js:game.js
  const ringRadius = (i) => R * (0.34 + 0.29 * i);
  const ballRadius = (i) => Math.min(R * 0.12, ringRadius(i) * Math.sin(Math.PI / N) * 0.78);

  function rnd() { return Math.floor(Math.random() * nColors); }

  function newBoard() {
    grid = [];
    for (let i = 0; i < RINGS; i++) {
      grid.push([]);
      for (let k = 0; k < N; k++) grid[i].push(rnd());
    }
  }
```

- `ringRadius(i)` … i 番目のリングの半径です。内側（i=0）は `R` の 34%、中は 63%、外側は 92% になります。`R` を基準にしているので、画面の大きさが変わっても形はそのまま拡大・縮小されます
- `ballRadius(i)` … i 番目のリングの玉の半径です。内側のリングは円周が短いので、玉を大きくしすぎると隣とぶつかります。円周を8等分したときの「となりの玉までの距離の半分」は `半径 × sin(π/8)` で計算できるので、その 78% にして少しすき間をあけます。外側のリングでは大きくなりすぎないよう `R * 0.12` で頭打ちにしています
- `rnd()` … 0〜`nColors - 1` のランダムな整数を返します。`Math.random()` は 0 以上 1 未満の小数なので、`nColors` 倍して `Math.floor` で切り捨てます
- `newBoard()` … 3本のリングそれぞれに、ランダムな色番号を8個ずつ入れます

## 区画の角度を求める関数

`start()` 関数の **下** に追加します。

```js:game.js
  function angleOf(k, r) { return (k + r) * (Math.PI * 2 / N) - Math.PI / 2; }
```

区画 `k` の玉が、円のどの角度にあるかを返します。Canvas の角度は **ラジアン**（1周 = `Math.PI * 2`）で、0 が右（3時の方向）、時計回りに増えていきます。1周を8等分すると1区画は `Math.PI * 2 / 8` なので、`k` 倍すれば k 番目の角度です。最後に `- Math.PI / 2`（90度）を引いて、**区画0が真上（12時）** に来るようにしています。

2つ目の引数 `r` は「何区画ぶんずらすか」です。今は 0 を渡しますが、ステップ5でリングをなめらかに回すときに使います。

角度が分かれば、玉の位置は三角関数で求められます。

- x 座標 = 中心 `cx` + `Math.cos(角度)` × 半径
- y 座標 = 中心 `cy` + `Math.sin(角度)` × 半径

## draw() にリングとハブを描く

`draw()` の背景を塗る行（`ctx.fillStyle = bg; ctx.fillRect(0, 0, W, H);`）の **下**（`draw()` の閉じかっこ `}` の手前）に追加します。

```js:game.js

    // rings
    for (let i = 0; i < RINGS; i++) {
      const rr = ringRadius(i);
      ctx.strokeStyle = 'rgba(255,255,255,.12)';
      ctx.lineWidth = ballRadius(i) * 2.4;
      ctx.beginPath(); ctx.arc(cx, cy, rr, 0, Math.PI * 2); ctx.stroke();
      ctx.strokeStyle = 'rgba(0,0,0,.25)';
      ctx.lineWidth = 2;
      ctx.beginPath(); ctx.arc(cx, cy, rr, 0, Math.PI * 2); ctx.stroke();
      const br = ballRadius(i);
      for (let k = 0; k < N; k++) {
        const a = angleOf(k, 0);
        ctx.fillStyle = COLORS[grid[i][k]];
        ctx.beginPath(); ctx.arc(cx + Math.cos(a) * rr, cy + Math.sin(a) * rr, br, 0, Math.PI * 2); ctx.fill();
      }
    }

    // hub
    const hr = ringRadius(0) * 0.5;
    ctx.fillStyle = '#2a2050';
    ctx.beginPath(); ctx.arc(cx, cy, hr, 0, Math.PI * 2); ctx.fill();
    ctx.strokeStyle = 'rgba(255,207,74,.6)'; ctx.lineWidth = 3; ctx.stroke();
    ctx.fillStyle = '#ffcf4a';
    ctx.font = 'bold ' + Math.round(hr * 0.42) + 'px system-ui, sans-serif';
    ctx.textAlign = 'center'; ctx.textBaseline = 'middle';
    ctx.fillText('↻', cx + hr * 0.38, cy);
    ctx.fillText('↺', cx - hr * 0.38, cy);
```

### リングの「レール」

`ctx.arc(cx, cy, 半径, 0, Math.PI * 2)` で円を作り、`ctx.stroke()` で線だけを描きます。1本目は線の太さを玉の直径より少し太く（`ballRadius(i) * 2.4`）して、うっすら白い **レール** にします。2本目は細い黒の線で、レールの中心を引きしめます。

`'rgba(255,255,255,.12)'` は「白を 12% の濃さで」という意味です。半透明にすると背景のグラデーションが透けて、なじみます。

### 玉

二重の `for` で、リング `i` の区画 `k` を全部まわります。`angleOf(k, 0)` で角度を出し、cos・sin で位置を計算して、`grid[i][k]` の色で塗りつぶした円（`ctx.fill()`）を描きます。

### ハブ

中心に小さな円を描き、左右に `↺`（反時計回り）と `↻`（時計回り）の矢印を置きます。「右側をタップすると時計回り」という操作のヒントを、絵でも伝えるためです。`textAlign = 'center'` と `textBaseline = 'middle'` で、文字の中心が指定した座標に来るようにしています。

## 最初に盤面を作る

ファイルの最後のほう、`resize();` と `loop();` の間に `newBoard();` を入れます。

```js:game.js
  resize();
  newBoard();
  loop();
```

タイトル画面のうしろにも盤面が見えるように、ページを開いた時点で一度作っておきます。
