## このステップのゴール

パッと一瞬で入れかわっていた玉を、**くるっとなめらかに回る** ようにします。回っている間はそのリングのレールを黄色く光らせ、回転が終わるまでは次の操作を受けつけないようにします。

ポイントは「**データはアニメーションが終わってから書きかえる**。それまでは見た目の角度だけをずらす」という考え方です。

## 変数を追加する

`let grid = [];` の行の **下** に2行追加します。

```js:game.js
  let rot = [0, 0, 0]; // animated rotation offset in sector units
  let anim = null;     // {ring, dir, t}
```

さらに `let score = 0, moves = ...` の行の **下** に1行追加します。

```js:game.js
  let busy = false;
```

- `rot` … リングごとの「見た目のずれ」を **区画の単位** で持ちます。`rot[2] = 0.5` なら、外側のリングを半マスぶん回した位置に描きます
- `anim` … 今動いている回転アニメーションの情報です。`ring`（どのリング）、`dir`（向き）、`t`（進み具合、0〜1）を持ちます。回っていないときは `null` です
- `busy` … 回転や消える演出の最中は `true` にして、その間の入力を無視します

## start() にリセットを追加する

`start()` の最初の行 `score = 0; moves = START_MOVES; nColors = 4; chain = 0;` を、次の2行に **書きかえます**。

```js:game.js
    score = 0; moves = START_MOVES; nColors = 4; chain = 0; busy = false; anim = null;
    rot = [0, 0, 0];
```

## turn() を書きかえ、finishTurn() を追加する

`function turn(ring, dir) { ... }` 全体を、次のコードに **書きかえます**。

```js:game.js
  function turn(ring, dir) {
    if (state !== 'play' || busy) return;
    busy = true;
    moves--;
    updateHud();
    anim = { ring, dir, t: 0 };
  }

  function finishTurn() {
    const { ring, dir } = anim;
    const old = grid[ring].slice();
    for (let k = 0; k < N; k++) grid[ring][(k + dir + N) % N] = old[k];
    rot[ring] = 0;
    anim = null;
    busy = false;
  }
```

`turn()` は、もう `grid` を書きかえません。`busy = true` にして、`anim` に「このリングをこの向きに回し始めたよ」と記録するだけです。`{ ring, dir, t: 0 }` は `{ ring: ring, dir: dir, t: 0 }` の省略した書き方です。

`finishTurn()` はアニメーションが終わったときに呼ばれ、ステップ4と同じやり方で **データを1マス回し**、同時に見た目のずれ `rot[ring]` を 0 に戻します。データが1マス進んだぶん、ずれを0に戻すので、見た目の位置は変わりません。これで「つなぎ目」が見えずになめらかに回ったように見えます。

`const { ring, dir } = anim;` は **分割代入** という書き方で、`const ring = anim.ring; const dir = anim.dir;` と同じ意味です。

## loop() でアニメーションを進める

`function loop() { ... }` 全体を、次のコードに **書きかえます**。

```js:game.js
  function loop() {
    if (anim) {
      anim.t += 1 / 9;
      const e = Math.min(1, anim.t);
      rot[anim.ring] = anim.dir * (1 - Math.pow(1 - e, 3));
      if (anim.t >= 1) finishTurn();
    }
    draw();
    requestAnimationFrame(loop);
  }
```

アニメーション中なら、毎フレーム `t` を 1/9 ずつ増やします。約9フレーム（60fps で 0.15 秒）で 1 になります。

### イージング … 動きに「緩急」をつける

`t` をそのまま `rot` に使うと、一定の速さでカクッと始まってカクッと止まります。そこで `1 - (1 - e)³` という式を通します。この式は、`e` が 0→1 に進むとき、**最初は速く、最後はゆっくり** 1 に近づきます。こうした「進み具合を変形する式」を **イージング** と呼び、この形は「ease-out（だんだん遅く）」と呼ばれます。

最後に `dir`（1 か -1）をかけて、回す向きを決めます。`t` が 1 以上になったら `finishTurn()` でデータを確定させます。

## draw() を書きかえる

`// rings` の中の、太いレールの色を決める行

```js:game.js
      ctx.strokeStyle = 'rgba(255,255,255,.12)';
```

を、次のように **書きかえます**。

```js:game.js
      ctx.strokeStyle = (anim && anim.ring === i) ? 'rgba(255,207,74,.55)' : 'rgba(255,255,255,.12)';
```

回っているリングだけ、レールを黄色く光らせます。`条件 ? A : B` は「条件が正しければ A、そうでなければ B」という **三項演算子** です。

さらに、玉を描くループの中の

```js:game.js
        const a = angleOf(k, 0);
```

を、次のように **書きかえます**。

```js:game.js
        const a = angleOf(k, rot[i]);
```

ステップ2で用意しておいた `angleOf` の2つ目の引数に `rot[i]` を渡すと、そのリングの玉が全部 `rot[i]` 区画ぶんずれた角度で描かれます。ガイド線は回したくないので `angleOf(k, 0)` のままです。

> [!CHECK] 動作チェック
> - リングをタップすると、玉が1マスぶんくるっとなめらかに回る（最初は速く、最後はふわっと止まる）
> - 回っている間、そのリングのレールが黄色く光る
> - 回転中に連打しても、回るのは1マスずつ（回り終わるまで次の操作を受けつけない）
> - 回り終わったあとの玉の並びは、ステップ4と同じように1マスずれている
