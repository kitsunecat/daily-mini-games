## このステップのゴール

最後の仕上げです。

- 手数が 0 になったら **ゲームオーバー** にして、スコアを表示する
- **ハイスコア** をブラウザに保存し、次に開いたときも残るようにする
- 「もう一度」ボタンや Enter キーで **リトライ** できるようにする
- 手数が残り少なくなったら MOVES を赤くして知らせる
- スコアが増えると **色の種類が増えて** 難しくなる

これで完成品と同じゲームになります。

## ハイスコアを読みこむ

`const N = 8;` の行の **上** に追加します。

```js:game.js
  const BEST_KEY = 'dmg-ring-turn-best';
```

`const SHAPES = [...]` の行の **下** に追加します。

```js:game.js

  let best = 0;
  try { best = parseInt(localStorage.getItem(BEST_KEY) || '0', 10) || 0; } catch (e) { best = 0; }
  $best.textContent = best;
```

### localStorage … ブラウザに小さなデータを保存する

`localStorage` は、ページを閉じても消えない、ブラウザの小さな保存場所です。`localStorage.setItem(キー, 文字列)` で保存し、`localStorage.getItem(キー)` で取り出します。

- 保存できるのは **文字列だけ** なので、取り出したら `parseInt(..., 10)` で数（10進数）に直します
- まだ一度も保存していなければ `getItem` は `null` を返すので、`|| '0'` で `'0'` にしておきます。さらに数に直せなかったとき（`NaN`）のために、最後にも `|| 0` をつけています
- キーの名前は、同じサイトのほかのゲームとぶつからないよう、ゲームごとにちがう名前（`dmg-ring-turn-best`）にします
- プライベートブラウズなどで localStorage が使えないとエラーになることがあるので、`try { ... } catch` で囲んでおきます

## updateHud() を書きかえる

`function updateHud() { ... }` 全体を、次のコードに **書きかえます**。

```js:game.js
  function updateHud() {
    $score.textContent = score;
    $moves.textContent = moves;
    $moves.parentElement.classList.toggle('low', moves <= 5);
    $best.textContent = best;
  }
```

`classList.toggle('low', 条件)` は、条件が正しければ `low` クラスをつけ、正しくなければ外します。`$moves.parentElement` は MOVES の数字を囲んでいる `<div class="stat">` で、ステップ1で書いた CSS の `.stat.low b { color: #ff6b7d; }` により、手数が 5 以下になると数字が赤くなります。

## gameOver() を追加する

`start()` 関数の **下**（`turn()` の上）に追加します。

```js:game.js

  function gameOver() {
    state = 'over';
    let isBest = false;
    if (score > best) {
      best = score; isBest = true;
      try { localStorage.setItem(BEST_KEY, String(best)); } catch (e) { /* ignore */ }
    }
    updateHud();
    $title.textContent = 'ゲームオーバー';
    $text.innerHTML = 'スコア <b class="hl">' + score + '</b>' + (isBest ? '<br>ハイスコア更新！' : '<br>ベスト ' + best);
    $start.textContent = 'もう一度';
    $overlay.classList.remove('hidden');
    beep(200, 0.4, 'sawtooth', 0.06);
  }
```

1. `state` を `'over'` にします。これで `turn()` や `handlePoint()` の最初の `if (state !== 'play') return;` に引っかかり、リングは回せなくなります
2. スコアが `best` より大きければ、`best` を書きかえて `localStorage` に保存します。`String(best)` で文字列にしてから保存します
3. オーバーレイの見出しと文章を書きかえ、ボタンの文字を「もう一度」にして、`hidden` クラスを外して表示します
4. 低い「ブーッ」という音を鳴らします

`innerHTML` は HTML として文字を入れるので、`<br>` や `<b>` が使えます。ここで入れているのは自分で計算した数字だけなので安全ですが、ユーザーが入力した文字をそのまま `innerHTML` に入れるのは危険なので避けましょう。

「もう一度」ボタンを押したときに呼ばれるのは、これまでどおり `start()` です。`start()` はスコア・手数・盤面・演出をすべて最初に戻すので、そのままリトライになります。オーバーレイの見出しや文章は書きかわったままですが、ゲーム中は隠れているので問題ありません。

## resolve() でゲームオーバーと色の追加を判定する

`resolve()` の最初の `if (!m.length) { ... }` の中を、次のように **書きかえます**。

```js:game.js
    if (!m.length) {
      busy = false;
      if (score >= 600 && nColors < 5) { nColors = 5; $hint.textContent = '新しい色が増えた！'; }
      if (score >= 2000 && nColors < 6) { nColors = 6; $hint.textContent = 'さらに色が増えた！'; }
      if (moves <= 0) setTimeout(gameOver, 300);
      return;
    }
```

もう消えるものがなくなった、つまり **1回の操作の結果がすべて出そろった** タイミングで判定します。

- スコアが 600 を超えたら色を5種類（紫・★）、2000 を超えたら6種類（オレンジ・＋）に増やします。色が増えると3つそろう確率が下がるので、だんだん難しくなります。`rnd()` は `nColors` を見ているので、これだけで新しく出てくる玉に新しい色がまざるようになります
- 手数が 0 以下ならゲームオーバー。`setTimeout` で 0.3 秒待ってから出すので、最後の回転の結果を一瞬見てから画面が切りかわります

判定を `turn()` ではなくここで行うのが大事です。最後の1手で色がそろえば手数が回復するので、「残り1手で回して手数が 0 になった → でもそろって +2 → まだ遊べる」という逆転が起こります。

## キーボードでリトライ

`window.addEventListener('keydown', ...)` の中の最初の行

```js:game.js
    if (state !== 'play') return;
```

を、次のように **書きかえます**。

```js:game.js
    if (state !== 'play') {
      if (e.key === 'Enter' || e.key === ' ') { e.preventDefault(); start(); }
      return;
    }
```

タイトル画面とゲームオーバー画面では、Enter キーかスペースキーでスタート（リトライ）できるようにします。`e.preventDefault()` で、スペースキーでページがスクロールするのを防ぎます。

> [!CHECK] 動作チェック
> - 手数が 5 以下になると、MOVES の数字が赤くなる
> - 手数が 0 になると「ゲームオーバー」の画面が出て、スコアが表示される
> - 初めて遊んだあとは「ハイスコア更新！」と出て、上の BEST にスコアが入る
> - ページを再読み込みしても、BEST に前回までの最高スコアが残っている
> - 「もう一度」や Enter / Space キーで、最初から遊べる
> - スコアが 600 を超えると「新しい色が増えた！」と出て、紫の★の玉が出てくるようになる
> - 完成品（このゲームのページ）と同じように遊べる

## 改造アイデア

> [!TIP] リングを4本にする
> `RINGS` を 4 にして、`ringRadius()` の係数（`0.34 + 0.29 * i`）を `0.3 + 0.22 * i` くらいに変えると、4つそろえるルールになります。`findMatches()` の判定も、全部のリングを `for` でまわして比べる形に書きかえてみましょう。ガイド線やフラッシュで使っている `ringRadius(2)` は `ringRadius(RINGS - 1)` に直します。

> [!TIP] 区画の数を変える
> `N` を 6 や 10 にすると、盤面の雰囲気ががらっと変わります。玉の大きさは `ballRadius()` が自動で計算してくれるので、ほかを直さなくても動きます。

> [!TIP] 時間制限モード
> 手数のかわりに「残り 60 秒」のタイマーにしてみましょう。`loop()` の中で経過時間を数えて減らし、0 になったら `gameOver()` を呼びます。消すと +3 秒、のように時間を回復させると、手数のときと同じバランスになります。

> [!TIP] ヒント機能
> 「あと1回まわせばそろう手」を探すには、6通りの手（3本のリング × 2方向）それぞれについて、`grid` のコピーを回してから `findMatches()` と同じ判定をすれば分かります。見つかった手のリングを光らせる、ヒントボタンを作ってみましょう。
