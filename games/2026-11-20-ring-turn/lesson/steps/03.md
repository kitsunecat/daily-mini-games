## このステップのゴール

ただの色つきの丸だった玉を、光が当たったような **立体的な玉** にします。さらに、色ごとに **白いマーク（●▲■◆★＋）** をのせて、色が見分けにくい人でも形で区別できるようにします。背景には、区画の境目を示すうすいガイド線も引きます。

## 形の一覧を追加する

`const COLORS = [...]` の行の **下** に追加します。

```js:game.js
  const SHAPES = ['circle', 'tri', 'square', 'diamond', 'star', 'plus'];
```

`COLORS[0]`（赤）には `SHAPES[0]`（丸）、`COLORS[1]`（黄）には `SHAPES[1]`（三角）…のように、**同じ番号どうしを組にして** 使います。色番号が分かれば、色もマークも決まります。

## 玉を描く関数を追加する

`// drawing` のコメントの **下**、`function draw() {` の **上** に、3つの関数を追加します。

```js:game.js
  function drawShape(shape, x, y, r) {
    ctx.beginPath();
    if (shape === 'circle') ctx.arc(x, y, r, 0, Math.PI * 2);
    else if (shape === 'tri') { for (let i = 0; i < 3; i++) { const a = -Math.PI / 2 + i * Math.PI * 2 / 3; ctx.lineTo(x + Math.cos(a) * r, y + Math.sin(a) * r * 1.05 + r * 0.12); } ctx.closePath(); }
    else if (shape === 'square') ctx.rect(x - r * 0.75, y - r * 0.75, r * 1.5, r * 1.5);
    else if (shape === 'diamond') { ctx.moveTo(x, y - r); ctx.lineTo(x + r, y); ctx.lineTo(x, y + r); ctx.lineTo(x - r, y); ctx.closePath(); }
    else if (shape === 'star') { for (let i = 0; i < 10; i++) { const a = -Math.PI / 2 + i * Math.PI / 5; const rr = i % 2 ? r * 0.45 : r; ctx.lineTo(x + Math.cos(a) * rr, y + Math.sin(a) * rr); } ctx.closePath(); }
    else { const t = r * 0.35; ctx.rect(x - t, y - r, t * 2, r * 2); ctx.rect(x - r, y - t, r * 2, t * 2); }
    ctx.fill();
  }

  function drawBall(x, y, r, c) {
    const g = ctx.createRadialGradient(x - r * 0.35, y - r * 0.4, r * 0.1, x, y, r);
    g.addColorStop(0, 'rgba(255,255,255,.9)');
    g.addColorStop(0.3, COLORS[c]);
    g.addColorStop(1, shade(COLORS[c]));
    ctx.fillStyle = g;
    ctx.beginPath(); ctx.arc(x, y, r, 0, Math.PI * 2); ctx.fill();
    ctx.fillStyle = 'rgba(255,255,255,.85)';
    drawShape(SHAPES[c], x, y, r * 0.42);
  }

  function shade(hex) {
    const n = parseInt(hex.slice(1), 16);
    const f = (v) => Math.round(v * 0.55);
    return 'rgb(' + f(n >> 16) + ',' + f((n >> 8) & 255) + ',' + f(n & 255) + ')';
  }
```

### drawShape() … 中心 (x, y)・大きさ r のマーク

`ctx.beginPath()` で新しい図形を始め、形ごとに線をつないで、最後に `ctx.fill()` で塗ります。

- **丸** … `arc` で円
- **三角** … 真上（`-Math.PI / 2`）から 120度（`Math.PI * 2 / 3`）ずつ回した3つの点を `lineTo` でつなぎます。三角形は重心が下にずれて見えるので、少しだけ下げて（`+ r * 0.12`）バランスをとっています
- **四角** … `rect(左上x, 左上y, 幅, 高さ)`
- **ひし形** … 上・右・下・左の4点をつなぎます
- **星** … 36度（`Math.PI / 5`）ずつ10個の点を回りながら、偶数番目は外側（`r`）、奇数番目は内側（`r * 0.45`）にとると、5つのとがりがある星になります
- **プラス** … 縦長と横長の長方形を2つ重ねます

`closePath()` は、最後の点から最初の点へ線を戻して図形を閉じる命令です。

### drawBall() … 立体的な玉

`createRadialGradient(x1, y1, r1, x2, y2, r2)` は「小さな円から大きな円へ」広がるグラデーションです。小さな円の中心を玉の **左上にずらす** のがポイントで、こうすると左上から光が当たってハイライトが光っているように見えます。

- 0（ハイライトの中心）… ほぼ白
- 0.3 … 本来の色
- 1（玉のふち）… 本来の色を暗くした色

最後に、半透明の白でマークをのせます。

### shade() … 色を暗くする

`'#ff5a6e'` のような色の文字列を、55% の明るさにした `'rgb(140,50,61)'` のような文字列に変えます。

1. `hex.slice(1)` で先頭の `#` を取り、`parseInt(..., 16)` で16進数として数に直します
2. `n >> 16` で上の8ビット（赤）、`(n >> 8) & 255` で真ん中（緑）、`n & 255` で下の8ビット（青）を取り出します。`>>` はビットを右にずらす演算、`& 255` は下8ビットだけを残す演算です
3. それぞれに 0.55 をかけて `rgb(...)` の形に組み立てます

色ごとに暗い色を手で用意しなくても、計算で作れるのが便利です。

## draw() を書きかえる

### ガイド線を追加

`draw()` の背景を塗る行（`ctx.fillStyle = bg; ctx.fillRect(0, 0, W, H);`）と `// rings` の間に追加します。

```js:game.js

    // sector guide lines
    ctx.strokeStyle = 'rgba(255,255,255,.07)';
    ctx.lineWidth = 2;
    for (let k = 0; k < N; k++) {
      const a = angleOf(k, 0);
      ctx.beginPath();
      ctx.moveTo(cx + Math.cos(a) * ringRadius(0) * 0.6, cy + Math.sin(a) * ringRadius(0) * 0.6);
      ctx.lineTo(cx + Math.cos(a) * (ringRadius(2) + R * 0.16), cy + Math.sin(a) * (ringRadius(2) + R * 0.16));
      ctx.stroke();
    }
```

8つの区画の方向に、中心近くから外側のリングの少し外まで、うすい線を引きます。「この線の上に3つの玉が並んだら消える」という目安になります。

### 玉の描き方を drawBall() に変える

`// rings` の中の、玉を描いている2行

```js:game.js
        ctx.fillStyle = COLORS[grid[i][k]];
        ctx.beginPath(); ctx.arc(cx + Math.cos(a) * rr, cy + Math.sin(a) * rr, br, 0, Math.PI * 2); ctx.fill();
```

を、次の1行に **書きかえます**。

```js:game.js
        drawBall(cx + Math.cos(a) * rr, cy + Math.sin(a) * rr, br, grid[i][k]);
```

> [!CHECK] 動作チェック
> - 玉の左上に白いハイライトがあり、ふちが暗くなって立体的に見える
> - 赤い玉には ●、黄色には ▲、緑には ■、青には ◆ の白いマークがのっている
> - 8方向にうっすらとガイド線が見える
