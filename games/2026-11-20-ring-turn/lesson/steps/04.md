## このステップのゴール

リングをタップ（クリック）して **1マス回せる** ようにします。右半分をタップすると時計回り、左半分なら反時計回り。PC ではキーボードの Q/W/E・A/S/D でも回せるようにします。1回まわすごとに手数（MOVES）が1減ります。

このステップでは、まず **データ（grid）を回す** ことだけに集中します。見た目のアニメーションは次のステップでつけるので、今は玉がパッと一瞬で移動します。

## updateHud() と start() を書きかえる

`function start() { ... }` 全体を、次のコードに **書きかえます**（`updateHud()` が増え、`start()` の中身も増えています）。

```js:game.js
  function updateHud() {
    $score.textContent = score;
    $moves.textContent = moves;
  }

  function start() {
    score = 0; moves = START_MOVES; nColors = 4; chain = 0;
    newBoard();
    state = 'play';
    $overlay.classList.add('hidden');
    $hint.textContent = '右側タップで時計回り、左側タップで反時計回り';
    updateHud();
  }
```

- `updateHud()` … 変数 `score`・`moves` の値を、上の表示（HUD）に書きこみます。HUD は「ヘッドアップディスプレイ」の略で、ゲーム画面に重ねる情報表示のことです。値を変えたら必ずこれを呼ぶ、と決めておくと表示がずれません
- `start()` … スコアと手数を最初に戻し、新しい盤面を作ってからゲームを始めます。あとで「もう一度」ボタンでも同じ関数を呼ぶので、ここで **全部をリセット** しておくのが大事です

## turn() … リングを回す

`start()` 関数の **下**（`angleOf` の上）に追加します。

```js:game.js

  function turn(ring, dir) {
    if (state !== 'play') return;
    moves--;
    updateHud();
    const old = grid[ring].slice();
    for (let k = 0; k < N; k++) grid[ring][(k + dir + N) % N] = old[k];
  }
```

`ring` は回すリングの番号（0〜2）、`dir` は向きで、`1` が時計回り、`-1` が反時計回りです。

### 配列をぐるっと回す

時計回りに1マス回すと、区画 `k` にあった玉は区画 `k + 1` に移ります。ただし最後の区画7の玉は、区画8ではなく **区画0** に戻らなければいけません。

そこで使うのが `%`（割った余り）です。`8 % 8` は `0` なので、`(k + 1) % N` とすれば 7 の次が 0 になります。反時計回り（`dir = -1`）のときは `0 - 1 = -1` になってしまいますが、先に `N` を足して `(k + dir + N) % N` とすれば `(0 - 1 + 8) % 8 = 7` となり、うまくいきます。

書きこみながら読むと、まだ読んでいない玉を上書きしてしまうので、`slice()` で **元の並びのコピー** `old` を作ってから、`old` を読んで `grid[ring]` に書きこみます。

## 入力を受け取る

`// input` のコメントから `$start.addEventListener(...)` の行までを、次のコードに **書きかえます**。

```js:game.js
  // input
  function handlePoint(x, y) {
    if (state !== 'play') return;
    const dx = x - cx, dy = y - cy;
    const d = Math.hypot(dx, dy);
    let ring = -1, bestD = Infinity;
    for (let i = 0; i < RINGS; i++) {
      const dd = Math.abs(d - ringRadius(i));
      if (dd < bestD) { bestD = dd; ring = i; }
    }
    if (d < ringRadius(0) * 0.45 || bestD > R * 0.2) return;
    turn(ring, dx >= 0 ? 1 : -1);
  }

  cv.addEventListener('pointerdown', (e) => {
    e.preventDefault();
    const r = cv.getBoundingClientRect();
    handlePoint(e.clientX - r.left, e.clientY - r.top);
  });
  $start.addEventListener('click', (e) => { e.stopPropagation(); start(); });
  window.addEventListener('keydown', (e) => {
    if (state !== 'play') return;
    const map = { q: [0, 1], w: [1, 1], e: [2, 1], a: [0, -1], s: [1, -1], d: [2, -1] };
    const v = map[e.key.toLowerCase()];
    if (v) { e.preventDefault(); turn(v[0], v[1]); }
  });
```

### pointerdown … マウスとタッチをまとめて受け取る

`pointerdown` は、マウスのボタンを押したときにも、指で画面に触れたときにも発生するイベントです。これ1つでパソコンとスマホの両方に対応できます。`e.preventDefault()` で、ブラウザが勝手にする動き（ダブルタップで拡大など）を止めます。

`e.clientX`・`e.clientY` はウィンドウの左上からの位置なので、Canvas の左上の位置（`r.left`・`r.top`）を引いて **Canvas の中での座標** に直してから `handlePoint()` に渡します。

### handlePoint() … どのリングをタップしたか

1. タップした点と中心との差 `dx`・`dy` から、`Math.hypot(dx, dy)` で中心からの距離 `d` を求めます（三平方の定理 √(dx² + dy²) と同じです）
2. 3本のリングの半径と `d` の差を比べて、**一番近いリング** を選びます
3. ただし、ハブのあたり（中心に近すぎる）や、どのリングからも遠すぎる場所（`R * 0.2` より離れている）は無視します
4. `dx >= 0`、つまり中心より **右** をタップしたら時計回り（`1`）、左なら反時計回り（`-1`）で `turn()` を呼びます

リングの細い線の上をぴったりタップしなくても、近いリングが選ばれるので、スマホの指でも操作しやすくなります。

### キーボード

`map` は「キーの文字 → [リング番号, 向き]」の対応表です。Q・W・E が内・中・外を時計回り、A・S・D がその反時計回りです。`e.key.toLowerCase()` で小文字にそろえるので、CapsLock がオンでも動きます。対応表にないキーなら `v` は `undefined` になり、何もしません。

> - キーボードの Q / W / E、A / S / D でも内・中・外のリングが回る
> - ハブ（中心）や、リングから遠い四すみをタップしても何も起きない
