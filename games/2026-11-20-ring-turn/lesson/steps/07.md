## このステップのゴール

そろった玉がパッと入れかわるだけでは、何が起きたか分かりにくく、気持ちよさもありません。そこで、

- そろった玉が **しぼんで消え**、新しい玉が **ふくらんで出てくる** アニメーション
- 消えた方向に走る **光の線**（フラッシュ）
- 「+30」「×2 連鎖」のような **得点のポップアップ**
- 回す・消す・スタートのときの **効果音**

を足して、手ごたえのあるゲームにします。

## 変数と効果音の関数を追加する

`let grid = [];` の行の **下** に1行追加します。

```js:game.js
  let scale = [];      // per slot scale for pop / spawn animation
```

`let busy = false;` の行の **下** に追加します。

```js:game.js
  let popups = [];
  let flashes = [];
  let audio = null;

  function beep(freq, dur, type, vol) {
    try {
      if (!audio) audio = new (window.AudioContext || window.webkitAudioContext)();
      const o = audio.createOscillator();
      const g = audio.createGain();
      o.type = type || 'sine';
      o.frequency.value = freq;
      g.gain.setValueAtTime(vol || 0.08, audio.currentTime);
      g.gain.exponentialRampToValueAtTime(0.0001, audio.currentTime + dur);
      o.connect(g); g.connect(audio.destination);
      o.start(); o.stop(audio.currentTime + dur);
    } catch (e) { /* ignore */ }
  }
```

- `scale` … `grid` と同じ形の2次元配列で、玉1つ1つの **大きさの倍率**（1 がふつう、0 で見えない）を持ちます
- `popups` … 画面に浮かんでいる得点表示のリスト
- `flashes` … 光の線のリスト

### Web Audio API で音を作る

音声ファイルを用意しなくても、ブラウザの **Web Audio API** で「ピッ」という音を作れます。

1. `AudioContext` … 音を鳴らすための作業場。最初に音を鳴らすときに1回だけ作ります（ブラウザは、ユーザーが一度タップするまで音を出させてくれないので、タップのあとで作るのが安全です）
2. `createOscillator()` … 発振器。`frequency`（周波数、Hz）で音の高さ、`type` で音色（`'sine'` やわらか、`'square'` ピコピコ、`'triangle'` その中間、`'sawtooth'` ビーッと強い）を決めます
3. `createGain()` … 音量つまみ。`exponentialRampToValueAtTime` で、`dur` 秒かけて音量をほぼ 0 まで下げると、「ポン」と自然に消える音になります
4. 発振器 → 音量 → スピーカー（`audio.destination`）の順につないで、`start()`・`stop()` します

古いブラウザなどで失敗してもゲームが止まらないよう、全体を `try { ... } catch` で囲んでいます。

## start() と turn() に追加する

`start()` 全体と `turn()` 全体を、次のように **書きかえます**（`rot` の行に2つ追加、`beep(...)` の行がそれぞれ1行ずつ増えています）。

```js:game.js
  function start() {
    score = 0; moves = START_MOVES; nColors = 4; chain = 0; busy = false; anim = null;
    rot = [0, 0, 0]; popups = []; flashes = [];
    newBoard();
    state = 'play';
    $overlay.classList.add('hidden');
    $hint.textContent = '右側タップで時計回り、左側タップで反時計回り';
    updateHud();
    beep(520, 0.12, 'triangle');
  }
```

```js:game.js
  function turn(ring, dir) {
    if (state !== 'play' || busy) return;
    busy = true;
    moves--;
    updateHud();
    anim = { ring, dir, t: 0 };
    beep(300 + ring * 90, 0.06, 'square', 0.04);
  }
```

回すときの音は `300 + ring * 90` Hz なので、内側ほど低く、外側ほど高い音になります。どのリングを回したか、耳でも分かります。

## resolve() に演出を入れる

`function resolve() { ... }` 全体を、次のコードに **書きかえます**。前半はステップ6と同じで、`updateHud();` より下が変わっています。

```js:game.js
  function resolve() {
    const m = findMatches();
    if (!m.length) {
      busy = false;
      return;
    }
    chain++;
    const gain = m.length * 30 * chain + (m.length >= 2 ? 20 * m.length : 0);
    score += gain;
    moves += m.length * 2 + (chain >= 2 ? 1 : 0);
    updateHud();
    m.forEach(k => {
      const a = angleOf(k, 0);
      const col = COLORS[grid[0][k]];
      flashes.push({ a, t: 0, col });
    });
    popups.push({ text: '+' + gain + (chain >= 2 ? '  ×' + chain + ' 連鎖' : ''), t: 0 });
    beep(600 + chain * 120, 0.18, 'triangle', 0.09);
    $hint.textContent = chain >= 2 ? chain + ' 連鎖！' : 'そろった！手数 +' + (m.length * 2);
    // pop animation
    let t = 0;
    const popStep = () => {
      t += 1 / 12;
      m.forEach(k => { for (let i = 0; i < RINGS; i++) scale[i][k] = Math.max(0, 1 - t); });
      if (t < 1) { requestAnimationFrame(popStep); return; }
      m.forEach(k => { for (let i = 0; i < RINGS; i++) { grid[i][k] = rnd(); scale[i][k] = 0; } });
      let s = 0;
      const growStep = () => {
        s += 1 / 10;
        m.forEach(k => { for (let i = 0; i < RINGS; i++) scale[i][k] = Math.min(1, s); });
        if (s < 1) { requestAnimationFrame(growStep); return; }
        setTimeout(resolve, 80);
      };
      requestAnimationFrame(growStep);
    };
    requestAnimationFrame(popStep);
  }
```

### フラッシュとポップアップを登録する

そろった区画ごとに、その方向の角度 `a` と、消える玉の色 `col` を `flashes` に追加します。色は玉を取りかえる **前に** 読んでおくのがポイントです。得点の文字は `popups` に追加します。どちらも `t`（0 から 1 へ進む寿命）を持たせ、描くのは `draw()` の仕事にします。

連鎖が続くほど `600 + chain * 120` Hz と音が高くなっていくので、連鎖の気持ちよさが増します。

### しぼむ → 取りかえ → ふくらむ

ステップ6ではすぐに玉を取りかえていましたが、ここでは2段階の小さなアニメーションにします。

1. `popStep` … 毎フレーム `t` を 1/12 ずつ増やし、そろった玉の `scale` を `1 - t` にして **しぼませます**。`t < 1` の間は `requestAnimationFrame(popStep)` で自分を呼び続けます
2. しぼみ切ったら、玉を新しい色に取りかえ、`scale` を 0 にします
3. `growStep` … 今度は `scale` を 0 から 1 へ **ふくらませます**
4. ふくらみ切ったら、少し間をおいて（80ミリ秒）`resolve()` をもう一度呼び、連鎖を調べます

`popStep` や `growStep` のように、関数の中で作った関数は、外側の変数（`m`・`t`・`s`）を覚えたまま何度でも呼べます。これを **クロージャ** と呼びます。おかげで「今どの区画を消しているか」を別の変数に保存しておかなくても済みます。

## draw() に演出を描く

### フラッシュ

ガイド線を描く `for` 文のあと、`// rings` の **上** に追加します。

```js:game.js

    // flashes for cleared sectors
    flashes = flashes.filter(f => f.t < 1);
    flashes.forEach(f => {
      f.t += 0.04;
      ctx.save();
      ctx.globalAlpha = 1 - f.t;
      ctx.strokeStyle = f.col;
      ctx.lineWidth = R * 0.22 * (1 - f.t * 0.5);
      ctx.lineCap = 'round';
      ctx.beginPath();
      ctx.moveTo(cx + Math.cos(f.a) * ringRadius(0), cy + Math.sin(f.a) * ringRadius(0));
      ctx.lineTo(cx + Math.cos(f.a) * ringRadius(2), cy + Math.sin(f.a) * ringRadius(2));
      ctx.stroke();
      ctx.restore();
    });
```

- `filter(f => f.t < 1)` で、寿命が終わったものをリストから取りのぞきます
- 残りは `t` を進めながら、内側のリングから外側のリングまで、太い線を消えた玉の色で描きます。`globalAlpha`（全体の不透明度）を `1 - t` にするので、だんだん透明になって消えます
- `lineCap = 'round'` で線の両はしを丸くします
- `ctx.save()` と `ctx.restore()` で囲むと、その間に変えた `globalAlpha` や線の設定が、あとで描く玉に影響しません

### 玉の大きさ

`// rings` の中の、玉を描くループ

```js:game.js
      for (let k = 0; k < N; k++) {
        const a = angleOf(k, rot[i]);
        drawBall(cx + Math.cos(a) * rr, cy + Math.sin(a) * rr, br, grid[i][k]);
      }
```

を、次のように **書きかえます**。

```js:game.js
      for (let k = 0; k < N; k++) {
        const s = scale[i][k];
        if (s <= 0.01) continue;
        const a = angleOf(k, rot[i]);
        drawBall(cx + Math.cos(a) * rr, cy + Math.sin(a) * rr, br * s, grid[i][k]);
      }
```

玉の半径に `scale` をかけます。ほとんど 0 のときは `continue` で描くのを飛ばします（半径 0 のグラデーションを作るとエラーになることがあるためです）。

### ポップアップ

`draw()` の最後、`ctx.fillText('↺', cx - hr * 0.38, cy);` の行の **下**（`draw()` の閉じかっこの手前）に追加します。

```js:game.js

    // popups
    popups = popups.filter(p => p.t < 1);
    popups.forEach(p => {
      p.t += 0.018;
      ctx.save();
      ctx.globalAlpha = Math.min(1, (1 - p.t) * 2);
      ctx.fillStyle = '#fff';
      ctx.font = 'bold ' + Math.round(R * 0.11) + 'px system-ui, sans-serif';
      ctx.textAlign = 'center';
      ctx.fillText(p.text, cx, cy - R * 1.02 + (1 - p.t) * 18 + R * 0.06);
      ctx.restore();
    });
```

リングの上に得点の文字を出します。`(1 - p.t) * 18` の部分で、時間がたつにつれて少しずつ **上へ浮かび** ます。`globalAlpha` を `(1 - t) * 2` にしているので、前半はくっきり、後半でだんだん消えます（`Math.min(1, ...)` で 1 を超えないようにしています）。約1秒（1 ÷ 0.018 ≒ 56 フレーム）で消えます。

> [!CHECK] 動作チェック
> - スタートすると「ポン」と音が鳴り、回すたびに短い音が鳴る（外側のリングほど高い音）
> - 色がそろうと、その方向に色つきの光の線が走り、玉がしぼんで消えてから新しい玉がふくらんで出てくる
> - リングの上に「+30」などの得点が浮かんで消える。連鎖すると「+60  ×2 連鎖」のように出る
> - 消える演出の最中はリングを回せない
