## このステップのゴール

3つのファイルを用意して、ゲーム画面の土台を作ります。上に「SCORE・MOVES・BEST」の表示、まん中にゲームを描く **Canvas**（キャンバス）とその上に重ねるタイトル画面（オーバーレイ）、下にひとことヒントを置きます。Canvas には、まず紫色の背景だけを描きます。

完成すると、こんなゲームになります。

- 画面の中心から **内・中・外の3重のリング** があり、それぞれに色玉が **8個ずつ** 並んでいる
- リングの **右半分をタップすると時計回り**、**左半分をタップすると反時計回り** に1マス回る
- 中心から同じ方向（放射状）に並んだ **内・中・外の3つの玉の色がそろうと消えて** スコアになる
- 1回まわすと手数（MOVES）が1減り、消すと手数が回復する。消えたあとの新しい玉でまたそろうと **連鎖**
- 手数が0になったらゲームオーバー。ハイスコアはブラウザに保存される

## game.js

JavaScript はまず「画面の大きさに合わせて Canvas を用意し、背景を描きつづける」ところまでを書きます。

```js:game.js
(() => {
  'use strict';
  const cv = document.getElementById('cv');
  const ctx = cv.getContext('2d');
  const $score = document.getElementById('score');
  const $moves = document.getElementById('moves');
  const $best = document.getElementById('best');
  const $overlay = document.getElementById('overlay');
  const $title = document.getElementById('ov-title');
  const $text = document.getElementById('ov-text');
  const $start = document.getElementById('start');
  const $hint = document.getElementById('hint');

  const N = 8;           // sectors per ring
  const RINGS = 3;
  const START_MOVES = 20;
  const COLORS = ['#ff5a6e', '#ffc93c', '#4fd18b', '#4aa8ff', '#c77dff', '#ff8f3c'];

  let W = 0, H = 0, DPR = 1, cx = 0, cy = 0, R = 0;
  let state = 'title'; // title | play | over

  function resize() {
    const r = cv.getBoundingClientRect();
    DPR = Math.min(window.devicePixelRatio || 1, 2);
    W = r.width; H = r.height;
    cv.width = Math.round(W * DPR); cv.height = Math.round(H * DPR);
    ctx.setTransform(DPR, 0, 0, DPR, 0, 0);
    cx = W / 2; cy = H / 2;
    R = Math.min(W, H) * 0.46;
  }
  window.addEventListener('resize', resize);

  function start() {
    state = 'play';
    $overlay.classList.add('hidden');
    $hint.textContent = '右側タップで時計回り、左側タップで反時計回り';
  }

  // input
  $start.addEventListener('click', (e) => { e.stopPropagation(); start(); });

  // drawing
  function draw() {
    ctx.clearRect(0, 0, W, H);
    // background
    const bg = ctx.createRadialGradient(cx, cy, 0, cx, cy, Math.max(W, H) * 0.7);
    bg.addColorStop(0, '#33275a'); bg.addColorStop(1, '#1a1330');
    ctx.fillStyle = bg; ctx.fillRect(0, 0, W, H);
  }

  function loop() {
    draw();
    requestAnimationFrame(loop);
  }

  resize();
  loop();
})();
```

### 全体を (() => { ... })(); で囲む

ファイル全体を「すぐ実行される関数」で囲むと、中で作った変数がページ全体（グローバル）に漏れません。`'use strict';` は、うっかりミスをエラーとして教えてくれるモードです。

### 要素と定数

`document.getElementById()` で HTML の要素を取り出し、変数に入れておきます。要素を入れた変数の名前の先頭に `$` をつけているのは「これは画面の部品だよ」と見分けやすくするための目印です（特別な意味はありません）。

- `N = 8` … 1本のリングに並ぶ玉の数（リングを8つの **区画** に分けます）
- `RINGS = 3` … リングの数（0 が内側、1 が中、2 が外側）
- `START_MOVES = 20` … 最初の手数
- `COLORS` … 玉の色。最初は前の4色だけを使い、スコアが増えると5色目・6色目が出てきます

### resize() … 画面の大きさから Canvas を準備する

1. `cv.getBoundingClientRect()` で、Canvas の実際の大きさ（CSS ピクセル）を測り、`W`・`H` に入れます
2. `devicePixelRatio`（DPR）は、高精細な画面で「CSS の 1px が実際は何ドットか」を表す数です。Canvas の中身のピクセル数（`cv.width`・`cv.height`）を DPR 倍にすると、ぼやけずにくっきり描けます。大きすぎると重くなるので 2 で頭打ちにしています
3. `ctx.setTransform(DPR, 0, 0, DPR, 0, 0)` は「これから描くものを全部 DPR 倍する」という設定です。これで、このあとは CSS ピクセルの座標のまま描けば、ちょうど画面に合います
4. `cx`・`cy` は画面の中心、`R` はリング全体の大きさの基準です。縦と横の短いほうの 46% にしておくと、縦長のスマホでも横長のパソコンでもはみ出しません

ウィンドウの大きさが変わったら（スマホを横にしたときなど）、もう一度 `resize()` を呼びます。

### draw() と loop() … 毎フレーム描きなおす

`draw()` は画面を全部消して（`clearRect`）、背景を描きます。`createRadialGradient` は **円形のグラデーション** で、中心が明るい紫、外側が暗い紫になります。

`loop()` は `draw()` を呼んだあと `requestAnimationFrame(loop)` で「次に画面を書きかえるタイミングで、もう一度 loop を呼んで」とブラウザに頼みます。これで1秒間に約60回、描きなおしが続きます。今は毎回同じ絵ですが、あとでリングが回ったり玉が消えたりするアニメーションを、この仕組みの上に作っていきます。

### start() とボタン

スタートボタンが押されたら `start()` を呼び、`state` を `'play'` にして、オーバーレイに `hidden` クラスをつけて隠します。`state` はゲームの状態で、`'title'`（タイトル画面）・`'play'`（プレイ中）・`'over'`（ゲームオーバー）のどれかになります。

`e.stopPropagation()` は、ボタンのクリックが下の要素に伝わらないようにするおまじないです。

> [!NOTE]
> `$score`・`$title`・`$text` などはまだ使っていませんが、先に取り出しておきます。あとのステップで使います。
